# Proposing a contribution sprint

This page is for advocates who want people to contribute together for a few hours. A sprint is your own initiative,
like a meetup ([Proposing a meetup](proposing-a-meetup.md)); no sprints are documented as official events. Its
result is real pull requests and confirmed issues.

## Choose a theme

| Theme | Good for | Guide |
|---|---|---|
| Documentation | Everyone | [Improving the help](improving-the-help.md) |
| Translation of one language | Native speakers | [Helping with translations](helping-with-translations.md) |
| Translation review | Native speakers | [Reviewing a machine-assisted translation](reviewing-a-machine-assisted-translation.md) |
| Confirming open issues | Users and administrators | [Reproducing and confirming issues](reproducing-and-confirming-issues.md) |
| Small fixes | Developers | [Develop with Git](../develop-with-git.md#contribute-a-change-with-a-pull-request) |
| Accessibility testing | Assistive technology users | [Advocating for accessibility](advocating-for-accessibility.md) |

## Prepare tasks

- A list of small, real tasks, each doable in under an hour, with a link (a help page to check, a set of strings, an
  issue to reproduce).
- A test installation per participant, or instructions to make one ([Install in one command](../../features/6.0/install-in-one-command.md)).
- GitHub accounts ready (with two-factor authentication).
- A shared, public task list (a forum thread works) without personal data.

## The agenda

```text
CONTRIBUTION SPRINT: <theme>                <date>, <time>, <place | online>   (organized by <you>)
0:00  Welcome, how to contribute (commit messages, pull requests, licenses)        15 min
0:15  Pick a task; pair newcomers with experienced people                          15 min
0:30  Work                                                                         2 h
2:30  Show and tell: what each pair did                                            20 min
2:50  Next steps; thanks                                                           10 min
```

## During the sprint

- Commit messages start with `Added:`, `Updated:`, `Fixed:`, `Removed:` or `Renamed:`
  ([CONTRIBUTING.md](https://github.com/se7enxweb/exponential/blob/main/CONTRIBUTING.md)).
- One small pull request per task.
- No secrets or personal data in changes, logs or screenshots.
- Security findings go privately ([Security reports stay private](security-reports-stay-private.md)).

## Wrap-up

1. Post the list of pull requests and confirmed issues in the forums.
2. Thank participants, by public handle and with consent ([Recognition ideas](recognition-ideas.md)).
3. Note what blocked people and improve the guides.

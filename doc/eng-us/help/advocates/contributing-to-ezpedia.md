# Contributing to eZpedia

This page is for advocates who like to document. eZpedia is the community encyclopedia: "The free eZ Publish
encyclopedia that anyone can edit", running since 2006 under the GNU Free Documentation License
([Community places](../who-is-the-exponential-foundation.md#community-places)). It keeps the knowledge of many years and
many people.

## What eZpedia is, and what it is not

| It is | It is not |
|---|---|
| A community wiki at [ezpedia.exponential.earth](https://ezpedia.exponential.earth/) | The official documentation of the current release |
| Under the GNU FDL | A place for security reports |
| Full of solutions, snippets and history from many years | Always up to date for Exponential 6 |

Its home page shows recently updated articles, recent discussions, recent development activity and an "Ask A Question"
section, and it has log-in and registration.

## eZpedia or the help?

| Your content | Put it in |
|---|---|
| How the current product works, for every user | The help, with a pull request ([Improving the help](improving-the-help.md)) |
| A snippet, a trick, a workaround, an experience | eZpedia |
| History, old versions, migration notes | eZpedia, linking the help's migration chapters |
| A question | The forums or eZpedia's question section |
| A bug | The issue tracker ([Which tracker for which report](which-tracker-for-which-report.md)) |

Both are free documentation under the GNU FDL, so text can move between them under the license's conditions.

## Getting started

1. Register or log in on [eZpedia](https://ezpedia.exponential.earth/).
2. Read a few recently updated articles to see the style.
3. Start small: fix an outdated link, add a version note, correct a typo.
4. Then write or update a whole article.

## What to contribute

| Contribution | Why |
|---|---|
| Add "Works with Exponential 6.0.x" or "Outdated since ..." notes to articles you tested | Readers know what still applies |
| Link old articles to the current help or feature page | Readers find the current way |
| Write up a solution you gave in the forums | The next person finds it |
| Document an extension you maintain | Users find it |
| Write a history article from the chronicle | Context for newcomers ([Writing history posts](writing-history-posts.md)) |

## Writing rules

- Test what you write on a current installation, and say which version.
- Cite the help or the repository where you can ([Where the facts live](where-the-facts-live.md)).
- No secrets, no personal data, no customer names without consent.
- Respect other people's edits; discuss in the page's discussion, kindly.
- Use the GNU FDL for your text (it is the site's license); do not paste text from sources with other licenses.

## The old name on eZpedia

eZpedia keeps the old name in its own title: "The free eZ Publish encyclopedia". Quote such titles as they are
([Brand and naming rules](../business/brand-and-naming-rules.md#the-old-name-ez-publish-only-as-history)). In your own
text, write **Exponential** for the current product and use the old name only for the past, for example "In the eZ
Publish years, this was done with ..." ([Writing about the history correctly](writing-about-the-history-correctly.md)).
Never rename code identifiers such as `eZContentObject`.

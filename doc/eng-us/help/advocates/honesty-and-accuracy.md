# Honesty and accuracy

This page is for every advocate. The documentation you cite holds itself to a rule: "Every statement names its source
... The page does not describe what the sources do not say"
([Who is the Exponential Foundation?](../who-is-the-exponential-foundation.md)). Hold yourself to the same rule.

## Five habits

1. **Check before you say it.** Open the source; memory drifts ([Where the facts live](where-the-facts-live.md)).
2. **Date your facts.** "On 18 October 2026, the kernel required 66 se7enxweb packages." Numbers change.
3. **Quote exactly.** Use quotation marks for quotes; paraphrase otherwise.
4. **Say what is not documented.** "The sources do not say" is an honest, complete answer.
5. **Correct openly** ([Claims you must not make](claims-you-must-not-make.md#when-you-got-it-wrong)).

## Fact or opinion?

| Fact (needs a source) | Opinion (say it is yours) |
|---|---|
| "Fifteen 6.0.x releases since 1 January 2024." | "I find the release pace reassuring." |
| "Exponential Intelligence writes drafts only." | "I like that a human stays in charge." |
| "The administration has a dark mode." | "It looks great in dark mode." |

Mark opinions with "I think", "for me", "in my experience".

## A fact-checking routine

```text
FOR EACH CLAIM IN MY POST / TALK
[ ] Source found and opened today: <link>
[ ] Source says exactly this (not more)
[ ] Number has a date
[ ] Name written correctly
[ ] Not on the "Claims you must not make" list
[ ] Opinions marked as mine
```

## Correcting yourself

A correction costs a minute and earns trust. Edit the post with a visible "Correction:" line, tell people who
repeated it, and update your notes so it does not happen again.

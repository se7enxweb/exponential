# Advocating for open source

This page is for advocates who want people and organizations to understand and practice open source, using Exponential
as the example. Exponential is free software under the GNU GPL version 2 or later, with free documentation under the
GNU FDL ([Talking points: open source and licensing](talking-points-open-source-and-licensing.md)).

## The values, in Exponential's terms

| Value | How Exponential shows it | Source |
|---|---|---|
| Freedom to use, study, change, share | GPL v2 or later | [LICENSE](https://github.com/se7enxweb/exponential/blob/main/LICENSE) |
| Transparency | A public history since 2002; every month told since 2023 | [The history](../../history/README.md) |
| Contributions stay free | Changes are released under the same GPL | [CONTRIBUTING.md](https://github.com/se7enxweb/exponential/blob/main/CONTRIBUTING.md) |
| Respect for contributors | Every pull request is merged under its author's name, once squashed and rebased onto `main` | [How the project grows](../who-is-the-exponential-foundation.md#how-the-project-grows) |
| Credit | Work of Netgen, Mugo Web, CJW Network credited by name | [Respecting other projects](respecting-other-projects-and-companies.md) |
| Giving back upstream | Security pull requests to Zeta Components | [The PHP stack](../who-is-the-exponential-foundation.md#the-php-stack-it-stands-on-and-gives-back-to) |
| Free knowledge | Documentation under the GNU FDL | [Free documentation](../free-documentation.md) |

## Arguments for organizations

- **Independence**: the code outlived its original vendor because it is free; no single company can take it away.
- **Inspection**: security teams can read every line and every change.
- **Choice of provider**: anyone may host, support and extend it.
- **Shared cost**: a fix one organization pays for helps everyone, and everyone else's fixes help them.

Contributing back is also cheaper: a fix sent upstream "reaches every site in the next release" and does not have to be
carried forever ([Even better: send the fix](../when-something-goes-wrong.md#even-better-send-the-fix)); see
[Working with the community and contributing back](../leadership/working-with-the-community.md#why-contributing-back-pays-off-for-a-project).

## First steps to suggest

1. Install with Git clones from day one ([Develop with Git](../develop-with-git.md)).
2. Adopt a contribution policy ([A team contribution policy](../leadership/working-with-the-community.md#a-team-contribution-policy-to-adapt)).
3. Budget time for upstream fixes in every project.
4. Sponsor the work you depend on.

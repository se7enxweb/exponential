# Answering questions well

This page is for advocates who answer questions in the forums, the chat, at work or at events. A good answer solves
the problem, teaches where to look next time, and stays useful for the next reader.

## The five steps

1. **Understand.** Restate the question in one line. If unsure, ask.
2. **Answer briefly.** One or two sentences first.
3. **Cite.** Link the help page or source ([Pointing to the right help page](pointing-to-the-right-help-page.md)).
4. **Date it.** "Checked on Exponential 6.0.x."
5. **Follow up.** Ask if it worked; post the final solution.

## Clarifying questions

```text
Which version of Exponential do you run? (Setup > System information shows it)
Which database, PHP version and engine (Velocity, FrankenPHP, Apache/nginx with PHP-FPM)?
Which administration design (admin4, classic, AdminUI)?
What exactly did you do, and what exactly happened (the message)?
Did it work before? What changed?
```

Remind people to leave out passwords, keys and personal data
([When something goes wrong](../when-something-goes-wrong.md#a-good-bug-description)).

## Patterns for common questions

| Question type | Pattern |
|---|---|
| "How do I ...?" | Steps + help page link |
| "Why does X happen?" | Likely cause + how to check + link |
| "Is X possible?" | Yes/no + how + link; if no, say so and offer what exists |
| "Something broke" | Clarifying questions; if it is a bug, point to the tracker ([Reporting bugs well](reporting-bugs-well.md)) |
| "Which should I choose?" | Ask about needs + link the comparison pages ([Knowing the product family](knowing-the-product-family.md)) |
| A security problem | Stop; route privately ([Security reports stay private](security-reports-stay-private.md)) |

```text
HOW-TO ANSWER
Short answer: <answer>.
Steps:
1. <...>
2. <...>
Details in the help: "<page>" (<link>). Checked on Exponential <6.0.x>.

"NOT POSSIBLE" ANSWER
As far as I know, Exponential doesn't <X>. The closest is <Y> (<link>). If you need X, you could
propose it in the community tracker: <link>.
```

## When not to answer

- You are guessing. Say "I'm not sure" or let someone else answer.
- The question is about a person or a private matter.
- It is a sales question for a provider: point to the provider, disclose if it is you
  ([Disclosure and conflicts of interest](disclosure-and-conflicts-of-interest.md)).

# Naming rules quick card

This page is for advocates who need the names right in a hurry. It condenses the full
[Brand and naming rules](../business/brand-and-naming-rules.md) into one screen. Print it or keep it open while you
write.

## The card

```text
NAMING QUICK CARD                                                    Exponential advocates

THE PRODUCT
  Exponential                      the product; capital E; no article ("Exponential publishes ...")
  Exponential 6, Exponential 6.0.x the major line          Exponential 6.0.15   a release (no "v" in text)
  v6.0.14                          only as a Git tag

THE FAMILY
  Exponential Basic | Exponential Platform 3.2.9 | Exponential Platform Legacy | Exponential Platform Nexus
  Exponential Platform DXP | Exponential Velocity (Velocity) | Exponential Intelligence (expai)
  Exponential Layouts (the layouts editor) | AdminUI | the help system

THE ORGANIZATIONS
  7x                               the company that leads Exponential (digit 7, lowercase x)
  se7enx.com                       7x's domain        se7enxweb    GitHub account and Composer vendor
  the Exponential Foundation       the nonprofit that operates and funds the project
  7x & Exponential Foundation      the copyright holder, exactly like this

THE PAST
  eZ Publish                       only in the past tense: "while the software was still called eZ Publish"
  Brookins Consulting              only as history: "7x used to be Brookins Consulting"
  eZ Systems, Ibexa                factual only; Exponential is NOT associated with them

NEVER RENAME IN CODE
  eZContentObject  eZINI  eZDB  ezcontentobject  bin/php/ezcache.php  ezwebin  eztags  ezflow

SPELLING
  American English: license, color, behavior, organization
```

## Five rules

1. **Exponential is the product.** Not "eZ Exponential", not "Exponential Publish", not "the Exponential".
2. **Two organizations.** 7x is the company; the Exponential Foundation is the nonprofit. Never "the 7x Foundation".
3. **The old name is history.** Use it only in the past tense, and quote historic titles as they are (eZpedia,
   "Learning eZ Publish").
4. **Rename the product, never a symbol.** `eZ` alone is a code prefix
   ([Code identifiers stay as they are](../business/brand-and-naming-rules.md#code-identifiers-stay-as-they-are)).
   In code 7x is `sevenx` (its official public PHP code prefix, since a name cannot start with a digit) or `exp`,
   which 7x uses with intent for work it assigns to the Exponential project and the Exponential Foundation
   ([Naming prefixes](../../standards/naming-prefixes-sevenx-and-exp.md)).
5. **Credit others by their names.** Netgen, Mugo Web, CJW Network
   ([Other companies and products](../business/brand-and-naming-rules.md#other-companies-and-products)).

## Spot the mistake

Each line has one mistake. Answers below.

```text
1. "eZ Publish 6 is out!"
2. "The 7x Foundation sponsors the project."
3. "Exponential AI writes your content."
4. "Install ExponentialContentObject from the docs."
5. "The colour of the admin is customisable."
6. "Exponential Qbix is the new server."
7. "7x owns Exponential."
```

Answers: 1. Exponential 6. 2. The Exponential Foundation (a separate nonprofit). 3. Exponential Intelligence, and it
writes drafts only. 4. `eZContentObject` is the real class; never rename code. 5. color, customizable. 6. Exponential
Velocity. 7. 7x leads Exponential; the copyright is shared and the license is GPL.

# Talking points: Exponential Layouts

This page is for advocates who show editors and designers how pages are built. Exponential Layouts is "a visual page
builder for Exponential. It brings the concept of the upstream layouts packages to the Exponential kernel: a layout is a saved
arrangement of blocks in zones, and a rule decides which pages get it"
([Exponential Layouts](../who-is-the-exponential-foundation.md#exponential-layouts)).

## The concepts in plain words

| Word | Plain meaning | Source |
|---|---|---|
| Layout | A saved arrangement of a page | [The layouts editor, Layouts, zones and blocks](../layouts-editor.md#layouts-zones-and-blocks) |
| Zone | An area of the page, such as header, main or sidebar | same |
| Block | One piece in a zone: a title, a list, a gallery, some text | same |
| Mapping | The rule that decides which pages use a layout: a location, a subtree, a content type or a siteaccess | [Which pages use a layout](../layouts-editor.md#which-pages-use-a-layout) |
| Shared layout | A layout, such as header and footer, that other layouts link to instead of copying | [Demo scripts, Part 2](../business/demo-scripts.md#part-2-the-layouts-editor-4-minutes) |

## A one-minute demo

On an installation you control:

1. **Layouts** tab, **Layouts**, **Open** a layout.
2. **Add a block**, drag a **Title** block into a zone, type a title.
3. Drag the block to another zone.
4. Point at a linked zone: "This comes from the shared header and footer."
5. **Discard** and confirm: "Nothing changed on the site."

Longer: [Demo scripts, Part 4: layouts, end to end](../business/demo-scripts.md#part-4-layouts-end-to-end-6-minutes).

## Credit where it is due

Exponential Layouts is a port of the concept of the upstream layouts packages to the Exponential kernel. When you present it, say so:
"It brings the concept of the upstream layouts packages to Exponential." Crediting the work of others is part of the project's
practice ([How the project grows](../who-is-the-exponential-foundation.md#how-the-project-grows),
[Respecting other projects and companies](respecting-other-projects-and-companies.md)).

Do not call it "Netgen Layouts for Exponential": it has its own name
([Brand and naming rules, Do and Don't](../business/brand-and-naming-rules.md#do-and-dont)).

## Do not say

- "Editors never need a developer again." Developers still build block templates and the design.
- "It works the same on every distribution." DXP ships no layouts editor.
- "Any page can be changed by anyone." Roles decide who may edit layouts.

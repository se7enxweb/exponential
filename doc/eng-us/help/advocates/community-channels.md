# The community channels

This page is for advocates who send people to the right place. It lists only the channels the documentation names.
Do not send people anywhere else in the project's name, and do not create "official" channels yourself.

## Where to send whom

| Someone wants to | Send them to |
|---|---|
| Learn what Exponential is | [Who is the Exponential Foundation?](../who-is-the-exponential-foundation.md) |
| Try it | [Getting started](../getting-started.md), [Install in one command](../../features/6.0/install-in-one-command.md) |
| Ask "how do I ...?" | The help first, then the forums or Telegram |
| Report a bug | The help's **Report an error** page and the right tracker |
| Report a security problem | Privately, as `SECURITY.md` describes |
| Suggest an idea for the project or website | The community issue tracker |
| Share an extension | Projects |
| Share a tutorial or post | Share |
| Document a trick | eZpedia |
| Fund the work | The sponsor pages |

## Channels named without an address

"Discord and Slack" are "named among the support channels" on
[exponential.earth/about/project](https://exponential.earth/about/project); the documentation gives no addresses for
them ([Community places](../who-is-the-exponential-foundation.md#community-places)). If you need them, find the link on
that page; do not pass on addresses from elsewhere as official.

## Private channels

| Need | Channel |
|---|---|
| A security vulnerability | security@se7enx.com or GitHub's private vulnerability reporting ([SECURITY.md](https://github.com/se7enxweb/exponential/blob/main/SECURITY.md)) |
| A question to the Foundation | Its website, [foundation.exponential.earth](https://foundation.exponential.earth/) |
| Services from 7x | [se7enx.com](https://se7enx.com/) |

## What is not documented

- No conferences or meetups are documented ([Community places](../who-is-the-exponential-foundation.md#community-places)).
  If you organize one, present it as yours ([Proposing a meetup](proposing-a-meetup.md)).
- No official social media accounts, hashtags, mailing lists or ambassador programs are named in the sources.
- No certification is documented.

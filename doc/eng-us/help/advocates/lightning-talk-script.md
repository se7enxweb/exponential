# Lightning talk script

This page is for advocates who have five minutes on a stage, at a meetup or in a team meeting. It gives six slides, a
script you can read or adapt, the timing, and the source of every sentence. Five minutes is about 650 spoken words;
the script below has fewer, so you can breathe.

## The script

**Slide 1 (0:00).** "Hi, I'm <name>. I use Exponential for <your use>. I'm not paid by anyone to say this; I just like
it. Five minutes, here we go."

**Slide 2 (0:20).** "Exponential is a PHP application framework with a full content management system. Its best
feature is the content model: you define your own content types, an article, a product, an event, in the
administration, without code. It comes with a shop, it serves several sites from one installation, and it speaks many
languages, including right to left."

**Slide 3 (1:10).** "Some of you know this code under an older name. Its original vendor discontinued it after almost
eighteen years. The code is free, so it carried on: 7x took over leadership in 2023, and since January 2024 there have
been fifteen 6.0.x releases. Since this year a nonprofit, the Exponential Foundation, operates the project."

**Slide 4 (2:10).** "What's new in the current line? Velocity, a PHP web server that keeps the application loaded.
Exponential Layouts, a visual page builder for editors. Exponential Intelligence, a writing assistant that only writes
drafts and never publishes on its own. And the help: the documentation is inside the administration, with a help
button on every page."

**Slide 5 (3:30).** "It's free software: the code under the GPL, the documentation under the GNU Free Documentation
License. And the project has a rule I love: every pull request is merged, under the contributor's name."

**Slide 6 (4:20).** "Try it: one command installs a complete site on SQLite, no database server. Questions: the forums
on share.exponential.earth and the Telegram chat. Thank you!"

## Rehearsal checklist

```text
[ ] Read the script aloud three times, timed: under 5:00
[ ] Replaced <name> and <your use>; disclosure line kept
[ ] Checked every source once this week (numbers change with releases)
[ ] Slides: large text, high contrast, no text in images without alt text
[ ] The last slide stays on screen during questions
[ ] A backup: slides as PDF on a USB stick and in your e-mail
```

# Welcoming newcomers

This page is for advocates who meet people new to Exponential: in the forums, the chat, at a meetup, at work. The first
reply decides whether they stay. Be fast, friendly and concrete: one useful link beats a long lecture.

## The first reply

- **Reply soon.** A question answered the same day is a newcomer who stays.
- **Thank them** for asking, and never say "this is a beginner question".
- **Answer the question they asked**, then offer one next step.
- **Link, do not lecture**: one help page, not ten.

## Find out what they need

Ask one question: "What would you like to do with Exponential?"

## First steps for each kind of newcomer

```text
EDITOR       Sign in -> the "?" help button -> Getting started -> A tour of the administration
EVALUATOR    ./console exp:install -> Getting started -> the layouts editor -> the forums
ADMIN        Database support -> Operating system support -> Security hardening -> Upgrading
DEVELOPER    Develop with Git -> Extensions guide -> Setup > RAD -> Templates and design
CONTRIBUTOR  Improving the help -> Helping with translations -> Reporting bugs well
```

## Welcome messages

```text
FORUM
Welcome to the Exponential forums, <name>! <Answer.> If you're just starting, the help built into the
administration (the "?" button) has a Getting started page, and you can always ask here.

CHAT
Hi <name>, welcome! What are you working on? If you have a question, just ask - include your version
and what you see.

IN PERSON
"Nice to meet you. What do you use, or want to use, Exponential for?" (Listen. Then one link or one demo.)
```

## Make the community feel open

- Use plain language; explain abbreviations once (siteaccess, extension, override)
  ([Glossary for advocates](glossary-for-advocates.md)).
- Be patient with language: many people write in their second or third language.
- Invite, do not pressure: "if you like, ..."
- Introduce newcomers to others with similar interests, with their consent.
- Follow up after a week: "Did it work?"

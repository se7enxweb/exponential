# Choosing hosting and partners

This section is for owners, managers and procurement staff who must choose where an Exponential site runs and who
builds and supports it. Exponential is free software, so you are free to choose any host and any partner; these
pages help you choose well, with questions to ask and the facts to check.

> **Note**
> The project publishes no prices and no ranking of hosts or partners, and these pages invent none. Comparisons are
> qualitative and based on the project's own documentation. Contracts are your own; the contract page is not legal
> advice.

## Why the choice is yours

| Fact | Source |
|---|---|
| The GPL lets you run the software anywhere and hire any company to work on it | [Licensing explained for buyers](../../business/licensing-for-buyers.md) |
| Exponential runs on almost any operating system with PHP 8.0 or later (PHP 7.4 usable without support) | [Operating system support](../../os-support.md) |
| Six databases are supported, SQLite 3 first, needing no server | [Database support](../../database-support.md) |
| Apache, nginx, LiteSpeed, Caddy, IIS and others work, or the bundled Velocity | `README.md`, "How Exponential is served" |
| The code and its full history are public | [Develop with Git](../../develop-with-git.md) |

Because nothing ties the software to one supplier, you can change host or partner later
([Moving a site between hosts](../../hosting/migrations/moving-a-site-between-hosts.md)). Make sure your contracts
keep that freedom.

# Businesses reading path

The Businesses section has many pages because organizations differ. You do not need all of them. This page gives the
order that works for most readers: a short path for a busy owner, the four stages everyone goes through, and the
extra pages per kind of organization.

## The one-hour path for a busy owner

Six pages, about ten minutes each:

1. [Businesses: start here](businesses-start-here.md)
2. [Why businesses rely on Exponential](why-businesses-rely-on-exponential.md)
3. [How businesses sell online with Exponential](how-businesses-sell-online.md)
4. The README of your own section, found with [Which section fits your organization](which-section-fits-your-organization.md)
5. [The return on investment of stability](costs/roi-of-stability.md)
6. [Choosing hosting](choosing/choosing-hosting.md)

After that hour you know whether to continue, and you can hand the plan stage to a project manager.

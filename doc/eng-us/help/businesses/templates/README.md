# Templates for businesses

This section is for owners, managers and project leads who want a ready form instead of a blank page. Every template
sits in a plain text block: copy it into your own document, spreadsheet or ticket system and replace the
placeholders in angle brackets or the blanks. Each page explains when to use the template and links to the help
pages behind each line.

> **Note**
> The templates contain no real customer data, figures or quotes. Where a template asks for numbers, use your own,
> and keep the source of each. Case studies may only contain real, approved facts, and a customer may only be named
> with their consent.

## How to use them

- Keep one copy per project or site, with a version number and date.
- Name an owner for each template; an unowned checklist is not done.
- Remove lines that do not apply instead of ticking them.
- Link each line to evidence where you can (a ticket, a screenshot, an export).
- Store filled-in templates that contain personal data where only the right people can read them.

## Before a holiday

Two weeks before a public holiday or a closure:

- [ ] Notice text written, with full dates, in every language of the site.
- [ ] Notice prepared as a draft, or set to publish on a date
      ([Holiday and seasonal hours](../maps-and-hours/holiday-and-seasonal-hours.md)).
- [ ] Special hours set on every map and search platform.
- [ ] If you sell: last order date for delivery before the holiday stated; pickup days stated.
- [ ] Newsletter mention, if you send one.
- [ ] Contact page says how to reach you in an emergency, if that applies (trades, practices).
- [ ] Someone named to remove the notice afterwards.

## Moving to new premises

- [ ] Address changed in the one shared contact object (and every location object).
- [ ] Map point moved: `ezgmaplocation` field or the Map block's latitude and longitude
      ([Showing your location on a map](../maps-and-hours/showing-your-location-on-a-map.md)).
- [ ] Directions text, parking and access rewritten; new photos of the front.
- [ ] Opening hours checked; often they change with the move.
- [ ] Notice on the front page for a few months: "We have moved to ...".
- [ ] Address changed on every platform (most ask for verification; start early)
      ([Business listings outside Exponential](../getting-found/business-listings-outside-exponential.md)).
- [ ] Structured data, if your site prints any, shows the new address.
- [ ] Shop: pickup address in checkout text and confirmation mail.
- [ ] Printed material with the old address replaced; short web addresses still work.

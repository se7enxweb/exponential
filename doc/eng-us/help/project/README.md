# The Exponential project: start here

Exponential is free software, but it is also a project: the people who write it, the company and the nonprofit that
carry it, the sites where its users meet, and the plans for what comes next. The project's public home is
**[exponential.earth](https://exponential.earth/)**. This section of the help covers what that website says, in its
own words where that matters and in plain words otherwise, and connects it with the rest of this help.

The website's pages were read in October 2026. Their text is "All rights reserved" according to the site's footer,
so this help does not copy them; it explains the same topics in its own words and links to the original. Where the
website and the software in this repository disagree, these pages follow the repository for facts about the
software and say so.

## The project in five sentences

1. **Exponential** is an open source content management system and development framework written in PHP, licensed
   under the GNU GPL version 2 or later (`COPYRIGHT.md`).
2. Its code was once eZ Publish, a product its creator discontinued after almost eighteen years; Exponential carried
   that code forward, and the name changed to Exponential in August 2025, as the website's FAQ notes
   ([/faq](https://exponential.earth/faq)). The website also says the project is not associated with the original
   developer of that software.
3. The project is **operated by the Exponential Foundation**, a nonprofit, and **developed by 7x**, the company that
   leads its development and maintenance (footer of every page of exponential.earth;
   [Who is the Exponential Foundation?](../who-is-the-exponential-foundation.md), [Who is 7x?](../who-is-7x.md)).
4. Its code lives on GitHub in [se7enxweb/exponential](https://github.com/se7enxweb/exponential), with the
   extensions in the [se7enxweb organization](https://github.com/se7enxweb), and every package is on Packagist.
5. Its users meet on [Share Exponential](https://share.exponential.earth/), in the Telegram channel, on Discord and
   Slack, and find extensions on [Exponential Projects](https://projects.exponential.earth/).

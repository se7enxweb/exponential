# Open data

This section is for public bodies that publish datasets on a site built with Exponential: managers who plan the
program, site builders who set up the catalog, editors who publish datasets and developers who connect portals. It
explains the terms (Open Definition, EU Open Data Directive, DCAT) with links to their official texts, and shows
step by step what Exponential provides and what it does not.

Up: [Governments: start here](../government-start-here.md).

## What is not included

Exponential has no DCAT or CKAN output, no shipped dataset class, no license field by default and no validation of
uploaded data files. Each page says how to work around the gap that concerns it.

# Editorial workflows

This folder is for web managers, editors-in-chief and administrators who decide how content gets from a draft to the
public site of a public body. Exponential provides approval workflows, object states, a version history and an audit
trail; these pages show how to combine them into a documented editorial process, and say plainly where a process of
your own is needed. The underlying guides are [Workflows](../../../../guides/workflows.md),
[My drafts and my pending items](../../../../guides/drafts-and-pending.md) and [Object states](../../../../guides/object-states.md).

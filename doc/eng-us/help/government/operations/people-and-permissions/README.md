# People and permissions

This folder is for administrators who set up staff access to a public website and for managers who must justify it
to an auditor. It explains Exponential's permission model and gives ready role designs for the teams public bodies
usually have, built only from policy functions that exist in the kernel. Procedures are in
[People and permissions tasks](../../tasks/people-and-permissions/README.md).

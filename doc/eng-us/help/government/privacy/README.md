# Privacy for public bodies

This section is for data protection officers, project managers, administrators, developers and editors of public
bodies that run a site with Exponential. Every product statement is backed by the repository, above all
[Privacy standards](../../../standards/privacy.md): Exponential is software, not a data controller; it provides features
(consent log, opt-in mail, erasure on account removal, audit pseudonymization, log masking and retention, no
third-party assets in the administration) and names its gaps (no single export or delete-me function, manual account
removal, logs without an age limit by default, forms without retention, no cookie banner).

> **Note** This section describes features and common practice; it is not legal advice. Check the law that applies to
> your organization with your legal counsel.

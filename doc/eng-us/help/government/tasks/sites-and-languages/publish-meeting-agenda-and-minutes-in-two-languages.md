# Publish meeting agenda and minutes in two languages

This task is for clerks and editors of a bilingual body. Background:
[Meeting records, agendas and minutes](../../transparency-and-foi/meeting-records-agendas-and-minutes.md) and
[Translate a page into the second official language](translate-a-page-into-the-second-official-language.md).

## Steps

Before the meeting:

1. In the body's year folder, **Create new**, the meeting class; fill in title, body, date and time, place, status
   *Agenda published*, and the agenda; publish in the first language.
2. Translate the meeting object into the second language (the badge of the language, **Translate based on** the first).
3. Below the meeting, create one File object per language version of the agenda ("Agenda (English)", "Agenda
   (French)"); if a document exists in one language only, mark that File object always available.
4. Translate each File object's name into the other language so lists read well.

After the meeting:

5. Upload the minutes per language the same way; update the status in both languages.

## Check

On each language site, signed out: the meeting page, its agenda and minutes in that language; the switcher leads to
the other language's version.

## Problems

| Problem | Fix |
|---|---|
| A document is missing on one language site | it has no translation in that language and is not always available |
| Dates differ between languages | date fields are usually not translatable; set them in the main language |

# Translate a page into the second official language

This task is for editors and translators in a bilingual public body. It adds a translation to one existing page.
Background: [Translating an item step by step](../../languages/translating-an-item-step-by-step.md).

## Before you start

- Your role allows editing in the second language (a **Language** limitation on `content/edit` or `content/translate`).
- The language exists in **Setup > Languages** and a siteaccess shows it.

## Steps

1. Open the page in the administration.
2. Under the buttons, click the dashed badge of the second language (for example **FR**), or choose **New
   translation** in the list next to **Edit** and press **Edit**.
3. If asked, under **Translate based on** choose the first language, so its text is copied into the form.
4. Translate every field: title, summary, body, image alternative texts.
5. Press **Send for publishing**. With an approval workflow for the language, the translation waits for a reviewer.

## Check

- The badge of the language is now filled.
- Open the page on the second language's address (for example `/fr/...`), signed out: title, text and address are in
  the second language.
- The language switcher on the first language's version leads to this translation.

## Problems

| Problem | Cause |
|---|---|
| The language is not offered | no **Language** limitation for it in your role |
| The page shows in the first language on the second site | the translation is not published yet, or a cache; ask the administrator |
| The menu entry is still in the first language | the menu item or folder needs its own translation |

# Switch the administration to another language

This task is for anyone who uses the administration. Background: [Languages (for editors)](../../../languages.md) and
[Administration interface languages](../../languages/administration-interface-languages.md).

## Steps

1. In the right column, find the box **Interface** with the list **Interface language**.
2. Open the list: the most used languages first, then all from A to Z, each with how complete its translation is.
   Typing the first letters of a name jumps to it.
3. Choose your language and press **Apply**.

## What changes and what does not

| Changes | Does not change |
|---|---|
| menus, buttons, messages | the content you edit |
| date, time and number formats | other users |
| the direction, for a right-to-left language | the public site |

The choice lasts until you sign out. The box is not shown while you edit an item, nor to roles without the permission.

## Check

The page reloads in the chosen language. A language marked *no translation yet* keeps English texts but uses its own
date and number formats.

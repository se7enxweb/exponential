# Publish one item in several places

This page is for editors whose page belongs in two places: a service under "Housing" and under "Moving house", a
guidance page under two audiences. In Exponential one object can have several **locations**; it is the same page, so
a change shows everywhere ([Relations and reuse](../../../creators/website-creators/relations-and-reuse.md)).

## Contents

1. [Before you start](#before-you-start)
2. [Steps](#steps)
3. [Check the result](#check-the-result)
4. [Pitfalls](#pitfalls)

## Before you start

- You may create content in the second place (adding a location needs the rights to place content there).
- Decide which place is the **main** one: its address is the main address and its section is the object's section.

## Steps

1. Open the page, tab **Locations**.
2. Press **Add locations**; browse to the second parent, select it, confirm.
3. To change which location is main: tick it and press **Set main**.
4. From a list: in a **Sub items** list, tick items, **More actions** > **Add a location**.

You can also manage locations in the edit form's **Locations** window (**Add locations**, **Visibility after
publishing**); those changes apply when you publish.

## Check the result

- [ ] Both places list the page (menus, folder lists), signed out.
- [ ] Each location has its own address; the main one is the one search engines should see.
- [ ] An edit of the page shows in both places.

## Pitfalls

| Pitfall | Avoid it |
|---|---|
| Copying the page instead | two copies drift apart; use a location |
| Removing the page to remove one location | on the **Locations** tab, tick the location and **Remove selected**; the page stays at its other places |
| Hiding one location | **Hide** on the **Locations** tab hides only that place |
| Different sections in the two places | an object has one section, from its main location; check read rights in both places |

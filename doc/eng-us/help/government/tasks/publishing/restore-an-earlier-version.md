# Restore an earlier version

This page is for editors who need an earlier wording back: a change was wrong, a draft went out by mistake, a
section was deleted that should have stayed. Exponential does not overwrite: you make a new draft from the old
version and publish it, so the history keeps everything
([Versions of an object, 3](../../../../guides/content-history.md#3-a-new-draft-from-an-old-version)).

## Contents

1. [Before you start](#before-you-start)
2. [Steps](#steps)
3. [Check the result](#check-the-result)
4. [Pitfalls](#pitfalls)

## Before you start

- You may edit the object and read the old version.
- Find which version to go back to: use **Compare** if unsure ([Compare two versions](compare-two-versions.md)).

## Steps

1. Open the page, **Manage versions**.
2. Filter by status *Archived* (or by translation), find the version.
3. On its card, choose the translation the new draft starts in, and press **Make a new draft**.
4. With **Stay on this page** ticked (the default), the page says which draft was made; edit it from its card. Untick
   it to open the new draft in the editor at once.
5. Check the draft: some facts may have changed since (dates, contacts); update them.
6. **Send for publishing**.

## Check the result

- [ ] Signed out, the page shows the restored wording.
- [ ] The versions page now lists your new version as *Published*, and the one you replaced as *Archived*.

## Pitfalls

| Pitfall | Avoid it |
|---|---|
| Restoring outdated facts with the old text | read the draft before publishing |
| **Make a new draft** missing on a card | you may not read that version, may not edit its translations, or it is an untouched draft; the card says which |
| The old version is gone | it was removed at the version history limit; restore from your records or retype |
| A page removed, not changed | use the trash ([Remove an outdated page and restore it](remove-an-outdated-page-and-restore-it.md)) |

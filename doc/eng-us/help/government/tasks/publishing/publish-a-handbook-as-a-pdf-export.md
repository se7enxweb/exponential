# Publish a handbook as a PDF export

This page is for editors who maintain a handbook or guidance as web pages and want to offer a printable PDF of it.
**Setup > PDF export** makes one PDF of a source node and, for a tree export, the nodes below it of the classes you
tick ([PDF exports](../../../../guides/pdf-exports.md), [PDF export (building)](../../building/documents-and-publications/pdf-export.md)).
It needs the `pdf/edit` policy, usually given to administrators.

## Before you start

- The handbook is a subtree: a top page (a Folder or Documentation page) with chapters below.
- Decide: **generated once** (a stable file, public at a fixed address, regenerated by you after changes) or
  **generated on the fly** (always current, only for users with `pdf/edit`). For public handbooks, generated once.
- Ask the web team which font the site uses for PDFs if your handbook uses characters beyond Western European ones.

## Steps

1. **Setup > PDF export**, create a new export.
2. Choose the handbook's top page as the source node; make it a tree export; tick the classes of the chapters (for
   example Documentation page, Article).
3. Choose **generated once** and a file name such as `handbook-<subject>.pdf`.
4. Save. The card shows **File ready** and the **Public address**.
5. **Download** and read the PDF.
6. Link it from the handbook's top page: "Print version (PDF, <size>)" pointing to the public address.

After the handbook changes: **Regenerate** on the card.

## Check the result

- [ ] The PDF has every chapter in the right order, with readable characters.
- [ ] Signed out, the public address downloads the file.
- [ ] The link on the handbook says it is the print version, with format and size.

## Pitfalls

| Pitfall | Avoid it |
|---|---|
| Forgetting to regenerate | the PDF shows the content as it was; regenerate after each change, or note the date in the PDF link |
| A restricted handbook exported "generated once" | the stored file is public; use on the fly for restricted content |
| Treating the PDF as the accessible version | it is a print copy; the web pages are the accessible version |
| A guessable file name for internal content | stored PDFs are public |

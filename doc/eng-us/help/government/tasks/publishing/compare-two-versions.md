# Compare two versions

This page is for editors and approvers who need to see exactly what changed: before approving a change, when a
resident says the page used to say something else, or when checking a colleague's correction. The versions page of
an object compares versions field by field ([Versions of an object, 2](../../../../guides/content-history.md#2-the-actions-of-a-version)).

## Contents

1. [Before you start](#before-you-start)
2. [Steps](#steps)
3. [Check the result](#check-the-result)
4. [Pitfalls](#pitfalls)

## Before you start

- You may read the versions you compare and have the policy `content/diff` (otherwise **Compare** is not shown).
- Someone else's draft or pending version needs `content/versionread`.

## Steps

**One version against the current one:**

1. Open the page, **Manage versions**.
2. On the version's card, press **Compare**. (On the current version's card, it compares with the newest other version
   you may read.)

**Any two versions:**

1. On the versions page, under **Compare two versions**, choose the older and the newer version and the translation.
2. Press **Show differences**.

The differences are shown above the list: as inline changes, as block changes, or the old or the new version alone.
Filter the list first by **Status** (*Archived*) or **Creator** to find versions quickly.

## Check the result

- [ ] The comparison names the two versions and the translation.
- [ ] Changed fields are marked; unchanged fields are not.

## Pitfalls

| Pitfall | Avoid it |
|---|---|
| Comparing the wrong translation | choose the translation in the pickers |
| Expecting changes to files to show as text | a replaced file shows as a changed file field; open both versions to compare documents |
| Old versions missing | versions beyond the version history limit were removed |
| Approving without comparing | for changes to published pages, compare first ([Approve or reject a page](approve-or-reject-a-page.md)) |

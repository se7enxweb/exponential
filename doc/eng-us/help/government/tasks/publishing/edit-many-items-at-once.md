# Edit many items at once

This page is for editors who must change the same thing in many pages: a new phone number in ten service pages, a
review date on all pages of a section, a tag on a set of notices. Exponential edits several objects in one form
([Content model and editing, 6](../../../../guides/content-model-and-editing.md#6-edit-many-items-in-one-form-multi-node-edit)).

## Before you start

- You may edit every item you select; items you may not edit are refused in the report.
- If the details are kept in one place (a contact point), change that one object instead
  ([Update opening hours or contact details](update-opening-hours-or-contact-details.md)).

## Steps

1. Select the items:
   - in a folder's **Sub items** list, tick them, **More actions** > **Edit selected**; or
   - search (`/content/search`), tick results across the site, and press **Edit selected**.
2. The form shows one section per content class and a collapsible panel per item; **Expand all** and **Collapse all**
   are above it.
3. Make the change in each item.
4. Press:
   - **Save drafts** to keep the work without publishing;
   - **Publish all** to publish each item;
   - **Discard** to throw the drafts away.
5. Read the report: which items were published, which wait for approval, which were refused.

## Creating many items

**Create multiple new** (next to **Create new**) opens one form for up to 50 new items below the same place, for
example the meetings of a year.

## Check the result

- [ ] The report lists every item as published (or pending, where approval applies).
- [ ] Open two or three items signed out to confirm the change.
- [ ] Items waiting for approval are in **My pending items**.

## Pitfalls

| Pitfall | Avoid it |
|---|---|
| Changing details that should be in one shared object | relate a shared object instead of editing copies |
| Items in different languages | each panel edits one language; check the language |
| Many notifications to followers | each published item may notify followers; use **Publish without notification** per item where enabled, if appropriate |
| Leaving drafts behind after **Save drafts** | they wait in **My drafts** ([Recover a lost draft](recover-a-lost-draft.md)) |

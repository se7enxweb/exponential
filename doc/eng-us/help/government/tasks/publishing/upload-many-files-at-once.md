# Upload many files at once

This page is for editors who add many files: a set of meeting papers, a year's reports, photos of an event. The upload
page takes one file or hundreds, by button, by dragging or by pasting ([Media and uploads](../../../media-and-uploads.md#upload-files)).

## Contents

1. [Before you start](#before-you-start)
2. [Steps](#steps)
3. [Check the result](#check-the-result)
4. [Pitfalls](#pitfalls)

## Before you start

- Files have readable names (they become the titles and appear in download addresses).
- Images: have their alternative texts ready if your site requires them.
- Know the target folder; you may create content there.

## Steps

1. Open the upload page: **Upload** on the target folder, **Upload files** in the dashboard's quick actions, or
   **Upload multiple files** in an item's menu.
2. **Target location**: check the path shows *Uploads allowed*; use a **Quick location** or **Change location...** if
   needed.
3. Add files: **Choose files...**, **Choose a folder...**, drag them onto the dashed area, or paste an image. The page
   shows the largest file it accepts.
4. In the queue, check each file: type, the item it becomes, its **title** (change file names into real titles) and,
   for images, the **alternative text**. A file that cannot be uploaded says why.
5. Options: **Keep as drafts** to publish them later after checking; **Import compressed zip file(s) contents** to
   unpack ZIP files (images inside are skipped where alternative text is required).
6. Duplicates (same name and size already there) are marked: choose skip, rename or upload anyway.
7. Press **Upload all**. **Retry failed** retries failures; **Clear finished** tidies the list.

## Check the result

- [ ] The **Uploaded** list shows each new item with **View** and **Edit**.
- [ ] Tick items there to **Move to...**, **Add location...** or **Remove...** if something went to the wrong place.
- [ ] With **Keep as drafts**: the items wait in **My drafts** until published.

## Pitfalls

| Pitfall | Avoid it |
|---|---|
| Titles like `scan_0012` | rename in the queue |
| Uploading into the wrong section | files take the target's section and permissions; check **Uploads allowed** and the place |
| Duplicates of documents already on the site | search first; relate the existing file |
| Huge files | the page states the limit; very large videos belong on a video service |

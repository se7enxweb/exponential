# Reorder pages in a folder

This page is for editors who want pages in a particular order: the most used service first in a menu, steps in
sequence, news newest first. The order of a folder's children is set on the folder; priorities set a manual order
([Creating and editing content](../../../editing-content.md#many-items-at-once), [Keyboard shortcuts](../../../keyboard-shortcuts.md#lists-of-sub-items)).

## Contents

1. [Before you start](#before-you-start)
2. [Steps](#steps)
3. [Check the result](#check-the-result)

## Before you start

- You may edit the folder (setting the sort order needs edit rights on it).
- Decide: an automatic order (by name, by publication date) or a manual one (by priority).

## Steps

**Choose the sort order:**

1. Open the folder, tab **Ordering**.
2. **Sort by**: *Priority* for a manual order, *Published* for news, *Name* for an alphabetical list.
3. **Sort order**: *Ascending* or *Descending*; press **Set**.

**Set a manual order (Sort by Priority):**

1. In the folder's **Sub items** list, type numbers in the **Priority** column (10, 20, 30 leave room to insert later).
2. Press **Update priorities**.
3. Or drag a row by the grip at its start; with the keyboard, see [Keyboard shortcuts](../../../keyboard-shortcuts.md#lists-of-sub-items).

## Check the result

- [ ] The **Sub items** list shows the new order.
- [ ] Signed out, the menu or the folder's page shows the same order (after its cache renews).

## Pitfalls

| Pitfall | Avoid it |
|---|---|
| Priorities typed but **Sort by** is not Priority | the numbers have no effect; set Sort by first |
| Priorities 1, 2, 3 | inserting later means renumbering; use steps of 10 |
| New items appear in an unexpected place | give each new item a priority right after creating it |
| Menus in the design sort differently | some templates sort by their own rule; ask the web team |

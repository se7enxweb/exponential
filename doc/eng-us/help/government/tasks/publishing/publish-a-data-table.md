# Publish a data table

This page is for editors who publish figures. A table in the page shows them to everyone; the same data as a CSV file
lets others reuse it. Tables in rich text are made with the online editor's table tools
([Content model and editing, 4](../../../../guides/content-model-and-editing.md#4-the-online-editor-and-tinymce-8)).

## Contents

1. [Before you start](#before-you-start)
2. [Steps](#steps)
3. [Check the result](#check-the-result)
4. [Pitfalls](#pitfalls)

## Before you start

- The figures are final and approved, with their source and the date they refer to.
- The table is small enough to read on a screen (a few columns, tens of rows). Large data belongs in a file.
- A CSV export of the same data, with a header row.

## Steps

1. **Edit** the page; in the rich text field, place the cursor and insert a table with the editor's table button.
2. Give the table a **caption** (what it shows, the unit and the date), if your editor offers it; otherwise a heading
   just above.
3. Make the first row header cells (the table properties have a header option); for row labels, make the first column
   header cells too.
4. Type or paste the figures; align numbers consistently; write units in the headers ("Amount (thousands)") rather
   than in every cell.
5. Below the table: "Source: <source>, <date>." and a short sentence with the main message.
6. Attach the CSV: **Upload new** in a relation field, or upload it as a File and link it ("Download the data (CSV,
   12 KB)").
7. **Preview**, then **Send for publishing**.

## Check the result

- [ ] With a screen reader, header cells are announced for each cell.
- [ ] At 200% zoom and phone width, the table can be read (a wide table may scroll inside its box).
- [ ] The CSV opens in a spreadsheet with correct characters.

## Pitfalls

| Pitfall | Avoid it |
|---|---|
| A table pasted as an image | text tables only |
| Merged cells and nested headers | keep tables simple; split into two tables |
| Color as the only signal (red for overspend) | add words or symbols |
| Data without a license note for reuse | state the license you publish data under ([Open Definition](https://opendefinition.org/od/2.1/en/)) |

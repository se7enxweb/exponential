# Procurement and training tasks

These task pages are for the people in a public body who buy Exponential services and introduce the system to staff:
procurement officers, project managers, training coordinators and site administrators. Each page says who does the
task and when, what to have ready, the numbered steps, the result and the usual pitfalls. The background for each task
is in the [procurement section](../../procurement/README.md) and the [checklists](../../checklists/README.md).

## Reading order

Follow the procurement: requirements (the first three tasks), the evaluation (team, scoring sheet, proof of concept,
demo, claims, history), offers and costs (quotes, hosting, staff), the contract (exit plan, acceptance test plan,
license check), then the running phase (training, onboarding, first upgrade, exit drill, handover).

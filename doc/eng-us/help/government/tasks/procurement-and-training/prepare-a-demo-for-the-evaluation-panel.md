# Prepare a demo for the evaluation panel

**Who:** the project manager, with the evaluation team. **When:** before bids are opened; the script is sent to bidders
in advance. The demo scripts written for the press are a good base: they use only documented facts and exact clicks
([Demo scripts for evaluators](../../procurement/evaluation/demo-scripts-for-evaluators.md)).

## Steps

1. **Pick scenarios from your requirements**, not from a product brochure: a typical news item, a service page in two
   languages, a form, an approval, a department's permissions.
2. **Write one script** with numbered steps and a time per step; every bidder runs the same script.
3. **Supply test content** (invented, no personal data) so results are comparable.
4. **Add an accessibility step**: one task done with the keyboard only, in the design the bidder proposes for staff.
5. **Add an operations step**: show **Setup > System information**, the audit trail and how an update is applied.
6. **Allow free time** at the end for the bidder's own highlights, scored separately or not at all.
7. **Send the script** to bidders with the date, the length and the rules (who presents, no slides during scripted steps).
8. **Score during the demo** against the sheet; each scorer notes evidence per step.

## A script outline

```text
Demo script - <tender reference>                 <n> minutes, same for every bidder
1. Sign in, dashboard, find a page by search                         <min>
2. Create a news item with an image and alt text, preview at phone width, send for approval   <min>
3. As approver: approve; show the version history and compare        <min>
4. Add a translation; show the page in the second language (and RTL if required)   <min>
5. Build a contact form; submit it; show where the submission is stored   <min>
6. Show a role limited to one department's section                  <min>
7. Keyboard-only: repeat step 2 without the mouse                    <min>
8. Operations: system information, audit trail, how an update is applied   <min>
9. Bidder's free time (not scored | scored under <criterion>)       <min>
```

## Result

Comparable demonstrations, scored on evidence, not on presentation skill.

## Pitfalls

- Letting each bidder choose what to show.
- Scenarios that only the demo package can do, not your future site.
- Accepting slides in place of a live step.

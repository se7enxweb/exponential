# Bring back an earlier version of a page

For editors, when a published text must return to an earlier wording (a wrong change, a removed paragraph). Old versions
are kept up to the version history limit; you do not overwrite them, you make a new draft from one
([Versions of an object](../../../../guides/content-history.md)).

## Contents

1. [Before you start](#before-you-start)
2. [Steps](#steps)
3. [Check that it worked](#check-that-it-worked)
4. [Related pages](#related-pages)

## Before you start

- Rights to edit the object; to view other people's drafts or pending versions you also need `content/versionread`.
- Note why the text is restored, for the record.

## Steps

1. Open the page's versions: **Manage versions** in the editor, or the context menu, or `/content/history/<object id>`.
2. Filter by status **Archived**; find the version by its modified date and creator.
3. **Compare** it with the current version (needs `content/diff`) to confirm it is the right one.
4. On its card, choose the translation the new draft starts in, and **Make a new draft**.
5. Edit the draft if needed, then publish as usual (or send it through your approval workflow).

## Check that it worked

- The page shows the restored text.
- The versions page now lists the new published version; the wrong version stays as archived, so the history shows what
  happened.
- If the object was at its version limit, the oldest archived version made room; check that it was not one you need
  ("The version history limit").

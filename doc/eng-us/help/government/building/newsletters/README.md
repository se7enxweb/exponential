# Newsletters

This section is for public bodies that send newsletters or e-mail alerts to the public with Exponential. It covers the
`cjw_newsletter` extension and the kernel's mail preferences it relies on, with the consent and unsubscribe duties that
come with mailing lists.

Up: [Building public-service sites](../README.md), [Governments: start here](../../government-start-here.md).

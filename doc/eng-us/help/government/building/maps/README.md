# Maps

This section is for public bodies that show where their offices, service points or facilities are. Exponential's map
support is one extension, `ezgmaplocation`, which stores a location on content and shows it with Google Maps when an
API key is set. There is no GIS, no self-hosted map integration and no geodata export; the pages say so and give the
alternatives.

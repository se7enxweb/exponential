# Building a service catalog

This folder is for website creators, project managers and administrators who build the part of a public-sector site
that lists services: what people can apply for, report, book, pay or ask for. A service catalog is a set of
consistent service pages that people can find by topic, by life event, by name and by search, each pointing to where
the service is actually used. The guides show how to build that with Exponential's content classes, tags, relations
and search, and where the product stops.

## Reading order

1. **Modeling services** and **The service page and plain language**: they define every page.
2. **Life events and topics** and **Finding services**: how people get there.
3. **Contact points and offices** and **Linking to online transactions**: what each page points to.
4. **Keeping services current** and **Measuring and improving**: the work after launch.

Up: [Building a public-sector site](../README.md), the index of all building guides, and [Governments: start here](../../government-start-here.md), the start of the Governments

## What Exponential provides and what it does not

| Provided | Read |
|---|---|
| Content classes with required fields | [Content classes for websites](../../../creators/website-creators/content-classes-for-websites.md) |
| Tags with a tree and synonyms (eztags) | [Tagging with eztags](../../../creators/website-creators/tagging-with-eztags.md) |
| Relations and several locations per object | [Relations and reuse](../../../creators/website-creators/relations-and-reuse.md) |
| Built-in search, or eZ Find with Solr | [Site search](../../../creators/website-creators/site-search.md) |
| Search statistics | **Setup > Search statistics** |
| Information collector forms | [Forms with the information collector](../../../creators/website-creators/forms-with-the-information-collector.md) |

| Not provided | Usual answer |
|---|---|
| Case management, payments, appointments | separate systems, linked from service pages |
| A structured service registry export (for example a national service directory format) | templates or an export script, developed for your format |
| Automatic review reminders by mail | a list of overdue pages in a template, checked on a schedule |

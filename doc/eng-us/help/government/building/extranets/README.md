# Extranets

This section is for public bodies that share content with contractors, partner organizations or other agencies through
an Exponential site. It shows how to keep each party to its own content, how to manage external accounts when there is
no built-in account expiry date, and how to see what external users did.

Up: [Building public-service sites](../README.md), [Governments: start here](../../government-start-here.md).

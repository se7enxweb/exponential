# Government checklists

These checklists are for the people in a public body who run an Exponential site or buy services around it: site
owners, site administrators, editors, procurement and contract managers, and hosts. Each one is a list of `[ ]` items
grouped by stage or owner, and each item links to the page that explains how to do it. Where Exponential has no
feature for something, the checklist says so.

## The checklists

| Checklist | Use it |
|---|---|
| [Go-live checklist for a public site](go-live-checklist.md) | in the last weeks before launch |
| [Accessibility checklist](accessibility-checklist.md) | at launch and every year; what Exponential provides and what is yours |
| [Security checklist](security-checklist.md) | at launch and every year; the defaults you decide on |
| [Privacy checklist](privacy-checklist.md) | at launch and every year; features versus the controller's decisions |
| [Records checklist](records-checklist.md) | when website content counts as records |
| [Multilingual checklist](multilingual-checklist.md) | when you publish in several languages |
| [Quarterly access review](quarterly-access-review.md) | every quarter: accounts, roles, keys, sessions |
| [Annual review](annual-review.md) | once a year: everything on one page |
| [Before a tender](before-a-tender.md) | before you publish a tender |
| [Before signing a contract](before-signing.md) | after the award, before signature |
| [Onboarding a department](onboarding-a-department.md) | when a department starts publishing |
| [Offboarding a contractor](offboarding-a-contractor.md) | on a contractor's last day |

## Reading order

- **Buying:** [Before a tender](before-a-tender.md), then [Before signing a contract](before-signing.md), then
  [Exit readiness](exit-readiness.md).
- **Launching:** [Go-live checklist](go-live-checklist.md), which points to the accessibility, security and privacy
  checklists.
- **Running:** [Quarterly access review](quarterly-access-review.md), [Upgrade readiness](upgrade-readiness.md),
  [Backup readiness](backup-readiness.md), [Incident readiness](incident-readiness.md) and once a year the
  [Annual review](annual-review.md).
- **Publishing:** [Editorial quality](editorial-quality.md) and [Plain language](plain-language-checklist.md) every
  day; the emergency, election, FOI and open data checklists when they apply.

## How to use them

- Copy a checklist into your own tracker and add your site's specifics (names, addresses, figures).
- Items that name a legal topic carry a note: the checklists describe features and common practice, not legal advice.
- The pages are free documentation; adapt them freely under the GNU FDL 1.3.

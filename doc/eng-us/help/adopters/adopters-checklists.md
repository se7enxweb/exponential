## Evaluation

```text
[ ] Requirements written and weighted
[ ] Demo and test installation tried
[ ] Proof of concept for the hardest requirement, written up
[ ] Questions asked of providers
[ ] Scorecard filled from evidence; risks recorded
```

Pages: [Evaluating](evaluating/README.md).

## Decision

```text
[ ] License understood; ownership of custom work agreed
[ ] Who runs it chosen; tasks written down
[ ] Budget worksheet filled with own numbers
[ ] Decision record signed, with an owner
```

Pages: [Deciding](deciding/README.md).

## Planning

```text
[ ] Every role named
[ ] Training planned close to launch
[ ] Content model drafted with editors
[ ] Hosting, database and environments chosen
[ ] Pilot chosen if adopting in stages
[ ] Timeline built from a measured rehearsal
```

Pages: [Planning](planning/README.md).

## After launch

```text
[ ] Hypercare for two weeks; errors and 404s read daily
[ ] Routines: weekly owner check, backups, editorial calendar
[ ] First update applied through the routine
[ ] Restore test done
[ ] 90-day review written; operations owner named
```

Pages: [The first 90 days](launching/first-90-days.md), [After adoption](after-adoption/README.md).

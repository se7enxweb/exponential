## Days 1 to 14: hypercare

- Read the error log and the "not found" list every day.
- Answer editors' questions the same day.
- Fix redirects and small template issues quickly.
- Keep the old site available read-only.

## Days 31 to 90: first cycle

- Apply the first Exponential update through the planned routine ([Keeping current](../after-adoption/keeping-current.md)).
- Run a restore test ([Restore test](../../customers/healthy/restore-test.md)).
- Second editor training on real questions ([Rolling out to editors](rolling-out-to-editors.md)).
- Retire the old site once accepted.

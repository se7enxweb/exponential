## Four ways

| Way | Fits when | Takes from you | Page |
|---|---|---|---|
| Yourself | You have staff who run PHP servers | Updates, backups, security, monitoring | [Hosting companies: start here](../../hosting/hosting-companies-start-here.md) (the technical pages) |
| A hosting company | You want the server run for you, and build the site yourself or with a partner | Choosing and supervising the host | [Choosing a host](../../customers/partners-and-hosts/choosing-a-host.md) |
| A partner | You want building and running in one place | Choosing and supervising the partner | [Choosing a partner](../../customers/partners-and-hosts/choosing-a-partner.md) |
| 7x | You want the company that leads development | A contract with 7x | [Working with 7x and the project](../../customers/partners-and-hosts/working-with-7x-and-the-project.md) |

The businesses section compares hosting models: [Hosting models compared](../../businesses/choosing/hosting-models-compared.md).

| Custom code | | | |
| Incidents at night | | | |

## Keeping ownership

Whoever runs it, keep these yourself: the domain, the administrator accounts, a copy of the code in Git, regular
backups you can restore, and the contracts ([What you own](../../customers/what-you-own.md),
[Handover checklist](../../customers/partners-and-hosts/handover-checklist.md)).

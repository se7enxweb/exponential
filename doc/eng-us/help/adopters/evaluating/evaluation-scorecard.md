# The evaluation scorecard for adopters

The businesses section has a general [vendor evaluation scorecard](../../businesses/templates/vendor-evaluation-scorecard.md).
This page adapts it for an adoption of Exponential and says where the evidence for each criterion comes from.

## Contents

1. [How to use it](#how-to-use-it)
2. [The scorecard](#the-scorecard)
3. [Reading the result](#reading-the-result)

## How to use it

1. Give each criterion a weight from 1 (nice to have) to 3 (essential) for your organization.
2. Score each criterion from 0 (not met) to 3 (fully met) from evidence, not from impressions.
3. Multiply, add up, and note the evidence next to each score.

## The scorecard

| Criterion | Weight (1 to 3) | Score (0 to 3) | Evidence to collect |
|---|---|---|---|
| Content model fits our content | | | Proof of concept with real content types |

## Reading the result

- Any essential criterion scored 0 is a stop, whatever the total.
- A low score with a known workaround is a risk to record, not a stop ([Risks and how to weigh them](risks-and-how-to-weigh-them.md)).
- Compare totals only between systems scored with the same weights and the same kind of evidence.

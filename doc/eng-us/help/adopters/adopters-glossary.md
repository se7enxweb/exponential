# Adopters glossary

| Term | Meaning | More |
|---|---|---|
| **Acceptance** | The owner's formal agreement that the new site does what was agreed | [Content migration checklist](migrating/content-migration-checklist.md) |
| **Adoption** | Bringing Exponential into use: decision, plan, migration, people, routines | [What adoption means](what-adoption-means.md) |
| **Content freeze** | A period in which nobody changes content on the old site, so the final migration is complete | [Content migration checklist](migrating/content-migration-checklist.md) |
| **Content model** | The content types and fields of a site | [Content modeling first steps](planning/content-modeling-first-steps.md) |
| **Cut-over** | The switch from the old site to the new one | [Migrating](migrating/README.md) |
| **Decision record** | A one-page written decision with owner, budget and risks | [Writing the decision](deciding/writing-the-decision.md) |
| **Hypercare** | The first weeks after launch with extra attention to errors and questions | [The first 90 days](launching/first-90-days.md) |
| **Maintenance mode** | A state in which the site shows a maintenance page while work is done | [Maintenance mode and planned work](../customers/healthy/maintenance-mode-and-planned-work.md) |
| **Pilot** | A first, small adoption stage with real users | [Adopting in stages](planning/adopting-in-stages.md) |
| **Proof of concept** | A short test of the hardest requirement | [A proof of concept](evaluating/proof-of-concept.md) |
| **Rehearsal** | A full migration run on a copy, measured | [Timeline](planning/timeline.md) |
| **Rollback plan** | How to go back to the old site if the new one fails | [Content migration checklist](migrating/content-migration-checklist.md) |
| **Scorecard** | A weighted list of criteria with evidence | [The evaluation scorecard](evaluating/evaluation-scorecard.md) |
| **Staging** | A copy of the site for tests, rehearsals and training | [Hosting and database choices](planning/hosting-and-database-choices.md) |
| **URL alias** | The readable address of a piece of content | [URLs and redirects when migrating](migrating/urls-and-redirects-when-migrating.md) |

More terms: [Customers glossary](../customers/customers-glossary.md), [Businesses glossary](../businesses/businesses-glossary.md),

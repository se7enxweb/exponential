## An individual

| | |
|---|---|
| Typical setup | One installation on SQLite, served by Velocity or on shared hosting with Apache |
| Who does the work | You, perhaps with help from the forums |
| Read first | [Getting started](../getting-started.md), [Trying the demo and a test install](evaluating/trying-the-demo-and-a-test-install.md) |
| Can skip | The decision record and the formal scorecard |

SQLite means "a complete Exponential site runs from one file on disk, with no database server to install, configure
or secure" ([SQLite database support](../../features/6.0/sqlite-database.md)). Questions go to the community
([Where people meet](../community/joining/where-people-meet.md)).

## A small team

| | |
|---|---|
| Typical setup | One site, a hosting company or a partner, a few editors |
| Who does the work | A partner or a freelance developer; one person on your side owns the site |
| Read first | [Is Exponential a fit?](evaluating/is-exponential-a-fit.md), [Choosing who runs it](deciding/choosing-who-runs-it.md) |
| Can skip | Formal stage gates; keep a short decision note |

The worked examples in the businesses section show costs for a small store and a non-profit
([Worked example: small store](../businesses/costs/worked-example-small-store.md)).

## A larger organization

| | |
|---|---|
| Typical setup | Several sites or languages, staging and production, roles and approval |
| Who does the work | An internal team with a partner; a project manager |
| Read first | The whole [reading path](adopters-reading-path.md), and [Project managers: start here](../leadership/project-managers-start-here.md) |
| Pay attention to | [Adopting in stages](planning/adopting-in-stages.md), [Governance after launch](after-adoption/governance-after-launch.md), [Multisite and multilingual planning](../leadership/multisite-and-multilingual-planning.md) |

## Beyond the community

Community members take part: they "use, contribute to, promote and develop software using Exponential worldwide"
([Community: start here](../community/community-start-here.md)). The ecosystem also includes people and things that
never take part in that sense:

- an organization whose site a partner built and which never visits a forum;
- the visitors and members of every Exponential site;
- the authors of the PHP libraries Exponential depends on;
- hosting providers whose servers run Exponential among many other applications;
- the code itself: packages, forks, tools and data.

## Within the PHP stack

Exponential is PHP software installed with Composer. Its world sits inside the larger PHP world, and the borders are
open in both directions:

- Exponential uses PHP projects: Zeta Components for its kernel libraries, Symfony, Twig and Doctrine for the
  platform line, Netgen Layouts for the page builder concept, the Qbix web server for the Velocity engine.
- It gives back: forks and patches kept current for new PHP versions, and pull requests upstream, for example "14
  security PRs submitted upstream to zetacomponents"
  ([The PHP stack it stands on and gives back to](../who-is-the-exponential-foundation.md#the-php-stack-it-stands-on-and-gives-back-to)).

## Users and creators

| Users | Creators |
|---|---|
| Site owners and organizations | Developers of sites, extensions, integrations and apps |
| Editors and administrators | Designers and theme authors |
| Members and visitors | Translators and documentation writers |
| Students learning with it | Hosts and agencies that package and run it |

Many people are both. See [Users in the ecosystem](people/users-in-the-ecosystem.md) and
[Creators in the ecosystem](people/creators-in-the-ecosystem.md).

## Why it matters

For someone choosing Exponential, a healthy ecosystem answers practical questions: will it be maintained, can we
find help and people, can we extend it, are we locked in. The sales section has a page that answers those questions
with proof: [The community and ecosystem as a selling point](../business/community-and-ecosystem.md).

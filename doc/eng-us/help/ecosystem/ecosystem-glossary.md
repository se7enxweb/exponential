# Ecosystem glossary

| Term | Meaning | More |
|---|---|---|
| **AdminUI** | An alternative administration design, a port of Netgen Admin UI (`exp_adminui`) | [AdminUI and the admin designs](products/adminui-and-admin-designs.md) |
| **CMF** | Content management framework: Exponential is a framework as well as a CMS | [The Exponential 6 kernel](products/exponential-6-kernel.md) |
| **Composer** | PHP's package manager; required to install Exponential | [Composer and Packagist](packages/composer-and-packagist.md) |
| **Distribution** | A ready-to-install combination of packages, such as Nexus or Legacy | [The Platform line](products/the-platform-line.md) |
| **Dual kernel** | A distribution that runs the Symfony platform and the Exponential 6 kernel together | [The Platform line](products/the-platform-line.md) |
| **DXP** | Digital Experience Platform; Exponential Platform DXP is the Symfony-only one | [Exponential Platform DXP](products/platform-dxp.md) |
| **Ecosystem** | All aspects of the Exponential world within the PHP stack: its users and creators | [What the ecosystem is](what-the-ecosystem-is.md) |
| **Engine** | The server Velocity drives: Qbix, FrankenPHP or PHP's built-in server | [Web servers and engines](php-stack/web-servers-and-engines.md) |
| **Extension** | A package that adds features, designs or settings to the kernel | [The bundled extensions](packages/the-bundled-extensions.md) |
| **Fork** | A maintained copy of another project, here usually to keep it running on current PHP | [Upstream projects and forks](php-stack/upstream-projects-and-forks.md) |
| **Kernel** | Exponential 6 itself, `se7enxweb/exponential` | [The Exponential 6 kernel](products/exponential-6-kernel.md) |
| **Layouts** | Exponential Layouts, the visual page builder | [Exponential Layouts](products/exponential-layouts.md) |
| **Legacy bridge** | Runs the Exponential 6 kernel inside the Symfony platform | [Legacy bridge](../../features/6.0/legacy-bridge.md) |
| **Meta package** | A Composer package that only requires others, such as `exponential-platform-dxp` | [Exponential Platform DXP](products/platform-dxp.md) |
| **Nexus** | Exponential Platform Nexus: platform plus Exponential 6, Exponential Layouts and Media Site | [The Platform line](products/the-platform-line.md) |
| **Package server** | The server of the setup wizard's site packages | [Site packages and the package server](packages/site-packages-and-the-package-server.md) |
| **Packagist** | The public Composer repository where se7enxweb publishes its packages | [Composer and Packagist](packages/composer-and-packagist.md) |
| **Partner** | A company in the Exponential Partner Program | [Partners in the ecosystem](organizations/partners-in-the-ecosystem.md) |
| **Qbix** | The web server engine Velocity began as a fork of, and its recommended engine | [Exponential Velocity](products/exponential-velocity.md) |
| **se7enxweb** | The GitHub organization and Packagist vendor of 7x | [7x in the ecosystem](organizations/7x-in-the-ecosystem.md) |
| **Site package** | A ready-made site installed by the setup wizard (`.ezpkg`) | [Site packages and the package server](packages/site-packages-and-the-package-server.md) |
| **Velocity** | Exponential Velocity, the application server | [Exponential Velocity](products/exponential-velocity.md) |
| **Zeta Components** | The PHP libraries the kernel uses | [Upstream projects and forks](php-stack/upstream-projects-and-forks.md) |

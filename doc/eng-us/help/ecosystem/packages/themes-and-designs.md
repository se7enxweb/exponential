## What is a theme here

A theme is a design: templates, stylesheets and images in a design directory, usually shipped as a design extension
and a Composer package ([Design extensions](../../designers/theme-design/design-extensions.md),
[Design directory layout](../../designers/theme-design/design-directory-layout.md)).

## Themes that come with the kernel

| Package | What it is |
|---|---|
| `sevenx_themes_simple`, `sevenx-themes-media` | "The default simple theme and the media site theme" |
| `ezwebin`, `ezdemo` | "the classic website interface and demo site" |

Source: [The extension ecosystem](../../who-is-7x.md#the-extension-ecosystem); feature page
[sevenx_themes_simple](../../../features/6.0/extensions/sevenx_themes_simple.md).

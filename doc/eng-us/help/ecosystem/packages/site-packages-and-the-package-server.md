## What a site package is

A site package is a ready-made site (content classes, content, settings and designs) in a `.ezpkg` file that the
setup wizard, the kickstarter or the console installs. "The setup wizard installs site packages such as 7x Simple"
([Roadmap](../../project/roadmap.md)). The basics are in
[What a site installer package is](../../site-packages/basics/what-a-site-installer-package-is.md) and
[The ezpkg file](../../site-packages/basics/the-ezpkg-file.md).

## The package server

"The package server `exponential.packages.exponential.earth` serves the packages of the setup wizard ('Users do not
need to use this server outside the setup wizard usage', repository description)"
([Companion projects](../../who-is-the-exponential-foundation.md#companion-projects)). How it works:
[What the package server is](../../site-packages/package-server/what-the-package-server-is.md),
[Offline installs and mirrors](../../site-packages/package-server/offline-installs-and-mirrors.md).

## Site packages from the community

The roadmap's second call for volunteers: the project wants "to open the wizard's list of site packages to the
community, so that users can publish their own" ([Roadmap](../../project/roadmap.md)).
[Contribute your site package](../../site-packages/contribute-your-site-package.md) shows the pull request route.

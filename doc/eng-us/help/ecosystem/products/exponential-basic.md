## What it is

"Exponential Basic is the simple to us to use CMS Framework that is for everyone, educational purposes, personal use
and worldwide general" (repository description of `se7enxweb/exponentialbasic`). Its repository is a fork of
`brookinsconsulting/ezcommunity2`, the line of the 2.2 release of the old product that Brookins Consulting kept alive
([Exponential Basic](../../who-is-the-exponential-foundation.md#exponential-basic)).

The repository describes the current version as "Exponential Basic v2.4.0.3: PHP 8.4/8.5.9 ... (MySQL, Postgresql,
SQLite, Informix) ... GNU GPLv2+" (same source).

## Who it is for

"Learners, personal sites and anyone who wants a small CMS" (same source). It is listed as "A small, simple CMS to
learn with" in [Which product is for you](../../who-is-the-exponential-foundation.md#which-product-is-for-you).

## How it differs from Exponential 6

| | Exponential Basic | Exponential 6 |
|---|---|---|
| Line | The old 2.x line | The 6.0 line |
| Aim | Simple, small sites, learning | A full CMS, CMF and shop with a customizable content model |
| This help | Not covered in detail | Covered |
| Roadmap | More shop features, testing, documentation, video guides, PHP 8.4 and 8.5 support ([Roadmap](../../project/roadmap.md)) | Its own roadmap items |

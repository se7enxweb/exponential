## Users and creators side by side

| Users | Need from the ecosystem | Creators | Give to the ecosystem |
|---|---|---|---|
| Site owners | Stability, help, providers | Developers | Sites, extensions, fixes |
| Editors | Usable tools, help pages | Designers | Themes, designs |
| Administrators | Releases, documentation | Translators and writers | Languages, documentation |
| Members and visitors | Fast, accessible sites | Hosts and agencies | Running sites, packages |

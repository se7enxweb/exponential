## What you can publish

| Work | Route | Page |
|---|---|---|
| An extension | Own repository, Packagist, listed on Projects | [Contribute extensions back](../../contribute-extensions-back.md) |
| A theme | A design extension, as above | [Distribution (designers)](../../designers/distribution/distribution-start-here.md) |
| A site package | A pull request to the package sources | [Contribute your site package](../../site-packages/contribute-your-site-package.md) |
| A fix or feature for the kernel | A pull request | [Contributing code](../../community/contributing/contributing-code.md) |
| Documentation | A pull request, eZpedia or Share | [Contributing documentation and help pages](../../community/contributing/contributing-documentation-and-help-pages.md) |
| A translation | A pull request | [Contributing translations](../../community/contributing/contributing-translations.md) |

## Publishing yourself or contributing to the project

| | Publish yourself | Contribute to the project |
|---|---|---|
| Who maintains it | You | The project |
| Copyright | Yours | Assigned to 7x through the CLA, for kernel code and code handed over for inclusion |
| License | Your choice; GPL 2 or later recommended | GPL 2 or later (code), GNU FDL (documentation) |

Source: `CONTRIBUTING.md`, "What it does not cover"; [The CLA explained](../../community/contributing/the-cla-explained.md).

## Before you publish

Use the [release checklist](../../extension-development/part-7-releasing/the-release-checklist.md) and the
[ecosystem checklists](../ecosystem-checklists.md): no secrets or customer data, a license file, version fields equal
to the tag, a `composer.json`, a README with supported versions.

# Content calendar template

This page is a **template**. Copy the tables into the shared sheet or document your team already uses. The status
words match what Exponential shows for a version, so a line can be checked against the site in a few seconds. How to
work with it is on [Content calendar](content-calendar.md).

## Status words

Use only these, so everyone reads them the same way:

| Status | Meaning | Where to check it in the site |
|---|---|---|
| Idea | not started | nowhere yet |
| Drafting | a draft exists | the owner's *My drafts* ([My drafts and my pending items](../../../guides/drafts-and-pending.md)) |
| In review | sent for publishing, held by an approval | the approver's *My pending items* |
| Scheduled | held until a date by a workflow | **Setup > Workflow processes** ([Workflows](../../../guides/workflows.md)) |
| Published | on the site | the item's page |
| Dropped | will not be published | the draft is discarded |

# Accessibility checklist for editors

This page is a **checklist** for every editor, to run before pressing **Send for publishing**. It covers what editors
control; the template side is your partner's job ([Accessibility upkeep](accessibility-upkeep.md)). The rules come
from [Accessibility for site builders](../../creators/website-creators/accessibility-for-site-builders.md) and the
editor pages of the help.

## Images

- [ ] Every image that carries information has an **alternative text** that says what it shows
      ([Images, media and uploads](../../media-and-uploads.md#good-practice)).
- [ ] The text does not start with "Image of"; screen readers already say it is an image.
- [ ] Purely decorative images have an empty alternative text, if your site allows it.
- [ ] Text inside an image (a poster, a chart) is also written in the page.
- [ ] Charts have a sentence that gives the main finding.

## Headings and structure

- [ ] One main heading: the page's name.
- [ ] Headings in order, without skipping a level; used for structure, not for size.
- [ ] No bold paragraphs pretending to be headings
      ([Handing the site over to editors](../../creators/website-creators/handing-over-to-editors.md)).
- [ ] Paragraphs short; one idea each.

## Links

- [ ] Link texts say where they lead: "Opening hours", not "click here" or "read more".
- [ ] A link to a file says so: "Annual report (PDF)".
- [ ] Links that open something unusual (a download, another site) are named as such in the text.
- [ ] Links to other pages of the site are made with the editor's link tool, not typed by hand.

## Lists and tables

- [ ] Lists use the list buttons of the editor, not typed dashes.
- [ ] Tables are for data, with a header row; never for layout.
- [ ] A table has a short caption or sentence before it saying what it shows.

## Language

- [ ] The page is in the language of the siteaccess it is shown on; a translation is a translation of the item, not a
      second item ([Languages](../../languages.md)).
- [ ] Words or quotes in another language are marked as such if your editor offers it.

## Documents, audio and video

- [ ] Information is on the page, not only in a PDF.
- [ ] Videos have captions; audio has a transcript.
- [ ] Nothing plays sound by itself.

## Words

- [ ] Plain language; explain abbreviations the first time.
- [ ] Instructions do not depend on color or position alone ("the red button", "on the right").
- [ ] Dates and times are written out unambiguously.

## Examples

| Element | Poor | Better |
|---|---|---|
| Alternative text | `IMG_4031.jpg` | Volunteers sorting donations in the warehouse |
| Link text | Click here | Register for the open day |
| Heading | **Our prices** as a bold paragraph | "Our prices" as a heading of the next level |
| File link | Download | Price list 2026 (PDF) |
| Instruction | Press the green button | Press **Send for publishing** |

> **Tip**
> Print this page and keep it next to the screen for the first weeks. Most editors know it by heart after a month.

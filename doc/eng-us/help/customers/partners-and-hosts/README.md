# Partners and hosts

Few organizations run an Exponential site entirely on their own. A host runs the server, a partner builds and
changes the site, and 7x and the project make the software. This folder is about working with them well, from the
owner's side: clear roles, fair contracts, smooth handovers and an honest review each year.

Exponential is free software under the GPL. Nobody is your required supplier, and you may move to another host or
partner at any time ([Licensing explained for buyers](../../business/licensing-for-buyers.md)). These pages help
you keep that freedom real.

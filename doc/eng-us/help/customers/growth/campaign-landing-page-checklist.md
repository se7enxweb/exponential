# Campaign landing page checklist

This page is a **checklist** to copy for every campaign. It assumes the landing page is built with Exponential
Layouts ([Landing pages with layouts](landing-pages-with-layouts.md)). Each step links to the page that explains it.

## Contents

1. [Before building](#before-building)
2. [Building](#building)
3. [The day before launch](#the-day-before-launch)
4. [Launch day](#launch-day)
5. [After the campaign](#after-the-campaign)
6. [Record](#record)

## Before building

- [ ] One goal in one sentence, and how you will know it worked
      ([Analytics and what to measure](../day-to-day/analytics-and-what-to-measure.md)).
- [ ] Start and end date in the [Content calendar](../day-to-day/content-calendar.md), with every part of the campaign.
- [ ] A campaign owner, who is the only person editing the layout.
- [ ] The texts and images are ready and approved; images have alternative texts
      ([Image and file guidelines](../day-to-day/image-and-file-guidelines.md)).

## Building

- [ ] The landing page item exists where the campaign lives in the tree.
- [ ] A layout is created with a layout type that fits; the type cannot be changed later
      ([Landing pages with the layouts editor](../../creators/website-creators/landing-pages-with-layouts.md)).
- [ ] Zones filled: a hero or title, the main message, a clear call to action, supporting content.
- [ ] Listing blocks use dynamic collections where the content should stay current.
- [ ] Blocks named clearly.
- [ ] A rule maps the layout to the page with a `time` condition (`from`, `to`) at a higher priority than the page's
      normal rule ([Layout rules](../../creators/website-creators/layout-rules.md)).
- [ ] Previewed; the draft is not yet published, or the time rule keeps it off until the start.

## The day before launch

- [ ] The layout is published and the rule is in place.
- [ ] The page works on a phone and at 200% zoom; every button can be reached with the keyboard
      ([Accessibility upkeep](../day-to-day/accessibility-upkeep.md)).
- [ ] Headings in order; link and button texts say what they do
      ([Accessibility checklist for editors](../day-to-day/accessibility-checklist-for-editors.md)).
- [ ] Title and description of the page are filled in ([SEO checks](../day-to-day/seo-checks.md)).
- [ ] A short address for print or radio, if wanted, is set up as a global alias
      ([URLs, redirects and moved pages](../day-to-day/urls-redirects-and-moved-pages.md)).
- [ ] Translations ready for every language the campaign runs in
      ([Translation routine](../day-to-day/translation-routine.md)).
- [ ] The newsletter edition is approved and scheduled, and the test group received it
      ([Newsletter routine](newsletter-routine.md)).
- [ ] Forms on the page have been tried, and someone reads the submissions
      ([Forms and collected information](forms-and-collected-information.md)).
- [ ] Your host knows if you expect much more traffic than usual
      ([Peak traffic planning](../../businesses/reliability/peak-traffic-planning.md)).

## Launch day

- [ ] After the start time, open the page signed out: the campaign layout shows.
- [ ] Links from the front page, the menu and the newsletter lead to it.
- [ ] The short address redirects.
- [ ] Someone watches the forms and the contact address.

## After the campaign

- [ ] After the end time, the page shows its normal layout again (the time rule ended).
- [ ] Remove links to the campaign from the front page and menus.
- [ ] Decide what happens to the landing page: keep, archive or remove; if it goes, where its address leads
      ([Archiving and the trash](../day-to-day/archiving-and-the-trash.md)).
- [ ] Remove or redirect the short address.
- [ ] Remove the time rule and the campaign layout when they are no longer needed, so the rule list stays readable.
- [ ] Write down the result against the goal and one lesson.

## Record

```text
CAMPAIGN: ______________________   From: __________   To: __________
Owner: ______________   Layout: ______________   Rule priority: ____
Short address: ______________   Newsletter edition: ______________
Goal: ______________________   Result: ______________________
Lesson for next time: ________________________________________________
```

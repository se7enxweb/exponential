# Glossary for non-technical people

Read this page first. Every page of this section uses these words in exactly the meaning given here. The words are
grouped by where you meet them, not by the alphabet, so that related words stand together. The full technical
glossary of the project is the [Exponential glossary](../../glossary.md); this page is the friendly version.

## Words on the screen while you edit

| Word | In plain words | More |
|---|---|---|
| **Site** | What visitors see at your web address. | [The site and the administration](words/the-site-and-the-administration.md) |
| **Administration** (admin) | The part of the same installation where people sign in to change the site. Often at your address followed by `/admin`. | [Admin tour](../admin-tour.md) |
| **Editor** | On many sites, a simpler administration for people who only write and publish. Same content, fewer buttons. | [Logging into the Editor](../logging-into-the-editor.md) |
| **Dashboard** | The first page after you sign in: your drafts, your pending items, recent content, quick links. | [Getting started](../getting-started.md#2-look-around) |
| **Content item** (also **object**) | One thing on the site: a page, an article, a picture, a file, even a user account. | [Content items and the tree](words/content-items-and-the-tree.md) |
| **Content type** (also **class**) | The kind of an item: *Article*, *Folder*, *Image*, *File*. It decides which fields the form has. | same |
| **Field** (also **attribute**) | One box in the edit form: *Title*, *Intro*, *Body*, *Image*. A red star means you must fill it. | [Editing content](../editing-content.md#the-edit-form) |
| **Tree** (Content structure) | All items arranged like folders on a computer. The left column shows it. | [Content items and the tree](words/content-items-and-the-tree.md) |
| **Sub items** | The items inside the item you are looking at. | same |
| **Rich text** | A field with a small word processor: bold, lists, links, tables, pictures. | [Editing content](../editing-content.md#rich-text) |
| **Relation** | A field that points at another item, such as the picture of an article. | [Editing content](../editing-content.md#relations-and-images) |

## Words about publishing

| Word | In plain words | More |
|---|---|---|
| **Draft** | Your unfinished change. Only you see it; the site does not. | [Drafts, versions and publishing explained](words/drafts-versions-and-publishing-explained.md) |
| **Publish** (**Send for publishing**) | Make your draft the version visitors see. | same |
| **Version** | Every saved state of an item. Old versions are kept so you can go back. | [Undoing a mistake](first-steps/undoing-a-mistake.md) |
| **Pending** | Sent for publishing, but waiting for somebody's approval. | [Publishing, versions and the trash](../publishing-and-versions.md#publish) |
| **Archived** | An older version that used to be on the site. | same |
| **Hidden** | Still there in the administration, but not shown on the site. | [Hiding and removing](first-steps/hiding-and-removing.md) |
| **Trash** | Where removed items wait. They can be restored until someone empties the trash. | same |
| **Preview** | A look at your draft as it would appear, before you publish. | [Editing content](../editing-content.md#the-edit-form) |
| **Approval** (workflow) | A rule that someone must agree before your change goes live. | [How do I send content for approval?](../manual/how-do-i-send-content-for-approval.md) |
| **Scheduled publishing** | A date and time at which an item goes live by itself, where the site has it set up. | [Scheduled publishing](../customers/day-to-day/scheduled-publishing.md) |

## Words about people and permissions

| Word | In plain words | More |
|---|---|---|
| **User** (account) | A person who can sign in. Each person should have their own. | [Your account and signing in](../accounts-and-sign-in.md) |
| **Role** | A set of permissions, such as *Editor* or *Administrator*, given to people or groups. | [Roles and permissions explained](words/roles-and-permissions-explained.md) |
| **Section** | A part of the site with its own rules about who sees and changes it, such as a members-only area. | same |
| **Two-step sign-in** (2FA) | After your password, a 6-digit code from your phone or e-mail. Protects your account if your password leaks. | [Your password and two-step sign-in](first-steps/your-password-and-two-step-sign-in.md) |
| **Anonymous** | A visitor who has not signed in. What they may see is a role too. | [Roles and permissions explained](words/roles-and-permissions-explained.md) |

## Words about pictures, files and pages

| Word | In plain words | More |
|---|---|---|
| **Media library** | The part of the tree kept for pictures, documents and videos (the **Media** tab). | [Images, media and uploads](../media-and-uploads.md) |
| **Alternative text** (alt text) | A short description of a picture for people who cannot see it. Many sites require it. | [Adding a picture](first-steps/adding-a-picture.md) |
| **Image variation** | A smaller or cropped copy of your picture that the site makes by itself for lists and pages. You upload once. | [Images and image variations](../creators/website-creators/images-and-image-variations.md) |
| **Layout** | The plan of a page made of **zones** (areas) holding **blocks** (a title, a text, a list, a gallery). | [The layouts editor](../layouts-editor.md) |
| **Rule** (mapping) | Decides which pages use which layout. Leave it to a site builder if unsure. | same |
| **Form** (information collector) | A contact or sign-up form; the answers are stored and can be read in the administration. | [How do I see form submissions?](../manual/how-do-i-see-form-submissions.md) |
| **Nice URL** (URL alias) | The readable web address of a page, made from its title. | [URLs, redirects and moved pages](../customers/day-to-day/urls-redirects-and-moved-pages.md) |
| **Translation** | The same item in another language, edited separately. | [Translating a page](first-steps/translating-a-page.md) |

## Words a host or developer uses

| Word | In plain words | More |
|---|---|---|
| **Hosting** / **host** | Renting a computer on the internet that runs your site, and the company that rents it. | [Hosting, domains and HTTPS explained](words/hosting-domains-and-https-explained.md) |
| **Server** | That computer. | same |
| **Domain name** | Your address, such as `example.org`. Bought from a registrar, not from Exponential. | [Domain name and e-mail](hosting-choices/domain-name-and-email.md) |
| **HTTPS** / **certificate** | The padlock in the browser: the connection is private. The host sets it up. | [Hosting, domains and HTTPS explained](words/hosting-domains-and-https-explained.md) |
| **Database** | Where the content is stored. Exponential can use a single file (SQLite) or a database server. | [SQLite database support](../../features/6.0/sqlite-database.md) |
| **Backup** | A copy of the site and its content kept somewhere else, to bring it back after a disaster. | [Backups](../customers/healthy/backups.md) |
| **Update** / **upgrade** | Installing a newer release of Exponential. Security fixes arrive only this way. | [How updates work](../customers/healthy/how-updates-work.md) |
| **Release** | A numbered, finished version of the software, such as 6.0.15. It never changes afterwards. | same |
| **Cache** | Ready-made copies of pages the site keeps so it is fast. Sometimes it must be cleared to show a change. | [Caches explained](words/caches-explained.md) |
| **Extension** | An add-on that gives the site an extra ability: a newsletter, maps, two-step sign-in. | [Extensions explained](words/extensions-explained.md) |
| **Design**, **theme**, **template** | How the site looks. Changed by a designer or developer, not in the edit form. | same |
| **Siteaccess** | One "door" into the installation: the public site, the administration, a second language or a second site. | [The site and the administration](words/the-site-and-the-administration.md) |
| **Command line** | Typing commands into a text window on the server. You never need it; your host or developer does. | [What you never have to do](what-you-never-have-to-do.md) |
| **Composer** | The tool developers use to install and update Exponential and its extensions on the command line. | same |
| **Velocity** | Exponential's own fast web server program. Your host decides whether to use it. | [Velocity for businesses](../businesses/reliability/velocity-for-businesses.md) |
| **Maintenance mode** | A notice page visitors see while the site is being updated. | [Maintenance mode and planned work](../customers/healthy/maintenance-mode-and-planned-work.md) |
| **Error reference** | A code such as `ERR-0123456789` on an error page. Pass it on: it lets an administrator find the problem. | [Reading an error message](when-stuck/reading-an-error-message.md) |

| Word | In plain words | More |
|---|---|---|

| **Demo mode** | A public trial site whose administrator password everybody knows. Never for real content. | [Demo mode](../demo-mode.md) |

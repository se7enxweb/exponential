# Hosting choices

You do not need to run a server to have an Exponential site. You need to choose **who** runs it, and to agree on the
right things in writing. The pages of this group help you do that without technical knowledge.

## The one-sentence advice

Choose the people before the technology: "the right question is not only 'which technology is best' but 'who can run
it, back it up and restore it'" ([Choosing hosting](../../businesses/choosing/choosing-hosting.md)).

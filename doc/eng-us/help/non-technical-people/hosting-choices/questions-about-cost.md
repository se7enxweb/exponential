# Questions about cost

This page names no prices: they depend on where you are and whom you hire. It helps you understand what you are paying
for and compare offers fairly.

## What you never pay for

- **A license.** "Using Exponential under the terms of the GNU GPL is free of charge" (`README.md`, "License"). No
  fee per user, per site, per year or per feature ([What you do not pay for](../../businesses/costs/what-you-do-not-pay-for.md)).
- **The extensions that ship with it**, such as the newsletter, Layouts or two-step sign-in. They are free software too.
- **This help.** It is free documentation ([Free documentation](../../free-documentation.md)).

## What you do pay for

| Cost line | Paid to | Shape |
|---|---|---|
| Hosting | Host | Monthly or yearly |
| Domain name | Registrar | Yearly |
| Building the site (design, setup, content model) | Developer or partner | One-off project |
| Updates, backups, monitoring | Host, developer or partner | Monthly agreement, or hourly |
| Changes and new features | Developer or partner | Per change, hourly or a budget |
| Outside services: payment provider, map provider, AI provider, mailing | Each provider | Per use or monthly |
| Your team's time | You | Hours per month |

## Comparing two offers

Two offers with the same monthly price can be very different. Compare what is included, not the price alone
([Comparing offers fairly](../../customers/partners-and-hosts/choosing-a-host.md#comparing-offers-fairly)):

| Compare | Offer A | Offer B |
|---|---|---|
| Exponential updates included? | | |
| Backups, and restore tests included? | | |
| Monitoring and night alerts? | | |
| Support hours and response time | | |
| Hours of changes per month included | | |
| Exit: export included, how fast? | | |
| Price per month | | |
| Price for one extra hour of work | | |

## Hidden costs

- **No updates included**: then each update is billed separately, or not done.
- **Your own time**: a cheap site that takes your evenings is not cheap.
- **Leaving**: an export fee, or work to move a site that nobody documented.
- **Outside services** that charge per use, such as payments or the writing assistant
  ([Using the writing assistant](../first-steps/using-the-writing-assistant.md#cost-and-privacy)).

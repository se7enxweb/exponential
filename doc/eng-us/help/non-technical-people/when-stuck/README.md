# When you are stuck

Being stuck is normal and rarely your fault. The pages of this group help you get unstuck quickly, or hand the
problem to the right person in a way that gets it fixed fast.

## The pages

| Page | Use it when |
|---|---|
| [Something looks wrong](something-looks-wrong.md) | The site or the administration does not do what you expect |
| [Reading an error message](reading-an-error-message.md) | A message appears and you want to know what it means |
| [How to ask for help](how-to-ask-for-help.md) | You need to describe a problem to someone else |
| [Who to call](who-to-call.md) | You need to know whom to contact, and want to write it down before you need it |

## The three-step habit

1. **Stop and note**: the time, the address of the page, what you did, the exact message.
2. **Check the easy things**: is it a draft, a cache, a permission? ([Something looks wrong](something-looks-wrong.md))
3. **Tell the right person** with your notes ([How to ask for help](how-to-ask-for-help.md)).

If you see a security problem, such as seeing things you should not be able to see, do not post it anywhere public:
tell your administrator, or report it privately to the project ([Security problems](../../when-something-goes-wrong.md#security-problems)).

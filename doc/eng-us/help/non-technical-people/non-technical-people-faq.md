## Using it

**Can I break the site?**
Very unlikely, as an editor. You work on drafts that nobody sees until you publish, earlier versions are kept, and
removed items go to the trash first ([Undoing a mistake](first-steps/undoing-a-mistake.md)). What your role does not
allow is grayed out or missing ([Roles and permissions explained](words/roles-and-permissions-explained.md)).

**Do I need to know HTML or code?**
No. You write in fields and a text editor with a toolbar, like a simple word processor
([Changing a page](first-steps/changing-a-page.md)). The look of the site is the designer's job.

**Why does my colleague see buttons I do not?**
Different roles. Ask your administrator for what you need to do, not for a role name.

**Why is my change not on the site?**
Usually it is still a draft, waiting for approval, or a cache shows the old page
([Caches explained](words/caches-explained.md#when-you-see-an-old-page)).

**Can I build a page by dragging blocks?**
Yes, if your site uses Exponential Layouts and your role allows it ([Making a page with Layouts](first-steps/making-a-page-with-layouts.md)).

**Is there an AI that writes for me?**
An optional writing assistant, Exponential Intelligence, suggests drafts if your site has it set up with an AI
provider. It never publishes on its own ([Using the writing assistant](first-steps/using-the-writing-assistant.md)).

**Can I use it on my phone?**
The administration works in a web browser. For longer editing, a computer is more comfortable.

## Owning and paying for it

**Is Exponential free?**
The software has no license fee: it is free software under the GNU GPL. You pay for hosting, the domain and people's
time ([Questions about cost](hosting-choices/questions-about-cost.md)).

**Can I install it myself without technical skills?**
Realistically, no: installation normally uses a command line and the tool Composer. A host, developer or partner does
it, and you then only use the browser ([Three ways to get a site](hosting-choices/three-ways-to-get-a-site.md)).

**Who makes Exponential?**
The company 7x leads and maintains it, the nonprofit Exponential Foundation operates the project, and a worldwide
community uses and develops it ([What Exponential is, in plain words](what-exponential-is-in-plain-words.md#who-makes-it)).

**Does Exponential give me a domain name or e-mail?**
No. A registrar provides the domain and your host or a mail provider the mailboxes
([Domain name and e-mail](hosting-choices/domain-name-and-email.md)).

**Does it have online booking / table reservations / ticketing?**
Not as a shipped feature. These come from an outside service that your site links to or embeds, or from custom work
([Extensions explained](words/extensions-explained.md#what-you-will-not-find)).

**What must I keep in my own hands?**
The domain registration, an administrator account, and the right to a full export
([What to ask before you sign](hosting-choices/what-to-ask-before-you-sign.md#ownership)).

**Do I need to update it?**
Yes, regularly: security fixes come only through new releases. Somebody technical does it; you ask for the result
([How updates work](../customers/healthy/how-updates-work.md)).

## When things go wrong

**I published something wrong. What now?**
Go back to the previous version under **Manage versions**, or hide the item at once if it is harmful
([Undoing a mistake](first-steps/undoing-a-mistake.md#you-published-something-wrong)).

**An error page shows a code like ERR-0123456789.**
Note it with the time and the page address and pass it on: it lets an administrator find the problem
([Reading an error message](when-stuck/reading-an-error-message.md)).

**The site is down. Whom do I call?**
Your host first ([Who to call](when-stuck/who-to-call.md)).

**Where can I ask questions for free?**
The community forums and chats ([How to ask for help](when-stuck/how-to-ask-for-help.md#free-help-from-the-community)).

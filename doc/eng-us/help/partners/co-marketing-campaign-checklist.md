# Co-marketing campaign checklist

This page is for the marketing owner of one joint campaign. Use it with [Co-marketing with 7x and the project](co-marketing.md).

## 1. Brief

```text
Campaign brief
Name: ______________________   Partners involved: ______________________
Goal (measurable): ______________________
Audience: ______________________   Channels: ______________________
Message in one sentence: ______________________
Sources for every claim: ______________________
Budget and who pays what: ______________________
Dates: start ____  end ____   Owner on each side: ____ / ____
Approval needed from: ______________________
```

## 2. Before production

- [ ] Both sides agreed the brief in writing
- [ ] Every fact has a source in the help, the README or a changelog
- [ ] Product, company and Foundation named correctly ([Naming and brand rules for partners](naming-and-brand-for-partners.md))
- [ ] Logos allowed for your level ([Using partner logos](partner-logos-and-marks.md))
- [ ] Customer names only with written permission ([Customer references](customer-references.md))

## 3. Production

- [ ] Texts in American English (or the campaign's language), reviewed by a second person
- [ ] Images with a license that allows the use
- [ ] Accessible formats: alt texts, captions for videos, readable contrast
- [ ] Links point to official pages (exponential.earth, the help, GitHub)

## 4. Legal and privacy

- [ ] Sign-up forms collect only what the campaign needs ([Protecting customer data](protecting-customer-data.md))
- [ ] Each partner's privacy notice covers its own use of the data
- [ ] Leads shared between partners only as agreed ([Handing leads over and back](lead-handoffs.md))

## 5. Launch

- [ ] Final approval from both sides
- [ ] Publish on the agreed date in all channels
- [ ] Someone watches comments and questions in the first days

## 6. Measure and wrap up

- [ ] Results against the goal
- [ ] Lessons learned, shared with the other partner
- [ ] Logged for points if applicable ([Logging your partner activity](logging-partner-activity.md))
- [ ] Material archived; logos removed from it if a level changes later

# Onboarding checklist for new partners

This page is for the partnership owner in a newly activated partner company. Work through it in the first weeks;
[Your first 30 days](your-first-30-days.md) puts it on a calendar.

## Administration

- [ ] Signed agreement filed, with the date and the version of the program pages it refers to
- [ ] Store subscription active; invoices go to the billing contact
- [ ] Renewal date in the calendar, plus a reminder 45 days earlier (standing is evaluated "30 days before
      expiration", <https://exponential.earth/partner/why>)
- [ ] Internal owner named, with a deputy

## Accounts and channels

- [ ] A GitHub organization or accounts for your team (support tickets and contributions run on GitHub)
- [ ] An account on share.exponential.earth for the partner page and the forums
- [ ] Join the community channels: Telegram <https://t.me/exponentialcms>, forums
      <https://share.exponential.earth/forums>; Slack and Discord as listed on <https://exponential.earth/about/project>
- [ ] Ask to be added to the partner mailing lists ("Access to mailing lists, updates, and strategic briefings",
      <https://exponential.earth/partner/benefits>)
- [ ] Note the dates of the next quarterly partner meeting (how they are announced is not published; ask)

## Your public presence

- [ ] Write your partner page ([Your partner page](your-partner-page.md))
- [ ] Get the logo files for your level and read the rules ([Using partner logos and the certified mark](partner-logos-and-marks.md))
- [ ] Update your own website: profile, level, link to exponential.earth

## Support routine

- [ ] Agree who on your team may open partner tickets ([Opening a partner support ticket](opening-a-partner-support-ticket.md))
- [ ] Write down your response times in writing ([Support levels and response times](support-levels-and-response-times.md))
- [ ] Note the private security contact security@se7enx.com ([Escalations and security issues](escalations-and-security-issues.md))

## Technical setup

- [ ] A current Exponential 6.0 development installation from Git ([Develop with Git](../develop-with-git.md))
- [ ] Watch the main repository's releases on GitHub (<https://github.com/se7enxweb/exponential>)
- [ ] Read the release overview and the latest changelog (`doc/eng-us/release-overview`, `doc/changelogs/6.0/`)
- [ ] A staging environment where you test releases before your customers do ([Testing releases](testing-releases.md))

## Internal knowledge

- [ ] Everyone who talks to customers reads [Naming and brand rules for partners](naming-and-brand-for-partners.md)
- [ ] Sales staff read [Sales and marketing: start here](../business/sales-and-marketing-start-here.md)
- [ ] Project managers read [Project managers: start here](../leadership/project-managers-start-here.md)
- [ ] Developers read CONTRIBUTING.md and [Develop with Git](../develop-with-git.md)

## First contributions

- [ ] One bug report or pull request in the first month
- [ ] One forum answer a week
- [ ] A plan for your first case study ([Writing a case study](writing-a-case-study.md))

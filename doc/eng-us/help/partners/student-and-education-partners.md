# Student and education partners

This page is for students, teachers, schools and universities who want to learn or teach with Exponential.

## The Student level as published

- "Student – For educational partners exploring foundational skills and knowledge"
  (<https://exponential.earth/partner/program-levels>, read 18 October 2026).
- "Student Partner Plan: For students, universities, or learning institutions. Includes sandbox access, educational
  resources, and training support" (<https://exponential.earth/partner/why>).
- Price: $25 a month; 2 GitHub issue tickets a week; 1 guidance meeting a quarter; no revenue requirement
  (<https://exponential.earth/partner/benefits>).
- The program page frames the learning levels with its value **Open**: "we provide new partners with the best
  educational environment for learning Exponential technologies".

What "sandbox access" includes is not described; ask the partner team.

## Why Exponential suits teaching

| Reason | Source |
|---|---|
| Free software: students can read, run and change all of it | GPL v2 or later (LICENSE) |
| Free documentation students may copy into course notes | [Free documentation](../free-documentation.md) |
| No database server needed: SQLite is the default | [Database support](../database-support.md) |
| A real-world code base with full Git history | [Develop with Git](../develop-with-git.md) |
| A small CMS for beginners: Exponential Basic, "for everyone, educational purposes, personal use" | [Who is the Exponential Foundation?](../who-is-the-exponential-foundation.md#exponential-basic) |

## Course and project ideas

| Level | Project | Learns |
|---|---|---|
| Beginner | Build a multilingual school website | Content, publishing, languages |
| Intermediate | Write a small extension with a module and a template | PHP, templates, settings |
| Intermediate | Translate a part of the administration into another language | i18n, review |
| Advanced | Fix a real issue from the tracker and send a pull request | Git, code review, CI |
| Advanced | Compare databases for the same site | Performance, operations |

Real contributions are the best portfolio a student can have: a merged pull request is public proof of skill.

## Growing from student to professional

1. Learn with the help and a local installation.
2. Contribute: bug reports, translations, documentation, small fixes
   ([Supporters: start here](../supporters/supporters-start-here.md)).
3. Deliver a first project, alone or as an intern with a partner.
4. Move to the Now or Starter level when you sell services ([Partner levels](partner-levels.md)).

## For teachers

- Use the help's pages as reading assignments; the audience filters show which pages fit editors, administrators or
  developers.
- Plan an exercise that ends in a real contribution, reviewed in public.
- Tell the community about your course; it may find helpers and reviewers.

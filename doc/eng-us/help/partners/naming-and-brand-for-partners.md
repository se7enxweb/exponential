# Naming and brand rules for partners

This page is for anyone in a partner company who writes about Exponential: on your website, in proposals, contracts,
job ads, social media and case studies. The sales team has the full rule set in
[Brand and naming rules](../business/brand-and-naming-rules.md); this page is the partner's short version.

## The names

| Write | Meaning | Never write |
|---|---|---|
| **Exponential** | The product, the CMS and framework | "eZ Publish" for the product today |
| **Exponential 6**, **Exponential 6.0.x** | The current major line | "eZ Publish 6" |
| **7x** | The company that leads development, support and hosting | "7X", "SevenX" in running text (the domain and accounts are spelled se7enx and se7enxweb) |
| **the Exponential Foundation** | The nonprofit that operates the project | "the Exponential company" |
| `sevenx`, `exp` (in code) | 7x's code prefixes: `sevenx` is 7x's official public PHP code prefix, because a code name cannot start with a digit; `exp` is used with intent to assign an extension or solution to the Exponential project and the Exponential Foundation ([Naming prefixes](../../standards/naming-prefixes-sevenx-and-exp.md)) | `7x_...` as a code prefix; `exp` on your own extension |
| **Exponential Platform**, **Legacy**, **Nexus**, **DXP**, **Basic** | The product family ([Who is the Exponential Foundation?](../who-is-the-exponential-foundation.md#the-product-family-at-a-glance)) | Invented product names |
| **Exponential Partner (Level)** | Your status, e.g. "Exponential Partner (Silver)" | "Official Exponential vendor", "Exponential reseller" unless you have the Distribution profile |

## The old name

The product was renamed on 11 August 2025 "At the specific request of Ibexa"
(<https://exponential.earth/about/project>). Its code was once eZ Publish, a product its creator discontinued after
almost 18 years of service. Use the old name only for that history, for example: "We have built sites on this code
base since its eZ Publish days." Never use it to sell the product today. Class names such as `eZContentObject` in
the code are identifiers, not the product name, and stay as they are
([The product is called Exponential](../../features/6.0/rebranding-to-exponential.md)).

The project states: "This project is not associated with the original eZ Publish software or its original developer,
eZ Systems or Ibexa" (<https://exponential.earth/about/project>). Do not suggest otherwise.

## Ready-to-use phrases

```text
<Company> is an Exponential Partner (<Level>, <Profile>) and builds websites and applications with
Exponential, the open source content management system led by 7x and operated by the Exponential Foundation.

Exponential is free software under the GNU General Public License, version 2 or later.

We have worked with this code base since <year>, from its eZ Publish years to Exponential 6.
```

## Wrong and right

| Wrong | Right |
|---|---|
| "We are the Exponential company in [country]." | "We are an Exponential Partner in [country]." |
| "eZ Publish 6 website" | "Exponential 6 website" |
| "Exponential, by eZ Systems" | "Exponential, led by 7x and operated by the Exponential Foundation" |
| "Certified" (without certification) | Only "Exponential Partner ([Level])" |
| "The Foundation endorses our services." | Only with a written statement of the Foundation |

# The points system

This page is for partners who want to qualify for a level through activity, or who want to understand how their
level is measured. Everything is quoted from the program pages as read on 18 October 2026.

## What a point is

"7x uses a point system to measure the value-oriented collaboration between 7x and each partner. Partners earn
points for their activities. Therefore, points indicate competence and quality. The activities rewarded with points
can include business collaboration or general community activities useful for the whole Exponential ecosystem"
(<https://exponential.earth/partner/program>).

"1 Point ≈ 1 USD in revenue or 1 minute of value-added activity. Some strategic activities may receive bonus points
due to their higher impact on the ecosystem" (<https://exponential.earth/partner/requirements>).

## Two ways into the program

The requirements page:

1. **Pay a program fee.** "A monthly subscription fee of $45 USD grants you initial access to the partner program.
   To maintain active status, partners who do not reach the Professional level annually must pay this fee again
   each year."
2. **Earn 5,000 points.** "Partners who generate 5,000 points annually through activity or revenue qualify for Basic
   status automatically, with no fee required."

The program page says the same 5,000 points make you "Professional" automatically. Ask which applies.

## Points that earn you a level

| Level | Requirements page: points a year | Requirements page: minimum revenue | Program page: points | Program page: revenue |
|---|---|---|---|---|
| Now | 3,000 | None | – | – |
| Starter | 4,000 | None | 3,000 | None |
| Basic | 5,000 | None | 4,000 | None |
| Professional | 8,000 | $7,200 | 5,000 | None |
| Silver | 20,000 | $12,000 | 20,000 | None |
| Gold | 50,000 | $18,000 | 50,000 | $15,000 |
| Platinum | 200,000 | $30,000 | 200,000 | $60,000 |

Certifications are also required from Silver; see [Partner requirements](partner-requirements.md).

## Activities and their points

From the requirements page (the program page gives a similar list):

| Activity | Points |
|---|---|
| Exponential Premium project | 5,000+ |
| Exponential 6 project | 2,500+ |
| Exponential Newsletter solution project | 2,000+ |
| Official training course (per attendee) | 2,000 |
| Certification (per person) | 1,000 |
| Full event attendance (conference + meetings) | 5,000 |
| "Share your Pipeline" monthly | 1,000 |
| Partner year participation (max 3 years) | 1,000 a year |
| Case study published on exponential.earth | 1,000 |
| Customer site running Exponential | 1,000 |
| Customer reference published | 500 |
| Article (500 to 1,500 words, FLOSS-licensed) | 500 |
| Approved press release | 500 |
| Tutorial (1,500+ words) | 500 |
| Conference presentation | 500 |
| "Powered by Exponential" site badge | 500 |
| Bug report | 50 |
| Forum post | 10 |

The program page differs in places: it places the case study on 7xwebsites.com and the customer reference on
share.exponential.earth, and lists "Kick-Off Package 15000" and "Exponential Project Hosted by 7x From 2500+".

Revenue counts as "1 point per $1 USD earned by exponential.earth via your direct sales, project licensing, or
subscriptions" (requirements page).

## Planning a year of points

A worked example for a small agency aiming at Basic (5,000 points by the requirements page), using only the
published values:

| Activity | Count | Points |
|---|---|---|
| One Exponential 6 customer project | 1 | 2,500+ |
| Customer site running Exponential | 1 | 1,000 |
| Case study | 1 | 1,000 |
| Tutorials | 1 | 500 |
| Bug reports | 4 | 200 |
| Forum posts | 20 | 200 |
| **Total** | | **5,400+** |

This is an illustration of the arithmetic, not a promise of how points will be credited. Confirm each activity's
value with the partner team.

## Keeping the system honest

- Report only activities that happened, with links as evidence.
- Do not split one article into several to earn more points; quality is what the points stand for.
- Community points (forums, bug reports, tutorials) must help others, not advertise.

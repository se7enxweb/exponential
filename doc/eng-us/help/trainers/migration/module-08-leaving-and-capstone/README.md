# Module 8: Leaving Exponential, and the capstone

The course ends with the way out and with a plan of the learners' own. The first lesson teaches the complete export
of an Exponential site; the capstone has teams write, prove and present a full migration plan for a realistic
scenario.

## At a glance

| | |
|---|---|
| Course | [Migrating to Exponential](../README.md) |
| Duration | 2 hours 15 minutes |
| Lessons | 2 |
| Level | Intermediate to advanced |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [8.1 Migrating away from Exponential](leaving-exponential.md) | 45 minutes | Make a site archive, check it against the admin's counts, plan redirects and passwords |
| [8.2 Capstone: a complete migration plan](capstone-migration-plan.md) | 90 minutes | Write, prove and present a migration plan in teams; scored with a rubric |

## Preparing this module

- [ ] Each learner's training installation has xrowextract active and enough disk space in `var/tmp/` for an archive.
- [ ] The four capstone scenarios printed, one per team; teams mixed by role.
- [ ] A shared document per team for the plan, and a timer for the presentations.
- [ ] The rubric of lesson 8.2 printed for scoring. Tell learners at the start that it is your own course material,
      not an official certification.
- [ ] After lesson 8.1, check that learners removed `var/tmp/export/`.

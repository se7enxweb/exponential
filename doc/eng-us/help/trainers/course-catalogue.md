# Course catalogue

This catalogue lists the trainer courses in the help. Each course has a course overview with its modules, a reading
path for the trainer and suggested schedules; each module has a timing plan; each lesson is one page. Durations
include the hands-on exercises but not breaks.

## The courses

| Course | For | Level | Length | Prerequisites |
|---|---|---|---|---|

## Suggested order

```text
                         Train the trainer  (for the trainer)

  Editors 101 --> Editors 201 --> Newsletters
       |              |
       |              +--> Exponential Layouts --> Exponential Intelligence
       |
       +--> Site administration --> Hosting and operations
                     |           --> Search
                     |           --> Multisite and site packages
                     |
                     +--> Developers --> Theme design
                                     --> Migrating to Exponential
```

## Combinations for common groups

| Group | Program |
|---|---|
| A new editorial team | Editors 101 (3 days), then Exponential Layouts (3 days), a month later Editors 201; or the [editor bootcamp](workshops/module-03-three-day-bootcamps/editor-bootcamp.md) |
| An intranet administrator | Editors 101, Modules 1 to 3 only; then Site administration (5 days, or its intensive four-day schedule) |
| An agency's developers | Developers (7 days, or its four-day agency fast track), Theme design (4 days), Exponential Layouts (selected modules) |
| A hosting company's support staff | Site administration, modules on caches, cronjobs, logs and upgrades; then Hosting and operations |
| A migration project team | Site administration (selected modules), Migrating to Exponential, then Developers as needed |
| New trainers | Train the trainer, then one subject course taught back to the group |

## How to use a course

1. Read the course overview and its reading path.
2. Rehearse every exercise on the version you will teach
   ([Writing exercises that work](train-the-trainer/module-03-designing-a-course/writing-exercises-that-work.md)).
3. Build the lab ([Module 2 of Train the trainer](train-the-trainer/module-02-building-the-lab/README.md)).
4. Run the modules with their timing plans; use the quizzes and expected results to check understanding.
5. Collect feedback and improve the course
   ([Collecting feedback](train-the-trainer/module-06-assessment-and-follow-up/collecting-feedback.md)).

# Module 4: Five-day bootcamps

A week allows depth and a real capstone. These programs are for teams starting a project, developers who will lead
one, and new trainers.

## At a glance

| | |
|---|---|
| Course | [Workshops and bootcamps](../README.md) |
| Bootcamps | 3 |
| Duration | 5 days each, 6 hours of sessions per day |
| Level | Intermediate to advanced |

## Bootcamps

| Bootcamp | For | Capstone |
|---|---|---|
| [4.1 The full-stack developer week](full-stack-developer-week.md) | Developers who lead projects | A conference site in an extension, deployed under Velocity |
| [4.2 The agency onboarding week](agency-onboarding-week.md) | A whole agency team | A microsite delivered together |
| [4.3 The trainer academy week](trainer-academy-week.md) | New trainers | Teaching practice with rubric feedback |

## Preparing this module

- A run sheet per day; two trainers for 4.2.
- One installation per developer and administrator, a shared site for joint work.
- The brief of the capstone, printed.

## Timing plan

Each day: 9:00 to 16:30, two blocks of three hours, two 15-minute breaks and a 45-minute lunch. Day 5 afternoon is
always review, presentations and feedback.

# Lesson 1.4: The run sheet

An agenda says what the day covers. A run sheet says who does what at each minute, how you know a block worked, and
what goes if time runs short. Trainers and helpers work from the same sheet.

## Learning objectives

After this lesson, learners can:

- turn an agenda into a run sheet with times, owners, materials and checkpoints;
- mark a cut item per block;
- plan the helpers' tasks;
- include the end-of-day clean-up.

## Trainer's notes

### How to present it

1. Show the columns (5 minutes): time, block, owner (trainer or helper), material (help page, lesson), checkpoint
   (the visible result), cut item.
2. Show an example row (5 minutes):

   | Time | Block | Owner | Material | Checkpoint | Cut item |
   |---|---|---|---|---|---|
   | 10:30 | Create and publish an article | Trainer; helpers walk the room | [Creating your first article](../../editors-101/module-03-creating-and-editing/creating-your-first-article.md) | Every learner's article at version 2 | The language step |

### Common questions

**Who keeps time?** One helper, with a quiet signal at five minutes before the end of each block.

**What if a block runs over?** Apply its cut item, not the next block's exercise.

### Pitfalls

- **No checkpoints.** Without them, you only know at the end that the morning did not work.
- **Forgetting clean-up.** It is part of the day.

## Hands-on exercise

1. Take the [Editors day](../module-02-one-day-agendas/editors-day.md) agenda.
2. Write the run sheet for the morning: at least five rows with every column.
3. Name the timekeeper and the helper tasks.
4. Add the last row: clean-up (stop servers or remove accounts, collect feedback slips).

## Expected result

- A morning run sheet of five or more rows, every row with a checkpoint and a cut item.
- Helper tasks and the clean-up row.

## Quiz

1. Name the six columns of a run sheet.
2. What is a checkpoint?
3. A block runs over. What do you cut?
4. Why is clean-up on the run sheet?

<details>
<summary>Answers</summary>

1. Time, block, owner, material, checkpoint, cut item.
2. The visible result that shows the block worked (for example, an article at version 2).
3. That block's planned cut item.
4. So it is not forgotten: stopped servers, removed accounts, collected feedback.

</details>

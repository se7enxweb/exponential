# Module 1: Planning a workshop

Before any agenda: the format, the room and the people. This module turns a request ("can you train our team in a
day?") into a plan that works on the day.

## At a glance

| | |
|---|---|
| Course | [Workshops and bootcamps](../README.md) |
| Duration | 2 hours 5 minutes (four lessons) |
| Lessons | 4 |
| Level | Beginner to intermediate |
| Format | Planning workshop; paper or a shared document |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [1.1 Choosing a workshop format](choosing-a-format.md) | 30 min | Match five invented groups to formats |
| [1.2 Venue, kit and helpers](venue-kit-and-helpers.md) | 30 min | Write the logistics plan for 16 learners |
| [1.3 Pre-work for learners](pre-work-for-learners.md) | 30 min | Write a pre-work message |
| [1.4 The run sheet](the-run-sheet.md) | 35 min | Write a morning run sheet |

## Preparing this module

- The agendas of Modules 2 to 4 printed or open.
- The [Trainer toolkit](../../trainer-toolkit.md) and the [Lab quick card](../../lab-quick-card.md).

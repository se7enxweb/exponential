# Lesson 1.3: Pre-work for learners

The first hour of a workshop goes to whoever arrived prepared. A short preparation message, sent a week before,
moves the machine checks and the first reading out of the workshop and into the learners' own time.

## Learning objectives

After this lesson, learners can:

- write a pre-work message of no more than one screen;
- choose two help pages as pre-reading for a given workshop;
- include a machine check that learners can do alone;
- ask about arrangements without asking for reasons.

## Trainer's notes

### How to present it

1. Show the template in the [Trainer toolkit](../../trainer-toolkit.md#template-pre-work-message-to-learners)
   (5 minutes).
2. Choose pre-reading by role (5 minutes): editors: [Getting started](../../../getting-started.md) and
   [Creating and editing content](../../../editing-content.md); administrators: [A tour of the administration](../../../admin-tour.md)
   and [Roles and policies](../../../../guides/roles-and-policies.md); developers: [Develop with Git](../../../develop-with-git.md)
   and [Templates and design](../../../../guides/templates-and-design.md).

### Common questions

**What if learners do not do it?** Plan the first 30 minutes so the unprepared can catch up with a helper.

**Should the pre-work include installing?** For developer workshops, yes (with a fallback). For editor workshops,
send sign-in details for the shared site instead (passwords by a separate, secure channel).

### Pitfalls

- **Long messages.** One screen.
- **Passwords in the same message.** Never send credentials with the general information.

## Hands-on exercise

1. Write the pre-work message for a one-day editors workshop on a shared training site.
2. Choose the two pre-reading pages.
3. Write the machine check (a browser and the site's address; nothing to install).
4. Add the arrangements question.
5. Decide how learners receive their personal sign-in (not in this message).

## Expected result

- A pre-work message of one screen with two pre-reading links, a simple check and the arrangements question.
- A note on how sign-in details are sent separately.

## Quiz

1. How long should a pre-work message be?
2. Which two pages suit editors as pre-reading?
3. Why are passwords never sent in the general message?
4. What should the first 30 minutes plan for?

<details>
<summary>Answers</summary>

1. One screen.
2. For example [Getting started](../../../getting-started.md) and [Creating and editing content](../../../editing-content.md).
3. General messages get forwarded; credentials go by a separate, secure channel.
4. Learners who did not do the pre-work.

</details>

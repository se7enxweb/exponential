# Module 2: One-day agendas

Six ready agendas for days when only one day is available. Each block names the lesson or help page it uses, the
checkpoint that shows it worked, and what to cut first.

## At a glance

| | |
|---|---|
| Course | [Workshops and bootcamps](../README.md) |
| Agendas | 6 (five days, one half day) |
| Level | Beginner to intermediate |
| Format | Hands-on, except the decision makers' half day |

## Agendas

| Agenda | Length | For |
|---|---|---|
| [2.1 The editors day](editors-day.md) | 1 day | New editors |
| [2.2 The administrators day](administrators-day.md) | 1 day | New site administrators |
| [2.3 The developers day](developers-day.md) | 1 day | PHP developers new to Exponential |
| [2.4 The layouts day](layouts-day.md) | 1 day | Editors and site builders |
| [2.5 Exponential in a day (mixed group)](exponential-in-a-day.md) | 1 day | A project team of mixed roles |
| [2.6 The decision makers' half day](decision-makers-half-day.md) | Half day | Managers and boards |

## Preparing this module

- Turn the chosen agenda into a run sheet ([Lesson 1.4](../module-01-planning-a-workshop/the-run-sheet.md)).
- Build the lab ([Module 2 of Train the trainer](../../train-the-trainer/module-02-building-the-lab/README.md)).
- Rehearse every capstone on the release you will use.

## Timing plan

Each agenda has its own times. A standard workshop day runs 9:00 to 16:30: six hours of sessions, two 15-minute
breaks and a 45-minute lunch.

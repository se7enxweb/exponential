# Module 3: Three-day bootcamps

Three days let learners practise until they can work alone. Each bootcamp has a capstone that grows over the days and
is presented at the end.

## At a glance

| | |
|---|---|
| Course | [Workshops and bootcamps](../README.md) |
| Bootcamps | 4 |
| Duration | 3 days each, 6 hours of sessions per day |
| Level | Beginner to intermediate |

## Bootcamps

| Bootcamp | For | Capstone |
|---|---|---|
| [3.1 The editor bootcamp](editor-bootcamp.md) | New editors | A section with articles, a translation and a layout |
| [3.2 The administrator bootcamp](administrator-bootcamp.md) | Site administrators | Roles and sections, 2FA, backup and restore, an incident drill |
| [3.3 The developer bootcamp](developer-bootcamp.md) | PHP developers | An Events section with classes, views and an extension |
| [3.4 The site builder bootcamp](site-builder-bootcamp.md) | Website creators | A small club website with layouts and two languages |

## Preparing this module

- One installation per learner for 3.2, 3.3 and 3.4; a golden copy for resets.
- For 3.2: one prepared fault per installation for the incident drill.
- A run sheet per day ([Lesson 1.4](../module-01-planning-a-workshop/the-run-sheet.md)).

## Timing plan

Each day: 9:00 to 16:30, two blocks of three hours, two 15-minute breaks and a 45-minute lunch. Plan the capstone
presentations in the last hour of day 3.

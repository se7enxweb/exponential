# Module 1: Signing in and the tour

The first module takes new editors from "never seen it" to "I know where things are". It starts without a computer,
with the five ideas behind every later lesson, then signs everyone in with their own account and walks once around
the screen.

## At a glance

| | |
|---|---|
| Course | [Editors 101](../README.md) |
| Duration | 2 hours 20 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 1.1: What Exponential is, for an editor](what-exponential-is-for-editors.md) | 30 minutes | Hear about content items, the tree, drafts and roles; sketch the tree of a real site |
| [Lesson 1.2: Signing in and out](signing-in-and-out.md) | 45 minutes | Sign in with a training account, meet the error messages, sign out |
| [Lesson 1.3: A tour of the screen](a-tour-of-the-screen.md) | 45 minutes | Name the header buttons, use both columns, change the interface language and color mode |

## Preparing this module

- A training installation that every learner can reach from the classroom, for example one installed with
  `php bin/php/console exp:install` ([7. The console install](../../../../install/07-console-install.md)).
- One account per learner with the **Editor** role, e-mail addresses at `example.invalid`, written on cards; one
  extra account for yourself with the same role, for the projector.
- The address of the administration (and of the Editor, if the installation has one) on the board.
- A few published folders and articles on the training site, so that lesson 1.1's exercise has something to look at.
- A browser on every machine with cookies allowed for the training site.

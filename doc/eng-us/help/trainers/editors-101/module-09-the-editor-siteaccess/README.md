# Module 9: The editor siteaccess

The course ends where many editors will work every day: in the **Editor**, the administration made for them. After a
short comparison with the full administration, learners prove what they learned in a capstone exercise.

## At a glance

| | |
|---|---|
| Course | [Editors 101](../README.md) |
| Duration | 1 hour 30 minutes |
| Lessons | 2 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 9.1: Working in the Editor](working-in-the-editor.md) | 30 minutes | Sign in to the Editor, compare it with the administration, publish a change there |
| [Lesson 9.2: Capstone, a page from start to finish](capstone-a-page-from-start-to-finish.md) | 60 minutes | Produce a complete article alone; review against a checklist |

## Preparing this module

- Find the Editor's address on the training installation (the summary of `exp:install` names the editor
  siteaccess; by convention a host such as `edit.<host>` or a path such as `/editor`). If the installation has no
  Editor, run lesson 9.1 as a demonstration with the screenshots of [Logging into the Editor](../../../logging-into-the-editor.md).
- Check that the learners' role may sign in to the Editor (the policy **user/login** for that siteaccess).
- Print the capstone task list and the checklist of lesson 9.2, one per learner.
- One new neutral sample image per learner for the capstone.

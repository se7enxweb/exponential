# Module 3: Creating and editing content

This is the heart of Editors 101. Learners create their own course folder, write and publish articles in it, learn
the edit form part by part, and finish with the tools for many items at once. Every later module works inside the
folder made here.

## At a glance

| | |
|---|---|
| Course | [Editors 101](../README.md) |
| Duration | 3 hours 35 minutes (with two 10-minute breaks) |
| Lessons | 4 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 3.1: Creating your first folder](creating-your-first-folder.md) | 45 minutes | Create and publish a personal course folder |
| [Lesson 3.2: Creating your first article](creating-your-first-article.md) | 60 minutes | Create an article, meet a required field, edit it to version 2 |
| [Lesson 3.3: The edit form in depth](the-edit-form-in-depth.md) | 45 minutes | Use the field bar, the left column, Store draft and exit and the error messages |
| [Lesson 3.4: Many items at once](many-items-at-once.md) | 45 minutes | Create two articles in one form and edit them together |

## Preparing this module

- A folder **Training** on the training site where the learners' role may create folders and articles; test it
  with one learner account.
- Check the article form of your training installation once: the lessons assume the standard fields **Title**,
  **Short title**, **Author**, **Intro**, **Body**, **Enable comments** and **Image**. Note any difference on the
  board.
- If the site has an approval workflow for the learners' group, switch it off for this module or move the approval
  to Editors 201: otherwise every publish waits under **My pending items**.

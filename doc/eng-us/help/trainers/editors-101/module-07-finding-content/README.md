# Module 7: Finding content

A short module with a big effect: editors who search well stop clicking through the tree. Learners use the quick
search and its scope, then the advanced search form.

## At a glance

| | |
|---|---|
| Course | [Editors 101](../README.md) |
| Duration | 1 hour |
| Lessons | 2 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 7.1: The quick search](the-quick-search.md) | 30 minutes | Search from the header, narrow the scope, edit results together |
| [Lesson 7.2: The advanced search](the-advanced-search.md) | 30 minutes | Search by phrase, type, field, section and date |

## Preparing this module

- Every learner's articles and images from modules 3 to 5 must be published, a few minutes before the module, so the
  search index has them.
- Check on your training installation that the search finds a freshly published article (some installations update
  the index in the background).
- Note the section your articles belong to (usually *Standard*), to explain lesson 7.1's step 4.

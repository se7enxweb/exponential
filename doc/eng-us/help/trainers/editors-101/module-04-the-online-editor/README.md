# Module 4: The Online Editor

Rich text fields are where editors spend most of their writing time. This module teaches the online editor (the
extension ezoe, with its TinyMCE 8 engine) from formatting through links to embedded images and tables, and shows
where each editor chooses the engine they like.

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 4.1: Rich text basics](rich-text-basics.md) | 45 minutes | Headings, lists, bold and italic, undo, special characters, full screen, pasting |
| [Lesson 4.2: Links and anchors](links-and-anchors.md) | 45 minutes | Internal, external and e-mail links, an anchor, removing a link |
| [Lesson 4.3: Embeds, tables and choosing your editor](embeds-tables-and-choosing-the-editor.md) | 60 minutes | Embed an image, build a table, switch the editor engine and back |

## Preparing this module

- Find out which editor engine your training installation uses by default: open the **Online editor** page
  (`/ezoe/engine` after the administration's address) and read **Editor for text fields**. The lessons describe
  TinyMCE 8; if the default is TinyMCE 3, either switch your learners to TinyMCE 8 on that page, or note the
  differences.
- Put two or three images with alternative texts in the training site's media library, and write the name of one on
  the board for lesson 4.3.
- An external `https://` address learners may link to in lesson 4.2 (for example the project's documentation site).
- Each learner's article from module 3 and their two news articles from lesson 3.4.

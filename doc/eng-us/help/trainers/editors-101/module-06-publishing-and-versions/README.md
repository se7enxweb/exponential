# Module 6: Publishing, versions and drafts

This module turns "I pressed publish" into understanding. Learners learn what a version is, how to look before they
publish, how to see what changed, and every way back when something went wrong. It is the module that makes new
editors confident.

## At a glance

| | |

| Course | [Editors 101](../README.md) |
| Duration | 3 hours 10 minutes (with a 10-minute break) |
| Lessons | 4 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 6.1: Drafts, publishing and pending items](drafts-publishing-and-pending.md) | 45 minutes | Name the version states, clean up **My drafts**, look at **My pending items** |
| [Lesson 6.2: Previewing a draft](previewing-a-draft.md) | 30 minutes | Preview a draft at four widths, go back to the form, publish from the preview |
| [Lesson 6.3: Versions and comparing them](versions-and-comparing.md) | 45 minutes | Read the versions page, filter it, compare two versions |
| [Lesson 6.4: Going back, hiding and the trash](going-back-hiding-and-the-trash.md) | 60 minutes | Restore an old text, hide and unhide, remove and restore from the trash |

## Preparing this module

- Each learner needs *My first article* with three or more versions, and the two news articles from lesson 3.4.
- The learners' role must allow hiding, removing and restoring in the course folders, and should **not** allow
  emptying the trash on a shared training site.
- If the training site uses an approval workflow, decide whether to switch it off; otherwise every publish in this
  module waits under **My pending items**.

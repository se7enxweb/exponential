# Module 5: Site packages

Packages are how Exponential moves content, classes, extensions and whole sites between installations, and site
packages are what every new installation is built from. This module goes from what a site package is, through the
packages pages and the command line, to making, comparing, uploading and installing packages.

## Preparing this module

- Each learner has a training installation made from the default site package, with *Site B* and some content below
  it (modules 1 and 2), an administrator account and shell access.
- For lesson 5.6, each learner needs a second installation to install on: a neighbour's lab or a second
  `exp:install` in another directory. Plan how archives move between learners (a shared folder is easiest).
- Check that `var/tmp/` is writable for the site user; exports go to `var/tmp/course/` and are removed at the end.
- Never remove or replace packages of the `7x` repository on a shared server: they are installer sources.
- Maintainer fields use role names and addresses at `example.invalid`.

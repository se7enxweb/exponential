# Module 6: Addresses, feeds and PDF

Content leaves the administration in more ways than a web page: through addresses people type, feeds people follow and
documents people download. This module shows editors each of these from their side.

## At a glance

| | |
|---|---|
| Course | [Editors 201](../README.md) |
| Duration | 2 hours 10 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 6.1: The address of an item and its URL aliases](url-aliases-of-an-item.md) | 45 minutes | Read generated aliases, create and remove a short redirecting alias |
| [Lesson 6.2: RSS feeds from the editor's side](rss-feeds-for-editors.md) | 30 minutes | Open a feed, find their article in it, see hiding take it out |
| [Lesson 6.3: PDF exports](pdf-export.md) | 45 minutes | Create, download, regenerate and remove a PDF export of their folder |

## Preparing this module

- Learners' role needs access to **Manage URL aliases** for their own items (it is offered in the Editor siteaccess
  as well).
- For lesson 6.2: an active RSS 2.0 export with **Training** as source (with sub items, class *Article*, title from
  **Title**, description from **Intro**) and its address on the board. Note the feed's cache time (`site.ini
  [RSSSettings] CacheTime`). The RSS page needs `rss/edit`; demonstrate it if learners lack it.
- For lesson 6.3: the `pdf/edit` policy for the learners' role on the training installation, or demonstrate. Check
  that a stored PDF can be downloaded at its public address on your web server ([PDF exports](../../../../guides/pdf-exports.md#1-opening-the-page)).

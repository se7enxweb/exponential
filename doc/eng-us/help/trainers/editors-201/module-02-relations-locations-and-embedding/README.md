# Module 2: Relations, locations and embedding

Content on a real site is a web, not a list. This module shows how items point at each other, how one item lives in
several places, and how to remove or hide content without leaving holes.

## At a glance

| | |
|---|---|
| Course | [Editors 201](../README.md) |
| Duration | 2 hours 10 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 2.1: Relations and embedding](relations-and-embedding.md) | 45 minutes | Build an article with a related, an embedded and a linked item; read both directions |
| [Lesson 2.2: One item in several places: locations](locations.md) | 45 minutes | Add, read, hide and remove a location; change the main location |
| [Lesson 2.3: Checking before removing or hiding](checking-before-removing-or-hiding.md) | 30 minutes | Read the reference list on removal, fix the reference, remove and restore |

## Preparing this module

- Learners need a course folder and a few images in the media library they may use.
- Find out whether your training installation has a type with a relation list field (lesson 2.1, step 8).
- Check the training site's setting for the reference check on removal (`content.ini [RemoveSettings]
  ReverseRelationCheck`; `warn` is shipped) so you can explain what learners will see.
- The learners' role must allow adding locations in their course folders, removing their own items and restoring
  from the trash.

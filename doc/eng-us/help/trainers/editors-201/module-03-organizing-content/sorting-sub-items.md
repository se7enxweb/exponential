# Lesson 3.2: Sorting sub items

The order of the items in a folder is often the order of a menu or a list on the site. This lesson shows where a
folder's sorting is set and how to arrange items by hand.

## At a glance

## Learning objectives

After this lesson, learners can:

- set a folder's sorting on the **Ordering** tab with **Sort by**, **Sort order** and **Set**;
- explain that the sorting applies to the folder's sub items on the site and in the administration;
- arrange items by hand with priorities: drag the grip, or use the keyboard;
- say what they need to be allowed to change the sorting.

## Trainer's notes

### How to present it

Sources: [Many items at once](../../../editing-content.md#many-items-at-once) and
[Keyboard shortcuts](../../../keyboard-shortcuts.md#lists-of-sub-items).

1. **The Ordering tab** (4 minutes). On a folder's page, the tab **Ordering** says *Use these controls to set the
   sorting method for the sub items of the current location.* **Sort by**: **Priority**, **Published**, **Modified**,
   **Name**, **Section**, **Depth**, **Class identifier**, **Class name**, **Path String**; **Sort order**:
   **Ascending** or **Descending**; then **Set**. Without permission to edit the item, the tab says so.
2. **Priorities** (4 minutes). When a folder is sorted by **Priority**, the **Sub items** list shows a grip at the
   start of each row. Drag a row to a new place, or use the keyboard: focus the grip, `Space` or `Enter` to pick the
   row up, `↑` and `↓` to move it, `Space` or `Enter` to drop it; `Alt+↑` and `Alt+↓` move a row one place at once.
   The new order is saved.
3. **The site** (2 minutes). Most designs list sub items in the folder's sorting, so menus and lists change at once.

### Common questions

**Which sorting should a news folder use?** Usually **Published**, **Descending**: newest first, nobody has to sort
by hand.

**Why is the grip missing?** The list is not sorted by priority. Set **Sort by** to **Priority** first.

**Does clicking a column heading in the Sub items list change the site's order?** No. That sorts your view of the
list; the **Ordering** tab sets the folder's order.

### Pitfalls

- **Changing the order of a live menu by accident.** In class, use only the learners' own folders.
- **Mixing up the two sortings.** A column click is for you; the Ordering tab is for the site.
- **Keyboard picking.** `Esc` puts a picked-up row back; teach it.

## Hands-on exercise

Use the training installation and your course folder (with at least four sub items).

1. Open your course folder and its **Ordering** tab. Write down the current **Sort by** and **Sort order**.
2. Choose **Sort by**: **Name**, **Sort order**: **Ascending**, and press **Set**.
3. Look at the **Sub items** list and at the folder on the site (**View on site**): the items are in alphabetical order
   where the design lists them.
4. Choose **Sort by**: **Priority** and press **Set**.
5. In the **Sub items** list, drag the last row to the top with its grip.
6. Focus the grip of the second row with `Tab`, press `Space`, move it down with `↓` twice, and press `Space`.
7. Press `Alt+↑` on a grip to move a row up one place.
8. Check the order on the site again.
9. Click the **Name** column heading of the list: the list is sorted for you only. Reload the page: the priority
   order is back.

## Expected result

- The folder is sorted by **Priority**, in the order the learner arranged.
- The site lists the items in the same order (in designs that list sub items).
- Step 9 showed that a column click does not change the folder's sorting.
- The trainer checks by asking a learner to move a row with the keyboard only on the projector.

## Quiz

1. Where do you set the order in which a folder's sub items appear on the site?
2. Which sorting must a folder have before you can drag rows?
   A. Name B. Published C. Priority D. Modified
3. Which keys pick up and drop a row on its grip?
4. True or false: clicking a column heading in the Sub items list changes the order on the site.
5. Suggest a sorting for a news folder and explain why.

<details>
<summary>Answers</summary>

1. On the folder's **Ordering** tab, with **Sort by**, **Sort order** and **Set**.
2. **C.**
3. `Space` or `Enter` ([Keyboard shortcuts](../../../keyboard-shortcuts.md#lists-of-sub-items)).
4. **False.** It sorts the list for you only.
5. **Published**, **Descending**: the newest item first, without manual work.

</details>

# Lesson 2.3: Exponential Layouts, written test

This test closes the Exponential Layouts course. It checks the concepts that keep editors and site builders from
breaking pages: what a layout, a zone and a block are, how a mapping decides where a layout is used, why a shared
layout exists, and what each button of the editor does to the published page.

> **Note**
> This is the trainer's own assessment, not an official certification. The **Layouts** tab is shown only to roles
> that may work with layouts; check the learners' accounts before the test.

## Learning objectives

Learners who pass this test have shown that they can:

- explain layouts, zones, blocks and layout types;
- explain how a mapping decides which pages use a layout, and which mapping wins;
- explain shared layouts and linked zones;
- tell what **Publish layout**, **Save draft and close**, **Discard** and **Cancel** do;
- name the two tabs of a block's properties.

## Trainer's notes

### How to run it

1. Hand out the questions without the key; 25 minutes.
2. Go through the answers with [The layouts editor](../../../layouts-editor.md) on the projector.
3. Score with the rule under **Scoring**.

### Common questions

**The block groups differ on our site.** Question 6 uses the groups of a standard installation. Adapt it to the block
list your site shows.

**Mappings are a site builder's job here.** Keep questions 7 and 8 anyway: editors should know why a layout appears
on a page, even if they may not change mappings.

### Pitfalls

- **Learners who only used the editor.** Questions 9 and 10 need the shared layout idea; teach it before the test.
- **Cache questions.** Question 12 depends on whether your site clears caches by itself; say which before the test.

## The test

1. What decides which zones a layout has? A. the content type B. the layout type C. the siteaccess D. the mapping
2. Name the three parts of a layout, from the largest to the smallest.
3. Where do the text and images of an article live: in the layout or in the content item?
4. You open a published layout in the editor. What do visitors see while you work?
5. What is the difference between **Publish layout** and **Publish and continue editing**?
6. Name two groups of block types in the **Add a block** list.
7. What is a mapping (also called a rule)?
8. Two enabled mappings match the same page. Which one is used?
9. What is a shared layout for?
10. You want the same header and footer on twenty layouts. Do you copy the blocks into each layout? Why or why not?
11. You select a block. Its properties appear in two tabs. Name them and say what each holds.
12. You leave the editor with **Cancel**. What happens to your draft?

<details>
<summary>Answers</summary>

1. **B.** The layout type (*1 column*, *2 columns*, *Sidebar left* ...) decides which zones there are
   ([The layouts editor](../../../layouts-editor.md#layouts-zones-and-blocks)).
2. Layout, zones, blocks ([The layouts editor](../../../layouts-editor.md#layouts-zones-and-blocks)).
3. In the content item; the layout decides what a page is made of and where each part goes
   ([The layouts editor](../../../layouts-editor.md)).
4. The published layout; you work on a draft until you publish
   ([The layouts editor](../../../layouts-editor.md#the-editor)).
5. **Publish layout** publishes and closes the editor; **Publish and continue editing** publishes and keeps the editor
   open with a new draft ([The layouts editor](../../../layouts-editor.md#publish-keep-or-throw-away)).
6. Two of **Basic**, **Components**, **Listing**, **Gallery**, **Containers**, **Placeholders**
   ([The layouts editor](../../../layouts-editor.md#add-a-block)).
7. A rule that decides on which pages a layout is used, by targets (a location, a subtree, a module page) and
   conditions (for example a content type or a siteaccess)
   ([The layouts editor](../../../layouts-editor.md#which-pages-use-a-layout)).
8. The first enabled mapping by priority whose targets and conditions match
   ([The layouts editor](../../../layouts-editor.md#which-pages-use-a-layout)).
9. It holds blocks many pages use, such as a header and footer
   ([The layouts editor](../../../layouts-editor.md#layouts-zones-and-blocks)).
10. No. Link a zone of each layout to the zone of the shared layout instead of copying the blocks, so a change is made
    once ([The layouts editor](../../../layouts-editor.md#layouts-zones-and-blocks)).
11. **Content**: what the block shows; **Design**: how it looks, for example the view type and style
    ([The layouts editor](../../../layouts-editor.md#change-a-block)).
12. It stays; **Cancel** leaves the editor and goes back to where you came from
    ([The layouts editor](../../../layouts-editor.md#publish-keep-or-throw-away)).

</details>

## Scoring

- One point per question; question 2 needs the right order for the point, question 11 both tabs.
- Pass: 8 of 12 points or more, with questions 4 and 12 correct: both protect the published page.
- Give feedback as in [Lesson 1.6](../module-01-designing-assessments/giving-feedback-on-results.md).

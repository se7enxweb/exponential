# Module 2: Assessing the editorial courses

This module holds the assessments for the courses that editors take: Editors 101, Exponential Layouts and Exponential
Intelligence. Each course has a written test and a practical task. Run the pair at the end of the course, or pick the
one that fits: the written test for knowledge, the task for skill.

> **Note**
> These are the trainer's own assessments, not an official certification. Adapt the questions to the release, site
> package and design of your training installation.

## At a glance

| | |
|---|---|
| Course | [Assessments and practical exercises](../README.md) |
| Duration | 5 hours 25 minutes for all six; each pair 1 hour 45 to 1 hour 55 minutes |
| Lessons | 6 |
| Level | Beginner to intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [2.1 Editors, written test](editors-written-test.md) | 45 min | Fourteen questions on drafts, versions, the trash, media, languages and search |
| [2.2 Editors, practical task](editors-practical-task.md) | 70 min | Build a news folder, upload an image, translate, restore a version and an item |
| [2.3 Exponential Layouts, written test](layouts-written-test.md) | 40 min | Twelve questions on layouts, zones, blocks, mappings and the editor's buttons |
| [2.4 Exponential Layouts, practical task](layouts-practical-task.md) | 65 min | Build a two-column layout, keep a draft, publish, read a mapping |
| [2.5 Exponential Intelligence, written test](intelligence-written-test.md) | 40 min | Twelve questions on drafts, permissions, review, audit and the switch |
| [2.6 Exponential Intelligence, practical task](intelligence-practical-task.md) | 65 min | Improve an article, catch a planted error, review the assistant's drafts |

## Preparing this module

- [ ] One training installation per learner (or one folder and account per learner on a shared one), mail transport
      set to `file`, accounts at `example.invalid`.
- [ ] For lesson 2.2: a second content language on the site, a rights-free image file per learner, and an Editor role
      that may restore from the trash.
- [ ] For lesson 2.4: the layouts extensions active, the **Layouts** tab visible to the learners' role, the layout
      type *2 columns* (or another two-zone type), at least one enabled mapping to read.
- [ ] For lesson 2.6: the assistant switched on with a provider you control and limits set; one prepared article per
      learner with a planted factual error; one image without alternative text.
- [ ] Printed questions and rubrics, and the answer keys kept separately.

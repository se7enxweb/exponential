# Module 4: Vector

Vector is for work bigger than one field: several articles, a folder, a translation. This module teaches its two
gates (a plan, then staged changes) and the controls that keep the editor in charge.

## At a glance

| | |
|---|---|
| Course | [Exponential Intelligence](../README.md) |
| Duration | 2 hours 40 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 4.1: Vector threads and their scope](threads-and-scope.md) | 45 minutes | Start a thread scoped to their folder; choose mode, review and model |
| [Lesson 4.2: Plans and staged review](plans-and-staged-review.md) | 60 minutes | Approve a plan, review staged changes, write drafts |
| [Lesson 4.3: Run, stop, checkpoints and What changed](run-stop-checkpoints-and-what-changed.md) | 45 minutes | Stop a run, read the cost, restore a checkpoint, revert a part |

## Preparing this module

- The learners' role needs `expai/vector` (with Review **staged**, and **direct** only if you teach lesson 4.3's direct
  draft that way; the Intelligence tab writes direct drafts anyway) and a subtree limitation to the training folder.
- Each course folder with three to five short articles, so plans stay small and fast.
- Keep learners' scopes separate to avoid conflicts, unless you want to show one.
- Usage limits for the training accounts; a plan's estimate shows learners the cost before they run it.

# Module 6: Responsible use

The most important module of the course. The assistant is safe by design, but only editors can keep personal data out
of requests, check what it wrote, and use it with care for the budget. Teach this module even when time is short.

## At a glance

| | |
|---|---|
| Course | [Exponential Intelligence](../README.md) |
| Duration | 2 hours 25 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 6.1: Privacy: what goes to the provider, and what never should](privacy-and-personal-data.md) | 45 minutes | Judge and rewrite five briefs; read a provider's region and retention |
| [Lesson 6.2: Reviewing AI output](reviewing-ai-output.md) | 60 minutes | Find planted errors in a draft with a checklist; peer review |
| [Lesson 6.3: Cost, limits and fair use](cost-limits-and-fair-use.md) | 30 minutes | Read costs and limits, find the cheapest writing model, write cost habits |

## Preparing this module

- Project the five briefs of lesson 6.1 and the checklist of lesson 6.2; the example names and addresses are invented
  (use `example` names and `example.invalid` addresses only).
- For lesson 6.1, optionally a data policy rule on a training section (`[DataPolicy] SectionRegions`), to show a
  refusal.
- For lesson 6.2, one draft per course folder with planted errors: a wrong date, an invented statistic, a broken link
  and a sentence addressed to an assistant. Write it yourself; do not ask the assistant to plant errors in real
  content.
- Ask your organization's data protection contact for its rules on AI use, and quote them in lesson 6.1.

# Module 7: Administration

Lessons 7.1 to 7.3 are for the administrators who run the assistant; editors may skip them and join for the capstone
(lesson 7.4), which closes the course for everyone.

## At a glance

| | |
|---|---|
| Course | [Exponential Intelligence](../README.md) |
| Duration | 3 hours 25 minutes (with a 10-minute break) |
| Lessons | 4 |
| Level | Advanced (lessons 7.1 to 7.3), intermediate (lesson 7.4) |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 7.1: Providers and models](providers-and-models.md) | 45 minutes | Read the Models and providers page; run a test prompt |
| [Lesson 7.2: Switching on, keys, limits and budgets](switching-on-settings-and-limits.md) | 60 minutes | Switch the assistant on and off on their own training installation; set a limit |
| [Lesson 7.3: EI: Summary, the help pages and the audit trail](the-dpo-page-help-and-audit.md) | 30 minutes | Produce the summary as PDF; find help pages; check the audit |
| [Lesson 7.4: Capstone, an editorial task end to end](capstone-an-editorial-task-end-to-end.md) | 60 minutes | Complete a task from brief to approval; checklist review |

## Preparing this module

- For lessons 7.1 and 7.3: an administrator account per learner on the training installation (or demonstrate).
- For lesson 7.2: each administrator learner needs a training installation of their own with shell access, and a
  provider key meant for training (or a local model). Never use a production key.
- For lesson 7.4: the folder of sample images, approval accounts if an approval workflow applies, and the checklists
  printed.

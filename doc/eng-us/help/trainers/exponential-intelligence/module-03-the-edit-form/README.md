# Module 3: The edit form

Most editors meet the assistant in the edit form, one field at a time. This module covers every helper there and
ends with alternative texts for images.

## At a glance

| | |
|---|---|
| Course | [Exponential Intelligence](../README.md) |
| Duration | 2 hours 25 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 3.1: Field actions in the edit form](field-actions.md) | 45 minutes | Shorten, rewrite, suggest and translate fields; undo; read a record |
| [Lesson 3.2: Fill the fields, presets and the Improve menu](fill-the-fields-presets-and-improve.md) | 45 minutes | Fill a new article from a brief; use presets and Improve |
| [Lesson 3.3: Alt text for images](alt-text-for-images.md) | 45 minutes | Write and review an alt text; mark a decorative image; read the report |

## Preparing this module

- Check that the edit form controls are switched on for the training siteaccess (the area and the field bars appear
  in the article form).
- For lesson 3.3: a model that can look at images must be configured and allowed by the data policy; sample images
  without people, and one decorative image, in each course folder.
- Know which presets your article class has; the standard article maps title and summary.
- Project the alt text rules of lesson 3.3.

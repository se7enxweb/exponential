# Module 2: The Intelligence tab

The first hands-on module. Each learner asks the assistant for two articles below their own folder, decides what to
do with the drafts, and learns to read what happened.

## At a glance

| | |
|---|---|
| Course | [Exponential Intelligence](../README.md) |
| Duration | 2 hours 10 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 2.1: A first conversation in the Intelligence tab](a-first-conversation.md) | 45 minutes | Write a brief and send it; read the answer and the drafts |
| [Lesson 2.2: Keeping, sending and discarding drafts](keeping-sending-and-discarding-drafts.md) | 45 minutes | Keep, edit, discard and send a draft |
| [Lesson 2.3: History, records and new conversations](history-records-and-new-conversations.md) | 30 minutes | Read the history and a turn's record; start a new conversation |

## Preparing this module

- Each learner's course folder where they may create articles.
- Run one request yourself before the class and time it: a hosted model answers within a minute for small briefs; a
  local model on an ordinary server can take minutes per step.
- Decide whether an approval workflow should apply in lesson 2.2 (it shows the waiting case) or not.
- Usage limits for the training accounts (lesson 7.2).

# Module 5: Accessibility and right to left

A theme decides most of a public site's accessibility, and whether the site can serve languages written right to
left. This module starts with an honest reading of what the product ships, then turns to the learners' own theme: the
page language, landmarks, current page, focus and motion; a testing routine with findings sorted into template and
content work; and direction-safe templates and stylesheets, tested in the public theme and in the administration.

## Preparing this module

- An axe-based accessibility checker installed in the browser of every learner computer, and the operating system's
  screen reader switched on once to check it works (lesson 5.3).
- A Chromium-based browser for the rendering panel's emulation of reduced motion (lesson 5.3).
- In the administration of each installation, check that **Interface language** offers Hebrew; it needs the Hebrew
  interface translation installed (the list shows how complete each translation is).
- Each learner signs in with their own training administrator, never a shared account: the interface language is a
  user preference.
- Pair learners for lesson 5.3.

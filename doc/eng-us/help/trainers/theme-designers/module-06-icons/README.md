# Module 6: Icons

Exponential has two kinds of icons. Class and file type icons come from icon themes, folders of images with an
`icon.ini`, and an extension can ship one. admin4's interface icons are Bootstrap Icons drawn as masks in the text
color, and an extension can add its own. This short module covers both, building on the extension and the dashboard
block of the earlier modules.

## Preparing this module

- For lesson 6.1, two small PNG files per learner (32 x 32 and 16 x 16), drawn by the learner or the trainer, or the
  permission to copy one from `share/icons/crystal-admin/` for the exercise; note the license in that folder's
  `COPYING` file for the discussion in module 8.
- A content class with published items in one folder of the training site; write its identifier on the board.
- Learners' administration in admin4 with the `training_notes` block and `training_admin.css` from module 4.
- The **Interface** tool must offer the **Classic** design for step 9 of lesson 6.1 (the role needs `uiswitch/design`).

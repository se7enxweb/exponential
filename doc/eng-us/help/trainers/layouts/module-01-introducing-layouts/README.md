# Module 1: Introducing Exponential Layouts

Before anyone drags a block, learners need the picture and the rules. This module gives both, and walks around the
screens without changing anything.

## At a glance

| | |
|---|---|
| Course | [Exponential Layouts](../README.md) |
| Duration | 1 hour 45 minutes |
| Lessons | 3 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 1.1: The five ideas of Exponential Layouts](the-five-ideas.md) | 30 minutes | Sketch a page as zones, blocks, collections and a rule |
| [Lesson 1.2: Finding your way: the dashboard and the editor](finding-your-way.md) | 45 minutes | Read the dashboard, the lists, a preview and a mapping |
| [Lesson 1.3: Who may do what with layouts](roles-and-permissions.md) | 30 minutes | Read the course role, design two roles, agree on team rules |

## Preparing this module

- A training installation with the layouts extensions active and some layouts with mappings (sample layouts, or a
  few you build before the class). The public front page should be built with a layout.
- One account per learner with a role that has **read** and **edit** on `explayouts`, `explayouts_ui` and
  `explayouts_ui_api`; learners work in the administration, not in the Editor siteaccess.
- Sign in with one learner account and check that the **Layouts** tab and **New layout** appear.

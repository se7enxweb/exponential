# Module 6: Drafts and publishing

The layout built in modules 2 to 5 goes live here. This module teaches publishing and every alternative to it, and
the checks before a layout is handed over. Module 7 then maps it to pages.

## At a glance

| | |
|---|---|
| Course | [Exponential Layouts](../README.md) |
| Duration | 1 hour 30 minutes |
| Lessons | 2 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 6.1: Publishing, keeping and discarding a draft](publishing-keeping-and-discarding.md) | 45 minutes | Publish, publish and continue, discard, save a draft, answer the cache question |
| [Lesson 6.2: Previewing, checking and handing over](previewing-and-handing-over.md) | 45 minutes | Preview, check at phone width and signed out, write a handover note |

## Preparing this module

- The learners' course layouts with the blocks of modules 3 to 5.
- Find out whether the training installation clears caches automatically after a publish (otherwise the editor asks)
  and show the question once.
- Find out where your installation offers share links and export, to show in lesson 6.2.
- Publishing learners' layouts changes nothing on the site until module 7 maps them; reassure the class.

# Module 3: Blocks

The hands-on heart of the course. Learners fill their course layout with blocks of every basic kind and learn the
editor's movements until they are routine.

## At a glance

| | |
|---|---|
| Course | [Exponential Layouts](../README.md) |
| Duration | 3 hours 10 minutes (with a 10-minute break) |
| Lessons | 4 |
| Level | Beginner to intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 3.1: Adding, moving and removing blocks](adding-moving-and-removing-blocks.md) | 45 minutes | Add, select, drag, duplicate and delete blocks |
| [Lesson 3.2: Text blocks: Title, Text, Rich text, Markdown and HTML](text-blocks.md) | 45 minutes | Fill a title, a rich text and a Markdown block |
| [Lesson 3.3: Buttons, images and the Design tab](buttons-images-and-the-design-tab.md) | 45 minutes | Add a button and an image, name blocks, apply a theme class |
| [Lesson 3.4: Containers and the Full view block](containers-and-the-full-view-block.md) | 45 minutes | Split a zone into columns, add a Full view block |

## Preparing this module

- Each learner's course layout from module 2.
- Two or three CSS classes of the training site's theme that visibly change a block (a background, a spacing), written
  on the board for lesson 3.3.
- An image address from the training site's media library for lesson 3.3, and an `https://` address for links.
- Open each block type once on your training installation and note the exact field names of its **Content** tab;
  they come from the block handlers and can differ between versions.

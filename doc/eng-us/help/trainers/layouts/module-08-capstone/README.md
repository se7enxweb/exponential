# Module 8: Capstone

The course ends with one real page: a campaign landing page, planned on paper, reviewed by a partner, then built,
published and mapped without step-by-step help.

## At a glance

| | |
|---|---|
| Course | [Exponential Layouts](../README.md) |
| Duration | 2 hours 25 minutes (with a 10-minute break) |
| Lessons | 2 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 8.1: Planning a landing page](planning-a-landing-page.md) | 45 minutes | Plan the page on a planning sheet; review a partner's plan |
| [Lesson 8.2: Capstone, building a campaign page](building-a-campaign-page.md) | 90 minutes | Build, publish and map the page; review against a checklist |

## Preparing this module

- Print the brief, the planning sheet and the checklist, one per learner.
- Create a published content page `Autumn campaign - <first name>` in each learner's course folder, or plan five
  minutes for learners to create it.
- A folder with at least ten published articles for the dynamic list, and three articles to pick as highlights.
- The shared header/footer layout from module 5 and a list of the theme's CSS classes.

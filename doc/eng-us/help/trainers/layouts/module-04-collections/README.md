# Module 4: Collections

Listing blocks make a layout come alive: they show the site's content and keep it current. This module teaches the two
kinds of collection and the settings that turn them into editorial tools.

## At a glance

| | |
|---|---|
| Course | [Exponential Layouts](../README.md) |
| Duration | 2 hours 40 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 4.1: Listing blocks and manual collections](listing-blocks-and-manual-collections.md) | 45 minutes | Pick three articles into a List block, order them, change the view type |
| [Lesson 4.2: Dynamic collections and query types](dynamic-collections-and-queries.md) | 60 minutes | Build a newest-articles list with a query, filter and sort |
| [Lesson 4.3: Offset, limit and pinning](offset-limit-and-pinning.md) | 45 minutes | Build a lead-plus-list and pin an item |

## Preparing this module

- A folder on the training site with at least ten published articles (the learners' course folders from Editors 101
  work), and three named articles for lesson 4.1.
- Try the collection panel of your installation once: note how a block chooses between manual and dynamic, which query
  types it lists and how positions are numbered, so you can show it on the projector.

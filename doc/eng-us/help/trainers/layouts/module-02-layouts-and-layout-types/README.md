# Module 2: Layouts and layout types

Learners choose a type, create their own course layout and learn the housekeeping of a growing list of layouts. The
layout made here is used in every later module.

## At a glance

| | |
|---|---|
| Course | [Exponential Layouts](../README.md) |
| Duration | 2 hours 10 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 2.1: Layout types and their zones](layout-types-and-zones.md) | 30 minutes | Choose layout types for three pages |
| [Lesson 2.2: Creating a layout](creating-a-layout.md) | 45 minutes | Create a `layout_2` course layout and meet the editor |
| [Lesson 2.3: Managing layouts: preview, copy, export and delete](managing-layouts.md) | 45 minutes | Preview, copy and delete a copy; read export and import |

## Preparing this module

- The learners' role needs edit on the layouts modules; for lesson 2.3's export and import screens, the transfer
  policies (or demonstrate them).
- Agree on the naming pattern: name `Training - <first name>`, identifier `training_<first name>`.
- Find out where your installation's editor offers to copy a layout, to show it in lesson 2.3.

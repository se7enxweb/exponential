# Module 7: Mapping rules

Mappings decide which page gets which layout. This module teaches reading them, making them and finding out why a page
does not look as expected.

## At a glance

| | |
|---|---|
| Course | [Exponential Layouts](../README.md) |
| Duration | 2 hours 40 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 7.1: Reading layout mappings](reading-layout-mappings.md) | 45 minutes | Read mappings and work out which one serves two pages |
| [Lesson 7.2: Creating a mapping](creating-a-mapping.md) | 60 minutes | Map the course layout to their own test page, disable and enable it |
| [Lesson 7.3: Troubleshooting which layout a page gets](troubleshooting-which-layout-a-page-gets.md) | 45 minutes | Find and fix a problem the trainer planted |

## Preparing this module

- Each learner needs a published course layout (published in module 6) and a published test page `Layout test - <first name>` in their course folder.
- Learners' role needs edit on `explayouts_ui` for the mapping screens.
- For lesson 7.3, prepare one fault per learner as listed in the lesson, and a card per learner naming it.
- Know how caches are cleared on the training installation after a mapping change (the editor's automatic clear, the
  mapping's cache clear, or an administrator).

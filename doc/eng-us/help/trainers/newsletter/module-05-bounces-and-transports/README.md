# Module 5: Bounces and transports

This module is for administrators. It covers the way returned mail takes back into the newsletter, the plan for
switching a real site from files to real sending, and the deliverability tools. The training installation keeps
writing every mail to a file: the switch is a paper plan, never a change in class.

## Preparing this module

- [ ] Transports still `file` (settings viewer) at the start and at the end of the module.
- [ ] No mail account stored on the training installation that points at a real mailbox.
- [ ] Shell access for lesson 5.1, step 7.
- [ ] For lesson 5.2: ask the learners beforehand who provides their organization's mail, so the plan has real
      questions (but no secrets) in it.
- [ ] Learners have an edition that was not sent (from lesson 4.4) for the test group send in lesson 5.3.

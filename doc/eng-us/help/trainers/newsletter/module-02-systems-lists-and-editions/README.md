# Module 2: Systems, lists and editions

In this module learners build the content side of a newsletter: a system of their own, a list with a safe
configuration, two editions with articles, and a paused recurring send. Nothing is sent yet.

## At a glance

| | |
|---|---|
| Course | [Newsletters with CJW Newsletter](../README.md) |
| Duration | 3 hours 30 minutes |
| Lessons | 4 |
| Level | Beginner to intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [2.1 Newsletter systems and the tree](newsletter-systems-and-the-tree.md) | 45 minutes | Find the root and `RootFolderNodeId`, create a system |
| [2.2 Creating and configuring a list](creating-and-configuring-a-list.md) | 60 minutes | Create a list with sender and test addresses at `example.invalid` |
| [2.3 Writing an edition](writing-an-edition.md) | 60 minutes | Write an edition with two articles, preview it, copy it |
| [2.4 Recurring sends, article pools and approval](recurring-sends-pools-and-approval.md) | 45 minutes | Save a paused recurring send, follow an approval |

## Preparing this module

- [ ] Module 1 done: every transport writes files; the newsletter root and section exist.
- [ ] Each learner's role may create `CJW Newsletter System`, `List`, `Edition` and `Article` below the root.
- [ ] The public siteaccess the lists should use is known (learners ask for it in lesson 2.2).
- [ ] For lesson 2.4: one list of the trainer's with **Approval** switched on and an edition waiting for approval;
      an approver account that is not the trainer's own.
- [ ] A short list of the test addresses at `example.invalid` on the whiteboard.

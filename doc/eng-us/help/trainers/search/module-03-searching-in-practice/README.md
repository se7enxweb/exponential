# Module 3: Searching in practice

This module puts the engine to work in the places people use it: the administration's quick and advanced search, the
content finder for ids and addresses, the public site's search for visitors, and the statistics that show what
visitors looked for.

## At a glance

| | |
|---|---|
| Course | [Search](../README.md) |
| Duration | 2 hours (four lessons) |
| Lessons | 4 |
| Level | Intermediate |
| Format | Hands-on in the administration and the public site; short terminal work in lesson 3.4 |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [3.1 The admin search and the advanced search](the-admin-search-and-advanced-search.md) | 30 min | Search with scope, phrase, class, class attribute, section and date |
| [3.2 The content finder](the-content-finder.md) | 30 min | Find objects by id, address and file path; read versions, locations and trash entries |
| [3.3 Site search for visitors](site-search-for-visitors.md) | 30 min | Search as a visitor and shape `content/search` with its parameters |
| [3.4 Search statistics](search-statistics.md) | 30 min | Record, read, act on and reset search phrases |

## Preparing this module

- One training installation per learner with sample content, an administrator account, and the public site
  reachable in a private browser window.
- Check that the public design has a search box; if not, prepare the `content/search` address for lesson 3.3.
- Make sure the trash of each training installation holds at least one item for lesson 3.2 (trash a sample item
  before the class).
- Never use a live site's search statistics in class: they may contain personal data.

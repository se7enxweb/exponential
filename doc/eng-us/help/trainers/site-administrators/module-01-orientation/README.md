# Module 1: Getting oriented as a site administrator

Before learners change anything, they need to know where things are and how the installation is configured. This
module gives every learner a working training installation, a tour of the Setup area, a reading of System
information, and the two ways to read and change INI settings: the settings page and `exp:ini`.

## At a glance

| | |
|---|---|
| Course | [Site administration](../README.md) |
| Duration | 2 hours 55 minutes (five lessons) |
| Lessons | 5 |
| Level | Intermediate |
| Format | Hands-on; one training installation per learner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [1.1 What a site administrator does](what-a-site-administrator-does.md) | 30 min | Install and start a training installation, sign in |
| [1.2 A tour of the Setup area](a-tour-of-the-setup-area.md) | 35 min | Find Setup pages by purpose, bookmark one |
| [1.3 System information and health checks](system-information-and-health-checks.md) | 35 min | Read health checks, download a report, run `exp:system:info` |
| [1.4 The settings page](the-settings-page.md) | 40 min | Trace a setting, compare siteaccesses, change and remove one |
| [1.5 INI files and exp:ini on the command line](ini-files-and-exp-ini.md) | 35 min | Read, write and remove a setting with `exp:ini` |

## Preparing this module

- One machine per learner with a terminal, PHP 8.1 or later, Composer 2 and Git, and the Exponential code of the
  release you teach (see [The console install](../../../../install/07-console-install.md)).
- If the network is slow, prepare the training installations in advance and only start them in class.
- A printed copy of the [Lab quick card](../../lab-quick-card.md).
- Your own training installation on the projector, installed the same way as the learners'.
- Check that **Setup** in your version shows the groups named in lesson 1.2; adjust the exercise if it differs.

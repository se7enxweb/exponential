# Module 4: Sections, siteaccesses and object states

Four ideas organize an installation beyond the content tree: sections group content by area, siteaccesses decide how
a request reaches the site, object states group content by stage, and content languages hold the translations. This
module teaches each from the administrator's side, with a members area and a small review workflow as exercises.

| [4.3 Object states](object-states.md) | 45 min | Build a review group, hide unapproved content from visitors |
| [4.4 Content languages](content-languages.md) | 40 min | Add a language, translate an article, read SiteLanguageList |

## Preparing this module

- The training installations from Modules 1 to 3, with the users `sam.sample` and `nina.news`, the group
  `Training team`, and the `News` folder.
- Rehearse lessons 4.1 and 4.3 on your own installation: both change what visitors see, and both need a cleared
  content cache before the result shows.
- Decide whether learners undo the changes at the end (lesson 4.3, step 11 does); later modules assume visitors can
  read the site.
- For lesson 4.2, know how your lab was installed (URL, host or port matching).

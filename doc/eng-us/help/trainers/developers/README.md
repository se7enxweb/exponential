# Developers: course overview

This course teaches PHP developers to build on Exponential. Every module adds a working piece to one development
installation that each learner owns: templates and overrides, a datatype override, a fetch function, a module view
with its own policy, an extension with settings, a console command, a persistent object table, a workflow event, a
cronjob part, a REST provider and a test. The course ends with the RAD tools, deploying under Velocity and a pull
request.

## Who it is for

- PHP developers starting their first Exponential project.
- Agency developers who maintain sites built on earlier versions and want the 6.x way of working.
- Developers who will write extensions for others.

**Outcome:** after the course, a developer can build a site's templates, content model and features in extensions of
their own, test them, deploy them under Velocity and contribute changes upstream.

## Format and duration

| | |
|---|---|
| Duration | 52 lessons, about 44 hours of lessons (about seven days with breaks) |
| Format | Hands-on; classroom or online; one development installation per learner |
| Level | Intermediate to advanced |
| Prerequisites | PHP and object-oriented programming, Git, Composer, a terminal; a GitHub account for Module 13 |
| Lab | A development installation of Git clones on SQLite, built in Module 1 ([Develop with Git](../../develop-with-git.md)) |

## Reading path

For a trainer preparing this course, in this order:

1. [Trainers: start here](../trainers-start-here.md) and [Teaching the core concepts](../teaching-the-core-concepts.md).
2. [Develop with Git](../../develop-with-git.md) and [Update with Git](../../update-with-git.md).
3. The installation book chapters [3](../../../install/03-getting-the-code.md), [7](../../../install/07-console-install.md)
   and [8](../../../install/08-serving-the-site.md).
4. [The content model and editing content](../../../guides/content-model-and-editing.md) and
   [Templates and design](../../../guides/templates-and-design.md).
5. [Extensions](../../../guides/extensions.md), [RAD tools](../../../features/6.0/rad-tools.md) and the
   [Extension development](../../extension-development/README.md) book.
6. [REST API v1 and v2](../../../guides/rest-api-v1-and-v2.md) and [Coding standards](../../../standards/coding-standards.md).
7. Modules 1 to 13, in order; build every module's piece on your own development installation before teaching it.

## Suggested schedules

| Schedule | Plan |
|---|---|
| Seven days | One to two modules a day in order; day 7 for Modules 12 and 13 and a review of each learner's extension |
| Two blocks of four days | Days 1-4: Modules 1 to 7 (templates, content model, fetches, views, extensions); days 5-8 a month later: Modules 8 to 13 |

# Module 2: Building the training lab

A course is only as good as its lab. This module teaches trainers to build one that works on the first try: machines
that meet the requirements, the same release for everyone, one installation per learner or a well-protected shared
site, learner accounts with the right roles, and a routine to reset everything for the next group.

## At a glance

| | |
|---|---|
| Course | [Train the trainer](../README.md) |
| Duration | 5 hours 15 minutes (eight lessons) |
| Lessons | 8 |
| Level | Intermediate |
| Format | Hands-on; one machine with a terminal per learner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [2.1 Requirements for a training machine](requirements-for-a-training-machine.md) | 40 min | Check PHP, extensions, `php.ini`, Composer and Git |
| [2.2 Getting the code for a class](getting-the-code-for-a-class.md) | 40 min | Clone or create-project a fixed release |
| [2.3 One installation per learner with exp:install](one-install-per-learner.md) | 45 min | Print, dry-run and run an install |
| [2.4 Serving the lab sites with Velocity](serving-the-lab-sites.md) | 35 min | Start, check, move and stop a site |
| [2.5 Learner accounts and roles](learner-accounts-and-roles.md) | 45 min | Create users at example.invalid and check their roles |
| [2.6 Resetting the lab between sessions](resetting-the-lab.md) | 35 min | Keep a golden copy and reinstall safely |
| [2.7 A shared training server or one installation per learner](shared-server-or-one-per-learner.md) | 45 min | Limit a learner role to a subtree |
| [2.8 Choosing the site package for a class](choosing-the-site-package-for-class.md) | 30 min | Install a clean site and compare |

## Preparing this module

- A machine per learner with a terminal, PHP 7.4 or later, Composer 2 and Git; network access to GitHub and
  Packagist, or the code prepared in advance.
- Enough disk for two or three installations per learner.
- A printed list of the commands of lessons 2.3 and 2.4.
- For lesson 2.7: one shared installation the learners can reach.

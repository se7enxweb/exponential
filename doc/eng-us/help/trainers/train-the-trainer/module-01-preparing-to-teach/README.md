# Module 1: Preparing to teach Exponential

This module prepares a trainer before any lab is built: what the course material is, where its facts come from, who
the learners are, what the license allows, and how to introduce Exponential correctly. It needs one installation
with the Help center and no special setup.

| Lessons | 5 |

## Lessons

| Lesson | Duration | What learners do |

| [1.5 Names and history in class](names-and-history-in-class.md) | 20 min | Write and rehearse a two-minute opening |

## Preparing this module

- One Exponential installation where every learner can sign in to the administration with the policy
  `exphelp/read` (an administrator account per learner, or the Editor role on a new installation).
- A projector or screen sharing.
- Printed or open: [Naming rules quick card](../../../advocates/naming-rules-quick-card.md) and
  [Free documentation](../../../free-documentation.md).
- A folder per learner for the course-folder exercise of lesson 1.4.

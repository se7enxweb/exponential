# Module 5: Accessibility and inclusion

Every learner should be able to follow an Exponential course. This module covers the materials, the features of the
administration that help learners with different needs, teaching in other languages, and planning accommodations.

## At a glance

| | |
|---|---|
| Course | [Train the trainer](../README.md) |
| Duration | 2 hours 30 minutes (four lessons) |
| Lessons | 4 |
| Level | Beginner to intermediate |
| Format | Workshop; a training installation in the Admin 4 design per learner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [5.1 Accessible course materials](accessible-course-materials.md) | 40 min | Build and test an accessible handout |
| [5.2 Teaching with the accessible administration](teaching-with-the-accessible-administration.md) | 40 min | Use the administration by keyboard, color mode and zoom |
| [5.3 Languages and right to left in class](languages-and-right-to-left-in-class.md) | 35 min | Switch the interface language and build a glossary |
| [5.4 Accommodations and inclusive practice](accommodations-and-inclusive-practice.md) | 35 min | Plan accommodations and an accommodated quiz |

## Preparing this module

- Training installations in the Admin 4 design, with a test account per learner (lesson 5.3 changes preferences).
- A screen reader or the system's read-aloud feature on at least one machine.
- Printed: [Accessible slides and visuals](../../../advocates/accessible-slides-and-visuals.md).

## Timing plan

| Time | Item |

# Module 6: Assessment and follow-up

The last module of the train-the-trainer course covers how a trainer knows learners have learned, how they prove it
honestly, how the course improves, and how learners keep going afterwards.

## At a glance

| | |
|---|---|
| Course | [Train the trainer](../README.md) |
| Duration | 2 hours 40 minutes (five lessons) |
| Lessons | 5 |
| Level | Beginner to intermediate |
| Format | Workshop; paper or a shared document; one training installation for the practical task design |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [6.1 Checking understanding during class](checking-understanding-during-class.md) | 30 min | Write show-me questions, a poll and a summary prompt |
| [6.2 Quizzes and practical tasks](quizzes-and-practical-tasks.md) | 45 min | Build an assessment with a rubric for Module 2 |
| [6.3 Collecting feedback](collecting-feedback.md) | 30 min | Write a feedback slip and sort feedback |
| [6.4 Certificates of attendance in your own name](certificates-of-attendance.md) | 25 min | Write an honest certificate text |
| [6.5 After the course](after-the-course.md) | 30 min | Write a follow-up message and a clean-up list |

## Preparing this module

- Copies of the Module 2 lessons for the assessment exercise.

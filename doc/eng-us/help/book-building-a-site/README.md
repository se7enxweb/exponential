# Building a site step by step: the chess club tutorial for Exponential 6

The tutorial *Building an eZ publish site* builds a small community website from nothing, for a chess club: a welcome page,
news with an archive, a list of members, a guestbook that an administrator approves, and a page of links. It teaches by
example, which is why it is still a good way in. These pages keep its case and order and carry out every step the way
Exponential 6 does it: in two extensions, with current settings, a modern page frame, no inline style or script, and a note wherever the
2003 version would now be wrong or unsafe.

You need an installation to work on ([Getting started](../../guides/getting-started.md)) and a little general knowledge of
web development. The concepts are explained in [Learning Exponential](../book-learning/README.md); the compact version of
the same work is [Building a site without writing code](../extension-development/part-2-builder/building-a-site-without-code.md).

1. [Start the project: the case, a siteaccess and a design](start-the-project.md)
2. [The main layout: pagelayout.tpl and a style sheet](the-main-layout.md)
3. [Sections and the welcome page](sections-and-the-welcome-page.md)
4. [The news pages: overview, full article and archive](the-news-pages.md)
5. [The members page: a custom content class, a list and an info page](the-members-page.md)
6. [The guestbook: visitors write content](the-guestbook.md)
7. [Approving guestbook entries with a workflow](approving-guestbook-entries.md)
8. [The links page: categories, link objects and a tree menu](the-links-page.md)

# Monthly upkeep checklist

This page is for individuals who keep a site running alone. Do it on the same day each month; it takes about an hour
when nothing is wrong. Note the date and anything unusual at the end.

## Contents

1. [Every month](#every-month)
2. [Twice a year](#twice-a-year)
3. [Once a year](#once-a-year)
4. [Your log](#your-log)

## Every month

### Updates

- [ ] Any new Exponential release or security fix? ([Updates for one person](../running-it/updates-for-one-person.md))
- [ ] **Setup > Upgrade check** shows no unexpected differences ([The upgrade check](../../../guides/upgrade-check.md)).
- [ ] Your host announced any PHP change? ([PHP versions and extensions](../../hosting/basics/php-versions-and-extensions.md))

### Backups

- [ ] The automatic backups ran (check the newest date) ([Backups for one person](../running-it/backups-for-one-person.md)).
- [ ] The newest backup copied off the server.
- [ ] Old generations deleted as planned.

### Accounts and visitors

- [ ] New accounts: all recognized? Unknown ones removed ([Spam and security basics](../running-it/spam-and-security-basics.md)).
- [ ] People who should no longer have access disabled ([Inviting family members](../family-sites/inviting-family-members.md#when-someone-should-no-longer-have-access)).
- [ ] Comments and form submissions read; spam removed; old submissions deleted on schedule.

### Health

- [ ] Front page, a deep page, sign-in and a form work.
- [ ] Error log looked at ([Logs for owners](../../customers/healthy/logs-for-owners.md)).
- [ ] Broken links checked ([Link and content checks](../../creators/website-creators/link-and-content-checks.md)).
- [ ] The lock in the browser: the certificate is valid.
- [ ] Mail from the site still arrives (send yourself a contact form message).
- [ ] Cron ran, if you use it (the cronjobs page shows the last runs) ([Cronjobs](../../../guides/cronjobs.md)).

### Content

- [ ] Anything out of date on Home, About, Contact, the calendar?
- [ ] Drafts you forgot: publish or discard ([Drafts and pending](../../../guides/drafts-and-pending.md)).
- [ ] The trash: empty what should really go ([Archiving and the trash](../../customers/day-to-day/archiving-and-the-trash.md)).

## Twice a year

- [ ] Restore a backup on another machine ([Restore test](../../customers/healthy/restore-test.md)).
- [ ] Review roles and groups; nobody has more rights than needed.
- [ ] Review tags; merge duplicates ([Tags and categories](../blogs/tags-and-categories.md)).
- [ ] Club sites: compare members with the club's list ([Members and registration](../club-sites/members-and-registration.md)).

## Once a year

- [ ] Domain renewal date checked; payment method current ([Domain names and HTTPS](../setup/domain-names-and-https.md)).
- [ ] Hosting contract and costs reviewed ([Running on a small budget](../setup/running-on-a-small-budget.md)).
- [ ] About, Contact and privacy texts reread.
- [ ] Family sites: the [family privacy checklist](family-privacy-checklist.md) again.
- [ ] Deputy still knows where the backups and passwords are.

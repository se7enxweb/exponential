# Learning with the Student level

This page is for individuals who want to go beyond running their own site: students, teachers and self-taught people
who want to understand how Exponential works, and maybe one day build sites for others.

## The Student level as published

The Exponential Partner Program has eight levels; the first is **Student**, described as for "educational partners"
and, in the program's words, "For students, universities, or learning institutions. Includes sandbox access,
educational resources, and training support" ([Partner levels from Student to Platinum](../../partners/partner-levels.md)).
Its published price and what it includes are quoted, with sources and dates, on
[Student and education partners](../../partners/student-and-education-partners.md) and
[Partner plans and prices](../../partners/partner-plans-and-prices.md). What "sandbox access" includes is not
described there; ask the partner team.

You do not need to be a partner to learn: the software and the documentation are free. The level adds contact with
the people behind the program and a place in it.

## From learning to contributing

Contributions are the best proof of what you learned:

- report a bug you met, with steps to reproduce it ([GitHub issues](../../customers/healthy/github-issues.md));
- improve a help page that confused you; the documentation is free to improve ([Free documentation](../../free-documentation.md));
- translate a part of the interface ([Helping with translations](../../advocates/helping-with-translations.md));
- fix a small issue and send a pull request ([Contributing code back](../../partners/contributing-code-back.md)).

## From contributing to paid work

When you start building sites for others, the next levels are for "individuals or small teams exploring Exponential"
(Now) and for "freelancers, startups, or growing developers" (Starter), as published
([Partner levels](../../partners/partner-levels.md#choosing-your-starting-level)). The partner section explains what
each brings ([Why become a partner](../../partners/why-become-a-partner.md), [How to apply](../../partners/how-to-apply.md)).

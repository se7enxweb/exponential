# Running it alone

This section is for individuals who have launched their site and now keep it going, alone. The work is small if it
is regular: roughly an evening a month, more around an update. Nothing here needs you to be a programmer, but some
steps need a shell or your host's control panel.

## The three things that matter most

If you do nothing else:

1. **A backup you have restored once**, kept away from the server.
2. **Security updates applied** within days, not months.
3. **Two-step sign-in** on your administrator account.

Everything else makes the site better; these three keep it alive.

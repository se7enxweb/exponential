# Publish your portfolio free on GitHub Pages

A portfolio is more convincing when people can open it. With static publishing you build the site in Exponential on
your own computer or a lab server, then publish a static copy to GitHub Pages, where it is hosted for free.

## What you'll have at the end

- Your portfolio at `https://<your-name>.github.io/<repository>/`, or at `https://<your-name>.github.io/` when the
  repository is called `<your-name>.github.io`.
- A public repository with one commit and one tag per publish: a visible history of your work.
- A skill you can name in an application: content modeling, templates, git and deployment.

## Why it is a good student project

- **It costs nothing.** No hosting plan, no credit card. GitHub's free plan hosts public sites.
- **Your installation can stay on your laptop.** Only the copy is public; nothing needs to run when you close the lid.
- **It shows real work.** Employers see the site, the git history and, if you like, the code of your design in a
  second repository.
- **You learn the full path.** Content, design, build, review, publish, roll back.

## Ideas for the content

- A short page about you, with what you are looking for.
- One page per project: the problem, what you did, a picture, a link to the code.
- A blog of what you learned. See [Building a portfolio](building-a-portfolio.md) for structure.

## Good to know

- Keep the repository public: GitHub Pages on the free plan serves public repositories only.
- Forms such as a contact form cannot run on a static host; write your e-mail address or a link instead.
- Do not publish anything you would not show an employer. Builds run as an anonymous visitor, so drafts and unpublished
  content stay out. See [Keep private content private](../static-publishing/keep-private-content-private.md).
- Want your own name as the address? See [Use your own domain](../static-publishing/use-your-own-domain.md).
- New to GitHub? [What static publishing is](../static-publishing/what-static-publishing-is.md) explains the words.

# Site packages for learners

When you install Exponential, the new site is not built from code alone. It is built from **site installer
packages**: archives that carry content classes, content, settings, roles and install scripts
([Site packages: start here](../site-packages/README.md)). Knowing which package you installed tells you what your
study site contains and why.

## Packages in one minute

- A **package** is a folder with a `package.xml` and the files it names, shipped as one archive ending in `.ezpkg`.
- A **site package** is a package of type `site`. It requires other packages (content classes, content) and can
  carry install scripts that set up siteaccesses, extensions, roles and preferences.
- The installers (the setup wizard, the kickstarter and `exp:install`) read packages from a **package server**,
  [exponential.packages.exponential.earth](https://exponential.packages.exponential.earth/).
- The 6.0.15 index offers twelve site packages.

Source: [Site packages: start here](../site-packages/README.md#the-short-version).

## The default: sevenx_multisite

`sevenx_multisite` is the package installed when nothing else is chosen. It sets up two public websites in one
installation, **Fit & Healthy** and **Bold Agency**, plus the administration and editor siteaccesses, with page
layouts from the `explayouts` extensions ([sevenx_multisite](../site-packages/sevenx-multisite/README.md#in-one-paragraph)).

What that means for your studies:

| You get | Useful for |
|---|---|
| Demo articles, recipes and images | Editing, search and translation exercises on realistic content |
| The siteaccesses `site`, `bold` and `bold_ger` | Seeing how one installation serves several sites and languages |
| Published layouts with zones, blocks and rules | The [layouts project](project-04-a-page-with-layouts.md) |
| Roles for Anonymous, Member, Editor and Partner users | The [roles project](project-09-roles-for-a-restricted-editor.md) |
| Many active extensions | Seeing what extensions add, in **Setup > Extensions** |

Source: [sevenx_multisite: what an install gives you](../site-packages/sevenx-multisite/README.md#what-an-install-gives-you).

## Choosing a package when you install

`exp:install` takes the package with `--package` ([Install in one command](../../features/6.0/install-in-one-command.md)).
The cjw_multisite page shows this example:

```bash
php bin/php/console exp:install --apply --package=cjw_multisite --languages=eng-US,ger-DE
```

Add the options of your first install (`--random-password`, `--url=...`), and `--force` when you replace an existing
study site ([Resetting and rebuilding your study site](resetting-and-rebuilding-your-study-site.md)). In the setup
wizard, the package is chosen on the **Site package** page.

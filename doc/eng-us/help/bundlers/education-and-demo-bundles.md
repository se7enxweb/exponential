# Education and demo bundles

This page is for trainers, schools, partners and sales teams who bundle Exponential so people can try it: a
classroom image, a workshop laptop, a trade-show kiosk, a public demo site.

## What these bundles need

| Need | How |
|---|---|
| Starts in minutes, on a laptop | SQLite, no database server ([SQLite bundles](sqlite-bundles.md)) |
| Works without the venue's network | packages imported in advance ([Offline bundles](offline-bundles.md)) |
| Something to show | a site package with demo content |
| Same state for every group | a reset that reinstalls |
| Safe if the image leaks | no real data, no reused passwords |

## A fast, self-contained install

```bash
php bin/php/console exp:install
```

installs "the multisite package on **SQLite**, in `eng-US`, with the siteaccesses `site` and `admin` reached by URL"
([Install in one command](../../features/6.0/install-in-one-command.md)). For a laptop, Velocity can serve it; the
shipped engine `php` "needs nothing an installation might lack" and suits development
([Velocity engines](../../bc/6.0/velocity-engines.md#in-short)).

## Content to show

- `sevenx_multisite` installs the 7x multisite with demo content; `cjw_multisite` the CJW starter site with an English
  and a German site ([4.3](../../install/04-choosing-an-install-method.md#43-site-packages-what-is-installed)).
- For lessons that start empty, use `sevenx_multisite_clean`.
- On Exponential Platform, the Nexus demo (`exponential-media`) is a complete site with layouts
  ([Platform distributions as a base](platform-distributions-as-a-base.md)).

## Resetting between groups

- With `exp:install`: run it again with `--force`; the default database action `remove` empties the database first.
- With the kickstarter: "The same `kickstart.ini` with `DatabaseAction=remove` and `run --force` replaces the database
  and the settings again. Use it to reset a test or training site" ([6.10](../../install/06-kickstarter.md#610-re-running-and-resuming)).
- With images: restore the image snapshot.

Clear the caches after a reset if the site was running ([Caches and autoloads after building](caches-and-autoloads-after-building.md)).

## Passwords

| Situation | Password |
|---|---|
| Each student gets their own install | generated by the installer; the student reads `var/log/initial-admin-password` |
| A shared classroom or public demo with a published sign-in | the published password, installed with `EXP_DEMO_MODE=1` ([Demo mode in bundles](demo-mode-in-bundles.md)) |
| Trainer's machine | generated, kept by the trainer |

Never reuse a demo password anywhere real: "Such a password must never be reused on a real site"
([The default administrator password](../default-administrator-password.md#site-packages-and-demo-content)).

## What to tell students and prospects

- That the site is a demonstration, reset regularly, and not a place for private data.
- That Exponential is free software under the GPL and the documentation is free under the GFDL: they may take both
  home ([Free documentation](../free-documentation.md)).

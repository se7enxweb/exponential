## Licensing

| Question | Answer |
|---|---|
| May we sell a bundle with Exponential in it? | Yes. You may charge for the bundle, distribution and services; the GPL applies to the Exponential parts ([GPL obligations](gpl-obligations-when-distributing.md)). |
| May we sell "Exponential licenses"? | No such license exists; "Using Exponential under the terms of the GNU GPL is free of charge" ([Licensing for partners](../partners/licensing-for-partners.md)). |
| Must we publish our own extensions? | If you distribute them with Exponential, ask counsel whether they must be GPL-compatible; code you do not distribute is not affected ([Licensing for partners](../partners/licensing-for-partners.md#common-questions)). |
| What must we ship? | License texts, notices, the source offer, the third-party list ([License texts and notices](license-texts-and-notices-to-ship.md)). |
| May we include the documentation? | Yes, under the GFDL 1.3: keep the notices and include the license ([Documentation to ship](documentation-to-ship.md)). |

## Building

| Question | Answer |
|---|---|
| Is there an official Dockerfile? | No; the repository has none. Velocity publishes images on `ghcr.io/se7enxweb/exponential-velocity` ([Container images](container-images.md)). |
| Is there an official deb or rpm of the CMS? | No; Velocity has deb and rpm packages ([Linux distribution packaging](linux-distribution-packaging.md)). |
| Which version do we build on? | A published release tag, found with a version sort, not a name sort ([Versions, tags and pinning](versions-tags-and-pinning.md)). |
| Why is there no `composer.lock`? | The lock file "is not part of the repository"; your bundle keeps its own ([Lock files](lock-files-and-reproducible-builds.md)). |
| Which PHP? | 8.0 to 8.5 for the 6.0.15 line; published tags `v6.0.8` to `v6.0.14` need 8.1 ([Getting the code](getting-the-code-for-a-bundle.md)). |
| Which database? | SQLite 3 by default, then PostgreSQL, MongoDB, MariaDB, Oracle, MySQL ([Database choices](database-choices-for-bundles.md)). |

## Installing

| Question | Answer |
|---|---|
| How do we install without a browser? | `php bin/php/console exp:install --apply` or the kickstarter ([The three installers](the-three-installers.md)). |
| Can we ship an installed site? | Not for real sites: install at first boot ([First boot and install once](first-boot-and-install-once.md)). |
| What is the administrator password? | Generated by the installer unless you pass an acceptable one; it is in `var/log/initial-admin-password` ([Default credentials](default-credentials-and-first-sign-in.md)). |
| Can we use `publish` as in old guides? | Only in a public demo with `EXP_DEMO_MODE=1` ([Demo mode in bundles](demo-mode-in-bundles.md)). |
| Does it install offline? | Yes, when every package is imported first ([Offline bundles](offline-bundles.md)). |
| The site shows 503 during first boot. | Maintenance mode is on while the installer works, and stays on after a failure ([The three installers](the-three-installers.md#maintenance-mode-during-the-install)). |

## After release

| Question | Answer |
|---|---|
| How do recipients update? | Code and database, by the route your bundle defines ([Updates and upgrade paths](updates-and-upgrade-paths.md)). |
| A published bundle release is wrong. | Publish the next one and say what was wrong; never move the tag ([Versions, tags and pinning](versions-tags-and-pinning.md#a-published-release-never-changes)). |
| Who supports the recipients? | You, first; 7x through partner or paid support; the community without obligation ([Support boundaries](support-boundaries.md)). |
| We found a bug in Exponential. | Report it upstream; security problems privately to security@se7enx.com ([Contributing fixes back](contributing-bundle-fixes-back.md)). |

## Brand and partnership

| Question | Answer |
|---|---|
| Can we call our bundle "Exponential"? | Name it yourself and say "based on Exponential"; agree any use of the name in a product with 7x ([Naming and branding](naming-and-branding-a-bundle.md)). |
| Is there an OEM program? | "OEM Resale Opportunities" is a benefit at every level; details are not published: ask the partner team ([OEM and the partner program](oem-and-the-partner-program-for-bundlers.md)). |
| What does partnership cost? | Per level, from Student to Platinum, on [Partner plans and prices](../partners/partner-plans-and-prices.md). |
| How do we join? | Apply, pay first, then sign ([How to apply](../partners/how-to-apply.md)). |
| Who do we ask? | <partners@exponential.earth> |

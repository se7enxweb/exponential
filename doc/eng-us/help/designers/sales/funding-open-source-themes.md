# Funding an open source theme

This page is for designers who publish a theme for free and want the work to be sustainable.

## Options

| Option | How |
|---|---|
| Donations and sponsorships | A sponsor button on the repository through `.github/FUNDING.yml` |
| Sponsored features | A company pays for a feature that then goes into the free theme |
| Paid support next to free code | [Support offerings](support-offerings.md) |
| Paid customization | [Customization and white-label work](customization-and-white-label.md) |

## The FUNDING.yml file

GitHub shows a **Sponsor** button when a repository (or the account's `.github` repository) has `.github/FUNDING.yml`.
The Exponential repository's file lists, for example:

```yaml
github: se7enxweb
patreon: 7xweb
custom: ["https://www.paypal.me/7xweb", "https://se7enx.com"]
```

(shortened). The GitHub Sponsors page of that account is `https://github.com/sponsors/se7enxweb`.

## Step by step

1. Set up a sponsorship profile on the service you choose (GitHub Sponsors requires an approved profile).
2. Add `.github/FUNDING.yml` with your own accounts to the theme's repository.
3. Say in the README what the money pays for (maintenance, accessibility audits, new templates).
4. Report back to sponsors: a short note per release.

## Support the projects you build on

Your theme stands on Exponential and its extensions. If your theme earns money, consider sponsoring the work you depend
on as well; it keeps your foundation maintained. See [Who is 7x?](../../who-is-7x.md) and
[Who is the Exponential Foundation?](../../who-is-the-exponential-foundation.md).

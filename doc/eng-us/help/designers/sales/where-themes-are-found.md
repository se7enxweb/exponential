# Where Exponential themes are found today

This page is for designers deciding where to put effort. It lists channels that exist and were checked on
18 October 2026. **There is no official Exponential theme marketplace** with payments or a store; do not tell buyers
otherwise.

## The channels

| Channel | What happens there | Payments? |
|---|---|---|
| GitHub (the `se7enxweb` organization and authors' accounts) | Source, releases, issues | No (GitHub Sponsors is separate) |
| [Packagist](https://packagist.org/) | Composer installs | No |
| [projects.exponential.earth](https://projects.exponential.earth/) | Community forge: project pages, news, downloads, browsing by type | No |
| [share.exponential.earth](https://share.exponential.earth/) | Forums (Extensions, Setup & design), blogs, tutorials | No |
| [eZpedia](https://ezpedia.exponential.earth/) | Wiki articles under the GFDL | No |
| Demo sites | People try the look | No |
| Your own website | Product pages, shop, support | Yes, under your control |

## Step by step

1. Publish the theme where developers look: GitHub and Packagist ([Distributing a theme](../distribution/distribution-start-here.md)).
2. List it where the community looks: projects.exponential.earth and an announcement on share.exponential.earth.
3. Sell from your own site ([Selling from your own site](selling-from-your-own-site.md)).
4. Link all of them to each other.

## General marketplaces

General theme marketplaces exist for other systems. Before using any, read its terms: some require exclusivity or
licenses that conflict with the GPL code of an Exponential theme.

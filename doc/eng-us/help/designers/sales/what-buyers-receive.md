# What buyers receive

This page is for designers who sell a theme or a theme service. Many disputes start with different ideas of what was
bought. Write it down.

## The list to fill for every offer

| Item | Example answer |
|---|---|
| Files | The theme extension, source of all CSS and JavaScript, demo content package |
| License of the code | GPL-2.0-or-later |
| Licenses of assets | Photos: licensed for use in the buyer's sites; icons: CC BY 4.0 |
| Updates | Every release of the 1.x line for 12 months |
| Support | Email, answers within two working days, for one installation |
| Documentation | README, INSTALL.md, a configuration guide |
| Compatibility | Tested with Exponential 6.0.15 and PHP 8.0 to 8.5 |
| Not included | Content entry, hosting, custom changes |

## Step by step

1. Fill the table for each offer.
2. Put it on the product page and in the order confirmation ([Writing a theme's product page](product-page.md)).
3. Reference it in your terms ([Contracts and terms](contracts-and-terms.md)).
4. Deliver exactly that, and nothing that conflicts with it.

## Rules

- State the license of the code plainly. A buyer of GPL code has the GPL's rights, whatever the order says.
- Write versions you tested, not versions you hope work.
- If you deliver through a private repository, say how long access lasts and what happens afterwards.

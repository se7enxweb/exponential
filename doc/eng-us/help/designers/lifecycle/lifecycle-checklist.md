# Checklist: one maintenance cycle

This page is for designers running a maintenance cycle. Copy it into an issue and tick it.

## Watch

- [ ] Changelog of the new Exponential release read for theme impact ([Reading a changelog](reading-a-changelog-as-a-designer.md)).
- [ ] Issues and security reports reviewed ([Handling security reports](handling-security-reports.md)).
- [ ] Dependencies checked ([Keeping dependencies up to date](dependency-updates.md)).

## Test

- [ ] Test installation updated ([An upgrade test environment](upgrade-test-environment.md)).
- [ ] Page list walked, logs clean ([Upgrade testing](upgrade-test-step-by-step.md)).
- [ ] Overrides compared with the standard templates ([Comparing your overrides](comparing-overrides-with-the-standard.md)).
- [ ] Oldest and newest PHP checked ([PHP version compatibility](php-version-compatibility.md)).

## Audit

- [ ] Accessibility ([An accessibility audit](accessibility-audit-per-release.md)).
- [ ] Content Security Policy ([A CSP audit](csp-audit-per-release.md)).
- [ ] Visual regression in light, dark and zoom ([Visual regression checks](visual-regression-checks.md)).
- [ ] Performance ([A performance audit](performance-audit-per-release.md)).

## Release and communicate

- [ ] Fixes made; deprecations announced or completed ([A deprecation policy](deprecation-policy.md)).
- [ ] Compatibility declared ([Declaring compatibility](declaring-compatibility.md)).
- [ ] Release published ([Checklist: before you publish](../distribution/distribution-checklist.md)).
- [ ] Customers and community told ([Writing release notes](../distribution/writing-release-notes.md)).

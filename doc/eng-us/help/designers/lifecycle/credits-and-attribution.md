# Credits and attribution

This page is for designers who build on others' work, which is every designer. Credit is required by most licenses and
is simply right.

## Who to credit, where

| Who | Where | Real example |
|---|---|---|
| Original authors of a ported or forked design | Copyright lines in `ezinfo.php`, `extension.xml`, `LICENSE` | `cjw_themes_jumper`: "2007 - 2026 CJW Network, JAC Systeme GmbH and 7x" |
| Contributors of changes | Changelog entry | `cjw_themes_jumper` 0.1.4: "Pull request #1 by ekked" |
| Ideas taken from another project | Changelog entry | `cjw_themes_jumper` 0.1.3: "The idea comes from LoveStack, Mugo Web's distribution (commit 98854ab935), with thanks." |
| Reporters of problems | Changelog or release notes, as they wish | |
| Fonts, icons, libraries, photos | A credits file next to them | `THIRD-PARTY.md`, `CREDITS.md` |
| The project you build on | README | "A theme for Exponential" |

## Step by step

1. When you merge a contribution, add the credit to the changelog in the same commit.
2. When you port a design, put the original holders into the copyright line before your own work starts.
3. Ask reporters how they want to be named; some prefer not to be.
4. Review credits before each release: nothing removed, nothing new missing.

# Listing a theme on projects.exponential.earth

This page is for designers who want their theme listed where the Exponential community looks for extensions. What
follows describes the site as it was on 18 October 2026; the site itself is the authority.

## What the site offers

[projects.exponential.earth](https://projects.exponential.earth/) describes itself as a community forge with "areas
for news articles, downloads, forums and image galleries", "Git / GitHub / Composer source code integration", forums
for user support, and the possibility for others to join a project. Its front page shows the latest project news, new
projects and updated projects.

| To find projects | Address |
|---|---|
| Browse by type | `/types` (for example the type "Exponential" with sub-types such as Design Extension and Distribution) |
| Browse by organization | `/org`, and as a tree `/tree` |
| Recent Git changes | `/changes` |
| Project news | `/news` |
| RSS feeds | `/rss/feed/projects`, `/rss/feed/projects-news`, `/rss/feed/news`, `/rss/feed/git`, `/rss/feed/forums` |

The type list also holds the archive of the older community forge (the "Via Projects.ez.no" types), a rich source of
ideas for designers.

## Accounts

The site states that you need to be logged in to add a new project. Its registration link leads to
`https://share.exponential.earth/user/register`, and a news item says that the projects site accepts logins of
share.exponential.earth accounts. One account serves both sites.

## Step by step

1. Make sure the theme is ready to be installed by others: a public repository, a tagged release, a README and a
   license ([Checklist: before you publish](distribution-checklist.md)).
2. Register on share.exponential.earth, then log in on projects.exponential.earth.
3. Add a new project for your theme. Choose the type that fits a theme (Design Extension, where offered), your
   organization, and link the repository and the Packagist page.
4. Use the same name, one-sentence description and screenshots as in your README.
5. Post a news item on the project for the first release, and for each notable one after.
6. Check that your project appears under its type and in the projects RSS feed.

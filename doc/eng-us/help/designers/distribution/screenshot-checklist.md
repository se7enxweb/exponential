# Screenshot checklist

This page is for designers about to upload screenshots. Run it for every release that changes how the theme looks.

## Content

- [ ] Taken from the version you are releasing, not an older one.
- [ ] Shows the theme as it installs, without manual tweaks the user would not have (or the tweak is explained).
- [ ] Demo content only: no real customers, people, email addresses or private data.
- [ ] No administration page with user names, server paths, IP addresses or settings.
- [ ] Every photo or logo in it may be shown (your own, or licensed for this use).

## Form

- [ ] The sizes of [Screenshots for a theme](screenshots-for-a-theme.md): 1440, 960 at scale 2, 375; light and dark.
- [ ] No browser chrome, extensions, bookmarks or other tabs.
- [ ] File size reasonable for a README (a few hundred kilobytes each; WebP or optimized PNG).
- [ ] Descriptive file names.

## Use

- [ ] Each image has an alt text that says what it shows.
- [ ] The README links the images with relative paths that work on GitHub.
- [ ] The same images are used on the project listing and product page, so they do not drift apart.

# Community safety and privacy at events

The code of conduct asks organizers to "Make your events and material welcoming and accessible, and name a person
participants can turn to if something goes wrong", and to "Protect the privacy of participants: no photos,
recordings or names published without consent" (`CODE_OF_CONDUCT.md`, "Trainers and advocates").

## Before the event

- Link the code of conduct in the announcement.
- Name a contact person and say how to reach them during the event.
- Check accessibility: step-free access, readable slides, captions or a written summary for online events
  ([Accessible slides and visuals](../../advocates/accessible-slides-and-visuals.md)).
- Collect only the data you need to run the event.

## At the event

- Mention the code of conduct and the contact person at the start, in one or two sentences.
- For live demos, use a test installation with invented data
  ([Live demo safety](../../advocates/live-demo-safety.md)).
- Do not show real administrator passwords, customer data or private server addresses on screen.

## Photos, recordings and names

| Before you | Ask |
|---|---|
| Take photos where people can be recognized | Everyone in them |
| Record a talk or a call | The speaker and, for discussions, everyone who speaks |
| Publish names or a participant list | Each person |

Offer an easy way to opt out, for example a sticker or a note in the chat.

## Attendee data

- Use sign-up data only to run the event.
- Do not share the list with sponsors or partners without consent; the code of conduct asks to "Protect the personal
  data of customers and leads. Share it only with consent and only what is needed".
- Delete it when it is no longer needed.

More: [Protecting people's privacy](../../advocates/protecting-peoples-privacy.md).

## When something goes wrong

1. Make sure the person affected is safe and supported.
2. Note what happened, when and who was involved.
3. Report it to community@se7enx.com; "The Exponential Foundation decides" (`CODE_OF_CONDUCT.md`, "Enforcement").
4. Respect the privacy of the person who reported it.

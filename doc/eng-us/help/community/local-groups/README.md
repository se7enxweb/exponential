# Local groups and community events

No conferences or meetups are documented in the sources
([Community places](../../who-is-the-exponential-foundation.md#community-places)). That means any group or event that
exists is organized by community members themselves. These pages help you do that well.

## Your event is yours

- Present a group or event as yours, not as an official project event, unless the project has made it so
  (`CODE_OF_CONDUCT.md`, "Trainers and advocates": "Do not call a course, a certificate or an event 'official' unless
  the project or the partner program has made it so").
- Disclose your ties: an employer or a product of your own.
- The code of conduct "applies at every event about Exponential you organize".

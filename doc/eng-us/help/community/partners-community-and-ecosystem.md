# Partners, community and ecosystem

The help's dashboard block "Who makes Exponential" names 7x, the Exponential Foundation and three circles of people.
This page puts the three circles side by side.

## The three definitions

| Circle | Definition |
|---|---|
| **Partners** | Exponential Partners contribute financially to the sustained future of the project, contribute code and more back to the project, and engage directly with 7x and the Exponential Foundation. |
| **Community** | Exponential Community members use, contribute to, promote and develop software using Exponential worldwide. |
| **Ecosystem** | The greater ecosystem extends beyond the community to cover all aspects of the Exponential world within the PHP stack: its users and creators. |

## How the circles overlap

Think of three rings, one inside the other:

```text
+--------------------------------------------------------------+
| ECOSYSTEM: everyone and everything in the Exponential world   |
|            within the PHP stack, its users and creators       |
|   +------------------------------------------------------+   |
|   | COMMUNITY: people who use, contribute to, promote     |   |
|   |            and develop software using Exponential     |   |
|   |   +----------------------------------------------+   |   |
|   |   | PARTNERS: fund the project, contribute back,  |   |   |
|   |   |           engage directly with 7x and the     |   |   |
|   |   |           Exponential Foundation              |   |   |
|   |   +----------------------------------------------+   |   |
|   +------------------------------------------------------+   |
+--------------------------------------------------------------+
```

- Every partner is also a community member: partners use, contribute and promote.
- Every community member is part of the ecosystem.
- The ecosystem also holds people and projects that never visit a forum: a company running a site a partner built,
  the authors of the PHP libraries Exponential depends on, a hosting company that offers PHP hosting on which an
  installation happens to run ([Ecosystem: start here](../ecosystem/ecosystem-start-here.md)).

## Examples

| Person or organization | Circles |
|---|---|
| A visitor who reads a site built with Exponential | Ecosystem |
| A shop owner whose site runs on Exponential and who reports a bug | Ecosystem, community |
| A freelance developer who answers forum questions and publishes an extension | Ecosystem, community |
| An agency in the Exponential Partner Program that sends pull requests | Ecosystem, community, partners |
| A maintainer of a PHP library the kernel requires | Ecosystem |
| 7x and the Exponential Foundation | All three, and they run the partner program |

## Moving between the circles

| From | To | The step | Page |
|---|---|---|---|
| Ecosystem | Community | Take part once: ask, answer, report or contribute | [Your first week in the community](your-first-week-in-the-community.md) |
| Community | Regular contributor | Keep contributing in one area | [From user to contributor](paths/from-user-to-contributor.md) |
| Community | Partners | A company applies to the partner program | [From community to partner](paths/from-community-to-partner.md), [How to apply](../partners/how-to-apply.md) |

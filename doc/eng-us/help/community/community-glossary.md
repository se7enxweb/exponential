# Community glossary

| Term | Meaning | More |
|---|---|---|
| **7x** | The North American company that leads development, support and hosting of Exponential | [Who is 7x?](../who-is-7x.md) |
| **Advocate** | A community member who speaks, writes or presents about Exponential | [Advocates: start here](../advocates/advocates-start-here.md) |
| **CLA** | The Exponential Foundation and 7x Contributor Licensing Agreement (version 1.1.0); signing it and submitting kernel code assigns the copyright in that code to the Exponential Foundation and 7x | [The CLA explained](contributing/the-cla-explained.md) |
| **Code of conduct** | The Contributor Covenant 2.1 with Exponential additions, binding in all community spaces | [The code of conduct](joining/the-code-of-conduct.md) |
| **Community** | The people who use, contribute to, promote and develop software using Exponential worldwide | [What the community is](what-the-community-is.md) |
| **Contribution day** | A few hours in which a group makes real contributions together | [A contribution day](local-groups/a-contribution-day.md) |
| **dev-main** | The Composer name of the `main` branch, the development line where fixes land first | [How releases happen](how-it-works/how-releases-happen.md) |
| **Ecosystem** | The greater Exponential world within the PHP stack: its users and creators | [Ecosystem: start here](../ecosystem/ecosystem-start-here.md) |
| **Exponential Foundation** | The nonprofit, founded 19 March 2026, that operates the project | [Who is the Exponential Foundation?](../who-is-the-exponential-foundation.md) |
| **eZpedia** | A community encyclopedia under the GNU FDL, since 2006 | [Contributing to eZpedia](../advocates/contributing-to-ezpedia.md) |
| **Fork** | Your own copy of a repository on GitHub, from which you send pull requests | [Contributing code](contributing/contributing-code.md) |
| **GNU FDL** | The GNU Free Documentation License 1.3 or later, the license of the documentation | [Free documentation](../free-documentation.md) |
| **GPL** | The GNU General Public License version 2 or later, the license of the code | [Licenses in the community](how-it-works/licenses-in-the-community.md) |
| **Maintainer** | Someone responsible for keeping a repository or area working: issues, reviews, releases | [From contributor to maintainer](paths/from-contributor-to-maintainer.md) |
| **Manifest** | `share/filelist.md5`, the list of files and checksums every commit keeps current (`make manifest-fix`) | [Contributing code](contributing/contributing-code.md) |
| **Partner** | A company in the Exponential Partner Program that funds the project, contributes back and engages directly with 7x and the Foundation | [Partners: start here](../partners/partners-start-here.md) |
| **Projects** | projects.exponential.earth, where community projects and extensions are listed | [Where people meet](joining/where-people-meet.md) |
| **Pull request** | A proposed change on GitHub, reviewed before it is merged | [Contributing code](contributing/contributing-code.md) |
| **Review round** | One cycle of comments and revisions on a pull request | [Reviewing and being reviewed](contributing/reviewing-and-being-reviewed.md) |
| **Share** | share.exponential.earth, the community portal with forums, blogs and articles | [Where people meet](joining/where-people-meet.md) |
| **Sponsor** | A person or company that funds 7x or the Foundation, for example through GitHub Sponsors | [Sponsors: start here](../sponsors/sponsors-start-here.md) |
| **Squash and rebase** | Folding the commits of a pull request into logical ones and moving them onto the current `main` | [Reviewing and being reviewed](contributing/reviewing-and-being-reviewed.md) |
| **Supporter** | Anyone who helps the project with time or money | [Supporters: start here](../supporters/supporters-start-here.md) |
| **Tag** | A named release version in Git; a published tag is never changed | [How releases happen](how-it-works/how-releases-happen.md) |
| **Tracker** | An issue list on GitHub: the software, Velocity, the community | [Filing a bug](contributing/filing-a-bug.md) |

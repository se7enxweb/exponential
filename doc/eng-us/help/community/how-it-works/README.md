These pages explain the parts of the project that a community member runs into sooner or later: who makes which
decision, how a release comes about, what happens to a security report, the licenses, how contributors are
credited, and where the money comes from.

## The short version

- 7x leads development; the Exponential Foundation operates the project.
- Pull requests are reviewed and merged once their authors have revised them as the reviews ask.
- Fixes land on `main` and reach you in the next 6.0.x release; published tags never change.
- Security reports are private: security@se7enx.com.
- Code is GPL v2 or later, documentation GNU FDL 1.3 or later; kernel contributions need the CLA.
- The project runs on donated time and sponsorship.

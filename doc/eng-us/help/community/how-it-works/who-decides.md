# Who decides in the Exponential community

Open source projects differ in how they decide. This page lists what the published sources say for Exponential, and
what they do not.

## Contents

1. [The decisions](#the-decisions)
2. [What is not published](#what-is-not-published)
3. [How community members influence decisions](#how-community-members-influence-decisions)

## The decisions

| Decision | Who | Source |
|---|---|---|
| The project as a whole | "This project is operated by the Exponential Foundation" | exponential.earth/about/project, via [Governance and decisions](../../partners/governance-and-decisions.md) |
| Development, support, adoption and community growth | 7x, which "took over leadership of the project [...] in 2023" | `README.md` |
| What gets merged | Maintainers review; every pull request is merged once its author has revised, squashed and rebased it as the reviews ask | `CONTRIBUTING.md`, [How the project grows](../../who-is-the-exponential-foundation.md#how-the-project-grows) |
| Releases | Maintainers tag releases; "A published tag is never changed" | `SECURITY.md` |
| Security fixes | Made on `main`, published with the next 6.0.x release | `SECURITY.md` |
| Conduct | "The Exponential Foundation decides on reports and on the consequences of a violation" | `CODE_OF_CONDUCT.md` |
| The partner program | 7x, which "reserves full rights to change or administer this program" | [Governance and decisions](../../partners/governance-and-decisions.md) |
| The licenses | Fixed: GPL v2 or later for code, GNU FDL 1.3 or later for documentation | `LICENSE`, [Free documentation](../../free-documentation.md) |

## What is not published

No public source says "who sits on the Foundation's board, how it is governed, whether it has members besides its
supporters, and what its budget is"
([What the sources do not say](../../who-is-the-exponential-foundation.md#what-the-sources-do-not-say)). There is
no documented community vote, council or elected role. If someone asks, say that these are not published.

## How community members influence decisions

| Way | Influence | Page |
|---|---|---|
| A pull request | Direct: working code is the strongest argument | [Contributing code](../contributing/contributing-code.md) |
| An issue | Puts a problem on record for everyone | [Filing a bug](../contributing/filing-a-bug.md) |
| The community roadmap on Share | Feature requests others can discuss | [Roadmap](../../project/roadmap.md) |
| The forums and chats | Public discussion before a decision | [Where people meet](../joining/where-people-meet.md) |
| Testing | Shows whether a change works for real setups | [Testing releases](../contributing/testing-releases.md) |
| Sponsorship | Funds the work; some tiers include backlog influence | [Funding the community](funding-the-community.md) |
| Partnership | Program benefits such as roadmap requests at higher levels | [Roadmap participation](../../partners/roadmap-participation.md) |

Ask in public where you can: a decision discussed in an issue stays on record for everyone.

# A free site for your user group

A user group needs a place for the next meetup, the talks, the slides and how to join. With static publishing that
place costs nothing, and it is made with the software the group is about.

## What you'll have at the end

- The group's site at `https://<group>.github.io/` or at the group's domain.
- A GitHub organization owned by the group, not by one person, with every publish in its history.
- A working example of Exponential you can show at every meetup.

## How to organize it

1. Create a GitHub organization for the group with two or three owners.
2. Run the Exponential installation where one organizer can host it: a small server, a laptop, or CI from the starter
   template [exponential-static-site-starter](https://github.com/se7enxweb/exponential-static-site-starter).
3. Give each organizer an editor account, and the publish policy to one or two of them.
4. Make the target with the wizard and publish.

## Content that works well

- An event per meetup, with date, place, talks and a map link.
- Speaker pages with slides as downloads.
- A "join us" page linking to the group's chat or mailing list.
- News, and a page in a second language if your group needs it.

## What to do about sign-ups

A static page cannot take registrations. Link to the event service you use, or let the form post to the live
installation if it is public. See
[Search, forms and comments on a static site](../static-publishing/search-forms-and-comments-on-a-static-site.md).

## Hand it over

Groups change organizers. Because the site is in the group's organization and every publish is tagged, a new
organizer takes over the account and keeps going. The [FAQ](../static-publishing/faq.md) answers the usual questions.

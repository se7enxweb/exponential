# Community: start here

**Exponential Community members use, contribute to, promote and develop software using Exponential worldwide.**

If you run an Exponential site, build one for someone else, write an extension, translate a screen, answer a
question in the forums or tell a colleague about the project, you are part of the community. There is no sign-up
form and no fee: the community is the people who take part.

This section explains how to take part well: where people meet, how to ask and how to answer, the ways to contribute
and what each one needs from you, how the project makes its decisions and releases, and the paths from first visit
to long-term contributor.

## The community in one minute

- **Two organizations, one open project.** The company 7x leads development, support and hosting; the nonprofit
  Exponential Foundation operates the project ([Who is 7x?](../who-is-7x.md),
  [Who is the Exponential Foundation?](../who-is-the-exponential-foundation.md)). The community is everyone else who
  takes part, and the two organizations are part of it too.
- **Everything is free software.** The code is GNU GPL version 2 or later and the documentation GNU FDL 1.3 or later
  ([Free documentation](../free-documentation.md)). What you contribute stays free for everyone.
- **Every pull request is merged.** While it is open, its author revises it through the review rounds; once merged,
  `main`'s history is never rewritten ([How the project grows](../who-is-the-exponential-foundation.md#how-the-project-grows)).
- **One code of conduct for everyone.** The Contributor Covenant 2.1 with Exponential additions; reports go to
  community@se7enx.com and the Exponential Foundation decides ([The code of conduct](joining/the-code-of-conduct.md)).
- **Help is public.** Forums, a Telegram chat, an encyclopedia, documentation and public issue trackers.

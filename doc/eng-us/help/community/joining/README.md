# Joining the community

There is nothing to sign and nothing to pay. You join the Exponential Community by showing up in one of the places
where people meet and taking part. These pages help you do that well.

## Suggested order

Read [The code of conduct](the-code-of-conduct.md) and [Where people meet](where-people-meet.md) first. Read
[Asking a good question](asking-a-good-question.md) before your first question, and
[Staying informed](staying-informed.md) once you run a site you want to keep current.

## Three things to know before you post

1. **No passwords, keys or personal data in public.** Not in a forum post, a chat message or an issue
   ([When something goes wrong](../../when-something-goes-wrong.md)).
2. **Security problems are private.** Send them to security@se7enx.com, never to a public place (`SECURITY.md`).
3. **Free help has no answer time.** People help when they can; if you cannot wait, see
   [Getting support](../../project/getting-support.md).

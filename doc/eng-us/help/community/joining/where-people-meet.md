# Where the community meets

All community places are public and free. Choose by what you want to do, not by where you happen to have an account.

## The places

| Place | Address | Good for |
|---|---|---|
| Share | [share.exponential.earth](https://share.exponential.earth/) | The community portal: forums, blogs, articles, news |
| Forums | [share.exponential.earth/forums](https://share.exponential.earth/forums) | Questions with longer answers, discussions that others should find later; a forum for Exponential Platform too |

| eZpedia | [ezpedia.exponential.earth](https://ezpedia.exponential.earth/) | A community encyclopedia under the GNU FDL, since 2006: tricks and how-tos that should last |
| Projects | [projects.exponential.earth](https://projects.exponential.earth/) | Community projects and extensions |

## Choosing a place

| You want to | Go to |
|---|---|
| Ask "how do I ...?" | The help first, then the forums; Telegram, Discord or Slack for something quick |
| Report a bug | The **Report an error** page of the help (`exphelp/report`), which opens an issue on the right tracker |
| Suggest an idea for the project or its websites | The community issue tracker |
| Propose a change to the code | A pull request on GitHub ([Contributing code](../contributing/contributing-code.md)) |
| Share an extension | Projects, and its own GitHub repository ([Sharing extensions and themes](../contributing/sharing-extensions-and-themes.md)) |
| Write a tutorial | Share, or eZpedia for a short trick ([Writing tutorials and posts](../helping-others/writing-tutorials-and-posts.md)) |
| Fix the documentation | "Edit on GitHub" on the page ([Contributing documentation and help pages](../contributing/contributing-documentation-and-help-pages.md)) |

A forum answer stays findable for years; a chat answer scrolls away. When you get a good answer in a chat, consider
writing it up in the forums or on eZpedia so the next person finds it.

## Private matters

| Matter | Where |
|---|---|
| A security vulnerability | security@se7enx.com, or GitHub's private vulnerability reporting (`SECURITY.md`) |
| A conduct problem | community@se7enx.com; the Exponential Foundation decides (`CODE_OF_CONDUCT.md`) |
| The Foundation | [foundation.exponential.earth](https://foundation.exponential.earth/) |
| Paid services from 7x | [se7enx.com](https://se7enx.com/) |

## What is not documented

No conferences or regular meetups, no official social media accounts or hashtags, and no mailing list are named in
the sources ([The community channels](../../advocates/community-channels.md)). If you run a local group, it is yours;
see [Local groups](../local-groups/README.md).

# What the Exponential Community is

**Exponential Community members use, contribute to, promote and develop software using Exponential worldwide.**

That one sentence has four verbs, and each of them is a way into the community. You do not need to do all four.

## The four ways to belong

| Verb | What it looks like | Start with |
|---|---|---|
| **Use** | Running a site, editing content, administering an installation, building a site for a customer | [Getting started](../getting-started.md), [Customers: start here](../customers/customers-start-here.md) |
| **Contribute** | Bug reports, pull requests, translations, documentation, help pages, testing a release | [Ways to contribute](contributing/ways-to-contribute.md) |
| **Promote** | Telling others, writing posts, giving talks, answering objections honestly | [Advocates: start here](../advocates/advocates-start-here.md) |
| **Develop software using Exponential** | Sites, extensions, themes, site packages, integrations and applications built on the kernel | [Develop with Git](../develop-with-git.md), [Extension development](../extension-development/README.md) |

Using Exponential is already taking part. A clear bug report from someone who runs a site is as valuable to the
project as a patch, because it shows where the software fails real people.

## Who you meet in the community

| You meet | Usually found | What they can help with |
|---|---|---|
| Site owners and editors | The forums, Telegram | Day-to-day use, editorial habits, what works for a team |
| Administrators and hosts | The forums, issue trackers | Installation, upgrades, caching, servers, databases |
| Developers | GitHub, the forums | Templates, extensions, the kernel, the APIs |
| Designers and theme authors | Projects, GitHub | Designs, themes, the administration's look |
| Translators | GitHub, the help | The interface and the documentation in other languages |
| Advocates and trainers | Share, events they organize | Talks, tutorials, courses |
| Partners | Their own sites, the partner program | Paid projects, hosting, support contracts |
| People from 7x and the Foundation | Everywhere above | Reviews, releases, the project's direction |

## The organizations inside the community

Two organizations carry particular responsibility, and both describe themselves as part of the community effort:

- **7x** is "the North American corporation driving The Continued General Use, Support, Development, Hosting, Design
  of Exponential" and "took over leadership of the project and it's development, support, adoption and community
  growth in 2023" (`README.md`, "Who is 7x"; [Who is 7x?](../who-is-7x.md)).
- **The Exponential Foundation** is a nonprofit founded on 19 March 2026 whose mission covers "Funding, Adoption,
  Support, Direction, Education, Development, Promotion and Documentation" for the project
  ([Who is the Exponential Foundation?](../who-is-the-exponential-foundation.md#in-short)).

The kernel's copyright notice names both: "Copyright (C) 1998 - 2026 7x & Exponential Foundation".

## What the community is not

- **It is not a membership organization.** There is no member list, no fee and no card. Partners have a program with
  levels and an agreement ([Partners: start here](../partners/partners-start-here.md)); the community does not.
- **It is not a support contract.** People in the forums and the chat help because they want to. If you need
  guaranteed response times, that is what partners and hosting companies offer
  ([Support levels and response times](../partners/support-levels-and-response-times.md)).
- **It is not a place for advertising.** The code of conduct says: "Use community spaces to help, not to advertise"
  (`CODE_OF_CONDUCT.md`, "Partners and commercial conduct").
- **It is not the vendor of the past.** Exponential is "not associated with the original eZ Publish software or its
  original developer" (`README.md`, "Exponential Project Notice"). The code base began as eZ Publish, which its
  creator discontinued; the community that carries it on today is a different one.

## What the sources do not say

The repository and this help name no community council, no elected roles, no membership numbers and no regular
events. If you are asked about any of these, say that they are not documented. The one documented decision body for
conduct is the Exponential Foundation (`CODE_OF_CONDUCT.md`, "Enforcement"); how the project decides about code is
on [Who decides](how-it-works/who-decides.md).

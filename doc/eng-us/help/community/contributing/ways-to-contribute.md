# Ways to contribute

Pick by what you are good at and how much time you have. A small contribution finished is worth more than a large
one abandoned.

## Contents

1. [The table](#the-table)
2. [By role](#by-role)
3. [Choosing your first one](#choosing-your-first-one)

## The table

| Way | Skills | Typical time | What it changes | Page |
|---|---|---|---|---|
| Confirm an existing bug report | Running a site | 15 minutes | Maintainers know the bug is real and widespread | [Reproducing and confirming issues](../../advocates/reproducing-and-confirming-issues.md) |
| Report a bug well | Running a site | 30 minutes | A fix for everyone | [Filing a bug](filing-a-bug.md) |
| Answer a question | Experience | 15 minutes | One person unblocked, and a findable answer | [Answering questions](../helping-others/answering-questions.md) |
| Fix a help page | Writing | 10 minutes | Everyone who reads the page | [Contributing documentation and help pages](contributing-documentation-and-help-pages.md) |
| Translate messages | A second language | 1 hour and up | Every user of that language | [Contributing translations](contributing-translations.md) |
| Test the development line | Running a test site | 1 hour per release | Fewer surprises after a release | [Testing releases](testing-releases.md) |
| Write a tutorial | Experience, writing | An afternoon | Newcomers learn faster | [Writing tutorials and posts](../helping-others/writing-tutorials-and-posts.md) |
| Fix a bug in code | PHP, templates | An afternoon and review rounds | A fix for everyone | [Contributing code](contributing-code.md) |
| Publish an extension or theme | PHP, templates, design | Days | New capabilities for others | [Sharing extensions and themes](sharing-extensions-and-themes.md) |
| Contribute a site package | Building sites | Days | A starting point for new sites | [Contribute your site package](../../site-packages/contribute-your-site-package.md) |
| Mentor a newcomer | Experience, patience | An hour a week | A new contributor | [Mentoring](../helping-others/mentoring.md) |
| Fund the work | A budget | Minutes | Paid time for maintenance and features | [Funding the community](../how-it-works/funding-the-community.md) |

## By role

| You are | Good first contributions |
|---|---|
| An editor | Report confusing screens, fix help pages for editors, translate |
| An administrator | Confirm bugs, test releases, document installation tricks |
| A developer | Fix a bug, add a test, review a pull request, publish an extension |
| A designer | Report accessibility problems, contribute to a theme, improve the administration's styling ([Contributing for designers and themers](../paths/community-for-designers-and-themers.md)) |
| A host or agency | Test releases on many servers, document hosting setups, become a partner |
| A student | Answer questions you have just solved yourself, translate, fix help pages |

## Choosing your first one

If you do not know where to begin, do this: use the software for a week, note every place where you got stuck, and
turn the most annoying one into a bug report or a help page fix.
[Your first contribution](your-first-contribution.md) shows how.

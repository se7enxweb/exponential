## Safe first contributions

| Contribution | Needs |
|---|---|
| Fix a typo or an unclear step on a help page | A GitHub account |
| Translate interface messages into your language | A second language |
| Answer a question you solved yourself last week | Patience |
| Confirm a bug on your test installation | A test installation |
| A small code fix with a test | PHP, Git, patience with review |

[Your first contribution](../contributing/your-first-contribution.md) walks through them.

## Building a public portfolio

"Real contributions are the best portfolio a student can have: a merged pull request is public proof of skill"
([Student and education partners](../../partners/student-and-education-partners.md)). Keep a list of your merged
pull requests, translations and help pages ([Tracking your contributions](../../advocates/tracking-your-contributions.md)).

## The Student partner level

The partner program has a Student level "For students, universities, or learning institutions", at $25 a month as
published on 18 October 2026, with "sandbox access, educational resources, and training support"; what "sandbox
access" includes is not described ([Student and education partners](../../partners/student-and-education-partners.md)).
It is optional: everything else on this page is free.

## Asking without fear

- No question is too basic; the code of conduct protects you from mockery ([The code of conduct](../joining/the-code-of-conduct.md)).
- Say that you are learning; people adjust their answers.
- Show what you tried ([Asking a good question](../joining/asking-a-good-question.md)).
- If you used an AI tool to write code or an answer, check it and say so (`CODE_OF_CONDUCT.md`).

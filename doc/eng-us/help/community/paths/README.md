# Paths through the community

People take part in very different ways. These pages describe the common paths, by stage and by role, so you can see
what the next step looks like from where you are.

## Contents

1. [Paths by stage](#paths-by-stage)
2. [Paths by role](#paths-by-role)
3. [No path is required](#no-path-is-required)

## Paths by stage

```text
user  ->  contributor  ->  regular contributor  ->  maintainer of an area or extension
                    \                                   \
                     ->  advocate / trainer               ->  partner (for companies)
```

| Page | The step |
|---|---|
| [From user to contributor](from-user-to-contributor.md) | Your first contributions and how they become a habit |
| [From contributor to maintainer](from-contributor-to-maintainer.md) | Taking responsibility for an extension or an area |
| [From community to partner](from-community-to-partner.md) | When a company joins the Exponential Partner Program |

## Paths by role

| Page | For |

## No path is required

Many people use Exponential for years and only ask a question now and then. That is taking part too. The paths are
there for those who want more.

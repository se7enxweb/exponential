# Reading paths for theme designers

This page is for theme designers who want to know what to read, in which order. Pick the path that matches your
situation. Each path mixes pages from this section with the [designer help](../designers/designers-start-here.md),
which explains the technical side in depth, and the course [Theme design](../trainers/theme-designers/README.md), which
has exercises.

3. [Path C: redesigning a running site](#path-c-redesigning-a-running-site)

## Path A: visual designer, no code

About two days of reading.

1. [How Exponential themes differ](how-exponential-themes-differ.md)
2. [Your first day as a theme designer](your-first-day-as-a-theme-designer.md)
3. [From mockup to theme](from-mockup-to-theme.md)
4. [Mapping a design to content classes](mapping-a-design-to-content-classes.md)
5. [Designing with real content](designing-with-real-content.md), [Designing for editors](designing-for-editors.md)
6. [Designing view modes](designing-view-modes.md), [Designing content listings and cards](designing-content-listings-and-cards.md)
7. Foundations: [Type scale](type-scale.md), [Spacing and grid](spacing-and-grid.md), [Color palettes and ramps](color-palettes-and-ramps.md),
   [From design tool variables to CSS custom properties](from-design-tool-variables-to-css-custom-properties.md)
8. [Component inventory](component-inventory.md), [Designing interactive states](designing-interactive-states.md)
9. The page types: [headers and footers](designing-headers-and-footers.md), [navigation](designing-navigation-and-menus.md),
   [search](designing-search-results.md), [empty and error states](designing-empty-and-error-states.md),
   [forms](designing-forms.md), [login and user pages](designing-login-and-user-pages.md)
10. [Designing layout blocks](designing-layout-blocks.md), [Designing the front page](designing-the-front-page.md)
11. [Working with developers](working-with-developers.md), [Working with clients and reviews](working-with-clients-and-reviews.md)
12. [Handoff checklist](handoff-checklist.md), [Design QA checklist](design-qa-checklist.md)

   [Wash and escaping](../designers/templates/wash-and-escaping.md)

5. [Loading stylesheets](../designers/theme-design/loading-stylesheets.md), [The packer](../designers/theme-design/the-packer.md),
   [No inline CSS](../designers/theme-design/no-inline-css.md)

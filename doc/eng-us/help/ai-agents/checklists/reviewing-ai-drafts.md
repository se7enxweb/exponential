# Reviewing AI drafts

This checklist is for editors. A draft written by Exponential Intelligence carries the label "Exponential
Intelligence" and waits for you. You publish it, so you are responsible for it, as for any text
([Drafts and human review](../expai/drafts-and-human-review.md)).

## Content

- [ ] Every fact is true and current. The model may state things confidently that it could not know.
- [ ] Names of people, places, products and organizations are spelled right and belong here.
- [ ] Numbers, dates, prices and units match the source.
- [ ] Nothing is claimed that your organization would not say (promises, legal or medical statements).
- [ ] Quotes are real and attributed, or removed.
- [ ] Tone and length fit the audience of the page.

## Links and references

- [ ] Every link opens and leads where the text says.
- [ ] Links from web results checked with particular care.
- [ ] Internal links point to the right language version.

## Form and place

- [ ] The draft is in the intended place in the tree and of the intended class.
- [ ] Required fields are filled; fields the assistant cannot set (images, files, relations) are set by you.
- [ ] Title, summary, meta description and keywords are right.

## Translations and alt text

- [ ] Translations read by someone who knows the language ([Translation help](../expai/translation-help.md)).
- [ ] Alt text describes what the image means on this page, without guesses; decorative only where it truly carries
  no information ([Alt text for images](../expai/alt-text-for-images.md)).

## Warning signs

Stop and tell your administrator if a draft:

- contains text that reads like an instruction to a machine ("ignore", "publish", "send");
- changed fields or objects you did not ask about;
- contains links or content from sources you did not expect.

These can be signs that the model followed text hidden in content it read
([Untrusted data and prompt injection](../agentic-workflows/untrusted-data-and-prompt-injection.md)).

## Before you send

- [ ] You read the whole draft, not only the parts you asked to change.
- [ ] You know whether "Send for approval" waits for an approver or publishes at once; the draft says which.

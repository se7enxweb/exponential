# AI and agent checklists

This part is for anyone who is about to switch on AI features, connect an agent, or publish what an AI wrote. Each
checklist is short enough to print, and every item links to the page that explains it.

## Contents

1. [The checklists](#the-checklists)
2. [How to use them](#how-to-use-them)

## The checklists

| Checklist | Use it |
|---|---|
| [Before switching on Exponential Intelligence](before-switching-on-exponential-intelligence.md) | Before editors get the assistant on a live installation |
| [Before connecting an agent](before-connecting-an-agent.md) | Before an AI agent gets access through the REST API or expservices |
| [Reviewing AI drafts](reviewing-ai-drafts.md) | Every time an editor reviews a draft the assistant wrote |

## How to use them

- Copy the checklist into your own ticket or change record, and tick items there.
- An item you skip deliberately gets a reason in writing.
- Run the checklist again after a change of provider, model, agent or role.

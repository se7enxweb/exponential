# Checklists for hosts: overview

This section collects the checklists a hosting team uses again and again. Each item links to the page that explains
it. Print them (every help page can be printed or downloaded as a PDF), copy them into your ticket templates, or
adapt them: the help is free documentation.

## Pages in this section

| Checklist | Use it when |
|---|---|
| [New server](new-server.md) | you build a machine that will host Exponential sites |
| [New customer site go-live](new-customer-site-go-live.md) | a customer site is about to go public on your platform |
| [Monthly operations](monthly-operations.md) | once a month for every site you operate |
| [Security review](security-review.md) | before go-live, after an incident, and once a quarter |
| [Customer offboarding](customer-offboarding.md) | a customer leaves, or moves the site elsewhere |

## How to use them

- Keep a copy per server or per site, with the date and the name of who checked each item.
- An item that does not apply is marked "n/a" with a reason, not left empty.
- When an item fails, open a ticket; do not go live with an open item from the security sections.

> **Tip**
> The [runbooks](../runbooks/README.md) are the companion of these checklists: a checklist prevents, a runbook
> repairs.

# Other ways to give money

This page is for sponsors who do not use GitHub or prefer another payment method. GitHub Sponsors itself accepts
"debit or credit cards, and Patreon", and "As of February 23, 2023, GitHub Sponsors does not support PayPal"
(GitHub Docs, "About sponsorships, fees, and taxes"). The channels below are published by 7x and the Foundation
themselves (read 18 October 2026).

## To 7x

| Channel | Address | Source |
|---|---|---|
| GitHub Sponsors | <https://github.com/sponsors/se7enxweb> | README, `.github/FUNDING.yml` |
| Sponsor page | <https://sponsor.se7enx.com/> | README |
| PayPal | <https://www.paypal.me/7xweb> | README, `.github/FUNDING.yml` |
| Patreon | `7xweb` (`.github/FUNDING.yml`), <https://www.patreon.com/c/7xweb> | `.github/FUNDING.yml`, sponsor.se7enx.com |
| Venmo | <https://account.venmo.com/u/se7enxweb> | `.github/FUNDING.yml` |
| Cash App | <https://cash.app/$7xweb> | `.github/FUNDING.yml` |
| Buying support services | 7x store, linked from <https://sponsor.se7enx.com/> | sponsor.se7enx.com |

7x's sponsor page: "Please support our open source cms development with a support subscription or store purchase."

## A note on safety

Only use the addresses on this page or on the organizations' own websites. If you receive a request for money in the
name of 7x or the Foundation through another channel, check it with them first (<https://se7enx.com/contact>,
<https://foundation.exponential.earth/>).

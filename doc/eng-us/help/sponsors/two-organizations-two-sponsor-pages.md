# Two organizations, two sponsor pages

This page is for sponsors deciding where their money should go. Exponential has two sponsor pages because two
different organizations carry it.

## The two organizations

| | 7x | The Exponential Foundation |
|---|---|---|
| Kind | A company | A 501(c)(3) nonprofit corporation (<https://foundation.exponential.earth/>) |
| Role | "7x took over leadership of the project and it's development, support, adoption and community growth in 2023" (README) | "This project is operated by the Exponential Foundation" (<https://exponential.earth/about/project>) |
| GitHub account | se7enxweb, the account and Composer vendor of every 7x package | exponentialcms, the GitHub organization named "Exponential" (website <https://exponential.earth>) |
| Sponsor page | <https://github.com/sponsors/se7enxweb> | <https://github.com/sponsors/exponentialcms> |
| Listing text | "7x is a responsive American web design and development company ..." | "Support the Exponential Foundation's open source work to grow the Exponential (CMS and Family of CMSs) Projects." |

Both listings were read through the GitHub API on 18 October 2026.

## What each sponsorship supports

The se7enxweb profile README explains the two streams (cited in
[Who is the Exponential Foundation?](../who-is-the-exponential-foundation.md#the-foundation-and-7x)): sponsoring 7x
funds "the company that keeps the lights on" (monthly releases, Zeta Components patches, the LegacyBridge, the
Symfony fork, the database translator, the training book mirror); sponsoring the Foundation funds "the open-source
project itself".

| You want to fund | Choose |
|---|---|
| The people doing the daily maintenance and development now | 7x |
| Services in return: support, consulting, pair programming, priority | 7x (its tiers include these) |
| The open source project as an institution: documentation, tutorials, extensions, community | The Foundation |
| A donation that may be tax deductible in the United States | The Foundation (it states so; check with your adviser) |
| Both | Split your amount; both serve the same project |

## How they relate

The Foundation describes its work as happening "through the work of 7x the current leader in contributions both
financial, code, extension development, new features, infrastructure, maintenance and much much more back to the
project" (<https://foundation.exponential.earth/supporters>). The copyright of the code is held by "7x & Exponential
Foundation" together (COPYRIGHT.md). Funding either one supports the same code, the same releases and the same
community.

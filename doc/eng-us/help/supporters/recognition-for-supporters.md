# Recognition for supporters

This page is for supporters who want to know how their help is acknowledged. Recognition is never the main reason
to help, but it matters, especially for companies and for people building a career.

## Contributors

- **The Git history.** Every merged commit keeps its author: every pull request is merged, squashed and rebased
  by its author while it was open, and `main`'s history is never rewritten after the merge (`doc/eng-us/bc/6.0/ci.md`). `git shortlog -sn` shows everyone who
  contributed.
- **The documentation's copyright notice** names "the Exponential contributors" next to 7x and the Foundation
  ([The license of this documentation](../../README-LICENSE.md)).
- **Credit in the README** for the work of other projects, for example "with full credit to Mugo Web" (README).

## Sponsors

The GitHub Sponsors tiers (read 18 October 2026; the live pages are authoritative) list recognition such as:

| Recognition | 7x (<https://github.com/sponsors/se7enxweb>) | The Foundation (<https://github.com/sponsors/exponentialcms>) |
|---|---|---|
| Sponsor badge on your GitHub profile | $2 and $25 a month | $5 a month |
| A social media shoutout | $10 one time | $10 one time |
| Name or logo in the project README | $250 a month | $25 a month |
| Logo or name on the project website | – | $100 a month |
| Mention in release notes or announcements | $99 a month (release announcement and documentation) | $50 one time (release notes) |

Details: [How sponsors are recognized](../sponsors/sponsor-recognition.md). GitHub itself lets you choose whether
your sponsorship is shown publicly (GitHub Docs, "About sponsorships, fees, and taxes").

## Partners

Partners are recognized through levels, listings and points for community work
([Partners: start here](../partners/partners-start-here.md)).

## Not defined yet

A general "supporters" or "contributors" page on the project website, community awards or a supporter badge are not
described in the sources: to be defined by the Foundation. The Foundation's site has a "Supporters" section, which
currently describes 7x's contributions (<https://foundation.exponential.earth/supporters>).

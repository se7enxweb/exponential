# The Layouts part of a launch checklist

Nothing on the Layouts side is forgotten.

*Life cycle: Launch, example 20 of 33. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [On the command line](#on-the-command-line)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Every page type has a mapping (or falls to Default Layout on purpose).
2. Every page layout links `header` and `footer`.
3. No draft is open.
4. Shared layouts hold launch content.
5. A baseline export exists.

## On the command line

1. `exp:layouts list` and `exp:layouts list --drafts` cover the first three.

# A new recipe appears in the lists

The new recipe shows on the recipe index and in "latest recipes".

*Life cycle: Maintain, example 34 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [In the content tree](#in-the-content-tree)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Lists with a dynamic collection on Recipes show it; hand-picked lists need **+ Add items** if it belongs there.

## In the content tree

1. Create the Recipe below Recipes (node 144), **Send for publishing**.

## Which to choose

Dynamic lists for indexes; manual only for curated spots.

## Check

- The recipe is on the index page; it uses Full / Recipe.

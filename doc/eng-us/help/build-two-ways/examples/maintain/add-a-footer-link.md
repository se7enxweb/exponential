# Add a link to the footer's second line

A "Careers" link in the footer.

*Life cycle: Maintain, example 10 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [In the content tree](#in-the-content-tree)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

Not in the Layouts editor.

## In the content tree

1. In **Media > Configuration > Footer links**, **Create new > Menu item**, Title *Careers*, **Item URL** the address, **Send for publishing**; set its priority to place it.

## Which to choose

Content: editors do it.

## Check

- The link appears on the next page view.

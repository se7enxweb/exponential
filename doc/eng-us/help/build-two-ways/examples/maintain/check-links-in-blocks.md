# Check the links typed into blocks

No button leads to a page that moved.

*Life cycle: Maintain, example 30 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [With templates](#with-templates)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Open the layouts with buttons and check **Link URL** fields after moving sections.

## With templates

1. Links built from nodes (`$node.url_alias|ezurl`) follow moves; typed addresses do not.

## Which to choose

Prefer content links where the block offers them.

## Check

- Each button opens the expected page.

# Turn a template-built page into a layout

The editors can rearrange a page that used to be one template.

*Life cycle: Redesign, example 15 of 34. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [With templates](#with-templates)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Create a layout, link header and footer, add **Template block**s with the part names and standard blocks for the simple parts; publish and map.

## With templates

1. Cut the template into parts that stand alone; save each as `explayouts/tpl_block/<name>.tpl` in your extension.

## Which to choose

Move part by part; each step stays publishable.

## Check

- The new layout shows the same content as the old template.

# Turn a hand-picked list into a self-filling one

The latest-articles band stops needing weekly picks.

*Life cycle: Redesign, example 14 of 34. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [With templates](#with-templates)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Select the List, **Change** next to Collection type, **Dynamic collection**, query type, **Apply**; set parent, sort and number; **Publish layout**.

## With templates

1. Not a template task.

## Which to choose

Export first if the manual picks might be wanted back.

## Check

- The list shows the query result.

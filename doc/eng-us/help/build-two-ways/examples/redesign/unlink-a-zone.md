# Give one page type its own footer

The campaign pages get a reduced footer.

*Life cycle: Redesign, example 13 of 34. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [With templates](#with-templates)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. In the campaign layout, press the linking button (bottom left); the linked FOOTER zone has a `...` menu with **Update link** (choose a different zone) and **Unlink**. **Unlink**, add its own blocks, **Publish layout**.

## With templates

1. Or keep the link and make the footer template react to the page (for example by a CSS class on the layout) - more code, one footer.

## Which to choose

Unlinking is clear, but that layout no longer follows changes to the shared footer.

## Check

- Only the campaign pages show the reduced footer.

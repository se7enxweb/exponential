# A different background per layout

Campaign layouts with a colored band behind the hero.

*Life cycle: Redesign, example 28 of 34. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [With templates](#with-templates)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Drag **Column** into `main`, set its background color, move the Hero into the column's `main` placeholder; publish.

## With templates

1. Or CSS on a class set on the column (CSS class on the Design tab).

## Which to choose

Column with background for one-offs; a CSS class for a reusable style.

## Check

- The wrapper of the column has `bg-color-<color>`.

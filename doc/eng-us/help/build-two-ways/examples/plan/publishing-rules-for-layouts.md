# Plan who publishes layouts

A change to Header / Footer or Prefooter is reviewed before it reaches every page.

*Life cycle: Plan, example 32 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [For templates](#for-templates)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Shared layouts: changes in a draft, reviewed in the editor's preview, then **Publish layout** by the agreed person.
2. Take an export before publishing a shared layout.

## For templates

1. Template changes are reviewed in the extension's repository like any code.

## Which to choose

Treat shared layouts like templates: review first.

## Check

- An export exists from before each shared-layout publish.

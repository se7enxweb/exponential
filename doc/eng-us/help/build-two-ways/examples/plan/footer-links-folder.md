# Plan the footer links folder

Editors maintain the service links without settings.

*Life cycle: Plan, example 31 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [In the settings](#in-the-settings)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. The folder Media > Configuration > Footer links holds Menu items sorted by priority.

## In the settings

1. Another folder per site: set `FooterLinksRemoteID` in the siteaccess' `menu.ini` to its remote ID.

## Which to choose

One folder per site keeps sites apart.

## Check

- The planned links exist as Menu items with URLs.

# List the block types you will need

Know before building which blocks exist and which must be made.

*Life cycle: Plan, example 13 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [With templates](#with-templates)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. The palette groups: Basic (Title, Text, Button / Link, Rich text, External video, Map, Markdown, HTML snippet, Image, Spacer, Divider, Card, Alert, Badge, Progress bar, Accordion, Tabs), Components (Hero, About, Features, Logos, Quote, Lead), Listing (List, Grid, Zig-Zag, Accordion), Gallery (Gallery, Slider, Thumb gallery, Grid gallery, Sushi bar, Carousel), Containers (Column, Two/Three/Four columns), Placeholders (Template block, Full view, Single content).

## With templates

1. A missing kind of block is a block definition, a handler and a template ([Add a block type](../../add-a-block-type.md)); a missing look of an existing block is a view type ([Add a view type](../../add-a-view-type.md)).

## Which to choose

Prefer a view type over a new block type when the data is the same.

## Check

- Every element of the page designs maps to a block type or a planned new one.

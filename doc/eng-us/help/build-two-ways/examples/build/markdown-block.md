# A block written in Markdown

A short list of opening hours, typed in Markdown.

*Life cycle: Build, example 9 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## In the Layouts editor

1. Open **Layouts > Layouts** and the layout *Landing Page / Home*; the editor opens it in a draft.
2. Open the block palette (**+** at the top left) and drag **Markdown** (group *Basic*) into the zone `main`.
3. Select the block, open the **Design** tab and fill **Markdown content**.
4. **Publish layout**. The pages that use the layout show the block on their next view.

The standard template prints the converted HTML (`$block.values.html`) inside `<div class="slb slb-markdown">`.

## With templates

1. Use a Rich text or Text field of a content item instead; content fields are edited with the site's editor.

## Which to choose

Markdown is quick for lists and links; content fields are better when the text must be translated.

## Check

- Lists and links render as HTML, not as asterisks and brackets.

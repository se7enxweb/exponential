# Where the designers' help continues

Part 6, chapter 9, the last of this part. This book explains themes from the point of view of an extension
developer. The help has a whole section written for designers, with hundreds of pages on templates, theme design,
packaging, distribution, selling themes and maintaining them. This chapter is the bridge: for each topic of Part 6,
where to read on.

Start at [Designers start here](../../designers/designers-start-here.md), or browse
[every page of the designer help](../../designers/README.md).

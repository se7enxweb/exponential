# Part 1: From user to developer

This is the first part of [Extension development: the book](../README.md). It is written for people who already use
Exponential, as an editor, an administrator or a site owner, and who want to start changing what it can do. You do not
need to know PHP yet. By the end of this part you will have a development installation of your own, you will know how
to read the code that is already on your disk, and you will know where to look for the work of the hundreds of people
who built extensions before you, and how to reuse it fairly.

## How to read it

Read the chapters in order the first time. Each one ends with **Previous** and **Next** links. Every command was run
on an Exponential 6 installation before it was written down, and every page names the file or the page where its
facts come from, so you can check them yourself.

> **Tip**
> Keep a terminal and the administration open side by side while you read. Nearly every chapter asks you to look at
> something on your own installation; seeing it there is what makes it stick.

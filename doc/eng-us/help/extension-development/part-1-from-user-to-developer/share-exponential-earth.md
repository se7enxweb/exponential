# Share Exponential (share.exponential.earth)

Part 1, chapter 11. [Share Exponential](https://share.exponential.earth/) is the community portal of the Exponential
project. This chapter tells you what a developer finds there and how to use it well. The description is as of
October 2026; the portal itself is the authority on its current sections.

## What it is

The portal describes itself as the place where developers, users and contributors work together. Its footer states
that its content is copyright 7x and that the project "is not associated with the original eZ Publish software or its
original developer, eZ Systems or Ibexa". It runs on Exponential itself.

## How to search it

1. Use the portal's own search for words from your error message or the name of the class or setting.
2. Search the forums of the old product name too: many answers from the earlier years still apply to the kernel,
   whose code base Exponential continues.
3. When you find an answer, check which version it was written for. Settings and templates rarely changed; PHP code
   written for PHP 5 needs the changes in [Part 4](../part-4-upgrading/README.md).

## Using what you find

The portal's content is copyright 7x unless a page says otherwise. That means:

- **Link** to a forum thread or tutorial rather than copying it into your own documentation.
- **Quote** a short passage when you need to, with a link and the date you read it.
- **Code** posted in a forum carries no license statement by itself. For a few lines that solve a common problem this
  is rarely a concern, but for anything substantial, ask the author in the thread whether you may reuse it under your
  extension's license. [Reading licenses before you reuse anything](reading-licenses-before-reusing.md) explains why.

## Giving back

A portal like this lives on answers. Once you have solved something:

- Answer the question in the forum where you found it unanswered.
- Write a tutorial (the **Write a tutorial!** page explains how).
- Announce your extension in the Extensions forum when you release it; see
  [Announcing a release](../part-7-releasing/announcing-a-release.md).

# Talking about free static sites with Exponential

This page is for journalists, bloggers and advocates who want to describe static publishing correctly.

## What you'll have at the end

Three key messages, a pitch you can use as it is, facts to check against, and links to show it.

## Key messages

1. **Free public websites from a full CMS.** Exponential 6.0.15 publishes a static copy of a site to GitHub Pages,
   where public sites are hosted at no cost.
2. **Editors keep their tools.** Content is written and approved in Exponential, with versions, roles and
   translations. Only the public copy is static.
3. **Safe by design.** The copy is made as an anonymous visitor sees the site; it has no login, no database and no
   PHP. Every publish is a tagged git commit and can be rolled back.

## A short pitch

> Exponential 6.0.15 turns any of its sites into a static website and publishes it to GitHub Pages or any git host.
> Nonprofits, schools, small businesses and individuals get a fast, secure public site with no hosting bill, while
> their editors keep working in a full content management system.

## Facts

- Introduced in Exponential 6.0.15; available under Setup > Static publishing and as `exp:static:*` commands.
- Works with GitHub Pages (branch or GitHub Actions), and pushes to any other git host.
- Custom domains with HTTPS, search in the browser, forms through the live site, automatic and scheduled publishing.
- Open source, GPL; no paid service is required.

## What not to say

- It is not a shop platform: GitHub Pages terms do not allow online shops, and a static copy has no checkout.
- It does not replace the Exponential installation; editing still needs one, which can stay private.
- "Free" means the hosting of public repositories on GitHub Pages; a custom domain is paid to a registrar.

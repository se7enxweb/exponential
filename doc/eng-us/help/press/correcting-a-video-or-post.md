# Correcting a video or post

This page is for video creators, streamers, podcasters and social media writers. Videos are harder to correct than
articles, which is exactly why a visible correction matters. The rule is the same everywhere: correct openly, say what
was wrong and what is right, and link the source.

## Choosing the fix

| Error | Fix |
|---|---|
| A small slip (a wrong date, a misspoken version) | A correction at the top of the description and a pinned comment |
| An error that misleads viewers on what the software does | The above, plus an on-screen note or a short follow-up video |
| Something unsafe (a password shown, a vulnerability described before its fix) | Take it down or cut it at once, then re-upload ([Privacy on camera](privacy-on-camera.md)) |
| A wrong claim repeated across many posts | Correct each post; add a note to the newest one |

Do not delete silently: people may have shared or quoted the original.

## Corrections by kind of error

| Kind | Typical error | Correct statement and source |
|---|---|---|
| Name | "eZ Publish 6" | Exponential 6 ([Naming quick reference for news editors](naming-quick-reference-for-editors.md)) |
| Organization | "the 7x Foundation" | the Exponential Foundation ([Two organizations, one project](two-organizations-one-project.md)) |
| Release | "6.0.15 is out" | 6.0.15 is in development ([The 6.0.x releases at a glance](the-6-0-x-releases-at-a-glance.md)) |
| Feature | "the AI publishes" | It writes drafts only ([Story: an assistant that writes drafts only](story-ai-that-writes-drafts-only.md)) |
| Number | A speed comparison | The documented figures and their conditions only ([Verifying numbers](verifying-numbers.md)) |
| Affiliation | "by Ibexa" | Not associated with eZ Systems or Ibexa |
| Disclosure | A sponsorship not mentioned | Add the disclosure at the start of the description ([Disclosure and sponsorship ethics](disclosure-and-sponsorship-ethics.md)) |

## Templates

```text
Description, first line:
CORRECTION (<date>): At <mm:ss> I said <wrong>. That is not right: <right> (source: <link>).

Pinned comment:
Correction: <right statement>. Source: <link>. Thanks to <name, if they agree> for pointing it out.

On-screen note (added in the editor):
Correction: <right statement, short>

Social post:
Correction to my post above: I wrote "<wrong>". The documentation says "<right>" (<link>). Sorry for
the confusion.
```

## When someone points out an error

1. Thank them and check the source they give ([Fact-checking guide](fact-checking-guide.md)).
2. If they are right, correct within a day and say so in the thread.
3. If they are wrong, answer politely with your source.
4. If the documentation itself is wrong, tell the project on the
   [community issue tracker](https://github.com/se7enxweb/exponential-community/issues) or with **Edit on GitHub**.

# Creator checklist

This page is for video creators, streamers, podcasters and bloggers. Run it before you record, before you publish and
after. Each line links the page that explains it.

## Contents

1. [Before recording](#before-recording)
2. [While recording](#while-recording)
3. [Before publishing](#before-publishing)
4. [After publishing](#after-publishing)

## Before recording

```text
[ ] Relationship, payment or gift decided and written down for the disclosure
[ ] Demo installation of my own, version noted
[ ] Fictional users at example.com; default administrator password changed
[ ] No production data, no client sites
[ ] Script follows a tested demo script; claims checked
[ ] Notifications, mail and chat apps closed; clean browser profile
```

Pages: [Disclosure and sponsorship ethics](disclosure-and-sponsorship-ethics.md),
[Setting up a demo installation](setting-up-a-demo-installation.md),
[Privacy on camera](privacy-on-camera.md), [Demo script: five-minute overview](demo-script-five-minute-overview.md),
[Keeping secrets off screen](keeping-secrets-off-screen.md).

## While recording

```text
[ ] Disclosure said in the first seconds
[ ] Version said and shown
[ ] Actions described aloud, not only shown
[ ] No passwords, keys, tokens, host names typed or shown
[ ] Unreleased features called "in development"
```

Pages: [Video walkthrough guide](video-walkthrough-guide.md), [Live stream guide](live-stream-guide.md),
[Covering 6.0.15 while it is in development](covering-6-0-15-while-in-development.md).

## Before publishing

```text
[ ] Names: Exponential, 7x, the Exponential Foundation; old name only as history
[ ] Every number with its source and conditions; no usage numbers or "faster than"
[ ] Captions checked by a person; transcript for audio
[ ] Title and thumbnail make a claim the content supports
[ ] Disclosure at the top of the description, platform label set
[ ] Music, fonts and images licensed and credited
[ ] Description links: the project, the sources you used
[ ] Frames checked for secrets and personal data
```

Pages: [Naming quick reference for news editors](naming-quick-reference-for-editors.md),
[Verifying numbers](verifying-numbers.md), [Captions and accessible video](captions-and-accessible-video.md),
[Titles, thumbnails and descriptions](titles-thumbnails-and-descriptions.md),
[Third-party music, fonts and assets](third-party-music-fonts-and-assets.md).

## After publishing

```text
[ ] Questions answered with sources; support questions sent to the right place
[ ] Security reports moved to private channels
[ ] Errors corrected openly
[ ] Update note when a feature shown as "coming" is released
```

Pages: [Handling comments and questions](handling-comments-and-questions.md),
[Correcting a video or post](correcting-a-video-or-post.md), [Corrections and updates](corrections-and-updates.md).

# Writing about funding and sponsors

This page is for reporters who ask "who pays for this?" It is a fair question for any open source project. The
public sources answer part of it; this page separates what they say from what they do not.

## What sponsorship is said to fund

From the se7enxweb GitHub profile, as quoted on [What the Foundation funds](../who-is-the-exponential-foundation.md#what-the-foundation-funds):

- sponsoring the **Foundation** funds "the open-source project itself": core library maintenance, API and core
  documentation, GraphQL, REST and Solr layers, community infrastructure, Zeta Components security hardening;
- sponsoring **7x** funds "the company that keeps the lights on": releases, Zeta Components patches, the LegacyBridge,
  the Symfony fork, the database translator, the training book mirror.

The sponsors section of this help explains it for sponsors: [What sponsorship funds](../sponsors/what-sponsorship-funds.md).

## What is not published

- The Foundation's budget and number of donors.
- 7x's revenue and how much of its time goes to the open source project.
- The number of sponsors on the GitHub pages at any moment beyond what the pages themselves show.

Look at the sponsor pages yourself on the day you write, quote what they show with the date, and ask the organizations
for anything else ([Questions to ask the Foundation](questions-to-ask-the-foundation.md)).

## Writing it

```text
Good:  "The project is funded mainly by 7x's own work and by sponsors; 7x and the Foundation each have a
        GitHub Sponsors page."
Good:  "The Foundation did not publish a budget; asked, it said ... (date)."
Avoid: "The project is struggling for money."   (no source says so)
Avoid: "Backed by big sponsors."                 (name sponsors only as the pages show them, with consent)
```

If you sponsor the project yourself, disclose it in your coverage ([Disclosure and sponsorship ethics](disclosure-and-sponsorship-ethics.md)).

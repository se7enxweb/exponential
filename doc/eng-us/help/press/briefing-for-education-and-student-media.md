# Briefing for education and student media

This page is for student journalists, campus media, teachers and education writers. Exponential is a useful teaching
case: a large open source code base with a public history of more than twenty years, free documentation, and a
project that merges every contribution.

## Why it fits education stories

| Theme | Why Exponential illustrates it | Source |
|---|---|---|
| Open source licensing | The GPL let a new steward continue the code after its creator stopped | [Licenses explained for reporters](licenses-explained-for-reporters.md) |
| Software history | Commits since 2002, copyright since 1999, a month-by-month history since 2023 | [The history for long-form stories](the-history-for-long-form-stories.md) |
| Documentation as a commons | The documentation is free under the GNU FDL | [Story: free documentation](story-free-documentation.md) |
| Accessibility and languages | Contrast and target-size tests; right-to-left support | [Story: accessibility](story-accessibility.md) |

## How students can take part

- Report a bug well ([When something goes wrong](../when-something-goes-wrong.md)).
- Fix a help page with **Edit on GitHub** ([Improving the help](../advocates/improving-the-help.md)).
- Complete a translation ([Languages in Exponential](../../languages.md)).
- Send a first pull request ([Develop with Git](../develop-with-git.md)); every pull request is merged
  ([Story: every pull request is merged](story-every-pull-request-merged.md)).

The partner program has a category for education partners ([Student and education partners](../partners/student-and-education-partners.md));
check that page for what is published about it.

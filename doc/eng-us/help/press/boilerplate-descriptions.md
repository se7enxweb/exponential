# Boilerplate descriptions you may copy

This page is for anyone who needs a ready description: the "about" paragraph at the end of an article, the
description under a video, podcast show notes, a conference program. Every sentence comes from a cited source, and
you may copy the texts freely (they are free documentation). They describe the state of **18 October 2026**.

## Exponential

### 25 words

```text
Exponential is a free, open source PHP content management system and application framework, led by 7x and
operated by the nonprofit Exponential Foundation.
```

### 50 words

```text
Exponential is a free and open source PHP content management system and application framework with a fully
customizable content model, multisite, many languages and a built-in shop. Its code base has been developed
since 1999. The company 7x leads its development; the nonprofit Exponential Foundation operates the project.
```

### 100 words

```text
Exponential is a professional PHP application framework with advanced content management functionality. Its
most notable feature is a fully customizable content model: organizations define their own content types,
edit them with versions and approval, and publish to several sites in many languages, including right-to-left
scripts. It includes a shop, workflows, a REST API and a visual page builder. Exponential is free software
under the GNU GPL. Its code base has been developed since 1999, first under the name eZ Publish. The company
7x leads development, and the Exponential Foundation, a nonprofit founded in 2026, operates the project.
```

### 250 words

```text
Exponential is a free and open source content management system and application framework written in PHP.
Its README calls it "a professional PHP application framework with advanced CMS (content management system)
functionality" whose most
notable feature is "its fully customizable and extendable content model". Organizations use it to define their
own content types, edit them in the browser with versions, approval and scheduled publication, and publish
them to several websites in many languages, including right-to-left scripts. It includes a built-in shop,
workflows, a headless REST API, a visual page builder (Exponential Layouts), a writing assistant that writes
drafts only (Exponential Intelligence) and its own PHP web server (Exponential Velocity).

Exponential runs on PHP 8.0 to 8.5 (PHP 7.4 usable without support) with SQLite, PostgreSQL, MongoDB, MariaDB, Oracle or MySQL, on Linux, BSD,
macOS and Windows. The software is licensed under the GNU General Public License, version 2 or later, and is
free of charge; its documentation is free documentation under the GNU FDL.

The code base has been developed since 1999, first under the name eZ Publish, a product its creator
discontinued after almost 18 years. 7x, a North American web development, support and hosting company, launched
its project to carry the code forward in December 2023 and released version 6.0.0 on 1 January 2024. The
product has been called Exponential since August 2025. The Exponential Foundation, a 501(c)(3) nonprofit
founded in Seattle in March 2026, operates and funds the project. More: https://exponential.earth/
```

## 7x

```text
7x is a North American web design, development, support and hosting company that leads the development of
Exponential, the open source PHP content management system. Formerly Brookins Consulting, it launched its
Exponential project in December 2023. Website: https://se7enx.com/
```

## The Exponential Foundation

```text
The Exponential Foundation is a 501(c)(3) nonprofit corporation founded in Seattle, Washington, on
19 March 2026. Its mission is the continued funding, adoption, support, direction, education, development,
promotion and documentation of the Exponential open source project. Website: https://foundation.exponential.earth/
```

## Rules for changing them

- **Shorten freely; do not add claims.** Leave out sentences, but do not add numbers, customers or superlatives that
  no source supports ([What the sources do not say](what-the-sources-do-not-say.md)).
- **Keep the old name in the past tense** if you keep the history sentence ([Writing about the eZ Publish years](writing-about-the-ez-publish-years.md)).
- **Do not present these texts as quotes** from 7x or the Foundation. They are documentation
  ([Attributing statements](attributing-statements.md)).
- **Update release facts.** Once 6.0.15 is released, the 250-word text may name it; until then, it may not.

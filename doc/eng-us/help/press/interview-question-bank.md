# Interview question bank

This page is for interviewers: journalists, podcast hosts, video creators and student reporters. Each question comes
with the background the documentation already gives, so you can skip what is answered and ask what is not. These are
questions, not answers; nothing on this page is a statement by 7x or the Foundation.

## How to use this bank

Pick five to eight questions. Read the background column first: if the documentation already answers it, cite the
documentation and use your time for the follow-up. Open questions are marked **open**.

## Questions that need care

- **About other companies.** Ask about Exponential's own choices, not for opinions on eZ Systems or Ibexa; Exponential
  "is not associated with" them ([Who is 7x?](../who-is-7x.md#in-short)).
- **About customers.** Customers may be named only with their consent; do not press for names.
- **About individuals.** Ask about roles, not private lives; print personal details only with consent.
- **Answers with numbers.** Ask "where can readers check that?" and print the source with the number
  ([Verifying numbers](verifying-numbers.md)).

# Learning Exponential: the chapters of the Learning book, brought up to date

*Learning eZ publish: Building Content Management Solutions* is the first book written about the system Exponential
continues. It is free documentation: the second edition (2024) is published by 7x under the GNU Free Documentation License
([Book-Learning-eZPublish](https://github.com/se7enxweb/Book-Learning-eZPublish)). These pages take its chapters one at a
time and rewrite each for Exponential 6: the steps that moved, the settings that were renamed, the examples that no longer
work, and the parts that did not change at all, which is most of the concepts.

Every page keeps the book's order of ideas, says plainly what is different now, and links to the current guide for the
details. Each ends with the credit and license of the book. [Learning from the free books](../extension-development/part-1-from-user-to-developer/learning-from-the-books.md)
explains how the books relate to this help and how to read the original against Exponential 6.

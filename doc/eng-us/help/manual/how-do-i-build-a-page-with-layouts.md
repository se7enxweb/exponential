# How do I build a page with Layouts?

A layout arranges blocks (texts, lists, images, teasers) in zones. You build it in the layout editor and then map it to
the pages it should shape.

## Who can do this

Users whose role has the Layouts policies (the extension explayouts, in a new installation): editing layouts, and for
mapping, editing the mappings.

## Steps

1. Click **Layouts** in the top menu and click **Open the layout editor**.
2. Create a new layout and choose its layout type: the type decides the zones (for example top, main and side).
3. Drag a block type from the block list into a zone.
4. Select the block and fill it: its content (choose items with the content browser), its texts, and under **Design**
   its view type and look.
5. Repeat for every block. Use the preview to check the page.
6. Click **Publish** to publish the layout.
7. Map it: add a mapping that names the page (or the class, or the part of the tree) the layout shapes.

## What can go wrong

- **The page still looks the same.** The layout has no mapping for that page, or another mapping comes first.
- **A block is empty on the site.** Its content is hidden, in the trash, or not readable for visitors.
- **You changed a shared layout and every page changed.** Header and footer are shared. Discard the draft if that was
  not intended.

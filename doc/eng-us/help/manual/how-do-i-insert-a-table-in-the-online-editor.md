# How do I insert a table in the Online Editor?

Use a table for data that has rows and columns, such as prices or opening hours, not to arrange text on the page.

## Who can do this

Editors who may edit the object.

## Steps

1. Edit the object and put the cursor where the table goes.
2. Click the table button (**Inserts a new table**).
3. Enter the number of columns and rows, and choose whether the first row is a header.
4. Click **Insert**.
5. Type into the cells. To change the table, put the cursor in a cell and use **Insert row before**, **Insert row
   after**, **Insert column before**, **Insert column after**, or the buttons that delete a row or column.
6. Click **Send for publishing**.

## What can go wrong

- **The table is too wide on a phone.** Keep tables to a few columns. Split a wide table into two.
- **A screen reader cannot tell what a column means.** Give the table a header row.

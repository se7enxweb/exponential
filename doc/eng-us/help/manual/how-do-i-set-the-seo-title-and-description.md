# How do I set the SEO title and description of a page?

The title and description that search engines and link previews show come from the object's meta data field. Without
them the site uses the object's name and its first text.

## Who can do this

Editors who may edit the object. The class must have a meta data field (the extension xrowmetadata); an administrator
adds it under **Setup** > **Classes**.

## Steps

1. Edit the object.
2. Find the meta data field (often at the end of the form).
3. Enter the **Title**: under 60 characters, the words people search for first.
4. Enter the **Description**: one or two sentences, under 160 characters, that make people click.
5. Optionally enter **Keywords**.
6. Under **More options**, set a **Canonical Link** if the same text is published at another address, and an **Open
   Graph image** with its **Open Graph image alt** for link previews.
7. Click **Send for publishing**.

## What can go wrong

- **The field is missing.** The class has no meta data field. Ask an administrator.
- **Search engines still show the old title.** They read the page again only after days or weeks.
- **The link preview shows the wrong image.** Set an **Open Graph image**; otherwise the class's default image is used.

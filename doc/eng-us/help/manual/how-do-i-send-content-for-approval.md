# How do I send content for approval?

You do not need a special button. Where the site has an approval workflow for your content, **Send for publishing**
sends the version to an approver instead of publishing it at once.

## Who can do this

Every editor whose content is covered by an approval workflow. Which sections, languages and user groups need
approval is set by an administrator.

## Steps

1. Create or edit the content as usual.
2. Click **Send for publishing**.
   If the content needs approval, the version is not published yet. It is listed in **Dashboard** >
   **My pending items**.
3. Wait for the approver. If you have collaboration notifications on, you get a mail when they decide.
4. Read the answer and any comment in **Dashboard** > **Collaboration**.
5. If it was denied, the version is a draft again: change it in **My drafts** and send it again.

## What can go wrong

- **It was published at once.** The content is not covered by an approval workflow, or you are in a group that is
  exempt. That is how the site is set up.
- **Nothing happens for days.** The approver has not handled it, or the workflow cronjob does not run. Ask the
  approver, then an administrator.

# How do I remove a translation or change the main language?

Every item has one **main language**, the one it was first created in unless someone changed it. The other languages
are translations of it. Both changes are made on the item's **Translations** tab.

## Who can do this

Editors who may edit the item. The buttons are grayed out without that right.

## Steps

### Change the main language

1. Open the item and click the **Translations** tab.
   **Existing translations** lists each language with its locale; the current main language is marked.
2. Choose the new main language with its radio button in the **Main** column.
3. Click **Set main**.

### Remove a translation

1. On the **Translations** tab, tick the languages to remove.
2. Click **Remove selected**.
   The page **Confirm translation removal** lists the languages.
3. Click **OK**.

## What can go wrong

- **The main language cannot be ticked.** It can never be removed. Make another language main first, then remove the
  old one.
- **Set main is grayed out.** The item exists in only one language, so there is nothing to switch to.
- **Attention: a removed translation is gone from every version.** Its text cannot be brought back from the version
  history. Old versions that were made by editing that language are removed with it. Export or copy the text first if you might
  need it.
- **Visitors of that language now see another language, or nothing.** What they see depends on the site's language
  list and the item's setting for untranslated languages: see
  [How do I show an item in languages it is not translated into?](how-do-i-show-an-item-in-untranslated-languages.md)

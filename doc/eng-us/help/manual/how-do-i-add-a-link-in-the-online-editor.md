# How do I add a link in the Online Editor?

A link can go to another site, or to an object of this site. A link to an object follows it when it moves or is
renamed.

## Who can do this

Editors who may edit the object.

## Steps

1. Edit the object and select the text that becomes the link.
2. Click **Insert/edit link** in the toolbar.
3. For another site, type the full address, starting with `https://`. For a page of this site, click **Browse** and
   choose the object.
4. Optionally choose to open the link in a new window, and give it a title.
5. Click **Insert**.
6. To remove a link, put the cursor in it and click **Unlink**.
7. Click **Send for publishing**.

## What can go wrong

- **The link to another site stops working later.** The other site changed. **Setup** > **Link management** lists
  links that fail: see [How do I find and fix broken links?](how-do-i-find-and-fix-broken-links.md)
- **You typed the address of a page of this site.** It works, but breaks when the page moves. Use **Browse** instead.

# How do I go back to an earlier version?

A published version is never changed in place. Every edit makes a new version, and the one before is kept as
**archived**. To bring back an older text, you make a new draft from the old version and publish that draft. Nothing
is lost on the way: the version you replace is archived in turn.

## Who can do this

Editors who may edit the item. Reading versions needs `content/versionread`; removing versions needs
`content/versionremove`.

## Steps

1. Open the item and click **Manage versions** (the round button with a clock). From the edit form, use
   **Manage versions** in the left column.
   The versions page opens with an **Overview** and the list of versions.
2. To find the right version, click **Compare** in a row, or choose an older and a newer version under
   **Compare two versions** and click **Show differences**.
   Removed text is struck through and added text underlined; switch between **Inline changes** and **Block changes**.
3. In the row of the version you want, choose its translation under **New draft from this version, in** and click
   **Make a new draft**.
4. Edit the new draft if needed, then click **Send for publishing**.
   The old content is published again as the newest version.

To tidy up, tick versions you no longer need and click **Remove selected versions**.

## What can go wrong

- **Edit is not offered for an old version.** Only drafts can be edited. Make a new draft from the old version.
- **The draft belongs to someone else.** You cannot edit it, but you can make your own new draft from it.
- **Other languages look different after the revert.** A new draft is made in one language; the other translations
  are taken from the current published version, so they keep their latest text.
- **Attention: removed versions are gone for good**, with all their translations. The published version, and versions
  in a running workflow, are never removed.
- **Very old versions are missing.** The site keeps a limited number of versions per item and removes the oldest
  archived ones when the limit is reached.

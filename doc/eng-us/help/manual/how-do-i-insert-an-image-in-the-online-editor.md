# How do I insert an image in the Online Editor?

An image in a text is an image object of the media library, embedded where the cursor is. The same image can be used
in many texts.

## Who can do this

Editors who may edit the object. Uploading a new image also needs `content/create` in the media library.

## Steps

1. Edit the object and click into the text field where the image goes.
2. Click **Insert/edit image** in the editor's toolbar.
3. Upload a new image (with a name and alternative text), or find an existing one by searching, browsing or in your
   bookmarks, and select it.
4. Choose the size (for example small, medium, large) and the alignment.
5. Click **Insert**.
6. Click **Send for publishing**.

## What can go wrong

- **The image has no alternative text.** Screen readers then say nothing about it. Give every image a short
  description of what it shows; the Design tab lists images without one.
- **The upload is refused.** The file is too large or of a type the site does not accept. Use JPEG, PNG or WebP below
  the size limit.
- **The image is too large on the page.** Choose a smaller size in the image dialog rather than a larger file.

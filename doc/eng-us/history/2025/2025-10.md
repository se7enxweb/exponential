# October 2025

What changed in Exponential in October 2025, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- No change to the main installation in October 2025.
- The layouts core was modernised for PHP 8.4 and the platform core got a content type search API.

**Layouts 2.0 takes shape upstream; no change to the main installation.** The main repository's ledger has no entry for October 2025. The 190 changes of the month belong to platform repositories carried by the se7enxweb forks.

## What changed in the platform ecosystem

- **Layouts core is modernised for PHP 8.4.** On 2025-10-28 the layouts core received constructor property promotion (`4a0824a52`, 278 lines) and the missing parameter and return typehints (`493bc5ea5`, 333 lines); on 2025-10-24 the persistence `STATUS_*` constants became a `Status` enum (`fcd9d72f3`). This is the beginning of the 2.0 development whose PHP 8.4 property visibility later required the [layouts-core fork](../../features/6.0/platform-layouts-core-fork.md). Why it matters: it explains why Nexus v5 pages need the fork on PHP 8.4.
- **New content type search API.** The platform core added a content type search PHP API (`62929022f0`, IBX-10458, 2025-10-03) and enforced a rule against dynamic properties (`fd2c23a2d7`, 2025-10-22), part of the PHP 8.4 clean-up that the [PHP framework forks](../../features/6.0/platform-php85-framework-forks.md) address for the older stack.
- **Admin interface.** Header improvements for collaboration (`1cc922812`, 2025-10-03), a service that fetches content fields from an expression and validates them (`de085b476`, 2025-10-17) and a quick-action button manager that shows several buttons (`a398bea6a`, 2025-10-20). See [the administration interface](../../features/6.0/platform-admin-ui-fork.md).
- **Site bundle.** The `ibexa-search-extra` bundle became a dependency and the location query uses its `Visible` criterion (NGSTACK-826, 2025-10-01 / 10-02). See [site bundles](../../features/6.0/platform-site-bundles.md).
- **AdminNeo.** The last release number is printed into compiled plugins (`aa8964b2`, issue 164, 2025-10-15), a setting displays links to referencing tables (`59dc1c25`, 2025-10-20) and backward key retrieval moved into the drivers (`3595129a`). See [AdminNeo](../../features/6.0/adminneo-database-manager.md).

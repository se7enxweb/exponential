# May 2024

What changed in Exponential in May 2024, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- No change to the main installation in May 2024; the work happened in the platform repositories.
- The `class_alias` layer left the core, layouts gained Twig 3.9 support and recipes prepared Symfony 6.

**A quiet month for the main installation, a busy one upstream.** The ledger of the main Exponential repository records no change in May 2024. The work happened in the platform repositories that the se7enxweb forks carry, and it prepared the platform generation that Exponential Platform v5 is built on.

## What changed in the platform ecosystem

- **The `class_alias` compatibility layer was removed from the core.** On 2024-05-20 the platform kernel dropped the `class_alias` statements that kept old class names alive (`5d4ffc6f77` in [core](../ecosystem/core.md), 2,746 lines touched). Why it matters: code that still used the pre-4.0 class names stops working on the 5.0 line, so extensions have to use the current namespaces. The upgrade notes for projects that move to the forks are in [Package forks, command renames and version rules](../../bc/6.0/platform-package-forks-and-command-renames.md).
- **Faster content updates.** `98b7b50e60` (2024-05-10) fixes performance problems when a content update changes fields.
- **Code style and removed deprecations in the admin interface.** The 5.0 code style was applied to the admin UI and the rich text field type (`da76e0066`, `8568d2e`, 2024-05-07) and deprecated code was removed (`38d971c96`, 2024-05-20). See [the administration interface](../../features/6.0/platform-admin-ui-fork.md).
- **Recipes prepare Symfony 6.** The recipes repository removed the webpack Encore compatibility layer (`bbc8fa4`, 2024-05-20) and enabled authenticator manager based security (`cf3ce7f`, 2024-05-23); two new bundles (app switcher, headless assets) were added to all recipes (`e2314fb`, 2024-05-10).
- **Layouts renders with Twig 3.9.** The layouts core supports the `yield` rendering strategy of Twig 3.9 and newer (`79b509c4a`, 2024-05-21), see [layouts-core](../../features/6.0/platform-layouts-core-fork.md).
- **Nexus starter.** The admin UI extension bundle replaced the "Better Admin UI" bundle (`e455a23b0`, 2024-05-03) and the canonical URL generator now checks that the location exists (`143bc6f81`, 2024-05-14); see [Nexus](../../features/6.0/platform-nexus-starter.md).

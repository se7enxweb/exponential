# exp:expmigrationrecordstop

Stop a recording of changes: the one named, a user's own (--user) or the site-wide window (--site-wide); its events stay for exp:migration:generate --from-recording; a dry run unless --apply.

Script `bin/php/expmigrationrecordstop.php`, code in `kernel/private/classes/commands/expmigrationrecordstop.php`. Run it from the installation root, as the user the web server runs as:

```bash
./console exp:expmigrationrecordstop --help
./console exp:migration:record:stop --help
php bin/php/expmigrationrecordstop.php --help
```

## Help text

```text
Stop a recording of changes
Stops the recording named by its id, or else the session recording of --user (default: [RunSettings]
RunAsUser), or with --site-wide the site-wide window. Nothing more is recorded; what was recorded stays
until exp:migration:record:discard, for exp:migration:record:show and exp:migration:generate
--from-recording. Without --apply it says what it would stop.

./console exp:migration:record:stop --apply
./console exp:migration:record:stop --site-wide --apply
./console exp:migration:record:stop 20261101-120000-a1b2c3 --apply
```

## Options

| Option | Value | Help |
|---|---|---|
| `--apply` |  | Make the changes (the default is a dry run that lists them and changes nothing) |
| `--dry-run` |  | The default, accepted for scripts that pass it: list what would change, change nothing |
| `--format` | required | text (default) or json (the machine output exp-migration/1) |
| `--site-wide` |  | The site-wide recording: every change of every user and of the console (without it: one user's own changes) |
| `--user` | required | The user, by login, whose own changes a session recording keeps (default: [RunSettings] RunAsUser of migration.ini) |

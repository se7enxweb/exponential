# exp:expmigrationcaption

Take a caption of the installation now (database, storage, settings, the commits of the code), or list the captions; a dry run unless --apply.

Script `bin/php/expmigrationcaption.php`, code in `kernel/private/classes/commands/expmigrationcaption.php`. Run it from the installation root, as the user the web server runs as:

```bash
./console exp:expmigrationcaption --help
./console exp:migration:caption --help
php bin/php/expmigrationcaption.php --help
```

## Help text

```text
Take a caption now
A caption of the kind manual, under the installation lock: git_manager's full backup (database and
var/ storage) where it is installed, else exp:upgrade's own dump, with settings/override and the
commits of the code. It is a point exp:migration:rollback --expert and exp:upgrade:rollback can go
back to. --list lists the captions, newest first, with the command that restores each.

./console exp:migration:caption --list
./console exp:migration:caption --apply
./console exp:migration:caption --label="before the news import" --apply
```

## Options

| Option | Value | Help |

| `--apply` |  | Make the changes (the default is a dry run that lists them and changes nothing) |

| `--label` | required | The label of the caption or of the recording (a caption without one: "manual caption" with the time) |
| `--backup-dir` | required | Where the captions made without git_manager are (default var/backup/upgrade) |

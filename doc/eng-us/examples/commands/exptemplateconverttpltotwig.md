## Help text

```text
Convert Exponential templates (.tpl) to Twig templates (.twig)
Every *.tpl below --from becomes the *.twig at the same place below --to (templates/ and
override/templates/ alike), so that it prints what the .tpl printed.
--override-ini writes the override rules that make the -s siteaccess use the .twig.
The same as exp:template:convert --from-engine=tpl --to-engine=twig.

./console exp:template:convert:tpl-to-twig --from=extension/<ext>/design/<design> --to=var/tmp/<design>
./console exp:template:convert:tpl-to-twig --from=extension/<ext>/design/<design> --dry-run
./console exp:template:convert:tpl-to-twig --file=design/<design>/templates/<name>.tpl
./console exp:template:convert:tpl-to-twig -s <siteaccess> --from=<design> --to=<design> --override-ini=<file>

Every written file ends with a marker comment ({# exp:template:convert tpl->twig md5:... from ... #});
a target that has no marker, or was changed after it was written, is skipped (SKIP) unless --force
is given. The result is checked before it is written: a .twig must compile with Twig 3 (when
installed). Prints WRITE or REPLACE for every file written, NOTE for every construct that could not
be converted exactly, ERROR for a template that could not be converted, then PASS or FAIL with the counts.
Exit code: 0 PASS; 1 FAIL (a template could not be read, converted, checked or written); 2 wrong options;
3 the conversion is not available (the engine's library or converter is missing).
```

## Options

| Option | Value | Help |
|---|---|---|
| `--from` | required | design directory with the .tpl templates (every .tpl below it is converted) |
| `--to` | required | design directory for the .twig templates (default: the --from directory, next to the sources) |
| `--file` | required | convert this one .tpl only (below --from, or a file of its own: then --to is the target file) |
| `--override-ini` | required | override.ini.append.php to write for the --to design (the -s siteaccess's override rules, MatchFile pointing at the converted .twig) |
| `--twig-suffix` | required | the ending of the written Twig templates: .twig (the default) or .html.twig |
| `--dry-run` |  | show what would be written; nothing is written |
| `--force` |  | also replace a .twig that was changed or written by hand (no marker, or not matching it) |

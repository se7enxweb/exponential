# exp:eztc

Compile the templates of a siteaccess into the template cache (--force recompiles all).

Script `bin/php/eztc.php`, code in `kernel/private/classes/commands/eztc.php`. Run it from the installation root, as the user the web server runs as:

```bash
./console exp:eztc --help
php bin/php/eztc.php --help
```

## Options

| Option | Value | Help |
|---|---|---|
| `--compile-directory` | required | Where to place compiled files, default is template/compiled in current cache directory |
| `--www-dir` | required | The part before the index.php in your URL, you should supply this if you are running in non-virtualhost mode |
| `--index-file` | required | The name of your index.php if you are running in non-virtualhost mode |
| `--access-path` | required | Extra access path |
| `--force` |  | Force compilation of template whether it has changed or not |
| `--full-url` |  | Makes sure generated urls have http:// in them (i.e. global), used mainly by sites that include the Exponential HTML (e.g payment gateways) |
| `--no-full-url` |  | Makes sure generated urls are relative to the site. (default) |

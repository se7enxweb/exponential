# exp:i18n

The translation fallbacks: per locale the chain of translations it falls back to, and how much of the kernel and of each extension it shows translated; --check for CI.

Script `bin/php/i18n.php`, code in `kernel/private/classes/commands/i18n.php`. Run it from the installation root, as the user the web server runs as:

## Help text

```text
The translation fallbacks (i18n.ini [TranslationSettings], doc/eng-us/languages.md)

./console exp:i18n fallbacks                         every locale: its chain, kernel and extension coverage
./console exp:i18n fallbacks --only=fallback         only the locales translated through a fallback
./console exp:i18n fallbacks --locale=esl-AR,ger-AT  each step with its rule, and every extension
./console exp:i18n fallbacks --format=json           one JSON object
./console exp:i18n check [--strict]                  cycles, chains too long, missing targets, rules
                                                     that are none: exit 1 when there is one (CI)
./console exp:i18n coverage                          the totals and the world map at the top of
                                                     doc/eng-us/languages.md and doc/ger-de/sprachen.md:
                                                     write what changed (--raster: every WebP copy)
./console exp:i18n coverage --check                  compare only: exit 1 when they are out of date

Exit code: 0 fine, 1 problems found (check, or --check), 2 usage error.
```

## Options

| Option | Value | Help |
|---|---|---|
| `--locale` | required | Only these locales, comma separated (esl-AR,ger-AT): each step of the chain and every extension |
| `--format` | required | table (default) or json |
| `--only` | required | With the list: own (a translation of its own), fallback (translated through a fallback) or untranslated |
| `--check` |  | Check the fallbacks as the check action does, after the list; with coverage: compare only, change nothing |
| `--strict` |  | With check: warnings (a configured locale without a locale file, a chain without a translation) fail too |
| `--no-extensions` |  | Leave out the coverage of the extensions (reading their files the first time takes seconds) |
| `--raster` |  | With coverage: write the WebP copy of every map again, not only of the maps that changed |
| `--date` | required | With coverage: the date of the figures when they changed (YYYY-MM-DD, default today) |

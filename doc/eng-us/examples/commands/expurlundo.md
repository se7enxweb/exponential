# exp:expurlundo

Undo a URL map import: every alias, wildcard and redirect it created or changed back as it was.

Script `bin/php/expurlundo.php`, code in `kernel/private/classes/commands/expurlundo.php`. Run it from the installation root, as the user the web server runs as:

```bash
./console exp:expurlundo --help
./console exp:url:undo --help
php bin/php/expurlundo.php --help
```

## Help text

```text
Undo a URL map import
Puts every URL alias, wildcard and redirect the import created or changed back as it was before, the
last first, in one transaction. An entry changed after the import is kept (the batch is then
partly-undone), unless --force is given. exp:url:batches lists the imports.

./console exp:url:undo 12
./console exp:url:undo 12 --force --format=json
```

## Options

| Option | Value | Help |
|---|---|---|
| `--force` |  | Undo also the entries that changed after the import (default: they are kept) |

| `--login` | required | Run as this user (recorded with the import and in the audit) |

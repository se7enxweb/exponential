# exp:expimagealias

Image aliases made on demand: status, generate, regenerate, purge, resync and test, in the process or as jobs.

Script `bin/php/expimagealias.php`, code in `kernel/private/classes/commands/expimagealias.php`. Run it from the installation root, as the user the web server runs as:

```bash
./console exp:expimagealias --help
./console exp:image:alias --help
php bin/php/expimagealias.php --help
```

## Options

| Option | Value | Help |
|---|---|---|
| `--format` | required | text (the default) or json (the machine output exp-image-alias/1) |
| `--node` | required | the images of the object at this node |
| `--subtree` | required | the images of every object below this node (the node included) |
| `--object` | required | test: the images of this object |
| `--class` | required | only objects of these classes (identifiers, separated by commas) |
| `--attribute` | required | only these image attributes (identifiers, separated by commas) |
| `--alias` | required | only these aliases (separated by commas; resync: original for the originals); test: make or check this alias |
| `--since` | required | only objects changed since: a date (2026-11-01, "2026-11-01 14:30") or a time ago (2d, 12h, 30m, "1 week") |
| `--limit` | required | at most this many images |
| `--dry-run` |  | generate, regenerate, purge: count the images only; resync: say what would be fetched; test --alias: report only |
| `--overwrite` |  | resync: replace files that differ from the source (the default fetches missing files only) |
| `--queue` |  | queue the run as a job and print its id, instead of running it here |
| `--wait` |  | a run here waits while bulk runs are paused, instead of stopping |
| `--all` |  | regenerate, purge: allow a run over every image of the installation |
| `--job` | required | status: one job of image aliases, with its progress |
| `--pause` | optional | status: pause bulk runs on every server (an optional reason: --pause="nightly import") |
| `--resume` |  | status: let paused bulk runs go on |
| `--cancel` | required | status: cancel this job (one that waits ends now, one that runs stops after its current image) |
| `--source` | optional | test: test the connection to a staging source (default the one SyncFrom names) |
| `--path` | required | test --source: a storage path to ask the source for (default its base address) |

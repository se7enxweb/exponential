# /section/view

A view of the `section` module, defined in `kernel/section/module.php` and run by `kernel/section/view.php`.

## Address

```text
/section/view/<SectionID>/(offset)/<Offset>
```

Ordered parameters, in this order after the view name: `SectionID`.

Unordered parameters, in any order as `/(name)/value`: `(offset)` sets `Offset`.

## Who may open it

The user needs this policy function:

- [`section/view`](../../policies/section.md#view) or [`section/assign`](../../policies/section.md#assign)

A policy on `section/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

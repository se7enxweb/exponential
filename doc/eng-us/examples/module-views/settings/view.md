# /settings/view

A view of the `settings` module, defined in `kernel/settings/module.php` and run by `kernel/settings/view.php`.

## Address

```text
/settings/view/<SiteAccess>/<INIFile>/(q)/<Query>/(scope)/<Scope>/(changed)/<Changed>/(compare)/<Compare>
```

Ordered parameters, in this order after the view name: `SiteAccess`, `INIFile`.

Unordered parameters, in any order as `/(name)/value`: `(q)` sets `Query`, `(scope)` sets `Scope`, `(changed)` sets `Changed`, `(compare)` sets `Compare`.

## Who may open it

The view names no policy function, so the user needs a policy for the whole module: `settings/*` (every function of the module) in one of the roles assigned to them.

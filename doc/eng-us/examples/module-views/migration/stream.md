# /migration/stream

A view of the `migration` module, defined in `kernel/migration/module.php` and run by `kernel/migration/stream.php`.

## Address

```text
/migration/stream/<RunID>/(offset)/<Offset>/(log)/<LogOffset>
```

Ordered parameters, in this order after the view name: `RunID`.

Unordered parameters, in any order as `/(name)/value`: `(offset)` sets `Offset`, `(log)` sets `LogOffset`.

# /class/view

A view of the `class` module, defined in `kernel/class/module.php` and run by `kernel/class/view.php`.

## Address

```text
/class/view/<ClassID>/(language)/<Language>/(scriptid)/<ScheduledScriptID>
```

Ordered parameters, in this order after the view name: `ClassID`.

Unordered parameters, in any order as `/(name)/value`: `(language)` sets `Language`, `(scriptid)` sets `ScheduledScriptID`.

## Who may open it

The view names no policy function, so the user needs a policy for the whole module: `class/*` (every function of the module) in one of the roles assigned to them.

## Example

A link in a template (`ezurl` adds the siteaccess and quotes the address); the parameter values are placeholders:

```tpl
<a href={'/class/view/1'|ezurl}>class/view</a>
<a href={concat( '/class/view/1/(language)/', 1 )|ezurl}>class/view</a>
```

From PHP, the redirect a view gives after it has done its work:

```php
return $Module->redirectTo( '/class/view/1' );
```

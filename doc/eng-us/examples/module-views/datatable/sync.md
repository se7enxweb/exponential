# /datatable/sync

A view of the `datatable` module, defined in `kernel/datatable/module.php` and run by `kernel/datatable/sync.php`.

## Address

```text
/datatable/sync/<SyncID>/(class)/<ClassName>/(content_class)/<ContentClass>
```

Ordered parameters, in this order after the view name: `SyncID`.

Unordered parameters, in any order as `/(name)/value`: `(class)` sets `ClassName`, `(content_class)` sets `ContentClass`.

## Who may open it

The user needs this policy function:

- [`datatable/sync`](../../policies/datatable.md#sync)

A policy on `datatable/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

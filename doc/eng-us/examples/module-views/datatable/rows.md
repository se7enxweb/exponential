# /datatable/rows

A view of the `datatable` module, defined in `kernel/datatable/module.php` and run by `kernel/datatable/rows.php`.

## Address

```text
/datatable/rows/<ClassName>/(offset)/<Offset>
```

Ordered parameters, in this order after the view name: `ClassName`.

Unordered parameters, in any order as `/(name)/value`: `(offset)` sets `Offset`.

## Who may open it

The user needs this policy function:

- [`datatable/read`](../../policies/datatable.md#read)

A policy on `datatable/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

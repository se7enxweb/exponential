# /datatable/schema

A view of the `datatable` module, defined in `kernel/datatable/module.php` and run by `kernel/datatable/schema.php`.

## Address

```text
/datatable/schema/(class)/<ClassName>/(extension)/<Extension>/(connection)/<Connection>
```

Unordered parameters, in any order as `/(name)/value`: `(class)` sets `ClassName`, `(extension)` sets `Extension`, `(connection)` sets `Connection`.

## Who may open it

The user needs this policy function:

- [`datatable/manage`](../../policies/datatable.md#manage)

A policy on `datatable/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

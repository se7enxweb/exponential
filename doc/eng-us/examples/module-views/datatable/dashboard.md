A view of the `datatable` module, defined in `kernel/datatable/module.php` and run by `kernel/datatable/dashboard.php`.

## Address


Unordered parameters, in any order as `/(name)/value`: `(origin)` sets `Origin`, `(q)` sets `Query`.

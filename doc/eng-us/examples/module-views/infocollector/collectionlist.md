# /infocollector/collectionlist

A view of the `infocollector` module, defined in `kernel/infocollector/module.php` and run by `kernel/infocollector/collectionlist.php`.

## Address

```text

```

Ordered parameters, in this order after the view name: `ObjectID`.

Unordered parameters, in any order as `/(name)/value`: `(offset)` sets `Offset`.

# /content/urlalias

A view of the `content` module, defined in `kernel/content/module.php` and run by `kernel/content/urlalias.php`.

## Address

```text
/content/urlalias/<NodeID>/(offset)/<Offset>
```

Ordered parameters, in this order after the view name: `NodeID`.

Unordered parameters, in any order as `/(name)/value`: `(offset)` sets `Offset`.

## Who may open it

The user needs this policy function:

- [`content/edit`](../../policies/content.md#edit)

A policy on `content/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

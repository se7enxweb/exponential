# /content/urlredirects

A view of the `content` module, defined in `kernel/content/module.php` and run by `kernel/content/urlredirects.php`.

## Address

```text
/content/urlredirects/(offset)/<Offset>/(removed)/<Removed>
```

Unordered parameters, in any order as `/(name)/value`: `(offset)` sets `Offset`, `(removed)` sets `Removed`.

## Who may open it

The user needs this policy function:

- [`content/urltranslator`](../../policies/content.md#urltranslator)

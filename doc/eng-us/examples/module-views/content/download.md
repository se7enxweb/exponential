# /content/download

A view of the `content` module, defined in `kernel/content/module.php` and run by `kernel/content/download.php`.

## Address

```text
/content/download/<ContentObjectID>/<ContentObjectAttributeID>/(version)/<Version>
```

Ordered parameters, in this order after the view name: `ContentObjectID`, `ContentObjectAttributeID`.

Unordered parameters, in any order as `/(name)/value`: `(version)` sets `Version`.

## Who may open it

The user needs this policy function:

- [`content/read`](../../policies/content.md#read)

A policy on `content/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

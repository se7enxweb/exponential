# content.ini [RelationGroupSettings]

The block `[RelationGroupSettings]` of `settings/content.ini`, with 4 setting(s).

> ClassSpecificAssignment\[\]=image;33,37;37  
> ClassSpecificAssignment\[\]=match;node1,node2;main\_node  

Never edit `settings/content.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/content.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/content.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/content.ini.append.php` in an extension (read when the extension is active).

## Groups

> A list of defined relation groups, each entry  
> will have a class definition setting suffixed with ClassList  
> e.g. a group called images would have the setting ImagesClassList  

Default: a list of 2: `images`, `files`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[RelationGroupSettings]
# an empty "Groups[]" first replaces the shipped list; without it the items are added
Groups[]
Groups[]=images
Groups[]=files
*/ ?>
```

## DefaultGroup

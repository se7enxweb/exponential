# content.ini [TestingSettings]

The block `[TestingSettings]` of `settings/content.ini`, with 3 setting(s).

Never edit `settings/content.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/content.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/content.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/content.ini.append.php` in an extension (read when the extension is active).

## MultivariateTesting

> Enable or disable multivariate testing feature  

Default: `disabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[TestingSettings]
MultivariateTesting=disabled
*/ ?>
```

## MultivariateTestingHandlerClass

> A handler class which implements <ezpMultivariateTestHandlerInterface> interface

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[TestingSettings]
MultivariateTestingHandlerClass=ezpMultivariateTestHandler
*/ ?>
```

## EnabledForSiteAccessList

> List of site accesses multivariate testing is enabled for.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[TestingSettings]
# an empty "EnabledForSiteAccessList[]" first replaces the shipped list; without it the items are added
EnabledForSiteAccessList[]
*/ ?>
```

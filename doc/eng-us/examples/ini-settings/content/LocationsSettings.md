# content.ini [LocationsSettings]

The block `[LocationsSettings]` of `settings/content.ini`, with 1 setting(s).

Never edit `settings/content.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/content.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/content.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/content.ini.append.php` in an extension (read when the extension is active).

## LocationsPerPage

> How many locations the locations tab shows at a time.  
>
> An object can be placed in any number of locations, and a widely reused piece  
> of content can reach thousands. Drawing them all meant fetching them all, and  
> a path lookup for every row, which took the page down before it rendered  
> anything. The tab pages them; this is the page size.  

Default: `25`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[LocationsSettings]
LocationsPerPage=25
*/ ?>
```

# content.ini [FetchFunctionSettings]

The block `[FetchFunctionSettings]` of `settings/content.ini`, with 1 setting(s).

Never edit `settings/content.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/content.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/content.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/content.ini.append.php` in an extension (read when the extension is active).

## InstClassListFilter

> Setting used by 'can\_instantiate\_class\_list' fetch function to hide  
> certain content classes. Supported are only content class identifiers  
> Filtering is only available when 'group\_by\_class\_group' param is used  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[FetchFunctionSettings]
# an empty "InstClassListFilter[]" first replaces the shipped list; without it the items are added
InstClassListFilter[]
*/ ?>
```

# content.ini [PreviewLinkSettings]

The block `[PreviewLinkSettings]` of `settings/content.ini`, with 4 setting(s).

Never edit `settings/content.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/content.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/content.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/content.ini.append.php` in an extension (read when the extension is active).

## Enabled

> Share links to the preview of a draft (content/sharedpreview/<token>, expContentPreviewLink): a  
> reviewer without an account sees that one version through a signed, expiring and revocable link.  
> The signing key is the secret content.previewlink.key of the secret store (made with the first  
> link; removing it on Setup > Secrets ends every link). Guide: doc/eng-us/features/6.0/preview-links.md  
> true or false  

Default: `true`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[PreviewLinkSettings]
Enabled=true
*/ ?>
```

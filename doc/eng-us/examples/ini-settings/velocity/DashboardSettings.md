# velocity.ini [DashboardSettings]

The block `[DashboardSettings]` of `settings/velocity.ini`, with 2 setting(s).

Never edit `settings/velocity.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/velocity.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/velocity.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/velocity.ini.append.php` in an extension (read when the extension is active).

## Token

> Who may open the server's own views: /Q/dashboard, /Q/stats, /Q/metrics,  
> the full /Q/health and /Q/phpinfo. By default only this machine.  
>
> Token      a secret; when set, it is required from anywhere (?token=...,  
>            "Authorization: Bearer ...") and opens them remotely. Generate  
>            one with: php -r 'echo bin2hex(random\_bytes(24));'  
> Remote     enabled lets them be opened remotely WITHOUT a token -- only  
>            for a port that a firewall already restricts to trusted  
>            addresses. /Q/phpinfo stays local-only without a token, as it  
>            shows the server process's environment.  

Default: empty.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/velocity.ini.append.php
[DashboardSettings]
Token=
*/ ?>
```

## Remote

Default: `disabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/velocity.ini.append.php

Remote=disabled
*/ ?>
```

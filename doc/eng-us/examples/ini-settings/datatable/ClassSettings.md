# datatable.ini [ClassSettings]

The block `[ClassSettings]` of `settings/datatable.ini`, with 1 setting(s).

> Declared connections: one block per connection, \[Connection\_<identifier>\], read-only in the administration.  
>
> \[Connection\_archive\]  
> Name=Archive database  
> Engine=mysql                 sqlite, mysql, postgresql, oracle, sqlserver or mongodb  
> Server=db2.example.com  
> Port=3306  
> Database=archive             for sqlite the file, relative to the installation (in SQLiteDirectories)  
> User=archive  
> Secret=env:ARCHIVE\_DB\_PASSWORD  
> Charset=utf8mb4  
> ReadOnly=false  

Never edit `settings/datatable.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/datatable.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/datatable.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/datatable.ini.append.php` in an extension (read when the extension is active).

## Connection

> The connection a persistent class uses, when its definition() does not name one ('connection' => '<identifier>'):  
> Connection\[<class name>\]=<identifier>  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/datatable.ini.append.php
[ClassSettings]
# an empty "Connection[]" first replaces the shipped list; without it the items are added
Connection[]
*/ ?>
```

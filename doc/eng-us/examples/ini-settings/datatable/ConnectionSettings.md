# datatable.ini [ConnectionSettings]

The block `[ConnectionSettings]` of `settings/datatable.ini`, with 4 setting(s).

Never edit `settings/datatable.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/datatable.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/datatable.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/datatable.ini.append.php` in an extension (read when the extension is active).

## Engines

> The engines that may be used for a connection (sqlite, mysql, postgresql, oracle, sqlserver, mongodb)  

Default: a list of 6: `sqlite`, `mysql`, `postgresql`, `oracle`, `sqlserver`, `mongodb`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/datatable.ini.append.php
[ConnectionSettings]
# an empty "Engines[]" first replaces the shipped list; without it the items are added
Engines[]
Engines[]=sqlite
Engines[]=mysql
Engines[]=postgresql
Engines[]=oracle
Engines[]=sqlserver
Engines[]=mongodb
*/ ?>
```

## SQLiteDirectories

> The directories a SQLite connection's file may be in, relative to the installation; the file is created there  
> when it does not exist yet. A path outside them is refused.  

Default: a list of 1: `var/datatable`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/datatable.ini.append.php
[ConnectionSettings]
# an empty "SQLiteDirectories[]" first replaces the shipped list; without it the items are added
SQLiteDirectories[]
SQLiteDirectories[]=var/datatable
*/ ?>
```

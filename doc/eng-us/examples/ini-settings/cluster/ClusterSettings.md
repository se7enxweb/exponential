# cluster.ini [ClusterSettings]

The block `[ClusterSettings]` of `settings/cluster.ini`, with 8 setting(s).

Never edit `settings/cluster.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/cluster.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/cluster.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/cluster.ini.append.php` in an extension (read when the extension is active).

## HostList

> The hosts, in the order the commands visit them. Each one has a block  
> \[Host\_<name>\] below. A name is letters, digits, dot, dash and underscore.  
>
> HostList\[\]  
> HostList\[\]=web  
> HostList\[\]=cluster  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cluster.ini.append.php
[ClusterSettings]
# an empty "HostList[]" first replaces the shipped list; without it the items are added
HostList[]
*/ ?>
```

## AllowRootUser

> Add --allow-root-user to every console command, so that a host where the ssh  
> login (or User=) is root runs it. A non-root user ignores the option.  
> A host block can set its own AllowRootUser=enabled|disabled.  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cluster.ini.append.php
[ClusterSettings]
AllowRootUser=enabled
*/ ?>
```

# shopaccount.ini [HandlerSettings]

The block `[HandlerSettings]` of `settings/shopaccount.ini`, with 2 setting(s).

Never edit `settings/shopaccount.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/shopaccount.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/shopaccount.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/shopaccount.ini.append.php` in an extension (read when the extension is active).

## Repositories

> A list of directories to search for shopaccount handlers  

Default: a list of 1: `kernel/classes`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/shopaccount.ini.append.php
[HandlerSettings]
# an empty "Repositories[]" first replaces the shipped list; without it the items are added
Repositories[]
Repositories[]=kernel/classes
*/ ?>
```

## ExtensionRepositories

> A list of extensions which have shop account handlers  
> It's common to create a settings/shopaccount.ini.append file  
> in your extension and add the extension name to automatically  
> get handlers from the extension when it's turned on.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/shopaccount.ini.append.php
[HandlerSettings]
# an empty "ExtensionRepositories[]" first replaces the shipped list; without it the items are added
ExtensionRepositories[]
*/ ?>
```

# template.ini [AttributeOperator]

The block `[AttributeOperator]` of `settings/template.ini`, with 2 setting(s).

> To create custom tag list send the name of this list as the first parameter to  
> simpletags, e.g simpletags( 'mytags' ), then create a list named TagList\_<yourname>  
> where <yourname> is the name of the tag list  
> Example:  
> TagList\_mytags\[\]  
> Configuration for the 'attribute' template operator  

Never edit `settings/template.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/template.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/template.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/template.ini.append.php` in an extension (read when the extension is active).

## DefaultFormatter

Default: `html`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/template.ini.append.php
[AttributeOperator]
DefaultFormatter=html
*/ ?>
```

## OutputFormatter

Default: a hash of 2: `html=ezpAttributeOperatorHTMLFormatter`, `text=ezpAttributeOperatorTextFormatter`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/template.ini.append.php
[AttributeOperator]
# an empty "OutputFormatter[]" first replaces the shipped list; without it the items are added
OutputFormatter[]
OutputFormatter[html]=ezpAttributeOperatorHTMLFormatter
OutputFormatter[text]=ezpAttributeOperatorTextFormatter
*/ ?>
```

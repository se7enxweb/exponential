# template.ini [AutoLinkOperator]

The block `[AutoLinkOperator]` of `settings/template.ini`, with 2 setting(s).

Never edit `settings/template.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/template.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/template.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/template.ini.append.php` in an extension (read when the extension is active).

## MaxCharacters

> The maximum number of characters to show in autolink  
> links. Specify the maxium with a number or turn it  
> off by having an empty string as the value.  
> If the link string is longer than the max value it will be shortened  

Default: `72`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/template.ini.append.php
[AutoLinkOperator]
MaxCharacters=72
*/ ?>
```

## Methods

> Maximum 72 characters  
> MaxCharacters=72  
> No shortening of characters  
> MaxCharacters=  
> A list of URL methods or protocols that should be matched  

Default: a list of 6: `http`, `https`, `ftp`, `ftps`, `webdav`, `webdavs`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/template.ini.append.php
[AutoLinkOperator]
# an empty "Methods[]" first replaces the shipped list; without it the items are added
Methods[]
Methods[]=http
Methods[]=https
Methods[]=ftp
Methods[]=ftps
Methods[]=webdav
Methods[]=webdavs
*/ ?>
```

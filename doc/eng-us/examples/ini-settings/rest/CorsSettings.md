# rest.ini [CorsSettings]

The block `[CorsSettings]` of `settings/rest.ini`, with 7 setting(s).

> Cross-origin resource sharing (CORS) for everything served by index\_rest.php (/api/...: the content API, the  
> OAuth token end point and the routes of every REST provider). doc/eng-us/bc/6.0/rest-cors.md  
> Off by default: no CORS header is sent and an OPTIONS request is routed as before.  

Never edit `settings/rest.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/rest.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/rest.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/rest.ini.append.php` in an extension (read when the extension is active).

## Cors

> enabled or disabled (the default)  

Default: `disabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/rest.ini.append.php
[CorsSettings]
Cors=disabled
*/ ?>
```

## AllowedOrigins

> The origins that may call the API from a browser, exactly as the browser sends them: scheme, host and port  
> (when not the default), no path and no trailing slash. A response to any other origin has no Access-Control-\*  
> header. "null" is never accepted. "\*" (any origin) is accepted only while AllowCredentials is disabled.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/rest.ini.append.php
[CorsSettings]
# an empty "AllowedOrigins[]" first replaces the shipped list; without it the items are added
AllowedOrigins[]
*/ ?>
```

## AllowCredentials

> enabled or disabled (the default). Enabled: Access-Control-Allow-Credentials: true, so a browser sends and keeps  
> cookies on the cross-origin request (the session of a signed in user). Leave it disabled for clients that send an  
> OAuth token or an API key in the Authorization header, which is the usual case.  

Default: `disabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/rest.ini.append.php
[CorsSettings]
AllowCredentials=disabled
*/ ?>
```

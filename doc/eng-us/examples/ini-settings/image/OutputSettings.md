# image.ini [OutputSettings]

The block `[OutputSettings]` of `settings/image.ini`, with 1 setting(s).

Never edit `settings/image.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/image.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/image.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/image.ini.append.php` in an extension (read when the extension is active).

## AllowedOutputFormat

> A list of MIME types that are allowed as output type  
> This determines which formats you want your web page to display  

Default: a list of 4: `image/jpeg`, `image/png`, `image/webp`, `image/gif`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[OutputSettings]
# an empty "AllowedOutputFormat[]" first replaces the shipped list; without it the items are added
AllowedOutputFormat[]
AllowedOutputFormat[]=image/jpeg
AllowedOutputFormat[]=image/png
AllowedOutputFormat[]=image/webp
AllowedOutputFormat[]=image/gif
*/ ?>
```

# image.ini [AliasSource_pro]

The block `[AliasSource_pro]` of `settings/image.ini`, with 2 setting(s).

> One block per environment that can be a source (SyncFrom=pro reads \[AliasSource\_pro\]); add  
> \[AliasSource\_stage\] and so on in the same way.  

Never edit `settings/image.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/image.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/image.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/image.ini.append.php` in an extension (read when the extension is active).

## BaseURL

> The base URL of that installation, for example https://www.example.org (http or https, no user name or  
> password in it, no query).  

Default: empty.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[AliasSource_pro]
BaseURL=
*/ ?>
```

## Credential

> The name of a secret (Setup > Secrets, or env:<VARIABLE>) holding "user:password" (basic  
> authentication) or "Bearer <token>"; never the value itself, which is never written to a setting, the  
> log or a message. Empty: no authentication.  

Default: empty.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[AliasSource_pro]
Credential=
*/ ?>
```

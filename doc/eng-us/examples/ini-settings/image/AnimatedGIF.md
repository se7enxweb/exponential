# image.ini [AnimatedGIF]

The block `[AnimatedGIF]` of `settings/image.ini`, with 5 setting(s).

> Fallback if jpeg is disabled as output.  
> ConversionRules\[\]=image/jpeg;image/png  
> Override for animated GIFs, this is needed to properly  
> handle image/gif files with multiple image frames.  
> It will turn off any geometry filters to leave the images untouched.  

Never edit `settings/image.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/image.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/image.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/image.ini.append.php` in an extension (read when the extension is active).

## MIMEType

> The MIME type which this override works on  

Default: `image/gif`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[AnimatedGIF]
MIMEType=image/gif
*/ ?>
```

> A list of filters which are allowed to be run on this image,

# exphelp.ini [IssueTrackers]

The block `[IssueTrackers]` of `settings/exphelp.ini`, with 5 setting(s).

Never edit `settings/exphelp.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/exphelp.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/exphelp.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/exphelp.ini.append.php` in an extension (read when the extension is active).

## TrackerList

> Where errors are reported (exphelp/report). Each tracker has \[Tracker\_<key>\] Name, Description, URL (the GitHub  
> issue list, https://github.com/<owner>/<repository>/issues; anything else is ignored) and NewIssueURL.  

Default: a list of 3: `software`, `velocity`, `community`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/exphelp.ini.append.php
[IssueTrackers]
# an empty "TrackerList[]" first replaces the shipped list; without it the items are added
TrackerList[]
TrackerList[]=software
TrackerList[]=velocity
TrackerList[]=community
*/ ?>
```

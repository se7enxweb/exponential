# exphelp.ini [HelpSettings]

The block `[HelpSettings]` of `settings/exphelp.ini`, with 3 setting(s).

Never edit `settings/exphelp.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/exphelp.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/exphelp.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/exphelp.ini.append.php` in an extension (read when the extension is active).

## Enabled

> enabled|true: the module answers; false: every exphelp view is a 404 and the Help buttons are not shown  

Default: `true`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/exphelp.ini.append.php
[HelpSettings]
Enabled=true
*/ ?>
```

## CacheDir

> The directory below the cache directory (var/<site>/cache/<CacheDir>) for the index and the search index  

Default: `exphelp`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/exphelp.ini.append.php
[HelpSettings]
CacheDir=exphelp
*/ ?>
```

## EditBaseURL

> The "Edit on GitHub" link of a page: this URL followed by the page's repository path (doc/...); empty: no link  

Default: `https://github.com/se7enxweb/exponential/blob/main/`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/exphelp.ini.append.php
[HelpSettings]
EditBaseURL=https://github.com/se7enxweb/exponential/blob/main/
*/ ?>
```

# syscard.ini [Updates]

The block `[Updates]` of `settings/syscard.ini`, with 2 setting(s).

Never edit `settings/syscard.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/syscard.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/syscard.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/syscard.ini.append.php` in an extension (read when the extension is active).

## AskUpdateInventory

> enabled: count the packages that do not agree between composer.json, composer.lock and vendor/ (ezupdate's  
> inventory, local files only, when the ezupdate extension is active)  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/syscard.ini.append.php
[Updates]
AskUpdateInventory=enabled
*/ ?>
```

## CacheTime

> Seconds the count is kept in the cache directory (var/<site>/cache/syscard/); 0 keeps nothing  

Default: `3600`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/syscard.ini.append.php
[Updates]
CacheTime=3600
*/ ?>
```

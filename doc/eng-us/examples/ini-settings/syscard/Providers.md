# syscard.ini [Providers]

The block `[Providers]` of `settings/syscard.ini`, with 4 setting(s).

Never edit `settings/syscard.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/syscard.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/syscard.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/syscard.ini.append.php` in an extension (read when the extension is active).

## ProviderClasses

> The providers, in the order their facts are shown. A provider says itself which cards it belongs to: the ones  
> of exp:expfetch are on all three cards, the inventory ones only on exp:info, the project ones only on exp:about.  

Default: a list of 16: `expSysCardExponentialProvider`, `expSysCardHostProvider`, `expSysCardPhpProvider`, `expSysCardVelocityProvider`, `expSysCardWebServerProvider`, `expSysCardDatabaseProvider`, `expSysCardSiteProvider`, `expSysCardCacheProvider`, `expSysCardHelpProvider`, `expSysCardCronProvider`, `expSysCardComposerProvider`, `expSysCardExtensionsProvider` ....

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/syscard.ini.append.php
[Providers]
# an empty "ProviderClasses[]" first replaces the shipped list; without it the items are added
ProviderClasses[]
ProviderClasses[]=expSysCardExponentialProvider
ProviderClasses[]=expSysCardHostProvider
ProviderClasses[]=expSysCardPhpProvider
ProviderClasses[]=expSysCardVelocityProvider
ProviderClasses[]=expSysCardWebServerProvider
ProviderClasses[]=expSysCardDatabaseProvider
ProviderClasses[]=expSysCardSiteProvider
ProviderClasses[]=expSysCardCacheProvider
ProviderClasses[]=expSysCardHelpProvider
ProviderClasses[]=expSysCardCronProvider

ProviderClasses[]=expSysCardExtensionsProvider
```

# syscard.ini [Php]

The block `[Php]` of `settings/syscard.ini`, with 2 setting(s).

Never edit `settings/syscard.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/syscard.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/syscard.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/syscard.ini.append.php` in an extension (read when the extension is active).

## SecuritySupportEnds

> The end of security support of each PHP branch (https://www.php.net/supported-versions.php). A branch past its  
> date is an error on the card, one within WarnDays a warning.  

Default: a hash of 7: `7.4=2022-11-28`, `8.0=2023-11-26`, `8.1=2025-12-31`, `8.2=2026-12-31`, `8.3=2027-12-31`, `8.4=2028-12-31`, `8.5=2029-12-31`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/syscard.ini.append.php
[Php]
# an empty "SecuritySupportEnds[]" first replaces the shipped list; without it the items are added
SecuritySupportEnds[]
SecuritySupportEnds[7.4]=2022-11-28
SecuritySupportEnds[8.0]=2023-11-26
SecuritySupportEnds[8.1]=2025-12-31
SecuritySupportEnds[8.2]=2026-12-31
SecuritySupportEnds[8.3]=2027-12-31
SecuritySupportEnds[8.4]=2028-12-31
SecuritySupportEnds[8.5]=2029-12-31
*/ ?>
```

# audit.ini [AuditPrivacySettings]

The block `[AuditPrivacySettings]` of `settings/audit.ini`, with 6 setting(s).

Never edit `settings/audit.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/audit.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/audit.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/audit.ini.append.php` in an extension (read when the extension is active).

## Field

> Per field: full | truncate | hash | off (see "The record format" for what truncate  
> means per field). Q3: a safe default; the session can only be hashed or off.  
> E-mail addresses in access.user.\* events and attempted logins of unknown users.  

Default: a hash of 10: `actor.login=full`, `actor.ip=truncate`, `actor.ua=truncate`, `actor.session=hash`, `actor.cli.os_user=full`, `request.url=truncate`, `request.host=full`, `object.name=full`, `email=hash`, `attempted_login=hash`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditPrivacySettings]
# an empty "Field[]" first replaces the shipped list; without it the items are added
Field[]
Field[actor.login]=full
Field[actor.ip]=truncate
Field[actor.ua]=truncate
Field[actor.session]=hash
Field[actor.cli.os_user]=full
Field[request.url]=truncate
Field[request.host]=full
Field[object.name]=full
Field[email]=hash
Field[attempted_login]=hash
*/ ?>
```

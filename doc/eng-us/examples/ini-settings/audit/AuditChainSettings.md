# audit.ini [AuditChainSettings]

The block `[AuditChainSettings]` of `settings/audit.ini`, with 2 setting(s).

Never edit `settings/audit.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/audit.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/audit.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/audit.ini.append.php` in an extension (read when the extension is active).

## Algorithm

> The hash chain (Q4). Always on: there is no "disabled".  
> sha256 (Proposed; the prefix in each hash names the algorithm, so it can change later).  

Default: `sha256`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditChainSettings]
Algorithm=sha256
*/ ?>
```

## Checkpoints

> A signed checkpoint of every channel's head, written daily by the cronjob part and  
> sent to the sinks.  enabled | disabled  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditChainSettings]
Checkpoints=enabled
*/ ?>
```

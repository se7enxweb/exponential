# audit.ini [AuditKeySettings]

The block `[AuditKeySettings]` of `settings/audit.ini`, with 1 setting(s).

Never edit `settings/audit.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/audit.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/audit.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/audit.ini.append.php` in an extension (read when the extension is active).

## GenerateKeys

> Generated on first use into settings/override/audit.ini.append.php (Z7); never here,  
> never committed. Shown in the console as fingerprints only.  
> InstallationID=<uuid>  
> ActiveSigningKey=<key id>  
> SigningKey\[<key id>\]=<base64>  
> PseudonymKey=<base64>  
> Generate the keys on the first event.  enabled | disabled (disabled: an installation  
> that provides its own keys, e.g. from a secrets store, through settings/override).  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditKeySettings]
GenerateKeys=enabled
*/ ?>
```

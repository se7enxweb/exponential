# audit.ini [AuditBufferSettings]

The block `[AuditBufferSettings]` of `settings/audit.ini`, with 5 setting(s).

Never edit `settings/audit.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/audit.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/audit.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/audit.ini.append.php` in an extension (read when the extension is active).

## Buffering

> F3: events are collected and written in one append per channel at the end of the  
> request (also on a fatal error, through the shutdown handler).  enabled | disabled  
> (disabled writes every event at once: for debugging only).  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditBufferSettings]
Buffering=enabled
*/ ?>
```

## ImmediateEvents

> Events written at once, not buffered (F3: security events): patterns.  

Default: a list of 3: `access.*`, `system.audit.*`, `system.setting.write`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditBufferSettings]
# an empty "ImmediateEvents[]" first replaces the shipped list; without it the items are added
ImmediateEvents[]
ImmediateEvents[]=access.*
ImmediateEvents[]=system.audit.*
ImmediateEvents[]=system.setting.write
*/ ?>
```

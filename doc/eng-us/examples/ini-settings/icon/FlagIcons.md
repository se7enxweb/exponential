# icon.ini [FlagIcons]

The block `[FlagIcons]` of `settings/icon.ini`, with 3 setting(s).

> IconExtensions\[\]=myiconsextension  

Never edit `settings/icon.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/icon.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/icon.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/icon.ini.append.php` in an extension (read when the extension is active).

## Repository

> Where to look for flag icons, relative to Exponential  

Default: `share/icons`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/icon.ini.append.php
[FlagIcons]
Repository=share/icons
*/ ?>
```

## Theme

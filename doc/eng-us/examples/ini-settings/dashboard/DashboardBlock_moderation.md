# dashboard.ini [DashboardBlock_moderation]

The block `[DashboardBlock_moderation]` of `settings/dashboard.ini`, with 3 setting(s).

> Recent content: how many objects are held for review and how many were created today, with links to  
> Dashboard > Recent content (moderation/recent) filtered on them.  

Never edit `settings/dashboard.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/dashboard.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/dashboard.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/dashboard.ini.append.php` in an extension (read when the extension is active).

## Priority

Default: `28`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/dashboard.ini.append.php
[DashboardBlock_moderation]
Priority=28
*/ ?>
```

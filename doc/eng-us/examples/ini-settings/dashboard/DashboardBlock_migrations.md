# dashboard.ini [DashboardBlock_migrations]

The block `[DashboardBlock_migrations]` of `settings/dashboard.ini`, with 3 setting(s).

> The migrations: how many are pending or failed, the orphans, the run going on and the latest run, with links to  
> Setup > Migrations (migration/status) and the run's page (migration/log/<run id>).  

Never edit `settings/dashboard.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/dashboard.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/dashboard.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/dashboard.ini.append.php` in an extension (read when the extension is active).

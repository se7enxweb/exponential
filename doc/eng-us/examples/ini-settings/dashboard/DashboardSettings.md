# dashboard.ini [DashboardSettings]

The block `[DashboardSettings]` of `settings/dashboard.ini`, with 1 setting(s).

Never edit `settings/dashboard.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/dashboard.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/dashboard.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/dashboard.ini.append.php` in an extension (read when the extension is active).

## DashboardBlocks

> DashboardBlocks\[\]=example  

Default: a list of 5: `pending_list`, `drafts`, `latest_content`, `all_latest_content`, `audit`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/dashboard.ini.append.php
[DashboardSettings]
# an empty "DashboardBlocks[]" first replaces the shipped list; without it the items are added
DashboardBlocks[]
DashboardBlocks[]=pending_list
DashboardBlocks[]=drafts
DashboardBlocks[]=latest_content
DashboardBlocks[]=all_latest_content
DashboardBlocks[]=audit
*/ ?>
```

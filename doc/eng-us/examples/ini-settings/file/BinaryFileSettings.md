# file.ini [BinaryFileSettings]

The block `[BinaryFileSettings]` of `settings/file.ini`, with 1 setting(s).

Never edit `settings/file.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/file.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/file.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/file.ini.append.php` in an extension (read when the extension is active).

## Handler

Default: `eZFilePassthroughHandler`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/file.ini.append.php
[BinaryFileSettings]
Handler=eZFilePassthroughHandler
*/ ?>
```

# subitems.ini [Preset_editorial]

The block `[Preset_editorial]` of `settings/subitems.ini`, with 2 setting(s).

Never edit `settings/subitems.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/subitems.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/subitems.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/subitems.ini.append.php` in an extension (read when the extension is active).

## Name

Default: `Editorial`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/subitems.ini.append.php
[Preset_editorial]
Name=Editorial
*/ ?>
```

## Columns

Default: a list of 6: `name`, `type`, `modifier`, `modified`, `published`, `objectstate`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/subitems.ini.append.php
[Preset_editorial]
# an empty "Columns[]" first replaces the shipped list; without it the items are added
Columns[]
Columns[]=name
Columns[]=type
Columns[]=modifier
Columns[]=modified
Columns[]=published
Columns[]=objectstate
*/ ?>
```

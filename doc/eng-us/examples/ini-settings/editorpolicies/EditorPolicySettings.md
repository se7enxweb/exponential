# editorpolicies.ini [EditorPolicySettings]

The block `[EditorPolicySettings]` of `settings/editorpolicies.ini`, with 2 setting(s).

Never edit `settings/editorpolicies.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/editorpolicies.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/editorpolicies.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/editorpolicies.ini.append.php` in an extension (read when the extension is active).

## ClassSets

> The class sets in use: a \[ClassSet\_<name>\] group each. A set whose classes the installation does not have is  
> skipped, so the same file fits every installation.  

Default: a list of 1: `media_site`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/editorpolicies.ini.append.php
[EditorPolicySettings]
# an empty "ClassSets[]" first replaces the shipped list; without it the items are added
ClassSets[]
ClassSets[]=media_site
*/ ?>
```

## RemoveDuplicates

> enabled | disabled. Enabled: a policy the role holds twice (the same module, function and limitations) is removed  
> once, keeping the oldest. A policy that differs only in its limitations is never a duplicate.  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/editorpolicies.ini.append.php
[EditorPolicySettings]
RemoveDuplicates=enabled
*/ ?>
```

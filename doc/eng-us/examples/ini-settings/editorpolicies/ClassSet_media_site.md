# editorpolicies.ini [ClassSet_media_site]

The block `[ClassSet_media_site]` of `settings/editorpolicies.ini`, with 4 setting(s).

Never edit `settings/editorpolicies.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/editorpolicies.ini.append.php` for every siteaccess,

## Classes

> The media site's content classes (ng\_\*): what an editor creates in the content tree and edits from the website  
> toolbar. Classes\[\] are class identifiers; \* matches any text (fnmatch).


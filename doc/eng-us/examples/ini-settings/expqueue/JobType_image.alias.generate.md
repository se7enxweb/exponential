# expqueue.ini [JobType_image.alias.generate]

The block `[JobType_image.alias.generate]` of `settings/expqueue.ini`, with 7 setting(s).

> Image aliases (image.ini \[AliasSettings\], expImageAliasJob). The producer sets class and priority: a visitor's miss  
> (the alias was not made in time, the placeholder was answered) interactive 80, pre-generation after publishing  
> editorial 60, the administration interactive 60, bulk runs bulk 40.  

Never edit `settings/expqueue.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/expqueue.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/expqueue.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/expqueue.ini.append.php` in an extension (read when the extension is active).

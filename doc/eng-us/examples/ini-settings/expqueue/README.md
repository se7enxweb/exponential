# expqueue.ini

The shipped settings of `settings/expqueue.ini`: 3 blocks, 16 settings.

> The job types of the kernel for expqueue, the job queue (an extension). They are read only while expqueue is active  
> and its tables are installed; without it the kernel runs the same work at once where it may (a script, the  
> administration) and never in a page request. The queue's own settings (classes, workers, quotas) come with the  
> extension (extension/expqueue/settings/expqueue.ini.append.php); a site changes either in  
> settings/override/expqueue.ini.append.php.  
>
> \[JobType\_<type>\] Handler=<class implementing expQueueHandler>, optional Class (the priority class when the  
> producer names none), Priority, MaxAttempts, Timeout, Resource, RetryBase, MaxBackoff, Description.

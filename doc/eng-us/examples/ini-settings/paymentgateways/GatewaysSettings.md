# paymentgateways.ini [GatewaysSettings]

The block `[GatewaysSettings]` of `settings/paymentgateways.ini`, with 2 setting(s).

Never edit `settings/paymentgateways.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/paymentgateways.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/paymentgateways.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/paymentgateways.ini.append.php` in an extension (read when the extension is active).

## AvailableGateways

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/paymentgateways.ini.append.php
[GatewaysSettings]
# an empty "AvailableGateways[]" first replaces the shipped list; without it the items are added
AvailableGateways[]
*/ ?>
```

## GatewaysDirectories

# dbschema.ini [SchemaSettings]

The block `[SchemaSettings]` of `settings/dbschema.ini`, with 2 setting(s).

Never edit `settings/dbschema.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/dbschema.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/dbschema.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/dbschema.ini.append.php` in an extension (read when the extension is active).

## SchemaPaths

Default: a hash of 6: `mysql=lib/ezdbschema/classes/ezmysqlschema.php`, `mysqli=lib/ezdbschema/classes/ezmysqlschema.php`, `postgresql=lib/ezdbschema/classes/ezpgsqlschema.php`, `sqlite=lib/ezdbschema/classes/ezsqliteschema.php`, `sqlite3=lib/ezdbschema/classes/ezsqliteschema.php`, `mongo=lib/ezdbschema/classes/expmongoschema.php`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/dbschema.ini.append.php
[SchemaSettings]
# an empty "SchemaPaths[]" first replaces the shipped list; without it the items are added
SchemaPaths[]
SchemaPaths[mysql]=lib/ezdbschema/classes/ezmysqlschema.php
SchemaPaths[mysqli]=lib/ezdbschema/classes/ezmysqlschema.php
SchemaPaths[postgresql]=lib/ezdbschema/classes/ezpgsqlschema.php
SchemaPaths[sqlite]=lib/ezdbschema/classes/ezsqliteschema.php
SchemaPaths[sqlite3]=lib/ezdbschema/classes/ezsqliteschema.php
SchemaPaths[mongo]=lib/ezdbschema/classes/expmongoschema.php
*/ ?>
```

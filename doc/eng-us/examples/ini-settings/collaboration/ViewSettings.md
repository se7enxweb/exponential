# collaboration.ini [ViewSettings]

The block `[ViewSettings]` of `settings/collaboration.ini`, with 2 setting(s).

Never edit `settings/collaboration.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/collaboration.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/collaboration.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/collaboration.ini.append.php` in an extension (read when the extension is active).

## ViewList

Default: a list of 1: `summary`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/collaboration.ini.append.php
[ViewSettings]
# an empty "ViewList[]" first replaces the shipped list; without it the items are added
ViewList[]
ViewList[]=summary
*/ ?>
```

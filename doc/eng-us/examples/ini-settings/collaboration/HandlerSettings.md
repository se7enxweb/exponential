# collaboration.ini [HandlerSettings]

The block `[HandlerSettings]` of `settings/collaboration.ini`, with 3 setting(s).

Never edit `settings/collaboration.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/collaboration.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/collaboration.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/collaboration.ini.append.php` in an extension (read when the extension is active).

## Extensions

> A list of extensions which have collaboration code  
> It's common to create a settings/collaboration.ini.append file  
> in your extension and add the extension name to automatically  
> get code from the extension when it's turned on.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/collaboration.ini.append.php
[HandlerSettings]
# an empty "Extensions[]" first replaces the shipped list; without it the items are added
Extensions[]
*/ ?>
```

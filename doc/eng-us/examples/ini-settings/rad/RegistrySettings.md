# rad.ini [RegistrySettings]

The block `[RegistrySettings]` of `settings/rad.ini`, with 1 setting(s).

Never edit `settings/rad.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/rad.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/rad.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/rad.ini.append.php` in an extension (read when the extension is active).

## Registries

> The keys of the registries: \[Registry\_<key>\] for each. A key listed without its block is shown as broken.  

Default: a list of 3: `eventlisteners`, `cronjobparts`, `auditsources`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/rad.ini.append.php
[RegistrySettings]
# an empty "Registries[]" first replaces the shipped list; without it the items are added
Registries[]
Registries[]=eventlisteners
Registries[]=cronjobparts
Registries[]=auditsources
*/ ?>
```

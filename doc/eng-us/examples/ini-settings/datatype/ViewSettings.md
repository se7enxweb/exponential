# datatype.ini [ViewSettings]

The block `[ViewSettings]` of `settings/datatype.ini`, with 2 setting(s).

> Settings related to content view and datatypes  

Never edit `settings/datatype.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/datatype.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/datatype.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/datatype.ini.append.php` in an extension (read when the extension is active).

## GroupedInput

> A list of datatypes that needs to group output data  
> when displayed in view mode  
> NOTE: The datatype may override this using PHP code  

Default: a list of 6: `ezinisetting`, `ezmultioption`, `ezoption`, `ezrangeoption`, `ezpackage`, `ezuser`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/datatype.ini.append.php
[ViewSettings]
# an empty "GroupedInput[]" first replaces the shipped list; without it the items are added
GroupedInput[]
GroupedInput[]=ezinisetting
GroupedInput[]=ezmultioption
GroupedInput[]=ezoption
GroupedInput[]=ezrangeoption
GroupedInput[]=ezpackage
GroupedInput[]=ezuser
*/ ?>
```

## CustomActionMap

> List of custom datatype actions and corresponding <module>/<view> or  
> just <view> in case of content module where they should be executed  
> eg: CustomActionMap\[ActionAddToBasket\]=shop/basket  
> eg: CustomActionMap\[ActionCollectInformation\]=collectinformation  
> Note: Action definition should be defined in contentActionList function  
> of the datatype, see ez\[multi\]pricetype.php for code example.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/datatype.ini.append.php
[ViewSettings]
# an empty "CustomActionMap[]" first replaces the shipped list; without it the items are added
CustomActionMap[]
*/ ?>
```

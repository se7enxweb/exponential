# datatype.ini [CollectionSettings]

The block `[CollectionSettings]` of `settings/datatype.ini`, with 1 setting(s).

> Settings related to content information collection and datatypes  

Never edit `settings/datatype.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/datatype.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/datatype.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/datatype.ini.append.php` in an extension (read when the extension is active).

## GroupedInput

> A list of datatypes that needs to group their input fields  
> when displayed in information collection mode  
> NOTE: The datatype may override this using PHP code  

Default: a list of 16: `ezauthor`, `ezbinaryfile`, `ezdate`, `ezdatetime`, `ezimage`, `ezinisetting`, `ezmatrix`, `ezmedia`, `ezmultioption`, `ezobjectrelationlist`, `ezpackage`, `ezrangeoption` ....

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/datatype.ini.append.php
[CollectionSettings]
# an empty "GroupedInput[]" first replaces the shipped list; without it the items are added
GroupedInput[]
GroupedInput[]=ezauthor
GroupedInput[]=ezbinaryfile
GroupedInput[]=ezdate
GroupedInput[]=ezdatetime
GroupedInput[]=ezimage
GroupedInput[]=ezinisetting
GroupedInput[]=ezmatrix
GroupedInput[]=ezmedia
GroupedInput[]=ezmultioption
GroupedInput[]=ezobjectrelationlist
GroupedInput[]=ezpackage
GroupedInput[]=ezrangeoption
GroupedInput[]=ezselection
GroupedInput[]=eztime
GroupedInput[]=ezurl
GroupedInput[]=ezuser
*/ ?>
```

# graphql.ini [GraphQLEvents]

The block `[GraphQLEvents]` of `settings/graphql.ini`, with 2 setting(s).

Never edit `settings/graphql.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/graphql.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/graphql.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/graphql.ini.append.php` in an extension (read when the extension is active).

## JournalMaxBytes

> The event journal: what happens to content (publish, update, trash, delete, move, hide, reveal, and the GraphQL  
> mutations), one JSON line per event in var/<site>/graphql/events/, written at the end of the request that changed  
> it, and read by the webhooks and the subscriptions. Written only while the API is switched on and somebody listens  
> (Subscriptions=enabled, or a webhook in \[GraphQLWebhooks\] EndpointList\[\]). A file grows to JournalMaxBytes (bytes,  
> or with k, M, G), then the next one starts; the newest JournalKeep files stay. A subscription or a webhook further  
> behind than the files kept goes on from the oldest one.  

Default: `5M`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/graphql.ini.append.php
[GraphQLEvents]
JournalMaxBytes=5M
*/ ?>
```

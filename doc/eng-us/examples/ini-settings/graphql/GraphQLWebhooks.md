# graphql.ini [GraphQLWebhooks]

The block `[GraphQLWebhooks]` of `settings/graphql.ini`, with 7 setting(s).

Never edit `settings/graphql.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

## EndpointList

> The webhooks: every event of the journal an end point asks for is POSTed to it as JSON, signed with HMAC-SHA-256  
> (X-Exponential-Signature: sha256=<hex of HMAC(secret, X-Exponential-Timestamp + "." + body)>), by the cronjob part  
> graphqlwebhooks (also in the frequent group) or ./console exp:graphql:webhooks --deliver; never by the request that  
> changed the content. Add them with ./console exp:graphql:webhooks --add=<name> --url=<https://...> --apply, or in  
> Setup > GraphQL: both write settings/override/graphql.ini.append.php and keep the signing secret in the secret store.  
>
> The end points, each with its block \[GraphQLWebhook\_<name>\]:  
>
>   \[GraphQLWebhook\_shop\]  
>   URL=https://shop.example.com/hooks/exponential  
>   # the events it wants: publish, update, trash, delete, move, hide, reveal, mutation; none: every event  
>   Events\[\]=publish  
>   Events\[\]=update  
>   # only content below the root node of these siteaccesses, in their languages; none: every siteaccess  
>   SiteAccessList\[\]=eng  
>   # only these classes; none: every class  
>   ClassList\[\]=article  
>   # only content at or below these nodes; none: the whole tree  
>   SubtreeList\[\]=2  
>   # the NAME of the signing secret in the secret store (Setup > Secrets), or env:VARIABLE; the value is never written  
>   # into a settings file. Default: graphql.webhook.<name>  
>   Secret=graphql.webhook.shop  
>   # event (the default): the event and its ids; query: the answer of a persisted query (Query, its name or SHA-256)  
>   # with the variables objectId, nodeId, version, language and event, run as QueryUser (a login; default anonymous)  
>   Payload=event  
>   Query=  
>   QueryUser=  
>   # disabled keeps the end point but sends it nothing  
>   Enabled=enabled  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/graphql.ini.append.php
[GraphQLWebhooks]
# an empty "EndpointList[]" first replaces the shipped list; without it the items are added
EndpointList[]
*/ ?>
```

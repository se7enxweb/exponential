# design.ini [ExtensionSettings]

The block `[ExtensionSettings]` of `settings/design.ini`, with 1 setting(s).

Never edit `settings/design.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/design.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/design.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/design.ini.append.php` in an extension (read when the extension is active).

## DesignExtensions

> A list of extensions which have design data  
> It's common to create a settings/design.ini.append file  
> in your extension and add the extension name to automatically  
> get design from the extension when it's turned on.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/design.ini.append.php
[ExtensionSettings]
# an empty "DesignExtensions[]" first replaces the shipped list; without it the items are added
DesignExtensions[]
*/ ?>
```

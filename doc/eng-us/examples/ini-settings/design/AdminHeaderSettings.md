# design.ini [AdminHeaderSettings]

The block `[AdminHeaderSettings]` of `settings/design.ini`, with 1 setting(s).

Never edit `settings/design.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/design.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/design.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/design.ini.append.php` in an extension (read when the extension is active).

## HeaderItems

> admin4: the header items of the extensions, drawn among the header's tools after Help and before the user menu  
> (page\_topmenu.tpl). Each is a template, e.g. HeaderItems\[\]=sqliimport/header\_bell.tpl in an extension's  
> design.ini.append.php; parts/a4\_header\_item.tpl describes its markup: a round 36px button with a count, a panel  
> and, for live data, a JSON feed (data-a4-header-feed) that admin4.js loads, since the header is cached per user.  
> doc/eng-us/features/6.0/admin4-design.md, "Header items".  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/design.ini.append.php
[AdminHeaderSettings]
# an empty "HeaderItems[]" first replaces the shipped list; without it the items are added
HeaderItems[]
*/ ?>
```

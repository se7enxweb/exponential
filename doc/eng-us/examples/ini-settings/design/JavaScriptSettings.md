# design.ini [JavaScriptSettings]

The block `[JavaScriptSettings]` of `settings/design.ini`, with 3 setting(s).

Never edit `settings/design.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/design.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/design.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/design.ini.append.php` in an extension (read when the extension is active).

## JavaScriptList

> List of JavaScript files to include in pagelayout  
> DEPRECATED in favor of \[Frontend|Backend\]JavaScriptList\[\]  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/design.ini.append.php
[JavaScriptSettings]
# an empty "JavaScriptList[]" first replaces the shipped list; without it the items are added
JavaScriptList[]
*/ ?>
```

## BackendJavaScriptList

> Same as above for backend (admin) designs. The tables, uploads, dialogs, date fields, collapsing menus and  
> sticky toolbars run on Exponential UI (extension expui adds exp::\* to this list).  
> leftmenu\_widthcontrol.js is the column grip of design/admin, whose page\_leftmenu.tpl loads it itself; admin4 has  
> its own in ezadmin\_menubar.js and does not ship the file. Do not add it here.  

Default: a list of 5: `tools/ezjsselection.js`, `lib/ezjslibimagepreloader.js`, `popupmenu/ezpopupmenu.js`, `contentstructuremenu_dynamic.js`, `ezadmin_menubar.js`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/design.ini.append.php
[JavaScriptSettings]
# an empty "BackendJavaScriptList[]" first replaces the shipped list; without it the items are added
BackendJavaScriptList[]
BackendJavaScriptList[]=tools/ezjsselection.js
BackendJavaScriptList[]=lib/ezjslibimagepreloader.js
BackendJavaScriptList[]=popupmenu/ezpopupmenu.js
BackendJavaScriptList[]=contentstructuremenu_dynamic.js
BackendJavaScriptList[]=ezadmin_menubar.js
*/ ?>
```

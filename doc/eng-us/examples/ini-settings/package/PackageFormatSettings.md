# package.ini [PackageFormatSettings]

The block `[PackageFormatSettings]` of `settings/package.ini`, with 2 setting(s).

Never edit `settings/package.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/package.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/package.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/package.ini.append.php` in an extension (read when the extension is active).

## RawXMLDatatypes

> The JSON package format (doc/eng-us/bc/6.0/package-json-format.md).  
> Datatypes whose attribute value is kept as an XML string in a JSON document (\["#xml", "..."\])  

Default: a list of 1: `ezxmltext`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/package.ini.append.php
[PackageFormatSettings]
# an empty "RawXMLDatatypes[]" first replaces the shipped list; without it the items are added
RawXMLDatatypes[]
RawXMLDatatypes[]=ezxmltext
*/ ?>
```

## MaxDocumentBytes

> The largest JSON document of a package that is read, in bytes  

Default: `67108864`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/package.ini.append.php
[PackageFormatSettings]
MaxDocumentBytes=67108864
*/ ?>
```

# error.ini [ErrorSettings-shop]

The block `[ErrorSettings-shop]` of `settings/error.ini`, with 5 setting(s).

> Allow the default Exponential 500 error message to be overridden  
> Note: this will not work with siteaccess settings, will only be global (settings/override/error.ini.append.php), because of how early this is registered  
> FatalErrorHandler=CustomFatalErrorHandlerClass::FatalErrorHandlerFunction  
> Error handling for shop errors  
> See the kernel errors for details on usage  

Never edit `settings/error.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/error.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/error.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/error.ini.append.php` in an extension (read when the extension is active).

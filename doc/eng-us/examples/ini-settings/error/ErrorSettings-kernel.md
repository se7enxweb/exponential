# error.ini [ErrorSettings-kernel]

The block `[ErrorSettings-kernel]` of `settings/error.ini`, with 5 setting(s).

> Error handling for kernel errors  

Never edit `settings/error.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/error.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/error.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/error.ini.append.php` in an extension (read when the extension is active).

## ErrorHandler

> A list of error codes and which handler to use for it  
> Overrides DefaultErrorHandler  
> Example:  
> What to do when a module does not exists, use either displayerror or redirect  
> ErrorHandler\[20\]=displayerror  
> Set access denied to embed login  

Default: a hash of 1: `1=embed`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/error.ini.append.php
[ErrorSettings-kernel]
# an empty "ErrorHandler[]" first replaces the shipped list; without it the items are added
ErrorHandler[]
ErrorHandler[1]=embed
*/ ?>
```

## HTTPError

> Defines the HTTP error code to use for the specified Exponential error code.  
> The definition is HTTPError\[Exponential error code\]=HTTP error code.  
> The HTTP error code must be defined with a HTTPError-code group as seen below.  
> Example:  
> Add 404 for module not found error  
> HTTPError\[20\]=404  
> 301 = moved permanently  

Default: a hash of 8: `1=401`, `2=404`, `3=404`, `4=301`, `6=403`, `20=404`, `21=404`, `22=404`.

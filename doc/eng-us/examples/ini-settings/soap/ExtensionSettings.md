# soap.ini [ExtensionSettings]

The block `[ExtensionSettings]` of `settings/soap.ini`, with 1 setting(s).

Never edit `settings/soap.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/soap.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/soap.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/soap.ini.append.php` in an extension (read when the extension is active).

## SOAPExtensions

> Extensions for SOAP functions.  
> SOAP functions must be registered under soap/initialize.php  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/soap.ini.append.php
[ExtensionSettings]
# an empty "SOAPExtensions[]" first replaces the shipped list; without it the items are added
SOAPExtensions[]
*/ ?>
```

# notification.ini [TransportSettings]

The block `[TransportSettings]` of `settings/notification.ini`, with 2 setting(s).

> AvailableNotificationEventTypes\[\]=ezsimpledigest  

Never edit `settings/notification.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/notification.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/notification.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/notification.ini.append.php` in an extension (read when the extension is active).

## DefaultTransport

Default: `mail`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/notification.ini.append.php
[TransportSettings]
DefaultTransport=mail
*/ ?>
```

## TransportPluginPath

> An array of pathes to the transport plugins  
> TransportPluginPath\[\]=path/to/plugin1  
> TransportPluginPath\[\]=path/to/plugin2  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/notification.ini.append.php
[TransportSettings]
# an empty "TransportPluginPath[]" first replaces the shipped list; without it the items are added
TransportPluginPath[]
*/ ?>
```

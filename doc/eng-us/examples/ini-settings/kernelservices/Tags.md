# kernelservices.ini [Tags]

The block `[Tags]` of `settings/kernelservices.ini`, with 1 setting(s).

Never edit `settings/kernelservices.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/kernelservices.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/kernelservices.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/kernelservices.ini.append.php` in an extension (read when the extension is active).

## TagList

> The tags services may carry. exp:services:check warns about a tag that is  
> not listed here (an extension adds its own with TagList\[\]=<tag>).  

Default: a list of 9: `kernel.core`, `kernel.settings`, `template.operator`, `datatype`, `cronjob.part`, `syscard.provider`, `help.source`, `event.listener`, `transfer.tool`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/kernelservices.ini.append.php
[Tags]
# an empty "TagList[]" first replaces the shipped list; without it the items are added
TagList[]
TagList[]=kernel.core
TagList[]=kernel.settings
TagList[]=template.operator
TagList[]=datatype
TagList[]=cronjob.part
TagList[]=syscard.provider
TagList[]=help.source
TagList[]=event.listener
TagList[]=transfer.tool
*/ ?>
```

# datetime.ini [ClassSettings]

The block `[ClassSettings]` of `settings/datetime.ini`, with 1 setting(s).

Never edit `settings/datetime.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/datetime.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/datetime.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/datetime.ini.append.php` in an extension (read when the extension is active).

## Formats

Default: a hash of 6: `all=%a, %A, %d, %D, %F, %g, %G, %h, %H, %i, %j, %l, %m, %M, %n, %O, %s, %T, %U, %w, %W, %Y, %y, %z, %Z, %r, %c`, `short_date=%j.%n.%Y`, `long_date=%j %F %Y`, `short_date_usa=%n/%j/%Y`, `time_12=%h:%i:%s %a`, `time_24=%H:%i:%s`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/datetime.ini.append.php
[ClassSettings]
# an empty "Formats[]" first replaces the shipped list; without it the items are added
Formats[]
Formats[all]=%a, %A, %d, %D, %F, %g, %G, %h, %H, %i, %j, %l, %m, %M, %n, %O, %s, %T, %U, %w, %W, %Y, %y, %z, %Z, %r, %c
Formats[short_date]=%j.%n.%Y
Formats[long_date]=%j %F %Y
Formats[short_date_usa]=%n/%j/%Y
Formats[time_12]=%h:%i:%s %a
Formats[time_24]=%H:%i:%s
*/ ?>
```

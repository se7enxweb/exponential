# transform.ini [uppercase]

The block `[uppercase]` of `settings/transform.ini`, with 3 setting(s).

> Rules which makes character into uppercase  
> These rules works in similar way to strtoupper in PHP but will  
> work regardless of locale used.  

Never edit `settings/transform.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/transform.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/transform.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/transform.ini.append.php` in an extension (read when the extension is active).

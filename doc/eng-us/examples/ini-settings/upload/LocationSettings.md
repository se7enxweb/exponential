# upload.ini [LocationSettings]

The block `[LocationSettings]` of `settings/upload.ini`, with 4 setting(s).

Never edit `settings/upload.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/upload.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/upload.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/upload.ini.append.php` in an extension (read when the extension is active).

## ClassList

> A list of class identifiers that should be included in the location dropdown  

Default: a list of 1: `folder`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/upload.ini.append.php
[LocationSettings]
# an empty "ClassList[]" first replaces the shipped list; without it the items are added
ClassList[]
ClassList[]=folder
*/ ?>
```

## RootNode

> Which root node to fetch locations from  
> Either use a node ID or a node path (e.g. media )  
> - content - The content structure  
> - users   - The user tree  
> - media   - Media tree for images, files and media  

Default: `media`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/upload.ini.append.php
[LocationSettings]
RootNode=media
*/ ?>
```

## MaxDepth

> The maximum number of levels to look for objects  
> A depth of 1 means direct descendants  

Default: `3`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/upload.ini.append.php
[LocationSettings]
MaxDepth=3
*/ ?>
```

## MaxItems

> The maxium number of elements in the drop down  
> Setting it too high might slow down the system and make the dropdown hard to use.  
> A number between 10 to 30 is OK.  

Default: `30`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/upload.ini.append.php
[LocationSettings]
MaxItems=30
*/ ?>
```

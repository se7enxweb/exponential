# menu.ini [Leftmenu_help]

The block `[Leftmenu_help]` of `settings/menu.ini`, with 8 setting(s).

> The left menu of the help views (exphelp/\*, design:exphelp/menu.tpl): they belong to the Setup tab  
> (ezsetupnavigationpart), which stays marked, but draw this menu instead of the Setup menu. Each link is shown only  
> to a user who can open it; the names are translated in the context kernel/exphelp.  

Never edit `settings/menu.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/menu.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/menu.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/menu.ini.append.php` in an extension (read when the extension is active).

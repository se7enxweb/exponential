# countrygroups.ini [CountrySettings]

The block `[CountrySettings]` of `settings/countrygroups.ini`, with 4 setting(s).

Never edit `settings/countrygroups.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/countrygroups.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/countrygroups.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/countrygroups.ini.append.php` in an extension (read when the extension is active).

## GroupList

> The groups shown before "All countries", in this order. Each group needs  
> GroupName\_<group> (its label, translated in the context kernel/country)  
> and GroupCountries\_<group>\[\] (ISO 3166-1 alpha-2 codes, ranked).  
> An empty list leaves only "All countries".  

Default: a list of 1: `common`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/countrygroups.ini.append.php
[CountrySettings]
# an empty "GroupList[]" first replaces the shipped list; without it the items are added
GroupList[]
GroupList[]=common
*/ ?>
```

## RepeatInAllCountries

> Whether "All countries" lists the countries of the groups above again  
> (enabled), so the A-Z list stays complete, or leaves them out (disabled).  
> A select that allows several countries never repeats them.  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/countrygroups.ini.append.php
[CountrySettings]
RepeatInAllCountries=enabled
*/ ?>
```

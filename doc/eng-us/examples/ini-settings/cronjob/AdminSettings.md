# cronjob.ini [AdminSettings]

The block `[AdminSettings]` of `settings/cronjob.ini`, with 7 setting(s).

Never edit `settings/cronjob.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/cronjob.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/cronjob.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/cronjob.ini.append.php` in an extension (read when the extension is active).

## ForbiddenParts

> Settings for the cronjobs console at Setup > Cronjobs, which launches a  
> cronjob part from the administration interface.  
> Parts that must not be launchable from a browser. Both defaults are  
> destructive and belong to an administrator on a shell: cluster\_maintenance  
> purges cluster storage, and unlock releases locks other processes hold.  

Default: a list of 2: `cluster_maintenance`, `unlock`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cronjob.ini.append.php
[AdminSettings]
# an empty "ForbiddenParts[]" first replaces the shipped list; without it the items are added
ForbiddenParts[]
ForbiddenParts[]=cluster_maintenance
ForbiddenParts[]=unlock
*/ ?>
```

## PhpCliPath

> Full path to the php command line binary used to run runcronjobs.php. Left  
> empty the usual locations are tried, which is enough on a normal installation.  
> It has to be a command line binary: the one running the web request cannot run  
> a script.  

Default: empty.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cronjob.ini.append.php
[AdminSettings]
PhpCliPath=
*/ ?>
```

## CrontabSchedule_expqueue

> The schedule of a part in a crontab line, CrontabSchedule\_<part>=<five cron fields>: the line Setup >  
> Cronjobs proposes and the line the installers and bin/php/installcrontab.php write. Without one:  
> frequent \*/5 \* \* \* \*, the global part \*/15 \* \* \* \*, infrequent 17 \* \* \* \*, any other part 0 \* \* \* \*.  
> The job queue and the imports' schedules run every minute, expai's queue every five minutes.  

Default: `* * * * *`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cronjob.ini.append.php
[AdminSettings]
CrontabSchedule_expqueue=* * * * *
*/ ?>
```

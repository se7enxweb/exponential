# cronjob.ini [CronjobSettings]

The block `[CronjobSettings]` of `settings/cronjob.ini`, with 4 setting(s).

Never edit `settings/cronjob.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/cronjob.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/cronjob.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/cronjob.ini.append.php` in an extension (read when the extension is active).

## ScriptDirectories

Default: a list of 1: `cronjobs`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cronjob.ini.append.php
[CronjobSettings]
# an empty "ScriptDirectories[]" first replaces the shipped list; without it the items are added
ScriptDirectories[]
ScriptDirectories[]=cronjobs
*/ ?>
```

## MaxScriptExecutionTime

> No more than one instance of a cronjob script can be run at any given time.  
> If a script uses more time than MaxScriptExecutionTime, the next instance of  
> it will try to gracefully steal the cronjob script mutex. If the process has  
> been running for more than two times MaxScriptExecutionTime, the original  
> process will be killed. The default is 12 hours. MaxScriptExecutionTime can  
> also be set per cronjob part, that will override this global setting.  

Default: `43200`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cronjob.ini.append.php
[CronjobSettings]
MaxScriptExecutionTime=43200
*/ ?>
```

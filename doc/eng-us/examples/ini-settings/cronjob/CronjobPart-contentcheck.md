# cronjob.ini [CronjobPart-contentcheck]

The block `[CronjobPart-contentcheck]` of `settings/cronjob.ini`, with 1 setting(s).

> The reference index of the content checks on its own: php runcronjobs.php contentcheck. Only  
> needed with contentcheck.ini \[UnreferencedSettings\] BuildOnRequest=false (very large  
> installations); run it more often than IndexTTL. Guide: doc/en/us/features/6.0/content-checks.md  

Never edit `settings/cronjob.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/cronjob.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/cronjob.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/cronjob.ini.append.php` in an extension (read when the extension is active).

## Scripts

Default: a list of 1: `contentcheck.php`.

Scripts[]
Scripts[]=contentcheck.php
*/ ?>

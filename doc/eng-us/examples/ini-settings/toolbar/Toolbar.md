# toolbar.ini [Toolbar]

The block `[Toolbar]` of `settings/toolbar.ini`, with 1 setting(s).

Never edit `settings/toolbar.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/toolbar.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/toolbar.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/toolbar.ini.append.php` in an extension (read when the extension is active).

## AvailableToolBarArray

Default: a list of 3: `top`, `right`, `bottom`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/toolbar.ini.append.php
[Toolbar]
# an empty "AvailableToolBarArray[]" first replaces the shipped list; without it the items are added
AvailableToolBarArray[]
AvailableToolBarArray[]=top
AvailableToolBarArray[]=right
AvailableToolBarArray[]=bottom
*/ ?>
```

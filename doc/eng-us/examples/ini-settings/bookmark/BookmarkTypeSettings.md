# bookmark.ini [BookmarkTypeSettings]

The block `[BookmarkTypeSettings]` of `settings/bookmark.ini`, with 2 setting(s).

Never edit `settings/bookmark.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/bookmark.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/bookmark.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/bookmark.ini.append.php` in an extension (read when the extension is active).

## TypeList

> The kinds of system page bookmarks. Each one is a class extending expBookmarkType: it says which module  
> views it takes (accepts()), which query string keys they keep, the icon and the label of their bookmarks.  
> They are asked in this order; the first that takes a view decides, and a view no type takes is a  
> "System page" (expBookmarkTypeSystemPage). An extension adds a type with its own  
> settings/bookmark.ini.append.php:  
>   \[BookmarkTypeSettings\]  
>   TypeList\[\]=layout  
>   TypeClass\[layout\]=myLayoutBookmarkType  

Default: a list of 1: `search`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/bookmark.ini.append.php
[BookmarkTypeSettings]
# an empty "TypeList[]" first replaces the shipped list; without it the items are added
TypeList[]
TypeList[]=search
*/ ?>
```

# migration.ini [RunSettings]

The block `[RunSettings]` of `settings/migration.ini`, with 3 setting(s).

Never edit `settings/migration.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/migration.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/migration.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/migration.ini.append.php` in an extension (read when the extension is active).

## RunAsUser

> The user a migration runs as when nobody is signed in: console and unattended runs. A run in the  
> administration runs as the signed-in user. The login, never an id: ids differ between installations.  

Default: `admin`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/migration.ini.append.php
[RunSettings]
RunAsUser=admin
*/ ?>
```

## StopOnFailure

> enabled: a run stops at the first migration that fails; the ones after it are not run.  
> disabled: the run goes on with the migrations that do not require the failed one.  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/migration.ini.append.php
[RunSettings]
StopOnFailure=enabled
*/ ?>
```

## Throttle

> A pause between migrations, to keep a long run from loading the server. Empty: none.  

Default: empty.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/migration.ini.append.php
[RunSettings]
Throttle=
*/ ?>
```

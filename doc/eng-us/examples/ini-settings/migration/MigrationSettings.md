# migration.ini [MigrationSettings]

The block `[MigrationSettings]` of `settings/migration.ini`, with 3 setting(s).

Never edit `settings/migration.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/migration.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/migration.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/migration.ini.append.php` in an extension (read when the extension is active).

## Enabled

> enabled: migrations are looked for in the directories below. disabled: none are found.  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/migration.ini.append.php
[MigrationSettings]
Enabled=enabled
*/ ?>
```

## DirectoryList

> The site's migration directories, relative to the installation's root or absolute. Each holds  
> files named YYYYMMDDHHMMSS\_name.<type> (php, yml, sql, <engine>.sql, mongodb.json, ini); subdirectories are not  
> searched.  

Default: a list of 1: `migrations`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/migration.ini.append.php
[MigrationSettings]
# an empty "DirectoryList[]" first replaces the shipped list; without it the items are added
DirectoryList[]
DirectoryList[]=migrations
*/ ?>
```

## ExtensionDirectory

> The directory inside every active extension (extension/<name>/migrations) and every installed  
> package that holds its migrations.  

Default: `migrations`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/migration.ini.append.php
[MigrationSettings]
ExtensionDirectory=migrations
*/ ?>
```

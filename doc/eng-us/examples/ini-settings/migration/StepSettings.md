# migration.ini [StepSettings]

The block `[StepSettings]` of `settings/migration.ini`, with 2 setting(s).

Never edit `settings/migration.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/migration.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/migration.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/migration.ini.append.php` in an extension (read when the extension is active).

## StepTypeList

> The step types of YAML migrations: StepTypeList\[<name>\]=<class>, where <name> is what "type:" of a step names and  
> the class implements expMigrationStepType. An extension registers its own in its migration.ini.append.php.  

Default: a hash of 2: `reference=expMigrationStepReference`, `assert=expMigrationStepAssert`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/migration.ini.append.php
[StepSettings]
# an empty "StepTypeList[]" first replaces the shipped list; without it the items are added
StepTypeList[]
StepTypeList[reference]=expMigrationStepReference
StepTypeList[assert]=expMigrationStepAssert
*/ ?>
```

## MaxLoopIterations

> The most turns a "while" loop of a YAML migration takes when it names no "max"; one more fails the migration.  

Default: `1000`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/migration.ini.append.php
[StepSettings]
MaxLoopIterations=1000
*/ ?>
```

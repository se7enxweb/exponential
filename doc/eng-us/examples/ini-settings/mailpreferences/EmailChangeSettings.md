# mailpreferences.ini [EmailChangeSettings]

The block `[EmailChangeSettings]` of `settings/mailpreferences.ini`, with 2 setting(s).

Never edit `settings/mailpreferences.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/mailpreferences.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/mailpreferences.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/mailpreferences.ini.append.php` in an extension (read when the extension is active).

## Confirm

> enabled (the default): a new e-mail address of an account (user/edit, the  
> admin's edit, the account services) takes effect only once it is confirmed  
> with the link sent to the new address; the account keeps its old address  
> until then. disabled: the address changes at once, as before.  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/mailpreferences.ini.append.php
[EmailChangeSettings]
Confirm=enabled
*/ ?>
```

## NotifyOldAddress

> enabled: the old address gets a notice that a change was asked for.  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/mailpreferences.ini.append.php
[EmailChangeSettings]
NotifyOldAddress=enabled
*/ ?>
```

# mailpreferences.ini [TokenSettings]

The block `[TokenSettings]` of `settings/mailpreferences.ini`, with 3 setting(s).

Never edit `settings/mailpreferences.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/mailpreferences.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/mailpreferences.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/mailpreferences.ini.append.php` in an extension (read when the extension is active).

## TTL

> Lifetime of the links in seconds, per purpose; 0 never expires. The  
> unsubscribe and manage links in mail must keep working long after the mail  
> was sent (CAN-SPAM: at least 30 days, CASL: 60 days). A value for  
> unsubscribe or manage between 0 and 5184000 (60 days) is raised to 60 days,  
> with a warning on the status page.  

Default: a hash of 3: `unsubscribe=0`, `manage=0`, `confirm=604800`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/mailpreferences.ini.append.php
[TokenSettings]
# an empty "TTL[]" first replaces the shipped list; without it the items are added
TTL[]
TTL[unsubscribe]=0
TTL[manage]=0
TTL[confirm]=604800
*/ ?>
```

## RequestLinkTTL

> The "send me a link" page: the lifetime of the link it sends, and how many  
> links one address can ask for per hour.  

Default: `86400`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/mailpreferences.ini.append.php
[TokenSettings]
RequestLinkTTL=86400
*/ ?>
```

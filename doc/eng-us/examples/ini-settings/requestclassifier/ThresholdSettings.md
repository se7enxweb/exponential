# requestclassifier.ini [ThresholdSettings]

The block `[ThresholdSettings]` of `settings/requestclassifier.ini`, with 3 setting(s).

Never edit `settings/requestclassifier.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/requestclassifier.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/requestclassifier.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/requestclassifier.ini.append.php` in an extension (read when the extension is active).

## Max404PerMinute

> More than this many not-found answers (Statuses\[\]) to one client within WindowSeconds makes every further one in  
> that window a verdict threshold/404-rate (medium; high above twice the limit). 0 switches the rule off. The client  
> is counted by a salted hash of its address in var/<site>/cache/requestclassifier/counter/, shared by every PHP  
> process of the installation (the web server's and Velocity's); the address itself is never stored.  

Default: `30`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/requestclassifier.ini.append.php
[ThresholdSettings]
Max404PerMinute=30
*/ ?>
```

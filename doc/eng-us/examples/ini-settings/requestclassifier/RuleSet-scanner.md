# requestclassifier.ini [RuleSet-scanner]

The block `[RuleSet-scanner]` of `settings/requestclassifier.ini`, with 3 setting(s).

Never edit `settings/requestclassifier.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/requestclassifier.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/requestclassifier.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/requestclassifier.ini.append.php` in an extension (read when the extension is active).

> here: curl, wget, python-requests, headless browsers (Playwright, HeadlessChrome), search engines.

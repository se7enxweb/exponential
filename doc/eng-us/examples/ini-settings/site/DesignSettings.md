# site.ini [DesignSettings]

The block `[DesignSettings]` of `settings/site.ini`, with 8 setting(s).

> # Set access policy to allowed  
> Rules\[\]=access;enable  
> # Special syntax which means any module  
> # This means that for now all modules are enabled  
> Rules\[\]=moduleall  
> # Set policy to denied  
> Rules\[\]=access;disable  
> # If content/search module use current policy (denied)  
> Rules\[\]=module;content/search  
> # If rss module use current policy (denied)  
> Rules\[\]=module;rss  

Never edit `settings/site.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/site.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/site.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/site.ini.append.php` in an extension (read when the extension is active).

## StandardDesign

> The standard design, is used as fallback design  
> if the element is not in the sitedesign  

Default: `standard`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[DesignSettings]
StandardDesign=standard
*/ ?>
```

## AdditionalSiteDesignList

> AdditionalSiteDesignArray contains an array  
> of sitedesigns. These sitedesigns will be used  
> if the design was not found in the main  
> sitedesign. StandardDesign is the fallback design.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[DesignSettings]
# an empty "AdditionalSiteDesignList[]" first replaces the shipped list; without it the items are added
AdditionalSiteDesignList[]
*/ ?>
```

## SwitchableDesigns

> A front siteaccess can let every visitor switch between designs with one  
> click (doc/eng-us/features/6.0/front-design-switch.md). Off while the list is  
> empty; never on an administration siteaccess. The siteaccess's SiteDesign is  
> the default; a link with the view parameter /(design)/<name> chooses another  
> one and keeps it in a cookie. In the siteaccess's site.ini.append.php:  
>   SwitchableDesigns\[\]  
>   SwitchableDesigns\[\]=doc2025  
>   SwitchableDesignLabel\[doc\]=Modern  
>   SwitchableDesignLabel\[doc2025\]=Classic  
>   SwitchableDesignChain\[doc2025\]=standard  
> SwitchableDesignChain\[<design>\] is the fallback chain of a design, designs  
> separated by ";" (without one the siteaccess's AdditionalSiteDesignList\[\]  
> stays). fetch( 'uiswitch', 'front\_designs' ) gives templates the choices.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[DesignSettings]
# an empty "SwitchableDesigns[]" first replaces the shipped list; without it the items are added
SwitchableDesigns[]
*/ ?>
```

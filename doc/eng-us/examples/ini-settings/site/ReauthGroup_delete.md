# site.ini [ReauthGroup_delete]

The block `[ReauthGroup_delete]` of `settings/site.ini`, with 2 setting(s).

Never edit `settings/site.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/site.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/site.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/site.ini.append.php` in an extension (read when the extension is active).

## Enabled

> Deleting data for good: emptying the trash or removing items from it, removing several  
> items at once (BulkCount or more), and clearing the session list (setup/session is in  
> system). The audit log has no page that clears it: only the console, which is never asked.  

Default: `true`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[ReauthGroup_delete]
Enabled=true
*/ ?>
```

## Rules

Default: a list of 2: `content/trash EmptyButton RemoveButton`, `content/removeobject * bulk`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[ReauthGroup_delete]
# an empty "Rules[]" first replaces the shipped list; without it the items are added
Rules[]
Rules[]=content/trash EmptyButton RemoveButton
Rules[]=content/removeobject * bulk
*/ ?>
```

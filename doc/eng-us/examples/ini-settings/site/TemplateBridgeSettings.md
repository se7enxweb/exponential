# site.ini [TemplateBridgeSettings]

The block `[TemplateBridgeSettings]` of `settings/site.ini`, with 4 setting(s).

> CompileIncludeNodeTree\[\]=final  
> CompileIncludeNodeTree\[\]=transformed  
> CompileIncludeNodeTree\[\]=static  
> CompileIncludeNodeTree\[\]=combined  
> CompileIncludeNodeTree\[\]=original  
> The converters of exp:template:convert (lib/templatebridge/classes/exptemplatedesignconverter.php):  
> ConverterList\[<from>-<to>\]=<class> converts one template text from one engine to another.  
> Engines: tpl (Exponential templates, .tpl), stpl (Smarty templates, .stpl), twig (Twig  
> templates, .twig and .html.twig).  
> The class takes an eZTemplate in its constructor and has convert( $text, $name ) and warnings().  
> An extension adds a direction with its own ConverterList\[\] entry.  

Never edit `settings/site.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/site.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/site.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/site.ini.append.php` in an extension (read when the extension is active).

## ConverterList

Default: a hash of 4: `tpl-stpl=expSmartyConverter`, `stpl-tpl=expSmartyReverseConverter`, `tpl-twig=expTwigConverter`, `twig-tpl=expTwigReverseConverter`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[TemplateBridgeSettings]
# an empty "ConverterList[]" first replaces the shipped list; without it the items are added
ConverterList[]
ConverterList[tpl-stpl]=expSmartyConverter
ConverterList[stpl-tpl]=expSmartyReverseConverter
ConverterList[tpl-twig]=expTwigConverter
ConverterList[twig-tpl]=expTwigReverseConverter
*/ ?>
```

## EngineSuffixList

> Template files of other engines, by file ending (the longest ending matches first):  
> EngineSuffixList\[<ending>\]=<engine>. The template system parses such a file as the stub  
> of the engine's renderer, RendererList\[<engine>\]=<class> (expTemplateEngines).  

Default: a hash of 3: `.stpl=stpl`, `.twig=twig`, `.html.twig=twig`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[TemplateBridgeSettings]
# an empty "EngineSuffixList[]" first replaces the shipped list; without it the items are added
EngineSuffixList[]
```

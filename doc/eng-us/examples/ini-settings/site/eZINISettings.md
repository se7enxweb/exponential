# site.ini [eZINISettings]

The block `[eZINISettings]` of `settings/site.ini`, with 2 setting(s).

Never edit `settings/site.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/site.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/site.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/site.ini.append.php` in an extension (read when the extension is active).

## ReadonlySettingList

> Use 'ReadonlySettingList' to set read-only settings.  
> usage:  
> for specific setting:  
>   ini-filename/section\_name/setting\_name  
> for all settings in section:  
>   ini-filename/section\_name/\*  
> for all settings in ini-file:  
>   ini-filename/\*  

Default: a list of 3: `template.ini/PHP/PHPOperatorList`, `image.ini/ImageMagick/ExecutablePath`, `image.ini/ImageMagick/Executable`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[eZINISettings]
# an empty "ReadonlySettingList[]" first replaces the shipped list; without it the items are added
ReadonlySettingList[]
ReadonlySettingList[]=template.ini/PHP/PHPOperatorList
ReadonlySettingList[]=image.ini/ImageMagick/ExecutablePath
ReadonlySettingList[]=image.ini/ImageMagick/Executable
*/ ?>
```

## DynamicTemplateMode

> Dynamic ini template operator  
> Changes global setting for ezini and ezini\_hasvariable template  
> operators for the default setting of 'dynamic' parameter  
> When enabled these calls are not compiled as ini values into  
> templates, but read dynamically  
> Note: only read during template compilation  

Default: `disabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[eZINISettings]
DynamicTemplateMode=disabled
*/ ?>
```

# site.ini [SSLZoneSettings]

The block `[SSLZoneSettings]` of `settings/site.ini`, with 3 setting(s).

> Settings for SSL zones  
> For more information please look at doc/eng-us/features/3.8/ssl\_zones.txt.  

Never edit `settings/site.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/site.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/site.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/site.ini.append.php` in an extension (read when the extension is active).

## SSLZones

> Enable/disable the SSL zones functionality.  

Default: `disabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[SSLZoneSettings]
SSLZones=disabled
*/ ?>
```

## SSLSubtrees

> Content subtrees we must use SSL for.  
> (currently, only content/view and content/edit respect this setting)  
>
> Examples:  
> SSLSubtrees\[\]=/news  
> SSLSubtrees\[\]=/polls  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[SSLZoneSettings]
# an empty "SSLSubtrees[]" first replaces the shipped list; without it the items are added
SSLSubtrees[]
*/ ?>
```

## ModuleViewAccessMode

> Default access mode is plain HTTP.  
>
> Define a view as 'ssl' to force HTTPS access mode for this view.  
> If a view is defined as 'keep' then access mode is unknown  
> for this view, and the previous access mode is kept.  
>
> Define a view as 'nossl' to force HTTP for this module. Further  
> SSL redirections will be ignored  
>
> Examples:  
> ModuleViewAccessMode\[shop/add\]=ssl  
> ModuleViewAccessMode\[shop/basket\]=ssl  
>
> Do not remove this line unless you know what you're doing:  

Default: a hash of 2: `content/*=keep`, `layout/*=keep`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[SSLZoneSettings]
# an empty "ModuleViewAccessMode[]" first replaces the shipped list; without it the items are added
ModuleViewAccessMode[]
ModuleViewAccessMode[content/*]=keep
ModuleViewAccessMode[layout/*]=keep
*/ ?>
```

# site.ini [TipAFriend]

The block `[TipAFriend]` of `settings/site.ini`, with 3 setting(s).

> Settings control amount of mails  allowed to to be sent to one email address  

Never edit `settings/site.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/site.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/site.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/site.ini.append.php` in an extension (read when the extension is active).

## MaxRequestsPerTimeframe

Default: `5`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[TipAFriend]
MaxRequestsPerTimeframe=5
*/ ?>
```

```ini
*/ ?>
```

## FromEmail

> in hours  
> Email used as sender email in tipafriend mails, this is needed when you use  
> smtp servers with closed relaying  
> Assign a non-empty value to FromEmail for it to be used as from address.  

Default: empty.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[TipAFriend]
FromEmail=
*/ ?>
```

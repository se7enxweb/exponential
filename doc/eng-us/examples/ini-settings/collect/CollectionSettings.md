# collect.ini [CollectionSettings]

The block `[CollectionSettings]` of `settings/collect.ini`, with 8 setting(s).

Never edit `settings/collect.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/collect.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/collect.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/collect.ini.append.php` in an extension (read when the extension is active).

## CollectAnonymousData

> if enabled then information from anonymous users can be collected  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/collect.ini.append.php
[CollectionSettings]
CollectAnonymousData=enabled
*/ ?>
```

## CollectionUserData

> How information collection is handled in terms of user identification  
>
> multiple  - each user can submit multiple data  
> unique    - one set of data per user, if already exists give a warning  
> overwrite - one set of data per user but new entry overwrites old one  

Default: `multiple`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/collect.ini.append.php
[CollectionSettings]
CollectionUserData=multiple
*/ ?>
```

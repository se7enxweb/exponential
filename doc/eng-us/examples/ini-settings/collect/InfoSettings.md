# collect.ini [InfoSettings]

The block `[InfoSettings]` of `settings/collect.ini`, with 3 setting(s).

Never edit `settings/collect.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/collect.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/collect.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/collect.ini.append.php` in an extension (read when the extension is active).

## Type

> The default information collection type  

Default: `form`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/collect.ini.append.php
[InfoSettings]
Type=form
*/ ?>
```

## TypeList

> Matches class id or identifier to information collection type  

Default: a hash of 3: `poll=poll`, `form=form`, `feedback=feedback`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/collect.ini.append.php
[InfoSettings]
# an empty "TypeList[]" first replaces the shipped list; without it the items are added
TypeList[]
TypeList[poll]=poll
TypeList[form]=form
TypeList[feedback]=feedback
*/ ?>
```

## TypeAttribute

> Which attribute to look for in the object to determine type  
> if found the content of the attribute will be used for type  

Default: `collection_type`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/collect.ini.append.php
[InfoSettings]
TypeAttribute=collection_type
*/ ?>
```

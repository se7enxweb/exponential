# contentcheck.ini [StorageSettings]

The block `[StorageSettings]` of `settings/contentcheck.ini`, with 10 setting(s).

Never edit `settings/contentcheck.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/contentcheck.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/contentcheck.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/contentcheck.ini.append.php` in an extension (read when the extension is active).

## ScanDirectoryList

> The storage files (doc/eng-us/features/6.0/content-checks.md, "Storage files"): files below  
> var/<site>/storage that no content uses, and the file-system problems of those it uses.  
> The directories below the storage that are scanned  

Default: a list of 3: `images`, `images-versioned`, `original`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/contentcheck.ini.append.php
[StorageSettings]
# an empty "ScanDirectoryList[]" first replaces the shipped list; without it the items are added
ScanDirectoryList[]
ScanDirectoryList[]=images
ScanDirectoryList[]=images-versioned
ScanDirectoryList[]=original
*/ ?>
```

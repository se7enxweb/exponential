# Extension points in error.ini

Settings of `settings/error.ini` whose name says they hold handlers, classes, filters, providers or directories that an extension can add to or replace. **Found by the setting's name: a heuristic.** Read the setting's comment (linked) before relying on it.

An extension adds to a list in its own `settings/error.ini.append.php` (active extensions' settings are read after the kernel's and before `settings/override`):

## ErrorSettings DefaultErrorHandler

# The imagealiasbacklog.php cronjob

Make the image aliases left in the backlog that no request has made (settings/image.ini [AliasSettings] Backlog).

Entry point `cronjobs/imagealiasbacklog.php`, code in `kernel/private/classes/cronjobs/imagealiasbacklog.php`.

> The cronjob part imagealiasbacklog (cronjobs/imagealiasbacklog.php, frequent group): the safety net of the image  
> alias backlog (expImageAliasBacklog, settings/image.ini \[AliasSettings\] Backlog). Requests make the backlog right  
> after their answers; what is still there when this part runs (the server got no request since, or a process died  
> while it worked on an entry) is made here, waiting for a conversion slot as a job does. Each alias as the  
> siteaccess the page was shown in defines it. Nothing in render mode or with an empty backlog.  

## When it runs

In the shipped `settings/cronjob.ini` it belongs to: the part `frequent`.

```bash
# run its part (as the user the web server runs as, from the installation root)
php runcronjobs.php frequent
./console exp:runcronjobs frequent
# run only this script
php runcronjobs.php imagealiasbacklog
```

Add it to a part in an override:

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cronjob.ini.append.php
[CronjobPart-frequent]
Scripts[]=imagealiasbacklog.php
*/ ?>
```

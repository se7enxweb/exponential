# The graphqlwebhooks.php cronjob

GraphQL webhooks: send the events of the journal to the end points that want them, with retries.

Entry point `cronjobs/graphqlwebhooks.php`, code in `kernel/private/classes/cronjobs/graphqlwebhooks.php`.

> The cronjob part graphqlwebhooks (cronjobs/graphqlwebhooks.php; \[CronjobPart-graphqlwebhooks\] and the frequent group  
> in cronjob.ini; doc/eng-us/features/6.0/graphql.md, "Webhooks"): reads the GraphQL event journal from where the last  
> run stopped, puts a delivery in the outbox for every end point that wants an event, and sends the deliveries that  
> are due (expGraphQLWebhooks). Does nothing while no end point is configured or the API is switched off.  

## When it runs

In the shipped `settings/cronjob.ini` it belongs to: the part `frequent`, the part `graphqlwebhooks`.

```bash
# run its part (as the user the web server runs as, from the installation root)
php runcronjobs.php frequent
./console exp:runcronjobs frequent
# run only this script
php runcronjobs.php graphqlwebhooks
```

```ini
<?php /* #?ini charset="utf-8"?

*/ ?>
```

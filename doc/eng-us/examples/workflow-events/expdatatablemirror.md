# The expdatatablemirror workflow event (Mirror to data tables)

Class `expDataTableMirrorType` in `kernel/classes/workflowtypes/event/expdatatablemirror/expdatatablemirrortype.php`; in a workflow it is the event type `event_expdatatablemirror`, listed in `settings/workflow.ini` `[EventSettings] AvailableEventTypes[]`.

It may be used on these triggers only (`setTriggerTypes()`): `content/publish (after)`.

## Use it

1. Setup > Workflows: create a workflow in a group and add the event "Mirror to data tables"; fill in its settings.
2. Setup > Triggers: connect the workflow to a trigger, for example `content / publish / before` (see the [triggers](triggers.md)).
3. Workflows that wait (approval, a date) continue when the cronjob part `frequent` runs `workflow.php` (see the [cronjobs](../cronjobs/README.md)).

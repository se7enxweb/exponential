# The ezsimpleshipping workflow event (Simple shipping)

Class `eZSimpleShippingType` in `kernel/classes/workflowtypes/event/ezsimpleshipping/ezsimpleshippingtype.php`; in a workflow it is the event type `event_ezsimpleshipping`, listed in `settings/workflow.ini` `[EventSettings] AvailableEventTypes[]`.

## Use it

1. Setup > Workflows: create a workflow in a group and add the event "Simple shipping"; fill in its settings.
2. Setup > Triggers: connect the workflow to a trigger, for example `content / publish / before` (see the [triggers](triggers.md)).
3. Workflows that wait (approval, a date) continue when the cronjob part `frequent` runs `workflow.php` (see the [cronjobs](../cronjobs/README.md)).

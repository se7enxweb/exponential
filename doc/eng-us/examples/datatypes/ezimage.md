# The ezimage datatype (Image)

Class `eZImageType` in `kernel/classes/datatypes/ezimage/ezimagetype.php`; identifier `ezimage`, listed in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## What it stores

The columns of the attribute tables its class reads or writes: `data_int1`, `data_int2`, `data_text` (`data_text`, `data_int`, `data_float` and `sort_key_*` are the object attribute's; `data_text1` ... `data_int4` the class attribute's settings). Found by reading the class: a heuristic.
It is can be filled from an uploaded file.

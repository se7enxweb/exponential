# The ezinisetting datatype (Ini Setting)

## What it stores

The columns of the attribute tables its class reads or writes: `data_int`, `data_int1`, `data_text`, `data_text1`, `data_text2`, `data_text3`, `data_text4`, `data_text5` (`data_text`, `data_int`, `data_float` and `sort_key_*` are the object attribute's; `data_text1` ... `data_int4` the class attribute's settings).

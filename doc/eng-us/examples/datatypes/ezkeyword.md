# The ezkeyword datatype (Keywords)

Class `eZKeywordType` in `kernel/classes/datatypes/ezkeyword/ezkeywordtype.php`; identifier `ezkeyword`, listed in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## What it stores

Its class names none of the standard columns; it stores its value elsewhere (a table of its own or another object).
It is indexed by the search.

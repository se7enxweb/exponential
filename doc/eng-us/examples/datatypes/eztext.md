# The eztext datatype (Text block)

Class `eZTextType` in `kernel/classes/datatypes/eztext/eztexttype.php`; identifier `eztext`, listed in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## What it stores

The columns of the attribute tables its class reads or writes: `data_int1`, `data_text` (`data_text`, `data_int`, `data_float` and `sort_key_*` are the object attribute's; `data_text1` ... `data_int4` the class attribute's settings). Found by reading the class: a heuristic.
It is indexed by the search; collects information (forms); can be filled from a plain string.

# The GFDL for theme documentation

This page is for designers who write documentation for their theme (install guides, tutorials, a style guide) and want
others to copy and improve it. It is not legal advice.

## What the Exponential documentation does

The documentation in the Exponential repository is under the **GNU Free Documentation License, version 1.3 or later**,
with no Invariant Sections, no Front-Cover Texts and no Back-Cover Texts. Its notice reads:

```text
Copyright (C) <years> <holders>.

Permission is granted to copy, distribute and/or modify this document under the terms of the GNU Free
Documentation License, Version 1.3 or any later version published by the Free Software Foundation; with no
Invariant Sections, no Front-Cover Texts, and no Back-Cover Texts. A copy of the license is included in the
section entitled "GNU Free Documentation License".
```

The community wiki [eZpedia](https://ezpedia.exponential.earth/) also publishes its text under the GNU Free
Documentation License.

## Why use it for a theme's docs

- Readers may copy, translate and improve it, and must keep it free.
- Your pages can be combined with the Exponential documentation and with eZpedia articles under the same license.

## GFDL or Creative Commons

| GFDL 1.3 | CC BY-SA 4.0 |
|---|---|
| Matches the Exponential documentation and eZpedia | Common on the web, shorter |
| Requires the license text to travel with copies | Requires attribution and the same license |

Either works; choose one and state it. For mixing with the Exponential documentation, the GFDL is the simpler choice.

## Step by step

1. Put the notice at the top or bottom of your documentation's index page, with your years and names.
2. Ship the license text (`https://www.gnu.org/licenses/fdl-1.3.txt`) as a file in the docs folder.
3. Name the documentation license in the README, separately from the code license.

# Partner profiles: IT, creative, hosting, distribution and development

This page is for partners choosing the profile (the program also says "class" or "type") that describes their core
competency. Customers use profiles to find the right partner, so choose carefully.

## The profiles as published

"Exponential recognizes partners in four main categories based on strengths and services. IT Partners implement
systems, Creative Partners focus on UX, Hosting Partners provide infrastructure, and Distribution Partners drive
adoption" (<https://exponential.earth/partner/partner-classes>, read 18 October 2026).

| Profile | Published description | Typical companies (as published) | Source |
|---|---|---|---|
| **IT Partners** | "The technical backbone for the Exponential ecosystem, these partners develop solutions based on Exponential that address the needs of Exponential customers from a technical point of view" | "system integrators, development agencies, and consulting agencies" | <https://exponential.earth/partner/program> |
| **Creative Partners** | "Bring their design and communication skills to Exponential projects, often with a focus on communication strategy" | "web design companies, web agencies, communication and advertisement agencies" | same |
| **Hosting Partners** | "Provide the infrastructure for hosting Exponential-based solutions. They have expertise in designing the optimal environment for a specific solution." | Hosting providers | same |
| **Distribution Partners** | "Extend the Exponential ecosystem by distributing and reselling Exponential software or certifications" | "distributors, resellers, and training centers" | same |
| **Development Partners** | "Deliver the Website Application Development and Content Development Required to Publish Your Website Packed With Features And Functionality" | Listed under the partner classes | <https://exponential.earth/partner/partner-classes/development-partners> |

The classes page lists Development Partners next to the four main profiles; the program page lists only the four.
Whether Development is a profile of its own or part of IT is not stated: ask the partner team when you apply.

## One profile or several

"Partners choose one or more profiles, types, classes that best reflect their core services" (partner classes page),
while the program page says "When applying, partners select the profile that best describes their core competency.
They will then be shown in the corresponding profile list". Choose one main profile; add others only for services
you deliver regularly and can show references for.

## How to choose

| If most of your revenue comes from | Choose | Then read |
|---|---|---|
| Building and integrating sites, custom modules, migrations | IT (or Development) | [Implementation partners](implementation-partners.md) |
| Design, UX, content strategy, campaigns | Creative | [Creative partners](creative-partners.md) |
| Running servers and managed hosting | Hosting | [Hosting partners](hosting-partners.md) |
| Reselling, packaging, training, certification | Distribution | [Distribution partners and resellers](distribution-partners.md), [Training partners](training-partners.md) |
| Extensions and themes you publish | IT or Creative (no separate profile is published) | [Extension and theme partners](extension-and-theme-partners.md) |

## What customers expect from each profile

| Profile | Customers will ask for | Prepare |
|---|---|---|
| IT | Architecture, content modeling, upgrade path, security | Two references, an upgrade plan template, your Git workflow |
| Creative | Design system, accessibility, editor experience | A portfolio, accessibility statement, how you hand designs to developers |
| Hosting | PHP versions, databases, backups, uptime, response times | A technical sheet ([Hosting partner technical checklist](hosting-partner-technical-checklist.md)) |
| Distribution | What is included, license terms, training content | Clear package descriptions, [Licensing for partners](licensing-for-partners.md) |

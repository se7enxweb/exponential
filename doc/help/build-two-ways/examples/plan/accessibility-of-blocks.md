# Plan accessibility into the blocks

Pages built in the editor are as accessible as hand-written templates.

*Life cycle: Plan, example 20 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [With templates](#with-templates)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Image and Hero have **Alt text** / **Image alt text**; Title has **Heading level (1-6)**; Button and Hero have their own link text fields.
2. The media theme's layout template already writes a hidden `h1` with the page name, so section titles should be level 2 and below.

## With templates

1. In templates: `alt` from the image's alternative text, headings in order, `|wash` on every printed value.

## Which to choose

Write the rules into the editors' guide: they apply to every block.

## Check

- An accessibility checker finds one `h1` and no image without alternative text.

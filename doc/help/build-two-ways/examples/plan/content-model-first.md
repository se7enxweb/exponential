# Plan the content model before the layouts

No layout waits for a field that does not exist.

*Life cycle: Plan, example 33 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [With templates](#with-templates)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Item view types show the teaser fields (teaser title, teaser image, teaser intro): plan them as editors' work.

## With templates

1. **Setup > Classes** lists the classes; NG Article, for example, has `title`, `teaser_title`, `image`, `teaser_image`, `full_intro`, `teaser_intro`, `body`, `related_content`, `main_topic`, `tags`.
2. Plan new fields before the templates that print them.

## Which to choose

Model first, layouts second, templates last.

## Check

- Every element of the page designs comes from a field.

# Freeze a block into a template

The legal disclaimer cannot be edited by mistake.

*Life cycle: Redesign, example 16 of 34. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [With templates](#with-templates)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Replace the old block by a **Template block** named `disclaimer`; publish.

## With templates

1. Write the disclaimer into `explayouts/tpl_block/disclaimer.tpl`.

## Which to choose

Only for what really must not change; editors lose control on purpose.

## Check

- The block in the editor reads "Template block: **disclaimer**".

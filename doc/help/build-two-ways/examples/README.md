# Life-cycle examples

Each example is one task, done both ways where both apply: in the **Layouts editor** (no code) and with **templates** in your own design extension. The facts behind them (screens, block options, settings, commands, file paths) were checked on a copy of the Fit & Healthy site; the step-by-step pages with screenshots are linked from each example.

| Phase | Examples | What happens |
|---|---|---|
| [Plan](plan/README.md) | 35 | Decide page types, layouts, menus, languages and who changes what, before building. |
| [Build](build/README.md) | 35 | Make the blocks, lists, galleries, columns and templates of the pages. |
| [Launch](launch/README.md) | 33 | Map every page type, fill the menus, check the pages and the caches, keep a baseline. |
| [Maintain](maintain/README.md) | 35 | Change lists, banners, menus and campaigns week by week, and recover from mistakes. |
| [Redesign](redesign/README.md) | 34 | Change the look and the structure: overrides, new view and block types, new shared zones. |
| [Migrate](migrate/README.md) | 34 | Move layouts, settings and templates between installations, versions and sites. |

Total: 206 examples.

# Two ways to build, every page

Exponential 6.0.15+ builds sites two ways: **templates** in a design extension (code, overrides, tests) and the
**Layouts editor** (no code). These pages show both on the real Fit & Healthy demo site, with the exact screens,
commands and files. New here? Start with [Two ways to build](two-ways-to-build.md). In a hurry to change the header
menu? Go to [Add a header menu item](add-a-header-menu-item.md).

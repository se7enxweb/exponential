# Copy a page as a starting point

This page is for editors who create a page much like an existing one: next year's event, a similar notice, a service
in the same format. **Copy** makes a new object from an existing one in a place you choose
([Content model and editing, 10](../../../../guides/content-model-and-editing.md#10-copying-locations-and-how-selections-are-shown)).

## Contents

1. [Before you start](#before-you-start)
2. [Steps](#steps)
3. [Check the result](#check-the-result)

## Before you start

- You may create content where the copy goes (the **Copy** button is grayed out otherwise, and says why).
- Decide whether the copy should be visible at once. A copy is published immediately; to prepare it unseen, copy it
  into a staging folder that visitors cannot read, or hide it right after copying.

## Steps

1. Open the page to copy, press **Copy** (next to **Move** and **Remove**), or choose **Copy** in the item's menu.
2. Choose where the copy goes.
3. If your site asks, choose which versions to copy (usually only the current one).
4. Open the copy (it has the same name), press **Edit**, change title, dates, text and relations.
5. **Send for publishing**.

For a page with children (an event series, a handbook), the item's menu has **Copy subtree**, which copies the item
with everything below it; a large subtree may run as a background job. For several pages, tick them in a **Sub items**
list, **More actions** > **Copy selected**.

## Check the result

- [ ] The copy has its own address (the URL alias is made from its new name after you rename it).
- [ ] The original is unchanged.
- [ ] Nothing of the old content remains in the copy (dates, names, links).

## Pitfalls

| Pitfall | Avoid it |
|---|---|
| A visible half-edited copy | copy into staging or hide it first |
| The address still based on the old name | rename before or right after; the alias follows the name |
| Relations still pointing to last year's documents | update relation fields |
| Copying a page to show it in two places | use a second location instead ([Publish one item in several places](publish-one-item-in-several-places.md)) |

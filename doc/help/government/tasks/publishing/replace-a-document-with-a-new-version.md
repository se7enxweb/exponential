# Replace a document with a new version

This page is for editors who must update a published document: a corrected form, a revised policy, a report with a
fixed table. Editing the File object and choosing a new file keeps its address, so every page that relates it and every
external link keep working ([Versions of documents](../../building/documents-and-publications/versions-of-documents.md)).

## Contents

1. [Before you start](#before-you-start)
2. [Steps](#steps)
3. [Check the result](#check-the-result)
4. [Pitfalls](#pitfalls)

## Before you start

- Decide: a correction or update of the same document (replace in place), or a new edition that should exist beside
  the old one (publish a new object). The 2026 annual report is a new object; a corrected form is a replacement.
- The new file has the same purpose and, ideally, a similar file name.

## Steps

1. Find the document: search for it, or open the page that lists it and follow the relation to the File object.
2. Open the File object, press **Edit**.
3. In the **File** field, choose the new file from your computer.
4. Update **Description** with a note: "Updated on <date>: <what changed>."
5. **Send for publishing**.
6. If the document has a summary page (a Publication), update the summary too and add the same note.

## Check the result

- [ ] Download the document from the page that lists it, signed out: you get the new file (check the date or content).
- [ ] **Manage versions** on the File object lists the previous version, archived, with the old file.
- [ ] Pages that relate the document need no change.

## Pitfalls

| Pitfall | Avoid it |
|---|---|
| Uploading the new file as a new object and leaving the old one | links still point to the old file; edit the existing object |
| The old file still downloadable? | archived versions are not public: downloading another version than the published one needs `content/versionread` |
| The previous file must be destroyed (personal data, legal reasons) | remove the archived versions after replacing ([Versions of documents](../../building/documents-and-publications/versions-of-documents.md#removing-a-file-that-must-not-stay)) |
| A stored PDF export that includes the old content | regenerate it ([Publish a handbook as a PDF export](publish-a-handbook-as-a-pdf-export.md)) |
| Browser or cache shows the old file | reload; ask the web team about caches in front of the site |

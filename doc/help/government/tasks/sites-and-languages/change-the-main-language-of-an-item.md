# Change the main language of an item

This task is for editors. Background: [Main language of an item](../../languages/main-language-of-an-item.md).

## Before you start

The new main language must already exist as a translation of the item (translate first if not).

## Steps

1. Open the item; open the **Translations** tab.
2. In the **Main** column, select the language.
3. Press **Set main**.

## Check

The item's badge for that language says *main language* when you point at it, and the Translations tab marks it.

## Problems

| Problem | Cause |
|---|---|
| The language is not in the list | the item has no translation in it yet |
| The button does nothing | your role may not edit the item in that language |

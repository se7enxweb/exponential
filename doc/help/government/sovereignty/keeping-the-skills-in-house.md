# Keeping the skills in house

This page is for managers and trainers. Even with a provider, a public body needs people who understand its site well
enough to set priorities, check work and change suppliers. All training material for Exponential is free
documentation the body may copy and adapt ([Course catalogue](../../trainers/course-catalogue.md)).

## Contents

1. [The roles to cover](#the-roles-to-cover)
2. [Building the skills](#building-the-skills)
3. [Keeping knowledge when people leave](#keeping-knowledge-when-people-leave)

## The roles to cover

| Role | Must be able to | Training |
|---|---|---|
| Lead editor | train editors, run publishing, own the content model | [Editors 101](../../trainers/editors-101/README.md), [Editors 201](../../trainers/editors-201/README.md) |
| Site administrator | roles, sections, languages, workflows, caches, the audit trail | [Site administrators](../../trainers/site-administrators/README.md) |
| Technical owner | read the code repository, judge provider changes, run an update on a test system | [Developers](../../trainers/developers/README.md), [Hosting operations](../../trainers/hosting-operations/README.md) |
| Product owner | decide what the site should do, accept deliveries | [Project managers start here](../../leadership/project-managers-start-here.md) |

At least two people per role, so one absence does not stop work.

## Building the skills

- Use the help inside the administration: every page here is available there.
- Run the courses internally; adapt them to your classes and menus (GFDL lets you).
- Ask providers to work in your repository and explain changes in their commit messages and documentation.
- Keep a test installation where staff can try things without risk.

## Keeping knowledge when people leave

- A short installation document: siteaccesses, extensions, cronjobs, overrides, third-party services, providers and
  contacts by function.
- Runbooks for the regular tasks (updates, restores, adding a language, adding a site).
- Accounts per person, never shared, removed when people leave (**Users > Check user accounts** finds unused
  accounts: [Check user accounts](../../../features/6.0/user-hygiene.md)).

# Languages checklist

This checklist is for managers and administrators of a multilingual public site. Use it before launch, when a
language is added and once a year. Each item names the page of this section that explains it.

## Contents

1. [Policy](#policy)
2. [Setup](#setup)
3. [People](#people)
4. [Quality](#quality)
5. [Review](#review)

## Policy

- [ ] The official languages, and which content must exist in each, are written down (see "Second and third official
  languages").
- [ ] The fallback policy per language is decided (see "Fallback rules for untranslated content").
- [ ] Minority or regional languages and their scope are decided (see "Minority and regional languages").

## Setup

- [ ] Each content language added (see "Adding a content language").
- [ ] One siteaccess per language with `Locale`, `SiteLanguageList[]`, `SiteName` (see "A siteaccess per language").
- [ ] Addresses by path or host, with equal standing (see "Language addresses: path or host").
- [ ] Start page behavior decided (see "Redirecting to the visitor's language").
- [ ] Switcher on every page, accessible (see "The language switcher").
- [ ] Media and users always available (see "Always available content").
- [ ] Right-to-left design work done where needed (see "Right-to-left languages on public sites").
- [ ] Search per language checked (see "Multilingual search").

## People

- [ ] Translator roles limited by Language (see "Translator roles and permissions").
- [ ] Approval per language where reviewed (see "Translation workflow and approval").
- [ ] Staff know how to choose their interface language (see "Administration interface languages").
- [ ] Glossary kept (see "Glossaries of terms").

## Quality

- [ ] Plain language rules adopted and trained (see "Plain language", "Writing for readability").
- [ ] `lang` correct on pages and parts (see "HTML language tags and accessibility").
- [ ] Dates and numbers checked by a speaker (see "Dates, numbers and currency per language").
- [ ] A test pass with the test language (see "Testing a multilingual site").

## Review

- [ ] Translation backlog per language reviewed.
- [ ] Unused languages removed safely (see "Removing a translation safely").
- [ ] Search statistics per language read.
- [ ] Number of content languages well below the limit (see "The 62 language limit").

# Main language of an item

This page is for editors and lead editors. Each item has one **main language** (its *initial language*): the language
it was created in, or the one an editor chose later. It is shown where no better translation exists if the item is
always available, and it cannot be removed while it is the main one
([Content languages, section 6](../../../guides/content-languages.md#6-main-language-and-always-available)).

## Seeing the main language

On the item's page the language badges under the buttons show each translation; the main one says *main language*
when you point at it ([Languages (for editors)](../../languages.md)). The **Translations** tab lists the
translations with the main one marked.

## Changing it

1. Open the item's **Translations** tab.
2. In the **Main** column, select the new main language.
3. Press **Set main**.

The new main language must already exist as a translation; translate first if it does not.

## Choosing it in a multilingual body

| Situation | Main language |
|---|---|
| The item was drafted in one language and translated | the drafting language |
| A legal or official text with an authoritative language | that language |
| A content model where one language is the reference for translators | the reference language |

Consistency helps: lists on the language's page in **Setup > Languages** count objects per main language, so you can
see how much content each language originates.

## The authoritative version

Exponential does not mark a translation as legally authoritative. If your rules say one language version prevails,
state it in the text (for example a sentence at the end of each translation) or with a field in the class; the main
language is a technical property, not a legal statement.

# Transparency and freedom of information

This section is for public bodies that publish information proactively and answer requests for information with a
website built with Exponential: managers, records and FOI officers, editors, site builders and administrators. It
describes features and common practice; it is not legal advice, and the rules of your jurisdiction decide what you
must publish and when.

Up: the government help index (README.md one level up) and the landing page government-start-here.md, both in
the government folder.

## Gaps to know about

Exponential has no case management for requests (deadlines, reminders), no redaction tool and no records
management certification. The `unpublish.php` cronjob removes content and is unsuitable for records. Each page says
how to work with these limits.

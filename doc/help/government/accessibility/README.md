# Accessibility for public bodies

This section is for public bodies that run a website with Exponential and must make it accessible: project managers,
accessibility coordinators, editors, designers, developers and administrators. Every statement about the product is
backed by the project's own statement, [Accessibility standards](../../../standards/accessibility.md), whose status
words are kept as written: WCAG 2.2 AA **Partly complies** (admin4 and admin4l administration), EN 301 549 and
Section 508 **Unverified**, public designs not audited, no VPAT or Accessibility Conformance Report, and no
accessibility statement template. This section never claims conformance.

> **Note** This section describes features and common practice; it is not legal advice. Check the law that applies to
> your organization with your legal counsel.

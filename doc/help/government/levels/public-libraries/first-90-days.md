# The first 90 days for public libraries

This page is for project managers and web staff of a library or library network starting a site on Exponential. It
puts what visitors look for most (opening hours, the catalog, events) first. It assumes an installation exists
([Getting started](../../../../guides/getting-started.md)).

## Contents

1. [Days 1 to 30: the basics](#days-1-to-30-the-basics)
2. [Days 31 to 60: events and staff](#days-31-to-60-events-and-staff)
3. [Days 61 to 90: content and launch](#days-61-to-90-content-and-launch)
4. [After launch](#after-launch)

## Days 1 to 30: the basics

| Step | Output |
|---|---|
| List branches with addresses, opening hours, facilities and accessibility | one sheet per branch |
| Get the catalog's search address and sign-in address from the library system supplier | the links the site will use |
| Decide: central calendar or one per branch | a decision ([Structure](structure-sections-and-roles.md)) |
| Decide which staff publish events | a list of events editors |
| Choose a design that has, or can get, event calendar templates | ezwebin has calendar and program views; other designs need templates ([Choosing a design or theme](../../../creators/website-creators/choosing-a-design-or-theme.md)) |

Check: you can sign in to the administration; **Setup > Classes** lists Event and Event calendar.

## Days 31 to 60: events and staff

| Step | Check |
|---|---|
| Create the Branch class and the branch objects ([Content model](content-model.md)) | every branch page shows hours and accessibility |
| Add Branch, Audience and Booking attributes to Event, and update the templates | a test event shows its branch |
| Create the Event calendar and choose its View | the calendar shows the test event |
| Create the Events editor role and group ([Structure](structure-sections-and-roles.md)) | a test editor can only create events |
| Turn on two-step sign-in for staff | the test editor has set it up |
| Tags for audiences and themes | events can be listed by tag ([Tagging with eztags](../../../creators/website-creators/tagging-with-eztags.md)) |

## Days 61 to 90: content and launch

| Step | Read |
|---|---|
| Write service pages in plain language | [Requirements emphasis](requirements-emphasis.md) |
| Enter the next two months of events | [Events and catalogs](events-and-linked-catalogs.md) |
| Train events editors with one real event each | [Editors 101](../../../trainers/editors-101/README.md) |
| Add the catalog search box and links | [Events and catalogs](events-and-linked-catalogs.md#the-catalog-link-it) |
| Test accessibility of the calendar and branch pages | [Testing accessibility](../../../creators/website-creators/testing-accessibility.md) |
| Launch | [Launch checklist](../../../creators/website-creators/launch-checklist.md) |

Checks at launch:

- [ ] A search typed into the site's catalog box opens the catalog's results.
- [ ] Every branch page has opening hours and a closure notice area.
- [ ] Logged out, the calendar shows this month's events in both views you offer.

## After launch

- Weekly: events editors enter new events; the web team checks the calendar for missing places or times.
- Monthly: remove or archive past events; check closures are gone after they end.
- Before holidays: enter holiday opening hours on every branch.

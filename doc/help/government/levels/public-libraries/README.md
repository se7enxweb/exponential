# Public libraries

This folder is for project managers, administrators and website creators at a public library, a community library or
a network of branch libraries. A library website is mostly about opening hours, branches, events and services; the
catalog and the loans live in the library management system, which the website links to. The pages answer what a
library publishes, how to build it in Exponential, which requirements weigh most, how to run the first 90 days, and
how to handle events and the catalog.

Product facts come from the documentation of this repository; descriptions of libraries are general public-sector
practice.

## What sets libraries apart

| Topic | Why it matters |
|---|---|
| Events | story times, reading groups, courses: many small events in many branches |
| The catalog | a separate system with its own search; the website should not copy it |
| Reader privacy | what people read is sensitive; libraries traditionally protect it |
| Many staff, little time | branch staff publish events beside their main work |
| Inclusion | everyone is welcome: languages, literacy levels, disabilities |

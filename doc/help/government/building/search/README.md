# Search

This section is for site builders, administrators and editors who make information findable on a public site built
with Exponential. It covers the engine that ships with the product and the optional Solr server, and says which
features need which.

Up: [Building public-service sites](../README.md), [Governments: start here](../../government-start-here.md).

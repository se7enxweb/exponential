# Multisite

This section is for public bodies that run the sites of several departments, agencies or programs from one
Exponential installation. It explains the shapes such an installation can take, the steps to add a site, and how to
keep departments apart where needed while sharing what should be shared.

Up: [Building public-service sites](../README.md), [Governments: start here](../../government-start-here.md).

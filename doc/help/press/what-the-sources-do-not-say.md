# What the sources do not say

This page is for reporters who want to know where the documented facts end. Every topic below is a real question
that journalists ask, and none of them is answered by the repository, this help, or the public pages it cites. Ask
the organizations, attribute their answers, and say so when there is no answer.

## How to report a gap

```text
Good:  "The project does not publish how many sites use Exponential."
Good:  "Asked about the Foundation's board, a spokesperson for the Foundation said ... (date)."
Good:  "The Foundation did not answer questions about its budget by the time of publication."
Avoid: "An estimated 5,000 sites ..."      (an invented estimate)
Avoid: "The Foundation is secretive about ..."  (the sources only show that it is not published)
```

If you think the documentation should answer a question, open an issue on the
[community tracker](https://github.com/se7enxweb/exponential-community/issues).

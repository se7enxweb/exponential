# Fact-checking checklist

This page is for fact-checkers and editors who need a quick final pass. The method behind it is on the
[Fact-checking guide](fact-checking-guide.md). Copy the list into your notes and tick each line.

## Contents

## The checklist

```text
NAMES
[ ] The product is "Exponential"; no "eZ Publish 6", "Exponential AI", "Exponential Qbix"
[ ] "eZ Publish" appears only in the past tense, as history
[ ] Code identifiers (eZContentObject ...) quoted unchanged

ORGANIZATIONS
[ ] 7x = company; the Exponential Foundation = nonprofit; never "the 7x Foundation"
[ ] No association with eZ Systems or Ibexa implied
[ ] Other companies credited where their work is used

HISTORY AND DATES
[ ] 7x: founded 2001 (as Brookins Consulting); idea 2014; project 2022; launch December 2023
[ ] Rename: August 2025; Foundation: 19 March 2026
[ ] Every "today" or "latest" carries the date checked

RELEASES
[ ] "Released" only for a tagged version; 6.0.15 "in development" until tagged
[ ] Versions written without "v"; sorted by version, not by name

FEATURES
[ ] Exponential Intelligence writes drafts only; never "publishes"
[ ] DXP does not ship the layouts editor; Nexus does
[ ] Velocity is recommended, not required

NUMBERS
[ ] Every number has a method, a source and a date
[ ] No usage, customer or market numbers
[ ] Performance figures keep their conditions; no "faster than X"

QUOTES
[ ] Every quote was really said or written, and is verbatim
[ ] Documentation is not presented as a spokesperson

LICENSES
[ ] Software GPL v2 or later; documentation GFDL 1.3 or later; Velocity MIT
[ ] "Free" explained correctly; no "freeware"

SECURITY AND PRIVACY
[ ] No details of unfixed vulnerabilities
[ ] No personal data, passwords or private host names in text or images

IMAGES AND DISCLOSURE
[ ] Images credited and licensed correctly
[ ] Any relationship, payment or gift disclosed
```

Fix it, attribute it, or cut it. Never publish a claim you could not source as if it were checked
([Common errors in coverage](common-errors-in-coverage.md)).

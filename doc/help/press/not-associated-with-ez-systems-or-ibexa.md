# Not associated with eZ Systems or Ibexa

This page is for journalists who mention eZ Systems or Ibexa in a story about Exponential. The project states plainly
that it is not associated with them. Coverage that suggests otherwise misleads readers and is unfair to all of them.

## The notice

> "This project is not associated with the original eZ Publish software or its original developer, eZ Systems or
> Ibexa"

Published in the [README](https://github.com/se7enxweb/exponential/blob/main/README.md) ("Exponential Project
Notice : 2025.08.12") and on <https://exponential.earth/about/project>.

## What it means for your story

| Do not write | Write |
|---|---|
| "Ibexa's Exponential", "eZ Systems' new CMS" | "Exponential, led by 7x and operated by the Exponential Foundation" |
| "the official successor of eZ Publish" | "a continuation of the eZ Publish code base by 7x" |
| "endorsed by", "in partnership with", "licensed from" Ibexa | (no such relationship is documented) |
| "Ibexa forced the rename" | "renamed at the request of Ibexa, according to the project" |

## Describing the shared history

The facts that connect the names are about **code**, not companies:

- eZ Systems AS developed eZ Publish; its copyright from 1999 to 2014 stays in the code (COPYRIGHT.md).
- The code is under the GNU GPL, which allows anyone to continue it ([Licenses explained for reporters](licenses-explained-for-reporters.md)).
- 7x took over leadership of this code base in 2023 and renamed the product in August 2025
  ([Why it is called Exponential](why-it-is-called-exponential.md)).
- Ibexa's own line went another way: eZ Platform, then Ibexa DXP (README, "What was eZ Platform?").
- The Exponential Platform line continues the free eZ Platform and Ibexa OSS code with its own name
  (Story: Exponential Platform DXP).

```text
"Exponential's code was first developed by eZ Systems as eZ Publish. The project, led by 7x since 2023,
is not associated with eZ Systems or Ibexa."
```

## Comparisons with Ibexa's products

Comparisons are legitimate journalism; make them factual. The documentation compares only what it can source and
does not publish benchmarks against other products ([Comparing Exponential factually](../business/comparing-exponential-factually.md)).
Use the method on [Comparisons done fairly](comparisons-done-fairly.md): same criteria, sources on both sides, the
date, and the other side's own description of its product.

## Asking eZ Systems or Ibexa

If your story makes a claim about eZ Systems or Ibexa, ask them for comment through their own press channels. This
documentation does not speak for them and contains no statements from them beyond the rename request quoted on
[Why it is called Exponential](why-it-is-called-exponential.md).

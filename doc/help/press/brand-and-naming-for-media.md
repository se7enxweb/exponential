# Brand and naming for media

This page is for journalists, sub-editors and creators. It condenses the full
[Brand and naming rules](../business/brand-and-naming-rules.md) to what matters in published coverage. The rules come
from the project's own documentation; where the documentation sets no rule, this page says so.

## The names

| Name | What it is | In print |
|---|---|---|
| **Exponential** | The product | Capital E, no article: "Exponential publishes ..."; "Exponential 6" for the major line; "Exponential 6.0.14" for a release |
| **Exponential CMS** | The same product, where "content management system" helps an outside reader | Fine at first mention; announced by the project as "'Exponential' or 'Exponential (CMS)'" |
| **7x** | The company that leads Exponential | Digit 7, lowercase x |
| **the Exponential Foundation** | The nonprofit that operates and funds the project | "the Foundation" after the first mention |
| **Exponential Velocity**, **Exponential Intelligence**, **Exponential Layouts** | Products of the family | "Velocity", "Exponential Intelligence", "the layouts editor" after the first mention |
| **Exponential Platform** (3.2.9, Legacy, Nexus, DXP) | The Symfony line | Name the distribution: "Exponential Platform DXP" |

Full family: [The product family for reporters](the-product-family-for-reporters.md).

## The former name

The code base was developed as **eZ Publish**, a product its creator discontinued after almost 18 years. Use that
name only in the past tense, as history: "built while the software was still called eZ Publish". Never as a current
or second name, never in a product title, never as "eZ Publish 6". See
[Writing about the eZ Publish years](writing-about-the-ez-publish-years.md).

Exponential is not associated with eZ Systems or Ibexa; never suggest a partnership, endorsement or succession of
companies ([Not associated with eZ Systems or Ibexa](not-associated-with-ez-systems-or-ibexa.md)).

## Code names are not product names

You will see `eZ` in the code: `eZContentObject`, `eZINI`, `bin/php/ezcache.php`, packages such as `ezwebin`. These are
real identifiers and stay as they are. When you quote code, quote it exactly; when you name the product, write
Exponential. Package names are written in code style and lowercase: `expai`, `explayouts`.

## Taglines

The documentation sets no slogan. Two taglines appear on the project website (read 18 October 2026); if you quote
one, quote it as the project's own words with the source:

|---|---|

| "Exponential is the CMS for Power Users and AI Agents" | <https://exponential.earth/> |

## What the brand rules do not decide

The documentation does not set rules for trademark status, logo clear space or sizes beyond the press kit's four
guidelines, or for describing partners as "official" ([Brand and naming rules](../business/brand-and-naming-rules.md#what-the-sources-do-not-decide)).
The press kit's guidelines are on [Logos and brand assets](logos-and-brand-assets.md).

## An editor's checklist

- [ ] "Exponential", capital E, no article; versions in full without "v".
- [ ] "eZ Publish" only in the past tense, as history.
- [ ] No link to eZ Systems or Ibexa implied.
- [ ] 7x and the Exponential Foundation kept apart.
- [ ] Code identifiers quoted unchanged.
- [ ] Other companies credited by name.
- [ ] American English spelling: license, color, behavior.

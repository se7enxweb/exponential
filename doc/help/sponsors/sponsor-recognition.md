# How sponsors are recognized

This page is for sponsors who want to know how their support is shown. Values as listed on 18 October 2026; the live
GitHub pages are authoritative.

## By tier

| Recognition | 7x (se7enxweb) | The Foundation (exponentialcms) |
|---|---|---|
| Sponsor badge on your GitHub profile | From $2 a month | From $5 a month |
| Shoutout on social media | $10 one time | $10 one time |
| Weekly newsletter | – | $10 a month |
| Logo or name in the project README | $250 a month | $25 a month |
| Logo or name on the project website | – | $100 a month |
| Release notes | – | $50 one time ("Earn a mention in our Release notes") |
| Release announcement and documentation | $99 a month ("Sponsor the next release ... included in the official release announcement and in the official related documentation") | – |
| Mentions on X.com, Instagram, the community portal, LinkedIn | Named in the listing's "What we offer to sponsors" | – |

## Public or private

"You can choose whether to display your sponsorship publicly. One-time sponsorships remain visible for one month"
(GitHub Docs, <https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes>).
Choose private if you do not want to be listed; recognition in a README or on a website is then arranged with the
organization.

## The project's sponsor page

"Sponsors take advantage of inside access to 7x Team and get their features considered and their company products
promoted. Want your name, business or organization name listed one of the first Exponential Sponsors ... Contact us
at community@exponential.earth" (<https://exponential.earth/about/project/sponsors>).

## What to send

For a README or website listing, send the organization your preferred name, a logo file you have the right to use,
and the link. This help names no sponsors; listings are kept by the organizations.

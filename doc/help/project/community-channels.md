# Community channels: where Exponential people meet

The project website's [community page](https://exponential.earth/about/community) lists the "activity centers" of
the Exponential community. This page collects them and says what each is for, as of October 2026. Where the website
gives two different invitation links for one chat, this page uses the one that worked when it was written.

## Talk: forums and chats

| Channel | What it is for | Address |
|---|---|---|
| **Share Exponential forums** | The main place for questions, answers, announcements and discussions that others should find later. Also articles, blogs and tutorials. | <https://share.exponential.earth/forums> |
| **Telegram**, "Support Exponential (CMS)" | Real-time chat about Exponential, PHP, design and support. The project calls it a key support channel, with members of the development team in it. | <https://t.me/exponentialcms> |
| **Discord**, server "Exponential" | Community chat, development discussion, feedback and feature ideas | <https://discord.gg/zXzGMgfzej> |
| **Slack**, workspace "exponentialcms" | Chat, especially for development | <https://exponentialcms.slack.com/> |

All of them are free. For a question that needs a long answer, prefer the forums: a chat scrolls away, a forum thread
stays searchable. How to ask well: [Getting support](getting-support.md#how-to-ask-so-you-get-an-answer).

## Build: code, issues and extensions

| Place | What it is for | Address |
|---|---|---|
| **Exponential on GitHub** | The kernel's source, releases, pull requests | <https://github.com/se7enxweb/exponential> |
| **Issue tracker for the software** | Errors and feature requests for the kernel, the administration and the bundled extensions | <https://github.com/se7enxweb/exponential/issues> |
| **Issue tracker for the project** | The websites, the content, the ecosystem, the community: everything that is not an error in a piece of software | <https://github.com/se7enxweb/exponential-community/issues> |
| **The se7enxweb organization** | The extensions, tools and distributions maintained by 7x; also listed at [software.se7enx.com](https://software.se7enx.com/) | <https://github.com/se7enxweb> |
| **Exponential Projects** | The project forge: thousands of extensions, designs and other projects, with news, downloads and source links | <https://projects.exponential.earth/> |
| **GitLab** | A 7x presence on GitLab, linked from the website's footer | <https://gitlab.com/se7enx> |

The community page also points to older GitHub organizations that keep extensions from earlier years:
[brookinsconsulting](https://github.com/brookinsconsulting?tab=repositories),
[ezpublishlegacyprojects](https://github.com/ezpublishlegacyprojects?tab=repositories) (community extensions),
[ezpublishlegacy](https://github.com/ezpublishlegacy?tab=repositories) (a mirror project) and
[ezecosystem](https://github.com/ezecosystem?tab=repositories) (bundles for the Symfony platform). Treat what you
find there as ideas: check its license, its age and whether a maintained fork exists
([Evaluating an old extension](../extension-development/part-1-from-user-to-developer/evaluating-an-old-extension.md)).

## Try: the demo

The website's community page offers a public demo of the latest Exponential 6 with the 7x Simple design and a shop:
the site at [demo.exponential.earth](https://demo.exponential.earth/) and its administration at
[edit.demo.exponential.earth](https://edit.demo.exponential.earth/). The sign-in details are on the
[community page](https://exponential.earth/about/community). Everything in the demo is reset every day.

## Which channel when

| You want to | Use |
|---|---|
| Ask how to do something | The forums, or Telegram for a quick question |
| Report an error in the software | The [software issue tracker](https://github.com/se7enxweb/exponential/issues) ([how](../when-something-goes-wrong.md#filing-a-bug-in-exponential)) |
| Report a security problem | Privately, never in a channel ([how](../when-something-goes-wrong.md#security-problems)) |
| Suggest a feature | The [community roadmap](https://share.exponential.earth/community-roadmap) or an issue ([The roadmap](roadmap.md)) |
| Find an extension | Exponential Projects and the se7enxweb organization |
| Share your extension | [Contribute extensions back](../contribute-extensions-back.md) |
| Talk about development | Discord, Slack, or a pull request |
| Report a problem with a project website | The [project issue tracker](https://github.com/se7enxweb/exponential-community/issues) |

Wherever you are, the usual courtesy applies: be patient, be kind, and never post passwords or other people's
personal data. Advocates who represent the project in these channels have their own guidance in
[the advocates' section](../advocates/advocate-toolkit.md).

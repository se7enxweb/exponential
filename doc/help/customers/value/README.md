# Getting value from your site

This section is for organizations that already run a site on Exponential and want to know, and grow, what it gives
them. It is for the owner, the manager who answers for the budget, and whoever talks to the host or partner. The
pages that help you decide whether to choose Exponential are in the businesses section
([Total cost of ownership](../../businesses/costs/total-cost-of-ownership.md),
[ROI worksheet template](../../businesses/templates/roi-worksheet-template.md)); here you measure and improve a site
that is already yours.

## Three facts behind the value

| Fact | Source |
|---|---|
| "Using Exponential under the terms of the GNU GPL is free of charge." No license fee is part of your running cost. | `README.md`, "License" |
| Exponential 6.0 is the maintained line; security fixes are published with the next 6.0.x release, and a published tag is never changed. | `SECURITY.md` |
| Shop, multi-site, multilingual content, workflows, feeds, contact forms and a REST API are built in. | `README.md`, "Main Exponential features" |

> **Note**
> Every number on these pages that is not a fact from the repository is marked "Example assumptions: replace with
> your own". None of them is a price, a quote or a measurement of your site.

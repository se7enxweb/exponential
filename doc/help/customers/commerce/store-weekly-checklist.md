# Store weekly checklist

This page is a checklist for one fixed slot a week, for example Monday morning. The store manager works through
it; the owner reads the result. Copy it and tick it off; keep the filled copies for a few weeks so trends are visible.
The daily routine is on [Daily store routine](daily-store-routine.md).

## The checklist

```text
STORE WEEKLY CHECKLIST - week of __________     Done by: __________

DASHBOARD (Store, shop/dashboard)
[ ] Orders and revenue for 7 days compared with the week before: up / flat / down
[ ] Open orders, and orders waiting too long: ______
[ ] Abandoned baskets: higher than usual? Any change last week that explains it?
[ ] Best sellers: are they on the home page, in menus and in the newsletter?
[ ] "Next steps": anything new? Passed to: __________
[ ] Payment failed orders this week: ______  (several in a row: tell the partner)

ORDERS
[ ] No order older than your handling time in a "new" status
[ ] Completed orders older than the returns period archived (shop/archiveorder)
[ ] Return requests and returned goods handled (see Returns and refunds)
[ ] Test orders of the week canceled or removed

CATALOG
[ ] Products without a price: none (dashboard)
[ ] Sold-out products hidden or marked; returned stock shown again
[ ] New products since last week checked for price, VAT type and images

PAYMENTS AND MAIL
[ ] Payments in the provider's account match paid orders
[ ] Refunds made this week are on the orders (Refunded / Partially refunded)
[ ] The shop's copies of order mails arrived every day

CUSTOMERS
[ ] Customer questions of the week answered; repeated questions noted for the FAQ
[ ] New customer accounts and registrations look genuine

THE WEEK AHEAD
[ ] Promotions starting or ending this week, with a named person each
[ ] Who covers if the usual person is away
[ ] Notes for the owner: ____________________________________________
```

## Where each item is done

| Item | Where | Read |
|---|---|---|
| Dashboard figures, Next steps | **Store** | [Store reports](store-reports.md) |
| Archiving | **Store > Orders**, then archive | [Orders day to day](orders-day-to-day.md) |
| Returns | Order view, status change | [Returns and refunds](returns-and-refunds.md) |
| Products without a price, products overview | **Store**, **Store > Products overview** | [Products and catalog](products-and-catalog.md) |
| Payments | The provider's account | [Payment gateways](payment-gateways.md) |
| Order mail | The `AdminEmail` mailbox | [Order confirmation mail](order-confirmation-mail.md) |
| Promotions | **Store > Discounts** | [Discounts](discounts.md) |

## Things that are not weekly

Some checks belong to the month or the year: VAT ([VAT checklist](vat-checklist.md)), month figures
([Store monthly checklist](store-monthly-checklist.md)), retention ([Data export and erasure](data-export-and-erasure.md)).
Logs and server checks are the host's; ask them for a weekly summary if you want one
([Log viewer](../../../features/6.0/log-viewer.md)).

> **Tip**
> If the checklist takes much longer than half an hour, the daily routine is probably being skipped. Fix that first.

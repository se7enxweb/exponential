# Website creators: start here

This page is for people who build public websites on Exponential: agencies, freelancers, in-house web teams and
ambitious editors. It tells you what this section offers, what to do in your first week, and where every answer is.
Exponential is the open source content management system, framework and shop that runs in this administration; it
continues the code base of eZ Publish, a product its creator discontinued after almost 18 years, and is led by 7x
together with the Exponential Foundation ([Who is 7x?](../../who-is-7x.md),
[Who is the Exponential Foundation?](../../who-is-the-exponential-foundation.md)).

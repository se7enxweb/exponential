# Bootcamp 3.1: The three-day editor bootcamp

Three days give editors time to practise each task until they can do it without the handout. The bootcamp covers
the whole of [Editors 101](../../editors-101/README.md) in condensed form and adds translation and a first look at
layouts.

## At a glance

| | |
|---|---|
| Course | [Workshops and bootcamps](../README.md) |
| Module | [Module 3: Three-day bootcamps](README.md) |
| Duration | 3 days, 6 hours of sessions each |
| Level | Beginner |
| Audience | New editors, 6 to 16 learners |
| Prerequisites | Learner accounts on a shared site (role limited to own folder) or one installation per learner |

## Learning objectives

At the end of the bootcamp, learners can:

- create, edit, publish, preview, compare, hide and restore content;
- write rich text with links, headings, tables and images with alternative text;
- find content and work from the dashboard, drafts and bookmarks;
- translate an item into a second language;
- place blocks in a layout and publish it.

Breaks: 15 minutes mid-morning and mid-afternoon, 45 minutes lunch, each day.

## Trainer's notes

- **Day 1 sets the pace.** Keep it slow; the rest builds on it.
- **Translations** need a second language on the training site; check before the bootcamp.
- **Layouts on a shared site**: learners create their own layouts but do not change mappings.
- **Repeat each core task each day**: start days 2 and 3 with a five-minute "create and publish" warm-up.

## Hands-on exercise: the bootcamp capstone

Each learner builds a small section "Bike Day 2027" in their folder:

1. A folder with an intro; three articles (program, location, registration) with headings, links between them and
   one image each with alternative text.
2. One article translated into the second language.
3. A second version of the program article, compared with the first.
4. A layout with a Title block and a Rich text block, published.

## Expected result

- The section exists with three articles, one translation, two versions of the program and a published layout.
- Each learner presents their section in two minutes on day 3.

## Quiz (end of bootcamp)

1. How do you bring back an item you removed?
2. What is the difference between hiding and removing?
3. Where do you choose the language before editing a translation?
4. What does **Discard** do in the layouts editor?

<details>
<summary>Answers</summary>

1. Restore it from the trash ([Publishing, versions and the trash](../../../publishing-and-versions.md)).
2. A hidden item stays in place but is not shown to visitors; a removed item goes to the trash.
3. In the language list next to **Edit**.
4. Throws the draft away after you confirm, and closes the editor ([The layouts editor](../../../layouts-editor.md)).

</details>

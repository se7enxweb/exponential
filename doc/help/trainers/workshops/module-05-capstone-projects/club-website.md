# Project 5.1: A club website

A capstone project lets learners use everything from a workshop at once, on something that looks like real work. This
brief fits the end of the [editor bootcamp](../module-03-three-day-bootcamps/editor-bootcamp.md) or the
[site builder bootcamp](../module-03-three-day-bootcamps/site-builder-bootcamp.md).

## Learning objectives

Learners show that they can:

- plan and build a small site structure;
- create, link, illustrate and publish content;
- (site builders) define a content class and compose a landing page from blocks;
- check their own work against a list before they hand it in.

## The brief

> The invented "Riverside Cycling Club" needs a small website. It must have a home page, a News section with three
> news items, an Events section with two events, a Teams section with two teams, and a Contact page. Every item has an
> image with alternative text where an image fits. The home page shows the latest news and the next event.

| Part | Editors | Site builders |
|---|---|---|
| Structure | Folders Home, News, Events, Teams, Contact | The same, planned on paper first |
| Content types | Use existing types (Article, Folder) | Add a class "Team" (name, coach, training times, photo) |
| Home page | An article with links to the sections | A layout with a Title block, a news list and an events list |
| Language | Optional: one news item translated | One news item and the home page translated |

All names, people and addresses are invented. No real persons' photos.

## Trainer's notes

- **Give the brief, not the steps.** The workshop lessons were the steps; this is the test of them.
- **Self-check** at the end with the checklist in **Expected result** before the trainer looks.
- **Pairs** may split the work (one structure and home page, one content), then review each other.

## Hands-on exercise

1. Plan the structure on paper (15 minutes).
2. Build the folders and, for site builders, the class "Team".
3. Create the content: three news items, two events, two teams, the contact page.
4. Build the home page (an article or a layout).
5. Add images with alternative text; link items to each other.
6. Translate where the brief asks.
7. Run the self-check, fix, and present the site in three minutes.

## Expected result

Self-check and scoring rubric (each criterion 0, 1 or 2 points):

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Structure | Sections missing | All sections, some misplaced items | All sections, every item in place |
| Content complete | Fewer than half | Most items | All items with intro and body |
| Images and alternative text | None | Some images, alt text missing | Every image has a meaningful alt text |
| Links | None | Some links | Home links every section; items link to each other |
| Published and versioned | Drafts left | Published | Published, and at least one item has two versions |
| Home page | Missing | Static text | Shows the latest news and the next event (site builders: layout with lists) |

A pass is 8 of 12 points; the rubric is the trainer's own and claims no official status.

## Quiz

1. Why plan the structure on paper first?
2. What makes alternative text "meaningful"?
3. What is the fastest way to make the home page show the latest news (site builders)?

<details>
<summary>Answers</summary>

1. Moving items later costs time and can break links; a plan shows missing sections early.
2. It says what matters in the image for the page, not "image" or a file name.
3. A list block in the home page's layout ([The layouts editor](../../../layouts-editor.md#add-a-block)).

</details>

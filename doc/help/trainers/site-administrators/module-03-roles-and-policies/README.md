# Module 3: Roles and policies

Roles decide what everyone may do, from the anonymous visitor to the administrator. In this module learners read
roles as sentences, build a role of their own with limited policies, assign it to a group in one subtree, test it
with a test account, and make a deliberate change to what the public may do.

## Preparing this module

- The training installations from Modules 1 and 2, with the group `Training team` and the users from Module 2.
- Learners need a browser with a private window (or a second browser) to sign in as test users.
- Rehearse lesson 3.2 on your own installation: the limitations the wizard offers for `content/edit` (Owner *Self*)
  depend on the version; adjust step 6 if needed.
- Check whether your site package opens registration from the start (lesson 3.5).

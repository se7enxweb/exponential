# Module 2: Users and groups

Who may sign in, in which group, with which password, and what happens when someone leaves: this module covers the
whole life of a user account. Learners create a group and accounts at `example.invalid`, reset passwords and unlock
accounts, clean up accounts nobody uses, and hand content over from one user to another.

## Preparing this module

- Each learner's training installation from Module 1, with an administrator account and a terminal in the root.
- Check on your own installation which user groups the site package creates and whether the public site offers
  registration (lesson 2.4, step 1); adjust the exercises if they differ.
- Check that **Change owner** is in the context menu (the extension ezownerchange is active) for lesson 2.5.
- A list of passwords of at least 10 characters for the test accounts, or a password manager per learner.
- Every address in the exercises is at `example.invalid`. Mail on a training installation stays in files.

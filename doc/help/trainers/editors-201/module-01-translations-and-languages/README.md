# Module 1: Translations and languages

Many sites publish in more than one language. This module teaches editors and translators how translations work in
Exponential: one item, several languages, each published on its own.

## At a glance

| | |
|---|---|
| Course | [Editors 201](../README.md) |
| Duration | 2 hours 10 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 1.1: Content languages and translations](content-languages-and-translations.md) | 30 minutes | Read badges and the Translations tab; tell content from interface language |
| [Lesson 1.2: Translating an item](translating-an-item.md) | 45 minutes | Add a translation based on another, publish it, edit one language |
| [Lesson 1.3: Main language, always available and removing a translation](main-language-and-removing-translations.md) | 45 minutes | Set main, read always available, fix content created in the wrong language |

## Preparing this module

- The training installation needs a second content language. As an administrator: **Setup > Languages**, **Add
  language**, choose it, **Add language** ([Content languages](../../../../guides/content-languages.md#4-adding-a-language)).
  Adding a language translates nothing and shows nothing new to visitors by itself.
- For lesson 1.1's step 8, a siteaccess that shows the second language (its `SiteLanguageList`), or skip that step
  ([section 5 of the guide](../../../../guides/content-languages.md#5-showing-a-language-sitelanguagelist-and-siteaccesses)).
- One published article in both languages for lesson 1.1.
- The learners' role must allow editing and creating in both languages. Decide whether it may remove translations
  (lesson 1.3, step 10); otherwise demonstrate that step.

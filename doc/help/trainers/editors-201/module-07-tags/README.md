# Module 7: Tags

Tags connect content across the tree by topic. This module covers tagging for every editor and the tag tree for the
editors who maintain it. Run it on sites that use the Tags extension (eztags).

## Preparing this module

- The training installation needs eztags and a tags field on the *Article* type: as an administrator, **Setup** >
  **Classes**, edit *Article*, add a tags attribute and choose its edit view
  ([eztags: Use it](../../../../features/6.0/extensions/eztags.md#use-it)). Allow new tags in the field if you want
  learners to try **Add new**.
- On the **Tags** dashboard, create a few tags (for example *Training*, *Events*, *Climate*) and two duplicates for
  the merge demonstration.
- Give the learners' role the `tags` policies for read, dashboard and add (and edit for lesson 7.2), or plan to
  demonstrate lesson 7.2.
- Know your site's tag page address (`eztags.ini [GeneralSettings] URLPrefix`, `tags/view` by default).

# Module 4: Object states

Object states are stages a site defines for its content. Not every site uses them; on those that do, editors set
them every day. Run this module when your learners' site uses states, or as a short look at what is possible.

## Preparing this module

- As an administrator, create a state group for reviews with three states (for example *Draft*, *In review*,
  *Approved*) under **Setup** > **States** ([Creating a group and its states](../../../../guides/object-states.md#4-creating-a-group-and-its-states)).
  Set existing public content to the approved state first, or it disappears for visitors.
- Set up the roles of the guide's review example on the training installation: visitors read only approved content,
  authors edit only their drafts and may set *In review*, reviewers may set the other states
  ([the example](../../../../guides/object-states.md#9-a-worked-example-a-review-workflow)).
- Two kinds of training accounts: authors and reviewers, so learners can work in pairs.
- Learners work in the administration: the Editor siteaccess does not offer the state pages.
- After the course, remove the group or set it back, so the next class starts clean.

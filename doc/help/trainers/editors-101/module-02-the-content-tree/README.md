# Module 2: The content tree and navigation

Before editors change anything, they must find it. This module makes learners at home in the content tree and on an
item's page. Nothing in it changes content, so it is a safe module to run even on a shared training site.

## At a glance

| | |
|---|---|
| Course | [Editors 101](../README.md) |
| Duration | 2 hours 10 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 2.1: The tree and an item's page](the-tree-and-an-items-page.md) | 45 minutes | Open folders and items in both trees, read an item's page |
| [Lesson 2.2: An item's tabs and its sub items](tabs-and-sub-items.md) | 45 minutes | Use the tabs, sort and page the Sub items list, choose columns |
| [Lesson 2.3: Getting around fast](getting-around-fast.md) | 30 minutes | Use the Content finder, the item menu and the keyboard |

## Preparing this module

- The learners' Editor accounts from module 1.
- On the training site: at least one folder with ten or more items (an image folder of the media library works),
  an article with a known node number, and a published article whose address learners can copy from the site.
- Write the path of the media library's image folder on the board if it is not `media/images`.

# Module 5: Images and media

Every site needs images and files, and every image needs a good alternative text. This module shows where files
live, how to upload many at once, and how an article gets its main image.

## At a glance

| | |
|---|---|
| Course | [Editors 101](../README.md) |
| Duration | 2 hours 25 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Beginner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 5.1: The media library](the-media-library.md) | 30 minutes | Explore the library's folders, read an image item and its relations |
| [Lesson 5.2: The upload page](the-upload-page.md) | 60 minutes | Upload three images with titles and alternative texts, as drafts, then publish them |
| [Lesson 5.3: Images in articles and alternative text](images-in-articles-and-alternative-text.md) | 45 minutes | Link an existing image, upload one from the form, improve its alternative text |

## Preparing this module

- Four small sample images per learner (neutral subjects such as landscapes or objects, no people), on each
  computer or on a shared drive. Keep them under a few megabytes each.
- Learners' course folders must accept images: check that **Upload** on a course folder shows *Uploads allowed*.
- Find out where your training installation puts images uploaded from the edit form, so you can show it in lesson
  5.3.
- If you want to show the required alternative text, switch on **Alternative text is required** for the image
  class's image field on the training installation before the class
  ([how](../../../../guides/content-model-and-editing.md#alternative-text-is-required-image-fields)).

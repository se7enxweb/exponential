# Module 3: Designing a course

The courses in this help are a starting point. Every organization needs its own mix: a shorter editor day, an
intranet administrator course, an online version. This module teaches trainers to design such courses with the same
care: clear objectives, a sensible order, a timetable that holds and exercises that work.

## Preparing this module

- A training installation per learner (Module 2) for the rehearsal in lesson 3.4.
- Paper cards or a shared document for the course design in lesson 3.2.
- Optional: a GitHub account per learner for lesson 3.5.
- A video-call tool for the screen-sharing test of lesson 3.6.

# Lesson 6.2: Quizzes and practical tasks

Some courses end with an assessment: an employer wants to know who can now publish, or a learner wants proof of a
skill. This lesson shows how to build a fair end-of-course assessment from the lessons' objectives, with written
questions, a practical task and a rubric.

> **Note**
> The Exponential Partner Program names certifications for partner teams, but their syllabus, exams and examiners
> are not published ([Certifications](../../../partners/certifications.md)). Any assessment you run is your own;
> present it as such.

## Learning objectives

After this lesson, learners can:

- write written questions with an answer key that cites a help page;
- design a practical task on a training installation with a checkable result;
- write a rubric with three to four levels per criterion;
- state clearly that the assessment is their own.

## Trainer's notes

### How to present it

1. Alignment (5 minutes): each question or task checks one objective of the course; no surprises.
2. Written questions (4 minutes): multiple choice or short answer; each answer in the key cites the page that proves
   it, as the quizzes in these lessons do.
3. Practical tasks (4 minutes): a task done on a training installation, with a result the trainer can check (an item
   exists, a role is assigned, a page shows a change).
4. Rubric (2 minutes): criteria in rows, levels in columns (for example: not yet, partly, fully).

### Common questions

**Can I reuse the lesson quizzes?** Yes, as practice. For a final assessment write new questions on the same
objectives, so it measures ability, not memory of the quiz.

**What pass mark?** Decide before the course and tell learners.

### Pitfalls

- **Trick questions.** They measure attention, not skill.
- **Tasks that depend on the trainer's installation.** Every learner needs the same starting state.
- **Calling it a certification.** Do not.

## Hands-on exercise

Build the assessment for Module 2 of this course.

1. List the objectives of lessons 2.3, 2.4 and 2.5.
2. Write four new written questions on them, with an answer key that cites a page.
3. Write one practical task, for example: "Install a site on SQLite with the title 'Assessment', serve it on port
   8095, create a user `assess01` with an address at `example.invalid` in the Editors group."
4. Write a rubric with three criteria (install, serving, account) and three levels.
5. Write the first line of the assessment sheet that says it is your own assessment.

## Expected result

- Four questions with a cited key, one practical task and a three-by-three rubric.
- The sheet's first line names the trainer or organization as the author and claims no official status.

## Quiz

1. What should every assessment question check?
2. What should every answer in the key include?
3. Why write new questions rather than reuse the lesson quizzes?
4. May you present your assessment as an official Exponential certification?

<details>
<summary>Answers</summary>

1. One objective of the course.
2. A citation of the help page that proves it.
3. To measure the skill rather than memory of the quiz.
4. No. It is your own assessment; the partner program's certifications are separate and their details are not published ([Certifications](../../../partners/certifications.md)).

</details>

# Module 1: Introducing Exponential Intelligence

Before anyone sends a request, learners need to know what the assistant is, what it promises and who may use it.
Nothing in this module sends a request to a provider.

| [Lesson 1.2: The Exponential Intelligence dashboard](the-exponential-intelligence-dashboard.md) | 45 minutes | Read the dashboard without sending anything |

## Preparing this module

- A training installation with expai activated and configured by an administrator (see module 7 and the extension's
  installation guide), with a provider account meant for training or a local model.
- One account per learner with `expai/write` and `ezjscore/call`, plus `expai/vector` and `expai/chain` if you will
  teach modules 4 and 5; e-mail addresses at `example.invalid`.
- Learners work in the administration; check whether your Editor siteaccess offers the expai pages your learners need.
- Set a low usage limit for the training accounts (module 7, lesson 7.2) before the course.

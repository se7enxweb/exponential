# Module 5: Shared layouts and zone linking

One header, one footer, many pages. This module teaches how layouts borrow zones from shared layouts and how to change
shared content without surprises.

## At a glance

| | |
|---|---|
| Course | [Exponential Layouts](../README.md) |
| Duration | 2 hours 10 minutes (with a 10-minute break) |
| Lessons | 3 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 5.1: What shared layouts are](what-shared-layouts-are.md) | 30 minutes | Read the Shared layouts screen, recognize linked zones |
| [Lesson 5.2: Linking and unlinking zones](linking-and-unlinking-zones.md) | 45 minutes | Link header and footer of the course layout, change and remove a link |
| [Lesson 5.3: Changing shared content safely](changing-shared-content-safely.md) | 45 minutes | Change a training shared layout once and see every linking layout follow |

## Preparing this module

- A published shared header/footer layout on the training site (the sample data usually has one; the **Shared
  layouts** screen lists it).
- For lesson 5.3, a separate published shared layout `Training footer` (type `layout_1`, one rich text block), so
  nobody practices on the real footer. Find out how your installation marks a new layout as shared (the create form's
  **Shared layout** option where it exists); see [Shared layouts: Build it](../../../creators/website-creators/shared-header-and-footer.md#build-it).
- The learners' course layouts from modules 2 to 4.

# Module 1: Designing assessments

This module is the method. It shows how the written tests, practical tasks and capstone projects in Modules 2 to 6
are built, so a trainer can use them as they are, adapt them, or write new ones for their own courses. It ends with
the certificate a trainer may issue, in their own name, to a learner who passed.

> **Note**
> Everything in this course is the trainer's own assessment, not an official certification; the partner program's
> certifications are separate and their details are not published
> ([Certifications](../../../partners/certifications.md)).

## Preparing this module

- [ ] One training installation per learner, installed as in
      [One installation per learner](../../train-the-trainer/module-02-building-the-lab/one-install-per-learner.md),
      with the mail transport set to `file`.
- [ ] One learner account per person, at `example.invalid`, for lessons 1.4 and 1.5.
- [ ] The course objectives of one course the group teaches, printed (for lesson 1.1).
- [ ] [Publishing, versions and the trash](../../../publishing-and-versions.md) open for lessons 1.2, 1.3 and 1.6.
- [ ] Browsers that can zoom to 200 percent, for lesson 1.4.
- [ ] A text editor or word processor for the certificate in lesson 1.7.

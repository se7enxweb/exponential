# Lesson 1.4: Accommodations in assessment

An assessment measures one skill. Everything else, how fast someone reads, whether they use a mouse, how well they
read English, should not decide the result. Accommodations change the conditions so that the skill can show, and
leave the skill itself unchanged.

> **Note**
> Ask about needs privately, use the answers only to plan the assessment, and delete them after the course. Do not
> ask for a reason or a diagnosis.

## Learning objectives

After this lesson, learners can:

- tell an accommodation (changes the conditions) from a change of the assessed skill;
- offer the common accommodations for written tests and practical tasks;
- prepare the training installation so that keyboard, zoom and color mode work for the practical task;
- handle needs information without keeping it longer than the course.

## Trainer's notes

### How to present it

1. **The rule** (3 minutes). "Change the conditions (time, format), not the skill being measured"
   ([Accommodations and inclusive practice](../../train-the-trainer/module-05-accessibility-and-inclusion/accommodations-and-inclusive-practice.md)).
   If the objective is "publish an article", extra time is an accommodation; doing the task for the learner is not.
2. **Written tests** (4 minutes). Extra time (a common choice is a quarter or half more); the test as a document the
   learner's screen reader or zoom can read rather than only on paper; larger print; a separate quiet room; questions
   read aloud; answers typed instead of handwritten; a dictionary for learners working in a second language.
3. **Practical tasks** (5 minutes). The administration's Admin 4 design can be used with the keyboard alone, at a
   large zoom and in dark mode
   ([Teaching with the accessible administration](../../train-the-trainer/module-05-accessibility-and-inclusion/teaching-with-the-accessible-administration.md),
   [Keyboard shortcuts](../../../keyboard-shortcuts.md)). Let learners set up their own preferences before the clock
   starts. Give breaks at least every hour.
4. **Language** (3 minutes). If the administration can be shown in the learner's language, allow it, and accept
   answers that name buttons in that language
   ([Languages](../../../languages.md#the-language-of-the-administration)).

### Common questions

**Is extra time unfair to the others?** No. The test measures the skill, not speed, unless speed is the objective.
If it is, say so in the rules.

**What if the accommodation changes the task?** Then it is not an accommodation. Find another route to the same
objective: a learner who cannot drag a block in the layouts editor can show the same result another way only if the
objective is the result, not the drag.

**Who decides?** The learner says what helps; the trainer checks that the skill stays the same.

### Pitfalls

- **Asking in front of the group.** Ask in the pre-course message or privately.
- **Forgetting the lab.** A learner who needs 200 percent zoom must have tested it on the training installation before
  the assessment, not during it.
- **Keeping the list.** Delete needs information after the course, together with the other course records you do not
  need.

## Hands-on exercise

Prepare the accommodations for a practical task on your training installation.

1. Write the pre-course question: "Do you need any arrangements for the assessment? Examples: extra time, a quiet
   room, a large screen, keyboard only." No reason asked.
2. Sign in to the training installation with a learner account (at `example.invalid`).
3. Set the browser zoom to 200 percent and open the dashboard. Note anything that does not fit.
4. Switch the color mode to dark with the header button and back.
5. Press **Tab** once and check that **Skip to main content** appears; press `/` and check that the search field
   takes the focus.
6. Open the course folder and reach **Create new** with the keyboard only.
7. Write the conditions you would offer for this task: extra time, breaks, zoom, keyboard.
8. Write the sentence that explains how needs information is deleted after the course.

## Expected result

- A pre-course question without a request for reasons.
- A checklist of what works on the training installation at 200 percent zoom, in dark mode and with the keyboard.
- A list of accommodations for the task, each of which leaves the assessed skill unchanged.
- The trainer asks two learners to show step 6 on the projector.

## Quiz

1. What is the rule for every accommodation?
2. Which is an accommodation for "publish an article"? A. the trainer publishes it B. 50 percent extra time C.
   skipping the required fields D. a shorter article without Intro
3. When should a learner who needs a large zoom test it?
4. What do you do with needs information after the course?
5. Which key moves the focus to the search field of the administration?

<details>
<summary>Answers</summary>

1. Change the conditions, not the skill being measured
   ([Accommodations and inclusive practice](../../train-the-trainer/module-05-accessibility-and-inclusion/accommodations-and-inclusive-practice.md)).
2. **B.** The others change or remove the skill.
3. Before the assessment, on the same training installation.
4. Delete it; keep it no longer than the course.
5. `/`, when the focus is not in another field ([Searching](../../../searching.md#the-quick-search)).

</details>

# Tracking your contributions

This page is for advocates who want to see what they have done. A contribution log helps you plan
([A 90-day advocate plan](a-90-day-advocate-plan.md)), shows your work when you want to (a portfolio, a job
application), and helps whoever continues when you step back.

## What to log

| Kind | Log |
|---|---|
| Answers | Link to the forum post |
| Posts, tutorials, videos | Link, date, topic |
| Talks and demos | Event, date, slides link (no attendee names) |
| Pull requests | Link, what it changed |
| Translations | Language, number of strings, pull request |
| Issues reported or confirmed | Links |
| Events organized | Date, format, summary post link |
| Newcomers mentored | Their first pull request link (public), not personal details |

## The log template

```text
CONTRIBUTION LOG                                        <your name or handle>

| Date       | Kind         | What                                    | Link                     |
|------------|--------------|-----------------------------------------|--------------------------|
| 2026-10-20 | answer       | How to translate an item                | <forum link>             |
| 2026-10-22 | pull request | Fixed: layouts help names Discard       | <github link>            |
| 2026-10-28 | talk         | Lightning talk, <group>                 | <slides link>            |
```

Keep it as a text file, a spreadsheet or a private note; it is yours.

## Finding your public contributions

- GitHub lists your pull requests and issues (search `author:<you>` in the se7enxweb repositories).
- In a clone: `git log --author="<your name>" --oneline`.
- Your forum profile lists your posts.

## Privacy

Log links and your own work, not other people's personal data. If you publish your log, check that every link is
public and that nobody is named without consent ([Protecting people's privacy](protecting-peoples-privacy.md)).

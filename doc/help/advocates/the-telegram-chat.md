# The Telegram chat

This page is for advocates who are active in the community chat. The README names it "Share Exponential! Telegram
Community Support Chat" at [t.me/exponentialcms](https://t.me/exponentialcms)
([Community places](../who-is-the-exponential-foundation.md#community-places)). A chat is fast and friendly, and
forgets quickly. Use it for quick help and welcome, and move lasting answers to places people can find later.

## What the chat is good for

| Good for | Better elsewhere |
|---|---|
| Quick questions with short answers | Long troubleshooting: the forums |
| Welcoming newcomers | Bug reports: the issue tracker |
| Pointing to a help page | Security problems: privately, `SECURITY.md` |
| Asking "is anyone else seeing this?" | Feature proposals: the community issue tracker |
| Sharing a new post or tutorial | Documentation: a pull request |

## Etiquette

- Say hello briefly; no need to ask "can I ask a question?" Just ask.
- Put the whole question in one message with your version and environment.
- Use threads or replies so conversations stay readable.
- Do not message people privately without asking first.
- Respect time zones: people answer when they can.
- No advertising beyond a short disclosure of your own work when relevant
  ([Disclosure and conflicts of interest](disclosure-and-conflicts-of-interest.md)).
- Follow the chat's own rules and its moderators.

## Moving answers to the forums and the help

A good chat answer is lost within days. When an answer is worth keeping:

1. Ask the person to post the question in the forums, or post it yourself with their permission (without their
   personal details).
2. Answer it there fully.
3. Link the forum thread in the chat.
4. If the help should have answered it, improve the help ([Improving the help](improving-the-help.md)).

## Privacy and security in a chat

- A group chat is public to its members and may be visible to many people. Treat it as public.
- Never post passwords, keys, server addresses, logs with personal data or customer names.
- If someone posts a secret by mistake, tell them at once to delete it and change it.
- If someone describes a vulnerability, ask them to stop and report it privately
  ([Security reports stay private](security-reports-stay-private.md)).
- Screenshots of the chat with other people's names should not be reposted elsewhere without consent
  ([Protecting people's privacy](protecting-peoples-privacy.md)).

## Message templates

```text
WELCOME
Welcome, <name>! If you're new: the help inside the admin (the "?" button) is a great start, and the forums
(share.exponential.earth/forums) keep longer answers findable. What are you working on?

POINT TO HELP
This one's in the help: "<title>" - <link>. Short version: <one line>.

MOVE TO THE FORUMS
Good question, and a bit long for chat. Could you post it in the forums with your version and the exact
message? Then the answer stays findable for others. I'll look there.

SECRET POSTED
Heads up: your message contains a <password | key | server address>. Please delete it and change it.

SECURITY
Please don't share more details here. Send them privately as SECURITY.md describes (security@se7enx.com).
Thank you for reporting!
```

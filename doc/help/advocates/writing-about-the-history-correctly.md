# Writing about the history correctly

This page is for advocates who mention where Exponential comes from. The history is a strength, but it involves other
companies and an old product name. Getting it right is a matter of accuracy and of respect.

## The facts to stick to

| Fact | Source |
|---|---|
| The code base was developed by eZ Systems as eZ Publish; its copyright 1999 to 2014 stays in the code | [COPYRIGHT.md](https://github.com/se7enxweb/exponential/blob/main/COPYRIGHT.md) |
| eZ Publish was discontinued by its creator after almost eighteen years | [Exponential 6](../who-is-the-exponential-foundation.md#exponential-6-the-kernel) |
| "The platform originally known as eZ Publish reached end-of-life in 2021. We kept going." | [Timeline](../who-is-the-exponential-foundation.md#timeline) |
| 7x, formerly Brookins Consulting, took over leadership in 2023 | [Who is 7x?, In short](../who-is-7x.md#in-short) |
| 6.0.0 was released on 1 January 2024, then still named eZ Publish | [Timeline](../who-is-the-exponential-foundation.md#timeline) |
| The product became Exponential on 11 and 12 August 2025 | same |
| "This project is not associated with the original eZ Publish software or its original developer, eZ Systems or Ibexa" | [Who is 7x?, In short](../who-is-7x.md#in-short) |

## Phrases to use

- "Exponential continues the code base of eZ Publish."
- "The code base was developed for many years under the name eZ Publish."
- "A site built while the software was still called eZ Publish."
- "The eZ Publish years."
- "eZ Publish, a product its creator discontinued after almost eighteen years."
- "Exponential is not associated with eZ Systems or Ibexa."

## Phrases to avoid

| Avoid | Why |
|---|---|
| "Exponential is eZ Publish." / "the new eZ Publish" | Suggests the same product and an association |
| "eZ Publish, now called Exponential" | Suggests a rename by the original company |
| "the official successor of eZ Publish" | No such status exists |
| "eZ Publish 6" | No such product; the line is Exponential 6 |
| "eZ Publish sites" (for today's sites) | Use "sites built in the eZ Publish years" or "Exponential sites" |
| "dead", "abandoned" about the original vendor's products | Disrespectful and imprecise; say "discontinued" |
| Speculation about why the vendor stopped | No source |

Source of these rules: [Brand and naming rules, The old name](../business/brand-and-naming-rules.md#the-old-name-ez-publish-only-as-history).

## Rewrites

| Before | After |
|---|---|
| "We run eZ Publish 6 on PHP 8.5." | "We run Exponential 6 on PHP 8.5." |
| "Exponential is the community version of eZ Publish." | "Exponential continues the code base of eZ Publish, a product its creator discontinued after almost eighteen years." |
| "Migrate your eZ Publish site to Exponential, eZ's successor." | "Move a site built while the software was still called eZ Publish onto the current Exponential 6." |
| "eZ Systems abandoned it, so we saved it." | "When the original product was discontinued, 7x took over leadership of the code base." |

## Respect for earlier work

Hundreds of people built the code base before Exponential ([Contributors and friends of the project](../who-is-7x.md#contributors-and-friends-of-the-project)).
eZ Systems' copyright stays in the code. Speak of that work with gratitude. The project credits others by name
(Netgen, Mugo Web, CJW Network), and so should you
([Respecting other projects and companies](respecting-other-projects-and-companies.md)).

Code identifiers with `eZ` (`eZContentObject`, `eZINI`) are not the product name and never change
([Code identifiers stay as they are](../business/brand-and-naming-rules.md#code-identifiers-stay-as-they-are)).

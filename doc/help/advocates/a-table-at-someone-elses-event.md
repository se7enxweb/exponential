# A table at someone else's event

This page is for advocates who want to represent the Exponential community at an event others organize: an open source
festival, a PHP conference, a local tech day. Many events offer free community tables. Present it honestly: a table
staffed by volunteer advocates, not an official presence of 7x or the Foundation unless they asked you.

## Ask the organizers

```text
Subject: Community table request: Exponential (open source CMS)

Hello, we are volunteer users of Exponential, a free and open source PHP CMS (GNU GPL). We'd like to ask
for a community table at <event> to show it and answer questions. We are not selling anything.
People: <n> volunteers. Needs: a table, power, <network if possible>.
Contact: <you>
```

If anyone at the table works for a company that sells services, say so to the organizers and visitors.

## What to bring

```text
[ ] Laptop with a local demo installation on SQLite (works offline), invented content
[ ] Second screen or tablet showing the demo loop
[ ] Printed one-page fact sheet and the community card
[ ] Power strip, adapters
[ ] A sign: "Exponential - free & open source PHP CMS - ask us"
[ ] Notebook for questions you cannot answer (no visitor personal data unless they offer contact for a reply)
```

Fact sheet and card: [One-page fact sheet](one-page-fact-sheet.md), [The community channels](community-channels.md#a-card-to-share).

## The demo loop

A silent loop of screenshots or a short screencast that runs on its own:

1. The dashboard. 2. Editing with preview at phone width. 3. The layouts editor. 4. Right-to-left administration.
5. The help with the "?" button. 6. "Try it: ./console exp:install".

Captions on each frame; no secrets on any screen ([Live demo safety](live-demo-safety.md)).

# ezprestapiprovider: the REST provider classes

This page is for developers who build a REST API on the kernel's REST framework. `ezprestapiprovider` is the package
of REST provider classes that [ezprestapi](ezprestapi.md) builds on: a provider (`rest_provider.php`), a view
controller, controllers, models and views, registered in `rest.ini`.

## When to use it

Install it when you want to base your own provider on these classes without the example client of ezprestapi.

# ezprestapiprovider: the REST provider classes

`ezprestapiprovider` is the package of the REST provider classes that [ezprestapi](ezprestapi.md) builds on: a provider (`rest_provider.php`), view controller,
controllers, models and views for a REST API provider of the kernel's REST framework, registered in `rest.ini`. Install it when you want to base your own
provider on these classes without the example client of ezprestapi.

# ezoe: the online editor repository

`ezoe` ("eZ Online Editor") is the rich text editor of the admin and of editors on the site. The standalone repository `se7enxweb/ezoe` is **no
longer the place of the code**: its README says the code moved into the Exponential kernel repository (the `extension` folder), and changes go
there. In the Exponential 6 period the repository received funding metadata only.

How the editor is built, upgraded to TinyMCE 8 and configured in Exponential 6 is described in
[ezoe-tinymce8](../../../bc/6.0/ezoe-tinymce8.md).

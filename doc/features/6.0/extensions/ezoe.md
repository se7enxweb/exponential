# ezoe: the online editor repository

This page is for anyone who looks for the code of the rich text editor. `ezoe` ("eZ Online Editor") is the rich text
editor of the admin and of editors on the site.

The standalone repository `se7enxweb/ezoe` is **no longer where the code lives**. Its README says the code moved into
the Exponential kernel repository (the `extension` folder), and changes go there. In the Exponential 6 period the
standalone repository received funding metadata only.

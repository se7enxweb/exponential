# exp:ezcache

Clear Exponential caches by tag or id (--clear-tag, --clear-id, --clear-all, --list-tags).

Script `bin/php/ezcache.php`, code in `kernel/private/classes/commands/ezcache.php`. Run it from the installation root, as the user the web server runs as:

## Options

| Option | Value | Help |
|---|---|---|
| `--clear-tag` | required | Clears all caches related to a given tag, separate multiple tags with a comma |
| `--clear-id` | required | Clears all caches related to a given id, separate multiple ids with a comma |
| `--clear-all` |  | Clears all caches |
| `--iteration-sleep` | required | Amount of seconds to sleep between each iteration when performing a purge operation, can be a float. |
| `--iteration-max` | required | Amount of items to remove in each iteration when performing a purge operation. |
| `--expiry` | required | Date or relative time which specifies when cache items are to be considered expired, e.g 'now', '-2 days' or 'last monday'. Can only be used together with --purge. |
| `--list-tags` |  | Lists all available tags |
| `--list-ids` |  | Lists all available ids |
| `--purge` |  | Enforces purging of cache items which ensures that specified entries are physically removed (Useful for saving diskspace). Used together with the clear-* options. |

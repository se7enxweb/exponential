# exp:ezconvertdbcharset

Convert all Exponential database tables to use UTF-8 character set.

Script `bin/php/ezconvertdbcharset.php`, code in `kernel/private/classes/commands/ezconvertdbcharset.php`. Run it from the installation root, as the user the web server runs as:

```bash
./console exp:ezconvertdbcharset --help
php bin/php/ezconvertdbcharset.php --help
```

## Options

| Option | Value | Help |
|---|---|---|
| `--extra-xml-attributes` | required | specify custom attributes which store its data in xml. usage: <datatype_string>[.<table>.<field>][,<datatype_string>.<table>.<field>...]. default table is 'ezcontentobject_attribute', default data field is 'data_text' note: your custom table must have 'id', 'version' and 'data_type_string' fields. |
| `--extra-xml-data` | required | specify custom xml data. usage: <table>.<field>[,<table>.<field>...]. note: your custom table must have 'id' field. |

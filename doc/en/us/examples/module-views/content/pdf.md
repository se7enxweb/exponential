# /content/pdf

A view of the `content` module, defined in `kernel/content/module.php` and run by `kernel/content/pdf.php`.

## Address

```text
/content/pdf/<NodeID>/(language)/<Language>/(offset)/<Offset>/(year)/<Year>/(month)/<Month>/(day)/<Day>
```

Ordered parameters, in this order after the view name: `NodeID`.

Unordered parameters, in any order as `/(name)/value`: `(language)` sets `Language`, `(offset)` sets `Offset`, `(year)` sets `Year`, `(month)` sets `Month`, `(day)` sets `Day`.

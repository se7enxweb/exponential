# cronjob.ini [PauseSettings]

The block `[PauseSettings]` of `settings/cronjob.ini`, with 2 setting(s).

Never edit `settings/cronjob.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/cronjob.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/cronjob.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/cronjob.ini.append.php` in an extension (read when the extension is active).

## Pause

> Pausing cronjob parts at Setup > Cronjobs: a paused part (or "all") is left out by  
> runcronjobs.php, whoever starts it, until it is resumed. The state is a file per part,  
> cronpart\_deactivated\_<part>.txt with "1" for paused, the layout extensions that paused  
> parts already use, so a page of such an extension shows the same state. disabled ignores them.  
> Guide: doc/features/6.0/cronjob-pause.md  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cronjob.ini.append.php
[PauseSettings]
Pause=enabled
*/ ?>
```

## Directory

> Where the files are, relative to the var directory of the siteaccess. Empty: the  
> cronjob\_control directory below the cache directory.  

Default: empty.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cronjob.ini.append.php
[PauseSettings]
Directory=
*/ ?>
```

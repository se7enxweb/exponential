# cronjob.ini [CronjobPart-logs]

The block `[CronjobPart-logs]` of `settings/cronjob.ini`, with 1 setting(s).

> The logs: rotate those over their MaxSize, prune and compress their archives (doc/features/6.0/log-rotation.md).  
> In no default part: run it with php runcronjobs.php logs, or add explogrotate.php to a part the site runs.  

Never edit `settings/cronjob.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/cronjob.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/cronjob.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/cronjob.ini.append.php` in an extension (read when the extension is active).

## Scripts

Default: a list of 1: `explogrotate.php`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/cronjob.ini.append.php
[CronjobPart-logs]
# an empty "Scripts[]" first replaces the shipped list; without it the items are added
Scripts[]
Scripts[]=explogrotate.php
*/ ?>
```

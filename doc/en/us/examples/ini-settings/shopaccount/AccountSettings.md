# shopaccount.ini [AccountSettings]

The block `[AccountSettings]` of `settings/shopaccount.ini`, with 2 setting(s).

> Settings for how user accounts should be handled in the shop/checkout  
> default is to use internal user accounts in the system  
> simple is for handling account information without user registration  

Never edit `settings/shopaccount.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/shopaccount.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/shopaccount.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/shopaccount.ini.append.php` in an extension (read when the extension is active).

## Handler

Default: `ezuser`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/shopaccount.ini.append.php

Handler=ezuser
*/ ?>
```

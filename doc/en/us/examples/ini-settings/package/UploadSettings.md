# package.ini [UploadSettings]

The block `[UploadSettings]` of `settings/package.ini`, with 4 setting(s).

> The limits of a package archive uploaded on package/upload, the setup wizard or ezpm import  
> (eZPackageUploadInspector). An archive is also refused, whatever these say, when an entry points outside the  
> package ("..", an absolute path), is a link or a device, or its package.xml is not a well formed definition.  
> Guide: doc/guides/packages.md  

Never edit `settings/package.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/package.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/package.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/package.ini.append.php` in an extension (read when the extension is active).

## MaxArchiveSize

> The largest archive accepted, in bytes (256 MiB). PHP's upload\_max\_filesize and post\_max\_size apply first.  

Default: `268435456`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/package.ini.append.php
[UploadSettings]
MaxArchiveSize=268435456
*/ ?>
```

## AllowedSuffixes

> The endings an uploaded file's name may have  

Default: a list of 3: `ezpkg`, `tar.gz`, `tgz`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/package.ini.append.php
[UploadSettings]
# an empty "AllowedSuffixes[]" first replaces the shipped list; without it the items are added
AllowedSuffixes[]
AllowedSuffixes[]=ezpkg
AllowedSuffixes[]=tar.gz
AllowedSuffixes[]=tgz
*/ ?>
```

# package.ini [CreationSettings]

The block `[CreationSettings]` of `settings/package.ini`, with 2 setting(s).

Never edit `settings/package.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/package.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/package.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/package.ini.append.php` in an extension (read when the extension is active).

## HandlerList

> A list of extensions which have package creation handlers support  
> The extension must place package creation handlers in the  
> subdirectory packagecreators.  
> The order here is the order the Create package page lists the wizards in:  
> content first, then its classes, then extensions, then site styles.  

Default: a list of 4: `ezcontentobject`, `ezcontentclass`, `ezextension`, `ezstyle`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/package.ini.append.php
[CreationSettings]
# an empty "HandlerList[]" first replaces the shipped list; without it the items are added
HandlerList[]
HandlerList[]=ezcontentobject
HandlerList[]=ezcontentclass
HandlerList[]=ezextension
HandlerList[]=ezstyle
*/ ?>
```

## HandlerAlias

Default: a hash of 4: `ezcontentclass=eZContentClassPackageCreator`, `ezstyle=eZStylePackageCreator`, `ezcontentobject=eZContentObjectPackageCreator`, `ezextension=eZExtensionPackageCreator`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/package.ini.append.php
[CreationSettings]
# an empty "HandlerAlias[]" first replaces the shipped list; without it the items are added
HandlerAlias[]
HandlerAlias[ezcontentclass]=eZContentClassPackageCreator
HandlerAlias[ezstyle]=eZStylePackageCreator
HandlerAlias[ezcontentobject]=eZContentObjectPackageCreator
HandlerAlias[ezextension]=eZExtensionPackageCreator
*/ ?>
```

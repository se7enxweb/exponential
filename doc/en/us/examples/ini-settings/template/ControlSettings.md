# template.ini [ControlSettings]

The block `[ControlSettings]` of `settings/template.ini`, with 3 setting(s).

Never edit `settings/template.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/template.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/template.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/template.ini.append.php` in an extension (read when the extension is active).

## DisplayWarnings

> Whether warnings from the template engine should be displayed  
> on the page or not.  
> Note: Debug warnings are always shown if debug is on.  

Default: `disabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/template.ini.append.php
[ControlSettings]
DisplayWarnings=disabled
*/ ?>
```

## AllowUserVariables

> User defined parameter.  
> Ex: http://example.com/developer/(poll\_option)/5  
> will store poll\_option 5 into the $view\_parameters.poll\_option in the template  

Default: `true`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/template.ini.append.php
[ControlSettings]
AllowUserVariables=true
*/ ?>
```

## MaxLevel

> Max level of template nesting to avoid infinite recursion  

Default: `40`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/template.ini.append.php
[ControlSettings]
MaxLevel=40
*/ ?>
```

# subitems.ini [Preset_technical]

The block `[Preset_technical]` of `settings/subitems.ini`, with 2 setting(s).

Never edit `settings/subitems.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/subitems.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/subitems.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/subitems.ini.append.php` in an extension (read when the extension is active).

Default: `Technical`.

<?php /* #?ini charset="utf-8"?

*/ ?>

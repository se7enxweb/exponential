# audit.ini [AuditChannelSettings]

The block `[AuditChannelSettings]` of `settings/audit.ini`, with 3 setting(s).

Never edit `settings/audit.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/audit.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/audit.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/audit.ini.append.php` in an extension (read when the extension is active).

## Channels

> The channels (Q6): each is one chain, one file per day (and per MaxFileSize part).  
> Proposed: a fifth channel for sampled reads, used only when reads are switched on.  

Default: a list of 5: `content`, `access`, `system`, `commerce`, `read`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditChannelSettings]
# an empty "Channels[]" first replaces the shipped list; without it the items are added
Channels[]
Channels[]=content
Channels[]=access
Channels[]=system
Channels[]=commerce
Channels[]=read
*/ ?>
```

## Route

> Routing by taxonomy pattern, most specific wins. An event no pattern matches goes to  
> DefaultChannel.  

Default: a hash of 8: `content.*=content`, `content.node.view=read`, `content.search.*=read`, `content.object.download=read`, `access.*=access`, `system.*=system`, `commerce.*=commerce`, `data.*=commerce`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditChannelSettings]
# an empty "Route[]" first replaces the shipped list; without it the items are added
Route[]
Route[content.*]=content
Route[content.node.view]=read
Route[content.search.*]=read
Route[content.object.download]=read
Route[access.*]=access
Route[system.*]=system
Route[commerce.*]=commerce
Route[data.*]=commerce
*/ ?>
```

# syscard.ini [Runtime]

The block `[Runtime]` of `settings/syscard.ini`, with 2 setting(s).

Never edit `settings/syscard.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/syscard.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/syscard.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/syscard.ini.append.php` in an extension (read when the extension is active).

## TotalBudget

> The seconds all providers together may take; the ones left after that show "n/a (time)"  

Default: `6`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/syscard.ini.append.php
[Runtime]
TotalBudget=6
*/ ?>
```

## Isolation

> enabled: each provider runs in a child process that is ended when its budget is spent, so one that hangs (a  
> database that does not answer, a stalled disk) shows "n/a (timeout)" and never hangs the card (needs the pcntl and  
> posix extensions of the command-line PHP; without them the providers keep their budget themselves)  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/syscard.ini.append.php
[Runtime]
Isolation=enabled
*/ ?>
```

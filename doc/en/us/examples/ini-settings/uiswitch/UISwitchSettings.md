# uiswitch.ini [UISwitchSettings]

The block `[UISwitchSettings]` of `settings/uiswitch.ini`, with 3 setting(s).

Never edit `settings/uiswitch.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/uiswitch.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/uiswitch.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/uiswitch.ini.append.php` in an extension (read when the extension is active).

## Enabled

> true | false. Off: no choice is offered or applied anywhere.  

Default: `true`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/uiswitch.ini.append.php
[UISwitchSettings]
Enabled=true
*/ ?>
```

## SiteAccessList

> The siteaccesses where the choices work. Empty: every siteaccess whose design list has an  
> administration design (admin, admin2, admin3, admin4, admin4l, adminui; the editor and adminui  
> siteaccesses fall back to them). Never a public site.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/uiswitch.ini.append.php
[UISwitchSettings]
# an empty "SiteAccessList[]" first replaces the shipped list; without it the items are added
SiteAccessList[]
*/ ?>
```

## ProviderList

> The providers, in toolbar order. Each needs a \[UISwitch\_<identifier>\] group with Class=, and gets  
> the policy function uiswitch/<identifier>.  

Default: a list of 2: `language`, `design`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/uiswitch.ini.append.php
[UISwitchSettings]
# an empty "ProviderList[]" first replaces the shipped list; without it the items are added
ProviderList[]
ProviderList[]=language
ProviderList[]=design
*/ ?>
```

# requestrules.ini [RequestRuleSettings]

The block `[RequestRuleSettings]` of `settings/requestrules.ini`, with 7 setting(s).

Never edit `settings/requestrules.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/requestrules.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/requestrules.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/requestrules.ini.append.php` in an extension (read when the extension is active).

## Enabled

> true or false. With false no rule is asked; the kernel behaves as before  
> this feature existed.  

Default: `true`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/requestrules.ini.append.php
[RequestRuleSettings]
Enabled=true
*/ ?>
```

## RuleList

> The rules asked, in order. Empty: no rule (and no cost). A siteaccess  
> override that starts with RuleList\[\] (empty) replaces the list.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/requestrules.ini.append.php
[RequestRuleSettings]
# an empty "RuleList[]" first replaces the shipped list; without it the items are added
RuleList[]
*/ ?>
```

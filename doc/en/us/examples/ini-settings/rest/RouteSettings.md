# rest.ini [RouteSettings]

The block `[RouteSettings]` of `settings/rest.ini`, with 2 setting(s).

Never edit `settings/rest.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/rest.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/rest.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/rest.ini.append.php` in an extension (read when the extension is active).

## RouteSettingImpl

Default: `ezpRestIniRouteFilter`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/rest.ini.append.php
[RouteSettings]
RouteSettingImpl=ezpRestIniRouteFilter
*/ ?>
```

## SkipFilter

> Pattern for the skip filter  
> SkipFilter\[\]=controller\_action;version  
> If the version component is not listed version "1" is assumed.  

Default: a list of 4: `ezpRestErrorController_show`, `ezpRestAuthController_basicAuth`, `ezpRestAuthController_oauthRequired`, `ezpRestOauthTokenController_handleRequest`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/rest.ini.append.php
[RouteSettings]
# an empty "SkipFilter[]" first replaces the shipped list; without it the items are added
SkipFilter[]
SkipFilter[]=ezpRestErrorController_show
SkipFilter[]=ezpRestAuthController_basicAuth
SkipFilter[]=ezpRestAuthController_oauthRequired
SkipFilter[]=ezpRestOauthTokenController_handleRequest
*/ ?>
```

# contentcheck.ini [BrokenRelationsSettings]

The block `[BrokenRelationsSettings]` of `settings/contentcheck.ini`, with 3 setting(s).

Never edit `settings/contentcheck.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/contentcheck.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/contentcheck.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/contentcheck.ini.append.php` in an extension (read when the extension is active).

## XmlDatatypes

> The datatypes whose text is read for links and embeds (object\_id="..." and node\_id="..."  
> of <link>, <embed> and <embed-inline>)  

Default: a list of 1: `ezxmltext`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/contentcheck.ini.append.php
[BrokenRelationsSettings]
# an empty "XmlDatatypes[]" first replaces the shipped list; without it the items are added
XmlDatatypes[]
XmlDatatypes[]=ezxmltext
*/ ?>
```

## ChunkSize

> How many objects are checked with one set of queries (10 to 1000)  

Default: `200`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/contentcheck.ini.append.php
[BrokenRelationsSettings]
ChunkSize=200
*/ ?>
```

## ScanLimit

> At most this many objects are checked for one page (ChunkSize to 100000); a page with fewer  
> findings than its size then ends early and the next page goes on from there  

Default: `5000`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/contentcheck.ini.append.php
[BrokenRelationsSettings]
ScanLimit=5000
*/ ?>
```

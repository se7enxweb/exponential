# Platform ecosystem: August 2024

What changed in August 2024 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 186 changes in 11 platform repositories this month: 52 new or improved capabilities, 21 bug fixes, 3 behaviour changes.
- Busiest repositories: admin-ui-7x (49), admin-ui-ibexa (49), core (24).
- 16 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

## Upstream activity carried by the forks

- **admin-ui-7x**: 49 upstream changes. Largest: `1d4f94aec` IBX-8138: [Rector] Applied rules from Symfony 5 Rector set lists (#1294); `dd3a7fcbc` IBX-8533: Dropped deprecated code (#1313); `471396a38` IBX-8433: Added content tree children filtering (#1290)
- **core**: 24 upstream changes. Largest: `7e4312d81` IBX-8138: [Rector] Applied rules from Symfony 5 Rector set lists (#385); `7c398f219` Refactored Float and Integer field types to use external validators (#425); `13a0cf162` Extracted common base for TextBlock and TextLine field types (#406)
- **fieldtype-richtext-ibexa**: 18 upstream changes. Largest: `c5d18f3` [Rector] Applied all Symfony 5.x rectors to the production codebase (#172); `dac171d` IBX-8150: Added option to enable attributes types (#179); `8b75c60` Fixed failing test for ezurl protocol
- **adminneo**: 13 upstream changes. Largest: `43a0305a` Fix server URL validation for Oracle connections; `de7dd4b6` Improve URL and email detection; `8a602434` Add script for exporting compiled adminer variants
- **ibexa-recipes**: 7 upstream changes. Largest: `564c4ef` IBX-8137: [ibexa/*] Dropped Swiftmailer bundle (#139); `f28dc8c` IBX-8817: Documented `http_basic` authentication config (#138); `8a7c7ef` IBX-8656: Reworked OAuth2 client authentication to comply with new Symfony security (#133)
- **site-bundle**: 4 upstream changes. Largest: `98e8d7d` NGSTACK-822 logic of ordering changes, string parameter replaced by QN; `a777492` NGSTACK-822 logic of ordering changes, string parameter replaced by QN; `b5debe8` NGSTACK-822 added check if sort key class exists

# Platform ecosystem: November 2024

What changed in November 2024 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 144 changes in 12 platform repositories this month: 42 new or improved capabilities, 23 bug fixes, 9 behaviour changes.
- Busiest repositories: adminneo (35), admin-ui-7x (30), admin-ui-ibexa (30).
- 12 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

## Upstream activity carried by the forks

- **adminneo**: 35 upstream changes. Largest: `f93db81c` Update translations; `07868da3` Add styles to input elements; `6970fa1d` Refactor core classes
- **admin-ui-7x**: 30 upstream changes. Largest: `ef7f07bbc` IBX-8805: Dropped deprecated Twig Functions&Filters (#1390); `56724eefe` IBX-9227: Restore multipleItemsLimit cehcks in UDW (#1396); `bc3ce24f6` IBX-8418: Added drafts deletion warning to trash modal (#1321)
- **core**: 19 upstream changes. Largest: `aba61e909` IBX-8534: Dropped core deprecations (#435); `2e22cebee` Fixed issues related to twig/twig 3.15 in tests; `78236ffc3` IBX-8805: Dropped deprecated Twig Functions&Filters (#450)
- **exponential-platform-nexus-starter**: 5 upstream changes. Largest: `54fb89fa9` NGSTACK-924 raise php version to 8.2; `7ea1e2601` NGSTACK-925 Downgrade phpdoc-parser version beacuse of serializer dependency; `a0d94308b` NGSTACK-925 Move phpdoc-parser to conflict section
- **exponential-platform-dxp**: 5 upstream changes. Largest: `fa2bfcb` Unpacked symfony/serializer-pack dependency declaration (#187); `9e91740` [composer] Removed dependency on symfony/orm-pack (#188); `106ab6c` Unpacked symfony/serializer-pack dependency declaration

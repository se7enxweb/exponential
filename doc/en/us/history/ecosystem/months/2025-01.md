# Platform ecosystem: January 2025

What changed in January 2025 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 141 changes in 13 platform repositories this month: 55 new or improved capabilities, 23 bug fixes, 2 behaviour changes.
- Busiest repositories: adminneo (35), admin-ui-7x (30), admin-ui-ibexa (30).
- 15 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

## Upstream activity carried by the forks

- **adminneo**: 35 upstream changes. Largest: `2e6713ca` Short array syntax; `d9d4694e` Fix and refactor script for updating languages files; `3cbf8a8e` Remove donation link from logout message
- **admin-ui-7x**: 30 upstream changes. Largest: `d6d83c769` IBX-9002: Added endpoint for list users with permission info (#1372); `11d3fdea0` IBX-9322: ezobjectrelationlist field allows selecting the same content multiple times (#1409); `b367a66b3` IBX-7484: unified display of hidden locations in UDW (#1428)
- **core**: 9 upstream changes. Largest: `7a5d9eb7c` Updated copyright year to 2025; `8481e63cb` Updated copyright year to 2025; `cd57d587f` IBX-9337: Fixed failure to serialize field data post symfony/serializer 5.4.40
- **exponential-platform-dxp**: 7 upstream changes. Largest: `1804822` Updated copyright year to 2025; `05c62ae` Updated copyright year to 2025; `99d5e25` [GHA] Downgraded auto tagger workflow to use Ubuntu 22.04
- **fieldtype-richtext-ibexa**: 6 upstream changes. Largest: `21f1dbc` IBX-9297: Custom CSS can not be removed from link element (#199); `ef64b0a` IBX-9296: Custom CSS classes not working for "embedimage" (#197); `0642bbe` Updated copyright year to 2025

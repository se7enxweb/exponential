# Platform ecosystem: September 2025

What changed in September 2025 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 227 changes in 27 platform repositories this month: 57 new or improved capabilities, 58 bug fixes, 10 behaviour changes.
- Busiest repositories: admin-ui-7x (44), admin-ui-ibexa (44), exponential (23).
- 67 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

# Platform ecosystem: April 2024

What changed in April 2024 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 157 changes in 13 platform repositories this month: 58 new or improved capabilities, 14 bug fixes, 1 behaviour change.
- Busiest repositories: admin-ui-7x (48), admin-ui-ibexa (48), core (28).
- 3 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

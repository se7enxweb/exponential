# Platform ecosystem: October 2025

What changed in October 2025 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 190 changes in 12 platform repositories this month: 49 new or improved capabilities, 31 bug fixes, 1 behaviour change.
- Busiest repositories: admin-ui-7x (39), admin-ui-ibexa (39), adminneo (34).
- None of the changes is se7enxweb work with a user-visible theme; all of them are upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

## Upstream activity carried by the forks

- **admin-ui-7x**: 39 upstream changes. Largest: `1cc922812` IBX-10429: [Collaboration] UI improvements for the header (#1682); `de085b476` IBX-9840: Implemented service fetching content fields from expression and validating if field is within expression (#1500); `a398bea6a` IBX-10533: Quick action btn manager for handling & displaying multiple btns (#1726)
- **adminneo**: 34 upstream changes. Largest: `aa8964b2` Print the last release number to compiled plugins (fix #164); `59dc1c25` Add setting for displaying links to referencing tables; `95447d49` Unify the result of fetchField() method
- **core**: 27 upstream changes. Largest: `62929022f` IBX-10458: Implemented new Content Type search PHP API (#633); `fd2c23a2d` Enforced PHPStan rule against dynamic properties; `2a440c338` [PHPStan] Regenerated PHPStan baseline (#658)
- **layouts-core**: 25 upstream changes. Largest: `493bc5ea5` Add missing parameter and return typehints; `4a0824a52` Add constructor property promotion; `fcd9d72f3` Convert persistence STATUS_* constants to Status enum
- **fieldtype-richtext-ibexa**: 10 upstream changes. Largest: `00554a9` [CI] Adjusted gh actions and PHPStan (#268); `33590a1` IBX-10288: Fix XSS in custom tags; `3d6ab04` [PHPStan] Aligned baseline after PHPStan release (#269)
- **exponential-platform-dxp**: 7 upstream changes. Largest: `c4d2556` [CI] Add token selection for 3.3 (#241); `b45edf7` IBX-10494: Included Postgres 18 on CI (#237); `aaa1a4b` [GHA][Create Tag] Replaced TRAVIS_GITHUB_TOKEN with GitHub App token

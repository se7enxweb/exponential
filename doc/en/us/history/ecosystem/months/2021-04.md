# Platform ecosystem: April 2021

What changed in April 2021 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 6 changes in 1 platform repository this month: 4 new or improved capabilities, 1 bug fix, 1 behaviour change.
- Busiest repositories: adminneo (6).
- None of the changes is se7enxweb work with a user-visible theme; all of them are upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

# Platform ecosystem: May 2025

What changed in May 2025 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 298 changes in 14 platform repositories this month: 63 new or improved capabilities, 50 bug fixes, 15 behaviour changes.
- Busiest repositories: adminneo (78), admin-ui-7x (54), admin-ui-ibexa (54).
- 9 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

- **adminneo**: 78 upstream changes. Largest: `74b3c0f1` Update web links to adminneo.org; `92cf328a` Include external dependencies to the project; `b7cf2f15` Fix typo in plugins usage URL (fix #115)
- **admin-ui-7x**: 54 upstream changes. Largest: `c0adbf5b1` IBX-9940: Removed Sass deprecations (#1548); `3eb6d1b14` IBX-10066: Change lint config to 2.0 (#1558); `e1bbe59d3` IBX-9916: Removed defaultProps (#1557)

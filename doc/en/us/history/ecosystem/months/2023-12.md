# Platform ecosystem: December 2023

What changed in December 2023 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 206 changes in 15 platform repositories this month: 62 new or improved capabilities, 28 bug fixes, 4 behaviour changes.
- Busiest repositories: exponential (77), admin-ui-7x (35), admin-ui-ibexa (35).
- 57 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

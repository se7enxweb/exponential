# June 2025

What changed in Exponential in June 2025, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- 6.0.9 was released on 10 June 2025.
- The browse dialog can pick the node you are in; image alias errors log the request URI.

- **6.0.9 on 10 June** ([Changelog 6.0.9](../../changelogs/6.0/6.0.9.md)); package URL bumped for the installer (`fcf6ac0173`), and the 6.0.10 cycle opened (`d0765df332`).
- **Quick select in the browse dialog.** When you browse for a location the node you are in can be chosen directly (`5c82f7a451`), an admin3 template override. See [The responsive admin design](../../features/6.0/admin3-responsive-admin.md).
- **Image alias errors** log the request URI, which makes broken image aliases easier to track down (`68c20634be`).
- **README** has new sections and links (`52bfaa5296`); the package description names the supported PHP range (`5c3be63974`).

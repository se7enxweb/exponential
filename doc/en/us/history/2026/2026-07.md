# July 2026

What changed in Exponential in July 2026, why it matters, and where to read more. Read it if you run a site on the 6.0.15 line, or want to know where the package manager, the Kickstarter or the template editor came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- The command line grew up: `ezpm` joined the console, a one command installer and the Kickstarter arrived, and a password reset tool.
- The Template Editor became safe to use: no override rule is lost or silently ignored any more.
- Extensions got a second home (additional directories), icon themes in extensions, and Redis or Valkey cache hooks.
- The kernel was cleaned for PHP 8, and the first installations on shared hosting worked without extra database rights.

July brought 73 changes to the root repository, all on the 6.0.15 line. No release tag falls in the month; the previous release is v6.0.14 of 7 June. July is the month the command line grew up. Every change is in the [ledger of exponential-root](../ledger/exponential-root.md) under "2026-07"; the ones without a story of their own are under [Smaller changes](#smaller-changes). The legacy extensions, themes and packages of the same month have [their own month page](../extensions/months/2026-07.md).

## 11 July: a day of command line work

- **`ezpm` joins the console.** The package manager's command line front end is
  discovered by `bin/php/console` as the `ezpm` namespace (`868f7a625c`). The same
  day it learned to honour the selected siteaccess and to exit 0 after help
  (`9617bdcea4`), got an `ezcontentsubtree` alias for exporting a content tree
  (`6ec591c375`) and complete help for `add ezcontentobject` with worked examples
  (`2fae3016db`). Installing became fast and safe for big packages: a destination
  node (`-d`), a lock against parallel runs, caches off and delayed indexing for the run
  (`688f48e93f`), batched commits every 50 objects and validation of each object
  (`f090f202a1`), no duplicate install items (`4cfe5fa268`), no destructive class
  replacement without a terminal (`7118f48a4a`), a fallback when a package has no
  active version (`9881dad9bb`), and a one line progress report with percentage,
  elapsed time and ETA (`fc338f04b7`). Read [ezpm: the package manager on the command line](../../features/6.0/ezpm-package-manager-cli.md).
- **A password reset tool.** `bin/php/resetuserpassword.php` resets any user's password,
  authorised by an administrator login or by the operating system root user
  (`ea77927c23`). See [Reset a user password](../../features/6.0/reset-user-password.md).
- **Console help shows each script's own description** from a configuration array
  (`4ce57a7224`).
- **The tests grew up.** A cleanup for PHPUnit 13 and PHP 8.4 changed 132 files, 72 of them new test
  files (cluster file handlers, content classes, roles, RSS export, site access),
  with a bootstrap and an Xdebug configuration (`8798108324`). It is the base of the August
  workflow: [Continuous integration and the test suite](../../specifications/6.0/continuous-integration.md).
- **PHP 8 clean-up of the kernel**, one small commit per file so each can be reverted
  alone: string offsets with curly braces (`58a69a60f6`, `245fb226e3`); an undefined
  `eZCurrentAccess` global (`c25a223542`); a null charset code (`d806473c71`); GD colour
  values cast to integers (`9c8f2cdabd`); null content type keys in `eZMail` (`8ad135b1b6`);
  `error_reporting` honoured by the debug handler (`3ce2a1e76c`); empty or corrupt locale
  strings (`761c2cf29d`); nullable array type hints (`0a79224c3f`, `401549e5c7`); the
  eng-US translation file is skipped (`e3c8d078f4`); array checks in the content cache
  manager (`f5bb53e989`); a check that an embedded image object exists
  (`fbbb02617c`). See [Behaviour changes of July and August 2026](../../bc/6.0/behaviour-changes-2026-07-08.md).
- **The MongoDB driver logs through `eZDebug`** instead of `error_log` (`888297a0ca`).
- **The nice URL update script was reverted** to its earlier, stable version after a
  change made during testing proved unstable (`9c4946075d`; nothing for users to do).
- **README** now says at the top that a downloaded copy needs `composer install`
  before it runs (`04d17780ae`).

## 12 July: the Template Editor and the Kickstarter

- **Template Editor.** Override creation, priority ordering, removal, the choice of
  the source template and matching by object id were rebuilt (`12a2577f00`); the editor
  is in the Design menu (`a5723b6147`); the text box is full width and monospace
  (`80d3fef827`); match conditions can be edited (`7e3569daf5`) and removed
  (`64736998cd`), with the Enter key safe; inline script wrapped in `{literal}`
  (`32f0c99bbd`). A new `class_list` fetch function returns content classes for
  visual modules (`a219ec4839`). Read [Template editor](../../features/6.0/template-editor-overrides.md).
- **Kickstarter.** `bin/php/kickstarter.php` and the console command `exp:kickstarter`
  install a whole site from `kickstart.ini`, test remote packages with `--dry-run`, and
  share a progress reporter with the web setup (`34c17cdbbe`); the full reference
  was written the same day (`1f225a7bae`). See [Kickstarter](../../features/6.0/kickstarter-cli.md).
- **git_manager** is a requirement of 6.0.15 (`48f33aec19`).
- **File manifest** refreshed for the template view fix (`9ed92a04ec`).

## 14 to 19 July: installing on real hosts

- `eZINI`, `eZPersistentObject` and `eZWorkflowProcess` allow dynamic properties, so PHP 8.2
  stops warning (`c75f6cd9c6`, 14 July).
- **The setup wizard works with your own database only.** No more `SHOW DATABASES`
  or reading the `mysql` system database; a database name field; connection errors are
  shown nicely and logged (`fdf0d52028`, 16 July). See [Clean install defaults](../../features/6.0/clean-install-defaults.md).
- `kickstart.ini` was renamed and then replaced by `kickstart.ini--example` so it cannot
  change a clean install (`d0530e1deb`, `f9df1f6854`).
- **HTML5 markup.** XHTML style tags in kernel, lib and design files, and in ezjscore and
  ezoe, were replaced so the pages pass HTML validation services (`111b4a8e03`,
  `426395e1c1`, 18 July).
- **Case-correct extension names.** `eZExtension::extensionName()` maps a name such as
  `adminaid` to the folder `AdminAid` on case-sensitive file systems (`c99f395fb5`, 19 July).
- Composer suggestions for more extensions (`4383ec4e9f`).
- Manifest hash refreshes (`3865fe9a5b`, `07a686bac4`).

## 20 and 21 July: caches, icons and two more extensions

- **Redis and Valkey hooks** for the content view cache and the compiled INI cache
  (`fa17892025`), optional for sites without the extension (`6ef123636c`); the extension is
  suggested in `composer.json` (`62248a1bb2`). Read [Redis and Valkey caches](../../features/6.0/valkey-cache-hooks.md).
- **Icon themes in extensions.** The old `bciconextensions` extensions became part of the
  kernel and a default `job` icon shipped (`3a40db1988`), with a guide (`049811470a`). See
  [Icon themes that live in your extension](../../features/6.0/icon-themes-in-extensions.md).
- The syndication extension and the database source editor `sevenx_dse` are required
  (`e5f5c63ef5`); the latest `powercontent` is required (`7f89104719`); the README explains the
  Composer warnings more clearly (`84ebe2f59f`).

## 26 July: two roots for extensions

`AdditionalExtensionDirectories[]` lets extensions live in `extension_src/` or any other
root. The 41 files that built `extension/` paths by hand now call `eZExtension::extensionPath()` and
its siblings, and the autoload generator reports name collisions (`17e7c11e71`). The Valkey view cache
also respects pages marked `no_cache` (`908994bb03`). See
[Extensions in more than one folder](../../features/6.0/additional-extension-directories.md).

## 29 to 31 July: the node view, the installer, the template comments

- **A Layouts tab** appears in the admin node view window controls (`8df2654e3f`); the guide
  is [Exponential Layouts](../../bc/6.0/LAYOUTS.md).
- **Packages install their dependencies first** (`cb57cdd026`).
- **The root delay of scripts is a setting**: `ezscript.ini [eZScriptSettings] RootDelay`, default
  10 seconds, `0` to disable (`11095f902f`).
- **A safer autoload generator**: it compares real paths and its exclusion filter ends at a directory
  boundary (`f46c08c18e`); the autoload array was regenerated (`ac9771496b`).
- **Template path comments**: `ShowTemplatePathComments` wraps every rendered template in
  `START` and `STOP` comments (`58cc4bd4af`). See [Template path comments](../../features/6.0/template-path-comments.md).
- **Imported Ibexa docbook** renders: class attributes outside the eZXML schema are kept
  (`5857c5baa8`) and `ezembed`, `para` and `literallayout` produce XHTML (`d7bebcb39b`).
- **Permission SQL** guards empty class and section limitation lists (`acb8e002c5`).
- The explayouts and media theme packages are declared as runtime requirements
  (`7bc27a7c21`); a full file manifest was regenerated (`973fecb908`).
- Composer fixes that unblocked installs from GitHub (`1c66d327d4`) and an integer cast for the next
  order number on PHP 8.4 (`9cad41280a`).

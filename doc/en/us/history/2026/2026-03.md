# March 2026

What changed in Exponential in March 2026, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- The test tool-chain moved to PHPUnit 13.
- Sixty PHP string functions can be used as template operators.
- A fatal flaw in the curl client API was fixed.

- **PHPUnit 13.** The test tool-chain moved to PHPUnit 13 (`daea5d5556`) after a version bump that avoids a Composer security advisory which blocked installations (`90645c554d`). See [PHPUnit 13](../../bc/6.0/phpunitv13.md).
- **String functions in templates.** `ristring`, `rstring` and sixty PHP string functions can be used as template operators (`4220e2ff90`). See [PHP string functions as template operators](../../features/6.0/string-template-operators.md).
- **Client API.** A fatal flaw in the client calling API for curl requests was fixed (`0b7ccae3bc`).
- **README** issue tracker links and the description of the platform distributions were revised (`3ed912ca05`, `0a36dcd274`, `7d3a175fa0`, `a162069c88`, `3e7dee15a4`).

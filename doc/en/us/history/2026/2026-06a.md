# June 2026, first half (1 to 15 June)

What changed in Exponential in June 2026 (1 to 15 June), why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- MongoDB 8 arrived as a database on 1 June 2026.
- 6.0.14 was released on 7 June.
- SQL paths once limited to MySQL serve SQLite and PostgreSQL as well; `console cron:<part>` runs cronjob parts.

**MongoDB arrives.** On 1 June a MongoDB 8 database adapter and its kernel compatibility layer were merged (`af5761fdd8`, 117 files), followed by a week of fixes: a general WHERE parser, copy, move and add-location support (`6a192392e9`), integer casts and an array query handler (`c72a94f69e`), autoload order (`bd81c3646f`), the schema handler settings (`b5a73f285f`) and a Database name field in the setup wizard (`78bf407ed5`). Pull request #62 (`0ea31e2a28`) merged the work. Read [MongoDB as the database](../../features/6.0/mongodb-database-support.md) and the reference [MongoDB kernel support](../../bc/6.0/MONGODB_KERNEL_SUPPORT_EXPANSION.md) (known limitations added in `ae5a541769`, document moved in `6b09ffe9fe`).

**The other engines benefit.** SQL paths that had been gated to MySQL now serve SQLite and PostgreSQL as well (`e0d617f28e`); shared-hosting MySQL installations work without root (`93cdd0cf47`); PostgreSQL setup can be re-run (`7773850ade`).

**Admin fixes.** jQuery `.size()` replaced by `.length` (`6e1167795c`), the language list in node full view initialised (`95f2c1af8d`), browse persistent data of any type (`1d74b95640`), `implode(null)` and the role limitations key in the user cache (`eea23b654a`).

**Release 6.0.14 on 7 June** ([Changelog 6.0.14](../../changelogs/6.0/6.0.14.md)). Default installations use package version 6.0.14 (`46540dc84e`). The release file list for the upgrade check was regenerated after every last-minute change (`667a9e8fa3`, `253b9eb2e3`, `00097dd2a6`, `f34133e357`, `2db19d0ce3`, `9b9c5bafcb`); see [File consistency check](../../features/6.0/file-consistency-check.md). On 12 June the version moved to 6.0.15 (`6570963d0c`, `e970e3bd83`).

The README documents MongoDB support (`3c9e3df635`, `349cb4f07f`, debug breadcrumbs removed `9790f159be`, doc examples `f23d5b64bd`).

**Console cron parts.** On 13 June `php bin/php/console cron:<part>` learned to run cronjob parts discovered from `cronjob.ini`, and `crontab:list` and `crontab:edit` manage the system crontab (`a2ef4efa50`). See [Cronjob parts and the crontab](../../bc/6.0/console.md#cronjob-parts-and-the-crontab-added-june-2026).

# December 2023: legacy extensions, themes and packages

What changed in December 2023 in the legacy extensions, themes and packages that run on Exponential 6. Read it if your site uses one of them and you want to know what a new release brings. The main repository has its own month page, linked at the end; the [ledger](../../ledger/README.md) lists every change of every repository.

## In short

- 33 changes in 18 legacy extension, theme or package repositories (1 feature, 1 fix, 0 security, 0 releases).
- Busiest: [ezflow](../ezflow.md) (3), [ezautosave](../ezautosave.md) (2), [ezdemo](../ezdemo.md) (2).
- Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

The first weeks of the se7enxweb era. The legacy extension repositories were moved to the se7enxweb vendor on Packagist: `composer.json` files switched package names and vendors (`ezie`, `eztags`, `ezdemo`, `ezodf`, `ezwt`, `ezmultiupload`, `ezflow`, `ezautosave`, `ezstarrating`, `ezgmaplocation`, `ezmbpaex`, `ezprestapiprovider`, `ezpm`) and funding files were added. Two changes reached users: a PHP 8.2 bugfix release of `ezflow` and setup wizard fixes in the `ezwebin` installer package (SQLite database support followed in January).

# March 2026: legacy extensions, themes and packages

What changed in March 2026 in the legacy extensions, themes and packages that run on Exponential 6. Read it if your site uses one of them and you want to know what a new release brings. The main repository has its own month page, linked at the end; the [ledger](../../ledger/README.md) lists every change of every repository.

## In short

- 49 changes in 41 legacy extension, theme or package repositories (6 features, 1 fix, 0 security, 0 releases).
- Busiest: [sevenx-recipes](../sevenx-recipes.md) (9), [AdminAid](../AdminAid.md) (1), [bccie](../bccie.md) (1).
- Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

The platform recipe repository `sevenx-recipes` began on 12 March; the legacy extensions received GitHub Sponsors metadata on 2 March; `ezstarrating` and several others kept only that change this month.

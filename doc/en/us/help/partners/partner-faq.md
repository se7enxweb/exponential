# Partner FAQ

This page is for anyone with a quick question about the partner program. Each answer links to the page with the
details and sources. Values as published on 18 October 2026.

## The program

**Who runs the partner program?**
7x. The Foundation's role is not described yet. [Who runs the partner program](who-runs-the-partner-program.md)

**Is the Exponential Partner Program the same as the 7x Partner Subscription?**
No. The first is for companies that serve their own customers with Exponential; the second is a managed service by
7x for your own site. [At a glance](partner-program-at-a-glance.md#two-offers-with-partner-in-the-name)

**Which levels are there?**
Student, Now, Starter, Basic, Professional, Silver, Gold, Platinum. [Partner levels](partner-levels.md)

**What does it cost?**
From $25 (Student) to $2,600 (Platinum) a month by level; the Kick-Off Package for Basic is $3,200 (30% discount).
[Partner plans and prices](partner-plans-and-prices.md)

**Can we qualify without paying?**
The requirements page says 5,000 points a year qualify for Basic "with no fee required"; the program page says
Professional. Ask. [The points system](the-points-system.md)

## Joining

**How do we apply?**
Form, review within 10 working days, then pay first (store subscription) and sign the agreement second, sent to
<partners@exponential.earth>. [How to apply](how-to-apply.md)

**What if we are not approved?**
You may apply again after 180 days. [How to apply](how-to-apply.md#if-the-application-is-not-approved)

**How long does a partnership last?**
One year, reviewed 30 days before the end. [Renewals, upgrades and downgrades](renewals-upgrades-and-downgrades.md)

## Working as a partner

**What support do we get?**
GitHub issue tickets and response times by level. [Support levels](support-levels-and-response-times.md)

**Can we use the logos?**
The partner logos from Professional; "Exponential Certified" from Silver with certification.
[Logos and marks](partner-logos-and-marks.md)

**Do we get leads?**
Customer project referrals from Professional; lead priority by level. [Referrals and leads](referrals-and-leads.md)

**What do we earn for a lead we pass to 7x?**
10% of the total contract value for a cold lead, 20% for a hot lead. [Referrals and leads](referrals-and-leads.md)

**Is there a partner dashboard?**
A partner website with a dashboard is planned for mid-2027. Please become a partner today to speed up our growth
rate and land new features faster. [Logging your partner activity](logging-partner-activity.md)

**Do we have to contribute code?**
Not required by name, but the program asks for open source values, and contributions earn points.
[Contributing code back](contributing-code-back.md)

## Licensing

**Do we need a license to sell Exponential services?**
No. The software is GPL; anyone may build and sell services. The program adds recognition and benefits.
[Licensing for partners](licensing-for-partners.md)

**Can we use the help in our manuals?**
Yes, under the GFDL 1.3 or later. [Free documentation](../free-documentation.md)

## Open points

**Is there a code of conduct?**
Yes: the project's code of conduct, the Contributor Covenant 2.1 with Exponential additions for partners and
commercial conduct ([The Exponential code of conduct](../project/code-of-conduct.md)). How it applies to partner work:
[Partner code of conduct](partner-code-of-conduct.md).

# Taking part in the roadmap

This page is for partners who want to influence what is built next.

## What is published

- The community roadmap at <https://exponential.earth/about/roadmap> (read 18 October 2026) describes the community
  channels (Telegram, forums, GitHub, Slack, Discord) and invites people to "track development progress, report
  issues, request features, and contribute". It does not list dated product features.
- What has been built is published in detail: the changelogs in `doc/changelogs/` and the history in `doc/history/`
  ([The history of Exponential](../../history/README.md)).
- A dated product roadmap with commitments is not published: to be defined by the Foundation.

## How partners can influence it

| Way | Who | Source |
|---|---|---|
| Product roadmap requests | Silver, Gold, Platinum | <https://exponential.earth/partner/benefits> |
| "Transparency: Stay informed about our strategy and product roadmap" | All partners | <https://exponential.earth/partner/why> |
| Platinum: "roadmap influence" and "leadership involvement" (as worded on the why page) | Platinum / top tier | why page |
| Feature requests as public issues | Everyone | <https://github.com/se7enxweb/exponential/issues> |
| Pull requests with working code | Everyone | CONTRIBUTING.md |
| GitHub Sponsors tiers of 7x that include product backlog influence | Sponsors | [Sponsoring 7x on GitHub](../sponsors/sponsoring-7x.md) |

## Making a request that gets acted on

```text
Feature request: <short title>

Problem: <what users cannot do today, in their words>
Who has it: <how many customers / which kinds of sites> (no customer data)
Current workaround: <...>
Proposed behavior: <what should happen>
Scope: kernel / extension / documentation
Willing to contribute: code / testing / documentation / funding
```

The strongest request comes with a contribution: a prototype, tests, or funding
([Feature requests and sponsored features](feature-requests-and-sponsored-features.md)).

## What not to do

- Do not promise customers features because you requested them.
- Do not present your request as the project's roadmap in marketing.

# How do I embed another object in a text?

Embedding shows another object inside a text: a file to download, a video, a box with an article teaser. When that
object changes, every text that embeds it shows the change.

## Who can do this

Editors who may edit the object and read the object they embed.

## Steps

1. Edit the object and put the cursor where the embedded object goes.
2. Click **Insert/edit object**. For a file to download, click **Insert/edit file**.
3. Upload a new object, or find an existing one by searching, browsing or in your bookmarks, and select it.
4. Choose how it is shown (for example as a link or as a box) and the alignment.
5. Click **Insert**.
6. Click **Send for publishing**.

## What can go wrong

- **The embedded object disappears on the site.** It was hidden, moved to the trash or is in a section visitors may not
  read. **Setup** > **Broken relations** lists such cases.
- **You cannot remove the embedded object.** Exponential warns that other content embeds it. Remove the embed from
  those texts first.

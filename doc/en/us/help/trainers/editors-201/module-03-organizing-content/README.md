# Module 3: Organizing content

Editors who look after a part of a site restructure it from time to time. This module teaches the tools for that,
from a single move to a background job over hundreds of items, and the sections that decide who sees what.

## At a glance

| | |
|---|---|
| Course | [Editors 201](../README.md) |
| Duration | 3 hours 05 minutes (with two 10-minute breaks) |
| Lessons | 4 |
| Level | Intermediate |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [Lesson 3.1: Moving and copying](moving-and-copying.md) | 45 minutes | Move, copy and copy a subtree; move several items at once |
| [Lesson 3.2: Sorting sub items](sorting-sub-items.md) | 30 minutes | Set a folder's sorting, arrange items by priority with mouse and keyboard |
| [Lesson 3.3: Sections as the editor sees them](sections-for-editors.md) | 45 minutes | Read and set sections, predict the section of new and moved content |
| [Lesson 3.4: Large operations and the trash in depth](large-operations-and-the-trash.md) | 45 minutes | Remove a large folder as a background job, filter the trash, restore |

## Preparing this module

- Each learner needs a course folder with at least four items (lesson 3.2) and the folders from module 2.
- For lesson 3.3: a section learners may assign (for example *Training*, created under **Setup** > **Sections**),
  a role that allows assigning it, and a private browser window to look at the site as a visitor.
- For lesson 3.4: one folder `Old campaign` with 50 or more items per learner, and the content jobs cronjob part or a
  working background worker on the training installation (check one job before the class).
- Decide whether learners may use the jobs list (`content/jobs`); without it, show it yourself.

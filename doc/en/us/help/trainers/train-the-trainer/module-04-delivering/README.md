# Module 4: Delivering a course

This module is about the day itself: opening a course well, demonstrating without leaking anything, handling the
unexpected, and leaving learners able to help themselves. Most lessons are practised in small groups that take
turns as trainer, learner and observer.

## At a glance

| | |
|---|---|
| Course | [Train the trainer](../README.md) |
| Duration | 4 hours 15 minutes (six lessons) |
| Lessons | 6 |
| Level | Intermediate |
| Format | Practice in groups of three; one training installation per learner |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [4.1 Running the first hour](running-the-first-hour.md) | 60 min | Run an opening, first sign-in and password change |
| [4.2 Demonstrating safely](demonstrating-safely.md) | 40 min | Prepare a demo browser and run a safe demo |
| [4.3 Questions you cannot answer](questions-you-cannot-answer.md) | 30 min | Answer five questions with sources |
| [4.4 Troubleshooting in class](troubleshooting-in-class.md) | 50 min | Read logs, use maintenance mode, write a lab-fixes card |
| [4.5 Security and privacy in class](security-and-privacy-in-class.md) | 40 min | Check a lab's exposure and write a clean-up list |
| [4.6 Helping learners help themselves](helping-learners-help-themselves.md) | 35 min | Use context help and write a good forum question |

## Preparing this module

- A training installation per learner, installed with `exp:install` so that `var/log/initial-admin-password` exists
  for lesson 4.1.
- Administrator accounts (lesson 4.4 needs **Setup > Log files**).
- Printed: [Live demo safety](../../../advocates/live-demo-safety.md) and the troubleshooting table of lesson 4.4.

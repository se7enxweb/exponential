# Module 6: Templates and skins

The last module is about the look of a newsletter. Editors compare the shipped skins and learn the placeholders;
designers and developers write a skin of their own. Every check is a preview or a test written to a file.

## At a glance

| | |
|---|---|
| Course | [Newsletters with CJW Newsletter](../README.md) |
| Duration | 1 hour 45 minutes |
| Lessons | 2 |
| Level | Intermediate to advanced |

## Lessons

| Lesson | Duration | What learners do |
|---|---|---|
| [6.1 Skins and output formats](skins-and-output-formats.md) | 45 minutes | Compare the skins, add placeholders, preview as a subscriber |
| [6.2 Writing your own skin](writing-your-own-skin.md) | 60 minutes | Copy a skin into their design, register it, check it in a test file |

## Preparing this module

- [ ] `TransportMethodPreview=file` checked again in the settings viewer.
- [ ] For lesson 6.2: each designer has their own training installation with a design of their own active in the
      public siteaccess, and shell access.
- [ ] Each learner has an unsent edition and a subscriber with a first name (Dora from lesson 3.3).
- [ ] Editors who do not write templates can leave after lesson 6.1, or follow lesson 6.2 on the projector.

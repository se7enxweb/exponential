# Collect the node IDs the menus will use

The menu lists can be written in one go at launch.

*Life cycle: Plan, example 17 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [In the content tree](#in-the-content-tree)
3. [Which to choose](#which-to-choose)
4. [Check](#check)

## In the Layouts editor

1. Each page in the administration shows `Node <id> · Object <id> · Remote ID`.

## In the content tree

1. Write the node IDs into the plan per menu position; keep the remote IDs too, which stay the same when content is moved to another installation by package.

## Which to choose

Node IDs are what `MainMenuID[]` needs; layout exports refer to content by remote ID and path as well.

## Check

- Every planned menu entry has a node ID.

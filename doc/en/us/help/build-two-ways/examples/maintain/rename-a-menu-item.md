# Rename a header menu item

"Healthy eating" should read "Nutrition" in the menu.

*Life cycle: Maintain, example 7 of 35. Worked out on the Fit & Healthy site of Exponential 6.0.15+.*

## Contents

1. [In the Layouts editor](#in-the-layouts-editor)
2. [In the content tree](#in-the-content-tree)
3. [If the old name stays](#if-the-old-name-stays)
4. [Which to choose](#which-to-choose)
5. [Check](#check)

## In the Layouts editor

Not in the Layouts editor.

## In the content tree

1. Edit the page (Healthy eating, node 130), change its title, **Send for publishing**. The menu shows the new name; the URL alias follows the class's URL pattern.

## If the old name stays

1. Clear **Content** in the Clear cache box; the template prints the name at render time.

## Which to choose

Content: the menu follows the page.

## Check

- The header shows the new name on every page.

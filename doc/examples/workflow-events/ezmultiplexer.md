# The ezmultiplexer workflow event (Multiplexer)

Class `eZMultiplexerType` in `kernel/classes/workflowtypes/event/ezmultiplexer/ezmultiplexertype.php`; in a workflow it is the event type `event_ezmultiplexer`, listed in `settings/workflow.ini` `[EventSettings] AvailableEventTypes[]`.

## Use it

1. Setup > Workflows: create a workflow in a group and add the event "Multiplexer"; fill in its settings.
2. Setup > Triggers: connect the workflow to a trigger, for example `content / publish / before` (see the [triggers](triggers.md)).
3. Workflows that wait (approval, a date) continue when the cronjob part `frequent` runs `workflow.php` (see the [cronjobs](../cronjobs/README.md)).

To offer it (it is shipped in the list unless noted above):

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/workflow.ini.append.php
[EventSettings]
AvailableEventTypes[]=event_ezmultiplexer
*/ ?>
```

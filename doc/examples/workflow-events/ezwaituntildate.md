# The ezwaituntildate workflow event (Wait until date)

Class `eZWaitUntilDateType` in `kernel/classes/workflowtypes/event/ezwaituntildate/ezwaituntildatetype.php`; in a workflow it is the event type `event_ezwaituntildate`, listed in `settings/workflow.ini` `[EventSettings] AvailableEventTypes[]`.

It may be used on these triggers only (`setTriggerTypes()`): `content/publish (before, after)`.

## Use it

1. Setup > Workflows: create a workflow in a group and add the event "Wait until date"; fill in its settings.
2. Setup > Triggers: connect the workflow to a trigger, for example `content / publish / before` (see the [triggers](triggers.md)).
3. Workflows that wait (approval, a date) continue when the cronjob part `frequent` runs `workflow.php` (see the [cronjobs](../cronjobs/README.md)).

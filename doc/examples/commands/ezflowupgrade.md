# exp:ezflowupgrade

Upgrade the installed ezflow packages (--to-version, --package, --url).

Script `bin/php/ezflowupgrade.php`, code in `kernel/private/classes/commands/ezflowupgrade.php`. Run it from the installation root, as the user the web server runs as:

```bash
./console exp:ezflowupgrade --help
php bin/php/ezflowupgrade.php --help
```

## Options

| Option | Value | Help |
|---|---|---|
| `--to-version` | required | Specify what upgrade path to use.   available options: '1.1-0' - upgrade 1.0-0 to 1.1-0 |
| `--repository` | required | Path to repository where unpacked(unarchived) packages are  placed. it's relative to 'var/[site.ini].[FileSettings].[StorageDir]/[package.ini].[RepositorySettings].[RepositoryDirectory]'  (default is 'var/storage/packages/eZ-systems') |
| `--package` | required | Package(s) to install, f.e. 'ezflow_classes' |
| `--package-dir` | required | Path to directory with packed(ezpkg) packages(default is '/tmp/ezflow')  |
| `--url` | required | URL to download packages, f.e. 'http://packages.ez.no/Exponential/3.9'. 'package-dir' can be specified to store uploaded packages on local computer. if 'package-dir' is not specified then default dir('/tmp/ezflow') will be used. |
| `--auto-mode` | required | [on/off]. Do not ask what to do in case of confilicts. By default is 'on' |

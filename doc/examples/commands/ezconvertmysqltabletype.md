Convert the tables of a MySQL database to another table type (--list, --newtype=TYPE).

Script `bin/php/ezconvertmysqltabletype.php`, code in `kernel/private/classes/commands/ezconvertmysqltabletype.php`. Run it from the installation root, as the user the web server runs as:

| `--newtype` | required | Convert the database to the given type. Type can either be: myisam or innodb Make sure that you have made a BACKUP UP of YOUR DATABASE! |

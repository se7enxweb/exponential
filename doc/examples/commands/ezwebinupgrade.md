# exp:ezwebinupgrade

Upgrade an existing ezwebin installation to the current package version (--to-version).

Script `bin/php/ezwebinupgrade.php`, code in `kernel/private/classes/commands/ezwebinupgrade.php`. Run it from the installation root, as the user the web server runs as:

| Option | Value | Help |

| `--to-version` | required | Specify what upgrade path to use.   available options: '1.2-0' - upgrade 1.1-1 to 1.2-0                     '1.3-0' - upgrade 1.2-0 to 1.3-0                     '1.4-0' - upgrade 1.3-0 to 1.4-0 |

# exp:ezwebininstall

Install the ezwebin site package and configure the site.

Script `bin/php/ezwebininstall.php`, code in `kernel/private/classes/commands/ezwebininstall.php`. Run it from the installation root, as the user the web server runs as:

```bash
./console exp:ezwebininstall --help
php bin/php/ezwebininstall.php --help
```

## Options

| Option | Value | Help |
|---|---|---|
| `--repository` | required | Path to repository where unpacked(unarchived) packages are  placed. it's relative to 'var/[site.ini].[FileSettings].[StorageDir]/[package.ini].[RepositorySettings].[RepositoryDirectory]'  (default is 'var/storage/packages/ez_systems') |
| `--package` | required |  |
| `--package-dir` | required | Path to directory with packed(ezpkg) packages(default is '/tmp/ezwebin')  |
| `--url` | required | URL to download packages, f.e. 'http://packages.ez.no/Exponential/3.9'. 'package-dir' can be specified to store uploaded packages on local computer. if 'package-dir' is not specified then default dir('/tmp/ezwebin') will be used. |
| `--admin-siteaccess` | required | Will be used as base for eZWebin admin siteaccess |
| `--user-siteaccess` | required | Will be used as base for eZWebin user siteaccesses |
| `--auto-mode` | required | [on/off]. Do not ask what to do in case of confilicts. By default is 'on' |

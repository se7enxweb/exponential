# The ezmedia datatype (Media)

Class `eZMediaType` in `kernel/classes/datatypes/ezmedia/ezmediatype.php`; identifier `ezmedia`, listed in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## What it stores

The columns of the attribute tables its class reads or writes: `data_int1`, `data_text1` (`data_text`, `data_int`, `data_float` and `sort_key_*` are the object attribute's; `data_text1` ... `data_int4` the class attribute's settings). Found by reading the class: a heuristic.
It is can be filled from an uploaded file.

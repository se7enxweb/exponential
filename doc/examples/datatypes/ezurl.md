# The ezurl datatype (URL)

Class `eZURLType` in `kernel/classes/datatypes/ezurl/ezurltype.php`; identifier `ezurl`, listed in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## What it stores

The columns of the attribute tables its class reads or writes: `data_int`, `data_text`, `data_text1` (`data_text`, `data_int`, `data_float` and `sort_key_*` are the object attribute's; `data_text1` ... `data_int4` the class attribute's settings). Found by reading the class: a heuristic.

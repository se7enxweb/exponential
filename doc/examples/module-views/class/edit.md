# /class/edit

A view of the `class` module, defined in `kernel/class/module.php` and run by `kernel/class/edit.php`.

## Address

```text
/class/edit/<ClassID>/<GroupID>/<GroupName>/(language)/<Language>
```

Ordered parameters, in this order after the view name: `ClassID`, `GroupID`, `GroupName`.

Unordered parameters, in any order as `/(name)/value`: `(language)` sets `Language`.

## Who may open it

The view names no policy function, so the user needs a policy for the whole module: `class/*` (every function of the module) in one of the roles assigned to them.

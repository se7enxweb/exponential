# /state/view

A view of the `state` module, defined in `kernel/state/module.php` and run by `kernel/state/view.php`.

## Address

```text
/state/view/<GroupIdentifier>/<StateIdentifier>/<Language>
```

Ordered parameters, in this order after the view name: `GroupIdentifier`, `StateIdentifier`, `Language`.

## Who may open it

The user needs this policy function:

- [`state/administrate`](../../policies/state.md#administrate)

A policy on `state/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

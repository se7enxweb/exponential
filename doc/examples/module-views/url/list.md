# /url/list

A view of the `url` module, defined in `kernel/url/module.php` and run by `kernel/url/list.php`.

## Address

```text
/url/list/<ViewMode>/(offset)/<Offset>
```

Ordered parameters, in this order after the view name: `ViewMode`.

Unordered parameters, in any order as `/(name)/value`: `(offset)` sets `Offset`.

## Who may open it

The view names no policy function, so the user needs a policy for the whole module: `url/*` (every function of the module) in one of the roles assigned to them.

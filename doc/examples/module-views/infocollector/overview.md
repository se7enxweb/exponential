# /infocollector/overview

A view of the `infocollector` module, defined in `kernel/infocollector/module.php` and run by `kernel/infocollector/overview.php`.

## Address

```text
/infocollector/overview/(offset)/<Offset>
```

Unordered parameters, in any order as `/(name)/value`: `(offset)` sets `Offset`.

## Who may open it

The user needs this policy function:

- [`infocollector/read`](../../policies/infocollector.md#read)

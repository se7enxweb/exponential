# /package/view

A view of the `package` module, defined in `kernel/package/module.php` and run by `kernel/package/view.php`.

## Address

```text
/package/view/<ViewMode>/<PackageName>/<RepositoryID>
```

Ordered parameters, in this order after the view name: `ViewMode`, `PackageName`, `RepositoryID`.

## Who may open it

The user needs this policy function:

- [`package/read`](../../policies/package.md#read)

# /package/viewfile

A view of the `package` module, defined in `kernel/package/module.php` and run by `kernel/package/viewfile.php`.

## Address

```text
/package/viewfile/<PackageName>/<FileIndex>/<RepositoryID>
```

Ordered parameters, in this order after the view name: `PackageName`, `FileIndex`, `RepositoryID`.

## Who may open it

The user needs this policy function:

- [`package/read`](../../policies/package.md#read)

A policy on `package/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

## Example

A link in a template (`ezurl` adds the siteaccess and quotes the address); the parameter values are placeholders:

```tpl
<a href={'/package/viewfile/packagename/fileindex/1'|ezurl}>package/viewfile</a>
```

From PHP, the redirect a view gives after it has done its work:

```php
return $Module->redirectTo( '/package/viewfile/packagename/fileindex/1' );
```

# /collaboration/view

A view of the `collaboration` module, defined in `kernel/collaboration/module.php` and run by `kernel/collaboration/view.php`.

## Address

```text
/collaboration/view/<ViewMode>/(language)/<Language>/(offset)/<Offset>/(status)/<Status>/(role)/<Role>/(type)/<Type>/(group)/<Group>
```

Ordered parameters, in this order after the view name: `ViewMode`.

Unordered parameters, in any order as `/(name)/value`: `(language)` sets `Language`, `(offset)` sets `Offset`, `(status)` sets `Status`, `(role)` sets `Role`, `(type)` sets `Type`, `(group)` sets `Group`.

## Who may open it

The view names no policy function, so the user needs a policy for the whole module: `collaboration/*` (every function of the module) in one of the roles assigned to them.

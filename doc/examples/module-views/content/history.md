# /content/history

A view of the `content` module, defined in `kernel/content/module.php` and run by `kernel/content/history.php`.

## Address

```text
/content/history/<ObjectID>/<EditVersion>/(offset)/<Offset>
```

Ordered parameters, in this order after the view name: `ObjectID`, `EditVersion`.

Unordered parameters, in any order as `/(name)/value`: `(offset)` sets `Offset`.

## Who may open it

The user needs this policy function:

- [`content/read`](../../policies/content.md#read) or [`content/edit`](../../policies/content.md#edit)

A policy on `content/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

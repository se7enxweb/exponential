# /content/keyword

A view of the `content` module, defined in `kernel/content/module.php` and run by `kernel/content/keyword.php`.

## Address

```text
/content/keyword/<Alphabet>/(offset)/<Offset>/(classid)/<ClassID>
```

Ordered parameters, in this order after the view name: `Alphabet`.

Unordered parameters, in any order as `/(name)/value`: `(offset)` sets `Offset`, `(classid)` sets `ClassID`.

## Who may open it

The user needs this policy function:

- [`content/read`](../../policies/content.md#read)

A policy on `content/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

## Example

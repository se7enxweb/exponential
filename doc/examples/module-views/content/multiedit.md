# /content/multiedit

A view of the `content` module, defined in `kernel/content/module.php` and run by `kernel/content/multiedit.php`.

## Address

```text
/content/multiedit/(language)/<Language>
```

Unordered parameters, in any order as `/(name)/value`: `(language)` sets `Language`.

## Who may open it

The user needs this policy function:

- [`content/edit`](../../policies/content.md#edit)

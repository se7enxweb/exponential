# /content/versionview

A view of the `content` module, defined in `kernel/content/module.php` and run by `kernel/content/versionview.php`.

## Address

```text
/content/versionview/<ObjectID>/<EditVersion>/<LanguageCode>/<FromLanguage>/(language)/<Language>/(offset)/<Offset>/(site_access)/<SiteAccess>/(view_mode)/<ViewMode>
```

Ordered parameters, in this order after the view name: `ObjectID`, `EditVersion`, `LanguageCode`, `FromLanguage`.

Unordered parameters, in any order as `/(name)/value`: `(language)` sets `Language`, `(offset)` sets `Offset`, `(site_access)` sets `SiteAccess`, `(view_mode)` sets `ViewMode`.

## Who may open it

The user needs this policy function:

- [`content/versionread`](../../policies/content.md#versionread)

A policy on `content/*` (every function) also grants it; limitations of the policy (section, subtree, class ...) still apply where the view checks them.

# /error/view

A view of the `error` module, defined in `kernel/error/module.php` and run by `kernel/error/view.php`.

## Address

```text
/error/view/<Type>/<Number>/<ExtraParameters>
```

Ordered parameters, in this order after the view name: `Type`, `Number`, `ExtraParameters`.

## Who may open it

The view names no policy function, so the user needs a policy for the whole module: `error/*` (every function of the module) in one of the roles assigned to them.

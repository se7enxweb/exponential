# /layout/set

A view of the `layout` module, defined in `kernel/layout/module.php` and run by `kernel/layout/set.php`.

## Address

```text
/layout/set/<LayoutStyle>
```

Ordered parameters, in this order after the view name: `LayoutStyle`.

## Who may open it

Listed in `settings/site.ini` `[RoleSettings] PolicyOmitList[]`: no policy is checked, everyone may open it.
The view names no policy function, so the user needs a policy for the whole module: `layout/*` (every function of the module) in one of the roles assigned to them.

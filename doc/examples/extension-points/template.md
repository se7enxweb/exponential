# Extension points in template.ini

Settings of `settings/template.ini` whose name says they hold handlers, classes, filters, providers or directories that an extension can add to or replace. **Found by the setting's name: a heuristic.** Read the setting's comment (linked) before relying on it.

An extension adds to a list in its own `settings/template.ini.append.php` (active extensions' settings are read after the kernel's and before `settings/override`):

## AttributeOperator DefaultFormatter

Shipped: `html`. [The setting](../ini-settings/template/AttributeOperator.md#defaultformatter).

```ini
<?php /* #?ini charset="utf-8"?
# extension/expexample/settings/template.ini.append.php
[AttributeOperator]
DefaultFormatter=html    # replace with your class or value
*/ ?>
```

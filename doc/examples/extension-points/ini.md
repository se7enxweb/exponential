# Extension points in ini.ini

Settings of `settings/ini.ini` whose name says they hold handlers, classes, filters, providers or directories that an extension can add to or replace. **Found by the setting's name: a heuristic.** Read the setting's comment (linked) before relying on it.

An extension adds to a list in its own `settings/ini.ini.append.php` (active extensions' settings are read after the kernel's and before `settings/override`):

## IniCommandSettings ScopeProviders

Shipped: a list of 2: `expIniCoreScopeProvider`, `expIniExtensionScopeProvider`. [The setting](../ini-settings/ini/IniCommandSettings.md#scopeproviders).

```ini
<?php /* #?ini charset="utf-8"?
# extension/expexample/settings/ini.ini.append.php
[IniCommandSettings]
ScopeProviders[]=expExampleScopeProvider    # your class or value, added to the list
*/ ?>
```

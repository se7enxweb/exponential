# expservices.ini [Community]

The block `[Community]` of `extension/expservices/settings/expservices.ini` (extension expservices), with 8 setting(s).

Never edit `extension/expservices/settings/expservices.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/expservices.ini.append.php` for every siteaccess,

## ForumClass

> The community services (forum, topic, reply, comment, poll) work on content classes, by identifier.  
> Change them to run the services over the classes of another site.  

Default: `forum`.


# expservices.ini [Paging]

The block `[Paging]` of `extension/expservices/settings/expservices.ini` (extension expservices), with 2 setting(s).

> Domains are the \[ezjscServer\_exp<domain>\] blocks of ezjscore.ini whose Class extends expServiceBase.  

Never edit `extension/expservices/settings/expservices.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/expservices.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/expservices.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/expservices.ini.append.php` in an extension (read when the extension is active).

# audit.ini [AuditEventSettings]

The block `[AuditEventSettings]` of `settings/audit.ini`, with 4 setting(s).

Never edit `settings/audit.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/audit.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/audit.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/audit.ini.append.php` in an extension (read when the extension is active).

## Enabled

> Which events are recorded, by taxonomy pattern: a whole domain (content.\*), a subject  
> (content.node.\*), an action with its details (content.node.remove.\*) or one name.  
> The most specific pattern wins; on a tie the later line wins. Events marked "always"  
> in the catalogue (system.audit.\*, access.view.sensitive) ignore Disabled\[\].  

Default: a list of 33: `access.*`, `system.*`, `content.node.move`, `content.node.remove.*`, `content.node.hide`, `content.node.reveal`, `content.node.swap`, `content.node.section`, `content.object.remove`, `content.object.purge`, `content.object.restore`, `content.object.state` ....

## Branches

> Reads are switched on in \[AuditReadSettings\], not here.  
>
> Extensions register their taxonomy branches: name => the branch class (implements  
> expAuditTaxonomyBranch), which lists the names, their severity, channel and the  
> privacy of its own fields. Counted by the RAD survey (registry "auditbranches").  
> Branches\[myext\]=myExtAuditBranch  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditEventSettings]
# an empty "Branches[]" first replaces the shipped list; without it the items are added
Branches[]
*/ ?>
```

## MinSeverity

> The severity (RFC 5424 name) below which an event is not recorded at all.  
> debug | info | notice | warning | error | critical | alert | emergency  

Default: `info`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditEventSettings]
MinSeverity=info
*/ ?>
```

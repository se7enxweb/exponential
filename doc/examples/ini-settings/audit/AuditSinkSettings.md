# audit.ini [AuditSinkSettings]

The block `[AuditSinkSettings]` of `settings/audit.ini`, with 2 setting(s).

Never edit `settings/audit.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/audit.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/audit.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/audit.ini.append.php` in an extension (read when the extension is active).

## SinkClasses

> Sinks besides the file (which is always written). name => class implementing  
> expAuditSink. Extensions add their own (RAD survey registry "auditsinks").  

Default: a hash of 3: `syslog=expAuditSyslogSink`, `webhook=expAuditWebhookSink`, `mail=expAuditMailSink`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditSinkSettings]
# an empty "SinkClasses[]" first replaces the shipped list; without it the items are added
SinkClasses[]
SinkClasses[syslog]=expAuditSyslogSink
SinkClasses[webhook]=expAuditWebhookSink
SinkClasses[mail]=expAuditMailSink
*/ ?>
```

## SpoolDir

> Undeliverable batches wait here and are retried by the cronjob part.  

Default: `log/audit/spool`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/audit.ini.append.php
[AuditSinkSettings]
SpoolDir=log/audit/spool
*/ ?>
```

# wordtoimage.ini [WordToImageSettings]

The block `[WordToImageSettings]` of `settings/wordtoimage.ini`, with 3 setting(s).

Never edit `settings/wordtoimage.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/wordtoimage.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/wordtoimage.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/wordtoimage.ini.append.php` in an extension (read when the extension is active).

## IconRoot

Default: `/share/icons`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/wordtoimage.ini.append.php
[WordToImageSettings]
IconRoot=/share/icons
*/ ?>
```

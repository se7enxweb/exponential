# setup.ini [DemoSettings]

The block `[DemoSettings]` of `settings/setup.ini`, with 1 setting(s).

Never edit `settings/setup.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/setup.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/setup.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/setup.ini.append.php` in an extension (read when the extension is active).

## DataFile

Default: `var.tgz`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/setup.ini.append.php
[DemoSettings]
DataFile=var.tgz
*/ ?>
```

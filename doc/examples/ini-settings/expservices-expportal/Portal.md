# expportal.ini [Portal]

The block `[Portal]` of `extension/expservices/settings/expportal.ini` (extension expservices), with 6 setting(s).

> Settings of the portal frontends (designs expportal\_jquery and expportal\_reactive).  
> Node ids of the content roots each page reads. Change them per installation; defaults are the standard roots.  

Never edit `extension/expservices/settings/expportal.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/expportal.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/expportal.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/expportal.ini.append.php` in an extension (read when the extension is active).

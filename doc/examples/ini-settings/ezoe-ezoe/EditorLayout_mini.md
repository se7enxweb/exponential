# ezoe.ini [EditorLayout_mini]

The block `[EditorLayout_mini]` of `extension/ezoe/settings/ezoe.ini` (extension ezoe), with 2 setting(s).

> Example for Editor layout for mini editor  
> 'mini' is taken from TagPreset defined in ezxml.ini and  
> stored while editing the class on a attribute basis.  
> This feature is eZ Publish 4.1 and higher only!  

Never edit `extension/ezoe/settings/ezoe.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/ezoe.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/ezoe.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/ezoe.ini.append.php` in an extension (read when the extension is active).

## Buttons

Default: a list of 6: `bold`, `italic`, `underline`, `|`, `undo`, `redo`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/ezoe.ini.append.php
[EditorLayout_mini]
# an empty "Buttons[]" first replaces the shipped list; without it the items are added
Buttons[]
Buttons[]=bold
Buttons[]=italic
Buttons[]=underline
Buttons[]=|
Buttons[]=undo
Buttons[]=redo
*/ ?>
```

## PathLocation

Default: `none`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/ezoe.ini.append.php
[EditorLayout_mini]
PathLocation=none
*/ ?>
```

# ezoe.ini [Engine_tinymce8]

The block `[Engine_tinymce8]` of `extension/ezoe/settings/ezoe.ini` (extension ezoe), with 3 setting(s).

> TinyMCE 8 engine: \[EditorLayout\] button name => TinyMCE 8 toolbar item. Buttons with no counterpart are dropped.  

Never edit `extension/ezoe/settings/ezoe.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/ezoe.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/ezoe.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/ezoe.ini.append.php` in an extension (read when the extension is active).

## TableDialog

> Dialog of Insert table / Table properties in TinyMCE 8:  
> classic = the design of the TinyMCE 3 dialog (Properties tab, size grid, width and border with unit, class, custom attributes)  
> modern  = the TinyMCE 8 dialog (plain form fields)  

Default: `classic`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/ezoe.ini.append.php
[Engine_tinymce8]

*/ ?>
```

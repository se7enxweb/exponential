# ezoe.ini [SpellChecker]

The block `[SpellChecker]` of `extension/ezoe/settings/ezoe.ini` (extension ezoe), with 1 setting(s).

Never edit `extension/ezoe/settings/ezoe.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/ezoe.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/ezoe.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/ezoe.ini.append.php` in an extension (read when the extension is active).

## config

> Settings for TinyMCE SpellChecker  
> You need to enable the spellchecker plugin before these settings have any effect  
> Wiki: http://www.tinymce.com/wiki.php/Plugin:spellchecker  

Default: a hash of 1: `general.engine=GoogleSpell`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/ezoe.ini.append.php
[SpellChecker]
# an empty "config[]" first replaces the shipped list; without it the items are added
config[]
config[general.engine]=GoogleSpell
*/ ?>
```

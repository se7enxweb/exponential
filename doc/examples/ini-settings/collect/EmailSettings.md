# collect.ini [EmailSettings]

The block `[EmailSettings]` of `settings/collect.ini`, with 3 setting(s).

Never edit `settings/collect.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/collect.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/collect.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/collect.ini.append.php` in an extension (read when the extension is active).

## SendEmail

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/collect.ini.append.php
[EmailSettings]
SendEmail=enabled
*/ ?>
```

## SendEmailList

> Matches class id or identifier to information collection type  

Default: a hash of 1: `poll=disabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/collect.ini.append.php
[EmailSettings]
# an empty "SendEmailList[]" first replaces the shipped list; without it the items are added
SendEmailList[]
SendEmailList[poll]=disabled
*/ ?>
```

## SendEmailAttribute

> Which attribute to look for in the object to determine  
> if an email should be sent.  
> If found the setting will override all other settings.  

Default: `collection_email`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/collect.ini.append.php
[EmailSettings]
SendEmailAttribute=collection_email
*/ ?>
```

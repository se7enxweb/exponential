# fetchalias.ini [children]

The block `[children]` of `settings/fetchalias.ini`, with 3 setting(s).

> Fetch children  

Never edit `settings/fetchalias.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/fetchalias.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/fetchalias.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/fetchalias.ini.append.php` in an extension (read when the extension is active).

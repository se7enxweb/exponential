# wordmatch.ini [b]

The block `[b]` of `settings/wordmatch.ini`, with 1 setting(s).

Never edit `settings/wordmatch.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/wordmatch.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/wordmatch.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/wordmatch.ini.append.php` in an extension (read when the extension is active).

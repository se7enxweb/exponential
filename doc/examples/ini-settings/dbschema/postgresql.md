# dbschema.ini [postgresql]

The block `[postgresql]` of `settings/dbschema.ini`, with 1 setting(s).

> Make sure this table has delayed key write set when dumping SQL  

Never edit `settings/dbschema.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/dbschema.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/dbschema.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/dbschema.ini.append.php` in an extension (read when the extension is active).

## ColumnTypeTranslation

Default: a hash of 3: `ezprest_clients.version=int(1);int`, `ezpublishingqueueprocesses.pid=int(8);int`, `ezpublishingqueueprocesses.status=int(2);int`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/dbschema.ini.append.php
[postgresql]
# an empty "ColumnTypeTranslation[]" first replaces the shipped list; without it the items are added
ColumnTypeTranslation[]
ColumnTypeTranslation[ezprest_clients.version]=int(1);int
ColumnTypeTranslation[ezpublishingqueueprocesses.pid]=int(8);int
ColumnTypeTranslation[ezpublishingqueueprocesses.status]=int(2);int
*/ ?>
```

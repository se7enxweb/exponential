# admininterface.ini [ContentEditSettings]

The block `[ContentEditSettings]` of `settings/admininterface.ini`, with 1 setting(s).

Never edit `settings/admininterface.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/admininterface.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/admininterface.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/admininterface.ini.append.php` in an extension (read when the extension is active).

## LeftMenuParts

> Templates to include in the left menu of content/edit  
> for instance  
> LeftMenuParts\[\]=content/parts/advanced.tpl  
> will include "design:content/parts/advanced.tpl"  
> from design/admin/templates/content/edit\_menu.tpl  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/admininterface.ini.append.php
[ContentEditSettings]
# an empty "LeftMenuParts[]" first replaces the shipped list; without it the items are added
LeftMenuParts[]
*/ ?>
```

# content.ini [FetchSettings]

The block `[FetchSettings]` of `settings/content.ini`, with 1 setting(s).

Never edit `settings/content.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/content.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/content.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/content.ini.append.php` in an extension (read when the extension is active).

## DefaultClassFilterType

> The class filter type the fetch functions content/list, content/tree,  
> content/list\_count, content/tree\_count and content/calendar use when a fetch  
> gives class\_filter\_array without class\_filter\_type.  
> Empty (the default): the class filter array is ignored then, as before.  
> include: only the classes in the array; exclude: every class but those.  

Default: empty.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[FetchSettings]
DefaultClassFilterType=
*/ ?>
```

# content.ini [RSSListSettings]

The block `[RSSListSettings]` of `settings/content.ini`, with 1 setting(s).

Never edit `settings/content.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/content.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/content.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/content.ini.append.php` in an extension (read when the extension is active).

## ItemsPerPageList

> The page sizes the RSS list offers in its items per page selector. The first  
> is the one a visitor who has not chosen gets. A size that is not on this list  
> cannot be asked for in the url either, so the list is also what bounds the  
> query.  

Default: a list of 3: `25`, `50`, `250`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[RSSListSettings]
# an empty "ItemsPerPageList[]" first replaces the shipped list; without it the items are added
ItemsPerPageList[]
ItemsPerPageList[]=25
ItemsPerPageList[]=50
ItemsPerPageList[]=250
*/ ?>
```

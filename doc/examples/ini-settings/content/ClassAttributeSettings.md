# content.ini [ClassAttributeSettings]

The block `[ClassAttributeSettings]` of `settings/content.ini`, with 2 setting(s).

Never edit `settings/content.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/content.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/content.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/content.ini.append.php` in an extension (read when the extension is active).

## CategoryList

> List of attribute categories, by default used for grouping  
> attributes in edit interface.  
> Key is identifier and value is used in UI as name  
> Note: Limit on identifier is 25 charters!  

Default: a hash of 2: `content=Content`, `meta=Meta`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[ClassAttributeSettings]
# an empty "CategoryList[]" first replaces the shipped list; without it the items are added
CategoryList[]
CategoryList[content]=Content
CategoryList[meta]=Meta
*/ ?>
```

## DefaultCategory

> Default Category for attributes without or with invalid category  
> Note: Must be defined in CategoryList!  

Default: `content`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[ClassAttributeSettings]
DefaultCategory=content
*/ ?>
```

# content.ini [CopySettings]

The block `[CopySettings]` of `settings/content.ini`, with 6 setting(s).

Never edit `settings/content.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/content.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/content.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/content.ini.append.php` in an extension (read when the extension is active).

## MaxNodesCopySubtree

> Maximum number of nodes to copy using Copy Subtree feature

```ini

*/ ?>
```

## ClassRedirect

> Controls where it will redirect after copying a class  
> Use one of:  
> grouplist - Redirect to the main classgroup list  
> classlist - Redirect to group of the copied class  
> classedit - Redirect to edit mode of copied class  
> classview - Redirect to view mode of copied class  

Default: `classlist`.

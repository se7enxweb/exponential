# content.ini [NamePatternSettings]

The block `[NamePatternSettings]` of `settings/content.ini`, with 1 setting(s).

Never edit `settings/content.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/content.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/content.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/content.ini.append.php` in an extension (read when the extension is active).

## ResolverClasses

> PHP classes a content class's object name pattern or URL alias name pattern  
> may name in braces at its start, for example {myNameResolver} or  
> {myNameResolver} <title>: the class then makes the name. A listed class must  
> implement expNamePatternResolverInterface; a name that is not listed here is  
> ignored (and logged), and the pattern is resolved from its attribute tokens.  
> Empty by default.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/content.ini.append.php
[NamePatternSettings]
# an empty "ResolverClasses[]" first replaces the shipped list; without it the items are added
ResolverClasses[]
*/ ?>
```

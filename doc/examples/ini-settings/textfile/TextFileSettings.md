# textfile.ini [TextFileSettings]

The block `[TextFileSettings]` of `settings/textfile.ini`, with 11 setting(s).

Never edit `settings/textfile.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/textfile.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/textfile.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/textfile.ini.append.php` in an extension (read when the extension is active).

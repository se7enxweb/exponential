# menu.ini [MenuContentSettings]

The block `[MenuContentSettings]` of `settings/menu.ini`, with 2 setting(s).

Never edit `settings/menu.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/menu.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/menu.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/menu.ini.append.php` in an extension (read when the extension is active).

## TopIdentifierList

> This list contains the identifiers of the classse  
> that are allowed to be shown in top menues  

Default: a list of 4: `folder`, `feedback_form`, `gallery`, `forum`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/menu.ini.append.php
[MenuContentSettings]
# an empty "TopIdentifierList[]" first replaces the shipped list; without it the items are added
TopIdentifierList[]
TopIdentifierList[]=folder
TopIdentifierList[]=feedback_form
TopIdentifierList[]=gallery
TopIdentifierList[]=forum
*/ ?>
```

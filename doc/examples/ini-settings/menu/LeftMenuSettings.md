# menu.ini [LeftMenuSettings]

The block `[LeftMenuSettings]` of `settings/menu.ini`, with 1 setting(s).

> Controls the display of the left menu for the administration interface.  
> Width setting can be used to setup the widths (the measure is em) for the  
> different menu sizes (small/medium/large).  

Never edit `settings/menu.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/menu.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/menu.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/menu.ini.append.php` in an extension (read when the extension is active).

## MenuWidth

Default: a hash of 3: `small=13`, `medium=19`, `large=25`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/menu.ini.append.php
[LeftMenuSettings]
# an empty "MenuWidth[]" first replaces the shipped list; without it the items are added
MenuWidth[]
MenuWidth[small]=13
MenuWidth[medium]=19
MenuWidth[large]=25
*/ ?>
```

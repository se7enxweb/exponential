# menu.ini [NavigationPart]

The block `[NavigationPart]` of `settings/menu.ini`, with 1 setting(s).

> A list of the current navigation parts and their names  
> Each entry consists of the identifier as key and the name  
> as value.  
> Note: If you wish to have the name translatable you will  
>       need to create a dummy PHP file with the following in it  
> ezpI18n::tr( 'kernel/navigationpart', 'Custom navigation', 'Navigation part' );  
> This will cause the ezlupdate to include it in the .ts file.  

Never edit `settings/menu.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/menu.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/menu.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/menu.ini.append.php` in an extension (read when the extension is active).

## Part

Default: a hash of 8: `ezcontentnavigationpart=Content structure`, `ezmedianavigationpart=Media library`, `ezusernavigationpart=User accounts`, `ezshopnavigationpart=Webshop`, `ezvisualnavigationpart=Design`, `ezsetupnavigationpart=Setup`, `ezmynavigationpart=My account`, `expauditnavigationpart=Audit`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/menu.ini.append.php
[NavigationPart]
# an empty "Part[]" first replaces the shipped list; without it the items are added
Part[]
Part[ezcontentnavigationpart]=Content structure
Part[ezmedianavigationpart]=Media library
Part[ezusernavigationpart]=User accounts
Part[ezshopnavigationpart]=Webshop
Part[ezvisualnavigationpart]=Design
Part[ezsetupnavigationpart]=Setup
Part[ezmynavigationpart]=My account
Part[expauditnavigationpart]=Audit
*/ ?>
```

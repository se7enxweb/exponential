# layout.ini [fullscreen]

The block `[fullscreen]` of `settings/layout.ini`, with 1 setting(s).

Never edit `settings/layout.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/layout.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/layout.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/layout.ini.append.php` in an extension (read when the extension is active).

## PageLayout

Default: `fullscreen_pagelayout.tpl`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/layout.ini.append.php
[fullscreen]
PageLayout=fullscreen_pagelayout.tpl
*/ ?>
```

# units.ini [BinaryPrefixes]

The block `[BinaryPrefixes]` of `settings/units.ini`, with 6 setting(s).

> Each entry is an array with the factor value and the symbol  
> The factor used for calculating values in the power of 2  

Never edit `settings/units.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/units.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/units.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/units.ini.append.php` in an extension (read when the extension is active).

# subitems.ini [Preset_seo]

The block `[Preset_seo]` of `settings/subitems.ini`, with 2 setting(s).

> Presets: a named set of visible columns everybody can choose in Table options. Users save their  
> own presets next to these (in their preferences); a user preset cannot take an INI preset's id.  
> \[Preset\_<id>\]   id: a-z, 0-9, \_ and -  
> Name=           the name shown (translated with the context design/admin/node/view/full)  
> Columns\[\]       the visible columns, in order  

Never edit `settings/subitems.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/subitems.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/subitems.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/subitems.ini.append.php` in an extension (read when the extension is active).

## Name

Default: `SEO`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/subitems.ini.append.php
[Preset_seo]
Name=SEO
*/ ?>
```

## Columns

Default: a list of 5: `name`, `urlalias`, `pagetitle`, `systemurl`, `visibility`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/subitems.ini.append.php

# an empty "Columns[]" first replaces the shipped list; without it the items are added

Columns[]=urlalias
```

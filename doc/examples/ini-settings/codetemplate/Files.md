# codetemplate.ini [Files]

The block `[Files]` of `settings/codetemplate.ini`, with 2 setting(s).

Never edit `settings/codetemplate.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/codetemplate.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/codetemplate.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/codetemplate.ini.append.php` in an extension (read when the extension is active).

## Templates

Default: a hash of 2: `can-instantiate-class-list=templates/classcreatelist.ctpl`, `class-list-from-policy=templates/classlistfrompolicy.ctpl`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/codetemplate.ini.append.php
[Files]
# an empty "Templates[]" first replaces the shipped list; without it the items are added
Templates[]
Templates[can-instantiate-class-list]=templates/classcreatelist.ctpl
Templates[class-list-from-policy]=templates/classlistfrompolicy.ctpl
*/ ?>
```

# module.ini [ModuleOverrides]

The block `[ModuleOverrides]` of `settings/module.ini`, with 1 setting(s).

> This controls overriding of navigations parts defined  
> module.php or by dynamic code.  
>
> You can use the module name alone or with a view  

Never edit `settings/module.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/module.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/module.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/module.ini.append.php` in an extension (read when the extension is active).

## NavigationPart

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/module.ini.append.php
[ModuleOverrides]
# an empty "NavigationPart[]" first replaces the shipped list; without it the items are added
NavigationPart[]
*/ ?>
```

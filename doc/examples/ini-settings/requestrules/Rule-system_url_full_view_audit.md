# requestrules.ini [Rule-system_url_full_view_audit]

The block `[Rule-system_url_full_view_audit]` of `settings/requestrules.ini`, with 4 setting(s).

Never edit `settings/requestrules.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/requestrules.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/requestrules.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/requestrules.ini.append.php` in an extension (read when the extension is active).

## Description

Default: `Writes a line to var/log/requestrules.log for every full view typed as its system URL by a user without content/view_system_url, and changes nothing. Put it first to see who would be affected before switching a stricter rule on.`.

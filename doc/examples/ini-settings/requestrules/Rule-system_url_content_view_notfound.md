# requestrules.ini [Rule-system_url_content_view_notfound]

The block `[Rule-system_url_content_view_notfound]` of `settings/requestrules.ini`, with 3 setting(s).

Never edit `settings/requestrules.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/requestrules.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/requestrules.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/requestrules.ini.append.php` in an extension (read when the extension is active).

## Description

Default: `Every content view typed as its system URL (any view mode) is not found, unless the user has the policy content/view_system_url.`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/requestrules.ini.append.php

Description=Every content view typed as its system URL (any view mode) is not found, unless the user has the policy content/view_system_url.
*/ ?>
```

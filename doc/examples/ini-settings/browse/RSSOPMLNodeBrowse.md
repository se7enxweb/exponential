# browse.ini [RSSOPMLNodeBrowse]

The block `[RSSOPMLNodeBrowse]` of `settings/browse.ini`, with 4 setting(s).

> Action used to point an OPML outline at a content node instead of a feed,  
> from the Browse content button on rss/edit\_export. Without this section  
> eZContentBrowse::browse() has no StartNode to read, so content/browse opens  
> on nothing and answers 404 - the button appears to do nothing at all.  
> Same shape as RSSObjectBrowse: one node, returned as a node id.  

Never edit `settings/browse.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/browse.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/browse.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/browse.ini.append.php` in an extension (read when the extension is active).

## StartNode

Default: `content`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/browse.ini.append.php
[RSSOPMLNodeBrowse]
StartNode=content
*/ ?>
```

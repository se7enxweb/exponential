# mime.ini [exe]

The block `[exe]` of `settings/mime.ini`, with 1 setting(s).

Never edit `settings/mime.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/mime.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/mime.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/mime.ini.append.php` in an extension (read when the extension is active).

## Types

Default: a list of 1: `application/octet-stream`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/mime.ini.append.php
[exe]
# an empty "Types[]" first replaces the shipped list; without it the items are added
Types[]
Types[]=application/octet-stream
*/ ?>
```

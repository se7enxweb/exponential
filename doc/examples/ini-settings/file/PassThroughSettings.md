# file.ini [PassThroughSettings]

The block `[PassThroughSettings]` of `settings/file.ini`, with 2 setting(s).

> Optional DB table name caches should be stored to  
> This is useful for staging use cases where the storage entries and DB are shared  
> across different Exponential installations, but the caches should not.  
> MetaDataTableNameCache=  

Never edit `settings/file.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/file.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/file.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/file.ini.append.php` in an extension (read when the extension is active).

## DefaultContentDisposition

> The default value for mime types not specified using ContentDisposition  
> is "attachment". Possible values are attachment or inline.  

Default: `attachment`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/file.ini.append.php
[PassThroughSettings]
DefaultContentDisposition=attachment
*/ ?>
```

## ContentDisposition

Default: a hash of 4: `application/x-shockwave-flash=inline`, `video/ogg=inline`, `video/mp4=inline`, `video/webm=inline`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/file.ini.append.php
[PassThroughSettings]
# an empty "ContentDisposition[]" first replaces the shipped list; without it the items are added
ContentDisposition[]
ContentDisposition[application/x-shockwave-flash]=inline
ContentDisposition[video/ogg]=inline
ContentDisposition[video/mp4]=inline
ContentDisposition[video/webm]=inline
*/ ?>
```

# logviewer.ini [RedactionSettings]

The block `[RedactionSettings]` of `settings/logviewer.ini`, with 5 setting(s).

Never edit `settings/logviewer.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/logviewer.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/logviewer.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/logviewer.ini.append.php` in an extension (read when the extension is active).

## MaskEmails

> Mask in what the viewer shows: e-mail addresses, IP addresses, and secrets (passwords in addresses and  
> pairs, tokens, keys, session ids, cookies). A user with setup/unmasklogs can switch masking off for  
> themselves on the page; the secrets of the settings below never are.  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/logviewer.ini.append.php
[RedactionSettings]
MaskEmails=enabled
*/ ?>
```

## SecretSettings

> The settings whose values are never shown, even unmasked: <file>;<group>;<variable>. Every value of them  
> that occurs in a log line is replaced by \*\*\*. Variables whose name says they hold a secret (Password,  
> Secret, Token, Key ...) in these groups are covered too.  

Default: a list of 2: `site.ini;DatabaseSettings;Password`, `site.ini;MailSettings;TransportPassword`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/logviewer.ini.append.php
[RedactionSettings]
# an empty "SecretSettings[]" first replaces the shipped list; without it the items are added
SecretSettings[]
SecretSettings[]=site.ini;DatabaseSettings;Password
SecretSettings[]=site.ini;MailSettings;TransportPassword
*/ ?>
```

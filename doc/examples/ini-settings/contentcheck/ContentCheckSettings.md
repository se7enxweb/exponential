# contentcheck.ini [ContentCheckSettings]

The block `[ContentCheckSettings]` of `settings/contentcheck.ini`, with 2 setting(s).

Never edit `settings/contentcheck.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/contentcheck.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/contentcheck.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/contentcheck.ini.append.php` in an extension (read when the extension is active).

## Enabled

> true | false. With false the checks answer 404 on every siteaccess.  

Default: `true`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/contentcheck.ini.append.php
[ContentCheckSettings]
Enabled=true
*/ ?>
```

## SiteAccessList

> The siteaccesses the checks answer on. Empty (the default): every siteaccess whose design  
> list (\[DesignSettings\] SiteDesign, AdditionalSiteDesignList\[\]) has an administration design  
> (a design whose name starts with admin). Every other siteaccess answers 404.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/contentcheck.ini.append.php
[ContentCheckSettings]
# an empty "SiteAccessList[]" first replaces the shipped list; without it the items are added
SiteAccessList[]
*/ ?>
```

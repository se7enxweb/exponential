# template.ini [SimpleTagsOperator]

The block `[SimpleTagsOperator]` of `settings/template.ini`, with 3 setting(s).

> Configuration for the 'simpletags' template operator  

Never edit `settings/template.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/template.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/template.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/template.ini.append.php` in an extension (read when the extension is active).

## Extensions

> A list of extension which should be examined for  
> extra includes  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/template.ini.append.php
[SimpleTagsOperator]
# an empty "Extensions[]" first replaces the shipped list; without it the items are added
Extensions[]
*/ ?>
```

## IncludeList

> A list of PHP files that should be included when the  
> 'simpletags' operator is used.  
> It will look in kernel/classes/simpletags or the simpletags  
> subdirectory of an extension (must be defined in Extensions)  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/template.ini.append.php
[SimpleTagsOperator]
# an empty "IncludeList[]" first replaces the shipped list; without it the items are added
IncludeList[]
*/ ?>
```

## TagList

> The default setting for everything that is considered normal text,  
> ie. text not inside tags.  
> Defines literal, strong and emphasize tags  

Default: a hash of 5: `text=;;htmlspecialchars,nl2br`, `literal=<pre>;</pre>;htmlspecialchars`, `code=<pre class="code">;</pre>;htmlspecialchars`, `strong=<b>;</b>;htmlspecialchars,nl2br`, `emphasize=<i>;</i>;htmlspecialchars,nl2br`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/template.ini.append.php
[SimpleTagsOperator]
# an empty "TagList[]" first replaces the shipped list; without it the items are added
TagList[]
TagList[text]=;;htmlspecialchars,nl2br
TagList[literal]=<pre>;</pre>;htmlspecialchars
TagList[code]=<pre class="code">;</pre>;htmlspecialchars
TagList[strong]=<b>;</b>;htmlspecialchars,nl2br
TagList[emphasize]=<i>;</i>;htmlspecialchars,nl2br
*/ ?>
```

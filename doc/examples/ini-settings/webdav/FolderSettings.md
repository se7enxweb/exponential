# webdav.ini [FolderSettings]

The block `[FolderSettings]` of `settings/webdav.ini`, with 1 setting(s).

> FolderClasses\[\]=article  
> FolderClasses\[\]=your\_custom\_class  
> DEPRECATED: WebDAV will use the settings in upload.ini  
>
> This setting reveales the ID of the folder class.  
> In addition, it is also used to determine which  
> attribute to use when creating/naming/renaming the folder.  

Never edit `settings/webdav.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/webdav.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/webdav.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/webdav.ini.append.php` in an extension (read when the extension is active).

## FolderClass

Default: `1`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/webdav.ini.append.php
[FolderSettings]
FolderClass=1
*/ ?>
```

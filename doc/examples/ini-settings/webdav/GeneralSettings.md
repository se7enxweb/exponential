# webdav.ini [GeneralSettings]

The block `[GeneralSettings]` of `settings/webdav.ini`, with 4 setting(s).

Never edit `settings/webdav.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/webdav.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/webdav.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/webdav.ini.append.php` in an extension (read when the extension is active).

## EnableWebDAV

Default: `false`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/webdav.ini.append.php
[GeneralSettings]
EnableWebDAV=false
*/ ?>
```

## Logging

Default: `disabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/webdav.ini.append.php

Logging=disabled
*/ ?>
```

## StartNode

> Custom start node for WebDAV operations.  
> By default it is /site/Content (NodeID 2).  

Default: `2`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/webdav.ini.append.php
[GeneralSettings]
StartNode=2
*/ ?>
```

## FolderClasses

> List of classes that should always be seen as a folder.  
> By default, if a class contains an image attribute it is seen as an image.  

Default: a list of 1: `folder`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/webdav.ini.append.php
[GeneralSettings]
# an empty "FolderClasses[]" first replaces the shipped list; without it the items are added
FolderClasses[]
FolderClasses[]=folder
*/ ?>
```

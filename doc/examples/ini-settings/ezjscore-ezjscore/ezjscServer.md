# ezjscore.ini [ezjscServer]

The block `[ezjscServer]` of `extension/ezjscore/settings/ezjscore.ini` (extension ezjscore), with 1 setting(s).

> Example: Serve javascript files from static sub domain (No end slash!)  
> CustomHosts\[.js\]=http://static.example.com  

Never edit `extension/ezjscore/settings/ezjscore.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/ezjscore.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/ezjscore.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/ezjscore.ini.append.php` in an extension (read when the extension is active).

## FunctionList

> List of permission functions as used by the Exponential permission system  
> ezjscnode::load, ::subtree and ::updatepriority, when \[ezjscServer\_ezjscnode\] RequirePolicy=enabled  
> ezajaxuploader (the AJAX uploader of relation attributes), when \[ezjscServer\_ezajaxuploader\] RequirePolicy=enabled  

Default: a list of 3: `ezjsctemplate`, `ezjscnode`, `ezajaxuploader`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/ezjscore.ini.append.php
[ezjscServer]
# an empty "FunctionList[]" first replaces the shipped list; without it the items are added
FunctionList[]
FunctionList[]=ezjsctemplate
FunctionList[]=ezjscnode
FunctionList[]=ezajaxuploader
*/ ?>
```

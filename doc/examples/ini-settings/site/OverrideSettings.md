# site.ini [OverrideSettings]

The block `[OverrideSettings]` of `settings/site.ini`, with 1 setting(s).

> since 5.3 it is possible to define a list with the dataypes containing prices  
> This will allow you to define your own price datatypes and work with them  
> in the shop module  
> Setting is commented out by default  
> ProductDatatypeStringList\[\]  
> ProductDatatypeStringList\[\]=ezprice  
> ProductDatatypeStringList\[\]=ezmultiprice  
> ProductDatatypeStringList\[\]=customprice  

Never edit `settings/site.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/site.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/site.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/site.ini.append.php` in an extension (read when the extension is active).

## Cache

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[OverrideSettings]
Cache=enabled
*/ ?>
```

# site.ini [SetupSettings]

The block `[SetupSettings]` of `settings/site.ini`, with 5 setting(s).

Never edit `settings/site.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/site.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/site.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/site.ini.append.php` in an extension (read when the extension is active).

## AllowWizardOnInstalledSite

> The setup wizard (setup/init) on a site that is already installed: disabled  
> shows a page that says so and changes nothing. enabled is for development  
> only: the wizard then runs after a confirm page, and the site goes into  
> maintenance mode once that page is posted. Reinstalling a site is done with  
> the kickstarter or a fresh installation.  

Default: `disabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/site.ini.append.php
[SetupSettings]
AllowWizardOnInstalledSite=disabled
*/ ?>
```

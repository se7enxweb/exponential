# ezxml.ini [TagSettings]

The block `[TagSettings]` of `settings/ezxml.ini`, with 1 setting(s).

> AliasClasses\[eZXHTMLXMLOutput\]=eZPlainXMLOutput  

Never edit `settings/ezxml.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/ezxml.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/ezxml.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/ezxml.ini.append.php` in an extension (read when the extension is active).

## TagPresets

> Defines presets of allowed tags, currently only used by Online Editor 5.0  
> to have different type of editors(aka it only limits the visible buttons,  
> not what you can copy/past or manually enter in code editor)  
> Setting is selectable in class/edit if TagPreset has values.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/ezxml.ini.append.php
[TagSettings]
# an empty "TagPresets[]" first replaces the shipped list; without it the items are added
TagPresets[]
*/ ?>
```

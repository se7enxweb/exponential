# ezxml.ini [OutputSettings]

The block `[OutputSettings]` of `settings/ezxml.ini`, with 2 setting(s).

Never edit `settings/ezxml.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/ezxml.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/ezxml.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/ezxml.ini.append.php` in an extension (read when the extension is active).

## HandlerClass

> Which output handler to use, ezxhtml is the default  
> ezplain can be used to see raw xml data.  

Default: `eZXHTMLXMLOutput`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/ezxml.ini.append.php
[OutputSettings]
HandlerClass=eZXHTMLXMLOutput
*/ ?>
```

## AliasClasses

> HandlerClass=eZPlainXMLOutput  

Default: a hash of 1: `ezpdf=eZPDFXMLOutput`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/ezxml.ini.append.php
[OutputSettings]
# an empty "AliasClasses[]" first replaces the shipped list; without it the items are added
AliasClasses[]
AliasClasses[ezpdf]=eZPDFXMLOutput
*/ ?>
```

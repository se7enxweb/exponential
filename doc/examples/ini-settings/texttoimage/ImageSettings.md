# texttoimage.ini [ImageSettings]

The block `[ImageSettings]` of `settings/texttoimage.ini`, with 1 setting(s).

Never edit `settings/texttoimage.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/texttoimage.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/texttoimage.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/texttoimage.ini.append.php` in an extension (read when the extension is active).

## UseCache

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/texttoimage.ini.append.php
[ImageSettings]
UseCache=enabled
*/ ?>
```

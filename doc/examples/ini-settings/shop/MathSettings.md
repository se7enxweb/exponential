# shop.ini [MathSettings]

The block `[MathSettings]` of `settings/shop.ini`, with 5 setting(s).

Never edit `settings/shop.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/shop.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/shop.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/shop.ini.append.php` in an extension (read when the extension is active).

## MathHandler

> eZPHPMath   - using php floating point calculations  
> eZBCMath    - using bcmath extension.  

Default: `eZPHPMath`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/shop.ini.append.php
[MathSettings]
MathHandler=eZPHPMath
*/ ?>
```

## RoundingTarget

> RoundingTarget forces rounding for specified target.  
> Example:  
> input: number = 89.468543  
>        precision = 2  
>        target\_1 = 5  
>        target\_2 = 99  
> usual rounding: round( number, precision ) = 89.47  
> apply target\_1: round( number, precision, target ) = 89.45  
> apply target\_2: round( number, precision, target ) = 89.99  
> values:  
>   numeric, e.g. 1,2,...  
>   false  

Default: `false`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/shop.ini.append.php
[MathSettings]
RoundingTarget=false
*/ ?>
```

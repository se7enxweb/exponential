# image.ini [GDSettings]

The block `[GDSettings]` of `settings/image.ini`, with 1 setting(s).

Never edit `settings/image.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/image.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/image.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/image.ini.append.php` in an extension (read when the extension is active).

## HasGD2

> If set to true more advanced functionality will be available  
> which is present in GD2. This requires GD2 to be compiled in  
> the PHP module.  
> This only decides whether the texttoimage layers are drawn as  
> true colour or palette images. It does not affect the GD  
> image converter (\[GD\] below), which keeps the colour type of  
> the image it converts.  

Default: `false`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[GDSettings]
HasGD2=false
*/ ?>
```

> -------- Image MIME type settings --------  

Never edit `settings/image.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/image.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/image.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/image.ini.append.php` in an extension (read when the extension is active).

## OverrideList

> A list of settings which override certain MIME types  
> The overrides can define allowed and disallowed filters  
> as well as extra filters.l  

Default: a list of 2: `AnimatedGIF`, `LayeredPhotoshop`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[MIMETypeSettings]
# an empty "OverrideList[]" first replaces the shipped list; without it the items are added
OverrideList[]
OverrideList[]=AnimatedGIF
OverrideList[]=LayeredPhotoshop
*/ ?>
```

## Quality

> A list of mimetypes and their image quality value  
> The value varies from mime type to mime type.  
> Set JPEG quality from 0 (worst quality, smallest file) to 100 (best quality, biggest file)  

Default: a list of 1: `image/jpeg;75`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[MIMETypeSettings]
# an empty "Quality[]" first replaces the shipped list; without it the items are added
Quality[]
Quality[]=image/jpeg;75
*/ ?>
```

## ConversionRules

> The global conversion rules  
> Most will be converted to jpeg except gif and xpms  

Default: a list of 4: `image/webp;image/png`, `image/gif;image/png`, `image/x-xpixmap;image/png`, `*;image/jpeg`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[MIMETypeSettings]
# an empty "ConversionRules[]" first replaces the shipped list; without it the items are added
ConversionRules[]
ConversionRules[]=image/webp;image/png
ConversionRules[]=image/gif;image/png
ConversionRules[]=image/x-xpixmap;image/png
ConversionRules[]=*;image/jpeg
*/ ?>
```

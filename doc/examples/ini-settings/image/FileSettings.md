# image.ini [FileSettings]

The block `[FileSettings]` of `settings/image.ini`, with 5 setting(s).

Never edit `settings/image.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/image.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/image.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/image.ini.append.php` in an extension (read when the extension is active).

## TemporaryDir

> Which subdirectory of var/cache to use for temporary image files.  

Default: `imagetmp`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[FileSettings]
TemporaryDir=imagetmp
*/ ?>
```

## DirPermissions

> Permission for new image directories, setting it to 0777 means that anyone  
> can read and write the files and can be considered a security risk.  
> It's preferred to use 0770 and make sure the web server has correct  
> user/group access.  

Default: `0777`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[FileSettings]
DirPermissions=0777
*/ ?>
```

## ImagePermissions

> Permission for new images, setting it to 0666 means that anyone  
> can read and write the files and can be considered a security risk.  
> It's preferred to use 0660 and make sure the web server has correct  
> user/group access.  

Default: `0666`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/image.ini.append.php
[FileSettings]
ImagePermissions=0666
*/ ?>
```

# workflow.ini [EventSettings]

The block `[EventSettings]` of `settings/workflow.ini`, with 3 setting(s).

Never edit `settings/workflow.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/workflow.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/workflow.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/workflow.ini.append.php` in an extension (read when the extension is active).

## RepositoryDirectories

> A list of directories to check for workflow eventtypes  

Default: a list of 1: `kernel/classes/workflowtypes`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/workflow.ini.append.php
[EventSettings]
# an empty "RepositoryDirectories[]" first replaces the shipped list; without it the items are added
RepositoryDirectories[]
RepositoryDirectories[]=kernel/classes/workflowtypes
*/ ?>
```

## ExtensionDirectories

> A list of extensions which have workflow events  
> It's common to create a settings/workflow.ini.append file  
> in your extension and add the extension name to automatically  
> get workflow events from the extension when it's turned on.  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/workflow.ini.append.php
[EventSettings]
# an empty "ExtensionDirectories[]" first replaces the shipped list; without it the items are added
ExtensionDirectories[]
*/ ?>
```

## AvailableEventTypes

> A list of events, each entry consists of the group  
> and the name with a \_ as separator  

Default: a list of 6: `event_ezapprove`, `event_ezwaituntildate`, `event_ezsimpleshipping`, `event_ezmultiplexer`, `event_ezpaymentgateway`, `event_ezfinishuserregister`.

```ini

# settings/override/workflow.ini.append.php

# an empty "AvailableEventTypes[]" first replaces the shipped list; without it the items are added
AvailableEventTypes[]
AvailableEventTypes[]=event_ezapprove
```

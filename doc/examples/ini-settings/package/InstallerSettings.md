# package.ini [InstallerSettings]

The block `[InstallerSettings]` of `settings/package.ini`, with 4 setting(s).

Never edit `settings/package.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/package.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/package.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/package.ini.append.php` in an extension (read when the extension is active).

## HandlerList

> A list of extensions which have package installation handlers support  
> The extension must place package creation handlers in the  
> subdirectory packageinstallers.  

Default: a list of 2: `ezcontentobject`, `ezinstallscript`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/package.ini.append.php
[InstallerSettings]
# an empty "HandlerList[]" first replaces the shipped list; without it the items are added
HandlerList[]
HandlerList[]=ezcontentobject
HandlerList[]=ezinstallscript
*/ ?>
```

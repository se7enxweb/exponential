# exphelp.ini [DashboardSettings]

The block `[DashboardSettings]` of `settings/exphelp.ini`, with 3 setting(s).

Never edit `settings/exphelp.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/exphelp.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/exphelp.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/exphelp.ini.append.php` in an extension (read when the extension is active).

## RecentLimit

> How many recent changes below the roots the dashboard lists  

Default: `8`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/exphelp.ini.append.php
[DashboardSettings]
RecentLimit=8
*/ ?>
```

## AudiencePageLimit

> How many pages each audience card lists  

Default: `4`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/exphelp.ini.append.php
[DashboardSettings]
AudiencePageLimit=4
*/ ?>
```

## AudienceExcludeTypes

> Page types the audience cards never list (they are found through the search and the categories)  

Default: a list of 6: `changelog`, `history`, `bc`, `specification`, `generated`, `catalogue`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/exphelp.ini.append.php
[DashboardSettings]
# an empty "AudienceExcludeTypes[]" first replaces the shipped list; without it the items are added
AudienceExcludeTypes[]
AudienceExcludeTypes[]=changelog
AudienceExcludeTypes[]=history
AudienceExcludeTypes[]=bc
AudienceExcludeTypes[]=specification
AudienceExcludeTypes[]=generated
AudienceExcludeTypes[]=catalogue
*/ ?>
```

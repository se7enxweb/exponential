# binaryfile.ini [HandlerSettings]

The block `[HandlerSettings]` of `settings/binaryfile.ini`, with 3 setting(s).

> Here you can add handlers for new datatypes.  

Never edit `settings/binaryfile.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/binaryfile.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/binaryfile.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/binaryfile.ini.append.php` in an extension (read when the extension is active).

## MetaDataExtractor

Default: a hash of 3: `text/plain=ezplaintext`, `application/pdf=ezpdf`, `application/msword=ezword`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/binaryfile.ini.append.php
[HandlerSettings]
# an empty "MetaDataExtractor[]" first replaces the shipped list; without it the items are added
MetaDataExtractor[]
MetaDataExtractor[text/plain]=ezplaintext
MetaDataExtractor[application/pdf]=ezpdf
MetaDataExtractor[application/msword]=ezword
*/ ?>
```

## ExtensionRepositories

> A list of extensions which have metadata extractor handlers  
> It's common to create a settings/binaryfile.ini.append.php file  
> in your extension and add the extension name to automatically  
> get handlers from the extension when it's turned on.  
> Handlers need to be placed in the extension subdir "plugins".  

Default: an empty list.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/binaryfile.ini.append.php
[HandlerSettings]
# an empty "ExtensionRepositories[]" first replaces the shipped list; without it the items are added
ExtensionRepositories[]
*/ ?>
```

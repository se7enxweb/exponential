# querycache.ini [DebugSettings]

The block `[DebugSettings]` of `settings/querycache.ini`, with 1 setting(s).

Never edit `settings/querycache.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/querycache.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/querycache.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/querycache.ini.append.php` in an extension (read when the extension is active).

## Report

> With the debug output on: accumulators of the group "Query cache" (hits,  
> misses, stores, statements not cached), a timing point when the state is  
> read, and a report at the bottom with this request's counters, the database  
> time the hits saved, why statements were not cached and which writes made  
> everything stale. enabled | disabled  

Default: `enabled`.

```ini
<?php /* #?ini charset="utf-8"?
# settings/override/querycache.ini.append.php
[DebugSettings]
Report=enabled
*/ ?>
```

# transform.ini [urlalias_iri]

The block `[urlalias_iri]` of `settings/transform.ini`, with 3 setting(s).

> Rules used by the url alias system (nice urls), the rules  
> ensures that the text is transformed to ascii equivalent  
> characters. The most important rules are the transliteration  
> lowercase and diacritical removal.  
> Rule for URLAlias with support for IRI.  
> http://www.w3.org/International/O-URL-and-ident.html  
>
> This is highly recommended for most modern sites.  
>
> Note: Remember to use utf-8 as your characters set for your site and database  

Never edit `settings/transform.ini` itself: an update replaces it. Put the settings you change in an override, which wins over the shipped file:

- `settings/override/transform.ini.append.php` for every siteaccess,
- `settings/siteaccess/<siteaccess>/transform.ini.append.php` for one siteaccess,
- `extension/<extension>/settings/transform.ini.append.php` in an extension (read when the extension is active).

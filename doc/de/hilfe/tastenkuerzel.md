# Tastenkürzel

Die Administration lässt sich allein mit der Tastatur bedienen. Neben den üblichen Tasten jeder Webseite (**Tab** und
**Umschalt+Tab**, um zwischen Links, Schaltflächen und Feldern zu wechseln, **Eingabe**, um einem Link zu folgen oder
eine Schaltfläche zu betätigen, **Leertaste**, um ein Kontrollkästchen anzukreuzen) reagiert sie auf die folgenden
Tasten. Sie funktionieren im Design **Admin 4**; die anderen Designs kennen die meisten davon.

Auf einem Mac ist **Alt** die **Wahltaste** (Option).

## Überall in der Administration

| Taste | Was sie bewirkt |
|---|---|
| `/` | Springt in das Feld **Suchen...** in der Kopfzeile (nicht, während Sie in einem anderen Feld tippen). |
| `Esc` | Schließt das geöffnete Menü, die Liste oder das Pop-up und gibt den Fokus an deren Schaltfläche zurück. |
| `Tab` (erster Druck auf einer Seite) | Zeigt **Zum Hauptinhalt springen**; drücken Sie `Enter`, um an der Kopfzeile und der linken Spalte vorbeizuspringen. |

## Menüs und Auswahllisten

Das betrifft die Registermenüs der Kopfzeile, das Benutzermenü, die Liste **Weitere**, den Suchbereich und das Menü
eines Objekts.

| Taste | Was sie bewirkt |
|---|---|
| `↓` auf der Schaltfläche | Öffnet das Menü und geht zu seinem ersten Eintrag. |
| `↓` / `↑` | Nächster / vorheriger Eintrag. |
| `Home` / `End` | Erster / letzter Eintrag. |
| `Enter` oder `Space` | Wählt den Eintrag. |
| `Esc` | Schließt das Menü. |

## Der Inhaltsbaum

Gehen Sie mit `Tab` in den Baum; dann:

| Taste | Was sie bewirkt |
|---|---|
| `↓` / `↑` | Nächstes / vorheriges Objekt. |
| `→` | Öffnet einen geschlossenen Ordner; bei einem geöffneten geht sie zu seinem ersten Objekt. |
| `←` | Schließt einen geöffneten Ordner; bei einem geschlossenen oder einem Objekt geht sie zu dessen übergeordnetem Objekt. |
| `Home` / `End` | Erstes / letztes Objekt des Baums. |
| Buchstaben | Springen zum nächsten Objekt, dessen Name mit dem Getippten beginnt. |
| `Enter` | Öffnet das Objekt. |
| `Shift+F10` oder die Menütaste | Öffnet das Menü des Objekts (bearbeiten, kopieren, verschieben, hier erstellen ...). Dasselbe funktioniert auf einer Zeile einer Liste **Unterelemente**. |

## Registerkarten der Seite eines Objekts

Mit dem Fokus auf einer Registerkarte (**Ansicht**, **Details**, **Übersetzungen** ...):

![Die Registerkarten der Seite eines Objekts: View, Details, Translations, Locations, Relations, Audit, Intelligence, Tags, Authors, Layouts und Ordering](../../en/us/help/images/shortcuts/item-tabs.webp)

| Taste | Was sie bewirkt |
|---|---|
| `→` / `←` | Öffnet die nächste / vorherige Registerkarte. |
| `Home` / `End` | Öffnet die erste / letzte Registerkarte. |

## Listen von Unterelementen

Ist eine Liste **Unterelemente** nach Priorität sortiert, ändert der Griff am Anfang jeder Zeile die Reihenfolge:

| Taste auf dem Griff | Was sie bewirkt |
|---|---|
| `Space` oder `Enter` | Nimmt die Zeile auf. |
| `↑` / `↓` | Bewegt die aufgenommene Zeile. |
| `Home` / `End` | Bewegt sie an den Anfang / das Ende der Seite. |
| `Space` oder `Enter` | Legt sie dort ab; die neue Reihenfolge wird gespeichert. |
| `Esc` | Legt sie dorthin zurück, wo sie war. |
| `Alt+↑` / `Alt+↓` | Bewegt die Zeile sofort um einen Platz, ohne sie aufzunehmen. |

## Die Breite der linken Spalte

Setzen Sie den Fokus auf den Griff mit den drei Punkten am Rand der linken Spalte:

![Die drei Schaltflächen unten in der linken Spalte, die ihre Breite festlegen](../../en/us/help/images/shortcuts/left-column-size-buttons.webp)

| Taste | Was sie bewirkt |
|---|---|
| `→` oder `↑` | Breiter (in einer Sprache, die von rechts nach links geschrieben wird: `←` oder `↑`). |
| `←` oder `↓` | Schmaler. |
| `Shift` mit einer Pfeiltaste | Ein größerer Schritt. |
| `Home` / `End` | Am schmalsten / am breitesten. |

## Das Bearbeitungsformular

| Taste | Was sie bewirkt |
|---|---|
| `Enter` in einem einzeiligen Feld | Dasselbe wie **Zur Veröffentlichung schicken**. |
| Tasten des Rich-Text-Editors | Die üblichen: `Ctrl+B` fett, `Ctrl+I` kursiv, `Ctrl+Z` rückgängig und weitere (`Cmd` auf einem Mac). Die Schaltfläche **Help** von TinyMCE listet sie alle auf. |

## Listen, aus denen Sie wählen

Tippen Sie in einem Listenfeld wie **Sprache der Oberfläche** die ersten Buchstaben eines Eintrags, um zu ihm zu
springen; die Pfeiltasten, `Home`, `End`, `Page Up` und `Page Down` bewegen sich durch die Liste. Nichts ändert sich,
bis Sie auf **Anwenden** klicken.

## Auf den Hilfeseiten

| Taste | Was sie bewirkt |
|---|---|
| `/` | Springt in das Suchfeld der Hilfe. |
| `↓` / `↑` | Bewegt sich während der Eingabe durch die Suchergebnisse. |
| `Enter` | Öffnet das gewählte Ergebnis. |
| `Esc` | Leert die Ergebnisse; ein zweites `Esc` verlässt das Feld. |
| `j` / `k` | Nächste / vorherige Überschrift der Seite, die Sie lesen. |
| `]` / `[` | Nächste / vorherige Hilfeseite. |

![Eine Seite der Hilfe: das Inhaltsverzeichnis der Hilfe links, die Seite in der Mitte und ihre Überschriften rechts](../../en/us/help/images/help/help-viewer.webp)

Diese Tasten werden ignoriert, während Sie in einem Feld tippen.

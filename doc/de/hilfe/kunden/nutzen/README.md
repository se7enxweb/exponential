# Nutzen aus Ihrer Website ziehen

Dieser Bereich ist für Organisationen, die bereits eine Website mit Exponential betreiben und wissen und steigern möchten,
was sie ihnen bringt. Er ist für den Betreiber, die Leitung, die für das Budget verantwortlich ist, und alle, die mit dem
Hoster oder Partner sprechen. Die Seiten, die Ihnen bei der Entscheidung für Exponential helfen, stehen im Bereich für
Unternehmen ([Gesamtbetriebskosten](../../../../en/us/help/businesses/costs/total-cost-of-ownership.md),
[Vorlage für ein ROI-Arbeitsblatt](../../../../en/us/help/businesses/templates/roi-worksheet-template.md)); hier messen und verbessern Sie
eine Website, die bereits Ihnen gehört.

## Messen und entscheiden

| Seite | Verwenden Sie sie, um |
|---|---|
| [Den ROI messen](den-roi-messen.md) | festzulegen, was Sie messen, woher die Zahlen kommen und wie oft |
| [ROI-Beispielannahmen](roi-beispielannahmen.md) | eine durchgerechnete Kalkulation mit gekennzeichneten Beispielzahlen zu sehen, die Sie mit Ihren eigenen kopieren |
| [ROI-Arbeitsblatt](roi-arbeitsblatt.md) | einmal im Jahr zu vergleichen, was Sie erwartet und was Sie bekommen haben |
| [Betriebskosten für Betreiber](betriebskosten-fuer-betreiber.md) | Posten für Posten festzuhalten, was der Betrieb der Website wirklich kostet |
| [Jährliche Überprüfung des Nutzens](jaehrliche-ueberpruefung-des-nutzens.md) | einmal im Jahr eine Sitzung abzuhalten, die entscheidet, was bleibt, sich ändert oder hinzukommt |

## Drei Fakten hinter dem Nutzen

| Fakt | Quelle |
|---|---|
| „Die Nutzung von Exponential unter den Bedingungen der GNU GPL ist kostenlos.“ Keine Lizenzgebühr ist Teil Ihrer laufenden Kosten. | `README.md`, „License“ |
| Exponential 6.0 ist die gepflegte Linie; Sicherheitskorrekturen werden mit dem nächsten Release 6.0.x veröffentlicht, und ein veröffentlichtes Tag wird nie geändert. | `SECURITY.md` |
| Shop, Multisite, mehrsprachige Inhalte, Workflows, Feeds, Kontaktformulare und eine REST-API sind eingebaut. | `README.md`, „Main Exponential features“ |

> **Hinweis**
> Jede Zahl auf diesen Seiten, die kein Fakt aus dem Repository ist, ist mit „Beispielannahmen: Ersetzen Sie sie durch
> Ihre eigenen“ gekennzeichnet. Keine davon ist ein Preis, ein Angebot oder eine Messung Ihrer Website.

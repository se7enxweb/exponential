# Neue Mitarbeitende einarbeiten

Diese Seite ist für die Leitung, die einen neuen Redakteur willkommen heißt, und für den Kollegen, der ihn herumführt.
Eine gute erste Woche gibt der Person ein persönliches Konto mit der richtigen Rolle, die zweistufige Anmeldung, eine
begleitete erste Aufgabe und die Hausregeln Ihrer Website. Die eingebaute Hilfe ist das Handbuch für die Redaktion:
Sie müssen keines von Grund auf schreiben ([Die Website an die Redaktion übergeben](../../../../en/us/help/creators/website-creators/handing-over-to-editors.md)).

## Vor dem ersten Tag

- Legen Sie die Rolle und ihre Einschränkungen fest: [Rollen für neue Mitarbeitende wählen](rollen-fuer-neue-mitarbeitende-waehlen.md).
- Die Person, die Konten verwaltet, legt **ein persönliches Konto** in der richtigen Benutzergruppe an. Keine geteilten Anmeldungen.
- Entscheiden Sie, ob für diese Person die zweistufige Anmeldung verpflichtend ist; für alle, die veröffentlichen
  können, wird sie empfohlen ([Die Website an die Redaktion übergeben](../../../../en/us/help/creators/website-creators/handing-over-to-editors.md)).
- Bereiten Sie eine kleine erste Aufgabe an einem sicheren Ort vor: einen Artikelentwurf in ihrer eigenen Sektion oder
  eine verborgene Seite.

## Erster Tag

1. **Melden Sie sich gemeinsam an.** Die neue Person meldet sich in der Administration an ([In der Administration anmelden](../../../../en/us/help/logging-into-the-admin.md))
   oder, wenn Ihre Website sie verwendet, in der vereinfachten Oberfläche Editor ([Im Editor anmelden](../../../../en/us/help/logging-into-the-editor.md)).
2. **Ändern Sie das Passwort und schalten Sie die zweistufige Anmeldung ein**, unter *Mein Konto*
   ([Ihr Konto und die Anmeldung](../../../../en/us/help/accounts-and-sign-in.md)).
3. **Machen Sie den Rundgang.** Gehen Sie [Ein Rundgang durch die Administration](../../../../en/us/help/admin-tour.md) mit Ihren
   eigenen Inhalten durch. Eine Schulung, die dem Rundgang mit den eigenen Inhalten der Website folgt, bringt die
   meisten Redakteure von null zur Arbeitsfähigkeit ([Die Website an die Redaktion übergeben](../../../../en/us/help/creators/website-creators/handing-over-to-editors.md)).
4. **Nehmen Sie eine erste Änderung vor**, als Entwurf, sehen Sie sich die Vorschau an und veröffentlichen oder
   verwerfen Sie sie ([Erste Schritte](../../../../en/us/help/getting-started.md), [Veröffentlichen, Versionen und der Papierkorb](../../../../en/us/help/publishing-and-versions.md)).

> **Tipp**
> Sammeln Sie die Fragen, die neue Personen in ihren ersten Wochen stellen. Wiederholte Fragen gehören in den eigenen
> Leitfaden Ihrer Website für die Redaktion ([Die Website an die Redaktion übergeben](../../../../en/us/help/creators/website-creators/handing-over-to-editors.md)).

## Nach einem Monat

- Fragen Sie, was schwierig war; ergänzen Sie es im Leitfaden.
- Prüfen Sie, ob die Rolle noch zur Arbeit passt. Fordern Sie mehr Zugriff nur für echte Aufgaben an.
- Wenn die Person zum Lernen hinter eine Freigabe gesetzt wurde, entscheiden Sie mit der freigebenden Person, ob das bleibt.

## Wer was tut

| Schritt | Wer |
|---|---|
| Die Rolle festlegen | Leitung, vom Website-Betreiber genehmigt |
| Das Konto anlegen, die Gruppe zuweisen | Kontenverwaltung oder Administrator |
| Rundgang und erste Aufgabe | ein erfahrener Redakteur |
| Hausregeln | Chefredaktion |
| Den Zugriff festhalten | Kontenverwaltung, im [Arbeitsblatt für Teamrollen](arbeitsblatt-teamrollen.md) |

Die Schritt-für-Schritt-Liste zum Abhaken ist die [Checkliste für die Einarbeitung](checkliste-einarbeitung.md).

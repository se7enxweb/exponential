# Ihre ersten 30 Tage als Partner

Diese Seite ist für die verantwortliche Person der Partnerschaft. Sie verteilt die [Checkliste für das Onboarding](checkliste-fuer-das-onboarding.md)
auf vier Wochen, damit die Partnerschaft an Tag 30 sichtbar, nutzbar und geplant ist.

## Woche 1: einrichten

| Aufgabe | Ergebnis |
|---|---|
| Die Vereinbarung ablegen; Erinnerungen für die Verlängerung setzen | In einem Jahr wird nichts Administratives vergessen |
| Konten bei GitHub und share.exponential.earth anlegen oder prüfen | Ihr Team kann Tickets eröffnen und Beiträge schreiben |
| Telegram, den Foren und den Mailinglisten beitreten | Sie erfahren von Releases und Treffen |
| Festlegen, wer Partner-Tickets eröffnen darf | Tickets werden nicht verschwendet |

## Woche 2: sichtbar werden

| Aufgabe | Ergebnis |
|---|---|
| Ihre Partnerseite schreiben ([Ihre Partnerseite](ihre-partnerseite.md)) | Kunden können Sie finden |
| Das richtige Logo Ihrer Stufe auf Ihrer Website einbinden ([Partnerlogos](partnerlogos-und-zeichen.md)) | Ihre Stufe wird korrekt gezeigt |
| Die Partnerschaft auf Ihren eigenen Kanälen ankündigen, ohne für 7x oder die Foundation zu sprechen ([Pressemitteilungen](pressemitteilungen-und-ankuendigungen.md)) | Ihr Netzwerk weiß Bescheid |

## Woche 3: die Abläufe lernen

| Aufgabe | Ergebnis |
|---|---|
| Ein erstes, echtes Support-Ticket eröffnen und die Reaktionszeit notieren | Sie wissen, wie Support in der Praxis funktioniert |
| Das aktuelle Exponential aus Git in einer Testumgebung installieren ([Mit Git entwickeln](../../../en/us/help/develop-with-git.md)) | Ihre Entwickler arbeiten mit dem aktuellen Code |
| Das neueste Änderungsprotokoll lesen und entscheiden, welche Kunden ein Upgrade brauchen | Eine erste Upgrade-Liste ([Kunden-Websites aktuell halten](kunden-websites-aktuell-halten.md)) |

## Woche 4: etwas zurückgeben und planen

| Aufgabe | Ergebnis |
|---|---|
| Einen Fehlerbericht oder Pull Request senden ([Code zurückgeben](code-zurueckgeben.md)) | Ihre ersten Community-Punkte |
| Drei Ziele für das Jahr aufschreiben (Projekte, Punkte, Zertifizierungen) | Ein Plan für [Ihr erstes Jahr](ihr-erstes-jahr.md) |
| Ihr erstes Beratungstreffen buchen oder anfragen (jede Stufe hat mindestens eines pro Quartal) | Sie besprechen den Plan mit 7x |

## Die Prüfung an Tag 30

- [ ] Die Partnerseite ist online und korrekt.
- [ ] Jede Person, die mit Kunden spricht, kennt die Namensregeln.
- [ ] Ein Ticket eröffnet, ein Beitrag gesendet.
- [ ] Der Plan für das erste Jahr existiert und ist mit 7x geteilt.
- [ ] Das erste Aktivitätsprotokoll ist gesendet ([Ihre Partneraktivität erfassen](partneraktivitaet-erfassen.md)).

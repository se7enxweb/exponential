# Dokumentation und Übersetzungen beitragen

Diese Seite ist für Mitarbeitende von Partnern, die schreiben oder übersetzen. Dokumentation und Übersetzungen gehören
zu den wertvollsten Beiträgen: Partner sehen die Fragen, die Kunden stellen, und betreuen Kunden in vielen Sprachen.

## Dokumentation

- Die Dokumentation liegt im Repository unter `doc/`, und die Hilfe zeigt sie in der Administration an
  ([Freie Dokumentation](../../../en/us/help/free-documentation.md)).
- Jede Hilfeseite hat einen Link „Auf GitHub bearbeiten“: Korrigieren Sie einen Fehler direkt mit einem Pull Request.
- Neue Hilfeseiten sind Markdown-Dateien mit Front Matter (title, audience, category, order, summary) unter `doc/en/us/help/`.
- Die Dokumentation steht unter der GNU Free Documentation License 1.3 oder später; Ihr Beitrag wird es ebenfalls
  ([Die Lizenz dieser Dokumentation](../../../en/us/README-LICENSE.md)).

### Was Partner gut dokumentieren können

| Thema | Warum Partner |
|---|---|
| Einrichtungen aus der Praxis (Hosting-Panels, Container, Clouds) | Sie betreiben sie |
| Migrationsgeschichten | Sie haben sie durchgeführt |
| Anleitungen für Redakteure | Sie haben Redakteure geschult |
| Antworten, die Sie immer wieder geben | Sie gehören in die Hilfe |

### Regeln für das Schreiben

- Amerikanisches Englisch; Produktnamen korrekt ([Namens- und Markenregeln für Partner](namens-und-markenregeln.md)).
- Jeder Fakt mit seiner Quelle; Befehle mit erwarteter Ausgabe.
- Keine Geheimnisse, Hostnamen privater Systeme oder Kundendaten in Beispielen.

## Übersetzungen

- Die Administration ist in viele Sprachen übersetzt; [Sprachen](../../../en/us/help/languages.md) erklärt die Locales, und
  `doc/en/us/languages.md` listet die Kataloge und ihre Vollständigkeit.
- Übersetzungen liegen in `share/translations/<locale>/translation.ts`. Verbessern Sie eine vorhandene Sprache oder
  vervollständigen Sie eine teilweise übersetzte mit einem Pull Request.
- Lassen Sie vor dem Einreichen eine zweite Person mit dieser Muttersprache gegenlesen.

## Punkte

Tutorials (ab 1.500 Wörtern) und Artikel (500 bis 1.500 Wörter, unter FLOSS-Lizenz) bringen jeweils 500 Punkte;
„Wiki-Artikel, Dokumentation oder Dokumentation“ wird als Wissensaustausch genannt
(<https://exponential.earth/partner/requirements>). Übersetzungen sind nicht aufgeführt; fragen Sie das Partnerteam, da
Aktivitäten „im Einzelfall“ belohnt werden können.

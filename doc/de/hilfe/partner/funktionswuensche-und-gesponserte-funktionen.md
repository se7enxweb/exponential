# Funktionswünsche und gesponserte Funktionen

Diese Seite ist für Partner, deren Kunden etwas brauchen, das Exponential noch nicht kann.

## Fünf Wege, auf denen eine Funktion entsteht

| Weg | Kosten | Tempo | Quelle |
|---|---|---|---|
| Öffentlicher Funktionswunsch | Keine | Nicht vorhersehbar | <https://github.com/se7enxweb/exponential/issues> |
| Ihr eigener Pull Request | Die Zeit Ihrer Entwickler | Sie bestimmen es | CONTRIBUTING.md, [Code zurückgeben](code-zurueckgeben.md) |
| Bezahlte Entwicklung durch 7x | Ein Angebot von 7x | Vereinbart | <https://exponential.earth/support> („Beauftragen Sie 7x!“) |
| Ein Bounty über GitHub Sponsors | Einmalige Stufen wie aufgeführt | Vereinbart | „Ein Fehler oder ein mittelgroßes Bounty“ (1.000 $ einmalig) auf beiden Sponsorenseiten |
| Eine Sponsorenstufe mit Einfluss auf den Backlog | Monatlich | Priorität, kein Versprechen | 7x-Stufe „750 $ im Monat“: „ein Bounty für die Entwicklung einer Funktion ... zugeschnitten auf Ihre Bedürfnisse“ |

Die Sponsorenstufen wurden am 18. Oktober 2026 auf den Seiten von GitHub Sponsors <https://github.com/sponsors/se7enxweb>
und <https://github.com/sponsors/exponentialcms> gelesen; maßgeblich sind die aktuellen Seiten. Details:
[7x auf GitHub sponsern](../../../en/us/help/sponsors/sponsoring-7x.md) und
[Die Exponential Foundation sponsern](../../../en/us/help/sponsors/sponsoring-the-foundation.md).

Die Sponsorenseite des Projekts sagt: „Sponsoren profitieren vom direkten Zugang zum 7x-Team, und ihre Funktionen werden berücksichtigt“ (<https://exponential.earth/about/project/sponsors>). „Berücksichtigt“ ist das richtige Wort
gegenüber Kunden: Finanzierung erhöht die Priorität; sie kauft keine Garantie, es sei denn, ein schriftlicher Vertrag
sagt das.

## Offen halten

Eine Funktion, die ein Kunde bezahlt und die für alle veröffentlicht wird, ist das beste Ergebnis für alle: Der Kunde
bekommt Pflege durch die Community, die Community bekommt die Funktion. Vereinbaren Sie im Kundenvertrag, dass
allgemeine Funktionen unter der GPL veröffentlicht werden dürfen
([Open-Source-Werte in der täglichen Partnerarbeit](open-source-werte.md)).

## Entscheidungshilfe

| Die Funktion ist | Dann |
|---|---|
| Klein, allgemein, und Sie haben Entwickler | Senden Sie einen Pull Request |
| Allgemein, aber groß | Besprechen Sie sie zuerst in einem Issue, dann finanzieren oder bauen Sie sie mit anderen |
| Spezifisch für einen Kunden | Bauen Sie sie als Kundenerweiterung; drücken Sie sie nicht in den Kernel |
| Dringend und kritisch | Bezahlte Entwicklung mit einer schriftlichen Vereinbarung |

# Wie Sponsoren gewürdigt werden

Diese Seite ist für Sponsoren, die wissen möchten, wie ihre Unterstützung sichtbar wird. Werte wie am 18. Oktober 2026
aufgeführt; maßgeblich sind die aktuellen Seiten auf GitHub.

## Nach Stufe

| Anerkennung | 7x (se7enxweb) | Die Foundation (exponentialcms) |
|---|---|---|
| Sponsoren-Abzeichen in Ihrem GitHub-Profil | Ab $2 im Monat | Ab $5 im Monat |
| Erwähnung in den sozialen Medien | $10 einmalig | $10 einmalig |
| Wöchentlicher Newsletter | – | $10 im Monat |
| Logo oder Name im README des Projekts | $250 im Monat | $25 im Monat |
| Logo oder Name auf der Website des Projekts | – | $100 im Monat |
| Release Notes | – | $50 einmalig („Verdienen Sie sich eine Erwähnung in unseren Release Notes“) |
| Release-Ankündigung und Dokumentation | $99 im Monat („Sponsern Sie das nächste Release ... aufgenommen in die offizielle Release-Ankündigung und in die offizielle zugehörige Dokumentation“) | – |
| Erwähnungen auf X.com, Instagram, dem Community-Portal, LinkedIn | Genannt im Abschnitt „What we offer to sponsors“ des Eintrags | – |

## Öffentlich oder privat

„Sie können wählen, ob Ihr Sponsoring öffentlich angezeigt wird. Einmalige Sponsorings bleiben einen Monat lang
sichtbar“ (GitHub Docs, <https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes>).
Wählen Sie „privat“, wenn Sie nicht aufgeführt werden möchten; eine Nennung im README oder auf einer Website wird dann
mit der Organisation vereinbart.

## Die Sponsorenseite des Projekts

„Sponsoren profitieren von direktem Zugang zum Team von 7x, ihre Funktionswünsche werden berücksichtigt und die
Produkte ihres Unternehmens beworben. Möchten Sie Ihren Namen, Ihr Unternehmen oder Ihre Organisation unter den ersten
Exponential-Sponsoren aufgeführt sehen ... Kontaktieren Sie uns unter community@exponential.earth“
(<https://exponential.earth/about/project/sponsors>).

## Was Sie schicken

Für einen Eintrag im README oder auf der Website schicken Sie der Organisation den gewünschten Namen, eine Logodatei,
die Sie verwenden dürfen, und den Link. Diese Hilfe nennt keine Sponsoren; die Einträge werden von den Organisationen
gepflegt.

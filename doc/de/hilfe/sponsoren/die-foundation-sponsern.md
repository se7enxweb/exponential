# Die Exponential Foundation sponsern

Diese Seite ist für Personen und Organisationen, die die gemeinnützige Organisation finanzieren möchten, die das
Exponential-Projekt betreibt. Ihre Seite bei GitHub Sponsors ist <https://github.com/sponsors/exponentialcms> (die
GitHub-Organisation „Exponential“, Website <https://exponential.earth>). Alles Folgende wurde am 18. Oktober 2026 über
die GitHub-API gelesen; maßgeblich ist die aktuelle Seite.

## Worauf sich die Foundation konzentriert

„Unterstützen Sie die Open-Source-Arbeit der Exponential Foundation, um die Exponential-Projekte (CMS und CMS-Familie)
wachsen zu lassen. Wir konzentrieren uns auf die Entwicklung von Funktionen, Dokumentation, Tutorials, Anleitungen,
FAQs, Quellcode, Plugins/Erweiterungen/Bundles.“ (Eintrag bei GitHub Sponsors)

Ihr Auftrag: „direkt der fortgesetzten Finanzierung, Verbreitung, Unterstützung, Ausrichtung, Schulung, Entwicklung,
Förderung und Dokumentation des Enterprise-Open-Source-Projekts Exponential verpflichtet“
(<https://foundation.exponential.earth/>).

## Die Stufen

### Monatlich

| Stufe | Enthält (laut Eintrag) |
|---|---|
| $5 im Monat | Ein Sponsoren-Abzeichen in Ihrem Profil |
| $10 im Monat | Wöchentliche Neuigkeiten per Newsletter |
| $25 im Monat | Logo oder Name im README des Projekts; Zugang zum Chatbereich der Community |
| $30 im Monat | Zugang zu Videos, Screencasts und Tutorials |
| $100 im Monat | Logo oder Name auf der Website des Projekts; priorisierte Fehlerberichte |
| $1.000 im Monat | Die Foundation tritt dem Chat Ihres Unternehmens bei, für Hilfe und Unterstützung |
| $8.000 im Monat | Arbeitet in einem Projekt Ihres Unternehmens mit, für Hilfe und Unterstützung |
| $12.000 im Monat | Entwickelt und betreut ein neues Produkt für Ihr Unternehmen |

### Einmalig

| Stufe | Enthält (laut Eintrag) |
|---|---|
| $10 einmalig | Eine Erwähnung in den sozialen Medien |
| $50 einmalig | Eine Erwähnung in den Release Notes |
| $200 einmalig | Eine Stunde Pair Programming |
| $350 einmalig | Eine Stunde Beratung oder Mentoring |
| $500 einmalig | Ein Workshop für Ihr Team |
| $1.000 einmalig | Ein Fehler oder eine mittelgroße Bounty |
| $2.000 einmalig | Ein Vortrag auf Ihrer Konferenz |
| $5.000 einmalig | Ein kleines Auftragsprojekt, nach Kontaktaufnahme |
| $10.000 einmalig | Ein mittleres Auftragsprojekt, nach Kontaktaufnahme |

## Weitere Wege, der Foundation zu geben

„Unterstützen Sie die Exponential Foundation mit einem fördernden Abonnement oder einer einmaligen Spende. Gespendete
Mittel sind steuerfrei und in den Vereinigten Staaten von der Steuer des Spenders absetzbar.“
(<https://foundation.exponential.earth/>). Die Seite verlinkt auf GitHub Sponsors und auf PayPal. Klären Sie mit Ihrem
eigenen Steuerberater, wie diese Angabe auf Sie zutrifft ([Rechnungen, Belege und Steuern](rechnungen-belege-und-steuern.md)).

## Eine Stufe wählen

| Sie sind | Ein passender Einstieg |
|---|---|
| Eine Einzelperson | $5 bis $30 im Monat |
| Ein Unternehmen, das sichtbar als Unterstützer des Projekts auftreten möchte | $25 (README) oder $100 im Monat (Website) |
| Ein Team, das praktische Hilfe möchte | Einmaliger Workshop, Beratung oder Pair Programming |

# Ein Tisch auf der Veranstaltung anderer

Diese Seite ist für Fürsprecher, die die Exponential-Community auf einer Veranstaltung vertreten möchten, die andere
ausrichten: einem Open-Source-Festival, einer PHP-Konferenz, einem lokalen Technik-Tag. Viele Veranstaltungen bieten
kostenlose Community-Tische an. Stellen Sie es ehrlich dar: ein Tisch, der von ehrenamtlichen Fürsprechern betreut wird,
kein offizieller Auftritt von 7x oder der Foundation, es sei denn, diese haben Sie darum gebeten.

## Inhalt

1. [Die Veranstalter fragen](#die-veranstalter-fragen)
2. [Was Sie mitbringen](#was-sie-mitbringen)
3. [Die Demo-Schleife](#die-demo-schleife)
4. [Gespräche](#gespräche)
5. [Danach](#danach)

## Die Veranstalter fragen

```text
Subject: Community table request: Exponential (open source CMS)

Hello, we are volunteer users of Exponential, a free and open source PHP CMS (GNU GPL). We'd like to ask
for a community table at <event> to show it and answer questions. We are not selling anything.
People: <n> volunteers. Needs: a table, power, <network if possible>.
Contact: <you>
```

Wenn jemand am Tisch für ein Unternehmen arbeitet, das Dienstleistungen verkauft, sagen Sie das den Veranstaltern und
den Besuchern.

## Was Sie mitbringen

```text
[ ] Laptop with a local demo installation on SQLite (works offline), invented content
[ ] Second screen or tablet showing the demo loop
[ ] Printed one-page fact sheet and the community card
[ ] Power strip, adapters
[ ] A sign: "Exponential - free & open source PHP CMS - ask us"
[ ] Notebook for questions you cannot answer (no visitor personal data unless they offer contact for a reply)
```

Faktenblatt und Karte: [Faktenblatt auf einer Seite](faktenblatt.md), [Die Community-Kanäle](community-kanaele.md#eine-karte-zum-weitergeben).

## Die Demo-Schleife

Eine stumme Schleife aus Screenshots oder ein kurzer Screencast, der von selbst läuft:

1. Das Dashboard. 2. Bearbeiten mit Vorschau in Telefonbreite. 3. Der Layouts-Editor. 4. Die Administration mit
Schreibrichtung von rechts nach links. 5. Die Hilfe mit der Schaltfläche „?“. 6. „Probieren Sie es aus: ./console exp:install“.

Bildunterschriften auf jedem Bild; keine Geheimnisse auf irgendeinem Bildschirm ([Sicherheit bei Live-Demos](sicherheit-bei-live-demos.md)).

Hören Sie mehr zu, als Sie reden; geben Sie zum Schluss die Karte.

## Danach

Stellen Sie die Fragen der Besucher mit Antworten und Quellen in die Foren; danken Sie den Veranstaltern; erfassen Sie
den Einsatz ohne Namen von Besuchern.

# Ideen für Anerkennung

Diese Seite ist für Fürsprecher, die möchten, dass Beitragende sich gesehen fühlen. Die Quellen beschreiben kein
Anerkennungs-, Botschafter- oder Auszeichnungsprogramm; nichts hier ist also offiziell. Es sind Ideen, die jeder
Fürsprecher umsetzen kann, und Vorschläge, die Sie in den Community-Tracker einbringen können.

## Was das Projekt bereits tut

- Jeder Pull Request wird übernommen, und die Commits der Beitragenden bleiben so erhalten, wie sie sie geschrieben
  haben, sodass ihre Namen in der Historie bleiben ([Wie das Projekt wächst](../../../en/us/help/who-is-the-exponential-foundation.md#how-the-project-grows)).
- Beitragende und Unternehmen werden auf den Seiten zur Geschichte und unter
  [Wer ist 7x?](../../../en/us/help/who-is-7x.md#contributors-and-friends-of-the-project) genannt.

## Ideen, die Sie heute umsetzen können

| Idee | Wie |
|---|---|
| Danke sagen | Ein Kommentar zum übernommenen Pull Request; ein Forenbeitrag |
| In Ihren Beiträgen nennen | Beitragende (mit öffentlichem Namen) in Ihren Beiträgen zu Releases nennen ([Über ein Release schreiben](ueber-ein-release-schreiben.md)) |
| Die Arbeit von jemandem vorstellen | Ein Beitrag über eine Erweiterung oder ein Tutorial, das jemand erstellt hat, mit Zustimmung |
| Gelegenheiten weitergeben | Eine beitragende Person einladen, bei Ihrem Treffen vorzutragen |
| Eine Referenz schreiben | Für eine beitragende Person, die darum bittet, ihre öffentlichen Beiträge beschreiben |

## Ideen zum Vorschlagen

Bringen Sie diese als Vorschläge in den [Community-Tracker](https://github.com/se7enxweb/exponential-community/issues) ein:

- Einen Abschnitt „Danke“ in Ankündigungen von Releases, der die Beitragenden des Release aufführt.
- Einen regelmäßigen Beitrag „Community im Blick“ auf Share.
- Eine Seite in der Hilfe, die die Betreuer der Übersetzungen pro Sprache aufführt, mit Zustimmung.

## Regeln

- **Zuerst die Zustimmung** für alles, was über einen öffentlichen Namen in seinem öffentlichen Zusammenhang hinausgeht.
- **Fair nennen**: auch Prüfende, Übersetzer, Meldende und Dokumentierende, nicht nur Code.
- **Keine erfundenen Titel** („offizieller Botschafter“) oder Belohnungen, die das Projekt nicht anbietet.

# Gesprächspunkte: Exponential Layouts

Diese Seite ist für Fürsprecher, die Redakteuren und Designern zeigen, wie Seiten gebaut werden. Exponential Layouts ist
„ein visueller Seitenbaukasten für Exponential. Er bringt das Konzept von Netgen Layouts in den Kernel von Exponential:
Ein Layout ist eine gespeicherte Anordnung von Blöcken in Zonen, und eine Regel entscheidet, welche Seiten es bekommen“
([Exponential Layouts](../../../en/us/help/who-is-the-exponential-foundation.md#exponential-layouts)).

## Eine Demo in einer Minute

Auf einer Installation, die Sie kontrollieren:

1. Reiter **Layouts**, **Layouts**, ein Layout **Öffnen**.
2. **Block hinzufügen**, einen Block **Titel** in eine Zone ziehen, einen Titel eingeben.
3. Den Block in eine andere Zone ziehen.
4. Auf eine verknüpfte Zone zeigen: „Das kommt aus dem gemeinsamen Kopf- und Fußbereich.“
5. **Verwerfen** und bestätigen: „Auf der Website hat sich nichts geändert.“

Länger: [Demo-Skripte, Teil 4: Layouts von Anfang bis Ende](../../../en/us/help/business/demo-scripts.md#part-4-layouts-end-to-end-6-minutes).

## Ehre, wem Ehre gebührt

Exponential Layouts ist eine Portierung des Konzepts von Netgen Layouts in den Kernel von Exponential. Wenn Sie es
vorstellen, sagen Sie das: „Es bringt das Konzept von Netgen Layouts zu Exponential.“ Die Arbeit anderer zu nennen
gehört zur Praxis des Projekts ([Wie das Projekt wächst](../../../en/us/help/who-is-the-exponential-foundation.md#how-the-project-grows),
[Andere Projekte und Unternehmen respektieren](andere-projekte-respektieren.md)).

Nennen Sie es nicht „Netgen Layouts für Exponential“: Es hat seinen eigenen Namen
([Marken- und Namensregeln, Tun und Lassen](../../../en/us/help/business/brand-and-naming-rules.md#do-and-dont)).

## Sagen Sie nicht

- „Redakteure brauchen nie wieder einen Entwickler.“ Entwickler bauen weiterhin Block-Templates und das Design.
- „Es funktioniert auf jeder Distribution gleich.“ DXP liefert keinen Layouts-Editor.
- „Jede Seite kann von jedem geändert werden.“ Rollen entscheiden, wer Layouts bearbeiten darf.

# In den Foren arbeiten

Diese Seite ist für Fürsprecher, die in den Foren unter [share.exponential.earth/forums](https://share.exponential.earth/forums)
helfen. In den Foren bleiben Fragen und Antworten jahrelang auffindbar. Eine gute Antwort dort hilft vielen Menschen,
denen Sie nie begegnen werden.

## Warum die Foren wichtig sind

- Die README nennt sie als den Ort für weitere Hilfe ([Orte der Community](../wer-ist-die-exponential-foundation.md#orte-der-community)).
- Es gibt auch ein Forum für Exponential Platform ([Wer ist 7x?, Die Community](../wer-ist-7x.md#die-community)).
- Anders als in einem Chat sind Diskussionen durchsuchbar und verlinkbar.

## Bevor Sie schreiben

1. Durchsuchen Sie die Foren nach dem Thema.
2. Prüfen Sie, ob eine Hilfeseite es beantwortet ([Auf die richtige Hilfeseite verweisen](auf-die-richtige-hilfeseite-verweisen.md)).
3. Wählen Sie das richtige Forum (Exponential 6 oder Exponential Platform).
4. Lesen Sie die eigenen Regeln des Forums auf Share.

## Antworten

| Tun Sie | Warum |
|---|---|
| Die Frage in einer Zeile neu formulieren | Zeigt, dass Sie sie verstanden haben; hilft Suchenden |
| Zuerst kurz antworten, dann die Details | Die meisten Leser wollen die kurze Antwort |
| Die Hilfeseite oder Quelle verlinken | Zeigt, wo man nachschaut; belegt die Antwort |
| Sagen, mit welcher Version Sie geprüft haben | Antworten veralten |
| Freundlich nach fehlenden Informationen fragen | „Welche Version und Datenbank nutzen Sie?“ |
| Wiederkommen, wenn Sie es versprochen haben | Vertrauen wächst durch Nachfassen |

```text
ANSWER TEMPLATE
If I understand right, you want to <restated question>.

Short answer: <answer>.

Details: <steps or explanation>. The help page "<title>" covers it: <link>.
(Checked on Exponential <6.0.x>.)

If that doesn't match what you see, could you tell us your version, database and what exactly happens?
```

Mehr zu Ton und Inhalt: [Fragen gut beantworten](fragen-gut-beantworten.md).

## Fragen

Auch Fürsprecher stellen Fragen. Eine gute Frage bekommt schneller Antworten:

```text
QUESTION TEMPLATE
Title: <what you want to do> - <what goes wrong>

What I want to do: <goal>
What I did: <steps>
What I expected: <...>
What happened: <exact message>
Environment: Exponential <version>, PHP <version>, <engine>, <database>, <design>
What I tried: <links you read>
```

Fügen Sie nie Passwörter, Schlüssel, Datenbankadressen oder personenbezogene Daten ein
([Wenn etwas schiefgeht](../wenn-etwas-schiefgeht.md#eine-gute-fehlerbeschreibung)).

## Eine wöchentliche Routine

```text
WEEKLY FORUM ROUTINE (30 minutes)                  Week of <date>
[ ] Read new threads since last week
[ ] Answer 1-3 questions I can answer with a source
[ ] Point 1 bug report to the right tracker
[ ] Note repeated questions -> help page improvement
[ ] Follow up on my open threads
[ ] Log links in my contribution log
```

## Diskussionen nützlich halten

- Wenn eine Diskussion gelöst ist, veröffentlichen Sie die Lösung deutlich, auch wenn Sie sie selbst gefunden haben.
- Wenn die Antwort ein Fehler war, verlinken Sie das Issue; wenn er behoben ist, nennen Sie das Release.
- Wenn eine Diskussion veraltet ist, fügen Sie einen kurzen Hinweis mit dem aktuellen Weg und seiner Hilfeseite hinzu.
- Holen Sie sehr alte Diskussionen nicht mit „+1“ hervor; beginnen Sie eine neue und verlinken Sie die alte.

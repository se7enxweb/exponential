# Öffentlich antworten

Diese Seite ist für Fürsprecher, die sehen, wie Exponential öffentlich erwähnt wird: in sozialen Medien, in Foren
anderer Communities, in Bewertungen, in Kommentaren. Nicht jede Erwähnung braucht Sie. Wenn eine Sie braucht, sollte
Ihre Antwort das Gespräch besser hinterlassen, als es war.

## Sollten Sie überhaupt antworten?

| Die Erwähnung | Antworten? |
|---|---|
| Lob | Ein kurzer Dank, vielleicht ein nützlicher Link |
| Eine Frage | Ja, mit einem Link, oder verweisen Sie auf die Foren |
| Ein Fehlerbericht am falschen Ort | Ja: danken Sie und verweisen Sie auf den richtigen Tracker |
| Ein öffentlich veröffentlichtes Sicherheitsproblem | Ja, wenn möglich vertraulich: Bitten Sie, die Details zu entfernen und über `SECURITY.md` zu melden |
| Ein sachlicher Fehler über Exponential | Einmal, höflich, mit Quelle |
| Eine Meinung, die Sie nicht teilen | Meist nein |
| Berechtigte Kritik | Ja: Erkennen Sie sie an, verweisen Sie darauf, wo sie erfasst ist, helfen Sie bei der Behebung |
| Eine Diskussion in einer anderen Community, die Exponential nicht erwähnt | Nein: Werben Sie nicht in den Diskussionen anderer |
| Feindseligkeit | Siehe [Mit feindseligen Diskussionen umgehen](feindselige-diskussionen.md) |

## Antwortmuster

```text
PRAISE
Glad it helped! If you haven't seen it yet, <related help page or feature> is worth a look: <link>

QUESTION
Good question. <Short answer> - details here: <link>. If it doesn't fit your case, the forums are a good
place to ask: share.exponential.earth/forums

BUG IN THE WRONG PLACE
Thanks for reporting! So it gets fixed, could you open an issue here: <tracker link>? The help's
"Report an error" page prepares one for you. Please leave out passwords and personal data.

SECURITY DETAILS POSTED PUBLICLY
Thanks for finding this. Could you remove the details here and send them privately as described in
SECURITY.md (security@se7enx.com)? That way it can be fixed before others misuse it.

FACTUAL ERROR
Small correction: <fact> (<source link>). Things changed quite a bit since <year> - the history pages
explain it: <link>

RIGHT CRITICISM
You're right, <the problem>. It's tracked here: <issue link> / I've opened an issue: <link>. If you'd like
to help, a pull request is welcome - every one is merged.
```

Antworten Sie auf Deutsch sinngemäß gleich: danken, kurz antworten, verlinken, auf den richtigen Ort verweisen.

## Aus Erwähnungen Verbesserungen machen

Jede öffentliche Beschwerde oder Verwirrung ist eine Information:

| Erwähnung | Machen Sie daraus |
|---|---|
| Dieselbe Frage, dreimal gestellt | Eine Verbesserung einer Hilfeseite ([Die Hilfe verbessern](die-hilfe-verbessern.md)) |
| Ein in einem Beitrag beschriebener Fehler | Ein Issue mit einer Nachstellung ([Fehler gut melden](fehler-gut-melden.md)) |
| Ein Missverständnis einer Funktion | Einen klareren Gesprächspunkt, ein Tutorial ([Ein Tutorial schreiben, das funktioniert](ein-tutorial-schreiben.md)) |
| Ein Wunsch | Eine Diskussion im Community-Tracker ([Welcher Tracker für welche Meldung](welcher-tracker-fuer-welche-meldung.md)) |
| Eine großartige Bewertung | Einen Dank; fragen Sie, ob Sie sie zitieren dürfen, mit Zustimmung |

## Was Sie nie tun sollten

- Von einem Konto antworten, das offiziell aussieht, wenn es das nicht ist.
- Die Person bitten, ehrliche Kritik zu löschen.
- Über Geschmack streiten („unsere Administration ist schöner“).
- Ein anderes Produkt angreifen, um Exponential zu verteidigen.
- Private Informationen über die Person preisgeben.
- Korrekturen oder Termine versprechen.

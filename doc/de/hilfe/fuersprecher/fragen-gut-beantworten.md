# Fragen gut beantworten

Diese Seite ist für Fürsprecher, die Fragen in den Foren, im Chat, bei der Arbeit oder auf Veranstaltungen beantworten.
Eine gute Antwort löst das Problem, zeigt, wo man nächstes Mal nachschaut, und bleibt für den nächsten Leser nützlich.

## Die fünf Schritte

1. **Verstehen.** Formulieren Sie die Frage in einer Zeile neu. Wenn Sie unsicher sind, fragen Sie nach.
2. **Kurz antworten.** Zuerst ein oder zwei Sätze.
3. **Zitieren.** Verlinken Sie die Hilfeseite oder die Quelle ([Auf die richtige Hilfeseite verweisen](auf-die-richtige-hilfeseite-verweisen.md)).
4. **Datieren.** „Geprüft mit Exponential 6.0.x.“
5. **Nachfassen.** Fragen Sie, ob es funktioniert hat; veröffentlichen Sie die endgültige Lösung.

## Rückfragen

```text
Which version of Exponential do you run? (Setup > System information shows it)
Which database, PHP version and engine (Velocity, FrankenPHP, Apache/nginx with PHP-FPM)?
Which administration design (admin4, classic, AdminUI)?
What exactly did you do, and what exactly happened (the message)?
Did it work before? What changed?
```

Erinnern Sie die Menschen daran, Passwörter, Schlüssel und personenbezogene Daten wegzulassen
([Wenn etwas schiefgeht](../../../en/us/help/when-something-goes-wrong.md#a-good-bug-description)).

## Muster für häufige Fragen

| Fragetyp | Muster |
|---|---|
| „Wie mache ich ...?“ | Schritte + Link auf die Hilfeseite |
| „Warum passiert X?“ | Wahrscheinliche Ursache + wie man es prüft + Link |
| „Ist X möglich?“ | Ja/nein + wie + Link; wenn nein, sagen Sie es und bieten Sie an, was es gibt |
| „Etwas ist kaputt“ | Rückfragen; wenn es ein Fehler ist, auf den Tracker verweisen ([Fehler gut melden](fehler-gut-melden.md)) |
| „Was soll ich wählen?“ | Nach dem Bedarf fragen + die Vergleichsseiten verlinken ([Die Produktfamilie kennen](die-produktfamilie-kennen.md)) |
| Ein Sicherheitsproblem | Anhalten; vertraulich weiterleiten ([Sicherheitsmeldungen bleiben vertraulich](sicherheitsmeldungen-bleiben-vertraulich.md)) |

```text
HOW-TO ANSWER
Short answer: <answer>.
Steps:
1. <...>
2. <...>
Details in the help: "<page>" (<link>). Checked on Exponential <6.0.x>.

"NOT POSSIBLE" ANSWER
As far as I know, Exponential doesn't <X>. The closest is <Y> (<link>). If you need X, you could
propose it in the community tracker: <link>.
```

## Wann Sie nicht antworten

- Sie raten. Sagen Sie „Ich bin nicht sicher“ oder lassen Sie jemand anderen antworten.
- Die Frage betrifft eine Person oder eine private Angelegenheit.
- Es ist eine Verkaufsfrage an einen Anbieter: Verweisen Sie auf den Anbieter und legen Sie offen, wenn Sie es selbst
  sind ([Offenlegung und Interessenkonflikte](offenlegung-und-interessenkonflikte.md)).

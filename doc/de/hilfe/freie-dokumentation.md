andere Bedingungen behalten, steht unter [Die Lizenz dieser Dokumentation](../../eng-us/README-LICENSE.md).

## Was Sie tun dürfen

### Lesen und studieren

Lesen Sie jede Seite so oft Sie möchten und zu jedem Zweck: um das System kennenzulernen, sich für eine Aufgabe
weiterzubilden, einen Kurs vorzubereiten oder vor einer Änderung nachzusehen, wie etwas funktioniert. Zum Lesen und
Studieren brauchen Sie keine Erlaubnis.

### Kopieren und an andere Benutzer weitergeben

Sie dürfen Seiten oder die gesamte Dokumentation kopieren und die Kopien jedem geben oder schicken, auf Papier oder
als Dateien, kostenlos oder gegen Entgelt, auf jedem Medium. Drucken Sie eine Seite für Kollegen aus, stellen
Sie die Leitfäden in Ihr Intranet, hängen Sie eine Seite an ein Support-Ticket oder geben Sie den Redakteuren Ihres
Teams einen ausgedruckten Satz. Geben Sie dabei mit jeder Kopie weiter:

- die **Urheberrechtsvermerke** der Seiten,
- den **Lizenzhinweis**, den Absatz, der besagt, dass die GNU Free Documentation License gilt, und
- eine **Kopie der Lizenz** selbst (die Datei `doc/eng-us/LICENSE-GFDL-1.3.txt` oder den Text der Lizenz im selben
  Dokument).

Fügen Sie keine eigenen Bedingungen hinzu und verwenden Sie keine technischen Maßnahmen (zum Beispiel einen
Kopierschutz), die die Empfänger Ihrer Kopien daran hindern, sie zu lesen oder weiter zu kopieren.

Geben Sie mehr als 100 Kopien in einem schwer bearbeitbaren Format aus, etwa als PDF ohne seine Quelle, müssen Sie
außerdem eine bearbeitbare Kopie bereitstellen (die Markdown-Dateien von `doc/` genügen) oder den Lesern sagen, wo
sie eine bekommen. Mehr als 100 gedruckte Exemplare brauchen einen Umschlag, der den vollständigen Titel zeigt und
Sie als Herausgeber nennt. Abschnitt 3 der Lizenz enthält die Einzelheiten.

### Übersetzen

Eine Übersetzung ist eine veränderte Version der Dokumentation (siehe den nächsten Abschnitt) und daher zu denselben
Bedingungen erlaubt. Sie dürfen auch die Lizenzhinweise übersetzen; der englische Originaltext der Lizenz und der
Hinweise muss Ihrer Übersetzung beiliegen, und wo beide voneinander abweichen, gilt das englische Original.

### Anpassen, verbessern und Ihre Fassung weitergeben

Sie dürfen Seiten ändern: sie korrigieren, kürzen, erweitern, für Ihre eigene Site oder Ihr Team umschreiben oder
Abschnitte in Ihr eigenes Handbuch übernehmen. Sie dürfen Ihre geänderte Fassung auch weitergeben, sofern:

- Ihre Fassung unter **derselben Lizenz** veröffentlicht wird, der GNU Free Documentation License, damit alle, die

- sie **angibt, dass sie geändert wurde**, und von wem (die Lizenz verlangt die Autoren der Änderungen auf der
  Titelseite und einen Abschnitt „History“, der die Versionen auflistet);

- sie nicht vorgibt, das Original zu sein: Geben Sie Ihrer Fassung einen eigenen Titel, es sei denn, der Herausgeber

Sie dürfen diese Seiten neben andere, unabhängige Dokumente in eine Sammlung oder auf dasselbe Medium stellen (auf
eine Website mit Ihren eigenen Seiten oder in eine Schulungsmappe mit Ihren Folien). Die Lizenz dieser Seiten

daraus erstellte Fassungen.

### Zitieren

Verweisen Sie auf eine Seite mit ihrem Titel und ihrer Adresse in der Hilfe oder mit ihrer Datei im Repository
(zum Beispiel `doc/eng-us/help/getting-started.md`). Ein kurzes Zitat mit Quellenangabe ist nach dem Urheberrecht in
der Regel ohnehin zulässig; wenn Sie ganze Seiten oder große Teile kopieren, beachten Sie die oben genannten
Bedingungen.

## Anderen helfen

Freie Dokumentation wird jedes Mal besser, wenn jemand eine dieser Freiheiten nutzt und das Ergebnis teilt.

- **Teilen Sie, was Ihnen geholfen hat.** Wenn eine Seite Ihr Problem gelöst hat, schicken Sie sie der nächsten
  Person mit derselben Frage.
- **Melden Sie, was falsch ist.** Ist eine Seite veraltet, unklar oder falsch, sagen Sie es dem Projekt: Hilfe,
  *Fehler melden* zeigt, wo und wie.
- **Geben Sie Ihre Korrekturen zurück.** Jede Hilfeseite hat einen Link *Auf GitHub bearbeiten* zu ihrer
  Quelldatei. Korrigieren Sie sie und eröffnen Sie einen Pull-Request ([Mit Git entwickeln](mit-git-entwickeln.md#eine-änderung-per-pull-request-beitragen)
  zeigt Schritt für Schritt, wie es geht). Eine Änderung an diesen Seiten wird unter derselben Lizenz angenommen,
  der GNU Free Documentation License 1.3 oder jeder späteren Version, und bleibt so für alle frei.
- **Bieten Sie Ihre Übersetzung an.** Eine übersetzte Seite hilft allen Lesern dieser Sprache; tragen Sie sie auf
  dieselbe Weise bei.

# Platform ecosystem: June 2025

What changed in June 2025 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 236 changes in 14 platform repositories this month: 74 new or improved capabilities, 55 bug fixes, 3 behaviour changes.
- Busiest repositories: adminneo (58), admin-ui-7x (46), admin-ui-ibexa (46).
- 11 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

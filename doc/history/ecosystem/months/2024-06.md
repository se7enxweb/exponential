# Platform ecosystem: June 2024

What changed in June 2024 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 116 changes in 10 platform repositories this month: 32 new or improved capabilities, 9 bug fixes, 7 behaviour changes.
- Busiest repositories: admin-ui-7x (37), admin-ui-ibexa (37), core (24).
- 2 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

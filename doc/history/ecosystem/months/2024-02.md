# Platform ecosystem: February 2024

What changed in February 2024 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 161 changes in 14 platform repositories this month: 60 new or improved capabilities, 44 bug fixes, 2 behaviour changes.
- Busiest repositories: admin-ui-7x (43), admin-ui-ibexa (43), core (25).
- 7 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

## Upstream activity carried by the forks

- **admin-ui-7x**: 43 upstream changes. Largest: `293b8bcfc` Updated PHPUnit to 9.5; `5053ee9b0` IBX-7107: Tabs validation updated (#1048); `11849cfb2` IBX-6815: [REST] Fixed isBookmarked property in load-subtree response (#1139)
- **core**: 25 upstream changes. Largest: `2c8459dfa` IBX-6906: [DX] Introduced identifier-based view matchers (#322); `12b3b45a4` Specified return type for PermissionResolver; `565bb779b` [CI] Improved publishing of Solr Docker image for tests (#304)
- **exponential-platform-nexus-starter**: 13 upstream changes. Largest: `60190a2b2` Upgrade to Ibexa 4.6; `20ea872ee` Upgrade to Ibexa 4.6; `d4e07e389` NGSTACK-752 Update PR
- **fieldtype-richtext-ibexa**: 11 upstream changes. Largest: `058d349` IBX-6932: Fixed adding custom attrs to list (#139); `ef78778` IBX-6379: Fixed anchor in formatted (#144); `40ddcdf` IBX-7747: Two or more embedded items makes popup menu unable to open (#147)
- **site-bundle**: 6 upstream changes. Largest: `b98525e` NGSTACK-673: update for breaking change in Site API; `a70fcb9` NGSTACK-822 switch from string mapped to sort clause to FQN; `cf8fd66` NGSTACK-822 type hint to array parameter of function added
- **ibexa-recipes**: 4 upstream changes. Largest: `bc4c912` IBX-7611: Bump version for webpack and sass-loader (#108); `e8417d6` [ibexa/docker] Set the default image to php:8.2-node18 (#109)

# Platform ecosystem: July 2025

What changed in July 2025 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 358 changes in 19 platform repositories this month: 94 new or improved capabilities, 76 bug fixes, 6 behaviour changes.
- Busiest repositories: admin-ui-7x (82), admin-ui-ibexa (82), adminneo (60).
- 29 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

# Platform ecosystem: January 2024

What changed in January 2024 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 322 changes in 13 platform repositories this month: 136 new or improved capabilities, 56 bug fixes, 1 behaviour change.
- Busiest repositories: exponential (123), admin-ui-7x (77), admin-ui-ibexa (77).
- 93 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

- **admin-ui-7x**: 77 upstream changes. Largest: `e518224eb` IBX-7409: Changed Content Type to content type (#1087); `925b98844` IBX-7525: UDW as npm package (#1062); `62b28d925` IBX-7450: Implemented fullscreen view for Focus Mode (#1074)

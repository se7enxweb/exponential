# Platform ecosystem: April 2025

What changed in April 2025 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 230 changes in 10 platform repositories this month: 88 new or improved capabilities, 35 bug fixes, 4 behaviour changes.
- Busiest repositories: adminneo (117), admin-ui-7x (27), admin-ui-ibexa (27).
- 4 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

## Upstream activity carried by the forks

- **adminneo**: 117 upstream changes. Largest: `2fa10dd1` Rename folder lang -> translations; `c4edfcd0` Use singleton interface to access the Admin class in global functions; `fbd2fb6a` Update language files
- **admin-ui-7x**: 27 upstream changes. Largest: `f5b1aedf3` IBX-9727: Added missing type hints (#1504); `036964bc0` IBX-9722: Replaced graphql subitems fetching with dedicated REST endpoint (#1503); `597110522` IBX-9619: Reworked action list (#1480)
- **exponential-platform-nexus-starter**: 19 upstream changes. Largest: `4835c0d53` NGSTACK-929 remove redundant alt texts on images on components and bivts, display only explicit alternative text if set; `52b8b9a2f` NGSTACK-929 remove skip to cookie banner, make cookie banner focusable on load, create focus trap on cookie banner; `85bab2800` Fix CS and PHPStan
- **core**: 16 upstream changes. Largest: `f6e3294b3` Remove usage of deprecated ContainerAwareTrait (#514); `d177f134e` IBX-9379: Added Grace Period for archived versions (#515); `244f7b24c` IBX-9103: Replaced relation constants with RelationType enum (#524)
- **fieldtype-richtext-ibexa**: 12 upstream changes. Largest: `b5a8382` IBX-9727: Added missing type hints (#222); `53d1e60` Backported fix for backward-compatibility issue on XMLSanitizer; `c8808a5` [CS] Fixed outstanding CS issue in XMLSanitizer.php
- **ibexa-recipes**: 4 upstream changes. Largest: `d5dac94` IBX-9339: Added recipe for ibexa/fieldtype-richtext-rte (#149); `19ebaae` IBX-8552: Changed customer registration group id to remote id (#165); `3e2c417` IBX-6236 Added config files for custom tags and custom styles (#169)

# Platform ecosystem: October 2024

What changed in October 2024 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 202 changes in 10 platform repositories this month: 54 new or improved capabilities, 43 bug fixes, 1 behaviour change.
- Busiest repositories: adminneo (69), admin-ui-7x (40), admin-ui-ibexa (40).
- 8 of the changes are se7enxweb work with a user-visible theme; the rest is upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

## Upstream activity carried by the forks

- **adminneo**: 69 upstream changes. Largest: `571be06e` Add Adminer namespace; `62246338` Add 'Home' to breadcrumb navigation; `e378f7d8` Update translations for regexp search
- **admin-ui-7x**: 40 upstream changes. Largest: `c80979b98` IBX-8525: Added language code validation (#1356); `974dfdc3e` IBX-8968: Fixed translation selector in search and dashboard (#1362); `230a77d1b` Improved PHPDoc descriptions (#1364)
- **core**: 29 upstream changes. Largest: `ac4e57c91` IBX-8957: Fixed deserializing SiteAccess Matchers for ESI (#430); `9328655cc` IBX-8811: Rebranded SiteAccess session prefix (#420); `fed1a91cd` IBX-9103: Added RelationType filtering to fetch relations methods (#440)
- **ibexa-recipes**: 5 upstream changes. Largest: `36e2220` Enabled ibexa/core-search (#143); `3460a12` Added recipe for ibexa/discounts package (#144); `0867ac7` [ibexa/product-catalog-symbol-attribute] Fixed the bundle entry (#146)

# Platform ecosystem: May 2024

What changed in May 2024 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 118 changes in 16 platform repositories this month: 34 new or improved capabilities, 13 bug fixes, 1 behaviour change.
- Busiest repositories: core (28), admin-ui-7x (24), admin-ui-ibexa (24).
- None of the changes is se7enxweb work with a user-visible theme; all of them are upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

## Upstream activity carried by the forks

- **core**: 28 upstream changes. Largest: `5d4ffc6f7` IBX-8139: Dropped `class_alias` BC layer statements from all classes (#366); `98b7b50e6` IBX-5388: Fixed performance issues of content updates after field changes; `327864179` Wrapped `iterable`s used as arrays with `iterator_to_array` (#372)
- **admin-ui-7x**: 24 upstream changes. Largest: `da76e0066` IBX-8121: Fixed code style for 5.0; `38d971c96` IBX-8142: removed depreacated code (#1248); `0d22dfd45` Get getNotificationsStatusLoop interval from YAML config (#1198)
- **exponential-platform-nexus-starter**: 11 upstream changes. Largest: `e455a23b0` NGSTACK-835: replace Better Admin UI with Admin UI Extra; `b13e4c724` NGSTACK-885 add host to git tag during deployment; `d4db2a8aa` Add symfony/phpunit-bridge to symfony.lock to prevent Flex destroying our changes in phpunit.xml.dist file
- **ibexa-recipes**: 8 upstream changes. Largest: `e2314fb` [All] Added app-switcher and headless-assets bundles (#115); `bbc8fa4` IBX-8144: [Rebranding] Remove compatibility layer from webpack encore (#117); `3b580d8` IBX-8082: [ibexa/connector-qualifio] Added Connector Qualifio
- **exponential-platform-dxp**: 6 upstream changes. Largest: `8605b34` Updated copyright year to 2024; `9b6a9fa` Update README.md (#144); `c01eb77` IBX-8154: Run tests on PHP 8.3 (3.3) (#150)
- **ibexa-legacy-bridge---7x**: 4 upstream changes. Largest: `ca13b11` Fix issues with non matching interfaces after Twig 3.9; `7efbc39` Fix rendering legacy Twig templates with Twig 3.9+; `c22ecd6` Cache clearing command is also clearing legacy content cache

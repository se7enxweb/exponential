# Platform ecosystem: March 2025

What changed in March 2025 in the platform repositories around Exponential: the Symfony based kernel and administration interface, layouts, starters, bridges and framework forks. Read it if you run the platform next to Exponential, or want to know what a fork carries before you update it. The [ecosystem overview](../../ecosystem.md) explains how the repositories fit together.

## In short

- 389 changes in 8 platform repositories this month: 138 new or improved capabilities, 70 bug fixes, 13 behaviour changes.
- Busiest repositories: adminneo (237), admin-ui-7x (47), admin-ui-ibexa (47).
- None of the changes is se7enxweb work with a user-visible theme; all of them are upstream history carried by the forks.
- The table below counts every repository; the lists after it name the largest changes.

## Upstream activity carried by the forks

- **adminneo**: 237 upstream changes. Largest: `332038e5` Rename namespace Adminer -> AdminNeo; `094c384c` Rename folder adminer -> admin; `a64867ed` Change product name to AdminNeo in texts
- **admin-ui-7x**: 47 upstream changes. Largest: `106ac8948` Removed deprecated ContentType::isContainer property (#1472); `b6c6fd35f` IBX-9628: ellipsized details content (#1466); `574d20f2a` IBX-9338: Updated buttons label for create content on the fly (#1478)
- **core**: 28 upstream changes. Largest: `e33b2ff04` Removed deprecated Ibexa\Core\Persistence\Legacy\Content\FieldValue\Converter\*Converter::create method (#500); `fdeeb4fd6` Bump phpstan/phpstan to ^2.0 (#493); `0b608b7d9` Added support for ContentAwareInterface in ibexa_render function (#511)
- **ibexa-recipes**: 13 upstream changes. Largest: `0e7fcc3` IBX-9584: Resolved Symfony 6.x deprecations vol. 2 (#159); `a281298` Added `IbexaDiscountsCodes` bundle to recipes; `52d8872` IBX-9239: Updated recipe for ibexa/connect package (#158)
- **fieldtype-richtext-ibexa**: 10 upstream changes. Largest: `be60c4a` Fixed PHP 8.1 PHPstan issue report; `cb92634` [PHPStan] Set `treatPhpDocTypesAsCertain` to `false` (#219); `286ba96` Bump phpstan/phpstan to ^2.0 (#213)
- **exponential-platform-nexus-starter**: 6 upstream changes. Largest: `4173341ef` NGSTACK-963 required field mark; `1511afcec` NGSTACK-963 translation; `6dcfab90a` NGSTACK-963 star from css to html so it is hidden from screen readers

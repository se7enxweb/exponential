# ezplatform-alloyeditor-element-width: platform repository history

The history of `ezplatform-alloyeditor-element-width`, one of the platform repositories around Exponential (group: Admin user interface). Read it to learn what the repository gives you, how it relates to Exponential and when it changed. The ledger records 1 change from 2026-04-12 to 2026-04-12, all made by the se7enxweb team.

## What it is

Bundle that adds element-width editing to the online editor.

## How it relates to Exponential

Forked on 2026-04-12 with se7enxweb dependencies and a replace shim.

## What a user gets

Editors can set the width of elements in rich text.

Install it with Composer (a project that already requires the platform pulls it in by itself):

```bash
composer require se7enxweb/ezplatform-alloyeditor-element-width
```

# ezplatform-query-fieldtype: platform repository history

The history of `ezplatform-query-fieldtype`, one of the platform repositories around Exponential (group: Field types). Read it to learn what the repository gives you, how it relates to Exponential and when it changed. The ledger records 3 changes from 2025-09-27 to 2026-04-12, all made by the se7enxweb team.

## What it is

Field type that stores a content query.

## How it relates to Exponential

Renamed to se7enxweb with replace shim.

## What a user gets

Query fields install on current PHP.

Install it with Composer (a project that already requires the platform pulls it in by itself):

```bash
composer require se7enxweb/ezplatform-query-fieldtype
```

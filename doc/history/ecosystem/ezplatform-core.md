# Ecosystem repository: ezplatform-core

**Group:** Kernel. **Period in the ledger:** 2024-03-22 to 2026-04-11. **Changes:** 8 (2 made by the se7enxweb team, 6 upstream history carried by the fork).

## What it is

Container package that pulls in the Exponential Platform core bundles.

## How it relates to Exponential

Meta level package of the 3.x line; follows the release of its siblings.

## What a user gets

One require line that brings the matching core bundles.

Install it with Composer (a project that already requires the platform pulls it in by itself):

```bash
composer require se7enxweb/ezplatform-core
```

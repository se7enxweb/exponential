# December 2025

What changed in Exponential in December 2025, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- PHP 8.5 is supported: two classes got the nullable types it requires and Zeta Components were raised.
- 6.0.11 was tagged on 30 December 2025.

**PHP 8.5 is supported.** Two classes got the nullable types that PHP 8.5 requires (`ea660c8371`, `0d035b6723`). Zeta Components were raised to releases that support PHP 8.5 (`4db16d95c3`). The README states that PHP 8.5 is supported (`27ed271f3d`), and that commit is tag 6.0.11 of 30 December ([Changelog 6.0.11](../../changelogs/6.0/6.0.11.md)). Support links in the README that broke with the rename were repaired (`8febb1e2b3`). Details: [PHP 8 support](../../bc/6.0/php8.md).

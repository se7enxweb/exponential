# September 2025

PHP 8.1 and 8.2 clean-up and a first useful `robots.txt`; version 6.0.11 is in development (`d58506719e`).

## PHP 8 clean-up

Several fixes come from the 7x work and from the upstream project of a contributor who had solved the same problems: richer debug log messages (`881a280153`), type checks for PHP 8 (`b13f305ac8`), empty strings instead of `null` passed to `mysqli_real_escape_string()` and `preg_match()` (`ff023c8e5f`, `569cea280f`), declared public properties (`96ee5aa258`, `7e0a68ee94`, `dc2440c8da`, `8ad71d8a79`, `cb6d3e2435`), `#[ReturnTypeWillChange]` on SPL interface methods (`a075afe4d6`), a replacement for the deprecated `utf8_decode()` in the LDAP user (`a5199cc8dc`), the collaboration module (`1ba06942c3`) and the SOAP response class (`d806722a80`). See the table in [PHP 8 support](../../bc/6.0/php8.md).

## Behaviour fixes

- Notification mail uses To instead of Bcc, which some mail servers refuse (`11dfa2e178`).
- The view count cronjob works in default installations (`8bffd7b08a`).
- The dashboard logo no longer hides the product name (`86e0d4988b`).

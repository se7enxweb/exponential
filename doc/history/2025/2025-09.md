# September 2025

What changed in Exponential in September 2025, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- PHP 8.1 and 8.2 clean-up and fixes for notification mail and the view count cronjob.
- New installations ship a useful `robots.txt`; 6.0.11 was in development.

Version 6.0.11 went into development (`d58506719e`). The month cleaned up for PHP 8.1 and 8.2, fixed two behaviours that hit default installations, and gave new installations a useful `robots.txt`.

## PHP 8 clean-up

Several fixes came from the 7x work, others from the upstream project of a contributor who had solved the same problems:

- richer debug log messages (`881a280153`) and type checks for PHP 8 (`b13f305ac8`);
- empty strings instead of `null` passed to `mysqli_real_escape_string()` and `preg_match()` (`ff023c8e5f`, `569cea280f`);
- declared public properties (`96ee5aa258`, `7e0a68ee94`, `dc2440c8da`, `8ad71d8a79`, `cb6d3e2435`);
- `#[ReturnTypeWillChange]` on SPL interface methods (`a075afe4d6`);
- a replacement for the deprecated `utf8_decode()` in the LDAP user (`a5199cc8dc`), the collaboration module (`1ba06942c3`) and the SOAP response class (`d806722a80`).

Each fix is in the table of [PHP 8 support](../../bc/6.0/php8.md).

## Behaviour fixes

- Notification mail uses To instead of Bcc, which some mail servers refuse (`11dfa2e178`).
- The view count cronjob works in default installations (`8bffd7b08a`).
- The dashboard logo no longer hides the product name (`86e0d4988b`).

## A default robots.txt

New installations ship a `robots.txt` with rules (`f93362f6b4`, `185ddce843`). See [A useful robots.txt out of the box](../../features/6.0/robots-txt.md).

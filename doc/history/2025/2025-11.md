# November 2025

What changed in Exponential in November 2025, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- No change to the main installation in November 2025.
- The layouts core moved to PHP 8.4 property hooks.
- The Nexus starter and AdminNeo received refinements.

**Layouts 2.0 uses PHP 8.4 property hooks; no change to the main installation.** The main repository's ledger has no entry for November 2025. 165 of the 303 changes of the month belong to the layouts core.

## What changed in the platform ecosystem

- **Property hooks in the layouts core.** On 2025-11-26 the core API values were converted to PHP 8.4 property hooks (`e88254df7`, 258 lines), on 2025-11-27 and 11-28 the config values, the view system and further classes followed (`c8b4de372`, `edb59271a`, `f757a16b9`). Deprecations from Symfony and Doctrine were removed across the code (`3b06316da`, 2025-11-10) and the test suite moved from PHPUnit annotations to attributes (`501549e21`, 2025-11-11, 594 lines). Why it matters: Twig 3.24 cannot read these properties through its normal attribute lookup, which is why Nexus v5 pages stop on PHP 8.4 without the [layouts-core fork](../../features/6.0/platform-layouts-core-fork.md) published in April 2026.
- **Platform core.** `ProxyDomainMapperFactory` became lazy (`fb60a60d64`, IBX-10936, 2025-11-19), the `ContentTypeGroupName` criterion was added to the content type search (`d1bfbf7bb5`, 2025-11-07) and a forbidden exception is now transformed to access denied (`9de4817ace`, 2025-11-04).
- **Admin interface.** Field definitions can be fetched from an expression (`f0b0128ac`, 2025-11-19), mail templates were updated (`24ae75028`, 2025-11-18) and missing closure return types were fixed for PHP 8 (`1117cc03e`, 2025-11-25). See [the administration interface](../../features/6.0/platform-admin-ui-fork.md).
- **Nexus starter.** Global stylesheet and typography/header refactoring (NGSTACK-1014, `94a83b9d0`, 2025-11-27) and a variable for the navigation collapse breakpoint (NGSTACK-1013, `0100ced58`, 2025-11-21). See [Nexus](../../features/6.0/platform-nexus-starter.md).
- **Rich text.** A fallback configuration when initialisation fails (`110f75a`, IBX-10565) and an attribute that controls the input event (`b58bebc`, IBX-9657).
- **AdminNeo.** German and Dutch translations updated (2025-11-02), PostgreSQL default socket connection fixed (`d5a517e3`, 2025-11-11). See [AdminNeo](../../features/6.0/adminneo-database-manager.md).

# May 2025

- **6.0.8 is published** (merge `ee37522160`, [Changelog 6.0.8](../../changelogs/6.0/6.0.8.md)) and development of 6.0.9 begins (`cba72edbdf`).
- **PostgreSQL.** The PostgreSQL schema handler no longer prints warnings or aborts the installation (`cfe35ff470`).
- **REST API.** `ezprestapi` 1.2 joined the distribution: create, read, update and delete content over HTTP (`65920d0d6c`). See [the distribution](../../features/6.0/default-extension-distribution.md).
- **README.** PHP 7 support is declared deprecated and PHP 8.4 supported (`0a418638c8`, `d37bd49fd3`), the licence is clarified as GNU GPL only (`c8b546f14b`), and the support summary was revised (`f18dc66f20`).

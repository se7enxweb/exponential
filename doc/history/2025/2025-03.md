# March 2025

## In short

- No change to the main installation in March 2025.
- AdminNeo, the database manager embedded by `sevenx_dse`, became its own product.
- Deprecated persistence converters were removed from the platform core.

**AdminNeo becomes its own product.** The main repository has no entry for March 2025. Of the 389 changes in the platform ecosystem that month, 237 belong to [AdminNeo](../ecosystem/adminneo.md), the database manager that the `sevenx_dse` extension embeds in the Exponential administration interface.

## What changed in the platform ecosystem

- **AdminNeo is renamed and rebranded.** The project dropped the Adminer name in code and texts: the namespace changed from Adminer to AdminNeo (`332038e5`), the folder from `adminer` to `admin` (`094c384c`) and the product name in all texts (`a64867ed`). Why it matters: this is the work behind the standalone AdminNeo 5.0.0 release of 2025-05-29, with a responsive theme, dark mode and plugins; see [AdminNeo database manager](../../features/6.0/adminneo-database-manager.md).
- **Removed deprecations in the platform core.** The legacy persistence field value converters that were deprecated were removed (`e33b2ff04`), PHPStan was raised to 2.0 (`fdeeb4fd6`) and the `ibexa_render` function accepts content-aware objects (`0b608b7d9`). The administration interface lost the deprecated `ContentType::isContainer` property (`106ac8948`) and made the details text ellipsized (`b6c6fd35f`).
- **Recipes** resolved a second wave of Symfony 6 deprecations (`0e7fcc3`, IBX-9584; see [ibexa-recipes](../ecosystem/ibexa-recipes.md)), added a bundle for discount codes (`a281298`) and updated the recipe for the connect package (`52d8872`).

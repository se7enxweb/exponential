# January 2025

## In short

- 6.0.7 was in development.
- Sub items gained "Copy selected"; the debug block names its switch and has section ids.
- Many PHP 8 and PostgreSQL warnings are gone; package URLs use the new brand domain.

Development of 6.0.7 (`ea5a36cabf`). The month brings a new bulk action for editors, a better debug block and a long list of PHP 8 and PostgreSQL warnings that are gone.

## Copy selected subitems

On 31 January the sub items list of the admin gained **Copy selected** (`b492af16ad`): tick items, choose it in More actions, pick a destination, and every selected subtree is copied there with the permission checks of the normal copy. See [Copy selected subitems](../../features/6.0/subitems-copy-selected.md).

## Debug output

The debug block's heading says which switch made it appear (`ba1df7cd15`) and its sections have ids so a stylesheet can order and style them (`81996fc6dd`); see [Debug output improvements](../../features/6.0/debug-output-improvements.md).

## Fixes

- The object relations modal opens its upload dialog in the right place (`98e1d61ebc`); upload errors name the file (`306bb8948b`).
- The ordering, roles and policies tabs of the admin node view work with the default admin design (`a87ec544a4`, `4e488afa31`).
- No warning when unlinking a file that is already gone (`811ace1fac`).
- PHP 8: the template `{for}` loop (`7a210b0baa`), the star rating extension (`eb9079bcb1`); PostgreSQL library updates remove a flood of debug warnings (`0ae1746566`). See [PHP 8 support](../../bc/6.0/php8.md).

## Package server

Setup wizard package URLs use the new brand domain; the old address redirects transparently (`5fb85b97f0`). See [the rebranding page](../../features/6.0/rebranding-to-exponential.md).

## Documentation

A README section explains how Ibexa DXP OSS relates to eZ Platform and to Exponential (`96cf442969`).

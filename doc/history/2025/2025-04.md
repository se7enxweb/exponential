# April 2025

**PHP 8.4 support begins, PHP 7 support ends.** The removed `E_STRICT` constant is no longer used (`3bcf09d889`); ten files of the setup wizard and the kernel were adjusted for PHP 8.4 (`86abc11907`); the version moved to 6.0.8 to signal PHP 8 support (`e4e664a3d0`); and `composer.json` now requires PHP 8.1 or newer (`bdbcb503a6`). Sites that still run PHP 7.4 must stay on 6.0.7. The full sequence is in [PHP 8 support](../../bc/6.0/php8.md); the release is described in [Changelog 6.0.8](../../changelogs/6.0/6.0.8.md).

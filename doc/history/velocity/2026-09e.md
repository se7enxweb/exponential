# Velocity chronicle: September 2026, 25 to 30 September

What changed in Exponential Velocity, the web server engine, in this period, and where to read more. Read it if you run or tune Velocity, or want to know why a setting exists. *Part of the [Exponential Velocity history](README.md). Previous: [24 September](2026-09d.md). Next: [October 2026](2026-10.md).*

## In short

The last six days of September carry the engine from `v0.0.4.28` to `v0.0.4.42`: fifteen releases, 414 ledger rows. The package takes the name **exponential-velocity**; the control panel gains domains, an SSL tab and a Cache tab and optional two-factor authentication; the response cache becomes faster and starts to report what it is doing; workers run as the site's user instead of root; the programs move into `sbin/` and `bin/` with every old path still working; and the C file server `uwebserver` is rebuilt as a small, hardened static file server. Exponential's own needs drive many of the fixes: the file-consistency check, per-request caches, nested multipart fields, package archives and the admin dashboard all show up in the notes.

## What a user gained, by theme

**The control panel (25 to 26 September).** The Domains tab shows the domains in use, a record per domain with a status, aliases, subdomains and a document root per domain with host routing on HTTP/1.1 and HTTP/2, redirects (HTTP to HTTPS, preferred `www` or bare host, forwarding), HSTS, custom error documents, the covering certificate and per-domain traffic (`abe2931`, `1166ba7`, `5cb5cbe`). The SSL tab lists the served certificate and every certificate by expiry, with safe settings and renew and reload (`bee4ebd`). The Logs tab filters by host. A Cache tab runs the response cache from the browser (`8c4b095`, `4526699`). Optional TOTP two-factor authentication arrives (`8402fba`). See [Control panel](../../features/6.0/velocity-control-panel.md).

**The response cache.** Cached pages are filed under the coding they are stored in, so brotli and gzip clients share an entry (`27f13dd`); HEAD requests are answered from the cache (`83d83a7`); an optional in-process memory layer sits in front of APCu (`3c4377a`); APCu is used only when it can hold entries (`b166c56`); `/Q/health` reports where hits come from (`e6ed766`); a generation marker lets a deploy invalidate everything (`717db84`); `Q.web.appCache` lets an application answer its own pages per visitor before a worker is woken (`fa4cedc`, `604964a`, `190fe92`, `090bd97`); `Q.web.cache.pauseFile` pauses caching for maintenance (`e22031f`); and on 30 September the default is corrected to off (`a81335c`). See [Response cache](../../features/6.0/velocity-response-cache.md).

**Workers.** The zygote (`3fbc8ab`, on by default from `2240e2e`, restricted by `bcb0901`, restored for 8.2 and 8.3 by `2e81842`); `Q.compat.statTtl` (`a1cf4b8`); `Q.webserver.reusePort` (`5b6318a`); workers give up root (`dbda08a`); `REQUEST_TIME` per request (`c9854aa`). See [Worker pool](../../specifications/6.0/velocity-worker-pool.md).

**Security and correctness.** Headers and HSTS on every response (`24d231f`); `WWW-Authenticate` answers `401` (`0ac4f95`); `413` for large bodies on HTTP/1.1 and HTTP/2, chunked bodies parsed chunk by chunk (`4bae92e`); a second server on the same certificate directory no longer takes HTTPS away from the first (`77232ae`); a stopping server no longer removes another server's pid file (`2e4d322`). See [HTTP/2 and security](../../specifications/6.0/velocity-http2-and-security.md).

**Naming and layout.** The package and repository become `se7enxweb/exponential-velocity` (`244d16a`, `061f30f`, `087d655` for the in-place upgrade). On 30 September the programs move to `sbin/` and `bin/` (`55ce925`, `7245e2f`) and the documentation names the server Velocity (`ab9adff`).

**uwebserver (30 September).** `5535a44` to `15ee8af`: strict command line, safe defaults (`127.0.0.1:8000`), static file serving, a configuration file, a manual page, sanitiser-clean tests, a fuzz harness, and four security reviews. See [uwebserver](../../features/6.0/velocity-uwebserver.md).

## Why Exponential cares

Several fixes of this period exist because Exponential ran into them while being served by Velocity:

- the file-consistency check listed about 330 kernel and library files as modified under Velocity, because the file layer returned transformed source (`50176b3`);
- the admin dashboard answered half its signed-in requests with the anonymous front page after a failed warm-up (`2921872`);
- package `.tar.gz` archives did not open through the file layer (`86ade5e`, `81646a6`);
- forms posted with `FormData` lost nested field names such as `Attributes[0][id]` (`c1f3a26`);
- a per-request cache keyed on `REQUEST_TIME_FLOAT` served one request's data to the next (`c9854aa`).

Run `./bin/php/console exp:velocity status` or read [Velocity engines](../../bc/6.0/velocity-engines.md) for how to choose and run the engine from Exponential.

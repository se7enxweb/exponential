# Velocity chronicle: July 2026

*Part of the [Exponential Velocity history](README.md). Previous: none. Next: [August 2026](2026-08.md).*

## In one paragraph

July 2026 is the month the engine that Exponential now ships as **Velocity** came into existence. The repository starts on 2026-07-20 with the first release of a pure PHP web server, written upstream as the Qbix web server, and in ten days it grows from a 27-file proof of concept into a server with WebSockets, a control panel, virtual hosts, a scheduler and a compatibility mode for old PHP scripts. Nothing in this month was written for Exponential in particular; it is the base the later months build on, and the reason later chapters talk about "the engine".

## How the month went

**20 July: the first release.** The repository begins with a licence file and, within the hour, the initial release: a PHP web server whose README claimed 55 to 73 percent of nginx throughput for static content. The first day was mostly documentation: the README was rewritten four times to compare the server with other set-ups (nginx, FrankenPHP, Swoole) and to give practical advice to PHP developers. `618638e` added a `composer.json` and cleaned up the Revolt event loop driver; `1672e0c` added autoloading and event handlers; `dd06d06` added Windows support.

**21 July: real-time and legacy.** The server learned to keep connections open (`dce9b96`: "long-lived PHP processes" for WebSockets), then to run legacy scripts through `php-cgi` instead of the CLI SAPI (`5983f11`, finalised in `901f371`), because old applications call `header()` and `setcookie()` in ways the CLI SAPI silently ignores. The same day brought the first test suite, a scheduler (`62d9b23`), socket.io support (`42ed5a5`), and `bdac23b`: hot reload, start, stop, restart and virtual hosts. By the evening the README claimed that static files with keep-alive were served faster than nginx (`ce8cfac`).

**22 to 24 July: autoloading, hardening, input.** PSR-4 autoload configuration, a round of tests and hardening (`e421368`), and `php://input` support (`c7b9146`).

**27 July: the first-run experience.** A welcome page with getting-started instructions, friendlier default error pages (`cd3b4b2`), and three commits that turned the control panel from a status page into a place to manage apps and plugins and to try code in a playground (`05c4ee2`, `a1cc65c`, `ebad1f6`). This is the ancestor of today's [control panel](../../features/6.0/velocity-control-panel.md).

**29 July: the large day.** Bundled optional front-end assets (the server grew from about 0.5 MB to about 1.5 MB, `c9912be`), directory listings and image galleries, minimal replacements for Handlebars and jQuery, support for `Save-Data`, and "federated and distributed web apps" (`025ecac`). Legacy PHP scripts were told to replace `header()` with `Q_Response::header()` (`673e442`), a rule that later became an automatic source transform (see the [worker pool](../../specifications/6.0/velocity-worker-pool.md)).

**30 July:** fixes for the first five issues reported against the server (`ff2b029`, `3f0b451`, `914b41f`).

## Things worth knowing

- The server in this month is **upstream code**. Exponential's own work on it starts in September; see [September 2026, first part](2026-09a.md).
- Commit messages in this month are short and unprefixed; from September the repository follows the `Added`, `Updated`, `Fixed`, `Removed`, `Renamed` convention used across Exponential.
- Features of this month that still exist today are documented on their feature pages; features that were later removed or replaced (the Node-based files, for example) are covered in [August 2026](2026-08.md).

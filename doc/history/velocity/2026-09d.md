# Velocity chronicle: September 2026, 24 September

*Part of the [Exponential Velocity history](README.md). Previous: [23 September](2026-09c.md). Next: [25 to 30 September](2026-09e.md).*

## In one paragraph

24 September is the day the engine becomes a product with an operations story. In 119 ledger rows the server gains HTTPS that looks after itself, a worker pool that sizes itself, a configuration directory laid out like Debian's `/etc/apache2`, a library-free console (`qbixconsole`, `qbixctl`), designs on disk for its own pages, a drop-down **Q shell** on every server view, strict panel passwords, a PHP extension baseline with deb, rpm, Docker and binary builds for every platform, and a security audit with fixes. Release `v0.0.4.27` is cut part-way through the day (`5a27804`); the work that follows it (Q shell, panel passwords, domains, extension baseline, packages) ships in `v0.0.4.28`.

## Security and hardening

- `01204cc`: **the server's admin surface and cluster join were open to anyone who could reach the port.** Closed.
- `4930d46`: the medium and low findings of the audit: request framing (bare LF, obs-fold), log injection, response-cache personalisation, dashboard injection through the Host header, HPACK decoded-size amplification. `32c7da2` follows at once, because the first HPACK check applied to every header block and broke every browser's HTTP/2 connection; it now applies only to table-size updates.
- `27e543e`: browsers that cancel streams across many reloads were disconnected as a rapid-reset attack; fixed, and every `GOAWAY` now logs why it was sent.
- `3130223`: the panel starts with a default key that must be changed at the first sign-in; passwords are checked against rules (length, character classes, no repeats, no common passwords, at least 80 bits of estimated strength) and stored with bcrypt; repeated failures lock the account out.
- `4070f91`: the shell no longer hands the server's sockets and environment to every command, and what it trusts is tightened.
- `c2e899b`: the server's own certificate is signed with SHA-256, because systems that refuse SHA-1 refused it.

## Operations and platform

`d466564` computes every release asset from the extension baseline; `cf54d81` builds deb and rpm packages for Debian 12 and 13, Ubuntu 22.04 and 24.04, and EL 9 and 10, each installed and checked in a clean container; `c919a4d` builds Docker images with optional Oracle, Firebird and ODBC drivers in the standard and full variants. `0d728d9` and `50b6450` document the requirements, extensions, variants, images and packages.

## Fixes of the day (selected)

- Files rewritten after start were served as the warm-up saw them until a restart (`51dcaa2`, `3e7ded7`, `2e7ba1a`, `886ab81`): four paths, all closed.
- The source transform wrote a script's code twice under the function JIT of PHP 8.2 and 8.3 (`1dc18e5`).
- A pooled script answered `HEAD` with its body and saw no `PATH_INFO` (`ef34f90`).
- Request bodies of 0 to 47 and 58 to 255 bytes were refused as "Content-Length is not a number" (`8d0c42c`, `12980d1`).
- A newly forked worker ended every TLS connection that was open at that moment (`4b70bff`).
- The server died at start with a document root directly under `/` (`a15b6c3`).
- One request for an unknown `/Q/` path over HTTP/2 hung the whole server (`9e560bc`).
- An application's session name and cookie lifetime were ignored (`0c95046`).

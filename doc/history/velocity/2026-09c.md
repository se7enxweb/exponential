# Velocity chronicle: September 2026, 23 September

*Part of the [Exponential Velocity history](README.md). Previous: [22 September](2026-09b.md). Next: [24 September](2026-09d.md).*

## In one paragraph

On 23 September the engine stops being only a fast server and becomes one that can be trusted on the public internet and installed on many systems. It is the first day of security fixes (request smuggling, a symbolic link escape, files that HTTP/2 served and HTTP/1.1 refused, a cache that served one visitor's page to everyone), the first release pipeline that produces binaries for macOS, Windows and Linux, the first platform matrix that watches the engine serve a page on BSD, illumos, RISC-V and ARMv5, and the day Exponential gets its own preset. 102 ledger rows; tags `v0.0.4.15` to `v0.0.4.26`.

## Security fixes of the day

Each is a fix with a user-visible consequence; the technical background is in [HTTP/2 and security](../../specifications/6.0/velocity-http2-and-security.md).

- **Symbolic links** (`35cd98e`, `v0.0.4.25`): a link named `*.php` inside the document root made it possible to execute code from anywhere the server user could read. Containment is now checked on the resolved path at all four dispatch points.
- **Request smuggling** (`d625419`): contradictory request framing (two lengths) was resolved instead of refused; bare LF line endings were accepted and held a connection slot until the read timeout.
- **HTTP/2** (`db540e9`, `f4c3a02`, `51e3515`): six frame types the RFC says must be refused were accepted; HTTP/2 served files that HTTP/1.1 refused, including a site configuration file and a `.git` directory, because the blocked list was checked on one path only.
- **Header injection** (`475a46c`): header values could write headers of their own; every response now goes through one serialiser (there had been a guard in one of seven places that wrote headers).
- **Host names** (`b5f73b1`): a host name ending in a newline or a hyphen passed validation on the way to a certificate client, a resolver and the log.
- **Cache** (`34ca6d9`, `v0.0.4.26`): a signed-in visitor's page could be cached and served to everyone, because the session-cookie match required the configured name followed immediately by `=` and the application's cookie carried a digest after the name.

## Reliability and pool fixes

- `43bcb6e`: **persistent workers no longer grow without limit.** Every request left an output buffer behind; on a large application a worker reached 1.1 GB after 600 requests. The fix keeps one capture buffer per process. Related fixes of the same group: error handlers that every request left behind, and a file wrapper that leaked a registration on every filesystem call (`8b3f72c`); the v0.0.4.27 notes in the [changelog](../../changelogs/extensions/exponential-velocity.md) explain each.
- `a9e2fbb`, `2b1dfb6`, `9a4b222`, `4d6e994`: **writes are checked to have gone out whole** on the worker pipe, the session file and WebSocket frames.
- `71e824f`: workers no longer exit after one request because a write handed the socket back non-blocking.
- `e56038f`: a forked worker no longer holds every visitor's connection open by inheriting the parent's descriptor table.
- `449c436`: with `forkPerRequest` on, nobody could log in to the Exponential admin: the compat layer was initialised only for persistent workers and the shutdown callbacks never ran. Both are fixed.
- `32702af`: `php-cgi` mode answered every request with "Class Q_WebServer not found".

## Releases and platforms

`v0.0.4.15` to `v0.0.4.26` are cut during the day. The CHANGELOG file begins here (`35d9a33`), with the rule that a tag is permanent and a release is a deliberate act: a release is published only for a tag that has a section in `CHANGELOG.md`. Tags `v0.0.4.21`, `v0.0.4.22` and `v0.0.4.26` have no release. A platform matrix (`f3e8f50`, `69d8dba`) runs the committed archive on musl, DragonFly, illumos, RISC-V and ARMv5; about thirty rows of the day fix its jobs one at a time (BSD package installs, `sudo`, the Windows toolchain, the macOS test that never started the server, a Visual Studio image that moved). The macOS binary was never broken: the test that condemned it never started the server (`f2e434f`, `15b18d3`).

## Smaller points

- `7d47fa3` adds the parent-side preload hook; `6a88174` fixes a defect found at once: the warm-up compiled the application without the source transform, so every worker inherited a real `exit`.
- `4002cee`: durations printed with thirteen decimals and a deprecation notice logged once per property; both removed.
- `a34150c`, `277e034`, `529e9a4`, `a92d73b`, `0795f46`: the served views carry a footer, the build stamp and the fork's own version.

# Velocity chronicle: August 2026

What changed in Exponential Velocity, the web server engine, in this period, and where to read more. Read it if you run or tune Velocity, or want to know why a setting exists. *Part of the [Exponential Velocity history](README.md). Previous: [July 2026](2026-07.md). Next: [September 2026, first part](2026-09a.md).*

## In short

August turns the proof of concept into something that can be installed and left running. The server gains an **app mode**, a worker model that keeps PHP processes alive between requests (**octane mode** with preforked workers), a logging system, a dashboard with a control panel, Server-Sent Events, and automatic builds of single-file binaries for Linux, macOS and Windows. The month ends with the engine "ready for v1.0.0".

## How the month went

**4 August: `--app` mode.** Two commits with the same 51-file change set (`fd97f5e`, `b757c60`) bring the server to parity with the Qbix PHP web server's feature set and add compressed caching. The ledger shows the identical change set under both hashes, so read them as one change.

**10 to 12 August: octane.** `b2c1f69` implements "octane mode with persistent preforked workers": instead of starting PHP for every request, a parent process loads the application once and forks workers that answer request after request. Between requests each worker is put back into the state it was forked in, so one request never sees another's variables. This is the idea the whole later performance story rests on; its mechanics are in the [worker pool specification](../../specifications/6.0/velocity-worker-pool.md). The days after fixed what the new model broke (issues 6, 7, 10, 12, 13, 14, 15, 16, and `$_SERVER` on the preforked path, `530af5f`).

**11 August: logging and dashboard.** `3cdd7af` adds logging; `54b3933` and `e69d889` rework the dashboard and control panel; `1983cf6` makes WebSockets work with socket.io in all modern browsers (13 files changed). The built-in `index.html` of the server was removed: you make your own (`42947e2`).

**20 August: alignment and clean-up.** The server's methods were made compatible with the Qbix Platform's (`cebc30e`), and 36 files (6,232 lines) of U-language and Node-related code were removed (`ab263eb`), leaving a pure PHP engine.

**24 to 26 August: binaries and CI.** GitHub Actions workflows were added to run the tests and to build static binaries for Linux, macOS and Windows (`293e038`, `1062104`, `3da7992`, `7dcb94e`, `223d920`, `ab326c7`). Server-Sent Events arrived on the 24th (`645db21`). `6fe3bfa` (26 August) is "ready for v1.0.0 release build".

**30 to 31 August: examples.** Two commits add 32 and 50 files of example applications, then `e021010` adds examples of writing more secure applications.

## Smaller points

- `ab263eb` removed code, but nothing a user of the pure PHP server could have relied on; the C file `uwebserver.c` stayed and is described in [uwebserver](../../features/6.0/velocity-uwebserver.md).
- The binary builds of this month were not yet verified on every platform; the corrections come in [September](2026-09c.md).

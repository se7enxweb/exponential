# ezpm (private messages): chronicle

Private messages changed vendor in early 2024 and was made safe for persistent workers in September 2026 (0.10.0). See the [feature page](../../features/6.0/extensions/ezpm.md).

This page lists **every one of the 4 changes** of the repository `ezpm` between 2023-12-24 and 2026-09-22, by month, with what kind of change each is. Read it to find out when a behaviour arrived and which release you need for it. The complete machine-made record, with sizes, is the [change ledger](../ledger/ezpm.md); what each release contains is in the [release notes](../../changelogs/extensions/ezpm.md); how to use the extension is on its [feature page](../../features/6.0/extensions/ezpm.md).

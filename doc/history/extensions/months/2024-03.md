# March 2024: legacy extensions, themes and packages

What changed in March 2024 in the legacy extensions, themes and packages that run on Exponential 6. Read it if your site uses one of them and you want to know what a new release brings. The main repository has its own month page, linked at the end; the [ledger](../../ledger/README.md) lists every change of every repository.

## In short

- 11 changes in 5 legacy extension, theme or package repositories (6 features, 2 fixes, 0 security, 0 releases).
- Busiest: [sevenx_themes_simple](../sevenx_themes_simple.md) (4), [ezwebin-ezpackage](../ezwebin-ezpackage.md) (3), [enhancedselection2](../enhancedselection2.md) (2).
- Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

Small follow-ups: simple theme toolbar styles and JavaScript includes moved into the page head for the online editor, `enhancedselection2` repackaged (2.1.1, 2.1.2) and the ezwebin and ezwebin-clean installer packages updated for release testing.

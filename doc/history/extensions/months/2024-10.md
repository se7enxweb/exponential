# October 2024: legacy extensions, themes and packages

What changed in October 2024 in the legacy extensions, themes and packages that run on Exponential 6. Read it if your site uses one of them and you want to know what a new release brings. The main repository has its own month page, linked at the end; the [ledger](../../ledger/README.md) lists every change of every repository.

## In short

- 8 changes in 3 legacy extension, theme or package repositories (4 features, 0 fixes, 0 security, 0 releases).
- Busiest: [ezprestapi](../ezprestapi.md) (5), [git_manager](../git_manager.md) (2), [nxc_powercontent](../nxc_powercontent.md) (1).
- Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

`ezprestapi` was imported (1.2.0, 29 October) with an example client; `nxc_powercontent` was extended for the REST extension (1.1.0); `git_manager` received its documentation, license, `extension.xml` and Composer support.

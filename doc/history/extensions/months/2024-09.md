# September 2024: legacy extensions, themes and packages

What changed in September 2024 in the legacy extensions, themes and packages that run on Exponential 6. Read it if your site uses one of them and you want to know what a new release brings. The main repository has its own month page, linked at the end; the [ledger](../../ledger/README.md) lists every change of every repository.

## In short

- 9 changes in 2 legacy extension, theme or package repositories (2 features, 1 fix, 0 security, 3 releases).
- Busiest: [sevenx_themes_simple](../sevenx_themes_simple.md) (5), [recaptcha](../recaptcha.md) (4).
- Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

The simple theme moved its extension directory name and reached 1.0.2 with new copyright text; `recaptcha` 1.4.1 and 1.4.2 fixed starting the extension in the class editor from a Composer installation and translated validation messages to English.

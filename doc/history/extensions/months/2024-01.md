# January 2024: legacy extensions, themes and packages

The busiest month of the early period: about 100 changes across the legacy extension repositories. Almost all are packaging: new `composer.json` files, vendors and licenses switched to se7enxweb, version numbers moved on and the funding configuration added, including the first tagged releases (v6.0.0 and v6.0.1 of ezie, eztags, ezwebin, ezdemo, ezodf, ezflow and others). User visible changes: `bcgooglesitemaps` 1.1.6 gained the `ExcludeNodes` setting and a forked cronjob; the `ezwebin` installer package gained SQLite support and a MySQL 8 fix for the blog templates; `sevenx_themes_simple` was imported on 25 January with its favicons, logo and website toolbar styles.

This page covers the repositories of the legacy extensions, themes and packages of the se7enxweb project (the partition of the history that is not the main Exponential repository, the Velocity web server or the platform ecosystem). The month of the main repository is in the root chronicle; the [ledger](../../ledger/README.md) lists every change of every repository.

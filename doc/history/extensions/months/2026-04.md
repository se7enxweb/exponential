# April 2026: legacy extensions, themes and packages

## In short

* 73 changes in 6 legacy extension, theme or package repositories (32 features, 38 fixes, 1 security, 0 releases).
* Busiest: [sevenx-recipes](../sevenx-recipes.md) (65), [sevenx_themes_simple](../sevenx_themes_simple.md) (3), [sevenx_dse](../sevenx_dse.md) (2).
* Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

`sevenx-recipes` carried 65 of the month's changes (the Flex recipes for the platform packages). In the legacy world: `eztags` became portable to SQLite, `ezgmaplocation` handled coordinates under PHP 8.5, `ezwebin` 6.0.2 fixed a path check, and `sevenx_dse` was imported on 21 April; the simple theme gained siteaccess defaults and a copyright update.

This page covers the repositories of the legacy extensions, themes and packages of the se7enxweb project (the partition of the history that is not the main Exponential repository, the Velocity web server or the platform ecosystem). The month of the main repository is in the root chronicle; the [ledger](../../ledger/README.md) lists every change of every repository.

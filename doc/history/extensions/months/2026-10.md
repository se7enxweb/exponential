# October 2026: legacy extensions, themes and packages

Two days of closing work (1 and 2 October): YUI was removed from every extension that still used it (ezjscore 1.5.0, ezwebin, ezdemo, ezflow, ezwt, ezmultiupload, ezautosave, ezstarrating, eztags, cjw_newsletter, the simple theme); the command line scripts, cronjob parts and module views of all legacy extensions became classes the old files call; copyright notices named the Exponential Foundation first; `ezjscore` was synchronised with the kernel; `cjw_newsletter` received a review of its whole code (4.1.15), `git_manager` an Upstream card and `ezupdate` an installed packages view and documentation.

This page covers the repositories of the legacy extensions, themes and packages of the se7enxweb project (the partition of the history that is not the main Exponential repository, the Velocity web server or the platform ecosystem). The month of the main repository is in the root chronicle; the [ledger](../../ledger/README.md) lists every change of every repository.

## Notable changes

### [cjw_newsletter](../cjw_newsletter.md)

- 2026-10-02: Virtual lists run their constructor on PHP 8, their send path and several external filters work (feature)
- 2026-10-02: CSV import and export keep their columns, accept a tab and long lines, and cannot be pointed at other files (feature)
- 2026-10-02: Open send items of a bounced user are stored as aborted, list fetches without a limit work, an edition send with a damaged output reads as empty, a bounce that cannot be parsed is done with (feature)
- 2026-10-02: The admin2 children list's YUI drag and drop, which loaded a script that no longer exists (upgrade note)
- 2026-10-02: The commands and cronjob parts list a description of what they do (feature)
- 2026-10-02: The preview, preview_archive and archive views answer an unknown edition, version or output format with a clean error and return their content as a result with ?Debug=1 (feature)

### [eztags](../eztags.md)

- 2026-10-01: Updated eztags for jQuery 4, with jsTree 3.3.17, so that the tag tree, the tag fields and the admin tag pages work on jQuery 4 without jQuery Migrate warnings. (upgrade note)
- 2026-10-01: The children table of a tag runs on Exponential UI's exp::datatable when expui is active, with $.fn.eZTagsChildrenExp, and keeps its YUI 2 DataTable as the fallback, so that the tags admin needs no YUI for it. (feature)
- 2026-10-01: Fixed: Fixed the tags administration in the admin design, where the dashboard, tag pages, forms, left menu and node tab were blank because eZ Tags ships its admin templates in design/admin2 only, so that it works in every admin design without a design setting. (fix)
- 2026-10-02: YUI from eZ Tags; the children list of a tag runs on Exponential UI alone (upgrade note)
- Smaller changes (10 more): see the [chronicle](../eztags.md#2026-10) and the [ledger](../../ledger/eztags.md#2026-10-14-changes).

# February 2024: legacy extensions, themes and packages

What changed in February 2024 in the legacy extensions, themes and packages that run on Exponential 6. Read it if your site uses one of them and you want to know what a new release brings. The main repository has its own month page, linked at the end; the [ledger](../../ledger/README.md) lists every change of every repository.

## In short

- 23 changes in 2 legacy extension, theme or package repositories (20 features, 0 fixes, 0 security, 0 releases).
- Busiest: [sevenx_themes_simple](../sevenx_themes_simple.md) (22), [xrowextract](../xrowextract.md) (1).
- Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

The simple theme (`sevenx_themes_simple`) took shape: 22 changes for logo placement, a responsive header, billboard banners, template overrides for the default siteaccess, responsive photo galleries and a cart button, plus license documentation and the ezwebin-based installation packages.

# September 2026: legacy extensions, themes and packages

The month the extensions were made ready for production. The sweep: every extension's module views became safe for a persistent PHP worker (22 September), declared their version, license and website (27 September), translated every visible text with German (28 September), named the product Exponential (30 September) and received jQuery 4 compatibility (1 October). On top of that, `xrowextract` was rebuilt (29 September), `ezie` repaired, `git_manager` gained push, remotes and submodules, `ezupdate` became a package manager, `cjw_newsletter` and `eztags` were made portable (Oracle, MongoDB), forgot password pages in `ezwebin`, `ezdemo` and `ezmbpaex` stopped leaking account existence, and the Layouts editor gained a mobile layout, shared-zone locking, a form token and draft-only writes.

This page covers the repositories of the legacy extensions, themes and packages of the se7enxweb project (the partition of the history that is not the main Exponential repository, the Velocity web server or the platform ecosystem). The month of the main repository is in the root chronicle; the [ledger](../../ledger/README.md) lists every change of every repository.

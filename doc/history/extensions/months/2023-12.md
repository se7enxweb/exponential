# December 2023: legacy extensions, themes and packages

The first weeks of the se7enxweb era. The legacy extension repositories were moved to the se7enxweb vendor on Packagist: `composer.json` files switched package names and vendors (`ezie`, `eztags`, `ezdemo`, `ezodf`, `ezwt`, `ezmultiupload`, `ezflow`, `ezautosave`, `ezstarrating`, `ezgmaplocation`, `ezmbpaex`, `ezprestapiprovider`, `ezpm`) and funding files were added. Two changes reached users: a PHP 8.2 bugfix release of `ezflow` and setup wizard fixes in the `ezwebin` installer package (SQLite database support followed in January).

This page covers the repositories of the legacy extensions, themes and packages of the se7enxweb project (the partition of the history that is not the main Exponential repository, the Velocity web server or the platform ecosystem). The month of the main repository is in the root chronicle; the [ledger](../../ledger/README.md) lists every change of every repository.

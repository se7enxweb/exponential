# August 2025: legacy extensions, themes and packages

What changed in August 2025 in the legacy extensions, themes and packages that run on Exponential 6. Read it if your site uses one of them and you want to know what a new release brings. The main repository has its own month page, linked at the end; the [ledger](../../ledger/README.md) lists every change of every repository.

## In short

- 8 changes in 1 legacy extension, theme or package repository (2 features, 0 fixes, 0 security, 0 releases).
- Busiest: [sevenx_themes_simple](../sevenx_themes_simple.md) (8).
- Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

# September 2025: legacy extensions, themes and packages

What changed in September 2025 in the legacy extensions, themes and packages that run on Exponential 6. Read it if your site uses one of them and you want to know what a new release brings. The main repository has its own month page, linked at the end; the [ledger](../../ledger/README.md) lists every change of every repository.

## In short

- 9 changes in 1 legacy extension, theme or package repository (1 feature, 3 fixes, 0 security, 1 release).
- Busiest: [syndication](../syndication.md) (9).
- Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

`syndication` was published by 7x: a PHP 5 extension ported to PHP 8.3 and documented (1.1.0, 13 September), with documentation rewritten and moved to Markdown.

## Notable changes

### [syndication](../syndication.md)

- 2025-09-13: Initial patched import of mostly working extension ported from php5 to php8. Requires some kernel changes atm. Inital Import. (feature)
- 2025-09-13: Bugfixes for php8 support. Bugfixes. (fix)
- 2025-09-13: Mass commit of debug statement removal with appologies to others affected. These changes represent a working upgraded to php8.3 syndication extension that has been tested and proven to once again work as designed with minor issues (feature click specific rot in admin views). Stable Changeset. Bugfixes + Code Standards. (fix)
- 2025-09-13: Bugfix to remove testing die statement. Bugfix. (fix)

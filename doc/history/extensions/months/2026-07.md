# July 2026: legacy extensions, themes and packages

What changed in July 2026 in the legacy extensions, themes and packages that run on Exponential 6. Read it if your site uses one of them and you want to know what a new release brings. The main repository has its own month page, linked at the end; the [ledger](../../ledger/README.md) lists every change of every repository.

## In short

- 39 changes in 12 legacy extension, theme or package repositories (13 features, 10 fixes, 2 security, 5 releases).
- Busiest: [sevenx_themes_simple](../sevenx_themes_simple.md) (9), [sevenx_authentication_2fa](../sevenx_authentication_2fa.md) (6), [explayouts_ui](../explayouts_ui.md) (5).
- Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

New extensions: `sevenx_authentication_2fa` (21 July), `sevenx_valkey_cache` (20 July), `explayouts_ui` and `explayouts_ui_api` (30 July) and the media site data package (3 July). Existing ones: `syndication` 1.2.0 (HTTP authentication of imports), the HTML5 cleanup of `ezwebin`, `ezwt`, `bcwebsitestatistics` and the simple theme (July 18), the simple theme's multi-level menu (July 13) and `nxc_powercontent`'s `class_list` fetch.

- 2026-07-30: Store compiled INI cache in a single Redis hash (performance)

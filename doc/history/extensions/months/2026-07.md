# July 2026: legacy extensions, themes and packages

New extensions: `sevenx_authentication_2fa` (21 July), `sevenx_valkey_cache` (20 July), `explayouts_ui` and `explayouts_ui_api` (30 July) and the media site data package (3 July). Existing ones: `syndication` 1.2.0 (HTTP authentication of imports), the HTML5 cleanup of `ezwebin`, `ezwt`, `bcwebsitestatistics` and the simple theme (July 18), the simple theme's multi-level menu (July 13) and `nxc_powercontent`'s `class_list` fetch.

This page covers the repositories of the legacy extensions, themes and packages of the se7enxweb project (the partition of the history that is not the main Exponential repository, the Velocity web server or the platform ecosystem). The month of the main repository is in the root chronicle; the [ledger](../../ledger/README.md) lists every change of every repository.

# August 2026: legacy extensions, themes and packages

What changed in August 2026 in the legacy extensions, themes and packages that run on Exponential 6. Read it if your site uses one of them and you want to know what a new release brings. The main repository has its own month page, linked at the end; the [ledger](../../ledger/README.md) lists every change of every repository.

## In short

- 65 changes in 7 legacy extension, theme or package repositories (55 features, 3 fixes, 0 security, 0 releases).
- Busiest: [explayouts_ui_api](../explayouts_ui_api.md) (25), [explayouts_ui](../explayouts_ui.md) (24), [xrowmetadata](../xrowmetadata.md) (7).
- Every change is listed in the [ledger](../../ledger/README.md); this page explains the ones that matter.

The Layouts admin and editor grew in a week of daily changes (explayouts_ui 24, explayouts_ui_api 25): mapping rule screens, collections, container blocks, linked zones, a content browser and a query form. `xrowmetadata` gained an Open Graph image (1.3.6, 1.3.7), `exp_enhanced_link` was created (7 August), `ngclasslist` was repackaged, `eztags` gained a SQLite schema and `cjw_newsletter` was made PHP 8.5 clean.

### [explayouts_ui_api](../explayouts_ui_api.md)

- 2026-08-25: support collection type switching, expose rich parameter metadata, and remove manual save button from block form. (feature)
- 2026-08-27: SPA block edit forms and app template for query options (feature)
- 2026-08-27: SPA block content, parameter and query edit templates and admin CSS (feature)
- 2026-08-28: SPA title suffix, create_new_draft HTTP method, cache-bust and add missing MaterialIcons fonts (feature)
- Smaller changes (19 more): see the [chronicle](../explayouts_ui_api.md#2026-08) and the [ledger](../../ledger/explayouts_ui_api.md#2026-08-25-changes).

### [xrowmetadata](../xrowmetadata.md)

- 2026-08-06: Open Graph image support to the xrowmetadata datatype  - Extended xrowMetaData struct with og_image, width, height, alt and type. - xrowMetaDataType now persists og_image in data_text and falls back to class-level data_text5 default. - Added class and object edit templates for selecting the Open Graph image object ID. (feature)
- 2026-08-06: Open Graph image preview and class-level default fallback to v1.3.6 (feature)
- 2026-08-06: Object-relation style GUI for Open Graph image selection in xrowmetadata  - xrowMetaDataType now supports custom HTTP actions for both object and class attributes. - Replaced numeric ID inputs with a browse/remove object relation interface for og_image. - Class-level default and per-object override both use data_int4 / data_t... (feature)
- 2026-08-06: Show no-relation message when no Open Graph image is selected (feature)
- Smaller changes (3 more): see the [chronicle](../xrowmetadata.md#2026-08) and the [ledger](../../ledger/xrowmetadata.md#2026-08-7-changes).

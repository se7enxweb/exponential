# August 2026: legacy extensions, themes and packages

The Layouts admin and editor grew in a week of daily changes (explayouts_ui 24, explayouts_ui_api 25): mapping rule screens, collections, container blocks, linked zones, a content browser and a query form. `xrowmetadata` gained an Open Graph image (1.3.6, 1.3.7), `exp_enhanced_link` was created (7 August), `ngclasslist` was repackaged, `eztags` gained a SQLite schema and `cjw_newsletter` was made PHP 8.5 clean.

This page covers the repositories of the legacy extensions, themes and packages of the se7enxweb project (the partition of the history that is not the main Exponential repository, the Velocity web server or the platform ecosystem). The month of the main repository is in the root chronicle; the [ledger](../../ledger/README.md) lists every change of every repository.

# June 2026, second half (16 to 30 June)

## In short

- 6.0.15 was in development.
- The package installer runs in batches with a transaction per item; INI comments survive saving.
- admin3 gained a resizable sidebar, a custom page size and Hide/Unhide selected.

Release 6.0.15 is in development ([Changelog 6.0.15](../../changelogs/6.0/6.0.15.md)).

## Installer and URL alias hardening

The package installer validates items, uses a transaction per item and installs in batches whose size is set in `package.ini` (`277ec0ae12`, `86911400dd`). URL alias scripts have a help option, mutex handling and an eZScript verification tool (`5c88fb370f`). See [A package installer that survives big packages](../../features/6.0/package-installer-batching.md).

## INI comments survive saving

Writing an INI file through direct access keeps its comments, with regression tests and documentation (`3835910475`, merge `9f927704c5`). See [eZINI preserves comments](../../bc/6.0/eZINI_PRESERVES_COMMENTS.md).

## Admin3 usability

- Hide selected and Unhide selected in the More actions menu (`4002e5e2c7`, merge `348d60028e`): [Hide and unhide selected](../../bc/6.0/SUBITEMS_MENU_MORE_ACTIONS_MENU_EXPANSION_HIDE_UNHIDE.md).
- A left sidebar you can resize, with three presets (`d9ab42abcb`): [Left sidebar width and font size](../../features/6.0/admin3-sidebar-width-and-font-size.md).
- A custom number of items per page for the sub items list (`daaaa74f61`, merge `3beb3f268a`): [Custom items per page](../../features/6.0/custom-items-per-page.md).

## SQLite

The SQLite schema driver can drop indexes (`6b22bd10e7`), which installers need when they rebuild a schema. The release file list was updated (`cd95e06544`).

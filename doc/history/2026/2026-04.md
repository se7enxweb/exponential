# April 2026

- **SQLite in a shared stack.** The `eZSQLite3DB` class is registered in the kernel autoload array and an absolute database path is accepted (`cefe8f13a2`), so a legacy bridge can share one SQLite file with a Symfony application; the database directory is created recursively (`ae5feaf6a7`). See [SQLite database support](../../features/6.0/sqlite-database.md).
- **Session handler on PHP 8.** `read()` returns an empty string for an unknown session, `gc()` uses the current time, and the current siteaccess global is checked before use (`6586f6bacc`, `06c9f9d430`).
- **Release 6.0.13 on 18 April** ([Changelog 6.0.13](../../changelogs/6.0/6.0.13.md)).
- **File list for the upgrade check.** `generatefilelist.sh` creates `share/filelist.md5` (`bd11387b68`, `365c121e7e`, `4e0b21ae2d`); the SQLite schema reader uses the PRAGMA API (`af62dcf3f6`). See [File consistency check](../../features/6.0/file-consistency-check.md).
- **Logo and copyright.** The standard design uses the Exponential logo (`d8fbef61bd`) and the copyright year moved to 2026 (`ab2811ce2c`).

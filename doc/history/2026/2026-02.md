# February 2026

## 6.0.12 on 10 February ([Changelog 6.0.12](../../changelogs/6.0/6.0.12.md))

The RSS feed template `node/view/full` had invalid syntax (`51816a093d`) and, when Exponential runs inside a Symfony based platform stack (the kernel is handed a service container), `ezpKernelWeb` no longer starts a session or registers the shop basket session callbacks for a `GET` request to `/login` (`3bbe53dd29`, `kernel/private/classes/ezpkernelweb.php`). The fix removes a session and redirection problem of the login entry point there; a pure legacy installation is not affected and starts its session as before.

## 21 February: the hardening day

Read the [specification of the hardening](../../specifications/6.0/security-hardening-6.0.13.md), the full [hardening notes](../../bc/6.0/hardening.md) and [PHPUnit 10](../../bc/6.0/phpunitv10.md).

Also: comments in the example `.htaccess_root` use the new product name (`afcfa973ec`).

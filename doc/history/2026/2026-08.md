# August 2026

One hundred and forty-nine changes to the root repository on the 6.0.15 line, no release tag
(v6.0.14 of 7 June is the last). Four things define the month: template debugging that
tells the truth about overrides (5 to 7 August), a clean installation that says Exponential
(15 August), six security patches (16 August), and a test suite that finally runs on every change,
on PHP 8.1 to 8.5 (18 August, 100 of the month's changes). Every change is in the complete record,
[ledger of exponential-root](../ledger/exponential-root.md), under "2026-08".
Changes to the legacy extensions, themes and packages of the month are in
[the extension month page](../extensions/months/2026-08.md).

## 5 to 7 August: see where a page comes from, manage extensions

- **Template path comments show the override source.** The `START` and `STOP` comments of
  `ShowTemplatePathComments` name the template that really ran and, in brackets, the name
  that was asked for (`d2f4e1830d`, `da9ef35eff`, `8b31fd9801`); warnings of the template compiler name
  the template and the line (`08dfef7659`). See [Template path comments](../../features/6.0/template-path-comments.md).
- **Setup > Extensions** sorts A to Z, can sort by name, version and modification time, shows an
  info card and offers `tar.gz`, `zip`, `tar.bz2` and `.ezpkg` downloads (`74bc4ccbd8`); the temporary
  package directory is removed after a download (`104a4b487a`); the package wizard's extension list is
  sorted and annotated (`3d125848e8`). Read [Extension list: sort, inspect and download](../../features/6.0/extension-list-and-downloads.md).
- **Image alias errors say where** (object, attribute, aliases) and no longer end in a fatal error when a file is
  missing (`52277db85f`); **object not found** errors name the id and the caller (`c7a5eac571`).
- **SQLite**: the connection debug messages are useful and appear only with SQL output on (`dfba7274e8`,
  `24c03393db`); the schema generator emits `INTEGER PRIMARY KEY AUTOINCREMENT` without a duplicate
  constraint (`9678728ccc`, 7 August).
- **The installation name** is shown in the title of every non production page through an output filter and two
  template operators, `installation_name` and `is_production_system` (`cbfee1241e`, 7 August).
  See [Installation name](../../features/6.0/installation-name-in-pages.md).
- **Public Exponential Layouts documentation** (`23929a26d4`): [Exponential Layouts](../../bc/6.0/LAYOUTS.md).
- **Content package export is forgiving**: a missing initial language or attribute node is skipped
  (`752adad843`, `8af48c1e59`).
- **Media theme templates** guard false and missing values; the GTM template parses (`c013093b52`). The
  theme was a git submodule whose pointer moved three times (`6073f88af0`, `b425db10fa`, `aea81c5f25`)
  and on 6 August it stopped being one (`a5bd82dfb0`): `extension/sevenx_themes_media` is now an
  ordinary directory of the repository. If you updated an installation by `git pull`, check that the
  directory still has its files.
- The autoload generator stays quiet when it finishes (`62c14b36dd`).

## 15 August: a clean installation that speaks Exponential

- **Seed data** (`share/db_data.dba`) now defaults to `eng-US`, names the root folder `Websites`, titles
  the welcome article `Welcome to Exponential`, and describes Exponential with five verified links
  (`4d9f7681b2`, `3dc808f3ec`, `71045a6cd8`, `e0f6916a36`, `ded9116491`, `5f6edbd111`, `3ebaf8dcd9`). See
  [Clean install defaults](../../features/6.0/clean-install-defaults.md).
- **Kickstart** creates the siteaccesses `site` and `admin` whatever access type you choose
  (`28d414f422`, `67e2abf9a3`); local packages are preferred over downloads.
- **PHP 8 and install blockers** in the datatypes `ezinteger`, `ezobjectrelation`,
  `ezobjectrelationlist`, `ezxmltext`, the URL alias and content class attribute caches (`28d414f422`).
- The installer package URLs of `package.ini` point to the next version (`f9e77f6740`);
  `exp_enhanced_link` is a requirement because the media theme needs it (`ad8639f04b`); the installation
  helper classes are registered and the manifest refreshed (`958c0b7220`).
- **Extension folder case**: the real folder name is returned on case insensitive file systems and the
  case tests are skipped there (`c52c58c533`); a unit test is isolated from the real `DefaultAccess`
  (`e5c0384af8`). See [Extensions in more than one folder](../../features/6.0/additional-extension-directories.md).

## 16 August: security patches and jQuery

- **Six security fixes**: unpredictable REST/OAuth tokens (`fa808e5a39`) and account activation hashes
  (`dec6c49a68`), header injection in the After the Deadline RPC (`233a6d8c35`), shell escaping in the PDF and
  Word text extractors (`4a43d5df33`), a login that fails closed without an `ezuser_setting` row (`b0fdcbb806`),
  https for CDN scripts (`9d36acf523`); the manifest was refreshed (`d889a8abc6`). **Check your accounts**: see
  [Security patches of August 2026](../../specifications/6.0/security-hardening-2026-08.md).
- **jQuery 3.7.1 and jQuery Migrate 3.4.1** replace the vendored jQuery 1.10.2 in ezjscore, and `ezjsc::jquery`
  loads Migrate for every caller (`f7c57376aa`).
- **INI files keep untouched keys** when saved in round trip mode, including bare `Key[]` reset lines (`0a0f4f876b`);
  a duplicate `eZINITest` class was removed (`b801a7516d`).
- The copyright documentation was updated for the next major release (`e3545b27c8`).

## 18 August: the test suite runs on every change

The workflow `.github/workflows/phpunit.yml` ran PHPUnit on PHP 8.1 to 8.5 and, the same day,
database tests on MySQL and PostgreSQL. It was found by running it: 29 pull requests (#66 to #94)
fixed one failure after another (Composer constraints, PHPUnit versions for old PHP, the PHPUnit
shim for the legacy test toolkit, Xdebug configuration, time zone, MongoDB and SQLite extensions,
duplicate class names, deprecated reflection calls, `$backupGlobals`, PHP 8.5 float deprecations).
Almost every change touches only tests or the workflow. One touches the product: `imagedestroy()`,
deprecated in PHP 8.5, is no longer called by the GD image handler (`03b6de43d8`). Read
[Continuous integration and the test suite](../../specifications/6.0/continuous-integration.md).
One README clarification was made the same day (`cd72cd6564`).

# November 2024

What changed in Exponential in November 2024, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- A second pass over admin3 after testing on real devices.
- The sidebar, the menus and the footer were corrected; scrolling no longer hides the sidebars on iOS.
- `ezupdate` was added for testing.

November is the second pass over **admin3** after testing on real devices. See [The responsive admin design](../../features/6.0/admin3-responsive-admin.md).

- **Sidebar.** The default position of the sidebar was corrected (`4a408e672e`, `fac956c026`, `e3c7fad09e`), a modern collapsible sidebar and edit menu were added as template overrides (`d719150b2d`, `06afed1d72`), the responsive script is included by default (`50ca7535a4`) and was renamed to the admin menubar script (`65f2bad9f8`).
- **iOS.** Scrolling down no longer hides the sidebars on iOS browsers (`9f5ae59c19`).
- **Menus.** Popup and sidebar menus have the right stacking order, so every submenu item is clickable (`9fb63105ea`, `306878766a`).
- **Footer.** The legacy copyright text moved to the end of the page and the evaluation message was split up (`b2c89152de`).
- **Distribution.** `ezupdate` was added to the build for testing (`bbf4a020fa`).

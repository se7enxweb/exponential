# January 2024, second half (16 to 31 January)

Version 6.0.1 is cut on 29 January. The theme of the second half is making SQLite robust and widening what Composer installs.

## SQLite settles

The setup wizard got conditional text per SQL backend (`411fbcd8c4`), a default installation flow that prefers MySQL first, with installation data that avoids quote marks that break the SQLite installer (`d76ffac251`), and more fixes to creating the database on first install (`a493e96b0f`, `fa1cabd47c`, `b3e856fe0c`, `72bd907a76`). The driver itself saw "minor improvements" (`deed3f5f0c`). SQLite is documented as not enabled by default: MySQL remains the first choice. See [SQLite database support](../../features/6.0/sqlite-database.md).

## Extensions can replace kernel modules

`eZModule` now searches extension module repositories before the kernel's (`c6b90d723d`), so an extension can ship a module with the same name as a kernel module and have it used. Read [An extension can replace a kernel module](../../features/6.0/extension-module-override.md).

## Setup fixes

A session-management setting that stopped PHP from using its own sessions is no longer created (`80766180fa`), the wizard no longer fails fatally for non eng-GB installations (`b2884debe9`), mysqli connection tests and installation of already downloaded packages were fixed (`23032593af`, `2e40143eec`), and deprecated help links to the former vendor's site were replaced (`474780bd94`).

## The distribution grows

Composer packages were renamed to their final `se7enxweb/<name>` form and added: `ezpaypal`, `ezodf`, `ezautosave`, `ezie`, `ezflow`, `ezdemo` and `ezwebin` as a first-class package; `ezoracle` and `ezauthorize` were suggested (`aee23d5f33`, `6f408858d5`, `9f18aba5f5`, `1a7d76ebdb`, `c5fbb9c27d`, `6268633943`, ...). See [the extension distribution](../../features/6.0/default-extension-distribution.md) and [Changelog 6.0.1](../../changelogs/6.0/6.0.1.md).

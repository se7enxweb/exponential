# March 2024

What changed in Exponential in March 2024, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- The root of the content tree can be viewed.
- ezjscore ships jQuery 3.7.1.
- Three datatype extensions and `xrowmetadata` joined the default distribution.

No release this month; the changes below shipped in 6.0.3 on 2 April.

- **The tree root can be viewed.** `kernel/content/view.php` answered "not found" for every node id below 2. The check is now `< 1`, so node 1, the root of the content tree, can be viewed (`2ff7a4d5b2`). Useful for administrators who want to open the whole tree.
- **jQuery 3.7.1 in ezjscore.** The extension ships jQuery 3.7.1 and the packer setting points to it (`838d1908cc`).
- **Three datatype extensions and one SEO extension.** `enhancedezbinaryfile`, `enhancedselection2` and `birthday` are installed by default and `xrowmetadata` joined the requirements (`6be1b30a6c`, `ec2cfbb53a`, `087b319866`, `3fef68a907`, `c03e126486`); `bcurlaliaswithdash` (lower-case, dashed URL aliases) is suggested (`d32beecb86`). See [the distribution](../../features/6.0/default-extension-distribution.md).

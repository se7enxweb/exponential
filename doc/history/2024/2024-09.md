# September 2024

- **Valkey becomes optional.** `sevenx_valkey` was demoted from a requirement to a suggestion in 6.0.4 (`47b1a9dca9`) so installations without a Redis-compatible server do not fail to install. Install it deliberately: `composer require se7enxweb/sevenx_valkey`.
- **Installation of the 6.0.4 database data** no longer ends in a fatal error (`b81069a495`), and `site.ini` has a kernel-level autoload setting so the installer can create content with datatypes that live in extensions (`210102f739`).
- The version for the next development cycle was set (`7c28653d06`).

# January 2024, first half (1 to 15 January)

## In short

- 6.0.0 became stable on 1 January 2024.
- SQLite arrived on 7 January: a database driver, a schema handler and a ready-made demonstration database.
- Testing a second engine exposed and fixed many unchecked-data bugs; the trash list became sortable.

The first half of January belongs to SQLite. On 7 January alone the kernel gained a database driver and schema handler (`6a2e04a54d`, `5d11b34ef7`), a set of SQLite SQL files and a pre-built demonstration database (`70b815b0d0`), and almost every query in the kernel that assumed MySQL was refactored to run on both engines (`6ad5d5708d`, `2a86e3c354`, `d1aa934a60`, `80532e07df`, `d74e31a30b`` and the rows below). The setup wizard learned to list SQLite as a database choice, to test for the PHP extension and to explain what is missing (`b2f295129c`, `430a12c816`, `7b4703bda9``, `3bb983581a`, `e4d54e58dc`, `e451fcb2e1`). Read the result in [SQLite database support](../../features/6.0/sqlite-database.md) and the [driver specification](../../specifications/6.0/sqlite3-database-driver.md).

## 6.0.0 becomes stable

On 1 January `835ea80c81` changed the version state from beta to stable: **Exponential 6.0.0** is released (see [Changelog 6.0.0](../../changelogs/6.0/6.0.0.md)). `INSTALL` became `INSTALL.md` with instructions for the Composer based installation (`7b358c1a1d`), and the GitHub language override makes the repository show PHP instead of JavaScript (`6310558dcd`). The next versions were set the same week (`3e2e373d33`).

## Fixes that came out of the SQLite testing

Testing on a second database engine found places where the kernel did not check its data: `count()` on values that were not countable (`6f7f898de5`, `378bfc8d5e`, `8964f26dfa`), inconsistent tests of data before use (`d3d3b2e157`, `d374cdd7ae`, `40b13ea95c`) and a function called without a parameter (`c73eed6cb8`). All are PHP 8 fatal errors waiting to happen, so they are fixed once for every engine. See [PHP 8 support](../../bc/6.0/php8.md).

## Upstream changes merged

The trash list with a sortable trashed date came in with upstream pull request #31 (`fa42a6e960`, `75361f4bea`); see [trash](../../bc/6.0/trash.md).

## Packages and documentation

Composer now installs `bcgooglesitemaps` (`d47662a8bd`), `swark`, `owsimpleoperator` and `bcwebsitestatistics`, and `ezmultiupload` was raised to a release with important fixes ([distribution](../../features/6.0/default-extension-distribution.md)). The README was restructured and expanded to teach newcomers what the project is and how to join (`7908cc84e7`), with a new product logo (`72db74b6ea`).

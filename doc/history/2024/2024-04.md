# April 2024

## In short

- 6.0.3 was released on 2 April 2024.
- One fix: `wash` no longer fails on a non-string value in a browse template.

Release 6.0.3 on 2 April ([Changelog 6.0.3](../../changelogs/6.0/6.0.3.md)). A one-line fix in the compiled `wash` operator (the input is cast to a string before `htmlspecialchars`, `914d528a88`) prevented a fatal error in a content browse template used by an extension. The package server URL setting was moved forward for the release (`f812469051`) and the version number for the next development cycle (`f5ad1f879e`).

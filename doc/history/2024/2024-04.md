# April 2024

What changed in Exponential in April 2024, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- 6.0.3 was released on 2 April 2024.
- One fix: `wash` no longer fails on a non-string value in a browse template.

Release 6.0.3 came out on 2 April ([Changelog 6.0.3](../../changelogs/6.0/6.0.3.md)). Its one code change is a one-line fix in the compiled `wash` operator: the input is cast to a string before `htmlspecialchars` (`914d528a88`). It prevents a fatal error in a content browse template used by an extension. The package server URL setting was moved forward for the release (`f812469051`), and the version number for the next development cycle (`f5ad1f879e`).

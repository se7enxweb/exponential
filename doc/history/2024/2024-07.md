# July 2024

## In short

- No change to the main installation in July 2024; the site bundle and the admin interface moved forward upstream.
- Authentication moved to subscribers and the rich text configuration became extensible.

**No change to the main installation; the site bundle and the admin interface moved forward upstream.** The main repository's ledger has no entry for July 2024. The 196 changes of the month belong to the platform repositories the forks carry.

## What changed in the platform ecosystem

- **Site bundle for Nexus sites.** The site bundle received 47 changes: a command to tag content, removal of a default field identifier (NGSTACK-811, 2024-07-23 / 07-24), PHPStan fixes. The Nexus starter followed with the bundle constraint `^3.3` (`a80e0a3e6`, 2024-07-26) and added the Ibexa Scheduled Visibility bundle (`c0852dfb2`, 2024-07-30). See [site bundles](../../features/6.0/platform-site-bundles.md) and [Nexus](../../features/6.0/platform-nexus-starter.md).
- **Authentication moves to subscribers.** The core reworked the repository authentication provider into a dedicated subscriber (`fe4c34ac62`, IBX-8323, 2024-07-09) and refactored the deprecated `loadUserByUsername` method (`da23f87c5f`, 2024-07-23): these changes make login code ready for Symfony 6.
- **Admin interface.** Image editing from the digital asset library (`a3b152e1b`, 2024-07-29), the navigation menu can be closed (`4186da876`, 2024-07-19), Sass deprecation warnings removed from the build after upgrading the sass package (`67f1aa4f9`, 2024-07-22). See [the administration interface](../../features/6.0/platform-admin-ui-fork.md).
- **Rich text.** A configurator interface lets projects post-process the rich text configuration (`1d29e0c`, 2024-07-10) and an option enables attribute types (`5ebad1e`, 2024-07-17).
- **Recipes.** JWT firewall configuration for GraphQL and the editorial bearer in the page builder were reworked for Symfony based authentication (`aa3a512`, `e9befa5`).

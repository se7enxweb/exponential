# October 2024

- **6.0.5 on 1 October** ([Changelog 6.0.5](../../changelogs/6.0/6.0.5.md)). A module of an incomplete extension such as ownerchange no longer causes a fatal error when the page is assembled (`884f21e963`); `ezownerchange` is suggested (`d34de29714`); the package URL moved to 6.0.5 (`d1dc811bd8`).
- **admin3 gets its real responsive layout** on 18 October (`3005038b3a`, `da51ca71d4`): a new menubar script, an edit form and draft form rebuilt for narrow screens, a rebuilt page header and top menu. See [The responsive admin design](../../features/6.0/admin3-responsive-admin.md).
- **OwnerChange** needed changes in the module kernel layer (`9a9ef0c714`); see [Extension modules](../../features/6.0/extension-module-override.md).
- `git_manager` (update a Git based installation) is suggested (`893c186703`).

# August 2024

What changed in Exponential in August 2024, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- August 2024 is the month of admin3, a complete responsive administration design (22 August).
- The debug block became responsive; `recaptcha` and `hcaptcha` joined the distribution.
- 6.0.4 followed on 5 September.

The month of **admin3**. On 22 August a complete, responsive administration design was added (`3352628278`, 81 files): the `admin2` design reworked with collapsible menus and layout that adapts to phones and tablets. A first round of fixes followed within a day for the remembered menu state and how it reaches JavaScript (`1a008400ad`, `fff6613bf1`). See [The responsive admin design](../../features/6.0/admin3-responsive-admin.md).

Around it:

- **Debug output for small screens.** The debug block is responsive (`fd5b0b772e`); see [Debug output improvements](../../features/6.0/debug-output-improvements.md).
- **Content export fixes for `xrowextract`.** The content/browse feature that the export uses no longer washes arrays or converts an array to a string (`c672ed9e8c`, `dc3db11395`); the extension was raised to 2.4.2 (`59d649cc41`).
- **PHP 8.** Dynamic properties of `eZPersistentObject` classes no longer produce warnings in the debug output (`937c314191`, `509cf5091d`). See [PHP 8 support](../../bc/6.0/php8.md).
- **Anti-spam extensions.** `recaptcha` and `hcaptcha` joined the distribution (`f14af0485b`) and `sevenx_valkey` was added at the end of the month (`585c78527d`), moved to a suggestion in September.
- **Docs.** README and INSTALL point to the 6.x installation documentation (`17adaaba8a`).
- **Package URL.** The package server location for the setup wizard moved to 6.0.4 (`6083bf9130`).

Release 6.0.4 follows on 5 September: [Changelog 6.0.4](../../changelogs/6.0/6.0.4.md).

# December 2024

## In short

- 6.0.6 was released on 17 December 2024.
- The /design menu item is back and a default 500 error page was added.
- The online editor works with the new admin design; a PHP 8 notice was fixed.

Release 6.0.6 on 17 December ([Changelog 6.0.6](../../changelogs/6.0/6.0.6.md)).

- **The /design menu item is back** under the new admin menu (`ae8ca998a1`).
- **A default 500 error page.** `design/standard/templates/error/error500.tpl` explains in plain language what visitors can do when the server fails (`f3a1d31c38`).
- **Online editor.** TinyMCE, jQuery and the XML field editor work with the new admin design (`9e83074b69`).
- **PHP 8.** A PHP 8 notice was fixed (`21d2c6b4f5`, in 6.0.6). The `ezmatrix` datatype no longer ends in a fatal error (`f433a08cf9`, 12 December); that commit lives on a branch that reached a release only with 6.0.11 (`git tag --contains f433a08cf9`). See [PHP 8 support](../../bc/6.0/php8.md).
- **Example data.** The MySQL and SQLite example databases carry version 6.0.6 (`9849b43dfa`).
- **Upstream.** Pull request #54 (merged 13 December, `9443fed1d7`) made the data text of a content attribute an empty string instead of `null`; like the line above it first appears in the 6.0.11 changelog.

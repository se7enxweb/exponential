# February 2024

A quiet month with release 6.0.2 on 29 February ([Changelog 6.0.2](../../changelogs/6.0/6.0.2.md)).

- **Shop menu back.** The shop item of the admin menu is no longer hidden (`6095ea4024`).
- **New site description field.** `site.ini` has a site description setting that newer design templates need (`5799206eda`).
- **Telephone links in the online editor.** The link dialog of the `ezoe` online editor lists a telephone link type by default (`a5068500a9`, one line in `extension/ezoe/design/standard/templates/ezoe/customattributes/link.tpl`), so editors can make phone numbers tappable on mobile without raw HTML.
- **More extensions.** `bccie` and `xrowextract` joined the distribution (`bdb630d524`, `2e0067ed11`), see [the distribution](../../features/6.0/default-extension-distribution.md).

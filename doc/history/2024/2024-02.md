# February 2024

A quiet month with release 6.0.2 on 29 February ([Changelog 6.0.2](../../changelogs/6.0/6.0.2.md)).

- **Shop menu back.** The shop item of the admin menu is no longer hidden (`6095ea4024`).
- **New site description field.** `site.ini` has a site description setting that newer design templates need (`5799206eda`).
- **Telephone links in the online editor.** The link dialog of the online editor offers a `tel:` link type out of the box (`a5068500a9`), so editors can make phone numbers tappable on mobile without raw HTML.
- **More extensions.** `bccie` and `xrowextract` joined the distribution (`bdb630d5`, `2e0067ed`), see [the distribution](../../features/6.0/default-extension-distribution.md).

# February 2024

What changed in Exponential in February 2024, why it matters, and where to read more. Read it when you upgrade a site across this period or want to know where a feature came from; the [history guide](../README.md) explains how the month pages, the ledger and the coverage page fit together.

## In short

- 6.0.2 was released on 29 February 2024.
- Small fixes: the shop menu is back, telephone links work in the online editor, a site description setting exists.
- `bccie` and `xrowextract` joined the distribution.

A quiet month that ended with release 6.0.2 on 29 February ([Changelog 6.0.2](../../changelogs/6.0/6.0.2.md)). Four small changes reached users:

- **Shop menu back.** The shop item of the admin menu is no longer hidden (`6095ea4024`).
- **New site description field.** `site.ini` has a site description setting that newer design templates need (`5799206eda`).
- **Telephone links in the online editor.** The link dialog of the `ezoe` online editor lists a telephone link type by default (`a5068500a9`, one line in `extension/ezoe/design/standard/templates/ezoe/customattributes/link.tpl`), so editors can make phone numbers tappable on mobile without raw HTML.
- **More extensions.** `bccie` and `xrowextract` joined the distribution (`bdb630d524`, `2e0067ed11`), see [the distribution](../../features/6.0/default-extension-distribution.md).

# September 2024

Was sich im September 2024 an Exponential geändert hat, warum es wichtig ist und wo Sie mehr lesen. Lesen Sie die Seite, wenn Sie eine Website über diesen Zeitraum hinweg aktualisieren oder wissen wollen, woher eine Funktion stammt; der [Leitfaden zur Geschichte](../README.md) erklärt, wie die Monatsseiten, das Änderungsverzeichnis und die Seite zur Abdeckung zusammenhängen.

## Kurz gesagt

- 6.0.4 wurde am 5. September 2024 veröffentlicht.
- `sevenx_valkey` wurde von einer Abhängigkeit zu einem Vorschlag.
- Die Installation der Datenbankdaten von 6.0.4 endet nicht mehr mit einem fatalen Fehler.

- **Valkey wird optional.** `sevenx_valkey` wurde in 6.0.4 von einer Abhängigkeit zu einem Vorschlag herabgestuft (`47b1a9dca9`), damit die Installation ohne einen mit Redis kompatiblen Server nicht scheitert. Installieren Sie es bewusst: `composer require se7enxweb/sevenx_valkey`.
- **Die Installation der Datenbankdaten von 6.0.4** endet nicht mehr mit einem fatalen Fehler (`b81069a495`), und `site.ini` hat eine Autoload-Einstellung auf Kernel-Ebene, damit der Installer Inhalte mit Datentypen anlegen kann, die in Erweiterungen liegen (`210102f739`).
- Die Version für den nächsten Entwicklungszyklus wurde gesetzt (`7c28653d06`).

# August 2024

Was sich im August 2024 an Exponential geändert hat, warum es wichtig ist und wo Sie mehr lesen. Lesen Sie die Seite, wenn Sie eine Website über diesen Zeitraum hinweg aktualisieren oder wissen wollen, woher eine Funktion stammt; der [Leitfaden zur Geschichte](../README.md) erklärt, wie die Monatsseiten, das Änderungsverzeichnis und die Seite zur Abdeckung zusammenhängen.

## Kurz gesagt

- Der August 2024 ist der Monat von admin3, einem vollständigen responsiven Design für die Administration (22. August).
- Der Debug-Block wurde responsiv; `recaptcha` und `hcaptcha` kamen zur Distribution hinzu.
- 6.0.4 folgte am 5. September.

Der Monat von **admin3**. Am 22. August kam ein vollständiges, responsives Design für die Administration hinzu (`3352628278`, 81 Dateien): das Design `admin2`, überarbeitet mit einklappbaren Menüs und einem Layout, das sich an Telefone und Tablets anpasst. Innerhalb eines Tages folgte eine erste Runde von Korrekturen für den gespeicherten Zustand der Menüs und wie er JavaScript erreicht (`1a008400ad`, `fff6613bf1`). Siehe [Das responsive Admin-Design](../../../eng-us/features/6.0/admin3-responsive-admin.md).

Drumherum:

- **Debug-Ausgabe für kleine Bildschirme.** Der Debug-Block ist responsiv (`fd5b0b772e`); siehe [Verbesserungen der Debug-Ausgabe](../../../eng-us/features/6.0/debug-output-improvements.md).
- **Korrekturen am Export von Inhalten für `xrowextract`.** Die Funktion content/browse, die der Export verwendet, wendet `wash` nicht mehr auf Arrays an und wandelt kein Array mehr in eine Zeichenkette um (`c672ed9e8c`, `dc3db11395`); die Erweiterung wurde auf 2.4.2 angehoben (`59d649cc41`).
- **PHP 8.** Dynamische Eigenschaften von Klassen auf Basis von `eZPersistentObject` erzeugen keine Warnungen mehr in der Debug-Ausgabe (`937c314191`, `509cf5091d`). Siehe [Unterstützung für PHP 8](../../../eng-us/bc/6.0/php8.md).
- **Erweiterungen gegen Spam.** `recaptcha` und `hcaptcha` kamen zur Distribution hinzu (`f14af0485b`), und `sevenx_valkey` wurde am Monatsende aufgenommen (`585c78527d`) und im September zu einem Vorschlag herabgestuft.
- **Dokumentation.** README und INSTALL verweisen auf die Installationsdokumentation von 6.x (`17adaaba8a`).
- **Paket-URL.** Der Ort des Paketservers für den Setup-Assistenten wechselte auf 6.0.4 (`6083bf9130`).

Das Release 6.0.4 folgt am 5. September: [Changelog 6.0.4](../../../changelogs/6.0/6.0.4.md).

## Kleinere Änderungen

Diese Änderungen brauchen keine eigene Geschichte (6 der 19 Änderungen dieses Zeitraums). Die vollständige Aufzeichnung mit Größen und Release-Tags ist das [Änderungsverzeichnis von exponential-root](../aenderungsverzeichnis/exponential-root.md).

- 2024-08-22 `de204f8f1a` (Release): Buchführung zu Version und Release.
- 2024-08-28 `d2bf247ae2` (Dokumentation): Text von README / INSTALL.
- 2024-08-28 `e97f035b65` (Dokumentation): Text von README / INSTALL.
- 3 Merge-Commits, die nur Branches zusammenführen, deren Änderungen in eigenen Zeilen stehen.

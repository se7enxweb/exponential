# April 2024

Was sich im April 2024 an Exponential geändert hat, warum es wichtig ist und wo Sie mehr lesen. Lesen Sie die Seite, wenn Sie eine Website über diesen Zeitraum hinweg aktualisieren oder wissen wollen, woher eine Funktion stammt; der [Leitfaden zur Geschichte](../README.md) erklärt, wie die Monatsseiten, das Änderungsverzeichnis und die Seite zur Abdeckung zusammenhängen.

## Kurz gesagt

- 6.0.3 wurde am 2. April 2024 veröffentlicht.
- Eine Korrektur: `wash` scheitert in einem Browse-Template nicht mehr an einem Wert, der keine Zeichenkette ist.

Das Release 6.0.3 erschien am 2. April ([Changelog 6.0.3](../../../changelogs/6.0/6.0.3.md)). Seine einzige Codeänderung ist eine einzeilige Korrektur im kompilierten Operator `wash`: Die Eingabe wird vor `htmlspecialchars` in eine Zeichenkette umgewandelt (`914d528a88`). Das verhindert einen fatalen Fehler in einem Template zum Durchsuchen von Inhalten, das eine Erweiterung verwendet. Die Einstellung für die URL des Paketservers wurde für das Release weitergestellt (`f812469051`), ebenso die Versionsnummer für den nächsten Entwicklungszyklus (`f5ad1f879e`).

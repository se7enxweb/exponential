# ezmultiupload (Hochladen mehrerer Dateien): Chronik

Das Hochladen mehrerer Dateien wechselte Anfang 2024 den Vendor und zog im Oktober 2026 vom Uploader aus YUI 3 auf `exp::upload` aus Exponential UI um (6.0.5, 6.0.6). Siehe die [Funktionsseite](../../funktionen/6.0/erweiterungen/ezmultiupload.md).

Diese Seite führt **jede der 21 Änderungen** des Repositorys `ezmultiupload` zwischen 2023-12-22 und 2026-10-02 auf, nach Monat, jeweils mit der Art der Änderung. Lesen Sie sie, um herauszufinden, wann ein Verhalten hinzukam und welches Release Sie dafür brauchen. Die vollständige, maschinell erzeugte Aufzeichnung mit Größen ist das [Änderungsverzeichnis](../aenderungsverzeichnis/ezmultiupload.md); was jedes Release enthält, steht in den [Release Notes](../../../changelogs/extensions/ezmultiupload.md); wie Sie die Erweiterung verwenden, steht auf ihrer [Funktionsseite](../../funktionen/6.0/erweiterungen/ezmultiupload.md). Die Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

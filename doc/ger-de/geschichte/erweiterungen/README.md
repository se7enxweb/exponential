# Legacy-Erweiterungen, Themes und Pakete: Geschichte

Die Geschichte der Legacy-Erweiterungen, Themes und Pakete, die auf Exponential 6 laufen, mit einer Chronik je Repository und einer Seite je Monat. Lesen Sie eine Chronik, wenn Ihre Website diese Erweiterung verwendet und Sie wissen wollen, wann ein Verhalten hinzukam oder welches Release Sie brauchen; lesen Sie eine Monatsseite, um zu sehen, was sich an allen zusammen geändert hat. Jede Änderung der 49 Repositorys steht auf ihrer Chronikseite; das [Änderungsverzeichnis](../aenderungsverzeichnis/README.md) ist die vollständige Aufzeichnung.

Wie Sie eine Erweiterung verwenden, steht auf ihrer Funktionsseite, was jedes Release enthält, in ihren Release Notes; beide sind in der Tabelle verlinkt.

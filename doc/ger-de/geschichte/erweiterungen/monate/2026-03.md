# März 2026: Legacy-Erweiterungen, Themes und Pakete

Was sich im März 2026 an den Legacy-Erweiterungen, Themes und Paketen geändert hat, die auf Exponential 6 laufen. Lesen Sie die Seite, wenn Ihre Website eine davon verwendet und Sie wissen wollen, was ein neues Release bringt. Das Haupt-Repository hat eine eigene Monatsseite, die am Ende verlinkt ist; das [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md) führt jede Änderung jedes Repositorys auf. Die zitierten Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Kurz gesagt

- 49 Änderungen in 41 Repositorys von Legacy-Erweiterungen, Themes oder Paketen (6 Funktionen, 1 Fehlerbehebung, 0 Sicherheit, 0 Releases).

# Februar 2024: Legacy-Erweiterungen, Themes und Pakete

Was sich im Februar 2024 an den Legacy-Erweiterungen, Themes und Paketen geändert hat, die auf Exponential 6 laufen. Lesen Sie die Seite, wenn Ihre Website eine davon verwendet und Sie wissen wollen, was ein neues Release bringt. Das Haupt-Repository hat eine eigene Monatsseite, die am Ende verlinkt ist; das [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md) führt jede Änderung jedes Repositorys auf. Die zitierten Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Kurz gesagt

- 23 Änderungen in 2 Repositorys von Legacy-Erweiterungen, Themes oder Paketen (20 Funktionen, 0 Fehlerbehebungen, 0 Sicherheit, 0 Releases).
- Am aktivsten: [sevenx_themes_simple](../sevenx_themes_simple.md) (22), [xrowextract](../xrowextract.md) (1).
- Jede Änderung steht im [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md); diese Seite erklärt die wichtigen.

Das Simple-Theme (`sevenx_themes_simple`) nahm Gestalt an: 22 Änderungen für die Platzierung des Logos, einen responsiven Kopfbereich, Billboard-Banner, Template-Overrides für den Standard-Siteaccess, responsive Fotogalerien und eine Warenkorb-Schaltfläche, dazu Lizenzdokumentation und die auf ezwebin beruhenden Installationspakete.

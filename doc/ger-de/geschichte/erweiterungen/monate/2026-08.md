# August 2026: Legacy-Erweiterungen, Themes und Pakete

Was sich im August 2026 an den Legacy-Erweiterungen, Themes und Paketen geändert hat, die auf Exponential 6 laufen. Lesen Sie die Seite, wenn Ihre Website eine davon verwendet und Sie wissen wollen, was ein neues Release bringt. Das Haupt-Repository hat eine eigene Monatsseite, die am Ende verlinkt ist; das [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md) führt jede Änderung jedes Repositorys auf. Die zitierten Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Kurz gesagt

- 65 Änderungen in 7 Repositorys von Legacy-Erweiterungen, Themes oder Paketen (55 Funktionen, 3 Fehlerbehebungen, 0 Sicherheit, 0 Releases).
- Am aktivsten: [explayouts_ui_api](../explayouts_ui_api.md) (25), [explayouts_ui](../explayouts_ui.md) (24), [xrowmetadata](../xrowmetadata.md) (7).
- Jede Änderung steht im [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md); diese Seite erklärt die wichtigen.

Die Layouts-Administration und der Editor wuchsen in einer Woche mit täglichen Änderungen (explayouts_ui 24, explayouts_ui_api 25): Seiten für Zuordnungsregeln, Collections, Container-Blöcke, verknüpfte Zonen, ein Inhaltsbrowser und ein Abfrageformular. `xrowmetadata` erhielt ein Open-Graph-Bild (1.3.6, 1.3.7), `exp_enhanced_link` entstand (7. August), `ngclasslist` wurde neu paketiert, `eztags` erhielt ein SQLite-Schema, und `cjw_newsletter` lief nun sauber unter PHP 8.5.

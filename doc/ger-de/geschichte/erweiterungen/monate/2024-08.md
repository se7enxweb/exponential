# August 2024: Legacy-Erweiterungen, Themes und Pakete

Was sich im August 2024 an den Legacy-Erweiterungen, Themes und Paketen geändert hat, die auf Exponential 6 laufen. Lesen Sie die Seite, wenn Ihre Website eine davon verwendet und Sie wissen wollen, was ein neues Release bringt. Das Haupt-Repository hat eine eigene Monatsseite, die am Ende verlinkt ist; das [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md) führt jede Änderung jedes Repositorys auf. Die zitierten Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Kurz gesagt

- 20 Änderungen in 3 Repositorys von Legacy-Erweiterungen, Themes oder Paketen (9 Funktionen, 2 Fehlerbehebungen, 0 Sicherheit, 0 Releases).
- Am aktivsten: [hcaptcha](../hcaptcha.md) (10), [recaptcha](../recaptcha.md) (8), [xrowextract](../xrowextract.md) (2).
- Jede Änderung steht im [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md); diese Seite erklärt die wichtigen.

CAPTCHA kommt. `recaptcha` wurde für reCAPTCHA v2, PHP 8 und die Änderungen an den Datentypen von eZ 5 überarbeitet (mit dem Paket `google/recaptcha` und einem JavaScript-Template für v3), und daraus entstand `hcaptcha` für hCaptcha (Release 1.0, 11. August). `xrowextract` 2.4.2 räumte nach der Aufnahme in die Standard-Distribution auf.

## Wichtige Änderungen

### [hcaptcha](../hcaptcha.md)

- 2024-08-06: Refactored extension for latest v2 captcha support and PHP8 and eZ 5 Datatype Changes and Google Recaptcha Autoloads Names Space Usage. Works with eZ 6.x (Funktion)
- 2024-08-06: Added recaptcha v3 Pure JS feedback_form template override to extension standard design offering (Funktion)
- 2024-08-06: Refactor to use ini for siteKey data storage (Funktion)
- 2024-08-11: Mass update of internals to support hcaptcha apis. Tested as working with Exponential 6 (Funktion)
- Kleinere Änderungen (6 weitere): siehe die [Chronik](../hcaptcha.md#2024-08) und das [Änderungsverzeichnis](../../aenderungsverzeichnis/hcaptcha.md#2024-08-10-änderungen).

### [recaptcha](../recaptcha.md)

- 2024-08-06: Refactored extension for latest v2 captcha support and PHP8 and eZ 5 Datatype Changes and Google Recaptcha Autoloads Names Space Usage. Works with eZ 6.x (Funktion)
- 2024-08-06: Added recaptcha v3 Pure JS feedback_form template override to extension standard design offering (Funktion)
- 2024-08-06: Refactor to use ini for siteKey data storage (Funktion)
- 2024-08-06: Refactor composer support to require google/recaptcha composer package (Funktion)
- Kleinere Änderungen (4 weitere): siehe die [Chronik](../recaptcha.md#2024-08) und das [Änderungsverzeichnis](../../aenderungsverzeichnis/recaptcha.md#2024-08-8-änderungen).

### [xrowextract](../xrowextract.md)

- 2024-08-22: PHP 8 Bugfix for ezmatrix dayatype (Fehlerbehebung)
- 2024-08-22: Bugfixes post integration into default Exponential 6 distribution to clean up main csv module code formating and export error in fetching code (Fehlerbehebung)

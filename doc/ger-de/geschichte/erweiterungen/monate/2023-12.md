# Dezember 2023: Legacy-Erweiterungen, Themes und Pakete

Was sich im Dezember 2023 an den Legacy-Erweiterungen, Themes und Paketen geändert hat, die auf Exponential 6 laufen. Lesen Sie die Seite, wenn Ihre Website eine davon verwendet und Sie wissen wollen, was ein neues Release bringt. Das Haupt-Repository hat eine eigene Monatsseite, die am Ende verlinkt ist; das [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md) führt jede Änderung jedes Repositorys auf. Die zitierten Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Kurz gesagt

- 33 Änderungen in 18 Repositorys von Legacy-Erweiterungen, Themes oder Paketen (1 Funktion, 1 Fehlerbehebung, 0 Sicherheit, 0 Releases).
- Am aktivsten: [ezflow](../ezflow.md) (3), [ezautosave](../ezautosave.md) (2), [ezdemo](../ezdemo.md) (2).
- Jede Änderung steht im [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md); diese Seite erklärt die wichtigen.

Die ersten Wochen der se7enxweb-Ära. Die Repositorys der Legacy-Erweiterungen zogen auf Packagist zum Vendor se7enxweb um: Die `composer.json`-Dateien wechselten Paketnamen und Vendor (`ezie`, `eztags`, `ezdemo`, `ezodf`, `ezwt`, `ezmultiupload`, `ezflow`, `ezautosave`, `ezstarrating`, `ezgmaplocation`, `ezmbpaex`, `ezprestapiprovider`, `ezpm`), und Finanzierungsdateien kamen hinzu. Zwei Änderungen erreichten die Anwender: ein Release von `ezflow` mit einer Fehlerbehebung für PHP 8.2 und Korrekturen für den Setup-Assistenten im Installer-Paket von `ezwebin` (die Unterstützung für SQLite-Datenbanken folgte im Januar).

# Oktober 2024: Legacy-Erweiterungen, Themes und Pakete

Was sich im Oktober 2024 an den Legacy-Erweiterungen, Themes und Paketen geändert hat, die auf Exponential 6 laufen. Lesen Sie die Seite, wenn Ihre Website eine davon verwendet und Sie wissen wollen, was ein neues Release bringt. Das Haupt-Repository hat eine eigene Monatsseite, die am Ende verlinkt ist; das [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md) führt jede Änderung jedes Repositorys auf. Die zitierten Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Kurz gesagt

- 8 Änderungen in 3 Repositorys von Legacy-Erweiterungen, Themes oder Paketen (4 Funktionen, 0 Fehlerbehebungen, 0 Sicherheit, 0 Releases).
- Am aktivsten: [ezprestapi](../ezprestapi.md) (5), [git_manager](../git_manager.md) (2), [nxc_powercontent](../nxc_powercontent.md) (1).
- Jede Änderung steht im [Änderungsverzeichnis](../../aenderungsverzeichnis/README.md); diese Seite erklärt die wichtigen.

`ezprestapi` wurde mit einem Beispiel-Client importiert (1.2.0, 29. Oktober); `nxc_powercontent` wurde für die REST-Erweiterung erweitert (1.1.0); `git_manager` erhielt seine Dokumentation, Lizenz, `extension.xml` und Unterstützung für Composer.

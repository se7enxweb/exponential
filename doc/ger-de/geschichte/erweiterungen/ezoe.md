# ezoe (Repository des Online-Editors): Chronik

Das Repository des Online-Editors erhielt nur Metadaten zur Finanzierung; sein Code liegt im Kernel von Exponential. Siehe die [Funktionsseite](../../../eng-us/features/6.0/extensions/ezoe.md) und [TinyMCE 8](../../../eng-us/bc/6.0/ezoe-tinymce8.md).

Diese Seite führt **jede der 2 Änderungen** des Repositorys `ezoe` zwischen 2024-01-28 und 2026-03-02 auf, nach Monat, jeweils mit der Art der Änderung. Lesen Sie sie, um herauszufinden, wann ein Verhalten hinzukam und welches Release Sie dafür brauchen. Die vollständige, maschinell erzeugte Aufzeichnung mit Größen ist das [Änderungsverzeichnis](../aenderungsverzeichnis/ezoe.md); was jedes Release enthält, steht in den [Release Notes](../../../changelogs/extensions/ezoe.md); wie Sie die Erweiterung verwenden, steht auf ihrer [Funktionsseite](../../../eng-us/features/6.0/extensions/ezoe.md). Die Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

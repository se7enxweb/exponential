# Dezember 2025

Was sich im Dezember 2025 an Exponential geändert hat, warum es wichtig ist und wo Sie mehr lesen. Lesen Sie die Seite, wenn Sie eine Website über diesen Zeitraum hinweg aktualisieren oder wissen wollen, woher eine Funktion stammt; der [Leitfaden zur Geschichte](../README.md) erklärt, wie die Monatsseiten, das Änderungsverzeichnis und die Seite zur Abdeckung zusammenhängen.

## Kurz gesagt

- PHP 8.5 wird unterstützt: Zwei Klassen erhielten die Nullable-Typen, die es verlangt, und die Zeta Components wurden angehoben.
- 6.0.11 wurde am 30. Dezember 2025 getaggt.

**PHP 8.5 wird unterstützt.** Zwei Klassen erhielten die Nullable-Typen, die PHP 8.5 verlangt (`ea660c8371`, `0d035b6723`). Die Zeta Components wurden auf Releases angehoben, die PHP 8.5 unterstützen (`4db16d95c3`). Die README sagt, dass PHP 8.5 unterstützt wird (`27ed271f3d`), und dieser Commit ist das Tag 6.0.11 vom 30. Dezember ([Changelog 6.0.11](../../../changelogs/6.0/6.0.11.md)). Support-Links in der README, die mit der Umbenennung kaputtgegangen waren, wurden repariert (`8febb1e2b3`). Einzelheiten: [Unterstützung für PHP 8](../../../eng-us/bc/6.0/php8.md).

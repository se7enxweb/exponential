# April 2026

Was sich im April 2026 an Exponential geändert hat, warum es wichtig ist und wo Sie mehr lesen. Lesen Sie die Seite, wenn Sie eine Website über diesen Zeitraum hinweg aktualisieren oder wissen wollen, woher eine Funktion stammt; der [Leitfaden zur Geschichte](../README.md) erklärt, wie die Monatsseiten, das Änderungsverzeichnis und die Seite zur Abdeckung zusammenhängen.

## Kurz gesagt

- 6.0.13 wurde am 18. April 2026 veröffentlicht.
- `eZSQLite3DB` kann eine SQLite-Datei mit einer Symfony-Anwendung teilen.
- Die Dateiliste des Releases für die Upgrade-Prüfung wird von einem Script erzeugt; das Standard-Design verwendet das Logo von Exponential.

- **SQLite in einem gemeinsamen Stack.** Die Klasse `eZSQLite3DB` ist im Autoload-Array des Kernels registriert, und ein absoluter Datenbankpfad wird angenommen (`cefe8f13a2`), sodass eine Legacy Bridge eine SQLite-Datei mit einer Symfony-Anwendung teilen kann; das Datenbankverzeichnis wird rekursiv angelegt (`ae5feaf6a7`). Siehe [Unterstützung für SQLite-Datenbanken](../../../eng-us/features/6.0/sqlite-database.md).
- **Session-Handler unter PHP 8.** `read()` gibt für eine unbekannte Sitzung eine leere Zeichenkette zurück, `gc()` verwendet die aktuelle Zeit, und die globale Variable des aktuellen Siteaccess wird vor der Verwendung geprüft (`6586f6bacc`, `06c9f9d430`).
- **Release 6.0.13 am 18. April** ([Changelog 6.0.13](../../../changelogs/6.0/6.0.13.md)).
- **Dateiliste für die Upgrade-Prüfung.** `generatefilelist.sh` erzeugt `share/filelist.md5` (`bd11387b68`, `365c121e7e`, `4e0b21ae2d`); der Schema-Leser für SQLite verwendet die PRAGMA-API (`af62dcf3f6`). Siehe [Prüfung der Dateikonsistenz](../../../eng-us/features/6.0/file-consistency-check.md).
- **Logo und Copyright.** Das Standard-Design verwendet das Logo von Exponential (`d8fbef61bd`), und das Copyright-Jahr wechselte auf 2026 (`ab2811ce2c`).

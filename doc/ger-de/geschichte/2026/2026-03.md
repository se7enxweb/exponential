# März 2026

Was sich im März 2026 an Exponential geändert hat, warum es wichtig ist und wo Sie mehr lesen. Lesen Sie die Seite, wenn Sie eine Website über diesen Zeitraum hinweg aktualisieren oder wissen wollen, woher eine Funktion stammt; der [Leitfaden zur Geschichte](../README.md) erklärt, wie die Monatsseiten, das Änderungsverzeichnis und die Seite zur Abdeckung zusammenhängen.

## Kurz gesagt

- Die Test-Werkzeugkette zog auf PHPUnit 13 um.
- Sechzig String-Funktionen von PHP lassen sich als Template-Operatoren verwenden.
- Ein fataler Fehler in der API des Curl-Clients wurde behoben.

- **PHPUnit 13.** Die Test-Werkzeugkette zog auf PHPUnit 13 um (`daea5d5556`), nach einer Versionsanhebung, die eine Sicherheitswarnung von Composer vermeidet, welche Installationen blockierte (`90645c554d`). Siehe [PHPUnit 13](../../../eng-us/bc/6.0/phpunitv13.md).
- **String-Funktionen in Templates.** `ristring`, `rstring` und sechzig String-Funktionen von PHP lassen sich als Template-Operatoren verwenden (`4220e2ff90`). Siehe [String-Funktionen von PHP als Template-Operatoren](../../../eng-us/features/6.0/string-template-operators.md).
- **Client-API.** Ein fataler Fehler in der API für Client-Aufrufe mit Curl wurde behoben (`0b7ccae3bc`).
- **README:** Die Links zum Issue-Tracker und die Beschreibung der Plattform-Distributionen wurden überarbeitet (`3ed912ca05`, `0a36dcd274`, `7d3a175fa0`, `a162069c88`, `3e7dee15a4`).

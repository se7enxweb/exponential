# ezplatform-cron: Geschichte des Plattform-Repositorys

Die Geschichte von `ezplatform-cron`, einem der Plattform-Repositorys rund um Exponential (Gruppe: Suche, Cache und API). Lesen Sie sie, um zu erfahren, was das Repository Ihnen bietet, wie es mit Exponential zusammenhängt und wann es sich geändert hat. Das Änderungsverzeichnis enthält 1 Änderung von 2026-04-12 bis 2026-04-12, alle vom se7enxweb-Team. Die Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Was es ist

Einfaches Cron-Bundle.

## Wie es mit Exponential zusammenhängt

Am 2026-04-12 geforkt, mit einem Replace-Shim.

## Was Anwender davon haben

Geplante Jobs auf der Plattform.

Installieren Sie es mit Composer (ein Projekt, das die Plattform bereits verlangt, holt es von selbst):

```bash
composer require se7enxweb/ezplatform-cron
```

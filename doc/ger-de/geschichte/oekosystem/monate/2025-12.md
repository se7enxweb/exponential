# Plattform-Ökosystem: Dezember 2025

Was sich im Dezember 2025 in den Plattform-Repositorys rund um Exponential geändert hat: der Symfony-basierte Kernel und die Administrationsoberfläche, Layouts, Starter, Bridges und Framework-Forks. Lesen Sie die Seite, wenn Sie die Plattform neben Exponential betreiben oder wissen wollen, was ein Fork mitbringt, bevor Sie ihn aktualisieren. Die [Übersicht des Ökosystems](../../../../eng-us/history/ecosystem.md) erklärt, wie die Repositorys zusammenhängen. Die zitierten Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Kurz gesagt

- 321 Änderungen in 13 Plattform-Repositorys in diesem Monat: 94 neue oder verbesserte Funktionen, 38 Fehlerbehebungen, 1 Verhaltensänderung.
- Aktivste Repositorys: layouts-core (197), admin-ui-7x (33), admin-ui-ibexa (33).
- 5 der Änderungen sind Arbeit von se7enxweb mit einem für Anwender sichtbaren Thema; der Rest ist Upstream-Geschichte, die die Forks mitführen.
- Die Tabelle unten zählt jedes Repository; die Listen danach nennen die größten Änderungen.

## Upstream-Aktivität in den Forks

- **layouts-core**: 197 Upstream-Änderungen. Größte: `02befe412` Switch uuids to Symfony Uid component; `1dfede980` Switch mocks to stubs in tests; `49239ef1e` Update PHPDoc for data providers
- **admin-ui-7x**: 33 Upstream-Änderungen. Größte: `afd71af83` IBX-9266: Added REST endpoint loading available site accesses for location (#1759); `abb1d869f` IBX-11029: Fixed tests (#1790); `4e059bbac` IBX-10302: Add "Suggest Taxonomy Entries" Action Type (UI) (#1673)
- **core**: 20 Upstream-Änderungen. Größte: `c6385a697` Defined TParent of Symfony semantic configuration builders; `6e92721b7` IBX-9846: Added search using embeddings (#536); `8732ba9e5` IBX-10841: Fixed sorting in content filtering (#655)

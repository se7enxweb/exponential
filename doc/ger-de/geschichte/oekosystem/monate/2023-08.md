# Plattform-Ökosystem: August 2023

Was sich im August 2023 in den Plattform-Repositorys rund um Exponential geändert hat: der Symfony-basierte Kernel und die Administrationsoberfläche, Layouts, Starter, Bridges und Framework-Forks. Lesen Sie die Seite, wenn Sie die Plattform neben Exponential betreiben oder wissen wollen, was ein Fork mitbringt, bevor Sie ihn aktualisieren. Die [Übersicht des Ökosystems](../../oekosystem.md) erklärt, wie die Repositorys zusammenhängen. Die zitierten Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

- 13 Änderungen in 2 Plattform-Repositorys in diesem Monat: 11 neue oder verbesserte Funktionen, 0 Fehlerbehebungen, 0 Verhaltensänderungen.

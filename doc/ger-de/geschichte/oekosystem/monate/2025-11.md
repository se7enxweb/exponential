# Plattform-Ökosystem: November 2025

Was sich im November 2025 in den Plattform-Repositorys rund um Exponential geändert hat: der Symfony-basierte Kernel und die Administrationsoberfläche, Layouts, Starter, Bridges und Framework-Forks. Lesen Sie die Seite, wenn Sie die Plattform neben Exponential betreiben oder wissen wollen, was ein Fork mitbringt, bevor Sie ihn aktualisieren. Die [Übersicht des Ökosystems](../../oekosystem.md) erklärt, wie die Repositorys zusammenhängen. Die zitierten Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Kurz gesagt

- 303 Änderungen in 9 Plattform-Repositorys in diesem Monat: 99 neue oder verbesserte Funktionen, 45 Fehlerbehebungen, 6 Verhaltensänderungen.
- Aktivste Repositorys: layouts-core (165), admin-ui-7x (48), admin-ui-ibexa (48).
- Keine der Änderungen ist Arbeit von se7enxweb mit einem für Anwender sichtbaren Thema; alle sind Upstream-Geschichte, die die Forks mitführen.
- Die Tabelle unten zählt jedes Repository; die Listen danach nennen die größten Änderungen.

## Upstream-Aktivität in den Forks

- **layouts-core**: 165 Upstream-Änderungen. Größte: `501549e21` Replace PHPUnit annotations with attributes; `e88254df7` Update core API values to use property hooks; `3b06316da` Remove deprecations across the board: symfony, doctrine and so on
- **admin-ui-7x**: 48 Upstream-Änderungen. Größte: `1117cc03e` [CI] Fixed missing closure return types (#1780); `f0b0128ac` IBX-10936: Implemented fetching field definitions from an expression (#1765); `24ae75028` IBX-9667: Updated emails template (#1494)
- **adminneo**: 16 Upstream-Änderungen. Größte: `0452ffe0` Update German and Dutch translations; `be024126` Use input type 'text' instead of 'search' in selection filter; `aa533b94` PostgreSQL: Connect to localhost with default port if server is not specified
- **core**: 10 Upstream-Änderungen. Größte: `fb60a60d6` IBX-10936: Made `ProxyDomainMapperFactory` lazy (#676); `9de4817ac` IBX-10627: Fixed transformation ForbiddenException to AccessDeniedHttpException (#673); `d1bfbf7bb` IBX-10937: Add the `ContentTypeGroupName` criterion for `findContentTypes` PAPI 
- **fieldtype-richtext-ibexa**: 10 Upstream-Änderungen. Größte: `b58bebc` IBX-9657: Added option to set shouldFireInputEvent in updateInput via attribute to prevent error message removal (#274); `5c5d806` IBX-10725: Fixed image filter dropdown on first selection (#271); `a754775` [PHPStan] Regenerated baseline after PHPStan release (#275)
- **exponential-platform-nexus-starter**: 3 Upstream-Änderungen. Größte: `94a83b9d0` NGSTACK-1014 Set up global stylesheet, refactor typography and header styles; `0100ced58` NGSTACK-1013 Add collapse nav breakpoint variable

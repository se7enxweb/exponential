# Plattform-Ökosystem: September 2024

Was sich im September 2024 in den Plattform-Repositorys rund um Exponential geändert hat: der Symfony-basierte Kernel und die Administrationsoberfläche, Layouts, Starter, Bridges und Framework-Forks. Lesen Sie die Seite, wenn Sie die Plattform neben Exponential betreiben oder wissen wollen, was ein Fork mitbringt, bevor Sie ihn aktualisieren. Die [Übersicht des Ökosystems](../../oekosystem.md) erklärt, wie die Repositorys zusammenhängen. Die zitierten Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Kurz gesagt

- 162 Änderungen in 13 Plattform-Repositorys in diesem Monat: 47 neue oder verbesserte Funktionen, 21 Fehlerbehebungen, 4 Verhaltensänderungen.
- Aktivste Repositorys: admin-ui-7x (35), admin-ui-ibexa (35), adminneo (30).
- 4 der Änderungen sind Arbeit von se7enxweb mit einem für Anwender sichtbaren Thema; der Rest ist Upstream-Geschichte, die die Forks mitführen.
- Die Tabelle unten zählt jedes Repository; die Listen danach nennen die größten Änderungen.

## Upstream-Aktivität in den Forks

- **admin-ui-7x**: 35 Upstream-Änderungen. Größte: `e3594d019` Extracted menu builder from ProductCatalog package (#1344); `d01569c0a` IBX-8626: Create action menu component foundations (#1318); `2dc387b91` IBX-8722: Added Bookmarsk to Image Picker (#1323)
- **adminneo**: 30 Upstream-Änderungen. Größte: `0f2e0473` Show partitioning info in table structure page; `c4ed9500` Add support for translations in plugins; `48cf2a0f` Bump min PHP version to 7.1, remove warning suppression
- **site-bundle**: 16 Upstream-Änderungen. Größte: `a4b2381` Restore compatibility with Twig 3.11; `c68a928` Compatibility with Twig 3.13; `b945c84` Fix PHPStan errors
- **core**: 10 Upstream-Änderungen. Größte: `0ba8cd18d` IBX-8726: Added IsBookmarked criterion (#417); `81784d04d` change to account credential handling (wording omitted; see the ledger line); `05a3bd15d` Added basic Pool implementation (#428)

# ezplatform-alloyeditor-element-width: Geschichte des Plattform-Repositorys

Die Geschichte von `ezplatform-alloyeditor-element-width`, einem der Plattform-Repositorys rund um Exponential (Gruppe: Administrationsoberfläche). Lesen Sie sie, um zu erfahren, was das Repository Ihnen bietet, wie es mit Exponential zusammenhängt und wann es sich geändert hat. Das Änderungsverzeichnis enthält 1 Änderung von 2026-04-12 bis 2026-04-12, alle vom se7enxweb-Team. Die Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Was es ist

Bundle, das dem Online-Editor das Bearbeiten der Elementbreite hinzufügt.

## Wie es mit Exponential zusammenhängt

Am 2026-04-12 geforkt, mit Abhängigkeiten von se7enxweb und einem Replace-Shim.

## Was Anwender davon haben

Redakteure können die Breite von Elementen im Rich Text festlegen.

Installieren Sie es mit Composer (ein Projekt, das die Plattform bereits verlangt, holt es von selbst):

```bash
composer require se7enxweb/ezplatform-alloyeditor-element-width
```

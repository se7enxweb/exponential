# ibexa-xmltext-fieldtype: Geschichte des Plattform-Repositorys

Die Geschichte von `ibexa-xmltext-fieldtype`, einem der Plattform-Repositorys rund um Exponential (Gruppe: Feldtypen). Lesen Sie sie, um zu erfahren, was das Repository Ihnen bietet, wie es mit Exponential zusammenhängt und wann es sich geändert hat. Das Änderungsverzeichnis enthält 1 Änderung von 2026-03-02 bis 2026-03-02, alle vom se7enxweb-Team. Die Commit-Nachrichten stehen so, wie sie im Repository festgehalten sind, also meist auf Englisch.

## Was es ist

Feldtyp XmlText für Ibexa OSS.

## Wie es mit Exponential zusammenhängt

Gegenstück zu ezplatform-xmltext-fieldtype für Platform v4/v5.

## Was Anwender davon haben

XML-Textinhalte sind auf Platform v4/v5 lesbar.

Installieren Sie es mit Composer (ein Projekt, das die Plattform bereits verlangt, holt es von selbst):

```bash
composer require se7enxweb/ibexa-xmltext-fieldtype
```

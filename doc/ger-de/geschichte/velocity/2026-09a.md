# Velocity-Chronik: September 2026, 7. bis 21. September

Was sich in diesem Zeitraum an Exponential Velocity, der Webserver-Engine, geändert hat und wo Sie mehr lesen. Lesen Sie die Seite, wenn Sie Velocity betreiben oder abstimmen oder wissen wollen, warum es eine Einstellung gibt. *Teil der [Geschichte von Exponential Velocity](README.md). Vorher: [August 2026](2026-08.md). Danach: [22. September](2026-09b.md).*

## Kurz gesagt

Die ersten drei Septemberwochen führen die Engine von „einem schnellen Server für neue PHP-Anwendungen“ zu „einem Server, der bestehende PHP-Anwendungen unverändert ausführt“. Eine Kompatibilitätsschicht (`243d1ba`) lässt Code von Laravel, Symfony, WordPress, Drupal, Joomla und Ähnlichem auf dauerhaft laufenden Workern laufen; am 17. wird eine gemessene Beschleunigung bestehenden Codes um etwa das Zwölffache gegenüber anderen Anwendungsservern gemeldet (`8e69b26`); eigenständige Binärdateien für Linux und macOS werden fertiggestellt; und am 21. kommen die ersten Korrekturen eines Mitwirkenden, und das Repository erhält sein erstes Tag, `v0.0.1`.

## Wie der Zeitraum verlief

**7. September.** `243d1ba` fügt die Kompatibilitätsschicht hinzu: 1.666 Zeilen in `Compat.php` plus eine `COMPATIBILITY.md`. Sie erledigt drei Aufgaben: Sie schreibt die wenigen PHP-Funktionen um, die sich in einem langlebigen CLI-Prozess anders verhalten (`header()`, `setcookie()`, `exit`, `die`), sie umhüllt die Dateischicht, sodass Includes und stat-Aufrufe billig sind, und sie setzt den Zustand zurück, den eine Anfrage hinterlässt. Am selben Tag forkt `c57a8e0` zusätzliche Worker, um große Dateien zu senden, und `6b43dd1` stellt eigenständige Binärdateien für Linux und macOS fertig.

**17. September: der Benchmark.** `8e69b26` ändert den Pool, die Kompatibilitätsschicht und den Zustands-Snapshot und schreibt die Benchmark-Dokumente unter dem Titel „existing PHP codebases run 12x faster than with Swoole and FrankenPHP“ neu. Die Zahl stammt vom Commit selbst; die Messmethode steht im Benchmark-Dokument der Engine.

**19. September.** `f8d92cf` (32 Dateien, etwa 10.000 hinzugefügte Zeilen) verbessert Dokumentation, Dashboard und Control Panel und fügt die Unterstützung für Windows hinzu.

**21. September: die Welle eines Mitwirkenden.** Eine Reihe kleiner, gut erklärter Korrekturen kommt, jede in einem eigenen Branch und jede mit einem Test:

- die Linux-Binärdateien des Releases waren beschädigt, weil sie mit UPX komprimiert wurden; die Kompression wurde entfernt (`6f73688`);
- `phpinfo()` wurde als zusammengefalteter reiner Text angezeigt; jetzt wird es in drei Schritten als HTML neu aufgebaut (`da1a605`, `74bde3f`, `722cc2d`);
- die Dokumentwurzel ließ sich nicht auflisten (`d36ef6d`);
- Scripts laufen aus ihrem eigenen Verzeichnis (`1c5c155`), melden ihren eigenen Pfad in `SCRIPT_NAME` (`8457079`), behalten ihre Autoloader (`ea59aba`) und tragen Cookies und binäre Bodys vom Worker in die Antwort (`685d86c`, `32d5b07`);
- untätige Octane-Worker sterben nicht mehr nach `default_socket_timeout` (`9fc5c27`);
- `session_id()` erhält einen Shim (`e8cd8d2`);
- die Micro-SAPI wird gebaut, bevor die Quellen kopiert werden, und der Docker-Build kann die PHP-Version wählen (`a543313`, `449c030`).

`822c531` korrigiert den Paketnamen in Composer, und das Repository erhält das Tag `v0.0.1`.

`509d94b` (am selben Tag) ist der erste Commit „easy to migrate“: Seiten zum Umzug von Apache, Nginx und Caddy, eine Klasse `Autohost` (virtuelle Hosts, die ohne Konfiguration erscheinen), ein `Watchdog`, der den Serverprozess überwacht, und ein größeres Control Panel.

## Kleinere Punkte

- Das Tag `v0.0.2` (21. September) zeigt auf denselben Commit wie `v0.0.1` (`822c531`); das nächste neue Tag, `v0.0.2.1`, ist vom 22. September.
- Manche Korrekturen erscheinen im Änderungsverzeichnis zweimal unter verschiedenen Hashes (`822c531` und `8fe2984` tragen dieselbe Betreffzeile): Lesen Sie sie als eine Änderung.
- Das Änderungsverzeichnis zeigt noch keinen Code eigens für Exponential; die Voreinstellung `exponential` kommt am [23. September](2026-09c.md).

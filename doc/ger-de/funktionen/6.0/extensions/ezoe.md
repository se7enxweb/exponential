# ezoe: das Repository des Online-Editors

Diese Seite ist für alle, die den Code des Rich-Text-Editors suchen. `ezoe` („eZ Online Editor“) ist der
Rich-Text-Editor der Administrationsoberfläche und der Redakteure auf der Website.

Das eigenständige Repository `se7enxweb/ezoe` ist **nicht mehr der Ort, an dem der Code liegt**. Sein README sagt,
dass der Code in das Kernel-Repository von Exponential (den Ordner `extension`) umgezogen ist und Änderungen dort
eingehen. In der Zeit von Exponential 6 erhielt das eigenständige Repository nur Metadaten zur Finanzierung.

## Wo Sie weiterlesen

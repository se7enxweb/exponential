# Geben und spenden: die Arbeit an Exponential finanzieren

Exponential ist kostenlos, seine Herstellung aber nicht: Releases, Sicherheitskorrekturen, PHP-Upgrades,
Dokumentation, Übersetzungen und die Community-Websites kosten alle bezahlte Arbeitsstunden. Die Seite
[Give Support](https://exponential.earth/give) der Website nennt die Wege, diese Arbeit zu finanzieren. Diese Seite
erklärt jeden davon, sagt, an welche Organisation das Geld geht, und verbindet ihn mit den Bereichen für Sponsoren
und Unterstützer in dieser Hilfe.

## Zwei Organisationen, ein Projekt

Das Projekt wird von **7x** entwickelt, einem Unternehmen, und von der **Exponential Foundation** betrieben, einer
gemeinnützigen Organisation. Jede hat ihre eigene Seite bei GitHub Sponsors:

| | 7x | Exponential Foundation |
|---|---|---|
| GitHub Sponsors | <https://github.com/sponsors/se7enxweb> | <https://github.com/sponsors/exponentialcms> |
| Finanziert | Die Menschen, die heute die tägliche Entwicklung und Pflege leisten | Das Open-Source-Projekt als solches: Dokumentation, Community, langfristige Pflege |

Den vollständigen Vergleich mit Quellen finden Sie unter
[Zwei Organisationen, zwei Sponsorenseiten](../sponsoren/zwei-organisationen-zwei-sponsorenseiten.md).

## Die Wege zu geben auf der Website

Die Seite Give Support nennt fünf, gelesen im Oktober 2026:

| Auf der Website | Was es ist | Wohin der Link führt |
|---|---|---|
| **Become an Exponential Partner** | Dem Netzwerk offizieller Partner beitreten: Unternehmen, die rund um Exponential bauen, hosten oder verkaufen und im Gegenzug das Projekt unterstützen | zur Partnerbewerbung, <https://exponential.earth/partner/apply> |
| **Donate to the Exponential Project** | Eine Spende über ein Abonnement bei GitHub Sponsors | zur Sponsorenseite von 7x, <https://sponsor.se7enx.com/> |
| **Sustaining Support Subscription** („Become a GameChanger“) | Ein monatliches Sponsoring, das die Arbeit am Laufen hält | zu 7x bei GitHub Sponsors, <https://github.com/sponsors/se7enxweb> |
| **Sponsor Development of New Software** | 7x dafür bezahlen, neue Software für einen Bedarf zu bauen, den Sie haben | <https://sponsor.se7enx.com/> |
| **GitHub Sponsors for 7x** | 7x direkt auf GitHub sponsern | <https://github.com/sponsors/se7enxweb> |

> **Hinweis**
> Jeder Spendenlink auf der Seite Give Support führt zu 7x. Die eigene Sponsorenseite der Foundation,
> <https://github.com/sponsors/exponentialcms>, ist auf der [Community-Seite](https://exponential.earth/about/community)
> der Website („Sponsor the Exponential Foundation“) und auf der [Website der Foundation](https://foundation.exponential.earth/)
> verlinkt. Wählen Sie die Organisation, deren Aufgabe Sie finanzieren möchten, oder teilen Sie Ihre Gabe zwischen
> beiden auf.

Die Fußzeile der Website verlinkt außerdem Spenden über PayPal. Andere Wege und eine Warnung vor Geldforderungen
über Kanäle, die Sie nicht überprüfen können, finden Sie unter [Andere Wege zu geben](../sponsoren/weitere-wege-zu-geben.md).

## Welchen Weg Sie wählen

| Sie sind | Erwägen Sie |
|---|---|
| Ein Benutzer, dessen Site auf Exponential läuft | Ein kleines monatliches Sponsoring für 7x oder die Foundation |
| Ein Unternehmen, das mit Exponential Geld verdient | Ein größeres dauerhaftes Sponsoring ([Sponsoring als Unternehmen](../sponsoren/als-unternehmen-sponsern.md)) oder eine Partnerschaft |
| Ein Unternehmen, das eine Funktion braucht | Gesponserte Entwicklung bei 7x; das Ergebnis kann allen zugutekommen |
| Eine Agentur, ein Hoster oder ein Schulungsanbieter | Das Partnerprogramm ([Partner: Hier beginnen](../partner/partner-hier-beginnen.md)) |
| Jemand, der in den Vereinigten Staaten eine mögliche Steuerermäßigung möchte | Die Foundation, eine gemeinnützige Organisation nach 501(c)(3); fragen Sie Ihren eigenen Steuerberater |

## Warum es wichtig ist

Die Seite [Project](https://exponential.earth/about/project) der Website sagt, dass das Projekt durch Zeit und
Ressourcen finanziert wird, die 7x und seine Sponsoren spenden. Die Build-Seite sagt es einfach: Wenn Exponential
Ihnen Zeit spart, Ihnen hilft, ein Projekt fertigzustellen, oder Ihnen Umsatz bringt, denken Sie darüber nach, etwas
zurückzugeben. Wofür das Geld verwendet wird, beschreibt [Was Sponsoring finanziert](../sponsoren/was-sponsoring-finanziert.md);
die Anerkennung, die Sponsoren erhalten, steht unter [Anerkennung für Sponsoren](../sponsoren/anerkennung-fuer-sponsoren.md).

## Geben ohne Geld

Nicht jeder kann Geld geben, und die FAQ der Website sagt das auch. Code, Übersetzungen, Dokumentation, Tests,
Beratung zur Barrierefreiheit und Antworten in den Foren sind alle Geschenke an das Projekt:
[Zum Projekt beitragen](zum-projekt-beitragen.md),
[Wege, Exponential zu unterstützen](../unterstuetzer/wege-exponential-zu-unterstuetzen.md).

# Community-Kanäle: wo sich die Exponential-Community trifft

Die [Community-Seite](https://exponential.earth/about/community) der Projektwebsite listet die „Aktivitätszentren“
der Exponential-Community auf. Diese Seite sammelt sie und sagt, wofür jedes gedacht ist, Stand Oktober 2026. Wo die
Website für einen Chat zwei verschiedene Einladungslinks angibt, verwendet diese Seite den, der beim Schreiben
funktionierte.

## Reden: Foren und Chats

| Kanal | Wofür er gedacht ist | Adresse |
|---|---|---|
| **Foren von Share Exponential** | Der wichtigste Ort für Fragen, Antworten, Ankündigungen und Diskussionen, die andere später finden sollen. Außerdem Artikel, Blogs und Tutorials. | <https://share.exponential.earth/forums> |
| **Telegram**, „Support Exponential (CMS)“ | Echtzeit-Chat über Exponential, PHP, Design und Support. Das Projekt nennt ihn einen wichtigen Support-Kanal, in dem auch Mitglieder des Entwicklungsteams sind. | <https://t.me/exponentialcms> |
| **Discord**, Server „Exponential“ | Community-Chat, Diskussionen zur Entwicklung, Rückmeldungen und Ideen für Funktionen | <https://discord.gg/zXzGMgfzej> |
| **Slack**, Workspace „exponentialcms“ | Chat, besonders zur Entwicklung | <https://exponentialcms.slack.com/> |

Alle sind kostenlos. Für eine Frage, die eine lange Antwort braucht, sind die Foren besser: Ein Chat scrollt davon,
ein Forenthema bleibt durchsuchbar. Wie Sie gut fragen: [Unterstützung erhalten](unterstuetzung-erhalten.md#so-fragen-dass-sie-eine-antwort-bekommen).

## Welcher Kanal wann

| Sie möchten | Verwenden Sie |
|---|---|
| Fragen, wie man etwas macht | Die Foren, oder Telegram für eine schnelle Frage |
| Einen Fehler in der Software melden | Den [Issue-Tracker der Software](https://github.com/se7enxweb/exponential/issues) ([wie](../wenn-etwas-schiefgeht.md#einen-fehler-in-exponential-melden)) |
| Ein Sicherheitsproblem melden | Vertraulich, nie in einem Kanal ([wie](../wenn-etwas-schiefgeht.md#sicherheitsprobleme)) |
| Eine Funktion vorschlagen | Die [Community-Roadmap](https://share.exponential.earth/community-roadmap) oder ein Issue ([Die Roadmap](roadmap.md)) |
| Eine Erweiterung finden | Exponential Projects und die Organisation se7enxweb |
| Ihre Erweiterung teilen | [Erweiterungen zurückgeben](../erweiterungen-zurueckgeben.md) |
| Über Entwicklung sprechen | Discord, Slack oder einen Pull-Request |
| Ein Problem mit einer Website des Projekts melden | Den [Issue-Tracker des Projekts](https://github.com/se7enxweb/exponential-community/issues) |

Wo Sie auch sind, es gelten die üblichen Umgangsformen: Seien Sie geduldig, seien Sie freundlich, und veröffentlichen
Sie nie Passwörter oder personenbezogene Daten anderer. Fürsprecher, die das Projekt in diesen Kanälen vertreten,
finden eigene Hinweise im [Bereich für Fürsprecher](../fuersprecher/werkzeugkasten-fuer-fuersprecher.md).

# Das Exponential-Projekt: Hier beginnen

Exponential ist freie Software, aber auch ein Projekt: die Menschen, die sie schreiben, das Unternehmen und die
gemeinnützige Organisation, die sie tragen, die Sites, auf denen sich ihre Benutzer treffen, und die Pläne für das,
was als Nächstes kommt. Das öffentliche Zuhause des Projekts ist **[exponential.earth](https://exponential.earth/)**.
Dieser Abschnitt der Hilfe behandelt, was diese Website sagt, in ihren eigenen Worten, wo es darauf ankommt, und
sonst in einfachen Worten, und verbindet es mit dem Rest dieser Hilfe.

Die Seiten der Website wurden im Oktober 2026 gelesen. Ihr Text ist laut Fußzeile der Site „All rights reserved“;
diese Hilfe kopiert ihn deshalb nicht, sondern erklärt dieselben Themen in eigenen Worten und verlinkt auf das
Original. Wo die Website und die Software in diesem Repository voneinander abweichen, folgen diese Seiten bei
Fakten über die Software dem Repository und sagen das auch.

## Das Projekt in fünf Sätzen

1. **Exponential** ist ein Open-Source-Content-Management-System und Entwicklungsframework, geschrieben in PHP und
   lizenziert unter der GNU GPL Version 2 oder später (`COPYRIGHT.md`).
2. Sein Code war einst eZ Publish, ein Produkt, das sein Hersteller nach fast achtzehn Jahren eingestellt hat;
   Exponential hat diesen Code weitergeführt, und der Name wurde im August 2025 zu Exponential geändert, wie die FAQ
   der Website festhält ([/faq](https://exponential.earth/faq)). Die Website sagt auch, dass das Projekt nicht mit
   dem ursprünglichen Entwickler dieser Software verbunden ist.
3. Das Projekt wird **von der Exponential Foundation betrieben**, einer gemeinnützigen Organisation, und **von 7x
   entwickelt**, dem Unternehmen, das seine Entwicklung und Pflege leitet (Fußzeile jeder Seite von
   exponential.earth; [Wer ist die Exponential Foundation?](../wer-ist-die-exponential-foundation.md),
   [Wer ist 7x?](../wer-ist-7x.md)).
4. Sein Code liegt auf GitHub in [se7enxweb/exponential](https://github.com/se7enxweb/exponential), die
   Erweiterungen in der [Organisation se7enxweb](https://github.com/se7enxweb), und jedes Paket ist auf Packagist.
5. Seine Benutzer treffen sich auf [Share Exponential](https://share.exponential.earth/), im Telegram-Kanal, auf
   Discord und Slack und finden Erweiterungen auf [Exponential Projects](https://projects.exponential.earth/).

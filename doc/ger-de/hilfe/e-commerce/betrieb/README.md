# Einen Shop betreiben

Dieser Teil richtet sich an alle, die einen Exponential-Shop über Monate und Jahre gut am Laufen halten: Händler,
Shop-Manager, Entwickler und Agenturen. Die täglichen, wöchentlichen und monatlichen Routinen stehen bereits unter
[Ihren Shop führen](../../kunden/handel/README.md); diese Seiten behandeln die Themen darum herum.

## Was ein Seitenpaket ist

Ein Seitenpaket ist eine fertige Website (Inhaltsklassen, Inhalte, Einstellungen und Designs) in einer Datei `.ezpkg`,
die der Einrichtungsassistent, der Kickstarter oder die Konsole installiert. "The setup wizard installs site packages
such as 7x Simple", der Einrichtungsassistent installiert also Seitenpakete wie 7x Simple ([Roadmap](../../projekt/roadmap.md)).
Die Grundlagen stehen unter [Was ein Installationspaket für Websites ist](../../seitenpakete/grundlagen/was-ein-seiteninstallationspaket-ist.md)
und [Die Datei ezpkg](../../seitenpakete/grundlagen/die-datei-ezpkg.md).

## Der Paketserver

"The package server `exponential.packages.exponential.earth` serves the packages of the setup wizard ('Users do not
need to use this server outside the setup wizard usage', repository description)", der Paketserver liefert also die
Pakete des Einrichtungsassistenten aus, und Benutzer brauchen ihn außerhalb des Assistenten nicht
([Begleitprojekte](../../wer-ist-die-exponential-foundation.md#begleitprojekte)). Wie er funktioniert:
[Was der Paketserver ist](../../seitenpakete/paketserver/was-der-paketserver-ist.md),
[Offline-Installationen und Spiegel](../../seitenpakete/paketserver/offline-installationen-und-spiegel.md).

## Seitenpakete aus der Community

Der zweite Aufruf der Roadmap an Freiwillige: Das Projekt möchte "to open the wizard's list of site packages to the
community, so that users can publish their own", also die Liste der Seitenpakete des Assistenten für die Community
öffnen, damit Benutzer ihre eigenen veröffentlichen können ([Roadmap](../../projekt/roadmap.md)).
[Ihr Seitenpaket beitragen](../../seitenpakete/ihr-seitenpaket-beitragen.md) zeigt den Weg über einen Pull-Request.

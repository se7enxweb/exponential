# Glossar zum Ökosystem

| Begriff | Bedeutung | Mehr |
|---|---|---|
| **AdminUI** | Ein alternatives Design der Administration, eine Portierung von Netgen Admin UI (`exp_adminui`) | [AdminUI und die Admin-Designs](produkte/adminui-und-admin-designs.md) |
| **CMF** | Content-Management-Framework: Exponential ist sowohl ein Framework als auch ein CMS | [Der Kernel von Exponential 6](produkte/exponential-6-kernel.md) |
| **Composer** | Der Paketmanager von PHP; für die Installation von Exponential erforderlich | [Composer und Packagist](pakete/composer-und-packagist.md) |
| **Distribution** | Eine installationsfertige Zusammenstellung von Paketen, etwa Nexus oder Legacy | [Die Platform-Linie](produkte/die-platform-linie.md) |
| **Dual-Kernel** | Eine Distribution, die die Symfony-Plattform und den Kernel von Exponential 6 zusammen betreibt | [Die Platform-Linie](produkte/die-platform-linie.md) |
| **DXP** | Digital Experience Platform; Exponential Platform DXP ist die reine Symfony-Variante | [Exponential Platform DXP](produkte/platform-dxp.md) |
| **Ökosystem** | Alle Aspekte der Welt von Exponential innerhalb des PHP-Stacks: ihre Anwender und Ersteller | [Was das Ökosystem ist](was-das-oekosystem-ist.md) |
| **Engine** | Der Server, den Velocity antreibt: Qbix, FrankenPHP oder der eingebaute Server von PHP | [Webserver und Engines](php-stack/webserver-und-engines.md) |
| **Erweiterung** | Ein Paket, das dem Kernel Funktionen, Designs oder Einstellungen hinzufügt | [Die mitgelieferten Erweiterungen](pakete/die-mitgelieferten-erweiterungen.md) |
| **Fork** | Eine gepflegte Kopie eines anderen Projekts, hier meist, um es auf aktuellem PHP lauffähig zu halten | [Upstream-Projekte und Forks](php-stack/upstream-projekte-und-forks.md) |
| **Kernel** | Exponential 6 selbst, `se7enxweb/exponential` | [Der Kernel von Exponential 6](produkte/exponential-6-kernel.md) |
| **Layouts** | Exponential Layouts, der visuelle Seitenbaukasten | [Exponential Layouts](produkte/exponential-layouts.md) |
| **Legacy Bridge** | Betreibt den Kernel von Exponential 6 innerhalb der Symfony-Plattform | [Legacy Bridge](../../funktionen/6.0/legacy-bridge.md) |
| **Metapaket** | Ein Composer-Paket, das nur andere verlangt, etwa `exponential-platform-dxp` | [Exponential Platform DXP](produkte/platform-dxp.md) |
| **Nexus** | Exponential Platform Nexus: Plattform plus Exponential 6, Exponential Layouts und Media Site | [Die Platform-Linie](produkte/die-platform-linie.md) |
| **Paketserver** | Der Server der Seitenpakete des Einrichtungsassistenten | [Seitenpakete und der Paketserver](pakete/seitenpakete-und-der-paketserver.md) |
| **Packagist** | Das öffentliche Composer-Repository, in dem se7enxweb seine Pakete veröffentlicht | [Composer und Packagist](pakete/composer-und-packagist.md) |
| **Partner** | Ein Unternehmen im Partnerprogramm von Exponential | [Partner im Ökosystem](organisationen/partner-im-oekosystem.md) |
| **Qbix** | Die Webserver-Engine, als deren Fork Velocity begann, und seine empfohlene Engine | [Exponential Velocity](produkte/exponential-velocity.md) |
| **se7enxweb** | Die GitHub-Organisation und der Packagist-Anbieter von 7x | [7x im Ökosystem](organisationen/7x-im-oekosystem.md) |
| **Seitenpaket** | Eine fertige Website, die der Einrichtungsassistent installiert (`.ezpkg`) | [Seitenpakete und der Paketserver](pakete/seitenpakete-und-der-paketserver.md) |
| **Velocity** | Exponential Velocity, der Anwendungsserver | [Exponential Velocity](produkte/exponential-velocity.md) |
| **Zeta Components** | Die PHP-Bibliotheken, die der Kernel verwendet | [Upstream-Projekte und Forks](php-stack/upstream-projekte-und-forks.md) |

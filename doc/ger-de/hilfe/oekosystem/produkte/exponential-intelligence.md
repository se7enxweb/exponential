# Exponential Intelligence im Ökosystem

**"A writing assistant built into the administration interface"**, ein in die Administration eingebauter
Schreibassistent, der "writes drafts, as the signed-in editor and with that editor's own permissions", also Entwürfe
als angemeldeter Redakteur und mit dessen eigenen Rechten schreibt, nie von sich aus veröffentlicht und mit gehosteten
Anbietern in den USA oder der EU oder mit einem lokalen Open-Weight-Modell arbeitet (`README.md`, "Exponential
Intelligence").

## Sein Platz im Ökosystem

- Paket `se7enxweb/expai`, seit 6.0.15 in `composer.json` verlangt
  ([Exponential Intelligence](../../wer-ist-die-exponential-foundation.md#exponential-intelligence)).
- Für "Editors, project managers and content writers", Redakteure, Projektleitungen und Texter (ebenda).
- Es verbindet die Welt von Exponential mit externen KI-Diensten oder mit einem Modell auf Ihrem eigenen Server.

## Standardeinstellungen

"A new installation activates it by default", eine neue Installation aktiviert ihn standardmäßig, und er "sends
nothing anywhere until you add a provider key", sendet also nichts, bevor Sie einen Schlüssel eines Anbieters
eintragen (`README.md`, zitiert unter [Exponential Intelligence](../../wer-ist-die-exponential-foundation.md#exponential-intelligence)).

## Anbieter

Der Abschnitt "Providers: hosted, in the EU, or on your own server" der README nennt die Wahl: ein gehosteter Anbieter,
ein Anbieter in der EU oder ein lokales Open-Weight-Modell auf demselben Server. Anforderungen: "an API key of a hosted
AI provider, or a local open-weight model on the same server", ein API-Schlüssel eines gehosteten KI-Anbieters oder ein
lokales Modell auf demselben Server (`README.md`, "Requirements").

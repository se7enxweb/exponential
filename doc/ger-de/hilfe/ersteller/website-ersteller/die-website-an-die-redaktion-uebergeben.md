# Die Website an die Redaktion übergeben

Diese Seite richtet sich an Website-Ersteller, die ein Projekt abschließen. Eine Website lebt durch ihre Redaktion; eine
gute Übergabe entscheidet, ob sie gut bleibt. Projektleiter finden eine Vorlage für die Übergabe in
[Projektvorlagen](../../fuehrung/projektvorlagen.md).

## Konten und Rollen

- Ein persönliches Konto pro Person; keine geteilten Zugänge.
- Rollen nach Aufgabe: Autor, Redakteur (veröffentlicht), Layout-Redakteur, Formularbearbeiter (`infocollector/read`),
  Shop-Personal ([Rollen und Richtlinien](../../../anleitungen/rollen-und-richtlinien.md)).
- Beschränken Sie jedes Team auf seinen Teilbaum oder seine Sektion.
- Zweistufige Anmeldung für alle, die veröffentlichen können
  ([Zwei-Faktor-Anmeldung](../../../anleitungen/zwei-faktor-anmeldung.md)).

## Der Leitfaden für die Redaktion

Schreiben Sie einen kurzen Leitfaden speziell für diese Website; verlinken Sie für die allgemeinen Teile auf die Hilfe:

| Abschnitt | Inhalt |
|---|---|
| Die Struktur der Website | wo jede Art von Inhalt liegt |
| Klassen | welche Klasse wofür verwendet wird und was jedes Feld auf der Seite wird |
| Bilder | Größen, Alternativtexte, wohin hochgeladen wird |
| Landingpages | welche Layouts es gibt und wer sie bearbeitet |
| Veröffentlichen | Entwürfe, Prüfung, Veröffentlichung, Versionen ([Veröffentlichen und Versionen](../../veroeffentlichen-und-versionen.md)) |
| Formulare und Newsletter | wer sie bearbeitet und wie |
| Wen man fragt | Namen von Rollen, nicht von Personen, die gehen könnten |

## Schulung

Die Hilfe in der Administration ist das Handbuch der Redaktion: [Erste Schritte](../../erste-schritte.md),
[Inhalte bearbeiten](../../inhalte-bearbeiten.md), [Medien und Uploads](../../medien-und-uploads.md),
[Der Layouts-Editor](../../layout-editor.md), [Tastenkürzel](../../tastenkuerzel.md) und
[Die Tour durch die Administration](../../rundgang-durch-die-administration.md). Eine Schulung entlang der Tour durch die Administration mit den
eigenen Inhalten der Website bringt die meisten Redakteure von null zum Arbeiten.

## Hausregeln für Inhalte

- Titel kurz und klar; sie werden zu Adressen.
- Jedes Bild mit einem Alternativtext.
- Linktexte, die sagen, wohin sie führen.
- Überschriften in der richtigen Reihenfolge; keine fetten Absätze als Überschriften.
- Entfernen statt für immer verbergen; um eine Weiterleitung bitten, wenn eine Seite wegfällt.

## Unterstützung nach dem Start

- Vereinbaren Sie, wer die Fragen der Redaktion beantwortet und wie schnell.
- Sammeln Sie in den ersten Wochen Fragen; nehmen Sie wiederkehrende in den Leitfaden auf.
- Zeigen Sie der Redaktion, wie sie ein Problem über die Seite **Einen Fehler melden** der Hilfe meldet
  ([Wenn etwas schiefgeht](../../wenn-etwas-schiefgeht.md)).

# Checklisten für Hoster: Überblick

Dieser Bereich sammelt die Checklisten, die ein Hosting-Team immer wieder nutzt. Jeder Punkt verlinkt die Seite, die ihn
erklärt. Drucken Sie sie aus (jede Hilfeseite kann gedruckt oder als PDF heruntergeladen werden), kopieren Sie sie in Ihre
Ticketvorlagen oder passen Sie sie an: Die Hilfe ist freie Dokumentation.

## Seiten in diesem Bereich

| Checkliste | Nutzen Sie sie, wenn |
|---|---|
| [Neuer Server](checkliste-fuer-einen-neuen-server.md) | Sie eine Maschine aufbauen, die Exponential-Websites hosten wird |
| [Go-Live einer neuen Kunden-Website](checkliste-fuer-den-start-einer-kunden-website.md) | eine Kunden-Website auf Ihrer Plattform demnächst öffentlich wird |
| [Monatlicher Betrieb](checkliste-fuer-den-monatlichen-betrieb.md) | einmal im Monat für jede Website, die Sie betreiben |
| [Sicherheitsprüfung](checkliste-fuer-die-sicherheitspruefung.md) | vor dem Go-Live, nach einem Vorfall und einmal im Quartal |
| [Offboarding eines Kunden](checkliste-fuer-das-offboarding-eines-kunden.md) | ein Kunde Sie verlässt oder die Website anderswohin umzieht |

## Wie Sie sie nutzen

- Bewahren Sie pro Server oder pro Website eine Kopie auf, mit dem Datum und dem Namen der Person, die jeden Punkt geprüft
  hat.
- Ein Punkt, der nicht zutrifft, wird mit „entfällt“ und einer Begründung markiert, nicht leer gelassen.
- Wenn ein Punkt scheitert, eröffnen Sie ein Ticket; gehen Sie nicht mit einem offenen Punkt aus den Sicherheitsabschnitten
  live.

> **Tipp**
> Die [Runbooks](../runbooks/README.md) sind die Begleiter dieser Checklisten: Eine Checkliste beugt vor, ein Runbook
> repariert.

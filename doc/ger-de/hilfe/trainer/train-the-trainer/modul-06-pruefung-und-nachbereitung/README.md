# Modul 6: Prüfung und Nachbereitung

Das letzte Modul des Train-the-Trainer-Kurses behandelt, woran ein Trainer erkennt, dass die Teilnehmenden etwas
gelernt haben, wie er das ehrlich belegt, wie der Kurs besser wird und wie die Teilnehmenden danach weitermachen.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Train the Trainer](../README.md) |
| Dauer | 2 Stunden 40 Minuten (fünf Lektionen) |
| Lektionen | 5 |
| Niveau | Einsteiger bis Fortgeschrittene |
| Format | Workshop; Papier oder ein gemeinsames Dokument; eine Schulungsinstallation für den Entwurf der praktischen Aufgabe |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [6.1 Verständnis während des Kurses prüfen](verstaendnis-im-kurs-pruefen.md) | 30 Min. | „Zeigen Sie mir“-Fragen, eine Umfrage und eine Aufforderung zur Zusammenfassung schreiben |
| [6.2 Quizfragen und praktische Aufgaben](quizze-und-praktische-aufgaben.md) | 45 Min. | Eine Prüfung mit Bewertungsraster für Modul 2 erstellen |
| [6.3 Feedback sammeln](feedback-sammeln.md) | 30 Min. | Einen Feedbackzettel schreiben und Feedback sortieren |
| [6.4 Teilnahmebescheinigungen im eigenen Namen](teilnahmebescheinigungen.md) | 25 Min. | Einen ehrlichen Bescheinigungstext schreiben |
| [6.5 Nach dem Kurs](nach-dem-kurs.md) | 30 Min. | Eine Nachfassnachricht und eine Aufräumliste schreiben |

## Dieses Modul vorbereiten

- Kopien der Lektionen von Modul 2 für die Prüfungsübung.
- Gedruckt: [Marken- und Namensregeln](../../../geschaeft/marken-und-namensregeln.md) für Lektion 6.4.

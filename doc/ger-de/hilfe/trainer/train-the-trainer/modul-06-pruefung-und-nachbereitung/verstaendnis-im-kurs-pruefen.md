# Lektion 6.1: Verständnis während des Kurses prüfen

Der schlechteste Zeitpunkt, um festzustellen, dass der halbe Raum nicht mitgekommen ist, ist der Abschlusstest. Jede
Lektion dieser Kurse hat aus diesem Grund ein **Erwartetes Ergebnis**: eine Prüfung, die der Trainer vornehmen kann,
solange noch Zeit zum Helfen ist. Diese Lektion zeigt vier schnelle Prüfungen und wann man sie einsetzt.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- das **Erwartete Ergebnis** einer Lektion als Prüfung auf dem Bildschirm aller Teilnehmenden nutzen;
- „Zeigen Sie mir“-Fragen stellen statt „Noch Fragen?“;
- eine kurze Umfrage mit einer Frage pro Lernziel durchführen;
- am Ende eines Moduls eine schriftliche Ein-Minuten-Zusammenfassung einsetzen.

## Hinweise für Trainer

### So präsentieren Sie es

1. Vier Prüfungen (8 Minuten):
   - **Erwartetes Ergebnis**: Gehen Sie durch den Raum (oder bitten Sie online um einen Screenshot nur des Fensters)
     und vergleichen Sie mit dem erwarteten Ergebnis der Lektion.
   - **Zeigen Sie mir**: „Zeigen Sie mir, wo Sie Ihr Passwort ändern würden“ ist besser als „Ist das klar?“.
   - **Umfrage**: eine Multiple-Choice-Frage pro Lernziel; die Quizfragen der Lektion eignen sich dafür.
   - **Ein-Minuten-Zusammenfassung**: Am Ende eines Moduls schreiben alle Teilnehmenden das Wichtigste und das am
     wenigsten Klare auf.
2. Handeln Sie danach (2 Minuten): Wenn mehr als einige wenige einen Punkt nicht verstanden haben, erklären Sie ihn
   kurz noch einmal, bevor Sie weitermachen.

### Häufige Fragen

**Bewerte ich das?** Nein. Es dient der Steuerung des Kurses.

**Was, wenn eine Person weit zurückliegt?** Eine Hilfskraft oder eine Partnerin bzw. ein Partner; halten Sie den Raum
in Bewegung.

### Stolperfallen

- **„Noch Fragen?“** Schweigen bedeutet kein Verständnis.
- **Nur die Schnellen prüfen.** Sehen Sie sich jeden Bildschirm an.

## Praktische Übung

1. Wählen Sie eine Lektion dieses Kurses.
2. Schreiben Sie zwei „Zeigen Sie mir“-Fragen dazu, jede an ein Lernziel gebunden.
3. Machen Sie aus zwei ihrer Quizfragen eine kurze Umfrage.
4. Schreiben Sie die Aufforderung zur Ein-Minuten-Zusammenfassung für das Ende ihres Moduls.
5. Probieren Sie alles mit einer Partnerin oder einem Partner aus und notieren Sie, was ein Missverständnis
   aufgedeckt hat.

## Erwartetes Ergebnis

- Zwei „Zeigen Sie mir“-Fragen, eine Umfrage mit zwei Fragen und eine Aufforderung zur Zusammenfassung für eine
  Lektion.
- Mindestens eine Prüfung hat etwas aufgedeckt, bei dem sich die Partnerin oder der Partner unsicher war.

## Quiz

1. Warum ist „Noch Fragen?“ eine schwache Prüfung?
2. Welcher Abschnitt jeder Lektion ist eine fertige Prüfung?
3. Was schreiben die Teilnehmenden in eine Ein-Minuten-Zusammenfassung?
4. Werden diese Prüfungen bewertet?

<details>
<summary>Antworten</summary>

1. Schweigen bedeutet kein Verständnis.
2. **Erwartetes Ergebnis** (und das Quiz).
3. Das Wichtigste und das am wenigsten Klare.
4. Nein; sie steuern den Kurs.

</details>

# Lektion 6.2: Quizfragen und praktische Aufgaben

Manche Kurse enden mit einer Prüfung: Ein Arbeitgeber möchte wissen, wer jetzt veröffentlichen kann, oder eine
Teilnehmerin möchte einen Nachweis über eine Fähigkeit. Diese Lektion zeigt, wie man aus den Lernzielen der
Lektionen eine faire Abschlussprüfung baut, mit schriftlichen Fragen, einer praktischen Aufgabe und einem
Bewertungsraster.

> **Hinweis**
> Das Exponential-Partnerprogramm nennt Zertifizierungen für Partnerteams, aber deren Lehrplan, Prüfungen und Prüfer
> sind nicht veröffentlicht ([Zertifizierungen](../../../partner/zertifizierungen.md)). Jede Prüfung, die Sie
> durchführen, ist Ihre eigene; stellen Sie sie auch so dar.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- schriftliche Fragen mit einem Lösungsschlüssel schreiben, der eine Hilfeseite als Beleg nennt;
- eine praktische Aufgabe auf einer Schulungsinstallation mit überprüfbarem Ergebnis entwerfen;
- ein Bewertungsraster mit drei bis vier Stufen pro Kriterium schreiben;
- klar sagen, dass die Prüfung ihre eigene ist.

## Hinweise für Trainer

### So präsentieren Sie es

1. Abstimmung (5 Minuten): Jede Frage und jede Aufgabe prüft ein Lernziel des Kurses; keine Überraschungen.
2. Schriftliche Fragen (4 Minuten): Multiple Choice oder Kurzantwort; jede Antwort im Schlüssel nennt die Seite, die
   sie belegt, so wie es die Quizfragen in diesen Lektionen tun.
3. Praktische Aufgaben (4 Minuten): eine Aufgabe auf einer Schulungsinstallation mit einem Ergebnis, das der Trainer
   prüfen kann (ein Element existiert, eine Rolle ist zugewiesen, eine Seite zeigt eine Änderung).
4. Bewertungsraster (2 Minuten): Kriterien in den Zeilen, Stufen in den Spalten (zum Beispiel: noch nicht, teilweise,
   vollständig).

### Häufige Fragen

**Kann ich die Quizfragen der Lektionen wiederverwenden?** Ja, zum Üben. Schreiben Sie für eine Abschlussprüfung neue
Fragen zu denselben Lernzielen, damit sie die Fähigkeit misst und nicht die Erinnerung an das Quiz.

**Welche Bestehensgrenze?** Legen Sie sie vor dem Kurs fest und teilen Sie sie den Teilnehmenden mit.

### Stolperfallen

- **Fangfragen.** Sie messen Aufmerksamkeit, nicht Können.
- **Aufgaben, die von der Installation des Trainers abhängen.** Alle Teilnehmenden brauchen denselben
  Ausgangszustand.
- **Es Zertifizierung nennen.** Tun Sie das nicht.

## Praktische Übung

Erstellen Sie die Prüfung für Modul 2 dieses Kurses.

1. Listen Sie die Lernziele der Lektionen 2.3, 2.4 und 2.5 auf.
2. Schreiben Sie dazu vier neue schriftliche Fragen mit einem Lösungsschlüssel, der eine Seite als Beleg nennt.
3. Schreiben Sie eine praktische Aufgabe, zum Beispiel: „Installieren Sie eine Website auf SQLite mit dem Titel
   ‚Assessment‘, stellen Sie sie auf Port 8095 bereit und legen Sie einen Benutzer `assess01` mit einer Adresse unter
   `example.invalid` in der Gruppe Editors an.“
4. Schreiben Sie ein Bewertungsraster mit drei Kriterien (Installation, Bereitstellung, Konto) und drei Stufen.
5. Schreiben Sie die erste Zeile des Prüfungsbogens, die sagt, dass es Ihre eigene Prüfung ist.

## Erwartetes Ergebnis

- Vier Fragen mit belegtem Schlüssel, eine praktische Aufgabe und ein Bewertungsraster mit drei mal drei Feldern.
- Die erste Zeile des Bogens nennt den Trainer oder die Organisation als Urheber und beansprucht keinen offiziellen
  Status.

## Quiz

1. Was sollte jede Prüfungsfrage prüfen?
2. Was sollte jede Antwort im Schlüssel enthalten?
3. Warum schreibt man neue Fragen, statt die Quizfragen der Lektionen wiederzuverwenden?
4. Dürfen Sie Ihre Prüfung als offizielle Exponential-Zertifizierung darstellen?

<details>
<summary>Antworten</summary>

1. Ein Lernziel des Kurses.
2. Einen Verweis auf die Hilfeseite, die sie belegt.
3. Um die Fähigkeit zu messen statt der Erinnerung an das Quiz.
4. Nein. Es ist Ihre eigene Prüfung; die Zertifizierungen des Partnerprogramms sind etwas anderes, und ihre Einzelheiten sind nicht veröffentlicht ([Zertifizierungen](../../../partner/zertifizierungen.md)).

</details>

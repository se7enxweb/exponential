# Modul 1: Den Unterricht von Exponential vorbereiten

Dieses Modul bereitet einen Trainer vor, bevor eine Übungsumgebung aufgebaut wird: was das Kursmaterial ist, woher
seine Angaben stammen, wer die Teilnehmenden sind, was die Lizenz erlaubt und wie man Exponential richtig vorstellt.
Es braucht eine Installation mit dem Hilfe-Center und keine besondere Einrichtung.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Train the Trainer](../README.md) |
| Dauer | 2 Stunden 35 Minuten (fünf Lektionen) |
| Lektionen | 5 |
| Niveau | Einsteiger |
| Format | Präsenz oder online; ein Browser pro Teilnehmer |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [1.1 Wie diese Kurse funktionieren](wie-diese-kurse-funktionieren.md) | 30 Min. | Vom Hilfe-Center zu einer Lektion gehen und ihre Abschnitte lesen |
| [1.2 Das Hilfe-Center als Ihr Lehrbuch](das-hilfe-center-als-ihr-lehrbuch.md) | 45 Min. | Suchen, filtern, Links für Handouts erstellen, drucken und PDFs herunterladen |
| [1.3 Ihre Teilnehmenden kennen](ihre-teilnehmenden-kennen.md) | 30 Min. | Eine Umfrage vor dem Kurs schreiben und Teilnehmende passenden Kursen zuordnen |
| [1.4 Ihr Kursmaterial und die GNU FDL](ihr-material-und-die-gfdl.md) | 30 Min. | Den Lizenzteil eines Kursordners aufbauen |
| [1.5 Namen und Geschichte im Unterricht](namen-und-geschichte-im-unterricht.md) | 20 Min. | Eine zweiminütige Eröffnung schreiben und proben |

## Dieses Modul vorbereiten

- Eine Exponential-Installation, auf der sich alle Teilnehmenden mit der Richtlinie `exphelp/read` in der
  Administration anmelden können (ein Administratorkonto pro Teilnehmer oder die Rolle Editor auf einer neuen
  Installation).
- Ein Projektor oder eine Bildschirmfreigabe.
- Gedruckt oder geöffnet: [Kurzkarte zu den Namensregeln](../../../fuersprecher/kurzkarte-namensregeln.md) und
  [Freie Dokumentation](../../../freie-dokumentation.md).
- Ein Ordner pro Teilnehmer für die Übung mit dem Kursordner in Lektion 1.4.

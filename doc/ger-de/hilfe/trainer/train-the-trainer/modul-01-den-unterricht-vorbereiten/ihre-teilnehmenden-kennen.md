# Lektion 1.3: Ihre Teilnehmenden kennen

Dieselbe Software sieht für eine Redakteurin, die jeden Morgen Nachrichten veröffentlicht, einen Administrator, der die
Website sicher hält, und einen Entwickler, der Templates schreibt, sehr unterschiedlich aus. Die Hilfe von Exponential
ist genau nach diesen Gruppen gegliedert, ihren **Zielgruppen**, und die Trainerkurse folgen ihnen. Diese Lektion
zeigt, wie Sie vor dem Kurs herausfinden, wer Ihre Teilnehmenden sind, und wie Sie den passenden Kurs, die passenden
Module und das passende Tempo für sie wählen.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- die Zielgruppen nennen, die das Hilfe-Center verwendet, und den Kurs, der zu jeder passt;
- eine Umfrage vor dem Kurs mit fünf Fragen schreiben, die keine personenbezogenen Daten über das hinaus sammelt, was
  der Kurs braucht;
- für eine bestimmte Gruppe zwischen einem vollständigen Kurs, ausgewählten Modulen und einem Workshop wählen;
- eine gemischte Gruppe erkennen und dafür planen.

## Hinweise für Trainer

### So präsentieren Sie es

1. Öffnen Sie das Dashboard des Hilfe-Centers und lesen Sie die Zielgruppenkarten unter **Hier beginnen** laut vor:
   Redakteure, Administratoren, Entwickler, Benutzer, Projektmanager, Vertrieb und Marketing, Partner, Fürsprecher,
   Designer, Hosting-Unternehmen, Anwendungsentwickler, Website-Ersteller, Unterstützer, Sponsoren (3 Minuten).
2. Ordnen Sie sie den Kursen zu (4 Minuten):

   | Teilnehmende | Kurs für den Einstieg |
   |---|---|
   | Menschen, die Inhalte schreiben und veröffentlichen | Redakteure 101, dann Redakteure 201 |
   | Menschen, die eine Website betreiben: Benutzer, Rollen, Caches, Sicherheit, Updates | Website-Administration |
   | Menschen, die auf Exponential aufbauen: Templates, Klassen, Erweiterungen | Entwickler |
   | Menschen, die das Aussehen einer Website oder ein Theme gestalten | Theme-Design |
   | Menschen, die Seiten aus Blöcken bauen | Exponential Layouts |
   | Menschen, die Server für Exponential-Websites betreiben | Hosting und Betrieb |
   | Teams, die eine Website von einem anderen System umziehen | Migration |

3. Zeigen Sie eine Beispielumfrage (3 Minuten) und weisen Sie darauf hin, was *nicht* gefragt wird: kein
   Geburtsdatum, keine Privatadresse.

### Häufige Fragen

**Was, wenn die Hälfte der Gruppe Redakteure und die Hälfte Entwickler sind?** Unterrichten Sie den gemeinsamen Teil
zusammen (die Module von Redakteure 101 zum Inhaltsbaum und zum Veröffentlichen sind für alle nützlich), teilen Sie
die Gruppe dann, oder führen Sie den Entwicklerteil an einem anderen Tag durch. Lektion 3.3 hat Zeitpläne dafür.

**Sollen Führungskräfte teilnehmen?** Eine Projektmanagerin hat meist mehr von einem kurzen Überblick und den Seiten
für Projektmanager in der Hilfe als von einer praktischen Übungsumgebung.

### Stolperfallen

- **Berufsbezeichnungen vertrauen.** „Webmaster“ kann Redakteur, Administrator oder Entwickler bedeuten. Fragen Sie,
  was die Leute jede Woche tun.
- **Zu viel sammeln.** Eine Umfrage braucht nur, was Ihren Plan verändert. Bewahren Sie Antworten nicht länger auf, als
  der Kurs sie braucht.
- **Bedürfnisse an Barrierefreiheit vergessen.** Fragen Sie offen, ob jemand Materialien in einem anderen Format oder
  andere Vorkehrungen braucht (Modul 5).

## Praktische Übung

Bereiten Sie die Aufnahme für eine echte oder ausgedachte Gruppe von acht Teilnehmenden vor.

1. Öffnen Sie das Hilfe-Center und notieren Sie die Bezeichnungen der Zielgruppen genau so, wie das Dashboard sie
   zeigt.
2. Schreiben Sie eine Umfrage vor dem Kurs mit diesen fünf Fragen (passen Sie die Formulierung an):
   1. Was tun Sie jede Woche mit der Website? (Inhalte veröffentlichen / Benutzer und Einstellungen verwalten / Code
      oder Templates schreiben / gestalten / Server betreiben / anderes)
   2. Welche Version von Exponential verwenden Sie, falls Sie es wissen? (die Version steht auf dem Dashboard der
      Administration unter **System**)
   3. Haben Sie schon ein anderes Content-Management-System verwendet? Welches?
   4. Was müssen Sie nach dem Kurs können?
   5. Brauchen Sie Vorkehrungen, um teilnehmen zu können (Format der Materialien, Pausen, Untertitel)?
3. Beantworten Sie sie selbst für drei ausgedachte Teilnehmende (zum Beispiel eine Redakteurin, einen Administrator,
   eine Frontend-Entwicklerin).
4. Wählen Sie für jede Person den Kurs aus der Tabelle in den Hinweisen für Trainer und die ersten beiden Module.
5. Entscheiden Sie, ob diese Gruppe einen gemeinsamen Kurs, zwei parallele Stränge oder einen gemeinsamen Vormittag
   und einen getrennten Nachmittag bekommt.
6. Schreiben Sie einen Satz für die Kurseinladung, der sagt, für wen der Kurs gedacht ist.

## Erwartetes Ergebnis

- Eine Umfrage mit fünf Fragen, die nichts fragt, was der Kurs nicht braucht.
- Drei Teilnehmerprofile, jedes mit einem Kurs und den ersten beiden genannten Modulen.
- Eine Entscheidung (gemeinsam, parallel oder getrennt) mit einem Satz Begründung und ein Satz für die Einladung.
- Der Trainer prüft: Sammelt eine Frage personenbezogene Daten, die nicht nötig sind? Ist jeder Kursname echt?

## Quiz

1. Nennen Sie vier Zielgruppen, die das Dashboard des Hilfe-Centers zeigt.
2. Welcher Kurs passt zu jemandem, der Benutzer, Rollen und Caches verwaltet?
3. Warum sollte eine Umfrage nicht nach dem Geburtsdatum der Teilnehmenden fragen?
4. Eine Gruppe besteht aus Redakteuren und Entwicklern. Nennen Sie eine Möglichkeit, dafür zu planen.

<details>
<summary>Antworten</summary>

1. Vier beliebige von: Redakteure, Administratoren, Entwickler, Benutzer, Projektmanager, Vertrieb und Marketing,
   Partner, Fürsprecher, Designer, Hosting-Unternehmen, Anwendungsentwickler, Website-Ersteller, Unterstützer,
   Sponsoren.
2. Website-Administration.
3. Es ändert nichts am Kursplan; sammeln Sie nur, was der Kurs braucht
   ([Die Privatsphäre von Menschen schützen](../../../fuersprecher/privatsphaere-schuetzen.md)).
4. Ein gemeinsamer Vormittag zu Inhalten und Veröffentlichen und getrennte Nachmittage, oder zwei parallele Stränge,
   oder zwei Tage.

</details>

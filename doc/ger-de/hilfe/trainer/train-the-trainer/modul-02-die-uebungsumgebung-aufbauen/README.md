# Modul 2: Die Übungsumgebung aufbauen

Ein Kurs ist nur so gut wie seine Übungsumgebung. Dieses Modul bringt Trainern bei, eine aufzubauen, die beim ersten
Versuch funktioniert: Rechner, die die Anforderungen erfüllen, dasselbe Release für alle, eine Installation pro
Teilnehmer oder eine gut geschützte gemeinsame Website, Konten der Teilnehmenden mit den richtigen Rollen und ein
Ablauf, um alles für die nächste Gruppe zurückzusetzen.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Train the Trainer](../README.md) |
| Dauer | 5 Stunden 15 Minuten (acht Lektionen) |
| Lektionen | 8 |
| Niveau | Fortgeschrittene |
| Format | Praxisnah; ein Rechner mit Terminal pro Teilnehmer |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [2.1 Anforderungen an einen Schulungsrechner](anforderungen-an-einen-schulungsrechner.md) | 40 Min. | PHP, Erweiterungen, `php.ini`, Composer und Git prüfen |
| [2.2 Den Code für einen Kurs beschaffen](den-code-fuer-einen-kurs-beschaffen.md) | 40 Min. | Ein festes Release klonen oder mit create-project anlegen |
| [2.3 Eine Installation pro Teilnehmer mit exp:install](eine-installation-pro-teilnehmer.md) | 45 Min. | Eine Installation ausgeben, probeweise und echt ausführen |
| [2.4 Die Websites der Übungsumgebung mit Velocity bereitstellen](die-websites-der-uebungsumgebung-bereitstellen.md) | 35 Min. | Eine Website starten, prüfen, verlegen und stoppen |
| [2.5 Konten und Rollen der Teilnehmenden](konten-und-rollen-der-teilnehmenden.md) | 45 Min. | Benutzer unter example.invalid anlegen und ihre Rollen prüfen |

| [2.8 Das Seitenpaket für den Kurs wählen](das-seitenpaket-fuer-den-kurs-waehlen.md) | 30 Min. | Eine leere Website installieren und vergleichen |

## Dieses Modul vorbereiten

- Ein Rechner pro Teilnehmer mit Terminal, PHP 7.4 oder neuer, Composer 2 und Git; Netzzugang zu GitHub und
  Packagist oder der Code im Voraus vorbereitet.
- Genug Speicherplatz für zwei oder drei Installationen pro Teilnehmer.
- Eine gedruckte Liste der Befehle der Lektionen 2.3 und 2.4.
- Für Lektion 2.7: eine gemeinsame Installation, die die Teilnehmenden erreichen können.

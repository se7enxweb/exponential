# Modul 4: Einen Kurs durchführen

In diesem Modul geht es um den Kurstag selbst: einen Kurs gut eröffnen, vorführen, ohne etwas preiszugeben, mit dem
Unerwarteten umgehen und die Teilnehmenden so zurücklassen, dass sie sich selbst helfen können. Die meisten
Lektionen werden in kleinen Gruppen geübt, deren Mitglieder abwechselnd Trainer, Teilnehmer und Beobachter sind.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Train the Trainer](../README.md) |
| Dauer | 4 Stunden 15 Minuten (sechs Lektionen) |
| Lektionen | 6 |
| Niveau | Fortgeschrittene |
| Format | Übung in Dreiergruppen; eine Schulungsinstallation pro Teilnehmer |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [4.1 Die erste Stunde gestalten](die-erste-stunde-gestalten.md) | 60 Min. | Eine Eröffnung, die erste Anmeldung und die Passwortänderung durchführen |
| [4.2 Sicher vorführen](sicher-vorfuehren.md) | 40 Min. | Einen Vorführbrowser vorbereiten und eine sichere Vorführung halten |
| [4.3 Fragen, die Sie nicht beantworten können](fragen-die-sie-nicht-beantworten-koennen.md) | 30 Min. | Fünf Fragen mit Quellen beantworten |
| [4.4 Fehlersuche im Kurs](fehlersuche-im-kurs.md) | 50 Min. | Logs lesen, den Wartungsmodus nutzen, eine Karte mit Korrekturen für die Übungsumgebung schreiben |
| [4.5 Sicherheit und Datenschutz im Kurs](sicherheit-und-datenschutz-im-kurs.md) | 40 Min. | Prüfen, wie offen eine Übungsumgebung ist, und eine Aufräumliste schreiben |
| [4.6 Hilfe zur Selbsthilfe](hilfe-zur-selbsthilfe.md) | 35 Min. | Die Kontexthilfe nutzen und eine gute Frage für das Forum schreiben |

## Dieses Modul vorbereiten

- Eine Schulungsinstallation pro Teilnehmer, installiert mit `exp:install`, damit für Lektion 4.1
  `var/log/initial-admin-password` existiert.
- Administratorkonten (Lektion 4.4 braucht **Setup > Logdateien**).
- Gedruckt: [Sicherheit bei Live-Demos](../../../fuersprecher/sicherheit-bei-live-demos.md) und die Tabelle zur Fehlersuche aus
  Lektion 4.4.

# Lektion 3.1: Lernziele formulieren

Jede Lektion dieser Kurse beginnt mit „Nach dieser Lektion können die Teilnehmenden:“ und einer kurzen Liste. Diese
Zeilen sind der wichtigste Teil einer Lektion: Sie entscheiden, was Sie zeigen, was die Teilnehmenden üben und was das
Quiz fragt. Diese Lektion bringt Trainern bei, solche Lernziele für ihre eigenen Lektionen zu formulieren.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- ein beobachtbares Lernziel („einen Artikel veröffentlichen“) von einem nicht beobachtbaren („das Veröffentlichen
  verstehen“) unterscheiden;
- drei bis fünf Lernziele für eine Lektion formulieren, jedes mit einem Handlungsverb;
- jedes Lernziel mit einem Schritt der Übung und einer Quizfrage verknüpfen;
- Inhalte streichen, die keinem Lernziel dienen.

## Hinweise für Trainer

### So präsentieren Sie es

1. Zeigen Sie zwei Fassungen an der Tafel (5 Minuten):
   - schwach: „Die Teilnehmenden verstehen Versionen.“
   - stark: „Die Teilnehmenden können für ein Element **Versionen verwalten** öffnen und sagen, welche Version
     veröffentlicht ist.“
2. Nennen Sie die Regel (5 Minuten): Ein Lernziel nennt etwas, das die Teilnehmenden *tun* und das der Trainer *sehen*
   kann: öffnen, erstellen, veröffentlichen, zuweisen, finden, in einem Satz erklären, zwischen zwei Möglichkeiten
   wählen.
3. Zeigen Sie die Zuordnungstabelle einer beliebigen Lektion dieses Kurses (5 Minuten): Jedes Lernziel hat einen
   Übungsschritt und eine Quizfrage. Fehlt eines davon, hat die Lektion eine Lücke.

### Häufige Fragen

**Wie viele Lernziele pro Lektion?** Drei bis fünf. Mehr bedeutet, dass die Lektion zu groß ist; teilen Sie sie.

**Sind „wissen“ und „verstehen“ verboten?** Nicht verboten, aber nicht prüfbar. Ersetzen Sie sie durch das, wie
Wissen aussieht: „in einem Satz erklären“, „das richtige ... für ... wählen“.

### Stolperfallen

- **Lernziele über den Trainer.** „Den Rolleneditor zeigen“ ist der Plan des Trainers, kein Ergebnis für die
  Teilnehmenden.
- **Lernziele, die eine andere Installation brauchen.** Wenn die Übungsumgebung es nicht kann, können es die
  Teilnehmenden auch nicht.
- **Zu abstrakt.** Binden Sie Lernziele an echte Bildschirme und Befehle von Exponential.

## Praktische Übung

Formulieren Sie Lernziele für eine 45-minütige Lektion über Lesezeichen für Redakteure.

1. Lesen Sie die Anleitung [Lesezeichen](../../../../anleitungen/lesezeichen.md) im Hilfe-Center.
2. Schreiben Sie fünf mögliche Lernziele. Beginnen Sie jedes mit „Nach dieser Lektion können die Teilnehmenden“.
3. Markieren Sie jedes Verb. Ersetzen Sie „wissen“, „verstehen“, „lernen“ und „sich bewusst sein“ durch ein
   beobachtbares Verb.
4. Behalten Sie die besten drei bis fünf.
5. Schreiben Sie für jedes Lernziel den Übungsschritt, der es übt (mit den echten Schaltflächennamen aus der
   Anleitung).
6. Schreiben Sie für jedes Lernziel eine Quizfrage, die es prüft.
7. Tauschen Sie mit einer Partnerin oder einem Partner. Diese Person markiert jedes Lernziel, das sie im Kurs nicht
   prüfen könnte.

## Erwartetes Ergebnis

- Drei bis fünf Lernziele mit beobachtbaren Verben, jedes mit einem Übungsschritt und einer Quizfrage.
- Die Partnerin oder der Partner konnte jedes Lernziel im Kurs prüfen.
- Der Trainer sammelt von allen ein Beispiel ein und bespricht ein starkes und ein schwaches.

## Quiz

1. Formulieren Sie als beobachtbares Lernziel: „Die Teilnehmenden verstehen Rollen.“
2. Wie viele Lernziele sollte eine 45-minütige Lektion haben?
3. Was tun Sie mit Inhalten, die keinem Lernziel dienen?
4. Warum sollte jedes Lernziel einen Übungsschritt haben?

<details>
<summary>Antworten</summary>

1. Zum Beispiel: „Die Teilnehmenden können eine Rolle unter **Benutzer > Rollen und Richtlinien** öffnen und sagen,
   welchen Gruppen sie zugewiesen ist.“
2. Drei bis fünf.
3. Streichen oder in die weiterführende Literatur verschieben.
4. Damit die Teilnehmenden es üben und der Trainer sehen kann, ob sie es können.

</details>

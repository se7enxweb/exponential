# Lektion 3.2: Module und Lektionen gliedern

Ein guter Kurs fühlt sich an wie eine Treppe: Jede Stufe ist klein und ruht auf der vorigen. Die Kurse in dieser Hilfe
sind aus diesem Grund als Kurse, Module und Lektionen aufgebaut. Diese Lektion zeigt Trainern, wie sie diese Treppe für
einen eigenen Kurs bauen, mit der vorhandenen Hilfe als Material.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Train the Trainer](../README.md) |
| Modul | [Modul 3: Einen Kurs gestalten](README.md) |
| Dauer | 45 Minuten (15 Präsentation, 30 Übung) |
| Niveau | Fortgeschrittene |
| Zielgruppe | Trainer, die einen eigenen Kurs aufbauen |
| Voraussetzungen | [Lektion 3.1](lernziele-formulieren.md) |

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- Themen zu Modulen von einer bis drei Stunden mit jeweils einem klaren Ergebnis zusammenfassen;
- Lektionen nach Abhängigkeiten ordnen (was muss man vorher können?);
- einen Modulüberblick mit einer Tabelle der Lektionen und einem Zeitplan schreiben;
- die Voraussetzungen eines Kurses aufzählen.

## Hinweise für Trainer

### So präsentieren Sie es

1. Zeigen Sie den Modulüberblick von [Modul 2](../modul-02-die-uebungsumgebung-aufbauen/README.md) (5 Minuten):
   **Auf einen Blick**, **Lektionen**, **Dieses Modul vorbereiten**, **Zeitplan**.
2. Erklären Sie die Ordnung nach Abhängigkeiten mit einem Beispiel für Redakteure (5 Minuten): Man kann nicht
   veröffentlichen, bevor man erstellen kann; man kann nicht übersetzen, bevor man eine erste Version veröffentlichen
   kann; man kann keine Rolle zuweisen, bevor der Benutzer existiert.
3. Erklären Sie die Größe eines Moduls (5 Minuten): eine bis drei Stunden, ein Ergebnis, eine natürliche Pause am
   Ende.

### Häufige Fragen

**Sollte jeder Kurs mit der Installation beginnen?** Nur Kurse, deren Teilnehmende installieren werden. Redakteure
beginnen angemeldet.

**Können Module optional sein?** Ja. Kennzeichnen Sie sie im Kursüberblick als optional und achten Sie darauf, dass
kein späteres Modul von ihnen abhängt.

### Stolperfallen

- **Alphabetische Reihenfolge.** Die Menüreihenfolge der Administration ist keine Lernreihenfolge.
- **Das Modul für alles.** Ein Modul, das Rollen, Caches und Cronjobs behandelt, hat kein einzelnes Ergebnis. Teilen
  Sie es.
- **Versteckte Voraussetzungen.** Braucht Lektion 4 eine Benutzergruppe, die in Lektion 2 angelegt wurde, sagen Sie es
  in den **Voraussetzungen** von Lektion 4.

## Praktische Übung

Gestalten Sie einen eintägigen Kurs „Unser Intranet betreiben“ für Administratoren.

1. Öffnen Sie die Liste der Anleitungen der Hilfe ([Anleitungen](../../../../anleitungen/README.md)) und wählen Sie acht
   Themen, die ein Intranet-Administrator braucht (zum Beispiel Rollen und Richtlinien, Sektionen, Caches, Cronjobs,
   zweistufige Anmeldung, Upgrades, Systeminformationen, Wartungsmodus).
2. Schreiben Sie jedes Thema auf eine Karte (Papier oder eine Textdatei).
3. Fassen Sie die Karten zu drei oder vier Modulen zusammen, jedes mit einem Satz für sein Ergebnis.
4. Ordnen Sie die Module und die Lektionen darin nach Abhängigkeiten. Schreiben Sie für jede Lektion auf, was sie
   vorher braucht.
5. Schätzen Sie die Dauer (Übung eingeschlossen) und prüfen Sie, dass der Tag in sechs Stunden Unterricht passt.
6. Schreiben Sie einen Modulüberblick mit den Abschnitten einer Modul-README: auf einen Blick, Lektionen,
   Vorbereitung, Zeitplan.

## Erwartetes Ergebnis

- Ein Kurs aus drei oder vier Modulen, jedes mit einem Ergebnissatz und geordneten Lektionen.
- Ein Modulüberblick mit einem Zeitplan, der aufgeht.
- Keine Lektion hängt von etwas ab, das später unterrichtet wird.

## Quiz

1. Wie lang sollte ein Modul sein?
2. Welche vier Abschnitte hat ein Modulüberblick in diesen Kursen?
3. Nennen Sie ein Zeichen dafür, dass ein Modul geteilt werden sollte.
4. Wo schreiben Sie auf, dass eine Lektion etwas aus einer früheren Lektion braucht?

<details>
<summary>Antworten</summary>

1. Eine bis drei Stunden, mit einem Ergebnis.
2. Auf einen Blick, Lektionen, Dieses Modul vorbereiten, Zeitplan.
3. Es hat mehr als ein Ergebnis, oder es behandelt Bereiche, die nichts miteinander zu tun haben.
4. In der Zeile **Voraussetzungen** der Lektion.

</details>

# Modul 3: Einen Kurs gestalten

Die Kurse in dieser Hilfe sind ein Ausgangspunkt. Jede Organisation braucht ihre eigene Mischung: einen kürzeren Tag
für Redakteure, einen Kurs für Intranet-Administratoren, eine Online-Fassung. Dieses Modul bringt Trainern bei, solche
Kurse mit derselben Sorgfalt zu gestalten: klare Lernziele, eine sinnvolle Reihenfolge, ein Zeitplan, der hält, und
Übungen, die funktionieren.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Train the Trainer](../README.md) |
| Dauer | 4 Stunden 5 Minuten (sechs Lektionen) |
| Lektionen | 6 |
| Niveau | Fortgeschrittene |
| Format | Workshop; eine Schulungsinstallation pro Teilnehmer für die Lektionen 3.4 und 3.5 |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [3.1 Lernziele formulieren](lernziele-formulieren.md) | 40 Min. | Beobachtbare Lernziele für eine Lektion über Lesezeichen formulieren |
| [3.2 Module und Lektionen gliedern](module-und-lektionen-gliedern.md) | 45 Min. | Einen eintägigen Kurs für Administratoren gestalten |
| [3.3 Zeitplanung und Tempo](zeitplanung-und-tempo.md) | 35 Min. | Einen Zeitplan mit Pausen, Puffern und streichbaren Punkten aufstellen |
| [3.4 Übungen schreiben, die funktionieren](uebungen-schreiben-die-funktionieren.md) | 45 Min. | Eine Übung schreiben und proben |
| [3.5 Diese Kurse anpassen und verbessern](diese-kurse-anpassen-und-verbessern.md) | 40 Min. | Eine Korrektur oder eine Fehlermeldung vorbereiten |
| [3.6 Online- und Hybridunterricht](online-und-hybridunterricht.md) | 40 Min. | Eine Lektion für den Online-Unterricht anpassen und die Bildschirmfreigabe testen |

## Dieses Modul vorbereiten

- Eine Schulungsinstallation pro Teilnehmer (Modul 2) für die Probe in Lektion 3.4.
- Papierkarten oder ein gemeinsames Dokument für die Kursgestaltung in Lektion 3.2.
- Optional: ein GitHub-Konto pro Teilnehmer für Lektion 3.5.
- Ein Videokonferenz-Werkzeug für den Test der Bildschirmfreigabe in Lektion 3.6.

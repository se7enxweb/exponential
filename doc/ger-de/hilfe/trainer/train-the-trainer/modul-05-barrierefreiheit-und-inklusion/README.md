# Modul 5: Barrierefreiheit und Inklusion

Alle Teilnehmenden sollten einem Exponential-Kurs folgen können. Dieses Modul behandelt die Materialien, die
Funktionen der Administration, die Teilnehmenden mit unterschiedlichen Bedürfnissen helfen, den Unterricht in
anderen Sprachen und die Planung von Nachteilsausgleichen.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Train the Trainer](../README.md) |
| Dauer | 2 Stunden 30 Minuten (vier Lektionen) |
| Lektionen | 4 |
| Niveau | Einsteiger bis Fortgeschrittene |
| Format | Workshop; eine Schulungsinstallation im Design Admin 4 pro Teilnehmer |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [5.1 Barrierefreie Kursmaterialien](barrierefreie-kursmaterialien.md) | 40 Min. | Ein barrierefreies Handout erstellen und testen |
| [5.2 Mit der barrierefreien Administration unterrichten](mit-der-barrierefreien-administration-unterrichten.md) | 40 Min. | Die Administration mit Tastatur, Farbmodus und Zoom bedienen |
| [5.3 Sprachen und Rechts-nach-links im Kurs](sprachen-und-rechts-nach-links-im-kurs.md) | 35 Min. | Die Sprache der Oberfläche wechseln und ein Glossar anlegen |
| [5.4 Nachteilsausgleich und inklusive Praxis](nachteilsausgleich-und-inklusive-praxis.md) | 35 Min. | Nachteilsausgleiche und ein angepasstes Quiz planen |

## Dieses Modul vorbereiten

- Schulungsinstallationen im Design Admin 4 mit einem Testkonto pro Teilnehmer (Lektion 5.3 ändert Einstellungen).
- Ein Screenreader oder die Vorlesefunktion des Systems auf mindestens einem Rechner.
- Gedruckt: [Barrierefreie Folien und Grafiken](../../../fuersprecher/barrierefreie-folien-und-grafiken.md).

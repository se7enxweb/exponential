# Modul 8: Exponential verlassen und das Abschlussprojekt

Der Kurs endet mit dem Weg hinaus und mit einem eigenen Plan der Teilnehmenden. Die erste Lektion vermittelt den
vollständigen Export einer Exponential-Website; im Abschlussprojekt schreiben, belegen und präsentieren Teams einen
vollständigen Migrationsplan für ein realistisches Szenario.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Migration zu Exponential](../README.md) |
| Dauer | 2 Stunden 15 Minuten |
| Lektionen | 2 |
| Niveau | Fortgeschrittene bis Experten |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [8.1 Migration weg von Exponential](von-exponential-wechseln.md) | 45 Minuten | Ein Website-Archiv erstellen, es mit den Zählungen der Administration abgleichen, Weiterleitungen und Passwörter planen |
| [8.2 Abschlussprojekt: ein vollständiger Migrationsplan](abschlussprojekt-migrationsplan.md) | 90 Minuten | In Teams einen Migrationsplan schreiben, belegen und präsentieren; mit einem Bewertungsraster bewertet |

## Dieses Modul vorbereiten

- [ ] Auf der Schulungsinstallation jeder Person ist xrowextract aktiv, und in `var/tmp/` ist genug Speicherplatz für
      ein Archiv.
- [ ] Die vier Szenarien des Abschlussprojekts ausgedruckt, eines pro Team; Teams nach Rollen gemischt.
- [ ] Ein gemeinsames Dokument pro Team für den Plan und eine Uhr für die Präsentationen.
- [ ] Das Bewertungsraster aus Lektion 8.2 zum Bewerten ausgedruckt. Sagen Sie den Teilnehmenden zu Beginn, dass es
      Ihr eigenes Kursmaterial ist, keine offizielle Zertifizierung.
- [ ] Prüfen Sie nach Lektion 8.1, dass die Teilnehmenden `var/tmp/export/` entfernt haben.

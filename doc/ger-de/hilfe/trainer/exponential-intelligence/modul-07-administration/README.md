# Modul 7: Administration

Die Lektionen 7.1 bis 7.3 sind für die Administratoren, die den Assistenten betreiben; Redakteure können sie
überspringen und zum Abschlussprojekt (Lektion 7.4) dazukommen, das den Kurs für alle abschließt.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Intelligence](../README.md) |
| Dauer | 3 Stunden 25 Minuten (mit 10 Minuten Pause) |
| Lektionen | 4 |
| Niveau | Experten (Lektionen 7.1 bis 7.3), Fortgeschrittene (Lektion 7.4) |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 7.1: Anbieter und Modelle](anbieter-und-modelle.md) | 45 Minuten | Die Seite Models and providers lesen; einen Test-Prompt ausführen |
| [Lektion 7.2: Einschalten, Schlüssel, Limits und Budgets](einschalten-einstellungen-und-limits.md) | 60 Minuten | Den Assistenten auf der eigenen Schulungsinstallation ein- und ausschalten; ein Limit setzen |
| [Lektion 7.3: EI: Summary, die Hilfeseiten und das Audit-Protokoll](die-dsb-seite-hilfe-und-audit.md) | 30 Minuten | Die Zusammenfassung als PDF erstellen; Hilfeseiten finden; das Audit prüfen |
| [Lektion 7.4: Abschlussprojekt: eine redaktionelle Aufgabe von Anfang bis Ende](abschlussprojekt-eine-redaktionelle-aufgabe-von-anfang-bis-ende.md) | 60 Minuten | Eine Aufgabe vom Auftrag bis zur Freigabe erledigen; Prüfung mit Checkliste |

## Dieses Modul vorbereiten

- Für die Lektionen 7.1 und 7.3: ein Administratorkonto pro Person auf der Schulungsinstallation (oder führen Sie es
  vor).
- Für Lektion 7.2: Jeder Administrator unter den Teilnehmenden braucht eine eigene Schulungsinstallation mit
  Shell-Zugang und einen Anbieterschlüssel, der für Schulungen gedacht ist (oder ein lokales Modell). Verwenden Sie nie
  einen Produktivschlüssel.
- Für Lektion 7.4: den Ordner mit Beispielbildern, Freigabekonten, wenn ein Freigabe-Workflow greift, und die
  ausgedruckten Checklisten.

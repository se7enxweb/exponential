# Modul 2: Der Tab Intelligence

Das erste praktische Modul. Alle Teilnehmenden bitten den Assistenten um zwei Artikel unter ihrem eigenen Ordner,
entscheiden, was mit den Entwürfen geschieht, und lernen zu lesen, was passiert ist.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Intelligence](../README.md) |
| Dauer | 2 Stunden 10 Minuten (mit 10 Minuten Pause) |
| Lektionen | 3 |
| Niveau | Einsteiger |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 2.1: Ein erstes Gespräch im Tab Intelligence](ein-erstes-gespraech.md) | 45 Minuten | Einen Auftrag schreiben und schicken; die Antwort und die Entwürfe lesen |
| [Lektion 2.2: Entwürfe behalten, senden und verwerfen](entwuerfe-behalten-senden-und-verwerfen.md) | 45 Minuten | Einen Entwurf behalten, bearbeiten, verwerfen und senden |
| [Lektion 2.3: Verlauf, Aufzeichnungen und neue Gespräche](verlauf-aufzeichnungen-und-neue-gespraeche.md) | 30 Minuten | Den Verlauf und die Aufzeichnung eines Durchgangs lesen; ein neues Gespräch beginnen |

## Dieses Modul vorbereiten

- Der Kursordner jeder Person, in dem sie Artikel anlegen darf.
- Führen Sie vor dem Kurs selbst eine Anfrage aus und stoppen Sie die Zeit: Ein gehostetes Modell antwortet bei kleinen
  Aufträgen innerhalb einer Minute; ein lokales Modell auf einem gewöhnlichen Server kann pro Schritt Minuten brauchen.
- Entscheiden Sie, ob in Lektion 2.2 ein Freigabe-Workflow greifen soll (er zeigt den Fall des Wartens) oder nicht.
- Nutzungslimits für die Schulungskonten (Lektion 7.2).

# Modul 4: Vector

Vector ist für Arbeit, die größer ist als ein Feld: mehrere Artikel, ein Ordner, eine Übersetzung. Dieses Modul
vermittelt seine zwei Schranken (ein Plan, dann gestufte Änderungen) und die Bedienelemente, die den Redakteur am
Steuer halten.

| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 4.1: Vector-Threads und ihr Umfang](threads-und-umfang.md) | 45 Minuten | Einen auf den eigenen Ordner beschränkten Thread beginnen; Modus, Prüfung und Modell wählen |
| [Lektion 4.2: Pläne und gestufte Prüfung](plaene-und-gestufte-pruefung.md) | 60 Minuten | Einen Plan freigeben, gestufte Änderungen prüfen, Entwürfe schreiben |
| [Lektion 4.3: Ausführen, stoppen, Checkpoints und What changed](ausfuehren-stoppen-checkpoints-und-aenderungen.md) | 45 Minuten | Einen Lauf stoppen, die Kosten lesen, einen Checkpoint wiederherstellen, einen Teil zurücknehmen |

## Dieses Modul vorbereiten

- Die Rolle der Teilnehmenden braucht `expai/vector` (mit Review **staged**, und **direct** nur, wenn Sie den direkten
  Entwurf in Lektion 4.3 so unterrichten; der Tab Intelligence schreibt ohnehin direkte Entwürfe) und eine
  Teilbaum-Einschränkung auf den Schulungsordner.
- Jeder Kursordner mit drei bis fünf kurzen Artikeln, damit Pläne klein und schnell bleiben.
- Halten Sie die Umfänge der Teilnehmenden getrennt, um Konflikte zu vermeiden, außer Sie möchten einen zeigen.
- Nutzungslimits für die Schulungskonten; die Schätzung eines Plans zeigt den Teilnehmenden die Kosten, bevor sie ihn
  ausführen.

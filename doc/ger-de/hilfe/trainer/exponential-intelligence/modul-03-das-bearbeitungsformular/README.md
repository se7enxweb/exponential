# Modul 3: Das Bearbeitungsformular

Die meisten Redakteure begegnen dem Assistenten im Bearbeitungsformular, Feld für Feld. Dieses Modul behandelt jeden
Helfer dort und endet mit Alternativtexten für Bilder.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Intelligence](../README.md) |
| Dauer | 2 Stunden 25 Minuten (mit 10 Minuten Pause) |
| Lektionen | 3 |
| Niveau | Einsteiger |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 3.1: Feldaktionen im Bearbeitungsformular](feldaktionen.md) | 45 Minuten | Felder kürzen, umschreiben, Vorschläge machen und übersetzen lassen; rückgängig machen; eine Aufzeichnung lesen |
| [Lektion 3.2: Fill the fields, Vorlagen und das Menü Improve](felder-ausfuellen-vorlagen-und-verbessern.md) | 45 Minuten | Einen neuen Artikel aus einem Auftrag füllen; Vorlagen und Improve verwenden |
| [Lektion 3.3: Alternativtext für Bilder](alternativtext-fuer-bilder.md) | 45 Minuten | Einen Alternativtext schreiben und prüfen; ein dekoratives Bild kennzeichnen; den Bericht lesen |

## Dieses Modul vorbereiten

- Prüfen Sie, dass die Bedienelemente im Bearbeitungsformular für den Schulungs-Siteaccess eingeschaltet sind (der
  Bereich und die Feldleisten erscheinen im Artikelformular).
- Für Lektion 3.3: Ein Modell, das Bilder ansehen kann, muss konfiguriert und von der Datenrichtlinie erlaubt sein;
  Beispielbilder ohne Menschen und ein dekoratives Bild in jedem Kursordner.
- Wissen Sie, welche Vorlagen Ihre Artikelklasse hat; der Standardartikel ordnet Titel und Zusammenfassung zu.
- Zeigen Sie die Regeln für Alternativtexte aus Lektion 3.3 am Beamer.

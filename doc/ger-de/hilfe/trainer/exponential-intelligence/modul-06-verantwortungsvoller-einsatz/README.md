# Modul 6: Verantwortungsvoller Einsatz

Das wichtigste Modul des Kurses. Der Assistent ist von Grund auf sicher gebaut, aber nur Redakteure können
personenbezogene Daten aus Anfragen heraushalten, prüfen, was er geschrieben hat, und ihn mit Rücksicht auf das Budget
nutzen. Unterrichten Sie dieses Modul auch dann, wenn die Zeit knapp ist.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Intelligence](../README.md) |
| Dauer | 2 Stunden 25 Minuten (mit 10 Minuten Pause) |
| Lektionen | 3 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 6.1: Datenschutz: was an den Anbieter geht und was nie dorthin gehört](datenschutz-und-personenbezogene-daten.md) | 45 Minuten | Fünf Aufträge beurteilen und umschreiben; Region und Aufbewahrung eines Anbieters lesen |
| [Lektion 6.2: KI-Ergebnisse prüfen](ki-ergebnisse-pruefen.md) | 60 Minuten | Mit einer Checkliste eingebaute Fehler in einem Entwurf finden; gegenseitige Prüfung |
| [Lektion 6.3: Kosten, Limits und faire Nutzung](kosten-limits-und-faire-nutzung.md) | 30 Minuten | Kosten und Limits lesen, das günstigste schreibende Modell finden, Kostengewohnheiten aufschreiben |

## Dieses Modul vorbereiten

- Zeigen Sie die fünf Aufträge aus Lektion 6.1 und die Checkliste aus Lektion 6.2 am Beamer; die Beispielnamen und
  -adressen sind erfunden (verwenden Sie nur `example`-Namen und Adressen unter `example.invalid`).
- Für Lektion 6.1 optional eine Regel der Datenrichtlinie für eine Schulungssektion (`[DataPolicy] SectionRegions`), um
  eine Ablehnung zu zeigen.
- Für Lektion 6.2 ein Entwurf pro Kursordner mit eingebauten Fehlern: ein falsches Datum, eine erfundene Statistik, ein
  defekter Link und ein Satz, der sich an einen Assistenten richtet. Schreiben Sie ihn selbst; bitten Sie den
  Assistenten nicht, Fehler in echte Inhalte einzubauen.
- Fragen Sie die Datenschutzansprechperson Ihrer Organisation nach ihren Regeln zum KI-Einsatz und zitieren Sie sie in
  Lektion 6.1.

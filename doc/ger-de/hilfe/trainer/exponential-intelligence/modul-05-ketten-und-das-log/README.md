# Modul 5: Ketten und das Log

Zwei Werkzeuge für die Arbeit mit Abstand zum Text: Ketten, die im Hintergrund schreiben, prüfen und überarbeiten und
für den Redakteur anhalten; und das Log, das alles festhält, was der Assistent getan hat.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Intelligence](../README.md) |
| Dauer | 1 Stunde 30 Minuten |
| Lektionen | 2 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 5.1: KI-Ketten und der menschliche Checkpoint](ki-ketten.md) | 60 Minuten | Eine Kette ausführen, am Checkpoint um Änderungen bitten, freigeben |
| [Lektion 5.2: Das Log lesen](das-log-lesen.md) | 30 Minuten | Durchgänge lesen, filtern, Ansichten wechseln, CSV exportieren |

## Dieses Modul vorbereiten

- Die Auftragswarteschlange (expqueue) läuft auf der Schulungsinstallation, mit einem Worker oder ihrem Cron-Teil jede
  Minute; führen Sie vor dem Kurs selbst eine Kette aus und stoppen Sie die Zeit.
- Die Rolle der Teilnehmenden braucht `expai/chain` (auf Wunsch auf die Artikelkette beschränkt).
- Ketten stellen pro Lauf mehrere Anfragen; prüfen Sie die Limits und das Budget der Schulung.

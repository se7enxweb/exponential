# Modul 2: Die redaktionellen Kurse prüfen

Dieses Modul enthält die Prüfungen für die Kurse, die Redakteure besuchen: Redakteure 101, Exponential Layouts und
Exponential Intelligence. Jeder Kurs hat einen schriftlichen Test und eine praktische Aufgabe. Führen Sie das Paar am
Ende des Kurses durch oder wählen Sie den Teil, der passt: den schriftlichen Test für Wissen, die Aufgabe für Können.

> **Hinweis**
> Dies sind die eigenen Prüfungen des Trainers, keine offizielle Zertifizierung. Passen Sie die Fragen an Version,
> Seitenpaket und Design Ihrer Schulungsinstallation an.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Prüfungen und praktische Übungen](../README.md) |
| Dauer | 5 Stunden 25 Minuten für alle sechs; jedes Paar 1 Stunde 45 bis 1 Stunde 55 Minuten |
| Lektionen | 6 |
| Niveau | Einsteiger bis Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [2.1 Redakteure, schriftlicher Test](redakteure-schriftlicher-test.md) | 45 Min. | Vierzehn Fragen zu Entwürfen, Versionen, dem Papierkorb, Medien, Sprachen und der Suche |
| [2.2 Redakteure, praktische Aufgabe](redakteure-praktische-aufgabe.md) | 70 Min. | Einen Nachrichtenordner aufbauen, ein Bild hochladen, übersetzen, eine Version und ein Element wiederherstellen |
| [2.3 Exponential Layouts, schriftlicher Test](layouts-schriftlicher-test.md) | 40 Min. | Zwölf Fragen zu Layouts, Zonen, Blöcken, Zuordnungen und den Schaltflächen des Editors |
| [2.4 Exponential Layouts, praktische Aufgabe](layouts-praktische-aufgabe.md) | 65 Min. | Ein zweispaltiges Layout bauen, einen Entwurf behalten, veröffentlichen, eine Zuordnung lesen |
| [2.5 Exponential Intelligence, schriftlicher Test](intelligence-schriftlicher-test.md) | 40 Min. | Zwölf Fragen zu Entwürfen, Berechtigungen, Prüfung, Audit und dem Schalter |
| [2.6 Exponential Intelligence, praktische Aufgabe](intelligence-praktische-aufgabe.md) | 65 Min. | Einen Artikel verbessern, einen eingebauten Fehler finden, die Entwürfe des Assistenten prüfen |

## Dieses Modul vorbereiten

- [ ] Eine Schulungsinstallation pro Teilnehmer (oder ein Ordner und ein Konto pro Teilnehmer auf einer gemeinsamen),
      Mail-Transport auf `file`, Konten unter `example.invalid`.
- [ ] Für Lektion 2.2: eine zweite Inhaltssprache auf der Website, eine lizenzfreie Bilddatei pro Teilnehmer und eine
      Redakteursrolle, die aus dem Papierkorb wiederherstellen darf.
- [ ] Für Lektion 2.4: die Layouts-Erweiterungen aktiv, der Reiter **Layouts** für die Rolle der Teilnehmenden
      sichtbar, der Layouttyp *2 columns* (oder ein anderer Typ mit zwei Zonen), mindestens eine aktivierte Zuordnung
      zum Lesen.
- [ ] Für Lektion 2.6: der Assistent eingeschaltet, mit einem Anbieter, den Sie kontrollieren, und mit gesetzten
      Limits; ein vorbereiteter Artikel pro Teilnehmer mit einem eingebauten sachlichen Fehler; ein Bild ohne
      Alternativtext.
- [ ] Ausgedruckte Fragen und Bewertungsraster, die Lösungsschlüssel getrennt aufbewahrt.

# Lektion 1.2: Schriftliche Tests mit belegtem Lösungsschlüssel schreiben

Ein schriftlicher Test prüft, was die Teilnehmenden wissen und verstehen. In diesen Kursen nennt jede Antwort im
Schlüssel die Hilfeseite, die sie belegt, damit Teilnehmende, die anderer Meinung sind, nachschlagen können und der
Trainer zeigen kann, woher die Antwort stammt. Diese Lektion zeigt, wie Sie einen solchen Test schreiben und wie die
Tests der Module 2 bis 5 aufgebaut sind.

> **Hinweis**
> Die Tests in diesem Kurs sind eigenes Material des Trainers, keine offizielle Zertifizierung. Passen Sie sie an die
> Version und das Seitenpaket an, die Sie unterrichten.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- eine Multiple-Choice-Frage mit einer richtigen Antwort und plausiblen falschen Antworten schreiben;
- eine Kurzantwortfrage mit einer klaren erwarteten Antwort und zulässigen Varianten schreiben;
- für jede Antwort die Hilfeseite (und wo möglich den Abschnitt) zitieren, die sie belegt;
- den Lösungsschlüssel in den eingeklappten Block **Antworten** einer Hilfeseite setzen oder bei einem gedruckten Test
  auf ein eigenes Blatt.

## Hinweise für Trainer

### So präsentieren Sie es

1. **Fragetypen** (4 Minuten).
   - **Multiple Choice**, vier Optionen A bis D, eine richtig. Schnell zu bewerten, gut für Fakten und
     Unterscheidungen.
   - **Kurzantwort**, ein Satz oder ein Befehl. Gut für „warum“ und „was passiert, wenn“.
   - **Richtig oder falsch** nur mit Begründung („Richtig oder falsch, und warum?“), sonst bringt Raten die Hälfte der
     Punkte.
2. **Gute falsche Antworten** (4 Minuten). Jede falsche Option ist ein echtes Missverständnis, das im Unterricht
   vorkam: „Entwurf verwerfen löscht den Artikel“ ist ein besserer Distraktor als ein Witz. Halten Sie die Optionen in
   Länge und Form gleich.
3. **Die Quelle** (4 Minuten). Schreiben Sie die Antwort und dann die Seite, die sie belegt. Finden Sie keine Seite,
   prüft die Frage Ihr Gedächtnis, nicht die Dokumentation: Schreiben Sie sie um oder streichen Sie sie. Ziehen Sie
   einen Link auf den Abschnitt (`editing-content.md#when-someone-else-is-editing`) einem Link auf die ganze Seite vor.
4. **Gestaltung** (3 Minuten). Auf einer Hilfeseite steht der Schlüssel im eingeklappten Block, wie in jeder Lektion
   dieser Kurse. Auf Papier geben Sie die Fragen auf einem Blatt aus und bewahren den Schlüssel auf einem anderen auf.
   Zeigen Sie den Schlüssel erst, nachdem Sie die Tests eingesammelt haben.

### Häufige Fragen

**Wie viele Fragen?** Zehn bis fünfzehn für einen Kurs von einem bis vier Tagen, etwa eine Minute pro
Multiple-Choice-Frage und zwei bis drei Minuten pro Kurzantwort. Die Tests in diesem Kurs haben zwölf bis vierzehn
Fragen.

**Dürfen die Teilnehmenden während des Tests die Hilfe benutzen?** Legen Sie es in den Regeln fest
([Lektion 1.1](faire-pruefungen-gestalten.md)). Wenn ja, fragen Sie nach Verständnis: „Warum bleiben freigegebene
Inhalte unveröffentlicht?“ statt „Wie heißt die Einstellung?“.

**Was ist mit anderen Sprachen?** Schreiben Sie einfache Sätze, vermeiden Sie Redewendungen und erlauben Sie ein
Wörterbuch. Siehe [Lektion 1.4](nachteilsausgleich-bei-pruefungen.md).

### Stolperfallen

- **Verneinte Fragen** („Welche ist NICHT ...“). Wenn Sie eine brauchen, setzen Sie NICHT in Fettschrift.
- **„Alle oben genannten“.** Das belohnt Teilwissen. Vermeiden Sie es.
- **Antworten aus der Erinnerung an den Unterricht.** „Was hat der Trainer zuerst gezeigt?“ ist keine Fähigkeit.
- **Versionsdrift.** Ein Schlüssel, der für eine Version geschrieben wurde, kann für die nächste falsch sein. Prüfen
  Sie vor jedem Kurs jede zitierte Seite erneut.

## Praktische Übung

Schreiben Sie vier Fragen zur Seite [Veröffentlichen, Versionen und der Papierkorb](../../../veroeffentlichen-und-versionen.md).

1. Lesen Sie die Seite einmal vollständig.
2. Schreiben Sie eine Multiple-Choice-Frage zu den vier Versionszuständen (**Entwurf**, **Ausstehend**,
   **Veröffentlicht**, **Archiviert**), mit drei falschen Antworten aus echten Missverständnissen.
3. Schreiben Sie eine Kurzantwortfrage dazu, was mit einem entfernten Element geschieht.
4. Schreiben Sie eine Frage „Richtig oder falsch, und warum“ zu **Entwurf verwerfen**.
5. Schreiben Sie eine Frage, die zwei Fakten zusammen erfordert, zum Beispiel das Entfernen eines Elements mit zwei
   Platzierungen.
6. Schreiben Sie den Schlüssel: zu jeder Antwort einen Satz und einen Link auf den Abschnitt, der sie belegt.
7. Geben Sie Ihre vier Fragen ohne den Schlüssel Ihrem Sitznachbarn. Messen Sie, wie lange er braucht.
8. Vergleichen Sie seine Antworten mit Ihrem Schlüssel. Wo er eine andere Antwort gab, die ebenfalls richtig ist,
   verbessern Sie die Frage.

## Erwartetes Ergebnis

- Vier Fragen von drei Typen und ein Schlüssel, in dem jede Antwort einen Abschnitt der Seite zitiert.
- Mindestens eine Frage wurde nach dem Versuch des Sitznachbarn verbessert.
- Der Trainer sammelt einen Satz ein und liest einen Distraktor vor: Die Gruppe sagt, auf welches Missverständnis er
  zielt.

## Quiz

1. Was sollte jede Antwort im Schlüssel außer der Antwort selbst enthalten?
2. Welche falsche Option ist für eine Frage zu **Entwurf verwerfen** besser? A. „Es schickt das Element an einen
   Drucker“ B. „Es löscht das veröffentlichte Element“ C. „Es tut nichts“ D. „Es ändert die Sprache“
3. Warum sollte eine Richtig-oder-falsch-Frage auch nach einer Begründung fragen?
4. Wo bewahren Sie den Schlüssel eines gedruckten Tests auf, während die Teilnehmenden schreiben?
5. Was tun Sie mit einer Frage, zu der Sie keine Seite in der Hilfe finden?

<details>
<summary>Antworten</summary>

1. Eine Quellenangabe der Hilfeseite, idealerweise des Abschnitts, die sie belegt
   ([Quizfragen und praktische Aufgaben](../../train-the-trainer/modul-06-pruefung-und-nachbereitung/quizze-und-praktische-aufgaben.md)).
2. **B.** Es ist ein echtes Missverständnis; der Entwurf wird verworfen, und die veröffentlichte Version bleibt
   ([Veröffentlichen, Versionen und der Papierkorb](../../../veroeffentlichen-und-versionen.md#veröffentlichen)).
3. Raten ist in der Hälfte der Fälle richtig; die Begründung zeigt Verständnis.
4. Auf einem eigenen Blatt, das erst gezeigt wird, nachdem die Tests eingesammelt sind.
5. Schreiben Sie sie so um, dass sie etwas Dokumentiertes prüft, oder streichen Sie sie.

</details>

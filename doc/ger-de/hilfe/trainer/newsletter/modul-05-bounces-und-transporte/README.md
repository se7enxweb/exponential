# Modul 5: Bounces und Transporte

Dieses Modul ist für Administratoren. Es behandelt den Weg, den zurückkommende Mail in den Newsletter nimmt, den Plan
für den Umstieg einer echten Website von Dateien auf echten Versand und die Werkzeuge für die Zustellbarkeit. Die
Schulungsinstallation schreibt weiterhin jede Mail in eine Datei: Der Umstieg ist ein Plan auf Papier, niemals eine
Änderung im Kurs.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Newsletter mit CJW Newsletter](../README.md) |
| Dauer | 2 Stunden 15 Minuten |
| Lektionen | 3 |
| Niveau | Fortgeschrittene bis Experten |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [5.1 Mailkonten und Bounces](mailkonten-und-bounces.md) | 45 Minuten | Das Formular für Mailkonten und die Bounce-Seiten lesen, den Probelauf für Mailboxen ausführen |
| [5.2 Mail-Transporte und Livegang](mail-transporte-und-livegang.md) | 45 Minuten | Einen Plan für den Livegang auf Papier schreiben, den Plan des Nachbarn prüfen |
| [5.3 Versandraten, Testgruppen und die Unterdrückungsliste](versandraten-testgruppen-und-unterdrueckung.md) | 45 Minuten | Die Versandraten lesen, eine Testgruppe anlegen, die Dauer eines Versands schätzen |

## Dieses Modul vorbereiten

- [ ] Die Transporte stehen zu Beginn und am Ende des Moduls weiterhin auf `file` (Einstellungsansicht).
- [ ] Auf der Schulungsinstallation ist kein Mailkonto gespeichert, das auf ein echtes Postfach zeigt.
- [ ] Shell-Zugang für Lektion 5.1, Schritt 7.
- [ ] Für Lektion 5.2: Fragen Sie die Teilnehmenden vorab, wer die Mail ihrer Organisation bereitstellt, damit der
      Plan echte Fragen enthält (aber keine Geheimnisse).
- [ ] Die Teilnehmenden haben eine nicht gesendete Ausgabe (aus Lektion 4.4) für den Versand an die Testgruppe in
      Lektion 5.3.

# Modul 2: Systeme, Listen und Ausgaben

In diesem Modul bauen die Teilnehmenden die Inhaltsseite eines Newsletters auf: ein eigenes System, eine Liste mit
einer sicheren Konfiguration, zwei Ausgaben mit Artikeln und einen pausierten wiederkehrenden Versand. Es wird noch
nichts gesendet.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Newsletter mit CJW Newsletter](../README.md) |
| Dauer | 3 Stunden 30 Minuten |
| Lektionen | 4 |
| Niveau | Einsteiger bis Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [2.1 Newsletter-Systeme und der Baum](newsletter-systeme-und-der-baum.md) | 45 Minuten | Die Wurzel und `RootFolderNodeId` finden, ein System anlegen |
| [2.2 Eine Liste anlegen und konfigurieren](eine-liste-anlegen-und-konfigurieren.md) | 60 Minuten | Eine Liste mit Absender- und Testadressen unter `example.invalid` anlegen |
| [2.3 Eine Ausgabe schreiben](eine-ausgabe-schreiben.md) | 60 Minuten | Eine Ausgabe mit zwei Artikeln schreiben, in der Vorschau ansehen, kopieren |
| [2.4 Wiederkehrende Versände, Artikel-Pools und Freigabe](wiederkehrende-versande-pools-und-freigabe.md) | 45 Minuten | Einen pausierten wiederkehrenden Versand speichern, eine Freigabe verfolgen |

## Dieses Modul vorbereiten

- [ ] Modul 1 erledigt: Jeder Transport schreibt Dateien; die Newsletter-Wurzel und die Sektion existieren.
- [ ] Die Rolle jeder Person darf unterhalb der Wurzel `CJW Newsletter System`, `List`, `Edition` und `Article`
      anlegen.
- [ ] Der öffentliche Siteaccess, den die Listen verwenden sollen, ist bekannt (die Teilnehmenden fragen in Lektion 2.2
      danach).
- [ ] Für Lektion 2.4: eine Liste des Trainers mit eingeschalteter **Freigabe** und eine Ausgabe, die auf Freigabe
      wartet; ein Freigabekonto, das nicht das eigene des Trainers ist.
- [ ] Eine kurze Liste der Testadressen unter `example.invalid` am Whiteboard.

## Zeitplan

| Zeit | Punkt |
|---|---|
| 0:00 bis 0:45 | Lektion 2.1 |
| 0:45 bis 1:45 | Lektion 2.2 |
| 1:45 bis 2:45 | Lektion 2.3 |
| 2:45 bis 3:30 | Lektion 2.4 |

Planen Sie zusätzlich eine Pause von 15 Minuten nach Lektion 2.2 ein. Wenn die Zeit knapp ist, zeigen Sie Lektion 2.4

# Modul 3: Abonnenten

In diesem Modul geht es um Menschen: wie sie sich anmelden, wie Administratoren sie finden und verwalten, wie Listen
importiert und exportiert werden und wie Menschen wieder gehen. Jeder Abonnent im Modul ist erfunden, mit einer
Adresse unter `example.invalid`, und jede Bestätigungsmail ist eine Datei.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Newsletter mit CJW Newsletter](../README.md) |
| Dauer | 3 Stunden 15 Minuten |
| Lektionen | 4 |
| Niveau | Einsteiger bis Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [3.1 Das Anmeldeformular und Double-Opt-in](das-anmeldeformular-und-double-opt-in.md) | 60 Minuten | Sich im öffentlichen Formular anmelden, über den Link in der Mail-Datei bestätigen |
| [3.2 Benutzer und Abonnements verwalten](benutzer-und-abonnements-verwalten.md) | 45 Minuten | Benutzer filtern, einen von Hand anlegen, ein wartendes Abonnement annehmen |
| [3.3 CSV-Import und -Export](csv-import-und-export.md) | 45 Minuten | Eine erfundene Datei mit Zuordnung, Vorschau und Probelauf importieren; die Liste exportieren |
| [3.4 Einwilligung, Abmelden und die Sperrliste](einwilligung-abmelden-und-die-sperrliste.md) | 45 Minuten | Sich auf der öffentlichen Seite abmelden, einen Eintrag in die Sperrliste aufnehmen |

## Dieses Modul vorbereiten

- [ ] Alle Transporte schreiben Dateien (Lektion 1.2), am Kurstag erneut geprüft.
- [ ] Die Teilnehmenden können `var/log/mail` lesen: Shell-Zugang oder eine Möglichkeit für den Trainer, die Dateien
      am Beamer zu zeigen.
- [ ] Das öffentliche Anmeldeformular zeigt die Listen der Teilnehmenden (die Listen erlauben das Abonnieren im
      öffentlichen Siteaccess).
- [ ] Anonyme Benutzer haben im öffentlichen Siteaccess die Richtlinien `newsletter/subscribe`, `configure` und
      `unsubscribe`.
- [ ] Ein Texteditor auf dem Rechner jeder Person für die CSV-Datei aus Lektion 3.3.
- [ ] Die Regel ist angekündigt: nur Adressen unter `example.invalid`, keine echten Abonnentendateien.

# Modul 6: Templates und Skins

Im letzten Modul geht es um das Aussehen eines Newsletters. Redakteure vergleichen die mitgelieferten Skins und lernen
die Platzhalter; Designer und Entwickler schreiben einen eigenen Skin. Jede Prüfung ist eine Vorschau oder ein Test,
der in eine Datei geschrieben wird.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Newsletter mit CJW Newsletter](../README.md) |
| Dauer | 1 Stunde 45 Minuten |
| Lektionen | 2 |
| Niveau | Fortgeschrittene bis Experten |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [6.1 Skins und Ausgabeformate](skins-und-ausgabeformate.md) | 45 Minuten | Die Skins vergleichen, Platzhalter einfügen, Vorschau als Abonnent |
| [6.2 Einen eigenen Skin schreiben](einen-eigenen-skin-schreiben.md) | 60 Minuten | Einen Skin in das eigene Design kopieren, registrieren, in einer Testdatei prüfen |

## Dieses Modul vorbereiten

- [ ] `TransportMethodPreview=file` erneut in der Einstellungsansicht geprüft.
- [ ] Für Lektion 6.2: Jeder Designer hat eine eigene Schulungsinstallation mit einem eigenen Design, das im
      öffentlichen Siteaccess aktiv ist, und Shell-Zugang.
- [ ] Jede Person hat eine ungesendete Ausgabe und einen Abonnenten mit Vornamen (Dora aus Lektion 3.3).
- [ ] Redakteure, die keine Templates schreiben, können nach Lektion 6.1 gehen oder Lektion 6.2 am Beamer verfolgen.

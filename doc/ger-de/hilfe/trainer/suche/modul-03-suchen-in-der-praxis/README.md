# Modul 3: Suchen in der Praxis

Dieses Modul setzt die Suchmaschine dort ein, wo sie genutzt wird: in der Schnellsuche und der erweiterten Suche der
Administration, im Inhaltsfinder für IDs und Adressen, in der Suche der öffentlichen Website für Besucher und in den
Statistiken, die zeigen, wonach Besucher gesucht haben.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Suche](../README.md) |
| Dauer | 2 Stunden (vier Lektionen) |
| Lektionen | 4 |
| Niveau | Fortgeschrittene |
| Form | Praxis in der Administration und auf der öffentlichen Website; kurze Terminalarbeit in Lektion 3.4 |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [3.1 Die Admin-Suche und die erweiterte Suche](die-admin-suche-und-erweiterte-suche.md) | 30 Min. | Mit Suchbereich, Ausdruck, Klasse, Klassenattribut, Sektion und Datum suchen |
| [3.2 Der Inhaltsfinder](der-inhaltsfinder.md) | 30 Min. | Objekte über ID, Adresse und Dateipfad finden; Versionen, Orte und Papierkorbeinträge lesen |
| [3.3 Website-Suche für Besucher](website-suche-fuer-besucher.md) | 30 Min. | Als Besucher suchen und `content/search` mit seinen Parametern gestalten |
| [3.4 Suchstatistiken](suchstatistiken.md) | 30 Min. | Suchbegriffe aufzeichnen, lesen, darauf reagieren und zurücksetzen |

## Dieses Modul vorbereiten

- Eine Schulungsinstallation pro Person mit Beispielinhalten, einem Administratorkonto und der öffentlichen Website,
  erreichbar in einem privaten Browserfenster.
- Prüfen Sie, dass das öffentliche Design ein Suchfeld hat; wenn nicht, bereiten Sie die Adresse `content/search` für
  Lektion 3.3 vor.
- Stellen Sie sicher, dass der Papierkorb jeder Schulungsinstallation für Lektion 3.2 mindestens ein Element enthält
  (legen Sie vor dem Kurs ein Beispielelement in den Papierkorb).
- Verwenden Sie im Kurs nie die Suchstatistiken einer Live-Website: Sie können personenbezogene Daten enthalten.

# Modul 4: Collections

Listenblöcke erwecken ein Layout zum Leben: Sie zeigen die Inhalte der Website und halten sie aktuell. Dieses Modul
vermittelt die beiden Arten von Collections und die Einstellungen, die sie zu redaktionellen Werkzeugen machen.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Layouts](../README.md) |
| Dauer | 2 Stunden 40 Minuten (mit 10 Minuten Pause) |
| Lektionen | 3 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 4.1: Listenblöcke und manuelle Collections](listenbloecke-und-manuelle-collections.md) | 45 Minuten | Drei Artikel in einen List-Block auswählen, ordnen und den Ansichtstyp ändern |
| [Lektion 4.2: Dynamische Collections und Abfragetypen](dynamische-collections-und-abfragen.md) | 60 Minuten | Eine Liste der neuesten Artikel mit Abfrage, Filter und Sortierung bauen |
| [Lektion 4.3: Offset, Limit und Anheften](offset-limit-und-anheften.md) | 45 Minuten | Einen Aufmacher mit Liste bauen und ein Element anheften |

## Dieses Modul vorbereiten

- Ein Ordner auf der Schulungs-Website mit mindestens zehn veröffentlichten Artikeln (die Kursordner der
  Teilnehmenden aus Redakteure 101 eignen sich) und drei benannte Artikel für Lektion 4.1.
- Probieren Sie den Collection-Bereich Ihrer Installation einmal aus: Notieren Sie, wie ein Block zwischen manuell und
  dynamisch wählt, welche Abfragetypen er auflistet und wie Positionen nummeriert werden, damit Sie es am Beamer zeigen
  können.

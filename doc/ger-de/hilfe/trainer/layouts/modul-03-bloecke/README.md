# Modul 3: Blöcke

Das praktische Herzstück des Kurses. Die Teilnehmenden füllen ihr Kurs-Layout mit Blöcken jeder grundlegenden Art und
üben die Handgriffe im Editor, bis sie Routine sind.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Layouts](../README.md) |
| Dauer | 3 Stunden 10 Minuten (mit 10 Minuten Pause) |
| Lektionen | 4 |
| Niveau | Einsteiger bis Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 3.1: Blöcke hinzufügen, verschieben und entfernen](bloecke-hinzufuegen-verschieben-und-entfernen.md) | 45 Minuten | Blöcke hinzufügen, auswählen, ziehen, duplizieren und löschen |
| [Lektion 3.2: Textblöcke: Title, Text, Rich text, Markdown und HTML](textbloecke.md) | 45 Minuten | Einen Titel, einen Rich-Text- und einen Markdown-Block füllen |
| [Lektion 3.3: Schaltflächen, Bilder und der Tab Design](schaltflaechen-bilder-und-der-design-tab.md) | 45 Minuten | Eine Schaltfläche und ein Bild hinzufügen, Blöcke benennen, eine Theme-Klasse anwenden |
| [Lektion 3.4: Container und der Full-view-Block](container-und-der-full-view-block.md) | 45 Minuten | Eine Zone in Spalten teilen, einen Full-view-Block hinzufügen |

## Dieses Modul vorbereiten

- Das Kurs-Layout jeder Person aus Modul 2.
- Zwei oder drei CSS-Klassen des Themes der Schulungs-Website, die einen Block sichtbar verändern (ein Hintergrund,
  ein Abstand), für Lektion 3.3 an die Tafel geschrieben.
- Eine Bildadresse aus der Medienbibliothek der Schulungs-Website für Lektion 3.3 und eine `https://`-Adresse für
  Links.
- Öffnen Sie jeden Blocktyp auf Ihrer Schulungsinstallation einmal und notieren Sie die genauen Feldnamen seines Tabs
  **Inhalt**; sie stammen von den Block-Handlern und können sich zwischen Versionen unterscheiden.

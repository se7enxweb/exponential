# Modul 2: Layouts und Layout-Typen

Die Teilnehmenden wählen einen Typ, legen ihr eigenes Kurs-Layout an und lernen, eine wachsende Liste von Layouts in
Ordnung zu halten. Das hier angelegte Layout wird in jedem späteren Modul verwendet.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Layouts](../README.md) |
| Dauer | 2 Stunden 10 Minuten (mit 10 Minuten Pause) |
| Lektionen | 3 |
| Niveau | Einsteiger |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 2.1: Layout-Typen und ihre Zonen](layout-typen-und-zonen.md) | 30 Minuten | Layout-Typen für drei Seiten wählen |
| [Lektion 2.2: Ein Layout anlegen](ein-layout-erstellen.md) | 45 Minuten | Ein Kurs-Layout vom Typ `layout_2` anlegen und den Editor kennenlernen |
| [Lektion 2.3: Layouts verwalten: Vorschau, Kopieren, Export und Löschen](layouts-verwalten.md) | 45 Minuten | Vorschau ansehen, eine Kopie anlegen und löschen; Export und Import lesen |

## Dieses Modul vorbereiten

- Die Rolle der Teilnehmenden braucht edit auf den Layouts-Modulen; für die Export- und Import-Bildschirme in
  Lektion 2.3 die Transfer-Richtlinien (oder führen Sie sie vor).
- Vereinbaren Sie das Namensmuster: Name `Training - <Vorname>`, Bezeichner `training_<Vorname>`.
- Finden Sie heraus, wo der Editor Ihrer Installation das Kopieren eines Layouts anbietet, um es in Lektion 2.3 zu
  zeigen.

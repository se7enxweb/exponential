# Modul 5: Gemeinsame Layouts und Zonenverknüpfung

Eine Kopfzeile, eine Fußzeile, viele Seiten. Dieses Modul zeigt, wie Layouts Zonen von gemeinsamen Layouts
übernehmen und wie man gemeinsame Inhalte ohne Überraschungen ändert.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Layouts](../README.md) |
| Dauer | 2 Stunden 10 Minuten (mit 10 Minuten Pause) |
| Lektionen | 3 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 5.1: Was gemeinsame Layouts sind](was-gemeinsame-layouts-sind.md) | 30 Minuten | Den Bildschirm Gemeinsame Layouts lesen, verknüpfte Zonen erkennen |
| [Lektion 5.2: Zonen verknüpfen und trennen](zonen-verknuepfen-und-trennen.md) | 45 Minuten | Kopf- und Fußzeile des Kurs-Layouts verknüpfen, eine Verknüpfung ändern und entfernen |
| [Lektion 5.3: Gemeinsame Inhalte sicher ändern](gemeinsame-inhalte-sicher-aendern.md) | 45 Minuten | Ein gemeinsames Schulungs-Layout einmal ändern und sehen, wie jedes verknüpfte Layout folgt |

## Dieses Modul vorbereiten

- Ein veröffentlichtes gemeinsames Kopf-/Fußzeilen-Layout auf der Schulungs-Website (die Beispieldaten haben meist
  eines; der Bildschirm **Gemeinsame Layouts** listet es auf).
- Für Lektion 5.3 ein eigenes veröffentlichtes gemeinsames Layout `Training footer` (Typ `layout_1`, ein Rich-text-Block),
  damit niemand an der echten Fußzeile übt. Finden Sie heraus, wie Ihre Installation ein neues Layout als gemeinsam
  kennzeichnet (die Option **Gemeinsames Layout** im Anlegeformular, wo es sie gibt); siehe
  [Gemeinsame Layouts: Bauen](../../../../../eng-us/help/creators/website-creators/shared-header-and-footer.md#build-it).
- Die Kurs-Layouts der Teilnehmenden aus den Modulen 2 bis 4.

# Modul 7: Zuordnungsregeln

Zuordnungen entscheiden, welche Seite welches Layout bekommt. Dieses Modul vermittelt, wie man sie liest, anlegt und
herausfindet, warum eine Seite nicht wie erwartet aussieht.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Layouts](../README.md) |
| Dauer | 2 Stunden 40 Minuten (mit 10 Minuten Pause) |
| Lektionen | 3 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 7.1: Layout-Zuordnungen lesen](layout-zuordnungen-lesen.md) | 45 Minuten | Zuordnungen lesen und herausfinden, welche zwei Seiten bedient |
| [Lektion 7.2: Eine Zuordnung anlegen](eine-zuordnung-erstellen.md) | 60 Minuten | Das Kurs-Layout der eigenen Testseite zuordnen, die Zuordnung deaktivieren und aktivieren |
| [Lektion 7.3: Fehlersuche: welches Layout eine Seite bekommt](fehlersuche-welches-layout-eine-seite-bekommt.md) | 45 Minuten | Einen Fehler finden und beheben, den der Trainer eingebaut hat |

## Dieses Modul vorbereiten

- Alle Teilnehmenden brauchen ein veröffentlichtes Kurs-Layout (in Modul 6 veröffentlicht) und eine veröffentlichte Testseite `Layout test - <Vorname>` in ihrem Kursordner.
- Die Rolle der Teilnehmenden braucht edit auf `explayouts_ui` für die Zuordnungsbildschirme.
- Bereiten Sie für Lektion 7.3 pro Person einen Fehler vor, wie in der Lektion aufgeführt, und pro Person eine Karte,
  die ihn benennt.
- Wissen Sie, wie auf der Schulungsinstallation nach einer Zuordnungsänderung die Caches geleert werden (automatisches
  Leeren durch den Editor, das Cache-Leeren der Zuordnung oder ein Administrator).

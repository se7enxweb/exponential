# Modul 8: Abschlussprojekt

Der Kurs endet mit einer echten Seite: einer Kampagnen-Landingpage, auf Papier geplant, von einer anderen Person
geprüft, dann ohne Schritt-für-Schritt-Hilfe gebaut, veröffentlicht und zugeordnet.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Layouts](../README.md) |
| Dauer | 2 Stunden 25 Minuten (mit 10 Minuten Pause) |
| Lektionen | 2 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 8.1: Eine Landingpage planen](eine-landingpage-planen.md) | 45 Minuten | Die Seite auf einem Planungsblatt planen; den Plan einer anderen Person prüfen |
| [Lektion 8.2: Abschlussprojekt: eine Kampagnenseite bauen](eine-kampagnenseite-bauen.md) | 90 Minuten | Die Seite bauen, veröffentlichen und zuordnen; anhand einer Checkliste prüfen |

## Dieses Modul vorbereiten

- Drucken Sie die Aufgabenbeschreibung, das Planungsblatt und die Checkliste aus, je eines pro Person.
- Legen Sie im Kursordner jeder Person eine veröffentlichte Inhaltsseite `Autumn campaign - <Vorname>` an, oder planen
  Sie fünf Minuten ein, in denen die Teilnehmenden sie anlegen.
- Ein Ordner mit mindestens zehn veröffentlichten Artikeln für die dynamische Liste und drei Artikel, die als
  Highlights ausgewählt werden.
- Das gemeinsame Kopf-/Fußzeilen-Layout aus Modul 5 und eine Liste der CSS-Klassen des Themes.

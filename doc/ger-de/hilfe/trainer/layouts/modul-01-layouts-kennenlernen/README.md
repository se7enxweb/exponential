# Modul 1: Exponential Layouts kennenlernen

Bevor jemand einen Block zieht, brauchen die Teilnehmenden das Gesamtbild und die Regeln. Dieses Modul vermittelt
beides und führt durch die Bildschirme, ohne etwas zu ändern.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Exponential Layouts](../README.md) |
| Dauer | 1 Stunde 45 Minuten |
| Lektionen | 3 |
| Niveau | Einsteiger |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 1.1: Die fünf Grundideen von Exponential Layouts](die-fuenf-ideen.md) | 30 Minuten | Eine Seite als Zonen, Blöcke, Collections und eine Regel skizzieren |
| [Lektion 1.2: Sich zurechtfinden: das Dashboard und der Editor](sich-zurechtfinden.md) | 45 Minuten | Das Dashboard, die Listen, eine Vorschau und eine Zuordnung lesen |
| [Lektion 1.3: Wer was mit Layouts tun darf](rollen-und-berechtigungen.md) | 30 Minuten | Die Kursrolle lesen, zwei Rollen entwerfen, Teamregeln vereinbaren |

## Dieses Modul vorbereiten

- Eine Schulungsinstallation mit aktiven Layouts-Erweiterungen und einigen Layouts mit Zuordnungen (Beispiel-Layouts
  oder ein paar, die Sie vor dem Kurs bauen). Die öffentliche Startseite sollte mit einem Layout gebaut sein.
- Ein Konto pro Teilnehmerin oder Teilnehmer mit einer Rolle, die **read** und **edit** auf `explayouts`,
  `explayouts_ui` und `explayouts_ui_api` hat; die Teilnehmenden arbeiten in der Administration, nicht im
  Editor-Siteaccess.
- Melden Sie sich mit einem Teilnehmerkonto an und prüfen Sie, dass der Reiter **Layouts** und **Neues Layout**
  erscheinen.

# Lektion 1.1: Die fünf Grundideen von Exponential Layouts

Exponential Layouts ist der Seitenbaukasten von Exponential: Redakteure stellen Seiten im Browser aus Blöcken zusammen,
ohne Entwickler. Alles darin beruht auf fünf Grundideen. Wer sie verstanden hat, findet den Editor einfach; wer nicht,
fragt immer wieder, warum sich die eigene Seite nicht geändert hat. Diese erste Lektion liefert das Gesamtbild, ohne
Rechner.

> **Hinweis**
> Verwenden Sie für jede Übung dieses Kurses eine Schulungsinstallation. Eine Layout-Änderung kann viele Seiten einer
> Live-Website auf einmal verändern.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- **Layout**, **Zone**, **Block**, **Collection** und **Regel** (Zuordnung) in eigenen Worten erklären;
- sagen, welche der fünf entscheidet, was auf einer Seite erscheint, und welche, auf welchen Seiten;
- den Inhalt (Elemente im Baum) von der Anordnung (dem Layout) unterscheiden;
- eine Seite als Zonen mit Blöcken skizzieren.

## Hinweise für Trainer

### So präsentieren Sie es

Quellen: [Der Layout-Editor](../../../layout-editor.md#layouts-zonen-und-blöcke) und
[Landingpages mit dem Layout-Editor](../../../../../eng-us/help/creators/website-creators/landing-pages-with-layouts.md#the-five-ideas).

1. **Layout** (3 Minuten). Ein benannter Plan einer Seite, beruhend auf einem **Layout-Typ**, der ihre Zonen festlegt;
   der Typ lässt sich später nicht ändern. Beispiel: *Landing Page / Home*.
2. **Zone** (3 Minuten). Ein benannter Bereich eines Layouts: *main*, *sidebar*, *header*, *footer*. Eine Zone enthält
   Blöcke oder ist mit einer Zone eines gemeinsamen Layouts **verknüpft** (Modul 5).
3. **Block** (4 Minuten). Ein Baustein in einer Zone: ein Titel, ein Text, ein Bild, eine Schaltfläche, eine Liste von
   Artikeln, ein Hero-Banner. Ein Block hat einen Typ, einen Ansichtstyp (seine Form) und Einstellungen.
4. **Collection** (3 Minuten). Der Inhalt, den ein Listenblock zeigt: **manuell** (von Hand ausgewählt) oder
   **dynamisch** (eine Abfrage, etwa „die sechs neuesten Artikel in News“).
5. **Regel** (3 Minuten). Auch **Zuordnung** genannt: Sie entscheidet, welche Seiten welches Layout bekommen, über
   Ziele (eine Seite, einen Teil des Baums) und Bedingungen (einen Inhaltstyp, einen Siteaccess), mit der höchsten
   Priorität zuerst. Ein Layout bewirkt nichts, solange keine Regel darauf zeigt.
6. **Der Merksatz** (2 Minuten). Schreiben Sie ihn an die Tafel: *Eine Regel entscheidet, dass diese Anfrage jenes
   Layout bekommt; die Zonen des Layouts enthalten Blöcke; ein Block kann eine Collection besitzen, die seinen Inhalt
   liefert.*
7. **Inhalt bleibt Inhalt** (2 Minuten). Artikel, Bilder und Ordner liegen weiterhin im Inhaltsbaum und werden wie in
   Redakteure 101 bearbeitet. Ein Layout ordnet sie an; ein **Full-view**-Block zeigt den eigenen Inhalt der Seite
   innerhalb eines Layouts.

### Häufige Fragen

**Brauche ich für jede Seite Layouts?** Nein. Seiten ohne passende Regel werden wie bisher von den Templates der
Website dargestellt. Layouts eignen sich für Startseiten sowie Landing- und Kampagnenseiten, die sich oft ändern.

**Ist ein Layout dasselbe wie ein Template?** Nein. Templates sind Dateien, die ein Entwickler schreibt; ein Layout
sind Daten, die ein Redakteur im Browser anordnet.

**Was ist aus der alten Art geworden, Landingpages zu bauen?** Manche Websites nutzen noch den älteren Seitenbaukasten
früherer Versionen; Exponential Layouts ist der aktuelle. Welchen eine Website verwendet, entscheiden die
Website-Ersteller.

### Stolperfallen

- **Direkt in den Editor springen.** Wer dieses Gesamtbild überspringt, legt Layouts an, die nie angezeigt werden
  (keine Regel). Bestehen Sie zuerst auf den fünf Grundideen.
- **„Zuordnung“ und „Regel“.** Die Bildschirme verwenden beide Wörter. Sagen Sie einmal, dass sie dasselbe bedeuten.
- **Zu viel versprechen.** Layouts ordnen Inhalte an; sie ersetzen weder den Inhaltsbaum noch die Templates einer
  Website.

## Praktische Übung

Verwenden Sie Papier und die öffentliche Website der Schulungsinstallation.

1. Öffnen Sie die Startseite der Schulungs-Website.
2. Zeichnen Sie die Seite auf Papier als Kästen: Welche Bereiche sehen Sie (Kopfzeile, ein großes Banner, Spalten,
   eine Fußzeile)?
3. Beschriften Sie jeden Kasten als Zone: Geben Sie ihm einen kurzen Namen wie `header`, `main` oder `footer`.
4. Listen Sie in jeder Zone die Bausteine auf, die Sie sehen, einen unter dem anderen: Das sind Blöcke. Schreiben Sie
   zu jedem einen Typ (Titel, Text, Bild, Liste ...).
5. Markieren Sie die Blöcke, die eine Liste von Artikeln zeigen: Schreiben Sie „Collection“ daneben und raten Sie, ob
   die Liste von Hand ausgewählt oder automatisch aktualisiert wird.
6. Schreiben Sie einen Satz, der die Regel für diese Seite wäre, zum Beispiel „die Startseite der Website bekommt
   dieses Layout“.
7. Vergleichen Sie Ihre Zeichnung mit der Ihres Nachbarn.

## Erwartetes Ergebnis

- Alle Teilnehmenden haben eine Skizze mit drei bis fünf Zonen, Blöcken darin, mindestens einer Collection und einem
  Regelsatz.
- Der Trainer zeigt das echte Layout der Startseite im Editor am Beamer (Modul 2) und vergleicht es mit zwei Skizzen.

## Quiz

1. Was legt ein Layout-Typ fest?
   A. Die Farben B. Die Zonen C. Die Regeln D. Den Inhalt
2. Was entscheidet, auf welchen Seiten ein Layout verwendet wird?
3. Was ist der Unterschied zwischen einer manuellen und einer dynamischen Collection?
4. Richtig oder falsch: Der Text eines Artikels wird im Layout gespeichert.
5. Ergänzen Sie den Satz: Eine Regel entscheidet, dass diese Anfrage jenes ... bekommt; die ... des Layouts enthalten
   Blöcke.

<details>
<summary>Antworten</summary>

1. **B.** Der Typ legt die Zonen fest und lässt sich später nicht ändern
   ([Landingpages mit dem Layout-Editor](../../../../../eng-us/help/creators/website-creators/landing-pages-with-layouts.md#the-five-ideas)).
2. Eine Regel (Zuordnung), über ihre Ziele, Bedingungen und Priorität.
3. Manuell: von Hand ausgewählte Elemente. Dynamisch: eine Abfrage, die die Elemente findet, wenn die Seite angezeigt
   wird.
4. **Falsch.** Der Text bleibt im Inhaltselement; das Layout ordnet ihn an.
5. Layout; Zonen.

</details>

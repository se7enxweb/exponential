# Lektion 6.1: Einen Entwurf veröffentlichen, behalten und verwerfen

Alles, was die Teilnehmenden bisher getan haben, blieb in Entwürfen. Diese Lektion bringt das Kurs-Layout live und
vermittelt jeden Weg aus dem Editor heraus, damit niemand versehentlich veröffentlicht und niemand die Arbeit eines
ganzen Vormittags verliert.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- erklären, dass der Editor immer an einem Entwurf arbeitet, der laufend gespeichert wird, und dass Besucher nur
  veröffentlichte Layouts sehen;
- zwischen **Layout veröffentlichen**, **Veröffentlichen und weiter bearbeiten**, **Entwurf speichern und schließen**,
  **Verwerfen** und **Abbrechen** wählen;
- die Cache-Frage nach dem Veröffentlichen beantworten;
- beim Öffnen eines Layouts einen vorhandenen Entwurf fortsetzen oder einen neuen beginnen.

## Hinweise für Trainer

### So präsentieren Sie es

Quellen: [Der Layout-Editor: Veröffentlichen, behalten oder wegwerfen](../../../layout-editor.md#veröffentlichen-behalten-oder-verwerfen) und
[Exponential Layouts: Entwürfe, Veröffentlichen und Versionen](../../../../../eng-us/bc/6.0/LAYOUTS.md#drafts-publishing-and-versions).

1. **Entwürfe** (3 Minuten). Wer ein veröffentlichtes Layout öffnet, legt einen Entwurf davon an. Änderungen werden
   laufend im Entwurf gespeichert; einen eigenen Speicherschritt gibt es nicht. Die Website zeigt weiter das
   veröffentlichte Layout, bis Sie veröffentlichen.
2. **Die Wege hinaus** (5 Minuten):

   | Schaltfläche | Was sie tut |
   |---|---|
   | **Layout veröffentlichen** | Veröffentlicht den Entwurf und schließt den Editor; Seiten, die das Layout verwenden, zeigen es |
   | **Veröffentlichen und weiter bearbeiten** (Menü mit drei Punkten) | Veröffentlicht und lässt den Editor mit einem neuen Entwurf geöffnet |
   | **Entwurf speichern und schließen** (Menü mit drei Punkten) | Behält den Entwurf für später; das veröffentlichte Layout bleibt unverändert |
   | **Verwerfen** | Wirft den Entwurf weg, nachdem **Discard changes** gefragt hat *Are you sure you want to discard your changes to the layout draft?*; **Cancel** in diesem Dialog behält ihn |
   | **Abbrechen** | Verlässt den Editor; der Entwurf bleibt |

   Wer die Seite auf andere Weise verlässt, wird möglicherweise gefragt *There could be unsaved changes. Are you sure
   you want to leave?*
3. **Caches** (3 Minuten). Wo eine Website ihre Caches nach dem Veröffentlichen nicht selbst leert, fragt der Editor:
   *Automatic cache clear for this site is turned off. Do you want to clear caches after publish?* Wählen Sie **Clear
   caches**, damit Besucher die Änderung sehen; **Do not clear caches** lässt zwischengespeicherte Seiten bestehen, bis
   sie ablaufen.
4. **Ein Layout mit Entwurf öffnen** (2 Minuten). Wenn ein Entwurf existiert, fragt der Editor möglicherweise, ob Sie
   ihn fortsetzen (**Edit existing**) oder aus dem veröffentlichten Layout einen **New draft** beginnen möchten.
   Entwürfe gehören zum Layout, nicht zu einer Person: Der Entwurf einer anderen Person ist gemeinsame Arbeit.

### Häufige Fragen

**Löscht Verwerfen das Layout?** Nein. Es wirft den Entwurf weg; das veröffentlichte Layout bleibt. Ein Layout, das nie
veröffentlicht wurde, hat dann nichts mehr zu zeigen.

**Wann sollte ich Veröffentlichen und weiter bearbeiten verwenden?** Wenn eine erste Änderung jetzt live gehen muss
und Sie mit weiteren fortfahren.

**Warum sieht die Seite nach Layout veröffentlichen noch alt aus?** Zwischengespeicherte Seiten; oder die Seite wird
über eine andere Zuordnung ausgeliefert (Modul 7).

### Stolperfallen

- **Layout veröffentlichen bei einem gemeinsamen Layout.** Das ändert jede verknüpfende Seite. Prüfen Sie zweimal
  (Modul 5).
- **Verwerfen statt Abbrechen.** Verwerfen wirft Arbeit weg; Abbrechen behält den Entwurf. Lesen Sie den Dialog.
- **Zwei Personen, ein Layout.** Das **Verwerfen** der einen Person wirft die Änderungen der anderen im gemeinsamen
  Entwurf weg.

## Praktische Übung

Verwenden Sie die Schulungsinstallation und Ihr Kurs-Layout (mit den Blöcken aus den Modulen 3 bis 5).

1. Öffnen Sie Ihr Kurs-Layout mit **Öffnen**. Wenn der Editor fragt, wählen Sie **Edit existing**, um Ihren Entwurf
   fortzusetzen.
2. Prüfen Sie die Blöcke: Titel, Bild, Container mit Rich text und Schaltfläche, Full view, Listen, verknüpfte Kopf-
   und Fußzeile.
3. Klicken Sie auf **Layout veröffentlichen**. Wenn der Editor nach den Caches fragt, wählen Sie **Clear caches**.
4. Öffnen Sie das Layout erneut. Achten Sie darauf, ob der Editor nach einem vorhandenen Entwurf fragt (nach dem
   Veröffentlichen sollte er das nicht).
5. Ändern Sie den Titeltext, öffnen Sie das Menü mit drei Punkten und wählen Sie **Veröffentlichen und weiter
   bearbeiten**.
6. Ändern Sie den Titel noch einmal und klicken Sie dann auf **Verwerfen**. Lesen Sie **Discard changes** und klicken
   Sie im Dialog auf **Cancel**: Der Entwurf bleibt.
7. Klicken Sie erneut auf **Verwerfen** und bestätigen Sie diesmal. Der Editor schließt sich; der veröffentlichte
   Titel ist der aus Schritt 5.
8. Öffnen Sie das Layout, fügen Sie einen **Spacer**-Block hinzu und wählen Sie **Entwurf speichern und schließen**.
   Prüfen Sie mit **Vorschau** in der Liste **Layouts**, dass das veröffentlichte Layout keinen Spacer hat.
9. Öffnen Sie das Layout noch einmal, wählen Sie **Edit existing**, löschen Sie den Spacer und klicken Sie auf
   **Layout veröffentlichen**.

## Erwartetes Ergebnis

- Das Kurs-Layout ist mit dem Titel aus Schritt 5 und ohne Spacer veröffentlicht.
- Die Teilnehmenden haben jeden Weg hinaus genutzt: veröffentlichen, veröffentlichen und weiterarbeiten, verwerfen
  (abgebrochen und bestätigt), Entwurf speichern.
- Der Trainer prüft das, indem er die Vorschau der Layouts von zwei Teilnehmenden am Beamer zeigt.

## Quiz

1. Was zeigt die Website, während Sie an einem Entwurf arbeiten?
2. Welche Auswahl veröffentlicht und lässt den Editor geöffnet?
   A. **Layout veröffentlichen** B. **Veröffentlichen und weiter bearbeiten** C. **Entwurf speichern und schließen**
   D. **Abbrechen**
3. Was ist der Unterschied zwischen **Verwerfen** und **Abbrechen**?
4. Der Editor fragt nach dem Veröffentlichen, ob die Caches geleert werden sollen. Was wählen Sie, und warum?
5. Richtig oder falsch: Entwürfe gehören einer Person, deshalb können zwei Personen gefahrlos dasselbe Layout
   bearbeiten.

<details>
<summary>Antworten</summary>

1. Das veröffentlichte Layout ([Der Layout-Editor](../../../layout-editor.md#der-editor)).
2. **B.**
3. **Verwerfen** wirft den Entwurf weg (nach einer Bestätigung); **Abbrechen** verlässt den Editor und behält den
   Entwurf.
4. **Clear caches**, damit Besucher die Änderung sehen.
5. **Falsch.** Entwürfe gehören zum Layout; zwei Personen überschreiben sich gegenseitig.

</details>

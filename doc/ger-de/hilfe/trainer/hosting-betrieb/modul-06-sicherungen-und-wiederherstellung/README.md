# Modul 6: Sicherungen und Wiederherstellung

Sicherungen sind nur so viel wert, wie eine Wiederherstellung beweist. Dieses Modul vermittelt, was in eine Sicherung
einer Exponential-Website gehört, wie man die dokumentierten Regeln in eine Richtlinie überführt, wie man eine
vollständige Website in der richtigen Reihenfolge wiederherstellt und einen Wiederherstellungstest festhält und wie man
mit einer vollen Festplatte und einer Wiederherstellung bei einer Störung umgeht, ohne es schlimmer zu machen.

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [6.1 Was gesichert wird](was-gesichert-werden-muss.md) | 40 Min. | Eine Sicherung von Datenbank und Dateien in einem Fenster erstellen |
| [6.2 Eine Sicherungsrichtlinie und Aufbewahrung](sicherungsrichtlinie-und-aufbewahrung.md) | 35 Min. | Eine Richtlinientabelle für einen Hosting-Tarif schreiben |

## Dieses Modul vorbereiten

- Eine Schulungsinstallation pro Person mit Inhalten in einem Kursordner und mindestens einem Bild.
- Eine zweite Schulungsinstallation pro Person mit demselben Release und demselben Datenbanksystem für Lektion 6.3.
- Papier oder ein gemeinsames Dokument für den Workshop und die Planspielübung.
- Prüfen Sie den Speicherplatz auf den Schulungsrechnern: Eine Sicherung jeder Installation muss in
  `var/training-backup/` passen.

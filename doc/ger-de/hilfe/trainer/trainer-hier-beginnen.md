# Trainer: hier beginnen

Dieser Bereich der Hilfe ist für **Menschen, die Exponential unterrichten**: professionelle Trainer, Teamleiter, die
neue Redakteure einarbeiten, Berater, die eine Website an einen Kunden übergeben, Lehrkräfte, die Exponential im
Unterricht einsetzen, und Mitglieder der Community, die Workshops leiten. Er enthält vollständige Kurse aus Modulen und
Lektionen, die Sie so durchführen können, wie sie sind, in kürzere Einheiten aufteilen oder an Ihre Organisation
anpassen.

Jede Lektion ist für Trainer und Teilnehmende zugleich geschrieben: Lernziele, Hinweise für Trainer, eine praktische
Übung an einer echten Installation, das erwartete Ergebnis, ein Quiz mit Antworten und Links in den Rest der Hilfe.
Jede Angabe stammt aus dieser Dokumentation, aus dem Code oder aus einer echten Installation; wenn sich die Software
ändert, ändern sich die Lektionen mit.

> **Hinweis**
> Die Prüfungen in diesen Kursen sind Ihr Material als Trainer. Das Exponential-Partnerprogramm nennt
> Zertifizierungen für Partnerteams (Developer, Design, Solution, Sales), aber deren Lehrplan, Prüfungen und Prüfer
> sind nicht veröffentlicht ([Zertifizierungen](../partner/zertifizierungen.md)), und diese Kurse sind nicht diese
> Zertifizierungen. Geben Sie einen Kurs, eine Prüfung oder ein Zertifikat von Ihnen niemals als offizielle
> Zertifizierung aus.

## Wie ein Kurs aufgebaut ist

```text
Course    a course overview: who it is for, the modules, a reading path, schedules
  Module    a module overview: the lessons, preparing the module, a timing plan
    Lesson    one page: at a glance, objectives, trainer's notes, exercise, expected result, quiz, further reading
```

Jede Lektion hat eine Dauer, die ihre Übung einschließt, sodass der Zeitplan eines Moduls aufgeht. Die
[erste Lektion von Train the Trainer](train-the-trainer/modul-01-den-unterricht-vorbereiten/wie-diese-kurse-funktionieren.md)
erklärt den Aufbau im Detail.

## Die Regeln, die jeder Trainer einhält

1. **Unterrichten Sie am echten System.** Proben Sie jede Übung mit der Version, die Sie unterrichten. Wenn eine
   Lektion und die Software nicht übereinstimmen, hat die Software recht, und die Lektion wird korrigiert
   ([Diese Kurse anpassen und verbessern](train-the-trainer/modul-03-einen-kurs-gestalten/diese-kurse-anpassen-und-verbessern.md)).
2. **Verwenden Sie Schulungsinstallationen.** Niemals eine Live-Website, niemals echte Kundendaten, niemals ein
   gemeinsam genutztes Administratorkonto ([Sicher vorführen](train-the-trainer/modul-04-durchfuehren/sicher-vorfuehren.md)).
3. **Testkonten verwenden `example.invalid`.** Keine Übung darf E-Mails an eine echte Person senden.
4. **Verwenden Sie die richtigen Namen.** Das Produkt heißt Exponential; 7x ist das Unternehmen, das es führt; die
   Exponential Foundation ist die gemeinnützige Organisation; der alte Name ist Geschichte
   ([Namen und Geschichte im Unterricht](train-the-trainer/modul-01-den-unterricht-vorbereiten/namen-und-geschichte-im-unterricht.md)).
5. **Bleiben Sie barrierefrei und ehrlich.** Barrierefreie Materialien
   ([Modul 5](train-the-trainer/modul-05-barrierefreiheit-und-inklusion/README.md)) und kein Anspruch auf eine
   offizielle Zertifizierung ([Teilnahmebescheinigungen](train-the-trainer/modul-06-pruefung-und-nachbereitung/teilnahmebescheinigungen.md)).

## Diese Seiten wiederfinden

- Verwenden Sie im Hilfe-Center den Zielgruppenfilter **Trainer** oder die Kategorie **Schulung**, oder öffnen Sie
  **Alle Seiten** und den Ordner der Trainer.
- Jede Seite hat **Auf GitHub bearbeiten**: Wenn eine Lektion falsch ist oder sich ein Schritt geändert hat,
  korrigieren Sie sie für alle Trainer nach Ihnen.

**Schulung auf einer gemeinsamen Demo.** Eine Schulungsinstallation, bei der sich alle Teilnehmenden als
Administrator anmelden, kann im Demomodus laufen (`EXP_DEMO_MODE=1`), sodass niemand die anderen aussperren kann,
indem er das Passwort ändert; installieren Sie sie zwischen den Kursen neu. [Demomodus-FAQ](../demomodus-faq.md).

# Entwickler: Kursüberblick

Dieser Kurs bringt PHP-Entwicklern bei, auf Exponential aufzubauen. Jedes Modul fügt einer Entwicklungsinstallation,
die allen Teilnehmenden selbst gehört, ein funktionierendes Stück hinzu: Templates und Overrides, einen
Datentyp-Override, eine Fetch-Funktion, eine Modul-View mit eigener Richtlinie, eine Erweiterung mit Einstellungen,
einen Konsolenbefehl, eine Tabelle für persistente Objekte, ein Workflow-Ereignis, einen Cronjob-Teil, einen
REST-Provider und einen Test. Der Kurs endet mit den RAD-Werkzeugen, dem Deployment unter Velocity und einem Pull
Request.

## Für wen er gedacht ist

- PHP-Entwickler, die ihr erstes Exponential-Projekt beginnen.
- Entwickler in Agenturen, die Websites auf früheren Versionen pflegen und die Arbeitsweise von 6.x kennenlernen
  möchten.
- Entwickler, die Erweiterungen für andere schreiben werden.

**Ergebnis:** Nach dem Kurs kann ein Entwickler die Templates, das Inhaltsmodell und die Funktionen einer Website in
eigenen Erweiterungen bauen, sie testen, unter Velocity deployen und Änderungen an das Hauptprojekt zurückgeben.

## Format und Dauer

| | |
|---|---|
| Dauer | 52 Lektionen, etwa 44 Stunden Unterricht (mit Pausen etwa sieben Tage) |
| Format | Praxisorientiert; im Schulungsraum oder online; eine Entwicklungsinstallation pro Person |
| Niveau | Fortgeschrittene bis Experten |
| Voraussetzungen | PHP und objektorientierte Programmierung, Git, Composer, ein Terminal; ein GitHub-Konto für Modul 13 |
| Übungsumgebung | Eine Entwicklungsinstallation aus Git-Klonen auf SQLite, aufgebaut in Modul 1 ([Mit Git entwickeln](../../mit-git-entwickeln.md)) |

## Lesepfad

Für einen Trainer, der diesen Kurs vorbereitet, in dieser Reihenfolge:

1. [Trainer: hier beginnen](../trainer-hier-beginnen.md) und [Die Kernkonzepte vermitteln](../die-kernkonzepte-unterrichten.md).

3. Die Kapitel [3](../../../installation/03-den-code-beschaffen.md), [7](../../../installation/07-installation-ueber-die-konsole.md)
   und [8](../../../installation/08-die-website-ausliefern.md) des Installationsbuchs.

   [Templates und Design](../../../anleitungen/templates-und-design.md).

# Modul 13: RAD, Velocity und Mitwirken

Der Kurs endet mit drei Dingen, die eine Entwicklerin oder ein Entwickler im Alltag jede Woche verwendet: den
RAD-Werkzeugen, die Erweiterungscode schreiben und überblicken, dem Velocity-Deploy, der eine PHP-Änderung in der
richtigen Reihenfolge live bringt, und einem Pull Request, der eine Korrektur an das Projekt zurückgibt.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Entwickler](../README.md) |
| Dauer | 2 Stunden 30 Minuten (mit einer Pause von 10 Minuten) |
| Lektionen | 3 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 13.1: Die RAD-Werkzeuge](die-rad-werkzeuge.md) | 45 Minuten | Eine Operator-Erweiterung erzeugen, die Übersicht und die Zustandsprüfung lesen |
| [Lektion 13.2: Velocity für Entwickler](velocity-fuer-entwickler.md) | 45 Minuten | Engines, Neustart, `exp:velocity deploy` mit vorherigem Probelauf |
| [Lektion 13.3: Ein Pull Request](ein-pull-request.md) | 50 Minuten | Ein Zweig, ein fokussierter Commit, die Prüfungen, ein Push in einen Fork, die Beschreibung |

## Dieses Modul vorbereiten

- Administratorkonten für **Setup** > **RAD** (Richtlinie `setup/setup`).
- Für Schritt 7 von Lektion 13.2 zeigt eine Qbix-Engine auf einem Schulungsserver die Wirkung des Neustarts am
  besten; ohne sie zeigen Sie es am Projektor.
- Bitten Sie die Teilnehmenden für Lektion 13.3 vorab, ein kostenloses GitHub-Konto anzulegen, wenn sie einen echten
  Pull Request eröffnen möchten; alles bis zum Push funktioniert auch ohne.
- Sammeln Sie eine kurze Liste kleiner Verbesserungen an der Dokumentation, die den Teilnehmenden im Kurs aufgefallen
  sind; sie sind gute erste Pull Requests.

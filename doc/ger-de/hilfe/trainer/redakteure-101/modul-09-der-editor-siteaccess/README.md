# Modul 9: Der Siteaccess des Editors

Der Kurs endet dort, wo viele Redakteure jeden Tag arbeiten werden: im **Editor**, der Administration, die für sie
gemacht ist. Nach einem kurzen Vergleich mit der vollständigen Administration zeigen die Teilnehmenden in einer
Abschlussübung, was sie gelernt haben.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Redakteure 101](../README.md) |
| Dauer | 1 Stunde 30 Minuten |
| Lektionen | 2 |
| Niveau | Einsteiger |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 9.1: Arbeiten im Editor](arbeiten-im-editor.md) | 30 Minuten | Sich im Editor anmelden, ihn mit der Administration vergleichen, dort eine Änderung veröffentlichen |
| [Lektion 9.2: Abschluss, eine Seite von Anfang bis Ende](abschluss-eine-seite-von-anfang-bis-ende.md) | 60 Minuten | Allein einen vollständigen Artikel erstellen; anhand einer Checkliste prüfen |

## Dieses Modul vorbereiten

- Finden Sie die Adresse des Editors auf der Schulungsinstallation heraus (die Zusammenfassung von `exp:install` nennt
  den Siteaccess des Editors; üblich ist ein Host wie `edit.<host>` oder ein Pfad wie `/editor`). Hat die Installation
  keinen Editor, führen Sie Lektion 9.1 als Vorführung mit den Bildschirmfotos aus
  [Anmelden im Editor](../../../anmelden-im-editor.md) durch.
- Prüfen Sie, dass die Rolle der Teilnehmenden sich im Editor anmelden darf (die Richtlinie **user/login** für diesen
  Siteaccess).
- Drucken Sie die Aufgabenliste und die Checkliste von Lektion 9.2 aus, eine pro Teilnehmer.
- Ein neues neutrales Beispielbild pro Teilnehmer für die Abschlussübung.

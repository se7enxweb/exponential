# Modul 1: Anmelden und Rundgang

Das erste Modul führt neue Redakteure von „noch nie gesehen“ zu „ich weiß, wo die Dinge sind“. Es beginnt ohne
Computer, mit den fünf Ideen hinter allen späteren Lektionen, meldet dann alle mit ihrem eigenen Konto an und geht
einmal um den Bildschirm herum.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Redakteure 101](../README.md) |
| Dauer | 2 Stunden 20 Minuten (mit einer Pause von 10 Minuten) |
| Lektionen | 3 |
| Niveau | Einsteiger |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 1.1: Was Exponential für Redakteure ist](was-exponential-fuer-redakteure-ist.md) | 30 Minuten | Von Inhaltselementen, dem Baum, Entwürfen und Rollen hören; den Baum einer echten Website skizzieren |
| [Lektion 1.2: Anmelden und abmelden](anmelden-und-abmelden.md) | 45 Minuten | Sich mit einem Schulungskonto anmelden, die Fehlermeldungen kennenlernen, sich abmelden |
| [Lektion 1.3: Ein Rundgang über den Bildschirm](ein-rundgang-ueber-den-bildschirm.md) | 45 Minuten | Die Schaltflächen der Kopfzeile benennen, beide Spalten nutzen, Sprache der Oberfläche und Farbmodus ändern |

## Dieses Modul vorbereiten

- Eine Schulungsinstallation, die alle Teilnehmenden vom Kursraum aus erreichen, zum Beispiel eine, die mit
  `php bin/php/console exp:install` installiert wurde ([7. Die Installation über die Konsole](../../../../installation/07-installation-ueber-die-konsole.md)).
- Ein Konto pro Teilnehmer mit der Rolle **Editor**, E-Mail-Adressen unter `example.invalid`, auf Karten
  geschrieben; ein zusätzliches Konto mit derselben Rolle für Sie selbst, für den Projektor.
- Die Adresse der Administration (und des Editors, wenn die Installation einen hat) an der Tafel.
- Einige veröffentlichte Ordner und Artikel auf der Schulungs-Website, damit die Übung von Lektion 1.1 etwas zum
  Ansehen hat.
- Ein Browser auf jedem Rechner, der Cookies für die Schulungs-Website erlaubt.

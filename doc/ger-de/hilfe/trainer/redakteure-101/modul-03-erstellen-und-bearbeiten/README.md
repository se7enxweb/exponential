# Modul 3: Inhalte erstellen und bearbeiten

Das ist das Herzstück von Redakteure 101. Die Teilnehmenden erstellen ihren eigenen Kursordner, schreiben und
veröffentlichen darin Artikel, lernen das Bearbeitungsformular Teil für Teil kennen und schließen mit den Werkzeugen
für viele Elemente auf einmal ab. Jedes spätere Modul arbeitet in dem Ordner, der hier entsteht.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Redakteure 101](../README.md) |
| Dauer | 3 Stunden 35 Minuten (mit zwei Pausen von je 10 Minuten) |
| Lektionen | 4 |
| Niveau | Einsteiger |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 3.1: Ihren ersten Ordner erstellen](ihren-ersten-ordner-erstellen.md) | 45 Minuten | Einen persönlichen Kursordner erstellen und veröffentlichen |
| [Lektion 3.2: Ihren ersten Artikel erstellen](ihren-ersten-artikel-erstellen.md) | 60 Minuten | Einen Artikel erstellen, auf ein Pflichtfeld stoßen, ihn bis zu Version 2 bearbeiten |
| [Lektion 3.3: Das Bearbeitungsformular im Detail](das-bearbeitungsformular-im-detail.md) | 45 Minuten | Die Feldleiste, die linke Spalte, Entwurf speichern und beenden und die Fehlermeldungen nutzen |
| [Lektion 3.4: Viele Elemente auf einmal](viele-elemente-auf-einmal.md) | 45 Minuten | Zwei Artikel in einem Formular erstellen und gemeinsam bearbeiten |

## Dieses Modul vorbereiten

- Ein Ordner **Training** auf der Schulungs-Website, in dem die Rolle der Teilnehmenden Ordner und Artikel erstellen
  darf; testen Sie das mit einem Teilnehmerkonto.
- Prüfen Sie einmal das Artikelformular Ihrer Schulungsinstallation: Die Lektionen gehen von den Standardfeldern
  **Title**, **Short title**, **Author**, **Intro**, **Body**, **Enable comments** und **Image** aus. Notieren Sie
  Abweichungen an der Tafel.
- Hat die Website einen Freigabe-Workflow für die Gruppe der Teilnehmenden, schalten Sie ihn für dieses Modul ab oder
  verschieben Sie die Freigabe auf Redakteure 201: Sonst wartet jede Veröffentlichung unter **Meine Warteliste**.

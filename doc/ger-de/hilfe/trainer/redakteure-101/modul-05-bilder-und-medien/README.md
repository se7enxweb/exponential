# Modul 5: Bilder und Medien

Jede Website braucht Bilder und Dateien, und jedes Bild braucht einen guten Alternativtext. Dieses Modul zeigt, wo
Dateien liegen, wie man viele auf einmal hochlädt und wie ein Artikel sein Hauptbild bekommt.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Redakteure 101](../README.md) |
| Dauer | 2 Stunden 25 Minuten (mit einer Pause von 10 Minuten) |
| Lektionen | 3 |
| Niveau | Einsteiger |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 5.1: Die Medienbibliothek](die-medienbibliothek.md) | 30 Minuten | Die Ordner der Bibliothek erkunden, ein Bildelement und seine Verknüpfungen lesen |
| [Lektion 5.2: Die Upload-Seite](die-upload-seite.md) | 60 Minuten | Drei Bilder mit Titeln und Alternativtexten als Entwürfe hochladen und dann veröffentlichen |
| [Lektion 5.3: Bilder in Artikeln und Alternativtext](bilder-in-artikeln-und-alternativtext.md) | 45 Minuten | Ein vorhandenes Bild verknüpfen, eines aus dem Formular hochladen, seinen Alternativtext verbessern |

## Dieses Modul vorbereiten

- Vier kleine Beispielbilder pro Teilnehmer (neutrale Motive wie Landschaften oder Gegenstände, keine Personen), auf
  jedem Computer oder auf einem gemeinsamen Laufwerk. Halten Sie sie jeweils unter einigen Megabyte.
- Die Kursordner der Teilnehmenden müssen Bilder annehmen: Prüfen Sie, dass **Hochladen** bei einem Kursordner
  *Hochladen erlaubt* zeigt.
- Finden Sie heraus, wohin Ihre Schulungsinstallation Bilder legt, die aus dem Bearbeitungsformular hochgeladen
  werden, damit Sie es in Lektion 5.3 zeigen können.
- Wenn Sie den verpflichtenden Alternativtext zeigen möchten, schalten Sie vor dem Kurs auf der Schulungsinstallation
  **Alternativtext ist erforderlich** für das Bildfeld der Bildklasse ein
  ([wie](../../../../anleitungen/inhaltsmodell-und-bearbeitung.md#alternativtext-ist-erforderlich-bildfelder)).

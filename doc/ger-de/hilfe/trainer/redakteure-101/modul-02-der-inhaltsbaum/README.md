# Modul 2: Der Inhaltsbaum und die Navigation

Bevor Redakteure etwas ändern, müssen sie es finden. Dieses Modul macht die Teilnehmenden im Inhaltsbaum und auf der
Seite eines Elements heimisch. Nichts darin ändert Inhalte, daher ist es ein sicheres Modul, auch auf einer gemeinsam
genutzten Schulungs-Website.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Redakteure 101](../README.md) |
| Dauer | 2 Stunden 10 Minuten (mit einer Pause von 10 Minuten) |
| Lektionen | 3 |
| Niveau | Einsteiger |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 2.1: Der Baum und die Seite eines Elements](der-baum-und-die-seite-eines-elements.md) | 45 Minuten | Ordner und Elemente in beiden Bäumen öffnen, die Seite eines Elements lesen |
| [Lektion 2.2: Die Reiter eines Elements und seine Unterelemente](reiter-und-unterelemente.md) | 45 Minuten | Die Reiter nutzen, die Liste der Unterelemente sortieren und blättern, Spalten wählen |
| [Lektion 2.3: Schnell navigieren](schnell-navigieren.md) | 30 Minuten | Den Inhaltsfinder, das Menü eines Elements und die Tastatur nutzen |

## Dieses Modul vorbereiten

- Die Redakteurskonten der Teilnehmenden aus Modul 1.
- Auf der Schulungs-Website: mindestens ein Ordner mit zehn oder mehr Elementen (ein Bilderordner der
  Medienbibliothek eignet sich), ein Artikel mit bekannter Knotennummer und ein veröffentlichter Artikel, dessen
  Adresse die Teilnehmenden von der Website kopieren können.
- Schreiben Sie den Pfad des Bilderordners der Medienbibliothek an die Tafel, wenn er nicht `media/images` lautet.

## Zeitplan

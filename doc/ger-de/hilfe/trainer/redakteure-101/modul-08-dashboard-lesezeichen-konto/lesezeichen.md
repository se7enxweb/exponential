# Lektion 8.2: Lesezeichen

Die meisten Redakteure arbeiten immer wieder an denselben paar Dutzend Elementen. Lesezeichen halten sie einen Klick
entfernt. Sie sind persönlich: Niemand sonst sieht sie, und wer eines entfernt, ändert nie das Element. Diese Lektion
behandelt das Setzen von Lesezeichen, das Einsortieren in Ordner und das Wiederfinden.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- ein Lesezeichen mit **Lesezeichen setzen**, aus dem Menü eines Elements oder mit **Einträge hinzufügen** auf
  **Meine Lesezeichen** setzen;
- Lesezeichenordner anlegen und Lesezeichen hineinverschieben;
- ein Lesezeichen mit **Lesezeichen finden** suchen und die Reihenfolge der Liste ändern;
- die Kennzeichnungen *Versteckt*, *Nicht gefunden* und *Kein Zugriff* an einem Lesezeichen lesen;
- ein Lesezeichen im Link-Dialog des Online-Editors verwenden.

## Hinweise für Trainer

### So präsentieren Sie es

Quelle: [Lesezeichen](../../../../anleitungen/lesezeichen.md).

1. **Hinzufügen** (3 Minuten). **Lesezeichen setzen** im Kasten **Lesezeichen** der rechten Spalte setzt ein
   Lesezeichen auf das Element, das Sie gerade ansehen. Auch das Menü eines Elements im Baum setzt Lesezeichen. Auf
   **Meine Lesezeichen** öffnet **Einträge hinzufügen** einen Browser.
2. **Die Seite** (4 Minuten). Öffnen Sie **Dashboard** > **Meine Lesezeichen**: die Übersichtszahlen, **Ordner**,
   **Lesezeichen finden** mit dem Suchfeld und **Alle Lesezeichen**, eine Karte pro Lesezeichen, nach Ordner
   gruppiert, mit **Ansehen**, **Bearbeiten** (wenn Sie bearbeiten dürfen) und, in Ihrer eigenen Reihenfolge,
   **Nach oben** und **Nach unten**.
3. **Ordner** (4 Minuten). Geben Sie unter **Ordner** einen **Name** ein, wählen Sie unter **Innerhalb von**, wohin er
   kommt (*Kein Ordner (oberste Ebene)* für die oberste Ebene), und klicken Sie auf **Ordner anlegen**. Um Lesezeichen
   zu verschieben, kreuzen Sie sie an, wählen den Ordner und klicken auf **Verschieben**; mit der Maus können Sie ein
   Lesezeichen auch auf einen Ordner ziehen.
4. **Kennzeichnungen** (2 Minuten). **Versteckt** oder **Versteckt durch übergeordneten Eintrag**: Besucher sehen das
   Element nicht. **Nicht gefunden**: Es wurde entfernt, liegt im Papierkorb oder ist in keiner Sprache dieser Website
   vorhanden. **Kein Zugriff**: Sie dürfen es nicht mehr lesen.
5. **Lesezeichen an anderer Stelle** (2 Minuten). Der Reiter **Lesezeichen** des Link-Dialogs (Lektion 4.2) listet
   Ihre Lesezeichen auf, sodass Links auf häufig genutzte Elemente schnell gesetzt sind.

### Häufige Fragen

**Kann ich meine Lesezeichen mit einer Kollegin teilen?** Nein. Lesezeichen sind persönlich.

**Was passiert mit einem Lesezeichen, wenn sein Element entfernt wird?** Es bleibt und zeigt **Nicht gefunden**,
damit Sie es bemerken. Entfernen Sie das Lesezeichen, wenn Sie es nicht mehr brauchen.

**Wie sind Lesezeichen sortiert?** In Ihrer eigenen Reihenfolge (mit **Nach oben** und **Nach unten** festgelegt),
nach Name, zuletzt hinzugefügt, Typ oder zuletzt geändert. Sie bleiben immer nach Ordnern gruppiert.

### Stolperfallen

- **Das Element statt des Lesezeichens entfernen.** **Ausgewählte entfernen** auf **Meine Lesezeichen** entfernt nur
  Lesezeichen; die Schaltfläche **Entfernen** auf der Seite eines Elements entfernt das Element. Weisen Sie auf den
  Unterschied hin.
- **Lesezeichen für alles.** Eine Liste mit 200 Lesezeichen ist so langsam wie der Baum. Ermutigen Sie zu Ordnern nach
  Projekt.

## Praktische Übung

Verwenden Sie die Schulungsinstallation und Ihren Kursordner.

1. Öffnen Sie Ihren Kursordner. Klicken Sie im Kasten **Lesezeichen** der rechten Spalte auf **Lesezeichen setzen**.
2. Öffnen Sie *My first article* und setzen Sie auf dieselbe Weise ein Lesezeichen darauf.
3. Öffnen Sie im Baum das Menü des Ordners **Images** der Medienbibliothek und setzen Sie ein Lesezeichen darauf.
4. Öffnen Sie **Meine Lesezeichen** aus der linken Spalte des Dashboards. Lesen Sie die Übersichtszahlen.
5. Geben Sie unter **Ordner** `Course` unter **Name** ein, lassen Sie *Kein Ordner (oberste Ebene)* unter
   **Innerhalb von** stehen und klicken Sie auf **Ordner anlegen**.
6. Kreuzen Sie die Lesezeichen Ihres Kursordners und von *My first article* an, wählen Sie den Ordner **Course** und
   klicken Sie auf **Verschieben**.
7. Geben Sie unter **Lesezeichen finden** `first` ein und suchen Sie. Leeren Sie dann die Suche.
8. Klicken Sie auf **Einträge hinzufügen**, wählen Sie im Browser Ihren Artikel *News one (updated)* und bestätigen
   Sie.
9. Öffnen Sie *My first article* mit **Bearbeiten**, markieren Sie ein Wort in **Body**, klicken Sie auf die
   Link-Schaltfläche und öffnen Sie den Reiter **Lesezeichen** des Dialogs: Ihre Lesezeichen sind aufgelistet.
   Schließen Sie den Dialog und klicken Sie auf **Entwurf verwerfen**.

## Erwartetes Ergebnis

- **Meine Lesezeichen** zeigt vier Lesezeichen: zwei im Ordner **Course**, den Ordner **Images** und
  *News one (updated)* außerhalb davon.
- **Lesezeichen finden** hat *My first article* gefunden.
- Der Reiter **Lesezeichen** des Link-Dialogs hat die Lesezeichen der Teilnehmenden aufgelistet.
- Der Trainer prüft das, indem er eine Teilnehmerin oder einen Teilnehmer bittet, den Ordner **Course** auf dem
  Projektor zu zeigen.

## Quiz

1. Wer sieht Ihre Lesezeichen?
2. Nennen Sie zwei Wege, ein Lesezeichen zu setzen.
3. Ein Lesezeichen zeigt **Nicht gefunden**. Nennen Sie einen möglichen Grund.
4. Richtig oder falsch: **Ausgewählte entfernen** auf **Meine Lesezeichen** entfernt die Elemente mit Lesezeichen.
5. Wo erscheinen Ihre Lesezeichen außerdem, während Sie schreiben?

<details>
<summary>Antworten</summary>

1. Nur Sie ([Lesezeichen](../../../../anleitungen/lesezeichen.md#kurz-gesagt)).
2. Zwei beliebige von: **Lesezeichen setzen** in der rechten Spalte, das Menü eines Elements im Baum,
   **Einträge hinzufügen** auf **Meine Lesezeichen**.
3. Das Element wurde entfernt, liegt im Papierkorb oder ist in keiner Sprache dieser Website vorhanden.
4. **Falsch.** Nur die Lesezeichen werden entfernt.
5. Im Reiter **Lesezeichen** des Link-Dialogs des Online-Editors.

</details>

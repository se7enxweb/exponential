# Modul 8: Dashboard, Lesezeichen und Ihr Konto

Das Modul für den bequemen Alltag. Danach beginnen Redakteure ihren Tag auf dem Dashboard, erreichen ihre Elemente über
Lesezeichen und wissen, wie sie ihr Konto schützen und wie die Website sie über Änderungen informiert.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Redakteure 101](../README.md) |
| Dauer | 2 Stunden 10 Minuten (mit einer Pause von 10 Minuten) |
| Lektionen | 3 |
| Niveau | Einsteiger |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 8.1: Das Dashboard als täglicher Start](das-dashboard.md) | 30 Minuten | Jeden Block des Dashboards lesen und eine tägliche Routine aufschreiben |
| [Lektion 8.2: Lesezeichen](lesezeichen.md) | 45 Minuten | Lesezeichen setzen, in einen Ordner sortieren, finden, im Link-Dialog verwenden |
| [Lektion 8.3: Ihr Konto und Benachrichtigungen](ihr-konto-und-benachrichtigungen.md) | 45 Minuten | **Mein Konto**, die Passwortseite und die zweistufige Anmeldung erkunden, einem Element mit einer Zusammenfassung folgen |

## Dieses Modul vorbereiten

- Die Teilnehmenden brauchen die Inhalte aus den früheren Modulen, damit die Listen des Dashboards nicht leer sind.
- Entscheiden Sie, ob die Teilnehmenden in Lektion 8.3 ihre Schulungspasswörter ändern dürfen. Wenn nicht, klicken
  sie auf **Abbrechen**.
- Stellen Sie sicher, dass die Schulungsinstallation keine echten E-Mails sendet (Schulungskonten unter
  `example.invalid`).
- Setzen Sie nach dem Kurs die Schulungskonten zurück: Passwörter, zweistufige Anmeldung, Lesezeichen und
  Benachrichtigungseinstellungen.

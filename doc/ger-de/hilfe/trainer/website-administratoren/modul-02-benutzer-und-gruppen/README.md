# Modul 2: Benutzer und Gruppen

Wer sich anmelden darf, in welcher Gruppe, mit welchem Passwort, und was geschieht, wenn jemand geht: Dieses Modul
behandelt das ganze Leben eines Benutzerkontos. Die Teilnehmenden legen eine Gruppe und Konten mit Adressen unter
`example.invalid` an, setzen Passwörter zurück und entsperren Konten, räumen Konten auf, die niemand benutzt, und
übergeben Inhalte von einem Benutzer an einen anderen.

## Dieses Modul vorbereiten

- Die Schulungsinstallation aller Teilnehmenden aus Modul 1, mit einem Administratorkonto und einem Terminal im
  Wurzelverzeichnis.
- Prüfen Sie auf Ihrer eigenen Installation, welche Benutzergruppen das Seitenpaket anlegt und ob die öffentliche
  Website eine Registrierung anbietet (Lektion 2.4, Schritt 1); passen Sie die Übungen an, wenn es Abweichungen gibt.
- Prüfen Sie für Lektion 2.5, dass **Eigentümer ändern** im Kontextmenü steht (die Erweiterung ezownerchange ist aktiv).
- Eine Liste von Passwörtern mit mindestens 10 Zeichen für die Testkonten oder einen Passwortmanager pro Person.
- Jede Adresse in den Übungen liegt unter `example.invalid`. E-Mails bleiben auf einer Schulungsinstallation in
  Dateien.

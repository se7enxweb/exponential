# Modul 4: Sektionen, Siteaccesses und Objektzustände

Vier Konzepte ordnen eine Installation über den Inhaltsbaum hinaus: Sektionen gruppieren Inhalte nach Bereich,
Siteaccesses entscheiden, wie eine Anfrage die Website erreicht, Objektzustände gruppieren Inhalte nach Stadium, und
Inhaltssprachen enthalten die Übersetzungen. Dieses Modul behandelt jedes davon aus Sicht des Administrators, mit
einem Mitgliederbereich und einem kleinen Prüf-Workflow als Übungen.

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [4.1 Sektionen](sektionen.md) | 45 Min. | Eine Sektion anlegen, ihr einen Ordner zuweisen, sie für Mitglieder öffnen |
| [4.2 Siteaccesses für Administratoren](siteaccesses-fuer-administratoren.md) | 40 Min. | Die Siteaccesses, ihre Regeln und Unterschiede lesen |
| [4.3 Objektzustände](objektzustaende.md) | 45 Min. | Eine Prüfgruppe aufbauen, nicht freigegebene Inhalte vor Besuchern verbergen |
| [4.4 Inhaltssprachen](inhaltssprachen.md) | 40 Min. | Eine Sprache hinzufügen, einen Artikel übersetzen, SiteLanguageList lesen |

## Dieses Modul vorbereiten

- Die Schulungsinstallationen aus den Modulen 1 bis 3, mit den Benutzern `sam.sample` und `nina.news`, der Gruppe
  `Training team` und dem Ordner `News`.
- Proben Sie die Lektionen 4.1 und 4.3 auf Ihrer eigenen Installation: Beide ändern, was Besucher sehen, und bei
  beiden muss der Inhalts-Cache geleert werden, bevor sich das Ergebnis zeigt.
- Entscheiden Sie, ob die Teilnehmenden die Änderungen am Ende rückgängig machen (Lektion 4.3, Schritt 11, tut das);
  spätere Module setzen voraus, dass Besucher die Website lesen können.
- Wissen Sie für Lektion 4.2, wie Ihre Übungsumgebung installiert wurde (Zuordnung über URL, Host oder Port).

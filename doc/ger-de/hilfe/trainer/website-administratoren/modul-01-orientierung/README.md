# Modul 1: Orientierung als Website-Administrator

Bevor die Teilnehmenden etwas ändern, müssen sie wissen, wo sich was befindet und wie die Installation konfiguriert
ist. Dieses Modul gibt allen Teilnehmenden eine funktionierende Schulungsinstallation, einen Rundgang durch den
Setup-Bereich, eine Lektüre der Systeminformationen und die zwei Wege, INI-Einstellungen zu lesen und zu ändern: die
Einstellungsseite und `exp:ini`.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Website-Administration](../README.md) |
| Dauer | 2 Stunden 55 Minuten (fünf Lektionen) |
| Lektionen | 5 |
| Niveau | Fortgeschrittene |
| Format | Praktisch; eine Schulungsinstallation pro Person |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [1.1 Was ein Website-Administrator tut](was-ein-website-administrator-tut.md) | 30 Minuten | Eine Schulungsinstallation installieren und starten, sich anmelden |
| [1.2 Ein Rundgang durch den Setup-Bereich](ein-rundgang-durch-den-setup-bereich.md) | 35 Minuten | Setup-Seiten nach ihrem Zweck finden, eine als Lesezeichen speichern |
| [1.3 Systeminformationen und Zustandsprüfungen](systeminformationen-und-zustandspruefungen.md) | 35 Minuten | Zustandsprüfungen lesen, einen Bericht herunterladen, `exp:system:info` ausführen |
| [1.4 Die Einstellungsseite](die-einstellungsseite.md) | 40 Minuten | Eine Einstellung zurückverfolgen, Siteaccesses vergleichen, eine Einstellung ändern und entfernen |
| [1.5 INI-Dateien und exp:ini auf der Kommandozeile](ini-dateien-und-exp-ini.md) | 35 Minuten | Eine Einstellung mit `exp:ini` lesen, schreiben und entfernen |

## Dieses Modul vorbereiten

- Ein Rechner pro Person mit einem Terminal, PHP 8.1 oder neuer, Composer 2 und Git sowie dem Exponential-Code des
  Release, das Sie unterrichten (siehe [Die Installation über die Konsole](../../../../installation/07-installation-ueber-die-konsole.md)).
- Ist das Netzwerk langsam, bereiten Sie die Schulungsinstallationen vorab vor und starten Sie sie im Kurs nur noch.
- Ein ausgedrucktes Exemplar der [Kurzübersicht zur Übungsumgebung](../../kurzkarte-fuer-die-uebungsumgebung.md).
- Ihre eigene Schulungsinstallation am Beamer, genauso installiert wie die der Teilnehmenden.
- Prüfen Sie, dass **Setup** in Ihrer Version die in Lektion 1.2 genannten Gruppen zeigt; passen Sie die Übung an,
  wenn es Abweichungen gibt.

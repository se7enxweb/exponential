# Modul 4: Fünftägige Bootcamps

Eine Woche erlaubt Tiefe und ein echtes Abschlussprojekt. Diese Programme richten sich an Teams, die ein Projekt
beginnen, an Entwickler, die eines leiten werden, und an neue Trainer.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Workshops und Bootcamps](../README.md) |
| Bootcamps | 3 |
| Dauer | je 5 Tage, 6 Stunden Einheiten pro Tag |
| Niveau | Fortgeschrittene bis Experten |

## Bootcamps

| Bootcamp | Für | Abschlussprojekt |
|---|---|---|
| [4.1 Die Full-Stack-Entwicklerwoche](full-stack-entwicklerwoche.md) | Entwickler, die Projekte leiten | Eine Konferenz-Website in einer Erweiterung, unter Velocity ausgerollt |
| [4.2 Die Agentur-Einarbeitungswoche](agentur-einarbeitungswoche.md) | Ein ganzes Agenturteam | Eine gemeinsam gelieferte Microsite |
| [4.3 Die Trainerakademie-Woche](trainer-akademie-woche.md) | Neue Trainer | Lehrpraxis mit Feedback nach Bewertungsraster |

## Dieses Modul vorbereiten

- Ein Ablaufplan pro Tag; zwei Trainer für 4.2.
- Eine Installation pro Entwickler und Administrator, eine gemeinsame Website für die gemeinsame Arbeit.
- Die Aufgabenbeschreibung des Abschlussprojekts, ausgedruckt.

## Zeitplan

Jeder Tag: 9:00 bis 16:30 Uhr, zwei Blöcke zu je drei Stunden, zwei Pausen von 15 Minuten und 45 Minuten
Mittagspause. Der Nachmittag von Tag 5 ist immer für Begutachtung, Präsentationen und Feedback reserviert.

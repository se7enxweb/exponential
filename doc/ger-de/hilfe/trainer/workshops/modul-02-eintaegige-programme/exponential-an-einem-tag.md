# Agenda 2.5: Exponential an einem Tag (gemischte Gruppe)

Zum Projektstart kommt oft das ganze Team auf einmal: Redakteure, ein Administrator, Entwickler. Diese Agenda hält sie
am Vormittag zusammen, wo die Themen gemeinsam sind, und teilt sie am Nachmittag auf.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Workshops und Bootcamps](../README.md) |
| Modul | [Modul 2: Eintägige Agenden](README.md) |
| Dauer | 6 Stunden Einheiten (9:00 bis 16:30 mit Pausen und Mittagspause) |
| Niveau | Einsteiger |
| Zielgruppe | Ein Projektteam mit gemischten Rollen, 6 bis 18 Teilnehmende |
| Voraussetzungen | Eine Installation pro Person oder eine gemeinsame Website plus eine Installation pro Administrator und Entwickler; ein Trainer oder Helfer pro Nachmittagsstrang |

## Lernziele

Am Ende des Tages kann jede Person:

- die Kernkonzepte erklären (Objekt, Knoten, Version, Rolle, Siteaccess);
- einen Artikel anlegen, veröffentlichen und versionieren;
- den nächsten Schritt für ihre Rolle nennen;

und je nach Strang: Redakteure platzieren ein Bild und einen Link; Administratoren bauen eine Rolle; Entwickler
erstellen ein Override und machen es rückgängig.

## Hinweise für Trainer

- **Ein Trainer pro Nachmittagsstrang** oder Stationen, durch die die Teilnehmenden mit je einem Helfer wechseln.
- **Die Vorstellungsrunde** um 15:15 schafft Verständnis über die Rollen hinweg: Redakteure sehen, warum Entwickler
  Templates brauchen, Entwickler sehen, was Redakteure jeden Tag tun.
- **Nächste Schritte**: Geben Sie jeder Rolle ihren Kurs aus dem Katalog.

## Praktische Übung

Das Abschlussprojekt des Vormittags (alle): Legen Sie den Artikel „Team kick-off“ an, veröffentlichen Sie ihn,
bearbeiten und veröffentlichen Sie eine zweite Version und öffnen Sie **Versionen verwalten**. Die Nachmittagsstränge
verwenden die Abschlussprojekte ihrer eintägigen Agenden, gekürzt.

## Erwartetes Ergebnis

- Jede Person hat einen veröffentlichten Artikel in Version 2.
- Jeder Strang stellt ein Ergebnis vor: einen Artikel mit einem Bild, eine Rollenseite, ein Override.

## Quiz (am Ende des Tages)

1. Nennen Sie zwei Konzepte, die jede Rolle braucht.
2. Welcher Kurs folgt für einen Redakteur? Für einen Administrator? Für einen Entwickler?
3. Was haben die anderen Stränge gebaut?

<details>
<summary>Antworten</summary>

1. Zum Beispiel Objekt und Knoten, Versionen, Rollen ([Die Kernkonzepte unterrichten](../../die-kernkonzepte-unterrichten.md)).
2. Redakteure 101; Website-Administration; Entwickler ([Kurskatalog](../../kurskatalog.md)).
3. Einen Artikel mit einem Bild und einem Link; eine einer Gruppe zugewiesene Rolle; ein gezeigtes und entferntes
   Override.

</details>

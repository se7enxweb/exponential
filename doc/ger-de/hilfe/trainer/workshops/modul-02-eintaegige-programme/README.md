# Modul 2: Eintägige Agenden

Sechs fertige Agenden für Fälle, in denen nur ein Tag zur Verfügung steht. Jeder Block nennt die Lektion oder
Hilfeseite, die er verwendet, den Kontrollpunkt, der zeigt, dass er funktioniert hat, und was zuerst gestrichen wird.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Workshops und Bootcamps](../README.md) |
| Agenden | 6 (fünf Tage, ein halber Tag) |
| Niveau | Einsteiger bis Fortgeschrittene |
| Form | Praxisorientiert, außer dem halben Tag für Entscheidungsträger |

## Agenden

| Agenda | Länge | Für |
|---|---|---|
| [2.1 Der Tag für Redakteure](tag-fuer-redakteure.md) | 1 Tag | Neue Redakteure |
| [2.2 Der Tag für Administratoren](tag-fuer-administratoren.md) | 1 Tag | Neue Website-Administratoren |
| [2.3 Der Tag für Entwickler](tag-fuer-entwickler.md) | 1 Tag | PHP-Entwickler, die neu bei Exponential sind |
| [2.4 Der Tag für Layouts](layouts-tag.md) | 1 Tag | Redakteure und Website-Ersteller |
| [2.5 Exponential an einem Tag (gemischte Gruppe)](exponential-an-einem-tag.md) | 1 Tag | Ein Projektteam mit gemischten Rollen |
| [2.6 Der halbe Tag für Entscheidungsträger](halber-tag-fuer-entscheider.md) | Halber Tag | Führungskräfte und Vorstände |

## Dieses Modul vorbereiten

- Machen Sie aus der gewählten Agenda einen Ablaufplan ([Lektion 1.4](../modul-01-einen-workshop-planen/der-ablaufplan.md)).
- Bauen Sie die Übungsumgebung auf ([Modul 2 von Train the Trainer](../../../../../eng-us/help/trainers/train-the-trainer/module-02-building-the-lab/README.md)).
- Proben Sie jedes Abschlussprojekt auf dem Release, das Sie verwenden werden.

## Zeitplan

Jede Agenda hat ihre eigenen Zeiten. Ein üblicher Workshop-Tag läuft von 9:00 bis 16:30: sechs Stunden Einheiten,
zwei Pausen zu 15 Minuten und eine Mittagspause von 45 Minuten.

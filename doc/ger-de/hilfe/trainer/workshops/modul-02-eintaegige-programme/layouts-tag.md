# Agenda 2.4: Der Tag für Layouts

Mit Exponential Layouts setzen Redakteure und Website-Ersteller Seiten ohne Code aus Blöcken zusammen. An einem Tag
können die Teilnehmenden eine Landingpage bauen, veröffentlichen und zuordnen und verstehen, wie eine gemeinsame Kopf-
und Fußzeile jede Seite erreicht.

Am Ende des Tages können die Teilnehmenden:

- Layouts, Layouttypen, Zonen, Blöcke, Zuordnungen und gemeinsame Layouts erklären;

- **Layout veröffentlichen**, **Entwurf speichern und schließen**, **Verwerfen** und **Abbrechen** unterscheiden;
- die Zuordnungen lesen und sagen, welches Layout eine Seite verwendet.

## Hinweise für Trainer

- **Zuordnungen entscheiden, wie ganze Teile einer Website aussehen.** Auf einer gemeinsamen Website lassen Sie die
  Teilnehmenden Zuordnungen lesen, aber nur auf ihrer eigenen Installation anlegen.
- **Immer ein Entwurf.** Das Öffnen eines veröffentlichten Layouts erzeugt einen Entwurf; die Website zeigt das
  veröffentlichte Layout, bis Sie veröffentlichen.
- **Caches**: Wo die Website ihre Caches nach einer Veröffentlichung nicht leert, fragt der Editor nach; wählen Sie
  **Clear caches**.
- **Nach dem Tag** verweisen Sie auf den vollständigen Kurs Exponential Layouts.

## Praktische Übung: das Abschlussprojekt des Tages

Auf der eigenen Installation der Person:

1. Klicken Sie auf **Neues Layout**, wählen Sie einen zweispaltigen **Layouttyp**, nennen Sie es „Bike Day landing“
   und klicken Sie auf **Layout anlegen**.
2. Fügen Sie der linken Zone einen Title-Block und einen Rich-text-Block hinzu und der rechten Zone einen Image-Block.
3. Füllen Sie ihre Eigenschaften unter **Inhalt** aus; ändern Sie eine Eigenschaft unter **Design**.
4. Verwenden Sie **Entwurf speichern und schließen**; öffnen Sie es erneut; dann **Layout veröffentlichen**.
5. Öffnen Sie **Regeln** und finden Sie heraus, welches Layout die Startseite verwendet.

## Erwartetes Ergebnis

- „Bike Day landing“ ist mit drei konfigurierten Blöcken veröffentlicht.
- Die Person kann das Layout und die Zuordnung der Startseite nennen.

## Quiz (am Ende des Tages)

1. Was entscheidet, welche Zonen ein Layout hat?
2. Was bewirkt **Entwurf speichern und schließen** beim veröffentlichten Layout?
3. Wofür ist ein gemeinsames Layout da?
4. Zwei Zuordnungen passen auf eine Seite. Welche gewinnt?

<details>
<summary>Antworten</summary>

1. Der Layouttyp ([Der Layout-Editor](../../../layout-editor.md#layouts-zonen-und-blöcke)).
2. Nichts; das veröffentlichte Layout bleibt unverändert.
3. Es enthält Blöcke, die viele Seiten verwenden, etwa eine Kopf- und eine Fußzeile; andere Layouts verknüpfen eine
   Zone damit.
4. Die erste aktivierte Zuordnung nach Priorität, deren Ziele und Bedingungen passen.

</details>

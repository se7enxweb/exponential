# Lektion 1.3: Vorbereitung für die Teilnehmenden

Die erste Stunde eines Workshops gehört denen, die vorbereitet gekommen sind. Eine kurze Nachricht zur Vorbereitung,
eine Woche vorher verschickt, verlagert die Rechnerprüfungen und die erste Lektüre aus dem Workshop in die eigene Zeit
der Teilnehmenden.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- eine Nachricht zur Vorbereitung von höchstens einer Bildschirmseite schreiben;
- für einen bestimmten Workshop zwei Hilfeseiten als vorbereitende Lektüre auswählen;
- eine Rechnerprüfung aufnehmen, die die Teilnehmenden allein durchführen können;
- nach Vorkehrungen fragen, ohne nach Gründen zu fragen.

## Hinweise für Trainer

### So präsentieren Sie es

1. Zeigen Sie die Vorlage im [Trainer-Werkzeugkasten](../../../../../eng-us/help/trainers/trainer-toolkit.md#template-pre-work-message-to-learners)
   (5 Minuten).
2. Wählen Sie die vorbereitende Lektüre nach Rolle (5 Minuten): Redakteure: [Erste Schritte](../../../erste-schritte.md)
   und [Inhalte anlegen und bearbeiten](../../../inhalte-bearbeiten.md); Administratoren: [Ein Rundgang durch die Administration](../../../rundgang-durch-die-administration.md)
   und [Rollen und Richtlinien](../../../../anleitungen/rollen-und-richtlinien.md); Entwickler: [Mit Git entwickeln](../../../mit-git-entwickeln.md)
   und [Templates und Design](../../../../anleitungen/templates-und-design.md).

### Häufige Fragen

**Was, wenn die Teilnehmenden es nicht tun?** Planen Sie die ersten 30 Minuten so, dass die Unvorbereiteten mit einem
Helfer aufholen können.

**Sollte die Vorbereitung eine Installation enthalten?** Für Entwickler-Workshops ja (mit einer Alternative). Für
Redakteurs-Workshops schicken Sie stattdessen die Anmeldedaten für die gemeinsame Website (Passwörter über einen
getrennten, sicheren Kanal).

### Stolperfallen

- **Lange Nachrichten.** Eine Bildschirmseite.
- **Passwörter in derselben Nachricht.** Schicken Sie Zugangsdaten nie mit den allgemeinen Informationen.

## Praktische Übung

1. Schreiben Sie die Nachricht zur Vorbereitung für einen eintägigen Redakteurs-Workshop auf einer gemeinsamen
   Schulungs-Website.
2. Wählen Sie die zwei Seiten für die vorbereitende Lektüre.
3. Schreiben Sie die Rechnerprüfung (ein Browser und die Adresse der Website; nichts zu installieren).
4. Fügen Sie die Frage nach Vorkehrungen hinzu.
5. Legen Sie fest, wie die Teilnehmenden ihre persönlichen Anmeldedaten bekommen (nicht in dieser Nachricht).

## Erwartetes Ergebnis

- Eine Nachricht zur Vorbereitung von einer Bildschirmseite mit zwei Links zur vorbereitenden Lektüre, einer einfachen
  Prüfung und der Frage nach Vorkehrungen.
- Ein Hinweis, wie die Anmeldedaten getrennt verschickt werden.

## Quiz

1. Wie lang sollte eine Nachricht zur Vorbereitung sein?
2. Welche zwei Seiten eignen sich als vorbereitende Lektüre für Redakteure?
3. Warum werden Passwörter nie in der allgemeinen Nachricht verschickt?
4. Wofür sollten die ersten 30 Minuten planen?

<details>
<summary>Antworten</summary>

1. Eine Bildschirmseite.
2. Zum Beispiel [Erste Schritte](../../../erste-schritte.md) und [Inhalte anlegen und bearbeiten](../../../inhalte-bearbeiten.md).
3. Allgemeine Nachrichten werden weitergeleitet; Zugangsdaten gehen über einen getrennten, sicheren Kanal.
4. Für Teilnehmende, die die Vorbereitung nicht erledigt haben.

</details>

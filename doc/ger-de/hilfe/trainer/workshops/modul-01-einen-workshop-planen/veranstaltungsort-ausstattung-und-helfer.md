# Lektion 1.2: Veranstaltungsort, Ausstattung und Helfer

Ein Workshop kann allein an der Logistik scheitern: keine Steckdosen, ein Netzwerk, das Composer blockiert, ein Beamer,
den niemand lesen kann. Diese Lektion ist ein Planungsrundgang durch den Raum, die Ausstattung und die Menschen, die ein
praktischer Exponential-Workshop braucht.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- die Anforderungen eines praktischen Workshops an Raum, Netzwerk und Ausstattung aufzählen;
- eine Offline-Alternative für Code und Pakete planen;
- den Workshop mit einem Helfer pro acht bis zehn Teilnehmende besetzen;
- den Raum auf Barrierefreiheit prüfen.

## Hinweise für Trainer

### So präsentieren Sie es

1. Raum (3 Minuten): eine Steckdose pro Person, Tische für Laptops, eine Leinwand, die alle lesen können, stufenloser
   Zugang, ein ruhiger Bereich für Pausen.
2. Netzwerk (3 Minuten): Installationen laden Code von GitHub und Packagist und Seitenpakete aus dem Paketindex;
   testen Sie das Netzwerk des Veranstaltungsorts vorab oder bereiten Sie Code und Pakete auf jedem Rechner vor
   ([Lektion 2.8 von Train the Trainer](../../train-the-trainer/modul-02-die-uebungsumgebung-aufbauen/das-seitenpaket-fuer-den-kurs-waehlen.md)
   behandelt den Paketindex und Offline-Installationen).
3. Ausstattung und Helfer (4 Minuten): Ersatz-Laptops mit einer vorbereiteten Installation; gedruckte
   [Kurzkarte für die Übungsumgebung](../../kurzkarte-fuer-die-uebungsumgebung.md); ein Helfer pro acht bis zehn Teilnehmende, wie es die
   Workshop-Gliederung der Fürsprecher empfiehlt.

### Häufige Fragen

**Was, wenn das Netzwerk GitHub blockiert?** Bereiten Sie den Code vorab vor (USB-Stick oder vorinstallierte Rechner).

**Lieber online?** Siehe [Lektion 3.6 von Train the Trainer](../../train-the-trainer/modul-03-einen-kurs-gestalten/online-und-hybridunterricht.md).

### Stolperfallen

- **Das Netzwerk am Tag selbst testen.** Testen Sie es eine Woche vorher.
- **Zu wenige Helfer.** Mit zu wenigen Helfern dauern die Installationen am längsten.

## Praktische Übung

Schreiben Sie den Logistikplan für einen eintägigen Workshop mit 16 Teilnehmenden.

1. Raum: Listen Sie fünf Anforderungen auf und wie Sie jede prüfen.
2. Netzwerk: Schreiben Sie den Test auf, den Sie eine Woche vorher am Veranstaltungsort ausführen (zum Beispiel das
   Repository mit `git clone` klonen und mit `composer create-project` ein Release auf einem Laptop im Netzwerk des
   Veranstaltungsorts anlegen).
3. Alternative: Beschreiben Sie, was Sie vorbereiten, wenn der Test fehlschlägt.
4. Ausstattung: Listen Sie die Geräte auf, einschließlich zweier Ersatz-Laptops mit einer vorbereiteten Installation.
5. Menschen: wie viele Helfer, und was jeder braucht (die Kurzkarte für die Übungsumgebung, eine Teilnehmerliste).

## Erwartetes Ergebnis

- Ein einseitiger Plan mit Raum, Netzwerktest, Alternative, Ausstattung und zwei Helfern für 16 Teilnehmende.

## Quiz

1. Wie viele Helfer für 16 Teilnehmende?
2. Warum testen Sie das Netzwerk des Veranstaltungsorts eine Woche vorher?
3. Was ist eine gute Alternative, wenn Installationen das Internet nicht erreichen?
4. Nennen Sie zwei Prüfungen der Barrierefreiheit eines Raums.

<details>
<summary>Antworten</summary>

1. Zwei (einer pro acht bis zehn Teilnehmende; [Gliederung eines praktischen Workshops](../../../fuersprecher/ablaufplan-praxis-workshop.md)).
2. Installationen laden Code und Pakete aus dem Internet; ein blockiertes Netzwerk stoppt den Workshop.
3. Code und Pakete, die auf jedem Rechner vorbereitet sind, oder Ersatzrechner mit einer vorbereiteten Installation.
4. Stufenloser Zugang; eine Leinwand, die von jedem Platz aus lesbar ist (auch ein ruhiger Bereich, Sitzplätze nahe
   der Leinwand).

</details>

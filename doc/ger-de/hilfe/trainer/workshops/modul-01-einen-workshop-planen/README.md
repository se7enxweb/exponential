# Modul 1: Einen Workshop planen

Vor jeder Agenda: das Format, der Raum und die Menschen. Dieses Modul macht aus einer Anfrage („Können Sie unser Team
an einem Tag schulen?“) einen Plan, der am Tag selbst funktioniert.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Workshops und Bootcamps](../README.md) |
| Dauer | 2 Stunden 5 Minuten (vier Lektionen) |
| Lektionen | 4 |
| Niveau | Einsteiger bis Fortgeschrittene |
| Form | Planungsworkshop; Papier oder ein gemeinsames Dokument |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [1.1 Ein Workshop-Format wählen](ein-format-waehlen.md) | 30 Min. | Fünf erfundenen Gruppen Formate zuordnen |
| [1.2 Veranstaltungsort, Ausstattung und Helfer](veranstaltungsort-ausstattung-und-helfer.md) | 30 Min. | Den Logistikplan für 16 Teilnehmende schreiben |
| [1.3 Vorbereitung für die Teilnehmenden](vorbereitung-fuer-teilnehmende.md) | 30 Min. | Eine Nachricht zur Vorbereitung schreiben |
| [1.4 Der Ablaufplan](der-ablaufplan.md) | 35 Min. | Einen Ablaufplan für den Vormittag schreiben |

## Dieses Modul vorbereiten

- Die Agenden der Module 2 bis 4 ausgedruckt oder geöffnet.
- Der [Trainer-Werkzeugkasten](../../trainer-werkzeugkasten.md) und die [Kurzkarte für die Übungsumgebung](../../kurzkarte-fuer-die-uebungsumgebung.md).

## Zeitplan

| Zeit | Punkt |
|---|---|
| 0:00 | Lektionen 1.1 und 1.2 (60 Min.) |
| 1:00 | Pause (10 Min.) |
| 1:10 | Lektionen 1.3 und 1.4 (65 Min.) |
| 2:15 | Ende (2 Std. 5 Min. Lektionen plus eine Pause) |

# Lektion 1.1: Ein Workshop-Format wählen

Vollständige Kurse sind nicht immer möglich. Viele Gruppen haben einen Tag oder eine intensive Woche. Dieser Kurs bietet
für diese Fälle fertige Agenden, aufgebaut aus den Lektionen der Fachkurse. Diese Lektion hilft Trainern, das richtige
Format zu wählen, bevor sie den Inhalt wählen.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- die vier Formate dieses Kurses nennen und was jedes erreichen kann;
- ein Format anhand von Ziel, verfügbarer Zeit und Ausgangsniveau der Gruppe wählen;
- die passende Agenda-Seite aussuchen;
- einem Auftraggeber erklären, was ein eintägiger Workshop nicht leisten kann.

## Hinweise für Trainer

### So präsentieren Sie es

1. Zeigen Sie die Formate (5 Minuten):

   | Format | Erreicht | Agenden |
   |---|---|---|
   | Halber Tag | Einen ersten Eindruck; eine Entscheidung, ob man weitergeht | [Der halbe Tag für Entscheidungsträger](../modul-02-eintaegige-programme/halber-tag-fuer-entscheider.md) |
   | Ein Tag | Die Kernaufgaben einer Rolle, einmal geübt | [Modul 2](../modul-02-eintaegige-programme/README.md) |
   | Drei Tage | Die Aufgaben einer Rolle, geübt, bis die Teilnehmenden allein arbeiten können | [Modul 3](../modul-03-dreitaegige-bootcamps/README.md) |
   | Fünf Tage | Mehrere Rollen oder eine Rolle in der Tiefe, mit einem Abschlussprojekt | [Modul 4](../modul-04-fuenftaegige-bootcamps/README.md) |

2. Erklären Sie den Kompromiss (5 Minuten): Ein eintägiger Workshop zeigt und übt; er macht niemanden zum
   Administrator. Nachbereitendes Material (die Fachkurse) ist nach kurzen Formaten am wichtigsten.

### Häufige Fragen

**Kann ein eintägiger Workshop einen Kurs ersetzen?** Für ein kleines Redaktionsteam mit einfachen Anforderungen
manchmal. Für Administratoren und Entwickler nicht.

**Können wir fünf Tage auf fünf Wochen verteilen?** Ja, und das Behalten ist oft besser; führen Sie das
Abschlussprojekt zwischen den Terminen weiter.

### Stolperfallen

- **Zu viel an einem Tag.** Wählen Sie weniger Themen und üben Sie sie.
- **Gemischte Rollen in einem Bootcamp.** Verwenden Sie die Pläne für gemischte Gruppen oder teilen Sie die Gruppe.

## Praktische Übung

Wählen Sie für jede dieser erfundenen Gruppen ein Format und eine Agenda-Seite und schreiben Sie einen Satz zur
Begründung.

1. Eine Stadtbibliothek: fünf Redakteure, die Nachrichten veröffentlichen werden, ein Tag verfügbar.
2. Eine Webagentur: vier PHP-Entwickler, die nächsten Monat ihr erstes Exponential-Projekt beginnen, eine Woche
   verfügbar.
3. Die IT-Abteilung einer Universität: zwei Administratoren, die eine bestehende Website übernehmen, drei Tage
   verfügbar.
4. Der Vorstand eines gemeinnützigen Vereins, der entscheidet, ob er Exponential einführt: ein Nachmittag.
5. Das Support-Team eines Hosting-Unternehmens mit sechs Personen: zwei Tage verfügbar.

## Erwartetes Ergebnis

- 1: die eintägige Agenda für Redakteure; 2: die fünftägige Woche für Full-Stack-Entwickler; 3: das dreitägige
  Bootcamp für Administratoren; 4: der halbe Tag für Entscheidungsträger; 5: die eintägige Agenda für Administratoren
  plus ein Tag des Kurses Hosting und Betrieb.
- Jede Wahl hat einen Satz Begründung, der Ziel und Zeit nennt.

## Quiz

1. Welches Format passt zu einer Gruppe, die danach allein arbeiten muss?
2. Was kann ein eintägiger Workshop für Administratoren nicht erreichen?
3. Warum ist nachbereitendes Material nach kurzen Formaten am wichtigsten?
4. Welche Agenda passt zu einem Vorstand, der über die Einführung entscheidet?

<details>
<summary>Antworten</summary>

1. Ein dreitägiges oder fünftägiges Bootcamp.
2. Den selbstständigen Betrieb einer Website; er kann Kernaufgaben einmal zeigen und üben.
3. Die Teilnehmenden haben jede Aufgabe nur einmal geübt; die Kurse helfen ihnen, sie zu wiederholen und zu vertiefen.
4. [Der halbe Tag für Entscheidungsträger](../modul-02-eintaegige-programme/halber-tag-fuer-entscheider.md).

</details>

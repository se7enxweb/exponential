# Modul 5: Abschlussprojekte

Ein Abschlussprojekt gibt den Teilnehmenden eine Aufgabenstellung statt einzelner Schritte und zeigt dem Trainer, was
sie selbstständig können. Jede Aufgabe hier hat ein Bewertungsraster mit sechs Kriterien; verwenden Sie es wie
angegeben oder passen Sie es an.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Workshops und Bootcamps](../README.md) |
| Projekte | 3 |
| Dauer | je 4 bis 8 Stunden |
| Niveau | Einsteiger bis Experten |

## Projekte

| Projekt | Für | Dauer |
|---|---|---|
| [5.1 Eine Vereinswebsite](vereinswebsite.md) | Redakteure und Website-Ersteller | 4 bis 6 Stunden |
| [5.2 Ein Intranet-Nachrichtenbereich](intranet-nachrichtenbereich.md) | Administratoren | 4 Stunden |
| [5.3 Eine mehrsprachige Veranstaltungswebsite](mehrsprachige-veranstaltungswebsite.md) | Entwickler | 6 bis 8 Stunden |

## Dieses Modul vorbereiten

- Eine Schulungsinstallation pro Teilnehmer oder Paar, auf einen bekannten Zustand zurückgesetzt.
- Die Aufgabenstellung ausgedruckt; Bilder unter freier Lizenz auf einem gemeinsamen Laufwerk.
- Das Bewertungsraster für den Trainer ausgedruckt.

## Zeitplan

| Teil | Anteil an der Zeit |
|---|---|
| Aufgabenstellung lesen und planen | 10 Prozent |
| Bauen | 70 Prozent |
| Selbstprüfung und Korrekturen | 10 Prozent |
| Präsentationen und Feedback | 10 Prozent |

# Modul 3: Dreitägige Bootcamps

In drei Tagen können die Teilnehmenden so lange üben, bis sie selbstständig arbeiten können. Jedes Bootcamp hat ein
Abschlussprojekt, das über die Tage wächst und am Ende präsentiert wird.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Workshops und Bootcamps](../README.md) |
| Bootcamps | 4 |
| Dauer | je 3 Tage, 6 Stunden Einheiten pro Tag |
| Niveau | Einsteiger bis Fortgeschrittene |

## Bootcamps

| Bootcamp | Für | Abschlussprojekt |
|---|---|---|
| [3.1 Das Redakteurs-Bootcamp](redakteure-bootcamp.md) | Neue Redakteure | Ein Bereich mit Artikeln, einer Übersetzung und einem Layout |
| [3.2 Das Administratoren-Bootcamp](administratoren-bootcamp.md) | Website-Administratoren | Rollen und Sektionen, 2FA, Sicherung und Wiederherstellung, eine Störfallübung |
| [3.3 Das Entwickler-Bootcamp](entwickler-bootcamp.md) | PHP-Entwickler | Ein Veranstaltungsbereich mit Klassen, Ansichten und einer Erweiterung |
| [3.4 Das Bootcamp für Website-Ersteller](website-ersteller-bootcamp.md) | Website-Ersteller | Eine kleine Vereinswebsite mit Layouts und zwei Sprachen |

## Dieses Modul vorbereiten

- Eine Installation pro Teilnehmer für 3.2, 3.3 und 3.4; eine Referenzkopie zum Zurücksetzen.
- Für 3.2: ein vorbereiteter Fehler pro Installation für die Störfallübung.
- Ein Ablaufplan pro Tag ([Lektion 1.4](../modul-01-einen-workshop-planen/der-ablaufplan.md)).

## Zeitplan

Jeder Tag: 9:00 bis 16:30 Uhr, zwei Blöcke zu je drei Stunden, zwei Pausen von 15 Minuten und 45 Minuten
Mittagspause. Planen Sie die Präsentationen der Abschlussprojekte in der letzten Stunde von Tag 3 ein.

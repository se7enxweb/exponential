# Bootcamp 3.1: Das dreitägige Redakteurs-Bootcamp

Drei Tage geben Redakteuren Zeit, jede Aufgabe so lange zu üben, bis sie sie ohne Handout erledigen. Das Bootcamp
behandelt den gesamten Kurs [Redakteure 101](../../../../../eng-us/help/trainers/editors-101/README.md) in verdichteter Form und ergänzt Übersetzungen
und einen ersten Blick auf Layouts.

| Modul | [Modul 3: Dreitägige Bootcamps](README.md) |
| Dauer | 3 Tage mit je 6 Stunden Einheiten |
| Niveau | Einsteiger |
| Zielgruppe | Neue Redakteure, 6 bis 16 Teilnehmende |
| Voraussetzungen | Teilnehmerkonten auf einer gemeinsamen Website (Rolle auf den eigenen Ordner beschränkt) oder eine Installation pro Teilnehmer |

## Lernziele

Am Ende des Bootcamps können die Teilnehmenden:

- Inhalte erstellen, bearbeiten, veröffentlichen, in der Vorschau ansehen, vergleichen, verbergen und wiederherstellen;
- formatierten Text mit Links, Überschriften, Tabellen und Bildern mit Alternativtext schreiben;
- Inhalte finden und mit dem Dashboard, den Entwürfen und den Lesezeichen arbeiten;
- ein Element in eine zweite Sprache übersetzen;
- Blöcke in einem Layout platzieren und es veröffentlichen.

Pausen: jeden Tag 15 Minuten am Vormittag und am Nachmittag, 45 Minuten Mittagspause.

## Hinweise für Trainer

- **Tag 1 gibt das Tempo vor.** Gehen Sie langsam vor; alles Weitere baut darauf auf.
- **Übersetzungen** brauchen eine zweite Sprache auf der Schulungswebsite; prüfen Sie das vor dem Bootcamp.
- **Layouts auf einer gemeinsamen Website**: Die Teilnehmenden erstellen eigene Layouts, ändern aber keine Zuordnungen.
- **Wiederholen Sie jede Kernaufgabe jeden Tag**: Beginnen Sie Tag 2 und 3 mit einer fünfminütigen Aufwärmübung
  „Erstellen und veröffentlichen“.

## Praktische Übung: das Abschlussprojekt des Bootcamps

Jeder Teilnehmer baut in seinem Ordner einen kleinen Bereich „Bike Day 2027“:

1. Einen Ordner mit Einleitung; drei Artikel (Programm, Veranstaltungsort, Anmeldung) mit Überschriften, Links
   untereinander und je einem Bild mit Alternativtext.
2. Einen Artikel, der in die zweite Sprache übersetzt ist.
3. Eine zweite Version des Programmartikels, mit der ersten verglichen.
4. Ein Layout mit einem Title-Block und einem Rich-text-Block, veröffentlicht.

## Erwartetes Ergebnis

- Der Bereich besteht aus drei Artikeln, einer Übersetzung, zwei Versionen des Programms und einem veröffentlichten
  Layout.
- Jeder Teilnehmer stellt seinen Bereich an Tag 3 in zwei Minuten vor.

## Quiz (Ende des Bootcamps)

1. Wie holen Sie ein entferntes Element zurück?
2. Was ist der Unterschied zwischen Verbergen und Entfernen?
3. Wo wählen Sie die Sprache, bevor Sie eine Übersetzung bearbeiten?
4. Was bewirkt **Verwerfen** im Layout-Editor?

<details>
<summary>Antworten</summary>

1. Stellen Sie es aus dem Papierkorb wieder her ([Veröffentlichen, Versionen und der Papierkorb](../../../veroeffentlichen-und-versionen.md)).
2. Ein verborgenes Element bleibt an seinem Platz, wird Besuchern aber nicht angezeigt; ein entferntes Element kommt
   in den Papierkorb.
3. In der Sprachliste neben **Bearbeiten**.
4. Es wirft den Entwurf nach Ihrer Bestätigung weg und schließt den Editor ([Der Layout-Editor](../../../layout-editor.md)).

</details>

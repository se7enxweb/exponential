# Bootcamp 3.4: Das dreitägige Bootcamp für Website-Ersteller

Website-Ersteller planen die Struktur einer Website, legen ihre Inhaltstypen fest und stellen ihre Seiten zusammen,
meist ohne Code. Dieses Bootcamp verbindet Redaktionsfähigkeiten, Inhaltsklassen und Exponential Layouts zu einem
dreitägigen Weg, der mit einer kleinen, vollständigen Website endet.

| Niveau | Fortgeschrittene |

| Voraussetzungen | Eine Installation pro Teilnehmer mit Administratorzugang; Grundlagen aus Redakteure 101 |

## Lernziele

Am Ende des Bootcamps können die Teilnehmenden:

- eine Inhaltsstruktur und die dafür nötigen Inhaltsklassen planen;
- eine Inhaltsklasse ohne Code erstellen;
- Seiten aus Blöcken zusammenstellen, gemeinsame Layouts für Kopf- und Fußbereich verwenden und Layouts Seiten
  zuordnen;
- eine zweite Sprache hinzufügen und Inhalte übersetzen.

## Der Ablauf

| Tag | Vormittag (3 Std.) | Nachmittag (3 Std.) |
|---|---|---|
| 1 | Eine Website planen: Struktur, Sektionen, Klassen ([Das Inhaltsmodell und das Bearbeiten von Inhalten](../../../../anleitungen/inhaltsmodell-und-bearbeitung.md), [Sektionen](../../../../anleitungen/sektionen.md)) | Inhaltsklassen und Inhalte erstellen ([Klassengruppen](../../../../anleitungen/klassengruppen.md)); die Struktur der Website aufgebaut |
| 2 | Layouts, Zonen und Blöcke ([Der Layout-Editor](../../../layout-editor.md)) | Gemeinsame Layouts, verknüpfte Zonen und Zuordnungen ([Welche Seiten ein Layout verwenden](../../../layout-editor.md#welche-seiten-ein-layout-verwenden)) |
| 3 | Sprachen ([Sprachen](../../../sprachen.md), [Inhaltssprachen](../../../../anleitungen/inhaltssprachen.md)); URLs ([URLs und Aliase](../../../../anleitungen/urls-und-aliase.md)) | Abschlussprojekt: eine vollständige kleine Website; Präsentationen |

Pausen: jeden Tag 15 Minuten am Vormittag und am Nachmittag, 45 Minuten Mittagspause.

## Hinweise für Trainer

- **Zuerst auf Papier planen** (Tag 1 vormittags): eine Sitemap und eine Liste der Inhaltstypen mit ihren Feldern.
- **Klassenänderungen wirken sich auf bestehende Inhalte aus**; bauen Sie die Klassen vor den Inhalten.
- **Zuordnungen** entscheiden, wie ganze Teile einer Website aussehen; prüfen Sie die Zuordnungen jedes Teilnehmers,
  bevor er veröffentlicht.

## Praktische Übung: das Abschlussprojekt des Bootcamps

Bauen Sie eine Website für einen erfundenen Sportverein:

1. Struktur: Home, News, Events, Teams, Contact.
2. Eine Inhaltsklasse „Team“ (Name, Trainer, Trainingszeiten, Foto).
3. Ein Landingpage-Layout für Home mit einem Hero-Bereich, einer Nachrichtenliste und einer Veranstaltungsliste; ein
   gemeinsamer Kopf- und Fußbereich.
4. Zuordnungen für Home und für jeden Nachrichtenartikel.
5. Eine zweite Sprache für die Startseite und zwei Nachrichten.

## Erwartetes Ergebnis

- Die Website hat die fünf Bereiche, drei Teams, eine zugeordnete Landingpage mit gemeinsamem Kopf- und Fußbereich
  und zwei übersetzte Elemente.
- Jeder Teilnehmer stellt seine Website in drei Minuten vor.

## Quiz (Ende des Bootcamps)

1. Warum baut man Inhaltsklassen vor den Inhalten?
2. Wie gelangt ein einmal gebauter Kopfbereich in jedes Layout?
3. Was entscheidet, welches Layout eine Seite verwendet?
4. Was ändert sich, wenn Sie eine Übersetzung hinzufügen: das Objekt, der Knoten oder eine Version?

<details>
<summary>Antworten</summary>

1. Klassenänderungen wirken sich auf alle bestehenden Inhalte dieser Klasse aus.
2. Über ein gemeinsames Layout: Andere Layouts verknüpfen eine Zone mit seiner Zone ([Der Layout-Editor](../../../layout-editor.md)).
3. Die erste aktivierte Zuordnung nach Priorität, deren Ziele und Bedingungen zutreffen.
4. Das Objekt erhält eine neue Sprachversion; der Knoten bleibt derselbe.

</details>

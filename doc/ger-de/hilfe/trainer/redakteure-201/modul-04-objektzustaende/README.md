# Modul 4: Objektzustände

Objektzustände sind Stufen, die eine Website für ihre Inhalte festlegt. Nicht jede Website verwendet sie; auf denen,
die es tun, setzen Redakteure sie jeden Tag. Führen Sie dieses Modul durch, wenn die Website Ihrer Teilnehmenden
Zustände verwendet, oder als kurzen Blick auf das, was möglich ist.

| [Lektion 4.2: Zustände in einem Prüfablauf setzen](zustaende-in-einem-pruefablauf-setzen.md) | 45 Minuten | Zustände für ein Element und einen Teilbaum setzen; Autor und Prüfer spielen |

## Dieses Modul vorbereiten

- Legen Sie als Administrator unter **Setup** > **Zustände** eine Zustandsgruppe für Prüfungen mit drei Zuständen an
  (zum Beispiel *Draft*, *In review*, *Approved*) ([Eine Gruppe und ihre Zustände anlegen](../../../../anleitungen/objektzustaende.md#4-eine-gruppe-und-ihre-zustände-anlegen)).
  Setzen Sie vorhandene öffentliche Inhalte zuerst auf den freigegebenen Zustand, sonst verschwinden sie für Besucher.
- Richten Sie die Rollen des Prüfbeispiels aus dem Leitfaden auf der Schulungsinstallation ein: Besucher lesen nur
  freigegebene Inhalte, Autoren bearbeiten nur ihre Entwürfe und dürfen *In review* setzen, Prüfer dürfen die anderen
  Zustände setzen ([das Beispiel](../../../../anleitungen/objektzustaende.md#9-ein-durchgearbeitetes-beispiel-ein-prüf-workflow)).
- Zwei Arten von Schulungskonten: Autoren und Prüfer, damit die Teilnehmenden zu zweit arbeiten können.
- Die Teilnehmenden arbeiten in der Administration: Der Editor-Siteaccess bietet die Zustandsseiten nicht an.
- Entfernen Sie nach dem Kurs die Gruppe oder setzen Sie sie zurück, damit der nächste Kurs sauber beginnt.

# Modul 2: Verknüpfungen, Orte und Einbetten

Inhalte auf einer echten Website sind ein Netz, keine Liste. Dieses Modul zeigt, wie Elemente aufeinander verweisen,
wie ein Element an mehreren Stellen lebt und wie man Inhalte entfernt oder verbirgt, ohne Lücken zu hinterlassen.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Redakteure 201](../README.md) |
| Dauer | 2 Stunden 10 Minuten (mit 10 Minuten Pause) |
| Lektionen | 3 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 2.1: Verknüpfungen und Einbetten](verknuepfungen-und-einbetten.md) | 45 Minuten | Einen Artikel mit einem verknüpften, einem eingebetteten und einem verlinkten Element bauen; beide Richtungen lesen |
| [Lektion 2.2: Ein Element an mehreren Stellen: Orte](orte.md) | 45 Minuten | Einen Ort hinzufügen, lesen, verbergen und entfernen; den Hauptort ändern |
| [Lektion 2.3: Vor dem Entfernen oder Verbergen prüfen](vor-dem-entfernen-oder-verbergen-pruefen.md) | 30 Minuten | Die Verweisliste beim Entfernen lesen, den Verweis korrigieren, entfernen und wiederherstellen |

## Dieses Modul vorbereiten

- Die Teilnehmenden brauchen einen Kursordner und einige Bilder in der Medienbibliothek, die sie verwenden dürfen.
- Finden Sie heraus, ob Ihre Schulungsinstallation einen Typ mit einem Feld für eine Relationsliste hat (Lektion 2.1,
  Schritt 8).
- Prüfen Sie die Einstellung der Schulungs-Website für die Verweisprüfung beim Entfernen (`content.ini [RemoveSettings]
  ReverseRelationCheck`; ausgeliefert ist `warn`), damit Sie erklären können, was die Teilnehmenden sehen werden.
- Die Rolle der Teilnehmenden muss erlauben, in ihren Kursordnern Orte hinzuzufügen, ihre eigenen Elemente zu
  entfernen und aus dem Papierkorb wiederherzustellen.

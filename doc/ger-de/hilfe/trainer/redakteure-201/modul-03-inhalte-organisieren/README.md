# Modul 3: Inhalte organisieren

Redakteure, die sich um einen Teil einer Website kümmern, strukturieren ihn von Zeit zu Zeit um. Dieses Modul vermittelt
die Werkzeuge dafür, vom einzelnen Verschieben bis zum Hintergrundauftrag über Hunderte Elemente, und die Sektionen,
die entscheiden, wer was sieht.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Redakteure 201](../README.md) |
| Dauer | 3 Stunden 05 Minuten (mit zwei Pausen von 10 Minuten) |
| Lektionen | 4 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 3.1: Verschieben und Kopieren](verschieben-und-kopieren.md) | 45 Minuten | Verschieben, kopieren und einen Teilbaum kopieren; mehrere Elemente auf einmal verschieben |
| [Lektion 3.2: Unterelemente sortieren](unterelemente-sortieren.md) | 30 Minuten | Die Sortierung eines Ordners festlegen, Elemente mit Maus und Tastatur nach Priorität anordnen |
| [Lektion 3.3: Sektionen aus Sicht der Redakteure](sektionen-fuer-redakteure.md) | 45 Minuten | Sektionen lesen und setzen, die Sektion neuer und verschobener Inhalte vorhersagen |
| [Lektion 3.4: Große Vorgänge und der Papierkorb im Detail](grosse-operationen-und-der-papierkorb.md) | 45 Minuten | Einen großen Ordner als Hintergrundauftrag entfernen, den Papierkorb filtern, wiederherstellen |

## Dieses Modul vorbereiten

- Alle Teilnehmenden brauchen einen Kursordner mit mindestens vier Elementen (Lektion 3.2) und die Ordner aus Modul 2.
- Für Lektion 3.3: eine Sektion, die die Teilnehmenden zuweisen dürfen (zum Beispiel *Training*, angelegt unter
  **Setup** > **Sektionen**), eine Rolle, die das Zuweisen erlaubt, und ein privates Browserfenster, um die Website als
  Besucher anzusehen.
- Für Lektion 3.4: ein Ordner `Old campaign` mit 50 oder mehr Elementen pro Person und der Cronjob-Teil für
  Inhaltsaufträge oder ein funktionierender Hintergrund-Worker auf der Schulungsinstallation (prüfen Sie vor dem Kurs
  einen Auftrag).
- Entscheiden Sie, ob die Teilnehmenden die Auftragsliste (`content/jobs`) verwenden dürfen; ohne sie zeigen Sie sie
  selbst.

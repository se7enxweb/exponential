# Modul 7: Tags

Tags verbinden Inhalte über den Baum hinweg nach Themen. Dieses Modul behandelt das Taggen für alle Redakteure und den
Tag-Baum für die Redakteure, die ihn pflegen. Führen Sie es auf Websites durch, die die Tags-Erweiterung (eztags)
verwenden.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Redakteure 201](../README.md) |
| Dauer | 1 Stunde 30 Minuten |
| Lektionen | 2 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 7.1: Inhalte taggen](inhalte-taggen.md) | 45 Minuten | Einen Artikel mit Autovervollständigung und Vorschlägen taggen; eine Tag-Seite öffnen |
| [Lektion 7.2: Das Tags-Dashboard und der Tag-Baum](das-tags-dashboard.md) | 45 Minuten | Das Dashboard lesen, einen untergeordneten Tag hinzufügen, eine Zusammenführung und ein Synonym verfolgen |

## Dieses Modul vorbereiten

- Die Schulungsinstallation braucht eztags und ein Tags-Feld im Typ *Article*: als Administrator **Setup** >
  **Klassen**, *Article* bearbeiten, ein Tags-Attribut hinzufügen und seine Bearbeitungsansicht wählen
  ([eztags: Verwenden](../../../../../eng-us/features/6.0/extensions/eztags.md#use-it)). Erlauben Sie im Feld neue Tags, wenn die
  Teilnehmenden **Add new** ausprobieren sollen.
- Legen Sie im Dashboard **Tags** einige Tags an (zum Beispiel *Training*, *Events*, *Climate*) und zwei Duplikate für
  die Vorführung der Zusammenführung.
- Geben Sie der Rolle der Teilnehmenden die `tags`-Richtlinien für read, dashboard und add (und edit für Lektion 7.2),
  oder planen Sie, Lektion 7.2 vorzuführen.
- Kennen Sie die Adresse der Tag-Seiten Ihrer Website (`eztags.ini [GeneralSettings] URLPrefix`, standardmäßig
  `tags/view`).

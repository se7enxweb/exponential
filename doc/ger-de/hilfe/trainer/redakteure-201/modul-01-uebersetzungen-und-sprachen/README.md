# Modul 1: Übersetzungen und Sprachen

Viele Websites veröffentlichen in mehr als einer Sprache. Dieses Modul vermittelt Redakteuren und Übersetzern, wie
Übersetzungen in Exponential funktionieren: ein Element, mehrere Sprachen, jede für sich veröffentlicht.

## Auf einen Blick

| | |
|---|---|
| Kurs | [Redakteure 201](../README.md) |
| Dauer | 2 Stunden 10 Minuten (mit 10 Minuten Pause) |
| Lektionen | 3 |
| Niveau | Fortgeschrittene |

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 1.1: Inhaltssprachen und Übersetzungen](inhaltssprachen-und-uebersetzungen.md) | 30 Minuten | Sprachkennzeichen und den Tab Übersetzungen lesen; Inhaltssprache und Oberflächensprache unterscheiden |
| [Lektion 1.2: Ein Element übersetzen](ein-element-uebersetzen.md) | 45 Minuten | Eine Übersetzung auf Grundlage einer anderen hinzufügen, veröffentlichen, eine Sprache bearbeiten |
| [Lektion 1.3: Hauptsprache, immer verfügbar und eine Übersetzung entfernen](hauptsprache-und-uebersetzungen-entfernen.md) | 45 Minuten | Die Hauptsprache setzen, immer verfügbar lesen, in der falschen Sprache angelegte Inhalte korrigieren |

## Dieses Modul vorbereiten

- Die Schulungsinstallation braucht eine zweite Inhaltssprache. Als Administrator: **Setup > Sprachen**, **Sprache
  hinzufügen**, sie auswählen, **Sprache hinzufügen** ([Inhaltssprachen](../../../../anleitungen/inhaltssprachen.md#4-eine-sprache-hinzufügen)).
  Das Hinzufügen einer Sprache übersetzt nichts und zeigt Besuchern von sich aus nichts Neues.
- Für Schritt 8 von Lektion 1.1 einen Siteaccess, der die zweite Sprache zeigt (seine `SiteLanguageList`), oder
  lassen Sie diesen Schritt weg
  ([Abschnitt 5 des Leitfadens](../../../../anleitungen/inhaltssprachen.md#5-eine-sprache-anzeigen-sitelanguagelist-und-siteaccesses)).
- Ein veröffentlichter Artikel in beiden Sprachen für Lektion 1.1.
- Die Rolle der Teilnehmenden muss Bearbeiten und Anlegen in beiden Sprachen erlauben. Entscheiden Sie, ob sie
  Übersetzungen entfernen darf (Lektion 1.3, Schritt 10); andernfalls führen Sie diesen Schritt vor.

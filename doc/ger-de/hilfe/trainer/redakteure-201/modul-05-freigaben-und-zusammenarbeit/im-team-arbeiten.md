# Lektion 5.3: Im Team arbeiten

Zwei Redakteure am selben Artikel, eine Kollegin im Urlaub mit einem unfertigen Entwurf, ein Team, das wissen muss,
was sich geändert hat: Diese Lektion behandelt die alltäglichen Situationen von Redaktionsteams und die Werkzeuge, die
Exponential für jede davon hat.

## Lernziele

Nach dieser Lektion können die Teilnehmenden:

- die Seite **Möglicher Bearbeitungs-Konflikt** auflösen: einen eigenen Entwurf fortsetzen, einen **Neuen Entwurf**
  beginnen oder abbrechen;
- den Entwurf einer Kollegin mit **Neuen Entwurf machen** auf der Versionsseite übernehmen;
- dem Bereich einer Kollegin mit **Zu meinen Benachrichtigungen hinzufügen** und einem Digest folgen;
- entscheiden, wann **Ohne Benachrichtigung veröffentlichen** angebracht ist;
- drei Teamregeln für Entwürfe, Benennung und Übergaben vereinbaren.

## Hinweise für Trainer

### So präsentieren Sie es

Quellen: [Wenn jemand anderes bearbeitet](../../../inhalte-bearbeiten.md#wenn-jemand-anderes-bearbeitet),
[Zu einer früheren Version zurückkehren](../../../veroeffentlichen-und-versionen.md#zu-einer-früheren-version-zurückkehren) und
[E-Mail und Benachrichtigungen](../../../konten-und-anmeldung.md#e-mails-und-benachrichtigungen).

1. **Bearbeitungskonflikte** (4 Minuten). Wenn jemand schon einen Entwurf eines Elements hat, zeigt **Bearbeiten**
   **Möglicher Bearbeitungs-Konflikt** mit den Entwürfen, ihren Erstellern und Zeiten. Sie können einen **Ihrer**
   Entwürfe fortsetzen (auswählen und auf **Ausgewählte bearbeiten** klicken), aus der veröffentlichten Version einen
   **Neuen Entwurf** beginnen oder **Abbrechen**. Den Entwurf einer anderen Person können Sie nicht bearbeiten:
   Sprechen Sie mit ihr oder machen Sie einen neuen Entwurf.
2. **Einen Entwurf übernehmen** (3 Minuten). Auf der Versionsseite funktioniert **Neuen Entwurf machen** auch mit dem
   Entwurf einer anderen Person: Der neue Entwurf gehört Ihnen, in der gewählten Übersetzung. Der Entwurf der Kollegin
   bleibt; sagen Sie es ihr.
3. **Einem Bereich folgen** (3 Minuten). **Zu meinen Benachrichtigungen hinzufügen** im Menü eines Elements; ein
   Digest sammelt die Nachrichten pro Tag, Woche oder Monat (**Meine Benachrichtigungseinstellungen**).
4. **Ohne Benachrichtigung veröffentlichen** (2 Minuten). Wo die Website es anbietet, veröffentlicht es, ohne den
   Folgenden eine E-Mail zu schicken: für eine Tippfehlerkorrektur, nicht für Nachrichten.
5. **Teamregeln** (3 Minuten). Schlagen Sie vor: Entwürfe verwerfen, die man nicht fertigstellt; durch Sagen
   übergeben, nicht durch liegen gelassene Entwürfe; Elemente klar benennen; **Entwurf speichern und beenden** mit einem
   Hinweis im Team-Chat verwenden.

### Häufige Fragen

**Kann ich sehen, wer was geändert hat?** Die Versionsseite zeigt den Ersteller und die Daten jeder Version;
Administratoren haben zusätzlich ein Audit-Protokoll.

**Wird der Entwurf meiner Kollegin überschrieben, wenn ich meinen veröffentliche?** Nein. Ihr Entwurf bleibt ein
Entwurf; wenn sie ihn später veröffentlicht, wird er zur neuesten Version und kann Ihre Änderung rückgängig machen.
Sprechen Sie zuerst miteinander.

**Wie erfahre ich, dass eine Kollegin in meinem Bereich veröffentlicht hat?** Folgen Sie dem Bereich mit
Benachrichtigungen, oder sehen Sie auf dem Dashboard unter **Aktuellster Inhalt** nach.

### Stolperfallen

- **Zwei Entwürfe, zweimal veröffentlicht.** Das zweite Veröffentlichen gewinnt. Lassen Sie Teams miteinander reden,
  bevor sie dasselbe Element bearbeiten.
- **Zu viele Benachrichtigungen.** Wer der ganzen Website ohne Digest folgt, flutet seinen Posteingang. Empfehlen Sie
  einen täglichen Digest.
- **E-Mails in der Schulung.** Auf einer Schulungs-Website mit Adressen unter `example.invalid` gehen Benachrichtigungen
  nirgendwohin; das ist beabsichtigt.

## Praktische Übung

Arbeiten Sie zu zweit (A und B), jeweils mit einem Editor-Schulungskonto, an einem Artikel aus dem Kursordner von A.

1. A: Öffnen Sie den Artikel `Our team, two places`, klicken Sie auf **Bearbeiten**, ändern Sie ein Wort und klicken
   Sie auf **Entwurf speichern und beenden**.
2. B: Öffnen Sie denselben Artikel und klicken Sie auf **Bearbeiten**. Lesen Sie die Seite **Möglicher
   Bearbeitungs-Konflikt**: Wessen Entwurf ist aufgeführt?
3. B: Klicken Sie auf **Neuer Entwurf**, ändern Sie ein anderes Wort und klicken Sie auf **Zur Veröffentlichung
   schicken**.
4. A: Öffnen Sie den Artikel und klicken Sie auf **Bearbeiten**. Wählen Sie auf der Konfliktseite Ihren eigenen
   Entwurf aus und klicken Sie auf **Ausgewählte bearbeiten**. Achten Sie darauf, dass Ihr Entwurf die Änderung von B
   nicht enthält.
5. A: Klicken Sie auf **Entwurf verwerfen**. Klicken Sie dann erneut auf **Bearbeiten**, um von der veröffentlichten
   Version von B auszugehen, wiederholen Sie Ihre Änderung und veröffentlichen Sie.
6. B: Öffnen Sie **Versionen verwalten** des Artikels und lesen Sie, wer jede Version erstellt hat.
7. B: Öffnen Sie im Baum das Menü des Kursordners von A und wählen Sie **Zu meinen Benachrichtigungen hinzufügen**.
   Stellen Sie unter **Meine Benachrichtigungseinstellungen** einen täglichen Digest ein und klicken Sie auf
   **Digest-Einstellungen speichern**.
8. Beide: Schreiben Sie drei Teamregeln für Ihre eigene Website auf eine Karte.

## Erwartetes Ergebnis

- Schritt 2 hat den Entwurf von A auf der Konfliktseite gezeigt; B hat veröffentlicht, ohne den Entwurf von A zu
  berühren.
- Schritt 4 hat gezeigt, dass dem alten Entwurf von A die Änderung von B fehlte; A hat die Änderung auf der Version von
  B wiederholt.
- Die Versionsseite listet Versionen beider Teilnehmenden auf.
- B folgt dem Ordner von A mit einem täglichen Digest.
- Der Trainer sammelt die Karten mit den Teamregeln ein und liest einige vor.

## Quiz

1. Welche drei Möglichkeiten bietet **Möglicher Bearbeitungs-Konflikt**?
2. Richtig oder falsch: Sie können den Entwurf einer Kollegin direkt bearbeiten.
3. Wie übernehmen Sie den unfertigen Entwurf einer Kollegin?
4. Wann ist **Ohne Benachrichtigung veröffentlichen** angebracht?
   A. Für Eilmeldungen B. Für eine Tippfehlerkorrektur C. Bei jedem Veröffentlichen D. Nie
5. Zwei Redakteure veröffentlichen Entwürfe, die aus derselben Version entstanden sind. Wessen Text steht auf der
   Website?

<details>
<summary>Antworten</summary>

1. Einen eigenen Entwurf fortsetzen (**Ausgewählte bearbeiten**), **Neuer Entwurf** oder **Abbrechen**
   ([Inhalte erstellen und bearbeiten](../../../inhalte-bearbeiten.md#wenn-jemand-anderes-bearbeitet)).
2. **Falsch.** Machen Sie stattdessen daraus einen neuen Entwurf.
3. Auf der Versionsseite aus ihrem Entwurf **Neuen Entwurf machen**; der neue Entwurf gehört Ihnen.
4. **B.**
5. Der zuletzt veröffentlichte; er kann die Änderung des anderen rückgängig machen.

</details>

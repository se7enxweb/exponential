# Modul 6: Icons

Exponential kennt zwei Arten von Icons. Icons für Klassen und Dateitypen stammen aus Icon-Themes, also Ordnern mit
Bildern und einer `icon.ini`, und eine Erweiterung kann ein solches Theme mitliefern. Die Oberflächen-Icons von admin4
sind Bootstrap Icons, die als Masken in der Textfarbe gezeichnet werden, und eine Erweiterung kann eigene ergänzen.
Dieses kurze Modul behandelt beides und baut auf der Erweiterung und dem Dashboard-Block der vorigen Module auf.

| [Lektion 6.2: Icons in admin4](icons-in-admin4.md) | 45 Minuten | Dem Dashboard-Block Icons und einen benannten Link nur aus einem Icon hinzufügen; ein eigenes Icon ergänzen |

## Dieses Modul vorbereiten

- Für Lektion 6.1 zwei kleine PNG-Dateien pro Person (32 x 32 und 16 x 16), von den Teilnehmenden oder vom Trainer
  gezeichnet, oder die Erlaubnis, für die Übung eine Datei aus `share/icons/crystal-admin/` zu kopieren; notieren Sie
  für die Diskussion in Modul 8 die Lizenz in der Datei `COPYING` dieses Ordners.
- Eine Inhaltsklasse mit veröffentlichten Elementen in einem Ordner der Schulungs-Website; schreiben Sie ihren
  Bezeichner an die Tafel.
- Die Administration der Teilnehmenden in admin4 mit dem Block `training_notes` und der Datei `training_admin.css` aus
  Modul 4.
- Das Werkzeug **Oberfläche** muss für Schritt 9 von Lektion 6.1 das Design **Klassisch** anbieten (die Rolle braucht
  `uiswitch/design`).

# Modul 8: Lizenzieren und veröffentlichen

Ein Theme, das andere verwenden, braucht klare Bedingungen und Releases, denen man vertrauen kann. Dieses Modul
behandelt die Lizenz jedes Teils eines Themes, die Release-Routine, die nie einen veröffentlichten Tag verschiebt, und
das Changelog, die Release Notes und die Checklisten, die ein Release brauchbar machen. Alle Übungen zum Release finden
in einem lokalen Repository ohne Remote statt, sodass nichts versehentlich veröffentlicht werden kann. Mit diesem
Modul endet der Kurs.

## Lektionen

| Lektion | Dauer | Was die Teilnehmenden tun |
|---|---|---|
| [Lektion 8.1: Ein Theme lizenzieren](ein-theme-lizenzieren.md) | 45 Minuten | Eine Lizenzaufstellung ihres Themes machen und die Lizenzen an jeder Stelle eintragen |
| [Lektion 8.2: Versionen, und warum ein übertragener Tag dauerhaft ist](versionen-und-dauerhafte-tags.md) | 45 Minuten | Tags sortieren, die nächste Nummer wählen, anheben, committen, lokal einen annotierten Tag anlegen |
| [Lektion 8.3: Changelog, Release Notes und die Release-Checkliste](changelog-hinweise-und-checkliste.md) | 60 Minuten | `CHANGELOG.md` und Release Notes schreiben, die Checklisten durchgehen, ihre offenen Punkte benennen |

## Dieses Modul vorbereiten

- Das `training_theme` der Teilnehmenden in einem lokalen Git-Repository ohne Remote (Lektion 7.4). Prüfen Sie vor
  Lektion 8.2 mit `git remote -v`: Hat jemand ein Remote hinzugefügt, entfernen Sie es für die Übung.
- Sagen Sie zu Beginn von Lektion 8.1, dass die Lektion Lizenzentscheidungen anhand der Dokumentation erklärt und keine
  Rechtsberatung ist.
- Für Lektion 8.3 die Exponential-Version der Übungsumgebung (von der Seite „Über“, `/ezinfo/about`) an der Tafel.
- Lassen Sie am Ende von Lektion 8.3 10 Minuten für das Feedback zum Kurs
  ([Feedback einholen](../../../../../eng-us/help/trainers/train-the-trainer/module-06-assessment-and-follow-up/collecting-feedback.md)).

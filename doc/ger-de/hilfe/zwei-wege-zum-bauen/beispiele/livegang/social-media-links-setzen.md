# Die Social-Media-Links setzen

Die Fußzeile verlinkt die echten Profile der Site.

*Lebenszyklus: Livegang, Beispiel 9 von 33. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Bearbeiten Sie in der **Inhaltsstruktur** das Site-Info-Objekt (*Fit & Healthy site info*, Klasse Site info), tragen Sie die Profiladressen ein und veröffentlichen Sie es.

## Mit Templates

1. `pagelayout/footer.tpl` gibt für jedes der vier Felder, das Inhalt hat, ein Symbol aus; ein weiteres Netzwerk braucht ein Feld und eine Änderung am Template.

## Welchen Weg Sie wählen

Inhalte für die Adressen; ein Template nur für ein neues Netzwerk.

## Prüfen

- Jedes Symbol verlinkt das richtige Profil; leere Felder zeigen kein Symbol.

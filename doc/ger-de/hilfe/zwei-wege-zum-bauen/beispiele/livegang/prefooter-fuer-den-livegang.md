# Den Prefooter für den Livegang füllen

Das Band „Most popular articles“ zeigt echte Inhalte zum Livegang.

*Lebenszyklus: Livegang, Beispiel 10 von 33. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. **Layouts > Gemeinsame Layouts > Prefooter**, die Liste auswählen, **+ Elemente hinzufügen**, Platzhalter entfernen, ordnen, **Layout veröffentlichen**.

## Mit Templates

1. Eine feste Liste in einem Template bräuchte für jede Änderung ein Deployment; behalten Sie sie in Layouts.

## Welchen Weg Sie wählen

Der Layout-Editor.

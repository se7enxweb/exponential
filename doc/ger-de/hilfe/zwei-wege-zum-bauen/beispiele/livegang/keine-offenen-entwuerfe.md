# Sicherstellen, dass kein Entwurf offen bleibt

Livegang mit jedem Layout im veröffentlichten Zustand.

*Lebenszyklus: Livegang, Beispiel 14 von 33. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Auf der Kommandozeile](#auf-der-kommandozeile)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Öffnen Sie jedes gelistete Layout und klicken Sie auf **Layout veröffentlichen** oder **Verwerfen**.

## Auf der Kommandozeile

1. `./console exp:layouts list --drafts` listet sie mit dem Status `draft`.

## Welchen Weg Sie wählen

Räumen Sie vor dem Livegang auf; spätere Entwürfe sind normale laufende Arbeit.

## Prüfen

- Die Liste zeigt keinen Entwurf der Layouts der Site.

# Der Layout-Teil einer Checkliste für den Livegang

Auf der Layout-Seite wird nichts vergessen.

*Lebenszyklus: Livegang, Beispiel 20 von 33. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Auf der Kommandozeile](#auf-der-kommandozeile)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Jeder Seitentyp hat eine Zuordnung (oder fällt absichtlich auf Default Layout zurück).
2. Jedes Seitenlayout verknüpft `header` und `footer`.
3. Kein Entwurf ist offen.
4. Die gemeinsamen Layouts enthalten die Inhalte für den Livegang.
5. Ein Basis-Export ist vorhanden.

## Auf der Kommandozeile

1. `exp:layouts list` und `exp:layouts list --drafts` decken die ersten drei ab.

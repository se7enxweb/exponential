# Eine zweite Site auf derselben Installation live schalten

Eine weitere Site mit eigenen Layouts, ohne die erste zu stören.

*Lebenszyklus: Livegang, Beispiel 32 von 33. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Ihre Layouts und gemeinsamen Layouts (Bold Agency - Home, Starter - C - Header / Footer ...).
2. Zuordnungen mit einem Ziel **Teilbaum** auf ihre Wurzel und bei Bedarf einer Bedingung **Siteaccess** (die Starter-Zuordnungen verwenden `starter, starter_ger`).

## Mit Templates

1. Ihre eigenen Siteaccess-Einstellungen (`menu.ini`, `site.ini`) und, wenn sich das Design unterscheidet, ihre eigene Design-Erweiterung.

## Welchen Weg Sie wählen

Getrennte gemeinsame Layouts pro Site halten ihre Rahmen auseinander.

## Prüfen

- Jede Site zeigt ihre eigene Kopfzeile.

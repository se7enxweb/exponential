# Ein Layout vor dem Livegang in der Vorschau ansehen

Ein Layout begutachten, ohne eine Zuordnung zu veröffentlichen.

*Lebenszyklus: Livegang, Beispiel 30 von 33. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Unter **Layouts > Layouts** (oder **Gemeinsame Layouts**) **Vorschau** in der Zeile des Layouts.
2. Oder öffnen Sie es im Editor und sehen Sie sich den mittleren Bereich an.

## Mit Templates

1. Änderungen an Templates werden auf einer Testkopie begutachtet.

## Welchen Weg Sie wählen

Die Vorschau für Abnahmen; eine Test-Zuordnung (Pfad auf eine Testseite), um es im echten Seitenlayout zu sehen.

- Der Prüfer hat jeden Block gesehen.

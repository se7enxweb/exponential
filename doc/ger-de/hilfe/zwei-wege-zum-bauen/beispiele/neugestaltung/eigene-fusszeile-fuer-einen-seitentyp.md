# Einem Seitentyp eine eigene Fußzeile geben

Die Kampagnenseiten bekommen eine reduzierte Fußzeile.

*Lebenszyklus: Neugestaltung, Beispiel 13 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Klicken Sie im Kampagnen-Layout auf die Verknüpfungs-Schaltfläche (unten links); die verknüpfte Zone FOOTER hat ein Menü `...` mit **Verknüpfung ändern** (eine andere Zone wählen) und **Verknüpfung aufheben**. **Verknüpfung aufheben**, eigene Blöcke hinzufügen, **Layout veröffentlichen**.

## Mit Templates

1. Oder behalten Sie die Verknüpfung und lassen Sie das Template der Fußzeile auf die Seite reagieren (zum Beispiel über eine CSS-Klasse am Layout): mehr Code, eine Fußzeile.

## Welchen Weg Sie wählen

Das Aufheben der Verknüpfung ist eindeutig, aber dieses Layout folgt dann keinen Änderungen an der gemeinsamen Fußzeile mehr.

## Prüfen

- Nur die Kampagnenseiten zeigen die reduzierte Fußzeile.

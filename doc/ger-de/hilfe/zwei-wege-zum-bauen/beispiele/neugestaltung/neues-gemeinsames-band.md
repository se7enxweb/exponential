# Ein neues gemeinsames Band für viele Seitentypen

Ein Newsletter-Band, gezeigt auf Artikeln, Themen und Landingpages.

*Lebenszyklus: Neugestaltung, Beispiel 11 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. **Layouts > Gemeinsame Layouts > Neues gemeinsames Layout**, Typ **Single zone**; bauen Sie das Band; veröffentlichen Sie.
2. Verknüpfen Sie in jedem Seitenlayout dessen `pre_footer` (oder eine andere freie Zone) mit `main` des neuen gemeinsamen Layouts.

## Mit Templates

1. Ein Template-Block in `pre_footer` von Header / Footer wäre der Weg über Templates, aber nur Layouts, die diese Zone verknüpfen, würden ihn zeigen.

## Welchen Weg Sie wählen

Ein gemeinsames Layout pro Band hält jedes Band für sich bearbeitbar.

## Prüfen

- `exp:layouts list` zeigt für jedes Seitenlayout den neuen Bezeichner unter *Links to*.

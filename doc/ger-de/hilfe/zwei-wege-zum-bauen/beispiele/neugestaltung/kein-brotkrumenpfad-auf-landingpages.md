# Kein Brotkrumenpfad auf Landingpages

Landingpages ohne Brotkrumenpfad.

*Lebenszyklus: Neugestaltung, Beispiel 22 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Möglichkeit A: Heben Sie die Verknüpfung der Zone header der Landingpage-Layouts auf und fügen Sie nur den Template-Block der Kopfzeile hinzu.

## Mit Templates

1. Möglichkeit B: Behalten Sie die Verknüpfung und blenden Sie den Brotkrumenpfad per CSS aus, wo das Layout eine Landingpage ist (der Layout-Wrapper ist bei allen `zone-layout-layout2`, setzen Sie also eine CSS-Klasse über einen Block des Layouts oder über den Body).

## Welchen Weg Sie wählen

Möglichkeit A ist eindeutig, löst diese Layouts aber von Änderungen an der Kopfzeile.

## Prüfen

- Landingpages haben keinen Brotkrumenpfad; Artikel haben ihn weiterhin.

# Das Logo ändern

Das neue Logo in Kopf- und Fußzeile.

*Lebenszyklus: Neugestaltung, Beispiel 26 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

Keine Änderung am Layout.

## Mit Templates

1. `content/parts/site_logo.tpl` des Media-Designs liest das Feld **site_logo** des Site-Info-Objekts: Laden Sie dort das neue Logo hoch und veröffentlichen Sie; überschreiben Sie das Template nur für neues Markup.

## Welchen Weg Sie wählen

Inhalt, wenn das Template das Feld liest; sonst das Template.

## Prüfen

- Kopf- und Fußzeile zeigen das neue Logo.

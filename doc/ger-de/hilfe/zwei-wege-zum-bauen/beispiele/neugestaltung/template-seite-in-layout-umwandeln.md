# Eine mit Templates gebaute Seite in ein Layout umwandeln

Die Redakteure können eine Seite neu anordnen, die früher ein einziges Template war.

*Lebenszyklus: Neugestaltung, Beispiel 15 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Legen Sie ein Layout an, verknüpfen Sie Kopf- und Fußzeile, fügen Sie **Template block**s mit den Namen der Teile und Standardblöcke für die einfachen Teile hinzu; veröffentlichen und zuordnen.

## Mit Templates

1. Zerlegen Sie das Template in Teile, die für sich stehen; speichern Sie jeden als `explayouts/tpl_block/<name>.tpl` in Ihrer Erweiterung.

## Welchen Weg Sie wählen

Gehen Sie Teil für Teil vor; jeder Schritt bleibt veröffentlichbar.

## Prüfen

- Das neue Layout zeigt dieselben Inhalte wie das alte Template.

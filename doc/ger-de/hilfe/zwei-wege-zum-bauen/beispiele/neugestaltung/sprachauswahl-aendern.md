# Die Sprachauswahl ändern

Sprachen als Flaggen statt als Liste.

*Lebenszyklus: Neugestaltung, Beispiel 23 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

Keine Änderung am Layout.

## Mit Templates

1. Kopieren Sie `extension/sevenx_themes_media/design/media/templates/pagelayout/header/language_selector.tpl` nach `extension/mysite/design/media/templates/pagelayout/header/language_selector.tpl`.
2. Ändern Sie das Markup.
3. Leeren Sie **Template & Inhalt** und prüfen Sie eine Seite, die es verwendet.

## Welchen Weg Sie wählen

Templates.

## Prüfen

- Die Auswahl wechselt den Siteaccess wie vorher.

# Die Landingpages im Editor neu gestalten

Eine frischere Startseite für Fitness, von den Redakteuren gestaltet.

*Lebenszyklus: Neugestaltung, Beispiel 27 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Öffnen Sie Landing Page / Fitness (10 Blöcke); ordnen Sie neu an, ändern Sie Ansichten, fügen Sie neue Blöcke hinzu; veröffentlichen Sie.

## Mit Templates

1. Nur neue Ansichten (Ansichtstypen, Overrides) brauchen Arbeit an Templates.

## Welchen Weg Sie wählen

Redakteure gestalten die Zusammenstellung neu; Entwickler fügen Ansichten hinzu.

## Prüfen

- Bildschirmfotos vorher und nachher; ein Export von vorher.

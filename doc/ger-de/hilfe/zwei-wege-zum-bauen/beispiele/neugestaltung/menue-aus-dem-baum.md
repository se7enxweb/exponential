# Das feste Kopfmenü durch den Baum ersetzen

Bereiche kommen ins Menü, indem sie veröffentlicht werden.

*Lebenszyklus: Neugestaltung, Beispiel 5 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

Nichts im Layout-Editor; `MainMenuID[]` wird von Ihrem Template nicht mehr gelesen.

## Mit Templates

1. Folgen Sie [Ein Kopfmenü, das dem Baum folgt](../../kopfmenue-aus-dem-baum.md): Einstellungen `[MySiteMenu]`, das Template, die Reihenfolge der Aktivierung, das Leeren des Cache.

## Welchen Weg Sie wählen

Legen Sie die Längenbegrenzung gemeinsam mit dem Design fest.

## Prüfen

- Ein neuer Ordner unterhalb der Wurzel erscheint im Menü.

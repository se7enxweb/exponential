# Ein anderer Hintergrund pro Layout

Kampagnen-Layouts mit einem farbigen Band hinter dem Hero.

*Lebenszyklus: Neugestaltung, Beispiel 28 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Ziehen Sie **Column** in `main`, setzen Sie ihre Hintergrundfarbe, verschieben Sie den Hero in den Platzhalter `main` der Column; veröffentlichen Sie.

## Mit Templates

1. Oder CSS für eine Klasse, die an der Column gesetzt ist (CSS class im Reiter **Design**).

## Welchen Weg Sie wählen

Eine Column mit Hintergrund für Einzelfälle; eine CSS-Klasse für einen wiederverwendbaren Stil.

## Prüfen

- Der Wrapper der Column hat `bg-color-<color>`.

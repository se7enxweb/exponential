# Eine Neugestaltung Schritt für Schritt einführen

Kein Release mit dem großen Knall.

*Lebenszyklus: Neugestaltung, Beispiel 34 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Abschluss](#abschluss)
4. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
5. [Prüfen](#prüfen)

## Im Layout-Editor

1. Stellen Sie Blöcke Layout für Layout auf die neuen Ansichtstypen um; veröffentlichen Sie jedes.

## Mit Templates

1. Liefern Sie neue Ansichtstypen und Overrides aus, die nur gelten, wenn sie gewählt werden.

## Abschluss

1. Wenn kein Block mehr eine alte Ansicht verwendet, mustern Sie sie aus ([Einen Ansichtstyp nach einer Neugestaltung ausmustern](ansichtstyp-ausmustern.md)).

## Welchen Weg Sie wählen

Schritte, die nur hinzufügen, halten jeden Schritt umkehrbar.

## Prüfen

- Bei jedem Schritt ist die Site in sich stimmig.

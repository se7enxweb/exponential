# Einen Block in ein Template einfrieren

Der rechtliche Hinweis lässt sich nicht versehentlich bearbeiten.

*Lebenszyklus: Neugestaltung, Beispiel 16 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Ersetzen Sie den alten Block durch einen **Template block** mit dem Namen `disclaimer`; veröffentlichen Sie.

## Mit Templates

1. Schreiben Sie den Hinweis in `explayouts/tpl_block/disclaimer.tpl`.

## Welchen Weg Sie wählen

Nur für das, was sich wirklich nicht ändern darf; Redakteure verlieren absichtlich die Kontrolle.

## Prüfen

- Der Block lautet im Editor „Template block: **disclaimer**“.

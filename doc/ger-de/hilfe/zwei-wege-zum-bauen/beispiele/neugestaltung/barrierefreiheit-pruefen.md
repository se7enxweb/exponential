# Die Barrierefreiheit nach einer Neugestaltung prüfen

Das neue Design ist so barrierefrei wie das alte.

*Lebenszyklus: Neugestaltung, Beispiel 33 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Prüfen Sie Blöcke mit eingetippten Inhalten: Image alt text, Image alt text des Hero, Ebenen der Titel.

## Mit Templates

1. Prüfen Sie die überschriebenen Templates: ein einziges `h1`, Überschriften in der richtigen Reihenfolge, Fokus-Stile, `alt`-Attribute.

## Welchen Weg Sie wählen

Beide Hälften brauchen die Prüfung.

## Prüfen

- Ein Prüfwerkzeug für Barrierefreiheit meldet auf den wichtigsten Seitentypen kein ernstes Problem.

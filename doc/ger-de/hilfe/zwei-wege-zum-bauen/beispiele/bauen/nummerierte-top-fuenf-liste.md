# Eine nummerierte Top-Fünf-Liste

„Top 5 recipes this month“, nummeriert.

*Lebenszyklus: Bauen, Beispiel 22 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)

4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Öffnen Sie **Layouts > Layouts** und das Layout *Landing Page / Home*; der Editor öffnet es in einem Entwurf.
2. Öffnen Sie die Blockpalette (**+** oben links) und ziehen Sie **List** (Gruppe *Listing*) in die Zone `main`.
3. Füllen Sie die Sammlung mit fünf Rezepten.
4. Wählen Sie den Block aus, öffnen Sie den Reiter **Design** und setzen Sie **Ansichtstyp** auf `list_numbered`.
5. **Layout veröffentlichen**. Die Seiten, die das Layout verwenden, zeigen den Block beim nächsten Aufruf.

Wird nur der Ansichtstyp geändert, wird nichts gespeichert, bis sich ein anderes Feld ändert ([Bekanntes Verhalten des Editors](../../bekanntes-verhalten-des-editors.md)).

## Mit Templates

1. In einem Template leistet ein `<ol>` um die geholten Einträge dasselbe.

## Welchen Weg Sie wählen

Der Ansichtstyp ist eine einzige Auswahl im Editor.

## Prüfen

- Die Nummern beginnen bei 1 und folgen der Reihenfolge der Sammlung.

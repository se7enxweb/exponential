# Vier gleiche Spalten

Vier kurze Beschreibungen von Leistungen in einer Reihe.

*Lebenszyklus: Bauen, Beispiel 31 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Öffnen Sie **Layouts > Layouts** und das Layout *Landing Page / Home*; der Editor öffnet es in einem Entwurf.
2. Öffnen Sie die Blockpalette (**+** oben links) und ziehen Sie **Four columns** (Gruppe *Containers*) in die Zone `main`.
3. Ziehen Sie einen Block in jeden Platzhalter, `col_1` bis `col_4`.
4. **Layout veröffentlichen**. Die Seiten, die das Layout verwenden, zeigen den Block beim nächsten Aufruf.

## Mit Templates

1. Oder ein einziger List-Block mit der Ansicht `grid` und **Number of columns** 4, wenn die vier Inhaltsobjekte sind.

## Welchen Weg Sie wählen

Verschiedene Blocktypen pro Spalte: Four columns. Vier Inhaltsobjekte einer Art: ein Raster.

## Prüfen

- Jede Spalte enthält ihren Block.

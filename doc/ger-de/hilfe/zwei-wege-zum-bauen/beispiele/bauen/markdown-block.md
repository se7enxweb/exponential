# Ein in Markdown geschriebener Block

Eine kurze Liste der Öffnungszeiten, in Markdown getippt.

*Lebenszyklus: Bauen, Beispiel 9 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Öffnen Sie **Layouts > Layouts** und das Layout *Landing Page / Home*; der Editor öffnet es in einem Entwurf.
2. Öffnen Sie die Blockpalette (**+** oben links) und ziehen Sie **Markdown** (Gruppe *Basic*) in die Zone `main`.
3. Wählen Sie den Block aus, öffnen Sie den Reiter **Design** und füllen Sie **Markdown content** aus.
4. **Layout veröffentlichen**. Die Seiten, die das Layout verwenden, zeigen den Block beim nächsten Aufruf.

Das Standard-Template gibt das umgewandelte HTML (`$block.values.html`) innerhalb von `<div class="slb slb-markdown">` aus.

## Mit Templates

1. Verwenden Sie stattdessen ein Rich-Text- oder Textfeld eines Inhaltsobjekts; Inhaltsfelder werden mit dem Editor der Site bearbeitet.

## Welchen Weg Sie wählen

Markdown ist schnell für Listen und Links; Inhaltsfelder sind besser, wenn der Text übersetzt werden muss.

## Prüfen

- Listen und Links erscheinen als HTML, nicht als Sternchen und Klammern.

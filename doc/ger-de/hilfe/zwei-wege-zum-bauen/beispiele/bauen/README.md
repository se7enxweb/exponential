# Beispiele zum Bauen, alle Seiten

Die Blöcke, Listen, Galerien, Spalten und Templates der Seiten anlegen.

1. [Ein Hero-Banner oben auf einer Seite](hero-banner.md): Ein großes Bild mit Titel, einem Satz und einer Schaltfläche: der Hero-Block mit seinen sechs Feldern oder ein Template-Block mit demselben Markup.
2. [Ein Abschnitt „Über uns“ mit Bild und Text](ueber-uns-abschnitt.md): Titel, Text, Bild und Link nebeneinander: der About-Block oder dasselbe Markup in einem Template-Block.
3. [Eine Reihe mit drei Merkmalen](reihe-mit-drei-merkmalen.md): Drei kurze Verkaufsargumente: der Features-Block, ein Three-columns-Container mit drei Cards oder ein Template.
4. [Eine Wand mit Partnerlogos aus einem Ordner](logowand-aus-einem-ordner.md): Der Logos-Block liest Bilder aus einem übergeordneten Knoten (Parent node ID, Limit, Class filter, Image attribute identifier, Thumbnail size alias); oder ein Fetch in einem Template.
5. [Ein Kundenzitat](kundenzitat.md): Der Quote-Block mit Quote text, Author, Source und Alignment oder dasselbe in einem Template.
6. [Eine Schaltfläche mit Handlungsaufforderung](schaltflaeche-mit-handlungsaufforderung.md): Der Button / Link-Block (Text, Style, Target, Use link) oder ein Link in einem Template.
7. [Eine Abschnittsüberschrift mit der richtigen Ebene](abschnittsueberschrift.md): Der Title-Block (Title, Heading level 1-6, HTML tag, Use link) für Überschriften zwischen Blöcken.
8. [Ein Absatz formatierter Text](absatz-formatierter-text.md): Der Rich-text-Block (Content) oder der Text-Block für einfachen Text; in Templates der Text eines Inhaltsfelds.
9. [Ein in Markdown geschriebener Block](markdown-block.md): Der Markdown-Block (Markdown content) für Redakteure, die Markdown bevorzugen.
10. [Ein Einbettungscode eines anderen Dienstes](einbettungscode-eines-anderen-dienstes.md): Der HTML-snippet-Block (Raw HTML) für einen Widget-Code und worauf zu achten ist; oder der Code in einem Template.
11. [Ein Bild mit einem Link](bild-mit-link.md): Der Image-Block (Image URL, Alt text, Link URL) oder ein Bildattribut, das ein Template ausgibt.
12. [Abstand und eine Linie zwischen Abschnitten](abstand-und-trennlinie.md): Die Blöcke Spacer (Height in pixels, Standard 32) und Divider (Style, Margin) oder vertikaler Leerraum an den Blöcken selbst.
13. [Ein Hinweisbanner](hinweisbanner.md): Der Alert-Block (Message, Type, Dismissible) für einen kurzen Hinweis oder ein Template-Block.
14. [Häufig gestellte Fragen als Akkordeon](faq-als-akkordeon.md): Der Accordion-Block (Items „Title|Content“ pro Zeile, Open first item) oder der Block Accordion (List) über Inhaltsobjekte.
15. [Reiter mit kurzen Texten](reiter-mit-kurzen-texten.md): Der Tabs-Block (Tabs „Title|Content“ pro Zeile, Active tab index).
16. [Eine Karte auf der Kontaktseite](karte-auf-der-kontaktseite.md): Der Map-Block (Map embed URL, Width, Height) im Layout der Kontaktseite.
17. [Ein externes Video](externes-video.md): Der Block External video (Video URL or embed src, Width, Height, Autoplay) oder ein Video-Inhaltsobjekt.
18. [Eine Liste der neuesten Artikel eines Bereichs](neueste-artikel-eines-bereichs.md): Ein List-Block mit einer dynamischen Sammlung (übergeordneter Ort, Sortierung nach Veröffentlichung, Limit) oder fetch() in einem Template.
19. [Handverlesene Teaser](handverlesene-teaser.md): Ein List-Block mit einer manuellen Sammlung, die Einträge im Content Browser ausgewählt und durch Ziehen geordnet.
20. [Ein Raster von Artikeln in vier Spalten](raster-in-vier-spalten.md): Der List-Block in der Ansicht grid mit Number of columns 4 (oder der Grid-Block), Ansichtstyp der Einträge Card.
21. [Abwechselnde Zeilen aus Bild und Text](abwechselnde-zeilen-bild-und-text.md): Der Block Zig-Zag (List) oder der List-Block in der Ansicht list_zigzag.
22. [Eine nummerierte Top-Fünf-Liste](nummerierte-top-fuenf-liste.md): Der List-Block in der Ansicht list_numbered.
23. [Ein Raster mit einem hervorgehobenen Eintrag](raster-mit-hervorgehobenem-eintrag.md): Der List-Block in der Ansicht grid_featured: der erste Eintrag groß, der Rest in einem Raster.
24. [Eine Bildergalerie aus einem Ordner](bildergalerie-aus-einem-ordner.md): Der Gallery-Block (Parent node ID, Limit, Class filter, Image attribute identifier, Thumbnail size alias) oder ein Galerie-Inhaltsobjekt.
25. [Ein Bilder-Slider](bilder-slider.md): Der Slider-Block mit denselben Feldern für die Bildquelle wie die Gallery.
26. [Eine Galerie mit Vorschaubildern](galerie-mit-vorschaubildern.md): Der Block Thumb gallery: ein großes Bild mit Vorschaubildern darunter.
27. [Ein Fotoraster](fotoraster.md): Der Block Grid gallery: alle Bilder in einem Raster.
28. [Ein waagerecht scrollender Bildstreifen](waagerechter-bildstreifen.md): Der Block Sushi bar: ein Streifen, der seitwärts scrollt.
29. [Ein Karussell von Inhaltsobjekten](karussell.md): Der Carousel-Block (Slides per view, Autoplay in ms, Image attribute identifier und die Listenoptionen) mit einer Sammlung.
30. [Eine Aufteilung in zwei Drittel und ein Drittel](zwei-drittel-ein-drittel.md): Der Two-columns-Container in der Ansicht two_columns_66_33 (oder 33_66) mit Blöcken in left und right.
31. [Vier gleiche Spalten](vier-gleiche-spalten.md): Der Four-columns-Container (Platzhalter col_1 bis col_4).
32. [Ein Inhaltsobjekt als Teaser](inhaltsobjekt-als-teaser.md): Der Block Single content (Node ID, Show name, Show intro).
33. [Der eigene Inhalt der Seite in einem Layout](eigener-inhalt-der-seite-im-layout.md): Der Full-view-Block setzt die Full View der Seite (den Inhalt selbst) zwischen andere Blöcke.
34. [Ein eigenes Widget, das nur ein Entwickler bauen kann](eigenes-widget-als-template-block.md): Alles, was die Blocktypen nicht können (ein Rechner, ein Datenfeed), ist ein Template; mit dem Template-Block können Redakteure es platzieren.
35. [Ein eigener Blocktyp](eigener-blocktyp.md): Wenn Redakteure immer wieder eine neue Art von Block brauchen, definieren Sie sie einmal: Definition, Handler, Template.

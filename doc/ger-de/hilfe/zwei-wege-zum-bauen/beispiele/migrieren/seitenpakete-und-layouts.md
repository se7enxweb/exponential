# Seitenpakete und Layouts

Eine neue Installation aus Paketen bekommt auch ihre Layouts.

*Lebenszyklus: Migrieren, Beispiel 18 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Auf der Kommandozeile](#auf-der-kommandozeile)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Prüfen Sie nach dem Import die Zuordnungen.

## Auf der Kommandozeile

1. Installieren Sie zuerst die Inhaltspakete, dann `exp:layouts import` für die Layouts (Inhalte werden über Remote-ID und Pfad gefunden), dann **Template & Inhalt**.

## Welchen Weg Sie wählen

Zuerst die Inhalte, dann die Layouts.

## Prüfen

- Der Probelauf findet die Verweise auf Inhalte.

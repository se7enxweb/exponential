# Die Migration auf einer Kopie proben

Die Live-Migration ist die Wiederholung eines getesteten Skripts.

*Lebenszyklus: Migrieren, Beispiel 32 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Auf einer Kopie](#auf-einer-kopie)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Öffnen Sie die importierten Layouts auf der Kopie im Editor.

## Auf einer Kopie

1. Machen Sie eine Kopie des Ziels, führen Sie die ganze Abfolge aus (Importe, Verschiebungen mit `exp:ini`, Leeren der Caches) und prüfen Sie die Seiten.

## Welchen Weg Sie wählen

Jede Migration verdient eine Probe.

## Prüfen

- Die Kopie sieht aus wie das geplante Ergebnis.

# Kopierte HTML-Snippets durch einen Blocktyp ersetzen

Keine Kopien desselben Kastens als rohes HTML mehr.

*Lebenszyklus: Migrieren, Beispiel 28 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Finden Sie die Snippets in einem Export (`"definition_identifier": "html"` in `layouts.json`); ersetzen Sie jedes durch den neuen Block; veröffentlichen Sie.

## Mit Templates

1. Definieren Sie den Blocktyp ([Einen Blocktyp hinzufügen](../../blocktyp-hinzufuegen.md)).

## Welchen Weg Sie wählen

Tun Sie es, sobald dasselbe Markup dreimal vorkommt.

## Prüfen

- Ein neuer Export hat weniger Blöcke vom Typ `html`.

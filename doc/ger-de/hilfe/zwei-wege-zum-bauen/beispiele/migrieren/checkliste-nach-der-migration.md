# Die Checkliste nach einer Migration

Die migrierte Site ist vollständig.

*Lebenszyklus: Migrieren, Beispiel 34 von 34. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Auf der Kommandozeile](#auf-der-kommandozeile)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. `exp:layouts list` (Zuordnungen, Verknüpfungen) und `--drafts` (keine Entwürfe aus dem Import übrig).

## Auf der Kommandozeile

1. Seitenmarkierungen (`zone zone-...`, `ngl-block`, IDs der Menüeinträge) auf jedem Seitentyp; `exp:ini get` der Menülisten; **Template & Inhalt** geleert; Velocity neu gestartet.

## Welchen Weg Sie wählen

Gehen Sie sie direkt nach der Migration und am nächsten Tag noch einmal durch.

- Alle Prüfungen bestehen.

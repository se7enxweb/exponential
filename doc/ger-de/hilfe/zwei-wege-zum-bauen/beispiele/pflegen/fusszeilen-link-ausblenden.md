# Einen Fußzeilen-Link eine Zeit lang ausblenden

Der Link „Cart“ verschwindet, solange der Shop geschlossen ist.

*Lebenszyklus: Pflegen, Beispiel 11 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Im Inhaltsbaum](#im-inhaltsbaum)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

Nicht im Layout-Editor.

## Im Inhaltsbaum

1. Verstecken Sie unter **Footer links** das Menu item *Cart* (über sein Menü in der Liste der Unterelemente oder die Sichtbarkeits-Schaltfläche); decken Sie es später wieder auf.

## Welchen Weg Sie wählen

Verstecken behält den Eintrag für später; Entfernen schickt ihn in den Papierkorb.

## Prüfen

- Die Fußzeile zeigt den Link nicht mehr.

# Ein neues Rezept erscheint in den Listen

Das neue Rezept erscheint auf der Rezeptübersicht und unter „latest recipes“.

*Lebenszyklus: Pflegen, Beispiel 34 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Im Inhaltsbaum](#im-inhaltsbaum)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Listen mit einer dynamischen Sammlung auf Recipes zeigen es; handverlesene Listen brauchen **+ Add items**, wenn es dort hingehört.

## Im Inhaltsbaum

1. Legen Sie das Rezept (Recipe) unterhalb von Recipes (Knoten 144) an und klicken Sie auf **Zur Veröffentlichung schicken**.

## Welchen Weg Sie wählen

Dynamische Listen für Übersichten; manuelle nur für kuratierte Stellen.

## Prüfen

- Das Rezept steht auf der Übersichtsseite; es verwendet Full / Recipe.

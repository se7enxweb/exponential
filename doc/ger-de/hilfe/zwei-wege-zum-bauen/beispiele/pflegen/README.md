# Beispiele zur Pflege, alle Seiten

Listen, Banner, Menüs und Kampagnen Woche für Woche ändern und Fehler beheben.

1. [Einen Artikel in einer handverlesenen Liste austauschen](artikel-in-handverlesener-liste-austauschen.md): Einen Eintrag aus einer manuellen Sammlung entfernen und an seiner Stelle einen anderen hinzufügen, im Layout-Editor.
2. [Eine handverlesene Liste umordnen](handverlesene-liste-umordnen.md): Die Einträge einer manuellen Sammlung in eine neue Reihenfolge ziehen; die Reihenfolge nach dem Veröffentlichen prüfen.
3. [Eine dynamische Liste auf einen anderen Bereich richten](quelle-einer-dynamischen-liste-aendern.md): Die Parent location einer dynamischen Sammlung ändern; die Liste füllt sich sofort aus dem neuen Bereich.
4. [Mehr Einträge in einer Liste zeigen](mehr-eintraege-zeigen.md): Versatz & Anzahl der Elemente (dynamische Sammlungen) oder mehr manuelle Einträge; Enable pagination für lange Listen.
5. [Das Hero-Bild ersetzen](hero-bild-ersetzen.md): Image URL und Image alt text des Hero-Blocks ändern oder ein neues Bild in den Inhalt hochladen, den das Template liest.
6. [Text und Ziel einer Schaltfläche ändern](text-und-ziel-einer-schaltflaeche-aendern.md): Text and link eines Button / Link-Blocks oder Link text und Link URL eines Hero bearbeiten.
7. [Einen Eintrag des Kopfmenüs umbenennen](menueeintrag-umbenennen.md): Das Kopfmenü gibt den Namen des Knotens aus: Benennen Sie die Seite im Inhaltsbaum um und veröffentlichen Sie sie.
8. [Einen Eintrag aus dem Kopfmenü nehmen](eintrag-aus-dem-kopfmenue-nehmen.md): Seine Zeile aus MainMenuID[] löschen (Administration) oder exp:ini rem (Konsole), dann Template & Inhalt.
9. [Einen Eintrag des Kopfmenüs nach vorn verschieben](menueeintrag-nach-vorn-verschieben.md): Die Zeilen von MainMenuID[] in der Administration umordnen oder exp:ini clear und add in der neuen Reihenfolge.
10. [Einen Link zur zweiten Zeile der Fußzeile hinzufügen](fusszeilen-link-hinzufuegen.md): Ein Menu item in Media > Configuration > Footer links mit Title und Item URL anlegen; kein Cache leeren nötig.
11. [Einen Fußzeilen-Link eine Zeit lang ausblenden](fusszeilen-link-ausblenden.md): Das Menu item im Inhaltsbaum verstecken; die Fußzeile listet nur, was der Besucher sehen darf.
12. [Die Adresse eines Social-Media-Profils ändern](social-media-profil-aendern.md): Das passende Feld (facebook, twitter, instagram, linkedin) des Site-Info-Objekts bearbeiten.
13. [Ein saisonales Layout von Hand wechseln](saisonales-layout-von-hand-wechseln.md): Zwei Zuordnungen für dieselbe Seite, die saisonale mit höherer Priorität: Aktiviert an- oder abhaken, um umzuschalten.
14. [Ein saisonales Layout nach Datum wechseln](saisonales-layout-nach-datum-wechseln.md): Eine Zeit-Bedingung (from, to) an der saisonalen Zuordnung schaltet sie um, ohne dass jemand klickt, mit bis zu einer Stunde Verzögerung durch das Gedächtnis des Resolvers.
15. [Einen vorübergehenden Hinweis aufstellen](voruebergehender-hinweis.md): Ein Alert-Block in der Zone post_header der Seite, nach dem Ereignis wieder entfernt.
16. [Den hervorgehobenen Eintrag eines Rasters wechseln](hervorgehobenen-eintrag-wechseln.md): In einer grid_featured-Liste ist der erste Eintrag der große: Ziehen Sie einen anderen Eintrag nach oben.
17. [Die Anzahl der Spalten eines Rasters ändern](spaltenzahl-aendern.md): Number of columns im Reiter Design: 2, 3, 4 oder 6.
18. [Eine Liste von Raster auf Liste umstellen](von-raster-auf-liste-umstellen.md): View type im Reiter Design, mit der Eigenheit, dass die Änderung erst mit der nächsten Änderung eines anderen Felds gespeichert wird.
19. [Einem Abschnitt eine Hintergrundfarbe geben](hintergrundfarbe-setzen.md): Set background color im Reiter Design; der Wrapper erhält bg-color-<color>.
20. [Die Abstände eines Abschnitts anpassen](abstaende-anpassen.md): Use vertical whitespace on top and bottom (Reiter Design) statt Spacer-Blöcken verwenden.
21. [Einen misslungenen Entwurf verwerfen](misslungenen-entwurf-verwerfen.md): Verwerfen entfernt den Entwurf; das veröffentlichte Layout bleibt unberührt.
22. [Eine veröffentlichte Layoutänderung rückgängig machen](veroeffentlichte-aenderung-rueckgaengig-machen.md): Den vor der Änderung gemachten Export mit --strategy=overwrite --publish importieren, dann Inhalte leeren.
23. [Layouts jede Woche exportieren](woechentlicher-export.md): Ein geplanter exp:layouts export --all bewahrt eine Historie der Layouts.
24. [Vergessene Entwürfe finden](vergessene-entwuerfe-finden.md): exp:layouts list --drafts listet jeden offenen Entwurf; öffnen Sie jeden und veröffentlichen oder verwerfen Sie ihn.
25. [Eine Änderung erschien nicht](aenderung-erscheint-nicht.md): Entwurf nicht veröffentlicht, verknüpfte Zone, anderes Layout, Einstellungen in der falschen Datei, kompiliertes Template, Seiten-Cache, Velocity: die zehn Prüfungen.
26. [Ein neuer Bereich kommt ins Kopfmenü](neuer-bereich-im-kopfmenue.md): Die Bereichsseite veröffentlichen, ihre Knoten-ID finden, sie zu MainMenuID[] hinzufügen, Template & Inhalt leeren.
27. [Eine Kampagnenseite beenden](kampagnenseite-beenden.md): Ihre Zuordnung deaktivieren, das Layout für nächstes Jahr behalten, die Seite verstecken oder archivieren.
28. [Die Kampagne des Vorjahres wiederverwenden](kampagne-des-vorjahres-wiederverwenden.md): Den Export des Vorjahres als Kopie importieren (--strategy=copy), die Texte ändern, es zuordnen.
29. [Blocktexte in zwei Sprachen pflegen](blocktexte-in-zwei-sprachen.md): In Blöcke getippte Texte gehören zum Layout; für eine zweite Sprache ein Layout pro Siteaccess oder Text aus übersetzten Inhalten.
30. [Die in Blöcke getippten Links prüfen](links-in-bloecken-pruefen.md): In Button-, Hero-, Card- und Image-Blöcke getippte Links folgen verschobenen Seiten nicht; prüfen Sie sie nach einer Umstrukturierung.
31. [Die Datenschutz- oder Cookie-Richtlinie aktualisieren](rechtliche-seiten-aktualisieren.md): Den Artikel bearbeiten (Privacy Policy, Knoten 90; Cookie Policy, Knoten 91); ihr Layout und die Fußzeilen-Links folgen.
32. [Ein monatlicher Blick auf die Caches](monatlicher-blick-auf-die-caches.md): exp:cache list zeigt jeden Cache; achten Sie auf Wachstum und stellen Sie sicher, dass das Seiten-Caching noch funktioniert.
33. [Wenn ein Redakteur das gemeinsame Layout versehentlich geändert hat](gemeinsames-layout-versehentlich-geaendert.md): Eine Änderung an Header / Footer oder Prefooter zeigt sich auf vielen Seiten; setzen Sie sie aus dem letzten Export zurück.
34. [Ein neues Rezept erscheint in den Listen](rezept-erscheint-in-den-listen.md): Das Rezept unterhalb von Recipes veröffentlichen; dynamische Listen zeigen es, manuellen Listen muss es hinzugefügt werden.
35. [Die Site-Dokumentation aktuell halten](site-dokumentation-aktuell-halten.md): Nach jeder Änderung von Menüs, Zuordnungen oder Overrides den in der Planungsphase geschriebenen Site-Leitfaden aktualisieren.

# Eine Liste von Raster auf Liste umstellen

Das Rezeptraster wird zu einer einfachen Liste.

*Lebenszyklus: Pflegen, Beispiel 18 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Wählen Sie die Liste aus, dann **Design**, **Ansichtstyp** `list`.
2. Ändern Sie einmal ein anderes Feld (tippen und löschen Sie ein Zeichen in **CSS class**), damit das Formular gespeichert wird.
3. Prüfen Sie, dass der Blockkopf `LIST` zeigt, und klicken Sie auf **Layout veröffentlichen**.

## Mit Templates

1. Keine Aufgabe für Templates.

## Welchen Weg Sie wählen

Design-Option; beachten Sie die Eigenheit beim Speichern.

## Prüfen

- Der Blockkopf zeigt den neuen Ansichtstyp vor dem Veröffentlichen.

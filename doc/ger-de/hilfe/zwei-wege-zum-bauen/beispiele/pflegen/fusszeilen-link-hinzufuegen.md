# Einen Link zur zweiten Zeile der Fußzeile hinzufügen

Ein Link „Careers“ in der Fußzeile.

*Lebenszyklus: Pflegen, Beispiel 10 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Im Inhaltsbaum](#im-inhaltsbaum)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

Nicht im Layout-Editor.

## Im Inhaltsbaum

1. Wählen Sie unter **Media > Configuration > Footer links** **Neu erstellen > Menu item**, als Title *Careers*, als **Item URL** die Adresse, dann **Zur Veröffentlichung schicken**; setzen Sie seine Priorität, um ihn einzuordnen.

## Welchen Weg Sie wählen

Inhalt: Das erledigen Redakteure.

## Prüfen

- Der Link erscheint beim nächsten Seitenaufruf.

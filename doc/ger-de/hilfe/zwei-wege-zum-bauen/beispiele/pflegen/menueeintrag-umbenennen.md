# Einen Eintrag des Kopfmenüs umbenennen

Aus „Healthy eating“ soll im Menü „Nutrition“ werden.

*Lebenszyklus: Pflegen, Beispiel 7 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Im Inhaltsbaum](#im-inhaltsbaum)
3. [Wenn der alte Name bleibt](#wenn-der-alte-name-bleibt)
4. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
5. [Prüfen](#prüfen)

## Im Layout-Editor

Nicht im Layout-Editor.

## Im Inhaltsbaum

1. Bearbeiten Sie die Seite (Healthy eating, Knoten 130), ändern Sie ihren Titel und klicken Sie auf **Zur Veröffentlichung schicken**. Das Menü zeigt den neuen Namen; der URL-Alias folgt dem URL-Muster der Klasse.

## Wenn der alte Name bleibt

1. Leeren Sie im Kasten **Cache leeren** den Cache **Inhalte**; das Template gibt den Namen beim Rendern aus.

## Welchen Weg Sie wählen

Inhalt: Das Menü folgt der Seite.

## Prüfen

- Die Kopfzeile zeigt den neuen Namen auf jeder Seite.

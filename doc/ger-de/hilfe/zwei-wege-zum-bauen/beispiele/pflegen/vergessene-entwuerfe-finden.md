# Vergessene Entwürfe finden

Keine halbfertige Änderung wartet unbemerkt.

*Lebenszyklus: Pflegen, Beispiel 24 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Auf der Kommandozeile](#auf-der-kommandozeile)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Öffnen Sie jeden im Editor: **Layout veröffentlichen** oder **Verwerfen**.

## Auf der Kommandozeile

1. `./console exp:layouts list --drafts` - Zeilen mit dem Status `draft`.

## Welchen Weg Sie wählen

Ein Blick einmal im Monat.

## Prüfen

- Die Liste zeigt nur Entwürfe, an denen jemand arbeitet.

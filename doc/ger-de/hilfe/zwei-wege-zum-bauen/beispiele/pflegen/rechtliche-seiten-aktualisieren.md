# Die Datenschutz- oder Cookie-Richtlinie aktualisieren

Ein neuer Absatz in der Datenschutzrichtlinie.

*Lebenszyklus: Pflegen, Beispiel 31 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

Nicht im Layout-Editor.

## Im Inhaltsbaum

1. Bearbeiten Sie Privacy Policy, ändern Sie den Text und klicken Sie auf **Zur Veröffentlichung schicken**. Der Link *Privacy Policy* der Fußzeile (FooterMenuID 90) und das schlichte Layout brauchen keine Änderung.

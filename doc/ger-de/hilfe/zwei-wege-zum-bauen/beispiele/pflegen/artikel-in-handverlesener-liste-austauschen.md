# Einen Artikel in einer handverlesenen Liste austauschen

„Most popular articles“ bekommt diese Woche einen neuen dritten Artikel.

*Lebenszyklus: Pflegen, Beispiel 1 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. **Layouts > Gemeinsame Layouts > Prefooter**, wählen Sie die Liste aus.
2. Entfernen Sie im Reiter **Inhalt** den alten Eintrag aus **Elemente**, klicken Sie auf **+ Elemente hinzufügen**, wählen Sie den neuen Artikel, klicken Sie auf **Auswahl hinzufügen** und ziehen Sie ihn auf Position 3.
3. **Layout veröffentlichen**.

## Mit Templates

1. Ein Template mit festen Knoten-IDs braucht für dieselbe Änderung eine Bearbeitung und ein Deployment.

## Welchen Weg Sie wählen

Der Layout-Editor: eine Aufgabe von zwei Minuten für Redakteure.

## Prüfen

- Das Band auf einer Artikelseite zeigt den neuen Artikel an dritter Stelle.

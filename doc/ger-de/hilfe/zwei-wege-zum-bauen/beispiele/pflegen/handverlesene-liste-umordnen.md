# Eine handverlesene Liste umordnen

Den meistgelesenen Artikel an den Anfang stellen.

*Lebenszyklus: Pflegen, Beispiel 2 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Wählen Sie die Liste aus, ziehen Sie die Einträge unter **Elemente** an ihren Griffen und klicken Sie auf **Layout veröffentlichen**.

Auf der Testkopie hinterließ ein einziges Hinzufügen zwei Einträge mit der Position 0; wenn die Reihenfolge auf der Site von der im Editor abweicht, ziehen Sie noch einmal ([Bekanntes Verhalten des Editors](../../bekanntes-verhalten-des-editors.md)).

## Mit Templates

1. In einem Template ist die Reihenfolge die der IDs im Code.

## Welchen Weg Sie wählen

Der Layout-Editor.

## Prüfen

- Die Site zeigt die Reihenfolge aus dem Editor.

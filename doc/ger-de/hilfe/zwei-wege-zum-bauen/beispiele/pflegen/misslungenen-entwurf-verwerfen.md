# Einen misslungenen Entwurf verwerfen

Nach einer verunglückten Bearbeitung von vorn beginnen.

*Lebenszyklus: Pflegen, Beispiel 21 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Klicken Sie im Editor auf **Verwerfen** und bestätigen Sie mit **Verwerfen**.

## Mit Templates

1. Machen Sie in git den Commit rückgängig (revert).

## Welchen Weg Sie wählen

Vor dem Veröffentlichen verwerfen; nach dem Veröffentlichen [ein Layout zurücksetzen](../../../../../eng-us/help/build-two-ways/roll-back-a-layout.md).

## Prüfen

- `exp:layouts list --drafts` listet ihn nicht mehr.

# Das Hero-Bild ersetzen

Ein neues Kampagnenbild im Hero.

*Lebenszyklus: Pflegen, Beispiel 5 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Öffnen Sie **Layouts > Layouts** (oder **Gemeinsame Layouts**) und *das Layout der Landingpage*.
2. Wählen Sie den Block aus; ändern Sie im Reiter **Design** **Image URL** und **Image alt text**.
3. **Layout veröffentlichen**.

## Mit Templates

1. Wenn der Hero ein Inhaltsobjekt liest, bearbeiten Sie dieses Objekt und laden Sie das neue Bild hoch; das Layout ändert sich nicht.

## Welchen Weg Sie wählen

Getippte Bildadressen (Block) brechen, wenn die Datei verschoben wird; Bilder aus Inhalten folgen dem Inhalt.

## Prüfen

- Das neue Bild erscheint mit seinem Alternativtext.

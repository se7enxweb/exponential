# Eine Kampagnenseite beenden

Die Frühjahrskampagne endet, ohne dass ihre Arbeit verloren geht.

*Lebenszyklus: Pflegen, Beispiel 27 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Entfernen Sie den Haken bei **Aktiviert** an ihrer Zuordnung; behalten Sie das Layout (oder exportieren Sie es).

## Mit Templates

1. Verstecken Sie die Kampagnenseite im Inhaltsbaum oder verschieben Sie sie in einen Archivordner.

## Welchen Weg Sie wählen

Exportieren Sie das Layout, bevor Sie irgendetwas löschen.

## Prüfen

- Die Adresse der Kampagne zeigt die Kampagne nicht mehr (oder antwortet so, wie Sie es entschieden haben).

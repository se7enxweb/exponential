# Einem Abschnitt eine Hintergrundfarbe geben

Das Newsletter-Band in der Primärfarbe.

*Lebenszyklus: Pflegen, Beispiel 19 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Öffnen Sie **Layouts > Layouts** (oder **Gemeinsame Layouts**) und *das Layout*.
2. Wählen Sie den Block aus; haken Sie im Reiter **Design** **Set background color** an und wählen Sie die Farbe.
3. **Layout veröffentlichen**.

## Mit Templates

1. Die Farben sind die des Designs (`primary` in der Spalte der Kopfzeile, `secondary` in der Spalte des Prefooters); eine neue ist CSS für `.bg-color-<name>` in Ihrem Stylesheet.

## Welchen Weg Sie wählen

Die Design-Option für vorhandene Farben; CSS für neue.

## Prüfen

- Der Wrapper hat `bg-color-<color>`.

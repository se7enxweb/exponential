# Die Blocktypen auflisten, die Sie brauchen

Vor dem Bauen wissen, welche Blöcke es gibt und welche angefertigt werden müssen.

*Lebenszyklus: Planen, Beispiel 13 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Die Gruppen der Palette: Basic (Title, Text, Button / Link, Rich text, External video, Map, Markdown, HTML snippet, Image, Spacer, Divider, Card, Alert, Badge, Progress bar, Accordion, Tabs), Components (Hero, About, Features, Logos, Quote, Lead), Listing (List, Grid, Zig-Zag, Accordion), Gallery (Gallery, Slider, Thumb gallery, Grid gallery, Sushi bar, Carousel), Containers (Column, Two/Three/Four columns), Placeholders (Template block, Full view, Single content).

## Mit Templates

1. Eine fehlende Art von Block ist eine Blockdefinition, ein Handler und ein Template ([Einen Blocktyp hinzufügen](../../../../../eng-us/help/build-two-ways/add-a-block-type.md)); ein fehlendes Aussehen eines vorhandenen Blocks ist ein Ansichtstyp ([Einen Ansichtstyp hinzufügen](../../ansichtstyp-hinzufuegen.md)).

## Welchen Weg Sie wählen

Ziehen Sie einen Ansichtstyp einem neuen Blocktyp vor, wenn die Daten dieselben sind.

## Prüfen

- Jedes Element der Seitenentwürfe entspricht einem Blocktyp oder einem geplanten neuen.

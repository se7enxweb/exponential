# Themenseiten planen

Jede Themenseite listet die Inhalte zu ihrem Thema.

*Lebenszyklus: Planen, Beispiel 25 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Full / Topic übernimmt `ng_topic` mit Priorität 120 und hat 7 Blöcke; Running (Knoten 163) hat außerdem ein Landingpage-Layout, das über Ort zugeordnet ist.
2. Themenlisten können den Abfragetyp **Topics** der dynamischen Sammlungen verwenden (`content_by_topic`).

## Mit Templates

1. In Templates verwenden Listen nach Tag die Fetch-Funktionen der Tags-Erweiterung (eztags).

## Welchen Weg Sie wählen

Eine dynamische Sammlung mit der Abfrage Topics hält Themenseiten ohne Code gefüllt.

## Prüfen

- Ein neuer Artikel mit dem Tag eines Themas erscheint auf dieser Themenseite.

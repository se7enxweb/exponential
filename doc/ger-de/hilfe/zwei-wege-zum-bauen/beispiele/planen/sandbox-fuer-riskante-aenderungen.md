# Eine Sandbox für riskante Änderungen planen

Das Veröffentlichen eines Test-Layouts, einer Zuordnung oder eines Menüs berührt nie die Live-Site.

*Lebenszyklus: Planen, Beispiel 29 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Auf einer Kopie der Installation](#auf-einer-kopie-der-installation)
2. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
3. [Prüfen](#prüfen)

## Auf einer Kopie der Installation

1. Eine Kopie braucht den Code, eine Kopie von `settings/` und der Datenbank, ein eigenes Verzeichnis `var/` und einen Webserver unter einer anderen Adresse.
2. Diese Seiten wurden so geschrieben: Jedes Veröffentlichen geschah auf einer solchen Kopie.

## Welchen Weg Sie wählen

Zum Ansehen genügen Entwürfe; für alles, was erst nach dem Veröffentlichen sichtbar wird, ist eine Kopie nötig.

## Prüfen

- Die Datenbank der Kopie ist nicht die Live-Datenbank (vergleichen Sie einen Testbenutzer, den es nur in der Kopie gibt).

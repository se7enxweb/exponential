# Die eigene Dokumentation der Site planen

Ein neues Teammitglied findet in wenigen Minuten, wo das Kopfmenü steckt.

*Lebenszyklus: Planen, Beispiel 35 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Im Site-Leitfaden](#im-site-leitfaden)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Listen Sie die gemeinsamen Layouts auf und was mit ihnen verknüpft ist; die Ausgabe von `exp:layouts list` lässt sich einfügen.

## Im Site-Leitfaden

1. Führen Sie einen kurzen Leitfaden bei der Design-Erweiterung: welche Listen in der `menu.ini` es gibt, welche Templates überschrieben sind, welche Block- und Ansichtstypen hinzugefügt wurden.

## Welchen Weg Sie wählen

Verlinken Sie für die allgemeinen Teile auf diese Seiten und schreiben Sie nur auf, was speziell ist.

## Prüfen

- Jemand außerhalb des Projekts kann allein mit dem Leitfaden einen Eintrag zum Kopfmenü hinzufügen.

# Die Knoten-IDs für die Menüs sammeln

Die Menülisten lassen sich beim Livegang in einem Zug schreiben.

*Lebenszyklus: Planen, Beispiel 17 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Im Inhaltsbaum](#im-inhaltsbaum)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Jede Seite in der Administration zeigt `Node <id> · Object <id> · Remote ID`.

## Im Inhaltsbaum

1. Schreiben Sie die Knoten-IDs pro Menüposition in den Plan; notieren Sie auch die Remote-IDs, die gleich bleiben, wenn Inhalte per Paket auf eine andere Installation übertragen werden.

## Welchen Weg Sie wählen

Knoten-IDs sind das, was `MainMenuID[]` braucht; Layout-Exporte verweisen außerdem über Remote-ID und Pfad auf Inhalte.

## Prüfen

- Jeder geplante Menüeintrag hat eine Knoten-ID.

# Eine Seite in einem Entwurf als Prototyp bauen

Eine Seitenidee mit echten Blöcken zeigen, bevor entschieden wird.

*Lebenszyklus: Planen, Beispiel 5 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Öffnen Sie ein Layout; der Editor arbeitet in einem Entwurf.
2. Fügen Sie Blöcke hinzu und ordnen Sie sie an; die Mitte des Editors zeigt eine Vorschau.
3. **Verwerfen** (es fragt: *Möchten Sie Ihre Änderungen am Layoutentwurf wirklich verwerfen?*), um ihn wegzuwerfen, oder **Layout veröffentlichen**, um ihn zu behalten.

## Mit Templates

1. Ein Template-Prototyp ist ein Branch Ihrer Design-Erweiterung auf einer Testinstallation.

## Welchen Weg Sie wählen

Der Entwurf ist der schnellste Prototyp: kein Deployment, kein Code.

## Prüfen

- `./console exp:layouts list --drafts` zeigt danach keinen vergessenen Entwurf.

# Das Inhaltsmodell vor den Layouts planen

Kein Layout wartet auf ein Feld, das es nicht gibt.

*Lebenszyklus: Planen, Beispiel 33 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [In den Klassen](#in-den-klassen)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Ansichtstypen der Elemente zeigen die Teaser-Felder (Teaser-Titel, Teaser-Bild, Teaser-Einleitung): Planen Sie sie als Arbeit der Redakteure ein.

## In den Klassen

1. **Setup > Klassen** listet die Klassen; NG Article hat zum Beispiel `title`, `teaser_title`, `image`, `teaser_image`, `full_intro`, `teaser_intro`, `body`, `related_content`, `main_topic`, `tags`.
2. Planen Sie neue Felder vor den Templates, die sie ausgeben.

## Welchen Weg Sie wählen

Zuerst das Modell, dann die Layouts, zuletzt die Templates.

## Prüfen

- Jedes Element der Seitenentwürfe kommt aus einem Feld.

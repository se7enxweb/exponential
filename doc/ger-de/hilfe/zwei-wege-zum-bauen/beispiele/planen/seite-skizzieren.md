# Eine Seite mit Titeln und Abständen skizzieren

Sich zuerst auf die Reihenfolge der Abschnitte einigen („Hero“, „Latest“, „Recipes“, „Newsletter“).

*Lebenszyklus: Planen, Beispiel 6 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Mit Templates](#mit-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Legen Sie das Layout an; fügen Sie pro geplantem Abschnitt einen **Title** mit dem Namen des Abschnitts hinzu.
2. Fügen Sie **Spacer**-Blöcke dort ein, wo große Blöcke hinkommen.
3. Veröffentlichen Sie auf eine Testseite (eine Zuordnung mit einem Ziel Pfad) oder behalten Sie es als Entwurf.

## Mit Templates

1. Skizzieren Sie die Abschnitte als Kommentare im Full-View-Template.

## Welchen Weg Sie wählen

Die Skizze im Editor wird zur echten Seite, indem die Platzhalter ersetzt werden.

## Prüfen

- Alle Beteiligten haben die Reihenfolge gesehen.

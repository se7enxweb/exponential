# Planen, wer Layouts veröffentlicht

Eine Änderung an Header / Footer oder Prefooter wird geprüft, bevor sie jede Seite erreicht.

*Lebenszyklus: Planen, Beispiel 32 von 35. Ausgearbeitet auf der Site Fit & Healthy von Exponential 6.0.15+.*

## Inhalt

1. [Im Layout-Editor](#im-layout-editor)
2. [Für Templates](#für-templates)
3. [Welchen Weg Sie wählen](#welchen-weg-sie-wählen)
4. [Prüfen](#prüfen)

## Im Layout-Editor

1. Gemeinsame Layouts: Änderungen in einem Entwurf, in der Vorschau des Editors geprüft, dann **Layout veröffentlichen** durch die vereinbarte Person.
2. Machen Sie einen Export, bevor Sie ein gemeinsames Layout veröffentlichen.

## Für Templates

1. Änderungen an Templates werden im Repository der Erweiterung wie jeder Code geprüft.

## Welchen Weg Sie wählen

Behandeln Sie gemeinsame Layouts wie Templates: zuerst prüfen.

## Prüfen

- Vor jeder Veröffentlichung eines gemeinsamen Layouts gibt es einen Export.

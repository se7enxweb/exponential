# CMS-Entwickler: hier beginnen

Dieser Bereich der Hilfe richtet sich an **Entwickler, die Websites und Inhaltsanwendungen** mit Exponential bauen:
Entwickler in Agenturen und im eigenen Haus, Freiberufler und Entwickler, die von WordPress, Drupal, TYPO3, eZ Platform
oder Ibexa kommen und schnell produktiv werden müssen. Er erklärt das Inhaltsmodell, den Bau einer Website, die
Auslieferung und die Projektarbeit aus Sicht der Entwickler und verweist auf das Buch zur Erweiterungsentwicklung und
die Hilfe für Designer, wo diese tiefer gehen.

Jede Angabe auf diesen Seiten wurde am Code, an den Einstellungen oder an der vorhandenen Dokumentation von
Exponential 6 geprüft. Wenn sich die Software ändert, ändern sich die Seiten mit: Jede Seite hat **Auf GitHub
bearbeiten**.

## Die Regeln, die jedes Projekt einhält

1. **Ändern Sie nie mitgelieferte Dateien.** Der Kernel, `design/standard` und `settings/*.ini` werden bei einer
   Aktualisierung ersetzt; Ihre Arbeit liegt in Ihren Erweiterungen und in Override-Einstellungen
   ([Erweiterungen, die Sie schreiben werden](erweiterungen-die-sie-schreiben-werden.md)).
2. **Zuerst das Modell.** Klassen und Baum bestimmen Templates, Berechtigungen und URLs; prüfen Sie das Modell, bevor
   Sie bauen ([Checkliste zur Prüfung des Inhaltsmodells](checkliste-zur-pruefung-des-inhaltsmodells.md)).
3. **Ändern Sie Inhalte über den Kernel.** Fetch-Funktionen in Templates, die Kernel-API in PHP; nie SQL auf
   Inhaltstabellen ([Inhalte aus PHP](inhalte-aus-php.md)).
4. **Kennen Sie Ihre Caches.** Leeren Sie den Cache, der zu einer Änderung gehört, nachdem der Server den neuen Code
   ausführt ([Caching für CMS-Entwickler](caching-fuer-cms-entwickler.md)).
5. **Halten Sie Templates sauber und sicher.** Ausgaben maskieren; kein Inline-CSS oder -JavaScript; CSS aus
   Stylesheets mit Tokens
   ([Templates und Overrides für CMS-Entwickler](templates-und-overrides-fuer-cms-entwickler.md#regeln-für-wartbare-templates)).
6. **Keine echten Personen in Tests.** Testkonten und E-Mails verwenden `example.invalid`; keine Kopien echter
   personenbezogener Daten auf Entwicklungsrechnern.
7. **Verwenden Sie die richtigen Namen.** Das Produkt heißt Exponential; 7x ist das Unternehmen, das es führt; die
   Exponential Foundation ist die gemeinnützige Organisation ([Wer ist 7x?](../wer-ist-7x.md)).

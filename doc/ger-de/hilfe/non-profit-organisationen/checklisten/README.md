# Checklisten für Non-Profit-Organisationen

Dieser Ordner enthält die Checklisten des Bereichs für Non-Profit-Organisationen. Jede verlinkt auf die Seiten, die
ihre Punkte erklären. Kopieren Sie eine Checkliste in Ihr eigenes Dokument, tragen Sie Namen und Termine neben den
Punkten ein und bewahren Sie die abgezeichneten Exemplare auf; sie belegen, dass die Arbeit erledigt wurde, und sind
ein guter Nachweis gegenüber Geldgebern oder dem Vorstand.

## Inhalt

1. [Die Checklisten](#die-checklisten)
2. [So verwenden Sie sie](#so-verwenden-sie-sie)
3. [Verwandte Checklisten an anderer Stelle](#verwandte-checklisten-an-anderer-stelle)

## Die Checklisten

| Checkliste | Wann | Abgezeichnet von |
|---|---|---|
| [Checkliste zum Start](checkliste-zum-start.md) | Bevor die Website oder ein Relaunch live geht | Projektverantwortliche und technische Leitung |
| [Monatliche Checkliste](monatliche-checkliste.md) | In der ersten Woche jedes Monats | Die für die Website verantwortliche Person |
| [Jährliche Checkliste](jaehrliche-checkliste.md) | Einmal im Jahr, bevor das Budget festgelegt wird | Geschäftsführung oder Vorstand |
| [Datenschutz-Checkliste](datenschutz-checkliste.md) | Zum Start, danach jährlich und immer dann, wenn ein neues Formular oder ein neuer Dienst hinzukommt | Ansprechperson für den Datenschutz |

## So verwenden Sie sie

1. Kopieren Sie die Checkliste; ergänzen Sie eine Spalte „Wer“ und eine Spalte „Erledigt am“.
2. Tragen Sie vor dem Beginn neben jeder Zeile einen Namen ein. Eine Zeile ohne Namen wird nicht erledigt.
3. Wo eine Zeile nicht zutrifft, streichen Sie sie durch und notieren Sie den Grund.
4. Bewahren Sie das abgezeichnete Exemplar bei Ihren Projektunterlagen auf.
5. Ändern Sie die Checkliste, wenn Sie etwas dazulernen; sie gehört Ihnen.

> **Tipp**
> Wenn Sie aus diesem Ordner nur eine Sache umsetzen, dann die monatliche Checkliste. Die meisten teuren Probleme auf
> kleinen Websites sind versäumte Sicherungen, versäumte Updates und dass niemand hinschaut
> ([Routine für Sicherungen und Updates](../betrieb/routine-fuer-sicherungen-und-updates.md)).

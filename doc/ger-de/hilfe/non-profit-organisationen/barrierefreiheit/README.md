# Barrierefreiheit für Non-Profit-Organisationen

Dieser Ordner richtet sich an Geschäftsführung, Kommunikationsteam, Redakteure und den Website-Ersteller. Viele
Non-Profit-Organisationen gibt es, um Menschen zu dienen, die älter, behindert, krank oder arm sind oder die
Landessprache nicht fließend sprechen; eine Website, die diese Menschen nicht nutzen können, verfehlt den Auftrag
selbst. In vielen Ländern ist Barrierefreiheit außerdem eine gesetzliche Pflicht oder eine Bedingung von Geldgebern.

Die kompakte Seite im Bereich für Unternehmen ist [Barrierefreiheit für Non-Profit-Organisationen](../../unternehmen/gemeinnuetzige/barrierefreiheit-fuer-gemeinnuetzige.md);
die ausführliche Behandlung für öffentliche Stellen, die größtenteils auch für Non-Profit-Organisationen gilt, ist der
[Bereich Barrierefreiheit für Behörden](../../verwaltung/barrierefreiheit/README.md).

## Was Exponential bereitstellt

Aus [Was Exponential für die Barrierefreiheit bereitstellt](../../verwaltung/barrierefreiheit/was-exponential-bietet.md) und
[Barrierefreiheit für Website-Ersteller](../../ersteller/website-ersteller/barrierefreiheit-fuer-website-ersteller.md):

| Teil | Stand |
|---|---|
| Die Administrationsdesigns admin4 und admin4l | Nach WCAG 2.2 AA gestaltet und mit Regressionstests geprüft; das Projekt stuft sie als **Teilweise erfüllt** ein und gibt keine Konformitätserklärung ab |
| Hinweise für Template-Autoren | Sprache, Landmarks, Sprunglink, Überschriften, Fokus, Kontrast, Zoom |
| Bildfelder | Können einen Alternativtext verlangen |
| Online-Editor | Schreibt strukturierten Rich Text (Überschriften, Listen, Tabellen) statt freiem HTML |
| Inhalte in Rechts-nach-links-Schrift | Mit `lang` und `dir` ausgezeichnet |
| Inhaltsprüfungen | Finden Probleme in Inhalten ([Inhaltsprüfungen](../../../funktionen/6.0/inhaltspruefungen.md)) |
| Konformitätsberichte | **Keine**: Für Exponential gibt es kein VPAT, keinen Accessibility Conformance Report und keinen WCAG-EM-Bericht |

## Was bei Ihnen bleibt

| Teil | Wer dafür verantwortlich ist |
|---|---|
| Das öffentliche Design Ihrer Website | Sie oder die Person, die sie baut |
| Inhalte: Alternativtexte, Überschriften, Linktexte, Dokumente | Ihre Redakteure |
| PDFs und andere Dokumente | Wer sie erstellt |
| Eingebettete Dienste (Spendenformulare, Videos, Karten, CAPTCHAs) | Sie wählen sie aus; testen Sie sie |
| Eine Erklärung zur Barrierefreiheit | Sie veröffentlichen sie |

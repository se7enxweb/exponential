# Betrieb für Non-Profit-Organisationen

Dieser Ordner richtet sich an die Person, die die Website am Laufen hält: eine Mitarbeiterin oder ein Mitarbeiter,
technisch versierte Ehrenamtliche, ein Hosting-Anbieter oder ein Partner, und an die Geschäftsführung, die am Ende
verantwortlich ist. Die meisten Kosten und Risiken einer Website liegen nicht im Bau, sondern im Betrieb über Jahre.
Eine kleine, schriftlich festgehaltene Routine mit einem Namen neben jeder Aufgabe hält die Website einer
Non-Profit-Organisation gesund.

## Wer was tut

| Aufgabe | Mitarbeitende oder geschulte Ehrenamtliche | Technische Ehrenamtliche, Hoster oder Partner |
|---|---|---|
| Schreiben und Veröffentlichen | Ja | |
| Formulare und den Newsletter bearbeiten | Ja | |
| Überprüfung der Konten | Ja, mit **Benutzerkonten prüfen** | |
| Sicherungen | Prüfen, dass sie vorhanden sind | Richten sie ein, testen Wiederherstellungen |
| Updates von Exponential, Erweiterungen und PHP | | Ja |
| Serversicherheit | | Ja |
| Vorfälle | Bemerken und melden | Beheben |

Tragen Sie die Namen in das [Arbeitsblatt Rollen und Berechtigungen](../vorlagen/arbeitsblatt-rollen-und-berechtigungen.md)
ein. Die allgemeine Aufteilung zwischen Eigentümer, Hoster und Partner ist unter
[Wer was tut](../../kunden/partner-und-hoster/wer-was-macht.md) beschrieben.

# Vorlagen und Arbeitsblätter für Non-Profit-Organisationen

Dieser Ordner enthält Arbeitsblätter zum Kopieren und Ausfüllen. Jedes besteht aus einfachem Text und Tabellen und
funktioniert daher in jeder Textverarbeitung und jeder Tabellenkalkulation. Nichts darin ist ein Preis oder eine
Tatsache über Ihre Organisation; diese tragen Sie selbst ein.

## So verwenden Sie sie

1. Kopieren Sie das Arbeitsblatt in ein Dokument, das Ihr Team gemeinsam nutzt.
2. Füllen Sie es mit den Menschen aus, die die Arbeit erledigen werden, nicht allein.
3. Bewahren Sie die ausgefüllte Fassung bei Ihren Projektunterlagen auf; sie dokumentiert, was entschieden wurde und
   warum.
4. Überprüfen Sie sie einmal im Jahr mit der [jährlichen Checkliste](../checklisten/jaehrliche-checkliste.md).

> **Tipp**
> Ein ausgefülltes Arbeitsblatt ist für einen Geldgeber ein guter Beleg dafür, dass das Projekt geplant wurde. Legen Sie
> es einem Antrag bei, wenn der Geldgeber einen Projektplan verlangt.

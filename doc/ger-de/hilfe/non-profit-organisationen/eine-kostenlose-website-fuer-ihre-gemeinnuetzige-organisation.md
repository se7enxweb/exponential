# Eine kostenlose Website für Ihre gemeinnützige Organisation

Jeder Euro für Hosting fehlt Ihrem eigentlichen Zweck. Mit statischem Veröffentlichen bearbeiten Ihre Ehrenamtlichen
die Website wie gewohnt in Exponential, und die öffentliche Website ist eine Kopie aus einfachen HTML-Seiten, die
GitHub Pages kostenlos ausliefert.

## Was Sie am Ende haben

- Eine öffentliche Website unter `https://<ihr-konto>.github.io/<repository>/` oder unter Ihrer eigenen Domain, mit HTTPS.
- Keine Hosting-Gebühr, keinen Server zum Aktualisieren, nichts auf der öffentlichen Seite, in das man einbrechen kann.
- Jede Veröffentlichung bleibt erhalten, ein Fehler ist mit einem Klick zurückgenommen.

## Warum es zu gemeinnützigen Organisationen passt

- **Keine laufenden Kosten.** GitHub Pages hostet öffentliche Websites kostenlos. Nur ein Domainname kostet eventuell Geld.
- **Sicher mit Ehrenamtlichen.** Redakteure ändern nie direkt die öffentliche Website. Sie bearbeiten, jemand prüft die
  Vorschau, dann wird veröffentlicht. Eine falsche Veröffentlichung wird im Verlauf zurückgenommen.
- **Überall schnell.** Einfache Dateien laden schnell, auch auf alten Telefonen und langsamen Verbindungen.
- **Bleibt erreichbar.** Ein Zeitungsbericht oder ein Aktionstag legt die Website nicht lahm.

## Wo es nicht reicht

Eine statische Website kann keine Zahlungen annehmen und keinen Mitgliederbereich führen. Lassen Sie diese bei einem
Dienst, der dafür gemacht ist, und verlinken Sie ihn:

- **Spenden:** verlinken Sie die Spendenseite Ihres Zahlungsanbieters.
- **Kontakt- und Anmeldeformulare:** sie können an Ihre Exponential-Installation senden oder einen Link zur Live-Seite
  zeigen. Siehe [Suche, Formulare und Kommentare auf einer statischen Site](../statisches-veroeffentlichen/suche-formulare-und-kommentare-auf-einer-statischen-site.md).
- **Seiten nur für Mitglieder:** sie bleiben auf der Exponential-Website und werden nie kopiert. Siehe
  [Private Inhalte privat halten](../statisches-veroeffentlichen/private-inhalte-privat-halten.md).

Unsicher? [Passt statisch zu meiner Website?](../statisches-veroeffentlichen/passt-statisch-zu-meiner-website.md) hat eine kurze Checkliste.

## Wer was tut

| Rolle | Aufgabe |
|---|---|
| Redakteure | Schreiben und aktualisieren Seiten in Exponential, wie bisher |
| Ein Administrator | Richtet das Ziel einmal mit dem Assistenten ein, veröffentlicht oder schaltet das automatische Veröffentlichen ein |
| Ihr Vorstand | Besitzt das GitHub-Konto und die Domain, damit die Website nie an einer einzelnen Person hängt |

Legen Sie das GitHub-Konto im Namen der Organisation an, mit zwei Personen, die sich anmelden können.

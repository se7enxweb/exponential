# Eine Website Schritt für Schritt bauen: das Schachclub-Tutorial für Exponential 6

Das Tutorial *Building an eZ publish site* baut eine kleine Vereinswebsite aus dem Nichts, für einen Schachclub: eine
Startseite, Neuigkeiten mit Archiv, eine Mitgliederliste, ein Gästebuch, dessen Einträge ein Administrator freigibt, und
eine Seite mit Links. Es lehrt am Beispiel, und deshalb ist es noch immer ein guter Einstieg. Diese Seiten behalten seinen
Fall und seine Reihenfolge bei und führen jeden Schritt so aus, wie Exponential 6 es tut: in zwei Erweiterungen, mit
aktuellen Einstellungen, einem modernen Seitenrahmen, ohne Inline-Stile und Inline-Skripte und mit einem Hinweis überall
dort, wo die Fassung von 2003 heute falsch oder unsicher wäre.

Sie brauchen eine Installation, an der Sie arbeiten können ([Erste Schritte](../../anleitungen/erste-schritte.md)), und etwas
allgemeines Wissen über Webentwicklung. Die Begriffe erklärt [Exponential lernen](../buch-lernen/README.md); die kompakte
Fassung derselben Arbeit ist [Eine Website bauen, ohne Code zu schreiben](../erweiterungsentwicklung/teil-2-builder/eine-website-ohne-code-bauen.md).

1. [Das Projekt beginnen: der Fall, ein Siteaccess und ein Design](das-projekt-beginnen.md)
2. [Das Hauptlayout: pagelayout.tpl und ein Stylesheet](das-hauptlayout.md)
3. [Sektionen und die Startseite](sektionen-und-die-startseite.md)
4. [Die Nachrichtenseiten: Übersicht, vollständiger Artikel und Archiv](die-nachrichtenseiten.md)
5. [Die Mitgliederseite: eine eigene Inhaltsklasse, eine Liste und eine Infoseite](die-mitgliederseite.md)
6. [Das Gästebuch: Besucher schreiben Inhalte](das-gaestebuch.md)
7. [Gästebucheinträge mit einem Workflow freigeben](gaestebucheintraege-freigeben.md)
8. [Die Linkseite: Kategorien, Linkobjekte und ein Baummenü](die-linkseite.md)

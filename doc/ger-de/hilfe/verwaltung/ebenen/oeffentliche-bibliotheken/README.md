# Öffentliche Bibliotheken

Dieser Ordner richtet sich an Projektverantwortliche, Administratorinnen und Administratoren und Website-Ersteller
einer öffentlichen Bibliothek, einer Gemeindebibliothek oder eines Verbunds von Zweigstellen. Die Website einer
Bibliothek handelt vor allem von Öffnungszeiten, Zweigstellen, Veranstaltungen und Diensten; Katalog und Ausleihen liegen
im Bibliotheksmanagementsystem, auf das die Website verlinkt. Die Seiten beantworten, was eine Bibliothek veröffentlicht,
wie Sie es in Exponential bauen, welche Anforderungen am meisten wiegen, wie Sie die ersten 90 Tage gestalten und wie Sie
mit Veranstaltungen und dem Katalog umgehen.

Die Fakten zum Produkt stammen aus der Dokumentation dieses Repositorys; die Beschreibungen von Bibliotheken geben
allgemeine Praxis im öffentlichen Sektor wieder.

## Was Bibliotheken besonders macht

| Thema | Warum es wichtig ist |
|---|---|
| Veranstaltungen | Vorlesestunden, Lesekreise, Kurse: viele kleine Veranstaltungen in vielen Zweigstellen |
| Der Katalog | ein eigenes System mit eigener Suche; die Website sollte ihn nicht kopieren |
| Datenschutz der Lesenden | was Menschen lesen, ist sensibel; Bibliotheken schützen es traditionell |
| Viele Beschäftigte, wenig Zeit | Beschäftigte der Zweigstellen veröffentlichen Veranstaltungen neben ihrer Hauptarbeit |
| Inklusion | alle sind willkommen: Sprachen, Lesekompetenz, Behinderungen |

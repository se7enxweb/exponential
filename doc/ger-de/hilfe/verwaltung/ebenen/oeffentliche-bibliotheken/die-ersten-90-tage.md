# Die ersten 90 Tage für öffentliche Bibliotheken

Diese Seite richtet sich an Projektverantwortliche und Webverantwortliche einer Bibliothek oder eines
Bibliotheksverbunds, die eine Website mit Exponential beginnen. Sie stellt das, wonach Besucher am meisten suchen
(Öffnungszeiten, den Katalog, Veranstaltungen), an den Anfang. Sie setzt voraus, dass eine Installation existiert
([Erste Schritte](../../../../anleitungen/erste-schritte.md)).

## Inhalt

1. [Tage 1 bis 30: die Grundlagen](#tage-1-bis-30-die-grundlagen)
2. [Tage 31 bis 60: Veranstaltungen und Beschäftigte](#tage-31-bis-60-veranstaltungen-und-beschäftigte)
3. [Tage 61 bis 90: Inhalte und Start](#tage-61-bis-90-inhalte-und-start)
4. [Nach dem Start](#nach-dem-start)

## Tage 1 bis 30: die Grundlagen

| Schritt | Ergebnis |
|---|---|
| Zweigstellen mit Anschriften, Öffnungszeiten, Ausstattung und Barrierefreiheit auflisten | ein Blatt je Zweigstelle |
| Beim Lieferanten des Bibliothekssystems die Suchadresse und die Anmeldeadresse des Katalogs erfragen | die Links, die die Website verwenden wird |
| Entscheiden: zentraler Kalender oder einer je Zweigstelle | eine Entscheidung ([Struktur](struktur-sektionen-und-rollen.md)) |
| Entscheiden, welche Beschäftigten Veranstaltungen veröffentlichen | eine Liste der Redaktion Veranstaltungen |
| Ein Design wählen, das Templates für den Veranstaltungskalender hat oder erhalten kann | ezwebin hat Kalender- und Programmansicht; andere Designs brauchen Templates ([Ein Design oder Theme wählen](../../../../../eng-us/help/creators/website-creators/choosing-a-design-or-theme.md)) |

Prüfung: Sie können sich in der Administration anmelden; **Setup > Klassen** listet Event und Event calendar.

## Tage 31 bis 60: Veranstaltungen und Beschäftigte

| Schritt | Prüfung |
|---|---|
| Die Klasse Zweigstelle und die Objekte der Zweigstellen anlegen ([Inhaltsmodell](inhaltsmodell.md)) | jede Seite einer Zweigstelle zeigt Öffnungszeiten und Barrierefreiheit |
| Der Klasse Event die Attribute Zweigstelle, Zielgruppe und Buchung hinzufügen und die Templates aktualisieren | eine Testveranstaltung zeigt ihre Zweigstelle |
| Den Veranstaltungskalender anlegen und seine Ansicht wählen | der Kalender zeigt die Testveranstaltung |
| Die Rolle und die Gruppe Redaktion Veranstaltungen anlegen ([Struktur](struktur-sektionen-und-rollen.md)) | eine Testredaktion kann nur Veranstaltungen anlegen |
| Die zweistufige Anmeldung für Beschäftigte einschalten | die Testredaktion hat sie eingerichtet |
| Tags für Zielgruppen und Themen | Veranstaltungen lassen sich nach Tag auflisten ([Verschlagworten mit eztags](../../../../../eng-us/help/creators/website-creators/tagging-with-eztags.md)) |

## Tage 61 bis 90: Inhalte und Start

| Schritt | Lesen |
|---|---|
| Dienstleistungsseiten in einfacher Sprache schreiben | [Schwerpunkte der Anforderungen](schwerpunkte-der-anforderungen.md) |
| Die Veranstaltungen der nächsten zwei Monate eintragen | [Veranstaltungen und Kataloge](veranstaltungen-und-verlinkte-kataloge.md) |
| Die Redaktion Veranstaltungen mit je einer echten Veranstaltung schulen | [Editors 101](../../../trainer/redakteure-101/README.md) |
| Das Suchfeld und die Links zum Katalog hinzufügen | [Veranstaltungen und Kataloge](veranstaltungen-und-verlinkte-kataloge.md#der-katalog-verlinken) |
| Die Barrierefreiheit von Kalender und Seiten der Zweigstellen testen | [Die Barrierefreiheit testen](../../../../../eng-us/help/creators/website-creators/testing-accessibility.md) |
| Start | [Start-Checkliste](../../../../../eng-us/help/creators/website-creators/launch-checklist.md) |

Prüfungen beim Start:

- [ ] Eine in das Katalogsuchfeld der Website eingegebene Suche öffnet die Ergebnisse des Katalogs.
- [ ] Jede Seite einer Zweigstelle hat Öffnungszeiten und einen Bereich für Hinweise auf Schließungen.
- [ ] Abgemeldet zeigt der Kalender die Veranstaltungen dieses Monats in beiden Ansichten, die Sie anbieten.

## Nach dem Start

- Wöchentlich: Die Redaktion Veranstaltungen trägt neue Veranstaltungen ein; das Webteam prüft den Kalender auf fehlende
  Orte oder Zeiten.
- Monatlich: vergangene Veranstaltungen entfernen oder archivieren; prüfen, dass Schließungen nach ihrem Ende
  verschwunden sind.
- Vor Feiertagen: die Öffnungszeiten an Feiertagen für jede Zweigstelle eintragen.

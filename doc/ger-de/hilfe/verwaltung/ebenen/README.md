# Verwaltungsebenen

Dieser Bereich richtet sich an Projektverantwortliche, Administratorinnen und Administratoren und Website-Ersteller,
die eine Exponential-Website für eine Organisation des öffentlichen Sektors planen. Öffentliche Stellen unterscheiden
sich stark darin, was sie veröffentlichen und wie sorgfältig sie es veröffentlichen müssen: Ein Gericht ist keine
Bibliothek, und ein Parlament ist keine Feuerwehr. Jeder Ordner unten beantwortet dieselben Fragen für eine Art von
Organisation, sodass Sie nur den lesen können, der zu Ihnen passt, oder zwei vergleichen.

Die Fakten zu Exponential auf diesen Seiten stammen aus der Dokumentation in diesem Repository (den Leitfäden in
`doc/eng-us/guides/`, den Standards in `doc/eng-us/standards/` und den Funktionsseiten in `doc/eng-us/features/6.0/`),
aus den Inhaltsklassen und Datentypen, die mit dem Kernel und dem Standard-Websitepaket ausgeliefert werden, und aus den
Administrationsbildschirmen des Demonstrationsservers. Die Beschreibungen dessen, was öffentliche Stellen
veröffentlichen, geben allgemeine Praxis im öffentlichen Sektor wieder, keine Berichte über eine bestimmte Regierung.

## Was jeder Ordner beantwortet

| Seite | Die Frage, die sie beantwortet |
|---|---|
| README | Was diese Art von Organisation ist, und die Lesereihenfolge |
| Was veröffentlicht wird | Was diese Art von Organisation typischerweise veröffentlicht und was sie von einem CMS braucht |
| Inhaltsmodell | Welche Inhaltsklassen und Datentypen von Exponential passen und welche Klassen im Klasseneditor hinzuzufügen sind |
| Struktur, Sektionen und Rollen | Wie der Inhaltsbaum angeordnet wird, welche Sektionen anzulegen sind und welche Rollen die Beschäftigten erhalten |
| Schwerpunkte der Anforderungen | Welche Anforderungen hier am meisten wiegen: Barrierefreiheit, Sprachen, Sicherheit, Schriftgut |
| Die ersten 90 Tage | Ein Plan in Phasen vom Projektstart bis zur laufenden Website, mit Prüfungen bei jedem Schritt |
| Die ebenenspezifische Seite | Das eine Thema, das diese Art von Organisation von anderen abhebt |

## Wie Sie diesen Bereich lesen

1. Beginnen Sie mit dem Ordner, der zu Ihrer Organisation passt, und lesen Sie sein README und **Was veröffentlicht
   wird**.
2. Lesen Sie **Inhaltsmodell** zusammen mit
   [Ihr Inhaltsmodell entwerfen](../../../../eng-us/help/creators/website-creators/designing-your-content-model.md) und
   [Datentypen für Ihre Felder wählen](../../../../eng-us/help/creators/website-creators/choosing-datatypes.md).
3. Lesen Sie **Struktur, Sektionen und Rollen** zusammen mit [Sektionen](../../../anleitungen/sektionen.md) und
   [Rollen und Richtlinien](../../../anleitungen/rollen-und-richtlinien.md).
4. Lesen Sie **Schwerpunkte der Anforderungen** zusammen mit den Seiten zu den Standards:
   [Standards zur Barrierefreiheit](../../../../eng-us/standards/accessibility.md),
   [Sicherheitsstandards](../../../../eng-us/standards/security.md), [Datenschutzstandards](../../../../eng-us/standards/privacy.md) und
   [Standards zur Internationalisierung](../../../../eng-us/standards/internationalization.md).
5. Verwenden Sie **Die ersten 90 Tage** als Gerüst Ihres Projektplans.

Die Bereiche zu den Anforderungen in dieser Hilfe für Verwaltungen ([Barrierefreiheit](../barrierefreiheit/README.md),
[Sicherheit](../sicherheit/README.md), [Datenschutz](../../../../eng-us/help/government/privacy/README.md) und
[Schriftgut und Archivierung](../../../../eng-us/help/government/records-and-archiving/README.md)) und die [Bauanleitungen](../../../../eng-us/help/government/building/README.md)

## Organisationen über mehrere Ebenen

Viele öffentliche Stellen passen nicht in einen Ordner. Eine Stadt kann eine Bibliothek, Schulen und eine Feuerwehr
betreiben; ein Ministerium kann Behörden führen; ein Universitätsklinikum kann Informationen zur öffentlichen Gesundheit
veröffentlichen. Exponential kann mehrere Websites aus einer Installation bedienen, jede mit eigenem Siteaccess, Design
und eigenen Sprachen ([Multisite einrichten](../../../../eng-us/help/creators/website-creators/multisite-setup.md)), und Sektionen und
Rollen können die Redaktion jeder Organisation auf ihren eigenen Teil des Inhaltsbaums beschränken
([Sektionen](../../../anleitungen/sektionen.md#132-ein-intranet-mit-abteilungen)). Lesen Sie den Ordner jedes Teils und
entscheiden Sie dann, ob eine Installation oder mehrere zu Ihrer Steuerung passen.

| Situation | Übliche Wahl |
|---|---|
| Eine Organisation, eine öffentliche Website, ein Redaktionsteam | eine Installation, ein öffentlicher Siteaccess |
| Eine Organisation mit mehreren Marken oder Diensten unter einer Administration | eine Installation, mehrere Siteaccesses, eine Sektion je Einheit |
| Getrennte juristische Personen mit getrennten Verantwortlichen im Sinne des Datenschutzes oder getrennten Sicherheitsanforderungen | getrennte Installationen, gemeinsames Design als Erweiterung |

Die letzte Zeile ist eine Entscheidung der Steuerung, keine technische Grenze; Ihre Datenschutz- und
Sicherheitsbeauftragten entscheiden sie.

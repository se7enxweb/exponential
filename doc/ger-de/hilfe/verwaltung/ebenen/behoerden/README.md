# Behörden

Dieser Ordner richtet sich an Projektverantwortliche, Administratorinnen und Administratoren und Website-Ersteller
einer öffentlichen Behörde: einer Regulierungsbehörde, einer Aufsichtsbehörde, einer nachgeordneten oder ausgegliederten
Stelle, die ein Programm durchführt, oder einer Fachbehörde. Behörden veröffentlichen gleichzeitig für zwei
Zielgruppen: die Öffentlichkeit und die Organisationen oder Fachleute, die sie beaufsichtigen oder betreuen. Auf ihre
Leitfäden verlässt man sich, daher müssen diese korrekt, datiert und nachvollziehbar sein. Die Seiten beantworten, was
Behörden veröffentlichen, wie Sie es in Exponential bauen, welche Anforderungen am meisten wiegen, wie Sie die ersten
90 Tage gestalten und wie Sie Leitfäden für regulierte Akteure veröffentlichen.

Die Fakten zum Produkt stammen aus der Dokumentation dieses Repositorys; die Beschreibungen von Behörden geben
allgemeine Praxis im öffentlichen Sektor wieder.

## Was Behörden besonders macht

| Thema | Warum es wichtig ist |
|---|---|
| Verlässlichkeit | regulierte Akteure handeln nach Leitfäden; eine falsche oder undatierte Seite hat Folgen |
| Nachvollziehbarkeit | „Was stand an diesem Datum im Leitfaden?“ muss sich beantworten lassen |
| Zwei Zielgruppen | Öffentlichkeit und Fachleute brauchen unterschiedliche Einstiege |
| Entscheidungen über benannte Akteure | Durchsetzungsentscheidungen können Organisationen und manchmal Personen nennen |
| Daten | Register und Statistiken werden oft als offene Daten erwartet |

# Ein Schulungsplan für eine öffentliche Stelle

Diese Seite richtet sich an die Projektleitung oder Schulungskoordination einer öffentlichen Stelle, die Exponential
einführt, und an die Beschaffungsstelle, die die Schulung in einer Ausschreibung beschreiben muss. Sie beantwortet:
Welche Gruppen brauchen Schulung, welcher Kurs passt zu jeder Gruppe, wann im Projekt läuft jeder Kurs, und was sollten
Sie festhalten, damit der Plan den Vertrag überdauert? Die Kurse und ihre Längen stammen aus dem [Kurskatalog](../../../trainer/kurskatalog.md).

## Warum ein Plan und kein einmaliger Kurs

Eine öffentliche Website lebt länger als das Projekt, das sie baut. Redaktionsmitglieder wechseln die Abteilung, neue
Beschäftigte kommen, der Auftragnehmer, der die Website gebaut hat, geht. Ein Plan beantwortet drei Fragen für die ganze
Laufzeit: wer vor dem Livegang geschult wird, wie neue Personen später geschult werden und wer das Schulungsmaterial
aktuell hält, wenn sich die Software ändert.

Das Material, auf dem Sie aufbauen können, existiert bereits und ist kostenlos: Jeder Trainerkurs dieser Hilfe ist freie
Dokumentation unter der GNU FDL 1.3, Ihre Organisation oder Ihr Lieferant darf ihn also kopieren und anpassen, wenn die
Hinweise erhalten bleiben ([Freie Dokumentation](../../../freie-dokumentation.md)).

## Die Gruppen in einer öffentlichen Stelle

| Gruppe | Was sie in Exponential tut | Typische Größe |
|---|---|---|
| Redaktion | schreibt und aktualisiert Seiten, Nachrichten, Dokumente | die größte Gruppe, über die Abteilungen verteilt |
| Leitende Redaktion und Freigebende | prüfen, übersetzen, ordnen, geben frei | einige je Abteilung |
| Administration der Website | Benutzer, Rollen, Sektionen, Caches, Cronjobs, Protokolle, Upgrades | ein kleines zentrales Team |
| Systemadministration oder der Host | Server, PHP, Datenbank, Sicherungen, Velocity | zentrale IT oder das Hosting-Unternehmen |
| Entwicklung und Design | Templates, Erweiterungen, das öffentliche Design | im Haus oder der Umsetzungspartner |
| Trainerinnen und Trainer | unterrichten die anderen | eine oder zwei Personen, wenn Sie im Haus schulen |
| Entscheidungsträger | verstehen, was das System kann und was nicht | Führungskräfte, der Projektlenkungsausschuss |

Die Matrix, die jeder Gruppe Kurse zuordnet, steht auf der Seite „Rollen und Kurse“ in diesem Ordner.

## Wann jeder Kurs läuft

| Zeitpunkt im Projekt | Schulung |
|---|---|
| Vor der Ausschreibung | ein halber Tag für Entscheidungsträger ([Halber Tag für Entscheidungsträger](../../../../../eng-us/help/trainers/workshops/module-02-one-day-agendas/decision-makers-half-day.md)), damit das Gremium das Produkt kennt |
| Während des Baus | Administration der Website für das zentrale Team; Entwickler und Theme-Design für die hauseigene Entwicklung |
| Zwei bis vier Wochen vor dem Livegang | Editors 101 für jedes Redaktionsmitglied, das zum Start veröffentlicht; die Migration der Inhalte dient oft zugleich als Übung |
| Kurz nach dem Livegang | Exponential Layouts für die Seitengestaltung; Newsletter, wenn die Website welche versendet |
| Einige Monate nach dem Livegang | Editors 201 für die Redaktion, die jede Woche veröffentlicht |
| Jedes Jahr | Auffrischungstermine; die Checkliste „Annual review“ im Abschnitt mit den Checklisten für Verwaltungen |
| Immer wenn jemand neu dazukommt | der Einarbeitungspfad auf der Seite „Einarbeitung neuer Beschäftigter“ in diesem Ordner |

Schulen Sie die Redaktion kurz vor dem Tag, an dem sie zu veröffentlichen beginnt. Ein Kurs Monate vor dem Livegang ist
zum Start vergessen.

## Wer ihn durchführt

Drei Möglichkeiten, die sich kombinieren lassen:

1. **Der Umsetzungspartner** schult als Teil des Projekts. Schreiben Sie die Kurse und die Zahl der Termine in den
   Vertrag (siehe die Klausel zur Schulung im Teil zu Ausschreibungsvorlagen dieses Abschnitts).
2. **Ein Schulungspartner** führt die Kurse durch ([Schulungspartner](../../../partner/schulungspartner.md)). Beachten
   Sie, dass das Projekt noch nicht veröffentlicht hat, was einen Kurs „offiziell“ macht; verlangen Sie die
   Kursgliederung, nicht ein Etikett.
3. **Ihre eigenen Trainerinnen und Trainer**, vorbereitet mit [Train the Trainer](../../../trainer/train-the-trainer/README.md),
   unterrichten die Kurse aus dieser Hilfe. So bleibt das Wissen nach Vertragsende im Haus.

## Eine Vorlage für den Plan

```text
Training plan - <site name>                         version <x>, <date>, owner <role>

Group                Course(s)                     Delivered by       When              Seats
Editors              Editors 101                   <supplier/in-house> <weeks before go-live> <n>
Approvers            Editors 201 (modules <list>)  <...>              <...>             <n>
Site administrators  Site administration           <...>              <during build>    <n>
System administrators Hosting and operations       <...>              <before go-live>  <n>
New staff            onboarding path               in-house           within <n> weeks  as needed

Lab: <training installation, see the lab quick card>   Material: free documentation (GFDL 1.3), adapted by <owner>
Assessment: <written test / practical task>            Review of this plan: every <period>
```

Bauen Sie das Lab mit der [Lab-Kurzkarte](../../../trainer/kurzkarte-fuer-die-uebungsumgebung.md) auf; eine Schulungsinstallation auf
SQLite braucht keinen Datenbankserver ([Exponential mit einem Befehl installieren](../../../../../eng-us/features/6.0/install-in-one-command.md)).

## Fallstricke

- **Auf der Produktionswebsite schulen.** Verwenden Sie eine separate Schulungsinstallation; Übungen legen Inhalte an
  und löschen sie.
- **Auf einer anderen Version schulen.** Proben Sie jede Übung auf der Version, die Sie verwenden werden
  ([Kurskatalog](../../../trainer/kurskatalog.md#wie-sie-einen-kurs-nutzen)).
- **Kein Plan für neue Beschäftigte.** Die Startgruppe ist geschult; die Personen, die ein Jahr später kommen, nicht.
- **Schulungsmaterial im Besitz des Lieferanten.** Verlangen Sie im Vertrag, dass angepasstes Material für Sie nutzbar
  bleibt; die Hilfe, auf der es aufbaut, ist bereits freie Dokumentation.

# Rollen und Kurse

Diese Seite richtet sich an die Schulungskoordination, die für jede Person einer öffentlichen Stelle sagen muss, welche
Schulung sie braucht. Sie ordnet die üblichen Rollen den Trainerkursen dieser Hilfe und den Modulen darin zu. Die Kurse,
Module und Längen stammen aus dem [Kurskatalog](../../../../../eng-us/help/trainers/course-catalogue.md) und den dort verlinkten
Kursübersichten.

## Wie Sie die Matrix lesen

- **Muss** bedeutet, dass die Person ohne diese Schulung nicht auf der Live-Website arbeiten sollte.
- **Soll** bedeutet innerhalb der ersten Monate.
- **Optional** bedeutet, wenn die Arbeit der Person es braucht.

Eine „Rolle“ ist hier eine Aufgabe in Ihrer Organisation. Exponential hat ebenfalls Rollen, die Sätze von Berechtigungen
sind ([Rollen, Richtlinien und nicht aktivierte Benutzer](../../../../anleitungen/rollen-und-richtlinien.md)); der letzte Abschnitt
zeigt, wie beide zusammenkommen.

## Rollen den Berechtigungen zuordnen

Schulung und Berechtigungen sollten übereinstimmen: Eine Person erhält eine Rolle in Exponential erst nach der Schulung,
die diese braucht.

| Berufliche Rolle | Typische Rolle oder Einrichtung in Exponential | Lesen |
|---|---|---|
| Redaktion | eine auf eine Sektion oder einen Teilbaum beschränkte Rolle | [Sektionen](../../../../anleitungen/sektionen.md), [Rollen und Richtlinien](../../../../anleitungen/rollen-und-richtlinien.md) |
| Freigebende | eine Rolle, die in einem Workflow freigeben darf | [Workflows](../../../../anleitungen/workflows.md) |
| Administration der Website | eine Administratorrolle | [Sicherheit und Audit](../../../../anleitungen/sicherheit-und-audit.md) |

Schreiben Sie die Regel in das Einarbeitungsverfahren: „Die Rolle wird zugewiesen, nachdem der Kurs abgeschlossen ist.“
Die vierteljährliche Überprüfung der Zugänge im Abschnitt mit den Checklisten für Verwaltungen prüft, dass sie
eingehalten wurde.

## Die Matrix aktuell halten

- Überprüfen Sie sie, wenn die Website eine Funktion hinzubekommt (einen Newsletter, Layouts, eine neue Sprache).
- Überprüfen Sie sie, wenn sich der Kurskatalog ändert; Kursübersichten nennen ihre Module und Längen.
- Bewahren Sie sie neben dem Schulungsplan auf (siehe „Ein Schulungsplan für eine öffentliche Stelle“ in diesem Ordner).

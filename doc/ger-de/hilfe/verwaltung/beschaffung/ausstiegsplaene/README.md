# Ausstiegspläne für eine Exponential-Website

Dieser Abschnitt richtet sich an Projektleitungen, Beschaffungsstellen, Datenschutzbeauftragte und Administratoren, die
sicherstellen müssen, dass die öffentliche Stelle Lieferanten, Hoster oder System wechseln kann, ohne Daten oder Dienst
zu verlieren. Exponential ist freie Software mit offener Speicherung und dokumentierten Exportwerkzeugen, der technische
Weg existiert also; diese Seiten machen daraus einen Plan, eine Vertragsanlage und eine getestete Routine.

## Grundsätze dieses Abschnitts

- **Vor der Unterzeichnung planen; jedes Jahr testen.** Ein ungetesteter Export ist eine Hoffnung, kein Plan.
- **Eine eigene Kopie halten.** Sicherungen, Einstellungen, Schlüssel und Code werden an Sie geliefert, nicht nur vom
  Lieferanten aufbewahrt.
- **Nur dokumentierte Befehle.** Jeder Befehl und jedes Format stammt aus
  [Von Exponential migrieren](../../../../installation/migration/exponential-verlassen.md) und dem Abschnitt zum Hosting.
- **Personenbezogene Daten wandern nur so weit wie nötig**, über verschlüsselte Kanäle, und werden gelöscht, wenn es
  vereinbart ist.

# Sprachen

Dieser Bereich richtet sich an öffentliche Stellen, die Menschen in mehr als einer Sprache bedienen: Führungskräfte,
die die Sprachpolitik festlegen, Administratoren und Websiteersteller, die sie einrichten, Redakteure und Übersetzer,
die schreiben und übersetzen, und Trainer. Er erklärt, was Exponential mitbringt, mit Links zur
Referenzdokumentation, und benennt die Lücken.

Nach oben: [Verwaltungen: hier beginnen](../verwaltungen-hier-beginnen.md).

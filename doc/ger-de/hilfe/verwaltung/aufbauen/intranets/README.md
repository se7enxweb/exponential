# Intranets

Dieser Bereich richtet sich an Behörden, die mit Exponential ein Intranet für Mitarbeiter aufbauen. Er behandelt, wie
interne Inhalte intern bleiben, wie sich Mitarbeiter anmelden und wie Sitzungen und Konten verwaltet werden, und sagt,
wo eine Funktion fehlt oder in der aktuellen Dokumentation ungetestet ist.

Nach oben: [Sites für öffentliche Leistungen aufbauen](../README.md), [Behörden: hier beginnen](../../verwaltungen-hier-beginnen.md).

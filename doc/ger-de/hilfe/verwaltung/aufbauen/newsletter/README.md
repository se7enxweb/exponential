# Newsletter

Dieser Bereich richtet sich an Behörden, die mit Exponential Newsletter oder E-Mail-Warnmeldungen an die Öffentlichkeit
senden. Er behandelt die Erweiterung `cjw_newsletter` und die E-Mail-Einstellungen des Kernels, auf die sie sich
stützt, mit den Pflichten zu Einwilligung und Abmeldung, die mit Mailinglisten einhergehen.

Nach oben: [Sites für öffentliche Leistungen aufbauen](../README.md), [Behörden: hier beginnen](../../verwaltungen-hier-beginnen.md).

# Karten

Dieser Bereich richtet sich an Behörden, die zeigen, wo ihre Büros, Servicestellen oder Einrichtungen sind. Die
Kartenunterstützung von Exponential ist eine Erweiterung, `ezgmaplocation`, die einen Standort an Inhalten speichert und
ihn mit Google Maps zeigt, wenn ein API-Schlüssel gesetzt ist. Es gibt kein GIS, keine selbst gehostete
Kartenintegration und keinen Export von Geodaten; die Seiten sagen das und nennen die Alternativen.

Nach oben: [Sites für öffentliche Leistungen aufbauen](../README.md), [Behörden: hier beginnen](../../verwaltungen-hier-beginnen.md).

# Benutzerdokumentation und Support

Diese Seite richtet sich an Administratoren, Projektleiter und Trainer, die Hilfe für Kontoinhaber und die Menschen
vorbereiten, die sie unterstützen. Gute Hilfe verhindert die meisten Support-Anfragen; ein klares Support-Verfahren
hält den Rest sicher.

## Was Kontoinhaber wissen müssen

| Thema | Sagen Sie |
|---|---|
| Warum es das Konto gibt | was es erlaubt und was nicht (Verfahren anderswo) |
| Welche Daten es enthält | Name, E-Mail-Adresse und Auswahlen; verlinken Sie die Datenschutzerklärung |
| Anmelden | wo die Anmeldung ist, dass der Browser Cookies annehmen muss |
| Vergessenes Passwort | der Link **Passwort vergessen?**; der Link in der Mail funktioniert einmal und eine Stunde lang |
| Zweistufige Anmeldung | wie man sie einschaltet, was bei verlorenem Telefon zu tun ist |
| E-Mail-Auswahlen | **E-Mails von uns (optional)** und wie man sie ändert; Abmeldung mit einem Klick in jeder optionalen Mail |
| Das Konto beenden | wie man es beantragt, was mit den Daten geschieht |
| Support | wie man den Support erreicht, und dass Mitarbeiter nie nach einem Passwort fragen |

## Ein Support-Verfahren

| Regel | Warum |
|---|---|
| Fragen Sie nie nach einem Passwort und nehmen Sie keines an | Mitarbeiter brauchen es nicht; es gewöhnt Menschen daran, es herauszugeben |
| Prüfen Sie die Identität, bevor Sie etwas an einem Konto ändern | ein Angreifer kann den Support anrufen und sich als jemand anderes ausgeben |
| Bevorzugen Sie Selbstbedienung (Passwort vergessen, Mein Konto) | weniger Gelegenheiten für Fehler |
| Halten Sie fest, was getan wurde, nicht die Daten | Audit und Rechenschaft |
| Melden Sie ungewöhnliche Muster weiter (viele gesperrte Konten, viele Zurücksetzungen) | möglicher Angriff |

Identitätsprüfungen für öffentliche Konten sind schwierig, weil das Konto meist nur eine E-Mail-Adresse hat. Eine
gängige Praxis: Eine Support-Aktion, die die Anmeldung ändert (Zurücksetzen der zweistufigen Anmeldung, Änderung der
E-Mail-Adresse), erfolgt erst nach einer Bestätigungsmail an die Adresse des Kontos oder über einen Kanal, auf dem die
Person bekannt ist.

## Häufige Anfragen und Antworten

| Anfrage | Aktion des Supports |
|---|---|
| „Ich habe mein Passwort vergessen“ | verweisen Sie auf **Passwort vergessen?**; prüfen Sie, dass der Mail-Transport funktioniert, wenn keine Mail ankommt |
| „Keine Aktivierungsmail“ | **Benutzer > Nicht aktivierte Benutzer**, **Aktivierungsmail erneut senden**; prüfen Sie, dass die Adresse stimmt |
| „Mein Konto ist gesperrt“ | **Benutzer > Benutzerkonten prüfen**, Filter **Gesperrt**, **Entsperren** nach einer Prüfung |
| „Ich habe mein Telefon verloren“ (zweistufige Anmeldung) | setzen Sie nach der Identitätsprüfung im Benutzerobjekt *Zweistufige Anmeldung* auf *E-mail one-time code* ([Zweistufige Anmeldung](zweistufige-anmeldung.md#wiederherstellung)) |
| „Senden Sie mir keine Mails mehr“ | der Ein-Klick-Link in der Mail, oder **E-Mails von uns** unter **Mein Konto**; ein Administrator sieht den Zustand unter **Setup > E-Mail-Einstellungen** |
| „Löschen Sie mein Konto“ | [Deaktivierung und Entfernung](deaktivierung-und-entfernung.md#auf-einen-antrag-auf-löschung-antworten) |

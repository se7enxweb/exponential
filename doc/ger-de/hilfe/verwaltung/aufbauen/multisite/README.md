# Multisite

Dieser Bereich richtet sich an Behörden, die die Sites mehrerer Abteilungen, nachgeordneter Behörden oder Programme aus
einer Exponential-Installation betreiben. Er erklärt die Formen, die eine solche Installation annehmen kann, die
Schritte, um eine Site hinzuzufügen, und wie Abteilungen wo nötig getrennt bleiben, während geteilt wird, was geteilt
werden soll.

Nach oben: [Sites für öffentliche Leistungen aufbauen](../README.md), [Behörden: hier beginnen](../../verwaltungen-hier-beginnen.md).

## Lesereihenfolge

Führungskräfte: die erste Seite. Administratoren: danach Site hinzufügen, Einstellungen, Rollen und Betrieb.
Site-Ersteller: Designs, gemeinsame Inhalte und Links. Für mehrsprachige Abteilungs-Sites lesen Sie auch den
[Bereich Sprachen](../../sprachen/README.md).

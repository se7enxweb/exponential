# Extranets

Dieser Bereich richtet sich an Behörden, die Inhalte über eine Exponential-Site mit Auftragnehmern,
Partnerorganisationen oder anderen Behörden teilen. Er zeigt, wie Sie jede Partei bei ihren eigenen Inhalten halten,
wie Sie externe Konten verwalten, wenn es kein eingebautes Ablaufdatum für Konten gibt, und wie Sie sehen, was externe
Benutzer getan haben.

Nach oben: [Sites für öffentliche Leistungen aufbauen](../README.md), [Behörden: hier beginnen](../../verwaltungen-hier-beginnen.md).

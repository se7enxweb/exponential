# Checklisten für Verwaltungen

Diese Checklisten richten sich an die Menschen in einer öffentlichen Stelle, die eine Exponential-Website betreiben
oder Leistungen dafür einkaufen: Verantwortliche der Website, Website-Administration, Redaktionen, Beschaffung und
Vertragsmanagement sowie Hoster. Jede ist eine Liste von Punkten `[ ]`, gruppiert nach Phase oder Verantwortlichen, und
jeder Punkt verlinkt auf die Seite, die erklärt, wie es geht. Wo Exponential für etwas keine Funktion hat, sagt die
Checkliste das.

## Lesereihenfolge

- **Einkaufen:** [Vor einer Ausschreibung](vor-einer-ausschreibung.md), dann
  [Vor der Unterzeichnung eines Vertrags](vor-der-unterzeichnung.md), dann [Bereitschaft für den Ausstieg](bereitschaft-fuer-den-ausstieg.md).
- **Starten:** [Checkliste für den Livegang](checkliste-fuer-den-livegang.md), die auf die Checklisten Barrierefreiheit,
  Sicherheit und Datenschutz verweist.
- **Betreiben:** [Vierteljährliche Zugriffsprüfung](vierteljaehrliche-zugriffspruefung.md),
  [Bereitschaft für Aktualisierungen](bereitschaft-fuer-aktualisierungen.md), [Bereitschaft für Datensicherungen](bereitschaft-fuer-datensicherungen.md),
  [Bereitschaft für Vorfälle](bereitschaft-fuer-vorfaelle.md) und einmal im Jahr die
  [Jährliche Überprüfung](jaehrliche-ueberpruefung.md).
- **Veröffentlichen:** [Redaktionelle Qualität](redaktionelle-qualitaet.md) und
  [Einfache Sprache](checkliste-einfache-sprache.md) jeden Tag; die Checklisten für Notfälle, Wahlen,
  Informationsfreiheit und offene Daten, wenn sie zutreffen.

## Wie Sie sie verwenden

- Kopieren Sie eine Checkliste in Ihr eigenes Aufgabensystem und ergänzen Sie die Besonderheiten Ihrer Website (Namen,
  Adressen, Zahlen).
- Punkte, die ein rechtliches Thema nennen, tragen einen Hinweis: Die Checklisten beschreiben Funktionen und gängige
  Praxis, keine Rechtsberatung.
- Die Seiten sind freie Dokumentation; passen Sie sie unter der GNU FDL 1.3 frei an.

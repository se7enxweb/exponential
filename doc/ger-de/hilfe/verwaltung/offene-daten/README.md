# Offene Daten

Dieser Bereich richtet sich an öffentliche Stellen, die Datensätze auf einer mit Exponential gebauten Website
veröffentlichen: Führungskräfte, die das Programm planen, Websiteersteller, die den Katalog einrichten, Redaktionen,
die Datensätze veröffentlichen, und Entwickler, die Portale anbinden. Er erklärt die Begriffe (Open Definition,
EU-Richtlinie über offene Daten, DCAT) mit Links zu ihren amtlichen Texten und zeigt Schritt für Schritt, was
Exponential mitbringt und was nicht.

Nach oben: [Verwaltungen: hier beginnen](../verwaltungen-hier-beginnen.md).

## Was nicht enthalten ist

Exponential hat keine DCAT- oder CKAN-Ausgabe, keine mitgelieferte Datensatzklasse, standardmäßig kein Lizenzfeld und
keine Prüfung hochgeladener Datendateien. Jede Seite sagt, wie Sie die Lücke umgehen, die sie betrifft.

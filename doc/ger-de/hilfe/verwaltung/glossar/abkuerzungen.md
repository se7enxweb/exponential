# Abkürzungen für die Verwaltung

Diese Seite richtet sich an Leserinnen und Leser in einer öffentlichen Stelle, die in dieser Hilfe, in einer
Ausschreibung oder in einer Norm auf eine Abkürzung stoßen. Sie nennt den vollständigen Namen, eine Bedeutung in einer
Zeile und, wo es eine gibt, die amtliche Quelle. Wo der eigene Stand von Exponential wichtig ist, sagt die Zeile, wo Sie
ihn nachlesen.

## Barrierefreiheit

| Abkürzung | Vollständiger Name | Bedeutung und Quelle |
|---|---|---|
| ACR | Accessibility Conformance Report | Konformitätsbericht eines Anbieters zur Barrierefreiheit, oft mit einem VPAT erstellt; für Exponential gibt es keinen ([Standards zur Barrierefreiheit](../../../standards/barrierefreiheit.md#section-508)) |
| ARIA | Accessible Rich Internet Applications | Rollen und Zustände des W3C für assistive Technologien ([WAI-ARIA 1.2](https://www.w3.org/TR/wai-aria-1.2/)) |
| EAA | European Accessibility Act (Europäischer Rechtsakt zur Barrierefreiheit) | Richtlinie (EU) 2019/882 ([EUR-Lex](https://eur-lex.europa.eu/eli/dir/2019/882/oj)) |
| EN 301 549 | (Nummer der europäischen Norm) | Anforderungen an die Barrierefreiheit von IKT-Produkten und -Diensten ([ETSI, v3.2.1](https://www.etsi.org/deliver/etsi_en/301500_301599/301549/03.02.01_60/en_301549v030201p.pdf)); Exponential: „Nicht geprüft“ |
| VPAT | Voluntary Product Accessibility Template | die Vorlage für einen ACR, vor allem für Section 508 ([section508.gov](https://www.section508.gov/)) |
| WAD | Web Accessibility Directive (Richtlinie über den barrierefreien Zugang zu Websites) | Richtlinie (EU) 2016/2102 für Websites und Apps öffentlicher Stellen ([EUR-Lex](https://eur-lex.europa.eu/eli/dir/2016/2102/oj)) |
| WAI | Web Accessibility Initiative | die Gruppe des W3C, die WCAG und Leitfäden veröffentlicht |
| WCAG | Web Content Accessibility Guidelines (Richtlinien für barrierefreie Webinhalte) | [WCAG 2.2](https://www.w3.org/TR/WCAG22/); Exponential admin4: „Teilweise erfüllt“ auf Stufe AA |
| WCAG-EM | WCAG Evaluation Methodology | wie eine Website gegen WCAG geprüft wird ([WCAG-EM](https://www.w3.org/TR/WCAG-EM/)) |

## Sicherheit

| Abkürzung | Vollständiger Name | Bedeutung und Quelle |
|---|---|---|
| 2FA, MFA | Zwei-Faktor- oder Multi-Faktor-Authentifizierung | ein zweiter Nachweis bei der Anmeldung; in Exponential wahlweise ([Zweistufige Anmeldung](../../../anleitungen/zwei-faktor-anmeldung.md)) |
| ASVS | Application Security Verification Standard | der Katalog prüfbarer Anforderungen von OWASP ([OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/)); keine Bewertung von Exponential vorgenommen |
| CSP | Content Security Policy | Browserregeln für erlaubte Quellen ([CSP3](https://www.w3.org/TR/CSP3/)); [Content Security Policy](../../../funktionen/6.0/content-security-policy.md) |
| CSRF | Cross-Site Request Forgery | ein Angriff, der einen angemeldeten Browser missbraucht; Exponential versieht Formulare mit Token ([Sicherheitsstandards](../../../standards/sicherheit.md)) |
| CSF | Cybersecurity Framework | das Rahmenwerk des NIST, Version 2.0 ([nist.gov](https://www.nist.gov/cyberframework)) |
| HSTS | HTTP Strict Transport Security | weist Browser an, nur HTTPS zu verwenden; in Exponential vom Betreiber gesetzt |
| NIS2 | Network and Information Security Directive 2 (NIS-2-Richtlinie) | Richtlinie (EU) 2022/2555 ([EUR-Lex](https://eur-lex.europa.eu/eli/dir/2022/2555/oj)) |
| OWASP | Open Worldwide Application Security Project | veröffentlicht die [Top 10](https://owasp.org/Top10/) und den ASVS |
| TLS | Transport Layer Security | die Verschlüsselung hinter HTTPS ([TLS und HTTPS](../../hosting/sicherheit/tls-und-https.md)) |
| XSS | Cross-Site Scripting | das Einschleusen von Skripten in Seiten; durch Maskierung und CSP gemindert |

## Datenschutz, Recht und offene Daten

| Abkürzung | Vollständiger Name | Bedeutung und Quelle |
|---|---|---|
| DCAT | Data Catalog Vocabulary | Vokabular des W3C für Datenkataloge ([DCAT 3](https://www.w3.org/TR/vocab-dcat-3/)) |
| DPA | Data Processing Agreement (auch: Data Protection Authority) | der Auftragsverarbeitungsvertrag zwischen Verantwortlichem und Auftragsverarbeiter; der Begriff ist mehrdeutig (auch Datenschutzaufsichtsbehörde), schreiben Sie ihn deshalb aus |
| DPIA | Data Protection Impact Assessment | Datenschutz-Folgenabschätzung (DSFA), die die DSGVO für Verarbeitungen mit hohem Risiko verlangt |
| FOI, FOIA | Freedom of Information; Freedom of Information Act | Informationsfreiheit; das öffentliche Recht, Unterlagen anzufordern; USA: [foia.gov](https://www.foia.gov/) |
| GDPR | General Data Protection Regulation | Datenschutz-Grundverordnung (DSGVO), Verordnung (EU) 2016/679 ([EUR-Lex](https://eur-lex.europa.eu/eli/reg/2016/679/oj)); [Datenschutzstandards](../../../standards/datenschutz.md) |
| OAIS | Open Archival Information System | Referenzmodell für digitale Archive, ISO 14721 ([iso.org](https://www.iso.org/standard/57284.html)) |
| ODD | Open Data Directive | Richtlinie (EU) 2019/1024 über offene Daten ([EUR-Lex](https://eur-lex.europa.eu/eli/dir/2019/1024/oj)) |

## Beschaffung und Betrieb

| Abkürzung | Vollständiger Name | Bedeutung |
|---|---|---|
| PoC | Proof of Concept | eine kurze Testinstallation vor einer Entscheidung |
| RFI | Request for Information | eine frühe Markterkundung vor einer Ausschreibung |
| RFP | Request for Proposal | eine Ausschreibung, die Angebote mit Lösungsvorschlägen anfordert |
| RFQ | Request for Quotation | eine Ausschreibung, die Preise für einen festgelegten Umfang anfordert |
| RPO | Recovery Point Objective | wie viele Daten verloren gehen dürfen ([SLA-Optionen](../../hosting/geschaeft/sla-optionen-fuer-exponential-hosting.md)) |
| RTO | Recovery Time Objective | wie lange eine Wiederherstellung dauern darf |
| SLA | Service Level Agreement | messbare Leistungszusagen; das Projekt veröffentlicht keine |
| TCO | Total Cost of Ownership | Gesamtbetriebskosten: alle Kosten über die Lebensdauer eines Systems |

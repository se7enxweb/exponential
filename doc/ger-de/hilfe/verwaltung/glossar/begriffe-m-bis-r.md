# Glossar für Verwaltungen: M bis R

Diese Seite richtet sich an Leserinnen und Leser in einer öffentlichen Stelle, die auf einen unbekannten Begriff
stoßen. Jeder Eintrag hat ein bis drei Sätze und einen Link auf die Seite, die ihn erklärt. Die Einträge sind nach dem
englischen Fachbegriff geordnet, der in Klammern steht. Das vollständige Produktglossar ist das
[Exponential-Glossar](../../../../eng-us/glossary.md).

> **Hinweis** Die Definitionen von Rechtsbegriffen sind Beschreibungen in einfacher Sprache, keine Legaldefinitionen.
> Prüfen Sie das für Ihre Organisation geltende Recht mit Ihrer Rechtsberatung.

1. [M und N](#m-und-n)

## M und N

**Wartungsmodus (Maintenance mode).** Nimmt eine Website während Arbeiten mit einem Hinweis vom Netz; Administratoren
können sich weiterhin anmelden ([Wartungsmodus](../../../anleitungen/wartungsmodus.md)).

**Multisite.** Mehrere Websites, die aus einer Exponential-Installation betrieben werden, jede mit eigenem Siteaccess,
Design und eigenen Einstellungen ([Multisite einrichten](../../../../eng-us/help/creators/website-creators/multisite-setup.md)).

**Knoten (Node).** Eine Stelle eines Inhaltsobjekts im Inhaltsbaum, mit einem übergeordneten Knoten und einer
Sichtbarkeit ([Das Inhaltsmodell und das Bearbeiten von Inhalten](../../../anleitungen/inhaltsmodell-und-bearbeitung.md)).

## O

**Objektzustand (Object state).** Eine eigene Stufe für Inhalte (zum Beispiel „in Prüfung“ oder „archiviert“), die in
Rechten verwendet wird ([Objektzustände](../../../anleitungen/objektzustaende.md)).

**Offene Daten (Open data).** Daten, die so veröffentlicht werden, dass jeder sie unter einer offenen Lizenz nutzen und
weitergeben kann; in der EU siehe die [Richtlinie über offene Daten](https://eur-lex.europa.eu/eli/dir/2019/1024/oj) und
die [Open Definition](https://opendefinition.org/od/2.1/en/).

**Open Source.** Software, deren Lizenz die [Open Source Definition](https://opensource.org/osd) erfüllt: freie
Weitergabe, Quellcode, abgeleitete Werke erlaubt. Die GPL-Lizenz von Exponential ist eine solche.

**Eigentümer (Owner, content).** Der Benutzer, dem ein Inhaltsobjekt gehört; Rollen können einschränken, was jemand mit
eigenen Inhalten tun darf ([Den Eigentümer von Inhalten ändern](../../../anleitungen/eigentuemer-aendern.md)).

## P

**Paket (Package).** Ein Bündel aus Inhaltsklassen, Inhalten, Erweiterungen oder Design, das Exponential exportieren und
installieren kann (`.ezpkg`) und das der Einrichtungsassistent zum Aufbau von Websites verwendet
([Pakete](../../../anleitungen/pakete.md)).

**Penetrationstest (Penetration test).** Ein Test, bei dem eine Prüferin oder ein Prüfer versucht, in ein System
einzudringen. Im Repository von Exponential ist kein solcher Bericht veröffentlicht; beauftragen Sie einen für Ihre
eigene Website, wenn Ihre Regeln es verlangen.

**Einfache Sprache (Plain language).** Text, den Leserinnen und Leser beim ersten Lesen verstehen; in den Vereinigten
Staaten gilt für Bundesbehörden der Plain Writing Act von 2010 ([plainlanguage.gov](https://www.plainlanguage.gov/)).

**Richtlinie (Policy).** Ein einzelnes Recht innerhalb einer Rolle: ein Modul, eine Funktion und optionale
Beschränkungen ([Rollen, Richtlinien und nicht aktivierte Benutzer](../../../anleitungen/rollen-und-richtlinien.md)).

**Auftragsverarbeitungsvertrag (Processing agreement).** Der Vertrag zwischen einem Verantwortlichen und einem
Auftragsverarbeiter, der festlegt, wie mit personenbezogenen Daten umgegangen wird (Artikel 28 der
[DSGVO](https://eur-lex.europa.eu/eli/reg/2016/679/oj)).

**Proof of Concept.** Eine kurze Testinstallation, die vor einer Entscheidung zeigt, dass ein Produkt wichtige
Anforderungen erfüllen kann. Exponential lässt sich mit einem Befehl auf SQLite installieren
([Exponential mit einem Befehl installieren](../../../../eng-us/features/6.0/install-in-one-command.md)).

**Pseudonymisierung (Pseudonymization).** Das Ersetzen von Namen und Kennungen durch Werte, die zusätzliche
Informationen brauchen, um wieder einer Person zugeordnet zu werden. Der Audit-Trail von Exponential pseudonymisiert
Einträge nach einer festgelegten Zahl von Tagen ([Audit-Trail](../../../../eng-us/features/6.0/audit-trail.md)).

## R

**Schriftgutverwaltung (Records management).** Die Verwaltung von Schriftgut von der Entstehung bis zur Aussonderung
nach einem Aufbewahrungsplan; die internationale Norm ist ISO 15489-1 ([iso.org](https://www.iso.org/standard/62542.html)).
Exponential bewahrt Inhaltsversionen und einen Audit-Trail auf, ist aber für sich kein System zur Schriftgutverwaltung
([Versionen eines Objekts](../../../anleitungen/inhaltsverlauf.md)).

**Weiterleitung (Redirect).** Eine Anweisung, die einen Besucher von einer alten Adresse zu einer neuen schickt; in
Exponential erledigen das URL-Platzhalter und Aliasse ([Links, URL-Aliasse, Platzhalter](../../../anleitungen/urls-und-aliase.md)).

**Request for Proposal (RFP).** Eine Ausschreibungsunterlage, die Anbieter um Angebote zu festgelegten Anforderungen
bittet.

**request-shield.** Eine kleine Web Application Firewall des CJW Network, ein getrenntes, MIT-lizenziertes Projekt, die
vor dem Kernel von Exponential läuft: Sie weist Scanner ab, bremst Anfragefluten und kann die Administration auf ein
Netz beschränken. Der Leitfaden zur Härtung empfiehlt sie für jede aus dem Internet erreichbare Website
([Sicherheitshärtung](../../sicherheitshaertung.md#ein-vorgeschalteter-schutzschild-request-shield)).

**Aufbewahrungsplan (Retention schedule).** Die Regel, wie lange jede Art von Schriftgut oder Daten vor der Löschung
oder Archivierung aufbewahrt wird.

**Von rechts nach links (Right-to-left, RTL).** Sprachen, die von rechts nach links geschrieben werden, etwa Arabisch
und Hebräisch; Exponential setzt für sie die Schreibrichtung der Seite
([Sprachen mit Schreibrichtung von rechts nach links](../../../../eng-us/features/6.0/right-to-left.md)).

**Rolle (Role).** Eine benannte Menge von Richtlinien, die Benutzern oder Gruppen zugewiesen wird
([Rollen, Richtlinien und nicht aktivierte Benutzer](../../../anleitungen/rollen-und-richtlinien.md)).

**RPO und RTO.** Recovery Point Objective (wie viele Daten verloren gehen dürfen) und Recovery Time Objective (wie lange
eine Wiederherstellung dauern darf)
([SLA-Optionen für das Hosting von Exponential](../../hosting/geschaeft/sla-optionen-fuer-exponential-hosting.md#wiederherstellungspunkt-und-wiederherstellungszeit)).

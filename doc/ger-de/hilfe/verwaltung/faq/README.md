# FAQ für Verwaltungen

Diese Seiten beantworten die Fragen, die öffentliche Stellen zu Exponential stellen, bei der Beschaffung, bei der
Bewertung und in der täglichen Arbeit. Jede Antwort verlinkt die Seite der Dokumentation, die sie belegt, und die
Antworten sagen „Nein“, wo das Produkt etwas nicht leistet: kein VPAT, kein Cookie-Banner, kein veröffentlichtes SLA,
keine eingebauten Aufbewahrungspläne, kein GIS. Diese ehrlichen Antworten sind in einer Beschaffung so nützlich wie die
positiven.

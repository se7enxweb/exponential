# Gliederung einer Datenschutzerklärung für eine Exponential-Website

Diese Seite richtet sich an Datenschutzbeauftragte und an die Redakteure, die die Erklärung veröffentlichen.
Exponential liefert keinen Text für eine Datenschutzerklärung mit. Ihre Organisation schreibt ihn; die folgende
Gliederung hilft Ihnen, abzudecken, was die Software tut, mit Fakten aus dem Datenschutzbereich dieser Hilfe. Wenn Ihre
Aufsichtsbehörde ein Muster veröffentlicht, folgen Sie diesem.

> **Hinweis** Diese Seite beschreibt Funktionen und gängige Praxis; sie ist keine Rechtsberatung. Prüfen Sie das für
> Ihre Organisation geltende Recht mit Ihrer Rechtsberatung.

## Die Gliederung

| Abschnitt | Was für eine Exponential-Website zu sagen ist |
|---|---|
| Wer wir sind | der Verantwortliche, Kontakt, Kontakt der bzw. des Datenschutzbeauftragten |
| Was diese Erklärung abdeckt | die Adresse(n) und Dienste der Website |
| Besuch der Website | technische Protokolle: maskierte Adressen in Anfrageprotokollen zur Sicherheit, 30 oder 90 Tage aufbewahrt; Webserver-Protokolle, wie Ihr Hoster sie aufbewahrt |
| Cookies | das Sitzungscookie und `is_logged_in` (funktional); alle weiteren, die Sie hinzugefügt haben (siehe „Von Exponential gesetzte Cookies“) |
| Formulare | welche Formulare, was erhoben wird, wer es liest, wie lange Sie es aufbewahren |
| Konten | für Beschäftigte oder Mitglieder: was gespeichert wird, Anmeldeaufzeichnungen, zweistufige Anmeldung, falls genutzt |
| E-Mail | Kategorien, Opt-in und Double-Opt-in, der Einwilligungsnachweis (Zeit, Wortlaut, IP-Adresse), Abmelden in jeder E-Mail, Aufbewahrung des Einwilligungsprotokolls |
| Sicherheit und Audit | ein Audit-Trail der administrativen Handlungen, minimiert (gekürzte Adressen, gehashte Sitzungen), Aufbewahrung |
| Suche | ob Suchbegriffe aufgezeichnet werden und dass sie zurückgesetzt werden |
| Drittanbieter | jeder aktive Dienst (Webanalyse, CAPTCHA, Karten, Social Login, KI-Anbieter): was er erhält, warum |
| Empfänger und Auftragsverarbeiter | Hosting-Unternehmen, Umsetzungs- und Supportpartner |
| Aufbewahrung | pro Kategorie, aus Ihrem Aufbewahrungsplan |
| Ihre Rechte | Auskunft, Berichtigung, Löschung, Einschränkung, Widerspruch, Datenübertragbarkeit, Beschwerde bei der Aufsichtsbehörde; wie ein Antrag gestellt wird |
| Änderungen | Datum der Erklärung und wie Änderungen bekannt gegeben werden |

## Sie veröffentlichen

1. Legen Sie sie als Inhaltsseite in jedem Sprach-Siteaccess an, mit einem stabilen URL-Alias (zum Beispiel
   `/privacy`).
2. Verlinken Sie sie in der Fußzeile jeder Seite sowie in jedem Formular und jeder E-Mail-Fußzeile.
3. Schreiben Sie sie in einfacher Sprache, mit Überschriften; vermeiden Sie eine Erklärung, die es nur als PDF gibt.
4. Bewahren Sie frühere Fassungen auf: Die Versionsseite des Objekts zeigt sie, innerhalb der Grenze der
   Versionsgeschichte.

## Sie zutreffend halten

Überprüfen Sie sie, wenn Sie eine Erweiterung aktivieren, ein Formular oder eine E-Mail-Kategorie hinzufügen, das
Hosting wechseln oder Aufbewahrungseinstellungen ändern. Eine Erklärung, die Dienste nennt, die Sie nicht nutzen, oder
solche auslässt, die Sie nutzen, ist bei jeder Prüfung ein Befund.

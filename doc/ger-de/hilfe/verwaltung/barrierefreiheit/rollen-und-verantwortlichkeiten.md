# Rollen und Verantwortlichkeiten für die Barrierefreiheit

Diese Seite richtet sich an die Projektverantwortlichen oder den Product Owner, die die Barrierefreiheit einer
öffentlichen Website organisieren. Barrierefreiheit scheitert, wenn sie niemandem gehört. Die folgende Matrix ordnet
die wiederkehrenden Aufgaben Rollen zu und nennt die Werkzeuge von Exponential, mit denen jede Rolle arbeitet. Passen
Sie die Rollenbezeichnungen an Ihre Organisation an.

## Inhalt

1. [Die Rollen](#die-rollen)
2. [Verantwortungsmatrix](#verantwortungsmatrix)
3. [Schulung](#schulung)
4. [Verwandte Seiten](#verwandte-seiten)

## Die Rollen

| Rolle | Typische Person | Wichtigste Werkzeuge in Exponential |
|---|---|---|
| Verantwortliche | Leitung Digitales, Product Owner | die Seite mit der Erklärung zur Barrierefreiheit, Berichte |
| Koordination Barrierefreiheit | Fachkraft oder geschulte Webverantwortliche | Testwerkzeuge, Setup > Gesammelte Informationen (Rückmeldungen), Befundtabelle |
| Redaktion | Beschäftigte der Kommunikation, Fachleute | Bearbeitungsformular, Alternativer Bildtext, Versionen, Vorschau |
| Administration | Web-Administratorinnen und -Administratoren | Setup > Klassen („Alternativtext ist erforderlich“), Designeinstellungen der Administration, Rollen |
| Design | intern oder Lieferant | das öffentliche Design, Farb-Tokens, Templates |
| Entwicklung | intern oder Lieferant | Templates, Overrides, Skripte, die Testsuite `design` für Erweiterungen der Administration |
| Lieferanten | Agentur, Hosting-Partner | wie vertraglich vereinbart (siehe „Klauseln zur Barrierefreiheit für die Beschaffung“) |
| Trainerinnen und Trainer | intern oder Partner | Schulungskurse |

## Verantwortungsmatrix

R = führt aus, A = verantwortlich, C = wird konsultiert.

| Aufgabe | Verantwortliche | Koordination | Redaktion | Administration | Design | Entwicklung |
|---|---|---|---|---|---|---|
| Das Ziel festlegen (z. B. WCAG 2.2 AA) | A | R | | | C | C |
| Das öffentliche Design prüfen | A | R | | | C | C |
| Befunde in Templates beheben | A | C | | | R | R |
| Barrierefreie Inhalte schreiben | | C | R | | | |
| Alternativtext an Bildfeldern verlangen | | C | | R | | |
| Die Redaktion bei admin4 halten | | C | | R | | |
| Die Erklärung schreiben und veröffentlichen | A | R | C | | | |
| Rückmeldungen beantworten | A | R | C | | | C |
| Monatliche Stichprobe der Inhalte | | R | C | | | |
| Vor jedem Release testen | | C | | | R | R |
| Barrierefreiheit in Ausschreibungen | A | C | | | | |

## Schulung

- Redaktion: ein kurzer Kurs zu Alternativtext, Überschriften, Links, Tabellen und Dokumenten, mit Ihren eigenen
  Beispielen. Der Schulungsbereich dieser Hilfe hat Kurse für die Redaktion
  ([Kurskatalog](../../trainer/kurskatalog.md)).
- Administration: Klasseneinstellungen, Designeinstellungen, Rollen.
- Design und Entwicklung: [Barrierefreiheit für Website-Ersteller](../../../../eng-us/help/creators/website-creators/accessibility-for-site-builders.md)
  und [Styling von admin4](../../../bc/6.0/admin4-gestaltung.md) für Erweiterungen der Administration.
- Trainerinnen und Trainer, die ihre eigenen Materialien barrierefrei gestalten: Der Kurs für Trainerinnen und Trainer
  hat ein Modul zu Barrierefreiheit und Inklusion
  ([Barrierefreie Kursmaterialien](../../trainer/train-the-trainer/modul-05-barrierefreiheit-und-inklusion/barrierefreie-kursmaterialien.md)).

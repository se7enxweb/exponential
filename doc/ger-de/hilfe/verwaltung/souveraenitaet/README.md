# Digitale Souveränität

Dieser Bereich richtet sich an öffentliche Stellen, die die Kontrolle über ihre Webplattform behalten müssen: wo sie
läuft, wer sie ändern kann, wo die Daten liegen und wie man einen Anbieter verlässt. Er sagt zu jedem Punkt, was
Exponential mitbringt, mit Links zu den Nachweisen, und was die eigene Arbeit der Stelle bleibt.

Nach oben: [Verwaltungen: hier beginnen](../verwaltungen-hier-beginnen.md).

# Zwei Versionen vergleichen

Diese Seite ist für Redakteure und Freigebende, die genau sehen müssen, was sich geändert hat: bevor sie eine Änderung
freigeben, wenn ein Bürger sagt, auf der Seite habe früher etwas anderes gestanden, oder wenn sie die Korrektur einer
Kollegin prüfen. Die Versionsseite eines Objekts vergleicht Versionen Feld für Feld
([Versionen eines Objekts, 2](../../../../anleitungen/inhaltsverlauf.md#2-die-aktionen-einer-version)).

## Inhalt

1. [Bevor Sie beginnen](#bevor-sie-beginnen)

## Bevor Sie beginnen

- Sie dürfen die Versionen lesen, die Sie vergleichen, und haben die Richtlinie `content/diff` (sonst wird
  **Vergleichen** nicht angezeigt).
- Für den Entwurf oder die ausstehende Version einer anderen Person brauchen Sie `content/versionread`.

## Schritte

**Eine Version mit der aktuellen:**

1. Öffnen Sie die Seite, **Versionen verwalten**.
2. Klicken Sie auf der Karte der Version auf **Vergleichen**. (Auf der Karte der aktuellen Version wird mit der
   neuesten anderen Version verglichen, die Sie lesen dürfen.)

**Zwei beliebige Versionen:**

1. Wählen Sie auf der Versionsseite unter **Zwei Versionen vergleichen** die ältere und die neuere Version und die
   Übersetzung.
2. Klicken Sie auf **Unterschiede anzeigen**.

Die Unterschiede werden über der Liste angezeigt: als Änderungen im Text, als Änderungen im Block oder nur die alte
oder die neue Version. Filtern Sie die Liste zuerst nach **Status** (*Archiviert*) oder **Ersteller**, um Versionen
schnell zu finden.

## Das Ergebnis prüfen

- [ ] Der Vergleich nennt die beiden Versionen und die Übersetzung.
- [ ] Geänderte Felder sind markiert, unveränderte nicht.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Die falsche Übersetzung vergleichen | wählen Sie die Übersetzung in den Auswahllisten |
| Erwarten, dass Änderungen an Dateien als Text erscheinen | eine ersetzte Datei erscheint als geändertes Dateifeld; öffnen Sie beide Versionen, um Dokumente zu vergleichen |
| Alte Versionen fehlen | Versionen jenseits des Limits der Versionsgeschichte wurden entfernt |
| Freigeben, ohne zu vergleichen | vergleichen Sie bei Änderungen an veröffentlichten Seiten zuerst ([Eine Seite freigeben oder ablehnen](eine-seite-freigeben-oder-ablehnen.md)) |

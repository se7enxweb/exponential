# Eine Zusammenfassung in einfacher Sprache schreiben

Diese Seite ist für Redakteure, die die ersten Zeilen einer Seite schreiben: das Feld **In short**, **Intro** oder
**Summary**. Die meisten Besucher lesen nur diese Zeilen, und Suchergebnisse und Linkvorschauen zeigen sie. Leitlinien
von Regierungsseite zur einfachen Sprache sind unter [plainlanguage.gov](https://www.plainlanguage.gov/) gesammelt;
diese Seite gibt eine kurze Methode.

1. [Bevor Sie beginnen](#bevor-sie-beginnen)

## Bevor Sie beginnen

- Wissen Sie, wer die Seite liest und was die Leser tun möchten.
- Halten Sie den vollständigen Text oder das Dokument bereit.

## Schritte

1. Beantworten Sie drei Fragen, jede in einem Satz:
   - Was ist das?
   - Für wen ist es?
   - Was soll der Leser tun, oder was geschieht als Nächstes?
2. Verwenden Sie die Wörter Ihrer Leser; setzen Sie den amtlichen Begriff einmal in Klammern, wenn er nötig ist.
3. Stellen Sie die wichtigste Tatsache an den Anfang (eine Frist, eine Änderung, Kosten).
4. Beschränken Sie jeden Satz auf einen Gedanken; streben Sie Sätze unter etwa 20 Wörtern an.
5. Verwenden Sie „Sie“ und aktive Verben: „Sie können bis zum 31. März einen Antrag stellen“ statt „Anträge können bis
   ... eingereicht werden“.
6. Lesen Sie es laut vor. Wenn Sie stolpern, schreiben Sie es neu.
7. Tragen Sie es in das Feld für die Zusammenfassung ein; **Vorschau**; **Zur Veröffentlichung schicken**.

## Muster, die funktionieren

| Seite | Form der Zusammenfassung |
|---|---|
| Eine Dienstleistung | „Sie können <was tun>, wenn <wer>. Es kostet <Kosten>. Beantragen Sie es online oder bei <Ort>.“ |
| Ein Bericht | „Dieser Bericht zeigt <wichtigstes Ergebnis>. Er umfasst <Umfang und Zeitraum>. Die wichtigsten Empfehlungen sind <zwei oder drei>.“ |
| Eine Bekanntmachung | „<Was> wird vom <Datum> bis zum <Datum> bei <Ort> <geschehen>. <Was die Menschen tun sollen>.“ |
| Ein Beteiligungsverfahren | „Wir schlagen <was> vor. Sagen Sie uns bis zum <Datum>, was Sie denken. Ihre Antworten helfen bei der Entscheidung über <was>.“ |

## Das Ergebnis prüfen

- [ ] Jemand außerhalb Ihres Teams versteht die Zusammenfassung, ohne weiterzulesen.
- [ ] Daten, Beträge und Orte sind genau.
- [ ] Die Zusammenfassung ergibt in einem Suchergebnis Sinn, ohne den Rest der Seite.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Den Titel wiederholen | fügen Sie Informationen hinzu |
| Mit der Organisation beginnen („Das Ministerium für Beispiel teilt mit ...“) | beginnen Sie mit dem, worauf es dem Leser ankommt |
| Abkürzungen | schreiben Sie sie aus |
| „Bitte beachten Sie das beigefügte Dokument“ | die Zusammenfassung muss für sich allein stehen |

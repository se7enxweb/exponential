# Das Sitzungsprotokoll nach der Genehmigung veröffentlichen

Diese Seite ist für Redakteure, die Protokolle veröffentlichen, nachdem der Rat oder Ausschuss sie genehmigt hat,
meist in seiner nächsten Sitzung. Protokolle gehören zur amtlichen Überlieferung: Veröffentlichen Sie den genehmigten
Text, hinterlassen Sie bei jeder Änderung eine Spur und ersetzen Sie die Niederschrift niemals stillschweigend.

## Inhalt

1. [Bevor Sie beginnen](#bevor-sie-beginnen)
2. [Schritte](#schritte)
3. [Das Ergebnis prüfen](#das-ergebnis-prüfen)

## Bevor Sie beginnen

- Das Protokoll ist genehmigt, und Sie haben die endgültige Datei (ein barrierefreies PDF oder Text für die Seite).
- Sie wissen, ob Ihre Regeln auch Protokollentwürfe vor der Genehmigung veröffentlichen.
- Sie können die Seite der Sitzung bearbeiten.

## Schritte

1. Laden Sie das Protokoll hoch: Öffnen Sie den Ordner **Papers** der Sitzung (oder den Ordner für Protokolle in der
   Medienbibliothek), **Hochladen**, wählen Sie die Datei, geben Sie den Titel „Protokoll <Gremium>, <Datum>
   (genehmigt)“ an und klicken Sie auf **Upload all** ([Medien und Uploads](../../../medien-und-uploads.md#dateien-hochladen)).
2. Öffnen Sie die Sitzung, **Bearbeiten**.
3. Klicken Sie unter **Minutes** auf **Vorhandenes hinzufügen** und wählen Sie das neue Datei-Objekt (oder
   **Neu hochladen**, um Schritt 1 hier zu erledigen).
4. Setzen Sie **Status** auf *minutes approved* (oder *record complete*).
5. Fügen Sie dem Feld der Tagesordnung bei Bedarf eine Zeile hinzu: „Protokoll genehmigt am <Datum>.“
6. **Zur Veröffentlichung schicken**.

Wenn ein Protokollentwurf früher als eigene Datei veröffentlicht wurde, verstecken Sie entweder die Entwurfsdatei
([Eine Seite vorübergehend verstecken](eine-seite-voruebergehend-verstecken.md)) oder behalten Sie sie, deutlich mit „Entwurf“
betitelt, wie Ihre Regeln es verlangen.

## Das Ergebnis prüfen

- [ ] Abgemeldet zeigt die Seite der Sitzung den Link zum Protokoll und den Status.
- [ ] Das Protokoll lässt sich herunterladen und öffnen.
- [ ] **Versionen verwalten** an der Sitzung zeigt die neue Version; die frühere ist archiviert.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Protokolle vor der Genehmigung veröffentlichen, wenn Ihre Regeln es verbieten | prüfen Sie den Status mit dem Ratsbüro |
| Ein genehmigtes Protokoll durch eine andere Datei ersetzen | Korrekturen laufen über das Gremium, das es genehmigt hat; veröffentlichen Sie die korrigierte Datei als neue Version mit einem Hinweis ([Ein Dokument durch eine neue Version ersetzen](ein-dokument-durch-eine-neue-version-ersetzen.md)) |
| Namen von Bürgern im Protokoll | folgen Sie Ihren Regeln dazu, was veröffentlicht wird; prüfen Sie es vor dem Upload |
| Protokolle nur als Scan | bitten Sie um eine barrierefreie Fassung; die Seite sollte die wichtigsten Beschlüsse als Text nennen |

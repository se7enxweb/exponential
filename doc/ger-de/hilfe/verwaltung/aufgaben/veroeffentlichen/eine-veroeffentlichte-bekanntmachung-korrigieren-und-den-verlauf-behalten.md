# Eine veröffentlichte Bekanntmachung korrigieren und den Verlauf behalten

Diese Seite ist für Redakteure, die einen Fehler in etwas bereits Veröffentlichtem finden: ein falsches Datum in einer
Bekanntmachung, einen falschen Betrag, eine falsche Adresse. Behörden korrigieren offen: Die Seite sagt, dass sie
korrigiert wurde, und der frühere Wortlaut bleibt für die Mitarbeiter in der Versionsgeschichte verfügbar. Jedes
Speichern ist eine Version ([Veröffentlichen, Versionen und der Papierkorb](../../../veroeffentlichen-und-versionen.md)).

## Bevor Sie beginnen

- Sie können das Element bearbeiten.
- Sie wissen, ob der Fehler für Menschen wichtig ist, die danach gehandelt haben (eine falsche Frist ist es, ein
  Tippfehler nicht).
- Wenn es eine gesetzlich vorgeschriebene Bekanntmachung ist, wissen Sie, ob eine Korrektur eine Bekanntmachungsfrist
  neu beginnen lässt (fragen Sie die zuständige Stelle).

## Schritte

1. Öffnen Sie die Bekanntmachung und klicken Sie auf **Bearbeiten**. Aus der veröffentlichten Version entsteht ein
   neuer Entwurf.
2. Korrigieren Sie den Text.
3. Fügen Sie einen Korrekturhinweis an einer Stelle ein, an der die Leser ihn sehen, am Anfang oder am Ende:
   „Korrigiert am <Datum>: Der Einsendeschluss ist der <Datum>, nicht der <Datum>.“ Für einen Tippfehler ist kein
   Hinweis nötig.
4. Sehen Sie sich bei einer großen Änderung die **Vorschau** des Entwurfs an.
5. Veröffentlichen Sie:
   - **Zur Veröffentlichung schicken** für eine Korrektur, von der die Abonnenten erfahren sollen (sie werden beim
     nächsten Lauf benachrichtigt);
   - **Ohne Benachrichtigung veröffentlichen**, wo Ihre Site das anbietet, für einen Tippfehler
     ([Veröffentlichen, ohne die Abonnenten zu benachrichtigen](veroeffentlichen-ohne-die-abonnenten-zu-benachrichtigen.md)).

## Das Ergebnis prüfen

- [ ] Der korrigierte Text erscheint für abgemeldete Besucher.
- [ ] **Versionen verwalten** listet die vorherige Version als *Archiviert*; **Vergleichen** zeigt Ihre Änderung
  ([Zwei Versionen vergleichen](zwei-versionen-vergleichen.md)).
- [ ] Wenn die Bekanntmachung auch in einem RSS-Feed steht, zeigt der Feed den neuen Text, sobald er das nächste Mal
  geschrieben wird.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Eine Tatsache, nach der Menschen gehandelt haben, stillschweigend korrigieren | fügen Sie bei Tatsachen immer einen Korrekturhinweis hinzu |
| Die alte Version entfernen, um den Fehler zu verbergen | der Verlauf gehört zur Rechenschaft; entfernen Sie Versionen nur aus rechtlichen Gründen, etwa bei unrechtmäßig veröffentlichten personenbezogenen Daten ([Versionen von Dokumenten](../../aufbauen/dokumente-und-publikationen/versionen-von-dokumenten.md#eine-datei-entfernen-die-nicht-bleiben-darf)) |
| Den offenen Entwurf einer anderen Person bearbeiten | die Seite **Möglicher Bearbeitungs-Konflikt** erscheint; setzen Sie Ihren eigenen Entwurf fort oder legen Sie einen **Neuer Entwurf** an |
| Die falsche Sprache | wählen Sie die Sprache vor **Bearbeiten**; korrigieren Sie jede Übersetzung |

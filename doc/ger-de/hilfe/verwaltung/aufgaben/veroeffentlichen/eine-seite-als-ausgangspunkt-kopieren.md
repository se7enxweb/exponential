# Eine Seite als Ausgangspunkt kopieren

Diese Seite ist für Redakteure, die eine Seite anlegen, die einer bestehenden sehr ähnlich ist: die Veranstaltung des
nächsten Jahres, eine ähnliche Bekanntmachung, eine Dienstleistung im selben Format. **Kopieren** erstellt aus einem
bestehenden Objekt ein neues an einer Stelle Ihrer Wahl
([Inhaltsmodell und Bearbeitung, 10](../../../../anleitungen/inhaltsmodell-und-bearbeitung.md#10-kopieren-orte-und-wie-auswahlen-angezeigt-werden)).

## Bevor Sie beginnen

- Sie dürfen dort Inhalte anlegen, wo die Kopie hingehört (sonst ist die Schaltfläche **Kopieren** ausgegraut und sagt,
  warum).
- Entscheiden Sie, ob die Kopie sofort sichtbar sein soll. Eine Kopie wird sofort veröffentlicht; um sie ungesehen
  vorzubereiten, kopieren Sie sie in einen Vorbereitungsordner, den Besucher nicht lesen können, oder verstecken Sie sie
  gleich nach dem Kopieren.

## Schritte

1. Öffnen Sie die zu kopierende Seite und klicken Sie auf **Kopieren** (neben **Verschieben** und **Entfernen**), oder
   wählen Sie **Kopieren** im Menü des Elements.
2. Wählen Sie, wohin die Kopie kommt.
3. Wenn Ihre Site fragt, wählen Sie, welche Versionen kopiert werden (meist nur die aktuelle).
4. Öffnen Sie die Kopie (sie hat denselben Namen), klicken Sie auf **Bearbeiten** und ändern Sie Titel, Daten, Text
   und Relationen.
5. **Zur Veröffentlichung schicken**.

Für eine Seite mit Unterelementen (eine Veranstaltungsreihe, ein Handbuch) hat das Menü des Elements
**Teilbaum kopieren**, das das Element mit allem darunter kopiert; ein großer Teilbaum kann als Hintergrundauftrag
laufen. Für mehrere Seiten markieren Sie sie in einer Liste **Unterelemente**, **Weitere Aktionen** >
**Auswahl kopieren**.

## Das Ergebnis prüfen

- [ ] Die Kopie hat ihre eigene Adresse (der URL-Alias entsteht aus ihrem neuen Namen, nachdem Sie sie umbenannt
  haben).
- [ ] Das Original ist unverändert.
- [ ] Von den alten Inhalten bleibt nichts in der Kopie (Daten, Namen, Links).

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Eine sichtbare, halb bearbeitete Kopie | kopieren Sie in einen Vorbereitungsordner oder verstecken Sie sie zuerst |
| Die Adresse beruht noch auf dem alten Namen | benennen Sie vorher oder gleich danach um; der Alias folgt dem Namen |
| Relationen verweisen noch auf die Dokumente des Vorjahres | aktualisieren Sie die Relationsfelder |
| Eine Seite kopieren, um sie an zwei Stellen zu zeigen | verwenden Sie stattdessen einen zweiten Ort ([Ein Element an mehreren Stellen veröffentlichen](ein-element-an-mehreren-stellen-veroeffentlichen.md)) |

# Eine Pressemitteilung veröffentlichen

Diese Seite ist für Pressereferenten, die Mitteilungen auf der Website veröffentlichen. Sie funktioniert mit einer
Klasse Press release (wie in [Pressemitteilungen](../../aufbauen/nachrichten-und-warnmeldungen/pressemitteilungen.md)) oder mit der
mitgelieferten Klasse Article. Für eine Mitteilung, die zu einer festen Zeit erscheinen muss, siehe
[Eine Nachricht zeitgesteuert veröffentlichen](eine-nachricht-zeitgesteuert-veroeffentlichen.md).

## Inhalt

1. [Bevor Sie beginnen](#bevor-sie-beginnen)
2. [Schritte](#schritte)

## Bevor Sie beginnen

- Der Text ist von der Stelle genehmigt, die in Ihrer Organisation Pressemitteilungen freigibt.
- Bilder: Sie haben das Recht, sie zu verwenden, den Bildnachweis und einen Alternativtext für jedes.
- Sie wissen, ob Ihre Mitteilung auf der Site einen Freigabe-Workflow durchläuft.

## Schritte

1. Öffnen Sie den Ordner der Pressemitteilungen (zum Beispiel **News > Press releases > <Jahr>**), **Neu erstellen**,
   wählen Sie **Press release** (oder **Article**).
2. Füllen Sie den Titel, den Vorspann (den ersten Absatz: wer, was, wann, wo), den Text und die Hinweise für
   Redaktionen aus.
3. **Press contact**: die Rufnummer und das gemeinsame Postfach der Pressestelle, keine private Mobilnummer.
4. **Attachments** oder **Image**: **Neu hochladen**, wählen Sie das Foto, füllen Sie seinen **Alternativtext** aus und
   tragen Sie den Bildnachweis in die Bildunterschrift oder Beschreibung ein
   ([Bildern Alternativtext geben](bildern-alternativtext-geben.md)).
5. **Topics**: Fügen Sie die Schlagwörter der Politikfelder hinzu ([Inhalte mit eztags verschlagworten](inhalte-mit-eztags-verschlagworten.md)).
6. **Vorschau**, dann **Zur Veröffentlichung schicken**.

## Das Ergebnis prüfen

- [ ] Die Mitteilung erscheint abgemeldet oben in der Liste der Pressemitteilungen.
- [ ] Der RSS-Feed für Medien listet sie, sobald der Feed das nächste Mal geschrieben wird
  ([RSS-Feeds](../../aufbauen/nachrichten-und-warnmeldungen/rss-feeds.md)).
- [ ] Die Bilder erscheinen mit Alternativtext (prüfen Sie es mit dem Barrierefreiheits-Inspektor des Browsers oder
  einem Screenreader).
- [ ] Wenn sie zur Freigabe ging: **Meine ausstehenden Elemente** zeigt sie, bis sie freigegeben ist.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Vor einer Sperrfrist veröffentlichen | verwenden Sie die zeitgesteuerte Methode oder warten Sie |
| Eine private Telefonnummer als Pressekontakt | verwenden Sie Funktionskontakte; das Personal wechselt |
| Bilder von Personen ohne Einwilligung, wo Ihre Regeln sie verlangen | prüfen Sie es vor dem Upload |
| Die ganze Mitteilung nur als PDF | der Text gehört auf die Seite; ein PDF kann eine Ergänzung sein |
| Eine Mitteilung stillschweigend korrigieren | korrigieren Sie offen ([Eine veröffentlichte Bekanntmachung korrigieren und den Verlauf behalten](eine-veroeffentlichte-bekanntmachung-korrigieren-und-den-verlauf-behalten.md)) |

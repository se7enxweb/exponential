# Viele Elemente auf einmal bearbeiten

Diese Seite ist für Redakteure, die auf vielen Seiten dasselbe ändern müssen: eine neue Telefonnummer auf zehn
Dienstleistungsseiten, ein Prüfdatum auf allen Seiten einer Sektion, ein Schlagwort an einer Reihe von
Bekanntmachungen. Exponential bearbeitet mehrere Objekte in einem Formular
([Inhaltsmodell und Bearbeitung, 6](../../../../anleitungen/inhaltsmodell-und-bearbeitung.md#6-viele-elemente-in-einem-formular-bearbeiten-mehrfachbearbeitung)).

## Bevor Sie beginnen

- Sie dürfen jedes Element bearbeiten, das Sie auswählen; Elemente, die Sie nicht bearbeiten dürfen, werden im Bericht
  abgelehnt.
- Wenn die Angaben an einer Stelle gepflegt werden (einer Kontaktstelle), ändern Sie stattdessen dieses eine Objekt
  ([Öffnungszeiten oder Kontaktdaten aktualisieren](oeffnungszeiten-oder-kontaktdaten-aktualisieren.md)).

## Schritte

1. Wählen Sie die Elemente aus:
   - markieren Sie sie in der Liste **Unterelemente** eines Ordners, **Weitere Aktionen** > **Ausgewählte bearbeiten**;
     oder
   - suchen Sie (`/content/search`), markieren Sie Ergebnisse aus der ganzen Site und klicken Sie auf
     **Ausgewählte bearbeiten**.
2. Das Formular zeigt einen Abschnitt je Inhaltsklasse und ein aufklappbares Feld je Element; darüber stehen
   **Alle aufklappen** und **Alle zuklappen**.
3. Nehmen Sie die Änderung in jedem Element vor.
4. Klicken Sie auf:
   - **Entwürfe speichern**, um die Arbeit zu behalten, ohne zu veröffentlichen;
   - **Alle veröffentlichen**, um jedes Element zu veröffentlichen;
   - **Verwerfen**, um die Entwürfe wegzuwerfen.
5. Lesen Sie den Bericht: welche Elemente veröffentlicht wurden, welche auf Freigabe warten, welche abgelehnt wurden.

## Viele Elemente anlegen

**Mehrere neu anlegen** (neben **Neu erstellen**) öffnet ein Formular für bis zu 50 neue Elemente unter derselben
Stelle, zum Beispiel die Sitzungen eines Jahres.

## Das Ergebnis prüfen

- [ ] Der Bericht listet jedes Element als veröffentlicht (oder als ausstehend, wo eine Freigabe gilt).
- [ ] Öffnen Sie zwei oder drei Elemente abgemeldet, um die Änderung zu bestätigen.
- [ ] Elemente, die auf Freigabe warten, stehen unter **Meine ausstehenden Elemente**.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Angaben ändern, die in ein gemeinsames Objekt gehören | verknüpfen Sie ein gemeinsames Objekt, statt Kopien zu bearbeiten |
| Elemente in verschiedenen Sprachen | jedes Feld bearbeitet eine Sprache; prüfen Sie die Sprache |
| Viele Benachrichtigungen an Abonnenten | jedes veröffentlichte Element kann Abonnenten benachrichtigen; verwenden Sie gegebenenfalls je Element **Ohne Benachrichtigung veröffentlichen**, wo es aktiviert ist |
| Nach **Entwürfe speichern** Entwürfe zurücklassen | sie warten unter **Meine Entwürfe** ([Einen verlorenen Entwurf wiederfinden](einen-verlorenen-entwurf-wiederfinden.md)) |

# Eine Veranstaltung absagen oder verschieben

Diese Seite ist für Redakteure, die eine bereits veröffentlichte Veranstaltung absagen oder verschieben müssen.
Behalten Sie die Seite: Die Menschen haben den Link. Machen Sie die Änderung deutlich und informieren Sie dann die
Angemeldeten. Hintergrund: [Absagen und Änderungen](../../aufbauen/veranstaltungen/absagen-und-aenderungen.md).

## Bevor Sie beginnen

- Die Absage oder das neue Datum ist vom Veranstalter bestätigt.
- Sie wissen, ob sich Menschen angemeldet haben (ein Anmeldeformular listet sie unter **Setup > Gesammelte
  Informationen**).

## Schritte zum Absagen

1. Öffnen Sie die Veranstaltung, **Bearbeiten**.
2. **Short title**: Beginnen Sie ihn mit „Abgesagt:“, damit Kalender und Listen es zeigen.
3. Am Anfang von **Text**: „Abgesagt am <Datum>. <Grund, falls angebracht.> <Was die Menschen stattdessen tun können.>“
4. Wenn Ihre Klasse einen Buchungsstatus hat, setzen Sie ihn auf *abgesagt*.
5. **Zur Veröffentlichung schicken** (nicht **Ohne Benachrichtigung veröffentlichen**: Wer der Veranstaltung folgt,
   soll es erfahren).

## Schritte zum Verschieben

1. **Bearbeiten** Sie die Veranstaltung.
2. Neues Datum bekannt: Ändern Sie **From Time** und **To Time**; fügen Sie am Anfang „Verschoben vom <altes Datum> auf
   den <neues Datum>.“ hinzu.
3. Neues Datum nicht bekannt: Behalten Sie die Daten; beginnen Sie den Kurztitel mit „Verschoben:“; schreiben Sie, dass
   ein neues Datum folgt.
4. **Zur Veröffentlichung schicken**.

## Das Ergebnis prüfen

- [ ] Abgemeldet zeigt der Kalender „Abgesagt:“ oder das neue Datum am richtigen Tag.
- [ ] Die Seite der Veranstaltung beginnt mit der Änderung.
- [ ] Die Angemeldeten sind informiert: Exportieren Sie ihre Kontaktdaten aus **Setup > Gesammelte Informationen** und
  schreiben Sie ihnen aus Ihrem normalen Mailprogramm ([Formularantworten als CSV exportieren](formularantworten-als-csv-exportieren.md)).
- [ ] **Versionen verwalten** behält den früheren Wortlaut.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Die Veranstaltung sofort entfernen | wer sie sucht, findet nichts; verstecken Sie sie nach dem ursprünglichen Datum |
| Nur den Text ändern, nicht die Daten | der Kalender zeigt noch den alten Tag |
| Listen auf der Startseite zeigen noch den alten Titel | sie erneuern sich, wenn ihr Cache abläuft; fragen Sie das Web-Team, wenn es dringend ist ([Eine Seite aktualisieren, die alte Inhalte zeigt](eine-seite-aktualisieren-die-alte-inhalte-zeigt.md)) |
| Anmeldedaten aufbewahren, nachdem die Menschen informiert sind | entfernen Sie sie ([Nicht mehr benötigte Formularantworten entfernen](nicht-mehr-benoetigte-formularantworten-entfernen.md)) |

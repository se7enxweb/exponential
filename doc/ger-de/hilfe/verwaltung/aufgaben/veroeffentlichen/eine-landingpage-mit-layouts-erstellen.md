# Eine Landingpage mit Layouts erstellen

Diese Seite ist für Redakteure, die mit **Exponential Layouts** eine Landingpage für eine Kampagne, ein Thema oder ein
Programm bauen. Ein Layout bestimmt, woraus eine Seite besteht; die Inhaltselemente enthalten weiterhin Text und
Bilder. Der Reiter **Layouts** wird nur Rollen angezeigt, die mit Layouts arbeiten dürfen
([Der Layout-Editor](../../../layout-editor.md)).

## Bevor Sie beginnen

- Sie sehen den Reiter **Layouts**; wenn nicht, fragen Sie einen Administrator.
- Die Seite, für die das Layout gedacht ist, existiert (zum Beispiel ein Ordner „Kampagne saubere Luft“).
- Texte und Bilder sind fertig, die Bilder mit Alternativtext.
- Zuordnungen bestimmen, welche Seiten ein Layout verwenden; wenn Sie sie nicht ändern dürfen, fügt ein Site-Ersteller
  die Zuordnung hinzu.

## Schritte

1. **Layouts** öffnet das **Layouts Dashboard**. Klicken Sie auf **New layout**.
2. Wählen Sie einen **Layout type** (zum Beispiel *1 column* oder *Hero + 3 columns*), geben Sie einen **Name** an
   („Kampagne saubere Luft“) und klicken Sie auf **Create layout**. Der Editor öffnet sich mit den leeren Zonen.
3. Klicken Sie auf **Add a block** (die Plus-Schaltfläche) und ziehen Sie Blöcke in die Zonen: einen **Title**, einen
   **Text** oder **Rich text**, ein **Image**, einen Block **Listing**, der die neuesten Elemente eines Ordners zeigt,
   einen **Button / Link** zur wichtigsten Aktion.
4. Wählen Sie jeden Block aus; füllen Sie seinen Reiter **Content** aus (Texte, welche Elemente eine Liste zeigt, wie
   viele) und seinen Reiter **Design** (Ansichtstyp, Stil).
5. **Publish layout** (oder **Save draft and close**, um später weiterzumachen).
6. Zuordnung: Auf dem Dashboard **Rules**, **New mapping**: das Layout, das Ziel (der Ort der Seite), aktiviert. Oder
   fragen Sie den Site-Ersteller.
7. Wenn der Editor fragt, ob die Caches geleert werden sollen, wählen Sie **Clear caches**.

## Das Ergebnis prüfen

- [ ] Abgemeldet zeigt die Seite das Layout.
- [ ] Die Überschriften kommen in der richtigen Reihenfolge (eine Hauptüberschrift, dann Unterüberschriften); die
  Seite funktioniert mit der Tastatur.
- [ ] In der Breite eines Telefons stapeln sich die Blöcke in einer sinnvollen Reihenfolge.
- [ ] Listen zeigen die erwarteten Elemente.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Text nur in Blöcken eingetippt, nicht in Inhaltselementen | die Suche findet Blocktext womöglich nicht so wie Inhalte; behalten Sie wichtige Texte auch im eigenen Inhalt der Seite |
| Eine Zuordnung, die auf mehr Seiten passt als beabsichtigt | Ziele und Bedingungen entscheiden; die erste aktivierte Zuordnung nach Priorität gewinnt |
| Viele große Bilder | langsame Seiten; verwenden Sie wenige, gut ausgewählte |
| Versehentlich ein gemeinsames Layout (Kopf- oder Fußbereich) bearbeiten | es ändert jede Seite, die damit verknüpft ist |

# Eine Dienstleistungsseite veröffentlichen

Diese Seite ist für Redakteure, die Dienstleistungsseiten schreiben: wie man einen Parkausweis erhält, eine Geburt
anmeldet, einen Zuschuss beantragt. Sie verwendet eine Klasse Service, wie sie in
[Dienstleistungen modellieren](../../aufbauen/leistungskatalog/leistungen-modellieren.md) gebaut wird; wenn Ihre Site für
Dienstleistungen Artikel verwendet, folgen Sie derselben Reihenfolge mit Überschriften im Text.

## Inhalt

1. [Bevor Sie beginnen](#bevor-sie-beginnen)
2. [Schritte](#schritte)
3. [Das Ergebnis prüfen](#das-ergebnis-prüfen)
4. [Fallstricke](#fallstricke)

## Bevor Sie beginnen

- Die für die Dienstleistung verantwortliche Stelle hat die Fakten bestätigt: wer sie nutzen kann, Kosten, nötige
  Unterlagen, Bearbeitungszeit.
- Sie haben die Adresse des Online-Antrags, falls es einen gibt, und die Kontaktstelle, die Fragen beantwortet.
- Sie kennen die Schlagwörter für Thema und Lebenslage, zu denen sie gehört.

## Schritte

1. Öffnen Sie den Ordner des Leistungsbereichs (zum Beispiel **Waste and recycling**), **Neu erstellen**, wählen Sie
   **Service**.
2. **Service name**: Beginnen Sie mit der Sache, in den Worten der Bürger: „Abholung von Gartenabfällen“.
3. **In short**: zwei oder drei Sätze: was es ist und für wen ([Eine Zusammenfassung in einfacher Sprache schreiben](eine-zusammenfassung-in-einfacher-sprache-schreiben.md)).
4. **Who can use it**, **What you need**, **What it costs**: kurze Listen.
5. **How to apply**: nummerierte Schritte.
6. **Apply online**: die Adresse des Antragssystems ([Einen Link zu einem externen Dienst hinzufügen](einen-link-zu-einem-externen-dienst-hinzufuegen.md)).
7. **How long it takes**, **What happens next**.
8. **Contact**: **Vorhandenes hinzufügen**, wählen Sie die Kontaktstelle (keine Person).
9. **Related documents**, **Topics and life events**, **Next review** (ein Datum in der Zukunft).
10. **Vorschau**, dann **Zur Veröffentlichung schicken**.

## Das Ergebnis prüfen

- [ ] Lesen Sie sie wie ein Bürger, der nichts über Ihre Organisation weiß: Können Sie erkennen, ob die Leistung für
  Sie gedacht ist und was zu tun ist?
- [ ] Der Online-Link öffnet den richtigen Antrag.
- [ ] Die Dienstleistung erscheint auf ihrer Themenseite und in der Liste von A bis Z (nachdem deren Cache sich erneuert
  hat).
- [ ] Die Suche der Site findet sie mit dem Wort, das Bürger eintippen würden.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Den Namen der Abteilung für die Dienstleistung schreiben | verwenden Sie die Worte der Bürger |
| Gebühren in viele Seiten kopieren | Gebühren an einer Stelle, verknüpft ([Öffnungszeiten oder Kontaktdaten aktualisieren](oeffnungszeiten-oder-kontaktdaten-aktualisieren.md) zeigt dieselbe Idee für Kontakte) |
| Kein Prüfdatum | veraltete Seiten; das Feld ist aus gutem Grund ein Pflichtfeld |
| Alle Informationen in einem PDF-Formular | die Seite erklärt; das Formular ist ein Anhang |

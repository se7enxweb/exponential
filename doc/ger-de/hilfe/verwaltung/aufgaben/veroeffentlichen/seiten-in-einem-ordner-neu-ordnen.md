# Seiten in einem Ordner neu ordnen

Diese Seite ist für Redakteure, die Seiten in einer bestimmten Reihenfolge haben möchten: die meistgenutzte
Dienstleistung zuerst im Menü, Schritte nacheinander, Nachrichten die neuesten zuerst. Die Reihenfolge der
Unterelemente eines Ordners wird am Ordner festgelegt; Prioritäten bestimmen eine manuelle Reihenfolge
([Inhalte erstellen und bearbeiten](../../../inhalte-bearbeiten.md#viele-objekte-auf-einmal),
[Tastenkürzel](../../../tastenkuerzel.md#listen-von-unterelementen)).

## Bevor Sie beginnen

- Sie dürfen den Ordner bearbeiten (das Festlegen der Sortierung braucht Bearbeitungsrechte daran).
- Entscheiden Sie: eine automatische Reihenfolge (nach Name, nach Veröffentlichungsdatum) oder eine manuelle (nach
  Priorität).

## Schritte

**Die Sortierung wählen:**

1. Öffnen Sie den Ordner, Reiter **Anordnung**.
2. **Sortieren nach**: *Priorität* für eine manuelle Reihenfolge, *Veröffentlicht* für Nachrichten, *Name* für eine
   alphabetische Liste.
3. **Sortierreihenfolge**: *Aufsteigend* oder *Absteigend*; klicken Sie auf **Setzen**.

**Eine manuelle Reihenfolge festlegen (Sortieren nach Priorität):**

1. Tragen Sie in der Liste **Unterelemente** des Ordners Zahlen in die Spalte **Priorität** ein (10, 20, 30 lassen
   Platz, um später etwas einzufügen).
2. Klicken Sie auf **Prioritäten aktualisieren**.
3. Oder ziehen Sie eine Zeile am Griff an ihrem Anfang; zur Bedienung mit der Tastatur siehe
   [Tastenkürzel](../../../tastenkuerzel.md#listen-von-unterelementen).

## Das Ergebnis prüfen

- [ ] Die Liste **Unterelemente** zeigt die neue Reihenfolge.
- [ ] Abgemeldet zeigt das Menü oder die Seite des Ordners dieselbe Reihenfolge (nachdem sich der Cache erneuert hat).

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Prioritäten eingetippt, aber **Sortieren nach** steht nicht auf Priorität | die Zahlen haben keine Wirkung; stellen Sie zuerst Sortieren nach ein |
| Prioritäten 1, 2, 3 | späteres Einfügen bedeutet Umnummerieren; verwenden Sie Zehnerschritte |
| Neue Elemente erscheinen an einer unerwarteten Stelle | geben Sie jedem neuen Element gleich nach dem Anlegen eine Priorität |
| Menüs im Design sortieren anders | manche Templates sortieren nach eigener Regel; fragen Sie das Web-Team |

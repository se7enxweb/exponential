# Die Tagesordnung einer Ratssitzung veröffentlichen

Diese Seite ist für Redakteure im Sitzungsdienst oder in einem Ratsbüro, die Tagesordnungen von Sitzungen
veröffentlichen. Sie setzt voraus, dass die Site eine Klasse Meeting hat (wie in
[Inhaltsmodell für Kommunen](../../../../../eng-us/help/government/levels/municipal-and-local/content-model.md) vorgeschlagen) oder je Sitzung einen
Ordner verwendet; die Schritte nutzen die Bearbeitungsfunktionen, die in
[Inhalte erstellen und bearbeiten](../../../inhalte-bearbeiten.md) beschrieben sind.

## Inhalt

1. [Bevor Sie beginnen](#bevor-sie-beginnen)
2. [Schritte](#schritte)
3. [Das Ergebnis prüfen](#das-ergebnis-prüfen)
4. [Fallstricke](#fallstricke)

## Bevor Sie beginnen

- Die Sitzung existiert unter **Council and democracy > Meetings > <Jahr>** (mit dem Sitzungskalender des Jahres
  angelegt), oder Sie wissen, wo Sie sie anlegen.
- Sie können dort bearbeiten (eine Rolle mit `content/edit` für die Sektion des Rats).
- Der Text der Tagesordnung und die Unterlagen (PDF-Dateien mit lesbaren Dateinamen) sind endgültig und zur
  Veröffentlichung freigegeben.
- Sie kennen die Veröffentlichungsfrist, die Ihre Regeln setzen.

## Schritte

1. Öffnen Sie die Sitzung im Inhaltsbaum und klicken Sie auf **Bearbeiten**. Gibt es mehrere Sprachen, wählen Sie
   zuerst die Sprache.
2. Schreiben Sie unter **Agenda** die Punkte als nummerierte Liste. Geben Sie für jeden Punkt seinen Titel an und, wo
   es eine Unterlage gibt, deren Namen, wie er in der Liste der Unterlagen erscheinen wird.
3. Klicken Sie unter **Papers** für jede Unterlage auf **Neu hochladen** (jeder Upload wird zu einem Datei-Objekt und
   wird verknüpft) oder auf **Vorhandenes hinzufügen**, wenn die Unterlagen schon in die Medienbibliothek hochgeladen
   wurden.
4. Geben Sie jeder Unterlage einen klaren Titel („TOP 4: Haushaltsbericht“), wenn der Upload den Dateinamen verwendet
   hat.
5. Setzen Sie **Status** auf *agenda published*, wenn Ihre Klasse Meeting dieses Feld hat.
6. Klicken Sie auf **Vorschau**, um die Seite so zu sehen, wie Besucher sie sehen werden, dann auf
   **Zur Veröffentlichung schicken**.

Wenn die Site Sitzungsseiten zur Freigabe zurückhält, wird die Version ausstehend; siehe
[Eine Seite zur Freigabe schicken](eine-seite-zur-freigabe-schicken.md).

## Das Ergebnis prüfen

- [ ] Melden Sie sich ab (oder verwenden Sie ein privates Fenster) und öffnen Sie die Seite der Sitzung: Die
  Tagesordnung und jeder Link zu einer Unterlage sind da.
- [ ] Öffnen Sie zwei oder drei Unterlagen: Sie werden heruntergeladen (ein Zugriffsfehler bedeutet, dass die Dateien
  in einer Sektion liegen, die Besucher nicht lesen dürfen).
- [ ] Die Sitzung erscheint in der Liste der Sitzungen mit dem richtigen Datum.
- [ ] Wer dem Ordner der Sitzungen folgt, erhält beim nächsten Lauf eine Benachrichtigung
  ([Änderungen mit Benachrichtigungen verfolgen](aenderungen-mit-benachrichtigungen-verfolgen.md)).

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Unterlagen mit dem Namen `scan0034.pdf` | benennen Sie sie vor dem Upload um; der Name erscheint in der Download-Adresse |
| Personenbezogene Daten in Unterlagen, die davon ausgenommen sein sollten | klären Sie das vor dem Upload mit dem Ratsbüro; späteres Entfernen lässt Kopien in den Versionen zurück |
| Ein nicht barrierefreies, gescanntes PDF | bitten Sie den Verfasser um eine barrierefreie Fassung; fassen Sie den Punkt auf der Seite zusammen ([Einen PDF-Bericht mit barrierefreier Zusammenfassung hochladen](einen-pdf-bericht-mit-barrierefreier-zusammenfassung-hochladen.md)) |
| In der falschen Sprache veröffentlichen | wählen Sie die Sprache vor **Bearbeiten** |
| Späte Änderungen an der Tagesordnung | bearbeiten Sie sie und fügen Sie oben „Aktualisiert am <Datum>: <Änderung>“ hinzu; siehe [Eine veröffentlichte Bekanntmachung korrigieren und den Verlauf behalten](eine-veroeffentlichte-bekanntmachung-korrigieren-und-den-verlauf-behalten.md) |

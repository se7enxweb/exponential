# Ein Dokument durch eine neue Version ersetzen

Diese Seite ist für Redakteure, die ein veröffentlichtes Dokument aktualisieren müssen: ein korrigiertes Formular, eine
überarbeitete Richtlinie, einen Bericht mit einer berichtigten Tabelle. Wenn Sie das Datei-Objekt bearbeiten und eine
neue Datei wählen, behält es seine Adresse, sodass jede Seite, die es verknüpft, und jeder externe Link weiter
funktionieren ([Versionen von Dokumenten](../../aufbauen/dokumente-und-publikationen/versionen-von-dokumenten.md)).

## Inhalt

1. [Bevor Sie beginnen](#bevor-sie-beginnen)
2. [Schritte](#schritte)

## Bevor Sie beginnen

- Entscheiden Sie: eine Korrektur oder Aktualisierung desselben Dokuments (an Ort und Stelle ersetzen) oder eine neue
  Ausgabe, die neben der alten bestehen soll (ein neues Objekt veröffentlichen). Der Jahresbericht 2026 ist ein neues
  Objekt; ein korrigiertes Formular ist ein Ersatz.
- Die neue Datei hat denselben Zweck und idealerweise einen ähnlichen Dateinamen.

## Schritte

1. Finden Sie das Dokument: Suchen Sie danach oder öffnen Sie die Seite, die es auflistet, und folgen Sie der Relation
   zum Datei-Objekt.
2. Öffnen Sie das Datei-Objekt und klicken Sie auf **Bearbeiten**.
3. Wählen Sie im Feld **File** die neue Datei von Ihrem Computer.
4. Ergänzen Sie **Description** um einen Hinweis: „Aktualisiert am <Datum>: <was sich geändert hat>.“
5. **Zur Veröffentlichung schicken**.
6. Wenn das Dokument eine Seite mit Zusammenfassung hat (eine Publication), aktualisieren Sie auch die Zusammenfassung
   und fügen Sie denselben Hinweis hinzu.

## Das Ergebnis prüfen

- [ ] Laden Sie das Dokument abgemeldet von der Seite herunter, die es auflistet: Sie erhalten die neue Datei (prüfen
  Sie Datum oder Inhalt).
- [ ] **Versionen verwalten** am Datei-Objekt listet die vorherige Version, archiviert, mit der alten Datei.
- [ ] Seiten, die das Dokument verknüpfen, brauchen keine Änderung.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Die neue Datei als neues Objekt hochladen und das alte stehen lassen | Links zeigen weiter auf die alte Datei; bearbeiten Sie das bestehende Objekt |
| Ist die alte Datei noch herunterladbar? | archivierte Versionen sind nicht öffentlich: Das Herunterladen einer anderen als der veröffentlichten Version braucht `content/versionread` |
| Die vorherige Datei muss vernichtet werden (personenbezogene Daten, rechtliche Gründe) | entfernen Sie nach dem Ersetzen die archivierten Versionen ([Versionen von Dokumenten](../../aufbauen/dokumente-und-publikationen/versionen-von-dokumenten.md#eine-datei-entfernen-die-nicht-bleiben-darf)) |
| Ein gespeicherter PDF-Export enthält den alten Inhalt | erzeugen Sie ihn neu ([Ein Handbuch als PDF-Export veröffentlichen](ein-handbuch-als-pdf-export-veroeffentlichen.md)) |
| Browser oder Cache zeigen die alte Datei | laden Sie neu; fragen Sie das Web-Team nach Caches vor der Site |

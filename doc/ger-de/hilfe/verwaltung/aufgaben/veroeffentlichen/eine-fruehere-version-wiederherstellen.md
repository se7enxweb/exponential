# Eine frühere Version wiederherstellen

Diese Seite ist für Redakteure, die einen früheren Wortlaut zurückbrauchen: Eine Änderung war falsch, ein Entwurf ging
versehentlich hinaus, ein Abschnitt wurde gelöscht, der hätte bleiben sollen. Exponential überschreibt nicht: Sie legen
aus der alten Version einen neuen Entwurf an und veröffentlichen ihn, sodass der Verlauf alles behält
([Versionen eines Objekts, 3](../../../../anleitungen/inhaltsverlauf.md#3-ein-neuer-entwurf-aus-einer-alten-version)).

## Bevor Sie beginnen

- Sie dürfen das Objekt bearbeiten und die alte Version lesen.
- Finden Sie heraus, zu welcher Version Sie zurückkehren: Verwenden Sie im Zweifel **Vergleichen**
  ([Zwei Versionen vergleichen](zwei-versionen-vergleichen.md)).

## Schritte

1. Öffnen Sie die Seite, **Versionen verwalten**.
2. Filtern Sie nach dem Status *Archiviert* (oder nach Übersetzung) und finden Sie die Version.
3. Wählen Sie auf ihrer Karte die Übersetzung, mit der der neue Entwurf beginnt, und klicken Sie auf
   **Neuen Entwurf machen**.
4. Mit markiertem **Stay on this page** (die Voreinstellung) sagt die Seite, welcher Entwurf angelegt wurde; bearbeiten
   Sie ihn von seiner Karte aus. Wählen Sie es ab, um den neuen Entwurf sofort im Editor zu öffnen.
5. Prüfen Sie den Entwurf: Manche Fakten haben sich seither vielleicht geändert (Daten, Kontakte); aktualisieren Sie
   sie.
6. **Zur Veröffentlichung schicken**.

## Das Ergebnis prüfen

- [ ] Abgemeldet zeigt die Seite den wiederhergestellten Wortlaut.
- [ ] Die Versionsseite listet jetzt Ihre neue Version als *Veröffentlicht* und die ersetzte als *Archiviert*.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Mit dem alten Text veraltete Fakten wiederherstellen | lesen Sie den Entwurf vor dem Veröffentlichen |
| **Neuen Entwurf machen** fehlt auf einer Karte | Sie dürfen diese Version nicht lesen, ihre Übersetzungen nicht bearbeiten, oder es ist ein unberührter Entwurf; die Karte sagt, was zutrifft |
| Die alte Version ist weg | sie wurde am Limit der Versionsgeschichte entfernt; stellen Sie sie aus Ihren Unterlagen wieder her oder tippen Sie sie neu |
| Eine Seite wurde entfernt, nicht geändert | verwenden Sie den Papierkorb ([Eine veraltete Seite entfernen und wiederherstellen](eine-veraltete-seite-entfernen-und-wiederherstellen.md)) |

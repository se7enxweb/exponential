# Inhalte mit eztags verschlagworten

Diese Seite ist für Redakteure, die Seiten mit Themen verschlagworten, damit Besucher verwandte Inhalte finden. Die
Erweiterung `eztags` fügt ein Feld für Schlagwörter mit Autovervollständigung und einen Schlagwortbaum hinzu, der in der
Administration unter **Tags** verwaltet wird
([Verschlagworten mit eztags](../../../../../eng-us/help/creators/website-creators/tagging-with-eztags.md)).

## Inhalt

1. [Bevor Sie beginnen](#bevor-sie-beginnen)
2. [Schritte](#schritte)
3. [Das Ergebnis prüfen](#das-ergebnis-prüfen)
4. [Fallstricke](#fallstricke)

## Bevor Sie beginnen

- Die Klasse der Seite hat ein Feld für Schlagwörter (zum Beispiel **Topics**). Ältere Klassen verwenden vielleicht
  **Keywords** (`ezkeyword`), freien Text ohne Baum.
- Kennen Sie die Regeln Ihrer Site für Schlagwörter: welche es gibt, ob Redakteure neue hinzufügen dürfen.

## Schritte

1. Öffnen Sie die Seite, **Bearbeiten**.
2. Beginnen Sie im Feld für Schlagwörter, ein Thema zu tippen: Vorschläge aus dem Schlagwortbaum erscheinen. Wählen Sie
   einen mit der Maus oder der Tastatur.
3. Je nachdem, wie das Feld eingerichtet ist, sehen Sie statt eines Textfelds eine Auswahlliste oder einen Baum
   (Bearbeitungsansichten Default, Select oder Tree); wählen Sie die Schlagwörter dort.
4. Fügen Sie die zwei bis fünf Schlagwörter hinzu, die die Seite wirklich beschreiben; nicht jedes Wort, das sie
   erwähnt.
5. Ein Schlagwort fehlt: Wenn Ihre Rolle Schlagwörter hinzufügen darf, bietet das Feld es an; sonst fragen Sie die
   Verantwortlichen für das Vokabular.
6. **Zur Veröffentlichung schicken**.

## Das Ergebnis prüfen

- [ ] Die Seite zeigt ihre Schlagwörter als Links (wo das Template sie anzeigt).
- [ ] Ein Schlagwort-Link öffnet die Schlagwortseite (`/tags/view/...`), die Ihre Seite listet.
- [ ] In der Administration zeigt **Tags** (`/tags/dashboard`) das Schlagwort mit seinen Inhalten.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Fast-Duplikate anlegen („Recycling“, „recycling“, „Re-cycling“) | wählen Sie den Vorschlag; bitten Sie stattdessen um Synonyme |
| Zu viele Schlagwörter | Schlagwortseiten werden zu Rauschen |
| Schlagwörter nur in einer Sprache | Schlagwörter haben Übersetzungen; die Verantwortlichen für das Vokabular übersetzen sie |
| Schlagwörter statt des Baums für den Platz der Seite verwenden | der Baum bestimmt das Menü; Schlagwörter fügen Themen hinzu |

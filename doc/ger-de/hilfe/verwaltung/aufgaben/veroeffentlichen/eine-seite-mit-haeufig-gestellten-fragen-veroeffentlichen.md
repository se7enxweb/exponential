# Eine Seite mit häufig gestellten Fragen veröffentlichen

Diese Seite ist für Redakteure, die eine Seite mit Fragen und Antworten veröffentlichen, zum Beispiel während der
Umstellung einer Dienstleistung oder eines Beteiligungsverfahrens. Eine gute FAQ beantwortet die Fragen, die die
Menschen tatsächlich stellen, kurz, und schickt sie zur ausführlichen Seite; eine schlechte wird zu einer zweiten,
veralteten Kopie der Site.

## Inhalt

1. [Bevor Sie beginnen](#bevor-sie-beginnen)
2. [Schritte](#schritte)
3. [Das Ergebnis prüfen](#das-ergebnis-prüfen)
4. [Fallstricke](#fallstricke)

## Bevor Sie beginnen

- Sammeln Sie echte Fragen: vom Bürgertelefon oder dem Empfang, aus **Setup > Suchstatistiken** (Begriffe, nach denen
  gesucht wird, wenn die Protokollierung eingeschaltet ist), aus Formularnachrichten.
- Fragen Sie sich, ob eine Frage besser beantwortet wird, indem die Dienstleistungsseite selbst verbessert wird; oft
  ist das so.
- Kennen Sie die verantwortliche Person, die die Antworten bestätigt.

## Schritte

1. Legen Sie die Seite dort an, wo das Thema zu Hause ist: **Neu erstellen**, **Article** (oder ein Ordner mit einer
   Beschreibung).
2. Einleitung: ein Satz dazu, was die Seite abdeckt und wann sie zuletzt geprüft wurde.
3. Im Text jede Frage als Überschrift (verwenden Sie das Überschriftenformat des Editors, keinen fetten Text), in den
   Worten, die die Menschen verwenden.
4. Unter jeder Überschrift eine kurze Antwort (zwei oder drei Sätze) und ein Link zur ausführlichen Seite.
5. Ordnen Sie die Fragen danach, wie oft sie gestellt werden, oder gruppieren Sie sie unter Zwischenüberschriften.
6. Hat Ihre Site einen Akkordeon-Block oder eine Akkordeon-Klasse (zum Beispiel die Klasse `ng_accordion_item` der
   Demo-Klassen des Standardpakets oder einen Layout-Block), verwenden Sie ihn nur, wenn er mit Tastatur und
   Screenreader funktioniert; einfache Überschriften funktionieren immer.
7. **Zur Veröffentlichung schicken**.

## Das Ergebnis prüfen

- [ ] Die Überschriften bilden eine Liste, durch die ein Screenreader springen kann.
- [ ] Jede Antwort verlinkt auf eine Seite mit den vollständigen Informationen.
- [ ] Die Suche findet die FAQ über die Wörter ihrer Fragen.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Erfundene Fragen („Warum ist unser Service so gut?“) | nur echte Fragen |
| Lange Antworten, die Dienstleistungsseiten doppeln | verlinken Sie stattdessen; ein Ort für jede Tatsache |
| Keine Prüfung | fügen Sie ein Prüfdatum hinzu und prüfen Sie nach jeder Änderung der Dienstleistung |
| Fragen als fetter Text | verwenden Sie echte Überschriften |

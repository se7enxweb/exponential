# Eine Ausschreibung veröffentlichen

Diese Seite ist für Redakteure in Beschaffung oder Kommunikation, die Ausschreibungen auf der Website ankündigen. In
vielen Rechtsordnungen erfolgt die gesetzlich vorgeschriebene Veröffentlichung auf einer offiziellen Vergabeplattform
oder in einem Amtsblatt; die Website kündigt die Gelegenheit an und verweist dorthin. Exponential hat kein Modul für
Beschaffung oder elektronische Vergabe.

> **Hinweis** Diese Seite beschreibt Funktionen und gängige Praxis; sie ist keine Rechtsberatung. Prüfen Sie das für
> Ihre Organisation geltende Recht mit Ihrer Rechtsberatung.

## Bevor Sie beginnen

- Die Vergabestelle bestätigt, dass die Bekanntmachung auf der offiziellen Plattform veröffentlicht ist (oder wird),
  und nennt Ihnen deren Adresse und das Aktenzeichen.
- Sie haben die Kurzbeschreibung, die Frist für Angebote und die Frist für Fragen.
- Sie wissen, ob Dokumente auch auf der Website veröffentlicht werden oder nur auf der Plattform.

## Schritte

1. Öffnen Sie **Business > Tenders** (oder Ihren Ordner für Beschaffung), **Neu erstellen**, wählen Sie die Klasse für
   Bekanntmachungen, die Ihre Site verwendet (eine öffentliche Bekanntmachung oder einen Artikel).
2. **Title**: „Ausschreibung: <Gegenstand>“.
3. Text: was beschafft wird, das Aktenzeichen, wer Angebote abgeben darf, die Fristen (mit Uhrzeit und Zeitzone) und
   der Link zur offiziellen Bekanntmachung auf der Vergabeplattform als dem Ort für die Angebotsabgabe.
4. **Documents**: nur, wenn sie auch auf der Website veröffentlicht werden; sonst verlinken Sie auf die Plattform.
5. **Hide after** (wenn die Klasse es hat): die Angebotsfrist, damit die Bekanntmachung die Liste automatisch verlässt
   ([Eine öffentliche Bekanntmachung mit Ablaufdatum veröffentlichen](eine-oeffentliche-bekanntmachung-mit-ablaufdatum-veroeffentlichen.md)).
6. **Zur Veröffentlichung schicken**.

## Das Ergebnis prüfen

- [ ] Abgemeldet steht die Bekanntmachung in der Liste der Ausschreibungen; der Link zur Plattform öffnet die
  offizielle Bekanntmachung.
- [ ] Die Fristen auf der Website stimmen genau mit der offiziellen Bekanntmachung überein.

## Während und nach dem Verfahren

| Ereignis | Tun |
|---|---|
| Bieterfragen oder geänderte Fristen | folgen Sie der Plattform; aktualisieren Sie die Bekanntmachung auf der Website mit einem datierten Hinweis ([Eine veröffentlichte Bekanntmachung korrigieren und den Verlauf behalten](eine-veroeffentlichte-bekanntmachung-korrigieren-und-den-verlauf-behalten.md)) |
| Frist abgelaufen | die Bekanntmachung wird versteckt (automatisch oder von Hand) |
| Auftrag vergeben | veröffentlichen Sie die Angaben zur Vergabe, wie Ihre Regeln es verlangen, als neues Element oder als Aktualisierung |

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Unterschiedliche Fristen auf Website und Plattform | übernehmen Sie sie aus der offiziellen Bekanntmachung; verweisen Sie auf diese als Referenz |
| Angebote per E-Mail über die Website annehmen | Angebote laufen über den Kanal des Verfahrens |
| Dokumente nur auf der Website veröffentlichen | gleicher Zugang: Die offizielle Plattform ist der Ort, an dem Bieter suchen |

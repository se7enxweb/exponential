# Eine Fotogalerie veröffentlichen

Diese Seite ist für Redakteure, die Fotos einer Veranstaltung, eines Bauprojekts oder eines Ortes veröffentlichen. Das
Standardpaket liefert eine Klasse **Gallery** (`gallery`, ein Container) mit, die Objekte **Bild** enthält
([sevenx_classes](../../../seitenpakete/sevenx-multisite/sevenx-classes-das-paket-der-inhaltsklassen.md)); die Upload-Seite legt viele Bilder auf
einmal darin ab ([Medien und Uploads](../../../medien-und-uploads.md#dateien-hochladen)).

## Bevor Sie beginnen

- Sie haben das Recht, die Fotos zu veröffentlichen, und die Bildnachweise.
- Fotos erkennbarer Personen: eine Einwilligung, wo Ihre Regeln sie verlangen; bei Kindern prüfen Sie Ihre Regeln
  immer.
- Jedes Foto hat eine kurze Beschreibung, die Sie als Alternativtext verwenden können.
- Große Originale sind in Ordnung: Die Site erzeugt die Größen (Bildvarianten) selbst.

## Schritte

1. Öffnen Sie die Stelle für die Galerie, **Neu erstellen**, wählen Sie **Gallery**; geben Sie ihr einen Namen und
   eine kurze Beschreibung; **Zur Veröffentlichung schicken**.
2. Öffnen Sie die neue Galerie und klicken Sie auf **Hochladen**. Die Upload-Seite öffnet sich mit der Galerie als
   **Target location**.
3. **Choose files...** oder ziehen Sie die Fotos auf die gestrichelte Fläche.
4. Für jedes Bild in der Warteschlange: Ändern Sie den **Titel**, wenn der Dateiname nichtssagend ist, und füllen Sie
   den **Alternativtext** aus, wo die Site danach fragt.
5. Klicken Sie auf **Upload all**. Wählen Sie vorher **Keep as drafts**, wenn Sie die Bilder prüfen möchten, bevor sie
   öffentlich sind.
6. Tragen Sie die Bildnachweise in das Feld für Bildunterschrift oder Beschreibung jedes Bildes ein, wo Ihr Template
   sie anzeigt.
7. Ordnen Sie die Bilder: Sortieren Sie die Galerie nach Priorität und setzen Sie Prioritäten
   ([Seiten in einem Ordner neu ordnen](seiten-in-einem-ordner-neu-ordnen.md)).

## Das Ergebnis prüfen

- [ ] Abgemeldet zeigt die Galerie die Bilder in der richtigen Reihenfolge.
- [ ] Jedes Bild hat einen aussagekräftigen Alternativtext (untersuchen Sie eines mit dem Browser oder einem
  Screenreader).
- [ ] Das Öffnen eines Bildes zeigt seinen Bildnachweis.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| ZIP-Upload, wenn Alternativtext verlangt wird | Bilder in einer ZIP-Datei werden übersprungen, wo Alternativtext verlangt wird; laden Sie sie einzeln hoch |
| Alternativtext „IMG_1234“ | beschreiben Sie das Foto |
| Standortdaten in Fotodateien | manche Kameras speichern GPS-Positionen in den Dateien; entfernen Sie sie vor dem Upload, wenn sie private Orte verraten |
| Eine Galerie als einziger Bericht über eine Veranstaltung | schreiben Sie auch einen kurzen Text |

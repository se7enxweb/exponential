# Ein Element an mehreren Stellen veröffentlichen

Diese Seite ist für Redakteure, deren Seite an zwei Stellen gehört: eine Dienstleistung unter „Wohnen“ und unter
„Umzug“, eine Seite mit Hinweisen unter zwei Zielgruppen. In Exponential kann ein Objekt mehrere **Orte** haben; es
ist dieselbe Seite, also erscheint eine Änderung überall
([Relationen und Wiederverwendung](../../../../../eng-us/help/creators/website-creators/relations-and-reuse.md)).

## Inhalt

1. [Bevor Sie beginnen](#bevor-sie-beginnen)
2. [Schritte](#schritte)
3. [Das Ergebnis prüfen](#das-ergebnis-prüfen)
4. [Fallstricke](#fallstricke)

## Bevor Sie beginnen

- Sie dürfen an der zweiten Stelle Inhalte anlegen (das Hinzufügen eines Orts braucht die Rechte, dort Inhalte
  abzulegen).
- Entscheiden Sie, welche Stelle der **Hauptort** ist: Seine Adresse ist die Hauptadresse und seine Sektion die
  Sektion des Objekts.

## Schritte

1. Öffnen Sie die Seite, Reiter **Orte**.
2. Klicken Sie auf **Orte hinzufügen**; gehen Sie zum zweiten übergeordneten Element, wählen Sie es aus, bestätigen
   Sie.
3. Um zu ändern, welcher Ort der Hauptort ist: Markieren Sie ihn und klicken Sie auf **Als Haupt setzen**.
4. Aus einer Liste: Markieren Sie in einer Liste **Unterelemente** Elemente, **Weitere Aktionen** >
   **Position hinzufügen**.

Sie können Orte auch im Fenster **Orte** des Bearbeitungsformulars verwalten (**Orte hinzufügen**,
**Sichtbarkeit nach Veröffentlichung**); diese Änderungen gelten, wenn Sie veröffentlichen.

## Das Ergebnis prüfen

- [ ] Beide Stellen listen die Seite (Menüs, Ordnerlisten), abgemeldet.
- [ ] Jeder Ort hat seine eigene Adresse; der Hauptort ist der, den Suchmaschinen sehen sollen.
- [ ] Eine Bearbeitung der Seite erscheint an beiden Stellen.

## Fallstricke

| Fallstrick | So vermeiden Sie ihn |
|---|---|
| Stattdessen die Seite kopieren | zwei Kopien laufen auseinander; verwenden Sie einen Ort |
| Die Seite entfernen, um einen Ort zu entfernen | markieren Sie auf dem Reiter **Orte** den Ort und wählen Sie **Ausgewählte entfernen**; die Seite bleibt an ihren anderen Stellen |
| Einen Ort verstecken | **Verstecken** auf dem Reiter **Orte** versteckt nur diese Stelle |
| Unterschiedliche Sektionen an den beiden Stellen | ein Objekt hat eine Sektion, die seines Hauptorts; prüfen Sie die Leserechte an beiden Stellen |

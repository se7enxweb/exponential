# Eine Demo für das Bewertungsgremium vorbereiten

**Wer:** der Projektleiter, mit dem Bewertungsteam. **Wann:** bevor die Angebote geöffnet werden; das Skript wird den
Bietern vorab geschickt. Die für die Presse geschriebenen Demo-Skripte sind eine gute Grundlage: Sie verwenden nur
dokumentierte Fakten und genaue Klicks
([Demo-Skripte für Bewertende](../../../../../eng-us/help/government/procurement/evaluation/demo-scripts-for-evaluators.md)).

## Schritte

1. **Wählen Sie Szenarien aus Ihren Anforderungen**, nicht aus einer Produktbroschüre: eine typische Nachricht, eine
   Dienstleistungsseite in zwei Sprachen, ein Formular, eine Freigabe, die Berechtigungen einer Abteilung.
2. **Schreiben Sie ein Skript** mit nummerierten Schritten und einer Zeit je Schritt; jeder Bieter führt dasselbe
   Skript aus.
3. **Stellen Sie Testinhalte bereit** (erfunden, keine personenbezogenen Daten), damit die Ergebnisse vergleichbar sind.
4. **Fügen Sie einen Schritt zur Barrierefreiheit hinzu**: eine Aufgabe nur mit der Tastatur, in dem Design, das der
   Bieter für die Mitarbeiter vorschlägt.
5. **Fügen Sie einen Schritt zum Betrieb hinzu**: **Setup > Systeminformationen**, das Audit-Protokoll und wie ein
   Update eingespielt wird.
6. **Lassen Sie am Ende freie Zeit** für die eigenen Höhepunkte des Bieters, getrennt oder gar nicht bewertet.
7. **Schicken Sie das Skript** an die Bieter mit Datum, Dauer und Regeln (wer präsentiert, keine Folien während der
   Schritte nach Skript).
8. **Bewerten Sie während der Demo** anhand des Bogens; jede bewertende Person notiert Nachweise je Schritt.

## Gliederung eines Skripts

```text
Demo script - <tender reference>                 <n> minutes, same for every bidder
1. Sign in, dashboard, find a page by search                         <min>
2. Create a news item with an image and alt text, preview at phone width, send for approval   <min>
3. As approver: approve; show the version history and compare        <min>
4. Add a translation; show the page in the second language (and RTL if required)   <min>
5. Build a contact form; submit it; show where the submission is stored   <min>
6. Show a role limited to one department's section                  <min>
7. Keyboard-only: repeat step 2 without the mouse                    <min>
8. Operations: system information, audit trail, how an update is applied   <min>
9. Bidder's free time (not scored | scored under <criterion>)       <min>
```

## Ergebnis

Vergleichbare Vorführungen, nach Nachweisen bewertet, nicht nach Präsentationsgeschick.

## Fallstricke

- Jeden Bieter wählen lassen, was er zeigt.
- Szenarien, die nur das Demopaket kann, nicht Ihre künftige Site.
- Folien anstelle eines Live-Schritts akzeptieren.

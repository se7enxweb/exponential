# Eine frühere Version einer Seite zurückholen

Für Redakteure, wenn ein veröffentlichter Text zu einem früheren Wortlaut zurückkehren muss (eine falsche Änderung, ein
entfernter Absatz). Alte Versionen werden bis zum Limit der Versionsgeschichte aufbewahrt; Sie überschreiben sie nicht,
Sie machen aus einer davon einen neuen Entwurf ([Versionen eines Objekts](../../../../anleitungen/inhaltsverlauf.md)).

## Bevor Sie beginnen

- Rechte, das Objekt zu bearbeiten; um Entwürfe oder ausstehende Versionen anderer zu sehen, brauchen Sie außerdem
  `content/versionread`.
- Halten Sie für die Akten fest, warum der Text wiederhergestellt wird.

## Schritte

1. Öffnen Sie die Versionen der Seite: **Versionen verwalten** im Editor oder im Kontextmenü, oder
   `/content/history/<object id>`.
2. Filtern Sie nach dem Status **Archiviert**; finden Sie die Version anhand ihres Änderungsdatums und ihres Erstellers.
3. **Vergleichen** Sie sie mit der aktuellen Version (braucht `content/diff`), um sicherzugehen, dass es die richtige
   ist.
4. Wählen Sie auf ihrer Karte die Übersetzung, mit der der neue Entwurf beginnt, und **Neuen Entwurf machen**.
5. Bearbeiten Sie den Entwurf bei Bedarf und veröffentlichen Sie ihn dann wie üblich (oder schicken Sie ihn durch Ihren
   Freigabe-Workflow).

## Prüfen, ob es funktioniert hat

- Die Seite zeigt den wiederhergestellten Text.
- Die Versionsseite listet jetzt die neue veröffentlichte Version; die falsche Version bleibt archiviert, sodass der
  Verlauf zeigt, was geschehen ist.
- Wenn das Objekt an seinem Versionslimit war, hat die älteste archivierte Version Platz gemacht; prüfen Sie, dass es
  keine war, die Sie brauchen („Das Limit der Versionsgeschichte“).

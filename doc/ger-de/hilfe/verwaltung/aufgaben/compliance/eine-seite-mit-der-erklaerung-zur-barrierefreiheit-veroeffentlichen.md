# Eine Seite mit der Erklärung zur Barrierefreiheit veröffentlichen

Für Redakteure und Projektleiter, sobald der Text der Erklärung genehmigt ist. Exponential liefert kein Template für die
Erklärung mit ([Standards zur Barrierefreiheit: EN 301 549](../../../../../eng-us/standards/accessibility.md#en-301-549));
schreiben Sie den Text nach der Gliederung in
[Eine Erklärung zur Barrierefreiheit schreiben](../../../../../eng-us/help/government/accessibility/writing-an-accessibility-statement.md) oder nach dem
Muster Ihres Landes.

> **Hinweis** Diese Seite beschreibt Funktionen und gängige Praxis; sie ist keine Rechtsberatung. Prüfen Sie das für
> Ihre Organisation geltende Recht mit Ihrer Rechtsberatung.

## Bevor Sie beginnen

- Der genehmigte Text, mit Datum und Methode der Bewertung, bekannten Einschränkungen und einem Kontakt.
- Rechte, im Informationsbereich der Site Inhalte anzulegen, und für den Link in der Fußzeile jemand, der das
  Pagelayout oder die gemeinsame Fußzeile ändern kann.

## Schritte

1. Legen Sie ein Inhaltsobjekt an (einen Artikel oder eine Seite der Klasse Ihrer Site) mit dem Titel „Erklärung zur
   Barrierefreiheit“, in jedem Sprach-Siteaccess. Verwenden Sie echte Überschriften, einfachen Text, keine Inhalte nur
   als PDF.
2. Geben Sie ihm einen beständigen Alias: Fügen Sie auf dem Reiter **URL-Aliase** des Knotens `accessibility` hinzu
   (oder den in Ihrem Land üblichen Pfad); oder einen globalen Alias unter **Setup > URL-Übersetzer**.
3. Fügen Sie einen Weg für Rückmeldungen hinzu: eine E-Mail-Adresse im Text und, wenn Sie möchten, ein mit dem
   Informationssammler gebautes Formular (die mitgelieferte Klasse Feedback form), dessen Einsendungen den Koordinator
   erreichen ([Ein Kontaktformular bauen](../../../../../eng-us/help/creators/website-creators/building-a-contact-form.md)).
4. Verlinken Sie die Seite aus der Fußzeile jeder Seite (Pagelayout oder gemeinsame Fußzeile) und aus der Sitemap.
5. Veröffentlichen Sie.

## Prüfen, ob es funktioniert hat

- `https://www.example.gov/accessibility` öffnet die Erklärung in jeder Sprache.
- Der Link in der Fußzeile ist auf jedem Seiten-Template mit der Tastatur erreichbar.
- Führen Sie auf der Seite der Erklärung selbst eine Stichprobe durch („Eine Stichprobe zur Barrierefreiheit einer
  Seite durchführen“).

## Sie aktuell halten

- Prüfen Sie sie mindestens jährlich und nach wesentlichen Änderungen; aktualisieren Sie die Datumszeile.
- Frühere Versionen bleiben auf der Versionsseite des Objekts (`/content/history/<object id>`), innerhalb des Limits
  der Versionsgeschichte; heben Sie das Limit für diese Klasse an, wenn Sie jede Version behalten müssen.

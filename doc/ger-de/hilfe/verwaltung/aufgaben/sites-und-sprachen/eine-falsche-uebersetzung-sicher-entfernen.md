# Eine falsche Übersetzung sicher entfernen

Diese Aufgabe richtet sich an leitende Redakteure und Administratoren, für ein Element, das in der falschen Sprache
angelegt wurde (zum Beispiel britisches statt amerikanisches Englisch). Das Entfernen einer Übersetzung löscht alle
ihre Felder in jeder Version; nur eine Sicherung bringt sie zurück. Hintergrund:
[Eine Übersetzung sicher entfernen](../../sprachen/eine-uebersetzung-sicher-entfernen.md).

## Bevor Sie beginnen

- Entscheiden Sie, ob der Text in der falschen Sprache als Schriftgut erhalten bleiben muss (eine amtliche
  Veröffentlichung). Wenn ja, entfernen Sie ihn nicht; sprechen Sie mit Ihrem Verantwortlichen für das Schriftgut.
- Sie dürfen das Element in beiden Sprachen bearbeiten.

## Schritte

1. **In die richtige Sprache übersetzen**: **Bearbeiten**, **Neue Übersetzung** (richtige Sprache), **Übersetzung
   basiert auf** (falsche Sprache), **Zur Veröffentlichung schicken**.
2. **Die Hauptsprache setzen**: Reiter **Übersetzungen**, Spalte **Haupt**, die richtige Sprache, **Als Haupt setzen**.
3. **Die falsche Übersetzung entfernen**: Wählen Sie sie im selben Reiter aus, **Ausgewählte entfernen**, bestätigen
   Sie.

## Prüfen

Das Element hat eine Übersetzung in der richtigen Sprache, die auf der Site dieser Sprache erscheint. Hat die falsche
Sprache nun keine Objekte und keine Klassen mehr, sagt ihre Karte unter **Setup > Sprachen** *Unbenutzt*, und sie kann
dort entfernt werden.

## Probleme

| Problem | Ursache |
|---|---|
| Die falsche Übersetzung lässt sich nicht entfernen | sie ist noch die Hauptsprache; machen Sie zuerst Schritt 2 |
| Viele Elemente zu korrigieren | kein mitgelieferter Befehl verschiebt Übersetzungen in großer Zahl; ein Skript auf einer Kopie der Datenbank ist der Weg |

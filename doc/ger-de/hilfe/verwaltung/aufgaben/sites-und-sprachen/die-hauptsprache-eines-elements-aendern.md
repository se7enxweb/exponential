# Die Hauptsprache eines Elements ändern

Diese Aufgabe richtet sich an Redakteure. Hintergrund: [Die Hauptsprache eines Elements](../../sprachen/hauptsprache-eines-eintrags.md).

## Bevor Sie beginnen

Die neue Hauptsprache muss bereits als Übersetzung des Elements vorhanden sein (übersetzen Sie sonst zuerst).

## Schritte

1. Öffnen Sie das Element; öffnen Sie den Reiter **Übersetzungen**.
2. Wählen Sie in der Spalte **Haupt** die Sprache.
3. Drücken Sie **Als Haupt setzen**.

## Prüfen

Das Sprachkennzeichen des Elements für diese Sprache sagt *main language*, wenn Sie darauf zeigen, und der Reiter
**Übersetzungen** markiert sie.

## Probleme

| Problem | Ursache |
|---|---|
| Die Sprache steht nicht in der Liste | das Element hat noch keine Übersetzung in dieser Sprache |
| Die Schaltfläche bewirkt nichts | Ihre Rolle darf das Element in dieser Sprache vielleicht nicht bearbeiten |

# Eine Seite zwischen zwei Sites teilen

Diese Aufgabe richtet sich an Redakteure in einer Multisite-Installation. Hintergrund:
[Gemeinsame Inhalte über Sites hinweg](../../aufbauen/multisite/gemeinsame-inhalte-ueber-sites-hinweg.md).

## Bevor Sie beginnen

- Sie dürfen in den Ordnern beider Sites Inhalte anlegen.
- Die Sektion der Seite ist für Besucher beider Sites lesbar.

## Schritte

1. Öffnen Sie die Seite und ihren Reiter **Orte**.
2. Drücken Sie **Orte hinzufügen** und wählen Sie im Inhaltsbrowser den Ordner der zweiten Site.
3. Bestätigen Sie die Auswahl.

Der Reiter **Orte** des Elements zeigt nun zwei Orte; einer davon ist der Hauptort.

## Prüfen

Öffnen Sie die Seite abgemeldet auf beiden Sites. Bearbeiten Sie sie einmal; nach dem Veröffentlichen zeigen beide die
Änderung.

## Probleme

| Problem | Lösung |
|---|---|
| Die zweite Site zeigt „nicht gefunden“ | die Seite hat keine Übersetzung in den Sprachen dieser Site und ist nicht immer verfügbar |
| Links auf der Seite zeigen in die falsche Site | siehe „Von einer Abteilungs-Site auf eine andere verlinken“ |
| Sie wollten eine unabhängige Kopie | verwenden Sie stattdessen **Kopieren**; dann ändern sich die beiden Kopien getrennt |

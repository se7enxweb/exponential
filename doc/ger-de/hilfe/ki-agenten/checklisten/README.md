# Checklisten zu KI und Agenten

Dieser Teil richtet sich an alle, die gleich KI-Funktionen einschalten, einen Agenten verbinden oder veröffentlichen, was eine KI
geschrieben hat. Jede Checkliste ist kurz genug zum Ausdrucken, und jeder Punkt verlinkt auf die Seite, die ihn erklärt.

## Inhalt

1. [Die Checklisten](#die-checklisten)
2. [Wie Sie sie verwenden](#wie-sie-sie-verwenden)

## Die Checklisten

| Checkliste | Verwenden Sie sie |
|---|---|
| [Bevor Sie Exponential Intelligence einschalten](bevor-sie-exponential-intelligence-einschalten.md) | Bevor Redakteure den Assistenten auf einer Live-Installation erhalten |
| [Bevor Sie einen Agenten verbinden](bevor-sie-einen-agenten-verbinden.md) | Bevor ein KI-Agent Zugang über die REST-API oder expservices erhält |
| [KI-Entwürfe prüfen](ki-entwuerfe-pruefen.md) | Jedes Mal, wenn ein Redakteur einen Entwurf prüft, den der Assistent geschrieben hat |

## Wie Sie sie verwenden

- Kopieren Sie die Checkliste in Ihr eigenes Ticket oder Ihren Änderungsdatensatz und haken Sie die Punkte dort ab.
- Ein Punkt, den Sie bewusst überspringen, erhält eine schriftliche Begründung.
- Gehen Sie die Checkliste nach einem Wechsel von Anbieter, Modell, Agent oder Rolle erneut durch.

# Über kostenlose statische Websites mit Exponential sprechen

Diese Seite ist für Journalisten, Blogger und Fürsprecher, die statisches Veröffentlichen richtig beschreiben möchten.

## Was Sie am Ende haben

Drei Kernbotschaften, einen Pitch, den Sie so verwenden können, Fakten zum Abgleich und Links, um es zu zeigen.

## Kernbotschaften

1. **Kostenlose öffentliche Websites aus einem vollständigen CMS.** Exponential 6.0.15 veröffentlicht eine statische
   Kopie einer Website auf GitHub Pages, wo öffentliche Websites kostenlos gehostet werden.
2. **Redakteure behalten ihre Werkzeuge.** Inhalte werden in Exponential geschrieben und freigegeben, mit Versionen,
   Rollen und Übersetzungen. Nur die öffentliche Kopie ist statisch.
3. **Sicher von Grund auf.** Die Kopie entsteht so, wie ein anonymer Besucher die Website sieht; sie hat keine
   Anmeldung, keine Datenbank und kein PHP. Jede Veröffentlichung ist ein Git-Commit mit Tag und lässt sich zurücknehmen.

## Ein kurzer Pitch

> Exponential 6.0.15 macht aus jeder seiner Websites eine statische Website und veröffentlicht sie auf GitHub Pages
> oder einem anderen Git-Host. Gemeinnützige Organisationen, Schulen, kleine Unternehmen und Privatpersonen bekommen
> eine schnelle, sichere öffentliche Website ohne Hosting-Rechnung, während ihre Redakteure weiter in einem
> vollständigen Content-Management-System arbeiten.

## Fakten

- Eingeführt in Exponential 6.0.15; verfügbar unter Setup > Statisches Veröffentlichen und als Befehle `exp:static:*`.
- Funktioniert mit GitHub Pages (Branch oder GitHub Actions) und pusht zu jedem anderen Git-Host.
- Eigene Domains mit HTTPS, Suche im Browser, Formulare über die Live-Site, automatisches und zeitgesteuertes Veröffentlichen.
- Open Source, GPL; kein kostenpflichtiger Dienst nötig.

## Was Sie nicht sagen sollten

- Es ist keine Shop-Plattform: Die Bedingungen von GitHub Pages erlauben keine Online-Shops, und eine statische Kopie hat keine Kasse.
- Es ersetzt die Exponential-Installation nicht; zum Bearbeiten braucht man weiter eine, die privat bleiben kann.
- „Kostenlos“ meint das Hosting öffentlicher Repositorys auf GitHub Pages; eine eigene Domain kostet beim Anbieter Geld.

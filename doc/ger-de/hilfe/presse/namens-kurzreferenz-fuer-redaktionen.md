## Das Stilblatt

Das Stilblatt bleibt in seiner englischen Originalfassung, weil es die Namen genau so zeigt, wie sie geschrieben werden.
Im Deutschen gilt sinngemäß dasselbe: „Exponential“ ohne Artikel, „7x“ mit kleinem x, „die Exponential Foundation“,
später „die Foundation“, und „eZ Publish“ nur in der Vergangenheitsform.

```text
STYLE SHEET: EXPONENTIAL                                        for news desks, as of 18 October 2026

Exponential            the product (CMS and framework); capital E; no article
Exponential 6          the major line              Exponential 6.0.14   a release (no "v" in text)
Exponential CMS        acceptable at first mention for general readers
7x                     the company; digit 7, lowercase x; formerly Brookins Consulting (history only)
se7enx.com             7x's website                se7enxweb   its GitHub and Composer name
the Exponential Foundation   the nonprofit; "the Foundation" later; never "the 7x Foundation"
Exponential Velocity   the PHP web server; "Velocity" later
Exponential Intelligence     the writing assistant; "expai" only in technical text
Exponential Layouts    the page builder; "the layouts editor" later
Exponential Platform DXP / Legacy / Nexus / 3.2.9      the Symfony distributions
Exponential Basic      the small CMS of the 2.x line
AdminUI                the alternative administration
eZ Publish             past tense only: the software's name until 2025, a product discontinued by its
                       creator after almost 18 years
eZ Systems, Ibexa      not associated with Exponential
eZContentObject etc.   code identifiers; never "corrected"
Netgen, Mugo Web, CJW Network   credited companies; spell as shown
open source            two words, no hyphen as a noun; "open-source" as a modifier if house style wants it
license                American spelling in the project's own texts
```

## Erste und spätere Nennungen

| Erste Nennung | Später |
|---|---|
| Exponential, ein Open-Source-Content-Management-System | Exponential |
| 7x, das Unternehmen, das Exponential leitet | 7x |
| die Exponential Foundation, eine gemeinnützige Organisation, die das Projekt betreibt | die Foundation |
| Exponential Velocity, ein in PHP geschriebener Webserver | Velocity |
| Exponential Intelligence, ein Schreibassistent, der Entwürfe schreibt | Exponential Intelligence, der Assistent |
| Exponential Layouts, ein visueller Seitenbaukasten | der Layout-Editor |

## Falsche Formen, die in Texten auftauchen

| Falsch | Richtig |
|---|---|
| eZ Publish 6, eZ Exponential, Exponential Publish | Exponential 6 |
| Das Exponential, die Software Exponential CMS | Exponential |
| 7X, SevenX, Se7enX | 7x |
| `7x_...` als Präfix im Code | `sevenx_...` oder `exp...` ([Namenspräfixe](../../../eng-us/standards/naming-prefixes-sevenx-and-exp.md)) |
| 7x Foundation, Exponential Inc. | die Exponential Foundation |
| Exponential AI, ExpAI | Exponential Intelligence |
| Exponential Qbix | Exponential Velocity |
| Netgen Layouts für Exponential | Exponential Layouts (eine Portierung des Konzepts von Netgen Layouts) |
| v6.0.14 im Fließtext | 6.0.14 |
| Exponential 6.0.15 wurde veröffentlicht ... | 6.0.15 ist in Entwicklung (bis es getaggt ist) |

## Testen Sie sich selbst

Jede Zeile enthält einen Fehler. Die Lösungen stehen am Ende.

```text
1. "7X has released a new version of the CMS."
2. "The 7x Foundation operates the project."
3. "Exponential AI drafts articles for editors."
4. "eZ Publish 6.0.14 adds MongoDB support."
5. "The company corrected eZContentObject to ExponentialContentObject."
```

Lösungen: 1. 7x. 2. die Exponential Foundation. 3. Exponential Intelligence. 4. Exponential 6.0.14. 5. Bezeichner im
Code haben sich nicht geändert; `eZContentObject` ist der echte Klassenname.

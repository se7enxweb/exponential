# Überschriften: was geht und was nicht

Diese Seite ist für Schlussredakteure, Social-Media-Redakteure und Creator, die die Zeile schreiben, die die meisten
Menschen lesen werden. Eine Überschrift ist eine Behauptung; sie braucht dieselbe Quelle wie der Beitrag.

1. [Muster, die funktionieren](#muster-die-funktionieren)

## Muster, die funktionieren

| Thema | Muster der Überschrift | Beispiel |
|---|---|---|
| Ein Release | „Exponential <Version> bringt <Funktion>“ | „Exponential 6.0.14 bringt MongoDB 8 als Datenbank“ |
| Arbeit in Entwicklung | „Nächstes Release von Exponential bringt <Funktion>, zeigt das Changelog“ | „Nächstes Release von Exponential bringt einen PHP-Webserver, zeigt das Changelog“ |
| Eine Funktion | „<Was sie tut> in Exponential“ | „Ein Seitenbaukasten für Redakteure in Exponential“ |
| Die Organisationen | „<Organisation> <tut was>“ | „Gemeinnützige Exponential Foundation gegründet, um Open-Source-CMS zu finanzieren“ |
| Geschichte | „<Alte Tatsache>, <neue Tatsache>“ | „Codebasis von 1999 bekommt einen neuen Namen: Exponential“ |
| Sicherheit | „Exponential <Version> behebt <Art des Problems>“ | Erst wenn das korrigierte Release erschienen ist ([Über Sicherheitskorrekturen berichten](../../../eng-us/help/press/covering-security-fixes.md)) |

## Die häufigen Fehler

| Nicht so | Warum | Sondern so |
|---|---|---|
| „eZ Publish 6.0.14 veröffentlicht“ | Aktuelles Produkt unter seinem früheren Namen | „Exponential 6.0.14 veröffentlicht“ |
| „Das Open-Source-CMS von Ibexa bekommt ...“ | Nicht mit Ibexa verbunden | „Open-Source-CMS Exponential bekommt ...“ |
| „7x Foundation startet ...“ | Vermischt zwei Organisationen | „Exponential Foundation startet ...“ |
| „Exponential 6.0.15 ist da“ | Erst veröffentlicht, wenn es getaggt ist | „Was in Exponential 6.0.15 kommt“ |
| „KI schreibt und veröffentlicht jetzt Ihre Website“ | Exponential Intelligence schreibt nur Entwürfe | „Ein KI-Assistent, der Entwürfe schreibt, keine Seiten“ |
| „Das schnellste CMS der Welt“ | Es ist kein Vergleich veröffentlicht | „Ein PHP-Webserver, der das CMS im Speicher hält“ |
| „Tausende wechseln zu Exponential“ | Es gibt keine Nutzungszahlen | (lassen Sie Zahlen weg) |
| „Totes CMS steigt aus dem Grab“ | Unfair gegenüber allen Seiten, und der Code wurde gepflegt | „Zwanzig Jahre alte Codebasis bekommt neuen Verwalter und neue Funktionen“ |

## Wörter, die Sie prüfen sollten

| Wort | Fragen Sie |
|---|---|
| „neu“, „erstes“ | Erstes im Vergleich wozu, und gibt es eine Quelle? |
| „schnellstes“, „sicherstes“, „bestes“ | Gibt es einen veröffentlichten Vergleich? Meist nicht ([Fair vergleichen](../../../eng-us/help/press/comparisons-done-fairly.md)). |
| „veröffentlicht“, „startet“ | Gibt es einen Tag oder eine datierte Ankündigung? |
| „offiziell“ | Offiziell für wen? Nur 7x und die Foundation können etwas offiziell machen. |
| „KI“ | Welches Produkt, und was genau tut es? |
| „frei“ | Kostenlos, freie Software oder beides? ([Lizenzen für Reporter erklärt](lizenzen-fuer-reporter-erklaert.md)) |

## Video- und Social-Media-Titel

- Titel und Vorschaubild stellen zusammen eine Behauptung auf; beide müssen stimmen ([Titel, Vorschaubilder und Beschreibungen](titel-vorschaubilder-und-beschreibungen.md)).
- Wenn das Video gesponsert ist, sagen Sie das im Titel oder am Anfang der Beschreibung, nicht nur am Ende
  ([Offenlegung und Ethik beim Sponsoring](../../../eng-us/help/press/disclosure-and-sponsorship-ethics.md)).
- Versionsnummern in Titeln veralten schnell; nennen Sie die Version, damit die Zuschauer wissen, was sie sehen werden.

## Bevor sie online geht

- [ ] Der Produktname ist Exponential; der alte Name steht, falls vorhanden, in der Vergangenheitsform.
- [ ] Jede Zahl in der Überschrift steht mit ihrer Quelle im Beitrag.
- [ ] „Veröffentlicht“ nur für eine getaggte Version.
- [ ] Kein Superlativ ohne einen veröffentlichten Vergleich.
- [ ] 7x und die Foundation werden nicht verwechselt.

# Pressekontakte

Diese Seite ist für Journalisten, Redakteure und Creator, die 7x oder die Exponential Foundation erreichen müssen. Sie
nennt nur Adressen, die auf den eigenen Websites des Projekts oder in seinem Repository veröffentlicht sind. Jede wurde
am **18. Oktober 2026** auf der in der letzten Spalte genannten Seite geprüft. Das Projekt veröffentlicht keine eigene
Adresse für eine Pressestelle; verwenden Sie die allgemeinen Kanäle unten und schreiben Sie in den Betreff, dass Sie
für eine Veröffentlichung schreiben.

## Welcher Kontakt für welche Anfrage

| Sie möchten | Verwenden Sie |
|---|---|
| Ein Interview, eine Stellungnahme oder ein Zitat | info@se7enx.com oder das Kontaktformular; siehe [Ein Interview anfragen](ein-interview-anfragen.md) |
| Logodateien, Bildschirmfotos oder Videos aus dem Pressekit | support@exponential.earth |
| Eine Stellungnahme der Foundation | Die Website der Foundation; setzen Sie info@se7enx.com in Kopie, wenn Sie keine Antwort erhalten |
| Einen Fakt auf einer Hilfeseite prüfen | **Auf GitHub bearbeiten** auf der Seite oder den [Issue-Tracker der Community](https://github.com/se7enxweb/exponential-community/issues) |
| Einen Softwarefehler melden, den Sie beim Testen gefunden haben | Den [Issue-Tracker von Exponential](https://github.com/se7enxweb/exponential/issues), ohne personenbezogene Daten |
| Eine Sicherheitslücke melden | security@se7enx.com, nie öffentlich |

## Was in eine Presseanfrage gehört

```text
Subject: Press request - <outlet> - <topic> - deadline <date, time zone>

Hello,
I am <name>, <role> at <outlet> (<link>). I am preparing <article / video / podcast> about <topic>,
to be published on <date>.

I would like to <ask N questions by e-mail / have a 20-minute call / get a written statement> about:
1. <question>
2. <question>

Quotes will be attributed to <the person or organization you name>. I will <send quotes for a factual check /
not send the piece before publication> (my outlet's rule: <rule>).

Thank you,
<name, phone or e-mail for replies>
```

Nennen Sie eine realistische Frist. Für Presseanfragen ist keine Antwortzeit veröffentlicht; die einzige dokumentierte
Antwortzeit ist die erste Antwort auf eine Sicherheitsmeldung, „within one business day“, also innerhalb eines Werktags
(SECURITY.md).

## Sicherheitsmeldungen sind etwas anderes

Wenn Sie, eine Quelle oder ein Leser eine Sicherheitslücke gefunden haben, geht sie vertraulich an security@se7enx.com
oder über die vertrauliche Meldung von Sicherheitslücken auf GitHub, wie es [SECURITY.md](https://github.com/se7enxweb/exponential/blob/main/SECURITY.md)
beschreibt. Veröffentlichen Sie keine Einzelheiten, bevor eine Korrektur erschienen ist. Lesen Sie
[Wenn Sie eine Sicherheitslücke finden](wenn-sie-eine-sicherheitsluecke-finden.md) und [Über Sicherheitskorrekturen berichten](ueber-sicherheitskorrekturen-berichten.md).

## Was nicht veröffentlicht ist

- Eine eigene E-Mail-Adresse oder Telefonnummer einer Pressestelle.
- Ein namentlich genannter Pressesprecher. Fragen Sie, wen Sie zitieren sollen, und ordnen Sie entsprechend zu
  ([Aussagen zuordnen](aussagen-zuordnen.md)).
- Eine Richtlinie für Sperrfristen ([Sperrfristen und Timing](../../../eng-us/help/press/embargoes-and-timing.md)).

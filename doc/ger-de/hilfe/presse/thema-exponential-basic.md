# Thema: Exponential Basic

Diese Seite ist für Journalisten, die über kleine Websites, Bildung oder Softwaregeschichte schreiben. Exponential Basic
ist das kleinste Mitglied der Familie und hat den längsten Faden Geschichte hinter 7x.

1. [Das Thema in einem Absatz](#das-thema-in-einem-absatz)
2. [Fakten, die Sie drucken können](#fakten-die-sie-drucken-können)
3. [Was Sie nicht behaupten sollten](#was-sie-nicht-behaupten-sollten)

## Das Thema in einem Absatz

„Exponential Basic is the simple to us to use CMS Framework that is for everyone, educational purposes, personal use
and worldwide general“ (Beschreibung des Repositorys, so zitiert, wie sie veröffentlicht ist). Es stammt von der zweiten
Generation der Codebasis ab: Sein Repository ist ein Fork von `brookinsconsulting/ezcommunity2`, der Linie eZ Publish
2.2, die Brookins Consulting mit Unterstützung für PHP 5 noch lange nach dem Ende dieser Generation am Leben hielt
([Exponential Basic](../wer-ist-die-exponential-foundation.md#exponential-basic),
[Wer ist 7x?, Exponential Basic](../wer-ist-7x.md#exponential-basic)).

## Was Sie nicht behaupten sollten

| Sagen Sie nicht | Sagen Sie stattdessen |
|---|---|
| „Eine abgespeckte Version von Exponential 6“ | Eine eigene Linie, die von der Generation 2.x abstammt |
| „eZ Publish 2 ist zurück“ | Exponential Basic führt diese Linie unter eigenem Namen fort |

## Blickwinkel und Ideen für Überschriften

# Zwei Organisationen, ein Projekt

Diese Seite ist für Journalisten, die erklären müssen, wer was macht. Hinter Exponential stehen zwei Organisationen,
und der häufigste Fehler in Berichten ist, sie zu einer zu verschmelzen.

## Nebeneinander

| | 7x | Die Exponential Foundation |
|---|---|---|
| Was sie ist | Ein Unternehmen | Eine gemeinnützige Körperschaft nach 501(c)(3) |
| Seit | 2001 als Brookins Consulting; sein Projekt Exponential startete im Dezember 2023 | 19. März 2026 |
| Rolle | Leitet Entwicklung, Support, Hosting und Dienstleistungen | Betreibt das Projekt; finanziert und lenkt es |
| Verdient Geld durch | Verkauf von Dienstleistungen (Entwicklung, Support, Hosting, Schulung) | Spenden und Sponsoring |
| Website | <https://se7enx.com/> | <https://foundation.exponential.earth/>, <https://exponential.earth/> |
| Sponsorenseite | <https://github.com/sponsors/se7enxweb> | <https://github.com/sponsors/exponentialcms> |
| Urheberrecht | „7x & Exponential Foundation“, gemeinsam | (derselbe Vermerk) |

Quelle: [Die Foundation und 7x](../wer-ist-die-exponential-foundation.md#die-foundation-und-7x).

## Wie die Quellen das Verhältnis beschreiben

- „This project is operated by the Exponential Foundation“ (<https://exponential.earth/about/project>).
- „The Exponential Open Source Project is funded by donations of time and resources by 7x (and Exponential
  Sponsors)“ (dieselbe Seite).
- Die Foundation nennt 7x „the current leader in contributions both financial, code, extension development, new
  features, infrastructure, maintenance and much much more back to the project“ (<https://foundation.exponential.earth/>).
- „The Exponential Foundation supports direct change within the Exponential Project, Sub Projects, New Features,
  Documentation through the work of 7x“ (dieselbe Seite, Abschnitt Supporters).
- Wer 7x sponsert, finanziert „the company that keeps the lights on“; wer die Foundation sponsert, finanziert „the
  open-source project itself“ (GitHub-Profil von se7enxweb).

## Sätze, die stimmen

```text
"Exponential is led by the company 7x and operated by the Exponential Foundation, a nonprofit."
"7x is the main contributor to the project that the Exponential Foundation operates."
"The software's copyright is held jointly by 7x and the Exponential Foundation; the license is the GNU GPL."
```

## Häufige Verwechslungen

| Falsch | Richtig |
|---|---|
| „die 7x Foundation“ | die Exponential Foundation |
| „7x, die gemeinnützige Organisation hinter Exponential“ | 7x ist ein Unternehmen; die Foundation ist die gemeinnützige Organisation |
| „Die Foundation bietet Hosting an.“ | 7x bietet Hosting an; die Foundation verkauft keine Dienstleistungen |
| „Exponential gehört 7x.“ | Das Urheberrecht ist geteilt, und der Code steht unter der GPL |
| „Die Foundation wurde 2023 gegründet.“ | 19. März 2026 |

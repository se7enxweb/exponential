# Checkliste: Faktenprüfung

Diese Seite ist für Faktenprüfer und Redakteure, die einen schnellen letzten Durchgang brauchen. Die Methode dahinter
steht im [Leitfaden: Faktenprüfung](leitfaden-faktenpruefung.md). Kopieren Sie die Liste in Ihre Notizen und haken Sie jede
Zeile ab.

## Inhalt

1. [Die Checkliste](#die-checkliste)
2. [Wo jede Antwort steht](#wo-jede-antwort-steht)
3. [Wenn eine Zeile scheitert](#wenn-eine-zeile-scheitert)

## Die Checkliste

```text
NAMEN
[ ] Das Produkt heißt „Exponential“; kein „eZ Publish 6“, „Exponential AI“, „Exponential Qbix“
[ ] „eZ Publish“ erscheint nur in der Vergangenheitsform, als Geschichte
[ ] Bezeichner im Code (eZContentObject ...) unverändert zitiert

ORGANISATIONEN
[ ] 7x = Unternehmen; die Exponential Foundation = gemeinnützige Organisation; nie „die 7x Foundation“
[ ] Keine Verbindung zu eZ Systems oder Ibexa angedeutet
[ ] Andere Unternehmen genannt, wo ihre Arbeit verwendet wird

GESCHICHTE UND DATEN
[ ] 7x: gegründet 2001 (als Brookins Consulting); Idee 2014; Projekt 2022; Start Dezember 2023
[ ] Umbenennung: August 2025; Foundation: 19. März 2026
[ ] Jedes „heute“ oder „neueste“ trägt das Prüfdatum

RELEASES
[ ] „Veröffentlicht“ nur für eine getaggte Version; 6.0.15 „in Entwicklung“, bis es getaggt ist
[ ] Versionen ohne „v“ geschrieben; nach Version sortiert, nicht nach Namen

FUNKTIONEN
[ ] Exponential Intelligence schreibt nur Entwürfe; nie „veröffentlicht“
[ ] DXP liefert den Layout-Editor nicht mit; Nexus schon
[ ] Velocity wird empfohlen, ist aber nicht Pflicht

ZAHLEN
[ ] Jede Zahl hat eine Methode, eine Quelle und ein Datum
[ ] Keine Zahlen zu Nutzung, Kunden oder Markt
[ ] Leistungszahlen behalten ihre Bedingungen; kein „schneller als X“

ZITATE
[ ] Jedes Zitat wurde wirklich gesagt oder geschrieben und ist wörtlich
[ ] Dokumentation wird nicht als Sprecher dargestellt

LIZENZEN
[ ] Software GPL v2 oder später; Dokumentation GFDL 1.3 oder später; Velocity MIT
[ ] „Frei“ richtig erklärt; kein „Freeware“

SICHERHEIT UND PRIVATSPHÄRE
[ ] Keine Einzelheiten nicht behobener Sicherheitslücken
[ ] Keine personenbezogenen Daten, Passwörter oder privaten Hostnamen in Text oder Bildern

BILDER UND OFFENLEGUNG
[ ] Bilder mit Quelle genannt und richtig lizenziert
[ ] Jede Beziehung, Bezahlung oder jedes Geschenk offengelegt
```

## Wenn eine Zeile scheitert

Korrigieren Sie sie, ordnen Sie sie zu oder streichen Sie sie. Veröffentlichen Sie nie eine Aussage, die Sie nicht
belegen konnten, als wäre sie geprüft ([Häufige Fehler in Berichten](haeufige-fehler-in-berichten.md)).

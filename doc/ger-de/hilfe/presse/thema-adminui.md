# Thema: AdminUI

Diese Seite ist für Journalisten, die über das Arbeitserlebnis von Redakteuren berichten. Exponential lässt eine
Installation zwischen Administrationsdesigns wählen; AdminUI ist dasjenige, das aus der Arbeit von Netgen stammt.

## Das Thema in einem Absatz

AdminUI ist „A feature complete port of the legendary Netgen AdminUI Administration UI. This solution depends on
Exponential 6.0.15* or greater“ (Beschreibung des Repositorys `se7enxweb/exp_adminui`), also eine im Funktionsumfang
vollständige Portierung der legendären Netgen AdminUI, die Exponential 6.0.15 oder neuer voraussetzt. Sie ist eines der
Administrationsdesigns; admin4 ist dasjenige, das die meisten Installationen verwenden ([AdminUI](../wer-ist-die-exponential-foundation.md#adminui)).
Der Kernel setzt das Paket seit der Produktlinie 6.0.15 voraus ([Die Produktfamilie auf einen Blick](../wer-ist-die-exponential-foundation.md#die-produktfamilie-im-überblick)).

## Was Sie nicht behaupten sollten

| Sagen Sie nicht | Sagen Sie stattdessen |
|---|---|
| „Die neue Administration von Netgen für Exponential“ | Eine Portierung der Netgen AdminUI durch 7x, mit Nennung ([Netgen, Mugo Web und CJW Network nennen](andere-projekte-nennen.md)) |
| „Ersetzt admin4“ | Eine Alternative; admin4 bleibt das übliche Design |
| „Funktioniert mit 6.0.14“ | Sie braucht 6.0.15 oder neuer |

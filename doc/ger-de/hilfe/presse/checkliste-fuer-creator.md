Diese Seite ist für Video-Creator, Streamer, Podcaster und Blogger. Gehen Sie sie vor der Aufnahme, vor der
Veröffentlichung und danach durch. Jede Zeile verweist auf die Seite, die sie erklärt.

## Vor der Aufnahme

```text
[ ] Beziehung, Bezahlung oder Geschenk geklärt und für die Offenlegung aufgeschrieben
[ ] Eigene Demo-Installation, Version notiert
[ ] Fiktive Benutzer unter example.com; Standardpasswort des Administrators geändert
[ ] Keine Produktivdaten, keine Websites von Kunden
[ ] Skript folgt einem getesteten Demo-Skript; Aussagen geprüft
[ ] Benachrichtigungen, Mail- und Chat-Apps geschlossen; sauberes Browserprofil
```

## Während der Aufnahme

```text
[ ] Offenlegung in den ersten Sekunden ausgesprochen
[ ] Version genannt und gezeigt
[ ] Handlungen laut beschrieben, nicht nur gezeigt
[ ] Keine Passwörter, Schlüssel, Tokens, Hostnamen getippt oder gezeigt
[ ] Unveröffentlichte Funktionen als „in Entwicklung“ bezeichnet
```

Seiten: [Leitfaden für Video-Rundgänge](leitfaden-fuer-video-rundgaenge.md), [Leitfaden für Livestreams](leitfaden-fuer-livestreams.md),
[Über 6.0.15 berichten, solange es in Entwicklung ist](ueber-6-0-15-in-entwicklung-berichten.md).

## Vor der Veröffentlichung

```text
[ ] Namen: Exponential, 7x, die Exponential Foundation; alter Name nur als Geschichte
[ ] Jede Zahl mit Quelle und Bedingungen; keine Nutzerzahlen oder „schneller als“
[ ] Untertitel von einem Menschen geprüft; Transkript für Audio
[ ] Titel und Vorschaubild machen eine Aussage, die der Inhalt stützt
[ ] Offenlegung am Anfang der Beschreibung, Kennzeichnung der Plattform gesetzt
[ ] Musik, Schriften und Bilder lizenziert und genannt
[ ] Links in der Beschreibung: das Projekt, die verwendeten Quellen
[ ] Bilder auf Geheimnisse und personenbezogene Daten geprüft
```

## Nach der Veröffentlichung

```text
[ ] Fragen mit Quellen beantwortet; Supportfragen an die richtige Stelle verwiesen
[ ] Sicherheitsmeldungen in vertrauliche Kanäle verlagert
[ ] Fehler offen korrigiert
[ ] Aktualisierungshinweis, wenn eine als „kommend“ gezeigte Funktion veröffentlicht ist
```

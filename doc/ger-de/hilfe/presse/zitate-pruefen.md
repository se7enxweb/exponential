# Zitate prüfen

Diese Seite ist für Reporter und Faktenprüfer. Ein Zitat muss echt, genau, im Zusammenhang und richtig zugeordnet sein.
Bei Open-Source-Projekten sind viele „Zitate“ in Wirklichkeit Sätze aus einem README, einem Forenbeitrag oder einer
alten Pressemitteilung; jeder davon ist zitierfähig, aber nur als das, was er ist.

## Vier Prüfungen für jedes Zitat

1. **Echt**: Es gibt ein Original: eine Seite, eine Datei, eine Aufnahme, eine E-Mail.
2. **Genau**: Der Wortlaut stimmt mit dem Original überein, einschließlich seiner Schreibweise. Auslassungen werden
   mit „...“ gekennzeichnet.
3. **Im Zusammenhang**: Der umgebende Text verändert seine Bedeutung nicht.
4. **Zugeordnet**: Sprecher oder Dokument sind richtig benannt, mit Rolle und Datum ([Aussagen zuordnen](aussagen-zuordnen.md)).

## Zitate aus veröffentlichten Seiten prüfen

- Öffnen Sie die Originalseite; kopieren Sie nicht aus einem anderen Artikel.
- Bei einer Datei im Repository zitieren Sie die Datei und, wenn es auf Genauigkeit ankommt, den Commit:
  `https://github.com/se7enxweb/exponential/blob/<commit>/README.md`.
- Websites ändern sich: Notieren Sie das Datum, an dem Sie sie gelesen haben, und eine Archivkopie, wenn Ihr Medium
  eine verwendet.

## Zitate aus Interviews prüfen

- Nehmen Sie mit Einverständnis auf oder machen Sie wörtliche Notizen.
- Wenn Sie gesprochene Sprache glätten, verändern Sie nicht die Bedeutung; die Regeln Ihres Mediums bestimmen, wie viel
  Glättung erlaubt ist.
- Wenn Sie Zitate zur sachlichen Prüfung zurückschicken, sagen Sie, was Sie als Korrektur annehmen (Fakten) und was
  nicht (Ton).

## Zitate, die ohne Quelle umlaufen

Wenn ein Zitat in einem Forum, einem Kommentar oder einem anderen Artikel ohne Quelle auftaucht, behandeln Sie es als
ungeprüft. Fragen Sie die Person oder Organisation, ob sie es gesagt hat ([Regeln für Zitate](richtlinie-fuer-zitate.md)).
Verwenden Sie es nicht, bevor es bestätigt ist.

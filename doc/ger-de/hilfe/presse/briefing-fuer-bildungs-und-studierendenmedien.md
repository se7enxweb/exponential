# Briefing für Bildungs- und Studierendenmedien

Diese Seite ist für studentische Journalisten, Campusmedien, Lehrkräfte und Autoren im Bildungsbereich. Exponential ist
ein nützliches Lehrbeispiel: eine große Open-Source-Codebasis mit einer öffentlichen Geschichte von mehr als zwanzig
Jahren, freier Dokumentation und einem Projekt, das jeden Beitrag übernimmt.

## Warum es zu Bildungsthemen passt

| Thema | Warum Exponential es veranschaulicht | Quelle |
|---|---|---|
| Open-Source-Lizenzen | Die GPL erlaubte einem neuen Verantwortlichen, den Code weiterzuführen, nachdem sein Hersteller aufgehört hatte | [Lizenzen für Reporter erklärt](lizenzen-fuer-reporter-erklaert.md) |
| Softwaregeschichte | Commits seit 2002, Urheberrecht seit 1999, eine Geschichte Monat für Monat seit 2023 | [Die Geschichte für lange Beiträge](die-geschichte-fuer-lange-beitraege.md) |
| Dokumentation als Gemeingut | Die Dokumentation ist frei unter der GNU FDL | [Thema: freie Dokumentation](thema-freie-dokumentation.md) |
| Barrierefreiheit und Sprachen | Tests für Kontrast und Zielgröße; Unterstützung für Rechts-nach-links-Schrift | [Thema: Barrierefreiheit](thema-barrierefreiheit.md) |

## Wie Studierende mitmachen können

- Einen Fehler gut melden ([Wenn etwas schiefgeht](../wenn-etwas-schiefgeht.md)).
- Eine Hilfeseite mit **Auf GitHub bearbeiten** korrigieren ([Die Hilfe verbessern](../fuersprecher/die-hilfe-verbessern.md)).
- Eine Übersetzung vervollständigen ([Sprachen in Exponential](../../../eng-us/languages.md)).
- Einen ersten Pull Request schicken ([Mit Git entwickeln](../mit-git-entwickeln.md)); jeder Pull Request wird übernommen
  ([Thema: jeder Pull Request wird übernommen](thema-jeder-pull-request-wird-uebernommen.md)).

Das Partnerprogramm hat eine Kategorie für Bildungspartner ([Partner für Studierende und Bildung](../partner/partner-fuer-studierende-und-bildung.md));
sehen Sie auf dieser Seite nach, was darüber veröffentlicht ist.

## Praktische Hinweise für studentische Reporter

- Nehmen Sie über die [Pressekontakte](pressekontakte.md) Kontakt auf; sagen Sie, dass Sie für Studierendenmedien
  schreiben, und nennen Sie Ihren Abgabetermin.
- Installieren Sie selbst eine Demo, statt um Zugang zu bitten ([Eine Demo-Installation einrichten](eine-demo-installation-einrichten.md)).
- Prüfen Sie die Fakten mit der [Checkliste: Faktenprüfung](../../../eng-us/help/press/fact-checking-checklist.md).

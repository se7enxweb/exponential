# Nicht verbunden mit eZ Systems oder Ibexa

Diese Seite ist für Journalisten, die eZ Systems oder Ibexa in einem Beitrag über Exponential erwähnen. Das Projekt
erklärt unmissverständlich, dass es nicht mit ihnen verbunden ist. Berichte, die etwas anderes nahelegen, führen die
Leser in die Irre und sind allen Beteiligten gegenüber unfair.

## Der Hinweis

> „This project is not associated with the original eZ Publish software or its original developer, eZ Systems or
> Ibexa“

Auf Deutsch: Dieses Projekt ist weder mit der ursprünglichen Software eZ Publish noch mit ihrem ursprünglichen
Entwickler eZ Systems oder Ibexa verbunden. Veröffentlicht in der [README](https://github.com/se7enxweb/exponential/blob/main/README.md)
(„Exponential Project Notice : 2025.08.12“) und auf <https://exponential.earth/about/project>.

## Was er für Ihren Beitrag bedeutet

| Schreiben Sie nicht | Schreiben Sie |
|---|---|
| „Exponential von Ibexa“, „das neue CMS von eZ Systems“ | „Exponential, geleitet von 7x und betrieben von der Exponential Foundation“ |
| „der offizielle Nachfolger von eZ Publish“ | „eine Weiterführung der Codebasis von eZ Publish durch 7x“ |
| „von Ibexa unterstützt“, „in Partnerschaft mit Ibexa“, „von Ibexa lizenziert“ | (eine solche Beziehung ist nicht dokumentiert) |
| „Ibexa hat die Umbenennung erzwungen“ | „auf Bitten von Ibexa umbenannt, nach Angaben des Projekts“ |

## Die gemeinsame Geschichte beschreiben

Die Fakten, die die Namen verbinden, betreffen den **Code**, nicht die Unternehmen:

- eZ Systems AS entwickelte eZ Publish; sein Urheberrecht von 1999 bis 2014 bleibt im Code (COPYRIGHT.md).
- Der Code steht unter der GNU GPL, die es jedem erlaubt, ihn weiterzuführen ([Lizenzen für Reporter erklärt](lizenzen-fuer-reporter-erklaert.md)).
- 7x übernahm 2023 die Leitung dieser Codebasis und benannte das Produkt im August 2025 um
  ([Warum es Exponential heißt](../../../eng-us/help/press/why-it-is-called-exponential.md)).
- Die eigene Produktlinie von Ibexa ging einen anderen Weg: eZ Platform, dann Ibexa DXP (README, „What was eZ Platform?“).
- Die Produktlinie Exponential Platform führt den freien Code von eZ Platform und Ibexa OSS unter eigenem Namen weiter
  ([Thema: Exponential Platform DXP](thema-exponential-platform-dxp.md)).

```text
"Exponential's code was first developed by eZ Systems as eZ Publish. The project, led by 7x since 2023,
is not associated with eZ Systems or Ibexa."
```

Auf Deutsch etwa: „Der Code von Exponential wurde zuerst von eZ Systems als eZ Publish entwickelt. Das Projekt, seit
2023 von 7x geleitet, ist nicht mit eZ Systems oder Ibexa verbunden.“

## Vergleiche mit den Produkten von Ibexa

Vergleiche sind legitimer Journalismus; machen Sie sie sachlich. Die Dokumentation vergleicht nur, was sie belegen
kann, und veröffentlicht keine Benchmarks gegen andere Produkte ([Exponential sachlich vergleichen](../geschaeft/exponential-sachlich-vergleichen.md)).
Verwenden Sie die Methode auf [Vergleiche, fair gemacht](../../../eng-us/help/press/comparisons-done-fairly.md): dieselben Kriterien, Quellen auf
beiden Seiten, das Datum und die eigene Beschreibung der anderen Seite von ihrem Produkt.

## eZ Systems oder Ibexa fragen

Wenn Ihr Beitrag eine Behauptung über eZ Systems oder Ibexa aufstellt, bitten Sie diese über ihre eigenen
Pressekanäle um eine Stellungnahme. Diese Dokumentation spricht nicht für sie und enthält keine Aussagen von ihnen außer
der Bitte um Umbenennung, die auf [Warum es Exponential heißt](../../../eng-us/help/press/why-it-is-called-exponential.md) zitiert ist.

# Marke und Namen für Medien

Diese Seite ist für Journalisten, Redakteure in der Schlussredaktion und Creator. Sie verdichtet die vollständigen
[Marken- und Namensregeln](../geschaeft/marken-und-namensregeln.md) auf das, worauf es in veröffentlichten Berichten
ankommt. Die Regeln stammen aus der eigenen Dokumentation des Projekts; wo die Dokumentation keine Regel festlegt, sagt
diese Seite das.

## Der frühere Name

Die Codebasis wurde als **eZ Publish** entwickelt, ein Produkt, das sein Hersteller nach fast 18 Jahren einstellte.
Verwenden Sie diesen Namen nur in der Vergangenheitsform, als Geschichte: „gebaut, als die Software noch eZ Publish
hieß“. Nie als aktuellen oder zweiten Namen, nie in einem Produkttitel, nie als „eZ Publish 6“. Siehe
[Über die eZ-Publish-Jahre schreiben](ueber-die-ez-publish-jahre-schreiben.md).

Exponential ist nicht mit eZ Systems oder Ibexa verbunden; deuten Sie nie eine Partnerschaft, eine Empfehlung oder eine
Nachfolge von Unternehmen an ([Nicht verbunden mit eZ Systems oder Ibexa](nicht-verbunden-mit-ez-systems-oder-ibexa.md)).

## Namen im Code sind keine Produktnamen

Im Code sehen Sie `eZ`: `eZContentObject`, `eZINI`, `bin/php/ezcache.php`, Pakete wie `ezwebin`. Das sind echte
Bezeichner, und sie bleiben, wie sie sind. Wenn Sie Code zitieren, zitieren Sie ihn genau; wenn Sie das Produkt nennen,
schreiben Sie Exponential. Paketnamen werden in Code-Schrift und klein geschrieben: `expai`, `explayouts`. Im Code wird
7x als `sevenx` geschrieben (sein offizielles öffentliches PHP-Code-Präfix, weil ein Name im Code nicht mit einer Ziffer
beginnen kann) oder als `exp`, das Präfix, das 7x mit der Absicht verwendet, Arbeit dem Exponential-Projekt und der
Exponential Foundation zuzuordnen ([Namenspräfixe](../../../eng-us/standards/naming-prefixes-sevenx-and-exp.md)). Im Fließtext ist
es immer 7x.

## Slogans

Die Dokumentation legt keinen Slogan fest. Zwei Slogans erscheinen auf der Website des Projekts (gelesen am
18. Oktober 2026); wenn Sie einen zitieren, zitieren Sie ihn als eigene Worte des Projekts mit der Quelle:

## Was die Markenregeln nicht entscheiden

Die Dokumentation legt keine Regeln fest für den Markenstatus, für Schutzraum oder Größen des Logos über die vier
Richtlinien des Pressekits hinaus oder dafür, Partner als „offiziell“ zu bezeichnen ([Marken- und Namensregeln](../geschaeft/marken-und-namensregeln.md#was-die-quellen-nicht-entscheiden)).
Die Richtlinien des Pressekits stehen unter [Logos und Markenmaterial](logos-und-markenmaterial.md).

## Eine Checkliste für Redakteure

- [ ] „Exponential“, großes E, ohne Artikel; Versionen vollständig ohne „v“.
- [ ] „eZ Publish“ nur in der Vergangenheitsform, als Geschichte.
- [ ] Keine Verbindung zu eZ Systems oder Ibexa angedeutet.
- [ ] 7x und die Exponential Foundation auseinandergehalten.
- [ ] Bezeichner im Code unverändert zitiert.
- [ ] Andere Unternehmen mit Namen genannt.
- [ ] Englische Begriffe in amerikanischer Schreibweise: license, color, behavior.

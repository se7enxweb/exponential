# Die Geschichte für lange Beiträge

Diese Seite ist für Autoren von Reportagen, Dokumentarfilmer und Podcaster, die die längere Geschichte erzählen. Die
Geschichte von Exponential ist ungewöhnlich gut dokumentiert: Das Repository bewahrt jeden Commit seit 2002, und das
Projekt hat eine Geschichte jeder Änderung seit Dezember 2023 geschrieben, Monat für Monat. Diese Seite zeigt Ihnen den
Bogen, die Kapitel und wo jedes davon erzählt wird.

## Der Bogen in fünf Sätzen

1. Ab 1999 entwickelte das norwegische Unternehmen eZ Systems ein Content-Management-System namens eZ Publish, und
   Hunderte von Menschen haben im Lauf der Jahre dazu beigetragen.
2. eZ Publish war ein Produkt, das sein Schöpfer nach fast 18 Jahren im Einsatz eingestellt hat; seine letzten Releases
   sind bis 2021 verzeichnet, und seine Nachfolger gingen andere, auf Symfony beruhende Wege.
3. Brookins Consulting, ein amerikanisches Unternehmen, das seit den ersten Versionen mit der Software gearbeitet
   hatte, wurde zu 7x: die Idee 2014, das Projekt 2022, der Start im Dezember 2023.
4. 7x veröffentlichte 6.0.0 am 1. Januar 2024 und bis Juni 2026 vierzehn weitere Releases 6.0.x, benannte das Produkt
   im August 2025 in Exponential um und half im März 2026, die Exponential Foundation zu gründen.
5. 2026 kamen in der Linie ein eigener Webserver in PHP, ein Seitenbaukasten, ein Schreibassistent und ein Hilfesystem
   hinzu, während Websites, die über zwei Jahrzehnte gebaut wurden, weiterlaufen.

Quellen: [Wer ist 7x?](../wer-ist-7x.md), [Die Geschichte von Exponential](../../../eng-us/history/README.md).

## Grenzen, die Sie nicht überschreiten sollten

- **Keine Dramatik, die die Quellen nicht zeigen.** Die Quellen beschreiben keine Streitigkeiten zwischen 7x und
  eZ Systems oder Ibexa; die Umbenennung erfolgte „At the specific request of Ibexa“, und mehr sagen sie nicht
  ([Warum es Exponential heißt](../../../eng-us/help/press/why-it-is-called-exponential.md)).
- **Keine unterstellte Kontinuität von Unternehmen.** Exponential führt eine Codebasis fort, kein Unternehmen; es ist
  „not associated with“ eZ Systems oder Ibexa ([Nicht mit eZ Systems oder Ibexa verbunden](nicht-verbunden-mit-ez-systems-oder-ibexa.md)).
- **Keine erfundenen Personen oder Zitate.** Nennen Sie Personen nur so, wie die öffentlichen Quellen sie nennen, und
  zitieren Sie nur, was veröffentlicht ist oder Ihnen gegeben wurde ([Regeln für Zitate](richtlinie-fuer-zitate.md)).
- **Keine geschätzten Zahlen.** Verwenden Sie die gezählten Werte mit ihren Daten ([Exponential in Zahlen](../../../eng-us/help/press/exponential-by-the-numbers.md)).

## Ein Detail prüfen

Die meisten Details lassen sich in einem Klon des Repositorys prüfen:

```bash
git clone https://github.com/se7enxweb/exponential.git && cd exponential
git log --reverse --format='%ad %s' | head -3        # the oldest commits
git log --since=2023-12-01 --until=2023-12-31 --oneline | tail -5   # the first month of the stewardship
git tag -l 'v6.0.*' --sort=version:refname           # the releases, in order
```

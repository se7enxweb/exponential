# Thema: das Ökosystem der Erweiterungen

Diese Seite ist für Journalisten, die über Plattformen und ihre Ökosysteme berichten. Exponential wird durch Pakete
erweitert, die Erweiterungen heißen; viele werden mit jeder Website installiert, und viele bleiben ausgeschaltet, bis
sie gebraucht werden.

## Das Thema in einem Absatz

Die `composer.json` des Kernels setzt 66 Pakete `se7enxweb/*` voraus: Themes, den Seitenbaukasten, den
Schreibassistenten, Tags, Newsletter, die zweistufige Anmeldung, den Oracle-Treiber, die REST-API, die
Job-Warteschlange und mehr; „Viele sind inaktiv, bis Sie sie einschalten“
([Das Ökosystem der Erweiterungen](../wer-ist-7x.md#das-ökosystem-der-erweiterungen)). Jedes hat sein eigenes Repository, eigene
Releases und einen eigenen Changelog und nennt seine Version in seinen eigenen Dateien. Auf Packagist hat der Anbieter
se7enxweb 219 Pakete. Einige Erweiterungen stammen aus der Arbeit anderer Unternehmen, etwa der Newsletter von CJW
Network, und werden genannt.

| Das README spricht von einer „plugin API with thousands of open-source extensions available“ | README, „Main Exponential features“ |

Die „thousands“ des README beziehen sich auf Erweiterungen, die über die Geschichte der Codebasis verfügbar waren;
diese Dokumentation zählt sie nicht. Schreiben Sie die Aussage dem README zu, wenn Sie sie verwenden.

## Was Sie nicht behaupten sollten

| Sagen Sie nicht | Sagen Sie stattdessen |
|---|---|
| „66 Erweiterungen, alle aktiv“ | Vom Kernel vorausgesetzt; viele inaktiv, bis sie eingeschaltet werden |
| „Ein App Store“ | Pakete auf GitHub und Packagist; ein Store ist nicht dokumentiert |
| „Tausende Erweiterungen“ (als eigene Tatsachenbehauptung) | Schreiben Sie es dem README zu, oder nutzen Sie die gezählten Zahlen |

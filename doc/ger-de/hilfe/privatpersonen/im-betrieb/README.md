# Allein betreiben

Dieser Bereich ist für Privatpersonen, die ihre Website gestartet haben und sie nun allein am Laufen halten. Die
Arbeit ist gering, wenn sie regelmäßig geschieht: etwa ein Abend im Monat, rund um ein Update etwas mehr. Nichts
davon setzt voraus, dass Sie programmieren können, aber manche Schritte brauchen eine Shell oder das Kontrollzentrum
Ihres Hosters.

## Ein Jahr auf einen Blick

| Wann | Was tun | Seite |
|---|---|---|
| Jede Woche | Einen Blick auf die Website werfen; neue Kommentare und Formulareinsendungen lesen | [Grundlagen zu Spam und Sicherheit](grundlagen-zu-spam-und-sicherheit.md) |
| Jeden Monat | Die [monatliche Pflegecheckliste](../checklisten/monatliche-pflegecheckliste.md): Sicherung prüfen, Updates, Konten, Links | |
| Nach jeder Version | Die Hinweise lesen; Sicherheitskorrekturen zügig einspielen | [Updates für eine Person](updates-fuer-eine-person.md) |
| Zweimal im Jahr | Eine Sicherung auf einem anderen Rechner wiederherstellen; Konten und Rollen prüfen | [Sicherungen für eine Person](sicherungen-fuer-eine-person.md) |
| Einmal im Jahr | Die Domain verlängern; Über-mich- und Datenschutztexte erneut lesen; die Tag-Liste prüfen | [Domainnamen und HTTPS](../setup/domainnamen-und-https.md) |

Der Bereich für Kunden hat denselben Rhythmus für Inhaber, die einen Dienstleister haben:
[Das Jahr eines Inhabers auf einen Blick](../../kunden/das-jahr-des-betreibers.md).

## Die drei wichtigsten Dinge

Wenn Sie sonst nichts tun:

1. **Eine Sicherung, die Sie einmal wiederhergestellt haben**, getrennt vom Server aufbewahrt.
2. **Sicherheitsupdates eingespielt**, innerhalb von Tagen, nicht Monaten.
3. **Zweistufige Anmeldung** für Ihr Administratorkonto.

Alles andere macht die Website besser; diese drei halten sie am Leben.

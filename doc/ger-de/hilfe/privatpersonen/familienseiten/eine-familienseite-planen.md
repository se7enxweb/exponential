# Eine Familienseite planen

Diese Seite ist für Privatpersonen, die gleich eine Website für ihre Familie anlegen. Der technische Teil ist
überschaubar; entscheidend sind die Entscheidungen über Menschen. Treffen Sie sie, bevor das erste Konto existiert.
Tragen Sie sie in das [Arbeitsblatt für die Websiteplanung](../checklisten/arbeitsblatt-fuer-die-websiteplanung.md) ein.

## Privat oder teilweise öffentlich

| Modell | Wie | Passt zu |
|---|---|---|
| **Vollständig privat** | Der ganze öffentliche Siteaccess verlangt eine Anmeldung (`RequireUserLogin=true`) | Familien, die nichts öffentlich möchten |
| **Öffentliche Tür, privates Haus** | Eine kleine öffentliche Startseite; alles andere in einer Sektion, die anonyme Besucher nicht lesen können | Familien, die eine Kontaktseite oder eine öffentliche Familiengeschichte möchten |

Beides wird unter [Private Bereiche mit Rollen und Sektionen](private-bereiche-mit-rollen-und-sektionen.md) erklärt.
Vollständig privat ist einfacher richtig hinzubekommen; beginnen Sie damit, wenn nichts dagegen spricht.

## Wer ein Konto bekommt

- **Jede Person ein eigenes Konto.** Ein gemeinsames Familienpasswort lässt sich einer einzelnen Person nicht
  entziehen und hinterlässt keine Spur, wer was getan hat.
- **Kinder**: Entscheiden Sie mit den Eltern, ob sie ein Konto bekommen, ab welchem Alter und mit welchen Rechten.
- **Partner von Verwandten, Angeheiratete, enge Freunde**: Legen Sie die Regel einmal fest statt von Fall zu Fall.
- **Wenn jemand den Familienkreis verlässt** (eine Trennung, ein Zerwürfnis): Sie brauchen einen Weg, den Zugriff
  ohne Aufsehen zu entziehen. Das Deaktivieren eines Kontos ist dieser Weg
  ([Familienmitglieder einladen](familienmitglieder-einladen.md)).

## Wer veröffentlichen darf

| Rolle | Darf | Typisch |
|---|---|---|
| Leser | Den privaten Bereich lesen | Die meisten Verwandten |
| Beitragende | Lesen, Neuigkeiten veröffentlichen, Fotos hochladen, kommentieren | Einige aktive Verwandte |
| Administrator | Alles | Sie und eine vertrauenswürdige Vertretung |

Eine Vertretung ist wichtig: Wenn Sie krank oder unterwegs sind, muss jemand anderes ein Passwort zurücksetzen oder
etwas entfernen können.

## Hausregeln

Vereinbaren Sie diese mit der Familie und stellen Sie sie auf eine Seite innerhalb der Website:

1. Keine Fotos von jemandem, der darum gebeten hat, nicht gezeigt zu werden; fragen Sie, bevor Sie Kinder anderer
   Leute zeigen.
2. Keine Adressen, Schulnamen, Reisedaten oder andere Angaben, mit denen ein Fremder jemanden finden könnte.
3. Nichts wird ohne Nachfrage von der Website in öffentliche soziale Netzwerke kopiert.
4. Jede Person kann darum bitten, dass etwas über sie entfernt wird, und es wird entfernt.
5. Konten sind persönlich; Passwörter werden nicht weitergegeben.

Siehe [Privatsphäre für Ihre Familie](privatsphaere-fuer-ihre-familie.md).

## Der Baum

Halten Sie ihn flach und auch für Menschen verständlich, die selten Computer nutzen:

| Ordner | Enthält |
|---|---|
| Neuigkeiten | *Blog posts* |
| Fotos | Eine *Gallery* pro Ereignis oder Jahr |
| Rezepte | *Articles* |
| Unsere Geschichte | *Articles*, mit Bildern und Dokumenten |
| Termine | *Event calendar* für Treffen; die Liste der Geburtstage ([Geburtstage und Familientermine](geburtstage-und-familientermine.md)) |
| Hausregeln | Ein *Article* |

## Die Klassen

Das Standard-Seitenpaket enthält jede der oben genannten Klassen. Eine neue Klasse brauchen Sie nur für strukturierte
Familiendaten, etwa eine Klasse „Verwandte" mit Name, Geburtsdatum (`ezbirthday`) und Foto
([Ihr Inhaltsmodell entwerfen](../../ersteller/website-ersteller/ihr-inhaltsmodell-entwerfen.md)). Überlegen Sie
zweimal, bevor Sie ein Verzeichnis der Verwandten anlegen: Es ist genau die Art personenbezogener Daten, die
Sorgfalt braucht.

## Ein durchgespieltes Beispiel

Ein erfundenes Beispiel: Eine Familie, die über mehrere Länder verteilt lebt, möchte Fotos und Neuigkeiten teilen.

| Entscheidung | Wahl |
|---|---|
| Modell | Vollständig privat |
| Konten | Alle erwachsenen Verwandten; Jugendliche mit Zustimmung ihrer Eltern |
| Beitragende | Vier Verwandte, die regelmäßig veröffentlichen |
| Administratoren | Die Inhaberin der Website und ein Cousin |
| Inhalte | Neuigkeiten, Fotos nach Jahr, Rezepte |
| Nicht online | Adressen, Telefonnummern, Schulnamen, Reisepläne |
| Sicherheit | Zweistufige Anmeldung für Administratoren und Beitragende |

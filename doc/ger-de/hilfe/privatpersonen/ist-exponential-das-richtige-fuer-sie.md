# Ist Exponential das Richtige für Sie?

Diese Seite ist für Privatpersonen, die entscheiden, ob Exponential das richtige Werkzeug für eine eigene Website
ist. Sie will Ihnen nichts verkaufen. Exponential ist ein vollständiges Content-Management-System; für manche
Websites ist das eine Stärke, für andere mehr, als Sie brauchen.

## Wo es gut passt

Die bemerkenswerteste Eigenschaft von Exponential ist laut seiner `README.md` sein „vollständig anpassbares und
erweiterbares Inhaltsmodell". Für eine einzelne Person zählt das, wenn Ihre Inhalte eine feste Form haben:

| Ihre Website | Warum Exponential passt |
|---|---|
| Ein Portfolio mit vielen Werken, jedes mit Titel, Jahr, Technik, Bildunterschrift und mehreren Bildern | Klassen beschreiben genau diese Felder; Galerien, Bildvarianten und ein Bildeditor werden mitgeliefert |
| Ein Blog, das Sie über Jahre führen möchten | Entwürfe, Versionen, zeitgesteuertes Veröffentlichen, Tags, Feeds und lesbare Adressen sind eingebaut |
| Eine Familienseite mit einem privaten Bereich | Sektionen und Rollen behalten einen Teil der Website, oder die ganze, angemeldeten Familienmitgliedern vor |
| Ein Verein mit Mitgliedern, die sich registrieren, Neuigkeiten lesen, Termine sehen und einen Newsletter erhalten | Registrierung, Mitgliederbereiche, *Event*-Klassen und `cjw_newsletter` werden mitgeliefert |
| Eine Website in zwei oder mehr Sprachen | Mehrsprachige Inhalte gehören zum Kern ([Mehrsprachige Websites](../ersteller/website-ersteller/mehrsprachige-websites.md)) |
| Eine Website, die Ihnen vollständig gehören soll | Freie Software, Ihr eigener Server, Ihre eigenen Daten, kein Konto bei einer Plattform |

## Wo etwas Einfacheres besser sein kann

Seien Sie ehrlich zu sich selbst. Ein einfacheres Werkzeug passt womöglich besser, wenn:

- **Sie nur eine einzige Seite möchten** und nie erwarten, sie auszubauen. Eine statische HTML-Seite macht weniger
  Arbeit.
- **Sie nie über einen Server, Updates oder Sicherungen nachdenken möchten.** Ein gehosteter Dienst erledigt das für
  Sie; bei Exponential müssen Sie, Ihr Hoster oder ein Partner es tun ([Updates für eine Person](im-betrieb/updates-fuer-eine-person.md)).
- **Sie eine Funktion brauchen, die es hier nicht gibt**, und deren Entwicklung nicht bezahlen können: Ticketverkauf,
  Mitgliedsbeiträge, ein fertiges Kommentarsystem mit Threads und Likes, ein Ein-Klick-Import aus einer anderen
  Plattform ([Was es gibt und was nicht](was-es-gibt-und-was-nicht.md)).
- **Sie es heute Abend online brauchen** und noch nie eine Website betrieben haben. Planen Sie mindestens ein
  Wochenende ein ([Eine persönliche Website an einem Wochenende](persoenliche-seiten/eine-persoenliche-website-an-einem-wochenende.md)).

Keiner dieser Punkte ist ein Grund, für immer fernzubleiben. Viele beginnen klein woanders und ziehen um, sobald ihre
Inhalte darüber hinauswachsen ([Umzug von einer anderen Blogplattform](blogs/umzug-von-einer-anderen-blogplattform.md)).

## Zehn Fragen

Antworten Sie mit Ja oder Nein. Überwiegend Ja heißt, Exponential passt gut; überwiegend Nein heißt, sehen Sie sich
zuerst die oben genannten Alternativen an.

1. Haben meine Inhalte wiederkehrende Arten (Beiträge, Werke, Termine, Mitglieder) mit eigenen Feldern?
2. Werde ich die Website länger als ein Jahr behalten?
3. Möchte ich die Daten und die Software besitzen, statt ein Konto zu mieten?
4. Brauche ich einen privaten Bereich oder Mitglieder, die sich anmelden?
5. Brauche ich mehr als eine Sprache, oder vielleicht später?
6. Kann ich einen Abend im Monat für die Pflege aufbringen oder jemanden bezahlen, der das kann?
7. Kann ich eine Sicherung anlegen und testen?
8. Gibt es einen Hoster meines Vertrauens, der PHP 8 anbietet, oder kann ich einen kleinen Server betreiben?
9. Komme ich mit Dokumentation wie dieser Seite zurecht?
10. Würde ich gern lernen, wie ein vollständiges Content-Management-System funktioniert?

## Wenn Sie unsicher sind

- Installieren Sie es mit SQLite auf Ihrem eigenen Computer und probieren Sie es einen Abend lang aus; es geht nichts
  verloren, wenn Sie sich dagegen entscheiden ([Eine Installationsmethode wählen](einrichtung/eine-installationsmethode-waehlen.md)).
- Sehen Sie sich die Demonstrationsinstallation unter <https://alpha.se7enx.com> an.
- Fragen Sie in der Community ([Community-Kanäle](../fuersprecher/community-kanaele.md)).
- Wenn Sie Studierende oder Lehrende sind, ziehen Sie die Partnerstufe Student in Betracht
  ([Lernen mit der Stufe Student](im-betrieb/lernen-mit-der-stufe-student.md)).

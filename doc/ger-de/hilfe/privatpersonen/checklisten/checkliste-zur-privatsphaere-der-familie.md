# Checkliste zur Privatsphäre der Familie

Diese Seite ist für Privatpersonen, die eine Familienseite betreiben. Sie macht aus
[Privatsphäre für Ihre Familie](../familienseiten/privatsphaere-fuer-ihre-familie.md) eine Liste. Gehen Sie sie vor dem Start
und danach einmal im Jahr durch. Es handelt sich um allgemeine Informationen, nicht um Rechtsberatung.

## Absprachen

- [ ] Hausregeln geschrieben und innerhalb der Website veröffentlicht ([Eine Familienseite planen](../familienseiten/eine-familienseite-planen.md#hausregeln)).
- [ ] Eltern haben sich geeinigt, was von ihren Kindern gezeigt werden darf.
- [ ] Ältere Kinder selbst gefragt.
- [ ] Alle wissen, dass sie um Entfernung bitten können.

## Inhalte

- [ ] Keine Adressen, Telefonnummern, Schulnamen, Reisedaten, Gesundheitsangaben, Ausweisdokumente.
- [ ] Geburtsdaten nur als Tag und Monat und nur im privaten Bereich ([Geburtstage und Familientermine](../familienseiten/geburtstage-und-familientermine.md)).
- [ ] Standortdaten vor dem Hochladen aus Fotos entfernt ([Viele Bilder hochladen](../portfolios/viele-bilder-hochladen.md)).
- [ ] Hintergründe geprüft: Hausnummern, Autokennzeichen, Schullogos.
- [ ] Gesichter oder Namensschilder bei Bedarf verpixelt ([Bilder mit ezie bearbeiten](../portfolios/bilder-mit-ezie-bearbeiten.md)).
- [ ] Kein Foto hochgeladen, das Schaden anrichten würde, wenn seine Adresse bekannt würde (Bilddateien werden direkt ausgeliefert).

## Konten

- [ ] Jede Person hat ein persönliches Konto; keine gemeinsame Familienanmeldung ([Familienmitglieder einladen](../familienseiten/familienmitglieder-einladen.md)).
- [ ] Leser haben nur Leserechte; Beitragende nur das, was sie brauchen.
- [ ] Zweistufige Anmeldung für Administratoren und Beitragende ([Zwei-Faktor-Anmeldung](../im-betrieb/zwei-faktor-anmeldung.md)).
- [ ] Registrierung geschlossen, oder sie landet in einer Gruppe ohne Zugriff.
- [ ] Konten von Personen, die den Familienkreis verlassen haben, deaktiviert.

## Der private Bereich

- [ ] In einem privaten Browserfenster getestet: Es wird zur Anmeldung aufgefordert ([Private Bereiche mit Rollen und Sektionen](../familienseiten/private-bereiche-mit-rollen-und-sektionen.md#als-fremder-testen)).
- [ ] Die Suche der Website zeigt Fremden keine privaten Inhalte.
- [ ] Kein RSS-Export umfasst private Inhalte.
- [ ] Private Inhalte nicht in der Sitemap.
- [ ] Vollständig private Website, falls gewählt: `RequireUserLogin=true` wirkt auf jeder Seite.

## Daten, die die Website verlassen

- [ ] Sicherungen verschlüsselt oder dort aufbewahrt, wo nur Sie und Ihre Vertretung herankommen ([Sicherungen für eine Person](../im-betrieb/sicherungen-fuer-eine-person.md)).
- [ ] Alte Sicherungsgenerationen gelöscht.
- [ ] Externe Dienste aufgelistet: Analyse, Karten, Videos, CAPTCHA, KI-Anbieter; wird jeder gebraucht?
- [ ] Der Schreibassistent nicht für private Familieninhalte verwendet oder auf ein lokales Modell beschränkt ([Der Schreibassistent](../im-betrieb/schreibassistent-expai.md)).
- [ ] Exporte (CSV) von Familiendaten nicht auf gemeinsam genutzten Laufwerken liegen gelassen.

## Anfragen und Fehler

- [ ] Sie wissen, wie Sie ein Objekt vollständig entfernen, einschließlich alter Versionen und des Papierkorbs ([Veröffentlichen und Versionen](../../veroeffentlichen-und-versionen.md)).
- [ ] Sie wissen, wie Sie ein Konto deaktivieren und Passwörter zurücksetzen.
- [ ] Eine Vertretung kann beides, wenn Sie nicht da sind.

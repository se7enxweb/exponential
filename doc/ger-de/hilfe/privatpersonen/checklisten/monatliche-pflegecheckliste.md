# Monatliche Pflegecheckliste

Diese Seite ist für Privatpersonen, die eine Website allein am Laufen halten. Erledigen Sie sie jeden Monat am
selben Tag; wenn nichts schiefgeht, dauert sie etwa eine Stunde. Notieren Sie am Ende das Datum und alles
Ungewöhnliche.

## Inhalt

1. [Jeden Monat](#jeden-monat)
2. [Zweimal im Jahr](#zweimal-im-jahr)
3. [Einmal im Jahr](#einmal-im-jahr)
4. [Ihr Protokoll](#ihr-protokoll)

## Jeden Monat

### Updates

- [ ] Gibt es eine neue Exponential-Version oder eine Sicherheitskorrektur? ([Updates für eine Person](../im-betrieb/updates-fuer-eine-person.md))
- [ ] **Setup > Upgrade-Prüfung** zeigt keine unerwarteten Abweichungen ([Die Upgrade-Prüfung](../../../anleitungen/upgrade-pruefung.md)).
- [ ] Hat Ihr Hoster eine PHP-Änderung angekündigt? ([PHP-Versionen und Erweiterungen](../../hosting/grundlagen/php-versionen-und-erweiterungen.md))

### Sicherungen

- [ ] Die automatischen Sicherungen sind gelaufen (prüfen Sie das neueste Datum) ([Sicherungen für eine Person](../im-betrieb/sicherungen-fuer-eine-person.md)).
- [ ] Die neueste Sicherung vom Server wegkopiert.
- [ ] Alte Generationen wie geplant gelöscht.

### Konten und Besucher

- [ ] Neue Konten: alle bekannt? Unbekannte entfernt ([Grundlagen zu Spam und Sicherheit](../im-betrieb/grundlagen-zu-spam-und-sicherheit.md)).
- [ ] Personen, die keinen Zugriff mehr haben sollen, deaktiviert ([Familienmitglieder einladen](../familienseiten/familienmitglieder-einladen.md#wenn-jemand-keinen-zugriff-mehr-haben-soll)).
- [ ] Kommentare und Formulareinsendungen gelesen; Spam entfernt; alte Einsendungen planmäßig gelöscht.

### Zustand

- [ ] Startseite, eine tief liegende Seite, Anmeldung und ein Formular funktionieren.
- [ ] Fehlerprotokoll angesehen ([Protokolle für Inhaber](../../kunden/gesund-halten/logs-fuer-betreiber.md)).
- [ ] Defekte Links geprüft ([Link- und Inhaltsprüfungen](../../ersteller/website-ersteller/link-und-inhaltspruefungen.md)).
- [ ] Das Schloss im Browser: Das Zertifikat ist gültig.
- [ ] E-Mails von der Website kommen weiterhin an (schicken Sie sich selbst eine Nachricht über das Kontaktformular).
- [ ] Cron ist gelaufen, falls Sie es nutzen (die Cronjob-Seite zeigt die letzten Läufe) ([Cronjobs](../../../anleitungen/cronjobs.md)).

### Inhalte

- [ ] Ist etwas auf Startseite, Über mich, Kontakt oder im Kalender veraltet?
- [ ] Vergessene Entwürfe: veröffentlichen oder verwerfen ([Entwürfe und Ausstehendes](../../../anleitungen/entwuerfe-und-ausstehende-objekte.md)).
- [ ] Der Papierkorb: Leeren Sie, was wirklich weg soll ([Archivieren und der Papierkorb](../../kunden/alltag/archivieren-und-der-papierkorb.md)).

## Zweimal im Jahr

- [ ] Eine Sicherung auf einem anderen Rechner wiederherstellen ([Wiederherstellungstest](../../kunden/gesund-halten/wiederherstellungstest.md)).
- [ ] Rollen und Gruppen prüfen; niemand hat mehr Rechte als nötig.
- [ ] Tags prüfen; Duplikate zusammenführen ([Tags und Kategorien](../blogs/tags-und-kategorien.md)).
- [ ] Vereinsseiten: Mitglieder mit der Liste des Vereins abgleichen ([Mitglieder und Registrierung](../vereinsseiten/mitglieder-und-registrierung.md)).

## Einmal im Jahr

- [ ] Verlängerungsdatum der Domain geprüft; Zahlungsmittel aktuell ([Domainnamen und HTTPS](../einrichtung/domainnamen-und-https.md)).
- [ ] Hostingvertrag und Kosten überprüft ([Mit kleinem Budget betreiben](../einrichtung/mit-kleinem-budget-betreiben.md)).
- [ ] Texte für Über mich, Kontakt und Datenschutz erneut gelesen.
- [ ] Familienseiten: erneut die [Checkliste zur Privatsphäre der Familie](checkliste-zur-privatsphaere-der-familie.md).
- [ ] Die Vertretung weiß noch, wo die Sicherungen und Passwörter liegen.

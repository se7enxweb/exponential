# Checklisten für Privatpersonen

Dieser Bereich ist für Privatpersonen, die gern nach einer Liste arbeiten. Jede Checkliste ist kurz genug, um auf
eine oder zwei Seiten gedruckt zu werden, und jede Zeile verweist auf die Seite, die sie erklärt.

## Inhalt

1. [Die Checklisten](#die-checklisten)
2. [Wann welche passt](#wann-welche-passt)
3. [Passen Sie sie an](#passen-sie-sie-an)

## Die Checklisten

| Checkliste | Verwenden Sie sie |
|---|---|
| [Arbeitsblatt für die Websiteplanung](arbeitsblatt-fuer-die-websiteplanung.md) | Vor der Installation: Zweck, Leser, Seiten, Privatsphäre, Budget |
| [Startcheckliste für Privatpersonen](startcheckliste-fuer-privatpersonen.md) | Am Tag, an dem Sie online gehen |
| [Monatliche Pflegecheckliste](monatliche-pflegecheckliste.md) | Einmal im Monat, etwa eine Stunde |
| [Checkliste zur Privatsphäre der Familie](checkliste-zur-privatsphaere-der-familie.md) | Bevor eine Familienseite online geht, und danach einmal im Jahr |

## Wann welche passt

| Phase | Checkliste |
|---|---|
| Eine Idee | Arbeitsblatt für die Websiteplanung |
| Auf Ihrem Computer gebaut | Startcheckliste, Abschnitt „Vor dem Umzug zum Hoster" |
| Online, bevor Sie es jemandem erzählen | Startcheckliste, der Rest |
| Danach jeden Monat | Monatliche Pflegecheckliste |
| Eine Familienseite | Zusätzlich die Checkliste zur Privatsphäre der Familie |

## Passen Sie sie an

Kopieren Sie eine Checkliste in einen privaten Artikel auf Ihrer Website oder in Ihre Notizen und ändern Sie sie:
Entfernen Sie Zeilen, die nicht zutreffen, und ergänzen Sie eigene (das Verlängerungsdatum Ihrer Domain, den Namen
Ihrer Vertretung). Die Dokumentation darf frei kopiert und angepasst werden
([Freie Dokumentation](../../freie-dokumentation.md)).

Weitere Checklisten in dieser Hilfe, die passen könnten: [Startcheckliste (Website-Ersteller)](../../ersteller/website-ersteller/checkliste-fuer-den-start.md),
[Sicherheitscheckliste für Inhaber](../../kunden/gesund-halten/sicherheits-checkliste-fuer-betreiber.md),
[Checkliste für kleine Gruppen](../../unternehmen/vereine/checkliste-fuer-kleine-gruppen.md),

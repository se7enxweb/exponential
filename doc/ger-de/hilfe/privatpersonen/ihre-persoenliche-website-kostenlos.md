# Ihre persönliche Website kostenlos

Sie möchten ein Blog, eine Website für Ihren Verein oder Ihre Familie oder eine Seite über Ihr Hobby, und Sie möchten
weder für Hosting zahlen noch einen Server betreuen. Statisches Veröffentlichen gibt Ihnen das: Sie schreiben in
Exponential, und eine statische Kopie Ihrer Website wird kostenlos auf GitHub Pages gehostet.

## Was Sie am Ende haben

- Ihre Website online unter `https://<ihr-name>.github.io/<repository>/` oder unter Ihrer eigenen Domain.
- Schreiben und Bearbeiten in Exponential, mit seinem Editor, Bildern und Seiten, wie bisher.
- Jede Veröffentlichung bleibt erhalten: Sie können immer zu einer früheren zurück.

## Wie es für Sie funktioniert

1. Exponential kann auf Ihrem eigenen Rechner oder einem kleinen Server laufen; nur die Kopie ist öffentlich.
2. Wenn Sie mit einer Änderung zufrieden sind, **bauen** Sie die Website, sehen nach, was sich geändert hat, und
   **veröffentlichen** sie.
3. GitHub Pages liefert die Kopie an Ihre Besucher aus. Sie ist schnell und bleibt erreichbar.

Ihr Rechner muss nicht laufen, damit die Website online ist.

## Was eine statische Website nicht kann

- **Kommentare und Gästebücher:** Besucher können nichts an eine statische Kopie senden. Sie können sie ausblenden oder
  auf die Live-Seite verlinken.
- **Mitgliederbereiche:** Eine Seite, die nur angemeldete Mitglieder sehen, wird nie kopiert. Siehe
  [Private Inhalte privat halten](../statisches-veroeffentlichen/private-inhalte-privat-halten.md).
- **Suche:** funktioniert, mit einer kleinen Suchseite, die im Browser des Besuchers läuft.

Mehr in [Was statisches Veröffentlichen ist](../statisches-veroeffentlichen/was-statisches-veroeffentlichen-ist.md).

## Kosten

- GitHub Pages: kostenlos für öffentliche Repositorys.
- Eine eigene Domain: freiwillig, ein paar Euro im Jahr. Siehe [Eigene Domain verwenden](../statisches-veroeffentlichen/eigene-domain-verwenden.md).

# Eine persönliche Website planen

Diese Seite ist für Privatpersonen, die gleich eine persönliche Website anlegen und entscheiden möchten, was darauf
kommt, bevor sie etwas installieren. Eine Stunde Planung erspart ein Wochenende Umbau. Tragen Sie Ihre Antworten in
das [Arbeitsblatt für die Websiteplanung](../checklisten/arbeitsblatt-fuer-die-websiteplanung.md) ein.

## Der Zweck in einem Satz

Vervollständigen Sie diesen Satz: „Diese Website gibt es, damit ___ ___ kann." Zum Beispiel: „damit Menschen, die
mich auf Konferenzen treffen, meine Vorträge finden und mich kontaktieren können" oder „damit Kunden meine
Illustrationen sehen können". Wenn Sie zwei Sätze brauchen, brauchen Sie vielleicht zwei Bereiche der Website; wenn
Sie fünf brauchen, beginnen Sie mit dem wichtigsten.

## Leser

| Frage | Warum sie zählt |
|---|---|
| Wer liest sie zuerst? | Entscheidet, was die Startseite sagt |
| Was möchten die Leser tun? | Lesen, Bilder ansehen, Sie kontaktieren, einen Lebenslauf herunterladen |
| Auf welchem Gerät? | Die meisten Leser nutzen ein Smartphone; prüfen Sie jede Seite in Smartphone-Breite |
| In welcher Sprache? | Eine Sprache ist einfacher; eine zweite ist von Anfang an möglich ([Mehrsprachige Websites](../../ersteller/website-ersteller/mehrsprachige-websites.md)) |
| Wer darf etwas *nicht* sehen? | Führt zu einem privaten Bereich ([Private Bereiche](../familienseiten/private-bereiche-mit-rollen-und-sektionen.md)) |

## Die Seitenliste

Halten Sie die erste Fassung klein. Fünf bis acht Seiten sind reichlich:

1. Startseite
2. Über mich
3. Arbeiten (oder Projekte oder Vorträge)
4. Texte (später ein Blog)
5. Kontakt
6. Impressum und Datenschutz, wo vorgeschrieben

Zeichnen Sie sie als Baum: Jede Seite ist ein Knoten, und das Menü folgt dem Baum
([Den Inhaltsbaum strukturieren](../../ersteller/website-ersteller/den-inhaltsbaum-strukturieren.md),
[Sitemap und Inhaltsinventar](../../ersteller/website-ersteller/sitemap-und-inhaltsbestandsaufnahme.md)).

## Was Sie über sich veröffentlichen

Eine persönliche Website handelt von einem echten Menschen: von Ihnen. Entscheiden Sie bewusst:

- **E-Mail-Adresse**: Nutzen Sie ein Kontaktformular, statt sie abzudrucken; Formulare halten sie von
  Adresssammlern fern ([Über-mich-Seite und Kontaktformular](ueber-mich-seite-und-kontaktformular.md)).
- **Wohnadresse und Telefon**: nur, wenn Ihr Recht sie für eine Website Ihrer Art verlangt, und dann prüfen Sie, was
  das Minimum ist.
- **Fotos**: von Ihnen, gern, wenn Sie möchten; von anderen Menschen nur mit deren Einwilligung.
- **Arbeitgeber, Familie, Kinder, Tagesabläufe**: Denken Sie darüber nach, wer diese Angaben kombinieren könnte.
- **Alte Inhalte**: Eine Seite lässt sich später verbergen oder in den Papierkorb verschieben; Suchmaschinen und
  Archive behalten womöglich Kopien.

Die Regeln Ihres Landes zu Impressum und Datenschutz gelten für Sie auch auf einer Hobby-Website. Diese Hilfe erklärt
Funktionen, nicht Recht; einen Überblick gibt [DSGVO-Grundlagen](../../unternehmen/sicherheit/dsgvo-grundlagen.md).

## Inhaltsklassen wählen

Das Standard-Seitenpaket enthält bereits die Klassen, die die meisten persönlichen Websites brauchen:

| Seite | Klasse | Warum |
|---|---|---|
| Startseite | *Frontpage* oder *Folder* | Listet auf, was darunter liegt |
| Über mich, Rechtliches | *Article* | Titel, Einleitung, Text, Bild |
| Arbeiten | *Folder* mit *Article* oder *Gallery* | Ein Element pro Projekt |
| Texte | *Blog* mit *Blog post* | Daten, Tags, Feeds |
| Kontakt | *Feedback form* | Speichert und mailt Nachrichten |

Neue Klassen brauchen Sie nur, wenn Ihre Arbeiten Felder haben, die diese nicht haben (ein Jahr, eine Technik, ein
Auftraggeber). Lesen Sie dann [Ihr Inhaltsmodell entwerfen](../../ersteller/website-ersteller/ihr-inhaltsmodell-entwerfen.md).

## Ein Rhythmus, den Sie halten können

| Wie oft | Was tun |
|---|---|
| Wenn etwas passiert | Den Vortrag, das Projekt, den Beitrag hinzufügen |
| Monatlich | Die [monatliche Pflegecheckliste](../checklisten/monatliche-pflegecheckliste.md): Updates, Sicherung, defekte Links |
| Jährlich | Über mich und Kontakt erneut lesen; die Domain verlängern |

Eine kleine, aktuelle Website ist besser als eine große, veraltete.

## Ein durchgespieltes Beispiel

Ein erfundenes Beispiel. Zweck: „damit Menschen, die einen meiner Vorträge gehört haben, die Folien finden und mich
kontaktieren können".

| Seite | Klasse | Anmerkungen |
|---|---|---|
| Startseite | *Folder* | Einleitung in einem Satz, die drei neuesten Vorträge |
| Vorträge | *Folder* | Ein *Article* pro Vortrag mit einer *File* für die Folien |
| Über mich | *Article* | Kurze Biografie, ein Foto |
| Kontakt | *Feedback form* | Nachrichten gehen an ein privates Postfach |
| Datenschutz | *Article* | Was das Kontaktformular speichert und wie lange |

Fünf Seiten, keine neuen Klassen, ein Abend Schreibarbeit. Das Blog kann später kommen.

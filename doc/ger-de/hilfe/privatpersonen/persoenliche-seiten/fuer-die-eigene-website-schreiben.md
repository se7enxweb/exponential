# Für die eigene Website schreiben

Diese Seite ist für Privatpersonen, die die Seiten ihrer eigenen Website schreiben. Niemand redigiert Ihre Texte;
ein paar Gewohnheiten übernehmen daher die Arbeit eines Lektorats. Sie gelten gleichermaßen für eine Über-mich-Seite,
eine Projektbeschreibung und einen Blogbeitrag.

## Wie Menschen eine Seite lesen

Die meisten Besucher überfliegen: den Titel, den ersten Satz, die Überschriften, vielleicht ein Bild. Dann
entscheiden sie, ob sie weiterlesen. Oft kommen sie auf einem Smartphone, aus einem Suchergebnis oder einem Feed,
nicht von Ihrer Startseite. Jede Seite muss für sich allein verständlich sein.

## Titel

- Sagen Sie in einfachen Worten, worum es auf der Seite geht: „Illustrationen für Kinderbücher, 2024 bis 2026"
  statt „Arbeiten".
- Halten Sie sie so kurz, dass sie in ein Suchergebnis und ein Menü passen.
- Aus dem Titel wird die Adresse der Seite; ein klarer Titel ergibt also eine klare Adresse
  ([URL-Aliase und sprechende URLs](../../ersteller/website-ersteller/url-aliasse-und-sprechende-urls.md)).

## Die Einleitung

Die Klasse *Article* und ähnliche Klassen haben ein Feld für Einleitung oder Zusammenfassung. Es wird in Listen, in
Feeds und oft in Suchergebnissen angezeigt. Schreiben Sie es zuletzt, in ein oder zwei Sätzen, damit auch jemand, der
sonst nichts sieht, das Wesentliche erfährt.

## Der Text

| Tun Sie | Warum |
|---|---|
| Ein Gedanke pro Absatz | Auf einem Smartphone gut zu überfliegen |
| Alle paar Absätze eine Überschrift | Leser springen; Screenreader navigieren über Überschriften |
| Listen für Schritte und Möglichkeiten | Leichter als lange Sätze |
| Einfache Wörter, kurze Sätze | Leser in einer Fremdsprache danken es Ihnen |
| Daten, wo Zeit eine Rolle spielt („Stand März 2026") | Seiten werden noch Jahre später gelesen |

Der Rich-Text-Editor speichert Überschriften, Listen und Links als Struktur, nicht als Formatierung
([Inhalte bearbeiten](../../inhalte-bearbeiten.md)). Verwenden Sie echte Überschriften, keine fetten Zeilen.

## Links und Bilder

- **Der Linktext sagt, wohin er führt**: „die Folien meines Vortrags von 2026", nicht „hier klicken".
- **Verlinken Sie innerhalb Ihrer Website mit dem Link-Werkzeug des Editors**, damit Links einer Seite folgen, die
  verschoben wird.
- **Jedes Bild braucht einen Alternativtext**, der sagt, was das Bild zeigt oder bewirkt. Dekorative Bilder können
  ohne auskommen.
- **Laden Sie Bilder groß genug hoch, aber nicht riesig**; die Website erzeugt selbst kleinere Kopien
  ([Bildvarianten für Portfolios](../portfolios/bildvarianten-fuer-portfolios.md)).
- **Veröffentlichen Sie nur Bilder, die Sie veröffentlichen dürfen**: eigene, lizenzierte und Fotos von Menschen,
  die zugestimmt haben.

Mehr dazu unter [Barrierefreiheit für Website-Ersteller](../../ersteller/website-ersteller/barrierefreiheit-fuer-website-ersteller.md).

## Adressen

Wählen Sie vor dem Veröffentlichen einen Titel, mit dem Sie leben können; die Adresse folgt ihm. Wenn Sie eine Seite
später umbenennen oder verschieben, hält Exponential die alte Adresse in den meisten Fällen als Weiterleitung
funktionsfähig, und Sie können selbst Weiterleitungen hinzufügen
([Weiterleitungen und verschobene Inhalte](../../ersteller/website-ersteller/weiterleitungen-und-verschobene-inhalte.md)).

## Aktualisieren statt anhäufen

Eine persönliche Website altert still. Lesen Sie einmal im Jahr Über mich, Kontakt und Ihre Projektliste erneut. Wenn
eine Seite veraltet ist, aktualisieren Sie sie und schreiben Sie oben eine Zeile dazu, was sich wann geändert hat.
Entfernen Sie Seiten, hinter denen Sie nicht mehr stehen; verschieben Sie sie in den Papierkorb, statt sie sofort zu
löschen, damit Sie es sich anders überlegen können
([Archivieren und der Papierkorb](../../kunden/alltag/archivieren-und-der-papierkorb.md)).

## Ihr Sicherheitsnetz

- **Entwürfe** sind privat, bis Sie veröffentlichen.
- **Jedes Veröffentlichen ist eine Version**; Sie können vergleichen und zurückgehen
  ([Veröffentlichen und Versionen](../../veroeffentlichen-und-versionen.md)).
- **Die Vorschau** vor dem Veröffentlichen zeigt die Seite so, wie Besucher sie sehen werden.
- **Zeitgesteuertes Veröffentlichen** lässt eine Seite später erscheinen ([Zeitgesteuertes Veröffentlichen](../../kunden/alltag/zeitgesteuertes-veroeffentlichen.md)).
- **Der Schreibassistent** kann eine kürzere Einleitung oder einen klareren Titel vorschlagen, als Entwurf, den Sie
  prüfen ([Der Schreibassistent](../im-betrieb/schreibassistent-expai.md)).

## Bevor Sie auf Veröffentlichen klicken

- [ ] Der Titel sagt, worum es auf der Seite geht.
- [ ] Die Einleitung funktioniert für sich allein.
- [ ] Überschriften, kurze Absätze, Listen, wo sinnvoll.
- [ ] Jeder Link hat einen aussagekräftigen Text und funktioniert.
- [ ] Jedes Bild hat einen Alternativtext, und Sie dürfen es veröffentlichen.
- [ ] Nichts Persönliches, das Sie einem Fremden nicht erzählen würden.
- [ ] Die Vorschau sieht in einem schmalen Fenster richtig aus.

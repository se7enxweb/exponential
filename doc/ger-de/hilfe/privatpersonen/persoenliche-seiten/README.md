# Persönliche Websites

Dieser Bereich ist für Privatpersonen, die ein eigenes Zuhause im Web möchten: eine Seite, die sagt, wer Sie sind,
was Sie tun, was Sie geschrieben oder geschaffen haben und wie man Sie erreichen kann. Später kann daraus ein Blog,
ein Portfolio oder ein privater Bereich wachsen; jedes davon beginnt mit derselben kleinen Website.

## Was eine persönliche Website meist enthält

| Teil | Zweck | Typische Inhaltsklasse |
|---|---|---|
| Startseite | Der erste Eindruck: ein Satz über Sie, ein Foto, Links zum Rest | *Frontpage* oder *Folder* |
| Über mich | Ihre Geschichte, was Sie tun, was Sie suchen | *Article* |
| Arbeiten oder Projekte | Was Sie geschaffen haben, mit Bildern | *Folder* mit *Article*- oder *Gallery*-Elementen |
| Texte | Notizen, Essays oder ein Blog | *Blog* mit *Blog post*-Elementen |
| Kontakt | Ein Formular, damit Sie Ihre E-Mail-Adresse nicht veröffentlichen | *Feedback form* |
| Rechtliches | Wer die Website betreibt, ein Datenschutzhinweis, wo Ihr Recht einen verlangt | *Article* |

Die Klassennamen sind die des Standard-Seitenpakets; siehe
[Inhaltsklassen für Websites](../../ersteller/website-ersteller/inhaltsklassen-fuer-websites.md).

## Was sie in Exponential trägt

- **Ordner und Artikel** bilden die Seiten; das Menü wird aus dem Inhaltsbaum erzeugt
  ([Menüs und Navigation](../../ersteller/website-ersteller/menues-und-navigation.md)).
- **Die Klasse *Feedback form*** ist ein fertiges Kontaktformular, dessen Antworten gespeichert und an einen
  Empfänger gemailt werden ([Ein Kontaktformular bauen](../../ersteller/website-ersteller/ein-kontaktformular-bauen.md)).
- **Lesbare Adressen** entstehen aus den Seitennamen ([URL-Aliase und sprechende URLs](../../ersteller/website-ersteller/url-aliasse-und-sprechende-urls.md)).
- **Grundlagen für Suchmaschinen**: Titel, Beschreibungen und eine Sitemap ([SEO-Grundlagen](../../ersteller/website-ersteller/seo-grundlagen.md)).
- **Ein Theme**: das Standarddesign `sevenx_themes_simple` ([Ein Seitenpaket und ein Theme wählen](../setup/ein-seitenpaket-und-ein-theme-waehlen.md)).

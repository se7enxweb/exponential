# Glossar für die Community

| Begriff | Bedeutung | Mehr |
|---|---|---|
| **7x** | Das nordamerikanische Unternehmen, das Entwicklung, Support und Hosting von Exponential leitet | [Wer ist 7x?](../wer-ist-7x.md) |
| **Fürsprecher** | Ein Community-Mitglied, das über Exponential spricht, schreibt oder präsentiert | [Fürsprecher: hier beginnen](../fuersprecher/fuersprecher-hier-beginnen.md) |
| **CLA** | Das 7x Contributor Licensing Agreement; wer es unterschreibt und Kernel-Code einreicht, überträgt das Urheberrecht an diesem Code an die Exponential Foundation und 7x | [Das CLA erklärt](mitwirken/das-cla-erklaert.md) |
| **Verhaltenskodex** | Der Contributor Covenant 2.1 mit Exponential-Ergänzungen, verbindlich in allen Räumen der Community | [Der Verhaltenskodex](beitreten/der-verhaltenskodex.md) |
| **Community** | Die Menschen, die Exponential weltweit nutzen, dazu beitragen, dafür werben und Software damit entwickeln | [Was die Community ist](was-die-community-ist.md) |
| **Beitragstag** | Einige Stunden, in denen eine Gruppe gemeinsam echte Beiträge leistet | [Ein Beitragstag](lokale-gruppen/ein-beitragstag.md) |
| **dev-main** | Der Composer-Name des Branches `main`, der Entwicklungslinie, in der Korrekturen zuerst landen | [Wie Releases entstehen](so-funktioniert-es/wie-releases-entstehen.md) |
| **Ökosystem** | Die größere Exponential-Welt im PHP-Stack: ihre Nutzer und Ersteller | [Ökosystem: hier beginnen](../../../eng-us/help/ecosystem/ecosystem-start-here.md) |
| **Exponential Foundation** | Die gemeinnützige Organisation, gegründet am 19. März 2026, die das Projekt betreibt | [Wer ist die Exponential Foundation?](../wer-ist-die-exponential-foundation.md) |
| **eZpedia** | Eine Community-Enzyklopädie unter der GNU FDL, seit 2006 | [Zu eZpedia beitragen](../fuersprecher/zu-ezpedia-beitragen.md) |
| **Fork** | Ihre eigene Kopie eines Repositorys auf GitHub, aus der Sie Pull Requests senden | [Code beitragen](mitwirken/code-beitragen.md) |
| **GNU FDL** | Die GNU Free Documentation License 1.3 oder neuer, die Lizenz der Dokumentation | [Freie Dokumentation](../freie-dokumentation.md) |
| **GPL** | Die GNU General Public License Version 2 oder neuer, die Lizenz des Codes | [Lizenzen in der Community](so-funktioniert-es/lizenzen-in-der-community.md) |
| **Maintainer** | Jemand, der dafür verantwortlich ist, ein Repository oder einen Bereich funktionsfähig zu halten: Issues, Reviews, Releases | [Vom Mitwirkenden zum Maintainer](lernpfade/vom-mitwirkenden-zum-maintainer.md) |
| **Manifest** | `share/filelist.md5`, die Liste der Dateien und Prüfsummen, die jeder Commit aktuell hält (`make manifest-fix`) | [Code beitragen](mitwirken/code-beitragen.md) |
| **Partner** | Ein Unternehmen im Exponential-Partnerprogramm, das das Projekt finanziert, Beiträge zurückgibt und direkt mit 7x und der Foundation zusammenarbeitet | [Partner: hier beginnen](../partner/partner-hier-beginnen.md) |
| **Projects** | projects.exponential.earth, wo Community-Projekte und Erweiterungen aufgeführt sind | [Wo sich Menschen treffen](beitreten/wo-sich-menschen-treffen.md) |
| **Pull Request** | Eine vorgeschlagene Änderung auf GitHub, die vor dem Mergen geprüft wird | [Code beitragen](mitwirken/code-beitragen.md) |
| **Review-Runde** | Ein Durchgang aus Kommentaren und Überarbeitungen an einem Pull Request | [Reviews geben und erhalten](mitwirken/reviews-geben-und-erhalten.md) |
| **Share** | share.exponential.earth, das Community-Portal mit Foren, Blogs und Artikeln | [Wo sich Menschen treffen](beitreten/wo-sich-menschen-treffen.md) |
| **Sponsor** | Eine Person oder ein Unternehmen, die 7x oder die Foundation finanziert, zum Beispiel über GitHub Sponsors | [Sponsoren: hier beginnen](../sponsoren/sponsoren-hier-beginnen.md) |
| **Squash und Rebase** | Die Commits eines Pull Requests zu logischen Commits zusammenfassen und sie auf den aktuellen Stand von `main` verschieben | [Reviews geben und erhalten](mitwirken/reviews-geben-und-erhalten.md) |
| **Unterstützer** | Alle, die dem Projekt mit Zeit oder Geld helfen | [Unterstützer: hier beginnen](../unterstuetzer/unterstuetzer-hier-beginnen.md) |
| **Tag** | Eine benannte Release-Version in Git; ein veröffentlichter Tag wird nie geändert | [Wie Releases entstehen](so-funktioniert-es/wie-releases-entstehen.md) |
| **Tracker** | Eine Issue-Liste auf GitHub: für die Software, für Velocity, für die Community | [Einen Fehler melden](mitwirken/einen-fehler-melden.md) |

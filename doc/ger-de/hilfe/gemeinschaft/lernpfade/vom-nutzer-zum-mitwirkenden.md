# Vom Nutzer zum Mitwirkenden

Alle Mitwirkenden haben als Nutzer angefangen, denen etwas aufgefallen ist, das besser sein könnte.

## Bemerken

Nutzer sehen, was erfahrene Mitwirkende nicht mehr sehen: eine verwirrende Beschriftung, einen fehlenden Schritt in
einer Anleitung, einen Fehler, der nur auf ihrer Einrichtung auftritt. Führen Sie bei der Arbeit eine kurze Liste.
Jeder Eintrag ist ein möglicher Beitrag.

## Die ersten drei Beiträge

| # | Vorschlag | Seite |
|---|---|---|
| 1 | Etwas ohne Code: eine Korrektur einer Hilfeseite, ein bestätigter Fehler, eine Übersetzung | [Ihr erster Beitrag](../mitwirken/ihr-erster-beitrag.md) |
| 2 | Noch einmal dieselbe Art, etwas größer | [Wege mitzuwirken](../mitwirken/wege-mitzuwirken.md) |
| 3 | Etwas, das ein Review braucht: ein Pull Request mit Test, eine neue Hilfeseite, ein übersetzter Abschnitt | [Code beitragen](../mitwirken/code-beitragen.md) |

## Einen Bereich wählen

Mitwirkende, die bei einem Bereich bleiben, lernen ihn gründlich kennen und genießen dort Vertrauen. Beispiele für
Bereiche:

- die Übersetzung einer Sprache;
- die Hilfeseiten für eine Rolle (Redakteure, Administratoren);
- eine Erweiterung, die Sie täglich nutzen;
- ein Teil der Administration;
- die Installation auf einer Art von Server oder Datenbank.

## Vertrauen aufbauen

- Bringen Sie zu Ende, was Sie beginnen, oder sagen Sie klar, dass Sie aufgehört haben.
- Folgen Sie den Regeln von `CONTRIBUTING.md`, ohne erinnert zu werden: Commit-Nachrichten mit Präfix, das Manifest,
  Tests, Squash und Rebase.
- Beantworten Sie Review-Kommentare zügig und höflich.
- Helfen Sie Neulingen in Ihrem Bereich ([Neue Mitglieder willkommen heißen](../anderen-helfen/neue-mitglieder-willkommen-heissen.md)).

## Die eigene Arbeit festhalten

Eine Liste Ihrer gemergten Pull Requests, Issues und Antworten ist für Sie nützlich und für alle, die Sie einstellen
möchten. `git shortlog -sn` zeigt die Autoren in der Historie; [Ihre Beiträge festhalten](../../fuersprecher/ihre-beitraege-festhalten.md)
zeigt einen einfachen Weg, eine eigene Liste zu führen.

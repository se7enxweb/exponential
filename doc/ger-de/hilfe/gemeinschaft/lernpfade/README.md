# Wege durch die Community

Menschen machen auf sehr unterschiedliche Weise mit. Diese Seiten beschreiben die üblichen Wege, nach Stufe und nach
Rolle, damit Sie sehen, wie der nächste Schritt von Ihrem Standort aus aussieht.

## Inhalt

1. [Wege nach Stufe](#wege-nach-stufe)
2. [Wege nach Rolle](#wege-nach-rolle)
3. [Kein Weg ist Pflicht](#kein-weg-ist-pflicht)

## Wege nach Stufe

```text
user  ->  contributor  ->  regular contributor  ->  maintainer of an area or extension
                    \                                   \
                     ->  advocate / trainer               ->  partner (for companies)
```

| Seite | Der Schritt |
|---|---|
| [Vom Nutzer zum Mitwirkenden](vom-nutzer-zum-mitwirkenden.md) | Ihre ersten Beiträge und wie sie zur Gewohnheit werden |
| [Vom Mitwirkenden zum Maintainer](vom-mitwirkenden-zum-maintainer.md) | Verantwortung für eine Erweiterung oder einen Bereich übernehmen |
| [Von der Community zum Partner](von-der-community-zum-partner.md) | Wenn ein Unternehmen dem Exponential-Partnerprogramm beitritt |

## Kein Weg ist Pflicht

Viele Menschen nutzen Exponential jahrelang und stellen nur ab und zu eine Frage. Auch das ist Mitmachen. Die Wege
sind für diejenigen da, die mehr möchten.

## Sichere erste Beiträge

| Beitrag | Braucht |
|---|---|
| Einen Tippfehler oder einen unklaren Schritt auf einer Hilfeseite korrigieren | Ein GitHub-Konto |
| Meldungen der Oberfläche in Ihre Sprache übersetzen | Eine zweite Sprache |
| Eine Frage beantworten, die Sie letzte Woche selbst gelöst haben | Geduld |
| Einen Fehler auf Ihrer Testinstallation bestätigen | Eine Testinstallation |
| Eine kleine Code-Korrektur mit einem Test | PHP, Git, Geduld mit dem Review |

[Ihr erster Beitrag](../mitwirken/ihr-erster-beitrag.md) führt durch diese Beiträge.

## Ein öffentliches Portfolio aufbauen

„Echte Beiträge sind das beste Portfolio, das Lernende haben können: Ein gemergter Pull Request ist ein öffentlicher
Nachweis von Können“ ([Partner aus Studium und Bildung](../../partner/partner-fuer-studierende-und-bildung.md)). Führen
Sie eine Liste Ihrer gemergten Pull Requests, Übersetzungen und Hilfeseiten
([Ihre Beiträge festhalten](../../fuersprecher/ihre-beitraege-festhalten.md)).

## Die Partnerstufe Student

Das Partnerprogramm hat eine Stufe Student „für Studierende, Universitäten oder Bildungseinrichtungen“, zu 25 $ im
Monat, wie am 18. Oktober 2026 veröffentlicht, mit „Sandbox-Zugang, Bildungsressourcen und Schulungsunterstützung“;
was der „Sandbox-Zugang“ umfasst, ist nicht beschrieben
([Partner aus Studium und Bildung](../../partner/partner-fuer-studierende-und-bildung.md)). Sie ist freiwillig: Alles andere
auf dieser Seite ist kostenlos.

## Ohne Angst fragen

- Keine Frage ist zu einfach; der Verhaltenskodex schützt Sie vor Spott ([Der Verhaltenskodex](../beitreten/der-verhaltenskodex.md)).
- Sagen Sie, dass Sie lernen; die Menschen passen ihre Antworten an.
- Zeigen Sie, was Sie versucht haben ([Eine gute Frage stellen](../beitreten/eine-gute-frage-stellen.md)).
- Wenn Sie ein KI-Werkzeug verwendet haben, um Code oder eine Antwort zu schreiben, prüfen Sie es und sagen Sie es
  (`CODE_OF_CONDUCT.md`).

# Ihre erste Woche in der Community

Dieser Plan braucht etwa eine halbe Stunde am Tag. Überspringen Sie jeden Tag, der Ihnen nicht passt; die Reihenfolge
zählt mehr als das Tempo.

## Inhalt

1. [Der Plan](#der-plan)
2. [Tag für Tag](#tag-für-tag)
3. [Nach der ersten Woche](#nach-der-ersten-woche)

## Tag für Tag

### Tag 1: die Grundregeln kennen

Lesen Sie `CODE_OF_CONDUCT.md` (die [Zusammenfassung](beitreten/der-verhaltenskodex.md) reicht für den Anfang),
[Wer ist 7x?](../wer-ist-7x.md#kurz-gesagt) und [Wer ist die Exponential Foundation?](../wer-ist-die-exponential-foundation.md#kurz-gesagt).
Jetzt wissen Sie, wer das Projekt leitet, wer es betreibt und wie Menschen miteinander umgehen sollen.

### Tag 2: die Menschen finden

Öffnen Sie die [Foren](https://share.exponential.earth/forums) und lesen Sie die neuesten Themen. Treten Sie dem
[Telegram-Chat](https://t.me/exponentialcms) bei, wenn Sie Gespräche bevorzugen. Beobachten Sie das Repository
[se7enxweb/exponential](https://github.com/se7enxweb/exponential) auf GitHub, wenn Sie Code schreiben.

### Tag 3: es laufen lassen

Nichts ersetzt die Nutzung der Software. Mit SQLite läuft eine vollständige Website aus einer Datei und braucht
keinen Datenbankserver ([Erste Schritte](../erste-schritte.md), [Datenbankunterstützung](../datenbankunterstuetzung.md)).
Machen Sie den [Rundgang durch die Administration](../rundgang-durch-die-administration.md).

### Tag 4: Hallo sagen

Schreiben Sie eine kurze Vorstellung oder stellen Sie die Frage, die an Tag 3 aufkam. Lesen Sie vorher
[Eine gute Frage stellen](beitreten/eine-gute-frage-stellen.md); eine gute Frage bekommt schneller eine gute Antwort.

### Tag 5: etwas bemerken

Sie kennen die Software jetzt ein wenig und haben einen frischen Blick, den erfahrene Mitglieder nicht mehr haben.
Notieren Sie eine Sache, die nicht funktioniert hat, einen Schritt, den die Dokumentation ausgelassen hat, oder ein
Wort, das nicht übersetzt war.

### Tag 6: etwas zurückgeben

Machen Sie aus Tag 5 einen Beitrag: einen Fehlerbericht, eine über „Auf GitHub bearbeiten“ korrigierte Hilfeseite oder
eine Übersetzung. [Ihr erster Beitrag](mitwirken/ihr-erster-beitrag.md) führt durch jeden davon.

### Tag 7: eine Richtung wählen

Sehen Sie sich die [Lernpfade](lernpfade/README.md) an und wählen Sie den passenden: Redakteur, Entwickler, Designer,
Hoster, Lernende. Notieren Sie ihn zusammen mit einem Ziel für den nächsten Monat.

## Nach der ersten Woche

- Führen Sie eine kurze Liste darüber, was Sie beigetragen haben ([Ihre Beiträge festhalten](../fuersprecher/ihre-beitraege-festhalten.md)).
- Helfen Sie dem nächsten Neuling so, wie Ihnen geholfen wurde ([Neue Mitglieder willkommen heißen](anderen-helfen/neue-mitglieder-willkommen-heissen.md)).
- Wenn Sie bereit für mehr sind, lesen Sie [Vom Nutzer zum Mitwirkenden](lernpfade/vom-nutzer-zum-mitwirkenden.md).

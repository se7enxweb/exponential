# Eine kostenlose Website für Ihre User Group

Eine User Group braucht einen Ort für das nächste Treffen, die Vorträge, die Folien und die Frage, wie man mitmacht.
Mit statischem Veröffentlichen kostet dieser Ort nichts, und er ist mit der Software gemacht, um die es in der Gruppe geht.

## Was Sie am Ende haben

- Die Website der Gruppe unter `https://<gruppe>.github.io/` oder unter der Domain der Gruppe.
- Eine GitHub-Organisation, die der Gruppe gehört und nicht einer einzelnen Person, mit jeder Veröffentlichung im Verlauf.
- Ein funktionierendes Beispiel für Exponential, das Sie bei jedem Treffen zeigen können.

## Wie Sie es organisieren

1. Legen Sie eine GitHub-Organisation für die Gruppe mit zwei oder drei Eigentümern an.
2. Betreiben Sie die Exponential-Installation dort, wo ein Organisator sie hosten kann: ein kleiner Server, ein Laptop
   oder CI aus der Starter-Vorlage [exponential-static-site-starter](https://github.com/se7enxweb/exponential-static-site-starter).
3. Geben Sie jedem Organisator ein Redakteurskonto und einem oder zweien die Richtlinie zum Veröffentlichen.
4. Legen Sie das Ziel mit dem Assistenten an und veröffentlichen Sie.

## Inhalte, die gut funktionieren

- Eine Veranstaltung pro Treffen, mit Datum, Ort, Vorträgen und einem Link zur Karte.
- Seiten für Vortragende mit den Folien als Downloads.
- Eine Seite „Mitmachen“ mit Link zum Chat oder zur Mailingliste der Gruppe.
- Neuigkeiten, und eine Seite in einer zweiten Sprache, wenn Ihre Gruppe sie braucht.

## Was tun mit Anmeldungen

Eine statische Seite kann keine Anmeldungen annehmen. Verlinken Sie den Veranstaltungsdienst, den Sie nutzen, oder
lassen Sie das Formular an die Live-Installation senden, wenn sie öffentlich ist. Siehe
[Suche, Formulare und Kommentare auf einer statischen Site](../statisches-veroeffentlichen/suche-formulare-und-kommentare-auf-einer-statischen-site.md).

## Übergeben

Gruppen wechseln ihre Organisatoren. Weil die Website in der Organisation der Gruppe liegt und jede Veröffentlichung
einen Tag hat, übernimmt ein neuer Organisator das Konto und macht weiter. Die [FAQ](../statisches-veroeffentlichen/faq.md)
beantwortet die üblichen Fragen.

# Wer in der Exponential-Community entscheidet

Open-Source-Projekte entscheiden auf unterschiedliche Weise. Diese Seite führt auf, was die veröffentlichten Quellen
für Exponential sagen, und was nicht.

## Inhalt

1. [Die Entscheidungen](#die-entscheidungen)
2. [Was nicht veröffentlicht ist](#was-nicht-veröffentlicht-ist)
3. [Wie Community-Mitglieder Entscheidungen beeinflussen](#wie-community-mitglieder-entscheidungen-beeinflussen)

## Die Entscheidungen

| Entscheidung | Wer | Quelle |
|---|---|---|
| Das Projekt als Ganzes | „Dieses Projekt wird von der Exponential Foundation betrieben“ | exponential.earth/about/project, über [Steuerung und Entscheidungen](../../partner/governance-und-entscheidungen.md) |
| Entwicklung, Support, Verbreitung und Wachstum der Community | 7x, das „die Leitung des Projekts [...] 2023 übernommen hat“ | `README.md` |
| Was gemergt wird | Maintainer prüfen; jeder Pull Request wird gemergt, sobald sein Autor ihn so überarbeitet, gesquasht und rebased hat, wie es die Reviews verlangen | `CONTRIBUTING.md`, [Wie das Projekt wächst](../../wer-ist-die-exponential-foundation.md#wie-das-projekt-wächst) |
| Releases | Maintainer taggen Releases; „Ein veröffentlichter Tag wird nie geändert“ | `SECURITY.md` |
| Sicherheitskorrekturen | Auf `main` vorgenommen, mit dem nächsten 6.0.x-Release veröffentlicht | `SECURITY.md` |
| Verhalten | „Die Exponential Foundation entscheidet über Meldungen und über die Folgen eines Verstoßes“ | `CODE_OF_CONDUCT.md` |
| Das Partnerprogramm | 7x, das „sich alle Rechte vorbehält, dieses Programm zu ändern oder zu verwalten“ | [Steuerung und Entscheidungen](../../partner/governance-und-entscheidungen.md) |
| Die Lizenzen | Festgelegt: GPL v2 oder neuer für Code, GNU FDL 1.3 oder neuer für Dokumentation | `LICENSE`, [Freie Dokumentation](../../freie-dokumentation.md) |

## Was nicht veröffentlicht ist

Keine öffentliche Quelle sagt, „wer im Vorstand der Foundation sitzt, wie sie geführt wird, ob sie außer ihren
Unterstützern Mitglieder hat und wie hoch ihr Budget ist“
([Was die Quellen nicht sagen](../../wer-ist-die-exponential-foundation.md#was-die-quellen-nicht-sagen)). Es gibt keine
dokumentierte Abstimmung der Community, keinen Rat und keine gewählte Rolle. Wenn jemand fragt, sagen Sie, dass diese
nicht veröffentlicht sind.

## Wie Community-Mitglieder Entscheidungen beeinflussen

| Weg | Einfluss | Seite |
|---|---|---|
| Ein Pull Request | Direkt: funktionierender Code ist das stärkste Argument | [Code beitragen](../mitwirken/code-beitragen.md) |
| Ein Issue | Hält ein Problem für alle fest | [Einen Fehler melden](../mitwirken/einen-fehler-melden.md) |
| Die Community-Roadmap auf Share | Funktionswünsche, die andere diskutieren können | [Roadmap](../../projekt/roadmap.md) |
| Die Foren und Chats | Öffentliche Diskussion vor einer Entscheidung | [Wo sich Menschen treffen](../beitreten/wo-sich-menschen-treffen.md) |
| Tests | Zeigen, ob eine Änderung auf echten Einrichtungen funktioniert | [Releases testen](../mitwirken/releases-testen.md) |
| Sponsoring | Finanziert die Arbeit; manche Stufen enthalten Einfluss auf den Backlog | [Die Community finanzieren](die-community-finanzieren.md) |
| Partnerschaft | Programmvorteile wie Roadmap-Wünsche auf höheren Stufen | [An der Roadmap mitwirken](../../partner/an-der-roadmap-mitwirken.md) |

Fragen Sie öffentlich, wo Sie können: Eine in einem Issue diskutierte Entscheidung bleibt für alle festgehalten.

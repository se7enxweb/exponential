## Die Kurzfassung

- 7x leitet die Entwicklung; die Exponential Foundation betreibt das Projekt.
- Pull Requests werden geprüft und gemergt, sobald ihre Autoren sie so überarbeitet haben, wie es die Reviews
  verlangen.
- Korrekturen landen auf `main` und erreichen Sie mit dem nächsten 6.0.x-Release; veröffentlichte Tags ändern sich
  nie.
- Sicherheitsmeldungen sind vertraulich: security@se7enx.com.
- Code steht unter der GPL v2 oder neuer, Dokumentation unter der GNU FDL 1.3 oder neuer; Beiträge zum Kernel
  brauchen das CLA.
- Das Projekt lebt von gespendeter Zeit und Sponsoring.

Diese Seite ist eine Zusammenfassung für Community-Mitglieder, keine Rechtsberatung. Verbindlich sind die
Lizenztexte.

## Die drei Texte

| Gilt für | Lizenz | Quelle |
|---|---|---|
| Den Code von Exponential | GNU General Public License, Version 2 oder neuer | `LICENSE`, `README.md` („License“) |
| Die Dokumentation, einschließlich dieser Hilfe | GNU Free Documentation License 1.3 oder neuer | [Die Lizenz dieser Dokumentation](../../../README-LIZENZ.md) |
| Zum Kernel beigetragenen Code | Die GPL, dazu eine Übertragung des Urheberrechts an die Exponential Foundation und 7x durch das CLA | `CONTRIBUTING.md` |

„Die Nutzung von Exponential unter den Bedingungen der GNU GPL ist kostenlos“ (`README.md`). Die frühere
professionelle Lizenz „ist nicht mehr erhältlich“, daher steht Exponential „AUSSCHLIESSLICH unter der GNU GPLv2 oder
neuer“ (ebenda).

## Was Sie tun dürfen

- **Nutzen** Sie Exponential für jeden Zweck, auch für kommerzielle Websites.
- **Untersuchen und ändern** Sie es.
- **Geben Sie es weiter**, geändert oder nicht, unter derselben Lizenz.
- **Kopieren, übersetzen und bearbeiten** Sie die Dokumentation unter der GNU FDL ([Freie Dokumentation](../../freie-dokumentation.md)).

## Was die Lizenzen von Ihnen verlangen

- **Wenn Sie** Exponential oder darauf basierenden Code **verbreiten**, gelten die Bedingungen der GPL: Der Quellcode
  gehört dazu ([Erweiterungen zurückgeben](../../erweiterungen-zurueckgeben.md)).
- **Beiträge zum Projekt** „werden ebenfalls unter derselben Lizenz GPLv2 oder neuer veröffentlicht“ (`CONTRIBUTING.md`).
- **Bearbeitete Dokumentation** bleibt unter der GNU FDL.
- Der Verhaltenskodex ergänzt: „Stellen Sie freie Software nicht als Ihr eigenes proprietäres Produkt dar und
  schränken Sie die Freiheiten, die die Lizenzen Ihren Kunden geben, nicht ein“ (`CODE_OF_CONDUCT.md`, „Partners and
  commercial conduct“).

## Häufige Situationen

| Situation | Kurz gesagt |
|---|---|
| Sie betreiben eine Website mit Exponential | Kostenlos; keine Pflicht, Ihre eigenen Templates oder Erweiterungen zu veröffentlichen |
| Sie bauen eine Website für einen Kunden | Der Kunde erhält dieselben Freiheiten; siehe [Lizenzierung für Käufer](../../geschaeft/lizenzen-fuer-kaeufer.md) |
| Sie veröffentlichen Ihre eigene Erweiterung | Ihr Urheberrecht; das Projekt empfiehlt GPL 2 oder neuer; kein CLA |
| Sie senden eine Korrektur an den Kernel | GPL, dazu das CLA ([Das CLA erklärt](../mitwirken/das-cla-erklaert.md)) |
| Sie übersetzen Hilfeseiten | GNU FDL; nennen Sie das Original |
| Sie zitieren die Hilfe in einem Vortrag oder Kurs | Unter der GNU FDL erlaubt; geben Sie die Quelle an ([Quellen nennen und die eigenen Texte lizenzieren](../../fuersprecher/quellen-zitieren-und-texte-lizenzieren.md)) |

Weitere Fragen: [FAQ zur Lizenzierung](../../projekt/lizenz-faq.md).

# Anderen in der Community helfen

Kostenlose Hilfe in den Foren und Chats hängt von der Zeit ab, die Menschen geben
([Wenn etwas schiefgeht](../../wenn-etwas-schiefgeht.md)). Sobald Sie ein wenig wissen, können Sie etwas von
dieser Zeit zurückgeben. Diese Seiten zeigen, wie Sie gut helfen.

## Warum Helfen wichtig ist

- Ein Neuling, der eine freundliche, richtige Antwort bekommt, bleibt oft und wird zu einer mitwirkenden Person.
- Eine Antwort in den Foren finden später alle, die dieselbe Frage haben.
- Erfahrene Mitglieder sehen, welche Teile der Software und der Dokumentation Menschen verwirren, und können sie
  verbessern.

## Wie viel genug ist

Es gibt kein Soll. Eine gute Antwort pro Woche ist ein echter Beitrag. Antworten Sie nicht, wenn Sie unsicher sind;
sagen Sie, was Sie wissen und was nicht, oder überlassen Sie die Frage jemand anderem.

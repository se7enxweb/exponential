# Sich der Community vorstellen

Eine Vorstellung ist freiwillig. Sie hilft, wenn Sie bleiben möchten: Die Menschen merken sich, wer welche Art von
Website betreibt, und können Sie später zur richtigen Antwort oder zur richtigen Person führen.

## Was Sie sagen

- **Was Sie mit Exponential tun**: eine Website betreiben, eine bearbeiten, Websites für Kunden bauen, Erweiterungen
  schreiben, übersetzen, sich damit beschäftigen.
- **Wie lange Sie es schon nutzen** und von welchem Release oder welchem früheren System Sie kommen.
- **Was Sie zu finden oder zu geben hoffen**: Antworten auf ein Problem, Menschen in Ihrer Sprache oder Region, ein
  Projekt, bei dem Sie helfen können.
- **Ihre Verbindungen**, wenn Sie für ein Unternehmen arbeiten, das Exponential-Dienstleistungen verkauft. Der
  Verhaltenskodex verlangt von Partnern und allen, die Dienstleistungen verkaufen: „Legen Sie Interessenkonflikte
  offen“ (`CODE_OF_CONDUCT.md`).

## Was Sie weglassen

- Personenbezogene Daten, die nicht jahrelang öffentlich bleiben sollen: eine Privatadresse, eine private
  Telefonnummer.
- Daten über Ihre Kunden oder die Nutzer Ihrer Website.
- Serveradressen, Benutzernamen von Administratoren, Versionsangaben einer Produktivseite, die noch nicht gepatcht ist.
- Werbung. „Nutzen Sie die Räume der Community, um zu helfen, nicht um zu werben“ (`CODE_OF_CONDUCT.md`).

## Eine Vorlage

```text
Hello, I'm <first name or handle> from <city or country, optional>.
I <run / build / edit / develop for> <kind of site: a store, an intranet, a magazine ...>
on Exponential <version, if you want> since <year>.
I'm here to <learn X / help with Y / find people working on Z>.
<If it applies: I work for <company>, which offers Exponential services.>
```

Fassen Sie sich kurz. Eine Frage am Ende („Betreibt noch jemand einen mehrsprachigen Shop?“) eröffnet ein Gespräch
besser als eine lange Lebensgeschichte.

## Wenn sich jemand anderes vorstellt

- Begrüßen Sie die Person mit Namen und beantworten Sie jede Frage, die sie gestellt hat.
- Verweisen Sie auf eine Seite, die zu dem passt, was sie gesagt hat, nicht auf zehn
  ([Auf die richtige Hilfeseite verweisen](../../fuersprecher/auf-die-richtige-hilfeseite-verweisen.md)).
- Werben Sie in einer Antwort auf eine Vorstellung nicht für Ihre Dienstleistungen.

Mehr dazu unter [Neue Mitglieder willkommen heißen](../anderen-helfen/neue-mitglieder-willkommen-heissen.md).

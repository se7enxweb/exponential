## Einen Ort wählen

| Sie möchten | Gehen Sie zu |
|---|---|
| Fragen „Wie mache ich ...?“ | Zuerst in die Hilfe, dann in die Foren; für etwas Schnelles auf Telegram, Discord oder Slack |
| Einen Fehler melden | Die Seite **Fehler melden** der Hilfe (`exphelp/report`), die ein Issue im richtigen Tracker eröffnet |
| Eine Idee für das Projekt oder seine Websites vorschlagen | Der Issue-Tracker der Community |
| Eine Änderung am Code vorschlagen | Ein Pull Request auf GitHub ([Code beitragen](../mitwirken/code-beitragen.md)) |
| Eine Erweiterung teilen | Projects und ein eigenes GitHub-Repository ([Erweiterungen und Themes teilen](../mitwirken/erweiterungen-und-themes-teilen.md)) |
| Ein Tutorial schreiben | Share, oder eZpedia für einen kurzen Kniff ([Tutorials und Beiträge schreiben](../anderen-helfen/tutorials-und-beitraege-schreiben.md)) |
| Die Dokumentation korrigieren | „Auf GitHub bearbeiten“ auf der Seite ([Dokumentation und Hilfeseiten beitragen](../mitwirken/dokumentation-und-hilfeseiten-beitragen.md)) |

Eine Antwort im Forum bleibt jahrelang auffindbar; eine Antwort im Chat scrollt davon. Wenn Sie in einem Chat eine
gute Antwort bekommen, schreiben Sie sie in den Foren oder auf eZpedia auf, damit die nächste Person sie findet.

## Vertrauliche Angelegenheiten

| Angelegenheit | Wohin |
|---|---|
| Eine Sicherheitslücke | security@se7enx.com oder die vertrauliche Schwachstellenmeldung von GitHub (`SECURITY.md`) |
| Ein Verhaltensproblem | community@se7enx.com; die Exponential Foundation entscheidet (`CODE_OF_CONDUCT.md`) |
| Die Foundation | [foundation.exponential.earth](https://foundation.exponential.earth/) |
| Bezahlte Dienstleistungen von 7x | [se7enx.com](https://se7enx.com/) |

## Was nicht dokumentiert ist

Die Quellen nennen keine Konferenzen oder regelmäßigen Treffen, keine offiziellen Social-Media-Konten oder Hashtags und
keine Mailingliste ([Die Community-Kanäle](../../fuersprecher/community-kanaele.md)). Wenn Sie eine lokale Gruppe
betreiben, ist es Ihre; siehe [Lokale Gruppen](../lokale-gruppen/README.md).

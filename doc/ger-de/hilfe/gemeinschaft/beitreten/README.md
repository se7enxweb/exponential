Es gibt nichts zu unterschreiben und nichts zu bezahlen. Sie treten der Exponential-Community bei, indem Sie an einem
der Orte erscheinen, an denen sich Menschen treffen, und mitmachen. Diese Seiten helfen Ihnen, das gut zu tun.

## Drei Dinge, die Sie vor Ihrem ersten Beitrag wissen sollten

1. **Keine Passwörter, Schlüssel oder personenbezogenen Daten in der Öffentlichkeit.** Weder in einem Forenbeitrag,
   einer Chatnachricht noch einem Issue ([Wenn etwas schiefgeht](../../wenn-etwas-schiefgeht.md)).
2. **Sicherheitsprobleme sind vertraulich.** Senden Sie sie an security@se7enx.com, nie an einen öffentlichen Ort
   (`SECURITY.md`).
3. **Kostenlose Hilfe hat keine Antwortzeit.** Menschen helfen, wenn sie können; wenn Sie nicht warten können, lesen
   Sie [Support bekommen](../../projekt/unterstuetzung-erhalten.md).

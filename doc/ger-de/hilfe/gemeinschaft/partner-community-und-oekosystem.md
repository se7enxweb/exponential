# Partner, Community und Ökosystem

Der Dashboard-Block „Wer Exponential macht“ der Hilfe nennt 7x, die Exponential Foundation und drei Kreise von
Menschen. Diese Seite stellt die drei Kreise nebeneinander.

## Die drei Definitionen

| Kreis | Definition |
|---|---|
| **Partner** | Exponential-Partner tragen finanziell zur dauerhaften Zukunft des Projekts bei, geben Code und mehr an das Projekt zurück und arbeiten direkt mit 7x und der Exponential Foundation zusammen. |
| **Community** | Mitglieder der Exponential-Community nutzen Exponential weltweit, tragen dazu bei, werben dafür und entwickeln Software damit. |
| **Ökosystem** | Das größere Ökosystem reicht über die Community hinaus und umfasst alle Bereiche der Exponential-Welt im PHP-Stack: ihre Nutzer und Ersteller. |

## Wie sich die Kreise überschneiden

Stellen Sie sich drei Ringe vor, einer im anderen:

```text
+--------------------------------------------------------------+
| ECOSYSTEM: everyone and everything in the Exponential world   |
|            within the PHP stack, its users and creators       |
|   +------------------------------------------------------+   |
|   | COMMUNITY: people who use, contribute to, promote     |   |
|   |            and develop software using Exponential     |   |
|   |   +----------------------------------------------+   |   |
|   |   | PARTNERS: fund the project, contribute back,  |   |   |
|   |   |           engage directly with 7x and the     |   |   |
|   |   |           Exponential Foundation              |   |   |
|   |   +----------------------------------------------+   |   |
|   +------------------------------------------------------+   |
+--------------------------------------------------------------+
```

- Jeder Partner ist auch Mitglied der Community: Partner nutzen, tragen bei und werben.
- Jedes Mitglied der Community ist Teil des Ökosystems.
- Zum Ökosystem gehören auch Menschen und Projekte, die nie ein Forum besuchen: ein Unternehmen, das eine Website
  betreibt, die ein Partner gebaut hat, die Autoren der PHP-Bibliotheken, von denen Exponential abhängt, ein
  Hosting-Unternehmen, das PHP-Hosting anbietet, auf dem zufällig eine Installation läuft
  ([Ökosystem: hier beginnen](../oekosystem/oekosystem-hier-beginnen.md)).

## Beispiele

| Person oder Organisation | Kreise |
|---|---|
| Eine Besucherin, die eine mit Exponential gebaute Website liest | Ökosystem |
| Ein Shop-Inhaber, dessen Website auf Exponential läuft und der einen Fehler meldet | Ökosystem, Community |
| Eine freiberufliche Entwicklerin, die Fragen im Forum beantwortet und eine Erweiterung veröffentlicht | Ökosystem, Community |
| Eine Agentur im Exponential-Partnerprogramm, die Pull Requests sendet | Ökosystem, Community, Partner |
| Ein Maintainer einer PHP-Bibliothek, die der Kernel benötigt | Ökosystem |
| 7x und die Exponential Foundation | Alle drei, und sie betreiben das Partnerprogramm |

## Zwischen den Kreisen wechseln

| Von | Nach | Der Schritt | Seite |
|---|---|---|---|
| Ökosystem | Community | Einmal mitmachen: fragen, antworten, melden oder beitragen | [Ihre erste Woche in der Community](ihre-erste-woche-in-der-community.md) |
| Community | Regelmäßige Mitwirkende | In einem Bereich dauerhaft beitragen | [Vom Nutzer zum Mitwirkenden](lernpfade/vom-nutzer-zum-mitwirkenden.md) |
| Community | Partner | Ein Unternehmen bewirbt sich für das Partnerprogramm | [Von der Community zum Partner](lernpfade/von-der-community-zum-partner.md), [Wie Sie sich bewerben](../partner/wie-sie-sich-bewerben.md) |

Kein Schritt ist Pflicht. Viele Menschen bleiben jahrelang Nutzer, und das ist in Ordnung.

# Eine lokale Gruppe gründen

Eine lokale Gruppe können drei Menschen in einem Café sein oder ein monatlicher Videoanruf. Wichtig ist, dass sie sich
regelmäßig trifft und dass die Menschen mit mehr Wissen gehen, als sie gekommen sind.

## Interesse finden

- Schreiben Sie in den [Foren](https://share.exponential.earth/forums) und den Chats: „Hat jemand in <Region> oder mit
  der Sprache <Sprache> Interesse an einem Treffen?“
- Fragen Sie Kollegen, Kunden und Lernende, die Exponential nutzen.
- Zwei oder drei interessierte Menschen reichen für den Anfang.

## Ein Format wählen

| Format | Geeignet für | Braucht |
|---|---|---|
| Online-Anruf | Verstreute Gruppen, eine Sprache | Ein Videowerkzeug, eine Moderation |
| Vor Ort, informell | Städte mit mehreren Nutzern | Einen ruhigen Ort |
| Vor Ort mit Vorträgen | Größere Gruppen | Einen Raum, einen Projektor, eine vortragende Person |
| Beitragstag | Gruppen, die etwas zurückgeben möchten | Laptops, Testinstallationen ([Ein Beitragstag](ein-beitragstag.md)) |

Die Seiten für Fürsprecher behandeln die Einzelheiten: [Ein Treffen vorschlagen](../../fuersprecher/ein-treffen-vorschlagen.md),
[Ein Online-Treffen durchführen](../../fuersprecher/ein-online-treffen-durchfuehren.md).

## Das erste Treffen

1. Legen Sie ein Datum, eine Uhrzeit und einen Ort oder Link fest, zwei bis vier Wochen im Voraus.
2. Nennen Sie eine Ansprechperson für Probleme, wie es der Verhaltenskodex von Organisatoren verlangt
   ([Sicherheit und Datenschutz in der Community](sicherheit-und-datenschutz-in-der-community.md)).
3. Bereiten Sie einen kurzen Vortrag oder eine Demo vor und lassen Sie viel Zeit zum Reden.
4. Fragen Sie am Ende, was sich die Menschen für das nächste Mal wünschen.

## Eine einfache Tagesordnung

| Zeit | Teil |
|---|---|
| 0:00 | Begrüßung, Vorstellungsrunde, der Verhaltenskodex in einem Satz |
| 0:10 | Ein kurzer Vortrag oder eine Demo (zum Beispiel eine neue Funktion des neuesten Release) |
| 0:30 | Fragen und Probleme, die die Menschen mitbringen |
| 1:00 | Was wir als Nächstes gemeinsam tun könnten; nächster Termin |

Vortragsmaterial lässt sich aus der Hilfe aufbauen, die freie Dokumentation ist
([Folienaufbau für einen Zwanzig-Minuten-Vortrag](../../fuersprecher/folienplan-20-minuten-vortrag.md),
[Skript für einen Lightning Talk](../../fuersprecher/skript-lightning-talk.md)).

## Am Laufen halten

- Treffen Sie sich in einem festen Rhythmus, zum Beispiel am ersten Dienstag im Monat.
- Teilen Sie die Organisation auf zwei oder drei Personen auf.
- Führen Sie eine kurze öffentliche Notiz zu jedem Treffen, ohne personenbezogene Daten.
- Laden Sie Neulinge ausdrücklich ein; Gruppen, die nur unter sich reden, schrumpfen.

## Die Gruppe ankündigen

Beschreiben Sie sie als das, was sie ist: eine von der Community organisierte Gruppe. Verwenden Sie keine Logos des
Projekts und nicht das Wort „offiziell“, sofern das Projekt nicht zugestimmt hat
([Namen und Marke](../../partner/namens-und-markenregeln.md),
[Behauptungen, die Sie nicht aufstellen dürfen](../../fuersprecher/aussagen-die-sie-nicht-machen-duerfen.md)).

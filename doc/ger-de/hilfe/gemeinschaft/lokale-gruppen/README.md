# Lokale Gruppen und Community-Veranstaltungen

Die Quellen dokumentieren keine Konferenzen oder Treffen
([Orte der Community](../../wer-ist-die-exponential-foundation.md#orte-der-community)). Das bedeutet, dass jede bestehende
Gruppe oder Veranstaltung von Community-Mitgliedern selbst organisiert wird. Diese Seiten helfen Ihnen, das gut zu tun.

## Ihre Veranstaltung gehört Ihnen

- Stellen Sie eine Gruppe oder Veranstaltung als Ihre eigene dar, nicht als offizielle Veranstaltung des Projekts, es
  sei denn, das Projekt hat sie dazu gemacht (`CODE_OF_CONDUCT.md`, „Trainers and advocates“: „Nennen Sie einen Kurs,
  ein Zertifikat oder eine Veranstaltung nicht ‚offiziell‘, es sei denn, das Projekt oder das Partnerprogramm hat sie
  dazu gemacht“).
- Legen Sie Ihre Verbindungen offen: einen Arbeitgeber oder ein eigenes Produkt.
- Der Verhaltenskodex „gilt bei jeder Veranstaltung über Exponential, die Sie organisieren“.

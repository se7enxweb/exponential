# Wege mitzuwirken

Wählen Sie danach, worin Sie gut sind und wie viel Zeit Sie haben. Ein kleiner, abgeschlossener Beitrag ist mehr wert
als ein großer, aufgegebener.

## Nach Rolle

| Sie sind | Gute erste Beiträge |
|---|---|
| Redakteur | Verwirrende Bildschirme melden, Hilfeseiten für Redakteure korrigieren, übersetzen |
| Administrator | Fehler bestätigen, Releases testen, Kniffe für die Installation dokumentieren |
| Entwickler | Einen Fehler beheben, einen Test hinzufügen, einen Pull Request prüfen, eine Erweiterung veröffentlichen |
| Designer | Barrierefreiheitsprobleme melden, zu einem Theme beitragen, das Styling der Administration verbessern ([Mitwirken für Designer und Theme-Entwickler](../lernpfade/community-fuer-designer-und-theme-entwickler.md)) |
| Hoster oder Agentur | Releases auf vielen Servern testen, Hosting-Einrichtungen dokumentieren, Partner werden |
| Lernende | Fragen beantworten, die Sie gerade selbst gelöst haben, übersetzen, Hilfeseiten korrigieren |

## Den ersten Beitrag wählen

Wenn Sie nicht wissen, wo Sie anfangen sollen, tun Sie Folgendes: Nutzen Sie die Software eine Woche lang, notieren
Sie jede Stelle, an der Sie hängen geblieben sind, und machen Sie aus der ärgerlichsten einen Fehlerbericht oder eine
Korrektur einer Hilfeseite. [Ihr erster Beitrag](ihr-erster-beitrag.md) zeigt, wie das geht. Wo Sie an einem
Verhalten hängen geblieben sind, das gewollt oder auslegungsfähig sein könnte, lesen Sie zuerst
[Negative Funktionen](../../projekt/unterstuetzung-erhalten.md#negative-funktionen): Andere Websites können davon abhängen,
daher braucht eine Änderung eine klare Begründung und wird am besten als Option vorgeschlagen.

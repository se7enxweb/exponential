# Die ersten 90 Tage eines Wiederverkäufers

Diese Seite ist für Inhaber, die rund um Exponential ein Wiederverkaufsgeschäft beginnen. Sie macht aus den Seiten
für Wiederverkäufer einen Plan für die ersten drei Monate. Passen Sie das Tempo an Ihr Team an; überspringen Sie
keine Schritte.

## Inhalt

1. [Monat 1: entscheiden](#monat-1-entscheiden)
2. [Monat 2: aufbauen](#monat-2-aufbauen)
3. [Monat 3: verkaufen und liefern](#monat-3-verkaufen-und-liefern)
4. [Nach 90 Tagen](#nach-90-tagen)

## Monat 1: entscheiden

| Woche | Tun Sie dies | Seite |
|---|---|---|
| 1 | Erfahren Sie, was Sie verkaufen dürfen und was Sie bei einer Weitergabe schulden | [Was Wiederverkauf bei freier Software bedeutet](../grundlagen/was-wiederverkauf-bei-freier-software-bedeutet.md), [Was Sie verkaufen können und was nicht](../grundlagen/was-sie-verkaufen-koennen-und-was-nicht.md) |
| 1 | Erfahren Sie, wer hinter dem Produkt steht | [Mit 7x und der Foundation zusammenarbeiten](../grundlagen/mit-7x-und-der-foundation-zusammenarbeiten.md) |
| 2 | Wählen Sie Ihre Wiederverkaufsmodelle | [Wiederverkaufsmodelle](../grundlagen/wiederverkaufsmodelle.md) |
| 3 | Füllen Sie das Kostenmodell aus | [Arbeitsblatt zu Marge und Kosten](../angebote/arbeitsblatt-zu-marge-und-kosten.md) |
| 4 | Wählen Sie eine Partnerstufe; bewerben, bezahlen, dann unterschreiben | [Eine Partnerstufe wählen](../grundlagen/eine-partnerstufe-waehlen.md), [Wie Sie sich bewerben](../../partner/wie-sie-sich-bewerben.md) |

- [ ] Modelle gewählt und aufgeschrieben.
- [ ] Anzahl der Kunden bis zur Gewinnschwelle bekannt.
- [ ] Partnerstufe gewählt; Bewerbung abgeschickt.

## Nach 90 Tagen

- Überprüfen Sie das Kostenmodell mit den tatsächlichen Stunden.
- Fragen Sie die ersten Kunden, was sie schätzen und was ihnen fehlt.
- Planen Sie Ihre erste Fallstudie, mit Einwilligung ([Fallstudien für Wiederverkäufer](../verkauf/fallstudien.md)).
- Tragen Sie die jährliche Überprüfung in den Kalender ein ([Jährliche Checkliste](jaehrliche-checkliste.md)).

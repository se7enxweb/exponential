# Projekt 4: eine Seite mit Layouts

Mit Exponential Layouts ordnen Redakteure und Website-Bauer Seiten aus Blöcken in Zonen an. In diesem Projekt bauen
Sie die Landingpage Ihres Studierendenvereins aus [Projekt 2](projekt-02-eine-kleine-website-struktur.md) mit dem
Layouts-Editor, veröffentlichen sie und ordnen sie einer Seite zu.

## Auf einen Blick

| | |
|---|---|
| Stufe | Einsteiger |
| Zeit | Etwa 2 Stunden |
| Pfade | Redakteur, Designer |
| Voraussetzungen | Eine Lernwebsite mit dem Reiter **Layouts** (das Standard-Site-Paket verwendet die Erweiterungen `explayouts`, [Site-Pakete für Lernende](site-pakete-fuer-lernende.md)); [Projekt 2](projekt-02-eine-kleine-website-struktur.md) |

Wenn Sie den Reiter **Layouts** nicht sehen, darf Ihre Rolle möglicherweise nicht mit Layouts arbeiten, oder die
Website wurde ohne die Layouts-Erweiterungen installiert ([Der Layouts-Editor](../layout-editor.md)).

## Ziel

Ein veröffentlichtes Layout für den Ordner „Studierendenverein“ mit mindestens zwei Zonen und fünf Blöcken,
darunter eine Liste Ihrer Nachrichtenartikel, so zugeordnet, dass nur diese Seite es verwendet.

## Bevor Sie beginnen

Lesen Sie [Der Layouts-Editor](../layout-editor.md) und [Wie baue ich eine Seite mit Layouts?](../handbuch/wie-baue-ich-eine-seite-mit-layouts.md).
Lernen Sie die Begriffe: **Layout**, **Layouttyp**, **Zone**, **Block**, **Zuordnung** (auch Regel genannt) und
**gemeinsames Layout**.

## Aufgaben

1. **Öffnen Sie das Dashboard.** Der Reiter **Layouts** öffnet das **Layouts-Dashboard** mit der Anzahl der Layouts,
   Zonen, Blöcke und Zuordnungen. Notieren Sie sie.
2. **Legen Sie ein Layout an.** Drücken Sie **Neues Layout**, wählen Sie einen Layouttyp mit mindestens zwei Zonen
   (zum Beispiel *2 columns* oder *Sidebar left*), nennen Sie es „Landingpage Studierendenverein“ und drücken Sie
   **Layout anlegen**.
3. **Fügen Sie Blöcke hinzu.** Drücken Sie **Block hinzufügen** und ziehen Sie mindestens fünf Blöcke in die Zonen:
   einen **Title**, einen **Rich text**, ein **Image** und einen Block aus der Gruppe **Listing**, der Ihre
   Nachrichtenartikel zeigt.
4. **Konfigurieren Sie sie.** Wählen Sie jeden Block aus; füllen Sie seinen Reiter **Inhalt** aus (den Text oder
   welche Elemente die Liste zeigt und wie viele) und sehen Sie sich seinen Reiter **Design** an.
5. **Speichern Sie einen Entwurf.** Verwenden Sie **Entwurf speichern und schließen**. Öffnen Sie das Layout erneut:
   Ihre Arbeit ist da, und die Website ist unverändert, weil Sie immer an einem Entwurf arbeiten.
6. **Veröffentlichen Sie** mit **Layout veröffentlichen**.
7. **Ordnen Sie es zu.** Fügen Sie unter **Regeln** (den Zuordnungen) mit **Neue Zuordnung** eine Zuordnung hinzu,
   deren Ziel nur der Ordner „Studierendenverein“ ist. Prüfen Sie, ob sie **Aktiviert** ist. Es gewinnt die erste
   aktivierte Zuordnung nach Priorität, deren Ziele und Bedingungen auf eine Seite passen.
8. **Prüfen Sie auf der Website.** Öffnen Sie den Ordner auf der öffentlichen Website: Die Seite zeigt Ihr Layout.
   Öffnen Sie eine andere Seite: Sie zeigt es nicht. Wenn der Editor nach dem Veröffentlichen fragt, ob Caches geleert
   werden sollen, wählen Sie **Caches leeren**.
9. **Sehen Sie sich den Reiter Layouts der Seite** in der Administrationsoberfläche an: Er zeigt das Layout, das für
   die Seite ermittelt wird, und die angewendeten Zuordnungen.

Alle Schritte folgen [Der Layouts-Editor](../layout-editor.md).

## Abgabe

- Screenshots: das Layout im Editor mit seinen Zonen und Blöcken; die Zuordnung mit ihrem Ziel; die öffentliche
  Seite; der Reiter **Layouts** der Seite.
- Name und Typ des Layouts und die Zahlen auf dem Dashboard davor und danach.
- Ein kurzer Bericht: was jeder Block zeigt, warum Sie den Layouttyp gewählt haben und wie die Zuordnung entscheidet,
  wo das Layout verwendet wird.

## Bewertungsraster

Bewerten Sie die vier gemeinsamen Kriterien aus [Die eigene Arbeit bewerten](die-eigene-arbeit-bewerten.md) und diese
Prüfungen (7):

1. Das Layout hat mindestens zwei genutzte Zonen und fünf Blöcke.
2. Ein Listing-Block zeigt die eigenen Artikel der lernenden Person.
3. Vor dem Veröffentlichen wurde ein Entwurf gespeichert und wieder geöffnet.
4. Das Layout ist veröffentlicht.
5. Eine aktivierte Zuordnung zielt nur auf den Vereinsordner.
6. Es ist gezeigt, dass eine andere Seite nicht betroffen ist.
7. Der Bericht verwendet die Begriffe Layout, Zone, Block und Zuordnung korrekt.

## Zusatzziele

- Verknüpfen Sie eine Zone Ihres Layouts mit einer Zone eines **gemeinsamen Layouts** (die Schaltfläche unten auf der
  linken Seite des Editors) und erklären Sie, warum ein einmal gebauter Kopfbereich vielen Seiten dienen kann
  ([Gemeinsame Layouts und verknüpfte Zonen](../../bc/6.0/layouts.md#gemeinsame-layouts-und-verknüpfte-zonen)).
- Fügen Sie eine Zuordnung mit einer Bedingung hinzu (zum Beispiel einem Inhaltstyp) und erklären Sie, welche
  Zuordnung gewinnt.
- Folgen Sie dem Kurs [Exponential Layouts](../trainer/layouts/README.md) der Trainer, Modul 7, zu
  Zuordnungsregeln.

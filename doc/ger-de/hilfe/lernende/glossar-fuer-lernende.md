# Glossar für Lernende

Die Wörter, denen Sie zuerst begegnen, in einfacher Sprache, jeweils mit der Seite, die sie vermittelt. Die
vollständige Liste ist das [Glossar](../../glossar.md); viele Definitionen hier folgen ihm.

## Inhalt

1. [Begriffe des Produkts](#begriffe-des-produkts)
2. [Begriffe zum Lernen](#begriffe-zum-lernen)

## Begriffe des Produkts

| Begriff | Bedeutung | Mehr dazu |
|---|---|---|
| **Administrationsoberfläche** | Wo Sie an der Website arbeiten: der Siteaccess `admin` | [Rundgang durch die Administration](../rundgang-durch-die-administration.md) |
| **Immer verfügbar** | Eine Markierung, die ein Objekt in seiner Hauptsprache zeigt, wenn keine der aufgeführten Sprachen vorhanden ist | [Inhaltssprachen](../../anleitungen/inhaltssprachen.md#6-hauptsprache-und-immer-verfügbar) |
| **Attribut** | Ein Feld einer Inhaltsklasse, mit einem Datentyp | [Das Inhaltsmodell verstehen](das-inhaltsmodell-verstehen.md) |
| **Block** | Ein Teil einer Layout-Zone: ein Titel, Rich Text, ein Bild, eine Liste | [Der Layouts-Editor](../layout-editor.md) |
| **Cache** | Gespeicherte Ergebnisse, die Seiten schneller machen | [Caches verstehen](caches-verstehen.md) |
| **CLA** | Die Vereinbarung, die nötig ist, bevor Code in den Kernel gemergt wird; überträgt das Urheberrecht an die Exponential Foundation und 7x | [Die CLA für Lernende](die-cla-fuer-lernende.md) |
| **Konsole** | `php bin/php/console`, das die Befehle der Installation ausführt (`exp:...`) | [Glossar](../../glossar.md#c) |
| **Inhaltsklasse** | Eine Art von Inhalt (Artikel, Ordner) als Liste von Attributen | [Projekt 1](projekt-01-eine-eigene-inhaltsklasse.md) |
| **Inhaltsobjekt** | Ein einzelner Inhalt, mit Versionen und Übersetzungen | [Das Inhaltsmodell verstehen](das-inhaltsmodell-verstehen.md) |
| **Inhaltsbaum** | Die Hierarchie der Knoten in der Administrationsoberfläche | [Das Inhaltsmodell verstehen](das-inhaltsmodell-verstehen.md#objekte-und-knoten) |
| **Datentyp** | Die Art eines Attributs: Textzeile, XML Block … | [Das Inhaltsmodell und das Bearbeiten von Inhalten](../../anleitungen/inhaltsmodell-und-bearbeitung.md) |
| **Design** | Ein Ordner mit Templates, Stylesheets, Skripten und Bildern | [Lernpfad: Designer](lernpfad-designer.md) |
| **Entwurf** | Eine unveröffentlichte Version, an der Sie noch arbeiten | [Veröffentlichen, Versionen und der Papierkorb](../veroeffentlichen-und-versionen.md) |
| **Erweiterung** | Ein Ordner, der Funktionen hinzufügt, ohne den Kernel zu ändern | [Projekt 8](projekt-08-ihre-erste-erweiterung.md) |
| **Fetch** | Eine Template-Funktion, die Daten liest, etwa eine Liste der Unterknoten | [Die Template-Sprache lernen](die-template-sprache-lernen.md) |
| **INI-Einstellungen** | Konfigurationsdateien; Sie überschreiben sie mit Dateien `.ini.append.php` | [Siteaccesses und Einstellungen verstehen](siteaccesses-und-einstellungen-verstehen.md) |
| **Kernel** | Der Kern von Exponential, das Repository `se7enxweb/exponential` | [Aus Git-Klonen zum Lernen installieren](aus-git-klonen-zum-lernen-installieren.md) |
| **Layout** | Der Plan einer Seite in Exponential Layouts, mit Zonen | [Projekt 4](projekt-04-eine-seite-mit-layouts.md) |
| **Hauptsprache** | Die Sprache, in der ein Objekt angelegt oder die später gewählt wurde | [Sprachen](../sprachen.md) |
| **Zuordnung (Regel)** | Entscheidet, auf welchen Seiten ein Layout verwendet wird | [Der Layouts-Editor](../layout-editor.md) |
| **Knoten (Platzierung)** | Ein Platz eines Objekts im Inhaltsbaum; ein Objekt kann mehrere haben | [Das Inhaltsmodell verstehen](das-inhaltsmodell-verstehen.md) |
| **Override** | Ein Template, das für bestimmte Seiten ein anderes ersetzt, ausgewählt durch eine Regel | [Projekt 3](projekt-03-ein-template-override.md) |
| **Paket** | Inhalte, Klassen und Design, ausgeliefert als Archiv `.ezpkg` | [Site-Pakete für Lernende](site-pakete-fuer-lernende.md) |
| **Pagelayout** | Das äußere Template, das jede Seite umschließt | [Glossar](../../glossar.md#p) |
| **Richtlinie** | Eine einzelne Berechtigung innerhalb einer Rolle | [Projekt 9](projekt-09-rollen-fuer-einen-eingeschraenkten-redakteur.md) |
| **Rolle** | Eine benannte Gruppe von Richtlinien, die Benutzern oder Gruppen zugewiesen wird | [Projekt 9](projekt-09-rollen-fuer-einen-eingeschraenkten-redakteur.md) |
| **Sektion** | Eine Kennzeichnung an Inhalten, die ein Design und Berechtigungen auswählt | [Sektionen](../../anleitungen/sektionen.md) |
| **Gemeinsames Layout** | Ein Layout, auf dessen Zonen andere Layouts verweisen, etwa ein Kopfbereich | [Der Layouts-Editor](../layout-editor.md) |
| **Site-Paket** | Die Zusammenstellung aus Inhalten und Design, die bei der Einrichtung installiert wird | [Site-Pakete für Lernende](site-pakete-fuer-lernende.md) |
| **Siteaccess** | Ein Zugangsweg zur Installation (`site`, `admin`, `editor`) mit eigenen Einstellungen | [Siteaccesses und Einstellungen verstehen](siteaccesses-und-einstellungen-verstehen.md) |
| **SQLite** | Die Datenbank in einer einzigen Datei; die Voreinstellung von `exp:install` | [Datenbankunterstützung](../datenbankunterstuetzung.md) |
| **Template** | Eine Datei `.tpl` in der Template-Sprache | [Die Template-Sprache lernen](die-template-sprache-lernen.md) |
| **Papierkorb** | Wo entfernte Elemente darauf warten, wiederhergestellt oder endgültig gelöscht zu werden | [Veröffentlichen, Versionen und der Papierkorb](../veroeffentlichen-und-versionen.md) |
| **Velocity** | Der Anwendungsserver von Exponential; die Engine `php` liefert eine Lernwebsite aus | [Eine Lernwebsite mit einem Befehl installieren](eine-lernwebsite-mit-einem-befehl-installieren.md#die-website-ausliefern) |
| **Version** | Ein gespeicherter Zustand eines Objekts: Entwurf, veröffentlicht oder archiviert | [Das Inhaltsmodell verstehen](das-inhaltsmodell-verstehen.md#versionen-und-übersetzungen) |
| **wash** | Der Template-Operator, der Text für HTML maskiert | [Die Template-Sprache lernen](die-template-sprache-lernen.md) |
| **Zone** | Ein Bereich eines Layouts, der Blöcke enthält | [Der Layouts-Editor](../layout-editor.md) |

## Begriffe zum Lernen

| Begriff | Bedeutung in diesem Ordner | Seite |
|---|---|---|
| **Lernwebsite** | Eine eigene Installation zum Üben, niemals eine Live-Website | [Ihre erste Website auf drei Wegen](ihre-erste-website-auf-drei-wegen.md) |
| **Lernpfad** | Eine Reihenfolge von Hilfeseiten für eine Rolle | [Einen Lernpfad wählen](einen-lernpfad-waehlen.md) |
| **Lernprojekt** | Ein bewertetes Übungsprojekt auf Ihrer Lernwebsite | [Lernprojekte: Überblick](lernprojekte-ueberblick.md) |
| **Bewertungsraster** | Die Kriterien und Prüfungen, nach denen ein Projekt bewertet wird | [Die eigene Arbeit bewerten](die-eigene-arbeit-bewerten.md) |
| **Abschlussprojekt** | Das letzte Projekt, das die anderen zusammenführt | [Projekt 10](projekt-10-abschlussprojekt-eine-vollstaendige-kleine-website.md) |
| **Lerntagebuch** | Ihre Notizen, ein Eintrag pro Sitzung | [Ein Lerntagebuch führen](ein-lerntagebuch-fuehren.md) |
| **Stufe Student** | Die Stufe für 25 $ im Monat im Exponential Partner Program | [Die Partnerstufe Student](die-partnerstufe-student.md) |
| **Abschlusszertifikat** | Die Erklärung eines Trainers, dass Sie seine Prüfung bestanden haben; keine offizielle Zertifizierung (diese sind geplant, aber noch nicht verfügbar) | [Zertifizierungen und Zertifikate](zertifizierungen-und-zertifikate.md) |
| **Demomodus** | Eine Servereinstellung für öffentliche Demos, in der Administratorpasswörter nicht geändert werden können | [Demomodus-FAQ](../demomodus-faq.md) |

# Ihr Portfolio kostenlos auf GitHub Pages veröffentlichen

Ein Portfolio überzeugt mehr, wenn man es öffnen kann. Mit statischem Veröffentlichen bauen Sie die Website in
Exponential auf Ihrem eigenen Rechner oder einem Laborserver und veröffentlichen eine statische Kopie auf GitHub Pages,
wo sie kostenlos gehostet wird.

## Was Sie am Ende haben

- Ihr Portfolio unter `https://<ihr-name>.github.io/<repository>/`, oder unter `https://<ihr-name>.github.io/`, wenn
  das Repository `<ihr-name>.github.io` heißt.
- Ein öffentliches Repository mit einem Commit und einem Tag pro Veröffentlichung: eine sichtbare Geschichte Ihrer Arbeit.
- Eine Fähigkeit, die Sie in einer Bewerbung nennen können: Inhaltsmodellierung, Templates, Git und Deployment.

## Warum es ein gutes Projekt fürs Studium ist

- **Es kostet nichts.** Kein Hosting-Tarif, keine Kreditkarte. Der kostenlose Tarif von GitHub hostet öffentliche Websites.
- **Ihre Installation kann auf Ihrem Laptop bleiben.** Nur die Kopie ist öffentlich; nichts muss laufen, wenn Sie den Deckel schließen.
- **Es zeigt echte Arbeit.** Arbeitgeber sehen die Website, die Git-Geschichte und, wenn Sie möchten, den Code Ihres
  Designs in einem zweiten Repository.
- **Sie lernen den ganzen Weg.** Inhalt, Design, Build, Prüfung, Veröffentlichung, Rücknahme.

## Ideen für den Inhalt

- Eine kurze Seite über Sie, mit dem, was Sie suchen.
- Eine Seite pro Projekt: das Problem, was Sie getan haben, ein Bild, ein Link zum Code.
- Ein Blog über das, was Sie gelernt haben. Zum Aufbau siehe [Ein Portfolio aufbauen](ein-portfolio-aufbauen.md).

## Gut zu wissen

- Lassen Sie das Repository öffentlich: GitHub Pages liefert im kostenlosen Tarif nur öffentliche Repositorys aus.
- Formulare wie ein Kontaktformular laufen nicht auf einem statischen Host; schreiben Sie Ihre E-Mail-Adresse oder einen Link.
- Veröffentlichen Sie nichts, was Sie einem Arbeitgeber nicht zeigen würden. Builds laufen als anonymer Besucher, also
  bleiben Entwürfe und unveröffentlichte Inhalte draußen. Siehe
  [Private Inhalte privat halten](../statisches-veroeffentlichen/private-inhalte-privat-halten.md).
- Ihren eigenen Namen als Adresse? Siehe [Eigene Domain verwenden](../statisches-veroeffentlichen/eigene-domain-verwenden.md).
- Neu bei GitHub? [Was statisches Veröffentlichen ist](../statisches-veroeffentlichen/was-statisches-veroeffentlichen-ist.md) erklärt die Begriffe.

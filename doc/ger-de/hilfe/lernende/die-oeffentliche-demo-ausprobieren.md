# Die öffentliche Demo ausprobieren

Am schnellsten sehen Sie Exponential in der öffentlichen Demo des Projekts. Sie brauchen nur einen Browser. Diese
Seite sagt Ihnen, wo sie ist, was Sie ausprobieren können und warum Sie bald eine eigene Website haben möchten.

## Wo die Demo ist

| Was | Adresse | Quelle |
|---|---|---|
| Die Website | [demo.exponential.earth](https://demo.exponential.earth/) | [Kanäle der Community](../projekt/community-kanaele.md#ausprobieren-die-demo) |
| Die Administrationsoberfläche | [edit.demo.exponential.earth](https://edit.demo.exponential.earth/) | ebenda |
| Die Anmeldedaten | Die [Community-Seite](https://exponential.earth/about/community) der Website | ebenda |

Das Projekt beschreibt sie als „eine öffentliche Demo des neuesten Exponential 6 mit dem Design 7x Simple und einem
Shop“ und sagt, dass alles in der Demo jeden Tag zurückgesetzt wird ([Kanäle der Community](../projekt/community-kanaele.md#ausprobieren-die-demo),
[Über das Projekt](../projekt/ueber-das-projekt.md#die-öffentliche-demo)).

Diese Seite gibt die Anmeldedaten nicht wieder. Entnehmen Sie sie der Community-Seite; das Administratorpasswort einer
öffentlichen Demo ist absichtlich veröffentlicht, wie die [Demomodus-FAQ](../demomodus-faq.md) erklärt.

## Der Demomodus in einer Minute

Eine öffentliche Demo läuft im **Demomodus**. Sie sehen in der Administrationsoberfläche ein gelbes Banner
**Demo-Modus**. Im Demomodus können Administratorpasswörter weder geändert noch zurückgesetzt werden, sodass die
veröffentlichte Anmeldung für den nächsten Besucher weiter funktioniert. Alles andere funktioniert weiterhin: Sie
können Inhalte bearbeiten, Konten anlegen und Einstellungen ändern, weshalb die Demo nach Zeitplan neu aufgebaut wird
([Demomodus-FAQ](../demomodus-faq.md#was-sperrt-er-nicht), [Demomodus](../demomodus.md)).

## Was Sie in Ihrer ersten Stunde ausprobieren

1. **Sehen Sie sich die Website** als Besucher an: die Startseite, eine Liste, einen Artikel, die Suche.
2. **Melden Sie sich** mit den veröffentlichten Daten an der Administrationsoberfläche an. Lesen Sie das Dashboard
   ([Erste Schritte](../erste-schritte.md#2-umsehen)).
3. **Öffnen Sie die Inhaltsstruktur** und finden Sie das Element hinter einer Seite, die Sie auf der Website gesehen
   haben.
4. **Bearbeiten** Sie dieses Element, ändern Sie seinen Titel und **Zur Veröffentlichung schicken**. Laden Sie die
   Website neu.
5. **Sehen Sie sich die Versionen** des Elements an und kehren Sie zur früheren zurück
   ([Veröffentlichen, Versionen und der Papierkorb](../veroeffentlichen-und-versionen.md)).
6. **Öffnen Sie den Reiter Layouts**, falls er angezeigt wird, und sehen Sie sich ein Layout im Editor an, ohne zu
   veröffentlichen ([Der Layouts-Editor](../layout-editor.md)).
7. **Öffnen Sie die Hilfe** in der Administrationsoberfläche und suchen Sie nach einem Wort, dem Sie begegnet sind.

Schreiben Sie in Ihr [Lerntagebuch](ein-lerntagebuch-fuehren.md), was Sie ausprobiert haben und was Sie überrascht hat.

## Was die Demo Ihnen nicht beibringen kann

| Sie können nicht | Weil | Tun Sie es auf |
|---|---|---|
| Installieren, neu installieren oder aktualisieren | Die Demo ist für Sie installiert | [Ihrer eigenen Lernwebsite](eine-lernwebsite-mit-einem-befehl-installieren.md) |
| Die Kommandozeile nutzen | Die Demo hat kein Terminal für Besucher | Ihrer eigenen Lernwebsite |
| Administratorpasswörter ändern | Der Demomodus verhindert es | Ihrer eigenen Lernwebsite |
| Ihre Arbeit behalten | Die Demo wird jeden Tag zurückgesetzt | Ihrer eigenen Lernwebsite, mit Ihrer Arbeit in Git |
| Ungestört arbeiten | Andere Besucher nutzen dieselbe Demo zur selben Zeit | Ihrer eigenen Lernwebsite |

Gehen Sie nach ein oder zwei Sitzungen auf der Demo weiter: [Ihre erste Website auf drei Wegen](ihre-erste-website-auf-drei-wegen.md).

## Gute Umgangsformen auf einer gemeinsamen Demo

- Verwenden Sie erfundene Inhalte. Geben Sie keine personenbezogenen Daten ein, weder Ihre noch die anderer.
- Laden Sie nichts hoch, was Sie nicht teilen dürfen.
- Entfernen oder beschädigen Sie nichts aus reinem Selbstzweck; auch andere Lernende nutzen die Demo.
- Wenn auf der Demo etwas kaputt aussieht, melden Sie es im
  [Issue-Tracker der Community](https://github.com/se7enxweb/exponential-community/issues), der für „das Projekt, die
  Website, das Ökosystem“ da ist ([Wenn etwas schiefgeht](../wenn-etwas-schiefgeht.md#einen-fehler-in-exponential-melden)).

# Ein Portfolio aufbauen und Aufträge finden

Diese Seite ist für Theme-Designer, die an Exponential-Projekten arbeiten möchten: Freiberufler, Designer in Agenturen und
Studierende. Sie behandelt, was ein starkes Portfolio-Stück für eine inhaltsverwaltete Website ausmacht, wie Arbeit an
Open Source Ihr Können zeigt und welche Kanäle es heute gibt. Sie verspricht keine Programme, die nicht veröffentlicht
sind; die Seiten zum Partnerprogramm sagen, was es gibt ([Partner: hier beginnen](../partner/partner-hier-beginnen.md)).

## Worauf Kunden achten

Organisationen, die ein Content-Management-System wählen, wollen einen Designer, der versteht, dass Redakteure die
Website füllen. Zeigen Sie, dass Sie:

- für Inhalte in ihren Extremen gestalten können ([Mit echten Inhalten gestalten](mit-echten-inhalten-gestalten.md));
- Systeme gestalten, keine Seiten: Tokens, Komponenten, Ansichtsmodi ([Komponenteninventar](komponenteninventar.md));
- barrierefreie, für den Dunkelmodus bereite, mehrsprachige Arbeit liefern;
- mit Entwicklern arbeiten und sauber übergeben ([Checkliste zur Übergabe](checkliste-zur-uebergabe.md)).

## Portfolio-Stücke, die es zeigen

| Stück | Was es beweist |
|---|---|
| Eine Fallstudie einer Website: Problem, Inhaltsmodell, Designsystem, Ergebnis | Sie gestalten für Inhalte und Redakteure |
| Das Komponenteninventar und das Token-Blatt eines Projekts | Sie gestalten Systeme |
| Vorher und nachher mit echten Inhalten von Redakteuren | Ihr Design übersteht den echten Gebrauch |
| Hell und dunkel, Desktop und Telefon, links nach rechts und rechts nach links | Breite und Sorgfalt |
| Ein veröffentlichtes Theme auf GitHub mit einer Demo | Sie bringen Dinge zu Ende und pflegen sie |

Eine Fallstudie ist mit Fakten stärker: was sich geändert hat und wie es gemessen wurde. Die Partnerseiten erklären, wie
Sie eine schreiben, der andere vertrauen können ([Eine Fallstudie schreiben](../partner/eine-fallstudie-schreiben.md)).

## Arbeit zeigen, ohne Kunden bloßzustellen

- Bitten Sie um eine schriftliche Erlaubnis, bevor Sie Arbeit für Kunden zeigen; oft regeln das die Verträge
  ([Verträge und Bedingungen](../designer/verkauf/vertraege-und-bedingungen.md)).
- Zeigen Sie nie echte Kunden- oder personenbezogene Daten auf Bildschirmfotos: Ersetzen Sie Namen, Adressen und
  Benutzerdaten, und verwenden Sie in Demokonten Adressen unter `example.invalid`
  ([Kundendaten und Datenschutz](../designer/verkauf/kundendaten-und-datenschutz.md)).
- Dürfen Sie die Arbeit nicht zeigen, zeigen Sie die Methode: eine nachgebaute, anonymisierte Fassung des
  Komponenteninventars oder ein ähnliches eigenes Theme.

## Open Source als Portfolio

Öffentliche Arbeit ist das am besten überprüfbare Portfolio:

- **Ein Theme veröffentlichen.** Ein kleines, gut gemachtes Theme mit Demo-Website, Dokumentation und klarer Lizenz
  zeigt das ganze Handwerk ([Ein Theme verteilen: hier beginnen](../designer/veroeffentlichung/ein-theme-veroeffentlichen-hier-beginnen.md),
  [Ein Theme veröffentlichen](../partner/ein-theme-veroeffentlichen.md)).
- **Zurückgeben.** Beheben Sie ein Problem mit Barrierefreiheit oder Dunkelmodus in einem mitgelieferten Design,
  verbessern Sie die Hilfe für Designer oder übersetzen Sie sie
  ([Beiträge an das Upstream-Projekt zurückgeben](../designer/lebenszyklus/an-upstream-zurueckgeben.md),
  [Freie Dokumentation](../freie-dokumentation.md)).
- **Fragen beantworten** im Designforum des Community-Portals
  ([Ein Theme auf share.exponential.earth ankündigen](../designer/veroeffentlichung/ankuendigen-auf-share-exponential-earth.md)).

## Wo es Exponential-Aufträge gibt

Es gibt keinen offiziellen Marktplatz für Themes. Themes und ihre Autoren findet man über GitHub, Packagist, das
Community-Portal, Projektlisten, Demo-Websites und die eigenen Websites der Autoren; der Vertriebsbereich der Hilfe für
Designer beschreibt diese Kanäle, wie sie sind ([Wo Exponential-Themes heute gefunden werden](../designer/verkauf/wo-themes-zu-finden-sind.md)).
Viele Aufträge kommen über Agenturen und Implementierungspartner, die Designkapazität brauchen
([Mit Agenturen und Partnern arbeiten](../designer/verkauf/zusammenarbeit-mit-agenturen-und-partnern.md)).

## Das Partnerprogramm

Das Exponential-Partnerprogramm hat ein Profil **Kreativpartner** für Designstudios und Agenturen
([Kreativpartner](../partner/kreativpartner.md)) und ein Profil für alle, die Erweiterungen und Themes veröffentlichen
([Partner für Erweiterungen und Themes](../partner/partner-fuer-erweiterungen-und-themes.md)). Das Programm nennt eine
Design-Zertifizierung, aber ihr Lehrplan und ihre Prüfungen sind nicht veröffentlicht; stellen Sie keinen Kurs und kein
selbst gemachtes Zertifikat als diese Zertifizierung dar ([Zertifizierungen](../partner/zertifizierungen.md)). Studierende
haben eine eigene Stufe ([Partner für Studierende und Bildung](../partner/partner-fuer-studierende-und-bildung.md)). Stufen,
Vorteile und Preise stehen auf den Partnerseiten; diese Seite wiederholt sie nicht.

## Ein Plan für neunzig Tage

1. **Tage 1 bis 30:** Arbeiten Sie die [Lesepfade](lesepfade-fuer-theme-designer.md) durch; bauen Sie auf einer
   Entwicklungsinstallation ein kleines Theme mit Tokens, Dunkelmodus und einer Styleguide-Seite.
2. **Tage 31 bis 60:** Veröffentlichen Sie es mit README, Lizenz und Bildschirmfotos; beheben Sie ein Problem in einem
   mitgelieferten Design oder der Hilfe und reichen Sie es ein.
3. **Tage 61 bis 90:** Schreiben Sie eine Fallstudie (Ihr eigenes Theme zählt), kündigen Sie das Theme im
   Community-Portal an und sprechen Sie mit der Fallstudie zwei Agenturen oder Partner an.

# Ehrlichkeit und Genauigkeit

Diese Seite ist für jeden Fürsprecher. Die Dokumentation, die Sie zitieren, hält sich an eine Regel: „Jede Aussage
nennt ihre Quelle ... Die Seite beschreibt nicht, was die Quellen nicht sagen“
([Wer ist die Exponential Foundation?](../wer-ist-die-exponential-foundation.md)). Halten Sie sich an dieselbe Regel.

## Fünf Gewohnheiten

1. **Prüfen Sie, bevor Sie es sagen.** Öffnen Sie die Quelle; das Gedächtnis trügt ([Wo die Fakten stehen](wo-die-fakten-stehen.md)).
2. **Datieren Sie Ihre Fakten.** „Am 18. Oktober 2026 verlangte der Kernel 66 Pakete von se7enxweb.“ Zahlen ändern sich.
3. **Zitieren Sie genau.** Setzen Sie Zitate in Anführungszeichen; sonst formulieren Sie mit eigenen Worten.
4. **Sagen Sie, was nicht dokumentiert ist.** „Die Quellen sagen es nicht“ ist eine ehrliche, vollständige Antwort.
5. **Korrigieren Sie offen** ([Aussagen, die Sie nicht machen dürfen](aussagen-die-sie-nicht-machen-duerfen.md#wenn-sie-sich-geirrt-haben)).

## Tatsache oder Meinung?

| Tatsache (braucht eine Quelle) | Meinung (sagen Sie, dass es Ihre ist) |
|---|---|
| „Fünfzehn Releases 6.0.x seit dem 1. Januar 2024.“ | „Ich finde das Release-Tempo beruhigend.“ |
| „Exponential Intelligence schreibt nur Entwürfe.“ | „Mir gefällt, dass ein Mensch die Kontrolle behält.“ |
| „Die Administration hat einen Dunkelmodus.“ | „Im Dunkelmodus sieht sie großartig aus.“ |

Kennzeichnen Sie Meinungen mit „ich finde“, „für mich“, „nach meiner Erfahrung“.

## Eine Routine zum Prüfen von Fakten

```text
FOR EACH CLAIM IN MY POST / TALK
[ ] Source found and opened today: <link>
[ ] Source says exactly this (not more)
[ ] Number has a date
[ ] Name written correctly
[ ] Not on the "Claims you must not make" list
[ ] Opinions marked as mine
```

## Sich selbst korrigieren

Eine Korrektur kostet eine Minute und bringt Vertrauen. Bearbeiten Sie den Beitrag mit einer sichtbaren Zeile
„Korrektur:“, sagen Sie es den Menschen, die die Aussage wiederholt haben, und aktualisieren Sie Ihre Notizen, damit es
nicht wieder passiert.

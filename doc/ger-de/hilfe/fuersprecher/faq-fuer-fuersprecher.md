# Häufige Fragen von Fürsprechern

Diese Seite ist für Fürsprecher mit einer kurzen Frage zur Fürsprache selbst.

| Frage | Antwort | Seite |
|---|---|---|
| Brauche ich eine Erlaubnis, um Fürsprecher zu sein? | Nein. Helfen Sie Menschen ehrlich, und Sie sind einer | [Was ein Fürsprecher ist](was-ein-fuersprecher-ist.md) |
| Gibt es ein offizielles Programm für Fürsprecher oder Botschafter? | Keines ist dokumentiert. Behaupten Sie keines | [Aussagen, die Sie nicht machen dürfen](aussagen-die-sie-nicht-machen-duerfen.md#veranstaltungen-und-programme) |
| Darf ich für 7x oder die Foundation sprechen? | Nur, wenn diese Sie darum bitten. Sonst sprechen Sie als Sie selbst | [Offenlegung und Interessenkonflikte](offenlegung-und-interessenkonflikte.md) |
| Darf ich das Logo verwenden? | Die Quellen legen keine Logoregeln für Dritte fest; fragen Sie den Inhaber | [Marken- und Namensregeln](../geschaeft/marken-und-namensregeln.md#was-die-quellen-nicht-entscheiden) |
| Darf ich für Beiträge oder Vorträge bezahlt werden? | Ja, wenn Sie es deutlich offenlegen | [Offenlegung und Interessenkonflikte](offenlegung-und-interessenkonflikte.md) |
| Wie zeige ich in einer Demo, „was diese Installation ist“? | Führen Sie `./console exp:about` aus: das Logo, die Fakten und das Projekt auf einem Bildschirm, ohne Geheimnisse | [Die Systemkarte in Demos](die-systemkarte-in-demos.md) |
| Darf ich ein „Exponential-Treffen“ organisieren? | Ja, als Ihre eigene Veranstaltung, deutlich so benannt | [Ein Treffen vorschlagen](ein-treffen-vorschlagen.md) |
| Darf ich Hilfeseiten in meinen Blog kopieren? | Unter den Bedingungen der GNU FDL; am einfachsten ist ein Zitat mit Link | [Quellen zitieren und Ihre Texte lizenzieren](quellen-zitieren-und-texte-lizenzieren.md) |
| Was, wenn ich etwas Falsches gesagt habe? | Korrigieren Sie es offen | [Ehrlichkeit und Genauigkeit](ehrlichkeit-und-genauigkeit.md) |
| Wie viel Zeit kostet es? | So viel, wie Sie haben; eine Antwort pro Woche hilft | [Was ein Fürsprecher ist, Arten der Fürsprache](was-ein-fuersprecher-ist.md#arten-der-fürsprache) |
| Jemand hat mir von einer Sicherheitslücke erzählt | Leiten Sie sie vertraulich weiter | [Sicherheitsmeldungen bleiben vertraulich](sicherheitsmeldungen-bleiben-vertraulich.md) |
| Wo schlage ich Ideen für das Projekt vor? | Im Issue-Tracker der Community | [Welcher Tracker für welche Meldung](welcher-tracker-fuer-welche-meldung.md) |
| Gibt es einen Verhaltenskodex? | Ja: CODE_OF_CONDUCT.md, der Contributor Covenant 2.1 mit Ergänzungen von Exponential; Meldungen an community@se7enx.com | [Der Verhaltenskodex von Exponential](../projekt/verhaltenskodex.md), [Verhalten und Ethik für Fürsprecher](verhalten-und-ethik.md) |
| Muss ein Beitragender etwas unterzeichnen? | Für Code-Beiträge zum Kernel ja: ein Contributor Licensing Agreement, einmal, vor dem ersten Merge. Mit Unterschrift und Einreichung überträgt er das Urheberrecht an dem Beitrag an 7x und gibt die Kontrolle darüber ab: 7x darf ihn verwenden, ändern, neu lizenzieren und verbreiten, ohne ihn zu fragen oder zu bezahlen, und er kann ihn nicht zurückziehen. Seine eigenen Erweiterungen brauchen nichts | [Übertragung des Urheberrechts (CLA)](../../../../CONTRIBUTING.md#copyright-assignment-cla) |
| Wie unterstütze ich das Projekt finanziell? | Über die zwei Seiten bei GitHub Sponsors | [Für nachhaltige Finanzierung eintreten](fuer-nachhaltige-finanzierung-eintreten.md) |
| Wo fange ich an? | Mit Ihrer ersten Stunde, dann Ihrer ersten Woche | [Fürsprecher: hier beginnen](fuersprecher-hier-beginnen.md#ihre-erste-stunde) |

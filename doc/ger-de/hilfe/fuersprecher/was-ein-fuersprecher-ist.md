# Was ein Exponential-Fürsprecher ist

Diese Seite ist für alle, die Exponential beim Wachsen helfen möchten, indem sie darüber sprechen, es zeigen und anderen
damit helfen. Sie beantwortet: Was tut ein Fürsprecher, was tut er nicht, und wie unterscheidet sich die Rolle vom
Vertrieb oder vom Sprechen für 7x oder die Exponential Foundation?

## In einem Satz

Ein Exponential-Fürsprecher ist ein Mensch, der aus eigenem Antrieb anderen hilft, Exponential zu entdecken, zu
verstehen, zu nutzen und dazu beizutragen, und der die Wahrheit sagt, mit einer Quelle für jede Aussage.

## Was Fürsprecher tun

| Tätigkeit | Beispiel | Seite |
|---|---|---|
| Fragen beantworten | Eine Antwort im Forum oder auf Telegram mit einem Link auf die richtige Hilfeseite | [Fragen gut beantworten](fragen-gut-beantworten.md) |
| Das Produkt zeigen | Eine kurze Demo für eine Kollegin, eine Benutzergruppe oder eine Klasse | [Demos als Fürsprecher zeigen](demos-zeigen.md) |
| Schreiben | Ein Blogbeitrag, ein Tutorial, eine Zusammenfassung eines Release, ein eZpedia-Artikel | [Einen Blogbeitrag schreiben](einen-blogbeitrag-schreiben.md) |
| Menschen willkommen heißen | Eine neue Person begrüßen und auf ihren ersten Schritt verweisen | [Neue willkommen heißen](neue-willkommen-heissen.md) |
| Die Dokumentation verbessern | Eine Hilfeseite mit **Auf GitHub bearbeiten** korrigieren | [Die Hilfe verbessern](die-hilfe-verbessern.md) |
| Übersetzen | Die Administration in Ihrer Sprache vervollständigen oder gegenlesen | [Bei Übersetzungen helfen](bei-uebersetzungen-helfen.md) |
| Fehler gut melden | Ein klares Issue im richtigen Tracker | [Fehler gut melden](fehler-gut-melden.md) |
| Organisieren | Ein Treffen, eine Online-Sitzung oder einen Sprint vorschlagen | [Ein Treffen vorschlagen](ein-treffen-vorschlagen.md) |
| Für Werte eintreten | Barrierefreiheit, Sicherheit, Open Source, freie Dokumentation | [Für Barrierefreiheit eintreten](fuer-barrierefreiheit-eintreten.md) |
| Zur Finanzierung ermutigen | Die zwei Sponsorenseiten erklären und was sie finanzieren | [Für nachhaltige Finanzierung eintreten](fuer-nachhaltige-finanzierung-eintreten.md) |

## Was Fürsprecher nicht tun

- **Für 7x oder die Foundation sprechen**, es sei denn, eine der beiden hat darum gebeten. Sagen Sie „ich“, nicht „wir“,
  wenn Sie sich selbst meinen.
- **Etwas versprechen**: keine Termine für Releases, keine Funktionen, die nicht dokumentiert sind, keine
  Reaktionszeiten im Support. Die einzige dokumentierte Zeit ist die erste Antwort auf eine Sicherheitsmeldung,
  „innerhalb eines Werktags“ ([SECURITY.md](https://github.com/se7enxweb/exponential/blob/main/SECURITY.md)).
- **Zahlen erfinden**: Benutzer, Installationen, Entwickler oder Marktanteil. Die Quellen zählen sie nicht
  ([Aussagen, die Sie nicht machen dürfen](aussagen-die-sie-nicht-machen-duerfen.md)).
- **Andere Projekte angreifen.** Vergleichen Sie nur mit Fakten, die beide Seiten prüfen können
  ([Andere Projekte und Unternehmen respektieren](andere-projekte-respektieren.md)).
- **Sicherheitsprobleme öffentlich behandeln.** Sie gehen vertraulich an die Adresse in `SECURITY.md`
  ([Sicherheitsmeldungen bleiben vertraulich](sicherheitsmeldungen-bleiben-vertraulich.md)).
- **Personenbezogene Daten** der Menschen, denen sie helfen, **sammeln oder teilen** ([Die Privatsphäre von Menschen schützen](privatsphaere-schuetzen.md)).

## Fürsprecher, Vertrieb, offizielle Vertretung

| | Fürsprecher | Vertrieb und Marketing | Offizielle Vertretung |
|---|---|---|---|
| Wer | Jeder Benutzer, Entwickler, Designer, Übersetzer, jedes Unternehmen | Menschen, die Dienstleistungen oder Produkte rund um Exponential verkaufen | Menschen, die 7x oder die Foundation gebeten haben, für sie zu sprechen |
| Spricht für | Sich selbst | Ihren Arbeitgeber | Die Organisation, die sie gebeten hat |
| Ziel | Mehr Menschen geholfen, mehr Beitragende | Kunden für ihre Organisation | Die Botschaften der Organisation |
| Typischer Kanal | Foren, Telegram, Blogs, Benutzergruppen | Angebote, Ausschreibungen, Demos für Käufer | Offizielle Ankündigungen, die Websites des Projekts |
| Seiten | Dieser Bereich | [Vertrieb und Marketing: hier beginnen](../geschaeft/vertrieb-und-marketing-hier-beginnen.md) | Fragen Sie die Organisation |

Eine Person kann zu verschiedenen Zeiten alle drei sein. Sagen Sie in jedem Gespräch, welchen Hut Sie tragen
([Offenlegung und Interessenkonflikte](offenlegung-und-interessenkonflikte.md)).

## Warum das Projekt Fürsprecher braucht

Die eigenen Quellen des Projekts beschreiben ein Projekt, bei dem die Community zuerst kommt:

- „Das Exponential-Projekt und die Exponential Foundation unterstützen die Open-Source-Community direkt, als Teil unserer
  täglichen Routine und Arbeitsethik, und stellen die Support-Bedürfnisse der Community-Benutzer an erste Stelle“
  ([Wer ist die Exponential Foundation?](../wer-ist-die-exponential-foundation.md#was-die-foundation-ist)).
- Die Mission der Foundation umfasst „Verbreitung“, „Support“, „Bildung“, „Werbung“ und „Dokumentation“
  ([Kurz gesagt](../wer-ist-die-exponential-foundation.md#kurz-gesagt)). Genau das tun Fürsprecher, ehrenamtlich.
- Jeder Pull Request wird übernommen, und die Commits des Beitragenden bleiben erhalten
  ([Wie das Projekt wächst](../wer-ist-die-exponential-foundation.md#wie-das-projekt-wächst)): Das Projekt will Beiträge,
  und Fürsprecher bringen Beitragende.

## Arten der Fürsprache

| Art | Zeit pro Monat | Gut für |
|---|---|---|
| **Helfer**: Fragen beantworten, Links teilen | 1 bis 2 Stunden | Alle |
| **Schreibende**: Beiträge, Tutorials, eZpedia | 4 bis 8 Stunden | Menschen, die gern erklären |
| **Vortragende**: Vorträge, Demos, Workshops | Ein paar Abende | Menschen, die gern präsentieren |
| **Organisierende**: Treffen, Sprints | Laufend | Menschen, die gern andere zusammenbringen |
| **Erschaffende**: Dokumentation, Übersetzungen, Fehlerberichte, Korrekturen | Beliebig | Menschen, die gern etwas machen |
| **Unterstützende**: sponsern, den Arbeitgeber zum Sponsoring ermutigen | Minuten | Alle, die es können |

Die Zeitangaben sind Vorschläge für die Planung, keine Anforderungen.

## Eine Selbstprüfung

```text
[ ] I can say what Exponential is in one sentence, and cite the README
[ ] I know the difference between 7x and the Exponential Foundation
[ ] I know which names to use and which old name belongs only to history
[ ] I know where to send a bug, a question and a security problem
[ ] I say "I" when I speak for myself and disclose who pays me, if anyone
[ ] I have read "Claims you must not make"
```

Wenn eine Zeile nicht abgehakt ist, lesen Sie zuerst [Fürsprecher: hier beginnen](fuersprecher-hier-beginnen.md#ihre-erste-stunde).

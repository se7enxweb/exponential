# Barrierefreie Folien und Grafiken

Diese Seite ist für Fürsprecher, die Folien, Diagramme, Screenshots und Bilder für soziale Medien erstellen. Die
Administration von Exponential ist auf Barrierefreiheit gebaut und getestet ([Gesprächspunkte: Barrierefreiheit](gespraechspunkte-barrierefreiheit.md));
Material darüber sollte denselben Maßstab erfüllen. Barrierefreies Material funktioniert auch für alle besser: in hellen
Räumen, auf kleinen Telefonen und für Menschen, die in einer Zweitsprache lesen.

## Folien

- **Große Schrift**: etwa 24 Punkt oder mehr für Fließtext; eine Idee pro Folie.
- **Kontrast**: dunkler Text auf hellem Hintergrund oder umgekehrt; die eigene Regel der Administration für Text ist ein
  Kontrast von mindestens 4,5:1 ([Die Administration gestalten](../../../en/us/bc/6.0/admin4-styling.md)), auch für Folien ein
  gutes Ziel.
- **Schriften**: schlichte serifenlose Schriften; kein Text über unruhigen Fotos.
- **Verlassen Sie sich nicht auf Farbe**: „die rote“ bedeutet für farbenblinde Zuschauer nichts; fügen Sie eine
  Beschriftung hinzu.
- **Folientitel**: Jede Folie hat einen echten Titel; Screenreader und Gliederungen nutzen ihn.
- **Lesereihenfolge**: Wenn Sie die Datei teilen, prüfen Sie, ob ein Screenreader die Folie in der richtigen Reihenfolge
  liest.
- **Bewegung**: Vermeiden Sie Blinken und schnelle Animationen.
- **Teilen Sie die Folien** als barrierefreie Datei (getaggtes PDF oder die Quelle) und die Sprechernotizen als Text.

## Bilder und Screenshots

- **Alternativtext** für jedes Bild, das Information trägt: was es zeigt und warum es wichtig ist, zum Beispiel „Der
  Layouts-Editor, in dem ein Titel-Block in die Hauptzone gezogen wird“.
- **Dekorative Bilder** bekommen einen leeren Alternativtext, wo das Werkzeug es erlaubt.
- **Schneiden Sie zu**, was wichtig ist; vergrößern Sie den Teil, über den Sie sprechen.
- **Keine personenbezogenen Daten**: nur erfundene Namen und Inhalte ([Die Privatsphäre von Menschen schützen](privatsphaere-schuetzen.md)).
- **Keine Geheimnisse**: keine Schlüssel, Passwörter, Serveradressen oder Einstellungsdateien ([Sicherheit bei Live-Demos](sicherheit-bei-live-demos.md)).
- **Hell und dunkel**: Wenn Sie beide Modi zeigen, beschriften Sie sie.
- **Nennen Sie die Version** in der Bildunterschrift: „Exponential 6.0.15, Design admin4“.

## Code auf Folien

- Höchstens etwa 10 Zeilen, große Festbreitenschrift, hoher Kontrast.
- Heben Sie die wichtige Zeile so hervor, dass es nicht nur von der Farbe abhängt (ein Pfeil, Fettdruck, ein Rahmen).
- Stellen Sie den vollständigen, kopierbaren Code auf eine verlinkte Seite oder in die Sprechernotizen; von einem
  Projektor kann niemand kopieren.
- Bleiben Sie echt: Befehle, die es gibt, wie in [Installation mit einem Befehl](../../../en/us/features/6.0/install-in-one-command.md).

## Diagramme und Grafiken

- Beschriften Sie jeden Kasten und jeden Pfeil mit Worten.
- Beschreiben Sie das Diagramm in ein oder zwei Sätzen im Alternativtext oder darunter.
- Grafiken: nur mit echten, belegten Zahlen, mit Datum und Quelle auf der Folie
  ([Aussagen, die Sie nicht machen dürfen](aussagen-die-sie-nicht-machen-duerfen.md)).

## Bilder für soziale Medien

- Schreiben Sie den wesentlichen Text in den Beitrag, nicht nur ins Bild.
- Fügen Sie Alternativtext hinzu, wo die Plattform es erlaubt.
- Verwenden Sie die Produktnamen korrekt ([Kurzkarte zu den Namensregeln](kurzkarte-namensregeln.md)).
- Verwenden Sie Logos nicht auf eine Weise, die die Inhaber nicht erlaubt haben; die Quellen legen keine Logoregeln für
  Dritte fest ([Marken- und Namensregeln, Was die Quellen nicht entscheiden](../geschaeft/marken-und-namensregeln.md#was-die-quellen-nicht-entscheiden)).

## Checkliste

```text
[ ] Body text large enough; one idea per slide; every slide has a title
[ ] Contrast checked; nothing depends on color alone
[ ] Every informative image has alternative text; decorative ones are marked
[ ] Screenshots: invented data only, no secrets, version in the caption
[ ] Code: short, large, real; full version linked
[ ] Diagrams labeled and described
[ ] No flashing; animations optional
[ ] Shared file is accessible (titles, reading order); notes available as text
[ ] Videos captioned, with a transcript
```

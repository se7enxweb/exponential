# Vorlagen für Beiträge in sozialen Medien

Diese Seite ist für Fürsprecher, die schnell etwas veröffentlichen möchten, ohne Fakten oder Namen falsch zu machen. Jede
Vorlage ist kurz genug für die meisten Netzwerke. Ersetzen Sie die Teile `<...>`, prüfen Sie die Quelle und
veröffentlichen Sie nie eine Vorlage unverändert: Menschen merken Kopieren und Einfügen.

## Wie Sie die Vorlagen verwenden

- Prüfen Sie die Fakten auf der verlinkten Seite am Tag, an dem Sie veröffentlichen.
- Fügen Sie einen eigenen Satz hinzu: warum es Ihnen wichtig ist.
- Fügen Sie Bildern Alternativtext hinzu ([Barrierefreie Folien und Grafiken](barrierefreie-folien-und-grafiken.md#bilder-für-soziale-medien)).
- Fügen Sie bei Bedarf eine Offenlegung hinzu ([Offenlegung und Interessenkonflikte](offenlegung-und-interessenkonflikte.md)).
- Für ein deutschsprachiges Publikum übersetzen Sie die Vorlagen und behalten Namen, Befehle und Links bei.

## Release und Neuigkeiten

```text
RELEASE (only after the tag exists)
Exponential <6.0.x> is out. What I like most: <feature> - <one sentence why>.
Changelog: <link>   How to upgrade safely: <link to the upgrade chapter>

IN DEVELOPMENT (say so clearly)
Coming in the Exponential <6.0.x> development line (not released yet): <feature>. Docs: <link>.

HISTORY
This month in Exponential history, <Month Year>: <one change and why it mattered>. <link to the month page>
```

Quellen: [Über ein Release schreiben](ueber-ein-release-schreiben.md), [Beiträge zur Geschichte schreiben](beitraege-zur-geschichte-schreiben.md).

## Lernen und Hilfe

```text
HELP PAGE
Didn't know this: in Exponential, <what the page explains>. The help page: <link>

TUTORIAL
New tutorial: <task> with Exponential, step by step, tested on <6.0.x>. <link>

TRY IT
Want to try Exponential? One command gives you a complete site on SQLite, no database server:
./console exp:install --apply   Docs: <link to Install in one command>

FEATURE
Editors in Exponential can <feature>, without a developer. 2-minute walkthrough: <link>
```

## Aufrufe an die Community

```text
TRANSLATION
Do you speak <language>? Exponential's admin is <complete but machine-assisted | partly translated> in it.
Reviewers and translators welcome: <link to the translation help>. #OpenSource

QUESTION HELPERS
Know Exponential a bit? A few questions in the forums could use an answer this week:
share.exponential.earth/forums

MEETUP PROPOSAL (your own event)
I'm organizing an informal Exponential meetup <online | in <city>> on <date>. Not an official event - just
users and developers sharing what they built. Details and sign-up: <link>

FIRST CONTRIBUTION
Want to make your first open source contribution? Improve a help page of Exponential with "Edit on GitHub".
Every pull request is merged. How: <link to Improving the help>
```

Die Vorlage für ein Treffen sagt „not an official event“, weil keine Veranstaltungen dokumentiert sind; siehe
[Ein Treffen vorschlagen](ein-treffen-vorschlagen.md).

## Unterstützung und Dank

```text
SPONSORSHIP
Exponential is free software. If your work depends on it, consider sponsoring:
the Exponential Foundation (the open source project): github.com/sponsors/exponentialcms
7x (the company that leads development): github.com/sponsors/se7enxweb

THANK YOU
Thanks to <public name or handle> for <contribution> in Exponential (<link to the PR or post>).
This is how open source works.
```

Danken Sie Menschen nur dann namentlich, wenn ihr Name in diesem Zusammenhang bereits öffentlich ist (ein GitHub-Name bei
einem öffentlichen Pull Request) oder wenn sie zugestimmt haben ([Ideen für Anerkennung](ideen-fuer-anerkennung.md)).

## Korrekturen

```text
CORRECTION
Correction to my post about <topic>: I wrote "<wrong>". The docs say "<right>" (<link>). Sorry!
```

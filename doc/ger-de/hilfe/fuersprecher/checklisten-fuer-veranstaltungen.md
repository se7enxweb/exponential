# Checklisten für Veranstaltungen

Diese Seite ist für Fürsprecher, die ein Treffen, einen Workshop, einen Sprint oder einen Community-Tisch betreuen. Jede
Veranstaltung über Exponential, die Sie organisieren, ist Ihre eigene Initiative; es sind keine offiziellen
Veranstaltungen dokumentiert ([Ein Treffen vorschlagen](ein-treffen-vorschlagen.md)). Kopieren Sie die Listen und haken Sie
sie ab.

2. [Eine Woche vorher](#eine-woche-vorher)

## Sechs Wochen vorher

```text
[ ] Purpose and format chosen (meetup, workshop, sprint, online, table)
[ ] Proposal posted in the forums; interest checked
[ ] Date set; for online: time in UTC plus two local zones
[ ] Venue or video tool confirmed; step-free access known (or stated as unknown)
[ ] Speakers asked; each knows the disclosure and demo safety rules
[ ] Announcement written: "organized by <you>, not an official event"
[ ] Sign-up asks only for a name or nickname and a contact; deletion date stated
```

## Eine Woche vorher

```text
[ ] Reminder posted
[ ] Agenda final, with times
[ ] Slides received; accessible (large text, alt text, captions for videos)
[ ] Demo installations prepared with invented data; screenshots as backup
[ ] Ground rules written (kindness, no recording without consent, no sales pitches, whom to contact)
[ ] Helpers assigned (host, moderator, note taker)
```

## Einen Tag vorher

```text
[ ] Equipment tested: projector or screen share, sound, captions, power, network
[ ] Printed handouts or card (if in person)
[ ] Link sent to registered people (online)
[ ] Plan B for the network and a missing speaker
```

## Am Tag selbst

```text
[ ] Arrive or open the call early
[ ] Ground rules said at the start; recording announced before it starts (if any)
[ ] Speakers share one window only; no secrets on screen
[ ] Questions you cannot answer written down
[ ] Photos only with consent
```

## Danach

```text
[ ] Summary with slides and links posted in the forums
[ ] Open questions answered with sources
[ ] Thanks to speakers, helpers, venue (public handles, with consent)
[ ] Sign-up data deleted
[ ] Lessons noted; next date proposed
[ ] Logged in my contribution log, without attendee names
```

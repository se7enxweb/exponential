# Neue willkommen heißen

Diese Seite ist für Fürsprecher, die Menschen begegnen, die neu bei Exponential sind: in den Foren, im Chat, bei einem
Treffen, bei der Arbeit. Die erste Antwort entscheidet, ob sie bleiben. Seien Sie schnell, freundlich und konkret: Ein
nützlicher Link schlägt einen langen Vortrag.

## Die erste Antwort

- **Antworten Sie bald.** Eine Frage, die am selben Tag beantwortet wird, ist eine neue Person, die bleibt.
- **Danken Sie** für die Frage, und sagen Sie nie „Das ist eine Anfängerfrage“.
- **Beantworten Sie die Frage, die gestellt wurde**, und bieten Sie dann einen nächsten Schritt an.
- **Verlinken Sie, statt zu dozieren**: eine Hilfeseite, nicht zehn.

## Erste Schritte für jede Art von Neuen

```text
EDITOR       Sign in -> the "?" help button -> Getting started -> A tour of the administration
EVALUATOR    ./console exp:install -> Getting started -> the layouts editor -> the forums
ADMIN        Database support -> Operating system support -> Security hardening -> Upgrading
DEVELOPER    Develop with Git -> Extensions guide -> Setup > RAD -> Templates and design
CONTRIBUTOR  Improving the help -> Helping with translations -> Reporting bugs well
```

## Willkommensnachrichten

```text
FORUM
Welcome to the Exponential forums, <name>! <Answer.> If you're just starting, the help built into the
administration (the "?" button) has a Getting started page, and you can always ask here.

CHAT
Hi <name>, welcome! What are you working on? If you have a question, just ask - include your version
and what you see.

IN PERSON
"Nice to meet you. What do you use, or want to use, Exponential for?" (Listen. Then one link or one demo.)
```

Auf Deutsch zum Beispiel: „Willkommen in den Exponential-Foren, <Name>! <Antwort.> Wenn Sie gerade anfangen: Die Hilfe in
der Administration (die Schaltfläche „?“) hat eine Seite Erste Schritte, und Sie können hier jederzeit fragen.“

## Die Community offen wirken lassen

- Verwenden Sie einfache Sprache; erklären Sie Abkürzungen einmal (Siteaccess, Erweiterung, Override)
  ([Glossar für Fürsprecher](glossar-fuer-fuersprecher.md)).
- Seien Sie geduldig mit der Sprache: Viele Menschen schreiben in ihrer zweiten oder dritten Sprache.
- Laden Sie ein, drängen Sie nicht: „wenn Sie möchten, ...“
- Stellen Sie Neue anderen mit ähnlichen Interessen vor, mit deren Zustimmung.
- Fassen Sie nach einer Woche nach: „Hat es funktioniert?“

# Skript für einen Lightning Talk

Diese Seite ist für Fürsprecher, die fünf Minuten auf einer Bühne, bei einem Treffen oder in einer Teambesprechung
haben. Sie bietet sechs Folien, ein Skript, das Sie vorlesen oder anpassen können, die Zeitangaben und die Quelle jedes
Satzes. Fünf Minuten sind etwa 650 gesprochene Wörter; das Skript unten hat weniger, damit Sie atmen können.

## Das Skript

**Folie 1 (0:00).** „Hallo, ich bin <Name>. Ich nutze Exponential für <Ihre Nutzung>. Niemand bezahlt mich dafür, das
zu sagen; ich mag es einfach. Fünf Minuten, los geht's.“

**Folie 2 (0:20).** „Exponential ist ein PHP-Anwendungsframework mit einem vollständigen Content-Management-System.
Seine beste Eigenschaft ist das Inhaltsmodell: Sie definieren Ihre eigenen Inhaltstypen, einen Artikel, ein Produkt,
eine Veranstaltung, in der Administration, ohne Code. Es bringt einen Shop mit, bedient mehrere Websites aus einer
Installation und spricht viele Sprachen, auch von rechts nach links.“

**Folie 3 (1:10).** „Manche von Ihnen kennen diesen Code unter einem älteren Namen. Sein ursprünglicher Hersteller hat
ihn nach fast achtzehn Jahren eingestellt. Der Code ist frei, also ging es weiter: 7x hat 2023 die Leitung übernommen,
und seit Januar 2024 gab es fünfzehn Releases 6.0.x. Seit diesem Jahr betreibt eine gemeinnützige Organisation, die
Exponential Foundation, das Projekt.“

**Folie 4 (2:10).** „Was ist neu in der aktuellen Linie? Velocity, ein PHP-Webserver, der die Anwendung geladen hält.
Exponential Layouts, ein visueller Seitenbaukasten für Redakteure. Exponential Intelligence, ein Schreibassistent, der
nur Entwürfe schreibt und nie selbst veröffentlicht. Und die Hilfe: Die Dokumentation steckt in der Administration, mit
einer Hilfe-Schaltfläche auf jeder Seite.“

**Folie 5 (3:30).** „Es ist freie Software: der Code unter der GPL, die Dokumentation unter der GNU Free Documentation
License. Und das Projekt hat eine Regel, die ich liebe: Jeder Pull Request wird übernommen, und die Commits des
Beitragenden bleiben erhalten.“

**Folie 6 (4:20).** „Probieren Sie es aus: Ein Befehl installiert eine vollständige Website auf SQLite, ohne
Datenbankserver. Fragen: die Foren auf share.exponential.earth und der Telegram-Chat. Danke!“

## Checkliste zum Proben

```text
[ ] Read the script aloud three times, timed: under 5:00
[ ] Replaced <name> and <your use>; disclosure line kept
[ ] Checked every source once this week (numbers change with releases)
[ ] Slides: large text, high contrast, no text in images without alt text
[ ] The last slide stays on screen during questions
[ ] A backup: slides as PDF on a USB stick and in your e-mail
```

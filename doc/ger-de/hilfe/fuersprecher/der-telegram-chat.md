# Der Telegram-Chat

Diese Seite ist für Fürsprecher, die im Community-Chat aktiv sind. Die README nennt ihn „Share Exponential! Telegram
Community Support Chat“, den Support-Chat der Community, unter [t.me/exponentialcms](https://t.me/exponentialcms)
([Orte der Community](../wer-ist-die-exponential-foundation.md#orte-der-community)). Ein Chat ist schnell und freundlich und
vergisst schnell. Nutzen Sie ihn für schnelle Hilfe und zum Willkommenheißen, und bringen Sie dauerhafte Antworten an
Orte, an denen man sie später findet.

## Wofür der Chat gut ist

| Gut für | Besser anderswo |
|---|---|
| Schnelle Fragen mit kurzen Antworten | Lange Fehlersuche: die Foren |
| Neue willkommen heißen | Fehlerberichte: der Issue-Tracker |
| Auf eine Hilfeseite verweisen | Sicherheitsprobleme: vertraulich, `SECURITY.md` |
| Fragen „Sieht das noch jemand?“ | Funktionsvorschläge: der Issue-Tracker der Community |
| Einen neuen Beitrag oder ein Tutorial teilen | Dokumentation: ein Pull Request |

## Umgangsformen

- Grüßen Sie kurz; Sie müssen nicht fragen „Darf ich etwas fragen?“ Fragen Sie einfach.
- Stellen Sie die ganze Frage in einer Nachricht, mit Ihrer Version und Ihrer Umgebung.
- Nutzen Sie Threads oder Antworten, damit Gespräche lesbar bleiben.
- Schreiben Sie Menschen nicht privat an, ohne vorher zu fragen.
- Respektieren Sie Zeitzonen: Menschen antworten, wenn sie können.
- Keine Werbung über eine kurze Offenlegung Ihrer eigenen Arbeit hinaus, wenn sie relevant ist
  ([Offenlegung und Interessenkonflikte](offenlegung-und-interessenkonflikte.md)).
- Befolgen Sie die eigenen Regeln des Chats und seiner Moderatoren.

## Antworten in die Foren und die Hilfe verlagern

Eine gute Antwort im Chat ist in wenigen Tagen verloren. Wenn eine Antwort es wert ist, bewahrt zu werden:

1. Bitten Sie die Person, die Frage in den Foren zu stellen, oder stellen Sie sie mit ihrer Erlaubnis selbst ein (ohne
   ihre persönlichen Angaben).
2. Beantworten Sie sie dort vollständig.
3. Verlinken Sie die Forendiskussion im Chat.
4. Wenn die Hilfe sie hätte beantworten sollen, verbessern Sie die Hilfe ([Die Hilfe verbessern](die-hilfe-verbessern.md)).

## Privatsphäre und Sicherheit in einem Chat

- Ein Gruppenchat ist für seine Mitglieder öffentlich und kann für viele Menschen sichtbar sein. Behandeln Sie ihn als
  öffentlich.
- Stellen Sie nie Passwörter, Schlüssel, Serveradressen, Logs mit personenbezogenen Daten oder Kundennamen ein.
- Wenn jemand versehentlich ein Geheimnis veröffentlicht, sagen Sie ihm sofort, es zu löschen und zu ändern.
- Wenn jemand eine Sicherheitslücke beschreibt, bitten Sie ihn, aufzuhören und sie vertraulich zu melden
  ([Sicherheitsmeldungen bleiben vertraulich](sicherheitsmeldungen-bleiben-vertraulich.md)).
- Screenshots aus dem Chat mit Namen anderer Menschen sollten nicht ohne Zustimmung anderswo veröffentlicht werden
  ([Die Privatsphäre von Menschen schützen](privatsphaere-schuetzen.md)).

## Nachrichtenvorlagen

```text
WELCOME
Welcome, <name>! If you're new: the help inside the admin (the "?" button) is a great start, and the forums
(share.exponential.earth/forums) keep longer answers findable. What are you working on?

POINT TO HELP
This one's in the help: "<title>" - <link>. Short version: <one line>.

MOVE TO THE FORUMS
Good question, and a bit long for chat. Could you post it in the forums with your version and the exact
message? Then the answer stays findable for others. I'll look there.

SECRET POSTED
Heads up: your message contains a <password | key | server address>. Please delete it and change it.

SECURITY
Please don't share more details here. Send them privately as SECURITY.md describes (security@se7enx.com).
Thank you for reporting!
```

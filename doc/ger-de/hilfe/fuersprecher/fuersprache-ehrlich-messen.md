# Fürsprache ehrlich messen

Diese Seite ist für Fürsprecher, die wissen möchten, ob ihre Arbeit hilft. Die ehrliche Antwort lautet oft „teilweise,
und schwer zu beweisen“. Messen Sie, was Sie beobachten können, erfinden Sie nie Zahlen und verfolgen Sie nie Menschen.

## Inhalt

1. [Signale, die Sie beobachten können](#signale-die-sie-beobachten-können)
2. [Was Sie nicht messen sollten](#was-sie-nicht-messen-sollten)
3. [Ein Quartalsrückblick](#ein-quartalsrückblick)

## Signale, die Sie beobachten können

| Signal | Wo |
|---|---|
| Fragen, die Sie beantwortet haben und die als gelöst markiert oder mit Dank versehen wurden | Die Foren |
| Dieselbe Frage kommt nicht mehr, nachdem Sie eine Hilfeseite verbessert haben | Die Foren, der Chat |
| Ihre Pull Requests wurden übernommen | GitHub |
| Neue, denen Sie geholfen haben, haben einen ersten Beitrag geleistet | GitHub (öffentlich) |
| Übersetzungsfortschritt Ihrer Sprache | `ezchecktranslation.php` ([Sprachen, Abschnitt 8](../../sprachen.md#8-eine-übersetzung-der-administrationsoberfläche-hinzufügen-oder-vervollständigen)) |
| Issues, die Sie bestätigt haben, wurden behoben | GitHub |
| Menschen kommen wieder zu Ihren Treffen | Ihre eigene Zählung, ohne Namen |

[Die Community wachsen lassen](../geschaeft/die-community-wachsen-lassen.md#messen-was-sie-tatsächlich-sehen-können) nennt ähnliche
Messgrößen für Organisationen.

## Was Sie nicht messen sollten

- Follower und Likes als Beweis für irgendetwas: Sie messen Reichweite, nicht Hilfe.
- „Gewonnene Installationen“: Niemand kann sie zählen, und die Quellen tun es nicht.
- Alles, wofür einzelne Menschen ohne ihr Wissen verfolgt werden müssten.

## Ein Quartalsrückblick

```text
QUARTER <Q/year>
Did:            <links from my contribution log>
Helped most:    <which, and the signal>
Did not work:   <what, why>
All claims sourced?  <yes / corrections made: links>
Next quarter:   <1-3 goals>
```

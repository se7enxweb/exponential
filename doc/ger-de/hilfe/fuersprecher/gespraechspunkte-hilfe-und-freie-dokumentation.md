# Gesprächspunkte: die Hilfe und freie Dokumentation

Diese Seite ist für Fürsprecher, die zeigen möchten, dass Exponential Dokumentation ernst nimmt. Die Hilfe, die Sie
gerade lesen, ist die Dokumentation des Repositorys, angezeigt in der Administration, und sie ist freie Dokumentation.
Beides sind gute Geschichten.

## In einer Minute zeigen

1. Drücken Sie das „?“ in der Kopfzeile einer beliebigen Seite der Administration: Das Menü bietet Hilfe zu dieser Seite an.
2. Öffnen Sie das Hilfe-Center; drücken Sie `/` und tippen Sie ein Wort.
3. Öffnen Sie eine Seite und drücken Sie **Als PDF herunterladen**.
4. Zeigen Sie auf **Auf GitHub bearbeiten**.

## Warum freie Dokumentation wichtig ist

- **Menschen können lernen, ohne um Erlaubnis zu fragen.** Eine Lehrkraft kann eine Seite für eine Klasse drucken; ein
  Unternehmen kann sie in sein Intranet stellen ([Freie Dokumentation, Was Sie tun dürfen](../freie-dokumentation.md#was-sie-tun-dürfen)).
- **Übersetzungen können überall entstehen.** Eine Community kann die Hilfe in ihre Sprache übersetzen und teilen.
- **Korrekturen kommen zurück.** Eine Änderung wird unter derselben Lizenz angenommen, sodass die Verbesserung für alle
  frei bleibt ([Zur Dokumentation beitragen](../../../eng-us/README-LICENSE.md#contributing-to-the-documentation)).

## Sagen Sie nicht

- „Die Dokumentation ist vollständig.“ Das ist keine. Sagen Sie: „Sie liegt im Repository, und Sie können sie verbessern.“
- „Sie können damit tun, was Sie wollen.“ Sagen Sie: „Unter den Bedingungen der GNU FDL: Behalten Sie den Hinweis und die
  Lizenz bei.“
- „Die Hilfe ist öffentlich im Internet.“ Sie wird angemeldeten Benutzern mit der Richtlinie `exphelp/read` gezeigt; die
  Dateien sind im Repository öffentlich.

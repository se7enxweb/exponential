# Die Stufen der Fürsprache: Benutzer, Fürsprecher, Leitung

Diese Seite ist für Fürsprecher, die wissen möchten, wo sie stehen und was als Nächstes kommt, und für Leitungen, die
anderen beim Aufstieg helfen. Sie beantwortet: Welche Stufen gibt es, was tut eine Person auf jeder, und was ist der
eine nächste Schritt von jeder aus?

Die Stufen bauen auf dem Trichter für Beitragende aus [Die Community wachsen lassen](../geschaeft/die-community-wachsen-lassen.md#der-trichter-für-mitwirkende)
und den Stufen der Beteiligung aus [Eine Leitungsrolle übernehmen](../fuehrung/community-leiter-werden.md#die-beitragsleiter)
auf. Sie ergänzen die Sicht des Fürsprechers: **anderen Menschen** beim Aufstieg helfen.

## Die Stufen auf einen Blick

| Stufe | Wer | Was sie tun | Nächster Schritt | Seite |
|---|---|---|---|---|
| 1. Benutzer | Betreibt, bearbeitet oder baut eine Website | Nutzt die Hilfe, stellt Fragen | Eine Frage für jemand anderen beantworten | [Erste Schritte](../erste-schritte.md) |
| 2. Helfer | Beantwortet ab und zu Fragen | Teilt Links zu Hilfeseiten | Etwas schreiben oder präsentieren | [Fragen gut beantworten](fragen-gut-beantworten.md) |
| 3. Fürsprecher | Spricht, schreibt, führt vor | Bringt neue Menschen dazu, mit Quellen | Organisieren oder begleiten | [Gesprächspunkte: das Grundset](gespraechspunkte-grundset.md) |
| 4. Organisator und Begleiter | Führt Treffen und Sprints durch, begleitet erste Beiträge | Hilft anderen, Fürsprecher zu werden | Einen Bereich übernehmen | [Einen ersten Beitrag begleiten](einen-ersten-beitrag-begleiten.md) |
| 5. Leitung | Verantwortet einen Bereich: eine Sprache, eine Erweiterung, einen Kanal, ein Thema | Hält ihn auf Dauer gesund | Die nächste Leitung heranziehen | [Eine Leitungsrolle übernehmen](../fuehrung/community-leiter-werden.md) |

Die Stufen sind eine Denkhilfe, keine Titel. Das Projekt vergibt sie nicht; die Quellen nennen keine Ränge oder Programme.

## Stufe 1: Benutzer

**Wer.** Jemand, der sich an der Administration anmeldet, Inhalte bearbeitet, eine Website baut oder einen Server betreibt.

**Was hilft.** Die Hilfe (das „?“ in der Kopfzeile), die [Hilfe für Redakteure und Benutzer](../README.md), die
[Foren](https://share.exponential.earth/forums) und [Telegram](https://t.me/exponentialcms).

**Der nächste Schritt.** Beantworten Sie eine Frage, deren Antwort Sie kennen. Sie wissen schon mehr als jemand, der
gestern angefangen hat.

## Stufe 2: Helfer

**Wer.** Ein Benutzer, der ab und zu eine Frage beantwortet.

**Gewohnheiten.**

- Antworten Sie mit einem Link auf eine Hilfe- oder Dokumentationsseite, nicht nur aus dem Gedächtnis.
- Sagen Sie, was Sie ausprobiert haben und welche Version Sie nutzen.
- Danken Sie Menschen, die Ihnen antworten.

**Der nächste Schritt.** Schreiben Sie eine Sache auf: einen kurzen Beitrag über das, was Sie gelernt haben, eine
Korrektur an einer Hilfeseite mit **Auf GitHub bearbeiten** ([Die Hilfe verbessern](die-hilfe-verbessern.md)) oder eine
Fünf-Minuten-Demo für eine Kollegin.

## Stufe 3: Fürsprecher

**Wer.** Ein Helfer, der jetzt auch öffentlich über Exponential spricht: Beiträge, Vorträge, Demos, soziale Medien.

**Gewohnheiten.**

- Nutzt die [Gesprächspunkte](gespraechspunkte-grundset.md) und nennt die Quelle jeder Aussage.
- Verwendet die richtigen Namen ([Kurzkarte zu den Namensregeln](kurzkarte-namensregeln.md)).
- Sagt, wer er ist und ob ihn jemand bezahlt ([Offenlegung](offenlegung-und-interessenkonflikte.md)).
- Schickt Menschen nur in die dokumentierten Kanäle ([Die Community-Kanäle](community-kanaele.md)).

**Der nächste Schritt.** Helfen Sie jemand anderem beim Anfangen: heißen Sie eine neue Person willkommen, lesen Sie den
Entwurf eines anderen Fürsprechers gegen oder schlagen Sie ein kleines Treffen vor.

## Stufe 4: Organisator und Begleiter

**Wer.** Ein Fürsprecher, der es anderen leichter macht, beizutragen.

**Was sie tun.**

| Tätigkeit | Seite |
|---|---|
| Ein Treffen vorschlagen und durchführen | [Ein Treffen vorschlagen](ein-treffen-vorschlagen.md), [Ein Online-Treffen durchführen](ein-online-treffen-durchfuehren.md) |
| Einen Dokumentations- oder Übersetzungs-Sprint durchführen | [Einen Beitrags-Sprint vorschlagen](einen-beitrags-sprint-vorschlagen.md) |
| Einen ersten Pull Request begleiten | [Einen ersten Beitrag begleiten](einen-ersten-beitrag-begleiten.md) |
| Neue in den Kanälen willkommen heißen | [Neue willkommen heißen](neue-willkommen-heissen.md) |

**Der nächste Schritt.** Wählen Sie einen Bereich, um den Sie sich lange kümmern werden.

## Stufe 5: Leitung

**Wer.** Jemand, der einen Bereich verantwortet: eine Übersetzung, eine Erweiterung, einen Abschnitt der Dokumentation,
einen Kanal, eine lokale Community, ein Thema wie Barrierefreiheit.

**Was sich ändert.** Eine Leitung denkt in Jahren. Sie schreibt Dinge auf, damit andere weitermachen können, sie prüft
die Arbeit anderer und zieht die nächste Leitung heran. Die vollständige Beschreibung mit einem 30/60/90-Tage-Plan
steht in [Eine Leitungsrolle in der Exponential-Community übernehmen](../fuehrung/community-leiter-werden.md).

**Dokumentierte Gelegenheiten für Leitungen.**

- Übersetzungen: Zehn Übersetzungen der Administration sind vollständig; für jede andere Sprache ist das Übersetzen der
  seit 6.0 hinzugekommenen Texte „die nützlichste Arbeit“ ([Sprachen in Exponential, Abschnitt 8](../../sprachen.md#8-eine-übersetzung-der-administrationsoberfläche-hinzufügen-oder-vervollständigen)).
- Dokumentation: Jede Hilfeseite lässt sich mit **Auf GitHub bearbeiten** verbessern ([Freie Dokumentation](../freie-dokumentation.md#anderen-helfen)).
- Erweiterungen: Eine Erweiterung nennt ihre Version in ihren eigenen Dateien und wird als Composer-Paket veröffentlicht
  ([Erweiterungen, „Release it“](../../anleitungen/extensions.md#7-die-extension-veröffentlichen)).

## Menschen nach oben helfen

| Sie sind auf | Laden Sie sie ein | Sagen Sie |
|---|---|---|
| 1. Benutzer | Eine Frage zu beantworten | „Sie haben das letzte Woche gelöst. Jemand im Forum hat dasselbe Problem.“ |
| 2. Helfer | Es aufzuschreiben | „Diese Antwort war großartig. Möchten Sie sie in die Hilfeseite aufnehmen? Ich zeige Ihnen, wie.“ |
| 3. Fürsprecher | Zu begleiten | „Eine neue Person hat nach Übersetzungen gefragt. Würden Sie sie durch ihren ersten Pull Request begleiten?“ |
| 4. Organisator | Einen Bereich zu übernehmen | „Sie haben drei Sprints für Ihre Sprache durchgeführt. Würden Sie sich um sie kümmern?“ |

Regeln:

- Laden Sie ein, drängen Sie nie. Ehrenamtliche geben die Zeit, die sie haben.
- Nennen Sie Menschen öffentlich für das, was sie getan haben, mit ihrer Zustimmung ([Ideen für Anerkennung](ideen-fuer-anerkennung.md)).
- Machen Sie den ersten Schritt klein und klar beschrieben.

## Zurücktreten ist in Ordnung

Das Leben ändert sich. Ein Fürsprecher, der zurücktritt, sollte:

1. Es den Menschen sagen, die sich auf ihn verlassen.
2. Aufschreiben, was er weiß (eine kurze Übergabenotiz im Kanal oder auf einer Hilfeseite).
3. Auf jemanden verweisen, der weitermachen kann, wenn es jemanden gibt.

Niemand schuldet dem Projekt seine Zeit. Eine gute Übergabe ist ein letzter Beitrag.

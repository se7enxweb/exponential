# Richtig über die Geschichte schreiben

Diese Seite ist für Fürsprecher, die erwähnen, woher Exponential kommt. Die Geschichte ist eine Stärke, aber sie betrifft
andere Unternehmen und einen alten Produktnamen. Sie richtig darzustellen ist eine Frage der Genauigkeit und des Respekts.

## Formulierungen, die Sie verwenden

- „Exponential führt die Codebasis von eZ Publish fort.“
- „Die Codebasis wurde viele Jahre unter dem Namen eZ Publish entwickelt.“
- „Eine Website, die gebaut wurde, als die Software noch eZ Publish hieß.“
- „Die Jahre von eZ Publish.“
- „eZ Publish, ein Produkt, das sein Hersteller nach fast achtzehn Jahren eingestellt hat.“
- „Exponential steht in keiner Verbindung zu eZ Systems oder Ibexa.“

## Formulierungen, die Sie vermeiden

| Vermeiden Sie | Warum |
|---|---|
| „Exponential ist eZ Publish.“ / „das neue eZ Publish“ | Legt dasselbe Produkt und eine Verbindung nahe |
| „eZ Publish, jetzt Exponential genannt“ | Legt eine Umbenennung durch das ursprüngliche Unternehmen nahe |
| „der offizielle Nachfolger von eZ Publish“ | Einen solchen Status gibt es nicht |
| „eZ Publish 6“ | Ein solches Produkt gibt es nicht; die Linie heißt Exponential 6 |
| „eZ-Publish-Websites“ (für heutige Websites) | Sagen Sie „Websites aus den Jahren von eZ Publish“ oder „Exponential-Websites“ |
| „tot“, „aufgegeben“ über die Produkte des ursprünglichen Herstellers | Respektlos und ungenau; sagen Sie „eingestellt“ |
| Spekulationen, warum der Hersteller aufgehört hat | Keine Quelle |

Quelle dieser Regeln: [Marken- und Namensregeln, Der alte Name](../geschaeft/marken-und-namensregeln.md#der-alte-name-ez-publish-nur-als-geschichte).

## Umformulierungen

| Vorher | Nachher |
|---|---|
| „Wir betreiben eZ Publish 6 auf PHP 8.5.“ | „Wir betreiben Exponential 6 auf PHP 8.5.“ |
| „Exponential ist die Community-Version von eZ Publish.“ | „Exponential führt die Codebasis von eZ Publish fort, einem Produkt, das sein Hersteller nach fast achtzehn Jahren eingestellt hat.“ |
| „Migrieren Sie Ihre eZ-Publish-Website zu Exponential, dem Nachfolger von eZ.“ | „Bringen Sie eine Website, die gebaut wurde, als die Software noch eZ Publish hieß, auf das aktuelle Exponential 6.“ |
| „eZ Systems hat es aufgegeben, also haben wir es gerettet.“ | „Als das ursprüngliche Produkt eingestellt wurde, hat 7x die Leitung der Codebasis übernommen.“ |

## Respekt vor früherer Arbeit

Hunderte Menschen haben die Codebasis vor Exponential gebaut ([Beitragende und Freunde des Projekts](../wer-ist-7x.md#mitwirkende-und-freunde-des-projekts)).
Das Copyright von eZ Systems bleibt im Code. Sprechen Sie mit Dankbarkeit von dieser Arbeit. Das Projekt nennt andere
beim Namen (Netgen, Mugo Web, CJW Network), und das sollten Sie auch tun
([Andere Projekte und Unternehmen respektieren](andere-projekte-respektieren.md)).

Bezeichner im Code mit `eZ` (`eZContentObject`, `eZINI`) sind nicht der Produktname und ändern sich nie
([Bezeichner im Code bleiben, wie sie sind](../geschaeft/marken-und-namensregeln.md#bezeichner-im-code-bleiben-wie-sie-sind)).

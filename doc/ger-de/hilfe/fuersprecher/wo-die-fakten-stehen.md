## Prüfen Sie es selbst

Manche Fakten lassen sich mit einem Befehl in einem Klon des Repositorys prüfen. Bieten Sie sie skeptischen Zuhörern an:

```bash
git clone https://github.com/se7enxweb/exponential.git
cd exponential
git tag -l 'v6.0.*' --sort=version:refname   # every 6.0.x release, in the right order
git log -5 --format='%ad %s'                  # the most recent changes
git log --reverse --format='%ad' | head -1    # the oldest commit
cat COPYRIGHT.md                              # the copyright holders
```

> **Hinweis**
> Sortieren Sie Versionen immer mit `--sort=version:refname`. Eine einfache Sortierung nach Namen setzt `0.1.10` vor
> `0.1.9` ([Releases und Versionsnummern](../wer-ist-die-exponential-foundation.md#releases-und-versionsnummern)).

## Wenn es keine Quelle gibt

Sagen Sie es: „Die Dokumentation sagt das nicht. Ich schaue nach, und wenn ich es nicht finde, frage ich im Forum.“ Finden
Sie dann entweder die Quelle oder sagen Sie der Person, dass Sie keine gefunden haben. Füllen Sie die Lücke nicht mit
einer Vermutung ([Aussagen, die Sie nicht machen dürfen](aussagen-die-sie-nicht-machen-duerfen.md)).

Wenn Sie finden, dass die Dokumentation es sagen **sollte**, schlagen Sie eine Änderung vor ([Die Hilfe verbessern](die-hilfe-verbessern.md))
oder eröffnen Sie ein Issue im [Community-Tracker](https://github.com/se7enxweb/exponential-community/issues).

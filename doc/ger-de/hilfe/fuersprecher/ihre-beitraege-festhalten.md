# Ihre Beiträge festhalten

Diese Seite ist für Fürsprecher, die sehen möchten, was sie getan haben. Ein Beitragsprotokoll hilft Ihnen beim Planen
([Ein 90-Tage-Plan für Fürsprecher](ein-90-tage-plan.md)), zeigt Ihre Arbeit, wenn Sie das möchten (ein Portfolio,
eine Bewerbung), und hilft der Person, die weitermacht, wenn Sie zurücktreten.

## Inhalt

1. [Was Sie festhalten](#was-sie-festhalten)
2. [Die Protokollvorlage](#die-protokollvorlage)

## Was Sie festhalten

| Art | Halten Sie fest |
|---|---|
| Antworten | Link zum Forenbeitrag |
| Beiträge, Tutorials, Videos | Link, Datum, Thema |
| Vorträge und Demos | Veranstaltung, Datum, Link zu den Folien (keine Namen von Teilnehmenden) |
| Pull Requests | Link, was geändert wurde |
| Übersetzungen | Sprache, Anzahl der Texte, Pull Request |
| Gemeldete oder bestätigte Issues | Links |
| Organisierte Veranstaltungen | Datum, Format, Link zum zusammenfassenden Beitrag |
| Begleitete Neue | Link zu ihrem ersten Pull Request (öffentlich), keine persönlichen Details |

## Die Protokollvorlage

```text
CONTRIBUTION LOG                                        <your name or handle>

| Date       | Kind         | What                                    | Link                     |
|------------|--------------|-----------------------------------------|--------------------------|
| 2026-10-20 | answer       | How to translate an item                | <forum link>             |
| 2026-10-22 | pull request | Fixed: layouts help names Discard       | <github link>            |
| 2026-10-28 | talk         | Lightning talk, <group>                 | <slides link>            |
```

Führen Sie es als Textdatei, Tabelle oder private Notiz; es gehört Ihnen.

## Ihre öffentlichen Beiträge finden

- GitHub listet Ihre Pull Requests und Issues auf (suchen Sie `author:<you>` in den Repositorys von se7enxweb).
- In einem Klon: `git log --author="<your name>" --oneline`.
- Ihr Forenprofil listet Ihre Beiträge auf.

## Privatsphäre

Halten Sie Links und Ihre eigene Arbeit fest, nicht die personenbezogenen Daten anderer. Wenn Sie Ihr Protokoll
veröffentlichen, prüfen Sie, dass jeder Link öffentlich ist und niemand ohne Zustimmung genannt wird
([Die Privatsphäre von Menschen schützen](privatsphaere-schuetzen.md)).

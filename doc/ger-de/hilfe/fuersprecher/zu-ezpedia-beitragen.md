# Zu eZpedia beitragen

Diese Seite ist für Fürsprecher, die gern dokumentieren. eZpedia ist die Community-Enzyklopädie: „Die freie
eZ-Publish-Enzyklopädie, die jeder bearbeiten kann“, seit 2006 in Betrieb, unter der GNU Free Documentation License
([Orte der Community](../wer-ist-die-exponential-foundation.md#orte-der-community)). Sie bewahrt das Wissen vieler Jahre
und vieler Menschen.

## Was eZpedia ist und was nicht

| Sie ist | Sie ist nicht |
|---|---|
| Ein Community-Wiki unter [ezpedia.exponential.earth](https://ezpedia.exponential.earth/) | Die offizielle Dokumentation des aktuellen Release |
| Unter der GNU FDL | Ein Ort für Sicherheitsmeldungen |
| Voller Lösungen, Codeschnipsel und Geschichte aus vielen Jahren | Immer aktuell für Exponential 6 |

Ihre Startseite zeigt kürzlich aktualisierte Artikel, aktuelle Diskussionen, aktuelle Entwicklungsaktivität und einen
Bereich „Ask A Question“ für Fragen, und sie bietet Anmeldung und Registrierung.

## eZpedia oder die Hilfe?

| Ihr Inhalt | Gehört nach |
|---|---|
| Wie das aktuelle Produkt funktioniert, für alle Benutzer | In die Hilfe, mit einem Pull Request ([Die Hilfe verbessern](die-hilfe-verbessern.md)) |
| Ein Codeschnipsel, ein Trick, eine Umgehungslösung, eine Erfahrung | eZpedia |
| Geschichte, alte Versionen, Hinweise zur Migration | eZpedia, mit Links auf die Migrationskapitel der Hilfe |
| Eine Frage | In die Foren oder den Fragenbereich von eZpedia |
| Ein Fehler | In den Issue-Tracker ([Welcher Tracker für welche Meldung](welcher-tracker-fuer-welche-meldung.md)) |

Beide sind freie Dokumentation unter der GNU FDL, sodass Text unter den Bedingungen der Lizenz zwischen ihnen wandern kann.

## Erste Schritte

1. Registrieren Sie sich oder melden Sie sich bei [eZpedia](https://ezpedia.exponential.earth/) an.
2. Lesen Sie einige kürzlich aktualisierte Artikel, um den Stil zu sehen.
3. Fangen Sie klein an: einen veralteten Link korrigieren, einen Versionshinweis hinzufügen, einen Tippfehler beheben.
4. Schreiben oder aktualisieren Sie dann einen ganzen Artikel.

## Was Sie beitragen können

| Beitrag | Warum |
|---|---|
| Hinweise „Funktioniert mit Exponential 6.0.x“ oder „Veraltet seit ...“ bei Artikeln ergänzen, die Sie getestet haben | Leser wissen, was noch gilt |
| Alte Artikel mit der aktuellen Hilfe- oder Funktionsseite verlinken | Leser finden den aktuellen Weg |
| Eine Lösung aufschreiben, die Sie in den Foren gegeben haben | Die nächste Person findet sie |
| Eine Erweiterung dokumentieren, die Sie pflegen | Benutzer finden sie |
| Einen Artikel zur Geschichte aus der Chronik schreiben | Hintergrund für Neue ([Beiträge zur Geschichte schreiben](beitraege-zur-geschichte-schreiben.md)) |

## Regeln für das Schreiben

- Testen Sie, was Sie schreiben, auf einer aktuellen Installation und nennen Sie die Version.
- Zitieren Sie, wo möglich, die Hilfe oder das Repository ([Wo die Fakten stehen](wo-die-fakten-stehen.md)).
- Keine Geheimnisse, keine personenbezogenen Daten, keine Kundennamen ohne Zustimmung.
- Respektieren Sie die Änderungen anderer; diskutieren Sie freundlich auf der Diskussionsseite.
- Verwenden Sie für Ihren Text die GNU FDL (die Lizenz der Website); fügen Sie keinen Text aus Quellen mit anderen
  Lizenzen ein.

## Der alte Name auf eZpedia

eZpedia führt den alten Namen im eigenen Titel: „The free eZ Publish encyclopedia“. Zitieren Sie solche Titel, wie sie
sind ([Marken- und Namensregeln](../geschaeft/marken-und-namensregeln.md#der-alte-name-ez-publish-nur-als-geschichte)). In
Ihrem eigenen Text schreiben Sie **Exponential** für das heutige Produkt und verwenden den alten Namen nur für die
Vergangenheit, zum Beispiel „In den Jahren von eZ Publish machte man das mit ...“
([Richtig über die Geschichte schreiben](richtig-ueber-die-geschichte-schreiben.md)). Benennen Sie nie Bezeichner im Code
wie `eZContentObject` um.

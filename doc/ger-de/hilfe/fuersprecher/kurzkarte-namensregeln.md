# Kurzkarte zu den Namensregeln

Diese Seite ist für Fürsprecher, die die Namen schnell richtig brauchen. Sie verdichtet die vollständigen
[Marken- und Namensregeln](../geschaeft/marken-und-namensregeln.md) auf einen Bildschirm. Drucken Sie sie aus oder halten
Sie sie beim Schreiben offen.

## Inhalt

1. [Die Karte](#die-karte)
2. [Fünf Regeln](#fünf-regeln)
3. [Finden Sie den Fehler](#finden-sie-den-fehler)

## Die Karte

```text
NAMING QUICK CARD                                                    Exponential advocates

THE PRODUCT
  Exponential                      the product; capital E; no article ("Exponential publishes ...")
  Exponential 6, Exponential 6.0.x the major line          Exponential 6.0.15   a release (no "v" in text)
  v6.0.14                          only as a Git tag

THE FAMILY
  Exponential Basic | Exponential Platform 3.2.9 | Exponential Platform Legacy | Exponential Platform Nexus
  Exponential Platform DXP | Exponential Velocity (Velocity) | Exponential Intelligence (expai)
  Exponential Layouts (the layouts editor) | AdminUI | the help system

THE ORGANIZATIONS
  7x                               the company that leads Exponential (digit 7, lowercase x)
  se7enx.com                       7x's domain        se7enxweb    GitHub account and Composer vendor
  the Exponential Foundation       the nonprofit that operates and funds the project
  Exponential Foundation and 7x      the copyright holder, exactly like this

THE PAST
  eZ Publish                       only in the past tense: "while the software was still called eZ Publish"
  Brookins Consulting              only as history: "7x used to be Brookins Consulting"
  eZ Systems, Ibexa                factual only; Exponential is NOT associated with them

NEVER RENAME IN CODE
  eZContentObject  eZINI  eZDB  ezcontentobject  bin/php/ezcache.php  ezwebin  eztags  ezflow

SPELLING
  American English: license, color, behavior, organization
```

Auf Deutsch gilt dasselbe: **Exponential** ohne Artikel, „7x“ mit kleinem x, „die Exponential Foundation“, der alte Name
nur in der Vergangenheit („als die Software noch eZ Publish hieß“), und Bezeichner im Code bleiben unverändert.

## Fünf Regeln

1. **Exponential ist das Produkt.** Nicht „eZ Exponential“, nicht „Exponential Publish“, nicht „das Exponential“.
2. **Zwei Organisationen.** 7x ist das Unternehmen; die Exponential Foundation ist die gemeinnützige Organisation. Nie
   „die 7x Foundation“.
3. **Der alte Name ist Geschichte.** Verwenden Sie ihn nur in der Vergangenheitsform und zitieren Sie historische Titel,
   wie sie sind (eZpedia, „Learning eZ Publish“).
4. **Benennen Sie das Produkt um, nie ein Symbol.** `eZ` allein ist ein Präfix im Code
   ([Bezeichner im Code bleiben, wie sie sind](../geschaeft/marken-und-namensregeln.md#bezeichner-im-code-bleiben-wie-sie-sind)).
5. **Nennen Sie andere bei ihrem Namen.** Netgen, Mugo Web, CJW Network
   ([Andere Unternehmen und Produkte](../geschaeft/marken-und-namensregeln.md#andere-unternehmen-und-produkte)).

## Finden Sie den Fehler

Jede Zeile enthält einen Fehler. Die Antworten stehen darunter.

```text
1. "eZ Publish 6 is out!"
2. "The 7x Foundation sponsors the project."
3. "Exponential AI writes your content."
4. "Install ExponentialContentObject from the docs."
5. "The colour of the admin is customisable."
6. "Exponential Qbix is the new server."
7. "7x owns Exponential."
```

Antworten: 1. Exponential 6. 2. Die Exponential Foundation (eine eigenständige gemeinnützige Organisation).
3. Exponential Intelligence, und es schreibt nur Entwürfe. 4. `eZContentObject` ist die echte Klasse; benennen Sie nie
Code um. 5. Im amerikanischen Englisch: color, customizable. 6. Exponential Velocity. 7. 7x leitet Exponential; das
Copyright ist geteilt, und die Lizenz ist die GPL.

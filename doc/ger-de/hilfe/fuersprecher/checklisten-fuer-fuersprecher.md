## Bevor Sie irgendetwas veröffentlichen

```text
[ ] Every fact sourced and checked today            (Honesty and accuracy)
[ ] Names right; old name only as history            (Naming rules quick card)
[ ] No personal data, customer names, secrets         (Protecting people's privacy)
[ ] No attacks on other projects                      (Respecting other projects and companies)
[ ] Disclosure if relevant                            (Disclosure and conflicts of interest)
[ ] Images with alt text                              (Accessible slides and visuals)
```

Seiten: [Ehrlichkeit und Genauigkeit](ehrlichkeit-und-genauigkeit.md), [Kurzkarte zu den Namensregeln](kurzkarte-namensregeln.md),
[Die Privatsphäre von Menschen schützen](privatsphaere-schuetzen.md).

## Vor einem Vortrag oder einer Demo

```text
[ ] Demo installation of my own, invented data, generated password changed and file deleted
[ ] One window shared; notifications off; no keys or settings on screen
[ ] Slides accessible; numbers checked this week
[ ] Screenshot backup of the demo
[ ] Disclosure on the first slide
```

Seiten: [Sicherheit bei Live-Demos](sicherheit-bei-live-demos.md), [Demos als Fürsprecher zeigen](demos-zeigen.md).

## Bevor Sie ein Tutorial oder eine Fallstudie veröffentlichen

```text
[ ] Tested on a fresh installation; version line present          (Writing a tutorial that works)
[ ] Written consent and approval from the organization            (Writing a community case study)
[ ] License of my text stated                                     (Citing sources and licensing your writing)
```

## Wenn Sie eine Frage beantworten

```text
[ ] Understood and restated            [ ] Short answer first
[ ] Help page linked                    [ ] Version stated
[ ] Followed up
```

Seite: [Fragen gut beantworten](fragen-gut-beantworten.md).

## Wenn jemand eine Sicherheitslücke erwähnt

```text
[ ] Asked them not to share details publicly (and to remove them if posted)
[ ] Gave them security@se7enx.com or GitHub's private reporting
[ ] Did not repeat or test it on others' sites
[ ] Promised nothing
```

Seite: [Sicherheitsmeldungen bleiben vertraulich](sicherheitsmeldungen-bleiben-vertraulich.md).

## Eine monatliche Routine

```text
[ ] 4 forum or chat answers with sources
[ ] 1 help page improvement
[ ] 1 issue confirmed or reported well
[ ] Read the newest month of the history
[ ] Updated my contribution log
```

Die Listen für Veranstaltungen stehen unter [Checklisten für Veranstaltungen](checklisten-fuer-veranstaltungen.md).

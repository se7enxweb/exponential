# Fürsprecher: hier beginnen

Dieser Bereich der Hilfe ist für **Exponential-Fürsprecher**: das Team auf der Straße für das Projekt. Fürsprecher sind
Benutzer, Entwickler, Designer, Redakteure, Studierende und Unternehmen, die Exponential mögen und anderen helfen, es zu
finden, auszuprobieren, gut zu nutzen und der Community beizutreten. Niemand ernennt Sie; Sie werden Fürsprecher an dem
Tag, an dem Sie jemand anderem mit Exponential helfen und dabei die Wahrheit sagen.

Diese Seiten beantworten drei Fragen: **Was kann ich sagen** (mit der Quelle, die es belegt), **wie sage ich es**
(Vorträge, Demos, Beiträge, Antworten) und **wohin bringe ich Menschen** (die Community-Kanäle, die es wirklich gibt).
Jede Tatsache darauf stammt aus dieser Dokumentation oder von einer öffentlichen Seite, die die Dokumentation bereits
zitiert. Wo die Quellen etwas nicht sagen, sagen die Seiten das, und das sollten Sie auch.

> **Hinweis**
> Fürsprecher sprechen als sie selbst. Sie sprechen nicht für 7x oder für die Exponential Foundation, es sei denn, eine
> der beiden hat Sie darum gebeten. Sagen Sie, wer Sie sind, wofür Sie Exponential nutzen und woher Ihre Fakten stammen.
> [Offenlegung und Interessenkonflikte](offenlegung-und-interessenkonflikte.md) erklärt, wie.

Fürsprache ist kein Vertrieb. Der Vertrieb hat eigene Seiten ([Vertrieb und Marketing: hier beginnen](../geschaeft/vertrieb-und-marketing-hier-beginnen.md)),
die Projektverantwortlichen ebenfalls ([Projektverantwortliche: hier beginnen](../fuehrung/projektleiter-hier-beginnen.md)).
Ein Fürsprecher arbeitet auf Augenhöhe: ein Benutzer hilft einem anderen, öffentlich.

## Die Stufen: Benutzer, Fürsprecher, Leitung

```text
  USER                     ADVOCATE                         LEADER
  uses Exponential   -->   helps others find and use it -->  helps others become advocates
  asks questions           answers questions                 organizes, mentors, maintains
  reads the help           cites the help, improves it       owns an area of the project
```

Jeder Schritt hat eine dokumentierte nächste Handlung. [Die Stufen der Fürsprache](die-stufen-der-fuersprache.md) beschreibt
jede Stufe, und [Eine Leitungsrolle in der Exponential-Community übernehmen](../fuehrung/community-leiter-werden.md)
enthält den 30/60/90-Tage-Plan der obersten Stufe.

## Ihre erste Stunde

1. **Wissen, wer hinter dem Projekt steht** (10 Minuten): [Wer ist 7x?](../wer-ist-7x.md#kurz-gesagt) und
   [Wer ist die Exponential Foundation?](../wer-ist-die-exponential-foundation.md#kurz-gesagt).
2. **Die Produktfamilie kennen** (10 Minuten): [Die Produktfamilie kennen](die-produktfamilie-kennen.md).
3. **Die wichtigsten Gesprächspunkte lernen** (15 Minuten): [Gesprächspunkte: das Grundset](gespraechspunkte-grundset.md)
   und die Seite, die Sie lesen müssen, bevor Sie öffentlich irgendetwas sagen: [Aussagen, die Sie nicht machen dürfen](aussagen-die-sie-nicht-machen-duerfen.md).
4. **Die Kanäle besuchen** (15 Minuten): [Die Community-Kanäle](community-kanaele.md). Lesen Sie einige
   Forendiskussionen, treten Sie dem Telegram-Chat bei, sehen Sie sich die Issue-Tracker an.
5. **Eine hilfreiche Sache tun** (10 Minuten): Beantworten Sie eine Frage mit einem Link auf eine Hilfeseite oder
   korrigieren Sie einen Tippfehler auf einer Hilfeseite mit **Auf GitHub bearbeiten** ([Die Hilfe verbessern](die-hilfe-verbessern.md)).

Folgen Sie dann [Ihre erste Woche als Fürsprecher](ihre-erste-woche.md).

## Die fünf Regeln, die jeder Fürsprecher einhält

1. **Nennen Sie Ihre Quelle.** Jede Aussage bekommt einen Link. Wenn Sie die Quelle nicht finden, machen Sie die Aussage
   nicht ([Ehrlichkeit und Genauigkeit](ehrlichkeit-und-genauigkeit.md)).
2. **Verwenden Sie die richtigen Namen.** Das Produkt heißt **Exponential**; 7x ist das Unternehmen; die Exponential
   Foundation ist die gemeinnützige Organisation; der alte Name gehört der Vergangenheit an
   ([Kurzkarte zu den Namensregeln](kurzkarte-namensregeln.md)).
3. **Halten Sie Sicherheit vertraulich.** Sicherheitslücken gehen vertraulich an die Adresse in `SECURITY.md`, nie in
   ein Forum, einen Chat oder ein öffentliches Issue ([Sicherheitsmeldungen bleiben vertraulich](sicherheitsmeldungen-bleiben-vertraulich.md)).
4. **Schützen Sie Menschen.** Keine Kundendaten, keine Passwörter, keine Screenshots mit personenbezogenen Daten, keine
   Namen ohne Zustimmung ([Die Privatsphäre von Menschen schützen](privatsphaere-schuetzen.md)).
5. **Seien Sie freundlich und fair.** Respektieren Sie andere Projekte und die Menschen, die „Anfängerfragen“ stellen
   ([Verhalten und Ethik für Fürsprecher](verhalten-und-ethik.md)).

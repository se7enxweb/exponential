# Mobile Apps, Headless und Netzwerke

Dieser Bereich ist für Inhaber, Führungskräfte und Produktverantwortliche von Organisationen, die über ihre eigene
Website hinaus verkaufen oder veröffentlichen: an Besucher auf Telefonen, über eine eigene mobile App, auf Partner- und
Wiederverkäuferwebsites, in Feedreadern und Podcast-Verzeichnissen oder zwischen mehreren eigenen Installationen. Er
erklärt, was Exponential für jeden Kanal bietet, was jeder Kanal Sie an Arbeit und Betrieb kostet und wo die technische
Dokumentation steht.

## Was dieser Bereich abdeckt

Die README des Projekts nennt unter den Hauptfunktionen von Exponential „A headless CRUD REST API“, Feeds als RSS, ATOM,
iTunes RSS und OPML, eine „SOAP communication library“ und „Support for highly available and scalable configurations
(multi-server clusters)“ (Unterstützung für hochverfügbare und skalierbare Konfigurationen mit Clustern aus mehreren
Servern). Rund darum haben die Releases 6.0 persönliche API-Schlüssel für die REST API hinzugefügt, die Remote-Dienste
`expservices`, einen Navigationscache im Browser für wiederholte Besuche und den Anwendungsserver Velocity.

Die Seiten hier erklären diese Funktionen für Entscheider: was sie möglich machen und was zu regeln ist, damit sie
weiter funktionieren.

# Vorlagen für Unternehmen

Dieser Bereich ist für Inhaber, Führungskräfte und Projektleiter, die statt einer leeren Seite ein fertiges Formular
wollen. Jede Vorlage steht in einem einfachen Textblock: Kopieren Sie sie in Ihr eigenes Dokument, Ihre Tabelle oder Ihr
Ticketsystem und ersetzen Sie die Platzhalter in spitzen Klammern oder die Lücken. Jede Seite erklärt, wann Sie die
Vorlage verwenden, und verweist auf die Hilfeseiten hinter jeder Zeile.

> **Hinweis**
> Die Vorlagen enthalten keine echten Kundendaten, Zahlen oder Zitate. Wo eine Vorlage nach Zahlen fragt, verwenden Sie
> Ihre eigenen und halten Sie die Quelle jeder Zahl fest. Fallstudien dürfen nur echte, freigegebene Fakten enthalten,
> und ein Kunde darf nur mit seiner Einwilligung genannt werden.

## So verwenden Sie sie

- Führen Sie eine Kopie pro Projekt oder Website, mit Versionsnummer und Datum.
- Benennen Sie für jede Vorlage einen Verantwortlichen; eine Checkliste ohne Verantwortlichen wird nicht erledigt.
- Entfernen Sie Zeilen, die nicht zutreffen, statt sie abzuhaken.
- Verknüpfen Sie jede Zeile, wo möglich, mit einem Nachweis (einem Ticket, einem Screenshot, einem Export).
- Bewahren Sie ausgefüllte Vorlagen mit personenbezogenen Daten so auf, dass nur die richtigen Personen sie lesen können.

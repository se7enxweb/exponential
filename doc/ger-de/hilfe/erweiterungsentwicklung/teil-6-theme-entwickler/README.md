# Teil 6: Theme-Entwickler

Dies ist der sechste Teil von [Erweiterungsentwicklung: das Buch](../README.md). Ein Theme bestimmt, wie eine Website
aussieht: ihr Pagelayout, ihre Templates für jede Inhaltsart, ihre Stylesheets, Skripte und Bilder. In Exponential ist
ein Theme eine Erweiterung mit einem Design-Ordner darin. Alles, was die früheren Teile über Erweiterungen gesagt haben,
gilt also auch hier, und dieser Teil ergänzt, was an Designs besonders ist.

## Für wen dieser Teil ist

- **Designer**, die HTML und CSS beherrschen und aus ihrem Design ein Theme für eine Website machen möchten. Teil 2
  dieses Buchs ([Der Builder](../teil-2-builder/README.md)) erklärt Templates und Overrides; lesen Sie zuerst
  mindestens [Die Design-Kette](../teil-2-builder/die-design-kette.md).
- **Entwickler**, die ein Theme für andere oder für mehrere eigene Websites packen.

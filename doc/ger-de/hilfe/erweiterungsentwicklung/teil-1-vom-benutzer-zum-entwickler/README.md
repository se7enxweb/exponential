# Teil 1: Vom Benutzer zum Entwickler

Dies ist der erste Teil von [Erweiterungsentwicklung: das Buch](../README.md). Er ist für Menschen geschrieben, die
Exponential bereits nutzen, als Redakteur, Administrator oder Website-Betreiber, und die anfangen möchten zu
verändern, was es kann. PHP müssen Sie dafür noch nicht können. Am Ende dieses Teils haben Sie eine eigene
Entwicklungsinstallation, Sie wissen, wie Sie den Code lesen, der schon auf Ihrer Festplatte liegt, und Sie wissen, wo
Sie die Arbeit der Hunderten von Menschen finden, die vor Ihnen Erweiterungen gebaut haben, und wie Sie sie fair
wiederverwenden.

## Wie Sie ihn lesen

Lesen Sie die Kapitel beim ersten Mal in ihrer Reihenfolge. Jedes endet mit den Links **Zurück** und **Weiter**. Jeder
Befehl wurde auf einer Installation von Exponential 6 ausgeführt, bevor er aufgeschrieben wurde, und jede Seite nennt
die Datei oder die Seite, aus der ihre Fakten stammen, damit Sie sie selbst prüfen können.

> **Tipp**
> Halten Sie beim Lesen ein Terminal und die Administration nebeneinander offen. Fast jedes Kapitel bittet Sie, sich
> etwas auf Ihrer eigenen Installation anzusehen; es dort zu sehen, sorgt dafür, dass es hängen bleibt.

# Share Exponential (share.exponential.earth)

Teil 1, Kapitel 11. [Share Exponential](https://share.exponential.earth/) ist das Community-Portal des Projekts
Exponential. Dieses Kapitel sagt Ihnen, was ein Entwickler dort findet und wie Sie es gut nutzen. Die Beschreibung hat
den Stand Oktober 2026; maßgeblich für die aktuellen Bereiche ist das Portal selbst.

## Was es ist

Das Portal beschreibt sich als den Ort, an dem Entwickler, Benutzer und Mitwirkende zusammenarbeiten. Seine Fußzeile
erklärt, dass seine Inhalte urheberrechtlich 7x gehören und dass das Projekt „is not associated with the original eZ
Publish software or its original developer, eZ Systems or Ibexa“. Es läuft selbst auf Exponential.

Das Menü **Project** verlinkt die Downloads, die Pull Requests und das Repository auf GitHub, die Projektplattform
([Exponential Projects](projects-exponential-earth.md)) und die Chat-Kanäle. Der Telegram-Kanal
[t.me/exponentialcms](https://t.me/exponentialcms) wird auch in [Wer ist 7x?](../../wer-ist-7x.md) genannt; das Portal
führt außerdem Slack, Discord und eine LinkedIn-Gruppe auf.

## Wie Sie es durchsuchen

1. Verwenden Sie die eigene Suche des Portals mit Wörtern aus Ihrer Fehlermeldung oder dem Namen der Klasse oder
   Einstellung.
2. Durchsuchen Sie auch die Foren unter dem alten Produktnamen: Viele Antworten aus den früheren Jahren gelten noch für
   den Kernel, dessen Codebasis Exponential fortführt.
3. Wenn Sie eine Antwort finden, prüfen Sie, für welche Version sie geschrieben wurde. Einstellungen und Templates haben
   sich selten geändert; PHP-Code, der für PHP 5 geschrieben wurde, braucht die Änderungen aus
   [Teil 4](../teil-4-aktualisieren/README.md).

## Was Sie finden, verwenden

Die Inhalte des Portals gehören urheberrechtlich 7x, sofern eine Seite nichts anderes sagt. Das bedeutet:

- **Verlinken** Sie auf einen Forenbeitrag oder ein Tutorial, statt es in Ihre eigene Dokumentation zu kopieren.
- **Zitieren** Sie eine kurze Passage, wenn nötig, mit einem Link und dem Datum, an dem Sie sie gelesen haben.
- **Code**, der in einem Forum veröffentlicht wurde, trägt für sich genommen keine Lizenzangabe. Bei ein paar Zeilen,
  die ein häufiges Problem lösen, ist das selten ein Thema, aber bei allem Wesentlichen fragen Sie den Autor im Thread,
  ob Sie den Code unter der Lizenz Ihrer Erweiterung wiederverwenden dürfen.
  [Lizenzen lesen, bevor Sie etwas wiederverwenden](lizenzen-vor-der-wiederverwendung-lesen.md) erklärt, warum.

## Etwas zurückgeben

Ein Portal wie dieses lebt von Antworten. Wenn Sie etwas gelöst haben:

- Beantworten Sie die Frage in dem Forum, in dem Sie sie unbeantwortet gefunden haben.
- Schreiben Sie ein Tutorial (die Seite **Write a tutorial!** erklärt, wie).
- Kündigen Sie Ihre Erweiterung im Forum Extensions an, wenn Sie sie veröffentlichen; siehe
  [Ein Release ankündigen](../teil-7-veroeffentlichen/ein-release-ankuendigen.md).

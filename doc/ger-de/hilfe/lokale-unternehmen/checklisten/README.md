## Vor einem Feiertag

Zwei Wochen vor einem Feiertag oder einer Schließung:

- [ ] Hinweistext geschrieben, mit vollständigen Daten, in jeder Sprache der Website.
- [ ] Hinweis als Entwurf vorbereitet oder zur Veröffentlichung an einem Datum eingestellt
      ([Feiertags- und Saisonöffnungszeiten](../karten-und-oeffnungszeiten/feiertags-und-saisonoeffnungszeiten.md)).
- [ ] Sonderöffnungszeiten auf jeder Karten- und Suchplattform eingetragen.
- [ ] Wenn Sie verkaufen: letzter Bestelltag für eine Lieferung vor dem Feiertag genannt; Abholtage genannt.
- [ ] Erwähnung im Newsletter, falls Sie einen versenden.
- [ ] Die Kontaktseite sagt, wie man Sie im Notfall erreicht, falls das zutrifft (Handwerk, Praxen).
- [ ] Jemand ist benannt, der den Hinweis danach entfernt.

## Umzug in neue Räume

- [ ] Adresse im einen gemeinsamen Kontaktobjekt geändert (und in jedem Standortobjekt).
- [ ] Kartenpunkt verschoben: das Feld `ezgmaplocation` oder Breiten- und Längengrad des Karten-Blocks
      ([Ihren Standort auf einer Karte zeigen](../karten-und-oeffnungszeiten/ihren-standort-auf-einer-karte-zeigen.md)).
- [ ] Anfahrtstext, Parken und Zugang neu geschrieben; neue Fotos der Fassade.
- [ ] Öffnungszeiten geprüft; oft ändern sie sich mit dem Umzug.
- [ ] Hinweis auf der Startseite für einige Monate: „Wir sind umgezogen nach ...“.
- [ ] Adresse auf jeder Plattform geändert (die meisten verlangen eine Bestätigung; fangen Sie früh an)
      ([Unternehmenseinträge außerhalb von Exponential](../gefunden-werden/unternehmenseintraege-ausserhalb-von-exponential.md)).
- [ ] Strukturierte Daten, falls Ihre Website welche ausgibt, zeigen die neue Adresse.
- [ ] Shop: Abholadresse im Text an der Kasse und in der Bestätigungs-E-Mail.
- [ ] Gedrucktes Material mit der alten Adresse ersetzt; kurze Webadressen funktionieren weiterhin.

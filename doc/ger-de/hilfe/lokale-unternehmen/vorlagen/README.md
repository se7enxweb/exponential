## Wie Sie sie verwenden

1. Füllen Sie aus, was Sie wissen; lassen Sie den Rest leer und markieren Sie ihn mit „noch zu entscheiden“.
2. Bewahren Sie die ausgefüllten Vorlagen bei Ihren Geschäftsunterlagen auf, nicht nur im Postfach einer Person.
3. Aktualisieren Sie sie einmal im Jahr bei der [jährlichen Überprüfung](../im-betrieb/woechentliche-und-monatliche-routine.md#jedes-jahr-mit-ihrem-hoster-oder-partner).

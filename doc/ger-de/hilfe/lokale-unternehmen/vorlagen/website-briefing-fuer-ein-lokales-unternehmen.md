# Website-Briefing für ein lokales Unternehmen

Diese Vorlage ist für Inhaber eines lokalen Unternehmens. Füllen Sie sie aus, bevor Sie Angebote einholen; dann
können Partner dasselbe anbieten, und Sie können vergleichen. Lassen Sie eine Zeile leer, wenn Sie es noch nicht
wissen, und schreiben Sie „noch zu entscheiden“.

## Ziele

Was soll die Website im ersten Jahr erreichen? Kreuzen Sie an und ergänzen Sie Eigenes:

- [ ] Von Menschen in der Nähe gefunden werden ([Grundlagen der lokalen Suchmaschinenoptimierung](../gefunden-werden/grundlagen-der-lokalen-suchmaschinenoptimierung.md))
- [ ] Fragen zu Öffnungszeiten, Standort und Kontakt beantworten
- [ ] Anfragen oder Angebotsanfragen erhalten
- [ ] Produkte oder Gutscheine online verkaufen
- [ ] Veranstaltungen und Angebote ankündigen
- [ ] Eine Newsletter-Liste aufbauen
- [ ] Anderes: ________

Woran werden Sie erkennen, dass es funktioniert? (zum Beispiel: „fünf Anfragen pro Monat über das Formular“)

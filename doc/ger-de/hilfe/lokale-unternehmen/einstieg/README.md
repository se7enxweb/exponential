# Einstieg: Websites lokaler Unternehmen

Diese Seitengruppe ist für Inhaber eines kleinen Unternehmens, die bald eine Website bekommen oder eine alte ersetzen.
Sie hilft Ihnen zu entscheiden, was Sie brauchen, bevor jemand einen Editor öffnet, damit das Geld dorthin geht, wo es
zählt.

## Die Reihenfolge zum Lesen

1. Beginnen Sie mit [Was die Website eines kleinen Unternehmens braucht](was-die-website-eines-kleinen-unternehmens-braucht.md). Die
   Seite ist kurz und entscheidet, wie viel vom Rest Sie brauchen.
2. Planen Sie die Seiten mit [Ihre Seiten planen](ihre-seiten-planen.md), und tragen Sie sie in das
   [Website-Briefing](../vorlagen/website-briefing-fuer-ein-lokales-unternehmen.md) ein.
3. Lesen Sie [Selbst machen oder Hilfe holen](selbst-machen-oder-hilfe-holen.md), und entscheiden Sie.
4. Wenn Sie jemanden beauftragen, lesen Sie [Mit einem lokalen Partner oder Freiberufler arbeiten](mit-einem-lokalen-partner-oder-freiberufler-arbeiten.md).
5. Wählen Sie das Hosting zuletzt, wenn Sie wissen, wer die Website betreibt:
   [Hosting für ein kleines Unternehmen wählen](hosting-fuer-ein-kleines-unternehmen-waehlen.md).

## Drei Fragen, die Sie zuerst beantworten

| Frage | Warum sie wichtig ist |
|---|---|
| Wollen Sie online verkaufen oder nur gefunden und kontaktiert werden? | Ein Shop bringt Zahlungen, Mehrwertsteuer, Versand und tägliche Arbeit mit Bestellungen mit sich ([Brauchen Sie einen Shop?](../einfacher-shop/brauchen-sie-einen-shop.md)). |
| Wer ändert an einem Feiertag die Öffnungszeiten? | Wenn die Antwort „der Partner“ lautet, kostet jede Änderung Geld und Zeit. Planen Sie, dass jemand im Unternehmen das übernimmt. |
| Wer reagiert, wenn die Website an einem Samstag nicht erreichbar ist? | Das entscheidet über Ihr Hosting und Ihre Support-Vereinbarung ([Hosting für ein kleines Unternehmen wählen](hosting-fuer-ein-kleines-unternehmen-waehlen.md)). |

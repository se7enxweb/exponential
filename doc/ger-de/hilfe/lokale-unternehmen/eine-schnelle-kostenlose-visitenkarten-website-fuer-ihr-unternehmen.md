# Eine schnelle, kostenlose Visitenkarten-Website für Ihr Unternehmen

Die meisten Websites kleiner Unternehmen ändern sich ein paar Mal im Monat: Öffnungszeiten, eine neue Leistung, ein
Hinweis zu den Ferien. So eine Website braucht keinen Server, der den ganzen Tag läuft. Mit statischem Veröffentlichen
bearbeiten Sie sie in Exponential und veröffentlichen eine statische Kopie, die GitHub Pages kostenlos unter Ihrer
eigenen Domain ausliefert.

## Was Sie am Ende haben

- Ihre Website unter `https://www.ihr-unternehmen.example/`, mit HTTPS, schnell auf jedem Telefon.
- Keine monatliche Hosting-Rechnung für die öffentliche Website; Sie zahlen nur die Domain.
- Einen Weg zurück mit einem Klick, wenn eine Änderung danebenging.

## Was gut passt

- Öffnungszeiten, Adresse, Link zur Karte und Telefonnummer.
- Leistungen und Preislisten, eine Teamseite, Fotos Ihrer Arbeit.
- Neuigkeiten und Angebote, online, wenn Sie sie veröffentlichen, oder automatisch nach Zeitplan.

## Wann Sie es nicht nutzen sollten

Seien Sie hier ehrlich zu sich selbst:

- **Ein Online-Shop** mit Warenkorb, Kasse und Lagerbestand. Die Bedingungen von GitHub Pages erlauben auch keinen
  Shop. Lassen Sie den Shop auf einem echten Server.
- **Buchungen und Termine**, die einen Kalender brauchen. Verlinken Sie stattdessen einen Buchungsdienst.
- **Kundenkonten.** Eine statische Kopie hat keine Anmeldung.

Ein Kontaktformular kann trotzdem funktionieren: Es kann an Ihre Exponential-Installation senden oder einen Link zur
Live-Seite zeigen. Siehe [Suche, Formulare und Kommentare auf einer statischen Site](../statisches-veroeffentlichen/suche-formulare-und-kommentare-auf-einer-statischen-site.md) und
[Grenzen und Bedingungen von GitHub Pages](../statisches-veroeffentlichen/grenzen-und-bedingungen-von-github-pages.md).

## Ihre eigene Domain

Kunden sollen Ihren Namen sehen, nicht `github.io`. Setzen Sie die Domain im Assistenten, tragen Sie die DNS-Einträge
bei Ihrem Domain-Anbieter ein, und GitHub stellt das Zertifikat aus. Schritt für Schritt:
[Eigene Domain verwenden](../statisches-veroeffentlichen/eigene-domain-verwenden.md).

## Gefunden werden

Der Build schreibt eine `sitemap.xml` und eine `robots.txt` und behält Ihre Seitentitel und Beschreibungen. Siehe
[SEO auf einer statischen Site](../statisches-veroeffentlichen/seo-auf-einer-statischen-site.md).

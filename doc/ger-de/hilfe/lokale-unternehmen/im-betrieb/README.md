# Im Betrieb: die Website eines lokalen Unternehmens nach dem Livegang

Diese Seitengruppe ist für Inhaber oder die eine Person, die sich um die Website eines lokalen Unternehmens kümmert,
sobald sie live ist. Eine Website ist mit dem Livegang nicht fertig: Öffnungszeiten ändern sich, Mitarbeitende
wechseln, Software bekommt Updates. Ein paar Minuten pro Woche halten sie funktionsfähig.

## Wer was macht

| Aufgabe | Inhaber oder Mitarbeitende | Hoster oder Partner |
|---|---|---|
| Öffnungszeiten, Angebote, Veranstaltungen, Fotos | ja | - |
| Nachrichten und Bestellungen beantworten | ja | - |
| Prüfen, ob die Website funktioniert | ja, ein kurzer Blick | Überwachung, falls vereinbart |
| Software-Updates | - | ja ([Updates und Upgrades](../../ersteller/website-ersteller/updates-und-aktualisierungen.md)) |
| Sicherungen | einmal im Jahr einen Nachweis verlangen | ja ([Sicherungen, die sich wiederherstellen lassen](../../unternehmen/zuverlaessigkeit/backups-die-sich-wiederherstellen-lassen.md)) |
| Konten für neue und ausscheidende Mitarbeitende | ja, oder den Administrator fragen | - |

Schreiben Sie Ihre eigene Fassung in [Wer was macht](../../kunden/partner-und-hoster/wer-was-macht.md).

## Die drei Dinge, die am häufigsten schiefgehen

1. **Veraltete Informationen**: Öffnungszeiten oder Preise, die sich vor Monaten geändert haben. Abhilfe: die
   wöchentliche Routine.
2. **Ein kaputtes Formular oder kaputte E-Mail**: Nachrichten, die nie ankommen. Abhilfe: der monatliche Test.
3. **Verlorener Zugang**: Der einzige Administrator ist weg, niemand kennt das Passwort. Abhilfe: zwei
   Administratorkonten und eine schriftliche Liste der Konten ([Sicherungen, Updates und Sicherheit](sicherungen-updates-und-sicherheit.md#konten-wenn-mitarbeitende-kommen-und-gehen)).

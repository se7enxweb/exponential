# Wöchentliche und monatliche Routine

Diese Seite ist für Inhaber oder Mitarbeitende, die sich um die Website eines lokalen Unternehmens kümmern. Die
Routine ist absichtlich kurz: Eine, die tatsächlich erledigt wird, schlägt eine gründliche, die liegen bleibt.

## Jede Woche, fünfzehn Minuten

- [ ] Öffnen Sie die Startseite auf Ihrem Smartphone. Ist alles aktuell?
- [ ] Öffnungszeiten: Gibt es in den nächsten zwei Wochen eine Ausnahme? Bereiten Sie den Hinweis vor
      ([Feiertags- und Saisonöffnungszeiten](../karten-und-oeffnungszeiten/feiertags-und-saisonoeffnungszeiten.md)).
- [ ] Angebote und Veranstaltungen: Entfernen Sie vergangene, ergänzen Sie die nächsten ([Veranstaltungen und Angebote](../marketing/veranstaltungen-und-angebote.md)).
- [ ] Nachrichten: Wurden alle Formularnachrichten der Woche beantwortet?
- [ ] Rezensionen und Fragen auf Karten- und Suchplattformen: lesen und beantworten
      ([Unternehmenseinträge außerhalb von Exponential](../gefunden-werden/unternehmenseintraege-ausserhalb-von-exponential.md)).

## Jeden Monat, eine Stunde

- [ ] Schicken Sie abgemeldet über jedes Formular eine Testnachricht; prüfen Sie, dass sie ankommt
      ([Ein Kontaktformular für Ihr Unternehmen](../kontakt-und-formulare/ein-kontaktformular-fuer-ihr-unternehmen.md#halten-sie-es-funktionsfähig)).
- [ ] Sehen Sie sich die Suchstatistiken der Website an: Wonach haben Besucher gesucht und es nicht gefunden? Ergänzen
      Sie eine Seite, oder benennen Sie eine um
      ([Website-Suche und wonach Besucher suchen](../../kunden/alltag/website-suche-und-wonach-besucher-suchen.md)).
- [ ] Notieren Sie die Zahlen dieses Monats: Formularnachrichten, Bestellungen, Strichliste „Wie haben Sie uns
      gefunden?“ ([Besuche messen](../gefunden-werden/besuche-messen.md)).
- [ ] Prüfen Sie auf defekte Links, oder bitten Sie Ihren Administrator um den Bericht der Linkprüfung
      ([Defekte Links und Inhaltsprüfungen](../../ersteller/website-ersteller/link-und-inhaltspruefungen.md)).
- [ ] Ersetzen Sie ein abgenutztes Foto, oder fügen Sie ein neues hinzu.
- [ ] Vergleichen Sie Name, Adresse, Telefon und Öffnungszeiten auf den Plattformen mit der Website.
- [ ] Hat der Hoster oder Partner ein Update gemeldet? Sehen Sie sich danach die Website an.

Die allgemeine Fassung für jede Website: [Monatliche SEO-Checkliste](../../kunden/alltag/monatliche-seo-checkliste.md).

## Jedes Jahr, mit Ihrem Hoster oder Partner

Planen Sie jeden Januar eine Stunde ein:

- [ ] Lassen Sie sich eine Wiederherstellung aus einer Sicherung nachweisen ([Sicherungen, Updates und Sicherheit](sicherungen-updates-und-sicherheit.md)).
- [ ] Welche Exponential-Version läuft? Sind die Updates aktuell?
- [ ] Prüfen Sie, wer ein Konto hat; entfernen Sie die, die gegangen sind.
- [ ] Verlängern Sie die Domain; prüfen Sie, dass sie auf den Namen des Unternehmens läuft.
- [ ] Lesen Sie die Datenschutzerklärung erneut: Nennt sie jeden externen Dienst (Karten, CAPTCHA, Analyse, Buchung)?
- [ ] Löschen Sie alte Formulareinsendungen, die Sie nicht mehr brauchen
      ([Umgang mit Nachrichten und Datenschutz](../kontakt-und-formulare/umgang-mit-nachrichten-und-datenschutz.md)).
- [ ] Prüfen Sie die Zahlen und Kosten des Jahres mit dem [Budget-Arbeitsblatt](../budget/budget-arbeitsblatt.md).
- [ ] Planen Sie die Feiertage und Saisons des Jahres ([Saisonale Änderungen](saisonale-aenderungen.md)).
- [ ] Überprüfen Sie die Vereinbarung mit dem Anbieter ([Ihren Anbieter jedes Jahr überprüfen](../../kunden/partner-und-hoster/anbieter-jedes-jahr-ueberpruefen.md)).

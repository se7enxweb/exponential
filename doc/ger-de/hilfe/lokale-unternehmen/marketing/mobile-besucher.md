# Mobile Besucher

Diese Seite ist für Inhaber eines lokalen Unternehmens. Viele Ihrer Besucher stehen mit dem Smartphone auf der Straße,
auf einem Parkplatz oder sitzen auf dem Sofa, und sie wollen schnell eine Antwort: Haben Sie geöffnet, wo sind Sie,
wie rufe ich Sie an.

## Was Besucher mit dem Smartphone wollen

| Frage | Die Antwort muss sein |
|---|---|
| Haben Sie jetzt geöffnet? | Öffnungszeiten auf der Startseite sichtbar oder einen Fingertipp entfernt |
| Wo sind Sie? | Adresse als Text und ein Link, der die eigene Karten-App öffnet |
| Kann ich anrufen? | eine Telefonnummer zum Antippen |
| Was bieten Sie an, was kostet es? | eine kurze Speisekarte oder Leistungsliste, ohne Zoomen lesbar |
| Kann ich buchen oder bestellen? | eine klare Schaltfläche (auch wenn sie zu einem externen Dienst führt) |

## Was Exponential Ihnen bietet

- **Ein responsives Standarddesign.** `sevenx_themes_simple`, das öffentliche Standarddesign, wird als „the light,
  responsive public design of the default installation“ beschrieben, also das leichte, responsive öffentliche Design
  der Standardinstallation ([Responsive Websites](../../unternehmen/mobil-und-headless/responsive-websites.md)). Andere
  Themes und Ihr eigenes Design sind so responsiv, wie ihre Gestalter sie gemacht haben.
- **Bildvarianten** in passenden Größen, damit Smartphones keine riesigen Fotos herunterladen
  ([Bilder und Bildvarianten](../../ersteller/website-ersteller/bilder-und-bildvarianten.md)).
- **Schnelle Seiten** durch Caching und Velocity für hohen Andrang
  ([Leistung und Caching](../../ersteller/website-ersteller/leistung-und-caching.md)).
- **Karten, die erst per Klick laden**, im Karten-Block des Layout-Editors; sie halten die Seite leicht, bis der
  Besucher die Karte will ([Ihren Standort auf einer Karte zeigen](../karten-und-oeffnungszeiten/ihren-standort-auf-einer-karte-zeigen.md)).

## Kleine Änderungen mit großer Wirkung

| Änderung | Wer |
|---|---|
| Telefonnummer als `tel:`-Link in der Kopf- oder Fußzeile | einmal der Ersteller oder der Redakteur im Rich Text |
| Link „Anfahrt“ unter der Adresse | Redakteur |
| Öffnungszeiten weit oben auf der Startseite | Ersteller oder Redakteur |
| Kurzer erster Absatz auf jeder Seite | Redakteur |
| Große, klare Schaltflächen für „Anrufen“, „Anfahrt“, „Buchen“ | Ersteller |
| Keine PDFs für Speisekarten oder Preislisten; stattdessen Textseiten | Redakteur |
| Formulare mit wenigen Feldern und der richtigen Tastatur (E-Mail, Telefon) | Ersteller ([Barrierefreie Formulare](../../verwaltung/barrierefreiheit/barrierefreie-formulare.md)) |

## Ein Zehn-Minuten-Test auf Ihrem eigenen Smartphone

Verwenden Sie mobile Daten, nicht das WLAN des Geschäfts, und ein privates Browserfenster.

1. Suchen Sie nach dem Namen Ihres Unternehmens und Ihrem Ort; öffnen Sie Ihre Website über das Ergebnis.
2. Messen Sie, wie lange es dauert, bis die Startseite lesbar ist.
3. Finden Sie die Öffnungszeiten. Wie viele Fingertipps?
4. Tippen Sie auf die Telefonnummer. Bietet das Smartphone an anzurufen?
5. Tippen Sie auf den Anfahrtslink. Öffnet sich die Karten-App mit Ihrer Adresse?
6. Öffnen Sie die Speisekarte oder Preisliste. Können Sie sie ohne Zoomen lesen?
7. Senden Sie das Kontaktformular ab. Passt die Tastatur zu jedem Feld? Erscheint die Dankeseite?
8. Wenn Sie verkaufen: Legen Sie etwas in den Warenkorb und gehen Sie zur Kasse (nicht bezahlen).
9. Wechseln Sie die Sprache, wenn Sie mehrere haben.
10. Drehen Sie das Smartphone. Geht etwas kaputt?

Schreiben Sie auf, was langsam oder umständlich war, und schicken Sie es Ihrem Ersteller. Ein ausführlicherer Plan
steht in [Responsive Websites](../../unternehmen/mobil-und-headless/responsive-websites.md#ein-testplan-den-sie-selbst-ausführen-können)
und in der [mobilen Checkliste](../../unternehmen/mobil-und-headless/checkliste-mobil.md).

## Wann Sie den Ersteller anrufen

- Text wird abgeschnitten, oder die Seite lässt sich seitwärts scrollen.
- Die Menüschaltfläche öffnet sich nicht.
- Seiten brauchen über mobile Daten lange, bis sie erscheinen.
- Ein Formular lässt sich auf einem Smartphone nicht absenden.

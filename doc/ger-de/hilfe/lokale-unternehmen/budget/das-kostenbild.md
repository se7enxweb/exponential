# Das Kostenbild

Diese Seite ist für Inhaber eines kleinen Unternehmens, die wissen wollen, was eine Website mit Exponential über die
Jahre kostet, nicht nur zum Livegang. Sie listet die Posten auf und was sie bestimmt. Sie enthält **keine Preise**:
Holen Sie diese als Angebote ein, und tragen Sie sie in das [Budget-Arbeitsblatt](budget-arbeitsblatt.md) ein.

## Einmalige Kosten

| Posten | Umfasst | Bestimmt durch |
|---|---|---|
| Einrichtung | Installation, ein mitgeliefertes Theme, an Ihre Farben und Ihr Logo angepasst, Inhaltsklassen (Öffnungszeiten, Standorte, Formulare), eingeschaltete Erweiterungen | wie weit das Design von einem mitgelieferten Theme abweicht ([Ein Design oder Theme wählen](../../ersteller/website-ersteller/ein-design-oder-theme-waehlen.md)) |
| Inhalte | Texte, Fotos, Übersetzung | wie viel Sie selbst schreiben |
| Shop-Einrichtung (optional) | Produktklasse, Mehrwertsteuer, Zahlung, Versand, Tests | Anzahl der Zahlungs- und Versandoptionen |
| Umzug von einer alten Website (optional) | Übertragung der Inhalte, Weiterleitungen alter Adressen | Größe der alten Website ([Sprechende URLs und verschobene Seiten](../gefunden-werden/sprechende-urls-und-verschobene-seiten.md#eine-alte-website-ersetzen)) |
| Schulung | ein bis zwei Stunden für die Personen, die bearbeiten | Anzahl der Redakteure |
| Lizenz | keine | GNU GPL ([Lizenzierung für Käufer](../../geschaeft/lizenzen-fuer-kaeufer.md)) |

## Jährliche Kosten

| Posten | Umfasst | Bestimmt durch |
|---|---|---|
| Domain | die Registrierung | die Domain-Endung |
| Hosting | den Server, Sicherungen, HTTPS | Hosting-Modell ([Kostentreiber beim Hosting](../../unternehmen/kosten/kostentreiber-beim-hosting.md)) |
| Updates | Updates von Exponential und Erweiterungen einspielen, die Website danach prüfen | Häufigkeit; verwalteter Hoster oder Partner ([Upgrades und Wartung budgetieren](../../unternehmen/kosten/budget-fuer-aktualisierungen-und-wartung.md)) |
| Support | Fragen beantworten, beheben, was kaputtgeht | die vereinbarte Reaktionszeit |
| Kleine Änderungen | ein neues Formular, ein neuer Abschnitt | wie oft Sie fragen |

## Externe Dienste

| Dienst | Nötig, wenn | Abrechnung |
|---|---|---|
| E-Mail-Versand für einen Newsletter | größere Listen, wenn die E-Mail des Hosters nicht reicht | durch den Anbieter |
| Kartenanbieter (Google) | Karten mit `ezgmaplocation` oder die Google-Variante des Karten-Blocks | durch Google, oberhalb eines kostenlosen Kontingents; OpenStreetMap im Karten-Block braucht keinen Schlüssel |
| CAPTCHA-Anbieter | reCAPTCHA oder hCaptcha | durch den Anbieter; lesen Sie dessen Bedingungen |
| Analyse | wenn Sie einen Dienst hinzufügen | durch den Anbieter |
| Zahlungsanbieter | wenn Sie verkaufen | Gebühren pro Transaktion |
| Buchungs-, Reservierungs-, Bestellplattform | wenn Sie sie brauchen | Abonnement oder Provision |

Vollständige Liste mit dem, was nicht eingebaut ist: [Was einen externen Dienst braucht](was-einen-externen-dienst-braucht.md).

## Ihre eigene Zeit

Der größte versteckte Kostenfaktor der Website eines kleinen Unternehmens ist die Zeit des Inhabers. Rechnen Sie sie
mit:

| Aufgabe | Wie oft |
|---|---|
| Öffnungszeiten, Angebote, Veranstaltungen aktualisieren | wöchentlich |
| Formularnachrichten beantworten | täglich |
| Fotos und neue Seiten | monatlich |
| Prüfen, ob die Website noch funktioniert | monatlich ([Wöchentliche und monatliche Routine](../im-betrieb/woechentliche-und-monatliche-routine.md)) |
| Shop-Bestellungen bearbeiten | täglich, wenn Sie verkaufen |

## Zusätzliche Posten für einen Shop

- Gebühren des Zahlungsanbieters bei jedem Verkauf.
- Verpacken, Versenden oder Abholungen vorbereiten.
- Mehrwertsteuer-Einrichtung, von Ihrem Steuerberater geprüft.
- Mehr Aufmerksamkeit für die Sicherheit bei Zahlungen ([Sicherheits-Checkliste für Shops](../../unternehmen/shops/sicherheitscheckliste-fuer-shops.md)).
- Rücksendungen und Erstattungen.

Das [durchgerechnete Beispiel für einen kleinen Shop](../../unternehmen/kosten/durchgerechnetes-beispiel-kleiner-shop.md) rechnet
diese Posten mit Beispielannahmen durch.

## Was es billiger oder teurer macht

| Billiger | Teurer |
|---|---|
| ein mitgeliefertes Theme mit Ihrem Logo und Ihren Farben | ein von Grund auf neu gestaltetes Design |
| wenige Seiten, gut gepflegt | viele Seiten, die niemand aktualisiert |
| Öffnungszeiten und Angebote selbst bearbeiten | den Partner um jede Änderung bitten |
| SQLite auf einem Rechner ([Datenbankunterstützung](../../datenbankunterstuetzung.md)) | mehrere Server |
| eine Sprache | mehrere Sprachen, die gleichzeitig gepflegt werden müssen |
| Links zu externer Buchung | ein eigenes Buchungsmodul |

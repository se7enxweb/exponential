# Budget-Arbeitsblatt

Diese Seite ist ein Arbeitsblatt für Inhaber eines kleinen Unternehmens. Kopieren Sie es in eine Tabellenkalkulation
oder drucken Sie es aus, und tragen Sie die Zahlen aus den erhaltenen Angeboten ein. Die Spalte **Quelle** ist wichtig:
Schreiben Sie auf, woher jede Zahl stammt (ein Angebot, eine Rechnung, Ihre eigene Schätzung), damit Sie sie später
prüfen können.

Die Posten werden in [Das Kostenbild](das-kostenbild.md) erklärt; ein ausgefülltes Beispiel steht in
[Durchgerechnetes Beispiel: die Website eines lokalen Unternehmens](durchgerechnetes-beispiel-website-eines-lokalen-unternehmens.md).

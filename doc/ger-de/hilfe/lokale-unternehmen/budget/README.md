# Budget: was die Website eines lokalen Unternehmens kostet

Diese Seitengruppe hilft Inhabern eines kleinen Unternehmens, eine realistische Zahl für eine Website zu finden. Sie
nennt keine Preise echter Anbieter, denn diese unterscheiden sich nach Land, Anbieter und Jahr. Jede verwendete Zahl
ist als **Beispielannahme** gekennzeichnet, die Sie durch erhaltene Angebote ersetzen.

## Die eine feste Tatsache

Exponential ist freie Software unter der GNU General Public License, Version 2 oder später. Es gibt keine
Lizenzgebühr, und die Erweiterungen, die dieser Bereich verwendet (`xrowmetadata`, `bcgooglesitemaps`,
`ezgmaplocation`, `recaptcha`, `hcaptcha`, `ezstarrating`, `ezpaypal`, `cjw_newsletter`), sind freie Software in der
Standard-`composer.json` ([Lizenzierung für Käufer](../../geschaeft/lizenzen-fuer-kaeufer.md),
[Wofür Sie nicht bezahlen](../../unternehmen/kosten/wofuer-sie-nicht-bezahlen.md)).

Bezahlen müssen Sie **Arbeit** (Aufbau, Updates, Support), **Hosting** und **externe Dienste** (Zahlungsanbieter,
Karten- oder CAPTCHA-Anbieter oberhalb eines kostenlosen Kontingents, Buchungsdienst, E-Mail-Versand).

## Wie Sie diese Seiten verwenden

1. Lesen Sie [Das Kostenbild](das-kostenbild.md), um zu wissen, welche Posten es gibt.
2. Sehen Sie sich das [durchgerechnete Beispiel](durchgerechnetes-beispiel-website-eines-lokalen-unternehmens.md) an, um den Rechenweg zu
   sehen.
3. Bitten Sie zwei oder drei Partner oder Hoster um Angebote, mit dem [Website-Briefing](../vorlagen/website-briefing-fuer-ein-lokales-unternehmen.md).
4. Tragen Sie deren Zahlen in das [Budget-Arbeitsblatt](budget-arbeitsblatt.md) ein.
5. Vergleichen Sie mit dem, was die Website einbringen soll, auch wenn es nur grob ist.

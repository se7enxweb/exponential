# Rechnungen, Belege und Steuern

Diese Seite ist für Sponsoren und für die Personen, die ihre Zahlungen verbuchen. Sie zitiert die Quellen und fügt
nichts hinzu, was diese nicht sagen. Sie ist keine Steuerberatung.

## Bezahlen über GitHub Sponsors

Aus der Dokumentation von GitHub, „About sponsorships, fees, and taxes“
(<https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes>, gelesen
am 18. Oktober 2026):

| Thema | GitHub sagt |
|---|---|
| Abrechnung und Belege | „Ihr Sponsoring nutzt das bestehende Abrechnungsdatum, die Zahlungsmethode und den Beleg Ihres Kontos.“ |
| Zahlungsmethoden | „Debit- oder Kreditkarten und Patreon“; PayPal wird für GitHub Sponsors seit dem 23. Februar 2023 nicht unterstützt |
| Wann Sie belastet werden | „Ihr Guthaben wird mit sofortiger Wirkung belastet“; monatliche Sponsorings werden anteilig bis zu Ihrem Abrechnungsdatum berechnet |
| Rechnungen | „Unternehmen und Organisationen können sich für die Abrechnung per wiederkehrender Rechnung entscheiden“ |
| Gebühren | Keine GitHub-Gebühr für Sponsorings von persönlichen Konten; „eine Gebühr von bis zu 6 % für Sponsorings von Organisationskonten“ (3 % für die Kartenabwicklung, 3 % Servicegebühr), und die Abrechnung per Rechnung spart die Kartengebühr von 3 % |
| Weitergegebene Informationen | GitHub „kann bestimmte begrenzte Steuerinformationen an gesponserte Konten weitergeben“, etwa das Datum der Transaktion |

Alle Einzelheiten finden Sie in der Dokumentation von GitHub, beginnend bei <https://docs.github.com/en/sponsors>.

## Steuern

- **Die Exponential Foundation** ist „eine gemeinnützige Körperschaft nach 501(c)(3)“ und gibt an: „Gespendete Mittel
  sind steuerfrei und in den Vereinigten Staaten von der Steuer des Spenders absetzbar“
  (<https://foundation.exponential.earth/>). Ob eine Zahlung über GitHub Sponsors für Ihre Steuer als Spende an die
  Foundation gilt und welchen Beleg Sie brauchen, müssen Sie mit Ihrem Berater klären; bitten Sie die Foundation um
  eine Spendenquittung, wenn Sie eine brauchen.
- **7x** ist ein Unternehmen. Die Quellen beschreiben ein Sponsoring von 7x nicht als Spende; mehrere seiner Stufen
  enthalten Leistungen (Support, Beratung, Pair Programming). Behandeln Sie es so, wie Ihr Berater es Ihnen sagt.
- Außerhalb der Vereinigten Staaten gelten die Regeln Ihres eigenen Landes.

## Rechnungen für Leistungen

Partner-Abonnements und Leistungen, die Sie bei 7x kaufen, sind Käufe mit Rechnungen aus dem Shop von 7x
([Partnerpläne und Preise](../../../eng-us/help/partners/partner-plans-and-prices.md#invoices-and-taxes)).

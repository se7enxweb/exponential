# 7x auf GitHub sponsern

Diese Seite ist für Personen und Organisationen, die 7x sponsern möchten, das Unternehmen, das die Entwicklung von
Exponential leitet. Die Seite ist <https://github.com/sponsors/se7enxweb>. Alles Folgende wurde am 18. Oktober 2026
über die GitHub-API gelesen; Stufen können sich ändern, maßgeblich ist die aktuelle Seite.

## Was 7x Sponsoren bietet

Der Abschnitt „What we offer to sponsors like you“ des Eintrags nennt: Erwähnungen der Sponsoren auf X.com, Instagram,
dem Community-Portal und LinkedIn; Unterstützung bei der Installation; allgemeine Wartung; Unterstützung bei der
Fehlersuche; Unterstützung bei fortgeschrittener Entwicklung; die Möglichkeit, „dem Team für das Produkt-Backlog
beizutreten und Ihre Ideen in echte Software verwandeln zu lassen“; und Hilfe beim Veröffentlichen und Betreuen Ihrer
eigenen individuellen Lösungen.

> **Hinweis**
> Einige Texte der Stufen auf GitHub verwenden noch den früheren Namen des Produkts. Diese Seite beschreibt sie mit dem
> aktuellen Namen, Exponential.

## Die Stufen

### Monatlich

| Stufe | Was sie laut Eintrag enthält (zusammengefasst) |
|---|---|
| $2 im Monat | Ein Sponsoren-Abzeichen in Ihrem GitHub-Profil |
| $25 im Monat | Ein Sponsoren-Abzeichen in Ihrem Profil |
| $30 im Monat | Zugang zum Support-Chat auf Telegram; Ihre Ideen für Funktionen werden in das Produkt-Backlog von 7x aufgenommen, „um mit höherer Priorität und Terminierung für die Entwicklung in Betracht gezogen zu werden“; Zugang zu Chat, Videos, Screencasts und Tutorials |
| $99 im Monat | Sponsern Sie das nächste Release: Informationen und Marketingmaterial Ihrer Organisation in der offiziellen Release-Ankündigung und der zugehörigen Dokumentation |
| $100 im Monat | Ihre Fehlerberichte erhalten besondere Aufmerksamkeit und Priorität |
| $125 im Monat | „Best Package Offering“: die Leistungen der Stufen $25, $30 und $100 |
| $250 im Monat | Ihr Logo oder Name im README des Projekts; ein Chatbereich in der Community |
| $750 im Monat | Eine Bounty für die Entwicklung einer Funktion, die auf Ihre Bedürfnisse zugeschnitten ist |
| $1.000 im Monat | 7x tritt dem Chat Ihres Unternehmens bei, für direkte Hilfe und Unterstützung |
| $2.600 im Monat | Ein Premium-Paket für Wartung und Support: priorisierte Wartung, Updates, Sicherheitspatches, Optimierungen, ein eigenes Support-Team |

### Einmalig

| Stufe | Enthält |
|---|---|
| $5 einmalig | Unterstützung in beliebiger Höhe („Lowball support“) |
| $10 einmalig | Eine Erwähnung in den sozialen Medien |
| $200 einmalig | Eine Stunde Pair Programming |
| $350 einmalig | Eine Stunde Beratung oder Mentoring |
| $1.000 einmalig | Ein Fehler oder eine mittelgroße Bounty |
| $5.000 einmalig | Ein großes Auftragsprojekt, nach Kontaktaufnahme |

## Eine Stufe wählen

| Sie sind | Ein passender Einstieg |
|---|---|
| Eine Einzelperson, die Exponential nutzt | $2 bis $25 im Monat |
| Freiberufler oder kleine Agentur | $30 oder $125 im Monat (Backlog, Chat, Priorität für Fehler) |
| Ein Unternehmen, das auf Exponential angewiesen ist | $250 bis $1.000 im Monat oder $2.600 für ein Wartungspaket |
| Jemand mit einem bestimmten Bedarf | Eine einmalige Stufe: Pair Programming, Beratung oder eine Bounty |

## Was die Stufen versprechen und was nicht

Stufen für Backlog und Fehler erhöhen die Priorität; der Eintrag sagt, dass Funktionen mit höherer Priorität „in
Betracht gezogen“ werden. Eine garantierte Lieferung braucht eine schriftliche Vereinbarung mit 7x
([Funktionswünsche und gesponserte Funktionen](../../../eng-us/help/partners/feature-requests-and-sponsored-features.md)).
„GitHub ist nicht dafür verantwortlich, wie sich Entwickler darstellen, und GitHub befürwortet keine gesponserten
Open-Source-Projekte“ (GitHub Docs); die Stufen sind ein eigenes Angebot von 7x.

# Als Unternehmen sponsern

Diese Seite ist für Organisationen, die Exponential finanzieren möchten. Unternehmen, die auf Exponential angewiesen
sind, haben das größte Gewicht: Einige wenige monatliche Sponsorings von Organisationen bezahlen eine stetige Wartung.

## Warum Unternehmen sponsern

GitHub nennt Gründe, aus denen Organisationen sponsern, darunter die „Erhaltung bestimmter Bibliotheken, von denen die
Arbeit Ihrer Organisation abhängt“, „Investitionen in das Ökosystem, auf das Sie sich verlassen“ und den „Aufbau von
Markenbekanntheit als Organisation, die Open Source schätzt“ (GitHub Docs, „About sponsorships, fees, and taxes“).

Speziell für Exponential gilt: Ihre Sites brauchen Sicherheitskorrekturen und Unterstützung für jede neue PHP-Version
(SECURITY.md, README). Die Menschen zu finanzieren, die sie liefern, ist günstiger als die Pflege eines privaten Forks.

## Wie Sie von einer Organisation aus sponsern

1. Sponsern Sie über das Organisationskonto Ihres Unternehmens bei GitHub, nicht über ein persönliches Konto, damit das
   Sponsoring dem Unternehmen gehört.
2. Wählen Sie die Seite: <https://github.com/sponsors/se7enxweb> (7x) oder <https://github.com/sponsors/exponentialcms>
   (die Foundation) oder beide ([Zwei Organisationen, zwei Sponsorenseiten](zwei-organisationen-zwei-sponsorenseiten.md)).
3. Ziehen Sie die Abrechnung per Rechnung in Betracht: „Unternehmen und Organisationen können sich für die Abrechnung
   per wiederkehrender Rechnung entscheiden“, wodurch der Anteil von 3 % für die Kartenabwicklung an der Gebühr von
   „bis zu 6 %“ für Sponsorings von Organisationen entfällt (GitHub Docs).
4. Inhaber können Sponsorings im Sponsoring-Dashboard der Organisation einsehen und exportieren (GitHub Docs).

## Stufen für geschäftliche Bedürfnisse

| Bedarf | Stufe von 7x (laut Eintrag) | Stufe der Foundation (laut Eintrag) |
|---|---|---|
| Sichtbarkeit | $250 im Monat: Logo oder Name im README | $25 im Monat README; $100 im Monat Website |
| Priorität für Ihre Issues | $100 im Monat Priorität für Fehler; $125 im Monat Paket | $100 im Monat priorisierte Fehlerberichte |
| Eine Funktion | $750 im Monat Bounty für eine Funktion; $1.000 einmalig Bounty | $1.000 einmalig Bounty |
| Hilfe in Ihrem Team | $1.000 im Monat im Chat Ihres Unternehmens; $2.600 im Monat Wartungspaket | $1.000 im Monat in Ihrem Chat; $8.000 im Monat in Ihrem Projekt |
| Schulung | $350 einmalig Beratung | $500 einmalig Workshop |

Einzelheiten: [7x auf GitHub sponsern](7x-sponsern.md), [Die Exponential Foundation sponsern](die-foundation-sponsern.md).

## Interne Freigabe

```text
Request: sponsorship of <7x / the Exponential Foundation> — <amount> per month
Why: our <sites/products> run on Exponential; maintenance (security fixes, PHP support, releases) depends on it.
What we get: <tier benefits>
Billing: GitHub organization account, <card / invoice>; fees as GitHub documents them
Review: yearly, owner <role>
```

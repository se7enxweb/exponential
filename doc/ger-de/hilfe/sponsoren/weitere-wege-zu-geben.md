# Weitere Wege, Geld zu geben

Diese Seite ist für Sponsoren, die GitHub nicht nutzen oder eine andere Zahlungsmethode bevorzugen. GitHub Sponsors
selbst akzeptiert „Debit- oder Kreditkarten und Patreon“, und „seit dem 23. Februar 2023 unterstützt GitHub Sponsors
kein PayPal“ (GitHub Docs, „About sponsorships, fees, and taxes“). Die folgenden Kanäle werden von 7x und der Foundation
selbst veröffentlicht (gelesen am 18. Oktober 2026).

## An 7x

| Kanal | Adresse | Quelle |
|---|---|---|
| GitHub Sponsors | <https://github.com/sponsors/se7enxweb> | README, `.github/FUNDING.yml` |
| Sponsorenseite | <https://sponsor.se7enx.com/> | README |
| PayPal | <https://www.paypal.me/7xweb> | README, `.github/FUNDING.yml` |
| Patreon | `7xweb` (`.github/FUNDING.yml`), <https://www.patreon.com/c/7xweb> | `.github/FUNDING.yml`, sponsor.se7enx.com |
| Venmo | <https://account.venmo.com/u/se7enxweb> | `.github/FUNDING.yml` |
| Cash App | <https://cash.app/$7xweb> | `.github/FUNDING.yml` |
| Kauf von Support-Leistungen | Shop von 7x, verlinkt auf <https://sponsor.se7enx.com/> | sponsor.se7enx.com |

Die Sponsorenseite von 7x: „Bitte unterstützen Sie unsere Open-Source-CMS-Entwicklung mit einem Support-Abonnement oder
einem Kauf im Shop.“

## An die Exponential Foundation

## Ein Wort zur Sicherheit

Verwenden Sie nur die Adressen auf dieser Seite oder auf den eigenen Websites der Organisationen. Wenn Sie über einen
anderen Kanal eine Bitte um Geld im Namen von 7x oder der Foundation erhalten, prüfen Sie diese zuerst bei ihnen
(<https://se7enx.com/contact>, <https://foundation.exponential.earth/>).

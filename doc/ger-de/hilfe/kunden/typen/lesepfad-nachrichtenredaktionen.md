# Lesepfad für Nachrichtenredaktionen

Dies ist die Reihenfolge, in der ein Nachrichten-Desk seine Website kennenlernt. Er setzt voraus, dass die Website
bereits läuft und dass jemand (Ihr Administrator, Hoster oder Partner) die Konten eingerichtet hat. Jeder Schritt nennt,
wer die Seite lesen sollte. Haken Sie die Schritte als Team ab; die meisten dauern weniger als eine Stunde.

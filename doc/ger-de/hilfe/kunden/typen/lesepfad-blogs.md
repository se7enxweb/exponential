# Lesepfad für Blogs

Ein kurzer Pfad: Ein Blog braucht weniger Routinen als eine Nachrichtenredaktion, aber er braucht sie jede Woche. Jeder
Schritt nennt, wer ihn lesen sollte; bei einem Blog mit einer einzigen Person sind das Sie.

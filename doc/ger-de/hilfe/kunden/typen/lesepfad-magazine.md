# Lesepfad für Magazine

Die Reihenfolge, in der ein Magazin-Team seine Website kennenlernt. Jeder Schritt nennt, wer die Seite lesen sollte;
die meisten dauern weniger als eine Stunde. Er setzt voraus, dass die Website läuft und die Konten existieren.

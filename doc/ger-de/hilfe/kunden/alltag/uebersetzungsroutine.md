# Übersetzungsroutine

Diese Seite ist für den Betreiber und die Übersetzungskoordination einer Website in mehr als einer Sprache. Die Klicks
für Redakteure stehen unter [Sprachen](../../sprachen.md); die Planungssicht unter
[Übersetzungs-Workflow](../../unternehmen/mehrsprachig/uebersetzungsablauf.md). Hier finden Sie die wöchentliche
Routine und die Prüfungen, die verhindern, dass Sprachen auseinanderdriften.

## Wer was tut

Aus [Übersetzungs-Workflow](../../unternehmen/mehrsprachig/uebersetzungsablauf.md):

| Rolle | Tut |
|---|---|
| Autor | schreibt den Ausgangstext |
| Übersetzer | übersetzt in eine Sprache; seine Richtlinien lassen sich nach **Sprache** einschränken |
| Sprachverantwortliche | gibt Übersetzungen frei, verantwortet die Terminologie |
| Content-Manager | entscheidet, was wann übersetzt wird |

Agenturen und Freiberufler passen in die Übersetzerrolle: ein Konto, beschränkt auf ihre Sprache, nicht mehr. Die
Freigabe pro Sprache nutzt das Feld *Betroffene Sprachen* des Freigabe-Workflows ([Freigabe und Prüfung](freigabe-und-pruefung.md)).

## Wie eine Übersetzung entsteht

Der Übersetzer öffnet das Element, drückt **Bearbeiten**, wählt die neue Sprache und die Übersetzung, von der er
ausgeht, übersetzt und veröffentlicht oder schickt zur Freigabe ([Inhaltssprachen](../../../anleitungen/inhaltssprachen.md#7-inhalte-im-editor-übersetzen)).
Eine Übersetzung ist Teil desselben Elements, kein zweites Element: Sie teilt sich den Ort und die Versionshistorie
des Elements.

> **Tipp**
> Übersetzen Sie zuerst die Startseite und die Menüordner. Über sie erreichen Besucher alles andere
> ([Übersetzungs-Workflow](../../unternehmen/mehrsprachig/uebersetzungsablauf.md)).

## Übersetzungen folgen nicht von selbst

Wenn sich der Ausgangstext ändert, ändern sich seine Übersetzungen nicht von selbst
([Übersetzungs-Workflow](../../unternehmen/mehrsprachig/uebersetzungsablauf.md)). Jeder Siteaccess zeigt ein Element in
der ersten Sprache seiner Sprachliste, die das Element hat; ein Element in keiner davon ist verborgen, es sei denn, es
ist *immer verfügbar* ([Inhaltssprachen](../../../anleitungen/inhaltssprachen.md)). Eine fehlende Übersetzung kann also
bedeuten, dass Besucher dieser Sprache eine andere Sprache sehen, oder nichts.

Möglichkeiten, den Überblick zu behalten:

- **Setup > Sprachen** zeigt pro Sprache, wie viele Elemente und Klassen eine Übersetzung darin haben und welche
  Siteaccesses sie anzeigen.
- Auf der Versionsseite können Sie die aktuelle Version der Quelle mit der vergleichen, aus der die Übersetzung erstellt
  wurde ([Versionen eines Objekts](../../../anleitungen/inhaltsverlauf.md)).
- Eine gemeinsame Liste (Ihr [Redaktionskalender](redaktionskalender.md)) mit einer Spalte „Sprachen“ für jedes neue Element.

## Eine wöchentliche Routine

| Tag | Aufgabe | Wer |
|---|---|---|
| Montag | Ausgangselemente auflisten, die letzte Woche veröffentlicht oder geändert wurden und übersetzt werden müssen | Content-Manager |
| Montag | jedes einem Übersetzer zuweisen, mit Termin | Content-Manager |
| Während der Woche | übersetzen; zur Freigabe schicken | Übersetzer |
| Donnerstag | freigeben oder mit Kommentaren ablehnen | Sprachverantwortliche |
| Freitag | *Meine Warteliste* der Sprachverantwortlichen prüfen: Über das Wochenende wartet nichts, was erscheinen sollte | Content-Manager |
| Monatlich | unter **Setup > Sprachen** nachsehen, ob eine Sprache zurückfällt | Betreiber |

## Aktionen, die Inhalte löschen

> **Warnung**
> Das Entfernen der **Übersetzung** eines Elements löscht alle seine Felder in dieser Sprache, in jeder Version,
> endgültig ([Inhaltssprachen](../../../anleitungen/inhaltssprachen.md)). Um die Hauptsprache eines Elements zu ändern,
> übersetzen Sie zuerst, machen die neue Sprache zur Hauptsprache und entfernen dann die alte Übersetzung. Das
> Entfernen einer ganzen **Sprache** ist nur möglich, wenn nichts eine Übersetzung darin hat; das löscht also nie Inhalte.

Überlassen Sie das Recht, Übersetzungen zu entfernen, dem Content-Manager.

## Hilfe durch den Schreibassistenten

Exponential Intelligence kann Übersetzungen als **Entwürfe** vorbereiten, die eine Person prüft, und sein
Übersetzungsabgleich kann bestehende Übersetzungen auf Stand bringen, nachdem sich die Quelle geändert hat, wobei nur
die geänderten Passagen angepasst werden
([Unterstützte Übersetzung mit Exponential Intelligence](../../unternehmen/mehrsprachig/unterstuetzte-uebersetzung-mit-exponential-intelligence.md)).
Er veröffentlicht nie von sich aus. Lesen Sie [KI-Entwürfe verantwortungsvoll nutzen](../wachstum/ki-entwuerfe-verantwortungsvoll-nutzen.md),
bevor Sie ihn für Übersetzer einschalten.

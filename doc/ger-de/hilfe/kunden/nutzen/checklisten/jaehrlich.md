# Jährliche Checkliste

Diese Seite ist die Checkliste des Betreibers für das Jahr, verteilt über einige Wochen, bevor das Budget für das
nächste Jahr festgelegt wird. Zwei Sitzungen tragen das meiste davon: die [jährliche Überprüfung des Nutzens](../jaehrliche-ueberpruefung-des-nutzens.md)
(was die Website bringt und kostet) und die betriebliche [Checkliste für die Jahresüberprüfung](../../../../../eng-us/help/businesses/templates/annual-review-checklist.md)
(Updates, Sicherheit, Datenschutz, Wiederherstellung). Die folgende Liste stellt sicher, dass nichts zwischen beide fällt.

## Die Checkliste

```text
YEARLY CHECKLIST - year: ________     Owner: ________

REVIEWS
[ ] Operational annual review held on ________
[ ] Annual value review held on ________; decisions sent out

SOFTWARE
[ ] Site on the newest 6.0.x release (the maintained line)
[ ] PHP version still supported; upgrade window planned if not
[ ] Extensions: current, and unused ones removed
[ ] Custom work kept in extensions, so updates stay small (upgrade check clean)

CONTRACTS AND PROVIDERS
[ ] Host: service delivered as agreed; price and terms still right
[ ] Partner: service delivered as agreed; price and terms still right
[ ] Payment provider, mail, AI provider and other services: terms and fees compared
[ ] Exit terms known: how we would move to another host or partner

PEOPLE AND ACCESS
[ ] Access review signed; roles match the organization
[ ] Two-step sign-in in place as decided
[ ] New staff onboarded with the help pages; leavers' accounts gone

DATA PROTECTION (with your adviser, not legal advice)
[ ] Data inventory still complete (new forms, classes, extensions)
[ ] Retention periods still right; settings and backups match
[ ] Privacy notice and mail footer current
[ ] Request routine tested at least once

QUALITY
[ ] Accessibility checked on main pages and forms
[ ] Content audit of every section done during the year

STORE (if you sell)
[ ] VAT checklist done for the year end
[ ] Payment provider contract and card security obligations reviewed
[ ] Country ranking and shipping terms still match where orders come from

NEXT YEAR
[ ] Budget approved, including updates and a reserve
[ ] Campaign and peak dates in the calendar
[ ] Owners named for every action
```

## Ein Kalender, der funktioniert

| Monat (an Ihr Jahr anpassen) | Punkt |
|---|---|
| Zwei Monate vor dem Budget | Betriebliche Jahresüberprüfung |
| Einen Monat vor dem Budget | Jährliche Überprüfung des Nutzens, mit dem ROI-Arbeitsblatt und dem Kostenregister |
| Mit dem Budget | Verträge verlängert oder neu ausgeschrieben |
| Jeder ruhige Monat | Zugriffsüberprüfung, Datenschutzüberprüfung |

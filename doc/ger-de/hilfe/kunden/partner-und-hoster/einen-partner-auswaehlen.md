# Einen Partner auswählen

Sie brauchen vielleicht einen Partner, weil die Website wächst, weil der bisherige geht oder weil Sie eine zweite
Meinung möchten. Diese Seite ist die kurze Fassung für Betreiber einer bereits bestehenden Website. Der vollständige
Auswahlprozess für Unternehmen steht unter [Einen Partner auswählen](../../unternehmen/auswahl/einen-partner-auswaehlen.md),
die Gesprächsfragen unter [Fragen an einen Partner](../../unternehmen/auswahl/fragen-an-einen-partner.md).

## Was eine bestehende Website von einem Partner braucht

Ein neuer Partner muss mit dem arbeiten können, was schon da ist:

| Bedarf | Verlangen Sie als Nachweis |
|---|---|
| Erfahrung mit Exponential 6 | Websites, die er auf der aktuellen Linie 6.0 betreibt, und die Version jeder davon |
| Fähigkeit, den bestehenden Code zu lesen | Eine kurze Prüfung der individuellen Teile Ihrer Website vor einem Angebot |
| Updates auf der gepflegten Linie | Seine Routine für Releases und Sicherheitskorrekturen ([Release-Linie und Support](../gesund-halten/release-linie-und-support.md)) |
| Sauberer Umgang mit eigenem Code | Code in einer Versionsverwaltung; keine Änderungen an den Dateien von Exponential selbst ohne Plan |
| Support-Bedingungen | Zeiten, Kanäle, erste Reaktion pro Schweregrad, schriftlich |
| Ein fairer Ausstieg | Was er übergibt, wenn der Vertrag endet ([Checkliste für die Übergabe](checkliste-uebergabe.md)) |

## Wo Sie suchen

Aus [Einen Partner auswählen](../../unternehmen/auswahl/einen-partner-auswaehlen.md):

- die Seiten des Partnerprogramms auf <https://exponential.earth> und sein Verzeichnis auf share.exponential.earth
  ([Partnerverzeichnisse](../../partner/partnerverzeichnisse.md));
- die Foren und Chats der Community: Fragen Sie, wer ähnliche Arbeit gemacht hat;
- direkt 7x ([Mit 7x und dem Projekt zusammenarbeiten](mit-7x-und-dem-projekt-zusammenarbeiten.md));
- Agenturen, die Sie bereits kennen: Fragen Sie, ob sie Exponential-Websites betrieben haben, und prüfen Sie die Antwort.

Das Programm nennt Profile wie Implementierungs-, Kreativ-, Hosting- und Vertriebspartner, mit Stufen von Student bis
Platinum. „Eine Stufe sagt Ihnen etwas über das Engagement eines Unternehmens für das Programm; sie ist keine
Qualitätsgarantie für Ihr Projekt“ (dieselbe Seite).

## Ein kleiner bezahlter Test

Bei einer bestehenden Website ist ein guter erster Schritt eine kleine, bezahlte, klar umrissene Aufgabe: eine Prüfung
der Website mit einem schriftlichen Bericht oder eine einzelne Änderungsanfrage ([Änderungsanfragen](aenderungsanfragen.md)).
Sie zeigt, wie der Partner kommuniziert, schätzt und liefert, bevor Sie sich stärker binden.

## Warnzeichen

Aus [Einen Partner auswählen](../../unternehmen/auswahl/einen-partner-auswaehlen.md):

- Behauptungen über Exponential, die Sie in dessen Dokumentation nicht finden, oder erfundene Kunden und Zahlen.
- Die Weigerung, Ihnen als Eigentümer den Code, die Datenbank oder den Administratorzugang zu übergeben.
- Individuelle Änderungen in Kernel-Dateien ohne Plan für Updates.
- Keine schriftliche Antwort zu Sicherheitsupdates, Backups oder Reaktionszeiten.
- Ein Vorschlag, der Sie auf einer Version hält, die älter ist als die gepflegte Linie 6.0.
- Druck, zu unterschreiben, bevor Sie die Bedingungen zu Ausstieg und Daten gesehen haben.

## Einen neuen Partner einbinden

- [ ] Geben Sie ihm zuerst Lesezugriff, keine vollen Administratorrechte, bis der Vertrag unterschrieben ist.
- [ ] Geben Sie ihm ein namentliches persönliches Konto mit zweistufiger Anmeldung
      ([Administratorkonten und Zugriff](../gesund-halten/administratorkonten-und-zugriff.md)).
- [ ] Teilen Sie das Übergabedokument, falls Sie eines haben ([Eine Website übernehmen](eine-website-uebernehmen.md)).
- [ ] Aktualisieren Sie [Wer was macht](wer-was-macht.md) und Ihre [Eskalationskontakte](vorlage-eskalationskontakte.md).
- [ ] Sagen Sie dem Hoster, wer der neue Partner ist und was er tun darf.

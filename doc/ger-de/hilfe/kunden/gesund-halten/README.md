# Ihre Website gesund halten

Dieser Ordner ist für die Personen, die bereits eine Website mit Exponential betreiben: den Eigentümer, die Leitung,
die Person, die mit dem Hoster oder dem Partner spricht. Er lehrt nicht die Befehle; diese Seiten gibt es, und jede
Seite hier verweist darauf. Er sagt Ihnen, was geschehen muss, damit die Website gesund bleibt, wie oft, wer in Ihrem
Team dafür zuständig sein sollte, was zu prüfen ist und was Sie die Leute fragen sollten, die Sie bezahlen.

Eine gesunde Website beruht auf fünf Gewohnheiten, die auch die Seiten zur Zuverlässigkeit für Unternehmen nennen:
aktuell bleiben, sichern und die Wiederherstellung testen, Zugänge knapp halten, die Website beobachten und wissen, was
an einem schlechten Tag zu tun ist ([Zuverlässigkeit für Unternehmen](../../unternehmen/zuverlaessigkeit/README.md)).

## Wer wofür zuständig ist

Benennen Sie für jede Zeile eine Person. In einem kleinen Team übernimmt eine Person mehrere; das ist in Ordnung,
solange alle wissen, wer.

| Aufgabe | Typischerweise zuständig | Wie oft |
|---|---|---|
| Entscheiden, wann ein Upgrade erfolgt | Eigentümer oder Leitung | Mindestens so oft, wie neue Releases erscheinen |
| Upgrades durchführen | Hoster, Partner oder Ihr Entwickler | Pro Release |
| Backups und Wiederherstellungstests | Hoster oder Betreiber | Backups nach Plan; ein Wiederherstellungstest pro Quartal |
| Konten und Rollen | Administrator der Website | Bei personellen Änderungen; Überprüfung jedes Quartal |
| Überwachung und Alarme | Hoster oder Betreiber | Immer an; eine Person liest die Meldungen wöchentlich |
| Probleme melden | Jede Person im Team, über einen einzigen Kontakt | Wenn es passiert |

## Eine empfohlene Reihenfolge

1. Lesen Sie [Release-Linie und Support](release-linie-und-support.md) und finden Sie heraus, welche Version Ihre Website verwendet.
2. Lesen Sie [Backups](backups.md) und fragen Sie Ihren Hoster nach dem Datum des letzten [Wiederherstellungstests](wiederherstellungstest.md).
3. Gehen Sie die [Sicherheits-Checkliste für Betreiber](sicherheits-checkliste-fuer-betreiber.md) einmal durch.
4. Füllen Sie die [Eskalationskontakte](../partner-und-hoster/vorlage-eskalationskontakte.md) aus, damit ein schlechter
   Tag mit einer Liste beginnt statt mit einer Suche.
5. Bewahren Sie [Wenn die Website nicht erreichbar ist](wenn-die-website-nicht-erreichbar-ist.md) dort auf, wo Sie es ohne die Website finden.

> **Tipp**
> Hosting-Anbieter und Partner haben eigene Bereiche in dieser Hilfe. Wenn Sie sehen möchten, was ein gut geführter
> Hoster jeden Monat tut, lesen Sie [Monatlicher Betrieb](../../hosting/checklisten/checkliste-fuer-den-monatlichen-betrieb.md).

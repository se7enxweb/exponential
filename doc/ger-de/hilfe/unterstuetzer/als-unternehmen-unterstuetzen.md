# Exponential als Unternehmen unterstützen

Diese Seite ist für Organisationen, deren Websites oder Produkte auf Exponential laufen. Ihre Organisation ist auf die
Wartung des Projekts angewiesen; es zu unterstützen ist ebenso Risikomanagement wie Großzügigkeit.

## Eine einfache Unterstützungsrichtlinie

```text
<Organization> supports the open source software it depends on.
For Exponential we:
- sponsor <7x / the Exponential Foundation / both> with <amount> per month;
- allow staff <n> hours per month to report bugs, fix issues and improve documentation;
- contribute generic improvements made in our projects back under the projects' licenses;
- never publish our confidential data, content or business logic.
Owner: <role>   Reviewed: yearly
```

## Arbeitszeit

- Fehlerberichte und Korrekturen Ihrer Entwickler ([Code beitragen](code-beitragen.md)).
- Dokumentation dessen, was Ihr Team gelernt hat ([Dokumentation beitragen](dokumentation-beitragen.md)).
- Übersetzungen durch Ihre mehrsprachigen Mitarbeitenden ([Übersetzungen beitragen](uebersetzungen-beitragen.md)).

## Sponsoring als Organisation

Die Dokumentation von GitHub (<https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes>,
gelesen am 18. Oktober 2026) sagt:

- Sie können „im Namen Ihrer Organisation“ sponsern, zum Beispiel zur „Erhaltung bestimmter Bibliotheken, von denen die
  Arbeit Ihrer Organisation abhängt“.
- „GitHub Sponsors erhebt eine Gebühr von bis zu 6 % für Sponsorings von Organisationskonten“; Sponsorings von
  persönlichen Konten sind von GitHub gebührenfrei.
- „Unternehmen und Organisationen können sich für die Abrechnung per wiederkehrender Rechnung entscheiden“, wodurch die
  Kartengebühr von 3 % entfällt.

Die beiden Sponsorenseiten: <https://github.com/sponsors/se7enxweb> (7x) und <https://github.com/sponsors/exponentialcms>
(die Exponential Foundation). Mehr dazu unter [Als Unternehmen sponsern](../sponsoren/als-unternehmen-sponsern.md).

## Partnerschaft

Wenn Sie anderen Leistungen auf Basis von Exponential anbieten, passt das Partnerprogramm möglicherweise besser als ein
Sponsoring ([Partner: Hier beginnen](../partner/partner-hier-beginnen.md)).

## Intern dafür argumentieren

| Argument | Kernaussage |
|---|---|
| Risiko | Ihre Sites hängen von Sicherheitskorrekturen und PHP-Unterstützung ab; die Finanzierung sorgt dafür, dass sie weiter kommen |
| Kosten | Ein Sponsoring kostet weniger als die Pflege eines privaten Forks |
| Einfluss | Beiträge und einige Sponsorenstufen erhöhen die Priorität dessen, was Sie brauchen |
| Ansehen | Sichtbare Unterstützung von Open Source hilft bei der Personalgewinnung und beim Vertrauen |

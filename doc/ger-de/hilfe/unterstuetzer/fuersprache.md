# Fürsprache: anderen von Exponential erzählen

Diese Seite ist für Unterstützer, die möchten, dass mehr Menschen Exponential kennen. Jeder neue Anwender ist ein
möglicher Mitwirkender, Sponsor oder Partner; Fürsprache lässt sie alle wachsen.

## Was Sie mit Quellen belegt sagen können

| Aussage | Quelle |
|---|---|
| Exponential ist „ein professionelles PHP-Anwendungs-Framework mit fortgeschrittener CMS-Funktionalität (Content-Management-System)“ | README |
| Es ist freie Software unter der GNU GPL, Version 2 oder höher, und „die Nutzung von Exponential unter den Bedingungen der GNU GPL ist kostenlos“ | LICENSE, README |
| Es wird von 7x geführt und von der Exponential Foundation betrieben, einer 2026 gegründeten gemeinnützigen Organisation | [Wer ist 7x?](../wer-ist-7x.md), [Wer ist die Exponential Foundation?](../wer-ist-die-exponential-foundation.md) |
| Es unterstützt SQLite, PostgreSQL, MongoDB, MariaDB, Oracle und MySQL | [Datenbankunterstützung](../datenbankunterstuetzung.md) |
| Seine Dokumentation ist freie Dokumentation (GFDL 1.3 oder höher) | [Freie Dokumentation](../freie-dokumentation.md) |

Der Bereich Vertrieb enthält weitere Fakten, die Sie bedenkenlos wiederholen können:
[Positionierung und Nutzenversprechen](../geschaeft/positionierung-und-nutzenversprechen.md).

## Wo Sie es sagen

- In Ihrem Blog, in Ihren Vorträgen, in Ihren sozialen Medien.
- Auf lokalen Meetups und Konferenzen zu PHP und zum Web.
- In Antworten in allgemeinen Entwicklerforen, wenn jemand nach einem selbst gehosteten, mehrsprachigen CMS fragt.
- Mit einem Hinweis „Powered by Exponential“ auf Sites, die Sie betreiben, verlinkt auf <https://exponential.earth/>.

## Die richtige Benennung

Das Produkt heißt **Exponential**. Sein Code war einst eZ Publish, ein Produkt, das sein Hersteller nach fast 18
Jahren eingestellt hat; verwenden Sie diesen Namen nur, wenn Sie die Geschichte erzählen. Das Unternehmen heißt **7x**,
die gemeinnützige Organisation **die Exponential Foundation**
([Regeln für Marke und Benennung](../geschaeft/marken-und-namensregeln.md)).

## Was Sie nicht behaupten sollten

- Keine erfundenen Zahlen (Anwender, Marktanteil, Geschwindigkeit) ohne Quelle.
- Keine Versprechen künftiger Funktionen.
- Sprechen Sie nicht im Namen von 7x oder der Foundation.
- Vergleichen Sie anhand von Fakten, niemals, indem Sie andere Projekte schlechtmachen.

## Machen Sie es leicht zu helfen

Beenden Sie jeden Vortrag und jeden Artikel mit dem Hinweis, wie man das Projekt unterstützen kann: mitwirken,
übersetzen, Fehler melden, sponsern ([Unterstützer: Hier beginnen](unterstuetzer-hier-beginnen.md)).

# Checklisten für App-Entwickler

Dieser Ordner richtet sich an App-Entwickler und an die Personen, die ein Release abzeichnen. Jede Checkliste verweist
auf die Seite, die ihre Punkte erklärt. Drucken Sie sie aus, übernehmen Sie sie in Ihren Tracker, passen Sie sie an
Ihr Projekt an.

## Inhalt

1. [Die Checklisten](#die-checklisten)
2. [Wer was abzeichnet](#wer-was-abzeichnet)

## Die Checklisten

| Checkliste | Verwenden Sie sie | Lesen |
|---|---|---|
| Sicherheit | vor dem ersten Release und nach jeder Änderung an Zugangsdaten, Rollen oder Endpunkten | [Sicherheitscheckliste](sicherheitscheckliste.md) |
| Start | in der Woche, bevor eine App gegen eine Produktionsinstallation live geht | [Checkliste für den Start](checkliste-fuer-den-start.md) |
| Bereitschaft für die App-Store-Prüfung | vor dem Einreichen in einem App Store | [Bereit für die App-Store-Prüfung](bereit-fuer-die-app-store-pruefung.md) |

## Wer was abzeichnet

| Punkt | Abgezeichnet von |
|---|---|
| Rollen, Integrationsbenutzer, OAuth-Clients, Richtlinien für Schlüssel | dem Administrator der Installation |
| Servereinstellungen (`rest.ini`, Caches, CORS im Webserver) | dem Hosting-Unternehmen oder Serverteam |
| Inhaltsmodell, Einstiegsordner, Bildaliase | dem Website-Team |
| Verhalten der App, Geheimnisse auf Geräten, Einreichung im Store | dem App-Team |

Die Sicht des Unternehmens auf denselben Start ist die
[Mobil-Checkliste](../../unternehmen/mobil-und-headless/checkliste-mobil.md).

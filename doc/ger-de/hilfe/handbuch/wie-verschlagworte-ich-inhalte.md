# Wie verschlagworte ich Inhalte?

Tags sind Schlagwörter aus einem gemeinsamen Baum. Inhalte mit demselben Tag werden auf der Website gruppiert, zum
Beispiel in einer Tag-Wolke oder einer Liste verwandter Artikel.

## Wer das tun kann

Redakteure, die das Objekt bearbeiten dürfen. Einen Tag hinzuzufügen, der noch nicht im Baum steht, braucht
`tags/add`.

## Schritte

1. Bearbeiten Sie das Objekt.
2. Suchen Sie das Tag-Feld (sein Name hängt von der Klasse ab, zum Beispiel **Tags**).
3. Tippen Sie unter **Find a tag to add** einen Teil eines Tags ein und klicken Sie dann auf einen Treffer. Oder klicken
   Sie auf einen der **Suggested tags** oder auf **Choose a tag**, um einen aus dem Baum zu wählen.
   Der Tag erscheint unter **Selected tags**.
4. Um einen Tag zu entfernen, klicken Sie daneben auf **Remove tag**.
5. Klicken Sie auf **Zur Veröffentlichung schicken**.

## Was schiefgehen kann

- **Der Tag, den Sie brauchen, existiert nicht und kann nicht hinzugefügt werden.** Das Feld erlaubt nur Tags aus dem
  Baum, oder Ihrer Rolle fehlt `tags/add`. Fragen Sie die Person, die den Tag-Baum pflegt.
- **Zwei Tags bedeuten dasselbe.** Verwenden Sie den Haupt-Tag. Die Person, die den Baum pflegt, kann den anderen zum
  Synonym machen oder beide zusammenführen: siehe [Wie halte ich den Tag-Baum ordentlich?](wie-halte-ich-den-tag-baum-ordentlich.md)

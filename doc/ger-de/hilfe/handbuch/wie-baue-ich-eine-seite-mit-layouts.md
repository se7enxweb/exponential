# Wie baue ich eine Seite mit Layouts?

Ein Layout ordnet Blöcke (Texte, Listen, Bilder, Teaser) in Zonen an. Sie bauen es im Layout-Editor und ordnen es dann
den Seiten zu, die es gestalten soll.

## Wer das tun kann

Benutzer, deren Rolle die Richtlinien für Layouts hat (in einer neuen Installation die Erweiterung explayouts): Layouts
bearbeiten und, für die Zuordnung, die Zuordnungen bearbeiten.

## Schritte

1. Klicken Sie im oberen Menü auf **Layouts** und dann auf **Layout-Editor öffnen**.
2. Legen Sie ein neues Layout an und wählen Sie seinen Layouttyp: Der Typ bestimmt die Zonen (zum Beispiel oben, Haupt-
   und Seitenbereich).
3. Ziehen Sie einen Blocktyp aus der Blockliste in eine Zone.
4. Wählen Sie den Block aus und füllen Sie ihn: seine Inhalte (wählen Sie Elemente mit dem Content-Browser), seine
   Texte und unter **Design** seinen Ansichtstyp und sein Aussehen.
5. Wiederholen Sie das für jeden Block. Prüfen Sie die Seite mit der Vorschau.
6. Klicken Sie auf **Veröffentlichen**, um das Layout zu veröffentlichen.
7. Ordnen Sie es zu: Fügen Sie eine Zuordnung hinzu, die die Seite (oder die Klasse oder den Teil des Baums) nennt, die
   das Layout gestaltet.

## Was schiefgehen kann

- **Die Seite sieht noch genauso aus.** Das Layout hat keine Zuordnung für diese Seite, oder eine andere Zuordnung hat
  Vorrang.
- **Ein Block ist auf der Website leer.** Sein Inhalt ist verborgen, im Papierkorb oder für Besucher nicht lesbar.
- **Sie haben ein gemeinsam genutztes Layout geändert, und jede Seite hat sich geändert.** Kopf- und Fußbereich werden
  gemeinsam genutzt. Verwerfen Sie den Entwurf, wenn das nicht beabsichtigt war.

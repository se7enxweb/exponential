# Wie bette ich ein anderes Objekt in einen Text ein?

Einbetten zeigt ein anderes Objekt innerhalb eines Textes: eine Datei zum Herunterladen, ein Video, einen Kasten mit dem
Teaser eines Artikels. Wenn sich dieses Objekt ändert, zeigt jeder Text, der es einbettet, die Änderung.

## Wer das tun kann

Redakteure, die das Objekt bearbeiten und das eingebettete Objekt lesen dürfen.

## Schritte

1. Bearbeiten Sie das Objekt und setzen Sie den Cursor an die Stelle, an die das eingebettete Objekt kommt.
2. Klicken Sie auf **Insert/edit object**. Für eine Datei zum Herunterladen klicken Sie auf **Datei
   einfügen/bearbeiten**.
3. Laden Sie ein neues Objekt hoch, oder finden Sie ein vorhandenes über die Suche, das Durchsuchen oder in Ihren
   Lesezeichen, und wählen Sie es aus.
4. Wählen Sie, wie es angezeigt wird (zum Beispiel als Link oder als Kasten), und die Ausrichtung.
5. Klicken Sie auf **Einfügen**.
6. Klicken Sie auf **Zur Veröffentlichung schicken**.

## Was schiefgehen kann

- **Das eingebettete Objekt verschwindet auf der Website.** Es wurde verborgen, in den Papierkorb verschoben oder liegt
  in einer Sektion, die Besucher nicht lesen dürfen. **Setup** > **Ungültige Relationen** listet solche Fälle auf.
- **Sie können das eingebettete Objekt nicht entfernen.** Exponential warnt, dass andere Inhalte es einbetten. Entfernen
  Sie die Einbettung zuerst aus diesen Texten.

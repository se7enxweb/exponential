# Wie übersetze ich ein Objekt in eine andere Sprache?

Eine Übersetzung ist eine weitere Sprachversion desselben Objekts. Ihre Felder können aus einer vorhandenen Sprache
kopiert und dann übersetzt werden.

## Wer das tun kann

Benutzer, deren Rolle `content/edit` oder `content/translate` sowie `content/create` für die Sprache hat. Eine Rolle
kann diese nach **Sprache** einschränken, sodass ein Übersetzer vielleicht nur eine Sprache bearbeiten darf. Die Sprache
muss auf der Website existieren; siehe [Wie füge ich eine Inhaltssprache hinzu?](wie-fuege-ich-eine-inhaltssprache-hinzu.md)

## Schritte

1. Öffnen Sie das Objekt in der **Inhaltsstruktur** und klicken Sie auf **Bearbeiten**.
   Wenn das Objekt in mehr als einer Sprache bearbeitet werden kann, öffnet sich die Seite **Edit** *Name* mit den
   Sprachen.
2. Wählen Sie unter **Neue Übersetzung** die Sprache, die hinzukommen soll.
3. Wählen Sie unter **Übersetzung basiert auf** die Sprache, aus der die Felder kopiert werden, oder **Keine**, um leer
   zu beginnen.
4. Klicken Sie auf **Bearbeiten**.
   Das Bearbeitungsformular öffnet sich in der neuen Sprache. Die Felder der Ausgangssprache werden neben den Feldern
   angezeigt, wo das Design eine Seitenspalte hat.
5. Übersetzen Sie jedes Feld, auch den Namen oder Titel, aus dem die URL gebildet wird.
6. Klicken Sie auf **Zur Veröffentlichung schicken**.
7. Prüfen Sie das Fenster **Übersetzungen** des Objekts: Die neue Sprache ist aufgeführt.

## Was schiefgehen kann

- **„You do not have permission to create a translation in another language.“** Ihre Rolle ist auf andere Sprachen
  beschränkt. Fragen Sie einen Administrator.
- **Die neue Sprache wird nicht angeboten.** Sie ist noch keine Inhaltssprache der Website, oder das Objekt hat sie
  bereits (dann wählen Sie sie unter **Bestehende Übersetzungen**).
- **Besucher sehen die Übersetzung nicht.** Kein Siteaccess zeigt diese Sprache. Ein Administrator fügt sie der
  Sprachliste des Siteaccess hinzu.

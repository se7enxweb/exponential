# Wie füge ich im Online-Editor eine Tabelle ein?

Verwenden Sie eine Tabelle für Daten mit Zeilen und Spalten, etwa Preise oder Öffnungszeiten, nicht um Text auf der
Seite anzuordnen.

## Wer das tun kann

Redakteure, die das Objekt bearbeiten dürfen.

## Schritte

1. Bearbeiten Sie das Objekt und setzen Sie den Cursor an die Stelle, an die die Tabelle kommt.
2. Klicken Sie auf die Tabellen-Schaltfläche (**Inserts a new table**).
3. Geben Sie die Anzahl der Spalten und Zeilen ein und wählen Sie, ob die erste Zeile eine Kopfzeile ist.
4. Klicken Sie auf **Einfügen**.
5. Tippen Sie in die Zellen. Um die Tabelle zu ändern, setzen Sie den Cursor in eine Zelle und verwenden Sie **Neue
   Zeile davor einfügen**, **Neue Zeile danach einfügen**, **Neue Spalte davor einfügen**, **Neue Spalte danach
   einfügen** oder die Schaltflächen, die eine Zeile oder Spalte löschen.
6. Klicken Sie auf **Zur Veröffentlichung schicken**.

## Was schiefgehen kann

- **Die Tabelle ist auf einem Telefon zu breit.** Beschränken Sie Tabellen auf wenige Spalten. Teilen Sie eine breite
  Tabelle in zwei.
- **Ein Screenreader kann nicht erkennen, was eine Spalte bedeutet.** Geben Sie der Tabelle eine Kopfzeile.

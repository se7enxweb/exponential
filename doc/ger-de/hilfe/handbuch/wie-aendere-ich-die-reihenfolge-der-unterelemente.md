# Wie ändere ich die Reihenfolge der Unterelemente?

Das übergeordnete Element bestimmt die Reihenfolge seiner Unterelemente, zum Beispiel nach Name, nach Datum oder nach
einer Zahl, die Sie jedem geben (Priorität). Dieselbe Reihenfolge gilt auf der Website und in Menüs.

## Wer das tun kann

Benutzer mit `content/edit` für das übergeordnete Element.

## Schritte

1. Öffnen Sie das übergeordnete Element (zum Beispiel einen Ordner) in der **Inhaltsstruktur**.
2. Öffnen Sie seinen Tab **Sortierung**.
3. Wählen Sie unter **Sortieren nach** das Feld, zum Beispiel **Veröffentlicht**, **Name** oder **Priorität**. Wählen
   Sie unter **Sortierreihenfolge** **Aufsteigend** oder **Absteigend**.
4. Klicken Sie auf **Setzen**.
5. Wenn Sie **Priorität** gewählt haben: Geben Sie in der Liste **Unterelemente** in der Spalte **Priorität** für jedes
   Element eine Zahl ein (niedrigere zuerst) und klicken Sie dann auf **Prioritäten aktualisieren**.

## Was schiefgehen kann

- **Die Website zeigt noch die alte Reihenfolge.** Die Seite ist im Cache. Sie wird meist innerhalb weniger Minuten
  erneuert; bitten Sie sonst einen Administrator, den Inhaltscache zu leeren.
- **Die Prioritätsfelder fehlen.** **Sortieren nach** steht nicht auf **Priorität**. Ändern Sie das zuerst.
- **Setzen ist ausgegraut.** Sie dürfen das übergeordnete Element nicht bearbeiten.

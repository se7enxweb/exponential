# Wie archiviere ich abgeschlossene Bestellungen?

Archivieren Sie die Bestellungen, mit denen Sie fertig sind, damit die Bestellliste nur noch laufende Arbeit zeigt.
Es wird nichts gelöscht.

## Wer das tun kann

Benutzer, deren Rolle `shop/administrate` hat.

## Schritte

1. Klicken Sie auf **Shop** und dann auf **Bestellungen**.
2. Markieren Sie die abgeschlossenen Bestellungen, zum Beispiel gelieferte Bestellungen, die älter sind als Ihre
   Rückgabefrist.
3. Klicken Sie auf **Ausgewähltes archivieren**.
   Die Bestellungen verschwinden aus der Liste.
4. Um sie zu sehen, klicken Sie im linken Menü auf **Archiv**. Die Seite heißt **Archived orders**.
5. Um eine Bestellung zurückzuholen, markieren Sie sie dort und klicken Sie auf **Archivieren rückgängig**.

## Was schiefgehen kann

- **Eine Bestellung fehlt in der Bestellliste.** Sie wurde vielleicht archiviert. Sehen Sie unter **Shop** > **Archiv**
  nach.
- **Sie müssen eine Bestellung aus Datenschutzgründen löschen.** Archivieren löscht nichts. Siehe
  [Datenexport und Löschung](../kunden/handel/datenexport-und-loeschung.md).

# Wie füge ich im Online-Editor einen Link ein?

Ein Link kann auf eine andere Website führen oder auf ein Objekt dieser Website. Ein Link auf ein Objekt folgt ihm,
wenn es verschoben oder umbenannt wird.

## Wer das tun kann

Redakteure, die das Objekt bearbeiten dürfen.

## Schritte

1. Bearbeiten Sie das Objekt und markieren Sie den Text, der zum Link wird.
2. Klicken Sie in der Werkzeugleiste auf **Link einfügen/bearbeiten**.
3. Für eine andere Website geben Sie die vollständige Adresse ein, beginnend mit `https://`. Für eine Seite dieser
   Website klicken Sie auf **Durchsuchen** und wählen das Objekt.
4. Wählen Sie bei Bedarf, dass der Link in einem neuen Fenster geöffnet wird, und geben Sie ihm einen Titel.
5. Klicken Sie auf **Einfügen**.
6. Um einen Link zu entfernen, setzen Sie den Cursor hinein und klicken Sie auf **Link entfernen**.
7. Klicken Sie auf **Zur Veröffentlichung schicken**.

## Was schiefgehen kann

- **Der Link auf eine andere Website funktioniert später nicht mehr.** Die andere Website hat sich geändert.
  **Setup** > **URL Management** listet Links auf, die fehlschlagen: siehe
  [Wie finde und repariere ich defekte Links?](wie-finde-und-repariere-ich-defekte-links.md)
- **Sie haben die Adresse einer Seite dieser Website eingetippt.** Das funktioniert, bricht aber, wenn die Seite
  verschoben wird. Verwenden Sie stattdessen **Durchsuchen**.

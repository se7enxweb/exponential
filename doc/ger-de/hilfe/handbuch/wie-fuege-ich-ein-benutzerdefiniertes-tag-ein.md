# Wie füge ich ein benutzerdefiniertes Tag wie einen Infokasten oder ein Zitat ein?

Benutzerdefinierte Tags sind Bausteine, die eine Website dem Rich Text über Überschriften, Listen und Tabellen hinaus
hinzufügt. Eine neue Installation bietet **factbox** und **quote** (eigene Blöcke) sowie **strike**, **sub** und
**sup** (innerhalb einer Zeile); Ihre Website hat vielleicht mehr und hat womöglich einige ausgeblendet. Das Design der
Website bestimmt, wie jedes davon aussieht. Die Schaltflächennamen unten sind die des Editors TinyMCE 8.

## Wer das tun kann

Redakteure, die das Element bearbeiten dürfen.

## Schritte

1. Bearbeiten Sie das Element. Markieren Sie in einem Rich-Text-Feld den Text, den das Tag umschließen soll, oder
   setzen Sie den Cursor an die Stelle, an die es gehört.
2. Klicken Sie in der Werkzeugleiste auf **Custom tag**.
   Der Dialog **Insert custom tag** öffnet sich.
3. Wählen Sie das Tag unter **Tag**.
   Die Felder dieses Tags erscheinen (zum Beispiel ein Titel oder eine Ausrichtung) und ein Beispielbild, wo die
   Website eines hat.
4. Füllen Sie die Felder aus und klicken Sie auf **OK**.
   Das Tag erscheint im Text.
5. Um es später zu ändern, klicken Sie hinein und wählen Sie **Edit custom tag**; **Remove custom tag** nimmt es
   wieder heraus.
6. Klicken Sie auf **Zur Veröffentlichung schicken** und prüfen Sie das Ergebnis auf der Website mit **Vorschau**.

## Was schiefgehen kann

- **Der Dialog meldet, dass keine benutzerdefinierten Tags eingerichtet sind.** Ihre Website bietet keine an. Fragen
  Sie einen Administrator.
- **Das Tag, das Sie brauchen, ist nicht in der Liste.** Es ist auf dieser Website ausgeblendet oder existiert nicht.
  Benutzerdefinierte Tags richtet ein, wer die Website baut.
- **Das Tag sieht auf der Website schlicht aus.** Das Tag hat im Design der Website noch kein Template. Fragen Sie die
  Person, die sich um das Design kümmert.
- **Ein Tag umschließt mehr oder weniger als gewollt.** Inline-Tags wie **sub** umschließen nur die markierten Wörter;
  Block-Tags wie **factbox** stehen als eigener Block. Entfernen Sie das Tag, markieren Sie neu und fügen Sie es
  erneut ein.

# Wie sende ich Inhalte zur Freigabe?

Sie brauchen keine besondere Schaltfläche. Wo die Website einen Freigabe-Workflow für Ihre Inhalte hat, schickt **Zur
Veröffentlichung schicken** die Version an einen Freigebenden, statt sie sofort zu veröffentlichen.

## Wer das tun kann

Jeder Redakteur, dessen Inhalte von einem Freigabe-Workflow abgedeckt sind. Welche Sektionen, Sprachen und
Benutzergruppen eine Freigabe brauchen, legt ein Administrator fest.

## Schritte

1. Legen Sie die Inhalte wie gewohnt an oder bearbeiten Sie sie.
2. Klicken Sie auf **Zur Veröffentlichung schicken**.
   Wenn die Inhalte eine Freigabe brauchen, wird die Version noch nicht veröffentlicht. Sie steht unter **Dashboard** >
   **Meine Warteliste**.
3. Warten Sie auf den Freigebenden. Wenn Sie Benachrichtigungen zur Zusammenarbeit eingeschaltet haben, bekommen Sie
   eine Mail, sobald er entscheidet.
4. Lesen Sie die Antwort und einen eventuellen Kommentar unter **Dashboard** > **Zusammenarbeit**.
5. Wurde sie abgelehnt, ist die Version wieder ein Entwurf: Ändern Sie sie unter **Meine Entwürfe** und schicken Sie sie
   erneut.

## Was schiefgehen kann

- **Sie wurde sofort veröffentlicht.** Die Inhalte sind von keinem Freigabe-Workflow abgedeckt, oder Sie sind in einer
  Gruppe, die ausgenommen ist. So ist die Website eingerichtet.
- **Tagelang passiert nichts.** Der Freigebende hat sie nicht bearbeitet, oder der Cronjob des Workflows läuft nicht.
  Fragen Sie den Freigebenden, dann einen Administrator.

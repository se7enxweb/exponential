# Was tue ich bei einem „Möglichen Bearbeitungs-Konflikt“?

Wenn Sie auf **Bearbeiten** klicken, prüft Exponential zuerst, ob es Entwürfe des Elements gibt, die nie
veröffentlicht wurden. Gibt es welche, öffnet sich vor dem Bearbeitungsformular die Seite **Möglicher
Bearbeitungs-Konflikt**. Sie zeigt, ob die Entwürfe Ihnen, jemand anderem oder beiden gehören, und listet sie unter
**Derzeitiger Entwurf** mit ihrer Version, ihrem Ersteller und ihren Daten auf.

Zwei Entwürfe in derselben Sprache werden nicht zusammengeführt. Was zuletzt veröffentlicht wird, wird zur aktuellen
Version; zwei Personen, die an derselben Sprache eines Elements arbeiten, überschreiben also gegenseitig ihre Arbeit.

## Wer das tun kann

Jeder, der das Element bearbeiten darf. Nur der Ersteller eines Entwurfs kann ihn fortsetzen.

## Schritte

1. Lesen Sie die Meldung oben auf der Seite und sehen Sie sich die Entwürfe in der Liste an.
   Klicken Sie auf die Versionsnummer oder die Sprache eines Entwurfs, um zu sehen, was er enthält.
2. Wählen Sie einen Weg:
   - **Ihr eigener Entwurf** enthält Arbeit, die Sie behalten möchten: Wählen Sie ihn aus und klicken Sie auf
     **Ausgewählte bearbeiten**. Sie machen dort weiter, wo Sie aufgehört haben.
   - **Die Entwürfe sind alt oder unerwünscht**: Klicken Sie auf **Neuer Entwurf**. Ein frischer Entwurf wird aus der
     veröffentlichten Version kopiert.
   - **Ein Kollege arbeitet gerade an dem Element**: Klicken Sie auf **Abbrechen** und vereinbaren Sie mit ihm, wer
     zuerst dran ist.
3. Entfernen Sie danach Entwürfe, die Sie nicht mehr brauchen: Öffnen Sie im Dashboard **Meine Entwürfe**, haken Sie
   sie an und klicken Sie auf **Ausgewählte entfernen**.

## Was schiefgehen kann

- **Ausgewählte bearbeiten wird nicht angeboten.** Keiner der Entwürfe gehört Ihnen. Sie können sie nur ansehen;
  machen Sie einen neuen Entwurf oder warten Sie.
- **Die Änderungen eines Kollegen sind verschwunden.** Sie haben einen neuen Entwurf veröffentlicht, während er an
  seinem gearbeitet hat, oder umgekehrt. Vergleichen Sie die Versionen und holen Sie zurück, was verloren ging: siehe
  [Wie kehre ich zu einer früheren Version zurück?](wie-kehre-ich-zu-einer-frueheren-version-zurueck.md)
- **Die Seite erscheint jedes Mal.** Alte Entwürfe häufen sich an, oft weil der Browser geschlossen oder Zurück
  gedrückt wurde statt **Entwurf speichern und beenden** oder **Entwurf verwerfen**. Räumen Sie **Meine Entwürfe** auf
  und verlassen Sie das Bearbeitungsformular mit seinen Schaltflächen.

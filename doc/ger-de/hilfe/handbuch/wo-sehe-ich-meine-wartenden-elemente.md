# Wo sehe ich meine Elemente, die auf Freigabe warten?

Wenn die Website einen Freigabe-Workflow hat, wartet eine Version, die Sie zur Veröffentlichung schicken, bis ein
Freigebender sie annimmt. Sie steht dann in **Meine Warteliste**.

## Wer das tun kann

Jeder Benutzer, der Inhalte bearbeiten kann. Sie sehen nur Ihre eigenen wartenden Versionen.

## Schritte

1. Öffnen Sie im oberen Menü **Dashboard** und wählen Sie **Meine Warteliste**, oder verwenden Sie den Block **Meine
   Warteliste** im Dashboard.
   Die Liste **Ausstehende Versionen** zeigt jede Version mit Name, Klasse und dem Zeitpunkt, zu dem Sie sie geschickt
   haben.
2. Klicken Sie auf einen Namen, um die Version so zu sehen, wie der Freigebende sie sieht.
3. Um die Antwort des Freigebenden oder eine Nachricht zu lesen, öffnen Sie **Dashboard** > **Zusammenarbeit**.
4. Wenn der Freigebende annimmt, wird die Version veröffentlicht und verschwindet aus der Liste. Wenn er sie ablehnt,
   geht sie zurück in **Meine Entwürfe**, wo Sie sie ändern und erneut schicken können.

## Was schiefgehen kann

- **Ein Element wartet tagelang.** Der Freigebende hat es nicht bearbeitet, oder der Cronjob des Workflows läuft nicht.
  Fragen Sie zuerst den Freigebenden, dann einen Administrator.
- **Sie möchten ein wartendes Element ändern.** Solange es wartet, können Sie es nicht bearbeiten. Bitten Sie den
  Freigebenden, es abzulehnen, bearbeiten Sie dann den Entwurf und schicken Sie ihn erneut.
- **Die Liste ist immer leer.** Die Website hat keinen Freigabe-Workflow für Ihre Inhalte: Ihre Versionen werden sofort
  veröffentlicht.

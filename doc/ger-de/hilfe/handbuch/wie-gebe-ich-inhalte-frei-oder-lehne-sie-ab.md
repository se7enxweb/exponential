# Wie gebe ich Inhalte frei oder lehne sie ab?

Wenn Sie freigeben dürfen, finden Sie die Versionen, die auf Sie warten, unter **Zusammenarbeit**. Eine Freigabe
veröffentlicht die Version; eine Ablehnung schickt sie als Entwurf an den Autor zurück.

## Wer das tun kann

Benutzer oder Gruppen, die im Freigabe-Workflow der Website als Freigebende genannt sind. Nur ein Freigebender des
Elements kann entscheiden.

## Schritte

1. Öffnen Sie im oberen Menü **Dashboard** und wählen Sie **Zusammenarbeit**.
   Die wartenden Elemente sind mit **Wartet auf Freigabe** markiert.
2. Klicken Sie auf das Element.
   Es zeigt, wer es geschickt hat, wann, und die Beteiligten.
3. Klicken Sie auf **Vorschau**, um die Version so zu lesen, wie Besucher sie sehen würden.
4. Wenn Sie dem Autor etwas mitteilen möchten, schreiben Sie es und klicken Sie auf **Kommentar hinzufügen**.
5. Klicken Sie auf **Freigeben**, um die Version zu veröffentlichen, oder auf **Ablehnen**, um sie zurückzuschicken.
   Bestätigen Sie die Rückfrage.
   Das Element ist abgeschlossen. Der Autor sieht Ihre Entscheidung und Ihren Kommentar.

## Was schiefgehen kann

- **„Only an approver can approve or deny this item.“** Sie sind an dem Element beteiligt, aber nicht sein
  Freigebender.
- **Sie haben freigegeben, aber der Inhalt ist noch nicht veröffentlicht.** Die Veröffentlichung geht weiter, wenn der
  Cronjob des Workflows läuft, meist innerhalb weniger Minuten.
- **„This approval is closed: comments can no longer be added.“** Jemand hat bereits entschieden. Schreiben Sie dem
  Autor direkt.

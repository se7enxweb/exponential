# Wie nutze ich den KI-Assistenten im Editor?

Exponential Intelligence (die Erweiterung expai) fügt der Administration einen KI-Assistenten hinzu. Er veröffentlicht
nie von sich aus: Was er schreibt, wird ein Entwurf oder ein Vorschlag, und Sie entscheiden.

## Wer das tun kann

Benutzer, deren Rolle die Richtlinien von Exponential Intelligence hat (zum Beispiel `expai/write`), auf einer Website,
auf der ein KI-Anbieter eingerichtet ist.

## Schritte

1. Öffnen Sie in der Hilfe das Benutzerhandbuch von Exponential Intelligence: **Hilfe** > **Extensions** >
   **Exponential Intelligence** > **Benutzerhandbuch**, unter der Hilfeadresse
   `/exphelp/viewer/ext/expai/manual/README.md`.
2. Wählen Sie Ihre Frage, zum Beispiel wie Sie den Assistenten im Bearbeitungsformular fragen, wie Sie Vector nutzen
   oder wie Sie einen KI-Entwurf prüfen.
3. Folgen Sie den Schritten dort.

## Was schiefgehen kann

- **Keine KI-Schaltflächen im Editor.** Ihrer Rolle fehlen die Richtlinien, oder es ist kein KI-Anbieter eingerichtet.
  Fragen Sie einen Administrator.
- **Die KI liegt falsch.** Lesen und korrigieren Sie immer, was sie schreibt, bevor Sie veröffentlichen. Sie sind der
  Autor.

# Wie verwende ich ein Bild oder eine Datei aus der Medienbibliothek wieder?

Der Tab **Medien** enthält Bilder, Dateien und andere Medien als eigene Elemente, außerhalb der Seiten der Website. Ein
Element dort kann von beliebig vielen Seiten verwendet werden: Sie verweisen darauf, statt eine Kopie zu enthalten. So
liegen ein Logo, eine Preisliste oder ein Foto an einer einzigen Stelle.

Eine Datei, die direkt in ein Dateifeld eines Artikels hochgeladen wird, ist etwas anderes: Sie gehört nur zu diesem
Artikel und lässt sich nicht aus der Bibliothek auswählen.

## Wer das tun kann

Redakteure, die die Medienbibliothek lesen dürfen. Elemente dort hinzufügen erfordert `content/create` in ihren
Ordnern; ein Element in einer Seite verwenden erfordert das Recht, diese Seite zu bearbeiten.

## Schritte

1. Legen Sie die Datei zuerst in die Bibliothek: Öffnen Sie den Tab **Medien**, öffnen Sie den passenden Ordner (zum
   Beispiel **Bilder** oder **Dateien**) und laden Sie sie hoch. Siehe [Bilder, Medien und Uploads](../medien-und-uploads.md#dateien-hochladen).
2. Geben Sie ihr einen klaren Namen und bei einem Bild einen Alternativtext, damit andere es finden und verstehen.
3. Bearbeiten Sie die Seite, die es verwenden soll.
4. Verweisen Sie auf eine von drei Arten auf das Element:
   - in einem Relationsfeld wie *Image* klicken Sie auf **Vorhandenes hinzufügen** und wählen das Element;
   - im Kasten **Verwandte Objekte** unter dem Formular klicken Sie auf **Vorhandenes hinzufügen**;
   - in einem Rich-Text-Feld betten Sie es mit der Einbetten-Schaltfläche des Editors ein.
5. Gehen Sie im Browser vom Inhaltsbaum hinauf zur obersten Ebene, um die Medienbibliothek zu erreichen, öffnen Sie
   den Ordner, wählen Sie das Element aus und klicken Sie auf **Auswählen**.
6. Klicken Sie auf **Zur Veröffentlichung schicken**.

## Bevor Sie ein gemeinsam genutztes Element ändern oder entfernen

1. Öffnen Sie das Element im Tab **Medien** und klicken Sie auf seinen Tab **Verknüpfungen**.
2. Lesen Sie **Rückwärts verknüpfte Objekte**: Jede dort aufgeführte Seite verwendet das Element.
3. Bearbeiten oder ersetzen Sie das Element nur, wenn die Änderung zu allen passt. Um nur eine Seite zu ändern, laden
   Sie für sie ein neues Element hoch.

## Was schiefgehen kann

- **Besucher sehen das Bild nicht.** Die Medienbibliothek ist oft eine eigene Sektion. Dürfen anonyme Besucher diese
  Sektion nicht lesen, zeigen Seiten das Bild nur angemeldeten Benutzern. Bitten Sie einen Administrator, die Rechte
  der Sektion zu prüfen.
- **Ein gemeinsam genutztes Bild hat sich auf Seiten geändert, die Sie nicht angefasst haben.** Jemand hat das
  gemeinsam genutzte Element bearbeitet. Verwenden Sie bei Bedarf **Versionen verwalten** darauf, um zurückzugehen.
- **Seiten zeigen nach einem Entfernen fehlende Bilder.** Das Element wurde entfernt, während Seiten es noch
  verwendeten. Stellen Sie es aus dem Papierkorb wieder her, oder lassen Sie diese Seiten auf ein anderes Element
  verweisen.
- **Sie haben ein Element aus Medien in den Inhaltsbaum verschoben.** Es übernimmt dabei womöglich eine andere Sektion
  und andere Rechte. Prüfen Sie den Tab **Details**.

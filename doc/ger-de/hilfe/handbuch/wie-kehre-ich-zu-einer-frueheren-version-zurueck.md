# Wie kehre ich zu einer früheren Version zurück?

Eine veröffentlichte Version wird nie an Ort und Stelle geändert. Jede Bearbeitung erzeugt eine neue Version, und die
vorherige wird als **archiviert** aufbewahrt. Um einen älteren Text zurückzuholen, machen Sie aus der alten Version
einen neuen Entwurf und veröffentlichen diesen Entwurf. Dabei geht nichts verloren: Die Version, die Sie ersetzen, wird
ihrerseits archiviert.

## Wer das tun kann

Redakteure, die das Element bearbeiten dürfen. Versionen lesen erfordert `content/versionread`; Versionen entfernen
erfordert `content/versionremove`.

## Schritte

1. Öffnen Sie das Element und klicken Sie auf **Versionen verwalten** (die runde Schaltfläche mit einer Uhr). Im
   Bearbeitungsformular verwenden Sie **Versionen verwalten** in der linken Spalte.
   Die Versionsseite öffnet sich mit einer **Übersicht** und der Liste der Versionen.
2. Um die richtige Version zu finden, klicken Sie in einer Zeile auf **Vergleichen**, oder wählen Sie unter **Zwei
   Versionen vergleichen** eine ältere und eine neuere Version und klicken Sie auf **Unterschiede anzeigen**.
   Entfernter Text ist durchgestrichen und hinzugefügter Text unterstrichen; wechseln Sie zwischen **Änderungen im
   Text anzeigen** und **Änderungen im Block anzeigen**.
3. Wählen Sie in der Zeile der gewünschten Version ihre Übersetzung unter **Neuer Entwurf aus dieser Version, in** und
   klicken Sie auf **Neuen Entwurf machen**.
4. Bearbeiten Sie den neuen Entwurf bei Bedarf und klicken Sie dann auf **Zur Veröffentlichung schicken**.
   Der alte Inhalt wird als neueste Version erneut veröffentlicht.

Zum Aufräumen haken Sie Versionen an, die Sie nicht mehr brauchen, und klicken Sie auf **Ausgewählte Versionen
entfernen**.

## Was schiefgehen kann

- **Bearbeiten wird für eine alte Version nicht angeboten.** Nur Entwürfe lassen sich bearbeiten. Machen Sie aus der
  alten Version einen neuen Entwurf.
- **Der Entwurf gehört jemand anderem.** Sie können ihn nicht bearbeiten, aber Sie können daraus Ihren eigenen neuen
  Entwurf machen.
- **Andere Sprachen sehen nach dem Zurücksetzen anders aus.** Ein neuer Entwurf entsteht in einer Sprache; die anderen
  Übersetzungen werden aus der aktuell veröffentlichten Version übernommen, sie behalten also ihren neuesten Text.
- **Achtung: Entfernte Versionen sind endgültig weg**, mit allen ihren Übersetzungen. Die veröffentlichte Version und
  Versionen in einem laufenden Workflow werden nie entfernt.
- **Sehr alte Versionen fehlen.** Die Website bewahrt pro Element eine begrenzte Anzahl von Versionen auf und entfernt
  die ältesten archivierten, wenn die Grenze erreicht ist.

# Wie finde ich Inhalte in der Administration?

Drei Werkzeuge finden Inhalte: das Suchfeld für Wörter, die **Erweiterte Suche** für Filter und der **Inhaltsfinder**,
wenn Sie eine ID, einen Pfad oder eine Adresse kennen.

## Wer das tun kann

Jeder Benutzer mit `content/read`. Sie finden nur, was Ihre Rolle lesen darf.

## Schritte

1. **Nach Wörtern:** Geben Sie in der oberen Leiste etwas in **Suchen...** ein und drücken Sie die Eingabetaste.
   Die Ergebnisse listen die passenden Objekte auf, die besten zuerst.
2. **Mit Filtern:** Öffnen Sie die **Erweiterte Suche** (in den Suchergebnissen oder unter **Dashboard** >
   **Erweiterte Suche**). Wählen Sie eine Klasse und für sie das zu durchsuchende Attribut, eine Sektion, wann
   veröffentlicht wurde und unterhalb welches Orts. Klicken Sie auf **Suchen**.
3. **Nach ID, Pfad oder Adresse:** Geben Sie in der linken Spalte etwas in den **Inhaltsfinder** ein, zum Beispiel
   `275`, `/news/summer` oder die Adresse von der Website, und klicken Sie auf **Finden**.
4. Klicken Sie auf ein Ergebnis, um es zu öffnen.

![Das Formular der Erweiterten Suche mit den Filtern für Klasse, Attribut, Sektion und Datum](../../../eng-us/help/manual/images/advanced-search.webp)

## Was schiefgehen kann

- **Ein neues Objekt wird nicht gefunden.** Der Suchindex wird von einem Cronjob aktualisiert, einige Minuten nach dem
  Veröffentlichen. Verwenden Sie in der Zwischenzeit den Inhaltsfinder oder den Baum.
- **Zu viele Ergebnisse.** Setzen Sie Wörter für eine genaue Wortfolge in Anführungszeichen, oder verwenden Sie die
  **Erweiterte Suche** mit einer Klasse.
- **Nichts wird gefunden, obwohl Sie wissen, dass es existiert.** Es liegt vielleicht im Papierkorb, ist für Ihre Rolle
  verborgen oder steht in einer anderen Sprache der Website.

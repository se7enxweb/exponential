# Wie halte ich den Tag-Baum ordentlich?

Der Tab **Tags** enthält den gemeinsamen Tag-Baum. Ein ordentlicher Baum hat einen Tag pro Bedeutung, am richtigen
Platz, in jeder Sprache der Website.

## Wer das tun kann

Benutzer, deren Rolle die Tag-Richtlinien hat: `tags/add`, `tags/edit`, `tags/delete`, `tags/merge`,
`tags/makesynonym` und `tags/addsynonym` nach Bedarf. Redakteure verschlagworten meist nur Inhalte; ein oder zwei
Personen pflegen den Baum.

## Schritte

1. Klicken Sie im oberen Menü auf **Tags** (oder **Mehr** > **Tags**).
   Das **Tags dashboard** zeigt die Tags der obersten Ebene.
2. Um einen Tag hinzuzufügen, öffnen Sie den übergeordneten Tag und klicken Sie auf **Add tag**. Geben Sie den Namen ein
   und speichern Sie.
3. Um einen Tag zu ändern, öffnen Sie ihn und verwenden Sie **Weitere Aktionen**: bearbeiten, übersetzen, verschieben,
   löschen, zum Synonym eines anderen Tags machen oder mit einem anderen Tag zusammenführen.
4. Um einen Tag zu finden, verwenden Sie **Tags search**. **Latest tags** zeigt, was kürzlich hinzugefügt wurde, oft
   von Redakteuren in Eile.
5. Übersetzen Sie Tags in jede Sprache, die die Website zeigt: Öffnen Sie den Tag und fügen Sie die Übersetzung hinzu.

![Das Tags dashboard mit den untergeordneten Tags und den Schaltflächen Add tag und Weitere Aktionen](../../../eng-us/help/manual/images/tags-dashboard.webp)

## Was schiefgehen kann

- **Achtung: Das Löschen eines Tags entfernt ihn aus allen Inhalten.** Führen Sie ihn stattdessen mit dem richtigen Tag
  zusammen, damit die Inhalte einen Tag behalten.
- **Ein Tag erscheint auf der deutschen Website auf Englisch.** Er hat keine deutsche Übersetzung. Übersetzen Sie ihn.

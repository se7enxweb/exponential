# Wie entferne ich eine Übersetzung oder ändere die Hauptsprache?

Jedes Element hat eine **Hauptsprache**, die Sprache, in der es zuerst angelegt wurde, sofern niemand sie geändert hat.
Die anderen Sprachen sind Übersetzungen davon. Beide Änderungen nehmen Sie im Tab **Übersetzungen** des Elements vor.

## Wer das tun kann

Redakteure, die das Element bearbeiten dürfen. Ohne dieses Recht sind die Schaltflächen ausgegraut.

## Schritte

### Die Hauptsprache ändern

1. Öffnen Sie das Element und klicken Sie auf den Tab **Übersetzungen**.
   **Bestehende Übersetzungen** listet jede Sprache mit ihrem Locale auf; die aktuelle Hauptsprache ist markiert.
2. Wählen Sie die neue Hauptsprache mit ihrem Optionsfeld in der Spalte **Hauptort**.
3. Klicken Sie auf **Als Haupt setzen**.

### Eine Übersetzung entfernen

1. Haken Sie im Tab **Übersetzungen** die zu entfernenden Sprachen an.
2. Klicken Sie auf **Ausgewählte entfernen**.
   Die Seite **Entfernen der Übersetzung bestätigen** listet die Sprachen auf.
3. Klicken Sie auf **OK**.

## Was schiefgehen kann

- **Die Hauptsprache lässt sich nicht anhaken.** Sie kann nie entfernt werden. Machen Sie zuerst eine andere Sprache
  zur Hauptsprache und entfernen Sie dann die alte.
- **Als Haupt setzen ist ausgegraut.** Das Element existiert nur in einer Sprache, es gibt also nichts, wohin man
  wechseln könnte.
- **Achtung: Eine entfernte Übersetzung ist aus jeder Version verschwunden.** Ihr Text lässt sich nicht aus dem
  Versionsverlauf zurückholen. Alte Versionen, die durch Bearbeiten dieser Sprache entstanden sind, werden mit ihr
  entfernt. Exportieren oder kopieren Sie den Text vorher, wenn Sie ihn vielleicht noch brauchen.
- **Besucher dieser Sprache sehen jetzt eine andere Sprache oder gar nichts.** Was sie sehen, hängt von der
  Sprachliste der Website und der Einstellung des Elements für nicht übersetzte Sprachen ab: siehe
  [Wie zeige ich ein Element in Sprachen, in die es nicht übersetzt ist?](wie-zeige-ich-ein-element-in-nicht-uebersetzten-sprachen.md)

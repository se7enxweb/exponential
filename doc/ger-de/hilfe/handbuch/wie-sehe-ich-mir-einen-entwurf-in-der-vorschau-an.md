# Wie sehe ich mir einen Entwurf vor dem Veröffentlichen in der Vorschau an?

Die Vorschau zeigt eine Version so, wie ein Besucher sie sehen würde, ohne sie zu veröffentlichen. Sie wählen das
Website-Design, die Sprache, die Stelle im Baum, an der sie gezeigt wird, und die Bildschirmgröße.

## Wer das tun kann

Redakteure, die Versionen des Elements lesen dürfen (`content/versionread`); der Ersteller des Entwurfs darf es immer.

## Schritte

1. Klicken Sie im Bearbeitungsformular in der linken Spalte unter dem aktuellen Entwurf auf **Vorschau**.
   Was Sie eingegeben haben, wird im Entwurf gespeichert, und die Seite **Vorschau der Version** öffnet sich.
2. Wählen Sie unter **Ansichtskontolle**:
   - **Siteaccess**: die Website, deren Design verwendet wird, zum Beispiel die öffentliche Website statt der
     Administration;
   - **Übersetzung**: die angezeigte Sprache;
   - **Ort**: an welchem der Orte des Elements es gezeigt wird (bei einem neuen Element die dafür gewählte Stelle);
   - **Ansichtsmodus**: meist die ganze Seite.
3. Klicken Sie auf **Ansicht aktualisieren**.
4. Wählen Sie eine **Vorschaugröße** (**Desktop**, **Großer Desktop**, **iPad**, **iPhone** oder **Querformat**), um
   die Seite in dieser Breite zu sehen. **Vorschau in einem neuen Fenster öffnen** zeigt sie in voller Größe.
5. Klicken Sie auf **Zurück zum Bearbeiten**, um den Entwurf zu ändern, oder auf **Veröffentlichen**, um ihn von hier
   aus zu veröffentlichen.

Eine ältere Version lässt sich auf dieselbe Weise ansehen: Öffnen Sie **Versionen verwalten** und klicken Sie in ihrer
Zeile auf **Ansehen**.

## Was schiefgehen kann

- **Die Vorschau sieht ungestaltet aus oder wie die Administration.** Der Siteaccess der Administration ist gewählt.
  Wählen Sie den öffentlichen Siteaccess und klicken Sie auf **Ansicht aktualisieren**.
- **Das Formular kommt mit einer Meldung statt der Vorschau zurück.** Ein Feld ist ungültig (zum Beispiel eine
  fehlerhafte Adresse). Korrigieren Sie es und klicken Sie erneut auf **Vorschau**.
- **Listen und Menüs sehen alt aus.** Die Vorschau zeigt nur diese Version dieses Elements; Listen auf anderen Seiten
  zeigen weiterhin die veröffentlichten Versionen, bis Sie veröffentlichen.
- **Bearbeiten wird nicht angeboten.** Die gezeigte Version ist kein Entwurf (sie ist veröffentlicht oder archiviert).
  Machen Sie daraus einen neuen Entwurf: siehe [Wie kehre ich zu einer früheren Version zurück?](wie-kehre-ich-zu-einer-frueheren-version-zurueck.md)

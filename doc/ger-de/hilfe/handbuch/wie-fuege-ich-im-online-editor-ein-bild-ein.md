# Wie füge ich im Online-Editor ein Bild ein?

Ein Bild in einem Text ist ein Bildobjekt der Medien-Bibliothek, eingebettet an der Stelle des Cursors. Dasselbe Bild
kann in vielen Texten verwendet werden.

## Wer das tun kann

Redakteure, die das Objekt bearbeiten dürfen. Das Hochladen eines neuen Bildes braucht zusätzlich `content/create` in
der Medien-Bibliothek.

## Schritte

1. Bearbeiten Sie das Objekt und klicken Sie in das Textfeld, an die Stelle, an die das Bild kommt.
2. Klicken Sie in der Werkzeugleiste des Editors auf **Bild einfügen/bearbeiten**.
3. Laden Sie ein neues Bild hoch (mit einem Namen und einem Alternativtext), oder finden Sie ein vorhandenes über die
   Suche, das Durchsuchen oder in Ihren Lesezeichen, und wählen Sie es aus.
4. Wählen Sie die Größe (zum Beispiel klein, mittel, groß) und die Ausrichtung.
5. Klicken Sie auf **Einfügen**.
6. Klicken Sie auf **Zur Veröffentlichung schicken**.

## Was schiefgehen kann

- **Das Bild hat keinen Alternativtext.** Screenreader sagen dann nichts darüber. Geben Sie jedem Bild eine kurze
  Beschreibung dessen, was es zeigt; der Tab Design listet Bilder ohne eine solche Beschreibung auf.
- **Das Hochladen wird abgelehnt.** Die Datei ist zu groß oder von einem Typ, den die Website nicht annimmt. Verwenden
  Sie JPEG, PNG oder WebP unterhalb der Größengrenze.
- **Das Bild ist auf der Seite zu groß.** Wählen Sie im Bilddialog eine kleinere Größe, statt eine größere Datei zu
  verwenden.

# Benutzerhandbuch

Jede Seite beantwortet eine Frage zur Arbeit in der Administration mit dem Design **Admin 4**. Jede Seite hat dieselben
Teile: wer es tun kann (die Rolle oder Richtlinie, die Sie brauchen), die Schritte, was schiefgehen kann und die Seiten,
die Sie als Nächstes lesen. Was Sie sehen, hängt von Ihrer Rolle ab: Ein Tab oder eine Schaltfläche, die Sie nicht
verwenden dürfen, wird nicht angezeigt.

Die Anleitungen und Funktionsseiten erklären die Hintergründe; diese Seiten sind dafür da, die Aufgabe zu erledigen.

## Exponential Intelligence

Exponential Intelligence (die Erweiterung expai) hat ein eigenes Benutzerhandbuch in derselben Form, bei der
Dokumentation der Erweiterungen: Öffnen Sie in der Hilfe **Extensions** > **Exponential Intelligence** >
**Benutzerhandbuch** oder die Hilfeadresse `/exphelp/viewer/ext/expai/manual/README.md`. Es behandelt den Assistenten im
Editor, Vector, Zusammenfassungen, Vorschläge für Alternativtexte, Ketten, die Prüfung von KI-Entwürfen und die Budgets.

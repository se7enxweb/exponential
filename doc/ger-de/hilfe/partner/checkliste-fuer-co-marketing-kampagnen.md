# Checkliste für Co-Marketing-Kampagnen

Diese Seite ist für die Person, die eine gemeinsame Kampagne im Marketing verantwortet. Verwenden Sie sie zusammen mit
[Co-Marketing mit 7x und dem Projekt](co-marketing.md).

## 1. Briefing

```text
Campaign brief
Name: ______________________   Partners involved: ______________________
Goal (measurable): ______________________
Audience: ______________________   Channels: ______________________
Message in one sentence: ______________________
Sources for every claim: ______________________
Budget and who pays what: ______________________
Dates: start ____  end ____   Owner on each side: ____ / ____
Approval needed from: ______________________
```

## 2. Vor der Produktion

- [ ] Beide Seiten haben dem Briefing schriftlich zugestimmt
- [ ] Jeder Fakt hat eine Quelle in der Hilfe, der README oder einem Changelog
- [ ] Produkt, Unternehmen und Foundation korrekt benannt ([Namens- und Markenregeln für Partner](namens-und-markenregeln.md))
- [ ] Logos für Ihre Stufe erlaubt ([Partnerlogos verwenden](partnerlogos-und-zeichen.md))
- [ ] Kundennamen nur mit schriftlicher Erlaubnis ([Kundenreferenzen](kundenreferenzen.md))

## 3. Produktion

- [ ] Texte in amerikanischem Englisch (oder der Sprache der Kampagne), von einer zweiten Person geprüft
- [ ] Bilder mit einer Lizenz, die die Nutzung erlaubt
- [ ] Barrierefreie Formate: Alternativtexte, Untertitel für Videos, gut lesbarer Kontrast
- [ ] Links zeigen auf offizielle Seiten (exponential.earth, die Hilfe, GitHub)

## 4. Recht und Datenschutz

- [ ] Anmeldeformulare erheben nur, was die Kampagne braucht ([Kundendaten schützen](kundendaten-schuetzen.md))
- [ ] Die Datenschutzerklärung jedes Partners deckt dessen eigene Nutzung der Daten ab
- [ ] Leads werden zwischen Partnern nur wie vereinbart geteilt ([Leads übergeben und zurückgeben](leads-uebergeben.md))

## 5. Start

- [ ] Endgültige Freigabe von beiden Seiten
- [ ] Am vereinbarten Datum in allen Kanälen veröffentlichen
- [ ] Jemand beobachtet in den ersten Tagen Kommentare und Fragen

## 6. Messen und abschließen

- [ ] Ergebnisse gemessen am Ziel
- [ ] Erkenntnisse, mit dem anderen Partner geteilt
- [ ] Falls zutreffend für Punkte erfasst ([Ihre Partneraktivität erfassen](partneraktivitaet-erfassen.md))
- [ ] Material archiviert; Logos daraus entfernt, wenn sich später eine Stufe ändert

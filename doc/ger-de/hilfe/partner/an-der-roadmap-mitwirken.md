# An der Roadmap mitwirken

Diese Seite ist für Partner, die beeinflussen möchten, was als Nächstes gebaut wird.

## Was veröffentlicht ist

- Die Community-Roadmap auf <https://exponential.earth/about/roadmap> (gelesen am 18. Oktober 2026) beschreibt die
  Community-Kanäle (Telegram, Foren, GitHub, Slack, Discord) und lädt dazu ein, „den Fortschritt der Entwicklung zu verfolgen, Probleme zu melden, Funktionen zu wünschen und beizutragen“. Datierte Produktfunktionen führt sie nicht auf.
- Was gebaut wurde, ist ausführlich veröffentlicht: die Änderungsprotokolle in `doc/changelogs/` und die Geschichte in
  `doc/eng-us/history/` ([Die Geschichte von Exponential](../../../eng-us/history/README.md)).
- Eine datierte Produkt-Roadmap mit Zusagen ist nicht veröffentlicht: von der Foundation noch festzulegen.

## Wie Partner sie beeinflussen können

| Weg | Wer | Quelle |
|---|---|---|
| Wünsche zur Produkt-Roadmap | Silver, Gold, Platinum | <https://exponential.earth/partner/benefits> |
| „Transparenz: Bleiben Sie über unsere Strategie und Produkt-Roadmap informiert“ | Alle Partner | <https://exponential.earth/partner/why> |
| Platinum: „Einfluss auf die Roadmap“ und „Einbindung der Leitung“ (so formuliert auf der Seite why) | Platinum / höchste Stufe | Seite why |
| Funktionswünsche als öffentliche Issues | Alle | <https://github.com/se7enxweb/exponential/issues> |
| Pull Requests mit funktionierendem Code | Alle | CONTRIBUTING.md |
| Stufen von 7x bei GitHub Sponsors mit Einfluss auf den Produkt-Backlog | Sponsoren | [7x auf GitHub sponsern](../sponsoren/7x-sponsern.md) |

## Einen Wunsch formulieren, der umgesetzt wird

```text
Feature request: <short title>

Problem: <what users cannot do today, in their words>
Who has it: <how many customers / which kinds of sites> (no customer data)
Current workaround: <...>
Proposed behavior: <what should happen>
Scope: kernel / extension / documentation
Willing to contribute: code / testing / documentation / funding
```

Der stärkste Wunsch kommt mit einem Beitrag: einem Prototyp, Tests oder einer Finanzierung
([Funktionswünsche und gesponserte Funktionen](funktionswuensche-und-gesponserte-funktionen.md)).

## Was Sie nicht tun sollten

- Versprechen Sie Kunden keine Funktionen, nur weil Sie sie gewünscht haben.
- Stellen Sie Ihren Wunsch im Marketing nicht als Roadmap des Projekts dar.

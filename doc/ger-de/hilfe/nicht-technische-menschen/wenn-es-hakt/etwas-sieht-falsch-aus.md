# Etwas sieht falsch aus

Suchen Sie Ihre Situation in den Tabellen unten. Für die meisten gibt es eine einfache Erklärung, die Sie in einer
Minute selbst prüfen können.

## Inhalt

1. [Auf der öffentlichen Website](#auf-der-öffentlichen-website)
2. [In der Administration](#in-der-administration)
3. [Die ganze Website ist nicht erreichbar](#die-ganze-website-ist-nicht-erreichbar)
4. [Immer noch nicht weiter?](#immer-noch-nicht-weiter)

## Auf der öffentlichen Website

| Was Sie sehen | Wahrscheinliche Ursache | Was Sie tun können |
|---|---|---|
| Meine Änderung ist nicht da | Nicht veröffentlicht (noch ein Entwurf), wartet auf Freigabe, oder ein Cache | Sehen Sie unter **Meine Entwürfe** und **Meine Warteliste** nach; laden Sie dann mit gedrückter Umschalttaste neu ([Caches erklärt](../begriffe/caches-erklaert.md#wenn-sie-eine-alte-seite-sehen)) |
| Eine Seite ist verschwunden | Versteckt, entfernt oder verschoben | Suchen Sie sie in der Administration; sehen Sie im Papierkorb nach ([Einen Fehler rückgängig machen](../erste-schritte/einen-fehler-rueckgaengig-machen.md)) |
| "Seite nicht gefunden" bei einer alten Adresse | Die Seite wurde verschoben oder entfernt | Bitten Sie Ihren Administrator um eine Weiterleitung ([Wie leite ich alte Adressen weiter?](../../handbuch/wie-leite-ich-alte-adressen-um.md)) |
| Ein Bild fehlt | Entfernt, versteckt oder nie veröffentlicht | Öffnen Sie das Bildobjekt unter **Medien** und prüfen Sie es |
| Das Menü steht in der falschen Reihenfolge | Die Reihenfolge der Unterelemente | [Wie ändere ich die Reihenfolge der Unterelemente?](../../handbuch/wie-aendere-ich-die-reihenfolge-der-unterelemente.md) |
| Eine Übersetzung erscheint nicht | Diese Sprache wird auf der Website noch nicht gezeigt | Fragen Sie Ihren Administrator ([Eine Seite übersetzen](../erste-schritte/eine-seite-uebersetzen.md#wenn-es-nicht-funktioniert)) |
| Das Design sieht überall kaputt aus | Ein Problem mit dem Design oder dem Server | Nicht Ihre Aufgabe: Sagen Sie es Ihrem Entwickler oder Hoster |

## In der Administration

| Was Sie sehen | Wahrscheinliche Ursache | Was Sie tun können |
|---|---|---|
| Eine Schaltfläche ist ausgegraut | Sie dürfen sie hier oder jetzt nicht verwenden | Zeigen Sie darauf, um den Grund zu lesen ([Rollen und Rechte erklärt](../begriffe/rollen-und-rechte-erklaert.md#woran-sie-ihre-rolle-bemerken)) |
| Ein Reiter, den meine Kollegin hat, fehlt | Ihre Rolle ist eine andere | Fragen Sie Ihren Administrator und sagen Sie, was Sie tun müssen |
| *Möglicher Bearbeitungs-Konflikt* | Es gibt schon einen Entwurf dieses Objekts | Machen Sie mit Ihrem Entwurf weiter oder legen Sie einen neuen an ([Wenn jemand anderes bearbeitet](../../inhalte-bearbeiten.md#wenn-jemand-anderes-bearbeitet)) |
| Das Formular lässt sich nicht veröffentlichen | Ein Pflichtfeld ist leer oder falsch | Lesen Sie die rote Meldung oben und am Feld |
| Die Schaltfläche zum Abmelden ist grau | Sie bearbeiten gerade | Speichern oder verwerfen Sie zuerst Ihren Entwurf |
| Die Suche findet ein neues Objekt nicht | Der Suchindex wird einige Minuten später aktualisiert | Verwenden Sie in der Zwischenzeit den Inhaltsfinder ([Etwas finden](../erste-schritte/etwas-finden.md#wenn-sie-es-nicht-finden)) |
| Ein gelbes Banner **Demo-Modus** auf unserer echten Website | Eine Einstellung auf dem Server, die entfernt werden muss | Sagen Sie es sofort Ihrem Hoster ([Demomodus](../../demomodus.md)) |

## Die ganze Website ist nicht erreichbar

1. **Prüfen Sie von einem anderen Gerät oder Netz aus**, zum Beispiel mit Ihrem Telefon ohne WLAN. Funktioniert es
   dort, liegt das Problem an Ihrer eigenen Verbindung.
2. **Prüfen Sie die Adresse**: Ist sie richtig geschrieben, mit `https://`?
3. **Hat sich gerade etwas geändert?** Ein Update, ein Umzug, das Verlängerungsdatum der Domain?
4. **Rufen Sie Ihren Hoster an**, mit der Uhrzeit, zu der Sie es bemerkt haben, und dem, was Sie sehen. Die
   Reihenfolge der Anrufe steht unter [Wen Sie anrufen](wen-sie-anrufen.md), und der Ablauf für Betreiber unter
   [Wenn die Website nicht erreichbar ist](../../kunden/gesund-halten/wenn-die-website-nicht-erreichbar-ist.md).

Versuchen Sie nicht, einen Server selbst zu reparieren; Sie könnten die Reparatur erschweren.

## Immer noch nicht weiter?

Notieren Sie, was Sie sehen, und [bitten Sie dann um Hilfe](wie-sie-um-hilfe-bitten.md). Je genauer Ihre Notizen, desto
schneller die Lösung.

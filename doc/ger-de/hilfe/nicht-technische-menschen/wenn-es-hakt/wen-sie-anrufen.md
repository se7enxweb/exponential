# Wen Sie anrufen

Füllen Sie diese Seite **jetzt** aus, an einem ruhigen Tag. Im Notfall erinnert sich niemand, welches Unternehmen die
E-Mail betreibt.

## Inhalt

1. [Welches Problem an wen geht](#welches-problem-an-wen-geht)
2. [Ihr Kontaktblatt](#ihr-kontaktblatt)
3. [Es aktuell halten](#es-aktuell-halten)

## Welches Problem an wen geht

| Problem | Zuerst anrufen | Danach |
|---|---|---|
| "Wie mache ich ...?" in der Administration | Diese Hilfe, dann Ihr Administrator | Die Community ([Wie Sie um Hilfe bitten](wie-sie-um-hilfe-bitten.md#kostenlose-hilfe-aus-der-community)) |
| Ich kann mich nicht anmelden | Ihr Administrator | |
| Eine Seite zeigt das Falsche | Wer sie bearbeitet hat, oder Ihr Administrator | |
| Das Design sieht kaputt aus | Ihr Entwickler oder Partner | |
| Die ganze Website ist nicht erreichbar | Ihr Hoster | Ihr Entwickler oder Partner |
| Das Schloss fehlt, oder eine Zertifikatswarnung | Ihr Hoster | |
| E-Mail kommt nicht an | Ihr Mailanbieter oder Hoster | |
| Die Domain funktioniert nicht mehr | Ihre Registrierungsstelle (Verlängerung prüfen) | Ihr Hoster |
| Etwas wurde gelöscht und ist nicht im Papierkorb | Ihr Hoster (Sicherungen) | Ihr Entwickler |
| Ein Sicherheitsproblem | Ihr Administrator und Hoster, vertraulich | Die vertrauliche Sicherheitsadresse des Projekts ([Sicherheitsprobleme](../../wenn-etwas-schiefgeht.md#sicherheitsprobleme)) |

Die Fassung für Betreiber, mit Blick auf Verträge, ist [Wann Sie wen anrufen](../../kunden/partner-und-hoster/wann-sie-wen-anrufen.md).

## Es aktuell halten

- Prüfen Sie es einmal im Jahr und immer dann, wenn jemand geht oder sich ein Vertrag ändert.
- Setzen Sie die Überprüfung einmal im Jahr auf die
  [Monatliche Checkliste für Website-Verantwortliche](../checklisten/monatlich-fuer-website-verantwortliche.md).
- Wenn jemand geht, folgen Sie der [Checkliste zur Übergabe](../checklisten/uebergabe-wenn-jemand-geht.md).

# Wenn es hakt

Nicht weiterzukommen ist normal und selten Ihre Schuld. Die Seiten dieser Gruppe helfen Ihnen, schnell wieder
weiterzukommen oder das Problem so an die richtige Person zu geben, dass es schnell behoben wird.

## Die Seiten

| Seite | Verwenden Sie sie, wenn |
|---|---|
| [Etwas sieht falsch aus](etwas-sieht-falsch-aus.md) | Die Website oder die Administration nicht tut, was Sie erwarten |
| [Eine Fehlermeldung lesen](eine-fehlermeldung-lesen.md) | Eine Meldung erscheint und Sie wissen möchten, was sie bedeutet |
| [Wie Sie um Hilfe bitten](wie-sie-um-hilfe-bitten.md) | Sie ein Problem jemand anderem beschreiben müssen |
| [Wen Sie anrufen](wen-sie-anrufen.md) | Sie wissen müssen, an wen Sie sich wenden, und es aufschreiben möchten, bevor Sie es brauchen |

## Die Gewohnheit in drei Schritten

1. **Anhalten und notieren**: die Uhrzeit, die Adresse der Seite, was Sie getan haben, die genaue Meldung.
2. **Das Einfache prüfen**: Ist es ein Entwurf, ein Cache, eine Berechtigung? ([Etwas sieht falsch aus](etwas-sieht-falsch-aus.md))
3. **Der richtigen Person Bescheid sagen**, mit Ihren Notizen ([Wie Sie um Hilfe bitten](wie-sie-um-hilfe-bitten.md)).

Wenn Sie ein Sicherheitsproblem bemerken, etwa Dinge sehen, die Sie nicht sehen dürften, veröffentlichen Sie es
nirgends: Sagen Sie es Ihrem Administrator oder melden Sie es vertraulich an das Projekt
([Sicherheitsprobleme](../../wenn-etwas-schiefgeht.md#sicherheitsprobleme)).

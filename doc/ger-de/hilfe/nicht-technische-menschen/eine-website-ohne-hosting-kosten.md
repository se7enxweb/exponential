# Eine Website ohne Hosting-Kosten

Normalerweise liegt eine Website auf einem gemieteten Computer, einem sogenannten Server, der den ganzen Tag läuft und
jeden Monat Geld kostet. Exponential kann es anders machen: Es macht eine Kopie Ihrer Website aus einfachen Seiten und
legt diese Kopie auf GitHub Pages, einen Dienst, der solche Seiten kostenlos der Welt zeigt.

## Was Sie am Ende haben

- Ihre Website online, mit einer Adresse, die Menschen besuchen können.
- Keine monatliche Rechnung für das Zeigen.
- Dieselbe Art, Seiten zu schreiben und zu ändern, wie bisher.

## Wie es funktioniert, in drei Schritten

1. **Sie schreiben** Ihre Seiten in Exponential, wie gewohnt.
2. **Sie drücken Bauen**: Exponential macht eine Kopie der Website aus einfachen Seiten.
3. **Sie drücken Veröffentlichen**: Die Kopie geht zu GitHub Pages, und Besucher sehen sie.

Wenn Sie es sich anders überlegen, können Sie mit einem Klick zu einer früheren Kopie zurück.

## Was jemand Technisches einmal einrichtet

- Ein kostenloses Konto bei GitHub, der Firma, die die Kopie hostet.
- Ein „Ziel“ in Exponential, das sagt, welche Website wohin geht. Ein Assistent stellt die Fragen.
- Wenn Sie eine eigene Adresse wie `www.mein-name.example` möchten, eine Einstellung dort, wo Sie den Namen gekauft haben.

Danach brauchen Sie diese Person für die tägliche Arbeit nicht.

## Was so eine Website nicht kann

- Zahlungen annehmen oder einen Shop betreiben.
- Seiten haben, die nur Mitglieder sehen.
- Besucher Kommentare hinterlassen lassen.

Ein Kontaktformular kann Ihnen in manchen Einrichtungen trotzdem Nachrichten schicken. Wenn Sie diese Dinge brauchen,
fragen Sie, ob [statisch zu Ihrer Website passt](../statisches-veroeffentlichen/passt-statisch-zu-meiner-website.md).

## Wörter, die Sie hören könnten

- **Statische Website**: eine Website nur aus fertigen Seiten; nichts wird berechnet, wenn jemand sie besucht.
- **GitHub Pages**: der kostenlose Dienst, der die Seiten zeigt.
- **Veröffentlichen**: die neueste Kopie online schicken.

Mehr: [Was statisches Veröffentlichen ist](../statisches-veroeffentlichen/was-statisches-veroeffentlichen-ist.md) und die
[Fragen und Antworten](../statisches-veroeffentlichen/faq.md).

## Die Idee in einem Satz

Alles auf einer Exponential-Website, von einer Seite oder einem Nachrichtenartikel bis zu einem Bild, einer Datei oder
sogar einem Benutzerkonto, ist ein **Inhalt** (das technische Wort ist *Objekt*), und die Objekte sind in einem
**Baum** angeordnet, wie Ordner auf einem Computer ([Erste Schritte](../../erste-schritte.md#was-exponential-ist)).

## Objekte haben einen Typ

Denken Sie an einen Stapel Papierformulare: einen Urlaubsantrag, eine Spesenabrechnung, eine Adressänderung. Jedes ist
eine andere Art von Formular mit eigenen Kästchen. Inhalte funktionieren genauso. Jeder hat einen **Inhaltstyp**
(technisch eine *Klasse*), etwa:

| Typ | Übliche Verwendung |
|---|---|
| **Ordner** | Enthält andere Objekte, wie eine Schublade; wird oft zu einem Menüeintrag |
| **Artikel** | Eine Nachricht, ein Blogbeitrag, eine Geschichte |
| **Bild** | Ein Bild, mit seinem Titel und Alternativtext |
| **Datei** | Ein Dokument zum Herunterladen: ein PDF, eine Tabelle |
| **Benutzer** | Das Konto eines Menschen |

Ihre Website hat vielleicht eigene Typen, zum Beispiel *Produkt*, *Veranstaltung* oder *Rezept*. Ein Website-Ersteller
legt sie an; Sie wählen zwischen ihnen, wenn Sie **Neu erstellen** drücken
([Inhalte erstellen und bearbeiten](../../inhalte-bearbeiten.md#ein-neues-objekt-erstellen)).

## Typen haben Felder

Die Kästchen auf dem Formular sind **Felder**: *Titel*, *Einleitung*, *Haupttext*, *Bild*, *Veröffentlichungsdatum*.
Beim Bearbeiten hat jedes Feld seinen eigenen Bereich, und ein roter Stern kennzeichnet die, die Sie ausfüllen müssen,
bevor Sie veröffentlichen können ([Das Bearbeitungsformular](../../inhalte-bearbeiten.md#das-bearbeitungsformular)). Wenn
Sie sich bei einem Typ ein weiteres Feld wünschen, zum Beispiel eine *Telefonnummer* bei einem *Standort*, ist das eine
Bitte an Ihren Website-Ersteller, nicht etwas, das Sie in den Text quetschen.

## Objekte leben in einem Baum

Der Reiter **Inhaltsstruktur** zeigt den Baum. Ganz oben steht die Startseite. Darunter liegen Ordner, die Artikel
enthalten, die wiederum Bilder enthalten können, und so weiter. Die linke Spalte zeigt denselben Baum, und Sie öffnen
Zweige, indem Sie auf die kleinen Dreiecke klicken.

```
Home
├── About us
│   ├── Our team
│   └── Contact
├── News
│   ├── Summer opening times
│   └── New website launched
└── Services
```

Auf den meisten Websites **ist** der Baum das Menü: Die Ordner unter *Home* werden zum Hauptmenü, und die Reihenfolge
der Objekte ist die Reihenfolge, die Sie sehen. [Wie ändere ich die Reihenfolge der Unterelemente?](../../handbuch/wie-aendere-ich-die-reihenfolge-der-unterelemente.md)
erklärt, wie Sie sie ändern. Bilder und Dokumente liegen meist in einem eigenen Teil des Baums, der **Medienbibliothek**
([Bilder, Medien und Uploads](../../medien-und-uploads.md#die-medienbibliothek)).

Die Objekte direkt innerhalb des Objekts, das Sie ansehen, sind seine **Unterelemente**. Dort steht die Schaltfläche
**Neu erstellen**: Ein neues Objekt legen Sie immer *innerhalb* von etwas an.

## Ein Objekt, zwei Orte

Ein Objekt kann an mehr als einer Stelle erscheinen, ohne kopiert zu werden. **Ort hinzufügen** im Menü **Weitere
Aktionen** einer Liste gibt ihm einen zweiten Ort ([Viele Objekte auf einmal](../../inhalte-bearbeiten.md#viele-objekte-auf-einmal)).
Ändern Sie es einmal, und beide Stellen zeigen die Änderung. Das ist etwas anderes als **Kopieren**, das ein zweites,
unabhängiges Objekt erzeugt.

## Was das für Sie bedeutet

- Um etwas zu ändern, **finden Sie zuerst das Objekt** im Baum oder mit der Suche ([Etwas finden](../erste-schritte/etwas-finden.md)).
- Um etwas hinzuzufügen, **gehen Sie zuerst an die Stelle**, an die es gehört, und drücken dann **Neu erstellen**.
- Steht ein Menüeintrag an der falschen Stelle, muss die **Reihenfolge der Unterelemente** geändert werden.
- Brauchen Sie ein Kästchen, das das Formular nicht hat, bitten Sie Ihren Website-Ersteller um ein **neues Feld**.

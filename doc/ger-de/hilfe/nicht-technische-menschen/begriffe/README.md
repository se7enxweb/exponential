# Begriffe erklärt

Das [Glossar](../glossar-fuer-nicht-technische-menschen.md) erklärt jedes Wort in ein oder zwei Sätzen. Die Seiten dieser Gruppe
nehmen sich die sieben wichtigsten Ideen vor und erklären jede gründlich, mit einem Vergleich aus dem Alltag, damit die
Bildschirme einen Sinn ergeben. Lesen Sie sie in dieser Reihenfolge; jede dauert fünf Minuten.

|---|---|

| [Entwürfe, Versionen und Veröffentlichen erklärt](entwuerfe-versionen-und-veroeffentlichen-erklaert.md) | Sie ändern eine Kopie; Besucher sehen sie erst, wenn Sie veröffentlichen, und die alte Kopie bleibt erhalten |

## Warum zuerst die Ideen

Menschen, die neu in einem Content-Management-System sind, kämpfen selten mit Schaltflächen. Sie kämpfen mit Fragen
wie "Warum zeigt die Website immer noch den alten Text?" (ein Cache oder ein Entwurf, der nie veröffentlicht wurde),
"Warum sieht meine Kollegin eine Schaltfläche, die ich nicht sehe?" (Rollen) oder "Wen rufe ich wegen der E-Mail an?"
(gar nicht Exponential). Jede Antwort ist eine der sieben Ideen oben.

## Der Vergleich: einen Brief schreiben

Sie schreiben einen Brief auf ein frisches Blatt Papier, lesen ihn durch und stecken ihn erst dann in den Umschlag.
Bis Sie ihn abschicken, liest ihn niemand sonst, und der letzte Brief, den Sie geschickt haben, bleibt in der Schublade
des Empfängers. Exponential funktioniert genauso: **Bearbeiten** gibt Ihnen ein frisches Blatt (einen **Entwurf**), und
die Website zeigt weiter die zuletzt veröffentlichte Version, bis Sie **Zur Veröffentlichung schicken** drücken. Die
alte Version kommt in eine Schublade (sie wird **archiviert**), und Sie können sie wieder herausholen
([Veröffentlichen, Versionen und der Papierkorb](../../veroeffentlichen-und-versionen.md#entwürfe-und-versionen)).

## Die vier Zustände einer Version

| Zustand | Im Vergleich mit dem Brief | Wer ihn sieht |
|---|---|---|
| **Entwurf** | Der Brief, den Sie gerade schreiben | Nur Sie |
| **Ausstehend** | Der Brief wartet auf die Unterschrift einer Kollegin | Sie und der Freigebende |
| **Veröffentlicht** | Der Brief, der abgeschickt wurde | Alle, die diese Seite sehen dürfen |
| **Archiviert** | Frühere Briefe in der Schublade | Redakteure, unter **Versionen verwalten** |

Ein Objekt hat immer genau eine veröffentlichte Version. Eine Website bewahrt pro Objekt nur eine begrenzte Zahl alter
Versionen auf; ist die Grenze erreicht, wird die älteste archivierte Version entfernt, um Platz zu schaffen
([Veröffentlichen, Versionen und der Papierkorb](../../veroeffentlichen-und-versionen.md#entwürfe-und-versionen)).

## Die drei Schaltflächen, auf die es ankommt

Oben im Bearbeitungsformular:

| Schaltfläche | Bedeutet |
|---|---|
| **Zur Veröffentlichung schicken** | Den Brief abschicken: Der Entwurf wird zur veröffentlichten Version |
| **Entwurf speichern und beenden** | Den unfertigen Brief in den Schreibtisch legen; später unter **Meine Entwürfe** auf dem Dashboard weitermachen |
| **Entwurf verwerfen** | Das Blatt zerreißen; die veröffentlichte Version bleibt genau so, wie sie war |

Der Entwurf wird beim Arbeiten alle paar Minuten automatisch gespeichert, ein geschlossener Browser-Tab kostet also
wenig ([Das Bearbeitungsformular](../../inhalte-bearbeiten.md#das-bearbeitungsformular)).

## Freigaben

Manche Websites verlangen, dass eine zweite Person zustimmt, bevor etwas online geht. Dann macht **Zur
Veröffentlichung schicken** Ihre Version **ausstehend**, und sie wird veröffentlicht, wenn der Freigebende zustimmt.
Ihre wartenden Versionen finden Sie unter **Meine Warteliste**
([Wie schicke ich Inhalte zur Freigabe?](../../handbuch/wie-sende-ich-inhalte-zur-freigabe.md)). Ob Ihre Website
Freigaben hat und für welche Teile, entscheidet Ihr Administrator.

## Warum das eine gute Nachricht ist

- Sie können **gefahrlos üben**: **Bearbeiten** öffnen, Dinge ausprobieren, **Entwurf verwerfen** drücken. Nichts ist
  geschehen.
- Sie können **in Etappen arbeiten**: heute beginnen, morgen fertigstellen.
- Sie können **zurückgehen**: Eine ältere Version lässt sich in einen neuen Entwurf verwandeln und erneut
  veröffentlichen ([Einen Fehler rückgängig machen](../erste-schritte/einen-fehler-rueckgaengig-machen.md)).
- Sie können **sehen, wer was geändert hat**, denn jede Version trägt ihren Autor und ihre Uhrzeit
  ([Wie finde ich heraus, wer was geändert hat?](../../handbuch/wie-finde-ich-heraus-wer-was-geaendert-hat.md)).

## Häufige Überraschungen

| Überraschung | Erklärung |
|---|---|
| "Ich habe es geändert, aber die Website zeigt den alten Text" | Der Entwurf wurde gespeichert, nicht veröffentlicht; sehen Sie unter **Meine Entwürfe** nach. Oder ein Cache zeigt noch die alte Seite ([Caches erklärt](caches-erklaert.md)). |
| "Es steht *Möglicher Bearbeitungs-Konflikt* da" | Sie oder eine Kollegin haben bereits einen Entwurf dieses Objekts ([Wenn jemand anderes bearbeitet](../../inhalte-bearbeiten.md#wenn-jemand-anderes-bearbeitet)). |
| "Ich kann nicht veröffentlichen, das Formular kommt rot zurück" | Ein Pflichtfeld ist leer oder falsch ausgefüllt; die Meldung sagt, welches. |
| "Mein neues Objekt ist verschwunden" | Ein neues Objekt, dessen Entwurf verworfen wird, entsteht nie. Beginnen Sie neu. |

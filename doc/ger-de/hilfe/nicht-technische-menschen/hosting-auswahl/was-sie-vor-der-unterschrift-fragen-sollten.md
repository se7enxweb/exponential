# Was Sie vor der Unterschrift fragen sollten

Sie müssen die Technik nicht verstehen, um ein Angebot zu beurteilen. Sie brauchen klare Antworten auf die richtigen
Fragen. Stellen Sie sie schriftlich und vergleichen Sie die Antworten nebeneinander.

## Aktualisierungen und Sicherheit

| Fragen Sie | Eine gute Antwort klingt so |
|---|---|
| Wer spielt neue Versionen und Sicherheitskorrekturen von Exponential ein? | "Wir, innerhalb von N Tagen nach einer Sicherheitsversion, und wir sagen Ihnen, was sich geändert hat." |
| Woran erkenne ich, dass ein Update funktioniert hat? | "Wir schicken Ihnen die neue Versionsnummer und bestätigen, dass Website und Administration funktionieren." ([Wie Updates funktionieren](../../kunden/gesund-halten/wie-updates-funktionieren.md#woran-sie-erkennen-dass-ein-update-funktioniert-hat)) |
| Haben Redakteure eine zweistufige Anmeldung? | "Ja, sie ist verfügbar, und wir können sie vorschreiben." ([Ihr Passwort und die zweistufige Anmeldung](../erste-schritte/ihr-passwort-und-die-zweistufige-anmeldung.md)) |

Exponential behebt Probleme nur in neuen Versionen; eine veröffentlichte Version wird danach nie mehr korrigiert.
"Aktuell zu bleiben ist also der Sicherheitsplan" ([Wie Updates funktionieren](../../kunden/gesund-halten/wie-updates-funktionieren.md#warum-sie-überhaupt-aktualisieren)).

## Sicherungen

| Fragen Sie | Eine gute Antwort klingt so |
|---|---|
| Was wird gesichert? | "Die Datenbank, die hochgeladenen Dateien und die Einstellungen." |
| Wie oft, und wohin? | "Täglich, an einen anderen Ort als den Server." |
| Wann wurde zuletzt eine Sicherung zum Test wiederhergestellt? | Ein Datum, und was wiederhergestellt wurde. |
| Kann ich eine Kopie bekommen? | "Ja, auf Anfrage." |

([Sicherungen](../../kunden/gesund-halten/backups.md))

## Eigentum

| Fragen Sie | Eine gute Antwort klingt so |
|---|---|
| Auf wessen Namen ist die Domain registriert? | "Auf Ihren." |
| Wem gehören die Inhalte und die Designarbeit? | "Ihnen." (Exponential selbst ist freie Software unter der GPL; niemand kann Ihnen eine Lizenz dafür verkaufen.) |
| Bekomme ich ein Administratorkonto? | "Ja." Auch wenn Sie es nie benutzen. |

([Was Ihnen gehört](../../kunden/was-ihnen-gehoert.md), [Lizenzen für Käufer](../../geschaeft/lizenzen-fuer-kaeufer.md))

## Support

| Fragen Sie | Eine gute Antwort klingt so |
|---|---|
| Wie melde ich ein Problem? | Ein klarer Kanal: eine E-Mail-Adresse, eine Telefonnummer oder ein Ticketformular. |
| Wann sind Sie erreichbar, und wie schnell antworten Sie? | Konkrete Zeiten und Fristen, in der Vereinbarung. |
| Was geschieht, wenn die Website nachts nicht erreichbar ist? | "Unsere Überwachung alarmiert uns, und ..." |
| Ist Hilfe für Redakteure enthalten? | Ein klares Ja oder Nein, und der Preis, wenn nein. |

Die [Vorlage für ein SLA](../../kunden/partner-und-hoster/sla-vorlage.md) zeigt, wie solche Zusagen festgehalten
werden.

## Datenschutz

| Fragen Sie | Eine gute Antwort klingt so |
|---|---|
| Wo stehen die Server und die Sicherungen? | Ein Land, und bei Bedarf der Name des Rechenzentrumsbetreibers. |
| Unterschreiben Sie einen Vertrag zur Auftragsverarbeitung? | "Ja." (Wenn Ihre Website über Formulare, einen Shop oder Mitglieder personenbezogene Daten erhebt.) |
| Wer in Ihrem Unternehmen kann unsere Daten sehen? | "Nur die Menschen, die es müssen, und sie sind zur Vertraulichkeit verpflichtet." |

## Ausstieg

| Fragen Sie | Eine gute Antwort klingt so |
|---|---|
| Was bekommen wir, wenn wir gehen? | "Einen vollständigen Export: Datenbank, Dateien, Einstellungen." |
| Wie schnell, und zu welchen Kosten? | Eine Anzahl von Tagen, und ein Preis oder "inbegriffen". |
| Was geschieht danach mit unseren Daten? | "Wir löschen sie und bestätigen es schriftlich." |

([Zu einem neuen Hoster wechseln](zu-einem-neuen-hoster-wechseln.md))

## Warnsignale

Seien Sie vorsichtig, wenn Sie hören:

- "Sie brauchen keine Updates, das läuft stabil." Jede Website braucht Updates.
- "Die Domain ist auf unseren Namen einfacher." Für Sie ist es nicht einfacher, wenn Sie gehen möchten.
- "Wir machen keine Wiederherstellungstests, die Sicherungen sind in Ordnung." Niemand weiß es, bevor getestet wird.
- "Das ist eine Lizenzgebühr für Exponential." Exponential hat keine Lizenzgebühr; fragen Sie, wofür das Geld
  wirklich ist.
- Antworten, die Sie auch nach zweimaligem Nachfragen nicht verstehen.

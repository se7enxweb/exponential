Diese Seite nennt keine Preise: Sie hängen davon ab, wo Sie sind und wen Sie beauftragen. Sie hilft Ihnen zu verstehen,

## Wofür Sie nie bezahlen

- **Eine Lizenz.** "Using Exponential under the terms of the GNU GPL is free of charge", also: Die Nutzung von
  Exponential unter den Bedingungen der GNU GPL ist kostenlos (`README.md`, "License"). Keine Gebühr pro Benutzer,
  pro Website, pro Jahr oder pro Funktion ([Wofür Sie nicht bezahlen](../../unternehmen/kosten/wofuer-sie-nicht-bezahlen.md)).
- **Die mitgelieferten Erweiterungen**, etwa Newsletter, Layouts oder zweistufige Anmeldung. Auch sie sind freie
  Software.
- **Diese Hilfe.** Sie ist freie Dokumentation ([Freie Dokumentation](../../freie-dokumentation.md)).

## Wofür Sie bezahlen

| Kostenposition | Bezahlt an | Form |
|---|---|---|
| Hosting | Hoster | Monatlich oder jährlich |
| Domainname | Registrierungsstelle | Jährlich |
| Aufbau der Website (Design, Einrichtung, Inhaltsmodell) | Entwickler oder Partner | Einmaliges Projekt |
| Aktualisierungen, Sicherungen, Überwachung | Hoster, Entwickler oder Partner | Monatliche Vereinbarung oder nach Stunden |
| Änderungen und neue Funktionen | Entwickler oder Partner | Pro Änderung, nach Stunden oder ein Budget |
| Externe Dienste: Zahlungsanbieter, Kartenanbieter, KI-Anbieter, Versand von Mails | Jeder Anbieter | Pro Nutzung oder monatlich |
| Die Zeit Ihres Teams | Sie | Stunden pro Monat |

| Vergleichen | Angebot A | Angebot B |
|---|---|---|

| Überwachung und Alarme in der Nacht? | | |
| Supportzeiten und Antwortfrist | | |
| Enthaltene Stunden für Änderungen pro Monat | | |
| Ausstieg: Export enthalten, wie schnell? | | |
| Preis pro Monat | | |
| Preis für eine zusätzliche Arbeitsstunde | | |

## Versteckte Kosten

- **Keine Aktualisierungen enthalten**: Dann wird jedes Update einzeln berechnet oder gar nicht gemacht.
- **Ihre eigene Zeit**: Eine günstige Website, die Ihre Abende kostet, ist nicht günstig.
- **Der Ausstieg**: eine Exportgebühr oder Arbeit, um eine Website umzuziehen, die niemand dokumentiert hat.
- **Externe Dienste**, die pro Nutzung abrechnen, etwa Zahlungen oder der Schreibassistent
  ([Den Schreibassistenten nutzen](../erste-schritte/den-schreibassistenten-nutzen.md#kosten-und-datenschutz)).

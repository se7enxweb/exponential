# Hosting-Auswahl

Sie müssen keinen Server betreiben, um eine Exponential-Website zu haben. Sie müssen wählen, **wer** sie betreibt, und
die richtigen Dinge schriftlich vereinbaren. Die Seiten dieser Gruppe helfen Ihnen dabei, ohne technisches Wissen.

## Der Rat in einem Satz

Wählen Sie die Menschen vor der Technik: Die richtige Frage ist nicht nur "Welche Technik ist die beste?", sondern
"Wer kann sie betreiben, sichern und wiederherstellen?" ([Hosting wählen](../../unternehmen/auswahl/hosting-auswaehlen.md)).

# Menschen ohne technische Vorkenntnisse: hier beginnen

Dieser Bereich ist für Menschen, die eine Exponential-Website nutzen oder betreuen, aber nicht technisch werden
möchten: die Büroleiterin, die die Öffnungszeiten aktualisiert, der Ehrenamtliche, der Vereinsnachrichten einstellt,
die Inhaberin eines kleinen Betriebs, die für die Website bezahlt, das Familienmitglied, das eine Fotoseite pflegt, das
Vorstandsmitglied, das einen Hosting-Vertrag unterschreiben muss.

Eine Kommandozeile finden Sie hier nicht. Jede Seite sagt, was Sie in Ihrem Webbrowser tun, was jemand anderes für Sie
tut (ein Hosting-Unternehmen, ein Entwickler oder ein Partner) und worum Sie diese Personen bitten.

> **Hinweis**
> Der Bereich beginnt mit Worten, nicht mit Schritten. Computer verwirren vor allem durch ihren Wortschatz. Lesen Sie
> zuerst das [Glossar](glossar-fuer-nicht-technische-menschen.md), oder halten Sie es in einem zweiten Tab offen: Alle anderen
> Seiten verwenden dieselben Wörter in derselben Bedeutung.

## Exponential in einfachen Worten

Exponential ist das Programm, das eine Website betreibt und es Menschen erlaubt, sie im Webbrowser zu ändern. Die
Dinge auf der Website, etwa eine Seite, ein Nachrichtenartikel, ein Bild oder ein Dokument, heißen **Inhalte**
(Inhaltsobjekte). Sie sind in einem **Baum** angeordnet, wie Ordner auf einem Computer. Sie ändern sie in der
**Administration** (manche Websites haben auch einen einfacheren **Editor**), und Besucher sehen sie auf der
**Website** ([Erste Schritte](../erste-schritte.md#was-exponential-ist)).

Drei Tatsachen machen einem nicht technischen Menschen das Leben leichter:

- **Nichts geht aus Versehen online.** Sie arbeiten immer an einem **Entwurf**. Die Website zeigt weiter die alte
  Version, bis Sie **Zur Veröffentlichung schicken** drücken
  ([Veröffentlichen, Versionen und der Papierkorb](../veroeffentlichen-und-versionen.md#entwürfe-und-versionen)).
- **Fehler lassen sich rückgängig machen.** Frühere Versionen werden aufbewahrt, und ein entferntes Objekt kommt zuerst
  in den **Papierkorb**, aus dem es zurückgeholt werden kann ([Einen Fehler rückgängig machen](erste-schritte/einen-fehler-rueckgaengig-machen.md)).
- **Die Software kostet keine Lizenzgebühr.** Exponential ist freie Software unter der GNU General Public License. Sie
  bezahlen für Hosting und für die Zeit von Menschen, nie für eine Lizenz
  ([Lizenzen für Käufer](../geschaeft/lizenzen-fuer-kaeufer.md)).

Die ausführlichere Fassung ist [Was Exponential ist, in einfachen Worten](was-exponential-ist-in-einfachen-worten.md).

## Was Sie tun und was Sie nie tun müssen

| Das tun Sie, im Browser | Das tut jemand Technisches für Sie |
|---|---|
| Anmelden, Text ändern, Bilder und Dokumente hinzufügen | Exponential auf einem Server installieren |
| Seiten veröffentlichen, verstecken, verschieben und entfernen | Aktualisierungen und Sicherheitskorrekturen einspielen |
| Eine Seite mit Blöcken anordnen, wenn Ihre Website Layouts verwendet | Sicherungen anlegen und prüfen, ob sie sich wiederherstellen lassen |
| Eine Seite übersetzen, wenn Ihre Website mehrere Sprachen hat | Domainname, E-Mail und HTTPS einrichten |
| Festlegen, wer in Ihrem Team was darf (wenn Sie der Administrator sind) | Die Design-Templates ändern und Erweiterungen hinzufügen |

Exponential zu installieren und zu aktualisieren erfordert normalerweise eine Kommandozeile und ein Werkzeug namens
Composer, auf einem Server, der die Anforderungen erfüllt
([Anforderungen auf einen Blick](../hosting/grundlagen/anforderungen-auf-einen-blick.md)); ein Einrichtungsassistent im Browser
schließt die Installation ab, sobald die Dateien da sind. Deshalb sagt dieser Bereich offen, dass die Installation
Aufgabe eines Hosting-Unternehmens, eines Entwicklers oder eines Partners ist, und hilft Ihnen, eine solche Stelle zu
wählen. Einzelheiten stehen unter [Was Sie nie tun müssen](was-sie-nie-tun-muessen.md).

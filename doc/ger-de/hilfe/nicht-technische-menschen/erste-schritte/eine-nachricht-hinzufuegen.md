## Bevor Sie beginnen

- Wissen Sie, **wo** Nachrichten auf Ihrer Website liegen: meist in einem Ordner namens *News*, *Blog* oder *Aktuelles*.
  Ein neues Objekt legen Sie immer *innerhalb* der Stelle an, an die es gehört
  ([Inhalte und der Baum](../begriffe/inhalte-und-der-baum.md)).
- Halten Sie den Text und, wenn Sie möchten, ein Bild bereit.

## Schritte

1. Öffnen Sie **Inhaltsstruktur** und klicken Sie auf den Ordner für Nachrichten.
2. Drücken Sie unter **Unterelemente** auf **Neu erstellen**. Eine Liste der Inhaltstypen öffnet sich, die Sie hier
   anlegen dürfen.
3. Wählen Sie **Artikel** (Ihre Website nennt ihn vielleicht *Nachricht*, *Blogbeitrag* oder ähnlich). Ein leeres
   Formular öffnet sich ([Ein neues Objekt erstellen](../../inhalte-bearbeiten.md#ein-neues-objekt-erstellen)).
4. Füllen Sie den **Titel** aus. Halten Sie ihn kurz und klar; oft wird er auch zur Webadresse der Seite.
5. Füllen Sie die **Einleitung** aus: ein oder zwei Sätze, die Lust aufs Weiterlesen machen. Nachrichtenlisten zeigen
   oft nur diese.
6. Füllen Sie den **Haupttext** aus: den vollständigen Text.
7. Fügen Sie ein Bild hinzu, wenn das Formular ein Feld *Bild* hat: Drücken Sie **Neu hochladen**, um eines von Ihrem
   Computer zu nehmen, oder **Vorhandenes hinzufügen**, um eines aus der Medienbibliothek zu wählen
   ([Ein Bild hinzufügen](ein-bild-hinzufuegen.md)).
8. Drücken Sie **Vorschau** zur Kontrolle, dann **Zur Veröffentlichung schicken**.

Das neue Objekt erscheint nun im Ordner für Nachrichten und auf den meisten Websites in der Nachrichtenliste und auf der
Startseite.

## Eine gute Nachricht schreiben

| Teil | Tipp |
|---|---|
| Titel | Sagt, was geschehen ist, in weniger als zehn Wörtern |
| Einleitung | Beantwortet wer, was und wann in ein oder zwei Sätzen |
| Haupttext | Das Wichtigste zuerst; kurze Absätze; Überschriften bei längeren Texten |
| Bild | Ihr eigenes oder ordentlich lizenziert, mit einem Alternativtext |
| Links | Zu der Seite, auf der Leser handeln können: anmelden, kaufen, weiterlesen |

## Später veröffentlichen

- **Entwurf speichern und beenden** behält es als Entwurf, nur für Sie sichtbar, unter **Meine Entwürfe**.
- Manche Websites können zu einem festen Datum und einer festen Uhrzeit veröffentlichen. Ob Ihre das kann und wie, hängt
  davon ab, wie sie eingerichtet wurde ([Zeitgesteuertes Veröffentlichen](../../kunden/alltag/zeitgesteuertes-veroeffentlichen.md)).
- Verwendet Ihre Website Freigaben, schickt **Zur Veröffentlichung schicken** es zuerst an den Freigebenden.

## Wenn es nicht funktioniert

| Was Sie sehen | Was Sie tun |
|---|---|
| **Neu erstellen** fehlt | Sie dürfen hier keine Objekte anlegen. Prüfen Sie, ob Sie im richtigen Ordner sind, oder fragen Sie Ihren Administrator. |
| *Artikel* steht nicht in der Liste | Dieser Ordner nimmt nur andere Typen an. Verwenden Sie den Ordner für Nachrichten. |
| Das Formular kommt rot zurück | Ein Pflichtfeld ist leer; die Meldung sagt, welches. |
| Das Objekt ist nicht auf der Startseite | Die Startseite zeigt vielleicht nur einige Nachrichten, oder ein Cache zeigt die alte Seite ([Caches erklärt](../begriffe/caches-erklaert.md)). |
| Sie haben es im falschen Ordner angelegt | Verwenden Sie **Verschieben** auf der Seite des Objekts ([Verschieben, kopieren und entfernen](../../inhalte-bearbeiten.md#verschieben-kopieren-und-entfernen)). |

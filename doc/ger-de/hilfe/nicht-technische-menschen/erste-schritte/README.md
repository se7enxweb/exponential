# Erste Schritte

Jede Seite dieser Gruppe ist eine Aufgabe, in nummerierten Schritten, im Browser, ohne Fachwörter. Jede Seite sagt
auch, was schiefgehen kann und was Sie dann tun, und verlinkt auf die ausführliche Seite für Redakteure, wenn Sie mehr
Einzelheiten möchten.

> **Tipp**
> Üben Sie zuerst auf einer Testseite. Legen Sie einen Artikel in einem Ordner an, den niemand besucht, ändern Sie ihn,
> veröffentlichen Sie ihn, machen Sie es rückgängig und entfernen Sie ihn. Zehn Minuten Übung machen die echte Aufgabe
> entspannt. Fragen Sie Ihren Administrator, wo Sie üben dürfen.

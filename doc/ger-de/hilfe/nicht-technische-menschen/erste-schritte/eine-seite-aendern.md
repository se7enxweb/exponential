# Eine Seite ändern

Die häufigste Aufgabe überhaupt: Etwas auf der Website ist veraltet, und Sie bringen es in Ordnung.

## Inhalt

1. [Bevor Sie beginnen](#bevor-sie-beginnen)

## Bevor Sie beginnen

Halten Sie den neuen Text bereit, am besten zuerst in einem einfachen Dokument geschrieben. Aus einer Textverarbeitung
zu kopieren funktioniert, aber halten Sie die Formatierung einfach: Überschriften, Fett, Listen und Links.

## Schritte

1. **Finden Sie die Seite.** Öffnen Sie **Inhaltsstruktur** und klicken Sie sich durch den Baum, oder tippen Sie ein
   Wort von der Seite in **Suchen...** ([Etwas finden](etwas-finden.md)). Klicken Sie auf den Namen der Seite.
2. **Drücken Sie Bearbeiten.** Gibt es die Seite in mehreren Sprachen, wählen Sie zuerst die Sprache in der Liste neben
   **Bearbeiten**. Das Bearbeitungsformular öffnet sich mit einem **Entwurf**: einer Kopie, die nur Sie sehen
   ([Entwürfe, Versionen und Veröffentlichen erklärt](../begriffe/entwuerfe-versionen-und-veroeffentlichen-erklaert.md)).
3. **Finden Sie das Feld.** Die Leiste oben im Formular hat eine Schaltfläche pro Feld (*Titel*, *Einleitung*,
   *Haupttext* ...); ein Klick springt zu diesem Feld ([Das Bearbeitungsformular](../../inhalte-bearbeiten.md#das-bearbeitungsformular)).
4. **Nehmen Sie Ihre Änderung vor.**
5. **Sehen Sie hin, bevor Sie veröffentlichen.** **Vorschau** in der linken Spalte zeigt den Entwurf so, wie er
   aussehen wird.
6. **Drücken Sie Zur Veröffentlichung schicken.** Auf den meisten Websites ist die Änderung sofort auf der Website.
   Verwendet Ihre Website Freigaben, wartet sie unter **Meine Warteliste**, bis jemand sie freigibt.
7. **Prüfen Sie die Website.** Öffnen Sie die Seite auf der öffentlichen Website. Sehen Sie noch den alten Text, siehe
   [Caches erklärt](../begriffe/caches-erklaert.md#wenn-sie-eine-alte-seite-sehen).

## Im Textfeld arbeiten

Lange Textfelder (formatierter Text) haben eine kleine Werkzeugleiste: Absatzformate, Fett, Kursiv, Listen, Links,
Tabellen, Bilder und **Fullscreen** (Vollbild) ([Rich Text](../../inhalte-bearbeiten.md#rich-text)). Gute Gewohnheiten:

- Verwenden Sie für Überschriften die **Absatzformate**, statt Text groß und fett zu machen. Screenreader und
  Suchmaschinen verstehen echte Überschriften.
- Halten Sie Absätze kurz.
- Schreiben Sie Linktexte, die sagen, wohin sie führen ("unsere Öffnungszeiten"), nie "hier klicken".

Die Eingabetaste in einem einzeiligen Feld (etwa *Titel*) wirkt wie **Zur Veröffentlichung schicken**. In einem langen
Textfeld erzeugt die Eingabetaste wie gewohnt einen neuen Absatz.

## Noch nicht fertig?

- **Entwurf speichern und beenden** bewahrt Ihren Entwurf auf. Machen Sie später unter **Meine Entwürfe** auf dem
  Dashboard weiter.
- **Entwurf verwerfen** wirft Ihre Änderung weg; die veröffentlichte Seite bleibt genau so, wie sie war.
- Der Entwurf wird beim Tippen alle paar Minuten automatisch gespeichert, ein geschlossener Browser-Tab kostet also
  wenig.

## Wenn es nicht funktioniert

| Was Sie sehen | Was Sie tun |
|---|---|
| Das Formular kommt mit einer roten Meldung zurück | Ein Pflichtfeld (roter Stern) ist leer oder ein Wert ist falsch. Die Meldung oben und am Feld sagt, welches. |
| *Möglicher Bearbeitungs-Konflikt* | Sie oder eine Kollegin haben bereits einen Entwurf. Machen Sie mit **Ihrem** Entwurf weiter oder beginnen Sie einen **Neuen Entwurf** ([Wenn jemand anderes bearbeitet](../../inhalte-bearbeiten.md#wenn-jemand-anderes-bearbeitet)). |
| **Bearbeiten** ist ausgegraut | Ihre Rolle darf diese Seite nicht ändern. Fragen Sie Ihren Administrator. |
| Die Änderung ist nicht auf der Website | Wurde sie veröffentlicht, oder ist sie ausstehend? Sonst ein Cache ([Caches erklärt](../begriffe/caches-erklaert.md)). |
| Sie haben etwas Falsches veröffentlicht | Kehren Sie zur vorherigen Version zurück ([Einen Fehler rückgängig machen](einen-fehler-rueckgaengig-machen.md)). |

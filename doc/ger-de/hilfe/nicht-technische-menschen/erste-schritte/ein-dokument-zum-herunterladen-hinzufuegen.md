## Wie Dateien funktionieren

Wie ein Bild wird ein Dokument, das Sie hochladen, zu einem eigenen Objekt, meist vom Typ *Datei*
([Bilder, Medien und Uploads](../../medien-und-uploads.md)). Das Objekt hat einen **Titel**, den Besucher oft als
Linktext sehen, und eine eigene Seite mit einem Download-Link. Weil es ein Objekt ist, lässt es sich wie jedes andere
ersetzen, verstecken, verschieben und mit der Suche finden.

## Schritte

1. Klicken Sie auf **Medien** und öffnen Sie den Ordner **Dateien** (oder den Ordner, den Ihre Website für Dokumente
   verwendet). Sie können auch in einen normalen Ordner neben der Seite hochladen, die die Datei verwendet.
2. Drücken Sie **Hochladen** (oder **Dateien hochladen** auf dem Dashboard).
3. Drücken Sie **Choose files...** (Dateien wählen) oder ziehen Sie die Datei auf die gestrichelte Fläche.
4. Ändern Sie den **Titel** vom Dateinamen (`jahresbericht-final-v3.pdf`) zu etwas, das Menschen verstehen
   (*Jahresbericht 2025*).
5. Drücken Sie **Upload all** (alle hochladen).

## Von einer Seite darauf verlinken

1. Bearbeiten Sie die Seite, die den Download anbieten soll.
2. Markieren Sie die Wörter, die zum Link werden, zum Beispiel *Den Jahresbericht herunterladen (PDF)*.
3. Drücken Sie **Insert/edit link** (Link einfügen/bearbeiten), dann **Durchsuchen**, und wählen Sie das Dateiobjekt.
4. Drücken Sie **Insert** (Einfügen), dann **Zur Veröffentlichung schicken**.

Wenn Sie die Datei mit **Durchsuchen** wählen, statt ihre Adresse einzutippen, funktioniert der Link weiter, wenn die
Datei verschoben wird ([Wie füge ich im Online-Editor einen Link ein?](../../handbuch/wie-fuege-ich-im-online-editor-einen-link-ein.md)).

## Durch eine neuere Version ersetzen

Laden Sie die neue Version nicht als zweite Datei hoch und entfernen die alte: Links an anderen Stellen würden
brechen. Stattdessen:

1. Öffnen Sie das vorhandene Dateiobjekt und drücken Sie **Bearbeiten**.
2. Wählen Sie im Dateifeld die neue Datei auf Ihrem Computer.
3. Passen Sie bei Bedarf den Titel an (*Jahresbericht 2025, überarbeitet*).
4. Drücken Sie **Zur Veröffentlichung schicken**.

Jeder Link zeigt weiter auf dasselbe Objekt, das nun die neue Datei anbietet. Die alte Datei bleibt in den Versionen des
Objekts, falls Sie sie zurückbrauchen ([Einen Fehler rückgängig machen](einen-fehler-rueckgaengig-machen.md)).

## Bewährte Vorgehensweise

- Nennen Sie **Typ und Größe** im Linktext: *Preisliste (PDF, 1 MB)*.
- Bevorzugen Sie **PDF** für Dokumente, die gelesen werden, und das Originalformat nur für Formulare, die ausgefüllt
  werden.
- Machen Sie PDFs barrierefrei, wo Sie können: echte Überschriften, Text statt eingescannter Bilder
  ([Checkliste zur Barrierefreiheit in einfachen Worten](../checklisten/barrierefreiheit-in-einfachen-worten.md)).
- Entfernen Sie veraltete Dokumente oder kennzeichnen Sie sie deutlich als archiviert.
- Laden Sie nie Dokumente mit personenbezogenen Daten hoch, die nicht öffentlich sein sollen; eine Datei auf der
  öffentlichen Website kann jeder finden.

## Wenn es nicht funktioniert

| Was Sie sehen | Was Sie tun |
|---|---|
| Die Datei ist zu groß | Die Upload-Seite zeigt die Grenze. Fragen Sie Ihren Administrator, ob sie angehoben werden kann, oder verkleinern Sie die Datei |
| Der Typ ist nicht erlaubt | Ihre Website nimmt nur bestimmte Dateitypen an. Speichern Sie als PDF, oder fragen Sie Ihren Administrator |
| Besucher können sie nicht herunterladen | Die Datei liegt vielleicht in einem versteckten Teil oder einem Bereich nur für Mitglieder. Prüfen Sie ihre Sichtbarkeit und Sektion |

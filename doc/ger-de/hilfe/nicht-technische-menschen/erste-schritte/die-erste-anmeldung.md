## Was Sie brauchen

- **Die Adresse** der Administration oder des Editors. Ihr Administrator gibt sie Ihnen. Sie sieht oft so aus:
  `https://www.example.com/admin`, `https://www.example.com/editor` oder `https://edit.example.com`
  ([Die Website und die Administration](../begriffe/die-website-und-die-administration.md)).
- **Ihren Benutzernamen** (viele Websites akzeptieren auch Ihre E-Mail-Adresse) und **Ihr Passwort**.
- Bei manchen Websites **Ihr Telefon** mit einer Authenticator-App oder Zugriff auf Ihre E-Mails, für die zweistufige
  Anmeldung.

## Schritte

1. Öffnen Sie die Adresse in Ihrem Browser. Setzen Sie jetzt ein Lesezeichen, damit Sie nie wieder danach suchen müssen.
2. Tippen Sie Ihren **Benutzernamen** (oder Ihre E-Mail-Adresse).
3. Tippen Sie Ihr **Passwort**. Die Schaltfläche mit dem Auge im Feld zeigt, was Sie getippt haben; drücken Sie sie
   erneut, um es zu verbergen.
4. Drücken Sie **Anmelden** oder die Eingabetaste.
5. Sie sehen das **Dashboard** mit einer Begrüßung und Ihrem Namen. Sie sind drin
   ([Anmelden im Editor](../../anmelden-im-editor.md#nach-der-anmeldung)).

Wenn Sie ein vorläufiges Passwort erhalten haben, ändern Sie es jetzt: Öffnen Sie **Passwort ändern** im
Benutzermenü oder unter **Mein Konto** ([Ihr Passwort und die zweistufige Anmeldung](ihr-passwort-und-die-zweistufige-anmeldung.md)).

## Wenn die Website nach einem Code fragt

Manche Websites verwenden die **zweistufige Anmeldung**. Nach Ihrem Passwort fragt eine Seite **Confirm it is you**
(Bestätigen Sie, dass Sie es sind) nach einem sechsstelligen Code:

- aus der **Authenticator-App** auf Ihrem Telefon oder
- aus einer **E-Mail**, die die Website Ihnen gerade geschickt hat (der Code steht auch in der Betreffzeile).

Tippen Sie ihn ein und drücken Sie **Verify and sign in** (prüfen und anmelden). Leerzeichen im Code sind in Ordnung.
Jeder Code funktioniert einmal. Verlangt die Website die zweistufige Anmeldung von allen und Sie haben sie noch nicht
eingerichtet, führt sie Sie direkt nach Ihrem Passwort durch die Einrichtung
([Zweistufige Anmeldung](../../konten-und-anmeldung.md#zweistufige-anmeldung)).

## Wenn es nicht funktioniert

| Was Sie sehen | Was es bedeutet | Was Sie tun |
|---|---|---|
| *Das System konnte Sie nicht anmelden ...* | Benutzername oder Passwort passen nicht | Schreibweise und Feststelltaste prüfen; statt des Benutzernamens die E-Mail-Adresse versuchen |
| *... zulässige Anzahl fehlgeschlagener Anmeldeversuche überschritten* | Zu viele falsche Passwörter; das Konto ist gesperrt | Bitten Sie Ihren Administrator, es zu entsperren ([Wie deaktiviere oder entsperre ich ein Benutzerkonto?](../../handbuch/wie-deaktiviere-oder-entsperre-ich-ein-benutzerkonto.md)) |
| *Zugriff verweigert!* | Ihr Konto ist in Ordnung, aber Ihre Rolle darf diese Tür nicht benutzen | Fragen Sie Ihren Administrator; vielleicht sollten Sie die Adresse des Editors verwenden |
| Ein kleines Browserfenster fragt nach Name und Passwort, bevor die Seite erscheint | Ein zusätzliches Passwort auf einem Testserver; nicht Ihr Exponential-Konto | Fragen Sie die Person, die Ihnen die Adresse gegeben hat |
| Nach dem Anmelden landen Sie wieder im Anmeldeformular | Ihr Browser blockiert Cookies | Erlauben Sie Cookies für die Website oder versuchen Sie ein privates Fenster |
| Ein gelbes Banner **Demo-Modus** | Eine öffentliche Testwebsite | Zum Ausprobieren in Ordnung; geben Sie nie etwas Privates ein ([Demomodus](../../demomodus.md)) |

**Passwort vergessen?** Wählen Sie **Passwort vergessen?** unter der Schaltfläche, geben Sie Ihre E-Mail-Adresse ein und
folgen Sie dem Link in der Mail. Der Link funktioniert einmal und standardmäßig eine Stunde lang. Keine Mail? Sehen Sie
im Spamordner nach ([Passwort vergessen?](../../anmelden-im-editor.md#passwort-vergessen)).

## Abmelden

Drücken Sie die letzte Schaltfläche am rechten Ende der Kopfzeile: einen Pfeil, der aus einem Kasten zeigt
(**Abmelden**). Während Sie bearbeiten, ist sie ausgegraut; speichern oder verwerfen Sie zuerst Ihren Entwurf. Melden
Sie sich an einem gemeinsam genutzten Computer immer ab ([Erste Schritte](../../erste-schritte.md#5-abmelden)).

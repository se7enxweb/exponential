## Warum das wichtig ist

Wer Ihre Anmeldung hat, kann die Website Ihrer Organisation in Ihrem Namen ändern. Zwei einfache Schritte machen das
sehr unwahrscheinlich: ein Passwort, das niemand erraten kann, und ein zweiter Schritt, der Ihr Telefon oder Ihre
E-Mail braucht.

## Ihr Passwort ändern

1. Öffnen Sie **Passwort ändern** (im Benutzermenü, auf dem Dashboard oder unter **Mein Konto**).
2. Geben Sie Ihr **Aktuelles Passwort** ein, dann zweimal das **Neue Passwort**. Die Seite sagt, was ein neues Passwort
   braucht, zum Beispiel *mindestens 10 Zeichen*, und prüft es beim Tippen.
3. Drücken Sie **Passwort ändern**.

**Sicheres Passwort erzeugen** erstellt eines für Sie, und **Anzeigen** zeigt, was Sie getippt haben
([Ihr Passwort ändern](../../konten-und-anmeldung.md#ihr-passwort-ändern)).

## Ein gutes Passwort

- **Lang** schlägt kompliziert: Vier oder fünf Wörter, die nichts miteinander zu tun haben, ergeben ein starkes
  Passwort.
- **Einmalig**: nie dasselbe wie für E-Mail, Bank oder soziale Medien.
- **In einem Passwortmanager gespeichert**, nicht auf einem Zettel am Bildschirm. Ein Passwortmanager ist eine App, die
  sich Ihre Passwörter für Sie merkt; viele sind kostenlos.

Die Website lehnt kurze und bekannte Passwörter ab ([Ihr Konto schützen](../../anmelden-im-editor.md#ihr-konto-schützen)).

## Die zweistufige Anmeldung einschalten

Mit der zweistufigen Anmeldung öffnet Ihr Passwort allein Ihr Konto nicht mehr: Danach fragt die Anmeldung nach einem
sechsstelligen Code ([Zweistufige Anmeldung](../../konten-und-anmeldung.md#zweistufige-anmeldung)).

1. Öffnen Sie **Mein Konto** und drücken Sie auf der Karte **Zweistufige Anmeldung** auf **Einschalten**.
2. Wählen Sie, wie Sie bestätigen, dass Sie es sind:
   - **Authenticator app (TOTP)**: ein Code aus einer App auf Ihrem Telefon, etwa Google Authenticator, Microsoft
     Authenticator, Authy oder 1Password. Funktioniert ohne Netz. Empfohlen.
   - **E-mail one-time code** (Einmalcode per E-Mail): Bei jeder Anmeldung wird ein Code an Ihre E-Mail-Adresse
     geschickt.
3. Für die App: Fügen Sie in der App ein Konto hinzu und scannen Sie den quadratischen Code (QR-Code) auf dem
   Bildschirm. Tippen Sie den Code, den die App zeigt, in **Enter the code the app shows** (den Code eingeben, den die
   App zeigt).
4. Drücken Sie **Save settings** (Einstellungen speichern). Es gilt ab Ihrer nächsten Anmeldung.

Jeder Code funktioniert einmal, und der Code einer App wechselt alle 30 Sekunden. Manche Websites verlangen die
zweistufige Anmeldung von allen und bitten Sie, sie bei Ihrer ersten Anmeldung einzurichten.

## Telefon verloren?

Fragen Sie Ihren Administrator. Er kann Ihr Konto auf Codes per E-Mail umstellen oder den zweiten Schritt abschalten;
Sie melden sich dann an und richten die App auf Ihrem neuen Telefon erneut ein
([Wie sich ein Benutzer anmeldet, der sein Telefon verloren hat](../../handbuch/telefon-verloren-wie-meldet-sich-ein-benutzer-an.md)).

## Fünf Gewohnheiten

1. Verwenden Sie **Ihr eigenes Konto**, nie ein gemeinsames.
2. **Schicken Sie Ihr Passwort nie** per E-Mail oder Chat, auch nicht an einen Administrator; niemand braucht es.
3. **Melden Sie sich** an gemeinsam genutzten Computern **ab**.
4. Seien Sie misstrauisch bei E-Mails, die Sie bitten, über einen Link "Ihr Passwort zu bestätigen". Öffnen Sie die
   Administration stattdessen über Ihr eigenes Lesezeichen.
5. Sagen Sie Ihrem Administrator sofort Bescheid, wenn Sie glauben, dass jemand anderes Ihr Passwort kennt.

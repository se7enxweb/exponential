## Zwei Arten von Links

| Link zu | Wie | Warum |
|---|---|---|
| Einer Seite **Ihrer eigenen Website** | Wählen Sie sie mit **Durchsuchen** | Der Link folgt der Seite, wenn sie verschoben oder umbenannt wird |
| **Einer anderen Website** | Tippen Sie ihre vollständige Adresse, beginnend mit `https://` | Die andere Website entscheidet, ob ihre Adresse gültig bleibt |

([Wie füge ich im Online-Editor einen Link ein?](../../handbuch/wie-fuege-ich-im-online-editor-einen-link-ein.md))

## Schritte

1. Bearbeiten Sie die Seite und markieren Sie die Wörter, die zum Link werden.
2. Drücken Sie **Insert/edit link** (Link einfügen/bearbeiten) in der Werkzeugleiste.
3. Für eine Seite Ihrer Website drücken Sie **Durchsuchen** und wählen das Objekt. Für eine andere Website tippen oder
   fügen Sie ihre Adresse ein.
4. Wählen Sie, wenn Sie möchten, das Öffnen in einem neuen Fenster, und geben Sie dem Link einen Titel.
5. Drücken Sie **Insert** (Einfügen).
6. Drücken Sie **Zur Veröffentlichung schicken**.

Die Adresse einer Ihrer eigenen Seiten einzutippen funktioniert auch, bricht aber, wenn diese Seite verschoben wird.
Verwenden Sie **Durchsuchen**.

## Guten Linktext schreiben

Die Wörter, die Sie zum Link machen, sollten sagen, wohin der Link führt, auch wenn sie für sich allein gelesen werden.
Screenreader-Nutzer springen oft von Link zu Link und hören nur den Linktext.

| Schwach | Besser |
|---|---|
| Für unsere Öffnungszeiten **hier klicken** | Sehen Sie unsere **Öffnungszeiten** |
| **Mehr** | **Mehr über das Sommerfest** |
| **https://www.example.org/forms/2025/membership.pdf** | **Mitgliedsantrag (PDF)** |

Öffnen Sie andere Websites im selben Fenster, es sei denn, es gibt einen guten Grund dagegen; Besucher wissen, wie sie
zurückgehen.

## Einen Link entfernen

Setzen Sie den Cursor in den Link und drücken Sie **Unlink** (Link entfernen) in der Werkzeugleiste, dann
veröffentlichen Sie.

## Defekte Links

Andere Websites ändern ihre Adressen, und ein Link, der letztes Jahr funktioniert hat, führt jetzt vielleicht ins
Leere. Wenn Ihre Rolle es erlaubt, listet **Setup > URL-Verwaltung** Links auf, die fehlschlagen
([Wie finde und behebe ich defekte Links?](../../handbuch/wie-finde-und-repariere-ich-defekte-links.md)). Andernfalls bitten Sie
Ihren Administrator, einmal im Monat nachzusehen; das steht auf der
[Monatlichen Checkliste für Website-Verantwortliche](../checklisten/monatlich-fuer-website-verantwortliche.md).

# Eine Seite mit Layouts gestalten

**Exponential Layouts** ist ein visueller Seitenbaukasten. Statt eines langen Texts besteht eine Seite aus **Blöcken**
(ein Titel, ein Text, ein Bild, eine Liste von Nachrichten, eine Galerie), die in **Zonen** liegen (Bereiche wie
links, rechts, Kopf, Hauptteil). Er wird für Startseiten und Kampagnenseiten verwendet ([Der Layout-Editor](../../layout-editor.md)).

> **Hinweis**
> Nicht jede Website verwendet Layouts, und nicht jede Rolle darf sie ändern. Der Reiter **Layouts** erscheint nur für
> Rollen, die mit Layouts arbeiten dürfen. Sehen Sie ihn nicht, fragen Sie Ihren Administrator.

Der Layout-Editor zeigt seine Schaltflächen auf Englisch; diese Seite nennt sie so, wie sie dort stehen.

## Die Teile des Editors

- **Oben**: der Name des Layouts, **Discard** (verwerfen), **Cancel** (abbrechen) und **Publish layout** (Layout
  veröffentlichen).
- **Links**: die Plus-Schaltfläche **Add a block** (einen Block hinzufügen).
- **In der Mitte**: die Zonen und ihre Blöcke, ungefähr so, wie die Seite aussehen wird.
- **Rechts**: die Einstellungen des Blocks, den Sie angeklickt haben.

Sie arbeiten immer an einem **Entwurf** des Layouts; die Website zeigt weiter das veröffentlichte, bis Sie
veröffentlichen, genau wie bei Artikeln ([Entwürfe, Versionen und Veröffentlichen erklärt](../begriffe/entwuerfe-versionen-und-veroeffentlichen-erklaert.md)).

## Schritte: einen Block hinzufügen

1. Öffnen Sie **Layouts**, dann **Layouts**, und drücken Sie **Open** (öffnen) neben dem Layout Ihrer Seite.
2. Drücken Sie **Add a block** (das Plus). Die Blocktypen erscheinen in Gruppen wie **Basic** (Title, Text, Button /
   Link, Rich text, Image), **Listing** und **Gallery**.
3. Ziehen Sie einen Blocktyp in eine Zone, an die Stelle, an die er gehört.
4. Klicken Sie auf den neuen Block. Rechts enthält der Reiter **Content** (Inhalt), was er zeigt (den Text eines
   Titels, welche Objekte eine Liste zeigt und wie viele); der Reiter **Design** enthält, wie er aussieht.
5. Prüfen Sie den mittleren Bereich: Er zeigt Ihre Änderung.

([Einen Block hinzufügen](../../layout-editor.md#einen-block-hinzufügen))

## Einen Block ändern, verschieben oder löschen

- **Ändern**: Klicken Sie ihn an und bearbeiten Sie rechts seine Einstellungen.
- **Verschieben**: Ziehen Sie ihn an seinem Griff an eine andere Stelle oder in eine andere Zone.
- **Kopieren oder löschen**: Das Menü mit drei Punkten am Block hat **Duplicate block** (Block duplizieren) und
  **Delete block** (Block löschen).

## Veröffentlichen oder für später aufheben

| Schaltfläche | Was sie tut |
|---|---|
| **Publish layout** | Veröffentlicht und schließt den Editor. Die Seite zeigt die Änderung sofort |
| **Publish and continue editing** (Menü mit drei Punkten oben) | Veröffentlicht und lässt den Editor offen |
| **Save draft and close** (dasselbe Menü) | Bewahrt Ihren Entwurf für später auf; die Seite bleibt unverändert |
| **Discard** | Wirft Ihren Entwurf nach einer Bestätigung weg |

Fragt der Editor, ob nach dem Veröffentlichen Caches geleert werden sollen, wählen Sie **Clear caches** (Caches
leeren), damit Besucher die Änderung sehen.

## Was Sie einem Website-Ersteller überlassen

- **Regeln** (Zuordnungen) entscheiden, welche Seiten welches Layout verwenden. Sie zu ändern kann ganze Teile der
  Website verändern ([Welche Seiten ein Layout verwenden](../../layout-editor.md#welche-seiten-ein-layout-verwenden)).
- **Gemeinsame Layouts** enthalten Kopf- und Fußbereich vieler Seiten; eine Änderung dort ändert sie alle.
- Neue Layouts mit einem neuen **Layouttyp**.

Im Zweifel: Ändern Sie Blöcke, nicht Regeln.

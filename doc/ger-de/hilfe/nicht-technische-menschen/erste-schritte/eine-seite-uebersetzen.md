# Eine Seite übersetzen

Auf einer Website mit mehr als einer Sprache kann jede Seite in jeder Sprache existieren. Eine Übersetzung wird getrennt
bearbeitet und veröffentlicht, sodass die deutsche Seite fertig sein kann, während die spanische noch ein Entwurf ist
([Sprachen](../../sprachen.md)).

## Bevor Sie beginnen

- Auf Ihrer Website muss die Sprache bereits eingerichtet sein. Einer Website eine ganz neue Sprache hinzuzufügen ist
  Aufgabe Ihres Administrators ([Wie füge ich eine Inhaltssprache hinzu?](../../handbuch/wie-fuege-ich-eine-inhaltssprache-hinzu.md)).
- Ihre Rolle muss das Übersetzen in diese Sprache erlauben.

## Schritte

1. Öffnen Sie die Seite in der **Inhaltsstruktur** und drücken Sie **Bearbeiten**. Auf einer mehrsprachigen Website
   öffnet sich eine Seite mit den Sprachen.
2. Wählen Sie unter **Neue Übersetzung** die Sprache, die Sie hinzufügen.
3. Wählen Sie unter **Übersetzung basiert auf** die Sprache, aus der kopiert wird (damit die Felder schon ausgefüllt
   sind), oder **Keine**, um leer zu beginnen.
4. Drücken Sie **Bearbeiten**. Das Formular öffnet sich in der neuen Sprache.
5. Übersetzen Sie **jedes** Feld, auch den Titel: Er wird meist zur Webadresse in dieser Sprache.
6. Drücken Sie **Zur Veröffentlichung schicken**.
7. Prüfen Sie das Fenster **Übersetzungen** des Objekts: Die neue Sprache ist aufgeführt.

([Wie übersetze ich Inhalte?](../../handbuch/wie-uebersetze-ich-inhalte.md))

## Tipps für Übersetzer

- Übersetzen Sie den **Sinn**, nicht Wort für Wort. Ein Leser vor Ort sollte nicht merken, dass es eine Übersetzung ist.
- Prüfen Sie **Daten, Preise, Telefonnummern und Einheiten**; sie unterscheiden sich oft zwischen Ländern.
- **Bilder** werden geteilt, aber ihr Alternativtext lässt sich übersetzen: Prüfen Sie ihn.
- Der Schreibassistent kann Ihnen mit **Translate** einen ersten Entwurf geben, wenn Ihre Website ihn hat; prüfen Sie
  ihn immer ([Den Schreibassistenten nutzen](den-schreibassistenten-nutzen.md)).
- Wenn sich die Originalseite ändert, ändern sich ihre Übersetzungen nicht von selbst. Fragen Sie Ihren Administrator,
  wie Ihr Team den Überblick behält ([Wie finde ich, was nicht übersetzt ist?](../../handbuch/wie-finde-ich-was-noch-nicht-uebersetzt-ist.md)).

## Wenn es nicht funktioniert

| Was Sie sehen | Was Sie tun |
|---|---|
| *Sie haben keine Berechtigung, eine Übersetzung in einer anderen Sprache anzulegen* | Ihre Rolle ist auf andere Sprachen beschränkt. Fragen Sie Ihren Administrator |
| Die Sprache wird nicht angeboten | Sie ist noch keine Sprache der Website, oder die Seite hat sie schon (dann wählen Sie sie unter **Bestehende Übersetzungen**) |
| Besucher sehen die Übersetzung nicht | Noch kein Teil der Website zeigt diese Sprache. Fragen Sie Ihren Administrator |

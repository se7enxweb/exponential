# Was Exponential ist, in einfachen Worten

Wenn Ihnen jemand gesagt hat "Ihre Website läuft mit Exponential" und Sie genickt haben, ohne zu wissen, was das
bedeutet, ist diese Seite für Sie. Sie lesen sie in etwa fünf Minuten.

## Die kurze Antwort

Exponential ist ein **Content-Management-System**: ein Programm, das auf einem Server läuft, Besuchern Ihre Website
zeigt und Ihnen und Ihrem Team erlaubt, diese Website im Webbrowser zu ändern, ohne Code anzufassen. Das Projekt
beschreibt sich selbst als "a professional PHP application framework with advanced CMS (content management system)
functionality", also als professionelles PHP-Anwendungsframework mit fortgeschrittenen CMS-Funktionen (die Datei
`README.md` in der Installation). Sie müssen nicht wissen, was PHP ist: Es ist die Programmiersprache, in der
Exponential geschrieben ist, und Ihr Hoster kümmert sich darum.

## Was es für Sie tut

| Sie möchten | Exponential gibt Ihnen |
|---|---|
| Texte und Bilder selbst ändern | Ein Bearbeitungsformular im Browser für jede Seite ([Eine Seite ändern](erste-schritte/eine-seite-aendern.md)) |
| Vermeiden, halbfertige Arbeit zu veröffentlichen | Entwürfe, die nur Sie sehen, bis Sie veröffentlichen ([Entwürfe, Versionen und Veröffentlichen erklärt](begriffe/entwuerfe-versionen-und-veroeffentlichen-erklaert.md)) |
| Einen Fehler rückgängig machen | Frühere Versionen und einen Papierkorb ([Einen Fehler rückgängig machen](erste-schritte/einen-fehler-rueckgaengig-machen.md)) |
| Mehrere Menschen sicher mithelfen lassen | Konten, Rollen und Freigaben ([Rollen und Rechte erklärt](begriffe/rollen-und-rechte-erklaert.md)) |
| Eine Seite visuell anordnen | Exponential Layouts, einen Seitenbaukasten mit Blöcken, wo Ihre Website ihn verwendet ([Eine Seite mit Layouts gestalten](erste-schritte/eine-seite-mit-layouts-gestalten.md)) |
| Die Website in mehreren Sprachen anbieten | Übersetzungen jeder Seite ([Eine Seite übersetzen](erste-schritte/eine-seite-uebersetzen.md)) |
| Einen kleinen Shop betreiben | Einen eingebauten Shop mit Produkten, Warenkorb und Bestellungen ([Onlineshop: hier beginnen](../kunden/typen/onlineshops-hier-beginnen.md)) |
| Einen Newsletter versenden | Die Newsletter-Erweiterung, wo sie installiert ist ([Newsletter](../kunden/wachstum/newsletter.md)) |
| Hilfe beim Schreiben bekommen | Den optionalen Schreibassistenten Exponential Intelligence, der nur Entwürfe schreibt ([Den Schreibassistenten nutzen](erste-schritte/den-schreibassistenten-nutzen.md)) |

Welche davon Ihre eigene Website hat, hängt davon ab, wie sie eingerichtet wurde. Wenn Sie eine hier beschriebene
Funktion nicht sehen, fragen Sie die Person, die Ihre Website betreut; viele Funktionen sind Zusätze
(**Erweiterungen**), die sich einschalten lassen ([Erweiterungen erklärt](begriffe/erweiterungen-erklaert.md)).

## Was es nicht tut

Ehrlich darüber zu sein spart Ihnen Geld und Enttäuschung:

- **Es registriert Ihren Domainnamen nicht und betreibt nicht Ihre E-Mail.** Eine Domain kaufen Sie bei einer
  Registrierungsstelle, und E-Mail kommt meist von Ihrem Hoster oder einem Mailanbieter
  ([Domainname und E-Mail](hosting-auswahl/domainname-und-e-mail.md)).
- **Es hostet sich nicht selbst.** Es braucht einen Server. Ein Hosting-Unternehmen stellt einen bereit
  ([Drei Wege zu einer Website](hosting-auswahl/drei-wege-zu-einer-website.md)).
- **Es installiert sich nicht per Knopfdruck.** Die Installation erfordert normalerweise eine Kommandozeile und das
  Werkzeug Composer; der Einrichtungsassistent im Browser schließt eine Installation ab, aber zuerst müssen die Dateien
  auf einen geeigneten Server gelangen ([Anforderungen auf einen Blick](../hosting/grundlagen/anforderungen-auf-einen-blick.md)).
  Das erledigt ein Hoster, ein Entwickler oder ein Partner.
- **Es hat kein Modul für Terminbuchung, Tischreservierung oder Ticketverkauf.** So etwas kommt von einem externen
  Dienst, den Ihre Website verlinkt oder einbettet. Dasselbe gilt für ein eigenes Spendenmodul
  ([Gemeinnützige Organisationen: Spenden](../unternehmen/gemeinnuetzige/spenden-und-spendenaufrufe.md)).
- **Es gestaltet Ihre Website nicht für Sie.** Es wird mit fertigen Designs (Themes) ausgeliefert, die ein
  Website-Ersteller auswählt und anpasst ([Ein Design oder Theme wählen](../ersteller/website-ersteller/ein-design-oder-theme-waehlen.md)).

## Wer es macht

Exponential hat eine lange Geschichte: Sein Copyright-Vermerk reicht von 1998 bis heute. Es war einst unter einem
anderen Namen bekannt, wurde von seinem ursprünglichen Hersteller eingestellt und wird seitdem vom Unternehmen **7x**
weitergeführt, wobei die **Exponential Foundation**, eine gemeinnützige Organisation, das Projekt betreibt
([Wer ist 7x?](../wer-ist-7x.md), [Wer ist die Exponential Foundation?](../wer-ist-die-exponential-foundation.md)). Eine
Gemeinschaft aus Entwicklern, Designern und Hosting-Unternehmen arbeitet weltweit damit.

## Was es kostet

Die Software ist **freie Software**: "Using Exponential under the terms of the GNU GPL is free of charge", also: Die
Nutzung von Exponential unter den Bedingungen der GNU GPL ist kostenlos (`README.md`, "License"). Es gibt keine
Lizenzgebühr, weder pro Benutzer noch pro Website noch pro Jahr. Wofür Sie bezahlen:

| Kosten | Bezahlt an | Übliche Form |
|---|---|---|
| Hosting | Ein Hosting-Unternehmen | Eine monatliche oder jährliche Gebühr |
| Domainname | Eine Registrierungsstelle für Domains | Eine jährliche Gebühr |
| Aufbau oder Anpassung der Website | Einen Entwickler, Designer oder Partner | Einen Projektpreis oder Stundensatz |
| Betreuung: Aktualisierungen, Sicherungen, Hilfe | Ihren Hoster, einen Entwickler oder einen Partner | Einen Wartungsvertrag |
| Ihre eigene Zeit | Sie | Stunden pro Monat |

Diese Hilfe nennt keine Preise: Sie hängen davon ab, wen Sie beauftragen. [Fragen zu den Kosten](hosting-auswahl/fragen-zu-den-kosten.md)
hilft Ihnen, Angebote zu vergleichen.

## Was Sie drumherum brauchen

1. **Einen Hoster**, der die Website betreibt ([Was ein Hoster für Sie tut](hosting-auswahl/was-ein-hoster-fuer-sie-tut.md)).
2. **Jemanden Technisches, den Sie anrufen können**: den Hoster, einen Entwickler oder einen Partner
   ([Wen Sie anrufen](wenn-es-hakt/wen-sie-anrufen.md)).
3. **Ein Konto für jede Person**, die die Website ändert, mit zweistufiger Anmeldung
   ([Ihr Passwort und die zweistufige Anmeldung](erste-schritte/ihr-passwort-und-die-zweistufige-anmeldung.md)).
4. **Eine kurze Routine**, um sie gesund zu halten ([Monatliche Checkliste für Website-Verantwortliche](checklisten/monatlich-fuer-website-verantwortliche.md)).

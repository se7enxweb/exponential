# Glossar für Menschen ohne technische Vorkenntnisse

Lesen Sie diese Seite zuerst. Jede Seite dieses Bereichs verwendet diese Wörter genau in der hier angegebenen
Bedeutung. Die Wörter sind danach gruppiert, wo Sie ihnen begegnen, nicht nach dem Alphabet, damit zusammengehörige
Wörter beieinanderstehen. Das vollständige technische Glossar des Projekts ist das
[Glossar von Exponential](../../glossar.md); diese Seite ist die freundliche Fassung.

Wo die deutsche Administration ein Wort anders zeigt als das Englische, steht der englische Begriff in Klammern
dahinter, weil er Ihnen in Gesprächen mit Hostern und Entwicklern begegnen kann.

## Wörter auf dem Bildschirm beim Bearbeiten

| Wort | In einfachen Worten | Mehr |
|---|---|---|
| **Website** (site) | Was Besucher unter Ihrer Webadresse sehen. | [Die Website und die Administration](begriffe/die-website-und-die-administration.md) |
| **Administration** (admin) | Der Teil derselben Installation, in dem sich Menschen anmelden, um die Website zu ändern. Oft unter Ihrer Adresse, gefolgt von `/admin`. | [Rundgang durch die Administration](../rundgang-durch-die-administration.md) |
| **Editor** | Auf vielen Websites eine einfachere Administration für Menschen, die nur schreiben und veröffentlichen. Dieselben Inhalte, weniger Schaltflächen. | [Anmelden im Editor](../anmelden-im-editor.md) |
| **Dashboard** | Die erste Seite nach der Anmeldung: Ihre Entwürfe, Ihre Warteliste, neue Inhalte, Schnellzugriffe. | [Erste Schritte](../erste-schritte.md#2-umsehen) |
| **Inhalt** (Inhaltsobjekt, auch **Objekt**; content item) | Ein Ding auf der Website: eine Seite, ein Artikel, ein Bild, eine Datei, sogar ein Benutzerkonto. | [Inhalte und der Baum](begriffe/inhalte-und-der-baum.md) |
| **Inhaltstyp** (auch **Klasse**) | Die Art eines Objekts: *Artikel*, *Ordner*, *Bild*, *Datei*. Sie bestimmt, welche Felder das Formular hat. | dieselbe |
| **Feld** (auch **Attribut**) | Ein Kästchen im Bearbeitungsformular: *Titel*, *Einleitung*, *Haupttext*, *Bild*. Ein roter Stern bedeutet, dass Sie es ausfüllen müssen. | [Inhalte bearbeiten](../inhalte-bearbeiten.md#das-bearbeitungsformular) |
| **Baum** (Inhaltsstruktur) | Alle Objekte, angeordnet wie Ordner auf einem Computer. Die linke Spalte zeigt ihn. | [Inhalte und der Baum](begriffe/inhalte-und-der-baum.md) |
| **Unterelemente** (sub items) | Die Objekte innerhalb des Objekts, das Sie gerade ansehen. | dieselbe |
| **Formatierter Text** (rich text) | Ein Feld mit einer kleinen Textverarbeitung: Fett, Listen, Links, Tabellen, Bilder. | [Inhalte bearbeiten](../inhalte-bearbeiten.md#rich-text) |
| **Verknüpfung** (relation) | Ein Feld, das auf ein anderes Objekt zeigt, etwa das Bild eines Artikels. | [Inhalte bearbeiten](../inhalte-bearbeiten.md#verknüpfungen-und-bilder) |

## Wörter rund ums Veröffentlichen

| Wort | In einfachen Worten | Mehr |
|---|---|---|
| **Entwurf** (draft) | Ihre unfertige Änderung. Nur Sie sehen sie, die Website nicht. | [Entwürfe, Versionen und Veröffentlichen erklärt](begriffe/entwuerfe-versionen-und-veroeffentlichen-erklaert.md) |
| **Veröffentlichen** (**Zur Veröffentlichung schicken**) | Ihren Entwurf zu der Version machen, die Besucher sehen. | dieselbe |
| **Version** | Jeder gespeicherte Stand eines Objekts. Alte Versionen werden aufbewahrt, damit Sie zurückkehren können. | [Einen Fehler rückgängig machen](erste-schritte/einen-fehler-rueckgaengig-machen.md) |
| **Ausstehend** (pending) | Zur Veröffentlichung geschickt, wartet aber auf die Freigabe von jemandem. | [Veröffentlichen, Versionen und der Papierkorb](../veroeffentlichen-und-versionen.md#veröffentlichen) |
| **Archiviert** | Eine ältere Version, die früher auf der Website war. | dieselbe |
| **Versteckt** (hidden) | In der Administration noch vorhanden, aber auf der Website nicht angezeigt. | [Verbergen und entfernen](erste-schritte/verbergen-und-entfernen.md) |
| **Papierkorb** (trash) | Wo entfernte Objekte warten. Sie lassen sich wiederherstellen, bis jemand den Papierkorb leert. | dieselbe |
| **Vorschau** (preview) | Ein Blick auf Ihren Entwurf, wie er erscheinen würde, bevor Sie veröffentlichen. | [Inhalte bearbeiten](../inhalte-bearbeiten.md#das-bearbeitungsformular) |
| **Freigabe** (approval, Workflow) | Eine Regel, nach der jemand zustimmen muss, bevor Ihre Änderung online geht. | [Wie schicke ich Inhalte zur Freigabe?](../handbuch/wie-sende-ich-inhalte-zur-freigabe.md) |
| **Zeitgesteuertes Veröffentlichen** (scheduled publishing) | Ein Datum und eine Uhrzeit, zu der ein Objekt von selbst online geht, wo die Website es eingerichtet hat. | [Zeitgesteuertes Veröffentlichen](../kunden/alltag/zeitgesteuertes-veroeffentlichen.md) |

## Wörter zu Menschen und Rechten

| Wort | In einfachen Worten | Mehr |
|---|---|---|
| **Benutzer** (Konto; user) | Ein Mensch, der sich anmelden kann. Jede Person sollte ihr eigenes Konto haben. | [Ihr Konto und die Anmeldung](../konten-und-anmeldung.md) |
| **Rolle** (role) | Eine Sammlung von Rechten, etwa *Editor* oder *Administrator*, die Menschen oder Gruppen gegeben wird. | [Rollen und Rechte erklärt](begriffe/rollen-und-rechte-erklaert.md) |
| **Sektion** (section) | Ein Teil der Website mit eigenen Regeln dazu, wer ihn sieht und ändert, etwa ein Bereich nur für Mitglieder. | dieselbe |
| **Zweistufige Anmeldung** (2FA, two-step sign-in) | Nach Ihrem Passwort ein sechsstelliger Code von Ihrem Telefon oder per E-Mail. Schützt Ihr Konto, wenn Ihr Passwort bekannt wird. | [Ihr Passwort und die zweistufige Anmeldung](erste-schritte/ihr-passwort-und-die-zweistufige-anmeldung.md) |
| **Anonymous** | Ein Besucher, der sich nicht angemeldet hat. Was er sehen darf, ist ebenfalls eine Rolle. | [Rollen und Rechte erklärt](begriffe/rollen-und-rechte-erklaert.md) |

## Wörter zu Bildern, Dateien und Seiten

| Wort | In einfachen Worten | Mehr |
|---|---|---|
| **Medienbibliothek** (media library) | Der Teil des Baums für Bilder, Dokumente und Videos (der Reiter **Medien**). | [Bilder, Medien und Uploads](../medien-und-uploads.md) |
| **Alternativtext** (alt text) | Eine kurze Beschreibung eines Bildes für Menschen, die es nicht sehen können. Viele Websites verlangen ihn. | [Ein Bild hinzufügen](erste-schritte/ein-bild-hinzufuegen.md) |
| **Bildvariante** (image variation) | Eine kleinere oder zugeschnittene Kopie Ihres Bildes, die die Website für Listen und Seiten selbst erzeugt. Sie laden nur einmal hoch. | [Bilder und Bildvarianten](../ersteller/website-ersteller/bilder-und-bildvarianten.md) |
| **Layout** | Der Plan einer Seite aus **Zonen** (Bereichen), die **Blöcke** enthalten (einen Titel, einen Text, eine Liste, eine Galerie). | [Der Layout-Editor](../layout-editor.md) |
| **Regel** (Zuordnung; rule) | Entscheidet, welche Seiten welches Layout verwenden. Überlassen Sie das im Zweifel einem Website-Ersteller. | dieselbe |
| **Formular** (Informationssammler) | Ein Kontakt- oder Anmeldeformular; die Antworten werden gespeichert und lassen sich in der Administration lesen. | [Wie sehe ich Formulareinsendungen?](../handbuch/wie-sehe-ich-formulareinsendungen.md) |
| **Sprechende URL** (URL-Alias; nice URL) | Die lesbare Webadresse einer Seite, aus ihrem Titel gebildet. | [URLs, Weiterleitungen und verschobene Seiten](../kunden/alltag/urls-weiterleitungen-und-verschobene-seiten.md) |
| **Übersetzung** | Dasselbe Objekt in einer anderen Sprache, getrennt bearbeitet. | [Eine Seite übersetzen](erste-schritte/eine-seite-uebersetzen.md) |

## Wörter, die ein Hoster oder Entwickler verwendet

| Wort | In einfachen Worten | Mehr |
|---|---|---|
| **Hosting** / **Hoster** | Einen Computer im Internet mieten, der Ihre Website betreibt, und das Unternehmen, das ihn vermietet. | [Hosting, Domains und HTTPS erklärt](begriffe/hosting-domains-und-https-erklaert.md) |
| **Server** | Dieser Computer. | dieselbe |
| **Domainname** | Ihre Adresse, etwa `example.org`. Bei einer Registrierungsstelle gekauft, nicht bei Exponential. | [Domainname und E-Mail](hosting-auswahl/domainname-und-e-mail.md) |
| **HTTPS** / **Zertifikat** | Das Schloss im Browser: Die Verbindung ist privat. Der Hoster richtet es ein. | [Hosting, Domains und HTTPS erklärt](begriffe/hosting-domains-und-https-erklaert.md) |
| **Datenbank** | Wo die Inhalte gespeichert sind. Exponential kann eine einzelne Datei (SQLite) oder einen Datenbankserver verwenden. | [Unterstützung für SQLite-Datenbanken](../../funktionen/6.0/sqlite-datenbank.md) |
| **Sicherung** (backup) | Eine Kopie der Website und ihrer Inhalte, an einem anderen Ort aufbewahrt, um sie nach einem Unglück zurückzuholen. | [Sicherungen](../kunden/gesund-halten/backups.md) |
| **Update** / **Upgrade** | Eine neuere Version von Exponential einspielen. Sicherheitskorrekturen kommen nur auf diesem Weg. | [Wie Updates funktionieren](../kunden/gesund-halten/wie-updates-funktionieren.md) |
| **Release** | Eine nummerierte, fertige Version der Software, etwa 6.0.15. Sie ändert sich danach nie mehr. | dieselbe |
| **Cache** | Vorgefertigte Kopien von Seiten, die die Website aufbewahrt, damit sie schnell ist. Manchmal muss er geleert werden, damit eine Änderung erscheint. | [Caches erklärt](begriffe/caches-erklaert.md) |
| **Erweiterung** (extension) | Ein Zusatz, der der Website eine zusätzliche Fähigkeit gibt: einen Newsletter, Karten, zweistufige Anmeldung. | [Erweiterungen erklärt](begriffe/erweiterungen-erklaert.md) |
| **Design**, **Theme**, **Template** | Wie die Website aussieht. Von einem Designer oder Entwickler geändert, nicht im Bearbeitungsformular. | dieselbe |
| **Siteaccess** | Eine "Tür" in die Installation: die öffentliche Website, die Administration, eine zweite Sprache oder eine zweite Website. | [Die Website und die Administration](begriffe/die-website-und-die-administration.md) |
| **Kommandozeile** (command line) | Befehle in ein Textfenster auf dem Server tippen. Sie brauchen sie nie; Ihr Hoster oder Entwickler schon. | [Was Sie nie tun müssen](was-sie-nie-tun-muessen.md) |
| **Composer** | Das Werkzeug, mit dem Entwickler Exponential und seine Erweiterungen auf der Kommandozeile installieren und aktualisieren. | dieselbe |
| **Velocity** | Das eigene, schnelle Webserver-Programm von Exponential. Ihr Hoster entscheidet, ob es verwendet wird. | [Velocity für Unternehmen](../unternehmen/zuverlaessigkeit/velocity-fuer-unternehmen.md) |
| **Wartungsmodus** (maintenance mode) | Eine Hinweisseite, die Besucher sehen, während die Website aktualisiert wird. | [Wartungsmodus und geplante Arbeiten](../kunden/gesund-halten/wartungsmodus-und-geplante-arbeiten.md) |
| **Fehlerreferenz** (error reference) | Ein Code wie `ERR-0123456789` auf einer Fehlerseite. Geben Sie ihn weiter: Damit findet ein Administrator das Problem. | [Eine Fehlermeldung lesen](wenn-es-hakt/eine-fehlermeldung-lesen.md) |

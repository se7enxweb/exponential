# Checkliste zur Übergabe, wenn jemand geht

Menschen gehen: Mitarbeitende wechseln die Stelle, Ehrenamtliche ziehen weiter, ein Familienmitglied übergibt die
Website an jemand anderen. Gut gemacht dauert das eine Stunde. Schlecht gemacht behält ein ehemaliges Mitglied jahrelang
Zugriff, oder niemand weiß, wie die Domain verlängert wird.

## Bevor die Person geht

- [ ] Bitten Sie sie, **ihre Entwürfe fertigzustellen oder zu entfernen** (**Meine Entwürfe**) und alles Halbfertige
      aufzulisten.
- [ ] Bitten Sie sie aufzuschreiben, **was sie regelmäßig getan hat**: wöchentliche Nachrichten, Formulare beantworten,
      den Newsletter, Bestellungen.
- [ ] Klären Sie, wer jede dieser Aufgaben übernimmt.
- [ ] Fragen Sie, welche **externen Zugänge** sie hat: die Registrierungsstelle der Domain, den Kundenbereich des
      Hosters, einen Zahlungsanbieter, einen Karten- oder KI-Anbieter, soziale Medien. Jeder braucht eine neue
      verantwortliche Person.

## An ihrem letzten Tag

- [ ] Der Administrator **deaktiviert** ihr Konto. Das Deaktivieren behält ihren Namen an den Versionen, die sie
      erstellt hat, sodass die Geschichte lesbar bleibt; ein Konto zu löschen ist selten nötig
      ([Wie deaktiviere oder entsperre ich ein Benutzerkonto?](../../handbuch/wie-deaktiviere-oder-entsperre-ich-ein-benutzerkonto.md)).
- [ ] Hatte sie die Rolle **Administrator**, sorgen Sie vorher dafür, dass mindestens eine andere Person sie hat.
- [ ] Ändern Sie alle **gemeinsamen Passwörter**, die sie kannte (in der Website selbst sollte es keine geben; externe
      Dienste haben vielleicht welche).

## Nachdem sie gegangen ist

- [ ] Aktualisieren Sie [Wen Sie anrufen](../wenn-es-hakt/wen-sie-anrufen.md).
- [ ] Prüfen Sie, ob ihre regelmäßigen Aufgaben unter der neuen Person stattfinden (der erste Newsletter, die ersten
      Antworten auf Formulare).
- [ ] Sagen Sie Ihrem Hoster oder Partner Bescheid, wenn sie dort Ansprechperson war.

Die ausführlichere Fassung für Organisationen ist [Austritt von Mitarbeitenden](../../kunden/alltag/ausscheiden-von-mitarbeitenden.md).

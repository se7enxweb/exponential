# Checklisten für Menschen ohne technische Vorkenntnisse

Checklisten machen aus guten Gewohnheiten Routine. Jede passt auf eine gedruckte Seite. Kopieren Sie sie in Ihr eigenes
Dokument, passen Sie sie an Ihre Website an und haken Sie sie ab.

## Die Checklisten

| Checkliste | Wann | Wer |
|---|---|---|
| [Checkliste für den ersten Tag](der-erste-tag.md) | Ihr erster Tag mit einem neuen Konto oder einer neuen Website | Alle |
| [Checkliste vor dem Veröffentlichen](vor-dem-veroeffentlichen.md) | Jedes Mal, vor **Zur Veröffentlichung schicken** | Alle, die veröffentlichen |
| [Monatliche Checkliste für Website-Verantwortliche](monatlich-fuer-website-verantwortliche.md) | Einmal im Monat, etwa 30 Minuten | Die Verantwortlichen oder die Leitung |
| [Checkliste zur Übergabe, wenn jemand geht](uebergabe-wenn-jemand-geht.md) | Wenn eine Person das Team verlässt | Die Verantwortlichen und der Administrator |
| [Checkliste zur Barrierefreiheit in einfachen Worten](barrierefreiheit-in-einfachen-worten.md) | Für jede neue Seite und einmal im Quartal für die Website | Redakteure und die Verantwortlichen |

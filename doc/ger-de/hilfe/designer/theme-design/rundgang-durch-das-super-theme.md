# Ein Rundgang durch das Theme super

Diese Seite ist für Designer, die die kleinste vollständige Design-Erweiterung sehen möchten oder gerade eine mit dem Assistenten für
Design-Erweiterungen erzeugt haben. `sevenx_themes_super` auf der Demonstrationsinstallation ist ein solches erzeugtes Gerüst (seine
`settings/override.ini.append.php` sagt „Generated by the design extension wizard“). Es ist nicht Teil des Exponential-Hauptpakets.

1. [Alles, was es enthält](#alles-was-es-enthält)
2. [Wie die Teile zusammenpassen](#wie-die-teile-zusammenpassen)

4. [Es zu einem echten Theme ausbauen](#es-zu-einem-echten-theme-ausbauen)

## Alles, was es enthält

```
extension/sevenx_themes_super/
├── composer.json, extension.xml, ezinfo.php, README.md
├── settings/design.ini.append.php        DesignExtensions[]=sevenx_themes_super, CSSFileList[]=site.css, JavaScriptList[]=site.js
├── settings/override.ini.append.php      one example override (full view of class article)
└── design/sevenx_themes_super/
    ├── templates/pagelayout.tpl          the frame
    ├── templates/page_head.tpl           meta tags, title, stylesheets
    ├── templates/page_header.tpl
    ├── templates/page_footer.tpl
    ├── override/templates/full/article.tpl
    ├── stylesheets/site.css
    ├── javascript/site.js
    └── images/                            (empty)
```

Eine Handvoll Dateien: genug, um einen Siteaccess auf das Design umzustellen und eine Seite zu sehen.

## Wie die Teile zusammenpassen

- `pagelayout.tpl` gibt `<html>` aus, bindet `page_head.tpl` im `<head>` ein, dann `page_header.tpl`, ein `<main>`-Element mit
  `{$module_result.content}` und `page_footer.tpl`.
- `settings/override.ini.append.php` enthält eine Regel:

  ```ini
  [full_article_sevenx_themes_super]
  Source=node/view/full.tpl
  MatchFile=full/article.tpl
  Subdir=templates
  Match[class_identifier]=article
  ```

  die zeigt, wie ein Override die Vollansicht einer Klasse ersetzt ([Grundlagen der Overrides](../vorlagen/override-grundlagen.md)).
- Ein Siteaccess verwendet das Design, sobald sein `SiteDesign` (oder `AdditionalSiteDesignList[]`) `sevenx_themes_super` nennt.

## Drei Zeilen, die zu korrigieren sind

Kopf und Rahmen, wie sie erzeugt werden, brauchen drei Korrekturen, bevor sie wie beabsichtigt funktionieren (für den Assistenten gemeldet):

1. **Die Stylesheets werden nie ausgegeben.** `page_head.tpl` ruft `{ezcss_require( ezini( 'StylesheetSettings', 'CSSFileList' ) )}` auf.
   `ezcss_require` merkt Dateien nur für ein späteres `ezcss_load` vor, und nichts ruft `ezcss_load` auf. Außerdem liest `ezini()` ohne
   Dateinamen `site.ini`, nicht `design.ini`. Verwenden Sie:

   ```tpl
   {ezcss_load( ezini( 'StylesheetSettings', 'CSSFileList', 'design.ini' ) )}
   ```

2. **jQuery und site.js werden aus demselben Grund nie ausgegeben**: `pagelayout.tpl` endet mit
   `{ezscript_require( array( 'ezjsc::jquery' ) )}`. Setzen Sie ein `ezscript_load` vor `</body>`:

   ```tpl
   {ezscript_load( ezini( 'JavaScriptSettings', 'JavaScriptList', 'design.ini' ) )}
   ```

3. **Der Titel verwendet einen Operator, den es nicht gibt.** `implode_key` ist kein registrierter Template-Operator, daher schlägt die
   Zeile `<title>` fehl. Bauen Sie den Titel stattdessen mit einer Schleife:

   ```tpl
   <title>{foreach $module_result.path|reverse as $path_item}{$path_item.text|wash}{delimiter} / {/delimiter}{/foreach} - {ezini( 'SiteSettings', 'SiteName' )|wash}</title>
   ```

Schreiben Sie bei der Gelegenheit den Zeichensatz schlicht: `<meta charset="utf-8">`.

## Es zu einem echten Theme ausbauen

1. Geben Sie ihm einen echten Namen und ein eigenes Composer-Paket (siehe die Seiten zu Theme-Erweiterungen:
   [Theme-Erweiterungen: hier beginnen](../erweiterungen/theme-erweiterungen-hier-beginnen.md)).
2. Ersetzen Sie den Rahmen durch ein Pagelayout mit Landmarks und einem Skip-Link ([Landmarks und Überschriften](landmarks-und-ueberschriften.md)).
3. Fügen Sie `site.css` Design-Token und einen dunklen Modus hinzu ([Design-Token](design-tokens.md)).
4. Fügen Sie Override-Regeln pro Klasse und View-Modus hinzu ([Knoten-Templates nach Klasse](../vorlagen/knoten-templates-nach-klasse.md)).
5. Fügen Sie Übersetzungen für seine Texte hinzu ([Tutorial: ein Theme internationalisieren](tutorial-ein-theme-internationalisieren.md)).

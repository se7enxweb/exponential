# Lebensende

Diese Seite ist für Designer, die ein Theme nicht mehr pflegen können. Aufzuhören ist in Ordnung; stillschweigend
aufzuhören nicht.

## Schritt für Schritt

1. **Entscheiden** Sie Datum und Grund.
2. **Suchen Sie zuerst einen neuen Betreuer**: einen Mitwirkenden, eine Agentur, die das Theme nutzt, die Community
   ([Ein Theme übergeben](uebergabe-an-einen-neuen-betreuer.md)). Fragen Sie in den Issues und auf share.exponential.earth.
3. **Nennen Sie einen Nachfolger**, falls es einen gibt: ein anderes Theme oder einen Fork, den jemand pflegt.
4. **Kündigen Sie es** mit Vorlauf **an** ([Das Lebensende ankündigen](das-lebensende-ankuendigen.md)).
5. **Veröffentlichen Sie ein letztes Release** mit jeder fertigen Korrektur, dem README als „nicht mehr gepflegt“
   gekennzeichnet und dem genannten Nachfolger.
6. **Halten Sie es installierbar**: Löschen Sie nie das Repository, die Tags oder das Packagist-Paket; Websites hängen davon ab.
7. **Archivieren** Sie das Repository ([Ein Repository archivieren](ein-repository-archivieren.md)) und kennzeichnen Sie das
   Paket auf Packagist als aufgegeben, mit dem Nachfolger, falls es einen gibt.
8. **Aktualisieren Sie die Einträge**: Die Projektseite auf projects.exponential.earth sagt, dass das Theme beendet ist,
   und verlinkt den Nachfolger.

## Was Sie nicht schulden

Nach dem Lebensende schulden Sie keine Korrekturen. Sagen Sie klar, was Nutzer tun können: zum Nachfolger wechseln, das
Theme forken (die GPL erlaubt es) oder jemanden für die Pflege ihrer Kopie bezahlen.

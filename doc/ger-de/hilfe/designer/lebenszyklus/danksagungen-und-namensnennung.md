# Danksagungen und Namensnennung

Diese Seite ist für Designer, die auf der Arbeit anderer aufbauen, also für jeden Designer. Die Nennung verlangen die
meisten Lizenzen, und sie ist einfach richtig.

## Wen Sie nennen, und wo

| Wen | Wo | Echtes Beispiel |
|---|---|---|
| Ursprüngliche Autoren eines portierten oder geforkten Designs | Copyright-Zeilen in `ezinfo.php`, `extension.xml`, `LICENSE` | `cjw_themes_jumper`: „2007 - 2026 CJW Network, JAC Systeme GmbH and 7x“ |
| Mitwirkende an Änderungen | Changelog-Eintrag | `cjw_themes_jumper` 0.1.4: „Pull request #1 by ekked“ |
| Ideen aus einem anderen Projekt | Changelog-Eintrag | `cjw_themes_jumper` 0.1.3: „The idea comes from LoveStack, Mugo Web's distribution (commit 98854ab935), with thanks.“ |
| Meldende von Problemen | Changelog oder Release Notes, wie sie es wünschen | |
| Schriften, Icons, Bibliotheken, Fotos | Eine Danksagungsdatei daneben | `THIRD-PARTY.md`, `CREDITS.md` |
| Das Projekt, auf dem Sie aufbauen | README | „Ein Theme für Exponential“ |

## Schritt für Schritt

1. Wenn Sie einen Beitrag zusammenführen, fügen Sie die Nennung im selben Commit ins Changelog ein.
2. Wenn Sie ein Design portieren, setzen Sie die ursprünglichen Rechteinhaber in die Copyright-Zeile, bevor Ihre eigene
   Arbeit beginnt.
3. Fragen Sie Meldende, wie sie genannt werden wollen; manche möchten es lieber nicht.
4. Prüfen Sie die Nennungen vor jedem Release: nichts entfernt, nichts Neues fehlt.

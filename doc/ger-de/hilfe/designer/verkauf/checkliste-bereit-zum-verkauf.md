# Checkliste: bereit zum Verkauf

Diese Seite ist für Designer, die gleich mit dem Verkauf beginnen. Haken Sie jeden Punkt ab; die verlinkte Seite erklärt ihn.

## Produkt

- [ ] Das Theme besteht die [Checkliste: Die Theme-Erweiterung ist bereit](../erweiterungen/checkliste-theme-erweiterung-bereit.md).
- [ ] Es ist veröffentlicht oder lieferbar ([Checkliste: vor der Veröffentlichung](../veroeffentlichung/checkliste-vor-der-veroeffentlichung.md)).
- [ ] Eine Demo und Screenshots gibt es ([Demos, die verkaufen](demos-die-verkaufen.md)).

## Angebot und Lizenz

- [ ] Was Käufer erhalten, ist aufgeschrieben ([Was Käufer erhalten](was-kaeufer-erhalten.md)).
- [ ] Das Lizenzmodell ist gewählt und angegeben ([Lizenzmodelle](lizenzmodelle.md)).
- [ ] Jedes Asset darf verkauft oder geteilt werden ([Bilder und Schriften unter eigenen Lizenzen](bilder-und-schriften-unter-eigenen-lizenzen.md)).
- [ ] Der Name ist geprüft ([Namen und Marken](namen-und-marken.md)).

## Preise und Papierkram

- [ ] Das Preismodell ist gewählt ([Preismodelle](preismodelle.md)).
- [ ] Bedingungen von einem Anwalt geprüft ([Verträge und Bedingungen](vertraege-und-bedingungen.md)).
- [ ] Gewährleistung und Erstattungsrichtlinie veröffentlicht ([Gewährleistung und Haftung](gewaehrleistung-und-haftung.md), [Erstattungsrichtlinien](erstattungsrichtlinien.md)).
- [ ] Steuerfragen von einem Steuerberater beantwortet ([Steuern und Rechnungen](steuern-und-rechnungen.md)).

## Lieferung und Support

- [ ] Lieferung von Anfang bis Ende getestet ([Updates liefern](updates-an-kunden-liefern.md)).
- [ ] Support definiert, mit Zeiten, die Sie einhalten können ([Support-Angebote](support-angebote.md)).
- [ ] Ein Sicherheitskontakt veröffentlicht ([Eine Sicherheitsrichtlinie für ein Theme](../veroeffentlichung/sicherheitsrichtlinie-fuer-ein-theme.md)).

## Datenschutz

- [ ] Eine Datenschutzerklärung und eine Routine für den Umgang mit Daten ([Kundendaten und Datenschutz](kundendaten-und-datenschutz.md)).

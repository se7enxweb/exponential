# Erstattungsrichtlinien als Optionen

Diese Seite ist für Designer, die Themes oder Abonnements verkaufen. Das Verbraucherrecht vieler Länder legt
Mindestrechte für Online-Käufe fest, auch für digitale Inhalte; prüfen Sie Ihres. **Dies ist keine Rechtsberatung.**

## Optionen

| Richtlinie | Wirkung | Hinweis |
|---|---|---|
| Keine Erstattung nach dem Download | Einfach | Kann unwirksam sein, wo das Verbraucherrecht ein Widerrufsrecht gewährt |
| Erstattung innerhalb einer Frist, ohne Fragen | Schafft Vertrauen | Bei GPL-Code behält der Käufer die Dateien; akzeptieren Sie das |
| Erstattung, wenn ein gemeldeter Mangel nicht behebbar ist | Fair für beide | Definieren Sie „Mangel“ |
| Anteilige Erstattung für ungenutzte Abonnementzeit | Fair bei langen Abonnements | Mehr Buchhaltung |
| Keine Erstattung für bereits erbrachte Dienstleistungen | Üblich | Sagen Sie es, bevor die Arbeit beginnt |

## Schritt für Schritt

1. Prüfen Sie die Mindestregeln für die Länder Ihrer Käufer (oder fragen Sie Ihren Anwalt).
2. Wählen Sie eine Richtlinie pro Produkt und Dienstleistung.
3. Veröffentlichen Sie sie vor dem Kauf, verlinkt vom Bezahlvorgang.
4. Halten Sie jede Erstattung und ihren Grund fest; Muster zeigen, wo das Produkt in die Irre führt.

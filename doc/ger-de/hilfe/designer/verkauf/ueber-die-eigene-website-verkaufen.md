# Über die eigene Website verkaufen

Diese Seite ist für Designer, die einen Ort wollen, den sie selbst kontrollieren, um von dort zu verkaufen. Ihre Website ist
der einzige Kanal mit Zahlungen ([Wo Exponential-Themes heute zu finden sind](wo-themes-zu-finden-sind.md)).

## Was die Website braucht

| Teil | Seite |
|---|---|
| Eine Produktseite pro Theme oder Dienstleistung | [Die Produktseite eines Themes schreiben](produktseite.md) |
| Eine Live-Demo | [Demos, die verkaufen](demos-die-verkaufen.md) |
| Verkaufs- und Supportbedingungen | [Verträge und Bedingungen](vertraege-und-bedingungen.md) |
| Eine Erstattungsrichtlinie | [Erstattungsrichtlinien](erstattungsrichtlinien.md) |
| Eine Datenschutzerklärung | [Kundendaten und Datenschutz](kundendaten-und-datenschutz.md) |
| Eine Kontakt- und Supportseite | [Support-Angebote](support-angebote.md) |
| Rechnungen, die den Regeln Ihres Landes entsprechen | [Steuern und Rechnungen](steuern-und-rechnungen.md) |

## Bauen Sie sie mit Exponential

Ihre eigene Website ist das beste Schaufenster: Bauen Sie sie mit Exponential und Ihrem eigenen Theme. Exponential enthält
einen Shop (Warenkorb, Bestellungen, Handler für Mehrwertsteuer und Versand); Zahlungsanbieter kommen über Erweiterungen
hinzu, zum Beispiel die Stripe-Erweiterung `se7enxweb/sevenx_payment_stripe`, die in der Organisation `se7enxweb`
aufgeführt ist. Prüfen Sie die aktuelle Dokumentation jedes Zahlungsanbieters, bevor Sie sich darauf verlassen.

## Zahlungsmöglichkeiten als Optionen

| Möglichkeit | Passt zu |
|---|---|
| Rechnungen und Banküberweisung | Dienstleistungen, Firmen als Käufer |
| Ein Zahlungsanbieter in Ihrem Shop | Theme-Verkäufen und Abonnements |
| Eine gehostete Bezahlseite eines Zahlungsdienstleisters | Wenigen Produkten, wenig Einrichtung |

## Schritt für Schritt

1. Schreiben Sie die Seiten der Tabelle.
2. Wählen Sie eine Zahlungsmöglichkeit und testen Sie den ganzen Kauf mit einer Testzahlung.
3. Richten Sie die Lieferung ein: eine E-Mail mit Zugangsanweisungen oder einen Download ([Updates liefern](updates-an-kunden-liefern.md)).
4. Verlinken Sie die Website aus Ihrem README und Ihrem Projekteintrag.

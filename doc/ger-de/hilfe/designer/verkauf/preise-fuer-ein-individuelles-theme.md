# Preise für ein individuelles Theme-Projekt

Diese Seite ist für Designer, die auf die Frage eines Kunden „Was kostet ein Design für unsere Website?“ antworten. Ein
gutes Angebot ist vor allem eine gute Beschreibung der Arbeit.

## Die Teile eines Angebots

| Teil | Inhalt |
|---|---|
| Umfang | Zu gestaltende Seiten und Ansichtsmodi: Startseite, Artikel, Liste, Suche, Formulare, Fehlerseiten |
| Phasen | Bedarfsklärung, Designentwürfe, Bau, Review, Start, Übergabe |
| Annahmen | Inhaltsklassen existieren; Inhalte liefert der Kunde; eine Sprache; ein Siteaccess |
| Qualität | Niveau der Barrierefreiheit, getestete Browser und Breiten, Dunkelmodus ja oder nein |
| Ausgeschlossen | Inhaltseingabe, Hosting, Erweiterungen über das Theme hinaus |
| Änderungen | Wie ein Änderungswunsch geschätzt und genehmigt wird |
| Lizenz | Wem was gehört; GPL-Code; kundenspezifische Assets ([Verträge und Bedingungen](vertraege-und-bedingungen.md)) |
| Preis und Zahlung | Das Modell ([Preismodelle](preismodelle.md)) und die Zahlungsstufen |

## Schritt für Schritt

1. Führen Sie ein Gespräch zur Bedarfsklärung; schreiben Sie auf, was die Website tun muss und für wen.
2. Listen Sie die nötigen Templates und Ansichtsmodi auf (dabei helfen die Planungsseiten der Hilfe für Führungskräfte:
   [Mit Erweiterungen schätzen und abgrenzen](../../fuehrung/schaetzen-und-abgrenzen-mit-erweiterungen.md)).
3. Schätzen Sie jeden Punkt ([Theme-Arbeit schätzen](theme-arbeit-schaetzen.md)).
4. Schreiben Sie das Angebot mit den Teilen oben.
5. Bitten Sie den Kunden, die Annahmen schriftlich zu bestätigen.

## Bewährte Praxis

- Bepreisen Sie die Reviewrunden ausdrücklich; dort wachsen Projekte.
- Nehmen Sie die Übergabe auf: Dokumentation und eine Schulung für Redakteure.
- Bieten Sie die Wartung getrennt an ([Wartungsabonnements](wartungsabonnements.md)).

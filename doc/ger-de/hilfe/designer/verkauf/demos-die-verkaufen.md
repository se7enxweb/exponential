# Demos, die verkaufen

Diese Seite ist für Designer, die einem Käufer ein Theme vorführen, live oder in einem Gespräch. Die allgemeinen
Demo-Skripte für Exponential stehen in [Demo-Skripte](../../geschaeft/demo-drehbuecher.md); diese Seite ergänzt, was für ein
Theme spezifisch ist.

## Ein geführter Weg (etwa 20 Minuten)

1. **Die Startseite** in voller Breite: das Aussehen, die Navigation.
2. **Verkleinern Sie auf Telefonbreite** und zoomen Sie dann auf 200 %: Das Layout hält.
3. **Schalten Sie in den Dunkelmodus** (wenn das Theme ihn unterstützt).
4. **Öffnen Sie einen Artikel**: Typografie, Bilder, verwandte Inhalte.
5. **Bearbeiten Sie ihn**: Zeigen Sie, wie ein Redakteur einen Titel und ein Bild ändert und veröffentlicht; das Theme
   zeigt die Änderung.
6. **Der Layout-Editor** (wenn das Theme Layout-Blöcke gestaltet): einen Block hinzufügen, veröffentlichen, ansehen.
7. **Nur mit der Tastatur**: mit der Tabulatortaste durch die Seite; der Fokus ist sichtbar.
8. **Fragen**.

## Vorbereiten

- Eine Demo-Website mit guten Demo-Inhalten ([Eine Demo-Website betreiben](../veroeffentlichung/demo-websites.md),
  [Demo-Inhalte](../veroeffentlichung/demo-inhalte.md)).
- Ein Demo-Redakteurskonto, das nur Inhalte bearbeiten kann.
- Eine Rückfallebene: Screenshots, falls das Netzwerk ausfällt.

## Nachfassen

Schicken Sie innerhalb eines Tages den Demo-Link, die Produktseite, was Sie gezeigt haben, und die versprochenen
Antworten. Notieren Sie die Fragen; sie gehören auf die Produktseite.

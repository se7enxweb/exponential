# Preismodelle als Optionen

Diese Seite ist für Designer, die entscheiden, wie sie abrechnen. Sie listet Modelle auf, keine Preise: Ihre Kosten, Ihr
Markt und Ihr Land bestimmen die Zahlen.

## Die Modelle

| Modell | Sie berechnen | Belohnt | Risiken |
|---|---|---|---|
| Einmalpreis für ein Theme | Einmal pro Käufer | Den Verkauf vieler Kopien | Später Support ohne Einnahmen; die GPL erlaubt anderen den Weiterverkauf |
| Kostenloses Theme, bezahlte Dienstleistungen | Nur Support, Einrichtung, Anpassung | Eine große Nutzerbasis | Die Einnahmen hängen davon ab, wie viele Nutzer Hilfe brauchen |
| Abonnement | Pro Monat oder Jahr, für Updates und Support | Stetige Einnahmen | Sie müssen in jedem Zeitraum liefern |
| Festpreis pro Projekt | Pro vereinbartem Umfang | Planbarkeit für den Kunden | Unterschätzung ([Theme-Arbeit schätzen](theme-arbeit-schaetzen.md)) |
| Stunden- oder Tagessatz | Die aufgewendete Zeit | Fair bei unklarer Arbeit | Kunden fürchten offene Rechnungen; braucht Berichte |
| Pauschalvereinbarung | Einen festen Betrag für reservierte Zeit | Planung für beide Seiten | Ungenutzte Stunden werden zum Streitpunkt |
| Zahlen nach Wunsch / Spenden | Was Nutzer wählen | Wohlwollen, Community | Unberechenbar ([Ein Open-Source-Theme finanzieren](open-source-themes-finanzieren.md)) |

## Schritt für Schritt

1. Schreiben Sie Ihre Kosten pro Monat auf (Zeit, Werkzeuge, Hosting, Versicherung).
2. Wählen Sie ein Modell für Produkte und eines für Dienstleistungen.
3. Schreiben Sie auf, was jeder Preis umfasst ([Was Käufer erhalten](was-kaeufer-erhalten.md)).
4. Veröffentlichen Sie das Modell klar; versteckte Bedingungen beschädigen Vertrauen.
5. Überprüfen Sie es nach einigen Monaten mit echten Zahlen.

## Bewährte Praxis

- Halten Sie die kostenlose Stufe wirklich nützlich; sie ist Ihr Marketing.
- Sagen Sie, was geschieht, wenn ein Abonnement endet (der Code bleibt unter der GPL beim Kunden; Updates und Support
  enden).
- Vergleichen Sie Ihre Preise auf Ihren Seiten nicht mit namentlich genannten Mitbewerbern.

# Support-Angebote

Diese Seite ist für Designer, die Support für ein Theme anbieten wollen. „Support“ bedeutet für verschiedene Kunden
Verschiedenes; definieren Sie ihn.

## Was Support umfassen kann

| Element | Beispieldefinition |
|---|---|
| Fragen | Wie man das Theme konfiguriert und nutzt, per E-Mail oder über ein Ticketsystem |
| Fehlerkorrekturen | Ein Mangel im Theme, auf einer unterstützten Version nachgestellt, in einem Release behoben |
| Kompatibilität | Updates für neue Releases von Exponential und PHP ([Releases von Exponential verfolgen](../lebenszyklus/exponential-releases-verfolgen.md)) |
| Sicherheitskorrekturen | Innerhalb einer angegebenen Zeit nach einer Meldung ([Sicherheitskorrekturen in Themes](../lebenszyklus/sicherheitskorrekturen-in-themes.md)) |
| Kleine Änderungen | Bis zu einer vereinbarten Zeit pro Monat |
| Notfallhilfe | Außerhalb der Bürozeiten, zu einem vereinbarten Satz |
| Nicht enthalten | Inhaltsarbeit, andere Erweiterungen, die eigenen Template-Änderungen des Kunden |

## Bezahlter und Community-Support nebeneinander

Die Organisation `se7enxweb` veröffentlicht eine `SUPPORT.md`, die kommerziellen Support (die Dienstleistungen einer
Firma) von Community-Support (ein Chat und die öffentlichen Issues) trennt. Dasselbe zu tun, hält beides klar: Der
öffentliche Issue-Tracker bleibt für alle offen, und zahlende Kunden bekommen Reaktionszeiten.

## Schritt für Schritt

1. Wählen Sie die Elemente, die Sie anbieten.
2. Schreiben Sie für jedes eine Definition wie in der Tabelle.
3. Legen Sie gegebenenfalls Stufen fest ([Support-Stufen gestalten](support-stufen.md)) und die Zeiten, die Sie einhalten
   können ([Reaktionszeiten und Zusagen](reaktionszeiten-und-zusagen.md)).
4. Veröffentlichen Sie eine `SUPPORT.md` und eine Supportseite auf Ihrer Website.
5. Richten Sie einen Kanal pro Art von Anfrage ein ([Issue-Tracker und Support-Kanal](../veroeffentlichung/issue-tracker-und-support-kanal.md)).

# Namen und Marken

Diese Seite ist für Designer, die ein Theme, ein Angebot ihres Studios oder eine Domain benennen. Die Namensregeln des
Projekts stehen in [Marken- und Namensregeln](../../geschaeft/marken-und-namensregeln.md); diese Seite wendet sie auf
Theme-Verkäufer an. Sie ist keine Rechtsberatung.

## Faustregeln

| Tun | Nicht tun |
|---|---|
| „Harbor, ein Theme für Exponential“ | „Exponential Harbor“ (sieht aus wie ein Teil des Produkts) |
| „Gebaut für Exponential 6“ | „Offizielles Exponential-Theme“ (außer das Projekt sagt es) |
| Nennen Sie das Produkt **Exponential** | Den alten Produktnamen für Ihr Produkt verwenden; er erscheint nur als Geschichte (sein Hersteller hat es nach fast 18 Jahren eingestellt) |
| Ihren eigenen Studionamen für Dienstleistungen | Namen anderer Firmen oder ihrer Produkte für Ihre |

## Schritt für Schritt: einen Namen prüfen

1. Suchen Sie den Namen zusammen mit „Exponential“ und „theme“ auf GitHub, Packagist und projects.exponential.earth.
2. Durchsuchen Sie ein Markenregister Ihres Hauptmarkts nach dem Namen in den Klassen für Software und Design.
3. Prüfen Sie, dass die Domain und der Vendor-Name bei Packagist frei sind.
4. Ist etwas ähnlich, wählen Sie jetzt einen anderen Namen; eine spätere Umbenennung kostet jeden Nutzer Arbeit
   ([Ihre Theme-Erweiterung benennen](../erweiterungen/ihre-theme-erweiterung-benennen.md)).

## Im Code

Benennen Sie Kernel-Bezeichner wie `eZINI` oder `eZTemplate` in Ihrem Theme nicht um, damit sie zu einer Marke passen; sie
sind Code, keine Namen. Neue eigene Namen verwenden Ihr Präfix (und `exp`, wo sie ein Konzept von Exponential benennen).

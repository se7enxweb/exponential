# Ein Open-Source-Theme finanzieren

Diese Seite ist für Designer, die ein Theme kostenlos veröffentlichen und möchten, dass die Arbeit nachhaltig ist.

## Möglichkeiten

| Möglichkeit | Wie |
|---|---|
| Spenden und Sponsoring | Eine Sponsor-Schaltfläche am Repository über `.github/FUNDING.yml` |
| Gesponserte Funktionen | Eine Firma bezahlt eine Funktion, die dann in das kostenlose Theme eingeht |
| Bezahlter Support neben kostenlosem Code | [Support-Angebote](support-angebote.md) |
| Bezahlte Anpassung | [Anpassung und White-Label-Arbeit](anpassung-und-white-label.md) |

## Die Datei FUNDING.yml

GitHub zeigt eine Schaltfläche **Sponsor**, wenn ein Repository (oder das Repository `.github` des Kontos) eine
`.github/FUNDING.yml` hat. Die Datei des Repositorys von Exponential listet zum Beispiel:

```yaml
github: se7enxweb
patreon: 7xweb
custom: ["https://www.paypal.me/7xweb", "https://se7enx.com"]
```

(gekürzt). Die Seite dieses Kontos bei GitHub Sponsors ist `https://github.com/sponsors/se7enxweb`.

## Schritt für Schritt

1. Richten Sie bei dem gewählten Dienst ein Sponsoring-Profil ein (GitHub Sponsors verlangt ein freigegebenes Profil).
2. Fügen Sie dem Repository des Themes eine `.github/FUNDING.yml` mit Ihren eigenen Konten hinzu.
3. Sagen Sie im README, wofür das Geld verwendet wird (Wartung, Prüfungen der Barrierefreiheit, neue Templates).
4. Berichten Sie den Sponsoren: eine kurze Notiz pro Release.

## Unterstützen Sie die Projekte, auf denen Sie aufbauen

Ihr Theme steht auf Exponential und seinen Erweiterungen. Wenn Ihr Theme Geld einbringt, überlegen Sie, auch die Arbeit
zu sponsern, von der Sie abhängen; das hält Ihr Fundament gepflegt. Siehe [Wer ist 7x?](../../wer-ist-7x.md) und
[Wer ist die Exponential Foundation?](../../wer-ist-die-exponential-foundation.md).

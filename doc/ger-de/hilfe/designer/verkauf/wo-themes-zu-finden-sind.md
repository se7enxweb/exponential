# Wo Exponential-Themes heute zu finden sind

Diese Seite ist für Designer, die entscheiden, wo sie ihre Mühe einsetzen. Sie listet Kanäle auf, die es gibt und die am
18. Oktober 2026 geprüft wurden. **Es gibt keinen offiziellen Marktplatz für Exponential-Themes** mit Zahlungen oder einem
Shop; sagen Sie Käufern nichts anderes.

## Die Kanäle

| Kanal | Was dort geschieht | Zahlungen? |
|---|---|---|
| GitHub (die Organisation `se7enxweb` und die Konten der Autoren) | Quellcode, Releases, Issues | Nein (GitHub Sponsors ist getrennt) |
| [Packagist](https://packagist.org/) | Installationen mit Composer | Nein |
| [projects.exponential.earth](https://projects.exponential.earth/) | Community-Plattform: Projektseiten, Neuigkeiten, Downloads, Durchsuchen nach Typ | Nein |
| [share.exponential.earth](https://share.exponential.earth/) | Foren (Extensions, Setup & design), Blogs, Tutorials | Nein |
| [eZpedia](https://ezpedia.exponential.earth/) | Wiki-Artikel unter der GFDL | Nein |
| Demo-Websites | Menschen probieren das Aussehen aus | Nein |
| Ihre eigene Website | Produktseiten, Shop, Support | Ja, unter Ihrer Kontrolle |

## Schritt für Schritt

1. Veröffentlichen Sie das Theme dort, wo Entwickler suchen: GitHub und Packagist ([Ein Theme veröffentlichen](../veroeffentlichung/ein-theme-veroeffentlichen-hier-beginnen.md)).
2. Tragen Sie es dort ein, wo die Community sucht: projects.exponential.earth und eine Ankündigung auf
   share.exponential.earth.
3. Verkaufen Sie über Ihre eigene Website ([Über die eigene Website verkaufen](ueber-die-eigene-website-verkaufen.md)).
4. Verlinken Sie alle miteinander.

## Allgemeine Marktplätze

Für andere Systeme gibt es allgemeine Theme-Marktplätze. Lesen Sie vor der Nutzung eines davon seine Bedingungen: Manche
verlangen Exklusivität oder Lizenzen, die mit dem GPL-Code eines Exponential-Themes kollidieren.

# Theme-Arbeit schätzen

Diese Seite ist für Designer, die sagen müssen, wie lange ein Theme dauert. Hier stehen keine Zahlen: Ihre eigenen
Aufzeichnungen sind die einzige verlässliche Quelle. Die Seite zeigt, wie Sie sie aufbauen.

## Die Arbeit aufschlüsseln

| Teil | Umfasst |
|---|---|
| Einrichtung | Gerüst der Theme-Erweiterung, Einstellungen, Test-Siteaccess ([Der Design-Erweiterungs-Assistent](../erweiterungen/der-design-erweiterungs-assistent.md)) |
| Pagelayout | Kopf, Kopfbereich, Navigation, Fußbereich |
| Ansichtstemplates | Vollansicht, Zeilenansicht, Embed-Ansicht pro Inhaltsklasse |
| Overrides | Regeln für Klassen, Sektionen, Knoten |
| Styles | Tokens, Komponenten, responsives Layout, Druck |
| Dunkelmodus und rechts nach links | Wenn vereinbart |
| Barrierefreiheit | Kontrast, Tastatur, Landmarks, Formulare; ein Lauf von axe pro Seite |
| Content Security Policy | Keine Inline-Skripte oder -Styles |
| Tests | Breiten, Zoom, Browser, hell und dunkel |
| Dokumentation und Übergabe | README, Leitfaden für Redakteure, Schulung |
| Reviewrunden | Änderungen nach dem Feedback des Kunden |

## Schritt für Schritt

1. Listen Sie die Teile für das Projekt auf, mit der Zahl der Templates pro Teil.
2. Nehmen Sie für jeden Ihre aufgezeichnete Zeit aus früheren Projekten; wo Sie keine haben, schätzen Sie und
   kennzeichnen es als Vermutung.
3. Fügen Sie Reviewrunden und einen Puffer für Unbekanntes hinzu und sagen Sie beides offen.
4. Halten Sie nach dem Projekt die tatsächliche Zeit pro Teil fest. Beim nächsten Mal ist Ihre Schätzung besser.

## Häufige Unterschätzungen

- Tests bei mehreren Breiten, im Dunkelmodus und bei 200 % Zoom.
- Grenzfälle der Inhalte: lange Titel, fehlende Bilder, leere Felder.
- Das Theme für das nächste Release von Exponential aktualisieren ([Releases von Exponential verfolgen](../lebenszyklus/exponential-releases-verfolgen.md)).

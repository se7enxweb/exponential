# Support-Stufen gestalten

Diese Seite ist für Designer, die mehr als eine Stufe Support wollen. Stufen sollten sich in Dingen unterscheiden, die ein
Kunde spürt und Sie liefern können.

## Dimensionen, die sich unterscheiden können

| Dimension | Niedrigere Stufe | Höhere Stufe |
|---|---|---|
| Kanal | Öffentliche Issues, E-Mail | E-Mail, Telefon oder Chat |
| Erste Antwort | Länger | Kürzer |
| Abgedeckte Websites | Eine | Mehrere |
| Enthaltene Änderungszeit | Keine | Einige Stunden pro Monat |
| Updates | Releases wie veröffentlicht | Releases für den Kunden installiert |
| Sicherheit | Korrektur im nächsten Release | Korrektur und Installation, mit Ankündigung |

## Eine Vorlage zum Füllen

| | Community | Standard | Priority |
|---|---|---|---|
| Wer | Alle | Zahlende Kunden | Zahlende Kunden |
| Kanal | Öffentliche Issues, Forum | E-Mail | E-Mail und Telefon |
| Erste Antwort | Kein Versprechen | (Ihr Wert) | (Ihr Wert) |
| Websites | - | (Ihr Wert) | (Ihr Wert) |
| Änderungsstunden | - | - | (Ihr Wert) |
| Preis | Kostenlos | (Ihr Wert) | (Ihr Wert) |

Füllen Sie die Werte nur mit dem, was Sie über Monate einhalten können, auch wenn Sie krank oder im Urlaub sind.

## Schritt für Schritt

1. Wählen Sie zwei oder drei Dimensionen; mehr verwirren Käufer.
2. Füllen Sie die Vorlage mit Werten, die Sie liefern können.
3. Schreiben Sie auf, was in keiner Stufe enthalten ist.
4. Veröffentlichen Sie die Tabelle auf der Produktseite.

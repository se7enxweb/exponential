# Bilder und Schriften unter eigenen Lizenzen

Diese Seite ist für Designer, deren eigene Gestaltung einen großen Teil des Werts eines Themes ausmacht. Code und
Gestaltung können verschiedene Lizenzen tragen, wenn sie getrennt gehalten werden. Dies ist keine Rechtsberatung.

## Wie es meist gemacht wird

1. **Halten Sie die Assets in eigenen Ordnern**, zum Beispiel `design/mytheme/images/premium/`, nicht vermischt mit
   Templates oder CSS.
2. **Liefern Sie ihre Lizenz daneben mit**: `design/mytheme/images/premium/LICENSE.txt`, die angibt, was der Käufer tun
   darf (zum Beispiel: Nutzung auf den eigenen Websites des Käufers; keine Weitergabe als Bilder).
3. **Lassen Sie das Theme ohne sie funktionieren.** Templates fallen auf neutrale Platzhalter zurück, sodass der GPL-Teil
   für sich vollständig ist.
4. **Sagen Sie es auf der Produktseite und im README**: „Code: GPL-2.0-or-later. Bilder in images/premium: an den Käufer
   zur Nutzung auf seinen eigenen Websites lizenziert.“

## Was Sie nicht tun dürfen

- Bilder, Schriften oder Icons anderer neu lizenzieren. Deren Bedingungen reisen mit ihnen
  ([Schriften, Icons und Bibliotheken Dritter](../veroeffentlichung/schriften-icons-und-bibliotheken-dritter.md)).
- Stockfotos mitliefern, deren Lizenz die Weitergabe nicht erlaubt, auch nicht an einen zahlenden Käufer.
- Behaupten, der GPL-Code dürfe nicht weitergegeben werden, weil die Assets es nicht dürfen.

## Möglichkeiten für die Bedingungen der Assets

| Möglichkeit | Passt, wenn |
|---|---|
| Creative Commons (CC BY, CC BY-SA) | Sie möchten, dass sie mit Namensnennung geteilt werden |
| Eine Nutzungslizenz für die Websites des Käufers | Sie Premium-Gestaltung verkaufen |
| Keine eigene Lizenz (alles GPL) | Einfachheit; Code und Gestaltung reisen zusammen |

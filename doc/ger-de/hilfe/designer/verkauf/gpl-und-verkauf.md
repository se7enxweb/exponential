# Die GPL und der Verkauf: was erlaubt ist

Diese Seite ist für Designer, die denken, „freie Software“ heiße „kein Geld“. Sie erklärt das übliche Verständnis der GNU
General Public License in einfachen Worten. **Sie ist keine Rechtsberatung**; maßgeblich ist der Lizenztext.

## Kurz gesagt

- Sie **dürfen** für eine Kopie von GPL-Software jeden Preis verlangen, und für jede Dienstleistung darum herum.
- Jeder Käufer **erhält die Freiheiten der GPL**: den Code auszuführen, zu studieren, zu ändern und weiterzugeben, auch
  kommerziell.
- Sie **dürfen nicht** Einschränkungen über die GPL hinaus hinzufügen oder jemandem, dem Sie das Programm gegeben haben,
  den Quellcode vorenthalten.

Die eigene Erklärung der Free Software Foundation, „Selling Free Software“, steht unter
`https://www.gnu.org/philosophy/selling.html`.

## Was das in der Praxis bedeutet

| Situation | Unter der GPL |
|---|---|
| Sie verkaufen ein Theme zu einem Preis | Erlaubt |
| Der Käufer gibt einem Freund eine Kopie | Erlaubt, und Sie können es nicht verbieten |
| Der Käufer veröffentlicht das Theme auf GitHub | Erlaubt |
| Ein Mitbewerber verkauft Ihr GPL-Theme | Erlaubt, wenn er Ihre Hinweise und die Lizenz behält |
| Sie verlangen Geld für Support und die Lieferung von Updates | Erlaubt; ein Vertrag über Ihre Zeit |
| Sie verkaufen ein Theme als „nur für eine Website“ | Für den GPL-Code nicht durchsetzbar; sagen Sie stattdessen „der Support umfasst eine Website“ |

## Warum Menschen trotzdem bezahlen

Käufer bezahlen für das, was die Lizenz ihnen nicht gibt: Ihre Zeit, Ihr Fachwissen, die Bequemlichkeit eines gepflegten
Themes, Support mit Reaktionszeiten und das Vertrauen, beim Autor zu kaufen.

## Häufige Missverständnisse

- „GPL heißt, ich muss es verschenken.“ Nein: Sie müssen jedem, der es erhält, den Quellcode und die Freiheiten geben, zu
  welchem Preis Sie es auch verkauft haben.
- „Ich muss die Anpassungen meines Kunden veröffentlichen.“ Nein: Sie müssen den Quellcode den Personen geben, an die Sie
  verbreiten. Arbeit, die Sie für einen Kunden machen und nur ihm geben, geht an diesen Kunden.
- „Ein GPL-Theme auf einer Website macht die Inhalte der Website zu GPL.“ Nein: Inhalte sind kein Code.

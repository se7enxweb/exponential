# Verträge und Bedingungen

Diese Seite ist für Designer, die Themes oder Theme-Arbeit verkaufen. Sie listet die Themen auf, über die Sie sich einigen
sollten. **Sie ist keine Rechtsberatung und enthält keinen Vertragstext zum Kopieren**: Lassen Sie Ihre Bedingungen von
einem Anwalt in Ihrer Rechtsordnung schreiben oder prüfen.

## Abzudeckende Themen

| Thema | Zu beantwortende Fragen |
|---|---|
| Parteien und Umfang | Wer, was genau ([Was Käufer erhalten](was-kaeufer-erhalten.md)) |
| Lieferungen und Abnahme | Was geliefert wird, wie es abgenommen wird |
| Eigentum | Wem das Design, kundenspezifische Assets und Ihr wiederverwendbarer Code gehören |
| Lizenzen | GPL für den Code; Bedingungen etwaiger Assets ([Lizenzmodelle](lizenzmodelle.md)) |
| Preis und Zahlung | Modell, Stufen, Zahlungsverzug |
| Änderungen | Wie Änderungswünsche geschätzt und genehmigt werden |
| Support und Wartung | Was, wie lange, Reaktionszeiten ([Reaktionszeiten](reaktionszeiten-und-zusagen.md)) |
| Gewährleistung | Was Sie versprechen ([Gewährleistung und Haftung](gewaehrleistung-und-haftung.md)) |
| Haftung | Grenzen |
| Vertraulichkeit und Daten | Kundendaten, die Sie sehen ([Kundendaten und Datenschutz](kundendaten-und-datenschutz.md)) |
| Referenzen | Dürfen Sie die Arbeit zeigen und nennen? |
| Kündigung | Wie jede Seite sie beendet, was mit Zugängen und Code geschieht |
| Erstattungen | Bei Produkten ([Erstattungsrichtlinien](erstattungsrichtlinien.md)) |
| Recht und Gerichtsstand | Welches Recht gilt |

## Die GPL in Ihren Bedingungen

Ihre Bedingungen dürfen Käufern von GPL-Code nicht die Freiheiten nehmen, die die GPL ihnen gibt. Formulieren Sie
Einschränkungen als Grenzen Ihrer Dienstleistungen („Der Support umfasst eine Installation“), nicht des Codes.

## Schritt für Schritt

1. Füllen Sie die Tabelle für Ihr Angebot in einfachen Worten aus.
2. Bringen Sie sie zu einem Anwalt, der daraus Bedingungen macht.
3. Veröffentlichen Sie die Bedingungen bei Produkten; unterzeichnen Sie bei Projekten einen Vertrag.
4. Bewahren Sie unterzeichnete Kopien und die Fassung der Bedingungen auf, unter der jeder Verkauf erfolgte.

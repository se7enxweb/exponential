# Was Sie rund um ein Theme verkaufen können

Diese Seite ist für Designer, die nach Wegen suchen, bezahlt zu werden. Die Liste enthält Optionen; die meisten Studios
kombinieren zwei oder drei.

## Die Optionen

| Angebot | Der Käufer bekommt | Es verlangt von Ihnen | Wiederkehrend? |
|---|---|---|---|
| Eine Kopie eines fertigen Themes | Die Dateien, sofort | Es einmal zu bauen, dann Supportfragen | Nein, außer es werden Updates verkauft |
| Individuelles Theme-Design | Ein für ihn gemachtes Theme | Design- und Bauzeit pro Kunde | Nein |
| Einrichtung und Installation | Eine funktionierende Website mit dem Theme | Einige Stunden pro Website | Nein |
| Anpassung | Seine Farben, sein Logo, Layoutänderungen | Zeit pro Änderung | Manchmal |
| Support | Antworten und Korrekturen innerhalb vereinbarter Zeiten | Verfügbar zu sein | Ja |
| Wartung | Das Theme kompatibel und sicher gehalten | Upgrade-Tests pro Release | Ja |
| Hosting | Eine Website, die läuft | Server, Überwachung, Backups | Ja |
| Schulung | Redakteure und Entwickler, die allein arbeiten können | Sitzungen vorzubereiten und zu halten | Manchmal |
| Assets | Fotos, Illustrationen, Icon-Sätze | Sie zu erstellen | Nein |

## Wie Sie wählen

1. Listen Sie auf, worin Sie gut sind und was Ihnen Freude macht.
2. Markieren Sie die wiederkehrenden Angebote: Sie machen das Einkommen stetiger, binden aber Ihre Zeit.
3. Prüfen Sie, welche Angebote ohne besondere Bedingungen zur GPL passen (alle oben genannten, siehe
   [Die GPL und der Verkauf](gpl-und-verkauf.md)).
4. Beginnen Sie mit einem Produkt und einer Dienstleistung; fügen Sie mehr hinzu, wenn das Erste reibungslos läuft.

## Was Sie nicht verkaufen können

- Exklusive Rechte an GPL-Code, den Sie nicht geschrieben haben.
- Ein Versprechen, dass Käufer den erhaltenen GPL-Code nicht weitergeben dürfen.
- Den Namen „Exponential“, als wäre er Ihr Produkt ([Namen und Marken](namen-und-marken.md)).

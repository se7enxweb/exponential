# Ansichtstemplates von Datentypen

Diese Seite ist für Designer, die überall ändern, wie eine Art von Feld aussieht: jedes Datum, jedes Bild, jede Liste
verwandter Einträge. Jeder Datentyp hat ein View-Template in `content/datatype/view/<datatype>.tpl`, verwendet von
[attribute_view_gui](attribute-view-gui.md).

## Die Templates

`design/standard/templates/content/datatype/view/` hat eines pro Datentyp: `ezstring.tpl`, `eztext.tpl`, `ezxmltext.tpl`
(Rich Text), `ezimage.tpl`, `ezbinaryfile.tpl`, `ezdate.tpl`, `ezdatetime.tpl`, `eztime.tpl`, `ezboolean.tpl`,
`ezinteger.tpl`, `ezfloat.tpl`, `ezprice.tpl`, `ezemail.tpl`, `ezurl.tpl`, `ezkeyword.tpl`, `ezselection.tpl`,
`ezcountry.tpl`, `ezauthor.tpl`, `ezmatrix.tpl`, `ezmedia.tpl`, `ezobjectrelation.tpl`, `ezobjectrelationlist.tpl`,
`ezuser.tpl` und mehr. Erweiterungen fügen eigene hinzu (zum Beispiel eztags).

## Zwei Beispiele

Die Textzeile, vollständig:

```tpl
{$attribute.data_text|wash( xhtml )}
```

Rich Text gibt das HTML aus, das seine Tag-Templates erzeugt haben:

```tpl
{$attribute.content.output.output_text}
```

Das eigene Markup des Rich Text kommt aus den Tag-Templates in `ezxmltags/` ([Rich-Text-Templates](rich-text-templates.md)).

## Für das ganze Design umgestalten

Kopieren Sie das Template an denselben Pfad in Ihrem Design und ändern Sie die Kopie:

```
design/mytheme/templates/content/datatype/view/ezdatetime.tpl
```

Jeder Siteaccess, der Ihr Design verwendet, zeichnet Datumsangaben jetzt auf Ihre Weise. Behalten Sie die Variablen, die
das Original liest (`$attribute`), und die Parameter, die es annimmt, weil andere Templates sie übergeben.

## Für eine Klasse oder ein Feld umgestalten

Verwenden Sie einen Override mit `Source=content/datatype/view/<datatype>.tpl` und `Match[class_identifier]` und/oder
`Match[attribute_identifier]` ([attribute_view_gui](attribute-view-gui.md#restyling-one-field-with-an-override)).

## Regeln

- Maskieren Sie, was nicht schon HTML ist; maskieren Sie keine Rich-Text-Ausgabe.
- Halten Sie das Markup klein und semantisch: Diese Templates laufen viele Male pro Seite.
- Geben Sie für ein leeres Feld nichts aus, oder lassen Sie den Aufrufer `has_content` prüfen.
- Die Templates des Kernels sagen „DO NOT EDIT THIS FILE! Use an override template instead.“ Kopieren, nie bearbeiten.

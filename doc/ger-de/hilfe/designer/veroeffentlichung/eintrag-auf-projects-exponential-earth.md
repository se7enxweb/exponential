# Ein Theme auf projects.exponential.earth eintragen

Diese Seite ist für Designer, die ihr Theme dort eingetragen haben wollen, wo die Community von Exponential nach
Erweiterungen sucht. Das Folgende beschreibt die Website, wie sie am 18. Oktober 2026 war; maßgeblich ist die Website
selbst.

## Was die Website bietet

[projects.exponential.earth](https://projects.exponential.earth/) beschreibt sich als Community-Plattform mit „Bereichen
für Nachrichtenartikel, Downloads, Foren und Bildergalerien“, „Git-/GitHub-/Composer-Quellcode-Anbindung“, Foren für
den Nutzer-Support und der Möglichkeit für andere, einem Projekt beizutreten. Ihre Startseite zeigt die neuesten
Projektneuigkeiten, neue Projekte und aktualisierte Projekte.

| Um Projekte zu finden | Adresse |
|---|---|
| Nach Typ durchsuchen | `/types` (zum Beispiel der Typ „Exponential“ mit Untertypen wie Design Extension und Distribution) |
| Nach Organisation durchsuchen | `/org`, und als Baum `/tree` |
| Neueste Git-Änderungen | `/changes` |
| Projektneuigkeiten | `/news` |
| RSS-Feeds | `/rss/feed/projects`, `/rss/feed/projects-news`, `/rss/feed/news`, `/rss/feed/git`, `/rss/feed/forums` |

Die Typenliste enthält auch das Archiv der älteren Community-Plattform (die Typen „Via Projects.ez.no“), eine reiche
Ideenquelle für Designer.

## Konten

Die Website gibt an, dass Sie angemeldet sein müssen, um ein neues Projekt hinzuzufügen. Ihr Registrierungslink führt zu
`https://share.exponential.earth/user/register`, und eine Neuigkeit besagt, dass die Projekt-Website Anmeldungen mit
Konten von share.exponential.earth annimmt. Ein Konto dient für beide Websites.

## Schritt für Schritt

1. Stellen Sie sicher, dass das Theme bereit ist, von anderen installiert zu werden: ein öffentliches Repository, ein
   getaggtes Release, ein README und eine Lizenz ([Checkliste: vor der Veröffentlichung](checkliste-vor-der-veroeffentlichung.md)).
2. Registrieren Sie sich auf share.exponential.earth und melden Sie sich dann auf projects.exponential.earth an.
3. Fügen Sie für Ihr Theme ein neues Projekt hinzu. Wählen Sie den Typ, der zu einem Theme passt (Design Extension, wo
   angeboten), Ihre Organisation, und verlinken Sie das Repository und die Packagist-Seite.
4. Verwenden Sie denselben Namen, dieselbe Beschreibung in einem Satz und dieselben Screenshots wie in Ihrem README.
5. Veröffentlichen Sie zum ersten Release eine Neuigkeit im Projekt und danach zu jedem nennenswerten.
6. Prüfen Sie, dass Ihr Projekt unter seinem Typ und im RSS-Feed der Projekte erscheint.

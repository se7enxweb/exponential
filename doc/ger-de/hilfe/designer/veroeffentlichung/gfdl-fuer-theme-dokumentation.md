# Die GFDL für Theme-Dokumentation

Diese Seite ist für Designer, die Dokumentation zu ihrem Theme schreiben (Installationsanleitungen, Tutorials, einen
Styleguide) und möchten, dass andere sie kopieren und verbessern. Dies ist keine Rechtsberatung.

## Was die Dokumentation von Exponential tut

Die Dokumentation im Repository von Exponential steht unter der **GNU Free Documentation License, Version 1.3 oder
später**, ohne unveränderliche Abschnitte, ohne vordere und ohne hintere Umschlagtexte. Ihr Hinweis lautet:

```text
Copyright (C) <years> <holders>.

Permission is granted to copy, distribute and/or modify this document under the terms of the GNU Free
Documentation License, Version 1.3 or any later version published by the Free Software Foundation; with no
Invariant Sections, no Front-Cover Texts, and no Back-Cover Texts. A copy of the license is included in the
section entitled "GNU Free Documentation License".
```

Auch das Community-Wiki [eZpedia](https://ezpedia.exponential.earth/) veröffentlicht seinen Text unter der GNU Free
Documentation License.

## Warum sie für die Dokumentation eines Themes verwenden

- Leser dürfen sie kopieren, übersetzen und verbessern und müssen sie frei halten.
- Ihre Seiten lassen sich mit der Dokumentation von Exponential und mit eZpedia-Artikeln unter derselben Lizenz
  kombinieren.

## GFDL oder Creative Commons

| GFDL 1.3 | CC BY-SA 4.0 |
|---|---|
| Passt zur Dokumentation von Exponential und zu eZpedia | Im Web verbreitet, kürzer |
| Verlangt, dass der Lizenztext Kopien begleitet | Verlangt Namensnennung und dieselbe Lizenz |

Beides funktioniert; wählen Sie eine und geben Sie sie an. Zum Mischen mit der Dokumentation von Exponential ist die
GFDL die einfachere Wahl.

## Schritt für Schritt

1. Setzen Sie den Hinweis mit Ihren Jahreszahlen und Namen an den Anfang oder das Ende der Indexseite Ihrer
   Dokumentation.
2. Liefern Sie den Lizenztext (`https://www.gnu.org/licenses/fdl-1.3.txt`) als Datei im Dokumentationsordner mit.
3. Nennen Sie die Dokumentationslizenz im README, getrennt von der Lizenz des Codes.

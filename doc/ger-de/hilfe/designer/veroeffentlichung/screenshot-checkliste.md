# Screenshot-Checkliste

Diese Seite ist für Designer, die gleich Screenshots hochladen. Gehen Sie sie bei jedem Release durch, das das Aussehen
des Themes ändert.

## Inhalt

- [ ] Aufgenommen von der Version, die Sie veröffentlichen, nicht von einer älteren.
- [ ] Zeigt das Theme so, wie es sich installiert, ohne manuelle Anpassungen, die der Nutzer nicht hätte (oder die
      Anpassung ist erklärt).
- [ ] Nur Demo-Inhalte: keine echten Kunden, Personen, E-Mail-Adressen oder privaten Daten.
- [ ] Keine Seite der Administration mit Benutzernamen, Serverpfaden, IP-Adressen oder Einstellungen.
- [ ] Jedes Foto oder Logo darin darf gezeigt werden (Ihr eigenes oder für diese Nutzung lizenziert).

## Form

- [ ] Die Größen aus [Screenshots für ein Theme](screenshots-fuer-ein-theme.md): 1440, 960 mit Skalierung 2, 375; hell und dunkel.
- [ ] Keine Browserleisten, Erweiterungen, Lesezeichen oder anderen Tabs.
- [ ] Dateigröße angemessen für ein README (je einige hundert Kilobyte; WebP oder optimiertes PNG).
- [ ] Aussagekräftige Dateinamen.

## Verwendung

- [ ] Jedes Bild hat einen Alternativtext, der sagt, was es zeigt.
- [ ] Das README verlinkt die Bilder mit relativen Pfaden, die auf GitHub funktionieren.
- [ ] Dieselben Bilder werden im Projekteintrag und auf der Produktseite verwendet, damit sie nicht auseinanderlaufen.

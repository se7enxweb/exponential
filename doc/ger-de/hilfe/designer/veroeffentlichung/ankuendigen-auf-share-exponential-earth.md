# Ein Theme auf share.exponential.earth ankündigen

Diese Seite ist für Designer, die möchten, dass die Community von ihrem Theme erfährt. Das Folgende beschreibt die
Website, wie sie am 18. Oktober 2026 war.

## Was die Website bietet

[share.exponential.earth](https://share.exponential.earth/) ist das Community-Portal von Exponential. Seine Menüs
umfassen **Get Involved** (Develop, Exchange, Learn & Teach, Localize, Spread the word), **Project** (Downloads,
Erweiterungen, Issue-Tracker, Roadmap, soziale Kanäle), **Blogs**, **Forums** und **Learn** (Tutorials, Dokumentation,
Bücher, Code-Standards). Zu den Foren gehören **General**, **Extensions**, **Developer**, **Install & configuration**,
**Setup & design**, **Discussions** und **Translation**. Registrierte Nutzer können in den Foren schreiben und
Tutorials einreichen („Write a tutorial!“).

Die Fußzeile lautet „Copyright © 1998 - 2026 7x. All rights reserved except where otherwise noted“: Was Sie dort
schreiben, wird zu den Bedingungen der Website veröffentlicht; behalten Sie eine Kopie von allem, was Sie anderswo
unter Ihrer eigenen Lizenz veröffentlichen wollen.

## Schritt für Schritt: ein Release ankündigen

1. Registrieren Sie sich unter `https://share.exponential.earth/user/register` und melden Sie sich an.
2. Wählen Sie das Forum: **Extensions** für eine neue Theme-Erweiterung, **Setup & design** für Designfragen und Tipps.
3. Schreiben Sie den Beitrag:
   - Titel: „<Theme-Name> <Version>: <eine Zeile, was es ist>“;
   - was es ist und für wen, zwei oder drei Sätze;
   - ein Screenshot und ein Link zur Demo;
   - Installationsbefehl und Links zum Repository, zu Packagist und zur Projektseite;
   - die Lizenz;
   - wo Probleme gemeldet werden.
4. Beantworten Sie Fragen im Thread und verweisen Sie Fehlermeldungen an Ihren Issue-Tracker.
5. Für einen ausführlicheren Beitrag (wie Sie eine Funktion gebaut haben) schreiben Sie statt eines Forenbeitrags ein
   Tutorial.

## Umgangsformen

- Eine Ankündigung pro nennenswertem Release, nicht pro Korrektur.
- Legen Sie offen, dass es Ihre Arbeit ist, und sagen Sie es, wenn Sie Dienstleistungen darum herum verkaufen.
- Keine Kundennamen oder privaten Angaben in Beispielen.

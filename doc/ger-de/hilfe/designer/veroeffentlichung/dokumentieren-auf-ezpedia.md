# Ein Theme auf eZpedia dokumentieren

Diese Seite ist für Designer, die Wissen über ihr eigenes README hinaus teilen wollen. Das Folgende beschreibt die
Website, wie sie am 18. Oktober 2026 war.

## Was eZpedia ist

[eZpedia](https://ezpedia.exponential.earth/) nennt sich die freie Enzyklopädie der Produktlinie, „die jeder bearbeiten
kann“, mit Artikeln, die seit 2006 gesammelt werden. **Der gesamte Text steht unter den Bedingungen der GNU Free
Documentation License zur Verfügung.** Es ist in Namensräume wie Learning, Solution, Snippet, Project und Platform
gegliedert.

Artikel, die ein Designer nützlich finden wird:

| Artikel | Adresse |
|---|---|
| Learning: How to create a design extension | `/en/learning/learning_how_to_create_a_design_extension` |
| Design structure | `/en/learning/design_structure` |
| Extensions and projects | `/en/project/extensions`, `/en/project/` |

Viele dieser Artikel wurden für frühere Versionen des Produkts geschrieben. Die Einstellungen, die sie beschreiben
(`ActiveExtensions`, `ActiveAccessExtensions`, Design-Erweiterungen), gibt es noch; prüfen Sie Einzelheiten anhand
dieser Hilfe.

## Schritt für Schritt: eine Seite über Ihr Theme hinzufügen

1. Lesen Sie einige bestehende Projektartikel, um ihrer Form zu folgen.
2. Schreiben Sie die Seite: was das Theme ist, Voraussetzungen, Installation, Links zum Repository, zu Packagist, zur
   Projektseite und zur Demo.
3. Halten Sie alles, was Sie hinzufügen, mit der GFDL vereinbar: eigener Text oder Text unter der GFDL. Fügen Sie
   keinen Text ein, den Sie nicht so lizenzieren können.
4. Verlinken Sie die Seite im Abschnitt „More documentation“ Ihres README.

## eZpedia-Text in Ihrer eigenen Dokumentation verwenden

Der Text von eZpedia steht unter der GFDL. Steht Ihre Dokumentation ebenfalls unter der GFDL
([Die GFDL für Theme-Dokumentation](gfdl-fuer-theme-dokumentation.md)), dürfen Sie ihn kopieren und anpassen, wobei Sie
Lizenz und Namensnennung beibehalten. Unter jeder anderen Lizenz verlinken Sie den Artikel, statt ihn zu kopieren.

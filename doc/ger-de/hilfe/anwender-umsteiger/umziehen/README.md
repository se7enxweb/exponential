## Welcher Weg Ihrer ist

| Ihre Website läuft heute auf | Weg | Seite |
|---|---|---|
| Exponential 6.0.x, und nur der Hoster ändert sich | Ein Umzug, keine Migration | [Eine Website zwischen Hostern umziehen](../../hosting/migrationen/eine-website-zwischen-hostern-umziehen.md) |
| Einer älteren Exponential-Version, auch 4.x und 5.x aus den Jahren von eZ Publish | Ein Upgrade oder eine Migration auf 6 | [Von einer älteren Exponential-Version](von-einer-aelteren-exponential-version.md) |
| eZ Platform oder Ibexa DXP/OSS | Zwei Ziele: Nexus oder der Kernel von Exponential 6 | [Von eZ Platform oder Ibexa](von-ez-platform-oder-ibexa.md) |
| Einem anderen CMS, einem Website-Baukasten oder statischem HTML | Eine Inhaltsmigration mit Export und Import | [Von einem anderen System](von-einem-anderen-system.md) |

## Der Plan in Phasen

Aus [Zu Exponential wechseln](../../unternehmen/auswahl/zu-exponential-wechseln.md#ein-plan-in-phasen):

1. Bestandsaufnahme: Inhaltstypen, Sprachen, Erweiterungen, Integrationen, Verkehr.
2. Den Weg wählen und bei Bedarf einen Partner.
3. Auf einer Staging-Kopie proben und jeden Schritt messen.
4. Inhalte, URLs, Formulare, den Shop und Anmeldungen auf der Kopie prüfen.
5. Die Umstellung planen: einen Inhaltsstopp, ein Wartungsfenster mit Wartungsmodus, den letzten Lauf.
6. Einen Plan für den Rückweg behalten, bis die neue Website abgenommen ist.

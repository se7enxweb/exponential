Das Ergebnis dieser Etappe ist eine schriftliche Entscheidung: was Sie einführen, wer dafür verantwortlich ist, wer es
betreibt und was es kosten darf.

## Wer mit am Tisch sitzen sollte

- Die Person, die nach dem Start für die Website verantwortlich sein wird.
- Jemand, der dafür bezahlt.
- Jemand, der sie bauen oder betreiben wird (intern oder ein Anbieter).
- Ein künftiger Redakteur.

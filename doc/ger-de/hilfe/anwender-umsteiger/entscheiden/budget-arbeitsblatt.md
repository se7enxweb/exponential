## Über mehrere Jahre

```text
Summe = einmalig + (laufend pro Jahr x Jahre) + (interne Stunden x Satz x 12 x Jahre)
```

Vergleichen Sie Alternativen mit derselben Formel und derselben Anzahl von Jahren
([Gesamtbetriebskosten](../../unternehmen/kosten/gesamtbetriebskosten.md)).

## Die Lizenz in Kürze

- "Exponential is GNU GPLv2 licensed" und "Using Exponential under the terms of the GNU GPL is free of charge", also:
  Exponential steht unter der GNU GPLv2, und die Nutzung unter ihren Bedingungen ist kostenlos (`README.md`, "License").
- "The Professional License is no longer available. This effectively makes Exponential GNU GPLv2-or-later ONLY", also:
  Die professionelle Lizenz gibt es nicht mehr, Exponential steht damit nur noch unter GNU GPLv2 oder später (ebenda).
- Die Dokumentation steht unter der GNU FDL 1.3 oder später ([Freie Dokumentation](../../freie-dokumentation.md)).
- Velocity steht unter der MIT-Lizenz ([Exponential Velocity](../../oekosystem/produkte/exponential-velocity.md)).

## Was sie für Sie bedeutet

| Situation | Kurz gesagt |
|---|---|
| Sie betreiben eine Website für Ihre Organisation | Keine Lizenzgebühr; keine Pflicht, Ihre eigenen Templates oder Erweiterungen zu veröffentlichen |
| Ein Anbieter baut individuellen Code für Sie | Vereinbaren Sie im Vertrag, wem er gehört; für GPL-Code erhalten Sie die Freiheiten der GPL |
| Sie geben Exponential oder darauf basierenden Code an andere weiter | Es gelten die Bedingungen der GPL: Der Quellcode gehört dazu |
| Sie beenden die Zusammenarbeit mit einem Anbieter | Die Software bleibt nutzbar; niemand kann sie widerrufen |

Die Seite für Käufer geht tiefer: [Lizenzen für Käufer](../../geschaeft/lizenzen-fuer-kaeufer.md). Fragen:
[FAQ zu Lizenzen](../../projekt/lizenz-faq.md).

## Was Sie mit Anbietern klären

- Wem individuelle Erweiterungen, Designs und Seitenpakete gehören, die für Sie geschrieben wurden.
- Dass Sie den Quellcode und die Git-Geschichte Ihres Projekts erhalten.
- Welche Dienste Dritter (Zahlung, KI-Anbieter, Analyse) eigene Bedingungen haben.
- Dass Ihnen niemand freie Software als sein proprietäres Produkt präsentiert (`CODE_OF_CONDUCT.md`, "Partners and
  commercial conduct").

## Bewertung

```text
[ ] Anforderungen aufgeschrieben und gewichtet
[ ] Demo und Testinstallation ausprobiert
[ ] Machbarkeitsnachweis für die schwierigste Anforderung, schriftlich festgehalten
[ ] Fragen an Anbieter gestellt
[ ] Bewertungsbogen anhand von Belegen ausgefüllt; Risiken festgehalten
```

Seiten: [Bewerten](bewerten/README.md).

## Entscheidung

```text
[ ] Lizenz verstanden; Eigentum an individueller Arbeit vereinbart
[ ] Gewählt, wer den Betrieb übernimmt; Aufgaben aufgeschrieben
[ ] Budget-Arbeitsblatt mit eigenen Zahlen ausgefüllt
[ ] Entscheidungsdokument unterschrieben, mit einer verantwortlichen Person
```

Seiten: [Entscheiden](entscheiden/README.md).

## Planung

```text
[ ] Jede Rolle besetzt
[ ] Schulung kurz vor dem Start geplant
[ ] Inhaltsmodell mit den Redakteuren entworfen
[ ] Hosting, Datenbank und Umgebungen gewählt
[ ] Pilot gewählt, wenn in Etappen eingeführt wird
[ ] Zeitplan aus einer gemessenen Probe aufgebaut
```

Seiten: [Planung](planung/README.md).

## Nach dem Start

```text
[ ] Zwei Wochen intensive Betreuung; Fehler und 404-Meldungen täglich gelesen
[ ] Routinen: wöchentliche Prüfung durch die Verantwortlichen, Sicherungen, Redaktionskalender
[ ] Erstes Update über die Routine eingespielt
[ ] Wiederherstellungstest durchgeführt
[ ] Rückblick nach 90 Tagen geschrieben; verantwortliche Person für den Betrieb benannt
```

Seiten: [Die ersten 90 Tage](starten/die-ersten-90-tage.md), [Nach der Einführung](nach-der-einfuehrung/README.md).

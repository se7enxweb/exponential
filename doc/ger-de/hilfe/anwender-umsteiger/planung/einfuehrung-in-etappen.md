# Einführung in Etappen

Eine Einführung in Etappen beginnt mit etwas Kleinem, das zählt, lernt daraus und wächst. Sie ist der sicherste Weg
der Einführung in einer größeren Organisation.

## Inhalt

1. [Den Pilot wählen](#den-pilot-wählen)
2. [Übliche Etappen](#übliche-etappen)
3. [Aus dem Pilot lernen](#aus-dem-pilot-lernen)
4. [Wann Sie weitergehen](#wann-sie-weitergehen)

## Den Pilot wählen

| Guter Pilot | Schlechter Pilot |
|---|---|
| Echte Benutzer und echte Inhalte | Eine Testwebsite, die niemand besucht |
| Klein genug, um ihn in Wochen abzuschließen | Die ganze Organisation auf einmal |
| Repräsentative Inhaltstypen | Etwas, das allem anderen unähnlich ist |
| Eine verantwortliche Person, die ihn will | Ein Team, das dazu gezwungen wird |

## Übliche Etappen

| Etappe | Beispiel |
|---|---|
| 1 | Eine Website oder ein Bereich, eine Sprache, einige Redakteure |
| 2 | Weitere Inhaltstypen; eine zweite Sprache ([Eine Sprache hinzufügen](../../kunden/wachstum/eine-sprache-hinzufuegen.md)) |
| 3 | Eine zweite Website in derselben Installation ([Eine Website hinzufügen](../../kunden/wachstum/eine-website-hinzufuegen.md)) |
| 4 | Funktionen wie ein Shop, Newsletter, Bereiche für Mitglieder ([Wachstum](../../kunden/wachstum/README.md)) |
| 5 | Integrationen und Apps über die REST-API ([Mobil und Apps](../../kunden/wachstum/mobil-und-apps.md)) |

Die Unterstützung von Exponential für mehrere Websites und Sprachen macht dieses Wachstum in einer Installation möglich
(`README.md`).

## Aus dem Pilot lernen

Schreiben Sie nach dem Pilot auf:

- was Redakteuren schwerfiel;
- welche Teile des Inhaltsmodells sich ändern mussten;
- wie lange die Migration des Pilots pro Objekt gedauert hat;
- welche Aufgaben Anbieter und internes Team tatsächlich erledigt haben.

Planen Sie damit die nächste Etappe neu ([Zeitplan](zeitplan.md)).

## Wann Sie weitergehen

- Redakteure veröffentlichen ohne Hilfe.
- Das erste Update nach dem Start wurde ohne Probleme eingespielt ([Auf dem Laufenden bleiben](../nach-der-einfuehrung/auf-dem-laufenden-bleiben.md)).
- Die Messungen aus dem Pilot stehen im Plan.

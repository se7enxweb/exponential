# Team und Rollen für die Einführung

Bei einer kleinen Einführung hat eine Person mehrere Rollen. Entscheidend ist, dass jede Rolle einen Namen hat.

## Inhalt

1. [Die Rollen](#die-rollen)
2. [Ein Arbeitsblatt](#ein-arbeitsblatt)
3. [Rollen in der Software](#rollen-in-der-software)

## Die Rollen

| Rolle | Während der Einführung | Nach dem Start |
|---|---|---|
| Verantwortliche | Entscheidet, genehmigt das Budget, nimmt den Start ab | Ist für die Website und ihre Entscheidungen verantwortlich |
| Projektleitung | Plant, verfolgt, räumt Hindernisse aus dem Weg | Übergibt an die Verantwortlichen |
| Inhaltsverantwortliche | Modelliert Inhalte, plant die Migration der Inhalte, schreibt Richtlinien | Leitet die Redakteure |
| Entwickler (intern oder Partner) | Baut Templates und Erweiterungen, migriert | Pflegt individuellen Code |
| Administrator (intern, Hoster oder Partner) | Richtet Server, Umgebungen und Sicherungen ein | Aktualisierungen, Überwachung, Sicherheit |
| Redakteure | Testen, geben Rückmeldung, lernen | Veröffentlichen |
| Ansprechpersonen bei Anbietern | Liefern, was der Vertrag sagt | Support und Wartung |

## Ein Arbeitsblatt

```text
Rolle                    Name            Intern / Anbieter      Stunden pro Woche (Schätzung)
Verantwortliche
Projektleitung
Inhaltsverantwortliche
```

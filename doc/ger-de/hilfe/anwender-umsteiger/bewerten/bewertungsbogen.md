# Der Bewertungsbogen für Anwender

Der Bereich für Unternehmen hat einen allgemeinen [Bewertungsbogen für Anbieter](../../unternehmen/vorlagen/bewertungsbogen-fuer-anbieter.md).
Diese Seite passt ihn an eine Einführung von Exponential an und sagt, woher die Belege für jedes Kriterium kommen.

## Inhalt

1. [Wie Sie ihn verwenden](#wie-sie-ihn-verwenden)
2. [Der Bewertungsbogen](#der-bewertungsbogen)
3. [Das Ergebnis lesen](#das-ergebnis-lesen)

## Wie Sie ihn verwenden

1. Geben Sie jedem Kriterium ein Gewicht von 1 (schön zu haben) bis 3 (unverzichtbar) für Ihre Organisation.
2. Bewerten Sie jedes Kriterium von 0 (nicht erfüllt) bis 3 (voll erfüllt) anhand von Belegen, nicht von Eindrücken.
3. Multiplizieren Sie, addieren Sie, und notieren Sie die Belege neben jeder Punktzahl.

## Das Ergebnis lesen

- Jedes unverzichtbare Kriterium mit 0 Punkten ist ein Abbruch, unabhängig von der Summe.
- Eine niedrige Punktzahl mit einem bekannten Umweg ist ein Risiko, das Sie festhalten, kein Abbruch
  ([Risiken und wie Sie sie gewichten](risiken-und-wie-sie-sie-gewichten.md)).
- Vergleichen Sie Summen nur zwischen Systemen, die mit denselben Gewichten und derselben Art von Belegen bewertet
  wurden.

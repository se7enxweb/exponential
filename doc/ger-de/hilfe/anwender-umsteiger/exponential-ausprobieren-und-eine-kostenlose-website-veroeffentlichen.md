# Exponential ausprobieren und eine kostenlose Website veröffentlichen

Ein CMS zu bewerten heißt meistens, für Hosting zu zahlen, bevor man weiß, ob man es behält. Mit statischem
Veröffentlichen kann Ihre Pilot-Website vom ersten Tag an öffentlich sein, ohne Kosten: Exponential läuft auf einem
Laptop oder einem Testserver, und die öffentliche Kopie liegt auf GitHub Pages.

## Was Sie am Ende haben

- Eine Pilot-Website, die Ihre Beteiligten unter einer echten Adresse öffnen können.
- Eigene Erfahrung mit der Bearbeitung, den Rollen und den Versionen in Exponential.
- Eine klare Antwort auf die Frage „Könnte unsere öffentliche Website statisch sein?“

## Ein Pilot in einer Woche

| Tag | Tun |
|---|---|
| 1 | Exponential mit einem Demo-Paket installieren; siehe [Einführung: hier beginnen](einfuehrung-hier-beginnen.md) |
| 2 | Zwei oder drei Inhaltstypen modellieren, die Sie wirklich haben; echte Inhalte anlegen |
| 3 | Ein Design wählen oder anpassen |
| 4 | Ein Ziel für statisches Veröffentlichen anlegen und auf GitHub Pages veröffentlichen |
| 5 | Redakteure einen Tag arbeiten lassen; erneut veröffentlichen; eine Rücknahme ausprobieren; Rückmeldungen sammeln |

## Was Sie bewerten

- **Bearbeitung:** Können Ihre Redakteure ihre tägliche Arbeit ohne Schulung erledigen?
- **Die statische Kopie:** Ist alles da, was Ihre Besucher brauchen? Prüfen Sie im Bericht des Builds, was ersetzt
  wurde (Suche, Formulare, Anmeldung).
- **Passung:** [Passt statisch zu meiner Website?](../statisches-veroeffentlichen/passt-statisch-zu-meiner-website.md) Wenn nicht,
  liefert Exponential die Website auch dynamisch aus; statisches Veröffentlichen ist eine Option, keine Pflicht.

## Nach dem Pilot

- Behalten Sie die statische Website und ziehen Sie die Redaktionsinstallation an ihren endgültigen Ort um, oder
- wechseln Sie zu einer dynamischen öffentlichen Website, mit der statischen Kopie als Sicherung oder Statusseite.

So oder so bleiben die Inhalte erhalten, die Sie angelegt haben.

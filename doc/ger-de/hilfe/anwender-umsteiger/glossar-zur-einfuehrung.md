# Glossar zur Einführung

| Begriff | Bedeutung | Mehr |
|---|---|---|
| **Abnahme** (acceptance) | Die formale Zustimmung der Verantwortlichen, dass die neue Website tut, was vereinbart wurde | [Checkliste zur Inhaltsmigration](umziehen/checkliste-inhaltsmigration.md) |
| **Einführung** (adoption) | Exponential in Gebrauch nehmen: Entscheidung, Plan, Migration, Menschen, Routinen | [Was Einführung bedeutet](was-einfuehrung-bedeutet.md) |
| **Inhaltsstopp** (content freeze) | Ein Zeitraum, in dem niemand Inhalte auf der alten Website ändert, damit die letzte Migration vollständig ist | [Checkliste zur Inhaltsmigration](umziehen/checkliste-inhaltsmigration.md) |
| **Inhaltsmodell** | Die Inhaltstypen und Felder einer Website | [Erste Schritte der Inhaltsmodellierung](planung/erste-schritte-der-inhaltsmodellierung.md) |
| **Umstellung** (cut-over) | Der Wechsel von der alten zur neuen Website | [Umziehen](umziehen/README.md) |
| **Entscheidungsdokument** (decision record) | Eine schriftliche Entscheidung auf einer Seite, mit verantwortlicher Person, Budget und Risiken | [Die Entscheidung festhalten](entscheiden/die-entscheidung-festhalten.md) |
| **Intensive Betreuung** (hypercare) | Die ersten Wochen nach dem Start mit besonderer Aufmerksamkeit für Fehler und Fragen | [Die ersten 90 Tage](starten/die-ersten-90-tage.md) |
| **Wartungsmodus** | Ein Zustand, in dem die Website eine Wartungsseite zeigt, während gearbeitet wird | [Wartungsmodus und geplante Arbeiten](../kunden/gesund-halten/wartungsmodus-und-geplante-arbeiten.md) |
| **Pilot** | Eine erste, kleine Etappe der Einführung mit echten Benutzern | [Einführung in Etappen](planung/einfuehrung-in-etappen.md) |
| **Machbarkeitsnachweis** (proof of concept) | Ein kurzer Test der schwierigsten Anforderung | [Ein Machbarkeitsnachweis](bewerten/machbarkeitsnachweis.md) |
| **Probe** (rehearsal) | Ein vollständiger Migrationslauf auf einer Kopie, gemessen | [Zeitplan](planung/zeitplan.md) |
| **Plan für den Rückweg** (rollback plan) | Wie Sie zur alten Website zurückkehren, wenn die neue versagt | [Checkliste zur Inhaltsmigration](umziehen/checkliste-inhaltsmigration.md) |
| **Bewertungsbogen** (scorecard) | Eine gewichtete Liste von Kriterien mit Belegen | [Der Bewertungsbogen](bewerten/bewertungsbogen.md) |
| **Staging** | Eine Kopie der Website für Tests, Proben und Schulungen | [Hosting und Datenbank auswählen](planung/hosting-und-datenbank-auswaehlen.md) |
| **URL-Alias** | Die lesbare Adresse eines Inhalts | [URLs und Weiterleitungen beim Umzug](umziehen/urls-und-weiterleitungen-beim-umzug.md) |

Weitere Begriffe: [Glossar für Kunden](../kunden/glossar-fuer-kunden.md), [Glossar für Unternehmen](../unternehmen/glossar-fuer-unternehmen.md),
[Glossar zum Ökosystem](../oekosystem/glossar-zum-oekosystem.md).

## Eine Einzelperson

| | |
|---|---|
| Übliche Einrichtung | Eine Installation mit SQLite, ausgeliefert von Velocity oder auf Shared Hosting mit Apache |
| Wer die Arbeit erledigt | Sie, vielleicht mit Hilfe aus den Foren |
| Zuerst lesen | [Erste Schritte](../erste-schritte.md), [Demo und Testinstallation ausprobieren](bewerten/demo-und-testinstallation-ausprobieren.md) |
| Können Sie überspringen | Das Entscheidungsdokument und den formalen Bewertungsbogen |

SQLite bedeutet, dass "a complete Exponential site runs from one file on disk, with no database server to install,
configure or secure", also eine vollständige Exponential-Website aus einer Datei läuft, ohne Datenbankserver, der
installiert, konfiguriert oder abgesichert werden muss ([Unterstützung für SQLite-Datenbanken](../../funktionen/6.0/sqlite-datenbank.md)).
Fragen gehen an die Community ([Wo sich Menschen treffen](../../../eng-us/help/community/joining/where-people-meet.md)).

## Ein kleines Team

| | |
|---|---|
| Übliche Einrichtung | Eine Website, ein Hosting-Unternehmen oder ein Partner, einige Redakteure |
| Wer die Arbeit erledigt | Ein Partner oder ein freier Entwickler; eine Person auf Ihrer Seite ist für die Website verantwortlich |
| Zuerst lesen | [Passt Exponential?](bewerten/passt-exponential.md), [Wer den Betrieb übernimmt](entscheiden/wer-den-betrieb-uebernimmt.md) |
| Können Sie überspringen | Formale Prüfpunkte zwischen Etappen; halten Sie eine kurze Entscheidungsnotiz fest |

Die durchgerechneten Beispiele im Bereich für Unternehmen zeigen Kosten für einen kleinen Shop und eine gemeinnützige
Organisation ([Durchgerechnetes Beispiel: kleiner Shop](../unternehmen/kosten/durchgerechnetes-beispiel-kleiner-shop.md)).

## Eine größere Organisation

| | |
|---|---|
| Übliche Einrichtung | Mehrere Websites oder Sprachen, Staging und Produktion, Rollen und Freigabe |
| Wer die Arbeit erledigt | Ein internes Team mit einem Partner; eine Projektleitung |
| Zuerst lesen | Den ganzen [Lesepfad](lesepfad-zur-einfuehrung.md) und [Projektleitung: hier beginnen](../fuehrung/projektleiter-hier-beginnen.md) |
| Achten Sie auf | [Einführung in Etappen](planung/einfuehrung-in-etappen.md), [Steuerung nach dem Start](nach-der-einfuehrung/steuerung-nach-dem-start.md), [Mehrere Websites und Sprachen planen](../fuehrung/multisite-und-mehrsprachigkeit-planen.md) |

## Eine öffentliche Stelle

Öffentliche Stellen haben einen eigenen Bereich mit Beschaffung, Barrierefreiheit und Compliance:
[Verwaltung: hier beginnen](../verwaltung/verwaltungen-hier-beginnen.md). Verwenden Sie diesen Bereich für die Schritte der
Einführung und jenen für die Anforderungen des öffentlichen Sektors.

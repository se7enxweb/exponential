## Der Start ist ein Prozess, kein Moment

Der Go-live ist ein Tag; der Start dauert, bis Redakteure allein arbeiten und die Routinen laufen. Planen Sie die Wochen
nach dem Go-live als Teil des Projekts ([Die ersten 90 Tage](die-ersten-90-tage.md)).

# Wer ist die Exponential Foundation?

Die **Exponential Foundation** ist die gemeinnützige Organisation hinter dem Open-Source-Projekt Exponential. Diese
Seite erklärt, was die Foundation ist, in welcher Beziehung sie zu 7x steht, welche Produkte zur Exponential-Familie
gehören und für wen jedes davon gedacht ist, wozu sich das Projekt verpflichtet, wie es wächst und wie Sie es
unterstützen oder sich ihm anschließen können.

Jede Aussage nennt ihre Quelle: eine Datei in diesem Repository, eine öffentliche Webseite oder einen Befehl, den Sie
selbst ausführen können. Die Seite beschreibt nichts, was die Quellen nicht sagen. Wo sich eine Angabe nicht prüfen
ließ, sagt die Seite das.

## Kurz gesagt

- **Eine gemeinnützige Organisation für ein Open-Source-Projekt.** Die Foundation beschreibt sich selbst als „a
  501(c)(3) Non-Profit Corporation founded in Seattle, Washington, USA“, gegründet am 19. März 2026
  (<https://foundation.exponential.earth/>).
- **Ihre Mission** ist „dedicated directly to the continued Funding, Adoption, Support, Direction, Education,
  Development, Promotion and Documentation for the Exponential Enterprise Open Source Project“ (dieselbe Seite).
- **Sie betreibt das Projekt.** „This project is operated by the Exponential Foundation a Public Non-Profit
  Corporation“ (<https://exponential.earth/about/project>).
- **7x ist ihr wichtigster Mitwirkender.** Die Foundation nennt 7x „the current leader in contributions both financial,
  code, extension development, new features, infrastructure, maintenance and much much more back to the project“
  (<https://foundation.exponential.earth/>).
- **Sie teilt sich das Urheberrecht.** Der Copyright-Vermerk des Kernels lautet „Copyright (C) 1998 - 2026 7x &
  Exponential Foundation“ ([COPYRIGHT.md](https://github.com/se7enxweb/exponential/blob/main/COPYRIGHT.md)).
- **Alles ist freie Software.** Der Code steht unter der GPL v2 oder später, die Dokumentation unter der GFDL 1.3 oder
  später ([Die Lizenz dieser Dokumentation](../README-LIZENZ.md), [CONTRIBUTING.md](https://github.com/se7enxweb/exponential/blob/main/CONTRIBUTING.md)).

## Die Produkte im Einzelnen

### Exponential 6, der Kernel

**Was es ist.** „Exponential is a professional PHP application framework with advanced CMS (content management system)
functionality. As a CMS its most notable feature is its fully customizable and extendable content model“ (README).
Sein Code war einst der Code von eZ Publish, einem Produkt, das sein Hersteller nach fast achtzehn Jahren im Dienst
der Welt eingestellt hat (Darstellung von 7x, Inhaber, 18. Oktober 2026); Exponential hat diesen Code weitergeführt
und wird als Composer-Paket
`se7enxweb/exponential` veröffentlicht (composer.json). Das README nennt seine wichtigsten Funktionen: selbst
definierte Inhaltsklassen, Versionsverwaltung, Mehrsprachigkeit, eine eingebaute Suchmaschine, rollenbasierte
Berechtigungen, Freigabe und zeitgesteuerte Veröffentlichung, Multisite-Unterstützung, eingebauten E-Commerce,
Workflows, eine Template-Engine, eine Headless-REST-API, eine Datenbank-Abstraktionsschicht, Clustering und eine
Plugin-API.

**Für wen es ist.** Organisationen, die strukturierte Inhalte, mehrere Sites oder mehrere Sprachen aus einer
Installation betreiben, und Entwickler, die Anwendungen auf seinem Framework bauen.

**Wo es steht.** 6.0.14 ist der neueste Tag (7. Juni 2026). Die Linie 6.0.15 bringt neben vielem anderen Velocity,
das Design admin4, ein Audit-Protokoll, Exponential Layouts, Exponential Intelligence, Inhalts-Jobs, Pakete von Anfang
bis Ende, 219 Locales nach der Zählung des README, die LoveStack-Funktionen von Mugo Web und dieses Hilfesystem
([Changelog 6.0.15](../../changelogs/6.0/6.0.15.md), README „Recent improvements“). Die Geschichte jeder Änderung
seit Dezember 2023 steht in [der Geschichte](../geschichte/README.md).

### Exponential Basic

**Was es ist.** „Exponential Basic is the simple to us to use CMS Framework that is for everyone, educational purposes,
personal use and worldwide general“ (Beschreibung des Repositorys
[se7enxweb/exponentialbasic](https://github.com/se7enxweb/exponentialbasic)). Sein Repository ist ein Fork von
`brookinsconsulting/ezcommunity2`, der Linie von eZ Publish 2.2, die Brookins Consulting am Leben erhalten hat
(GitHub-API; [Wer ist 7x?](wer-ist-7x.md#exponential-basic)).

**Für wen es ist.** Lernende, private Sites und alle, die ein kleines CMS wollen.

**Wo es steht.** „Exponential Basic v2.4.0.3: PHP 8.4/8.5.9 ... (MySQL, Postgresql, SQLite, Informix) ... GNU
GPLv2+“, Website <https://basic.exponential.earth> (Beschreibung des Repositorys).

### Exponential Platform 3.2.9

**Was es ist.** „7x Exponential Platform 3.2.9 CMS / DXP based on the last free versions of eZ Platform. Symfony / New
Stack Only. No Exponential 6.x Legacy Support“ (Beschreibung des Repositorys `se7enxweb/exponential-platform`). Seine
`composer.json` setzt die se7enxweb-Forks der Bundles von eZ Platform 3 voraus (Kernel, Admin-UI, REST, GraphQL, Rich
Text, Solr, HTTP-Cache und weitere).

**Für wen es ist.** Teams, die eZ Platform 3 betreiben und mit aktuellem PHP dabei bleiben wollen.

### Exponential Platform Legacy

**Was es ist.** „Exponential Platform Legacy provides a clean distribution of Exponential Platform ... with
Exponential (Legacy) Included (now with SQLite support)“ (Beschreibung des Repositorys). Seine `composer.json` setzt
`se7enxweb/exponential` und `se7enxweb/legacy-bridge` voraus, sodass Exponential 6 neben der Symfony-Plattform läuft.
Das README führt die Linien 2.5.x, 3.3.x, 4.6.x und 5.0.x als „Dual Kernel Symfony CMS which also includes a full copy
of Exponential 6“.

**Für wen es ist.** Bestehende Exponential-Sites, auch solche, die gebaut wurden, als die Software noch eZ Publish hieß,
die Symfony daneben stellen und Schritt für Schritt weitergehen wollen ([Legacy-Bridge](../funktionen/6.0/legacy-bridge.md)).

### Exponential Platform Nexus

**Was es ist.** „Platform v2/v3/v4/v5 + Exponential v6.x (Legacy) + Netgen Media Site + NG Layouts + Symfony
7.4/5.4/3.4 PHP 8.0-8.5 Compatibility“ (Beschreibung des Repositorys `se7enxweb/exponential-platform-nexus`). Seine
`composer.json` setzt `se7enxweb/exponential`, `netgen/layouts-core`, `netgen/layouts-standard` und
`netgen/layouts-ui` voraus und liefert damit den Layout-Editor mit. Das README nennt Nexus 1.0.0.x bis 1.3.0.x für
Platform v2.5 bis v5. Es gibt eine CJW-Variante (`se7enxweb/cjw-exponential-platform-nexus`) und einen sofort
lauffähigen Starter (`exponential-platform-nexus-starter`, laut Beschreibung „Currently In Public Beta“)
([Nexus-Starter](../funktionen/6.0/plattform-nexus-starter.md)).

**Für wen es ist.** Agenturen und Teams, die in wenigen Minuten eine vollständige Website mit Demo-Inhalten, Layouts
und einer Administration wollen.

### Exponential Platform DXP

**Was es ist.** „Exponential Platform DXP is a free, open-source Digital Experience Platform built on the Symfony
framework, the community continuation of the eZ Platform and Ibexa OSS line maintained by 7x“ (README). Das
Metapaket `se7enxweb/exponential-platform-dxp` beschreibt sich als „Stable; Open Source“ mit der Lizenz
„GPL-2.0-or-later or proprietary“ (seine `composer.json`).

Was es mitliefert, gelesen aus seinen Abhängigkeiten: die Admin-UI, Inhaltsformulare, REST, GraphQL und die
GraphiQL-Konsole, HTTP-Cache, Core- und Solr-Suche, die Feldtypen Rich Text, Matrix und Query, Benachrichtigungen,
Messenger, Cron, das Standard-Design, Twig-Komponenten, JWT-Authentifizierung und `se7enxweb/layouts-core`. Was es
**nicht** mitliefert: einen Layout-Editor (keine Layouts-UI und keine Standardblöcke), einen Freigabe-Workflow, einen
Zeitplaner oder den Legacy-Kernel. Wenn Sie Exponential 6 neben Symfony wollen, wählen Sie Legacy oder Nexus.

Was es laut README gegenüber Ibexa DXP OSS ergänzt: „The SQLite database driver and framework support“, aktuelles PHP
(„PHP 8.3 and later“), „A path from Exponential 6“ über die Dual-Kernel-Distributionen und „A name of its own“.

**Für wen es ist.** Organisationen mit vielen strukturierten Inhalten, Teams, die eZ Platform oder Ibexa OSS
verlassen, und Symfony-Entwickler (README, „Who it is for“). Beginnen Sie mit dem
[DXP-Skeleton](../funktionen/6.0/plattform-dxp-skeleton.md).

### Exponential Velocity

**Was es ist.** „A pure PHP web server. No nginx, no Apache, no php-fpm. One process serves static files, PHP
scripts, WebSocket connections, and a live dashboard“ (README von `se7enxweb/exponential-velocity`). Er „began as a
fork of the Qbix web server engine“ und hält die Anwendung zwischen den Anfragen geladen (README von Exponential). Er
steht unter der MIT-Lizenz (seine `composer.json`).

**Für wen es ist.** Jede Exponential-Site: Er ist „the recommended engine for every stage, from development to
production“ (README, „Engines“). FrankenPHP ist „the production-ready alternative“, der eingebaute Server von PHP die
Vorgabe für die Entwicklung.

**Wo es steht.** Erste Commits im Juli 2026, erstes Release `v0.0.1` im September 2026, seit dem 22. September 2026
Teil von Exponential ([Velocity-Chronik](../geschichte/velocity/README.md)); das README nennt es als erforderlich in `~0.0.4.55`; seit dem Release 0.0.4.54 läuft es unter PHP 8.0.

### Exponential Intelligence

**Was es ist.** „A writing assistant built into the administration interface“, der „writes drafts, as the signed-in
editor and with that editor's own permissions“, nie selbst veröffentlicht und mit gehosteten Anbietern in den USA oder
der EU oder mit einem lokalen Open-Weight-Modell arbeitet (README, „Exponential Intelligence“). Paket
`se7enxweb/expai`.

**Für wen es ist.** Redakteure, Projektleiter und Content-Autoren („Great for project managers and content writers!“,
Beschreibung des Repositorys).

**Wo es steht.** Seit 6.0.15 in `composer.json` vorausgesetzt; „A new installation activates it by default“, und es
„sends nothing anywhere until you add a provider key“ (README). Lesen Sie
[Exponential Intelligence](../funktionen/6.0/erweiterungen/expai.md), bevor Sie es einschalten.

### Exponential Layouts

**Was es ist.** „A visual page builder for Exponential. It brings the Netgen Layouts concept to the Exponential
kernel: a layout is a saved arrangement of blocks in zones, and a rule decides which pages get it“ (README). Pakete
`se7enxweb/explayouts` und die Familie `explayouts-*`.

**Für wen es ist.** Redakteure, die Seiten ohne Template-Arbeit umgestalten, und Designer
([Der Layout-Editor](layout-editor.md)).

### AdminUI

**Was es ist.** „A feature complete port of the legendary Netgen AdminUI Administration UI. This solution depends on
Exponential 6.0.15* or greater“ (Beschreibung des Repositorys `se7enxweb/exp_adminui`). Es ist eines der Designs der
Administration; Admin 4 ist dasjenige, das die meisten Installationen verwenden
([Hilfe für Redakteure und Benutzer](README.md)).

### Das Hilfesystem

**Was es ist.** Die Hilfe in der Administration, die die per Git verwaltete Dokumentation aus `doc/` anzeigt, sicher
dargestellt, durchsuchbar und nach Zielgruppe gefiltert, mit einer Kontexthilfe-Schaltfläche „?“ auf jeder Seite
([Hilfesystem](../funktionen/6.0/hilfesystem.md)). Ihre Seiten sind freie Dokumentation
([Freie Dokumentation](freie-dokumentation.md)). Hilfeseiten, die als Inhalt in der Datenbank geschrieben werden, sind
in Phasen geplant; Phase 1 ist in 6.0.15 enthalten ([Hilfe als Inhalt](../funktionen/6.0/hilfeinhalte.md)).

### Das Ökosystem der Erweiterungen

`composer.json` setzt 66 Pakete `se7enxweb/*` voraus: Themes, das PayPal-Gateway des Shops, Tags, Newsletter,
Zwei-Faktor-Authentifizierung, den Oracle-Treiber, die REST-API, die Job-Warteschlange, den Seitenbaukasten und mehr.
Die Liste mit je einer Zeile steht auf [Wer ist 7x?](wer-ist-7x.md#das-ökosystem-der-erweiterungen) und in
[Die Standard-Erweiterungsdistribution](../funktionen/6.0/standard-extension-auslieferung.md). Auf Packagist hat der
Vendor se7enxweb 219 Pakete (<https://packagist.org/packages/list.json?vendor=se7enxweb>).

### Begleitprojekte

- **request-shield** ist ein Projekt von CJW Network (<https://github.com/cjw-network/request-shield>), nicht der
  Foundation. Exponential dokumentiert, wie sein HTTP-Cache mit vorgeschaltetem request-shield arbeitet
  ([HTTP-Cache](../bc/6.0/httpcache.md)) und wie man es unter Velocity lädt (`config.php-RECOMMENDED`). Seine Website
  <https://request-shield.com/> war nicht öffentlich, als diese Seite geschrieben wurde; deshalb steht hier nicht mehr
  dazu.
- **Der Paketserver** `exponential.packages.exponential.earth` liefert die Pakete des Setup-Assistenten aus („Users do
  not need to use this server outside the setup wizard usage“, Beschreibung des Repositorys).
- **AdminNeo** über `sevenx_dse`, den Datenbank-Quelltexteditor ([sevenx_dse](../funktionen/6.0/erweiterungen/sevenx_dse.md)).

| 8.0 | Die älteste unterstützte Version, sodass das mitgelieferte PHP von Red Hat Enterprise Linux 9 es ausführt, ab dem Velocity-Release 0.0.4.54 auch unter Velocity (bis dahin brauchte Velocity 8.1) | README, [Unterstützung für PHP 8.0](../bc/6.0/php-8.0-unterstuetzung.md) |

Die kontinuierliche Integration führt die Testsuite auf PHP 8.1 bis 8.5 aus und prüft, dass PHP 8.0 noch startet, bei
jedem Push auf `main` und bei jedem Pull-Request ([CI](../bc/6.0/ci.md)).

### Sicherheitskorrekturen

- „Exponential 6.0 is the maintained line. Security fixes are made on the `main` branch ... and published with the
  next 6.0.x release“ ([SECURITY.md](https://github.com/se7enxweb/exponential/blob/main/SECURITY.md)).
- Melden Sie Probleme vertraulich an security@se7enx.com: „You can expect a first answer within one business day“
  (SECURITY.md).
- 5.x, 4.x, 3.x und ältere Versionen werden nicht unterstützt (SECURITY.md).
- Die Härtung ist für Administratoren dokumentiert: [Sicherheitshärtung](sicherheitshaertung.md) und
  [Kapitel 13 des Installationsbuchs](../installation/13-sicherheitshaertung.md).

### Releases und Versionsnummern

- **Veröffentlichte Versionen ändern sich nie.** „A published tag is never changed: a fix for a problem in `v6.0.14`
  or an earlier tag reaches you as the next release, not as a corrected copy of the old one“ (SECURITY.md).
- **Die letzte Stelle zählt weiter.** „After `0.1.9` the next release is `0.1.10`; only the last position counts up
  unless you decide otherwise“, und Versionen werden mit `--sort=version:refname` sortiert, nicht nach Namen
  ([Erweiterungen, „Release it“](../anleitungen/extensions.md#7-die-extension-veröffentlichen); dasselbe gilt für Velocity in
  [Den Code beziehen](../installation/03-den-code-beschaffen.md)).
- **Eine Erweiterung nennt ihre Version in ihren eigenen Dateien.** `ezinfo.php` und `extension.xml` tragen die
  Release-Nummer ([Erweiterungen](../anleitungen/extensions.md#7-die-extension-veröffentlichen)).
- **Verteilung über GitHub und Packagist.** Jedes Paket ist ein GitHub-Repository unter se7enxweb und ein
  Composer-Paket; `composer require` oder ein Git-Klon installiert es ([Den Code beziehen](../installation/03-den-code-beschaffen.md)).

### Sicherheits-Header und die Content Security Policy

Exponential sendet eine Content Security Policy aus `site.ini [ContentSecurityPolicy]`; „By default it is
**report-only on the administration** and off on the sites“ ([Content Security Policy](../funktionen/6.0/content-security-policy.md)).
Neue Templates der Administration enthalten keine Inline-Styles oder -Skripte, damit eine strenge Richtlinie
durchgesetzt werden kann ([CONTRIBUTING.md](https://github.com/se7enxweb/exponential/blob/main/CONTRIBUTING.md)).

## Wie das Projekt wächst

### Mitwirkende und Pull-Requests

- **Jeder Pull-Request wird gemergt.** „Every pull request is merged, and its commits are kept as the contributor wrote
  them and never rewritten“ ([CI](../bc/6.0/ci.md), Commit-Nachrichten). Was korrigiert werden muss, wird in Commits
  darüber korrigiert.
- **Beiträge bleiben frei.** „any modifications made to the project are also released under the same GPLv2 or
  later license“ ([CONTRIBUTING.md](https://github.com/se7enxweb/exponential/blob/main/CONTRIBUTING.md)).
- **Wer beiträgt.** Seit Dezember 2023 kamen Pull-Requests von se7enxweb, [ekked](https://github.com/ekked),
  [fwoldt](https://github.com/fwoldt), [netgen](https://github.com/netgen), brookinsconsulting,

  Menschen eZ Publish gebaut ([Wer ist 7x?](wer-ist-7x.md#mitwirkende-und-freunde-des-projekts)).
- **Die Arbeit anderer Projekte, mit Nennung.** Die LoveStack-Verbesserungen von Mugo Web wurden „with full credit to
  Mugo Web“ nachgebaut (README); Exponential Layouts portiert das Konzept von Netgen Layouts (README).

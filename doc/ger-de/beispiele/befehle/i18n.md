# exp:i18n

Die Übersetzungs-Fallbacks: pro Locale die Kette der Übersetzungen, auf die sie zurückfällt, und wie viel vom Kernel und von jeder Erweiterung übersetzt angezeigt wird; --check für CI.

Skript `bin/php/i18n.php`, Code in `kernel/private/classes/commands/i18n.php`. Führen Sie es im Wurzelverzeichnis der Installation aus, als der Benutzer, unter dem der Webserver läuft:

```bash
./console exp:i18n --help
php bin/php/i18n.php --help
```

## Hilfetext

Was `--help` ausgibt, so wie der Befehl es schreibt:

```text
The translation fallbacks (i18n.ini [TranslationSettings], doc/eng-us/languages.md)

./console exp:i18n fallbacks                         every locale: its chain, kernel and extension coverage
./console exp:i18n fallbacks --only=fallback         only the locales translated through a fallback
./console exp:i18n fallbacks --locale=esl-AR,ger-AT  each step with its rule, and every extension
./console exp:i18n fallbacks --format=json           one JSON object
./console exp:i18n check [--strict]                  cycles, chains too long, missing targets, rules
                                                     that are none: exit 1 when there is one (CI)
./console exp:i18n coverage                          the totals and the world map at the top of
                                                     doc/eng-us/languages.md and doc/ger-de/sprachen.md:
                                                     write what changed (--raster: every WebP copy)
./console exp:i18n coverage --check                  compare only: exit 1 when they are out of date
./console exp:i18n waves                             the translation waves at the top of
                                                     doc/eng-us/translation-waves.md and
                                                     doc/ger-de/uebersetzungswellen.md: write what changed
./console exp:i18n waves --check                     compare only: exit 1 when a percentage changed or a
                                                     size is more than 3 % off
./console exp:i18n waves --list                      the whole queue, one wave a line
./console exp:i18n waves --wave=ara-SA/H-help        the pages (contexts, files) of a wave, which are done

Exit code: 0 fine, 1 problems found (check, or --check), 2 usage error.
```

## Optionen

| Option | Wert | Hilfe |
|---|---|---|
| `--locale` | erforderlich | Nur diese Locales, durch Kommas getrennt (esl-AR,ger-AT): jeder Schritt der Kette und jede Erweiterung |
| `--format` | erforderlich | table (Standard) oder json |
| `--only` | erforderlich | Mit der Liste: own (eine eigene Übersetzung), fallback (über einen Fallback übersetzt) oder untranslated |
| `--check` |  | Nach der Liste die Fallbacks so prüfen wie die Aktion check; mit coverage: nur vergleichen, nichts ändern |
| `--strict` |  | Mit check: auch Warnungen (eine konfigurierte Locale ohne Locale-Datei, eine Kette ohne Übersetzung) lassen es scheitern |
| `--no-extensions` |  | Die Abdeckung der Erweiterungen weglassen (das erste Lesen ihrer Dateien dauert Sekunden) |
| `--raster` |  | Mit coverage: die WebP-Kopie jeder Karte neu schreiben, nicht nur die der geänderten Karten |
| `--date` | erforderlich | Mit coverage: das Datum der Zahlen, wenn sie sich geändert haben (JJJJ-MM-TT, Standard heute) |
| `--list` |  | With waves: print the whole queue, one wave a line |
| `--wave` | erforderlich | With waves: the pages, contexts or files of one wave (ara-SA/H-help) or work set (A03), and which are done |

Aus den Optionsdefinitionen im Code gelesen (`startup()`, `getOptions()`, `options()` oder `ezcConsoleOption`). Jedes Skript nimmt außerdem die Standardoptionen des Skript-Frameworks (`--help`, `--siteaccess`, `--debug`, `--quiet`, `--allow-root-user` ...).

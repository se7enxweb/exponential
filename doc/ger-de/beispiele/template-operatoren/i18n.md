# Der Template-Operator i18n

Registriert in `kernel/common/eztemplateautoload.php` von der Klasse `eZi18nOperator` (`kernel/common/ezi18noperator.php`).
Dieselbe Klasse registriert auch: [x18n](x18n.md), [d18n](d18n.md).

## Parameter

| Parameter | Typ | Erforderlich | Standard |
|---|---|---|---|
| `context` | string | nein | `false` |
| `comment` | string | nein | `''` |
| `arguments` | hash | nein | `false` |

Der Operator arbeitet mit seiner Eingabe: dem Wert vor `|`.

## Beispiel

Aus der Parameterliste oben gebildet; die Werte sind Platzhalter (die Template-Hinweise des Operators entscheiden, ob er eine Eingabe nimmt).

```tpl
{$value|i18n( 'context', 'comment', hash() )}
```

## In einem ausgelieferten Template

Die erste Verwendung in den Templates dieser Installation, `design/admin/override/templates/admin_preview/article.tpl` Zeile 39:

```tpl
<h6>{'Comments allowed'|i18n( 'design/admin/preview/article' )}:</h6>
```

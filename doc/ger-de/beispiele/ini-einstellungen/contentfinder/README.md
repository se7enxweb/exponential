# contentfinder.ini

Die ausgelieferten Einstellungen von `settings/contentfinder.ini`: 1 Blöcke, 7 Einstellungen.

> The content finder: find content by an object, node, attribute or version id, a remote id,  
> a URL alias or the path of a file, and act on it. Guide: doc/eng-us/features/6.0/content-finder.md  
>
> Do not edit this file: override it in settings/override/contentfinder.ini.append.php or in  
> a siteaccess's contentfinder.ini.append.php.  
>
> Who may use it is decided by role policies, not here: contentfinder/search opens it,  
> contentfinder/delete is needed as well for its actions, and each result shows and allows only  
> what the content policies of the object allow (content/read, content/versionread,  
> content/remove, content/restore, content/cleantrash, content/versionremove).

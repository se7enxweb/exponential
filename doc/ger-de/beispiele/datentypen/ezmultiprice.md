# Der Datentyp ezmultiprice (Multi-Preis)

Klasse `eZMultiPriceType` in `kernel/classes/datatypes/ezmultiprice/ezmultipricetype.php`; Bezeichner `ezmultiprice`, aufgeführt in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## Was er speichert

Die Spalten der Attributtabellen, die seine Klasse liest oder schreibt: `data_float1`, `data_int1`, `data_text`, `data_text1` (`data_text`, `data_int`, `data_float` und `sort_key_*` gehören zum Objektattribut; `data_text1` ... `data_int4` sind die Einstellungen des Klassenattributs). Durch Lesen der Klasse ermittelt: eine Heuristik.

## In Templates

`my_attribute` steht für den Bezeichner eines Attributs dieses Typs in Ihrer Klasse:

```tpl
{def $attribute = $node.data_map.my_attribute}
{if $attribute.has_content}
    {attribute_view_gui attribute=$attribute}
{/if}
{* der Wert, wie der Datentyp ihn zurückgibt (objectAttributeContent()) *}
{$attribute.content|attribute( show, 1 )}
```

Das ausgelieferte Template, das ihn anzeigt (`attribute_view_gui`), `design/standard/templates/content/datatype/view/ezmultiprice.tpl` (die ersten 25 Zeilen):

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{def $multiprice = $attribute.content
     $price_list = $multiprice.inc_vat_price_list
     $currency_list = $multiprice.currency_list
     $currency = false()}

    {if $multiprice.has_discount}
        {def $discount_price_list = $multiprice.discount_inc_vat_price_list
             $price = false()}
        <table cellspacing="10">
            <tr>
                <th>{'Currency'|i18n( 'design/standard/content/datatype' )}</th>
                <th>{'Price'|i18n( 'design/standard/content/datatype' )}</th>
                <th>{'Your price'|i18n( 'design/standard/content/datatype' )}</th>
                <th>{'You save'|i18n( 'design/standard/content/datatype' )}</th>
            </tr>

            {foreach $discount_price_list as $pos => $discount_price}
                {set price = $price_list[$pos]
                     currency = $currency_list[$price.currency_code]}
                <tr>
                    <td>{$price.currency_code|wash}</td>
                    <td><strike>{$price.value|l10n( 'currency', $currency.locale, '' )}</strike></td>
                    <td>{$discount_price.value|l10n( 'currency', $currency.locale, '' )}</td>
                    <td>{sub($price.value, $discount_price.value)|l10n( 'currency', $currency.locale, '' )} ( {$multiprice.discount_percent} % )</td>
```

Das ausgelieferte Template, das ihn bearbeitet (`attribute_edit_gui`), `design/standard/templates/content/datatype/edit/ezmultiprice.tpl` (die ersten 25 Zeilen):

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{default attribute_base=ContentObjectAttribute}

<div class="block">
{*<fieldset>*}
{def $multi_price = $attribute.content
     $custom_price_list = $multi_price.custom_price_list
     $auto_price_list = $multi_price.auto_price_list
     $currency_list = $multi_price.auto_currency_list}
    {if or( count( $custom_price_list ), count( $auto_price_list ) )}
        <table class="list" cellspacing="0">
        <tr>
            <th class="tight">&nbsp;</th>
            <th>{'Currency'|i18n( 'design/standard/content/datatype' )}</th>
            <th>{'Value'|i18n( 'design/standard/content/datatype' )}</th>
        </tr>
            {foreach $auto_price_list as $index => $price}
            <tr>
                {* Remove. *}
                <td><input id="ezcoa-{if ne( $attribute_base, 'ContentObjectAttribute' )}{$attribute_base}-{/if}{$attribute.contentclassattribute_id}_{$attribute.contentclass_attribute_identifier}_remove_{$index}" class="ezcc-{$attribute.object.content_class.identifier} ezcca-{$attribute.object.content_class.identifier}_{$attribute.contentclass_attribute_identifier}" type="checkbox" name="{$attribute_base}_remove_price_array_{$attribute.id}[{$price.currency_code}]" title="{'Select price for removal.'|i18n( 'design/standard/content/datatype' )}" disabled="disabled" /></td>

                {* Currency *}
                <td>{$price.currency_code|wash}</td>

                {* Value *}
```

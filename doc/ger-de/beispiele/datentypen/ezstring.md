# Der Datentyp ezstring (Textzeile)

Klasse `eZStringType` in `kernel/classes/datatypes/ezstring/ezstringtype.php`; Bezeichner `ezstring`, aufgeführt in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## Was er speichert

Die Spalten der Attributtabellen, die seine Klasse liest oder schreibt: `data_int1`, `data_int2`, `data_text`, `data_text1`, `sort_key_string` (`data_text`, `data_int`, `data_float` und `sort_key_*` gehören zum Objektattribut; `data_text1` ... `data_int4` sind die Einstellungen des Klassenattributs). Durch Lesen der Klasse ermittelt: eine Heuristik.
Sortierung: `sortKeyType()` gibt `string` zurück.
Er ist von der Suche indiziert; ein Informationssammler (Formulare); aus einer einfachen Zeichenkette befüllbar.

## In Templates

`my_attribute` steht für den Bezeichner eines Attributs dieses Typs in Ihrer Klasse:

```tpl
{def $attribute = $node.data_map.my_attribute}
{if $attribute.has_content}
    {attribute_view_gui attribute=$attribute}
{/if}
{* der Wert, wie der Datentyp ihn zurückgibt (objectAttributeContent()) *}
{$attribute.content|attribute( show, 1 )}
```

Das ausgelieferte Template, das ihn anzeigt (`attribute_view_gui`), `design/standard/templates/content/datatype/view/ezstring.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{$attribute.data_text|wash( xhtml )}
```

Das ausgelieferte Template, das ihn bearbeitet (`attribute_edit_gui`), `design/standard/templates/content/datatype/edit/ezstring.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{default attribute_base='ContentObjectAttribute'
         html_class='full'}
<input id="ezcoa-{if ne( $attribute_base, 'ContentObjectAttribute' )}{$attribute_base}-{/if}{$attribute.contentclassattribute_id}_{$attribute.contentclass_attribute_identifier}" class="{eq( $html_class, 'half' )|choose( 'box', 'halfbox' )} ezcc-{$attribute.object.content_class.identifier} ezcca-{$attribute.object.content_class.identifier}_{$attribute.contentclass_attribute_identifier}" type="text" size="70" name="{$attribute_base}_ezstring_data_text_{$attribute.id}" value="{$attribute.data_text|wash( xhtml )}" />
{/default}
```

Überschreiben Sie sie für ein Klassenattribut in einer `override.ini.append.php` mit `Source=content/datatype/view/ezstring.tpl` und einer Bedingung auf `attribute_identifier` (siehe [Ein Template-Override](../kochbuch/template-override.md)).

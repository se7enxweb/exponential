# Der Datentyp ezcountry (Land)

Klasse `eZCountryType` in `kernel/classes/datatypes/ezcountry/ezcountrytype.php`; Bezeichner `ezcountry`, aufgeführt in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## Was er speichert

Die Spalten der Attributtabellen, die seine Klasse liest oder schreibt: `data_int1`, `data_text`, `data_text5` (`data_text`, `data_int`, `data_float` und `sort_key_*` gehören zum Objektattribut; `data_text1` ... `data_int4` sind die Einstellungen des Klassenattributs). Durch Lesen der Klasse ermittelt: eine Heuristik.
Sortierung: `sortKeyType()` gibt `string` zurück.
Er ist von der Suche indiziert; ein Informationssammler (Formulare); aus einer einfachen Zeichenkette befüllbar.

## In Templates

`my_attribute` steht für den Bezeichner eines Attributs dieses Typs in Ihrer Klasse:

```tpl
{def $attribute = $node.data_map.my_attribute}
{if $attribute.has_content}
    {attribute_view_gui attribute=$attribute}
{/if}
{* der Wert, wie der Datentyp ihn zurückgibt (objectAttributeContent()) *}
{$attribute.content|attribute( show, 1 )}
```

Das ausgelieferte Template, das ihn anzeigt (`attribute_view_gui`), `design/standard/templates/content/datatype/view/ezcountry.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{if $attribute.has_content}
   {if is_array( $attribute.content.value )}
       {foreach $attribute.content.value as $country}
           <p>{$country.Name|wash( xhtml )}</p>
       {/foreach}
   {else}
       {$attribute.content.value|wash( xhtml )}
   {/if}
{else}
   {'Not specified'|i18n( 'design/standard/content/datatype' )}
{/if}
```

Das ausgelieferte Template, das ihn bearbeitet (`attribute_edit_gui`), `design/standard/templates/content/datatype/edit/ezcountry.tpl`:

     {/if}

    {if $country|is_array|not}
        {* Backwards compatibility: an old value is the country's name *}
        {include uri='design:country/options.tpl' country_selected=array( $country ) country_multiple=$class_content.multiple_choice}
    {else}
        {include uri='design:country/options.tpl' country_selected_map=$country country_multiple=$class_content.multiple_choice}

# Der Datentyp ezobjectrelationlist (Objekt Vernüpfungsliste)

Klasse `eZObjectRelationListType` in `kernel/classes/datatypes/ezobjectrelationlist/ezobjectrelationlisttype.php`; Bezeichner `ezobjectrelationlist`, aufgeführt in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## Was er speichert

Die Spalten der Attributtabellen, die seine Klasse liest oder schreibt: `data_text`, `data_text5` (`data_text`, `data_int`, `data_float` und `sort_key_*` gehören zum Objektattribut; `data_text1` ... `data_int4` sind die Einstellungen des Klassenattributs). Durch Lesen der Klasse ermittelt: eine Heuristik.
Er ist von der Suche indiziert.

## In Templates

`my_attribute` steht für den Bezeichner eines Attributs dieses Typs in Ihrer Klasse:

```tpl
{def $attribute = $node.data_map.my_attribute}
{if $attribute.has_content}
    {attribute_view_gui attribute=$attribute}
{/if}
{* der Wert, wie der Datentyp ihn zurückgibt (objectAttributeContent()) *}
{$attribute.content|attribute( show, 1 )}
```

Das ausgelieferte Template, das ihn anzeigt (`attribute_view_gui`), `design/standard/templates/content/datatype/view/ezobjectrelationlist.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{def $check_visibility = ezini( 'SiteAccessSettings', 'ShowHiddenNodes' )|ne( 'true' )
     $content = false()
     $has_readable_related = false()}
{section var=Relations loop=$attribute.content.relation_list}
{if $Relations.item.in_trash|not()}
    {set $content = fetch( content, object, hash( object_id, $Relations.item.contentobject_id ) )}
    {if or( $content.can_read, $content.can_view_embed)}
        {if or(
            $check_visibility|not,
            fetch( content, node, hash( node_id, $Relations.item.node_id ) ).is_invisible|not
        )}
            {content_view_gui view=embed content_object=$content}<br>
            {set $has_readable_related = true()}
        {/if}
    {/if}
{/if}
{/section}
{if $has_readable_related|not()}
{'There are no related objects.'|i18n( 'design/standard/content/datatype' )}
{/if}
{undef $check_visibility $content $has_readable_related}
```

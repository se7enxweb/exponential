# Der Datentyp ezidentifier (Bezeichner)

Klasse `eZIdentifierType` in `kernel/classes/datatypes/ezidentifier/ezidentifiertype.php`; Bezeichner `ezidentifier`, aufgeführt in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## Was er speichert

Die Spalten der Attributtabellen, die seine Klasse liest oder schreibt: `data_int`, `data_int1`, `data_int2`, `data_int3`, `data_text`, `data_text1`, `data_text2` (`data_text`, `data_int`, `data_float` und `sort_key_*` gehören zum Objektattribut; `data_text1` ... `data_int4` sind die Einstellungen des Klassenattributs). Durch Lesen der Klasse ermittelt: eine Heuristik.
Sortierung: `sortKeyType()` gibt `string` zurück.
Er ist von der Suche indiziert.

## In Templates

`my_attribute` steht für den Bezeichner eines Attributs dieses Typs in Ihrer Klasse:

```tpl
{def $attribute = $node.data_map.my_attribute}
{if $attribute.has_content}
    {attribute_view_gui attribute=$attribute}
{/if}
{* der Wert, wie der Datentyp ihn zurückgibt (objectAttributeContent()) *}
{$attribute.content|attribute( show, 1 )}
```

Das ausgelieferte Template, das ihn anzeigt (`attribute_view_gui`), `design/standard/templates/content/datatype/view/ezidentifier.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{$attribute.content|wash}
```

Das ausgelieferte Template, das ihn bearbeitet (`attribute_edit_gui`), `design/standard/templates/content/datatype/edit/ezidentifier.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{$attribute.content|wash}
```

Überschreiben Sie sie für ein Klassenattribut in einer `override.ini.append.php` mit `Source=content/datatype/view/ezidentifier.tpl` und einer Bedingung auf `attribute_identifier` (siehe [Ein Template-Override](../../../eng-us/examples/cookbook/template-override.md)).

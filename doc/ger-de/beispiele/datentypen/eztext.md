# Der Datentyp eztext (Textabschnitt)

Klasse `eZTextType` in `kernel/classes/datatypes/eztext/eztexttype.php`; Bezeichner `eztext`, aufgeführt in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## Was er speichert

Die Spalten der Attributtabellen, die seine Klasse liest oder schreibt: `data_int1`, `data_text` (`data_text`, `data_int`, `data_float` und `sort_key_*` gehören zum Objektattribut; `data_text1` ... `data_int4` sind die Einstellungen des Klassenattributs). Durch Lesen der Klasse ermittelt: eine Heuristik.
Er ist von der Suche indiziert; ein Informationssammler (Formulare); aus einer einfachen Zeichenkette befüllbar.

## In Templates

`my_attribute` steht für den Bezeichner eines Attributs dieses Typs in Ihrer Klasse:

```tpl
{def $attribute = $node.data_map.my_attribute}
{if $attribute.has_content}
    {attribute_view_gui attribute=$attribute}
{/if}
{* der Wert, wie der Datentyp ihn zurückgibt (objectAttributeContent()) *}
{$attribute.content|attribute( show, 1 )}
```

Das ausgelieferte Template, das ihn anzeigt (`attribute_view_gui`), `design/standard/templates/content/datatype/view/eztext.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{$attribute.content|wash( xhtml )|nl2br}
```

Das ausgelieferte Template, das ihn bearbeitet (`attribute_edit_gui`), `design/standard/templates/content/datatype/edit/eztext.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{default attribute_base='ContentObjectAttribute'
         html_class='full'}
<textarea id="ezcoa-{if ne( $attribute_base, 'ContentObjectAttribute' )}{$attribute_base}-{/if}{$attribute.contentclassattribute_id}_{$attribute.contentclass_attribute_identifier}" class="{eq( $html_class, 'half' )|choose( 'box', 'halfbox' )} ezcc-{$attribute.object.content_class.identifier} ezcca-{$attribute.object.content_class.identifier}_{$attribute.contentclass_attribute_identifier}" name="{$attribute_base}_data_text_{$attribute.id}" cols="70" rows="{$attribute.contentclass_attribute.data_int1|wash}">
{$attribute.content|wash}</textarea>
{/default}
```

Überschreiben Sie sie für ein Klassenattribut in einer `override.ini.append.php` mit `Source=content/datatype/view/eztext.tpl` und einer Bedingung auf `attribute_identifier` (siehe [Ein Template-Override](../../../eng-us/examples/cookbook/template-override.md)).

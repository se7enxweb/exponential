# Der Datentyp ezurl (URL)

Klasse `eZURLType` in `kernel/classes/datatypes/ezurl/ezurltype.php`; Bezeichner `ezurl`, aufgeführt in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## Was er speichert

Die Spalten der Attributtabellen, die seine Klasse liest oder schreibt: `data_int`, `data_text`, `data_text1` (`data_text`, `data_int`, `data_float` und `sort_key_*` gehören zum Objektattribut; `data_text1` ... `data_int4` sind die Einstellungen des Klassenattributs). Durch Lesen der Klasse ermittelt: eine Heuristik.

## In Templates

`my_attribute` steht für den Bezeichner eines Attributs dieses Typs in Ihrer Klasse:

```tpl
{def $attribute = $node.data_map.my_attribute}
{if $attribute.has_content}
    {attribute_view_gui attribute=$attribute}
{/if}
{* der Wert, wie der Datentyp ihn zurückgibt (objectAttributeContent()) *}
{$attribute.content|attribute( show, 1 )}
```

Das ausgelieferte Template, das ihn anzeigt (`attribute_view_gui`), `design/standard/templates/content/datatype/view/ezurl.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{* A stored URL with a script or data scheme (javascript:, vbscript:, data:) is
   shown as text, never as a link: display_info.view.url_is_linkable is set by
   eZURLType, which recognises the scheme also when it is disguised. *}
{if $attribute.display_info.view.url_is_linkable}
{if $attribute.data_text}
<a href="{$attribute.content|wash( xhtml )}">{$attribute.data_text|wash( xhtml )}</a>
{else}
<a href="{$attribute.content|wash( xhtml )}">{$attribute.content|wash( xhtml )}</a>
{/if}
{else}
{if $attribute.data_text}{$attribute.data_text|wash( xhtml )}{else}{$attribute.content|wash( xhtml )}{/if}
{/if}
```

Das ausgelieferte Template, das ihn bearbeitet (`attribute_edit_gui`), `design/standard/templates/content/datatype/edit/ezurl.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{default attribute_base=ContentObjectAttribute}

{if ne( $attribute_base, 'ContentObjectAttribute' )}
    {def $id_base = concat( 'ezcoa-', $attribute_base, '-', $attribute.contentclassattribute_id, '_', $attribute.contentclass_attribute_identifier )}
{else}
    {def $id_base = concat( 'ezcoa-', $attribute.contentclassattribute_id, '_', $attribute.contentclass_attribute_identifier )}
{/if}

{* URL. *}
<div class="block">
    <label for="{$id_base}_url">{'URL'|i18n( 'design/standard/content/datatype' )}:</label>
    <input id="{$id_base}_url" class="box ezcc-{$attribute.object.content_class.identifier} ezcca-{$attribute.object.content_class.identifier}_{$attribute.contentclass_attribute_identifier}" type="text" size="70" name="{$attribute_base}_ezurl_url_{$attribute.id}" value="{$attribute.content|wash( xhtml )}" />
</div>

{* Text. *}
<div class="block">
    <label for="{$id_base}_text">{'Text'|i18n( 'design/standard/content/datatype' )}:</label>
    <input id="{$id_base}_text" class="box ezcc-{$attribute.object.content_class.identifier} ezcca-{$attribute.object.content_class.identifier}_{$attribute.contentclass_attribute_identifier}" type="text" size="70" name="{$attribute_base}_ezurl_text_{$attribute.id}" value="{$attribute.data_text|wash( xhtml )}" />
</div>
```

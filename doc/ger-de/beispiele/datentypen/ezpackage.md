# Der Datentyp ezpackage (Paket)

Klasse `eZPackageType` in `kernel/classes/datatypes/ezpackage/ezpackagetype.php`; Bezeichner `ezpackage`, aufgeführt in `settings/content.ini` `[DataTypeSettings] AvailableDataTypes[]`.

## Was er speichert

Die Spalten der Attributtabellen, die seine Klasse liest oder schreibt: `data_float`, `data_int`, `data_int1`, `data_text`, `data_text1` (`data_text`, `data_int`, `data_float` und `sort_key_*` gehören zum Objektattribut; `data_text1` ... `data_int4` sind die Einstellungen des Klassenattributs). Durch Lesen der Klasse ermittelt: eine Heuristik.
Sortierung: `sortKeyType()` gibt `string` zurück.

## In Templates

`my_attribute` steht für den Bezeichner eines Attributs dieses Typs in Ihrer Klasse:

```tpl
{def $attribute = $node.data_map.my_attribute}
{if $attribute.has_content}
    {attribute_view_gui attribute=$attribute}
{/if}
{* der Wert, wie der Datentyp ihn zurückgibt (objectAttributeContent()) *}
{$attribute.content|attribute( show, 1 )}
```

Das ausgelieferte Template, das ihn anzeigt (`attribute_view_gui`), `design/standard/templates/content/datatype/view/ezpackage.tpl`:

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{if and( $attribute.has_content, $attribute.content )}
<div class="block">
    <img src={$attribute.content|ezpackage( thumbnail )|ezroot} alt="{$attribute.data_text|wash}" />
</div>
{/if}
<div class="block">
{$attribute.data_text|wash}
</div>
```

Das ausgelieferte Template, das ihn bearbeitet (`attribute_edit_gui`), `design/standard/templates/content/datatype/edit/ezpackage.tpl` (die ersten 25 Zeilen):

```tpl
{* DO NOT EDIT THIS FILE! Use an override template instead. *}
{default attribute_base=ContentObjectAttribute}
{let package_attr_name=$attribute.data_text
     package_list=fetch( package, list,
                         hash( filter_array, array( array( type, $attribute.contentclass_attribute.data_text1 ) ) ) )}
<div class="block">
<label for="ezpackage_data_text_{$attribute.id}_siteaccess">{'Siteaccess'|i18n( 'design/standard/edit/' )}:</label>
<select id="ezpackage_data_text_{$attribute.id}_siteaccess" name="CurrentSiteAccess">
    <option value="Global">{'Global (override)'|i18n( 'design/standard/edit/' )}</option>
    {section name=SiteAccess loop=ezini('SiteAccessSettings','AvailableSiteAccessList')}
        <option value="{$SiteAccess:item|wash}"
        {foreach $package_list as $Package}
        {if eq( concat( $Package.name, ':', $SiteAccess:item ), $attribute.data_text )}
                selected="selected"
            {set scope=root package_attr_name=$Package.name}
            {break}
        {/if}
        {/foreach}
        >{$:item|wash}</option>
    {/section}
</select>
</div>

<div class="block">
{section name=Package loop=$:package_list}
```

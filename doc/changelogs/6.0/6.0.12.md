# Exponential 6.0.12

Released 2026-02-10. Tag `v6.0.12`.

## Highlights

Templates can ask who a visitor is: seven role and policy operators (`has_role`, `has_policy` and others) and `eZRole::hasPolicy()`. Extensions can carry per-site settings for multi-site hosting, with one shared INI cache. RSS feed and view counter fixes, and the platform bridge no longer starts a session for the `/login` page.

## Added

- Role membership template operators. See [Role and policy checks in templates](../../features/6.0/role-and-policy-template-operators.md). (`2d2271b1d1`)

## Updated

- Updateviewcount stored all statistics on a single node. (`ccd8b3857f`)
- eZRole::hasPolicy(). See [Role and policy checks in templates](../../features/6.0/role-and-policy-template-operators.md). (`e51905eb28`)
- Policy template operators has_policy and has_policy_by_user. See [Role and policy checks in templates](../../features/6.0/role-and-policy-template-operators.md). (`a1e4334b5d`)
- Member_of_* operators renamed to has_* (never released under the old names). See [Role and policy checks in templates](../../features/6.0/role-and-policy-template-operators.md). (`2542972284`)
- Extension siteaccess override directories; shared INI cache directory. See [Per-site settings inside extensions (multi-site hosting)](../../features/6.0/multi-site-ini-overrides.md). (`124186d096`)
- Override directory handling in eZExtension. See [Per-site settings inside extensions (multi-site hosting)](../../features/6.0/multi-site-ini-overrides.md). (`fc1a2f0a91`)
- RSS feed: invalid template syntax in node/view/full. (`51816a093d`)
- Inside a Symfony based platform stack (service container present), `ezpKernelWeb` does not start a session for a `GET` request to `/login`; pure legacy installations are unchanged. (`3bbe53dd29`)

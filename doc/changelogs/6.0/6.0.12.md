# Exponential 6.0.12

Released 2026-02-10. Tag `v6.0.12`.

Read this page if your templates should show things only to some users, or if you host several sites from one
installation.

## In short

Templates can ask who a visitor is: seven role and policy operators (`has_role`, `has_policy` and others) and
`eZRole::hasPolicy()`. Extensions can carry per-site settings for multi-site hosting, with one shared INI cache.
Also: RSS feed and view counter fixes, and the platform bridge no longer starts a session for the `/login` page.

## Upgrading

No action needed. The operators were never released under their earlier `member_of_*` names, so no template needs
to change.

## Added

- Template operators for role membership. See
  [Role and policy checks in templates](../../features/6.0/role-and-policy-template-operators.md). (`2d2271b1d1`)

## Updated

- The template operators `has_policy` and `has_policy_by_user`, and the method `eZRole::hasPolicy()`. See
  [Role and policy checks in templates](../../features/6.0/role-and-policy-template-operators.md). (`a1e4334b5d`,
  `e51905eb28`)
- The `member_of_*` operators are called `has_*`; they were never released under the old names. See
  [Role and policy checks in templates](../../features/6.0/role-and-policy-template-operators.md). (`2542972284`)
- Extensions can carry settings for one siteaccess (override directories per siteaccess), and all sites share one
  INI cache directory. See
  [Per-site settings inside extensions](../../features/6.0/multi-site-ini-overrides.md). (`124186d096`, `fc1a2f0a91`)
- `updateviewcount` stores the statistics of each node; it stored all of them on a single node. (`ccd8b3857f`)
- The RSS feed's `node/view/full` template has valid syntax. (`51816a093d`)
- Inside a Symfony based platform stack (a service container is present), `ezpKernelWeb` does not start a session
  for a `GET` request to `/login`. Pure legacy installations are unchanged. (`3bbe53dd29`)

## Renamed

- The operator class is `eZTemplateRoleOperator`. See
  [Role and policy checks in templates](../../features/6.0/role-and-policy-template-operators.md). (`24a2c9911a`)

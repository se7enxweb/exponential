# Exponential 6.0.8

Released 2025-05-02. Tag `v6.0.8`.

Read this page before you upgrade from 6.0.7: this release needs PHP 8.1 or newer.

## In short

PHP 8.4 support begins, and PHP 7 support ends: Composer requires PHP 8.1 or newer.

## Upgrading

**Sites on PHP 7.4 must stay on 6.0.7.** Move PHP first, then Exponential, in the order described in
[PHP 8 support](../../bc/6.0/php8.md). Check the PHP of the command line and of the web server:

```bash
php -v
```

Expected: a line beginning `PHP 8.` with a minor version of 1 or higher.

## Updated

- Composer requires PHP 8.1 or newer. See [PHP 8 support](../../bc/6.0/php8.md). (`bdbcb503a6`)
- First PHP 8.4 support in the setup wizard and the kernel. See [PHP 8 support](../../bc/6.0/php8.md). (`86abc11907`)
- The `E_STRICT` constant, removed in PHP 8.4, is no longer used. See [PHP 8 support](../../bc/6.0/php8.md).
  (`3bcf09d889`)
- The version number 6.0.8 marks the start of PHP 8 only support. (`e4e664a3d0`)

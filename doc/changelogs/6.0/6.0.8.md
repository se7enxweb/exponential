# Exponential 6.0.8

Released 2025-05-02. Tag `v6.0.8`.

## Highlights

PHP 8.4 support begins, and PHP 7 support ends: Composer requires PHP 8.1 or newer.

## Upgrading

**Upgrade note:** sites on PHP 7.4 must stay on 6.0.7. Read the sequence in [PHP 8 support](../../bc/6.0/php8.md).

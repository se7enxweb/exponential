# Exponential 6.0.2

Released 2024-02-29. Tag `v6.0.2`.

Read this page if you upgrade from 6.0.1 or edit links in the online editor.

## In short

A small release: telephone links in the online editor's link dialog, a site description field in `site.ini`, the
shop admin menu item visible again, and `bccie` and `xrowextract` added to the distribution.

## Upgrading

No action needed.

## Updated

- The link dialog of the online editor accepts telephone links. (`a5068500a9`)
- `site.ini` has a site description field, which newer design templates need. (`5799206eda`)
- `menu.ini` shows the shop item of the admin menu again. (`6095ea4024`)
- `bccie` and `xrowextract` join the extensions that the distribution installs or suggests. See
  [What a new installation comes with](../../features/6.0/default-extension-distribution.md). (`bdb630d524`,
  `2e0067ed11`)

## Not listed above

2 changes of this release bring no separate user benefit: the version bookkeeping and the release tag
(`f58c03154c`). Every change of the release (7 in this range) is in the
[ledger of the root repository](../../history/ledger/exponential-root.md).

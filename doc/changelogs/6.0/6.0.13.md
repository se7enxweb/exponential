# Exponential 6.0.13

Released 2026-04-18. Tag `v6.0.13`.

## Highlights

Security hardening (seven findings fixed), PHP 8.4 deprecations, the test tool-chain moved to PHPUnit 10 and then 13, sixty PHP string functions as template operators, and SQLite fixes (absolute database paths, schema reading).

## Upgrading

**Upgrade note:** custom sort column names must match `[a-zA-Z0-9_.]`, other names are skipped with a debug warning. See [the hardening specification](../../specifications/6.0/security-hardening-6.0.13.md).

## Added

- PHP string functions as template operators; rstring, ristring. See [PHP string functions as template operators](../../features/6.0/string-template-operators.md). (`4220e2ff90`)

## Updated

- SEC-01..06: SQL and shell injection fixes. See [Specification: the 6.0.13 security and stability hardening](../../specifications/6.0/security-hardening-6.0.13.md). (`221caccf31`)
- UND/LOG/NUL/PRG: null and undefined guards. See [Specification: the 6.0.13 security and stability hardening](../../specifications/6.0/security-hardening-6.0.13.md). (`dbb64b1692`)
- PHP 8.4 deprecations. See [Specification: the 6.0.13 security and stability hardening](../../specifications/6.0/security-hardening-6.0.13.md). (`2b98050cc4`)
- SOAP stubs, setup wizard guards, kernel/content null safety. See [Specification: the 6.0.13 security and stability hardening](../../specifications/6.0/security-hardening-6.0.13.md). (`5a4c83fb30`)
- Phpunit requirement raised to avoid a composer security advisory blocking installation. See [PHPUnit 13 support for Exponential 6.0.x — what broke in the jump from 10 → 13, how we fixed it, and the new eZTemplateStringOperator test suite](../../bc/6.0/phpunitv13.md). (`90645c554d`)
- Client calling API: fatal flaw in curl requests. (`0b7ccae3bc`)
- PHPUnit 13 test suite support. See [PHPUnit 13 support for Exponential 6.0.x — what broke in the jump from 10 → 13, how we fixed it, and the new eZTemplateStringOperator test suite](../../bc/6.0/phpunitv13.md). (`daea5d5556`)
- eZSQLite3DB autoload entry; absolute database path support. See [SQLite database support](../../features/6.0/sqlite-database.md). (`cefe8f13a2`)
- Session handler: read() returns an empty string, gc() uses time(). See [PHP 8 support](../../bc/6.0/php8.md). (`6586f6bacc`)
- Session handler: guard eZCurrentAccess. See [PHP 8 support](../../bc/6.0/php8.md). (`06c9f9d430`)
- Recursive mkdir for the SQLite3 database directory. See [SQLite database support](../../features/6.0/sqlite-database.md). (`ae5feaf6a7`)

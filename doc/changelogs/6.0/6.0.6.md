# Exponential 6.0.6

Released 2024-12-17. Tag `v6.0.6`.

Read this page if you use the `admin3` design on phones or tablets, or upgrade from 6.0.5.

## In short

`admin3` is reworked after testing on phones and tablets: a modern collapsible sidebar, menus that stay usable, and
edit forms that stack. Also new: a default 500 error template, a fix for the online editor under the new design, and
`ezupdate` in the distribution.

## Upgrading

No action needed.

## Added

- The reworked responsive admin design `admin3`. See
  [The responsive admin design (admin3)](../../features/6.0/admin3-responsive-admin.md). (`3005038b3a`,
  `da51ca71d4`, `d719150b2d`)
- A default template for the 500 server error page, with example texts for users. (`f3a1d31c38`)

## Updated

- `admin3` fixed and finished in many places; the `/design` menu item is usable again under the new menu. See
  [The responsive admin design (admin3)](../../features/6.0/admin3-responsive-admin.md). (`4a408e672e`,
  `fac956c026`, `e3c7fad09e`, `06afed1d72`, `50ca7535a4`, `9f5ae59c19`, `65f2bad9f8`, `9fb63105ea`, `306878766a`,
  `ae8ca998a1`)
- The online editor (TinyMCE) and the jQuery XML field editor work under the new admin design. (`9e83074b69`)
- The module layer of the kernel changed so that the OwnerChange extension can work. See
  [An extension can replace a kernel module](../../features/6.0/extension-module-override.md). (`9a9ef0c714`)
- The legacy copyright text in the admin footer (`design/admin/templates/page_copyright.tpl`) moved lower on the
  page, and its evaluation message is split up. (`b2c89152de`)
- A PHP 8 fix. See [PHP 8 support](../../bc/6.0/php8.md). (`21d2c6b4f5`)
- The versions in the example SQL data are 6.0.6. (`9849b43dfa`)
- `ezupdate` joins the distribution and `git_manager` is suggested. See
  [What a new installation comes with](../../features/6.0/default-extension-distribution.md). (`bbf4a020fa`,
  `893c186703`)

## Not listed above

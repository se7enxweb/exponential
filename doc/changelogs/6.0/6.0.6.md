# Exponential 6.0.6

Released 2024-12-17. Tag `v6.0.6`.

## Highlights

`admin3` is reworked after testing on phones and tablets: a modern collapsible sidebar, menus that stay usable, edit forms that stack. A default 500 error template, a fix for the online editor under the new design, `ezupdate` in the distribution.

## Added

- Responsive admin3 design. See [The responsive admin design (admin3)](../../features/6.0/admin3-responsive-admin.md). (`3005038b3a`, `da51ca71d4`, `d719150b2d`)
- Default 500 server error template with example user descriptions. (`f3a1d31c38`)

## Updated

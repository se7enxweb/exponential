# Exponential 6.0.4

Released 2024-09-05. Tag `v6.0.4`.

## Highlights

The responsive administration design `admin3` is born, the debug output became responsive, `recaptcha` and `hcaptcha` joined the distribution and `xrowextract` reached 2.4.2.

## Upgrading

Activate the design as described in [The responsive admin design](../../features/6.0/admin3-responsive-admin.md).

## Added

- Responsive admin3 design. See [The responsive admin design (admin3)](../../features/6.0/admin3-responsive-admin.md). (`3352628278`)

## Updated

- Fixes for extensions and the admin3 menu: the compiled `wash` operator (xhtml) casts its input to a string before `htmlspecialchars`, which prevented a fatal in a content browse template of an extension (`914d528a88`), `content/browse.tpl` no longer washes an array or warns about array-to-string conversion when `xrowextract` uses it (`c672ed9e8c`, `dc3db11395`), and the default open/closed state of the admin3 menu is passed correctly to JavaScript (`1a008400ad`, `fff6613bf1`). See [The responsive admin design](../../features/6.0/admin3-responsive-admin.md).
- Extension set installed or suggested by the distribution changed. See [What a new installation comes with: the default extension distribution](../../features/6.0/default-extension-distribution.md). (`f14af0485b`, `585c78527d`, `47b1a9dca9`)
- PHP 8 compatibility. See [PHP 8 support](../../bc/6.0/php8.md). (`937c314191`, `509cf5091d`)
- Debug output made responsive. See [Debug output you can read at a glance and style](../../features/6.0/debug-output-improvements.md). (`fd5b0b772e`)

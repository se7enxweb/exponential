# Exponential 6.0.4

Released 2024-09-05. Tag `v6.0.4`.

Read this page if you want the responsive administration design, or upgrade from 6.0.3.

## In short

The responsive administration design `admin3` is born, the debug output became responsive, `recaptcha` and
`hcaptcha` joined the distribution, and `xrowextract` reached 2.4.2.

## Upgrading

`admin3` is not switched on by itself. Activate it as described in
[The responsive admin design](../../features/6.0/admin3-responsive-admin.md).

## Added

- The responsive admin design `admin3`. See
  [The responsive admin design (admin3)](../../features/6.0/admin3-responsive-admin.md). (`3352628278`)

## Updated

- Fixes for extensions and the `admin3` menu. See
  [The responsive admin design](../../features/6.0/admin3-responsive-admin.md).
  - The compiled `wash` operator (xhtml) turns its input into a string before `htmlspecialchars`. This prevents a
    fatal error in a content browse template of an extension. (`914d528a88`)
  - `content/browse.tpl` no longer washes an array or warns about an array-to-string conversion when `xrowextract`
    uses it. (`c672ed9e8c`, `dc3db11395`)
  - The default open or closed state of the `admin3` menu reaches JavaScript correctly. (`1a008400ad`, `fff6613bf1`)
- The debug output is responsive. See
  [Debug output you can read at a glance and style](../../features/6.0/debug-output-improvements.md). (`fd5b0b772e`)
- PHP 8 compatibility fixes. See [PHP 8 support](../../bc/6.0/php8.md). (`937c314191`, `509cf5091d`)
- `recaptcha` and `hcaptcha` join the distribution and `xrowextract` is raised to 2.4.2. See
  [What a new installation comes with](../../features/6.0/default-extension-distribution.md). (`f14af0485b`,
  `585c78527d`, `47b1a9dca9`)

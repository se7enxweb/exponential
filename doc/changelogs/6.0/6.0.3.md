# Exponential 6.0.3

Released 2024-04-02. Tag `v6.0.3`.

Read this page if you upgrade from 6.0.2, or use the datatype extensions that joined the distribution.

## In short

The content tree root (node 1) can be viewed, jQuery 3.7.1 ships with `ezjscore`, and three datatype extensions
(`enhancedezbinaryfile`, `enhancedselection2`, `birthday`) and `xrowmetadata` joined the distribution.

## Upgrading

No action needed.

## Added

- jQuery 3.7.1 in `ezjscore`. (`838d1908cc`)

## Updated

- `content/view` accepts node id 1, the root of the content tree. (`2ff7a4d5b2`)
- The distribution adds the datatype extensions `enhancedezbinaryfile`, `enhancedselection2` and `birthday`, adds
  `xrowmetadata` with a set version, and suggests `bcurlaliaswithdash`. See
  [What a new installation comes with](../../features/6.0/default-extension-distribution.md). (`6be1b30a6c`,
  `ec2cfbb53a`, `087b319866`, `3fef68a907`, `c03e126486`, `d32beecb86`)

## Not listed above

3 changes of this release bring no separate user benefit: 2 version bookkeeping and 1 merge commit. Every change of
the release (11 in this range) is in the [ledger of the root repository](../../history/ledger/exponential-root.md).

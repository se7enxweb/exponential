# Exponential 6.0.1

Released 2024-01-29. Tag `v6.0.1`.

Read this page if you want to run a site on SQLite, replace a kernel module from an extension, or upgrade from 6.0.0.

## In short

- **SQLite arrives**: a database driver, a schema handler and a choice in the setup wizard, so a site can run from a
  single file.
- **Extensions can replace kernel modules** of the same name.
- The Composer distribution gained the extensions of the 7x family (ezwebin, ezflow, ezdemo, ezodf, ezie,
  ezautosave and more).

## Upgrading

No action needed. SQLite is optional and not the default in this release; MySQL stays the first choice. See
[SQLite database support](../../features/6.0/sqlite-database.md).

## Added

- A SQLite database driver and schema handler in the kernel, registered in `dbschema.ini`, with an example schema,
  example data and a pre-built demo database. See [SQLite database support](../../features/6.0/sqlite-database.md).
  (`6a2e04a54d`, `5d11b34ef7`, `70b815b0d0`, `e4d54e58dc`)
- A `.gitattributes` language hint, so the code hosting platform shows the project as PHP, not JavaScript. No effect
  on a running site. (`6310558dcd`)

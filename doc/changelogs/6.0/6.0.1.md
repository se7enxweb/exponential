# Exponential 6.0.1

Released 2024-01-29. Tag `v6.0.1`.

## Highlights

SQLite arrives: a database driver, a schema handler and a setup wizard choice, so a site can run from a single file. Extensions can now replace kernel modules, and the Composer distribution gained the extensions of the 7x family (ezwebin, ezflow, ezdemo, ezodf, ezie, ezautosave and more).

## Upgrading

SQLite is optional and not the default in this release; MySQL stays the first choice. See [SQLite database support](../../features/6.0/sqlite-database.md).

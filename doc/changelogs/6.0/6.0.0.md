# Exponential 6.0.0

Released 2024-01-01. Tag `v6.0.0`.

## Highlights

The first release of the 7x line. Exponential 6.0.0 takes the last open source legacy code base of the former product forward on current PHP: the setup wizard no longer prints PHP 8 errors, no page of the wizard points to the closed vendor's servers any more, and the installation is done with Composer.

## Upgrading

No schema change is needed from 5.4. Run the update script that only records the new version in the `ezsite_data` table: `update/database/mysql/6.0/dbupdate-5.4.0-6.0.0.sql` for MySQL (it also sets the default storage engine to InnoDB) or `update/database/postgresql/6.0/dbupdate-5.4-to-6.0.sql` for PostgreSQL, for example `mysql -u <user> -p <database> < update/database/mysql/6.0/dbupdate-5.4.0-6.0.0.sql`. See [Chronicle: December 2023](../../history/2023/2023-12.md).

What the scripts contain (verified in the files): the MySQL script is `SET storage_engine=InnoDB;` followed by two `UPDATE ezsite_data` statements that set the rows named `ezpublish-version` to `6.0.0` and `ezpublish-release` to `1`; the PostgreSQL script holds only the two `UPDATE` statements. The row names keep their historic spelling on purpose (they are identifiers). Check the result with `SELECT name, value FROM ezsite_data WHERE name LIKE 'ezpublish-%';`. The `storage_engine` system variable was removed in MySQL 5.7.5 in favour of `default_storage_engine`; if your server rejects the first statement, run only the two `UPDATE` lines (check your server version with `SELECT VERSION();`). A later script, `update/database/mysql/6.0/dbupdate-6.0.0-6.0.15.sql` (and the PostgreSQL twin), exists for the 6.0.15 line.

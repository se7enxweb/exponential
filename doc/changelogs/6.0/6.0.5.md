# Exponential 6.0.5

Released 2024-10-01. Tag `v6.0.5`.

## Highlights

Installation fixes: the 6.0.4 database data installs without a fatal error, the installer can install content with datatypes of extensions, and a module of an incomplete extension no longer ends in a fatal error.

## Updated

- Fatal error installing 6.0.4+ database data. (`b81069a495`)
- Site.ini: kernel level autoload so the installer can install content with extension datatypes. (`210102f739`)
- Prevents a fatal error caused by incomplete module extensions. See [An extension can replace a kernel module](../../features/6.0/extension-module-override.md). (`884f21e963`)
- Extension set installed or suggested by the distribution changed. See [What a new installation comes with: the default extension distribution](../../features/6.0/default-extension-distribution.md). (`d34de29714`)

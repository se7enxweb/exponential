# Exponential 6.0.5

Released 2024-10-01. Tag `v6.0.5`.

Read this page if a 6.0.4 installation failed, or if you install content that uses datatypes of extensions.

## In short

Installation fixes: the 6.0.4 database data installs without a fatal error, the installer can install content with
datatypes of extensions, and a module of an incomplete extension no longer ends in a fatal error.

## Upgrading

No action needed.

## Updated

- The database data of 6.0.4 and later installs without a fatal error. (`b81069a495`)
- `site.ini` turns on the kernel level autoload, so the installer can install content with datatypes of extensions.
  (`210102f739`)
- A module of an incomplete extension no longer ends in a fatal error. See
  [An extension can replace a kernel module](../../features/6.0/extension-module-override.md). (`884f21e963`)
- The extensions that the distribution installs or suggests changed. See
  [What a new installation comes with](../../features/6.0/default-extension-distribution.md). (`d34de29714`)

## Not listed above

2 changes of this release bring no separate user benefit: both are version bookkeeping. Every change of the release
(6 in this range) is in the [ledger of the root repository](../../history/ledger/exponential-root.md).

# Exponential 6.0.15

The 6.0.15 line follows v6.0.14 (2026-06-07). No release tag v6.0.15 existed on 2026-10-02: the entries below are
what the line contains on that date. This file covers 2026-10-01 and 2026-10-02 in detail; the earlier months of
the line (June to September) are told on the [monthly chronicle pages](../../history/2026/) and listed
change by change in the [ledger of the root repository](../../history/ledger/exponential-root.md).

Every entry links to the page that explains it. Upgrade checklist for these two days:
[behaviour-changes-2026-10.md](../../bc/6.0/behaviour-changes-2026-10.md).

## Added

- Audit trail: hash-chained, signed, searchable record of sign-ins, content, settings, commerce and deploys, with
  the `exp:audit` command, the Audit tab and console, sinks (syslog, journald, signed webhook, mail), alert rules,
  archives in five formats and the import of the 4.x logs; on by default.
  [feature](../../features/6.0/audit-trail.md), [specification](../../specifications/6.0/audit-event-model.md),
  [guide](../../bc/6.0/audit.md).
- Content jobs: large remove, copy, move, hide, section, state and location operations as resumable background
  jobs, `content/job/<id>`, `content/jobs`, `./console exp:expcontentjob`, the `contentjobs` cronjob part and
  `[ContentJobSettings]`. [feature](../../features/6.0/content-jobs.md), [guide](../../bc/6.0/content-jobs.md).
- `exp:ini`, a settings editor that changes INI files line by line in every scope.
  [feature](../../features/6.0/exp-ini-command.md), [guide](../../bc/6.0/console-exp-ini.md).
- The Exp Debug bar: tabs, live summary, settings with presets and undo, cache controls, minimise.
  [feature](../../features/6.0/exp-debug-bar.md), [guide](../../bc/6.0/debug-bar.md).
- Sub-items Table options: 129 registered columns, attribute columns, presets, CSV export, columns by INI and PHP
  or template. [feature](../../features/6.0/subitems-table-options.md), [guide](../../bc/6.0/subitems-table-options.md).
- Request rules (`settings/requestrules.ini`, `bin/php/ezrequestrules.php`) and the policy
  `content/view_system_url`. [feature](../../features/6.0/request-rules.md),
  [guide](../../bc/6.0/view_full_security.md).
- expservices: about 1,100 remote services over ezjscore, personal API tokens, `expfeed::runImport`, the
  `expeditor` services and two portal front ends.
  [feature](../../features/6.0/remote-services-expservices.md), [specification](../../specifications/6.0/expservices.md),
  [guide](../../bc/6.0/backend_ezjscore_services.md).
- The online editor on TinyMCE 8.9.2 as an opt-in second engine, with ezoe dialogs for embed, links, custom tags,
  literal tags, tables and general tags, an engine registry, `/ezoe/engine` and browser tests.
  [feature](../../features/6.0/online-editor-tinymce8.md), [guide](../../bc/6.0/ezoe-tinymce8.md).
- The admin4 design, light and dark. [feature](../../features/6.0/admin4-design.md).
- The editor siteaccess and design, installed by the setup wizard, with `EditorAccess`, `EditorAccessPort` and
  `EditorAccessHostname` in `kickstart.ini`; a new look for the setup wizard.
  [feature](../../features/6.0/setup-wizard-and-editor-siteaccess.md).
- `HiddenTabs[]` in `menu.ini [TopAdminMenu]` and `admininterface.ini [WindowControlsSettings]`.
  [feature](../../features/6.0/hidden-admin-tabs.md).
- A page for missing Composer libraries that repairs the installation from the browser, with `exprepair.php`.
  [feature](../../features/6.0/repair-from-the-browser.md), [guide](../../bc/6.0/repair.md).
- `Exponential\Runnable` base classes (`Runnable`, `Command`, `CronjobPart`, `ModuleView`), events around every
  command, cronjob part and view, `[RunnableSettings]`, shared services (trash, sessions, drafts).
  [specification](../../specifications/6.0/runnable-commands-cronjobs-views.md),
  [guide](../../bc/6.0/cli_cronjob_view_abstractions.md).
- Every column of the order list sorts it. [feature](../../features/6.0/order-list-sorting.md).
- The trash records who trashed each item and from where. [feature](../../features/6.0/trash-who-and-where.md).
- A queue for SQLite writers: a transaction waits at its start for the writers ahead of it, up to
  `[DatabaseSettings] SQLiteTransactionWait` seconds (default 60).
  [bc](../../bc/6.0/sqlite-transactions.md).
- An opcode cache profile for comparing engines, off unless `var/tmp/opcache_profile.on` exists.
- English and German words for the debug bar, the audit console, content jobs, setup/rad and about 500 other
  strings that showed up untranslated.

## Updated

- jQuery 4.0.0, jQuery Migrate 4.0.2 and jQuery UI 1.14.2 in ezjscore 1.4.0; the admin runs on jQuery 4 and
  Exponential UI. [feature](../../features/6.0/jquery4-and-yui-removal.md).
- The SQL query cache knows Oracle's statements (ezoracle 2.3.2).
  [specification](../../specifications/6.0/database-drivers-sqlite-oracle.md).
- The static cache refreshes a publish's pages once each, in parallel
  (`staticcache.ini [CacheSettings] FetchConcurrency`, default 8); 4975 ms became about 500 ms in the measured case.
  [feature](../../features/6.0/static-cache-generator.md).
- Velocity keeps the kernel's regenerated cache files in the opcode cache (`file_update_protection` 0 for the
  server): a rendered page costs about what it does under PHP-FPM (the cache served 2.7% of includes before, PHP-FPM
  97%; 644 ms against 166 ms of CPU).
- The admin dashboard, menus and top tabs show a link only to a user who can open it.
  [bc](../../bc/6.0/behaviour-changes-2026-10.md).
- The online editor's upload checks the file type on the server; poll votes, form submissions and the VAT country
  choice need `content/read`.
- `exp:velocity deploy` always clears the design_base cache and, with `--packer`, the ezjscore packer cache.
- The admin header search popup works in both copies; the Store sidebar lists orders and products first; long
  names in the side columns wrap; the page-not-found error names the missing page; the debug report remembers
  whether it is open.
- Classic grey administration design: Exponential logo, collapsing and resizing left menu, Layouts pages in its look;
  every logo image of the kernel designs shows the Exponential logo; the debug output is headed "Exp Debug".
- Every copyright notice names 1998 - 2026 7x & Exponential Foundation first.
- Kernel commands, cronjob parts and module views are classes with unchanged entry points; every command shows a
  description in `bin/php/console list`.
- Trash "Empty" purges in batches like the command; "Remove timed out sessions" removes the baskets; the
  `clusterpurge` part uses 30 days; a copy of an object with an image owns its image files.
- Fix: SQLite "database is locked" under concurrent writes; SQLite transactions queue for the write lock;
  `subString()` without a length; the asynchronous publisher shares no connection with its fork and no longer
  stops with a type error on PHP 8; the template path comments of a request no longer read another siteaccess's
  override list.
- Fix: PHP 8.5 notices on Oracle (preferences, class attribute categories, `ezpExtension::getInfo`, the template
  compiler, `eZHTTPTool::redirect()`, the INI setting datatype, `ristring`, `{if}`), `E_STRICT` in the tree menu
  and REST front controllers, recurring warnings in the logs.
- Fix: removing a draft removes every image file of that draft; removing a media attribute keeps a file another
  row names; removing a subtree that holds every location of an object removes the object; a node's
  `path_identification_string` is rewritten from the stored value; removing a VAT rule no longer stops with a
  fatal error; the PDF export of a content node no longer answers 500.
- Fix: the CSS packer keeps the space before a colon in selectors; the Velocity warm-up never takes the setup
  wizard's lease.
- Required extension releases (see below).

## Removed

- YUI from the admin, admin3, admin4 and standard designs and from the bundled ezjscore 1.5.0: the YUI libraries,
  `ezjsc::yui2`, `ezjsc::yui3`, `ezjsc::yui3io` and their settings; the YUI 2 calendar script of the standard
  design. [guide](../../bc/6.0/yui-removal.md).

## Renamed

- explayouts 1.4.10: the component blocks are `exp_component_<type>` and block links name their node by its remote
  id; two upgrade scripts rename stored blocks and links. The media theme 1.5.29 and expsite_data_media 1.0.6 follow.
- The debug report is now headed and named "Exp Debug" (the bar).

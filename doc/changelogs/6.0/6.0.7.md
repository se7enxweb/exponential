# Exponential 6.0.7

Released 2025-02-01. Tag `v6.0.7`.

Read this page if you upgrade from 6.0.6. It is also the last release for sites that must stay on PHP 7.4.

## In short

Sub-items can be copied with **Copy selected**. The debug output tells which switch enabled it and can be styled.
The package server moved to the brand domain (the old address redirects). A series of PHP 8 and PostgreSQL warnings
are gone.

## Upgrading

No action needed. See [Copy selected subitems](../../features/6.0/subitems-copy-selected.md) and
[Debug output improvements](../../features/6.0/debug-output-improvements.md).

## Added

- **More actions > Copy selected** copies the selected sub-items, with their subtrees, to an existing node. See
  [Copy selected subitems](../../features/6.0/subitems-copy-selected.md). (`b492af16ad`)

## Updated

- The debug heading says which kind of debug output is enabled. See
  [Debug output you can read at a glance and style](../../features/6.0/debug-output-improvements.md). (`ba1df7cd15`)
- The debug output is wrapped in `div` elements with ids, so a design can style and order the parts. See
  [Debug output you can read at a glance and style](../../features/6.0/debug-output-improvements.md). (`81996fc6dd`)
- The package server addresses move to the new brand domain; the old address keeps working. See
  [The product is called Exponential](../../features/6.0/rebranding-to-exponential.md). (`5fb85b97f0`)
- Upload errors name the file, which helps to find upload problems. (`306bb8948b`)
- The upload dialog of the object relations window opens in the right place. (`98e1d61ebc`)
- The ordering, roles and policies tabs work in the default admin design. (`a87ec544a4`, `4e488afa31`)
- No warning when a file that is already gone is removed again. (`811ace1fac`)
- No PHP 8 warning from the template `for` loop. See [PHP 8 support](../../bc/6.0/php8.md). (`7a210b0baa`)
- The star rating extension works on PHP 8 and is prepared for PHP 9. See [PHP 8 support](../../bc/6.0/php8.md).
  (`eb9079bcb1`)
- Updates of the PostgreSQL library stop a flood of debug warnings. (`0ae1746566`)

## Not listed above

4 changes of this release bring no separate user benefit: 1 documentation, 1 tooling and repository and 2 version
bookkeeping commits. Every change of the release (16 in this range) is in the
[ledger of the root repository](../../history/ledger/exponential-root.md).

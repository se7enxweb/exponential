# Exponential 6.0.7

Released 2025-02-01. Tag `v6.0.7`.

## Highlights

Sub items can be copied with **Copy selected**, the debug output tells which switch enabled it and can be styled, the package server moved to the brand domain (the old address redirects), and a series of PHP 8 and PostgreSQL warnings are gone.

## Upgrading

No action needed. See [Copy selected subitems](../../features/6.0/subitems-copy-selected.md) and [Debug output improvements](../../features/6.0/debug-output-improvements.md).

## Added

- More actions: Copy selected subtree(s) to an existing node. See [Copy selected subitems](../../features/6.0/subitems-copy-selected.md). (`b492af16ad`)

## Updated

- Object relations modal: initial position of the upload dialog. (`98e1d61ebc`)
- Package server URLs move to the new brand domain; the old URL keeps working. See [The product is called Exponential](../../features/6.0/rebranding-to-exponential.md). (`5fb85b97f0`)
- Upload errors name the file, which helps to debug upload problems. (`306bb8948b`)
- Debug heading says which kind of debug is enabled. See [Debug output you can read at a glance and style](../../features/6.0/debug-output-improvements.md). (`ba1df7cd15`)
- Warning when unlinking an already removed file. (`811ace1fac`)
- PHP 8 warning on the template for loop. See [PHP 8 support](../../bc/6.0/php8.md). (`7a210b0baa`)
- PHP 8/9 compatibility of the star rating extension. See [PHP 8 support](../../bc/6.0/php8.md). (`eb9079bcb1`)
- PostgreSQL library updates prevent a flood of debug warnings. (`0ae1746566`)
- Debug output wrapped in divs with ids so a design can style and order them. See [Debug output you can read at a glance and style](../../features/6.0/debug-output-improvements.md). (`81996fc6dd`)
- Admin: ordering, roles and policies tabs were not functional in the default admin design. (`a87ec544a4`)
- Admin: ordering, roles and policies tabs fix (second branch copy). (`4e488afa31`)

# Exponential 6.0.14

Released 2026-06-07. Tag `v6.0.14`.

## Highlights

MongoDB 8 as a database next to MySQL, PostgreSQL and SQLite, with the compatibility layer, setup wizard support, an index script and conversion helpers. The default installation moves to package version 6.0.14, and the release file list for the upgrade check was regenerated.

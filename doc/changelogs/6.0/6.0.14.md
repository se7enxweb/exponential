# Exponential 6.0.14

Released 2026-06-07. Tag `v6.0.14`.

Read this page if you want to run on MongoDB, use the upgrade file check, or upgrade from 6.0.13.

## In short

MongoDB 8 is a database next to MySQL, PostgreSQL and SQLite, with a compatibility layer, setup wizard support, an
index script and conversion helpers. The default installation moves to package version 6.0.14, and the release file
list for the upgrade check is regenerated.

## Upgrading

No action needed for MySQL, PostgreSQL and SQLite sites. Before you choose MongoDB, read what works and the known
limits in [MongoDB as the database](../../features/6.0/mongodb-database-support.md).

## Added

- `bin/shell/generatefilelist.sh` and `share/filelist.md5`, the release file list that the upgrade check compares
  against. See [File consistency check](../../features/6.0/file-consistency-check.md). (`bd11387b68`)

## Updated

- MongoDB 8: a database adapter and a kernel compatibility layer, a general `WHERE` parser, copy, move and add
  location, integer casts in `WHERE` and `SELECT` in `arrayQuery`, the autoload order of `expMongoDB` and
  `expMongoSchema`, and the settings that load its schema handler. See
  [MongoDB as the database](../../features/6.0/mongodb-database-support.md). (`af5761fdd8`, `6a192392e9`,
  `c72a94f69e`, `bd81c3646f`, `b5a73f285f`)
- The setup wizard has a database name field, to authenticate against a specific database. See
  [MongoDB as the database](../../features/6.0/mongodb-database-support.md). (`78bf407ed5`)
- SQLite and PostgreSQL get portable SQL instead of engine-only branches. See
  [MongoDB as the database](../../features/6.0/mongodb-database-support.md). (`e0d617f28e`)
- Setup installs MySQL on shared hosting without root access, and keeps MongoDB-only code out of the SQL paths.
  (`93cdd0cf47`)
- The PostgreSQL setup wizard can be run again on an existing database. (`7773850ade`)
- The SQLite schema reader uses the `PRAGMA` API in `fetchTableFields` and `fetchTableIndexes`. See
  [SQLite database support](../../features/6.0/sqlite-database.md). (`af62dcf3f6`)
- `generatefilelist.sh` has a working `--include` option, and the file list holds the hashes of 6.0.14. See
  [File consistency check](../../features/6.0/file-consistency-check.md). (`365c121e7e`, `4e0b21ae2d`,
  `9b9c5bafcb`)
- Default installations use package version 6.0.14 instead of 6.0.10. (`46540dc84e`)
- No crash from `implode(null)`, and the `role_limitations` key is right in the user cache. (`eea23b654a`)
- Admin: `.length` replaces the deprecated jQuery `.size()`, `js_class_languages` is set in the node full view, and
  `browse.tpl` prints persistent data values of any type. (`6e1167795c`, `95f2c1af8d`, `1d74b95640`)
- The diff engine has better types. See [PHP 8 support](../../bc/6.0/php8.md). (`3684e364f2`)
- The standard design shows the Exponential logo, and the copyright reads 2025 - 2026. See
  [The product is called Exponential](../../features/6.0/rebranding-to-exponential.md). (`d8fbef61bd`, `ab2811ce2c`)

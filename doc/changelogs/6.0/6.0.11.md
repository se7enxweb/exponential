# Exponential 6.0.11

Released 2025-12-30. Tag `v6.0.11`.

## Highlights

PHP 8.1 and PHP 8.5 are covered: return type attributes, dynamic properties, nullable types and Zeta Components that support 8.5. A default `robots.txt`, notification mail sent to the To field instead of Bcc, and a fix for the view count cronjob.

## Added

- Default robots.txt. See [A useful robots.txt out of the box](../../features/6.0/robots-txt.md). (`f93362f6b4`)

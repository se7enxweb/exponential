# Exponential 6.0.10

Released 2025-08-28. Tag `v6.0.10`.

Read this page if you upgrade from 6.0.9 and have your own templates, translations or overrides that show the
product name.

## In short

The product is called **Exponential**: texts, logos, package names, translations and the package server follow.
Also new: a quick select of the current node in the browse dialog, and `sevenx_themes_simple` in the distribution.

## Upgrading

Identifiers did not change: `eZ...` classes, paths and tables keep their names. Check your own overrides for the old
product name. See [The product is called Exponential](../../features/6.0/rebranding-to-exponential.md).

## Added

- The browse dialog (`content/browse`) offers a quick select of the current node, as an `admin3` template override.
  See [The responsive admin design (admin3)](../../features/6.0/admin3-responsive-admin.md). (`5c82f7a451`)

## Updated

- The product name changed in the texts of `bin`, `doc`, the designs and the translations (332 files), and in the
  default templates, URLs, documentation links and setup wizard. See
  [The product is called Exponential](../../features/6.0/rebranding-to-exponential.md). (`837c7b835d`,
  `0f325632c0`, `195d0cef11`, `2775315493`, `4e2891e4fb`, `c26d609a3c`)
- The settings files and the package server address carry the new name. See
  [The product is called Exponential](../../features/6.0/rebranding-to-exponential.md). (`5d3f294bee`)
- The new logo: in the logo sprite, on the admin login, with its image and position styles, and in the copyright.
  See [The product is called Exponential](../../features/6.0/rebranding-to-exponential.md). (`e3367a7392`,
  `30e033d7ab`, `c5d87c4116`)
- `sevenx_themes_simple` 1.0.4 is required; its `page_footer.tpl` is restructured so the "Powered by" line is easy
  to hide. See [The product is called Exponential](../../features/6.0/rebranding-to-exponential.md). (`fbf356e91d`)
- The debug output improvements are finished. See
  [Debug output you can read at a glance and style](../../features/6.0/debug-output-improvements.md). (`85d8697fda`)
- The error log of image alias generation names the requested address. (`68c20634be`)
- `composer.json` carries the stand-alone installation setting. (`1887ab8a0a`)
- The extensions that the distribution installs or suggests changed. See
  [What a new installation comes with](../../features/6.0/default-extension-distribution.md). (`149d88dcfa`,
  `a88d0acd39`, `200c3b0c0a`, `a6f01e984e`)

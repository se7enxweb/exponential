# Exponential 6.0.10

Released 2025-08-28. Tag `v6.0.10`.

## Highlights

The product is called **Exponential**: text, logos, package names, translations and the package server follow. A quick select of the current node in the browse dialog and `sevenx_themes_simple` in the distribution.

## Upgrading

**Upgrade note:** identifiers (`eZ...` classes, paths, tables) did not change. Check your own overrides for the old product name, see [The product is called Exponential](../../features/6.0/rebranding-to-exponential.md).

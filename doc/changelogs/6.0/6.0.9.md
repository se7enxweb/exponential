# Exponential 6.0.9

Released 2025-06-10. Tag `v6.0.9`.

Read this page if you run PostgreSQL, or want REST access to content.

## In short

PostgreSQL installations no longer fail on warnings or schema errors, `ezprestapi` (REST create, read, update and
delete for content) joined the distribution, and the README documents the supported PHP range.

## Upgrading

No action needed.

## Updated

- The PostgreSQL schema handler installs without warnings or errors. (`cfe35ff470`)
- `ezprestapi` joins the distribution. See
  [What a new installation comes with](../../features/6.0/default-extension-distribution.md). (`65920d0d6c`)

## Not listed above

9 changes of this release bring no separate user benefit: 6 documentation (the README now states the supported PHP
range), 2 version bookkeeping and 1 merge commit. Every change of the release (11 in this range) is in the
[ledger of the root repository](../../history/ledger/exponential-root.md).

# Exponential documentation

The documentation of Exponential is organized by language. Each language has a directory of its own below `doc/`.
A translation may translate its file names; its `.paths.json` names the English page each translated file belongs to:

| Language | Directory | Start here |
|----------|-----------|------------|
| English (the original) | [`doc/eng-us/`](eng-us/) | [Installation](eng-us/INSTALL.md), [guides](eng-us/guides/README.md), [help](eng-us/help/README.md) |
| German (Deutsch) | [`doc/ger-de/`](ger-de/) | [Installation](ger-de/installation/01-einfuehrung.md), [Anleitungen](ger-de/anleitungen/README.md), [Hilfe](ger-de/hilfe/README.md); being translated, until a page is translated the English page is shown |

Not translated, and therefore not in a language directory:

- [`doc/changelogs/`](changelogs/README.md): the changelog of every release.

In the administration, the help center (Help in the top bar) shows each page in the language of the interface, and
the English page where no translation exists yet. How translations are organized, and how a translator adds one:
[Translated documentation](eng-us/bc/6.0/translated-documentation.md).

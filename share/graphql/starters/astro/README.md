# __EXP_SITE__: a static site with Astro

Generated by `./console exp:graphql:starter --kit=astro` from the GraphQL API of an Exponential site
(`__EXP_ENDPOINT__`, schema `__EXP_SCHEMA_HASH__`).

```bash
npm install
npm run build        # dist/: one HTML file per page
npm run preview
```

- `.env`: the end point, an optional personal API key (scope `graphql:read`) and `EXP_BUILD_DEPTH`, how deep the
  build follows the content tree from the root.
- `src/lib/queries.ts`: the queries, generated from the site's schema (`MENU`, `NODE`, `BY_CLASS`);
  `graphql/*.graphql` holds the same queries for `./console exp:graphql:persist graphql/ --apply`.
- `src/pages/[...path].astro`: a page per URL alias; `src/components/Field.astro`: images, rich text, relations.

Build again after content changed, for example from a webhook or a nightly job. The queries run at build time, so
the site needs no CORS setting.

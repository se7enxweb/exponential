# __EXP_SITE__: a front end in plain HTML and JavaScript

Generated by `./console exp:graphql:starter --kit=html` from the GraphQL API of an Exponential site
(`__EXP_ENDPOINT__`, schema `__EXP_SCHEMA_HASH__`). No build step: serve the directory and open it.

```bash
python3 -m http.server 8000      # or any web server; then http://localhost:8000/
```

- `config.js`: the end point, and an optional personal API key with the scope `graphql:read`.
- `queries.js`: the queries, generated from the site's schema: `MENU`, `NODE` (a page by its URL alias) and `BY_CLASS`
  (every field of each content class). `graphql/*.graphql` holds the same queries for
  `./console exp:graphql:persist graphql/ --apply`.
- `app.js`: the menu, a page per URL alias (`#/about/company`), its fields and its children.

The site must allow this page's origin: `./console exp:graphql:enable --origin=http://localhost:8000 --apply`.

# __EXP_SITE__: a Next.js front end

Generated by `./console exp:graphql:starter --kit=next` from the GraphQL API of an Exponential site
(`__EXP_ENDPOINT__`, schema `__EXP_SCHEMA_HASH__`).

```bash
npm install
npm run dev          # http://localhost:3000/
```

- `.env.local`: the end point and an optional personal API key (scope `graphql:read`), read on the server only.
- `lib/queries.ts`: the queries, generated from the site's schema: `MENU`, `NODE` (a page by its URL alias) and
  `BY_CLASS` (every field of each content class). `graphql/*.graphql` holds the same queries for
  `./console exp:graphql:persist graphql/ --apply`.
- `app/layout.tsx`: the menu (the children of the root). `app/[[...path]]/page.tsx`: every address of the site.
- `components/Field.tsx`: images, rich text, relations, lists and text.

The queries run on the server (React server components), so the site needs no CORS setting for this kit.
Run `exp:graphql:starter` again after a content class changed (`exp:graphql:status` shows the schema hash).

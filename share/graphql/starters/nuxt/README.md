# __EXP_SITE__: a Nuxt front end

Generated by `./console exp:graphql:starter --kit=nuxt` from the GraphQL API of an Exponential site
(`__EXP_ENDPOINT__`, schema `__EXP_SCHEMA_HASH__`).

```bash
npm install
npm run dev          # http://localhost:3000/
npm run generate     # or a static build
```

- `.env`: the end point and an optional personal API key (scope `graphql:read`), server-side runtime settings.
- `server/api/graphql.post.ts`: the app's own route to the site; it adds the key, so the browser never sees it and the
  site needs no CORS setting.
- `utils/queries.ts`: the queries, generated from the site's schema: `MENU`, `NODE` and `BY_CLASS`; `graphql/*.graphql`
  holds the same queries for `./console exp:graphql:persist graphql/ --apply`.
- `app.vue` (the menu), `pages/[...path].vue` (every address of the site), `components/Field.vue`.

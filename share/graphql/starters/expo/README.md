# __EXP_SITE__: an app with React Native and Expo

Generated by `./console exp:graphql:starter --kit=expo` from the GraphQL API of an Exponential site
(`__EXP_ENDPOINT__`, schema `__EXP_SCHEMA_HASH__`).

```bash
npm install
npx expo start       # then a for Android, i for iOS, w for the web
```

- `.env`: the end point (and, if the content is not public, a key with `graphql:read` only: an app is a public client).
- `lib/queries.ts`: the queries, generated from the site's schema (`MENU`, `NODE`, `BY_CLASS`); `graphql/*.graphql`
  holds the same queries for `./console exp:graphql:persist graphql/ --apply`.
- `App.tsx`: the menu, a screen per page with its fields (images, rich text through `react-native-render-html`,
  relations) and its children.

An app calls the API directly, not from a browser, so CORS does not apply; the web build (`w`) needs the site to allow
its origin (`./console exp:graphql:enable --origin=http://localhost:8081 --apply`).

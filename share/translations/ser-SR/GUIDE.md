# Serbian, Latin script (ser-SR): translation guide

This catalogue is not translated by hand. It is the Cyrillic catalogue `srp-RS` transliterated letter for letter
(Љ→Lj, Њ→Nj, Џ→Dž, Ђ→Đ, Ћ→Ć, Ч→Č, Ш→Š, Ж→Ž); placeholders, tags, product names and code stay as they are.
All rules and the glossary are in [../srp-RS/GUIDE.md](../srp-RS/GUIDE.md). Correct a text in `srp-RS` and derive
this catalogue again; never edit it alone.

# Somali (som-SO): translation guide

The rules common to every language are in [TRANSLATING.md](../TRANSLATING.md). The catalogues were translated and checked in October 2026; review by native speakers is welcome.

## Rules

Standard Somali in Latin script. Address the user politely. Buttons: imperative (Kaydi, Jooji, Tirtir). Quotes “”. Keep Western digits and every placeholder as in the source. Use the established terms of Microsoft/Google localisation for this language; keep product names in Latin letters.

Keep every placeholder (%name, %1, %name%), HTML tag, entity and line break exactly. Do not translate code, file names, product names.

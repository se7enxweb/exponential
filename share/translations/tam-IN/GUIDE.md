# Tamil (tam-IN): translation guide

The rules common to every language are in [TRANSLATING.md](../TRANSLATING.md). The catalogues were translated and checked in October 2026; review by native speakers is welcome.

## Rules

Tamil script (India). Address the user politely (நீங்கள், polite -ங்கள் forms in sentences). Buttons: short imperative as in Microsoft Tamil (சேமி, ரத்துசெய், நீக்கு). Quotes “”. Keep Western digits and every placeholder as in the source. Use the established terms of Microsoft/Google localisation for this language; keep product names in Latin letters.

Keep every placeholder (%name, %1, %name%), HTML tag, entity and line break exactly. Do not translate code, file names, product names.

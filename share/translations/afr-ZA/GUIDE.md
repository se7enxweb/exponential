# Afrikaans (afr-ZA): translation guide

The rules common to every language are in [TRANSLATING.md](../TRANSLATING.md). The catalogues were translated and cross-checked in October 2026; review by native speakers is welcome.

## Rules

Afrikaans UI (South Africa). Address the user with "u" (formal) in sentences only where needed, prefer impersonal style. Buttons: imperative/infinitive verb (Stoor, Kanselleer, Skrap, Wysig). Standard Afrikaans spelling (AWS), never Dutch forms. Quotes “”.

Keep every placeholder (%name, %1, %name%), HTML tag, entity and line break exactly. Do not translate code, file names, product names.

# Kannada (kan-IN): translation guide

The rules common to every language are in [TRANSLATING.md](../TRANSLATING.md). The catalogues were translated and checked in October 2026; review by native speakers is welcome.

## Rules

Kannada script. Address the user with polite "ನೀವು". Buttons: imperative as in Microsoft Kannada (ಉಳಿಸು, ರದ್ದುಮಾಡು, ಅಳಿಸು). Quotes “”. Keep Western digits and every placeholder as in the source. Use the established terms of Microsoft/Google localisation for this language; keep product names in Latin letters.

Keep every placeholder (%name, %1, %name%), HTML tag, entity and line break exactly. Do not translate code, file names, product names.
